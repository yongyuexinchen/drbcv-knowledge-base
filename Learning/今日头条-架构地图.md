### 3.2 注册流程（时序图）

```mermaid
sequenceDiagram
    participant F as 前端
    participant R as 路由
    participant C as Crud
    participant S as Security
    participant DB as MySQL

    F->>R: POST /api/user/register {username, password}
    R->>C: get_user_by_username()
    C->>DB: SELECT * FROM user WHERE username=?
    DB-->>C: 不存在
    R->>C: create_user()
    C->>S: get_hash_password(明文密码)
    S-->>C: 乱码字符串
    C->>DB: INSERT INTO user (username, 乱码)
    R->>C: create_token(user_id) 🔴JWT改造点①
    C-->>R: token
    R-->>F: {code:200, data:{token, userInfo}}
```

### 3.3 登录流程（时序图）

```mermaid
sequenceDiagram
    participant F as 前端
    participant R as 路由
    participant C as Crud
    participant S as Security
    participant DB as MySQL

    F->>R: POST /api/user/login {username, password}
    R->>C: authenticate_user()
    C->>DB: SELECT * FROM user WHERE username=?
    DB-->>C: 找到张三
    C->>S: verify_password(输入密码, 数据库乱码)
    S-->>C: True/False
    alt 密码错误
        C-->>R: None
        R-->>F: 401 用户名或密码错误
    else 密码正确
        R->>C: create_token(user.id) 🔴JWT改造点①
        C-->>R: token
        R-->>F: {code:200, data:{token, userInfo}}
    end
```

### 3.4 鉴权流程（带 token 访问）

```mermaid
sequenceDiagram
    participant F as 前端
    participant A as Auth安检员
    participant C as Crud
    participant DB as MySQL
    participant R as 路由

    F->>A: GET /api/user/info<br/>Authorization: Bearer xxx
    A->>A: token = replace("Bearer ","")
    A->>C: get_user_by_token(token) 🔴JWT改造点②
    C->>DB: 查 UserToken 表 + 验证过期
    DB-->>C: 有效
    C-->>A: User 对象
    A-->>R: 放行，传入 user
    R-->>F: {code:200, data:{userInfo}}
```

## JWT 改造对照表（只改两处）

| 位置 | UUID 版（老师） | JWT 版（改造后） |
|------|----------------|-----------------|
| create_token | `str(uuid.uuid4())` + 存 UserToken 表 | `jwt.encode({sub, exp}, SECRET_KEY)` 不存库 |
| get_user_by_token | 查 UserToken 表 → 验过期 → 查 User | `jwt.decode(token, SECRET_KEY)` → 取 sub → 查 User |
| UserToken 表 | 需要 | 可以删掉 |
| 前端 | 零改动 | 零改动 |

**改造原则：接口契约（响应格式 + Authorization 头）不变，前端就安全。**
