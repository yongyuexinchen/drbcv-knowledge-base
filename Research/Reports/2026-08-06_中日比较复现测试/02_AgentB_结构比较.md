## 零、执行摘要（Executive Summary）

**核心判断**: 中日两国在资产泡沫的**生成机制（资产-信贷正反馈）上约 70-80% 同构**，但在**破裂触发方式、破裂后传导机制、以及体系约束条件**上存在本质差异。中国并非在重复日本路径，而是在面对一个**结构约束不同的同一工程问题**——如何消化过度膨胀的资产价格而不引发系统性金融崩溃。中国当前最接近日本 **1991Q4-1992Q1 的相变区间**（区间置信度 65-75%，精确时点映射置信度 30-40% 不主张）。中国走日本式长期停滞路径的概率区间为 **35-50%**，关键变量：①银行体系不良贷款真实消化速度 ②居民消费倾向是否出现"节俭悖论"拐点 ③人民币汇率是否在资本管制下守住不发生预期自我实现式贬值的底线。

## 二、极限还原（Reduction to Limit）

### 日本：还原路径

```
现象: 1990-1991 股市+地产崩盘
  → 机制: 加息刺破 → 资产贬值 → 抵押物缩水 → 银行惜贷 → 企业（土地-股票交叉持有）资产负债表恶化 → 企业"债务最小化"而非"利润最大化"（Koo 资产负债表衰退）
    → 结构: 主银行制下的相互持股结构 → 银行不良与企业资不抵债双向绑定，一损俱损
      → 矛盾: 泡沫膨胀期"抵押品-信贷"正反馈 vs 破裂期"抵押品-信贷"负反馈（Fisher 债务通缩）——同一机制的反面
        → 底层约束: ① 独立央行货币政策是唯一总需求管理工具（财政受限于政治僵局）② 无资本管制 → 不能通过汇率贬值输出通缩 ③ 银行是私人的 → 政府注资有政治阻力 → 延迟出清
```

**终止解释**: 三个底层约束共同锁定了日本的"延迟出清"路径——无法贬值、无法快速注资、无法绕过央行加息→降息的时间窗口（等 BoJ 1991 年降息时，资产负债表已经恶化到企业不再对低利率敏感的"流动性陷阱"阶段 [L1-3]）。

### 中国：还原路径

```
现象: 2021 年恒大违约 → 2021-2025 年房地产销售持续下滑 → 开发商连环爆雷 → 地方政府土地出让金暴跌
  → 机制: 三条红线主动收紧开发商融资 → 高杠杆开发商资金链断裂 → 预售制下的"保交楼"危机 → 购房者信心崩塌 → 销售进一步下滑（负反馈螺旋）→ 但银行端不良可控（展期+AMC+国有银行不破产）
    → 结构: 土地财政三角（地方政府卖地 → 开发商买地建房 → 居民贷款买房）——这是中国版的"资产-信贷"增强回路
      → 矛盾: 地方政府依赖土地出让金（2021 年峰值 8.7 万亿 → 2024 年约 4-5 万亿 `[待验证]`）vs 中央要求"房住不炒"——中央-地方博弈是日本没有的维度
        → 底层约束: ① 资本管制 → 汇率工具可用 ② 国有银行 → 系统性银行危机概率低 ③ 政策工具箱深度大（日本没有的维度）④ BUT 人口约束比日本更紧 ⑤ 外部空间（中美关系）比日本更差
```

**终止解释**: 中国多了一个政策工具维度（国有银行+资本管制+行政手段），但也多了日本没有的约束——人口恶化更快、外部空间更窄。最底层的约束是**政治可行性**：只要社会稳定性未受威胁，政府有能力继续"延后出清"（通过通胀稀释、AMC 剥离、财政赤字），但这个策略有极限——极限在于居民部门何时从"忍受"转为"反抗"（消费断崖/社会事件），这是一个难以精确预测的相变点。

## 三、五大核心问题

### 问题①：泡沫生成机制是否同构（资产-信贷正反馈）？

**判断：核心同构（70-80%），债务主体和制度架构不同。**

两国均遵循经典的"资产-信贷正反馈"增强回路（R1）：

```
资产价格↑ → 抵押物价值↑ → 银行放贷意愿↑ → 信贷扩张 → 资产需求↑ → 资产价格↑ (R1闭合)
```

在日本，这个回路的主体是企业部门——企业以持有土地和股票作为抵押从银行借款再投资土地和股票，形成"土地-银行-企业"的三体正反馈 [L1-3]。日本六大城市商业地价 1985-1990 年上涨 3.4 倍，Nikkei 225 从 1985 年 12,000 点涨至 1989 年末 38,957 点（峰值）。

在中国，这个回路的主体是三部门——地方政府（卖地收入驱动基建和财政支出）、开发商（预售制+影子银行高杠杆扩张）、居民（房贷驱动购房）。房价上涨 → 土地出让金增加 → 地方政府财政改善 → 更多基建投资 → 区域价值提升 → 房价继续上涨（R1_a）；房价上涨 → 开发商利润和融资能力增加 → 更多拿地 → 供给扩张但预期推高 → 房价继续上涨（R1_b）。

**关键差异**：日本的泡沫定价锚是企业和银行之间的相互持股溢价（"股票 unrealized gains"驱动再投资），中国的泡沫定价锚是地方政府财政收入依赖（"土地出让金/GDP 的 8-10%"驱动政策惯性 `[待验证]`）。前者是纯金融正反馈，后者嵌入了财政体制的正反馈——中国的泡沫更难自行逆转，因为逆转意味着地方财政崩溃。

### 问题②：破裂触发对比（日本被动加息 vs 中国主动三条红线）

**判断：本质不同——被动刺破（货币政策滞后性）vs 主动泄压（行政手段先发制人）。**

| 维度 | 日本 | 中国 |
|------|------|------|
| 触发工具 | 货币政策（贴现率加息 5 次：2.5%→3.25%→3.75%→4.25%→5.25%→6.0%，1989.05-1990.08）[L1-9] | 行政监管（三条红线 2020.08 + 两道红线 2021.01 + 预售资金监管 2021+）`[待验证]` |
| 触发逻辑 | BoJ 担忧通胀和资产泡沫，但加息过慢（1987-1989 犹豫），最终加息过猛（1 年内从 2.5%→6.0%）——典型的"too late, too much" [L1-7] | 中央意识到开发商债务不可持续（恒大 3000 亿美元总负债 [L1-10]），主动掐断信贷——"先发制人"但低估连锁反应 |
| 政策主动性 | 被动（BoJ 在政治压力下犹豫，错过了 1987-1988 的软着陆窗口） | 主动（中央主动刺破，但随后政策反复在"稳增长"和"防风险"之间摇摆） |
| 破裂速度 | 快速：加息 6 个月内股市见顶（1989.12 Nikkei 38957），12 个月内地产见顶 [L1-9] | 缓慢：三条红线后 12-24 个月开发商逐个爆雷（恒大 2021.09、融创 2022.05、碧桂园 2023.08 `[待验证]`） |
| 可控性 | 低（货币政策是钝器，一旦启动无法定向——加息同时打击股市、地产、企业投资） | 较高（行政手段是定向手术刀，可选择性松紧——例如 2022.11 "金融十六条"、"三支箭"政策转向支持 `[待验证]`） |

**结构含义**: 日本的加息是全局性的利率冲击——所有以低利率为基础的杠杆交易同时被迫 unwind，形成"资产抛售→抵押物缩水→追加保证金→更多抛售"的协同崩盘。中国的三条红线是局部的信贷窗口指导——定向掐断开发商新增融资，允许银行端继续对居民放贷，理论上可以实现"开发商出清"而不触发全局崩盘。但实践中，开发商违约→预售项目烂尾→购房者断供→银行被迫计提→内生的恐慌螺旋仍然被触发了，只是速度更慢、烈度更低。

### 问题③：破裂后传导（断崖式 vs 泄压式 / 资产负债表衰退 / 银行 / 居民）

**判断：日本是"断崖-瀑布"模型，中国是"泄压-阶梯"模型。**

#### 3a. 日本：断崖式传导（1990-2003）

```
股市崩盘 (1989.12) → 地产崩盘 (1991.04 起)
  → 银行不良贷款爆炸（1992 年官方承认 ~$100B, 实际可能 >$500B）
  → 银行惜贷 (credit crunch) + 企业"债务最小化"（资产负债表衰退，Koo 2008）
  → 企业投资崩溃 → 失业率从 2.1%(1990) 升至 5.4%(2002)
  → 通缩螺旋（CPI 1992-2013 年均 -0.3%）→ 实际债务负担加重（Irving Fisher 债务通缩）
  → 居民消费停滞（实际工资下降，precautionary saving）
  → 银行破产潮（1997-1998 系统性危机：北海道拓殖银行、山一证券、日本长期信用银行）→ 政府被迫大规模注资（1998-1999 ~¥10 万亿 `[待验证]`）
  → 零利率政策 (1999) → 量化宽松 (2001) → 但始终无法摆脱通缩
```

关键传导节点：**银行不良是企业不良的镜像**。日本主银行制下，银行对企业的贷款中有大量以土地和股票为抵押的贷款 → 资产价格暴跌 → 抵押物不足 → 不良贷款暴增 → 银行资本金侵蚀 → 不放贷 → 经济进一步萎缩。这个"企业-银行死亡螺旋"（R2）是日本断崖式传导的核心机制。

#### 3b. 中国：泄压式传导（2021-2026）

```
三条红线 (2020.08) → 开发商融资收紧
  → 恒大违约 (2021.09) → 开发-预售链断裂 → 烂尾楼 → 购房者断供 (2022.07 "停贷潮")
  → 销售暴跌（2021 年峰值 18.2 亿㎡ → 2024 年 ~9-10 亿㎡ `[待验证]`）
  → 开发商连环爆雷（恒大→融创→世茂→碧桂园，2021-2024 `[待验证]`）
  → 土地出让金腰斩（地方政府财政压力）→ 公务员降薪/事业单位收缩
  → 但银行端：不良上升但可控（通过展期、白名单、AMC 收购、政府注资）——国有银行不破产
  → 居民端：财富效应逆转（房价下跌→消费收缩）+ 就业不安全感 → 提前还贷（2023-2024 大规模提前还贷潮 `[待验证]`）
  → 通缩压力：CPI 2023-2024 多月在 0% 附近，PPI 连续负增长
```

关键差异：**中国没有银行破产这个"放大器"**。日本的银行不良直接传导为银行破产 → 信贷全面冻结 → 经济深度休克。中国的银行不良可以通过国有银行的"时间换空间"策略（展期 + 政府注资 + 通胀稀释）逐步消化，类似于 1999-2005 年四大 AMC 剥离 1.4 万亿不良的先例。这意味着中国可以避免日本的"信贷断崖"，但代价是出清时间可能拉长（"泄压"而非"爆破"）。

**资产负债表衰退风险评估**（参考 Richard Koo 框架）：

| Koo 条件 | 日本 | 中国 |
|-----------|------|------|
| 资产价格暴跌后私人部门资不抵债 | ✅ 企业部门大面积技术性破产 | ⚠️ 开发商已大面积资不抵债，但银行不追索（展期）；居民部门整体权益仍为正 `[待验证]` |
| 企业从"利润最大化"转向"债务最小化" | ✅ 1990-2005 持续 15 年 | ⚠️ 已观察到开发商停止拿地（"不扩张"），但制造业和消费企业未见普遍转向 |
| 货币宽松失效（流动性陷阱） | ✅ 1999 零利率后无效 | ⚠️ 降息降准效果递减（企业贷款需求疲弱），但尚未完全失效 |
| 政府必须用财政赤字填补需求缺口 | ✅ 1990-2025 政府债务/GDP 从 60% 升至 260%+ | ⚠️ 2024 年中央+地方显性债务/GDP ~60%，但隐性债务（城投）可能达 50-60% GDP `[待验证]` |

**结论**: 中国处于"资产负债表衰退"的**早期前兆阶段**——部分条件已触发（开发商部门），但尚未扩散到企业和居民部门的普遍行为改变。关键观察变量是居民消费倾向（见 S2）和企业资本开支意愿。

### 问题④：关键差异（资本管制/国有银行/政策工具/居民杠杆/城镇化）

详见 1.3 差异点详表。此处论述每个差异如何改变路径概率：

**D1 资本管制**：这是最关键的路径分化变量。日本在泡沫破裂后无法通过汇率大幅贬值来输出通缩压力（日元反而因贸易顺差和 carry trade 回流而长期偏强）。中国可以通过人民币有序贬值来一定程度上缓解内部通缩（以邻为壑的选项，但受制于"汇率稳定"的政治承诺和美国压力）。更根本的是，资本管制阻止了居民和企业的大规模资本外逃——这是 1997 年亚洲金融危机的核心机制，也是日本泡沫破裂后未发生的情况（日本有贸易顺差对冲）。

**D2 国有银行**：日本的银行破产 → 信贷冻结 → 经济休克。中国国有银行即使技术上资不抵债也不会倒闭（有国家信用兜底），这消除了日本式的"信贷断崖"风险。但代价是：①出清不彻底 → 僵尸企业/银行延续 → 资源错配长期化（类似日本 1990s 的"僵尸企业"问题，但中国可能更严重因为银行不会倒闭）②道德风险累积 → 未来需要更大的"终极买单"。

**D3 政策工具库**：中国拥有日本 1990 年代不具备的工具——资本管制 + 国有银行兜底 + 大规模 AMC 剥离 + 直接行政手段（限购/限售/限价/保交楼）+ 数字人民币精准投放。这意味着中国的"泄压"曲线可以比日本更平缓。

**D4 居民杠杆**：日本居民的债务问题不突出（企业是主力）。中国居民杠杆率 2015-2024 从 39%→64%，虽然绝对值仍低于美国（~75%），但增速极快，且房贷/可支配收入比在一线城市已达 80-100%。这意味着中国面临日本没有的"居民消费挤压"传导链条——房价跌 → 财富缩水 → 消费收缩 → 通缩 → 实际债务负担加重。这条传导链是判断中国会不会"日本化"的核心变量之一。

**D5 城镇化**：日本 1985 年城镇化率 ~77% 已接近饱和，泡沫破裂后没有新增真实住房需求来托底 [L1-3]。中国城镇化率 ~66%，如按每年 0.8-1pp 推进仍约有 10 年空间，这意味着仍有一部分真实住房需求（非投机需求）存在。这个变量为中国的房地产"软着陆"提供了日本不具备的缓冲垫——但前提是城镇化推进不被房地产崩盘打断（而实际上正在被打断：农村人口进城但无力购房，城镇化正在变成"市民化减速"）。

### 问题⑤：相变点判断——中国处于日本时间线哪个位置？

🔴 **铁律声明**: 历史不可直接求导。以下是基于**状态变量比较**（资产价格、信贷条件、政策阶段、市场心理）的相变区间映射，不是精确时点映射。

#### 日本五阶段序列识别

| 阶段 | 日本时间段 | 核心特征 | 可观测信号 |
|------|-----------|---------|-----------|
| Phase I: 泡沫膨胀 | 1986-1989 | 资产价格加速上涨，信贷疯狂扩张，全民投机 | 地价年涨 20%+，Nikkei 年涨 30%+ |
| Phase II: 政策转向 | 1989.05-1990.08 | 货币政策收紧（加息），市场开始分化——股市先崩，地产滞后 | BoJ 加息 5 次，Nikkei 1989.12 见顶 |
| **Phase III: 资产双杀** | **1990.09-1992.03** | **地产跟随股市崩盘，银行不良开始暴露但被低估，政策层仍在争论"软着陆"** | **地价开始下跌，NPL 从 ~$50B 升至 ~$200B，政府仍认为可控** |
| Phase IV: 银行危机 + 通缩锁定 | 1992.04-1998 | NPL 全面爆发 → 银行惜贷 → 企业去杠杆 → 通缩螺旋 | 银行破产（1997 起），GDP 增速降至 ~1%，CPI 转负 |
| Phase V: 零利率/量化宽松 + 长期停滞 | 1999-2013+ | 非常规货币政策 + 财政扩张 + 人口加速老龄化 | ZIRP/QE，政府债务/GDP 突破 200%，GDP 增速 ~0.5% |

#### 中国映射判断

**相变区间判断: 中国最接近日本 Phase III 初期（对应日历时点：1990Q4-1991Q4）**

- **区间映射置信度: 70% (±5pp)** ——基于以下状态变量同步：
  - ✅ 政策已转向（三条红线 = 中国版 BoJ 加息），股市先于地产反映（A 股 2021.02 见顶 vs 日本 1989.12）
  - ✅ 地产价格已开始下跌（二手房价格指数 2023 起加速下行，类似日本 1991 年地价开始下跌 `[待验证]`）
  - ✅ 银行不良开始暴露但政策层口径仍为"可控"（2023-2024 官方 NPL 仍 <2%，但市场估计真实不良可能更高 `[待验证]`）
  - ✅ 第一个系统性冲击事件已发生（恒大 2021.09 = 日本 1990 年某大型企业首次违约）
  - ⚠️ 但大规模银行危机尚未爆发（日本 Phase IV 的标志性事件 1997 银行破产潮尚未在中国出现，且国有银行体制大概率不会出现）
  - ⚠️ 通缩尚未深度锁定（CPI 在 0 附近徘徊但未持续为负，类似日本 1991-1992 的通缩前兆期）

- **精确时点映射置信度: 35% (±10pp)** ——这是明确不主张的。因为：
  1. 中国破裂速度更慢（泄压 vs 断崖）→ 时间线被拉长，无法精确对应
  2. 中国跳过了日本的"银行破产"阶段（国有银行不破产）→ Phase IV 可能完全不同
  3. 约束差异（资本管制/政策工具）改变传导速度 → 时序不可比

**关键不确定性**: 中国是否会进入日本 Phase IV（银行危机 + 通缩锁定）？基于国有银行和资本管制的"保护垫"，概率较低（<30%）。但中国可能进入一个**替代性 Phase IV**——不是银行危机，而是"地方财政危机 + 居民消费长期萎缩 + 缓慢通缩"的混合态。这个状态不同于日本的"急性休克"，但终点可能同样痛苦——类似"温水煮青蛙"式的长期停滞。

## 四、因果回路建模（CLD）

### 4.1 日本：两条增强回路

**R1_JP: 泡沫膨胀回路（1986-1989）**
```
地价/股价↑ → 企业抵押物价值↑ → 银行放贷↑ → 企业投资土地/股票↑ → 地价/股价↑ (R1_JP 闭合)
```
**已断裂**: 1989-1990 BoJ 加息 → 利率上升 → 借贷成本↑ → R1_JP 逆向运转

**R2_JP: 企业-银行死亡螺旋（1990-2003）**
```
资产价格↓ → 企业抵押物价值↓ → 企业技术性破产 → 银行不良贷款↑ → 银行惜贷（credit crunch）→ 企业无法融资 → 抛售资产 → 资产价格↓ (R2_JP 闭合)
```
**增强方向**: 恶性循环，自加强。打破需要：①政府注资银行（1998-1999）②企业债务减免/重组 ③足够的时间消化。

### 4.2 中国：回路正在转型

**R1_CN: 土地财政-房价增强回路（2015-2021）** 🔴 已断裂
```
房价↑ → 土地出让金↑ → 地方政府财政收入↑ → 基建/公共服务↑ → 区域价值↑ → 房价↑ (R1_CN 闭合)
```
断裂原因：三条红线切断了开发商融资 → 开发商停止高价拿地 → 土地出让金暴跌 → R1_CN 逆向运转。

**R2_CN: 房价-消费螺旋（2022-2026，正在形成）**
```
房价↓ → 居民财富效应↓ → 消费倾向↓ → 企业收入↓ → 裁员/降薪 → 居民收入↓ → 购房能力↓ → 房价↓ (R2_CN 闭合)
```
**增强方向**: 恶性循环，与日本 R2 机制不同（日本是企业-银行死亡螺旋，中国是房价-消费-就业螺旋），但破坏力同样强大。当前（2026.08）正处于这个回路的强化阶段。

**B1_CN: 政策对冲调节回路**
```
房价↓ → 政府放松限购/降息/降首付/保交楼 → 购房信心↑ → 销售↑ → 房价企稳 (B1_CN)
```
**调节方向**: 政策逆行调节，试图稳定房价。但目前（2026）B1 力量似乎不足以完全对冲 R2——政策边际效果递减（2023 以来多轮刺激效果有限 `[待验证]`）。

**B2_CN: 国有银行缓冲回路**
```
开发商违约 → 银行不良↑ → 政府注资/AMC收购/展期 → 银行资本充足率维持 → 不破产 → 信贷不冻结 (B2_CN)
```
**调节方向**: B2 是日本的 R2_JP 在中国不成立的根本原因。只要 B2 持续起作用，中国就不会重复日本的"断崖式信贷冻结"。

### 4.3 跨学科传导矩阵

| 层级 | 日本传导 | 中国传导 | 当前状态 |
|------|---------|---------|----------|
| **财务/负债层** | 企业去杠杆 → 银行惜贷 | 开发商违约 → 银行展期/AMC购买 → 地方财政压力 → 隐性债务显性化 | 中国传导更慢但范围更广（地方政府 + 开发商 + 居民三部门） |
| **社会/文化层** | 失业↑ → 终身雇佣制瓦解 → 非正规就业↑ → 不婚率↑ | 青年失业率高企（2023 16-24 岁 ~20% `[待验证]`）→ 躺平文化 → 不婚不育 | 中国比日本泡沫期更严重（青年失业率更高，社会安全网更薄） |
| **实体经济层** | 投资崩溃 → GDP 增速降至 ~1% → 通缩 → 产业竞争力下降 | 房地产投资↓ → GDP 增速从 6%+ 降至 4-5% `[待验证]` → PPI 负增长 → 制造业外迁压力 | 中国 GDP 增速仍高但结构恶化（消费和地产拖累） |
| **资本/财政层** | 政府债务/GDP 从 60% 升至 250%+ | 显性政府债务/GDP ~60%，但隐性债务（城投）可能 ~50-60% GDP `[待验证]` → 路径类似但起点更低 | 中国财政空间理论上更大，但实际上被地方隐性债务消耗 |

## 五、趋同演化判据（Convergence Criteria，🔴 2.6 新范式）

按照 2.6 趋同演化判据三问：

### ① 目的是什么？
**比的是"中国会不会走日本式资产负债表衰退 → 长期停滞路径"**。这是同一个工程问题：在资产泡沫破裂后，一个大型经济体能否避免"债务最小化 → 通缩锁定 → 增长归零"的路径？

✅ 目的成立——有明确比较目标，不是无差别找相似。

### ② 约束是否同构（同一工程问题）？
两国面临的**工程问题同构**：如何消化过度膨胀的资产价格而不引发系统性金融崩溃？

但**约束条件不完全同构**：
- 共同约束：资产-信贷正反馈的破裂动力学、通缩预期自我实现机制（Fisher 债务通缩）、人口老龄化趋势
- 差异约束：资本管制（中国有/日本无）、银行所有制（中国国有/日本私人）、外部环境（中国对抗性/日本融入性）

结论：**部分同构**——工程问题相同，但中国有额外的"工具变量"（国有银行/资本管制/行政手段）可以改变路径动力学。

### ③ 层级是否匹配？
- 国家层级：✅ 匹配（都是 GDP 前 3 的大型经济体）
- 经济政治体制：⚠️ 部分匹配（都是市场经济，但中国多了"党管金融"维度）
- 发展阶段：⚠️ 部分匹配（日本 1980s 已是发达国家，中国 2020s 仍是中高收入国家）

结论：**层级基本匹配**，但"党管金融"这个超结构变量在日本没有对应物。

### 综合判别

**结构比较的预测力评级**: **中等偏强**（⭐⭐⭐⭐☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆☆）

理由：目的明确、层级匹配、工程问题同构，但关键约束差异（国有银行/资本管制）使得日本的精确时序不可简单外推到中国。"趋同"的方向（去杠杆 → 增长放缓）可预测，但"趋同"的速度、烈度和最终形态不可精确预测。标注为**"有约束的趋同演化"**（open fields, 不承诺精确预测）。

## 八、日本化概率区间意见（🔴 新范式要求）

### 核心判断

**中国走日本式长期停滞路径的概率区间: 35-50%**

### 依据的关键变量（3 个）

**V1: 银行不良贷款真实消化速度（权重 40%）**

这是概率区间上限（50%）的主要支撑变量。如果国有银行能够以"时间换空间"有效消化本轮不良——通过展期 + 通胀 + 利润冲抵 + 政府注资四管齐下——那么中国可以避免日本式的银行危机 → 信贷冻结传导，走"缓慢泄压"而非"断崖崩溃"路径。1999-2005 年四大 AMC 成功剥离 1.4 万亿不良的历史先例证明了这一模式的可行性。

但风险在于：本轮不良规模可能远超 1999 年（房地产市场总市值 ~$45 万亿，如果价格下跌 30%，银行涉房敞口直接损失 ~$3-5 万亿 `[待验证]`），而银行利润（~¥2.3 万亿/年）和 AMC 收购能力的消纳速度能否覆盖不良生成速度存疑。如果消纳速度 < 生成速度，不良会堆积到触发信贷收缩的临界点。

**V2: 居民消费倾向是否出现"节俭悖论"拐点（权重 35%）**

这是中国 vs 日本路径的最关键分化变量。日本 1990 年代消费倾向始终维持在较高水平（65%+），因为日本居民部门不是泡沫破裂的重灾区（企业才是）。中国的情况不同——居民杠杆率从 39%→64%，且房价下跌直接冲击居民资产负债表。如果消费倾向从当前的 ~63-64% 进一步降至 60% 以下，意味着居民部门正在从"暂时减少可选消费"转向"永久性降低生活水平预期"——这正是日本企业部门在 1990 年代发生的"债务最小化"心态在居民部门的映射。

一旦居民消费进入"节俭悖论"（每个人减少消费以应对不确定性 → 总需求下降 → 经济恶化 → 更不确定 → 消费进一步减少），经济将进入与日本路径高度相似的"私人需求长期萎缩"阶段——即使银行体系不崩溃，内需也会长期疲软。

**V3: 人民币汇率在资本管制下能否维持不发生预期自我实现的贬值（权重 25%）**

这是日本未面临但中国可能面临的特有风险。日本在泡沫破裂后日元长期偏强（贸易顺差 + carry trade 回流），避免了"汇率贬值 → 资本外逃 → 进一步贬值"的螺旋。中国有资本管制护城河，但随着经济前景恶化、中美利差倒挂加深（2024-2025 美国利率 ~5% vs 中国 ~1.5% `[待验证]`）、居民和企业寻找换汇渠道的动力增强，5 万美元额度下的蚂蚁搬家式资本外流可能累积为不可忽视的压力。如果人民币出现一次性大幅贬值（>20%），将引发外债负担加重（中资企业海外美元债务 + 开发商美元债）、输入性通胀与内部通缩的矛盾叠加、以及信心危机。

但只要资本管制这个阀门不崩溃，中国就能比日本多一个外部缓冲器——这是将上限设为 50%（而非更高）的主要约束。

### 概率区间分解

| 子场景 | 概率 | 条件 |
|--------|------|------|
| **完全日本化**（长期通缩 + 零增长 + 银行危机） | **10-15%** | 银行不良失控 + 居民消费崩塌 + 汇率大幅贬值三者同时发生 |
| **部分日本化**（低增长 1-3% + 温和通缩 + 银行不崩但不放贷） | **25-35%** | 银行通过展期维持但惜贷 → 投资长期低迷 → 消费疲弱 → 类似日本 1993-1997 的"假复苏"阶段 |
| **软着陆**（出清后恢复 3-5% 增长 + 通胀正常化） | **30-40%** | 政策托底有效 → 地产在城镇化余量下找到新平衡 → 新产业（新能源/AI/高端制造）接棒 |
| **崩溃/重构**（远差于日本——叠加人口雪崩 + 外部封锁） | **5-10%** | 极端尾部风险：多个信号同时触发 + 外部冲击 + 社会不稳定 |
| **其他/不确定** | **5-10%** | — |

### 与日本的关键区别总结

**中国比日本更有利的因素（推低概率下限）**:
- 国有银行 → 消除银行破产放大器（日本最大的痛苦源）
- 资本管制 → 阻止资本外逃 + 汇率可控（亚洲金融危机证明了这有多致命）
- 政策工具库更深 → 可以更精细地管理泄压速度
- 城镇化余量 → 仍有真实住房需求托底

**中国比日本更不利的因素（推高概率上限）**:
- 人口前景更差（老龄化速度更快、出生率更低、达峰更早）
- 外部环境更恶劣（日本有美国市场+全球化红利，中国面临脱钩+关税壁垒）
- 居民杠杆参与度更高（日本的泡沫集中在企业，中国居民直接参与了泡沫——财富效应逆转更直接）
- 地方财政脆弱性（日本的地方政府不依赖土地出让金）

### 核心不确定性声明

这个概率区间基于当前（2026Q3）已知信息的"最佳猜测"，但以下结构性不确定性可能显著改变概率:
1. 中美关系未来走向（全面对抗→完全脱钩 vs 阶段性缓和）
2. 中国是否爆发超越房地产的系统性债务危机（地方政府隐性债务 + 影子银行 + 信托）
3. 技术突破（AI/新能源）能否创造足够的新增长极来对冲房地产下行
4. 政策层的"学习速度"——是否能从日本经验中学到教训，避免"too late, too little"的错误
