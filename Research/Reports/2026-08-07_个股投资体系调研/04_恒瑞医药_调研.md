## 一、公司本质：恒瑞卖什么？

### 1.1 一句话抽象

**恒瑞是中国最大的仿制药→创新药转型平台**。它的商业模式本质是：用仿制药的现金流反哺创新药研发，再通过创新药的独占期利润覆盖新一轮管线投入——一个内生循环的「研发-变现」飞轮。

### 1.2 收入结构拆解（三层）

| 层级 | 产品类型 | 占收入比（估算） | 增长态势 | 利润贡献 |
|:---:|---------|:---:|:---:|:---:|
| **仿制药** | 传统仿制药（抗肿瘤/麻醉/造影剂） | ~35-40% | ↓ 集采持续拖累 | 中低（量升价跌） |
| **仿制药（高壁垒）** | 首仿/难仿品种（白蛋白紫杉醇等） | ~15-20% | → 稳定 | 中高 |
| **创新药** | 自研创新药（PD-1卡瑞利珠单抗、阿帕替尼等）+ License-out | ~40-50% | ↑ 快速放量 | 高（但研发摊销大） |

### 1.3 商业模式可证伪命题

| 命题 | 如果为真 | 如果为假（证伪信号） |
|------|---------|-------------------|
| **创新药放量能覆盖仿制药集采损失** | 创新药收入占比持续提升，总营收恢复两位数增长 | 创新药增速放缓 + 仿制药加速下滑 → 总营收停滞或下降 |
| **License-out 能成为第二增长曲线** | 海外授权首付款+里程碑款每年 >30 亿且逐年递增 | 海外授权断档 2 年以上，或授权后退回（退货率 >30%） |
| **研发效率领先国内同业** | 每 10 亿研发投入产出 ≥1 个上市新药 | 管线临床失败率显著上升，NDA 获批率低于 50% |
| **集采对恒瑞的边际影响递减** | 仿制药存量品种集采覆盖率 >80% 后营收降幅收窄 | 每次新批次集采仍有 >5 亿品种被纳入，拖累不收敛 |

> [待验证] 仿制药具体收入占比 — 恒瑞近年不再单独披露仿制药/创新药分项，上述比例为多家券商估算范围。

### 4.2 竞争优势分析

**恒瑞的核心壁垒：**
1. **管线宽度第一**：50+ 创新药管线，覆盖肿瘤/自免/代谢/疼痛，国内最全
2. **商业化能力最强**：7000+ 人销售团队，覆盖全国 2 万+ 医院终端，远超百济（~3500 人）
3. **现金牛反哺**：仿制药仍贡献稳定现金流，研发投入无需依赖外部融资

**恒瑞的劣势：**
1. **国际化落后于百济**：百济泽布替尼已实现全球销售（FDA 批准），恒瑞尚无自主全球商业化品种
2. **First-in-class 匮乏**：管线以 Fast-follow 为主，原创靶点少
3. **研发效率争论**：人均产出 vs. 百济的争议 — 百济研发投入更高但产出更集中

## 五、核心矛盾

### 5.1 矛盾一：仿制药集采拖累 vs. 创新药放量

```
仿制药收入：每年 -5%～-10%（集采降价 + 量升不补价跌）
创新药收入：每年 +20%～+30%（新适应症获批 + 进院加速）

净效果 = 创新药增量 — 仿制药减量
```

**当前状态**：创新药占比已过 50% [待验证]，增量 > 减量，总营收开始恢复正增长。2026 TTM 营收增速 6.20% [L2-2] 印证此趋势。

**反转风险**：
- 若创新药增速从 25% 骤降至 10% 以下（如竞品 PD-1 价格战加剧 / 新药审批延迟）
- 同时第 11-12 批集采打击剩余大品种
- → 可能出现「青黄不接」：总营收 0 增长或负增长 1-2 个季度

### 5.2 矛盾二：国内医保单一买方 vs. 出海

```
国内路径：创新药 → 医保谈判 → 以价换量 → 毛利率承压（PD-1 年费用已降至 ~5 万）
出海路径：License-out → 首付款 + 里程碑 → 毛利率高 → 但需要 BD 能力和全球临床数据
```

**恒瑞的策略**：双轮驱动，但重心仍在国内。出海主要依赖 License-out（轻资产），而非自建海外销售团队（重资产）。

**正面**：2023-2024 年与默沙东/GSK 的 License-out 合作验证了管线全球价值。
**反面**：License-out 收入不稳定（取决于交易节奏），无法像百济泽布替尼那样形成持续海外现金流。

### 5.3 矛盾三：高研发投入 vs. 短期利润

- 研发费用率 ~27%，A 股医药最高之一
- 短期压制利润（PE 静态高），长期决定管线厚度
- 若研发效率下降（每 10 亿投入产出 <1 个 NDA），市场将重新定价

## 六、周期定位：创新药周期中的恒瑞

### 6.1 创新药行业周期框架

```
萌芽（2015-2018）  → 爆发（2019-2021） → 过热（2021 H2） → 出清（2022-2024） → 普及（2025-?）
  药审改革+        PD-1 上市+          港股18A泡沫+       集采+医保谈判+        创新药占比提升+
  人才回流         医保纳入             估值百倍           融资寒冬              商业化验证
```

### 6.2 恒瑞在周期中的位置

| 维度 | 出清期特征 | 恒瑞当前表现 | 判断 |
|------|-----------|------------|:---:|
| 估值 | PE 从 100→30-40 | PE(TTM) 44.65 | ✅ 已完成估值压缩 |
| 融资 | 一级市场冻结 | 恒瑞不依赖外部融资 | ✅ 穿越周期 |
| 管线 | 大批 Biotech 倒闭 | 50+ 管线持续推进 | ✅ 龙头受益出清 |
| 营收 | 行业增速下滑 | 恢复 6% 正增长 | ✅ 率先企稳 |
| 创新药占比 | 多数公司 <30% | >50% [待验证] | ✅ 领先进程 |

**定位结论**：恒瑞处于 **「出清末期 → 普及前期」的过渡阶段**。估值泡沫已出清（PE 从 100+ → 45），创新药营收占比过半，总营收恢复增长。这是创新药投资体系卡定义的「产业时钟领先 + 资本时钟滞后」错位 — 产业基本面已进入普及前期，但市场定价仍残留出清末期的谨慎。

## 🔴 Bear Case Analysis

### Bull Thesis
恒瑞是中国创新药转型最成功的平台型公司，仿制药集采边际影响递减，创新药占比过 50% 且加速放量，License-out 打开出海天花板，PE 从 100+ 压缩至 45 后估值合理。

### Key Failure Points

1. **创新药增速骤降（最核心风险）**
   - 触发条件：PD-1 价格战加剧（年费用降至 <3 万），或新适应症审批延迟 >6 个月
   - 影响程度：营收增速从 6% → 0-2%，PE 可能进一步压缩至 35 → -15% 股价

2. **ADC 管线全军覆没**
   - 触发条件：SHR-A1811 / SHR-A1904 / SHR-A2009 中 2 个以上临床失败
   - 影响程度：出海逻辑崩塌，License-out 合作方退货 → -25%

3. **仿制药新一轮集采超预期**
   - 触发条件：第 11-12 批集采纳入造影剂全线等核心大品种
   - 影响程度：单季营收冲击 >10 亿 → -10%
