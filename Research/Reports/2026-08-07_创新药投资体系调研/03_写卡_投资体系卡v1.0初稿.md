## ① 投资体系卡正文（v1.0 初稿）

### 存在目的（Purpose）

创新药体系的本质目的 **既不是「降低治疗成本」也不是「延长生命」**，而是：

> **以专利垄断为激励手段，将科学知识转化为可商业化的治疗方案，最终通过市场/医保双轨支付向患者交付健康改善。** [B:§1.2]

**三层目的拆解**：

| 层次 | 描述 | 可证伪方式 |
|------|------|-----------|
| 一级（直接） | 将基础科学发现（靶点/机制）转化为可上市药品 | 观察 IND→NDA 转化率 |
| 二级（中间） | 通过专利垄断期回收研发成本 + 获取超额利润 | 观察药企 ROIC vs 资本成本 |
| 三级（最终） | 改善患者健康产出（存活率/生活质量） | 需 10 年+ 长周期数据对比（部分可证伪） |

**关键洞察** [B:§1.2]：
- 「降低治疗成本」是 **支付方（医保）的目的**，不是药企的目的。药企的目的函数是利润最大化——专利期内定价越高越好。
- 「延长生命」是 **患者与社会的目的**，药企将其包装为价值主张。真正的底层可证伪信号：**当专利到期，原研药企是选择降价竞争还是放弃市场？**——答案揭示目的是利润还是健康。
- **终判**：创新药体系不是「改善人类健康」的道德工程，而是 **知识→资本→知识的增值循环**——健康改善是副产品，不是驱动力 [B:§1.3]。

**目的实现的核心约束** [B:§1.3]：

| 约束 | 描述 | 影响 |
|------|------|------|
| 知识约束 | 靶点发现成功率 <5% | R&D 投入 ≠ R&D 产出 |
| 资本约束 | 单药平均研发 $2.6B，周期 10-15 年 | 只有头部可玩 |
| 支付约束 | 全球医保支出占 GDP 3-10%，中国基金增速<支出增速 | 支付天花板制约定价上限 |
| 时间约束 | 专利 20 年（实际垄断期 ≈8-12 年） | 必须在专利期内赚回全部成本+利润 |
| 伦理约束 | 药品不能完全自由定价（公共健康属性） | 政府定价干预不可避免 |

### 产业链五层结构与价值捕获 [B:§2]

```
第五层：支付方（医保局 / 商保 / 患者自费）
  → 终极资金出口；决定整个链条的总蛋糕大小

第四层：终端渠道（医院 / 药店 / DTP 药房 / 互联网医疗）
  → 药品触达患者的最后一公里；处方权→流量分配权

第三层：制药企业（创新药企 / 仿制药企 / biotech / Big Pharma）
  → 核心价值创造者——发现靶点→开发→生产→注册→商业化

第二层：CXO（CRO / CDMO / CSO）
  → 研发/生产/销售外包服务商；药企的「卖水人」

第一层：上游（原料药/中间体/试剂/设备/耗材）
  → 基础生产要素供给；可替代性高，议价权最弱
```

**价值捕获铁律**：创新药产业链中，唯一创造超额价值的环节是「拥有专利的创新药企」。其他所有环节都在分配药企创造的剩余价值 [B:§2.3]。

| 层级 | 创造/捕获比 | 核心议价权来源 |
|------|:----------:|--------------|
| 创新药企 | **1.5-3.0** | 专利独占 + 临床数据 + 品牌 |
| CXO | 0.5-0.8 | 技术壁垒 + 客户粘性 + 规模效应 |
| 仿制药企 | 0.3-0.5 | 成本控制 + 渠道覆盖 |
| 上游原料药 | 0.3-0.5 | 无——同质化竞争 |
| 支付方（医保） | 0（纯买方） | **垄断买方定价权** |

**🔴 中国特殊变量**：医保局作为单一最大买方，掌握了远超美国商业保险的定价权——中国创新药企的价值捕获能力被 **体制性压制**：
- 美国：创新药企对多个分散买方（商保/PBM/患者）→ 定价权强
- 中国：创新药企对一个垄断买方（医保局）→ 定价权弱

→ **中国创新药企捕获超额价值的出路只有两条：①出海（面对分散买方）；②做出医保无法替代的独占性品种。** [B:§2.3]

### 核心矛盾（一阶 + 二阶）

**一阶三重矛盾** [B:§3.1]：

| # | 矛盾 | 核心张力 | 当前状态 |
|---|------|---------|---------|
| 1 | 研发长周期 vs 资本耐心短 | 10-15 年 vs 3-7 年 | 迫使 biotech 在 II 期即变现 |
| 2 | 集采压价 vs 创新激励 | 最低价中标 vs 临床价值定价 | 短→中过渡期（倒逼转型） |
| 3 | 出海受益 vs 地缘风险 | $500B+ 自由定价市场 vs 实体清单/FDA 关闭 | License-out 路径缓解但 CXO 直接受威胁 |

**二阶矛盾**（CLD 因果回路建模）[B:§3.2]：

- **增强环路 R1**（良性）：研发成功 → 估值提升 → 更多资金 → 更多管线
- **调节环路 B1**（冷却）：集采/医保降价 → 国内 ROI↓ → 资金外流/出海 → 国内研发放缓
- **增强环路 R2**（恶性）：出海受阻 → 海外市场关闭 → 只能依赖国内 → 定价天花板更低 → ROI 进一步↓ → 中国创新药可能被困在低定价市场

**脆弱节点**（破裂后果最严重的四个节点）[B:§3.2]：

| 脆弱节点 | 破裂后果 |
|---------|---------|
| 医保基金可持续性 | 创新药纳入医保的速度/价格进一步恶化 |
| 美元基金撤出 | 早期 biotech 融资断流 |
| FDA 准入关闭 | 出海逻辑归零 |
| CXO 脱钩 | 药明系失去全球客户 |

### 明斯基周期定位：出清末期 → 普及前期 [B:§4]

**判断依据**：

| 信号 | 观察 | 阶段 |

### 中国 vs 日本 1990s：高相似 —— 直接借鉴

**相似度**：高相似（7 项量变 + 2 项质变）[B:§5.4]

| 制度约束（支付） | 质变 | **质变**——中国单一买方 vs 日本混合支付 |
| 地缘约束 | 质变 | **质变**——中国面临制裁风险，日本无 |
| 技术基础 | 高相似 | 量变 |
| 竞争格局 | 中相似 | 量变 |
| 反馈机制 | 高相似 | 量变 |
| 失效方式 | 中相似 | 量变 |

**质变 2 项 → 借鉴级别：直接借鉴（结构模板可复用 + 警示双用）**

**日本经验对中国的直接启示** [B:§5.5]：

1. **方向有效**：日本从「仿制 + me-too」到「全球 first-in-class」花了 20 年。中国目前处于阶段 1→2 过渡期。国内降价倒逼出海——机制同构。
2. **路径不同**：日本通过并购（武田 $62B 收购 Shire）加速转型——中国因 CFIUS 限制，走 License-out + 自主海外临床路径。
3. **警示**：日本转型成功的不到 10 家（武田/安斯泰来/第一三共/卫材/中外制药），大批中小企业被淘汰——中国将有同样的大浪淘沙。
4. **时间线不能复用**：地缘约束质变意味着中国可能需要更长的出清期。
5. **相似度下调**：从最初 70-80% 下调至 **60-70%**（因地缘约束质变）[B:§5.5]。

**中国的结构优势 vs 日本** [B:§5.5]：

| 优势 | 中国 | 日本 1990s |
|------|------|:--------:|
| 工程师红利 | 大量海外归国科学家 | 较少 |
| 临床资源 | 患者基数大，入组快 | 患者少，临床慢 |
| 资本支持 | 港股 18A + 科创板 | 银行体系为主 |
| 制造能力 | CMO/CDMO 全球领先 | 一般 |
