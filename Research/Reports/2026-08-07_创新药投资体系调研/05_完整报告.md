## 一、执行摘要

**Radar 首张投资体系卡定稿**——创新药（持仓 35% 最大仓位）从"投资报告"升级为"可被现实打分的体系卡"。

1. **周期定位**：修复期中段（A 数据：PE 24.55 / 250 日分位 61.3% / 距低点 +27.9%）+ 出清末期→普及前期（B 结构：相变窗口）
2. **本质目的**：以专利垄断为激励，把科学知识转化为可商业化治疗方案——**不是降成本不是慈善**（审查修正为"激励相容"措辞）
3. **产业链洞察**：中国医保=垄断买方定价权 → 创新药企价值捕获被压制 → **出海是必然路径** → S1（License-out）权重最高
4. **持仓裁决**：35% → **25% 核心 + 10% 卫星**（审查驳回"不动等信号"）；无杠杆声明入卡
5. **S1-S5 止损线**：S5 地缘制裁（实体清单/FDA 审查/关税>25%）→ 立即清仓

## 二、调研结论（A/B 观点并列）

### Agent A（数据向）结论
- 修复期中段：PE 24.55（历史偏低）/ 250 日分位 61.3%（脱离底部未过热）/ 距低点 +27.9%
- 出海：2025H1 81 笔 License-out（NMPA）
- 政策：CDE 加速审批 + DRG/DIP 改革
- 头部：百济（4623 亿/+11.4%）恒瑞（3607 亿/+4.3%）今日领涨
- 7/8 数据源成功，6 个 🟢 高可信

### Agent B（结构向）结论
- purpose 三级抽象（专利垄断激励——直接/中间/最终）
- 产业链五层价值捕获（医保=垄断买方，中国特殊变量）
- 一阶三重矛盾 + 二阶 CLD 双环路（R1 良性/R2 恶性）
- 明斯基：出清末期→普及前期（头部 10% 对冲融资/~40% 僵尸待出清）
- 中日高相似（直接借鉴日本转型）/ 中韩中相似（警示框架）
- 持仓结论：逻辑成立但 35% 偏高（长期置信度 80%/中期 55%）

### A/B 一致性
- 5 项一致（脱离底部/非过热/出海驱动力/政策改善/头部质量）+ 4 项差异（框架/风险侧重/时间尺度/仓位建议）——**互补非矛盾**（A 价格动量 vs B 结构风险）
