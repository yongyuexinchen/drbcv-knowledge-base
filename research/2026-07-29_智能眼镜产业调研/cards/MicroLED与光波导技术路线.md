# MicroLED + 光波导技术路线

## 类比
**一句话比喻**：MicroLED 是火柴（极小但极亮），光波导是镜片里的光纤（把光从镜腿导到眼前）——两者的婚姻决定了 AR 眼镜能不能做成。

| 生活场景 | 映射 |
|---------|------|
| 火柴（MicroLED） | 本身就是光源，不需要背光，亮度可达百万尼特 |
| 光波导效率极低（<1%） | 就算火柴极亮，经过波导后只剩不到 1% → 这就是为什么需要超高亮度光源 |
| 婚礼能不能成 | MicroLED（火柴）+ 光波导（导光管）= 当前唯一可行的「类普通眼镜全彩 AR」路线 |

## 为什么这是下一代路线

**技术逻辑链**：
1. 光波导要实现类普通眼镜形态（薄+高透光率）
2. 但光波导的光效极低（衍射 <1%，阵列 5-10%）
3. 需要极高亮度的显示光源来补偿 → 传统 Micro OLED 亮度不够（~5000nit）
4. **MicroLED 亮度可达百万 nit** → 完美匹配光波导的低光效

## 当前状态（2024-2025）

| 环节 | 状态 | 关键玩家 |
|------|------|---------|
| 红色 MicroLED | ✅ 量产 | JBD（上海显耀） |
| 绿色 MicroLED | ✅ 量产 | JBD |
| 蓝色 MicroLED | ⚠️ 小批量 | JBD |
| 全彩合色 | ⚠️ 中试 | JBD、镭昱 |
| 衍射波导 | ✅ 量产（30-40°FOV） | 鲲游光电、至格科技、Dispelix |
| 碳化硅波导（70°FOV） | 🔴 原型（单片>$1000） | Meta Orion 专用供应链 |

## 时间线预判
- **2024-2025**：MicroLED 单色/双色量产，衍射波导 FOV 30-40°，代表：雷鸟 X2
- **2025-2027**：MicroLED 全彩突破，衍射波导 FOV 40-50°，成本降至 $50-100/片
- **2027-2030**：碳化硅波导 FOV 60-70°，接近量产经济性
- **2030+**：全息波导/超表面光学，可能替代现有方案

## 正例
- 雷鸟 X2：首个消费级全彩 MicroLED + 衍射波导一体机（FOV 36°，¥4,999）
- Meta Orion 原型：碳化硅波导 + MicroLED，FOV 70°，验证了高 FOV 可行性
- JBD：全球 MicroLED 微显示出货量第一，0.13" 面板亮度百万尼特

## 反例
- **LCoS + 光波导**（HoloLens 2 / Magic Leap 2）：LCoS 亮度不够 → 光效损失后画面暗 → 体积做不小 → 企业级勉强，消费级失败
- **DLP + 光波导**：体积更大、功耗更高 → 不适用于眼镜形态
