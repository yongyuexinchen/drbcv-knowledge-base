## 二、光学技术路线对比

### Birdbath（曲面反射式）

| 维度 | 评价 |
|------|------|
| **原理** | Micro OLED 显示屏 → 45° 半透半反镜 → 曲面反射镜 → 人眼 |
| **FOV** | 40-52°（主流产品 46-50°） |
| **亮度效率** | 较低（~15-25%），需高亮 Micro OLED 补偿 |
| **显示质量** | ★★★★★ 色彩准确、高对比度、高分辨率(1080P+) |
| **体积/重量** | 有一定厚度（~10-15mm），镜片较厚 |
| **透光率** | 一般（~30-50%），外界视野偏暗 |
| **成本** | ★★★★★ 成熟且较低（光学模组 ~$30-50） |
| **代表产品** | XREAL Air 系列、Rokid Max、雷鸟 Air 2、VITURE One |

**小结**：是目前 **消费级 AR 眼镜最主流方案**，画质好、成本低、量产成熟。适合观影/投屏/第二屏场景。缺点是体积较大、透视效果一般，不适合全天候佩戴。

### 光波导（衍射/阵列/全息）

| 维度 | 衍射光波导 | 阵列光波导 | 全息光波导 |
|------|-----------|-----------|-----------|
| **原理** | 入耦合光栅→波导内全反射→出耦合光栅→人眼 | 半透半反阵列→波导→出射 | 全息光学元件(HOE) |
| **FOV** | 25-50°（消费）/ 50-70°（企业） | 30-55° | 15-30° |
| **亮度效率** | 低（~1-5%），需极高亮度光源 | 中（~10-15%） | 低 |
| **显示质量** | ★★★ 色彩均匀性待提升、彩虹纹 | ★★★★ 较好 | ★★ 单色为主 |
| **体积/重量** | ★★★★★ 镜片极薄（~2-3mm）、类普通眼镜 | ★★★★ 较薄 | ★★★★★ 极薄 |
| **透光率** | ★★★★★ 高（>85%），外界视野清晰 | ★★★★★ 高 | ★★★★ |
| **成本** | ★★ 高（光学模组 ~$100-300） | ★★★ 中高 | ★★ 高 |
| **量产难度** | 较高（光栅精度要求高） | 高（镀膜良率低） | 极高 |
| **代表产品** | INMO Air 2、雷鸟 X2、Magic Leap 2、HoloLens 2 | Lumus（方案商） | North Focals、Akonia（Apple收购） |

### 自由曲面

| 维度 | 评价 |
|------|------|
| **原理** | 自由曲面棱镜/反射镜将侧方显示反射入眼 |
| **FOV** | 20-50° |
| **体积** | 较厚，视觉上不似普通眼镜 |
| **成本** | 中等 |
| **代表** | 早期 Google Glass、Epson Moverio、部分工业 AR |
| **现状** | 消费市场已基本被 Birdbath 和光波导取代，仅在特定工业场景使用 |

## 三、技术路线演进趋势

```
2020-2023:  Birdbath + Micro OLED     ← 当前主流（观影/投屏）
2023-2025:  衍射光波导 + MicroLED      ← 过渡期（开始量产，FOV小）
2025-2027:  碳化硅波导 / 表面浮雕光栅 + MicroLED  ← 下一代（Meta Orion路线）
2027+:      全息波导 / 超表面光学       ← 远期（Apple/Google投入）
```

**关键突破点**：
- **MicroLED 量产**：JBD（上海显耀）、镭昱等国产供应链已能提供全彩 MicroLED 微显，亮度可达百万 nit，是光波导的最佳搭档
- **碳化硅波导**：Meta Orion 采用，FOV 可达 70°，但成本极高
- **光引擎小型化**：从 LCoS → DLP → MicroLED，体积和功耗持续下降

## 五、赛道总结与判断

### 短期（2024-2025）：Birdbath 基本盘
- 观影投屏场景已验证 PMF（Product-Market Fit）
- 市场增速 ~50%/年
- 关键在于 **内容生态**（如 XREAL Beam 的空间桌面、和索尼/微软游戏主机的联动）

### 中期（2025-2027）：波导一体机过渡
- MicroLED 成本下降、全彩方案成熟
- 30-40° FOV 足够支撑信息提示+导航+翻译+AI 助手场景
- 重量降到 50-80g 时有望成为"全天候佩戴"设备
- **苹果入局是最大变量**（Vision Pro 路线外，Apple 内部有代号"Apple Glass"的光波导项目）

### 长期（2027+）：消费级真 AR
- 70°+ FOV + 类普通眼镜形态 + 全天续航
- Meta Orion 展示的技术路线（碳化硅波导+MicroLED+分体式计算 puck+肌电图腕带）提供了可行性的技术验证
- 关键瓶颈：波导成本（目前碳化硅波导单片超 $1000）、MicroLED 全彩良率、散热、AI 端侧算力

### 风险提示
- **退潮风险**：2023-2024 的 AR 眼镜热潮部分由 AI 概念驱动，若无法持续出货增长，可能重蹈 Google Glass 覆辙
- **苹果降维打击**：若 Apple 在 2026-2027 推出成熟 AR 眼镜，可能重塑市场格局
- **技术路线不确定性**：光波导 vs Birdbath 路线之争未定，MicroLED 量产进度决定胜负手
