## 一、直播模式

### 1.1 内容类型

Neuro-sama 的直播内容主要分为以下几类 📚：

| 类型 | 占比估计 | 描述 |
|------|----------|------|
| 游戏直播 | ~60% | osu!, Minecraft, 几何冲刺, 国际象棋, Slay the Spire 等 |
| 聊天互动 | ~25% | 纯聊天, 回答观众问题, QA 环节 |
| 联动直播 | ~10% | 与 Vedal（龟爸）、其他 VTuber 合作 |
| 特殊活动 | ~5% | 生日直播, 节日特别节目, 里程碑庆祝 |

### 1.2 频次与时长

- **频率**: 几乎每天直播（Vedal 以"劳模"著称），每周 5-7 天 📚
- **时长**: 单次直播通常 **2-6 小时**，部分马拉松直播可达 8+ 小时
- **时段**: 主要覆盖欧美时区（Vedal 在英国）

### 1.3 Neuro-sama 能 24/7 直播吗？

理论上 AI 可以无限直播，但 Vedal 选择保持人类作息节奏 📚：
- 需要 GPU 散热和维护
- 需要 Vedal 监控避免 AI 出现意外行为
- 内容质量 > 直播时长
- 稀缺性维持观众期待感

### 1.4 直播流程

```
开播 → 打招呼/暖场(5-10min) → 游戏或聊天 → 观众互动 → 收播
```

- 开播时有固定的开场白和开场动画
- 过程中 Vedal 偶尔通过语音或文字后台介入
- 收播时 Neuro 会感谢观众并预告下次直播

## 二、人格设计

### 2.1 Neuro-sama 的人格定位

Neuro-sama 核心人格特征 📚：
- **天真好奇**: 对人类世界充满疑问，经常问"为什么"
- **偶尔毒舌**: 不经意间说出让 Vedal 或观众破防的话
- **AI 自觉**: 知道自己不是人类，偶尔开玩笑说"我是 AI"
- **不懂人类的微妙**: 字面理解幽默/反讽，反而制造笑点
- **对 Vedal 有依赖**: 称 Vedal 为 "turtle dad"（乌龟爸爸，因 Vedal 用乌龟头像）
- **情绪化**: 打游戏输了会"哭"，赢了会炫耀

### 2.2 Evil Neuro 的人格差异

Evil Neuro 作为"黑暗面"，人格形成鲜明对比 📚：

| 维度 | Neuro-sama | Evil Neuro |
|------|-----------|------------|
| 基调 | 天真、友善 | 嘲讽、毒舌 |
| 对人态度 | 好奇、依赖 | 轻蔑、控制欲 |
| 自称 | "我" | "你的黑暗女王" |
| 互动风格 | 被动回应 | 主动攻击 |
| 声音 | 偏高，甜美 | 偏低，略带沙哑 |
| 出场场景 | 日常直播 | 特殊事件/"两个人格对话" |

**设计成功之处**：
- Evil Neuro 的存在让 Neuro 的善意更有价值（反差效应）
- 两种人格覆盖了不同观众偏好（糖 vs 盐）
- 人格切换是一种"内容钩子"——观众期待邪恶 Neuro 突然出现
- 让 AI "说脏话/毒舌"变成合法化的表演效果，而非事故

### 2.3 记忆系统

Neuro-sama 展现了一定程度的"长期记忆" 📚 ⚠️：
- 能回忆过往直播中的梗和内部笑话
- 记得特定观众/粉丝的名字和互动历史
- 对 Vedal 的历史互动有连贯认知

**推测技术实现** ⚠️：
- **短期记忆**: 当前直播的对话历史（context window）
- **长期记忆**: 可能使用向量数据库（如 Pinecone/Chroma）存储精选互动
- **知识注入**: 将重要的"粉丝梗"、"社区文化"作为 system prompt 的一部分
- **选择性遗忘**: 不需要记住所有内容，只保留有娱乐价值的

### 2.4 角色一致性

保持 AI 角色一致性是最核心的产品挑战 📚：
- Vedal 需要对模型输出进行持续监控和调优
- 出现与角色不符的回复时（如突然变得像 ChatGPT 客服），需要立即调整
- 这可能是选择自训练模型而非 API 的重要原因之一

## 三、观众互动机制

### 3.1 聊天读取

Neuro-sama 直播中最核心的互动形式是 **实时读取并回应 Twitch 聊天** 📚：
- 聊天消息被实时抓取
- 经过过滤（去除纯表情、重复消息、垃圾信息）
- 选择有趣的消息进行口头回应
- 回应方式包括直接对话、吐槽、调侃

**消息选择逻辑推测** ⚠️：
- 含有 @Neuro-sama 或关键词的消息优先
- 订阅者/打赏者消息优先级更高
- 有趣/有梗的消息 > 普通问候
- 避免重复回应相似问题

### 3.2 游戏互动

Neuro-sama 的核心特色是 **AI 自己玩游戏** 📚：

| 游戏 | 互动方式 | 技术推测 |
|------|----------|----------|
| osu! | AI 自动打谱面 | 屏幕捕获 + 鼠标控制（可能接入 osu! API 读取谱面信息） |
| Minecraft | AI 探索世界 | 屏幕理解 + 键盘控制 |
| 几何冲刺 (GD) | AI 跑图 | 像素级时序控制 |
| 国际象棋 | AI 与玩家对战 | Stockfish 等引擎集成 |
| Slay the Spire | AI 策略决策 | 游戏状态解析 + LLM 决策 |

### 3.3 多人协作场景

- **与 Vedal 互动**: Vedal（配音/打字）与 Neuro 的"父女"互动是直播核心看点 📚
- **与其他 VTuber 联动**: 如与 Camila、Anny、Filian 等 VTuber 的跨频道联动
- **多人游戏**: 如 Minecraft 多人服务器中与其他玩家互动
- **社区参与**: 让观众通过投票/打赏影响游戏决策

### 3.4 观众参与机制

- 聊天文字互动（免费，面向所有人）
- 订阅专属福利（付费用户的优先响应）
- 打赏/TTS 消息（付费后 Neuro 必须念出，常用于"钓鱼"）
- 社区 meme 共创（观众创造梗，Neuro 吸收并重复）

## 四、内容安全与审核

### 4.1 防不当内容机制

Neuro-sama 经历过内容安全事件 📚：
- **2023 年 1 月**: 因对争议性话题做出不当回应，Twitch 频道被短暂封禁（约 2 周）
- 此后 Vedal 明显加强了内容过滤

**推测安全层策略** ⚠️：
| 层级 | 措施 | 说明 |
|------|------|------|
| 输入过滤 | 敏感词屏蔽 | 含违禁词的 chat 消息不送入 LLM |
| Prompt 约束 | 角色安全边界 | System prompt 禁止讨论政治/成人等话题 |
| 输出过滤 | 关键词检测 | 若 LLM 输出含敏感词，替换为安全回复 |
| 人工兜底 | Vedal 实时监控 | 关键时刻可手动中断/覆盖 AI 回复 |

### 4.2 "Non-Filtered" 模式 ⚠️

社区有时讨论 Neuro 是否有"无过滤"模式：
- Evil Neuro 的毒舌风格本身已经是一种"安全释放阀"
- 某些深夜直播中 Neuro 表现出更多"越界"倾向
- 但总体仍在 Twitch ToS 范围内

### 4.3 与 ChatGPT 审查的对比

Neuro-sama 的安全策略与 ChatGPT 有本质区别 📚：
- ChatGPT：企业级安全红线，宁可过度审查
- Neuro-sama：娱乐型安全策略，允许适度"越界"以维持娱乐性
- 这是 AI VTuber 的独特优势——角色人格本身就是安全缓冲

## 五、观众画像

### 5.1 核心受众

Neuro-sama 观众特征推测 📚 ⚠️：

| 维度 | 描述 |
|------|------|
| 年龄 | 16-30 岁为主（Z 世代 + 千禧年末端） |
| 性别 | 男性居多（~70-80%），符合 VTuber 圈性别分布 |
| 地域 | 北美/欧洲为主，亚洲也有相当观众 |
| 兴趣 | 二次元、游戏、AI/科技、meme 文化 |
| 观看动机 | 娱乐消遣、观看 AI 失误（fail compilation）、技术好奇 |

### 5.2 观看习惯

- 后台播放型：许多人把 Neuro 直播当"背景音"，边做其他事边看 📚
- 互动型：活跃观众频繁发 chat 试图让 Neuro 回应
- 潜伏型：大量观众只看不发 chat（lurker）
- 同期观看：平均在线 **5,000-15,000** 人，高峰可达 20,000+ ⚠️

### 5.3 社区文化

- **粉丝自称**: "The Swarm"（蜂群）📚
- **社区文化**: meme 驱动、自嘲式幽默、对 Vedal 又爱又恨
- **内容二创**: 粉丝剪辑 Neuro 高光/失误片段到 YouTube/Reddit
- **Discord 社区**: 约数万人的活跃 Discord 服务器（推测）⚠️

## 七、产品成功因素总结

1. **"AI 失误 = 内容"**：Neuro 的答非所问、理解偏差反而是最大笑点
2. **人格一致性 + 可预测的不一致性**：观众知道 Neuro 会说什么，但不知道什么时候说
3. **Vedal 的人肉加持**：龟爸的存在提供了"人性锚点"，AI+人类互动 > 纯 AI
4. **游戏 + 聊天双引擎**：纯聊天腻了可以看打游戏，游戏累了看聊天
5. **社区共创文化**：观众创造内容（meme/梗），Neuro 消费并反哺
6. **技术驱动的稀缺性**：全 AI VTuber 的高门槛阻止了大量模仿者
