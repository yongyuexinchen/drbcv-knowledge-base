## 一、数据可信度审计（信息战实战教材）

**加沙死亡数字：同一件事，四个数量级**——这是本次调研最值得学的信息战案例：

| 来源 | 数字 | 特点 |
|------|------|------|
| 加沙卫生部（哈马斯控制） | ~48,000+（含14,000失踪） | 联合国采信但标注"哈方运行" |
| OHCHR（联合国人权办） | ~34,000（已验证身份） | **最低值、最保守**——只统计能验证身份的 |
| 《柳叶刀》学术信函（2024.7） | 推算 **186,000**（直接+间接） | 含疾病/饥饿/医疗崩溃，是直接死亡的4倍 |
| 以色列官方口径 | "至少15,000是战斗员" | 缩小"平民"数字 |

**信息战机制**：哈方倾向夸大总死亡（全算平民）、以方倾向夸大战斗员比例（缩小平民数字）、联合国只报最低验证值、学术界用模型推算真实全貌（可能是官方数字的4倍）。**这就是为什么"精确死亡数字"本身就是政治武器——数字的真实性取决于谁在数。**

**中立源铁律（沿用俄乌调研）**：
- ✅ 中立/严谨源：OHCHR、IPC饥荒审查委员会、CPJ记者统计、《柳叶刀》同行评审、Wikipedia交叉条目
- ⚠️ 单方源：IDF公告（夸大敌损缩小己损）、加沙卫生部（哈方）、伊朗/以色列官方
- 🔴 任何"精确到个位"的战场数字都不可信，只取量级+来源标注

### 2.1 时间线（2023.10 → 2026.8）

```

2023.10.27 以军地面进攻加沙北部（三阶段：北部→汗尤尼斯→拉法）
2023.11.24 首次停火（人质交换：105人质 ↔ 240巴囚）
2024.2.29  "面粉大屠杀"（援助点118死）→ 国际舆论转折点
2024.4-10  冲突外溢：伊朗两次直接攻击、真主党开战、辛瓦尔被击毙
2024.11.26 以黎停火（真主党撤至利塔尼河以北）
2024.12.8  阿萨德政权倒台 → "抵抗轴心"陆桥断裂
2025.1.19  加沙停火生效（第一阶段：33人质 ↔ ~1,900巴囚）
2025.3.18  以色列突袭打破停火（两天400+死）
2025.10.10 第三次停火（美支持和平计划第一阶段）

2026.7.31  特朗普宣布"和平委员会"达成解除哈马斯武装协议 ← 昨天！
```

### 2.2 以色列为什么不停火：内塔尼亚胡的政治生存

| 压力源 | 机制 |
|--------|------|
| **贪腐审判** | 2019年起三项指控；战争期间审判暂停，**停火=审判恢复=政治死亡** |
| **极右翼联盟** | 本-格维尔+斯莫特里赫控制关键议席，停火就退出政府→倒阁 |
| **安全叙事** | 30年"安全先生"人设被10.7击碎，战争是重塑形象唯一途径 |
| **国际逮捕令** | 2024.11 ICC 对内塔尼亚胡发出逮捕令——更不敢停（停了更被动） |

**"彻底消灭哈马斯"为何不可能**：哈马斯是意识形态不是军队；每个被炸死的平民家庭创造5个未来战士；IDF退役将军承认"哈马斯在已清理区域重新出现"；500-700km隧道网络多数完好。

### 2.3 哈马斯为什么"不投降"

无退路（投降=处决或终身监禁）+ 意识形态（"圣战是唯一道路"）+ 人质是唯一筹码 + 国际舆论越打越有利 + 战后治理真空（以色列拒绝法塔赫也拒绝哈马斯，国际托管被否决）。

**2026.7 关键转折**：哈马斯民事政府辞职 + 特朗普解除武装协议 = **战争从军事阶段转入政治终局阶段**。但哈马斯开价清晰：解除武装 ↔ 以色列撤军+重建。这个交换是否兑现，是 2026 下半年最大变量。

## 三、以伊线：影子战争变直接战争

### 3.1 三轮直接冲突（2024-2026）

| 轮次 | 时间 | 经过 | 结果 |
|------|------|------|------|
| 第一轮 | 2024.4 | 以炸伊朗驻大马士革领事馆 → 伊朗首次本土攻击（300+无人机导弹，99%被拦） → 以有限反击 | 伊朗展示"敢打"，以色列展示"拦得住" |
| 第二轮 | 2024.10 | 哈尼亚在德黑兰被暗杀 → 伊朗180枚弹道导弹 → 以打击军事目标 | 伊朗导弹突破部分拦截，以色列克制 |
| **十二日战争** | **2025.6.13-24** | **以色列先发制人：空袭纳坦兹/伊斯法罕/福尔多核设施（重创）+ 暗杀核科学家/将领** | **伊朗核能力倒退，美英法德推联合国决议** |
| 2026.2 | 美伊谈判破裂 → **美以联合军事打击伊朗** → 伊朗报复（平民伤亡） | 伊朗总统佩泽什基安公开道歉 |

### 3.2 军事不对称（核维度）

| | 以色列 | 伊朗 |
|---|--------|------|
| 核武器 | ~90枚核弹头（未公开承认） | 未拥有；60%浓缩铀（接近武器级90%） |
| 防空 | 多层（铁穹/大卫投石索/爱国者） | 老化俄制系统（十二日战争被瘫痪） |
| 远程打击 | F-35 隐身突防（已验证） | 弹道导弹库存（拦截率随批次下降） |

**以色列的窗口期逻辑**：代理人（真主党/哈马斯）已被敲掉 → 阿萨德倒台切断陆桥 → 美国（特朗普）全力支持 → 伊朗内部脆弱（最高领袖89岁继任问题、制裁经济）→ **"先拆代理人再打本体"已完成大半**。2025.6 打核设施就是这一逻辑的实践。

### 3.3 伊朗为什么不能全面开战

军力代差 + 以色列核威慑 + 美国参战（2026.2已验证）+ 国内经济崩溃边缘（制裁+通胀+影子船队维持生计）。伊朗的策略是"战略收缩+保留核筹码"——但**2025.6 核设施被炸后，这张王牌受损**。伊朗现在赌的是：重建核能力 + 等以色列/美国犯错 + 俄罗斯/中国外交掩护。

## 四、沙伊线：北京和解与三方博弈

### 4.1 北京协议（2023.3.10）

- 中国斡旋，伊朗与沙特复交（2023.6 利雅得使馆重开、2023.8 德黑兰使馆重开）
- **双方动因**：沙特=从也门战争抽身+美国安全承诺弱化（2021阿富汗撤军）+油价合作；伊朗=多线作战压力下减少敌人数量

### 4.2 中国的五重战略意图

① 能源安全（中东占中国原油进口40%+）② 一带一路安全（贸易路线稳定）③ 展示"全球安全倡议"可替代美国安全架构 ④ 去美元化（石油人民币结算探索）⑤ **低成本高收益：纯外交斡旋，不派一兵一卒**

**核心模式**：美国靠航母+制裁，中国靠"会议室+生意"——北京协议证明了第二种模式在"低烈度纠纷"场景有效。但**对以伊军事冲突，中国无有效约束力**（2026.2美以打击伊朗时中国只能口头呼吁）。

### 4.3 三方博弈矩阵

| 玩家 | 目标 | 手段 | 现状 |
|------|------|------|------|
| 美国 | 反伊朗联盟+保以色列+控石油美元 | 制裁+军事+外交 | 特朗普"亲以反伊"路线（2025.6参战、2026.2联合打击） |
| 中国 | 能源安全+去美元化+影响力 | 斡旋+经贸+武器进口 | 沙伊和解成功案例，但军事冲突无话语权 |
| 沙特 | 双头下注（美安全+中生意） | 油价杠杆+平衡外交 | 加沙战争后与以正常化停滞 |

## 五、石油线：油价、红海、OPEC+、霍尔木兹

### 5.1 油价时间线（2022-2026）

| 时间 | 事件 | 布伦特 |
|------|------|--------|
| 2022.3 | 俄乌战争爆发 | $120+（峰值） |
| 2022下半年-2023 | 衰退担忧+美国释放SPR | 回落 $70-85 |
| 2023.10 | 加沙战争 | 短暂跳涨后回落 |
| 2023.11-2025.10 | 红海危机（胡塞袭船） | 区间震荡，运费暴涨 |
| 2025.6 | 十二日战争（核设施被炸） | 跳涨 |
| 2026.2 | 美以联合打击伊朗 | 冲高至 $100+ |
| 2026.8.1 | 当前 | **$90.12**（近1月 $71.57-$100.69） |

**当前定价结构**：
- OPEC+ 减产保价 → **$70-75 地板价**
- 地缘风险溢价 → **$5-10/桶**（红海+以伊紧张）
- 需求疲软（中国电动车冲击）→ 压制上行

### 5.2 红海危机（已平息但留痕）

胡塞 2023.11 起袭船 → 苏伊士运河收入大减（绕行好望角）→ 运费暴涨 → **2025.10.10 加沙和平计划生效后胡塞停止袭船**（美胡也达成协议）。航运恢复正常，但保险溢价和绕行能力建设留下长期成本。

### 5.3 霍尔木兹情景（未发生，但被定价）

| 情景 | 概率 | 油价冲击 |
|------|:---:|---------|
| 基线（现状） | 高 | $90 中枢 |
| 部分封锁（袭船升级） | 中低 | $120-150 |
| 全面封锁（伊朗铤而走险） | 低 | $200+（1980年代油轮战争先例） |

**关键**：伊朗封锁霍尔木兹=自杀（自己60%出口走该海峡），所以"封锁"更可能是威慑话术。但**以色列打击伊朗能源出口设施**（哈格岛等）是更现实的升级路径。

### 5.4 对华能源安全

- 中东占中国原油进口 40%+（沙特/伊拉克/阿曼/阿联酋/伊朗含影子船队）
- 中国已建全球最大战略储备（约10亿桶+）+ 上海INE原油期货（人民币计价）
- 中沙关系：人民币结算探索中，但**石油人民币短期无法替代石油美元**（结算基础设施+美沙安全条约仍在）

## 七、与本地知识库的衔接

1. **《破灭后世界推演》"第三重门"**：中东军事冲突正是该报告预测的"全球性冲击共振"组成部分。黄金 $4107 历史高位 = 报告"非美元非美资产受益"判断的实盘验证。
2. **温铁军「资源主权国博弈」框架**：伊朗是"资源国被制裁"案例的活标本——但伊朗比俄罗斯脆弱（无完整工业体系），所以俄罗斯能扛住制裁战争，伊朗只能战略收缩。
3. **沃勒斯坦霸权周期**：美国在中东的"霸权透支"（两场战争+撤军+信誉损耗）+ 中国以"会议室"切入 = 霸权转移期的边缘渗透。以色列对伊朗的军事绝对优势 = 半边缘国家借核心国（美国）支持压制边缘国家（伊朗）的经典结构。
