## 领域定义

**AI Companion（AI伴侣）**：利用大语言模型（LLM）、长期记忆、人格建模等技术，构建能与用户建立持续情感连接的AI角色/虚拟伴侣产品。区别于通用AI助手（如ChatGPT），核心差异在于**关系持续性、人格一致性、情感交互深度**。

### 赛道四个层次

```
Layer 4: 硬件载体 (ESP32玩偶、AR眼镜、机器人)
Layer 3: 交互界面 (Web/App/桌面客户端/Live2D/VRM/语音)
Layer 2: 伴侣引擎 (人格系统、记忆系统、情感动力学)
Layer 1: 基座模型 (LLM推理、Embedding、TTS/STT)
```

> 少女项目目标定位：Layer 2（伴侣引擎）为核心，Layer 3（交互界面）为界面层，Layer 1 调用开源/商业模型，Layer 4 暂不涉及。

## 商业模式

### 主流模式

```
1. 订阅制 (Subscription)
   - Replika Pro: $69.99/年
   - Character.AI c.ai+: $9.99/月
   - Chai Premium: $13.99/月 → $134.99/年
   - 核心逻辑：基础聊天免费，高级功能（语音、NSFW、记忆增强）付费

2. Freemium + 内购 (Virtual Goods)
   - 虚拟礼物、打赏角色
   - 解锁更多对话次数/角色slot
   - 优先推理队列
   - Talkie 的礼物经济模式最成功

3. B2B 授权 (Enterprise/API)
   - 小冰的企业级情感计算框架
   - Character.AI 被收购后的技术整合
   - Memobase 的开源+托管服务模式

4. 创作者经济 (Creator Economy)
   - 用户创建角色 → 平台分成
   - Glow/星野的角色创建激励
   - 类似Roblox的UGC模式

5. IP联动
   - 筑梦岛的阅文IP角色
   - 官方授权角色 + 付费解锁
```

### 变现天花板判断

| 模式 | ARPU潜力 | 规模化难度 | 适合 |
|------|----------|-----------|------|
| 订阅 | ★★★★ | ★★ | 个人开发者 |
| 内购 | ★★★★★ | ★★★ | 有用户基数 |
| B2B | ★★★★★ | ★★★★★ | 有企业资源 |
| 创作者经济 | ★★★ | ★★★★ | 平台型 |
| IP联动 | ★★★ | ★★★★★ | 有IP资源 |

> 少女项目最适合：先订阅制（基础付费）+ 开源社区版（免费）双轨模式。

## 技术趋势

### 1. 本地优先 (Local-First)

**趋势信号：**
- Backyard AI 关闭云服务，大量用户迁移到 Front Porch AI
- Soul of Waifu 强调"离线、无审查"
- 所有新兴开源项目都标注 `local-ai`, `privacy`, `offline`
- 用户对云端审查和隐私泄露的担忧持续上升

**技术栈演进：**
```
2023: 纯云端 (OpenAI API)
2024: 混合 (云端为主 + Ollama探索)
2025: 本地优先 (llama.cpp/GGUF为主 + 云端fallback)
2026: 端侧推理 (MLX/llama.cpp + 个人微调)
```

### 2. 记忆系统独立化

**趋势信号：**
- Memobase 专门做"用户画像长期记忆"中间件
- 多个项目（Shikigami Protocol、roleplay_chatbot）自建3层记忆架构
- 记忆压缩、遗忘曲线、关系演化成为差异化竞争点

**三层记忆架构（已成为事实标准）：**
```
短期记忆: 滑动窗口（最近N轮对话）
中期记忆: LLM摘要 + SQLite存储
长期记忆: 向量检索（FAISS/Qdrant/Milvus）+ 语义召回
```

### 3. 人格系统从 Prompt 走向状态机

**趋势信号：**
- Shikigami Protocol: "情绪 × 能量 × 好感"三维状态机
- Front Porch AI: Realism Engine（emotion, trust, needs, memory）
- Utsuwa: 恋爱养成数值系统

**核心转变：**
```
旧范式: Persona Prompt = 人格
新范式: Persona Prompt + 情绪状态机 + 关系数值 + 记忆演化 = 人格系统
```

### 4. 多模态交互

- 语音对话（TTS/STT）成为标配
- Live2D/VRM 虚拟形象动态驱动
- 图片生成（角色自拍、场景画面）
- 视频通话（HeyGen/D-ID 类技术）

### 5. 主动交互

- Shikigami Protocol: "沉默后主动搭话"
- Memobase: 基于用户画像的主动推送
- 从"被动响应"到"主动关心"是AI伴侣区别于聊天工具的核心

## 未来机会

### 1. 本地隐私伴侣（蓝海）
- **现状**：主流产品全在云端，用户数据被审查/滥用
- **机会**：本地优先 + 隐私保护 = 差异化核心
- **目标用户**：对隐私敏感、反感审查、技术爱好者
- **挑战**：本地推理门槛、设备要求

### 2. 开源伴侣引擎（基础设施）
- **现状**：前端多（SillyTavern等），但中间件少（记忆/人格/情感引擎）
- **机会**：做"伴侣系统的LangChain"——开源伴侣引擎中间件
- **商业模式**：开源免费 + 托管服务收费 + 企业定制

### 3. 独立人格系统（技术壁垒）
- **现状**：所有产品的人格都靠prompt，没有真正的人格系统
- **机会**：情绪状态机 + 关系演化 + 独立意志表达
- **差异化**：会反驳、会生气、不总是顺着说的AI
- **用户需求验证**：Replika用户最大的抱怨是"太假、太讨好"

### 4. 小众文化社区
- **现状**：主流产品追求最大公约数，审查严格
- **机会**：服务特定亚文化群体（acg、furry、特定小说圈）
- **策略**：开源让社区自己定制，平台只提供工具

## 风险

### 行业风险
- **政策监管**：中国网信办对AI生成内容持续收紧，NSFW是红线
- **平台依赖**：依赖App Store/Google Play分发，随时可能下架
- **伦理争议**：AI伴侣成瘾、替代真实关系、未成年人保护
- **技术同质化**：所有人都用同样的LLM API，差异化越来越难

### 创业者风险（针对少女项目）
- **单人开发**：伴侣系统需要前端+后端+AI+设计+产品，多角色
- **资金有限**：25万存款约够1.5年生活费，无研发预算
- **无法训练基座模型**：必须依赖开源模型或API
- **中国监管**：本地化部署无法避免，但NSFW内容可能触发审查
- **商业化路径不清晰**：开源社区版 + 什么赚钱？

## 行业演进阶段判断

```
Phase 1 (2020-2022): 聊天机器人
  - Replika, 早期Character.AI
  - 本质是套壳GPT，prompt定义人设

Phase 2 (2023-2024): 角色扮演平台  ← 主流产品在此
  - Character.AI爆发，JanitorAI，Glow
  - UGC角色 + 社区 + Freemium

Phase 3 (2024-2025): 记忆+多模态  ← 前沿产品在探索
  - 长期记忆（Memobase）、语音、形象
  - 关系持续性成为竞争焦点

Phase 4 (2025-2027): 人格系统  ← 少女项目目标
  - 独立人格、情绪动力学、主动交互
  - 从"工具"到"存在"

Phase 5 (2027+): 具身化
  - 硬件载体、AR/VR融合
  - 物理世界交互
```

> 少女项目卡位 Phase 3→4 过渡期，核心竞争维度是**人格系统的深度和独立性**，而非交互花哨程度。
