## Domain（领域定义）

### 领域是什么？

**AI 伴侣（AI Companion）** — 利用 LLM、长期记忆、人格建模、多模态交互技术，构建能与用户建立**持续情感连接**的虚拟角色/伴侣系统。

### 领域边界

核心区别于通用 AI 助手（ChatGPT、Copilot）：

| 维度 | 通用 AI 助手 | AI 伴侣 |
|------|-------------|---------|
| 目标 | 完成任务 | 建立关系 |
| 交互模式 | 问答/指令 | 持续对话 + 主动发起 |
| 记忆需求 | 会话上下文（短） | 跨会话长期记忆（关系演化） |
| 人格 | 统一品牌人格 | 独立个体人格 |
| 情感 | 无/礼貌性 | 情感动力学（会生气、会反驳） |
| 商业模式 | B2B / API | B2C 订阅 + 内购 |
| 隐私敏感度 | 低 | 极高（亲密对话） |

### 核心价值链

```
模型层（LLM推理）
   ↓
记忆层（短期/中期/长期，遗忘曲线，记忆压缩）
   ↓
人格层（情绪状态机，关系数值演化，独立意志表达）
   ↓
交互层（Web/App/桌面，Live2D/VRM，语音TTS/STT）
   ↓
分发层（开源社区/GitHub/App Store/Web）
```

> 少女项目定位：**记忆层 + 人格层是核心战场**，交互层借用开源方案，模型层调用现有 API/本地推理，分发层走 GitHub 开源。

### 用户需求强度

已通过竞品行为验证：

1. **NSFW 是刚需** — Replika 移除 ERP 导致用户大规模流失，JanitorAI 靠"无审查"吸引数百万 MAU
2. **审查反感强烈** — Character.AI 被 Google 收购后过滤力度增强，用户大量外逃
3. **记忆缺失是最大痛点** — 所有竞品用户都在抱怨"AI 不记得我说过什么"
4. **讨好型人格让人疲惫** — Replika 用户最大抱怨是"太假、太讨好"
5. **隐私焦虑持续上升** — Backyard AI 关闭云服务后用户迁移到本地化方案

## Boundary（边界条件）

### 技术边界

| 能做到 | 做不到 |
|--------|--------|
| ✅ 调用开源 LLM（llama.cpp/Ollama）进行推理 | ❌ 训练/微调基座模型（无 GPU 集群） |
| ✅ 构建记忆系统（向量库 + 摘要 + 结构化存储） | ❌ 突破 LLM 本身的能力上限 |
| ✅ 实现情绪状态机 + 关系数值系统 | ❌ 实现真正的"意识"或"理解" |
| ✅ 集成 Live2D/VRM（已有成熟方案） | ❌ 自研视觉渲染引擎 |
| ✅ 集成 TTS/STT（Kokoro + Whisper） | ❌ 自研语音合成模型 |
| ✅ 构建 Web/桌面客户端（Electron/Tauri） | ❌ 原生移动 App（iOS/Android 需要额外技能） |
| ✅ 端到端加密本地存储 | ❌ 100% 防止逆向工程（客户端安全有上限） |

### 市场边界（天花板）

| 天花板类型 | 高度 | 说明 |
|-----------|------|------|
| 本地优先用户群 | 百万级 | 需要一定技术能力，比云端用户少 1-2 个数量级 |
| 中国市场 | 受限 | NSFW/无审查定位与监管矛盾，需走海外或低调运营 |
| 海外市场 | 可达 | GitHub + 英文社区，但营销/运营需要额外投入 |
| 整体天花板 | 10-50 万活跃用户 | 本地优先 + 技术门槛是天然漏斗 |

### 资源边界（个人开发者 + 25 万存款）

| 资源 | 预算 | 可持续性 |
|------|------|---------|
| 生活费 | ~1.5 万/月 | 约 16 个月 |
| 云计算/API | ~500-2000/月 | 本地优先降低此成本 |
| 设计/美术 | ~0（用户动画背景） | 可自己完成基本视觉 |
| 营销 | ~0（有机增长） | 依赖 GitHub + 社区传播 |
| 法律/合规 | ~0（开源免责） | 风险自担 |

> **关键约束：可投入有效开发时间约 4-6 个月全职当量（分散在 10-14 个月墙钟时间内），具体取决于考研结果。7-9 月每天 1-2h → 9-12 月暂停备考 → 考研后恢复。不能雇人，必须走开源有机增长路线。详见补充分析文档。**

### 用户边界（目标用户画像）

**核心用户（早期采用者）：**

- 18-35 岁，技术爱好者或二次元/ACG 圈
- 对 Character.AI/Replika 的审查和隐私问题不满
- 愿意折腾本地部署和配置
- 追求"真实感"而非"讨好感"的 AI 互动
- 有付费意愿但期望值合理（不是追求完美产品）

**不适合的用户：**

- 追求零门槛一键使用的普通用户（产品早期做不到）
- 需要移动端原生体验的用户（初期只有桌面端）
- 中国国内审查合规要求的用户（本地优先绕过了审查，但分发受限）

## Value（价值判断）

### 用户愿意付费吗？

**是的，但付费点不在"聊天"，而在"关系持续性和隐私安全感"。**

| 付费点 | 意愿 | 理由 |
|--------|------|------|
| 云备份（加密记忆同步） | ★★★★ | 换设备不丢记忆，类似 iCloud/1Password |
| 高级人格定制 | ★★★ | 深度个性化角色参数 |
| 优先支持/社区 | ★★ | 开源项目的典型模式 |
| 企业/商业授权 | ★★★ | 如果伴侣引擎成为基础设施 |

### 市场规模

- **TAM（总可寻址市场）**：全球 AI 伴侣用户 ~100M+
- **SAM（可服务市场）**：本地优先/隐私敏感用户 ~5-10M
- **SOM（可获取市场）**：GitHub 开源社区 + 二次元/ACG 圈 ~50K-200K 早期用户

> 这不是一个追求大众市场的项目，是**利基市场 + 开源社区**路线。

### 是否有网络效应或数据飞轮？

| 效应 | 强度 | 说明 |
|------|------|------|
| UGC（用户创建角色） | ★★ | 如果开放角色创建，但有 Character.AI 的百万角色在前 |
| 开源社区贡献 | ★★★ | 插件生态、记忆模型优化、语言本地化 |
| 记忆数据飞轮 | ★★ | 每个用户的记忆是独立的（本地），不形成跨用户飞轮 |
| 人格模版市场 | ★★★ | 用户分享人格配置模版 → 吸引更多用户 |

> 数据飞轮较弱（本地优先的代价），但开源社区飞轮可培养。

## 推荐等级

### 🏆 A 级：立即验证 — 独立人格记忆引擎（Personality + Memory Engine）

**为什么是 A 级：**

这是所有竞品（云端巨头 + 开源项目）的**共同盲区**。没有任何产品解决了"真正的人格一致性长期记忆"。这是一个可独立开发的模块，不需要前端能力、不需要移动端、不需要社区。

**验证路径：**

```
第一步：原型验证（有效开发时间 ~2-3 个月，墙钟时间需考虑 9-12 月备考中断）
  - 用 Python 实现一个情绪状态机（valence-arousal 模型）
  - 集成一个向量记忆库（FAISS/ChromaDB）
  - 做一个简单的 CLI/Terminal 对话界面
  - 验证：角色能否在 100 轮对话后保持人格一致性？

第二步：中间件化（3-4 个月）
  - 封装为独立 API 服务（FastAPI）
  - 提供 MCP 协议接入点
  - 开源发布 + 文档
  - 验证：第三方（如 SillyTavern）能否接入？

第三步：完整伴侣应用（6-12 个月）
  - 集成 Live2D + TTS
  - 构建桌面客户端（Tauri/Electron）
  - 云备份服务（可选付费）
```

> **关键：从最难但最独立的一层（记忆+人格引擎）开始，而非从最显眼但最依赖他人的一层（前端/视觉）开始。这是你当前技术能力下最高杠杆的切入点。**

### 👀 B 级：长期观察 — 完整桌面伴侣应用

**为什么是 B 级：**

- 需要前端能力（Live2D、UI、桌面框架），你当前不具备
- 需要产品打磨（UX、交互设计、多语言），需要用户反馈迭代
- 但方向上正确 — 等 A 级模块验证后自然过渡到 B 级

### ❌ C 级：不建议投入

- **做云端 AI 伴侣平台** — 烧钱 + 监管 + 与 Character.AI/MiniMax 正面竞争 = 自杀
- **做移动端 App** — iOS/Android 原生开发 + App Store 审查 = 技术和政策双重壁垒
- **做硬件载体** — ESP32 玩偶/AR 眼镜 = 需要硬件工程能力 + 供应链 = 不适合
- **做 UGC 角色社区** — 需要用户基础 + 内容审核 = 不适合个人开发者

## 关键判断

> **"不要做更好的 Character.AI，做 Character.AI 做不到的事。"**

少女项目不是在大厂的主场（用户规模、模型能力、资本）竞争，而是在大厂的盲区（本地隐私、独立人格、开源生态）建立不可替代性。

这不是一个"颠覆式创新"（Disruptive Innovation），而是"正交竞争"（Orthogonal Competition）——在一个大厂因为商业模式和监管压力而无法进入的维度上，提供他们永远无法提供的价值。
