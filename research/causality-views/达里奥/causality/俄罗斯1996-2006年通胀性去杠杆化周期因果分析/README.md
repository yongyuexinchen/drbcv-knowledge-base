# 俄罗斯1996-2006年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：俄罗斯1996-2006年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 外部压力下放弃钉住汇率制度，任货币浮动 → 决策者设定利率的灵活性增大
- 外资以不可持续方式强劲流入，积累大量外币债务（债务总额达GDP的112%，外币债务占GDP的38%） → 国际收支危机 货币危机爆发（1997-1998年）
- 货币大幅贬值（实际汇率下降72%） → 通胀率高企且不断上升（最高达91%）
- 放弃钉住汇率制度，实施紧缩政策（减少进口支出、提高本国货币吸引力） → 去杠杆化阶段结束，经济恢复增长（实际GDP用1.8年恢复至峰
