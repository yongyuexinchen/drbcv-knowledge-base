# 政治格局变化，民粹主义领导人上台（罗斯福）

> 属于因果簇：[[美国1926-1936年通缩性去杠杆化周期因果分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济萧条和痛苦去杠杆化 |
| **DV（因变量）** | 政治格局变化，民粹主义领导人上台（罗斯福） |
| **Chain（传导链）** | 经济萧条导致失业率上升（23%）、收入下降、社会不满情绪积累 → 民众对现有政府和经济体制失去信心 → 民粹主义领导人（罗斯福）提出改革方案，获得广泛支持 → 政治格局发生显著变化 |
| **Lag（时滞）** | 经济萧条持续约4年后（1933年） |
| **Threshold（临界值）** | 失业率上升超过20%，GDP下降超过25% |
| **前提与约束（Premises）** | 经济萧条严重且持续时间长；现有政府应对不力；存在有吸引力的民粹主义替代方案 |
| **Falsification（证伪条件）** | 如果经济萧条后没有出现政治格局变化或民粹主义领导人上台，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像船在风暴中受损，船员们会推翻无能的船长，选出一个他们认为能带领大家脱险的新船长

### 🔗 文字版因果链

1. 经济萧条导致失业率上升（23%）、收入下降、社会不满情绪积累
2. 民众对现有政府和经济体制失去信心
3. 民粹主义领导人（罗斯福）提出改革方案，获得广泛支持
4. 政治格局发生显著变化
