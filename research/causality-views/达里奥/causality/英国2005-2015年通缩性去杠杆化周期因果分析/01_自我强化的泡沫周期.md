# 自我强化的泡沫周期

> 属于因果簇：[[英国2005-2015年通缩性去杠杆化周期因果分析]]（第1块/7块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加与经济增长强劲 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加推动投资和消费，刺激经济增长 → 经济增长提高资产回报率，鼓励更多借债 → 更多借债进一步推动债务和资金增加，形成正反馈循环 |
| **Lag（时滞）** | 持续数年（2005-2008年） |
| **Threshold（临界值）** | 债务占GDP比例达到437%，增幅为GDP的89% |
| **前提与约束（Premises）** | 债务以英镑计价，大多数债权人是英国人；投资流入强劲，平均约占GDP的14%；经常账户赤字占GDP的3%；经济增速达到3%，GDP缺口峰值达4%；股票平均年化回报率为8% |
| **Falsification（证伪条件）** | 如果债务增加但经济增长停滞或资产回报率下降，泡沫周期不会形成 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球：雪球越大，滚得越快，但最终可能因过大而崩溃

### 🔗 文字版因果链

1. 债务增加推动投资和消费，刺激经济增长
2. 经济增长提高资产回报率，鼓励更多借债
3. 更多借债进一步推动债务和资金增加，形成正反馈循环
