# 自我强化的经济萧条和痛苦的去杠杆化

> 属于因果簇：[[英国2005-2015年通缩性去杠杆化周期因果分析]]（第3块/7块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 2008年全球金融危机冲击 |
| **DV（因变量）** | 自我强化的经济萧条和痛苦的去杠杆化 |
| **Chain（传导链）** | 金融危机导致GDP、股价和房价下跌 → 资产价格下跌减少抵押品价值，降低借贷能力 → 借贷减少导致投资和消费下降，进一步压低GDP → 收入减少增加偿债负担，导致更多违约和金融机构压力 → 金融机构压力导致信贷紧缩，加剧经济下行 |
| **Lag（时滞）** | 2008-2009年 |
| **Threshold（临界值）** | GDP下跌6%，股价下跌52%，房价下跌19%，失业率上升3% |
| **前提与约束（Premises）** | 偿债总额占GDP的82%，使英国容易受到冲击；金融机构面临巨大压力 |
| **Falsification（证伪条件）** | 如果金融危机发生但GDP、股价和房价没有出现自我强化式下跌，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多米诺骨牌：第一块倒下后，连锁反应导致全部倒下

### 🔗 文字版因果链

1. 金融危机导致GDP、股价和房价下跌
2. 资产价格下跌减少抵押品价值，降低借贷能力
3. 借贷减少导致投资和消费下降，进一步压低GDP
4. 收入减少增加偿债负担，导致更多违约和金融机构压力
5. 金融机构压力导致信贷紧缩，加剧经济下行
