# 俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 外部压力下允许货币浮动 → 决策者设定利率的灵活性增加
- 大量资本流入、债务增加、经济增长强劲、资产回报丰厚 → 自我强化的泡沫周期（不可持续发展）
- 外资流入减少（资本流入降幅为GDP的21%） → 货币政策收紧（短期利率上调19%）
- 货币贬值（实际汇率下降21%） → 通胀率上升（最高达15%）
- 货币贬值（导致以外币计价的偿债负担加重） → 债务占GDP比例增加（年化增幅12%）
- 决策者实施紧缩政策（提高本国货币吸引力） → 和谐的去杠杆化（债务占GDP比例下降14%，年化降幅8%）
