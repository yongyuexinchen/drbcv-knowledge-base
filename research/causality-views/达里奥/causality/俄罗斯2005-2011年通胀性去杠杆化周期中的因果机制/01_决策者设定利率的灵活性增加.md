# 决策者设定利率的灵活性增加

> 属于因果簇：[[俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部压力下允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的灵活性增加 |
| **Chain（传导链）** | 外部压力导致资本外流和货币贬值压力 → 决策者选择允许货币浮动而非固定汇率 → 货币贬值吸收部分外部冲击，减少对利率的被动调整需求 → 决策者获得更大的利率政策空间，以平衡通胀和增长 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 货币浮动且无大规模干预 |
| **前提与约束（Premises）** | 国家面临外部压力（如资本外流）；决策者优先考虑政策灵活性而非汇率稳定；存在一定程度的通胀容忍度 |
| **Falsification（证伪条件）** | 如果允许货币浮动后，利率灵活性未增加或政策空间反而受限，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像松开握紧的拳头，虽然暂时会晃动，但能更灵活地应对打击。

### 🔗 文字版因果链

1. 外部压力导致资本外流和货币贬值压力
2. 决策者选择允许货币浮动而非固定汇率
3. 货币贬值吸收部分外部冲击，减少对利率的被动调整需求
4. 决策者获得更大的利率政策空间，以平衡通胀和增长
