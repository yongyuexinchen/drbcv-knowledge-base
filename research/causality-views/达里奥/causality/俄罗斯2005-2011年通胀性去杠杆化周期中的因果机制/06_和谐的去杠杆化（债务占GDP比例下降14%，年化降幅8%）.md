## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策（提高本国货币吸引力） |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP比例下降14%，年化降幅8%） |
| **Chain（传导链）** | 决策者实施紧缩政策，提高利率或减少支出 → 本国货币吸引力增强，资本外流减缓 → 名义收入增加（因通胀或增长），债务负担相对减轻 → 债务占GDP比例下降 |
| **Lag（时滞）** | 中期（调整时期，约2-3年） |
| **Threshold（临界值）** | 使用9个典型政策工具中的4个，债务占GDP比例下降14% |
| **前提与约束（Premises）** | 决策者积极管控金融机构和处理坏账；实施足够的紧缩政策；本国货币大幅贬值后获得竞争力 |
| **Falsification（证伪条件）** | 如果紧缩政策未导致债务占GDP比例下降或下降幅度小于14%，则该断言不成立 |
| **Confidence（确信度）** | well-established |
