# 巴西1987-1995年恶性通胀性去杠杆化周期（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：巴西1987-1995年恶性通胀性去杠杆化周期.md

## 总体因果图

- 债务不断增加（尤其以外币计价的债务） → 自我强化的泡沫周期（经济增长强劲、股市回报丰厚）
- 高债务水平（尤其外币债务） → 自我强化的经济萧条和国际收支危机 货币危机
- 紧缩措施未能带来必要调整 → 汇率下跌和恶性通胀旋涡
