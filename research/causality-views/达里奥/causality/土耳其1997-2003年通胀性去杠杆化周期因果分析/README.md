# 土耳其1997-2003年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：土耳其1997-2003年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加，股市回报丰厚，经济增长强劲 → 自我强化的泡沫周期
- 外资流入减少（资本流入降幅为GDP的10%） → 货币政策收紧、货币大幅贬值、GDP和股价下跌、失业率上升
- 决策者放弃捍卫货币，允许货币贬值 → 债务占GDP比例增加9%（年化增幅6%）
- 实施紧缩政策、积极管控金融机构、IMF援助和结构性改革 → 和谐的去杠杆化，债务占GDP比例下降，经济恢复增长
