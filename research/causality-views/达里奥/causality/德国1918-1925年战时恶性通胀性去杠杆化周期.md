# 德国1918-1925年战时恶性通胀性去杠杆化周期

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 战争期间大规模举债（债务升至GDP的158%，其中64%为外币计价） |
| **DV（因变量）** | 战后恶性通胀（通胀率最高超过10000%） |
| **Chain（传导链）** | 战争期间政府大举借款，债务激增且以外币为主 → 战后工业基础受损，经济萧条，收入下降，政府继续承担战争开销 → 财政赤字扩大（峰值占GDP的11%），债务占GDP比例进一步上升165% → 紧缩措施不足以调整国际收支，资本外流，汇率下跌 → 决策者通过印钞弥补资金外流，货币供应激增 → 通胀预期自我强化，形成汇率下跌与通胀螺旋，最终恶性通胀 |
| **Lag（时滞）** | 从战争结束（1918年）到恶性通胀高峰（1923年），约5年；实际GDP恢复至战前峰值需15年 |
| **Threshold（临界值）** | 财政赤字占GDP比例超过11%时，通胀螺旋加速；通胀率超过10000%为恶性通胀峰值 |
| **前提与约束（Premises）** | 战败国身份，背负以外币计价的巨额债务；工业基础大面积受损，经济产出下降；政府继续承担战争相关开销，财政赤字持续；紧缩措施不足以恢复国际收支平衡；决策者选择印钞而非完全紧缩政策 |
| **Falsification（证伪条件）** | 若德国在战后采取足够紧缩的财政货币政策，或获得外部援助（如道威斯计划提前实施），通胀未超过10000%，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭因战争欠下巨额外债，战后收入锐减，但支出不减，只能靠借新债或印钞度日，最终货币贬值，物价飞涨，生活陷入恶性循环

### 🔗 文字版因果链

1. 战争期间政府大举借款，债务激增且以外币为主
2. 战后工业基础受损，经济萧条，收入下降，政府继续承担战争开销
3. 财政赤字扩大（峰值占GDP的11%），债务占GDP比例进一步上升165%
4. 紧缩措施不足以调整国际收支，资本外流，汇率下跌
5. 决策者通过印钞弥补资金外流，货币供应激增
6. 通胀预期自我强化，形成汇率下跌与通胀螺旋，最终恶性通胀
