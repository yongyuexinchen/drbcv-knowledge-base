# 葡萄牙通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：葡萄牙通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加、股市回报丰厚、经济增长强劲、外资流入强劲（占GDP约10%） → 自我强化的泡沫周期，债务达到GDP的273%，经济温和增长，
- 外资流入减少（投资组合流入降幅为GDP的40%） → GDP、股价、房价自我强化式下跌，失业率上升，金融机构压力增
- 欧洲央行提供充足经济刺激（M0增幅达GDP的15%，利率降至0%，实际汇率平均-1%） → 痛苦去杠杆化转变为和谐去杠杆化，经济步入通货再膨胀阶段，失业
