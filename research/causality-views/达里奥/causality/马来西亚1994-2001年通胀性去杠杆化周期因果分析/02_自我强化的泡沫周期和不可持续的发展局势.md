# 自我强化的泡沫周期和不可持续的发展局势

> 属于因果簇：[[马来西亚1994-2001年通胀性去杠杆化周期因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加、经济增长强劲（泡沫阶段） |
| **DV（因变量）** | 自我强化的泡沫周期和不可持续的发展局势 |
| **Chain（传导链）** | 大量资本流入推动债务增加和经济增长 → 经济增长吸引更多资本流入，形成正反馈循环 → 债务水平达到高位（占GDP 212%），且外币债务占比高（39%），使经济脆弱 → 经常账户赤字（占GDP 8%）依赖外资流入填补，加剧外部脆弱性 → 最终形成不可持续的泡沫局势 |
| **Lag（时滞）** | 数年（1994-1997年泡沫积累） |
| **Threshold（临界值）** | 债务占GDP超过200%，外币债务占GDP约39%，经常账户赤字占GDP 8%，GDP缺口峰值9% |
| **前提与约束（Premises）** | 资本流入持续强劲（平均占GDP 6%）；外部环境宽松，资金充裕；国内经济基本面看似强劲（增长10%） |
| **Falsification（证伪条件）** | 如果资本流入和债务增加没有导致经济脆弱或泡沫破裂，或者经济能够持续增长而不发生危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像吹气球，不断吹气（资本流入）使气球变大（债务和增长），但气球壁变薄（脆弱性增加），最终容易破裂。

### 🔗 文字版因果链

1. 大量资本流入推动债务增加和经济增长
2. 经济增长吸引更多资本流入，形成正反馈循环
3. 债务水平达到高位（占GDP 212%），且外币债务占比高（39%），使经济脆弱
4. 经常账户赤字（占GDP 8%）依赖外资流入填补，加剧外部脆弱性
5. 最终形成不可持续的泡沫局势
