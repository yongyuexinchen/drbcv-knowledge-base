# 决策者设定利率的更大灵活性

> 属于因果簇：[[马来西亚1994-2001年通胀性去杠杆化周期因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部压力下允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的更大灵活性 |
| **Chain（传导链）** | 外部压力导致资本外流和货币贬值压力 → 允许货币浮动而非固定汇率，使汇率调整吸收部分外部冲击 → 货币政策不再受汇率稳定目标束缚，可更灵活地调整利率以应对国内经济状况 |
| **Lag（时滞）** | 短期（数月至一年内） |
| **Threshold（临界值）** | 货币浮动后，汇率调整幅度足以缓解外部压力，且通胀上升在可控范围内（本案例中通胀最高5%） |
| **前提与约束（Premises）** | 国家面临外部压力，如资本外流或货币危机；决策者选择放弃固定汇率或钉住汇率制度；货币贬值不会引发恶性通胀（本案例中风险因素较少） |
| **Falsification（证伪条件）** | 如果允许货币浮动后，决策者设定利率的灵活性没有增加，或者货币政策反而受到更大约束（如因通胀失控而被迫紧缩），则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像松开刹车让车自然减速，虽然会颠簸，但比一直踩着刹车（固定汇率）更能灵活调整方向。

### 🔗 文字版因果链

1. 外部压力导致资本外流和货币贬值压力
2. 允许货币浮动而非固定汇率，使汇率调整吸收部分外部冲击
3. 货币政策不再受汇率稳定目标束缚，可更灵活地调整利率以应对国内经济状况
