## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部压力下允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的灵活性增加 |
| **Chain（传导链）** | 外部压力导致资本外流和货币贬值压力 → 允许货币浮动而非固定汇率，使汇率成为调整机制 → 汇率调整吸收部分外部冲击，减轻货币政策负担 → 决策者获得更大的利率设定空间 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 货币浮动需在资本账户开放且汇率弹性足够的情况下 |
| **前提与约束（Premises）** | 国家面临外部压力（如资本外流）；决策者选择不捍卫固定汇率；存在通胀容忍度 |
| **Falsification（证伪条件）** | 若允许货币浮动后利率灵活性未增加或经济恶化，则断言不成立 |
| **Confidence（确信度）** | well-established |

3. 汇率调整吸收部分外部冲击，减轻货币政策负担
4. 决策者获得更大的利率设定空间

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加、经济增长强劲、房地产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期（不可持续发展） |
| **Chain（传导链）** | 资本流入增加，债务累积 → 经济增长强劲，房地产回报高 → 这些因素相互促进，形成正反馈 → 债务达到危机前峰值，占GDP的58%，其中外币债务占GDP的30% → 经济脆弱性增加，对外资依赖加深 |
| **Lag（时滞）** | 约3年（1995-1998） |
| **Threshold（临界值）** | 债务占GDP超过58%，外币债务占GDP的30%，经常账户赤字占GDP的5% |
| **前提与约束（Premises）** | 资本流入持续强劲（平均占GDP的8%）；实际汇率升值（峰值16%）；外部环境稳定（未发生外部冲击） |
| **Falsification（证伪条件）** | 若债务和资本流入增加但未导致泡沫或危机，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同吹气球，越吹越大但终将破裂

### 🔗 文字版因果链

1. 资本流入增加，债务累积
2. 经济增长强劲，房地产回报高
3. 这些因素相互促进，形成正反馈
4. 债务达到危机前峰值，占GDP的58%，其中外币债务占GDP的30%
5. 经济脆弱性增加，对外资依赖加深

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部冲击（1997年亚洲金融危机）导致资本流入减少 |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 外资流入减少（资本流入降幅为GDP的8%） → 货币政策紧缩（短期利率上调20%） → 货币大幅贬值（实际汇率下降45%） → GDP和股价自我强化式下跌（分别跌7%和66%） → 失业率上升6%，通胀率最高达20% → 金融机构面临压力，央行外汇储备减少37% |
| **Lag（时滞）** | 1998-2003年，持续5年 |
| **Threshold（临界值）** | 资本流入降幅超过GDP的8%，短期利率上调20%，实际汇率下降45% |
| **前提与约束（Premises）** | 高债务水平（尤其外币债务）；依赖外国资金流入；存在约一半典型风险因素（如长期忽视通胀管控） |
| **Falsification（证伪条件）** | 若外部冲击未导致危机或危机程度较轻，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同多米诺骨牌，第一块倒下引发连锁反应

### 🔗 文字版因果链

1. 外资流入减少（资本流入降幅为GDP的8%）
2. 货币政策紧缩（短期利率上调20%）
3. 货币大幅贬值（实际汇率下降45%）
4. GDP和股价自我强化式下跌（分别跌7%和66%）
5. 失业率上升6%，通胀率最高达20%
6. 金融机构面临压力，央行外汇储备减少37%

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策、积极管控金融机构、处理坏账、结构性改革 |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP比例下降16%，经济恢复） |
| **Chain（传导链）** | 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的5%） → 提高本国货币吸引力 → 积极管控金融机构（银行国有化、提供流动性、直接购买问题资产） → 实施结构性改革增强劳动力市场灵活性 → 名义收入增加，债务与收入比率下降 → 实际汇率贬值至-29%，重新获得竞争力 → 实际GDP用4年恢复，股价7年恢复 |
| **Lag（时滞）** | 约4-7年（2003-2008） |
| **Threshold（临界值）** | 使用9个典型政策工具中的6个，债务占GDP比例下降16%（年化降幅3%） |
| **前提与约束（Premises）** | 决策者放弃捍卫货币，允许货币贬值；IMF援助计划支持；政策执行力度足够 |
| **Falsification（证伪条件）** | 若实施类似政策但债务未下降或经济未恢复，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同病人接受治疗，虽然痛苦但最终康复

### 🔗 文字版因果链

1. 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的5%）
2. 提高本国货币吸引力
3. 积极管控金融机构（银行国有化、提供流动性、直接购买问题资产）
4. 实施结构性改革增强劳动力市场灵活性
5. 名义收入增加，债务与收入比率下降
6. 实际汇率贬值至-29%，重新获得竞争力
7. 实际GDP用4年恢复，股价7年恢复
