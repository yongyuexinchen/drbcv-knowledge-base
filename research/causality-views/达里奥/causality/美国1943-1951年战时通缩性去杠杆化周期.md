# 美国1943-1951年战时通缩性去杠杆化周期

> **领域**：宏观经济学　|　**来源**：chapter_94.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 二战期间大规模借款以填补财政赤字 |
| **DV（因变量）** | 战后经济衰退（GDP下跌13%，失业率上升5%） |
| **Chain（传导链）** | 战争期间政府大量借款，债务升至GDP的150% → 经济转向战争生产，战后生产模式调整 → 战争结束，政府支出骤减，经济缺乏支撑 → GDP陷入自我强化式下跌，失业率上升 |
| **Lag（时滞）** | 战争结束后立即显现，持续1945-1950年 |
| **Threshold（临界值）** | 债务占GDP比例达到150% |
| **前提与约束（Premises）** | 美国为战胜国，战后衰退程度较轻；债务以美元计价，债权人为美国人；战争期间经济数据不反映典型关联性 |
| **Falsification（证伪条件）** | 若战后GDP未出现下跌或失业率未上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家庭为战争或重大事件大量借贷，事件结束后收入骤减，导致家庭经济陷入困境

### 🔗 文字版因果链

1. 战争期间政府大量借款，债务升至GDP的150%
2. 经济转向战争生产，战后生产模式调整
3. 战争结束，政府支出骤减，经济缺乏支撑
4. GDP陷入自我强化式下跌，失业率上升

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策与财政政策） |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP比例下降22%，失业率下降2%） |
| **Chain（传导链）** | 战后衰退持续较长时间，决策者采取刺激措施 → M0实际水平下降（降幅为GDP的0.9%），利率降至1% → 名义经济增长率（11%）远高于名义利率（2%） → 收入增加，债务与收入比率下降，经济活力提升 |
| **Lag（时滞）** | 刺激政策实施后，从1950年开始显现，实际GDP用6年达到前峰值 |
| **Threshold（临界值）** | 名义经济增长率高于名义利率（11% vs 2%） |
| **前提与约束（Premises）** | 决策者维持宽松政策，即使经济活力提升；美国为战胜国，具备政策空间；债务以本币计价，债权人为国内居民 |
| **Falsification（证伪条件）** | 若刺激政策未能降低债务占GDP比例或失业率未下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同病人大病后，医生给予充足营养和休息，使身体逐步恢复健康，而非强行手术

### 🔗 文字版因果链

1. 战后衰退持续较长时间，决策者采取刺激措施
2. M0实际水平下降（降幅为GDP的0.9%），利率降至1%
3. 名义经济增长率（11%）远高于名义利率（2%）
4. 收入增加，债务与收入比率下降，经济活力提升
