# 俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性.md

## 总体因果图

- 允许货币浮动（而非固定汇率） → 决策者设定利率的更大灵活性
- 外资以不可持续的方式强劲流入 → 积累大量债务（占GDP的89%，升幅为GDP的19%）
- 外资流入减少（资本流入降幅为GDP的8%） → 货币政策紧缩（短期利率上调7%）
- 货币大幅贬值（实际汇率下降30%） → GDP与股价自我强化式下跌（跌幅分别为4%和46%）
- 货币疲软 → 通胀率处于温和水平（最高达18%）
- 央行动用外汇储备维持货币稳定 → 外汇储备减少26%
- 实施紧缩政策（提高本国货币吸引力） → 痛苦的去杠杆化阶段持续时间略短于平均水平
- 本国货币大幅贬值（实际汇率跌至-17%） → 重新获得竞争力
