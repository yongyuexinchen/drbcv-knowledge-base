# 痛苦的去杠杆化阶段持续时间略短于平均水平

> 属于因果簇：[[俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第7块/8块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施紧缩政策（提高本国货币吸引力） |
| **DV（因变量）** | 痛苦的去杠杆化阶段持续时间略短于平均水平 |
| **Chain（传导链）** | 决策者实施紧缩政策，提高利率和财政纪律 → 本国货币吸引力增强，资本外流减缓 → 经济调整加快，去杠杆化过程缩短 → 痛苦阶段持续时间略短于平均水平 |
| **Lag（时滞）** | 中期（1-2年） |
| **Threshold（临界值）** | 使用了9个典型政策工具中的4个 |
| **前提与约束（Premises）** | 决策者愿意承受短期痛苦；政策执行力度足够；外部环境不再恶化 |
| **Falsification（证伪条件）** | 如果实施紧缩政策但去杠杆化时间未缩短，或反而延长，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像长痛不如短痛，通过节食和锻炼（紧缩政策）快速减肥，虽然过程痛苦，但比慢慢拖更有效。

### 🔗 文字版因果链

1. 决策者实施紧缩政策，提高利率和财政纪律
2. 本国货币吸引力增强，资本外流减缓
3. 经济调整加快，去杠杆化过程缩短
4. 痛苦阶段持续时间略短于平均水平
