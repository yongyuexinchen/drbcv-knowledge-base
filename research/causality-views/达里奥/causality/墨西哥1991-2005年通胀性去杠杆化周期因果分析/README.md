# 墨西哥1991-2005年通胀性去杠杆化周期因果分析（因果簇）

## 总体因果图

- 大量资本流入、债务增加（尤其外币计价债务占GDP25%） → 自我强化的泡沫周期（债务升至GDP85%，股市年回报25%，
- 政治暴力事件爆发（外部冲击） → 自我强化式经济萧条和国际收支危机 货币危机（GDP下跌10%
- 决策者实施紧缩政策、积极管控金融机构、IMF援助和结构性改革 → 和谐的去杠杆化（债务占GDP下降41%，实际GDP用2年恢复
