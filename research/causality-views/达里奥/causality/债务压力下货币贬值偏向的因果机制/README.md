# 债务压力下货币贬值偏向的因果机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：债务压力下货币贬值偏向的因果机制.md

## 总体因果图

- 高债务和借贷水平 → 政策制定者倾向于压低实际利率、贬值货币
- 国家元首寻求连任或民众满意 → 倾向于更多刺激政策（宽松货币政策）
- 中央银行家的独立性和专业判断 → 在宽松与紧缩之间取得平衡，逆势操作
- 极端环境（如债务危机、政治冲突） → 货币政策与政治权力的分离机制瓦解
- 弱货币/高通胀问题严重到无法忽视 → 政策制定者最终可能收紧货币政策（但往往滞后）
