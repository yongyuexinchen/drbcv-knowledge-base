# 战后经济衰退（GDP下跌13%，失业率上升5%）

> 属于因果簇：[[美国1943-1951年战时通缩性去杠杆化周期]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 二战期间大规模借款以填补财政赤字 |
| **DV（因变量）** | 战后经济衰退（GDP下跌13%，失业率上升5%） |
| **Chain（传导链）** | 战争期间政府大量借款，债务升至GDP的150% → 经济转向战争生产，战后生产模式调整 → 战争结束，政府支出骤减，经济缺乏支撑 → GDP陷入自我强化式下跌，失业率上升 |
| **Lag（时滞）** | 战争结束后立即显现，持续1945-1950年 |
| **Threshold（临界值）** | 债务占GDP比例达到150% |
| **前提与约束（Premises）** | 美国为战胜国，战后衰退程度较轻；债务以美元计价，债权人为美国人；战争期间经济数据不反映典型关联性 |
| **Falsification（证伪条件）** | 若战后GDP未出现下跌或失业率未上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家庭为战争或重大事件大量借贷，事件结束后收入骤减，导致家庭经济陷入困境

### 🔗 文字版因果链

1. 战争期间政府大量借款，债务升至GDP的150%
2. 经济转向战争生产，战后生产模式调整
3. 战争结束，政府支出骤减，经济缺乏支撑
4. GDP陷入自我强化式下跌，失业率上升
