## 总体因果图

- 财政困境、巨大财富与价值观差距、剧烈经济冲击同时存在（有毒组合） → 重大内部冲突（内战或革命）的可能性增加
- 民主制度在剧烈冲突时期的功能失调 → 民粹主义强人领导的革命崛起
- 强有力的和平改革者（领导力） → 国家避免灾难性崩溃，实现和平改革
