## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入和债务累积（外币计价债务占GDP的51%） |
| **DV（因变量）** | 自我强化的泡沫周期（债务占GDP达183%，GDP增速8%，股市年回报12%） |
| **Chain（传导链）** | 大量资本流入（平均占GDP的15%）填补经常账户赤字（占GDP的9%） → 债务增加，尤其是外币债务，使经济易受外资撤出影响 → 高资产回报率鼓励更多借债，刺激经济增长 → 债务和资金增加支撑经济增长，形成自我强化的泡沫 |
| **Lag（时滞）** | 约3年（1993-1996年泡沫积累，1996-1998年危机爆发） |
| **Threshold（临界值）** | 债务占GDP的183%（危机前峰值），外币债务占GDP的51%，经常账户赤字占GDP的9% |
| **前提与约束（Premises）** | 依赖外国资金流入；实行钉住汇率制度；存在外部压力 |
| **Falsification（证伪条件）** | 如果资本流入减少但未导致货币危机或经济萧条，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠信用卡透支维持高消费，债务越滚越大，一旦信用卡被停，生活立刻陷入困境。

### 🔗 文字版因果链

1. 大量资本流入（平均占GDP的15%）填补经常账户赤字（占GDP的9%）
2. 债务增加，尤其是外币债务，使经济易受外资撤出影响
3. 高资产回报率鼓励更多借债，刺激经济增长
4. 债务和资金增加支撑经济增长，形成自我强化的泡沫

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的34%） |
| **DV（因变量）** | 货币政策收紧、货币贬值、GDP和股价下跌（GDP跌14%，股价跌87%） |
| **Chain（传导链）** | 外资流入减少，导致国际收支压力 → 央行提高短期利率（上调11%）以维持货币稳定 → 实际汇率下降19%，货币大幅贬值 → 企业/银行因负债过高遭遇亏损潮，GDP和股价陷入自我强化式下跌 |
| **Lag（时滞）** | 约1-2年（1996-1998年） |
| **Threshold（临界值）** | 资本流入降幅为GDP的34%，偿债总额占GDP的49% |
| **前提与约束（Premises）** | 存在大量外币计价债务；央行外汇储备有限（减少100%）；企业/银行负债过高 |
| **Falsification（证伪条件）** | 如果外资流入减少但未导致货币大幅贬值或GDP大幅下跌，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一家公司突然失去主要客户，收入骤减，不得不借高利贷维持运营，最终资不抵债。

### 🔗 文字版因果链

1. 外资流入减少，导致国际收支压力
2. 央行提高短期利率（上调11%）以维持货币稳定
3. 实际汇率下降19%，货币大幅贬值
4. 企业/银行因负债过高遭遇亏损潮，GDP和股价陷入自我强化式下跌

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者放弃捍卫货币，允许货币浮动 |
| **DV（因变量）** | 通胀性去杠杆化，但为利率政策提供更大灵活性 |
| **Chain（传导链）** | 放弃钉住汇率制度，货币贬值 → 货币贬值导致进口成本上升，通胀暂时上升（最高8%） → 决策者获得设定利率的更大灵活性 → 实施紧缩政策，减少进口支出，提高本国货币吸引力 |
| **Lag（时滞）** | 即时（1997年放弃钉住汇率后） |
| **Threshold（临界值）** | 外汇储备减少100%，实际汇率贬值至-16% |
| **前提与约束（Premises）** | 决策者愿意承受短期通胀；存在IMF援助计划；决策者积极管控金融机构 |
| **Falsification（证伪条件）** | 如果货币浮动后未带来利率灵活性或经济恢复，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像松开刹车让车滑行，虽然速度暂时加快（通胀），但最终能控制方向（利率政策）。

### 🔗 文字版因果链

1. 放弃钉住汇率制度，货币贬值
2. 货币贬值导致进口成本上升，通胀暂时上升（最高8%）
3. 决策者获得设定利率的更大灵活性
4. 实施紧缩政策，减少进口支出，提高本国货币吸引力

| **Lag（时滞）** | 约5年（1998-2003年） |
| **Threshold（临界值）** | 债务占GDP比例下降88%（年化降幅15%），实际汇率跌至-16% |
| **前提与约束（Premises）** | 决策者实施紧缩政策；积极管控金融机构；存在IMF援助计划 |
| **Falsification（证伪条件）** | 如果实施紧缩政策但债务比例未下降或经济未恢复，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像病人经过痛苦的手术和康复训练，虽然过程艰难，但最终恢复健康。

### 🔗 文字版因果链

1. 减少进口支出（经常账户余额增幅为GDP的21%）
2. 银行国有化、提供流动性、直接购买不良资产
3. 实际经济增速提升，推动名义收入增加
4. 货币贬值提高竞争力，出口增加
5. 债务与收入比率下降，经济恢复
