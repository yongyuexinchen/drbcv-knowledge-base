# 自我强化的经济萧条和国际收支危机 货币危机

> 属于因果簇：[[阿根廷恶性通胀性去杠杆化周期的因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高额外币计价债务（占GDP的39%）与结构性弱点 |
| **DV（因变量）** | 自我强化的经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 高额外币债务使阿根廷易受外资撤出影响 → 大宗商品价格下跌冲击出口，外资流入减少 → 货币政策收紧，短期利率上调逾250% → 货币大幅贬值，实际汇率下跌60% → GDP和股价陷入自我强化式下跌，失业率上升 → 通胀率高企，金融机构承压，央行耗尽外汇储备后放弃捍卫货币 |
| **Lag（时滞）** | 冲击发生后数月内（1987-1990年持续） |
| **Threshold（临界值）** | 债务总额占GDP的70%，外币债务占GDP的39%，资本流入降幅为GDP的4% |
| **前提与约束（Premises）** | 危机前没有普遍泡沫，但存在外部泡沫式发展；经济存在结构性弱点；大宗商品价格下跌作为外部冲击 |
| **Falsification（证伪条件）** | 如果高额外币债务未导致资本外流和货币危机，或阿根廷能通过紧缩措施成功调整而不陷入恶性通胀，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭背负大量外币房贷，当收入（出口）下降时，银行收紧信贷，货币贬值使债务负担加重，最终导致财务崩溃

### 🔗 文字版因果链

1. 高额外币债务使阿根廷易受外资撤出影响
2. 大宗商品价格下跌冲击出口，外资流入减少
3. 货币政策收紧，短期利率上调逾250%
4. 货币大幅贬值，实际汇率下跌60%
5. GDP和股价陷入自我强化式下跌，失业率上升
6. 通胀率高企，金融机构承压，央行耗尽外汇储备后放弃捍卫货币
