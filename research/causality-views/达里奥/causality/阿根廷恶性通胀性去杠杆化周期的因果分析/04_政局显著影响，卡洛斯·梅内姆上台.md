# 政局显著影响，卡洛斯·梅内姆上台

> 属于因果簇：[[阿根廷恶性通胀性去杠杆化周期的因果分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 阿根廷恶性通胀性去杠杆化危机 |
| **DV（因变量）** | 政局显著影响，卡洛斯·梅内姆上台 |
| **Chain（传导链）** | 经济危机导致社会不满 → 民众对现政府失去信心 → 民粹主义领导人梅内姆获得支持 → 梅内姆上台执政 |
| **Lag（时滞）** | 危机期间及之后（1989年选举） |
| **Threshold（临界值）** | 危机严重程度足以引发政治更迭 |
| **前提与约束（Premises）** | 经济危机引发广泛社会不满；存在民粹主义领导人候选人；民主选举机制允许政权更迭 |
| **Falsification（证伪条件）** | 如果危机未导致政权更迭，或梅内姆未上台，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同公司经营失败导致董事会更换CEO，新领导往往以改革者形象出现

1. 经济危机导致社会不满
2. 民众对现政府失去信心
3. 民粹主义领导人梅内姆获得支持
4. 梅内姆上台执政
