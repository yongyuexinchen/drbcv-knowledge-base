# 债务增加和经济增长（GDP增速3%）

> 属于因果簇：[[奥地利通缩性去杠杆化周期中的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高资产回报率（股票年化回报率20%） |
| **DV（因变量）** | 债务增加和经济增长（GDP增速3%） |
| **Chain（传导链）** | 股市高回报吸引投资者和投机者 → 高回报鼓励更多借债投资，杠杆上升 → 借债刺激消费和投资，推动经济增长 → 债务累积至不可持续水平 |
| **Lag（时滞）** | 中期（1-3年） |
| **Threshold（临界值）** | 资产回报率显著高于债务成本（案例中20%远高于利率） |
| **前提与约束（Premises）** | 金融市场繁荣，投资者乐观；信贷可得性高；监管宽松，杠杆不受限制 |
| **Falsification（证伪条件）** | 如果高回报率未导致债务增加或经济过热，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同看到邻居炒股赚钱，自己也借钱炒股，但市场一旦下跌，债务和损失成倍放大

### 🔗 文字版因果链

1. 股市高回报吸引投资者和投机者
2. 高回报鼓励更多借债投资，杠杆上升
3. 借债刺激消费和投资，推动经济增长
4. 债务累积至不可持续水平
