# 奥地利经济自我强化式下跌（GDP下降4%，股价下跌66%）

> 属于因果簇：[[奥地利通缩性去杠杆化周期中的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 2008年全球金融危机（外部冲击） |
| **DV（因变量）** | 奥地利经济自我强化式下跌（GDP下降4%，股价下跌66%） |
| **Chain（传导链）** | 全球金融危机导致外资撤出和信贷冻结 → 奥地利偿债总额高（GDP的69%），金融机构压力巨大 → 资产价格下跌，企业和居民资产负债表恶化 → 收入减少，债务负担加重（债务占GDP比例增加39%） → 经济陷入通缩性萧条，形成自我强化螺旋 |
| **Lag（时滞）** | 即时至短期（数月内） |
| **Threshold（临界值）** | 偿债总额占GDP比例高（案例中69%），且外部冲击发生 |
| **前提与约束（Premises）** | 高杠杆、高外资依赖；金融机构脆弱；缺乏货币自主权（欧元区成员） |
| **Falsification（证伪条件）** | 如果外部冲击未导致经济大幅下滑，或经济能迅速恢复，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个高杠杆的投资者遇到股市崩盘，资产缩水，但债务不变，导致净值急剧下降，被迫抛售，进一步压低价格

### 🔗 文字版因果链

1. 全球金融危机导致外资撤出和信贷冻结
2. 奥地利偿债总额高（GDP的69%），金融机构压力巨大
3. 资产价格下跌，企业和居民资产负债表恶化
4. 收入减少，债务负担加重（债务占GDP比例增加39%）
5. 经济陷入通缩性萧条，形成自我强化螺旋
