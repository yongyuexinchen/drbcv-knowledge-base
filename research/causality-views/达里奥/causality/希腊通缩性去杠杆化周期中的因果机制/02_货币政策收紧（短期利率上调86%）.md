# 货币政策收紧（短期利率上调86%）

> 属于因果簇：[[希腊通缩性去杠杆化周期中的因果机制]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的34%） |
| **DV（因变量）** | 货币政策收紧（短期利率上调86%） |
| **Chain（传导链）** | 外资流入减少导致资本外流压力 → 为维持汇率稳定，央行被迫提高利率 → 利率上升导致借贷成本增加 → 货币与信贷环境收紧 |
| **Lag（时滞）** | 2008年全球金融危机后迅速显现 |
| **Threshold（临界值）** | 资本流入降幅为GDP的34% |
| **前提与约束（Premises）** | 希腊使用欧元，无法自主印钞或贬值；外资流入对填补经常账户赤字至关重要；全球金融危机导致全球资本流动逆转 |
| **Falsification（证伪条件）** | 如果外资流入减少但利率未上升，或央行有其他手段缓解资本外流，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个小商店依赖供应商赊账进货，一旦供应商停止赊账，店主只能提高售价或减少进货，导致生意萎缩

### 🔗 文字版因果链

1. 外资流入减少导致资本外流压力
2. 为维持汇率稳定，央行被迫提高利率
3. 利率上升导致借贷成本增加
4. 货币与信贷环境收紧
