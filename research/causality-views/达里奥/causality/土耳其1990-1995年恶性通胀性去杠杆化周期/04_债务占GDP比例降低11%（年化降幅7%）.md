# 债务占GDP比例降低11%（年化降幅7%）

> 属于因果簇：[[土耳其1990-1995年恶性通胀性去杠杆化周期]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策（减少进口支出，经常账户余额增幅为GDP的5%） |
| **DV（因变量）** | 债务占GDP比例降低11%（年化降幅7%） |
| **Chain（传导链）** | 紧缩政策减少进口，改善经常账户 → 本国货币吸引力提高，资本回流 → 名义收入增加（因通胀和增长） → 债务负担相对收入下降 → 债务与GDP比率降低 |
| **Lag（时滞）** | 政策实施后约1-2年债务比率显著下降 |
| **Threshold（临界值）** | 经常账户余额增幅达到GDP的5%时，债务比率下降明显 |
| **前提与约束（Premises）** | 决策者采取紧缩政策；存在IMF援助计划支持；金融机构坏账得到积极处理 |
| **Falsification（证伪条件）** | 若实施紧缩政策后债务比率未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人减少信用卡消费并增加收入，债务负担逐渐减轻，财务状况改善

### 🔗 文字版因果链

1. 紧缩政策减少进口，改善经常账户
2. 本国货币吸引力提高，资本回流
3. 名义收入增加（因通胀和增长）
4. 债务负担相对收入下降
5. 债务与GDP比率降低
