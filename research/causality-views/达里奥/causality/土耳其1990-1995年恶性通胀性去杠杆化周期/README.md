# 土耳其1990-1995年恶性通胀性去杠杆化周期（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：土耳其1990-1995年恶性通胀性去杠杆化周期.md

## 总体因果图

- 高额外币计价债务（占GDP的26%）和对外资流入的依赖（平均为GDP的2%） → 国际收支危机 货币危机（1993-1994年）
- 货币大幅贬值（实际汇率下跌26%） → 通胀率高企（最高达117%）
- 外资流入减少（降幅为GDP的8%） → GDP和股价自我强化式下跌（GDP跌12%，股价跌70%）
- 决策者实施紧缩政策（减少进口支出，经常账户余额增幅为GDP的5%） → 债务占GDP比例降低11%（年化降幅7%）
- 货币大幅贬值（实际汇率跌至-21%的低点） → 重新获得国际竞争力
