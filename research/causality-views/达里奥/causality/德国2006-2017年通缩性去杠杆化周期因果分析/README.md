# 德国2006-2017年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：德国2006-2017年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 危机前债务总额达到GDP的261%，偿债总额达到GDP的51% → 2008-2009年自我强化的经济萧条和痛苦的去杠杆化
- 欧洲央行提供充足经济刺激（M0增幅达GDP的14%，利率降至-1%，实际汇率平均-4%） → 德国从2009年开始步入通货再膨胀阶段，实现和谐的去杠杆化
