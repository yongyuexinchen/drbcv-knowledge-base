# 德国从2009年开始步入通货再膨胀阶段，实现和谐的去杠杆化

> 属于因果簇：[[德国2006-2017年通缩性去杠杆化周期因果分析]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 欧洲央行提供充足经济刺激（M0增幅达GDP的14%，利率降至-1%，实际汇率平均-4%） |
| **DV（因变量）** | 德国从2009年开始步入通货再膨胀阶段，实现和谐的去杠杆化 |
| **Chain（传导链）** | 欧洲央行实施扩张性货币政策 → 名义经济增长率高于名义利率（经济增长率平均3%，长期利率0%） → 收入增加推动债务与收入比率下降 → 失业率下降4%，债务占GDP比例下降56%（年化7%） → 实际GDP用3年时间恢复至之前峰值 |
| **Lag（时滞）** | 刺激政策后，2009年开始显现效果，持续数年 |
| **Threshold（临界值）** | M0增幅达GDP的14%，利率降至-1%，实际汇率平均-4% |
| **前提与约束（Premises）** | 德国积极管控金融机构和处理坏账，使用了9个政策工具中的6个；包括银行国有化、提供流动性、直接购买不良资产；欧洲央行决策者提供刺激 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义增长率未超过名义利率，或债务比率未下降，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 欧洲央行实施扩张性货币政策
2. 名义经济增长率高于名义利率（经济增长率平均3%，长期利率0%）
3. 收入增加推动债务与收入比率下降
4. 失业率下降4%，债务占GDP比例下降56%（年化7%）
5. 实际GDP用3年时间恢复至之前峰值
