# 阿根廷1998-2012年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：阿根廷1998-2012年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 资本流入强劲且货币回报丰厚 → 不可持续的发展局势（债务高企、经常账户赤字、竞争力下降）
- 外资流入减少 → 经济萧条和国际收支危机 货币危机
- 决策者放弃钉住汇率制度并实施紧缩政策 → 和谐的去杠杆化（债务占GDP比例下降，经济恢复增长）
- 经济危机 → 政治格局变化（民粹主义领导人上台）
