# 经济萧条和国际收支危机 货币危机

> 属于因果簇：[[阿根廷1998-2012年通胀性去杠杆化周期中的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少 |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 外资流入减少（资本流入降幅为GDP的10%） → 货币政策收紧，短期利率上调173% → 货币大幅贬值，实际汇率下降77% → GDP和股价自我强化式下跌（GDP跌15%，股价跌82%） → 失业率上升，通胀高企（最高32%） → 金融机构承压，央行耗尽外汇储备（减少66%） → 最终放弃捍卫货币，危机全面爆发 |
| **Lag（时滞）** | 2001-2002年，约1-2年 |
| **Threshold（临界值）** | 资本流入降幅占GDP的10%；短期利率上调173%；实际汇率下降77%；外汇储备减少66% |
| **前提与约束（Premises）** | 高债务水平，尤其外币债务占比高；钉住汇率制度缺乏灵活性；外部冲击（其他新兴经济体金融危机波及）；长期忽视通胀管控 |
| **Falsification（证伪条件）** | 如果外资流入减少但未引发货币大幅贬值和GDP大幅下跌，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个企业依赖短期借款运营，当银行突然抽贷，企业现金流断裂，导致破产。

### 🔗 文字版因果链

1. 外资流入减少（资本流入降幅为GDP的10%）
2. 货币政策收紧，短期利率上调173%
3. 货币大幅贬值，实际汇率下降77%
4. GDP和股价自我强化式下跌（GDP跌15%，股价跌82%）
5. 失业率上升，通胀高企（最高32%）
6. 金融机构承压，央行耗尽外汇储备（减少66%）
7. 最终放弃捍卫货币，危机全面爆发
