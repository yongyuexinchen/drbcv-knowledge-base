# 政治格局变化（民粹主义领导人上台）

> 属于因果簇：[[阿根廷1998-2012年通胀性去杠杆化周期中的因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济危机 |
| **DV（因变量）** | 政治格局变化（民粹主义领导人上台） |
| **Chain（传导链）** | 经济危机导致社会不满和失业率上升 → 民众对现有政府失去信心 → 民粹主义领导人（如爱德华多·杜阿尔德）获得支持 → 政权更迭，政治格局改变 |
| **Lag（时滞）** | 2001-2002年，危机期间 |
| **Threshold（临界值）** | 失业率上升3%，GDP下跌15% |
| **前提与约束（Premises）** | 民主政治体制，领导人通过选举上台；经济危机严重损害民众生活；民粹主义领导人提出吸引选民的政策 |
| **Falsification（证伪条件）** | 如果经济危机后原有政府仍保持权力，则此因果链不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同公司业绩大幅下滑，股东会更换管理层，希望新领导能扭转局面。

### 🔗 文字版因果链

1. 经济危机导致社会不满和失业率上升
2. 民众对现有政府失去信心
3. 民粹主义领导人（如爱德华多·杜阿尔德）获得支持
4. 政权更迭，政治格局改变
