# 芬兰1987-2001年通缩性去杠杆化周期中的因果机制

> **领域**：宏观经济学　|　**来源**：chapter_96.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少和货币信贷环境收紧 |
| **DV（因变量）** | 经济萧条和痛苦的去杠杆化 |
| **Chain（传导链）** | 外资流入减少导致外部融资中断 → 货币信贷环境收紧抑制投资和消费 → 资产价格下跌，银行偿付能力减弱 → GDP、股价、房价陷入自我强化式下跌 → 失业率上升，收入减少，债务占GDP比例反而上升 → 经济陷入萧条和痛苦的去杠杆化 |
| **Lag（时滞）** | 约1-2年（1989年外资逆转后，萧条持续至1993年） |
| **Threshold（临界值）** | 债务占GDP达到272%的危机前顶峰，经常账户赤字占GDP的3%，外资流入占GDP的3% |
| **前提与约束（Premises）** | 债务以本国货币计价但债权人多为外国人，易受外资撤出影响；实际汇率达到24%的峰值，竞争力恶化；决策者启动大规模紧缩政策（短期利率上调约700个基点） |
| **Falsification（证伪条件）** | 如果外资流入减少但经济仍能保持增长，或资产价格下跌未导致银行偿付能力显著减弱，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人依赖信用卡透支生活，一旦银行收紧信贷，收入又下降，债务负担反而更重，最终陷入财务危机

### 🔗 文字版因果链

1. 外资流入减少导致外部融资中断
2. 货币信贷环境收紧抑制投资和消费
3. 资产价格下跌，银行偿付能力减弱
4. GDP、股价、房价陷入自我强化式下跌
5. 失业率上升，收入减少，债务占GDP比例反而上升
6. 经济陷入萧条和痛苦的去杠杆化

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策宽松、财政刺激、积极处理坏账） |
| **DV（因变量）** | 和谐的去杠杆化（经济复苏，债务占GDP比例下降） |
| **Chain（传导链）** | 决策者提供流动性，将银行国有化，直接购买不良资产 → M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10% → 名义经济增长率（6%）高于名义利率（4%） → 收入增加，债务占GDP比例下降72% → 失业率下降6%，实际GDP在7年内恢复至峰值，股价5年内恢复 |
| **Lag（时滞）** | 约1-2年（1993年开始刺激，随后几年内效果显现） |
| **Threshold（临界值）** | M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10%，使用9个政策工具中的7个 |
| **前提与约束（Premises）** | 决策者积极管控金融机构和处理坏账；刺激政策足够大，能推动名义经济增长率高于名义利率；政策实施及时，避免萧条持续过久 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义增长率仍低于名义利率，或债务占GDP比例未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个重病患者输血和手术，虽然痛苦但能恢复健康，债务负担在收入增长中逐渐减轻

### 🔗 文字版因果链

1. 决策者提供流动性，将银行国有化，直接购买不良资产
2. M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10%
3. 名义经济增长率（6%）高于名义利率（4%）
4. 收入增加，债务占GDP比例下降72%
5. 失业率下降6%，实际GDP在7年内恢复至峰值，股价5年内恢复
