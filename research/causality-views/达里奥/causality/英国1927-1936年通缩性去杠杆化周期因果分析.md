# 英国1927-1936年通缩性去杠杆化周期因果分析

> **领域**：宏观经济学　|　**来源**：chapter_90.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务水平（债务总额达GDP的210%） |
| **DV（因变量）** | 经济萧条和痛苦的去杠杆化（1929-1931年） |
| **Chain（传导链）** | 高债务水平使英国容易受到外部冲击的伤害 → 美国股市崩盘及大萧条初期的影响波及英国 → GDP和股价陷入自我强化式下跌（GDP跌10%，股价跌61%） → 失业率上升7%，债务占GDP比例增加13%（年化增幅6%） → 举借新债以支付利息，实际收入水平下降，导致经济萧条和痛苦的去杠杆化 |
| **Lag（时滞）** | 冲击发生后短期内（约1-2年）显现 |
| **Threshold（临界值）** | 债务总额达到GDP的210%时，经济变得脆弱 |
| **前提与约束（Premises）** | 债务以英镑计价，大多数债权人是英国人；危机前英国未普遍出现泡沫，但外部经济体和金融市场存在泡沫；外部冲击（美国股市崩盘及大萧条）发生 |
| **Falsification（证伪条件）** | 如果高债务水平下，外部冲击未导致GDP和股价大幅下跌，或失业率未显著上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个背负高额房贷的人，即使平时收入稳定，一旦遇到突发失业或经济危机，就很容易陷入财务困境，甚至破产。

### 🔗 文字版因果链

1. 高债务水平使英国容易受到外部冲击的伤害
2. 美国股市崩盘及大萧条初期的影响波及英国
3. GDP和股价陷入自我强化式下跌（GDP跌10%，股价跌61%）
4. 失业率上升7%，债务占GDP比例增加13%（年化增幅6%）
5. 举借新债以支付利息，实际收入水平下降，导致经济萧条和痛苦的去杠杆化

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（切断英镑与黄金挂钩、M0增幅达GDP的2%、利率降至0%、实际汇率平均-8%） |
| **DV（因变量）** | 和谐的去杠杆化（1931年开始，失业率下降8%，债务占GDP比例下降29%） |
| **Chain（传导链）** | 决策者实施刺激性货币政策（切断金本位、增加货币供应、降低利率、贬值汇率） → 名义经济增长率（平均4%）高于名义利率（3%） → 实际收入水平上升，偿还旧债能力增强 → 债务与收入比率下降，失业率下降，经济逐步复苏 → 实际GDP在5年后达到之前峰值，股价在8年内恢复 |
| **Lag（时滞）** | 刺激政策实施后约1-2年显现效果 |
| **Threshold（临界值）** | 名义经济增长率高于名义利率（4% > 3%） |
| **前提与约束（Premises）** | 决策者愿意采取积极的货币政策刺激；英国未积极管控金融机构和处理坏账（仅使用9个政策工具中的1个）；外部环境允许货币贬值和利率下调 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义经济增长率未高于名义利率，或债务占GDP比例未下降，或失业率未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人负债累累时，如果找到高薪工作（高收入增长率），同时降低利息负担（低利率），就能逐步还清债务，而不是陷入债务螺旋。

### 🔗 文字版因果链

1. 决策者实施刺激性货币政策（切断金本位、增加货币供应、降低利率、贬值汇率）
2. 名义经济增长率（平均4%）高于名义利率（3%）
3. 实际收入水平上升，偿还旧债能力增强
4. 债务与收入比率下降，失业率下降，经济逐步复苏
5. 实际GDP在5年后达到之前峰值，股价在8年内恢复
