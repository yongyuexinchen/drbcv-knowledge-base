# 和谐的去杠杆化（1931年后，债务占GDP比例下降18%）

> 属于因果簇：[[日本1925-1936年通缩性去杠杆化周期因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（切断日元与黄金挂钩、降息至2%、管控金融机构） |
| **DV（因变量）** | 和谐的去杠杆化（1931年后，债务占GDP比例下降18%） |
| **Chain（传导链）** | 政府切断日元与黄金挂钩，允许货币贬值 → 利率降至2%，实际汇率为-26% → 积极管控金融机构和处理坏账 → 名义经济增长率（4.7%）高于名义利率（3.9%） → 收入水平上升，债务与收入比率下降 |
| **Lag（时滞）** | 刺激政策实施后约1-2年（1931年开始，效果在周期内显现） |
| **Threshold（临界值）** | 名义经济增长率超过名义利率（4.7% > 3.9%）时，债务比率下降 |
| **前提与约束（Premises）** | 决策者愿意采取积极干预措施；经济刺激力度足够大（使用9个政策工具中的3个）；金融机构得到有效管控 |
| **Falsification（证伪条件）** | 若刺激政策未能使名义增长率超过利率，或债务比率未下降，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像给一个溺水者扔救生圈（刺激政策），只要救生圈足够大（增长率>利率），就能浮上来，否则会沉得更深。

### 🔗 文字版因果链

1. 政府切断日元与黄金挂钩，允许货币贬值
2. 利率降至2%，实际汇率为-26%
3. 积极管控金融机构和处理坏账
4. 名义经济增长率（4.7%）高于名义利率（3.9%）
5. 收入水平上升，债务与收入比率下降
