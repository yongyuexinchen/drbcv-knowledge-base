# 日本政局显著变化，东条英机上台

> 属于因果簇：[[日本1925-1936年通缩性去杠杆化周期因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期经济萧条和痛苦去杠杆化 |
| **DV（因变量）** | 日本政局显著变化，东条英机上台 |
| **Chain（传导链）** | 经济萧条导致社会不满和民众痛苦 → 民粹主义领导人获得支持 → 东条英机上台，改变政治格局 |
| **Lag（时滞）** | 萧条持续数年后（约1931-1936年） |
| **Threshold（临界值）** | 萧条持续时间超过平均水平（1927-1931年） |
| **前提与约束（Premises）** | 经济萧条持续且未得到及时缓解；民众对现有政治体制失望；存在民粹主义领导人的政治空间 |
| **Falsification（证伪条件）** | 若经济萧条未导致政治格局变化，或东条英机上台与萧条无关，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像长期失业会让人对政府失去信心，转而支持激进的政治人物。

### 🔗 文字版因果链

1. 经济萧条导致社会不满和民众痛苦
2. 民粹主义领导人获得支持
3. 东条英机上台，改变政治格局
