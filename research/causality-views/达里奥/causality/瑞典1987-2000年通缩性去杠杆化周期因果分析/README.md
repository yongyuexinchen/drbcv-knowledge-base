# 瑞典1987-2000年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：瑞典1987-2000年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加、经济增长强劲、房地产市场回报丰厚 → 自我强化的泡沫周期
- 房地产价格下跌导致银行偿付能力减弱 → 自我强化的经济萧条和痛苦的去杠杆化
- 决策者提供充足的经济刺激（货币政策、财政政策、结构性改革） → 和谐的去杠杆化（通货再膨胀阶段）
