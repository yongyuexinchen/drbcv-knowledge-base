# 自我强化的泡沫周期

> 属于因果簇：[[瑞典1987-2000年通缩性去杠杆化周期因果分析]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、经济增长强劲、房地产市场回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务和资金增加支撑经济温和增长 → 经济活力处于高位，GDP缺口达到峰值 → 房地产回报丰厚吸引更多投资和信贷 → 债务和资产价格相互推动，形成正反馈循环 |
| **Lag（时滞）** | 1987-1990年，约3年 |
| **Threshold（临界值）** | 债务占GDP比例达到239%，增幅为GDP的15% |
| **前提与约束（Premises）** | 债务以本国货币计价；大多数债权人是本国居民；投资流入较少但为正，平均约占GDP的2%；经常账户赤字占GDP的3% |
| **Falsification（证伪条件）** | 如果债务增长但资产价格未同步上涨，或经济增速未达高位，则泡沫周期不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球：债务和资产价格互相推动，雪球越滚越大，直到坡底或遇到障碍

### 🔗 文字版因果链

1. 债务和资金增加支撑经济温和增长
2. 经济活力处于高位，GDP缺口达到峰值
3. 房地产回报丰厚吸引更多投资和信贷
4. 债务和资产价格相互推动，形成正反馈循环
