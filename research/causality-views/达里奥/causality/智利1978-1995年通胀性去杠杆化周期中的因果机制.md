# 智利1978-1995年通胀性去杠杆化周期中的因果机制

> **领域**：宏观经济学、国际金融、债务危机　|　**来源**：chapter_113.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入和债务增加（尤其外币债务占GDP的32%） |
| **DV（因变量）** | 自我强化的泡沫周期（股市回报丰厚、经济增长强劲、实际汇率升值） |
| **Chain（传导链）** | 外资大量流入，推动债务累积 → 债务融资支撑投资和消费，刺激经济增长（增速达7%） → 经济繁荣推高资产价格，股市年化回报率36% → 高回报鼓励更多借债和投资，形成正反馈循环 → 实际汇率升值36%，削弱竞争力，但资本流入持续掩盖失衡 |
| **Lag（时滞）** | 约1-3年（泡沫阶段持续1978-1981年） |
| **Threshold（临界值）** | 债务占GDP达145%，外币债务占GDP的32%，经常账户赤字占GDP的11% |
| **前提与约束（Premises）** | 资本账户开放，依赖外资流入；汇率制度缺乏弹性（钉住汇率）；存在外部冲击（如拉美债务危机）的可能性 |
| **Falsification（证伪条件）** | 若资本流入减少但经济未出现衰退或资产价格未大幅下跌，则泡沫阶段因果链不成立 |
| **Confidence（确信度）** | well-established |

1. 外资大量流入，推动债务累积

3. 经济繁荣推高资产价格，股市年化回报率36%

5. 实际汇率升值36%，削弱竞争力，但资本流入持续掩盖失衡

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入骤减（资本流入降幅为GDP的40%） |
| **DV（因变量）** | 经济萧条和国际收支/货币危机（GDP下跌14%，股市下跌74%，货币大幅贬值） |
| **Chain（传导链）** | 外资流入减少，融资缺口扩大 → 央行被迫收紧货币政策，短期利率上调31% → 高利率抑制投资和消费，经济陷入衰退 → 货币贬值预期导致资本外逃，实际汇率下降50% → GDP和股价螺旋式下跌，金融机构承压 → 央行耗尽外汇储备（减少53%）后放弃捍卫货币 |
| **Lag（时滞）** | 约1-2年（危机持续1981-1985年） |
| **Threshold（临界值）** | 偿债总额占GDP达45%，资本流入降幅为GDP的40% |
| **前提与约束（Premises）** | 高额外币债务使资产负债表暴露于汇率风险；外部冲击（拉美债务危机）触发资本流动逆转；货币政策受制于汇率目标 |
| **Falsification（证伪条件）** | 若外资减少但经济未出现深度衰退或货币未大幅贬值，则因果链不成立 |
| **Confidence（确信度）** | well-established |

1. 外资流入减少，融资缺口扩大

4. 货币贬值预期导致资本外逃，实际汇率下降50%
5. GDP和股价螺旋式下跌，金融机构承压
6. 央行耗尽外汇储备（减少53%）后放弃捍卫货币

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率下降50%） |
| **DV（因变量）** | 债务占GDP比例上升（增加73%，年化19%） |
| **Chain（传导链）** | 本币贬值，外币债务的本币价值上升 → 偿债负担加重，债务总额膨胀 → 政府为应对危机举借新债，财政赤字占GDP达4% → 名义GDP因衰退而萎缩，分母减小 → 债务与GDP之比急剧上升 |
| **Lag（时滞）** | 即时至1年内 |
| **Threshold（临界值）** | 外币债务占GDP的32%，贬值幅度达50% |
| **前提与约束（Premises）** | 存在大量外币计价债务；经济衰退导致名义GDP下降；政府需要财政刺激或救助 |
| **Falsification（证伪条件）** | 若贬值但债务占GDP比例未上升，则因果链不成立 |
| **Confidence（确信度）** | well-established |

1. 本币贬值，外币债务的本币价值上升
2. 偿债负担加重，债务总额膨胀
3. 政府为应对危机举借新债，财政赤字占GDP达4%
4. 名义GDP因衰退而萎缩，分母减小
5. 债务与GDP之比急剧上升

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施紧缩政策、积极处理坏账、结构性改革（使用9个政策工具中的5个） |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP下降129%，经常账户改善，竞争力恢复） |
| **Chain（传导链）** | 放弃钉住汇率，允许货币贬值 → 紧缩政策减少进口，经常账户余额增幅为GDP的11% → 提供流动性和购买不良资产，稳定金融体系 → IMF援助和结构性改革增强劳动力市场灵活性 → 名义收入增加，债务与收入比率下降 → 实际汇率跌至-32%，出口竞争力恢复 → GDP在5年后恢复峰值，股市在9年后恢复 |
| **Lag（时滞）** | 约5-9年（调整期至1990年代中期） |
| **Threshold（临界值）** | 债务占GDP下降129%，年化降幅13% |
| **前提与约束（Premises）** | 决策者采取足够紧缩政策而非过度印钞；国际支持（IMF）和结构性改革配套；外部环境允许出口增长 |
| **Falsification（证伪条件）** | 若政策实施后债务比例未下降或经济未恢复，则因果链不成立 |
| **Confidence（确信度）** | well-established |

1. 放弃钉住汇率，允许货币贬值

3. 提供流动性和购买不良资产，稳定金融体系
4. IMF援助和结构性改革增强劳动力市场灵活性
5. 名义收入增加，债务与收入比率下降
6. 实际汇率跌至-32%，出口竞争力恢复
7. GDP在5年后恢复峰值，股市在9年后恢复
