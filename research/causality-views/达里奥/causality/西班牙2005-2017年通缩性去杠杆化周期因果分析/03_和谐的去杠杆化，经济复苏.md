# 和谐的去杠杆化，经济复苏

> 属于因果簇：[[西班牙2005-2017年通缩性去杠杆化周期因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 欧洲央行提供充足的经济刺激（M0增幅达GDP的15%，利率降至-1%） |
| **DV（因变量）** | 和谐的去杠杆化，经济复苏 |
| **Chain（传导链）** | 欧洲央行增加货币供应和降低利率 → 名义经济增长率高于名义利率（经济增长率平均2%，长期利率降至1%） → 债务与收入比率下降（下降112%） → 失业率下降10% → 实际GDP逐步恢复至之前峰值 |
| **Lag（时滞）** | 2013年开始，实际GDP用了9年时间才达到之前的峰值 |
| **Threshold（临界值）** | M0增幅达GDP的15%，利率降至-1%，名义经济增长率高于名义利率 |
| **前提与约束（Premises）** | 欧洲央行决策者提供充足刺激；西班牙积极管控金融机构和处理坏账；实施了结构性改革，增强劳动力市场灵活性 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义经济增长率未高于名义利率，或债务与收入比率未下降，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像给病人输血和做手术，先稳定生命体征，再通过改革恢复健康

### 🔗 文字版因果链

1. 欧洲央行增加货币供应和降低利率
2. 名义经济增长率高于名义利率（经济增长率平均2%，长期利率降至1%）
3. 债务与收入比率下降（下降112%）
4. 失业率下降10%
5. 实际GDP逐步恢复至之前峰值
