# 阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析.md

## 总体因果图

- 高债务水平（尤其以外币计价的债务占GDP的15%） → 经济萧条和国际收支危机 货币危机（1980-1985年）
- 紧缩措施未能带来必要的调整 → 汇率急剧下跌和恶性通胀（通胀率超过1000%）
- 货币贬值（导致以外币计价的偿债负担加重）及政府举借新债应对危机 → 债务占GDP的比例增加33%（年化增幅7%）
- 央行动用外汇储备维持货币稳定 → 外汇储备减少83%，最终放弃捍卫货币
- 阿根廷积极管控金融机构和处理坏账（使用9个政策工具中的3个，包括银行国有化和提供流动性） → 危机处理效果（部分缓解，但未能阻止恶性通胀）
