# 外汇储备减少83%，最终放弃捍卫货币

> 属于因果簇：[[阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 央行动用外汇储备维持货币稳定 |
| **DV（因变量）** | 外汇储备减少83%，最终放弃捍卫货币 |
| **Chain（传导链）** | 货币面临贬值压力 → 央行动用外汇储备干预 → 外汇储备大量消耗（减少83%） → 储备耗尽，决策者放弃捍卫货币 |
| **Lag（时滞）** | 约5年（1980-1985年） |
| **Threshold（临界值）** | 外汇储备减少83% |
| **前提与约束（Premises）** | 存在持续的资本外流；储备规模有限；外部冲击持续 |
| **Falsification（证伪条件）** | 如果外汇储备减少但货币稳定，或未放弃捍卫，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用蓄水池的水救火，水耗尽后火势失控

### 🔗 文字版因果链

1. 货币面临贬值压力
2. 央行动用外汇储备干预
3. 外汇储备大量消耗（减少83%）
4. 储备耗尽，决策者放弃捍卫货币
