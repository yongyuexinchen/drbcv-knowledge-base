# 巴西1977-1987年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：巴西1977-1987年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 外资以不可持续的方式强劲流入，导致债务积累（债务总额达GDP的158%，其中70%为外币计价） → 国际收支危机 货币危机（1980-1983年）
- 决策者放弃钉住汇率制度，实施紧缩政策（减少进口、提高货币吸引力） → 和谐的去杠杆化（债务占GDP比例下降121%，年化降幅27%
- 货币贬值（实际汇率下降20%） → 通胀率高企且不断上升（最高达124%）
