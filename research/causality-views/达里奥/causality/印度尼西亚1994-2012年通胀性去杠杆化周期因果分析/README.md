# 印度尼西亚1994-2012年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：印度尼西亚1994-2012年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 大量资本流入、债务增加、股市回报丰厚 → 自我强化的泡沫周期
- 外资流入减少（资本流入降幅为GDP的13%） → 货币政策收紧、货币大幅贬值、GDP和股价下跌
- 决策者放弃钉住汇率制度，允许货币浮动 → 通胀性去杠杆化，但为利率政策提供更大灵活性
