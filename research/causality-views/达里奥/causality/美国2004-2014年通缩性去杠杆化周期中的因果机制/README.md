## 总体因果图

- 债务不断增加、经济增长强劲、资产回报丰厚 → 自我强化的泡沫周期
- 房地产市场崩盘 → 自我强化的经济萧条和痛苦的去杠杆化
- 决策者提供充足的经济刺激（货币政策与财政政策） → 将痛苦的去杠杆化转变为和谐的去杠杆化
