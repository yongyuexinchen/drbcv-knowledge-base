# 将痛苦的去杠杆化转变为和谐的去杠杆化

> 属于因果簇：[[美国2004-2014年通缩性去杠杆化周期中的因果机制]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策与财政政策） |
| **DV（因变量）** | 将痛苦的去杠杆化转变为和谐的去杠杆化 |
| **Chain（传导链）** | 货币政策增加M0（增幅达GDP的16%） → 利率降至0% → 实际汇率平均为-10% → 积极管控金融机构和处理坏账（使用6个政策工具） → 名义经济增长率高于名义利率 → 债务与收入比率下降，失业率下降 |
| **Lag（时滞）** | 2009年开始，实际GDP用4年恢复，股价用5年恢复 |
| **Threshold（临界值）** | M0增幅达GDP的16%，利率降至0%，实际汇率平均为-10% |
| **前提与约束（Premises）** | 决策者积极干预；使用多种政策工具（至少6个）；银行国有化、提供流动性、直接购买不良资产 |
| **Falsification（证伪条件）** | 如果刺激政策未能使名义经济增长率高于名义利率，或债务与收入比率未下降，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像医生给重病患者输血和手术：及时干预可以避免死亡，恢复健康

### 🔗 文字版因果链

1. 货币政策增加M0（增幅达GDP的16%）
2. 利率降至0%
3. 实际汇率平均为-10%
4. 积极管控金融机构和处理坏账（使用6个政策工具）
5. 名义经济增长率高于名义利率
6. 债务与收入比率下降，失业率下降
