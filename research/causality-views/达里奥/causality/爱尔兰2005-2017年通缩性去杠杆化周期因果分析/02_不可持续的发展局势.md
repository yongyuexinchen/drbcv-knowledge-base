# 不可持续的发展局势

> 属于因果簇：[[爱尔兰2005-2017年通缩性去杠杆化周期因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入依赖、货币和信贷环境收紧、相关国家经济状况恶化 |
| **DV（因变量）** | 不可持续的发展局势 |
| **Chain（传导链）** | 外资流入依赖使经济易受外部冲击 → 货币和信贷环境收紧增加偿债成本 → 相关国家经济恶化减少外部需求，加剧国内经济压力 → 多重压力叠加导致局势不可持续 |
| **Lag（时滞）** | 2005-2008年（泡沫阶段后期） |
| **Threshold（临界值）** | 实际汇率达到17%的峰值，短期利率上调约220个基点 |
| **前提与约束（Premises）** | 爱尔兰面临泡沫压力；依赖外资流入；货币和信贷环境收紧；相关国家经济状况恶化 |
| **Falsification（证伪条件）** | 如果外资流入持续稳定，或货币信贷环境宽松，或相关国家经济没有恶化，则局势可能不会变得不可持续 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多米诺骨牌：一个因素倒下，引发连锁反应，最终整体崩溃

### 🔗 文字版因果链

1. 外资流入依赖使经济易受外部冲击
2. 货币和信贷环境收紧增加偿债成本
3. 相关国家经济恶化减少外部需求，加剧国内经济压力
4. 多重压力叠加导致局势不可持续
