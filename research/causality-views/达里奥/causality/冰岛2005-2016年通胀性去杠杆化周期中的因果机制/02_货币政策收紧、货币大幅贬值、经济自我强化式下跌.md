# 货币政策收紧、货币大幅贬值、经济自我强化式下跌

> 属于因果簇：[[冰岛2005-2016年通胀性去杠杆化周期中的因果机制]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的49%） |
| **DV（因变量）** | 货币政策收紧、货币大幅贬值、经济自我强化式下跌 |
| **Chain（传导链）** | 外资流入减少导致国际收支压力 → 央行收紧货币政策（短期利率上调4%） → 货币大幅贬值（实际汇率下降29%） → GDP、股价、房价下跌（分别跌11%、96%、15%） → 失业率上升5%，通胀温和上升（最高18%） |
| **Lag（时滞）** | 冲击后迅速显现，萧条阶段持续约2年（2008-2010年） |
| **Threshold（临界值）** | 资本流入降幅达到GDP的49% |
| **前提与约束（Premises）** | 高债务水平使经济脆弱；存在全球金融危机等外部冲击；决策者最初试图捍卫货币 |
| **Falsification（证伪条件）** | 如果外资减少但货币未贬值或经济未衰退，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像水库依赖上游来水，一旦上游断流，水库水位骤降，下游农田干涸，整个生态系统崩溃。

### 🔗 文字版因果链

1. 外资流入减少导致国际收支压力
2. 央行收紧货币政策（短期利率上调4%）
3. 货币大幅贬值（实际汇率下降29%）
4. GDP、股价、房价下跌（分别跌11%、96%、15%）
5. 失业率上升5%，通胀温和上升（最高18%）
