# 哥伦比亚1995-2008年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：哥伦比亚1995-2008年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 外部压力下允许货币浮动 → 决策者设定利率的灵活性增加
- 大量资本流入、债务增加、经济增长强劲、房地产回报丰厚 → 自我强化的泡沫周期（不可持续发展）
- 外部冲击（1997年亚洲金融危机）导致资本流入减少 → 经济萧条和国际收支危机 货币危机
- 决策者实施紧缩政策、积极管控金融机构、处理坏账、结构性改革 → 和谐的去杠杆化（债务占GDP比例下降16%，经济恢复）
