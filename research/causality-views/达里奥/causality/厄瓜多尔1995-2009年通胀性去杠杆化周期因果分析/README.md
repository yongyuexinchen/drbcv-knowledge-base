# 厄瓜多尔1995-2009年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：厄瓜多尔1995-2009年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 高额外币计价债务（占GDP的56%）和对外资流入的依赖（平均占GDP的3%） → 国际收支危机 货币危机（1998-2000年）
- 决策者放弃钉住汇率制度并实施紧缩政策 → 痛苦的去杠杆化阶段持续时间相对较短（实际GDP用1.8年恢复
- 货币大幅贬值（实际汇率跌至-55%） → 厄瓜多尔重新获得国际竞争力
- 危机对政局造成显著影响 → 2003年卢西奥·古铁雷斯上台（民粹主义领导人）
