# 厄瓜多尔重新获得国际竞争力

> 属于因果簇：[[厄瓜多尔1995-2009年通胀性去杠杆化周期因果分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率跌至-55%） |
| **DV（因变量）** | 厄瓜多尔重新获得国际竞争力 |
| **Chain（传导链）** | 货币贬值降低本国商品在国际市场的价格 → 出口商品价格竞争力提升 → 经常账户改善（余额增幅为GDP的11%） → 经济恢复增长，实际GDP达到之前峰值 |
| **Lag（时滞）** | 约1-2年（竞争力提升到经济恢复） |
| **Threshold（临界值）** | 实际汇率贬值超过50%时，竞争力显著提升 |
| **前提与约束（Premises）** | 存在可贸易部门（出口导向）；国内通胀率低于贬值幅度（实际汇率贬值）；外部需求稳定 |
| **Falsification（证伪条件）** | 若货币贬值但经常账户未改善或经济未恢复，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同商店打折促销，降价吸引更多顾客，销量增加，但前提是商品质量不差且顾客有购买力。

### 🔗 文字版因果链

1. 货币贬值降低本国商品在国际市场的价格
2. 出口商品价格竞争力提升
3. 经常账户改善（余额增幅为GDP的11%）
4. 经济恢复增长，实际GDP达到之前峰值
