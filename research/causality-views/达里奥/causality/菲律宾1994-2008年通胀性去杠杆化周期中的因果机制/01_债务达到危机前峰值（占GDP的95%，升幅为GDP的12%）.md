# 债务达到危机前峰值（占GDP的95%，升幅为GDP的12%）

> 属于因果簇：[[菲律宾1994-2008年通胀性去杠杆化周期中的因果机制]]（第1块/8块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本流入强劲且货币回报丰厚（不可持续发展） |
| **DV（因变量）** | 债务达到危机前峰值（占GDP的95%，升幅为GDP的12%） |
| **Chain（传导链）** | 资本流入强劲，货币回报丰厚 → 鼓励更多借债，刺激经济增长 → 债务累积，达到危机前峰值 |
| **Lag（时滞）** | 约3年（1994-1997年泡沫阶段） |
| **Threshold（临界值）** | 债务占GDP比例达到95%，升幅为GDP的12% |
| **前提与约束（Premises）** | 很大一部分债务以外币计价（占GDP的51%）；外资流入平均约占GDP的12%，填补经常账户缺口；经常账户赤字占GDP的5% |
| **Falsification（证伪条件）** | 如果资本流入强劲但债务占GDP比例未显著上升，或债务增长未达到危机前峰值，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人收入增加后大量借贷消费，债务越积越多，最终面临还债压力

### 🔗 文字版因果链

1. 资本流入强劲，货币回报丰厚
2. 鼓励更多借债，刺激经济增长
3. 债务累积，达到危机前峰值
