## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率跌至-24%的低点） |
| **DV（因变量）** | 重新获得竞争力 |
| **Chain（传导链）** | 货币大幅贬值 → 出口商品在国际市场上价格下降 → 出口增加 → 经常账户改善 → 重新获得竞争力 |
| **Lag（时滞）** | 通货再膨胀阶段（1998年后） |
| **Threshold（临界值）** | 实际汇率跌至-24%的低点 |
| **前提与约束（Premises）** | 实施紧缩政策减少进口支出；经常账户余额增幅为GDP的11%；结构性改革增强劳动力市场灵活性 |
| **Falsification（证伪条件）** | 如果货币大幅贬值但出口未增加或经常账户未改善，则该断言被推翻 |
| **Confidence（确信度）** | well-established |
