# 决策者设定利率的灵活性增大

> 属于因果簇：[[菲律宾1994-2008年通胀性去杠杆化周期中的因果机制]]（第5块/8块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 放弃钉住汇率制度，允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的灵活性增大 |
| **Chain（传导链）** | 放弃钉住汇率制度 → 货币自由浮动 → 央行不再需要为维持汇率而牺牲利率政策 → 决策者可以更灵活地设定利率以应对经济状况 |
| **Lag（时滞）** | 通货再膨胀阶段（1998年后） |
| **Threshold（临界值）** | 放弃钉住汇率制度 |
| **前提与约束（Premises）** | 面临外部压力；痛苦的去杠杆化阶段持续时间略短于平均水平；决策者实施了充足的紧缩政策 |
| **Falsification（证伪条件）** | 如果放弃钉住汇率制度后利率灵活性未增加，或央行仍受其他因素制约，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像松开刹车后，司机可以更灵活地控制车速，而不是一直踩刹车

### 🔗 文字版因果链

1. 放弃钉住汇率制度
2. 货币自由浮动
3. 央行不再需要为维持汇率而牺牲利率政策
4. 决策者可以更灵活地设定利率以应对经济状况
