# 不可持续的发展局势

> 属于因果簇：[[日本1987-2017年通缩性去杠杆化周期因果分析]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩政策（短期利率上调约450个基点） |
| **DV（因变量）** | 不可持续的发展局势 |
| **Chain（传导链）** | 决策者启动大规模紧缩政策 → 货币与信贷环境收紧 → 高利率抑制投资和消费 → 债务负担加重，经济脆弱性增加 → 形成不可持续的发展局势 |
| **Lag（时滞）** | 政策实施后数月到一年内显现 |
| **Threshold（临界值）** | 短期利率上调约450个基点 |
| **前提与约束（Premises）** | 经济处于泡沫阶段，债务水平高；资产价格已过度膨胀 |
| **Falsification（证伪条件）** | 如果紧缩政策未导致经济不可持续，或经济仍能维持增长，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像踩刹车过猛，车虽然减速但可能失控

### 🔗 文字版因果链

1. 决策者启动大规模紧缩政策
2. 货币与信贷环境收紧
3. 高利率抑制投资和消费
4. 债务负担加重，经济脆弱性增加
5. 形成不可持续的发展局势
