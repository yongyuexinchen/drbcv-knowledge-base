# 名义GDP增速低于名义利率，去杠杆化速度缓慢

> 属于因果簇：[[日本1987-2017年通缩性去杠杆化周期因果分析]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 央行货币宽松力度不足 |
| **DV（因变量）** | 名义GDP增速低于名义利率，去杠杆化速度缓慢 |
| **Chain（传导链）** | 货币宽松不足，利率未能有效降低 → 名义利率高于名义GDP增速 → 债务利息负担超过经济增长带来的收入增加 → 债务占GDP比例持续上升（增加59%，年化3%） → 去杠杆化过程缓慢且痛苦 |
| **Lag（时滞）** | 政策不足的效果在数年内显现 |
| **Threshold（临界值）** | 名义GDP增速低于名义利率 |
| **前提与约束（Premises）** | 债务水平高，需要去杠杆化；决策者未提供足够经济刺激 |
| **Falsification（证伪条件）** | 如果货币宽松不足但名义GDP增速仍高于名义利率，或去杠杆化速度未减缓，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用勺子挖山：工具太小，进度缓慢

### 🔗 文字版因果链

1. 货币宽松不足，利率未能有效降低
2. 名义利率高于名义GDP增速
3. 债务利息负担超过经济增长带来的收入增加
4. 债务占GDP比例持续上升（增加59%，年化3%）
5. 去杠杆化过程缓慢且痛苦
