## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 特朗普政策（贸易紧张加剧、财政赤字增加） |
| **DV（因变量）** | 其他国家政府和投资者减少对美国资产的投资，引发资本战 |
| **Chain（传导链）** | 特朗普政策导致贸易紧张局势加剧和财政赤字增加 → 削弱外界对美国债务的信心 → 投资者对美元资产信任下降，减少购买美国国债等资产 → 其他国家政府可能不愿为美国赤字融资 → 美国继续大量发债，供需失衡，引发资本流动和货币争端 → 资本战爆发 |
| **Lag（时滞）** | 数月到数年（政策实施后逐步显现，如关税从2月1日生效，市场反应即时但资本流动调整需时间） |
| **Threshold（临界值）** | 关税加征10%或更高（如25%），或财政赤字持续扩大，导致信心显著恶化 |
| **前提与约束（Premises）** | 美国持续存在贸易逆差和财政赤字；其他国家持有大量美元和美国国债；地缘政治冲突升级，盟友间信任受损；欧洲等主要债权国拥有反制工具（如ACI） |
| **Falsification（证伪条件）** | 如果美国财政赤字下降、贸易紧张缓解，或者外国投资者继续增持美国资产，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像朋友之间借钱，如果借债人不断借钱且行为不端，债主会担心收不回钱，转而购买黄金等硬通货，甚至可能联合起来停止借钱，引发金融冲突。
