# 资产价格上涨，贫富差距扩大速度缩小（治标不治本）

> 属于因果簇：[[长期债务周期中的债务质量与去杠杆机制]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 央行大规模印钞购买资产（债务货币化） |
| **DV（因变量）** | 资产价格上涨，贫富差距扩大速度缩小（治标不治本） |
| **Chain（传导链）** | 央行印钞购买资产，增加资产需求，推高资产价格 → 资产价格上涨使持有者受益，缩小贫富差距扩大速度 → 但总债务水平过高，无法通过正常增长消化，问题未根本解决 |
| **Lag（时滞）** | 短期至中期（印钞后资产价格反应较快） |
| **Threshold（临界值）** | 央行大规模印钞购买资产（量化宽松） |
| **前提与约束（Premises）** | 央行有能力实施大规模资产购买；资产价格对流动性敏感；总债务水平已高到无法通过正常增长消化 |
| **Falsification（证伪条件）** | 如果印钞购买资产后资产价格未上涨，或贫富差距未缩小，或总债务水平被有效消化，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 给病人打止痛针：缓解疼痛（缩小贫富差距）但治标不治本，疾病（高债务）仍在

### 🔗 文字版因果链

1. 央行印钞购买资产，增加资产需求，推高资产价格
2. 资产价格上涨使持有者受益，缩小贫富差距扩大速度
3. 但总债务水平过高，无法通过正常增长消化，问题未根本解决
