# 长期债务周期中的债务质量与去杠杆机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：长期债务周期中的债务质量与去杠杆机制.md

## 总体因果图

- 债务资金的使用方式（高效投资 vs 消费性支出） → 债务的可持续性（能否产生足够收入还本付息）
- 债务增长快于收入增长（长期债务周期上行阶段） → 经济进入去杠杆阶段（支出下降、信用收缩、资产价格下跌）
- 央行大规模印钞购买资产（债务货币化） → 资产价格上涨，贫富差距扩大速度缩小（治标不治本）
