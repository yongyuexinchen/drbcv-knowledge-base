# 经济进入去杠杆阶段（支出下降、信用收缩、资产价格下跌）

> 属于因果簇：[[长期债务周期中的债务质量与去杠杆机制]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务增长快于收入增长（长期债务周期上行阶段） |
| **DV（因变量）** | 经济进入去杠杆阶段（支出下降、信用收缩、资产价格下跌） |
| **Chain（传导链）** | 债务增长快于收入增长，推高资产价格，产生财富效应 → 财富效应使人们感觉更富有，借更多钱，形成自我强化 → 偿债成本（本金+利息）增长快于收入增长，迫使削减支出 → 支出下降导致收入下降（一人支出是另一人收入），信用收缩，资产价格下跌 → 借款人违约，贷款人收缩信贷，经济进入去杠杆阶段 |
| **Lag（时滞）** | 持续几十年（上行阶段），去杠杆阶段约2-3年 |
| **Threshold（临界值）** | 偿债成本增速超过收入增速 |
| **前提与约束（Premises）** | 债务增长持续快于收入增长；存在财富效应和借贷行为；经济主体支出相互关联 |
| **Falsification（证伪条件）** | 如果债务增长快于收入增长但未导致偿债成本超过收入，或未引发去杠杆，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 温水煮青蛙：债务增长像水温上升，青蛙（经济）感觉舒适，直到水沸腾（偿债成本过高）才意识到危险，但为时已晚

### 🔗 文字版因果链

1. 债务增长快于收入增长，推高资产价格，产生财富效应
2. 财富效应使人们感觉更富有，借更多钱，形成自我强化
3. 偿债成本（本金+利息）增长快于收入增长，迫使削减支出
4. 支出下降导致收入下降（一人支出是另一人收入），信用收缩，资产价格下跌
5. 借款人违约，贷款人收缩信贷，经济进入去杠杆阶段
