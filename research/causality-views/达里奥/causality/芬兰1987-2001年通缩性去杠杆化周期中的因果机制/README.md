# 芬兰1987-2001年通缩性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：芬兰1987-2001年通缩性去杠杆化周期中的因果机制.md

## 总体因果图

- 外资流入减少和货币信贷环境收紧 → 经济萧条和痛苦的去杠杆化
- 决策者提供充足的经济刺激（货币政策宽松、财政刺激、积极处理坏账） → 和谐的去杠杆化（经济复苏，债务占GDP比例下降）
