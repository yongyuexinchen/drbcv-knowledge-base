# 决策者设定利率的更大灵活性

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第1块/7块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 放弃钉住汇率制度，允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的更大灵活性 |
| **Chain（传导链）** | 面临外部压力时，放弃钉住汇率，允许货币浮动 → 货币浮动导致暂时性通胀 → 但浮动汇率使货币政策不再受制于维持汇率稳定，从而为决策者设定利率提供了更大灵活性 |
| **Lag（时滞）** | 短期（通胀效应即时显现，政策灵活性在放弃钉住后逐步体现） |
| **Threshold（临界值）** | 无明确量化阈值，但需在外部压力下放弃钉住汇率 |
| **前提与约束（Premises）** | 国家面临外部压力（如资本外流、货币危机）；决策者愿意容忍暂时性通胀；存在独立的货币政策框架以利用汇率灵活性 |
| **Falsification（证伪条件）** | 如果允许货币浮动后，决策者设定利率的灵活性没有提高，或者货币政策反而受到更大约束，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像松开刹车踏板，虽然车子会暂时减速（通胀），但之后驾驶员可以更自由地控制速度（利率）

### 🔗 文字版因果链

1. 面临外部压力时，放弃钉住汇率，允许货币浮动
2. 货币浮动导致暂时性通胀
3. 但浮动汇率使货币政策不再受制于维持汇率稳定，从而为决策者设定利率提供了更大灵活性
