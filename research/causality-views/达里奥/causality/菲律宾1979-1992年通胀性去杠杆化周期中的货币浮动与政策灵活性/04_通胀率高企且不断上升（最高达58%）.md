# 通胀率高企且不断上升（最高达58%）

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第4块/7块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币疲软（实际汇率下降） |
| **DV（因变量）** | 通胀率高企且不断上升（最高达58%） |
| **Chain（传导链）** | 货币贬值导致进口商品价格上升 → 进口成本上升传导至国内物价 → 通胀预期形成，工资和价格螺旋上升 → 通胀率在萧条阶段最高达到58% |
| **Lag（时滞）** | 货币贬值后数月内通胀上升，持续整个萧条阶段 |
| **Threshold（临界值）** | 实际汇率下降超过16%，通胀率超过50% |
| **前提与约束（Premises）** | 存在高额外币债务（占GDP的56%）；经济依赖进口；存在通胀预期自我强化机制 |
| **Falsification（证伪条件）** | 如果货币贬值但通胀率没有显著上升，或者通胀率低于预期水平，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像进口水果价格因汇率下跌而上涨，最终带动整个水果市场价格上升

### 🔗 文字版因果链

1. 货币贬值导致进口商品价格上升
2. 进口成本上升传导至国内物价
3. 通胀预期形成，工资和价格螺旋上升
4. 通胀率在萧条阶段最高达到58%
