# 经济易受外资撤出影响，导致国际收支危机 货币危机

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第2块/7块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高额外币计价债务（占GDP的56%） |
| **DV（因变量）** | 经济易受外资撤出影响，导致国际收支危机/货币危机 |
| **Chain（传导链）** | 外币债务占GDP比例高（56%） → 外资流入强劲但不可持续，依赖外资填补经常账户缺口 → 外部冲击（大宗商品价格骤跌、政治暴力）导致外资流入减少 → 资本流入降幅达GDP的9%，货币政策收紧，货币大幅贬值 → 高额外币债务使偿债成本上升，加剧经济萧条和国际收支危机 |
| **Lag（时滞）** | 泡沫阶段积累，萧条阶段显现（约2-3年） |
| **Threshold（临界值）** | 外币债务占GDP的56%以上，资本流入降幅超过GDP的9% |
| **前提与约束（Premises）** | 存在经常账户赤字（占GDP的7%）；依赖外国资金流入；外部冲击发生时缺乏缓冲 |
| **Falsification（证伪条件）** | 如果高额外币债务没有导致外资撤出或危机，或者经济在类似债务水平下保持稳定，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像借了大量外币贷款的家庭，一旦收入来源（外资）中断，就会面临还债危机

### 🔗 文字版因果链

1. 外币债务占GDP比例高（56%）
2. 外资流入强劲但不可持续，依赖外资填补经常账户缺口
3. 外部冲击（大宗商品价格骤跌、政治暴力）导致外资流入减少
4. 资本流入降幅达GDP的9%，货币政策收紧，货币大幅贬值
5. 高额外币债务使偿债成本上升，加剧经济萧条和国际收支危机
