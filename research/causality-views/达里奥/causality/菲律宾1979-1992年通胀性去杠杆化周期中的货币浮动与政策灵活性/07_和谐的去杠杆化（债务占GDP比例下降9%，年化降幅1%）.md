# 和谐的去杠杆化（债务占GDP比例下降9%，年化降幅1%）

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第7块/7块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 积极管控金融机构和处理坏账（使用9个典型政策工具中的7个） |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP比例下降9%，年化降幅1%） |
| **Chain（传导链）** | 将银行国有化，提供流动性，直接购买不良资产 → 金融机构压力减轻，信贷渠道恢复 → 债务与收入比率下降，主要原因是名义收入增加 → 债务占GDP比例下降9%（年化降幅1%） |
| **Lag（时滞）** | 政策实施后1-2年债务比例开始下降 |
| **Threshold（临界值）** | 使用至少7个政策工具，债务占GDP比例下降9% |
| **前提与约束（Premises）** | 决策者积极干预金融机构；存在IMF援助和结构性改革；名义收入增长 |
| **Falsification（证伪条件）** | 如果积极管控金融机构但债务比例没有下降，或者下降幅度小于预期，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像清理坏账和整顿银行，虽然短期成本高，但能避免债务雪球越滚越大

### 🔗 文字版因果链

1. 将银行国有化，提供流动性，直接购买不良资产
2. 金融机构压力减轻，信贷渠道恢复
3. 债务与收入比率下降，主要原因是名义收入增加
4. 债务占GDP比例下降9%（年化降幅1%）
