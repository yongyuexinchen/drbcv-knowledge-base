# 英国GDP陷入自我强化式下跌，跌幅达15%

> 属于因果簇：[[英国1941-1967年战时通缩性去杠杆化周期]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 战后英国实际收入水平下降且政府继续承担战争开销 |
| **DV（因变量）** | 英国GDP陷入自我强化式下跌，跌幅达15% |
| **Chain（传导链）** | 战时生产模式结束，经济转型 → 实际收入下降，消费和投资减少 → 政府继续战争相关支出，财政压力大 → GDP下跌形成自我强化循环 |
| **Lag（时滞）** | 1943-1947年 |
| **Threshold（临界值）** | GDP跌幅达15% |
| **前提与约束（Premises）** | 英国为战胜国，衰退程度不如战败国严重；政府财政赤字持续存在；经济处于去杠杆化阶段 |
| **Falsification（证伪条件）** | 若战后GDP未出现持续下跌，或跌幅低于15%，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同战后工厂转产，工人失业，收入下降，消费减少，经济陷入恶性循环

### 🔗 文字版因果链

1. 战时生产模式结束，经济转型
2. 实际收入下降，消费和投资减少
3. 政府继续战争相关支出，财政压力大
4. GDP下跌形成自我强化循环
