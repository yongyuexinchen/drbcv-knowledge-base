# 债务占GDP比例下降88%，经济恢复竞争力，实际GDP5年恢

> 属于因果簇：[[泰国1993-2004年债务危机因果分析]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施紧缩政策和积极管控金融机构（使用8个政策工具） |
| **DV（因变量）** | 债务占GDP比例下降88%，经济恢复竞争力，实际GDP5年恢复峰值 |
| **Chain（传导链）** | 减少进口支出（经常账户余额增幅为GDP的21%） → 银行国有化、提供流动性、直接购买不良资产 → 实际经济增速提升，推动名义收入增加 → 货币贬值提高竞争力，出口增加 → 债务与收入比率下降，经济恢复 |
| **Lag（时滞）** | 约5年（1998-2003年） |
| **Threshold（临界值）** | 债务占GDP比例下降88%（年化降幅15%），实际汇率跌至-16% |
| **前提与约束（Premises）** | 决策者实施紧缩政策；积极管控金融机构；存在IMF援助计划 |
| **Falsification（证伪条件）** | 如果实施紧缩政策但债务比例未下降或经济未恢复，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 减少进口支出（经常账户余额增幅为GDP的21%）
2. 银行国有化、提供流动性、直接购买不良资产
3. 实际经济增速提升，推动名义收入增加
4. 货币贬值提高竞争力，出口增加
5. 债务与收入比率下降，经济恢复
