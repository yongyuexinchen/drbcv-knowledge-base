# 泰国1993-2004年债务危机因果分析（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：泰国1993-2004年债务危机因果分析.md

## 总体因果图

- 大量资本流入和债务累积（外币计价债务占GDP的51%） → 自我强化的泡沫周期（债务占GDP达183%，GDP增速8%，
- 外资流入减少（资本流入降幅为GDP的34%） → 货币政策收紧、货币贬值、GDP和股价下跌（GDP跌14%，股
- 决策者放弃捍卫货币，允许货币浮动 → 通胀性去杠杆化，但为利率政策提供更大灵活性
- 实施紧缩政策和积极管控金融机构（使用8个政策工具） → 债务占GDP比例下降88%，经济恢复竞争力，实际GDP5年恢
- 金融危机 → 泰国政局显著影响，为他信·西那瓦上台搭建舞台
