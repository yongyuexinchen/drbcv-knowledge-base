# 技术-经济范式演进的四阶段因果模型

> **领域**：宏观经济学、技术经济学、经济史　|　**来源**：chapter_15_part_01.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 技术革命的发生（“大爆炸”） |
| **DV（因变量）** | 技术-经济范式进入导入期（爆发阶段） |
| **Chain（传导链）** | 旧范式产业技术成熟，市场饱和，经济面临停滞威胁 → 新设计、新产品和充满盈利可能性的新领域出现，点燃企业家想象力 → 新兴产业惊人的增长速度和生产率表现吸引投资者 → 新范式承载者的活动与旧产业衰落形成鲜明对比，产生技术-经济裂痕 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 新兴产业展现出显著高于旧产业的生产率增长和投资回报率 |
| **前提与约束（Premises）** | 存在大量潜在投资资金；旧范式产业处于饱和状态；经济面临停滞威胁 |
| **Falsification（证伪条件）** | 如果新技术出现后，旧产业仍能保持增长且新产业未能吸引投资，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同新物种入侵生态系统的初期，旧物种面临生存压力，新物种迅速占据生态位

### 🔗 文字版因果链

1. 旧范式产业技术成熟，市场饱和，经济面临停滞威胁
2. 新设计、新产品和充满盈利可能性的新领域出现，点燃企业家想象力
3. 新兴产业惊人的增长速度和生产率表现吸引投资者
4. 新范式承载者的活动与旧产业衰落形成鲜明对比，产生技术-经济裂痕

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本在导入期后半段的主导地位 |
| **DV（因变量）** | 狂热阶段（投机、腐败、社会两极分化） |
| **Chain（传导链）** | 金融资本直接利益凌驾于整个体系运作之上 → 虚拟经济与实体经济脱钩，金融与生产脱节 → 财富在少数人手中集中，社会排斥加剧 → 大量过剩资金倾注于基础设施建设，导致过度投资 → 股市资产膨胀，形成赌博经济和金融泡沫 |
| **Lag（时滞）** | 中期（数年） |
| **Threshold（临界值）** | 金融资本利润超过生产资本利润，且社会财富集中度显著上升 |
| **前提与约束（Premises）** | 新范式潜力尚未充分展开；监管框架无能为力；个人主义思潮盛行 |
| **Falsification（证伪条件）** | 如果金融资本主导时期未出现投机泡沫和社会分化加剧，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同赌场中庄家通吃，赌徒们沉迷于快速致富的幻觉，最终导致泡沫破裂

### 🔗 文字版因果链

1. 金融资本直接利益凌驾于整个体系运作之上
2. 虚拟经济与实体经济脱钩，金融与生产脱节
3. 财富在少数人手中集中，社会排斥加剧
4. 大量过剩资金倾注于基础设施建设，导致过度投资
5. 股市资产膨胀，形成赌博经济和金融泡沫

## 因果断言 3

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 狂热阶段积累的结构性紧张关系（金融泡沫破裂、社会动荡） |
| **DV（因变量）** | 转折点（监管改革、制度重构） |
| **Chain（传导链）** | 金融泡沫破裂引发经济衰退 → 社会动荡和抗议活动加剧 → 决策者认识到现有做法不可持续 → 制定、实施和接受监管措施的条件成熟 → 确立新的增长模式，从金融标准转向生产能力标准 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 金融泡沫破裂且经济衰退严重到足以迫使政策转向 |
| **前提与约束（Premises）** | 存在社会力量推动改革；决策者愿意接受替代方案；结构性紧张关系无法通过旧方法解决 |
| **Falsification（证伪条件）** | 如果金融泡沫破裂后未出现制度重构，而是回到原有模式，则该断言不成立 |
| **Confidence（确信度）** | well-established |

1. 金融泡沫破裂引发经济衰退
2. 社会动荡和抗议活动加剧
3. 决策者认识到现有做法不可持续
4. 制定、实施和接受监管措施的条件成熟
5. 确立新的增长模式，从金融标准转向生产能力标准

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 范式成熟和市场饱和 |
| **DV（因变量）** | 成熟阶段（增长放缓、社会质疑、下一次革命酝酿） |
| **Chain（传导链）** | 最晚出现的技术体系和产品生命周期缩短 → 市场逐渐饱和，利润受生产力瓶颈制约 → 企业通过并购、出口和转移业务维持利润 → 社会对资本主义制度提出深刻质疑 → 对新技术解决方案的探求突破现有范式逻辑 → 下一次技术革命舞台搭建就绪 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 主要产业出现萎缩的投资机会和停滞的市场 |
| **前提与约束（Premises）** | 范式潜力已充分展开；社会对进步承诺的期待未完全兑现；存在未满足的社会需求 |
| **Falsification（证伪条件）** | 如果范式成熟后未出现增长放缓和社会质疑，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同果树结完果实后逐渐衰老，需要新树苗替代

### 🔗 文字版因果链

1. 最晚出现的技术体系和产品生命周期缩短
2. 市场逐渐饱和，利润受生产力瓶颈制约
3. 企业通过并购、出口和转移业务维持利润
4. 社会对资本主义制度提出深刻质疑
5. 对新技术解决方案的探求突破现有范式逻辑
6. 下一次技术革命舞台搭建就绪
