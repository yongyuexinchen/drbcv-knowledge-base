# 经济赶超成功（实现跳跃式发展）

> 属于因果簇：[[狂热阶段金融资本与两极分化及泡沫破裂的因果机制]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 后发国家利用技术革命机遇窗口（如亚洲四小龙） |
| **DV（因变量）** | 经济赶超成功（实现跳跃式发展） |
| **Chain（传导链）** | 后发国家具备地理、历史或国际条件 → 新范式提供跳跃式发展机会 → 吸引外国投资和技术转移 → 国内产业升级，出口增长 → 经济快速增长，实现赶超 |
| **Lag（时滞）** | 10-30年（导入期到成熟期） |
| **Threshold（临界值）** | 需要具备一定的基础设施和人力资本，以及稳定的政治环境 |
| **前提与约束（Premises）** | 国际地缘政治有利（如冷战时期美国支持）；国内政策支持开放和改革；全球市场需求旺盛 |
| **Falsification（证伪条件）** | 如果后发国家具备条件但未实现赶超，或赶超成功但无机遇窗口，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同赛车手在弯道超车，需要时机、技术和赛道条件

### 🔗 文字版因果链

1. 后发国家具备地理、历史或国际条件
2. 新范式提供跳跃式发展机会
3. 吸引外国投资和技术转移
4. 国内产业升级，出口增长
5. 经济快速增长，实现赶超
