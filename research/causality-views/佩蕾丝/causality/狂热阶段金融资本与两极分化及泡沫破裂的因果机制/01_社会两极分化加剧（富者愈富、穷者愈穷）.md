# 社会两极分化加剧（富者愈富、穷者愈穷）

> 属于因果簇：[[狂热阶段金融资本与两极分化及泡沫破裂的因果机制]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本与生产资本脱钩，金融资本追求高额短期收益 |
| **DV（因变量）** | 社会两极分化加剧（富者愈富、穷者愈穷） |
| **Chain（传导链）** | 金融资本脱离生产，专注于投机活动 → 投机活动集中于少数成功者，财富迅速集中 → 成功者财富增加，而落后部门缺乏资金陷入停滞 → 经济两极分化，社会差距扩大 |
| **Lag（时滞）** | 狂热阶段持续期间（数年） |
| **Threshold（临界值）** | 金融资本占经济主导地位，投机收益远超生产收益 |
| **前提与约束（Premises）** | 技术革命爆发阶段已形成新旧分化；金融资本具有流动性优势，可自由选择投资方向；制度与规则滞后，无法有效约束金融投机 |
| **Falsification（证伪条件）** | 如果金融资本脱钩但社会差距未扩大，或差距扩大但金融资本未脱钩，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同水流被引向高地，低地干涸，高地泛滥，水越多，干涸与泛滥越严重

### 🔗 文字版因果链

1. 金融资本脱离生产，专注于投机活动
2. 投机活动集中于少数成功者，财富迅速集中
3. 成功者财富增加，而落后部门缺乏资金陷入停滞
4. 经济两极分化，社会差距扩大
