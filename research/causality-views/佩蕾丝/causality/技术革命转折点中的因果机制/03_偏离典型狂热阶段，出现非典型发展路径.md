# 偏离典型狂热阶段，出现非典型发展路径

> 属于因果簇：[[技术革命转折点中的因果机制]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 技术革命导入期力度不足或金融资本不热衷 |
| **DV（因变量）** | 偏离典型狂热阶段，出现非典型发展路径 |
| **Chain（传导链）** | 金融资本更关注海外投资或旧技术，而非新技术 → 国内技术革命缺乏资金支持，产业现代化不足 → 狂热和泡沫发生在其他国家，而非本国 → 本国经历温和增长或衰退，而非典型狂热后的崩溃 → 制度背景和政治因素决定具体路径 |
| **Lag（时滞）** | 整个导入期和狂热阶段，可能持续数十年 |
| **Threshold（临界值）** | 金融资本对新技术投资低于临界水平 |
| **前提与约束（Premises）** | 国家处于技术革命的赶超阶段；金融资本有海外投资机会或旧技术仍有利可图；政府政策（如关税保护）影响产业和资本行为 |
| **Falsification（证伪条件）** | 如果金融资本不热衷但国内仍出现狂热，或导入期不足但仍有典型狂热，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一个人对新兴行业不感兴趣，而继续投资传统行业，其财富增长路径自然不同

### 🔗 文字版因果链

1. 金融资本更关注海外投资或旧技术，而非新技术
2. 国内技术革命缺乏资金支持，产业现代化不足
3. 狂热和泡沫发生在其他国家，而非本国
4. 本国经历温和增长或衰退，而非典型狂热后的崩溃
5. 制度背景和政治因素决定具体路径
