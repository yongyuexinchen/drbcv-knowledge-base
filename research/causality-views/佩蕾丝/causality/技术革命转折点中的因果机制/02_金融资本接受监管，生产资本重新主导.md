# 金融资本接受监管，生产资本重新主导

> 属于因果簇：[[技术革命转折点中的因果机制]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济崩溃和衰退 |
| **DV（因变量）** | 金融资本接受监管，生产资本重新主导 |
| **Chain（传导链）** | 经济崩溃使金融资本遭受巨大损失，其信誉受损 → 非法或欺诈行为被揭露，公众压力增大 → 金融资本无力抵抗，被迫接受新的规章制度 → 制度框架转向有利于实体经济，生产资本获得主导权 → 进入协同阶段，实现更和谐的增长 |
| **Lag（时滞）** | 崩溃后数年甚至更长时间，如1929年后经历大萧条和二战才建立凯恩斯框架 |
| **Threshold（临界值）** | 重大破产和失败事件发生，且不被救助 |
| **前提与约束（Premises）** | 金融资本在崩溃中遭受重大损失，无力反抗；社会和政治压力足够强大，推动监管改革；存在替代性的制度框架（如凯恩斯主义）可供采纳 |
| **Falsification（证伪条件）** | 如果经济崩溃后金融资本仍能维持主导，或监管未得到加强，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同孩子玩火被烫伤后，才愿意接受大人的规则

### 🔗 文字版因果链

1. 经济崩溃使金融资本遭受巨大损失，其信誉受损
2. 非法或欺诈行为被揭露，公众压力增大
3. 金融资本无力抵抗，被迫接受新的规章制度
4. 制度框架转向有利于实体经济，生产资本获得主导权
5. 进入协同阶段，实现更和谐的增长
