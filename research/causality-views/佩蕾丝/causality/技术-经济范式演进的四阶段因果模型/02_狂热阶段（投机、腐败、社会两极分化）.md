# 狂热阶段（投机、腐败、社会两极分化）

> 属于因果簇：[[技术-经济范式演进的四阶段因果模型]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本在导入期后半段的主导地位 |
| **DV（因变量）** | 狂热阶段（投机、腐败、社会两极分化） |
| **Chain（传导链）** | 金融资本直接利益凌驾于整个体系运作之上 → 虚拟经济与实体经济脱钩，金融与生产脱节 → 财富在少数人手中集中，社会排斥加剧 → 大量过剩资金倾注于基础设施建设，导致过度投资 → 股市资产膨胀，形成赌博经济和金融泡沫 |
| **Lag（时滞）** | 中期（数年） |
| **Threshold（临界值）** | 金融资本利润超过生产资本利润，且社会财富集中度显著上升 |
| **前提与约束（Premises）** | 新范式潜力尚未充分展开；监管框架无能为力；个人主义思潮盛行 |
| **Falsification（证伪条件）** | 如果金融资本主导时期未出现投机泡沫和社会分化加剧，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同赌场中庄家通吃，赌徒们沉迷于快速致富的幻觉，最终导致泡沫破裂

### 🔗 文字版因果链

1. 金融资本直接利益凌驾于整个体系运作之上
2. 虚拟经济与实体经济脱钩，金融与生产脱节
3. 财富在少数人手中集中，社会排斥加剧
4. 大量过剩资金倾注于基础设施建设，导致过度投资
5. 股市资产膨胀，形成赌博经济和金融泡沫
