# 技术-经济范式演进的四阶段因果模型（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：技术-经济范式演进的四阶段因果模型.md

## 总体因果图

- 技术革命的发生（“大爆炸”） → 技术-经济范式进入导入期（爆发阶段）
- 金融资本在导入期后半段的主导地位 → 狂热阶段（投机、腐败、社会两极分化）
- 狂热阶段积累的结构性紧张关系（金融泡沫破裂、社会动荡） → 转折点（监管改革、制度重构）
- 转折点后的制度框架确立（监管改革、社会凝聚力增强） → 协同阶段（生产时代、黄金时代）
- 范式成熟和市场饱和 → 成熟阶段（增长放缓、社会质疑、下一次革命酝酿）
