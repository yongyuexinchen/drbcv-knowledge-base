# 技术-经济范式进入导入期（爆发阶段）

> 属于因果簇：[[技术-经济范式演进的四阶段因果模型]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 技术革命的发生（“大爆炸”） |
| **DV（因变量）** | 技术-经济范式进入导入期（爆发阶段） |
| **Chain（传导链）** | 旧范式产业技术成熟，市场饱和，经济面临停滞威胁 → 新设计、新产品和充满盈利可能性的新领域出现，点燃企业家想象力 → 新兴产业惊人的增长速度和生产率表现吸引投资者 → 新范式承载者的活动与旧产业衰落形成鲜明对比，产生技术-经济裂痕 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 新兴产业展现出显著高于旧产业的生产率增长和投资回报率 |
| **前提与约束（Premises）** | 存在大量潜在投资资金；旧范式产业处于饱和状态；经济面临停滞威胁 |
| **Falsification（证伪条件）** | 如果新技术出现后，旧产业仍能保持增长且新产业未能吸引投资，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同新物种入侵生态系统的初期，旧物种面临生存压力，新物种迅速占据生态位

### 🔗 文字版因果链

1. 旧范式产业技术成熟，市场饱和，经济面临停滞威胁
2. 新设计、新产品和充满盈利可能性的新领域出现，点燃企业家想象力
3. 新兴产业惊人的增长速度和生产率表现吸引投资者
4. 新范式承载者的活动与旧产业衰落形成鲜明对比，产生技术-经济裂痕
