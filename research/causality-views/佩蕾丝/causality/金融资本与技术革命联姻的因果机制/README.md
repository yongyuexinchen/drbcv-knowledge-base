# 金融资本与技术革命联姻的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：金融资本与技术革命联姻的因果机制.md

## 总体因果图

- 技术革命爆发（新范式出现） → 金融资本大量涌入新兴产业（风险资本工具创新）
- 金融资本与新兴产业“联姻”（过度投入） → 金融资本与生产资本脱钩，引发金融狂热与危机
- 新旧范式共存（生产结构分叉） → 核心国家经济困境与赶超国家发展顶峰并存
