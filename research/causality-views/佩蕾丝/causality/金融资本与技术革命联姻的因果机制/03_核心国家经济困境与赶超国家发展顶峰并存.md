# 核心国家经济困境与赶超国家发展顶峰并存

> 属于因果簇：[[金融资本与技术革命联姻的因果机制]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新旧范式共存（生产结构分叉） |
| **DV（因变量）** | 核心国家经济困境与赶超国家发展顶峰并存 |
| **Chain（传导链）** | 技术革命爆发，新范式出现，但旧范式仍占主导 → 新兴产业生机勃勃但占经济份额小，传统产业成熟颓势显现 → 核心国家传统产业面临失业和价格波动，经济困境加剧 → 赶超国家利用成熟范式空间，无旧投资负担，进军新兴领域，达到发展顶峰 |
| **Lag（时滞）** | 中期（共存期持续数十年） |
| **Threshold（临界值）** | 新范式占经济份额较小，旧范式仍为主体 |
| **前提与约束（Premises）** | 核心国家存在大量成熟传统产业；赶超国家具备利用成熟范式的条件和空间；赶超国家无旧有投资负担 |
| **Falsification（证伪条件）** | 如果核心国家未出现经济困境，或赶超国家未能达到发展顶峰，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同新旧两代人同堂，老一代面临衰退，新一代充满活力，但家庭整体资源有限，导致代际间发展不平衡

### 🔗 文字版因果链

1. 技术革命爆发，新范式出现，但旧范式仍占主导
2. 新兴产业生机勃勃但占经济份额小，传统产业成熟颓势显现
3. 核心国家传统产业面临失业和价格波动，经济困境加剧
4. 赶超国家利用成熟范式空间，无旧投资负担，进军新兴领域，达到发展顶峰
