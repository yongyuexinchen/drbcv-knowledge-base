# 信用需求在任一价格水平上可能无限，导致投机性繁荣

> 属于因果簇：[[新金融体系与次贷危机：风险回归与监管缺失]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融市场变成仅依据价格运行的现货市场，存在大量不受限制的信用 |
| **DV（因变量）** | 信用需求在任一价格水平上可能无限，导致投机性繁荣 |
| **Chain（传导链）** | 金融市场以价格为导向，忽视个体信用评估 → 信用供给不受限制，需求对价格不敏感 → 经济周期中信用需求无限膨胀 → 引发投机性繁荣和金融不稳定 |
| **Lag（时滞）** | 周期性（随经济周期显现） |
| **Threshold（临界值）** | 当信用需求在任一价格水平上无限时 |
| **前提与约束（Premises）** | 市场缺乏对信用规模的限制；存在投机性繁荣的倾向 |
| **Falsification（证伪条件）** | 若信用需求对价格敏感且有限，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同自助餐不限量，食客会吃到撑（投机繁荣），最终导致身体不适（金融危机）

### 🔗 文字版因果链

1. 金融市场以价格为导向，忽视个体信用评估
2. 信用供给不受限制，需求对价格不敏感
3. 经济周期中信用需求无限膨胀
4. 引发投机性繁荣和金融不稳定
