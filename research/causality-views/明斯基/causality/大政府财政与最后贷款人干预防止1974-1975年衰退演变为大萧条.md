# 大政府财政与最后贷款人干预防止1974-1975年衰退演变为大萧条

> **领域**：宏观经济学　|　**来源**：chapter_24.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 强大的财政手段（自动稳定器如转移支付、税收下降，相机抉择如税收减免、失业保险扩展）和及时的最终贷款人干预 |
| **DV（因变量）** | 经济在1974-1975年衰退后迅速复苏，未陷入持续深度衰退或大萧条 |
| **Chain（传导链）** | 财政自动稳定器在收入下降时自动增加转移支付并减少税收，支撑总需求 → 相机抉择的财政措施（税收减免、失业保险扩展）进一步刺激消费和投资 → 最终贷款人（美联储）及时干预，提供流动性，防止金融机构破产蔓延 → 总需求得以维持，收入停止下滑，失业率在阶段性高点后回落 → 经济于1975年第二季度开始复苏，金融动荡消退，避免债务紧缩和大萧条 |
| **Lag（时滞）** | 即时至数月内（财政自动稳定器即时生效，相机抉择和干预在数周至数月内见效） |
| **Threshold（临界值）** | 财政赤字占GDP比例足够大（如转移支付和减税规模足以抵消私人需求下降）；最终贷款人干预及时且规模足够（如提供流动性覆盖银行挤兑需求） |
| **前提与约束（Premises）** | 存在大规模自动稳定器（如失业保障、累进税制）；政府有财政空间实施相机抉择措施；中央银行有能力和意愿充当最终贷款人；金融动荡主要限于金融机构和企业，未引发全面信心崩溃 |
| **Falsification（证伪条件）** | 如果1974-1975年衰退中，尽管有财政和干预措施，但收入持续大幅下降、失业持续上升、金融体系崩溃，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个病人突然重病，但因为有强健的免疫系统（自动稳定器）和及时的治疗（最终贷款人），很快康复，而不是像以前那样恶化成绝症（大萧条）。

### 🔗 文字版因果链

1. 财政自动稳定器在收入下降时自动增加转移支付并减少税收，支撑总需求
2. 相机抉择的财政措施（税收减免、失业保险扩展）进一步刺激消费和投资
3. 最终贷款人（美联储）及时干预，提供流动性，防止金融机构破产蔓延
4. 总需求得以维持，收入停止下滑，失业率在阶段性高点后回落
5. 经济于1975年第二季度开始复苏，金融动荡消退，避免债务紧缩和大萧条
