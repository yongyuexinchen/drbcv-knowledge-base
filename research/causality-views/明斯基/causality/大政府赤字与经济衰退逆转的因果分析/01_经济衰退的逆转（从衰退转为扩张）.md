# 经济衰退的逆转（从衰退转为扩张）

> 属于因果簇：[[大政府赤字与经济衰退逆转的因果分析]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大政府创造的巨额财政赤字 |
| **DV（因变量）** | 经济衰退的逆转（从衰退转为扩张） |
| **Chain（传导链）** | 政府支出超过收入，形成巨额赤字 → 赤字为经济注入总需求，抵消其他部门的盈余 → 总需求增加，企业销售和利润得以维持 → 企业现金流稳定，避免违约和破产，维持借贷能力 → 经济下滑被阻止，并迅速转为扩张 |
| **Lag（时滞）** | 即时（1975年当年） |
| **Threshold（临界值）** | 1975年第二季度联邦赤字达1022亿美元，较上年同期增加943亿美元 |
| **前提与约束（Premises）** | 所有部门的盈余和赤字之和为零（会计恒等式）；政府赤字必须足够大，足以抵消其他部门的净储蓄或投资减少；经济处于衰退期，存在闲置资源 |
| **Falsification（证伪条件）** | 如果政府赤字大幅增加但经济衰退未逆转或恶化，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像干旱时政府开闸放水，水库的水（赤字）流入干涸的农田（经济），庄稼（企业）得以存活并恢复生长。

### 🔗 文字版因果链

1. 政府支出超过收入，形成巨额赤字
2. 赤字为经济注入总需求，抵消其他部门的盈余
3. 总需求增加，企业销售和利润得以维持
4. 企业现金流稳定，避免违约和破产，维持借贷能力
5. 经济下滑被阻止，并迅速转为扩张
