# 大政府干预防止金融崩溃的因果机制（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：大政府干预防止金融崩溃的因果机制.md

## 总体因果图

- 大政府的财政政策（经济衰退中的大量政府赤字） → 私人金融承诺得以持久，投资组合结构优化，避免金融崩溃
- 最终贷款人干预（美联储、FDIC及私人金融机构的再融资） → 避免金融恐慌演变为全面金融危机
