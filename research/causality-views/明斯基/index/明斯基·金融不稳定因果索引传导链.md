## 主传导链

```
经济稳定期（繁荣持续）
        │
        ▼
企业融资结构漂移：对冲性融资 → 投机性融资 → 庞氏融资
（现金流入覆盖债务 → 只覆盖利息 → 连利息都靠新债）
        │
        ▼
金融创新加速（新工具/新机构放大杠杆）
        │
        ▼
金融脆弱性积累（利润依赖投资，投资依赖融资，融资依赖预期）
        │
        ▼
微小扰动 → 资产价格逆转 → 债务链断裂 → 金融危机
        │
        ▼
（若无干预）深度衰退
        │
        ▼
大政府赤字 + 最后贷款人干预 → 现金流抵消 → 衰退逆转
```

## 不变式

1. **融资结构是脆弱性仪表盘**：对冲→投机→庞氏，是危机的倒计时（但当局者看不到）
2. **稳定是危机的温床**：繁荣越久、越稳定，融资漂移越深，脆弱性越大——**反直觉核心**
3. **大政府是稳定器**：政府赤字和最后贷款人不是道德风险，是防止通缩螺旋的必要工具

## 跨作者交叉点

- **与达里奥**：明斯基解释了危机**为什么发生**（融资漂移），达里奥解释了危机**发生后的政策矩阵**（去杠杆四方式）——明斯基是"病因学"，达里奥是"治疗学"
- **与辜朝明**：明斯基上行（融资扩张）、辜朝明下行（负债最小化）——合起来是完整信贷周期
- **与付鹏**：付鹏 2020 卡"美联储无力退出宽松"正是明斯基"大政府介入后难以退出"的当代案例——政策被债务绑架
