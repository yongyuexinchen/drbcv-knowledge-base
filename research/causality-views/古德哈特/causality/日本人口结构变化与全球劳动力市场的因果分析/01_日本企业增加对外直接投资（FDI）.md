# 日本企业增加对外直接投资（FDI）

> 属于因果簇：[[日本人口结构变化与全球劳动力市场的因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 日本国内劳动力供给减少 |
| **DV（因变量）** | 日本企业增加对外直接投资（FDI） |
| **Chain（传导链）** | 日本国内劳动力减少导致劳动力成本上升和国内需求疲软 → 企业为追求利润最大化，寻求成本更低、增长更快的海外市场 → 企业通过增加对外直接投资，利用全球充裕的廉价劳动力和强劲的海外需求 |
| **Lag（时滞）** | 短期至中期（在‘失去的十年’期间即已显现） |
| **Threshold（临界值）** | 国内劳动力成本上升至企业无法通过国内生产维持利润时 |
| **前提与约束（Premises）** | 日本是开放经济体，资本可以自由流动；世界其他地区存在劳动力充裕和增长机会；企业以利润最大化为核心目标 |
| **Falsification（证伪条件）** | 如果日本国内劳动力减少但对外直接投资没有增加，或对外直接投资与国内劳动力变化无相关性 |
| **Confidence（确信度）** | well-established |
