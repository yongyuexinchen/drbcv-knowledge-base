# 企业部门从债权融资转向股权融资

> 属于因果簇：[[从债权融资转向股权融资的因果分析]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 纠正债权融资相对于股权融资的财务优势（如税收、监管待遇） |
| **DV（因变量）** | 企业部门从债权融资转向股权融资 |
| **Chain（传导链）** | 政策调整使股权融资的税后成本降低，债权融资的税后成本提高 → 企业融资决策中股权融资相对吸引力增加 → 企业新增融资中股权融资比例上升 → 企业杠杆率下降，财务稳定性增强 |
| **Lag（时滞）** | 中期（3-7年），取决于政策实施速度和市场反应 |
| **Threshold（临界值）** | 股权融资的财务优势（如税后成本、监管资本权重）需至少与债权融资持平或超过 |
| **前提与约束（Premises）** | 政策制定者有能力调整税收、监管等制度框架；企业治理结构允许股权融资的扩大；不涉及存量债务的强制转换，仅针对新增融资；资本市场深度足够，能吸收更多股权发行 |
| **Falsification（证伪条件）** | 如果股权融资财务优势大幅提升后，企业仍偏好债权融资，且杠杆率未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同调整两种商品的税率，使一种商品相对更便宜，消费者就会更多购买这种商品，从而改变消费结构

### 🔗 文字版因果链

1. 政策调整使股权融资的税后成本降低，债权融资的税后成本提高
2. 企业融资决策中股权融资相对吸引力增加
3. 企业新增融资中股权融资比例上升
4. 企业杠杆率下降，财务稳定性增强
