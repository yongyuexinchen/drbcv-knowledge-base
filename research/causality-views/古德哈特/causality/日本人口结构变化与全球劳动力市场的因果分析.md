# 日本人口结构变化与全球劳动力市场的因果分析

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 日本国内劳动力供给减少 |
| **DV（因变量）** | 日本企业增加对外直接投资（FDI） |
| **Chain（传导链）** | 日本国内劳动力减少导致劳动力成本上升和国内需求疲软 → 企业为追求利润最大化，寻求成本更低、增长更快的海外市场 → 企业通过增加对外直接投资，利用全球充裕的廉价劳动力和强劲的海外需求 |
| **Lag（时滞）** | 短期至中期（在‘失去的十年’期间即已显现） |
| **Threshold（临界值）** | 国内劳动力成本上升至企业无法通过国内生产维持利润时 |
| **前提与约束（Premises）** | 日本是开放经济体，资本可以自由流动；世界其他地区存在劳动力充裕和增长机会；企业以利润最大化为核心目标 |
| **Falsification（证伪条件）** | 如果日本国内劳动力减少但对外直接投资没有增加，或对外直接投资与国内劳动力变化无相关性 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 日本国内劳动力减少导致劳动力成本上升和国内需求疲软
2. 企业为追求利润最大化，寻求成本更低、增长更快的海外市场
3. 企业通过增加对外直接投资，利用全球充裕的廉价劳动力和强劲的海外需求

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 日本国内劳动力减少 |
| **DV（因变量）** | 日本总产出增长缓慢但人均产出（生产率）增长较快 |
| **Chain（传导链）** | 劳动力数量下降直接拖累总产出增长 → 企业通过提高生产率和资本深化（如自动化）来抵消劳动力减少的影响 → 人均产出因劳动力减少和产出稳定而上升 |
| **Lag（时滞）** | 中期（约2000年后显现） |
| **Threshold（临界值）** | 劳动力年均减少1%，而总产出年均增长约1% |
| **前提与约束（Premises）** | 企业能够进行技术升级和资本投资；劳动力市场具有灵活性，允许企业调整用工结构；排除资产泡沫破灭后的最初十年（1991-1999）的混乱期 |
| **Falsification（证伪条件）** | 如果日本人均产出增长率低于其他发达经济体，或生产率增长未能抵消劳动力下降的影响 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个乐队人数减少，但每个乐手演奏得更卖力、更高效，整体演奏效果（人均产出）反而提升了。

### 🔗 文字版因果链

1. 劳动力数量下降直接拖累总产出增长
2. 企业通过提高生产率和资本深化（如自动化）来抵消劳动力减少的影响
3. 人均产出因劳动力减少和产出稳定而上升

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 日本国内劳动力市场疲软（隐性失业） |
| **DV（因变量）** | 菲利普斯曲线平坦（工资增长停滞，即使失业率低） |
| **Chain（传导链）** | 日本劳动力市场存在大量非正规就业和隐性失业，整体失业率低估了劳动力市场的松弛程度 → 劳动力市场松弛抑制了工资上涨压力 → 即使失业率处于低位，工资增长依然缓慢，导致菲利普斯曲线平坦 |
| **Lag（时滞）** | 长期（近20年持续存在） |
| **Threshold（临界值）** | 失业率低于西方标准，但工资增长率接近零 |
| **前提与约束（Premises）** | 日本劳动力市场具有特殊性（如终身雇佣制、非正规就业比例高）；整体失业率不是衡量劳动力市场紧张程度的充分指标；通胀预期保持稳定或低迷 |
| **Falsification（证伪条件）** | 如果日本失业率显著下降但工资增长依然停滞，且无法用劳动力市场结构特征解释 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个水池看起来水位不高（低失业率），但池底有很多暗洞（隐性失业），水（工资）始终涨不起来。

### 🔗 文字版因果链

1. 日本劳动力市场存在大量非正规就业和隐性失业，整体失业率低估了劳动力市场的松弛程度
2. 劳动力市场松弛抑制了工资上涨压力
3. 即使失业率处于低位，工资增长依然缓慢，导致菲利普斯曲线平坦

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国自20世纪90年代以来的崛起（全球劳动力供给增加） |
| **DV（因变量）** | 日本经济表现（通缩、低利率、低工资增长） |
| **Chain（传导链）** | 中国等发展中国家融入全球经济，提供了大量廉价劳动力 → 日本企业通过对外直接投资和进口，利用全球劳动力红利 → 全球竞争加剧，对日本国内工资和价格产生下行压力 → 日本国内投资机会减少，导致利率和通胀低迷 |
| **Lag（时滞）** | 长期（自20世纪90年代起持续） |
| **Threshold（临界值）** | 全球劳动力供给增加足以改变日本企业的生产和投资决策 |
| **前提与约束（Premises）** | 全球化力量占主导地位；日本是开放经济体，深度融入全球供应链；中国等国的劳动力成本显著低于日本 |
| **Falsification（证伪条件）** | 如果中国崛起但日本经济表现没有相应变化，或日本经济变化可以用纯国内因素解释 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个城市修了新的高速公路，导致老城区的商业街（日本）客流减少，因为人们都去新城（中国）购物了。

### 🔗 文字版因果链

1. 中国等发展中国家融入全球经济，提供了大量廉价劳动力
2. 日本企业通过对外直接投资和进口，利用全球劳动力红利
3. 全球竞争加剧，对日本国内工资和价格产生下行压力
4. 日本国内投资机会减少，导致利率和通胀低迷
