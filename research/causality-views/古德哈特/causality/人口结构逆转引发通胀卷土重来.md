# 人口结构逆转引发通胀卷土重来

> **领域**：宏观经济学　|　**来源**：demog_ch05_inflation.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口结构逆转（劳动力短缺，工人议价能力增强） |
| **DV（因变量）** | 通胀压力上升（通胀卷土重来） |
| **Chain（传导链）** | 人口结构逆转导致劳动力短缺 → 劳动力短缺增强工人的议价能力 → 工人利用较强的议价能力争取更高的工资 → 工资上涨推高生产成本和消费能力 → 整体价格水平上升，通胀压力再度抬头 |
| **Lag（时滞）** | 中期（数年至数十年，随人口结构变化逐步显现） |
| **Threshold（临界值）** | 劳动力供给显著低于需求，工人议价能力足以扭转工资停滞状态 |
| **前提与约束（Premises）** | 社会保障体系仍将存在，老年人依赖政府援助，消费年龄分布曲线保持平坦或向上倾斜；为实现从工人向老年人的资源转移，必须显著提高对工人的征税税率；发达经济体（以及一些新兴经济体）出现劳动力短缺；排除大规模移民或自动化技术完全替代劳动力的情况 |
| **Falsification（证伪条件）** | 如果劳动力短缺出现但工资水平持续停滞，或通胀率在人口老龄化加深时反而持续下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像劳动力市场上供不应求时，工人像稀缺的明星球员一样可以要求更高的转会费和薪水，推高整个球队的运营成本，最终导致票价上涨。

### 🔗 文字版因果链

1. 人口结构逆转导致劳动力短缺
2. 劳动力短缺增强工人的议价能力
3. 工人利用较强的议价能力争取更高的工资
4. 工资上涨推高生产成本和消费能力
5. 整体价格水平上升，通胀压力再度抬头

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口老龄化（工人与被抚养者比例失衡） |
| **DV（因变量）** | 通胀上升 |
| **Chain（传导链）** | 人口老龄化导致工人数量相对减少，被抚养者（老年人和年轻人）比例上升 → 工人的产出大于自身消费，而被抚养者消费大于产出 → 工人与被抚养者之间的平衡被打破，社会总储蓄下降、消费需求结构变化 → 为实现资源从工人向老年人的转移，需提高税率或增加政府支出 → 政府支出增加和工资上涨共同推高通胀 |
| **Lag（时滞）** | 长期（人口结构变化缓慢，效应在数十年内逐步显现） |
| **Threshold（临界值）** | 劳动年龄人口占比下降至关键水平，抚养比显著上升 |
| **前提与约束（Premises）** | 社会保障体系持续存在，老年人依赖政府转移支付；老年人不会为更长寿命进行大量储蓄；政府通过征税实现资源转移，而非大幅削减福利 |
| **Falsification（证伪条件）** | 如果老龄化加深但政府通过削减福利或移民政策有效平衡抚养比，且通胀未上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭中赚钱的年轻人越来越少，而需要花钱的老人和孩子越来越多，家庭必须动用储蓄或借债，最终导致家庭财务压力增大，物价上涨。

### 🔗 文字版因果链

1. 人口老龄化导致工人数量相对减少，被抚养者（老年人和年轻人）比例上升
2. 工人的产出大于自身消费，而被抚养者消费大于产出
3. 工人与被抚养者之间的平衡被打破，社会总储蓄下降、消费需求结构变化
4. 为实现资源从工人向老年人的转移，需提高税率或增加政府支出
5. 政府支出增加和工资上涨共同推高通胀
