## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口结构和全球化的大逆转 |
| **DV（因变量）** | 实际利率上升 |
| **Chain（传导链）** | 人口结构和全球化逆转导致通胀上升 → 通胀持续多年后，预期调整 → 名义利率上升 → 名义利率上升幅度超过通胀，实际利率上升 |
| **Lag（时滞）** | 数年（通胀发生后需要几年预期才调整） |
| **Threshold（临界值）** | 名义利率上升幅度超过通胀率 |
| **前提与约束（Premises）** | 全球视角下，储蓄与投资动态决定均衡利率；封闭经济体储蓄等于投资，全球亦然；实际利率受多因素影响，此处聚焦人口与全球化逆转 |
| **Falsification（证伪条件）** | 如果名义利率上升幅度低于通胀，实际利率下降，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像烧水：人口逆转是火，通胀是水温上升，预期调整是水沸腾的延迟，实际利率是最终蒸汽压力，火够大蒸汽才足。
