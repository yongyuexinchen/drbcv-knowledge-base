# 债务陷阱的形成与锁定机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：债务陷阱的形成与锁定机制.md

## 总体因果图

- 长期低利率政策 → 债务陷阱（高负债率导致利率无法正常化，经济陷入通缩与债务积累
- 全球金融危机后银行监管要求提高资本充足率（CARs） → 欧洲银行跨境贷款大幅减少（去杠杆）
- 量化宽松（QE）和官方负利率政策 → 非金融企业债务进一步积累
- 高负债率 → 企业削减新投资（加剧衰退）
