# 企业削减新投资（加剧衰退）

> 属于因果簇：[[债务陷阱的形成与锁定机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高负债率 |
| **DV（因变量）** | 企业削减新投资（加剧衰退） |
| **Chain（传导链）** | 企业负债率过高，面临破产风险 → 为避免破产，企业觉得有必要大幅削减新投资 → 投资减少导致经济增长放缓，加剧衰退 |
| **Lag（时滞）** | 利率上升或经济下行时迅速显现 |
| **Threshold（临界值）** | 当企业负债率高到利率大幅或快速上升会使企业陷入债务偿付危机时 |
| **前提与约束（Premises）** | 企业面临破产风险；利率上升或经济环境恶化；企业无法通过股权融资或债务重组缓解压力 |
| **Falsification（证伪条件）** | 如果高负债率企业仍能维持或增加投资，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个背负高额房贷的人，一旦利率上升，只能削减所有非必要开支（包括子女教育投资），导致家庭未来发展受限

### 🔗 文字版因果链

1. 企业负债率过高，面临破产风险
2. 为避免破产，企业觉得有必要大幅削减新投资
3. 投资减少导致经济增长放缓，加剧衰退
