# 极权主义制度必然导致最坏者当政

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 极权主义制度（集体主义计划经济） |
| **DV（因变量）** | 最坏者（道德败坏者）当政 |
| **Chain（传导链）** | 极权主义制度要求对社会进行全面计划，需要集中巨大权力 → 民主政治家面临选择：僭取独裁权力或放弃计划，最终倾向独裁 → 独裁者面临选择：置道德于不顾或遭受失败，倾向不道德 → 极权主义机器的要求筛选出适应其纪律的人，即那些温驯、易受骗、无独立信念者 → 消极选择原则：教育高者观念多样，难以形成一致，因此需要降格到低级标准，吸引具有原始本能和共同趣味的人 → 通过制造敌人（如犹太人、富农）来团结支持者，这需要煽动仇恨，吸引最坏者 → 因此，极权主义制度必然产生道德败坏者当政的结果 |
| **Lag（时滞）** | 极权主义制度建立后，短期内（数年至数十年）即显现 |
| **Threshold（临界值）** | 当权力集中到足以压制反对意见并实行全面计划时 |
| **前提与约束（Premises）** | 极权主义制度要求全面计划和控制；存在需要团结的群众基础；领导层必须拥有绝对权力 |
| **Falsification（证伪条件）** | 如果存在一个极权主义政权由道德高尚者领导且长期保持道德水准，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为极权主义可为善可为恶、取决于领导人的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一场比赛，规则设计使得只有最不择手段的选手才能获胜，那么最终冠军必然是最坏的选手。

### 🔗 文字版因果链

1. 极权主义制度要求对社会进行全面计划，需要集中巨大权力
2. 民主政治家面临选择：僭取独裁权力或放弃计划，最终倾向独裁
3. 独裁者面临选择：置道德于不顾或遭受失败，倾向不道德
4. 极权主义机器的要求筛选出适应其纪律的人，即那些温驯、易受骗、无独立信念者
5. 消极选择原则：教育高者观念多样，难以形成一致，因此需要降格到低级标准，吸引具有原始本能和共同趣味的人
6. 通过制造敌人（如犹太人、富农）来团结支持者，这需要煽动仇恨，吸引最坏者
7. 因此，极权主义制度必然产生道德败坏者当政的结果
