# 成为主宰各国命运的暴虐权力

> 属于因果簇：[[国际计划经济导致冲突与奴役]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 控制重要原材料或特定经济领域的国际机构 |
| **DV（因变量）** | 成为主宰各国命运的暴虐权力 |
| **Chain（传导链）** | 控制原材料供应者决定是否增加供给、降低价格或生产者收入 → 决定是否允许国家创立新工业或禁止 → 控制所有重要原材料时，无批准则无新工业、新投资 → 该权力不受更高政治权力约束，难以有效质询 → 成为最暴虐和不负责任的权力 |
| **Lag（时滞）** | 权力一旦赋予，立即生效 |
| **Threshold（临界值）** | 控制所有重要原材料时，权力达到极致 |
| **前提与约束（Premises）** | 国际机构不受单一最高政治权力约束；机构可借口技术需要或人道理由辩护其行为 |
| **Falsification（证伪条件）** | 若国际机构能自我约束并公正行使权力，不滥用，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为国际技术机构可客观公正管理的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人控制全城的水源，他决定谁有水喝，谁没水喝，自然成为所有人的主宰。

### 🔗 文字版因果链

1. 控制原材料供应者决定是否增加供给、降低价格或生产者收入
2. 决定是否允许国家创立新工业或禁止
3. 控制所有重要原材料时，无批准则无新工业、新投资
4. 该权力不受更高政治权力约束，难以有效质询
5. 成为最暴虐和不负责任的权力
