# 国际计划经济导致冲突与奴役（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：国际计划经济导致冲突与奴役.md

## 总体因果图

- 各国独立实施经济计划，阻断外来影响 → 国际摩擦加剧，持久和平无望
- 国际性经济计划（超国家机构集中指导） → 强力统治、道德败坏、民族仇恨
- 控制重要原材料或特定经济领域的国际机构 → 成为主宰各国命运的暴虐权力
