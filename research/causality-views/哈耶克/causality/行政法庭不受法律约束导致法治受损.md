# 行政法庭不受法律约束导致法治受损

> **领域**：法学、政治学　|　**来源**：哈耶克_chapter_80_part_01_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 行政法庭不受法律规则和司法先例约束，以推行政策为目标 |
| **DV（因变量）** | 法治原则受损，公民自由受威胁，行政专制主义发展 |
| **Chain（传导链）** | 行政法庭被赋予自由裁量权，不受固定规则约束 → 行政机构在管理私人生活和公民财产时权力扩大且缺乏有效监督 → 法律赋予行政机构决定一般原则的权力，可剥夺公民私产 → 公民对行政决定的司法救济途径受限，法治保障削弱 → 长期积累导致行政专制主义倾向，法治传统被侵蚀 |
| **Lag（时滞）** | 过去二三十年（英国），美国自一战前开始，至20世纪30年代末显著 |
| **Threshold（临界值）** | 当行政机构获得不受固定规则约束的自由处置权，且法院仅审查越权而不审查实质时 |
| **前提与约束（Premises）** | 行政法庭以推行政策为公开目标，而非维持公正；法院和上诉委员会对行政行为的修正漏洞百出；行政机构拒绝受制于固定规则，拥有决定一般原则的权力 |
| **Falsification（证伪条件）** | 如果行政法庭在不受法律约束的情况下仍能保障公民权利和法治，且无行政专制主义案例出现，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与法治传统及杰斐逊'自由政府建立在猜忌而非信任上'的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同裁判在比赛中既当运动员又当裁判，且不受比赛规则约束，最终比赛公正性必然受损。

### 🔗 文字版因果链

1. 行政法庭被赋予自由裁量权，不受固定规则约束
2. 行政机构在管理私人生活和公民财产时权力扩大且缺乏有效监督
3. 法律赋予行政机构决定一般原则的权力，可剥夺公民私产
4. 公民对行政决定的司法救济途径受限，法治保障削弱
5. 长期积累导致行政专制主义倾向，法治传统被侵蚀
