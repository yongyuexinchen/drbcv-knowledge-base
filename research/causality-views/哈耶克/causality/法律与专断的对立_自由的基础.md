# 法律与专断的对立：自由的基础

> **领域**：政治哲学　|　**来源**：哈耶克_chapter_75_part_02_p3　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律（而非专断）作为政府治理的基础 |
| **DV（因变量）** | 公民自由（生命和财产由自己掌握） |
| **Chain（传导链）** | 政府依据明确的法律而非专断意志进行治理 → 法律为公民提供可预测的规则框架 → 公民在规则框架内享有生命和财产的安全保障 → 从而获得自由（不依赖政府参与） |
| **Lag（时滞）** | 即时（法律确立后即生效） |
| **Threshold（临界值）** | 法律必须明确且为人所知（如大宪章） |
| **前提与约束（Premises）** | 法律是公正且非专断的；法律能够有效约束政府行为；公民知晓并理解法律 |
| **Falsification（证伪条件）** | 若存在法律但公民自由被剥夺（如法律本身专断），则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同游戏规则：规则明确且公平，玩家才能自由发挥；若裁判随意改规则，玩家则无自由可言。

### 🔗 文字版因果链

1. 政府依据明确的法律而非专断意志进行治理
2. 法律为公民提供可预测的规则框架
3. 公民在规则框架内享有生命和财产的安全保障
4. 从而获得自由（不依赖政府参与）
