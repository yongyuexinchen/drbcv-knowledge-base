# 计划经济导致奴役之路

> **领域**：宏观经济学、政治哲学　|　**来源**：哈耶克_chapter_12_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体主义经济计划（计划经济） |
| **DV（因变量）** | 极权主义与个人自由的丧失（奴役） |
| **Chain（传导链）** | 集体主义经济计划要求集中控制资源分配 → 集中控制需要统一的目标和价值观，排斥个人偏好 → 为执行计划，权力机构不断扩大干预范围 → 个人经济自由被剥夺，进而政治自由和思想自由受限 → 最终走向极权主义，即‘奴役’ |
| **Lag（时滞）** | 长期过程，数十年至数代 |
| **Threshold（临界值）** | 当经济计划覆盖关键生产与分配领域，且缺乏市场反馈机制时 |
| **前提与约束（Premises）** | 适用于大规模、复杂经济体的中央计划；假定计划者无法获取充分信息以有效协调经济；排除小规模、简单经济中的有限计划 |
| **Falsification（证伪条件）** | 若存在一个长期运行、保持高水平个人自由的中央计划经济体，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、民主社会主义者（如巴巴拉·伍顿）的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像试图用一张地图精确指挥所有车辆，最终导致交通瘫痪，必须由交警强制管制，失去自由行驶的权利。

### 🔗 文字版因果链

1. 集体主义经济计划要求集中控制资源分配
2. 集中控制需要统一的目标和价值观，排斥个人偏好
3. 为执行计划，权力机构不断扩大干预范围
4. 个人经济自由被剥夺，进而政治自由和思想自由受限
5. 最终走向极权主义，即‘奴役’
