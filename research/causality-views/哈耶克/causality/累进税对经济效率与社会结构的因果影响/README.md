# 累进税对经济效率与社会结构的因果影响（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：累进税对经济效率与社会结构的因果影响.md

## 总体因果图

- 累进税制（高边际税率） → 经济效率下降（资源配置扭曲、激励减弱、竞争受限）
- 累进税制（高边际税率） → 社会不平等永久化（富人阶层固化，机会减少）
- 累进税制（高边际税率） → 资本形成地点扭曲（资本从个人转向既有企业，抑制创新）
