# 社会主义教育灌输与极权主义政党原型的因果链（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：社会主义教育灌输与极权主义政党原型的因果链.md

## 总体因果图

- 社会主义者采用的教育和灌输手段（如儿童政治组织、党员标识、生活全面组织化） → 纳粹和法西斯主义极权政党对这些手段的继承与有效利用
- 社会主义运动与特定集团（技术工人）利益结合，形成工人贵族 → 中产阶级下层（白领无产者）的相对地位恶化，转而支持法西斯主义
