# 中产阶级下层（白领无产者）的相对地位恶化，转而支持法西斯主义

> 属于因果簇：[[社会主义教育灌输与极权主义政党原型的因果链]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会主义运动与特定集团（技术工人）利益结合，形成工人贵族 |
| **DV（因变量）** | 中产阶级下层（白领无产者）的相对地位恶化，转而支持法西斯主义或民族社会主义 |
| **Chain（传导链）** | 社会主义政党优先提高产业工人的相对经济地位，形成工人贵族 → 新中产阶级（职员、教师、小公务员等）的相对地位恶化，感到被忽视和威胁 → 这些阶级对产业工人运动产生嫉妒和怨恨，认为劳工运动中的得势部分属于剥削阶级 → 法西斯主义和民族社会主义吸引这些失望的阶级，提供新的社会等级秩序和特权许诺 → 这些运动成功获得支持，形成对原有社会主义政党的反制 |
| **Lag（时滞）** | 数十年（随着社会主义运动扩展，阶级分化逐渐显现） |
| **Threshold（临界值）** | 当产业工人与中产阶级下层的收入差距显著（如火车司机收入比白领高几倍）时，怨恨加剧 |
| **前提与约束（Premises）** | 社会主义运动已在一个国家内与特定集团利益结合；社会存在多个无财产但地位不同的阶级；国家强制性机器决定个人收入和地位，迫使人们组织成集团以影响国家 |
| **Falsification（证伪条件）** | 若能证明法西斯主义的主要支持者并非中产阶级下层，而是其他阶级，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与马克思主义阶级分析冲突，后者认为法西斯主义是资产阶级的工具 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 社会主义政党优先提高产业工人的相对经济地位，形成工人贵族
2. 新中产阶级（职员、教师、小公务员等）的相对地位恶化，感到被忽视和威胁
3. 这些阶级对产业工人运动产生嫉妒和怨恨，认为劳工运动中的得势部分属于剥削阶级
4. 法西斯主义和民族社会主义吸引这些失望的阶级，提供新的社会等级秩序和特权许诺
5. 这些运动成功获得支持，形成对原有社会主义政党的反制
