# 对少数民族的歧视和压迫

> 属于因果簇：[[集中计划与个人权利的内在冲突]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济政策工具（如产业管制） |
| **DV（因变量）** | 对少数民族的歧视和压迫 |
| **Chain（传导链）** | 某些产业或活动主要由少数民族从事 → 政府以经济政策为手段，针对这些产业或职业阶层制定措施 → 表面上不违反保护少数民族权利的法规文字 → 实际上实现系统性歧视，且难以被法律追究 |
| **Lag（时滞）** | 中期（政策实施后逐渐显现） |
| **Threshold（临界值）** | 当少数民族集中于特定经济部门时，歧视效果显著 |
| **前提与约束（Premises）** | 政府拥有经济管制权力；少数民族在特定产业中占主导地位；法律只保护形式上的平等，不干预经济政策 |
| **Falsification（证伪条件）** | 如果存在一个经济管制体制下少数民族未受歧视的案例，且该体制未采取特殊保护措施，则此断言可被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为经济政策中性、不涉及歧视的观点冲突 |
| **Confidence（确信度）** | well-established |
