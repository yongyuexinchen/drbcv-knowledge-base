# 集中计划与个人权利的内在冲突（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：集中计划与个人权利的内在冲突.md

## 总体因果图

- 集中计划（政府全面控制经济生活） → 个人权利（如自由买卖、自由择业、旅行迁居自由、新闻自由）的实
- 经济政策工具（如产业管制） → 对少数民族的歧视和压迫
- 法治（事前确立的一般规则） → 个人自由（可预见性和免受专断权力侵害）
