## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 极权主义制度下的统一宣传与思想控制 |
| **DV（因变量）** | 社会对真理的认知与尊重被侵蚀，真理沦为当权者规定的工具 |
| **Chain（传导链）** | 极权主义为实现单一目标体系，需使人民自愿服从，故进行统一宣传 → 宣传不仅限于价值标准，因需为价值标准提供正当性理由，而扩展到对事实的断言 → 官方信条将事实与理论纳入其中，禁止公开批评与怀疑，以维护公众支持 → 知识传播机构（学校、报纸、广播等）被专门用于传播强化当局正确性的意见，压制异见 → 真理不再由个人良心发现，而由当权者规定，并随有组织行动需要而更改 → 最终导致社会对真理意义的意识丧失，独立探索精神与理性信念消逝 |
| **Lag（时滞）** | 长期（需持续宣传与隔绝其他信息来源，效果逐渐累积） |
| **Threshold（临界值）** | 当所有宣传工具被协调一致，且人民被长期与一切其他信息来源隔绝时 |
| **前提与约束（Premises）** | 极权主义制度已建立，且能有效控制所有宣传工具与信息来源；宣传的目的在于使人民接受官方价值标准并支持计划，而非单纯说服；人民被长期隔绝于独立与竞争的信息来源之外 |
| **Falsification（证伪条件）** | 若在极权主义制度下，存在独立信息来源或人民能保持批判性思考，且真理认知未被侵蚀，则该断言被推翻 |

### 🔗 文字版因果链

1. 极权主义为实现单一目标体系，需使人民自愿服从，故进行统一宣传
2. 宣传不仅限于价值标准，因需为价值标准提供正当性理由，而扩展到对事实的断言
3. 官方信条将事实与理论纳入其中，禁止公开批评与怀疑，以维护公众支持
4. 知识传播机构（学校、报纸、广播等）被专门用于传播强化当局正确性的意见，压制异见
5. 真理不再由个人良心发现，而由当权者规定，并随有组织行动需要而更改
6. 最终导致社会对真理意义的意识丧失，独立探索精神与理性信念消逝
