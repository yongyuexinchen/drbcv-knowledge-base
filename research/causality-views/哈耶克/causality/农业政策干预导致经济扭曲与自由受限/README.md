# 农业政策干预导致经济扭曲与自由受限（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：农业政策干预导致经济扭曲与自由受限.md

## 总体因果图

- 政府干预农业（价格控制、补贴、生产配额） → 农业经济适应性下降、问题累积、农民依附性增强、自由受限
- 农业人口减少（因技术进步和需求变化） → 农业收入相对下降，迫使劳动力转移
- 政府保护自然资源（如森林） → 资源浪费减少，但可能抑制经济发展
