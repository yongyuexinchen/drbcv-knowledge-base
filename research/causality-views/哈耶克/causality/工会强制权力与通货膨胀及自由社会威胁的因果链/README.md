## 总体因果图

- 工会拥有强制权力（如罢工纠察、封闭型企业协议、工会企业协议等） → 持续且日趋严重的通货膨胀
- 工会强制权力（如罢工纠察、封闭型企业协议等） → 自由社会的威胁（包括政府专断控制、集中计划管理）
