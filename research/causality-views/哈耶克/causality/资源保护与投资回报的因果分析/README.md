# 资源保护与投资回报的因果分析（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：资源保护与投资回报的因果分析.md

## 总体因果图

- 私人开发者缺乏长远观点或政府干预 → 资源浪费性开发
- 资源产权统一控制范围扩大 → 资源合理使用
- 资源消耗速度加快 → 知识增长和技术创新
- 政府以较低利率借款 → 政府投资效率
- 政府集中知识 → 资源决策质量
- 资源保护投资 → 未来收入
