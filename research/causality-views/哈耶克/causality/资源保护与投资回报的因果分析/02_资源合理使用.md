# 资源合理使用

> 属于因果簇：[[资源保护与投资回报的因果分析]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资源产权统一控制范围扩大 |
| **DV（因变量）** | 资源合理使用 |
| **Chain（传导链）** | 当产权控制范围与资源开发范围一致时，所有者承担全部后果 → 所有者有动力考虑长期收益，避免过度开发 → 资源使用趋于合理 |
| **Lag（时滞）** | 中期（数年至数十年） |
| **Threshold（临界值）** | 产权范围必须覆盖资源全部外部性 |
| **前提与约束（Premises）** | 仅当资源可明确界定产权且技术允许控制时；排除无法界定产权的资源（如深海鱼类） |
| **Falsification（证伪条件）** | 若产权统一后资源仍被过度开发，或出现垄断导致效率低下，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为私有产权必然导致资源耗竭的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个花园，若由所有住户共同管理，无人负责，杂草丛生；若划分给每户独立管理，则各户会精心照料。

### 🔗 文字版因果链

1. 当产权控制范围与资源开发范围一致时，所有者承担全部后果
2. 所有者有动力考虑长期收益，避免过度开发
3. 资源使用趋于合理
