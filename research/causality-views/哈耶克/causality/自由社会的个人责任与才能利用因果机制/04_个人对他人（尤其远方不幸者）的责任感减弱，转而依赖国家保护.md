# 个人对他人（尤其远方不幸者）的责任感减弱，转而依赖国家保护

> 属于因果簇：[[自由社会的个人责任与才能利用因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 小社会（熟人社区）的消失，被大社会网络取代 |
| **DV（因变量）** | 个人对他人（尤其远方不幸者）的责任感减弱，转而依赖国家保护 |
| **Chain（传导链）** | 工业化都市发展使个人脱离熟悉的小社会 → 个人失去邻里间的人身联系和友好关心 → 个人对远方陌生人的同情心无法像对熟人那样强烈 → 责任感减弱，个人转而要求国家提供保护和安全 |
| **Lag（时滞）** | 长期（城市化进程数十年至数百年） |
| **Threshold（临界值）** | 当个人无法凭具体知识判断他人处境时，责任感开始减弱 |
| **前提与约束（Premises）** | 个人认知和同情心有限，无法对抽象群体产生同等情感；目标必须有限且适合个人思维力和同情心；排除强制性的全球或国家集体责任 |
| **Falsification（证伪条件）** | 若大社会中个人对远方不幸者的责任感不减弱（如现代通讯增强同情），或小社会消失不导致依赖国家，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张扩大社会责任的福利国家理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同你更愿意帮助邻居搬家，但对千里之外的灾民捐款意愿较低，除非有具体故事触动

### 🔗 文字版因果链

1. 工业化都市发展使个人脱离熟悉的小社会
2. 个人失去邻里间的人身联系和友好关心
3. 个人对远方陌生人的同情心无法像对熟人那样强烈
4. 责任感减弱，个人转而要求国家提供保护和安全
