# 财富与自由的比例关系

> **领域**：政治哲学、社会学　|　**来源**：哈耶克_chapter_65_part_01_p3　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 个人财富的增加 |
| **DV（因变量）** | 个人有效自由的增加 |
| **Chain（传导链）** | 个人拥有更多财富，意味着拥有更多可支配资源 → 更多资源使个人能够实现更多目标、选择更多行动方案 → 因此，个人的有效自由（即实际可行的自由）随之增加 |
| **Lag（时滞）** | 即时，无显著时滞 |
| **Threshold（临界值）** | 财富与自由之间存在“适当比例”，即财富增长在达到一定水平前对自由有正向影响，但可能并非线性无限增长 |
| **前提与约束（Premises）** | 自由被理解为“有效自由”，即实际能力而非抽象权利；财富是扩大自由的主要手段之一；社会制度允许财富转化为行动机会（如市场、法律保障） |
| **Falsification（证伪条件）** | 如果发现财富增加但个人有效自由并未增加（例如在极端不平等或制度僵化下），则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与强调自由与财富分离的观点冲突，如某些共和主义传统认为自由依赖于政治参与而非财富 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像拥有更多工具的人能建造更多东西，财富就是自由的工具箱，但工具太多也可能堆满房间，反而碍事。

### 🔗 文字版因果链

1. 个人拥有更多财富，意味着拥有更多可支配资源
2. 更多资源使个人能够实现更多目标、选择更多行动方案
3. 因此，个人的有效自由（即实际可行的自由）随之增加
