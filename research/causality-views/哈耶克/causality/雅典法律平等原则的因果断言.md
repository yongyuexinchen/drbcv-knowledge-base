## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 公民在公民权利方面平等 |
| **DV（因变量）** | 法律面前人人平等（对所有雅典人适用同一法律） |
| **Chain（传导链）** | 每个公民在公民权利方面平等 → 因此每个人应在法律方面平等 → 因此提出针对任何个人的法律是不合法的，除非同样情况适用于所有雅典人 → 该原则成为雅典法律 |
| **Lag（时滞）** | 即时（观念到法律确立的时间不详，但德谟斯梯尼在公元前352年提及） |
| **Threshold（临界值）** | 无明确量化阈值，但要求“同样的情况应用于所有雅典人” |
| **前提与约束（Premises）** | 适用于雅典城邦的公民群体；以公民权利平等为前提；法律制定需遵循普遍性原则 |
| **Falsification（证伪条件）** | 若存在针对特定个人的法律被雅典法庭认可且未受惩罚，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同体育比赛中，规则必须对所有参赛者一致，不能为某个选手单独制定规则。

### 🔗 文字版因果链

1. 每个公民在公民权利方面平等
2. 因此每个人应在法律方面平等
3. 因此提出针对任何个人的法律是不合法的，除非同样情况适用于所有雅典人
4. 该原则成为雅典法律
