# 货币政策规则优于当局酌处权

> **领域**：宏观经济学　|　**来源**：哈耶克_chapter_85_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币当局拥有酌处权（而非遵循固定规则） |
| **DV（因变量）** | 货币政策效果的可预见性降低，扰动性增加 |
| **Chain（传导链）** | 货币当局在具体条件下决策，易受政治压力和短期紧迫性影响 → 缺乏固定规则约束时，当局行为的不确定性增大 → 货币政策及其影响的可预见性降低 → 货币供给扰动性增加，经济波动加剧 |
| **Lag（时滞）** | 短期决策的负面影响可能在政策实施后逐渐显现，具体时滞不确定 |
| **Threshold（临界值）** | 无明确量化阈值，但强调规则应设定明确的界限（如价格水平上下限） |
| **前提与约束（Premises）** | 货币当局面临政治压力且易高估眼前形势的紧迫性；存在一个可设计的自动机制能比酌处措施更可预见地调节货币供给；公共财政考虑对货币政策施加不利影响的可能性增大 |
| **Falsification（证伪条件）** | 如果能证明在实际操作中，酌处权政策比任何已知的固定规则都能更稳定地实现货币目标，且不增加不确定性，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义主张积极干预和酌处政策的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：固定规则（如限速）虽不灵活，但比让每个司机根据情况自行决定速度更能保证整体安全与可预测性。

### 🔗 文字版因果链

1. 货币当局在具体条件下决策，易受政治压力和短期紧迫性影响
2. 缺乏固定规则约束时，当局行为的不确定性增大
3. 货币政策及其影响的可预见性降低
4. 货币供给扰动性增加，经济波动加剧

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 通货膨胀（即使温和，如每年3%） |
| **DV（因变量）** | 个人依赖政府增加，政府控制扩张，自由社会基础被破坏 |
| **Chain（传导链）** | 通货膨胀侵蚀储蓄价值，打击储蓄热情，鼓励负债 → 个人防老能力下降，对政府保障的需求增加 → 通货膨胀消灭中产阶级，加剧社会隔阂与紧张 → 政府行动增加，控制变得必不可少，形成恶性循环 → 长期看，自由社会的基础被破坏 |
| **Lag（时滞）** | 长期效应，如价格水平每23.5年翻倍，在一个人工作寿命内翻两番 |
| **Threshold（临界值）** | 即使每年3%的温和通胀也危险，因为一旦依赖其刺激作用，就需更多通胀或衰退来付出代价 |
| **前提与约束（Premises）** | 公众未清醒认识到通胀后果，反对者力量弱小；货币当局有权但未行使阻止通胀的权力；存在扩张主义政策的直接利益诱惑 |
| **Falsification（证伪条件）** | 如果能证明温和通胀（如3%）在长期内不导致政府控制扩张，且不破坏自由社会基础，则该断言被推翻 |
| **Data（定量佐证）** | 每年3%通胀导致价格每23.5年翻倍，工作寿命内翻两番 |
| **Conflicts（观点冲突）** | 与支持扩张性货币政策以刺激就业的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同温水煮青蛙：缓慢升温（温和通胀）看似无害，但最终导致青蛙（自由社会）无法逃脱。

### 🔗 文字版因果链

1. 通货膨胀侵蚀储蓄价值，打击储蓄热情，鼓励负债
2. 个人防老能力下降，对政府保障的需求增加
3. 通货膨胀消灭中产阶级，加剧社会隔阂与紧张
4. 政府行动增加，控制变得必不可少，形成恶性循环
5. 长期看，自由社会的基础被破坏
