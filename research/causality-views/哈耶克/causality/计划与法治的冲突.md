# 计划与法治的冲突

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体主义经济计划 |
| **DV（因变量）** | 法治的破坏 |
| **Chain（传导链）** | 计划当局必须根据具体环境做出有意识的选择，无法事先用一般性规则约束自己 → 这种选择必然涉及对不同人的具体需要予以差别对待，并比较权衡各种利益 → 为了实施差别对待，法律必须授予当局自由裁量权，使专断行为合法化 → 随着计划扩大，立法权授予更多部门，法律变得模糊且不确定，导致法治衰落 |
| **Lag（时滞）** | 短期可见，长期加剧；在德国，法治衰落过程在希特勒上台前已发展一段时间 |
| **Threshold（临界值）** | 当政府行动的具体影响可预见时，法治即被破坏；当法律规则不再是一般性、形式性时，法治失效 |
| **前提与约束（Premises）** | 法治要求政府行动受事前规定并宣布的规则约束，且规则具有一般性和形式性；计划当局必须对具体需要做出选择，无法保持不偏不倚；法律面前形式上的平等与实质平等目标不相容 |
| **Falsification（证伪条件）** | 若能证明集体主义计划可以在不授予当局自由裁量权、不进行差别对待的情况下实施，且法律仍保持一般性和形式性，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的观点冲突，如认为计划可以通过民主程序实现公平分配而不破坏法治 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：如果规定所有车辆靠右行驶，大家都能预测；但如果交警随意指挥每辆车走不同路线，交通必然混乱。计划就像后者，使个人无法预测政府行动。

### 🔗 文字版因果链

1. 计划当局必须根据具体环境做出有意识的选择，无法事先用一般性规则约束自己
2. 这种选择必然涉及对不同人的具体需要予以差别对待，并比较权衡各种利益
3. 为了实施差别对待，法律必须授予当局自由裁量权，使专断行为合法化
4. 随着计划扩大，立法权授予更多部门，法律变得模糊且不确定，导致法治衰落
