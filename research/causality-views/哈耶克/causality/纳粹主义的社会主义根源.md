## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会主义思想中的集体主义因素（如组织、计划、反个人主义） |
| **DV（因变量）** | 纳粹主义的兴起与得势 |
| **Chain（传导链）** | 社会主义思想包含集体主义、反自由主义因素，这些因素与民族主义结合 → 左翼社会主义者与右翼社会主义者联合，排斥自由主义因素 → 德国战时经济（1914年）被视为社会主义的初步实现，强化了组织与计划观念 → 这些观念被桑巴特、普伦格、伦施等思想家系统化并广泛传播 → 最终这些思想汇聚成国家社会主义（纳粹主义）学说，并赢得德国大众支持 |
| **Lag（时滞）** | 约150年（思想演变从18世纪末至20世纪初） |
| **Threshold（临界值）** | 无明确量化阈值，但以1914年一战爆发和战时经济为关键转折点 |
| **前提与约束（Premises）** | 仅当社会主义中的自由主义因素（如国际主义、民主主义）被清除时；仅当德国缺乏强有力的资产阶级时；仅当民族主义失败和战败后社会动荡时 |
| **Falsification（证伪条件）** | 若能证明纳粹主义主要源于非社会主义思想（如纯粹民族主义或资本主义反动），或证明社会主义阵营普遍抵制纳粹，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与将纳粹主义视为纯粹非理性反叛的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个原本包含多种成分的溶液，当其中某些成分（自由主义）被蒸发，剩下的浓缩物（集体主义）与另一种物质（民族主义）反应，最终形成爆炸性化合物。

### 🔗 文字版因果链

1. 社会主义思想包含集体主义、反自由主义因素，这些因素与民族主义结合
2. 左翼社会主义者与右翼社会主义者联合，排斥自由主义因素
3. 德国战时经济（1914年）被视为社会主义的初步实现，强化了组织与计划观念
4. 这些观念被桑巴特、普伦格、伦施等思想家系统化并广泛传播
5. 最终这些思想汇聚成国家社会主义（纳粹主义）学说，并赢得德国大众支持
