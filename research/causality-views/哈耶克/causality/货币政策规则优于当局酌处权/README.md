# 货币政策规则优于当局酌处权（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：货币政策规则优于当局酌处权.md

## 总体因果图

- 货币当局拥有酌处权（而非遵循固定规则） → 货币政策效果的可预见性降低，扰动性增加
- 通货膨胀（即使温和，如每年3%） → 个人依赖政府增加，政府控制扩张，自由社会基础被破坏
