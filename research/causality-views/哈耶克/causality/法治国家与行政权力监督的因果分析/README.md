# 法治国家与行政权力监督的因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：法治国家与行政权力监督的因果分析.md

## 总体因果图

- 法治理想（普遍性规则之治）的兴起 → 行政权力受到有效监督与个人自由得到保障
- 民主的降临（人民主权） → 对权力滥用的防范机制被忽视
- 行政法院的设立（分权原则的极端解释） → 行政权力反而得到加强而非限制
