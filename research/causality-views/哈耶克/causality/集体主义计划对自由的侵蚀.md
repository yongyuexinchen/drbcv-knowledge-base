# 集体主义计划对自由的侵蚀

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_17_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体主义经济计划（中央集中管理经济） |
| **DV（因变量）** | 个人自由的丧失（通往奴役之路） |
| **Chain（传导链）** | 集体主义计划要求对经济活动进行集中管理，以取代市场竞争 → 集中管理需要赋予中央计划机构对资源的全面控制权 → 为执行统一计划，必须压制个人基于自身知识做出的分散决策 → 价格机制被扭曲，个人失去有效的经济信号和选择自由 → 经济控制权集中导致政治权力集中，最终走向极权主义 |
| **Lag（时滞）** | 长期过程，随计划实施程度加深而逐步显现 |
| **Threshold（临界值）** | 当中央计划取代竞争成为经济协调的主要手段时，自由开始系统性丧失 |
| **前提与约束（Premises）** | 仅当计划用于反对竞争、替代竞争时成立；在竞争与计划混合且计划占主导时，竞争无法有效运作；排除为竞争创造有利条件的计划（如法律框架建设）；假设中央计划者无法获取分散在个人手中的全部知识 |
| **Falsification（证伪条件）** | 若能证明中央计划在长期内能保持个人自由并有效配置资源，且无需政治集权，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的社会主义者（如兰格的市场社会主义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人试图用一张地图指挥所有人的日常行动，最终每个人都会失去自主判断和选择的能力，整个社会变成一台被操控的机器。

### 🔗 文字版因果链

1. 集体主义计划要求对经济活动进行集中管理，以取代市场竞争
2. 集中管理需要赋予中央计划机构对资源的全面控制权
3. 为执行统一计划，必须压制个人基于自身知识做出的分散决策
4. 价格机制被扭曲，个人失去有效的经济信号和选择自由
5. 经济控制权集中导致政治权力集中，最终走向极权主义
