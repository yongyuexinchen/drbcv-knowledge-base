# 计划导致奴役之路

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划（集体主义经济计划） |
| **DV（因变量）** | 奴役（极权主义） |
| **Chain（传导链）** | 中央计划要求统一目标，消除个人自由选择 → 为执行计划，需要集中权力并压制异议 → 权力集中导致少数人控制信息与资源 → 控制者利用权力巩固自身地位，扩大控制范围 → 最终形成极权主义，个人沦为工具 |
| **Lag（时滞）** | 长期（数十年，随计划扩展逐步显现） |
| **Threshold（临界值）** | 当计划覆盖关键经济部门并压制市场价格机制时 |
| **前提与约束（Premises）** | 仅在缺乏自发秩序和法治约束的条件下成立；适用于大规模、全面的中央计划，而非局部干预；假设计划者无法获取分散知识，且无有效反馈机制 |
| **Falsification（证伪条件）** | 若存在一个长期实行全面中央计划但未走向极权、且个人自由显著增长的国家实例，则可证伪 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、社会主义计划经济支持者（如奥斯卡·兰格）的市场社会主义理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭若由一人决定所有日常细节，起初高效，但长期会压抑成员个性，最终导致独裁家长制

### 🔗 文字版因果链

1. 中央计划要求统一目标，消除个人自由选择
2. 为执行计划，需要集中权力并压制异议
3. 权力集中导致少数人控制信息与资源
4. 控制者利用权力巩固自身地位，扩大控制范围
5. 最终形成极权主义，个人沦为工具
