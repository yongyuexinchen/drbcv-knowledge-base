## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划经济（中央集权计划） |
| **DV（因变量）** | 通往奴役之路（个人自由丧失） |
| **Chain（传导链）** | 计划经济要求政府集中控制生产资料和分配 → 集中控制导致信息分散和知识利用效率低下 → 为维持计划运行，政府必须强制推行统一目标 → 强制统一目标压制个人选择和市场自发秩序 → 最终导致极权主义和奴役 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 无明确量化阈值，但计划范围越广，奴役程度越深 |
| **前提与约束（Premises）** | 仅当计划取代市场机制时成立；在知识分散且无法集中汇总的社会中成立；排除自发秩序和法治框架下的有限干预 |
| **Falsification（证伪条件）** | 若存在一个长期运行的计划经济国家，其个人自由指数高于市场经济国家，且无极权倾向，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、苏联计划经济实践及其辩护者（如列宁、斯大林）冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 计划经济要求政府集中控制生产资料和分配
2. 集中控制导致信息分散和知识利用效率低下
3. 为维持计划运行，政府必须强制推行统一目标
4. 强制统一目标压制个人选择和市场自发秩序
5. 最终导致极权主义和奴役
