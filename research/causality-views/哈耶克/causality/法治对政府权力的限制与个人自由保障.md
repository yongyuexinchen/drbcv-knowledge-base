# 法治对政府权力的限制与个人自由保障

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法治原则（法律必须具有一般性、平等性、确定性，且限制政府强制性权力） |
| **DV（因变量）** | 个人自由的保障（防止政府任意强制，维护自由社会） |
| **Chain（传导链）** | 法治要求政府只能依据已知的一般性规则实施强制，不能针对特定个人或群体 → 法律必须具有前瞻性、确定性和平等性，使公民能预见法律后果，从而规划个人行为 → 政府自身也受法律约束，与私人一样遵守规则，减少压迫性规则通过的可能性 → 分权与司法审查确保行政强制行为受规则约束，防止行政酌情裁量权滥用 → 当法治成为社会共同理想并持续被追求时，立法与司法趋向于接近法治理想，从而保障个人自由 |
| **Lag（时滞）** | 长期（法治的建立和巩固需要数代人的努力，其效果在长期中显现） |
| **Threshold（临界值）** | 法治必须成为群体道义传统的一部分，被大多数人共识与接受；法律必须具有一般性、平等性、前瞻性、确定性 |
| **前提与约束（Premises）** | 法治是针对政府强制性活动的限制，不涉及非强制性活动；法律必须区分实质法与形式法，实质法才符合法治要求；法治要求分权，司法独立，行政强制行为受司法审核；法治是一个可接近但永远无法完全实现的理想，需要持续奋斗 |
| **Falsification（证伪条件）** | 如果存在一个自由社会，其法律不具备一般性、平等性、确定性，或政府可以不受法律约束而任意强制公民，且个人自由依然得到保障，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为政府可以拥有无限权力且仍能保障自由的观点冲突（如某些绝对主义理论） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法治如同交通规则：如果红绿灯只对部分车辆有效，或者规则随时改变，司机就无法安全驾驶，交通秩序就会崩溃；只有所有车辆都遵守同样的、明确的规则，交通才能顺畅，个人才能安全出行。

### 🔗 文字版因果链

1. 法治要求政府只能依据已知的一般性规则实施强制，不能针对特定个人或群体
2. 法律必须具有前瞻性、确定性和平等性，使公民能预见法律后果，从而规划个人行为
3. 政府自身也受法律约束，与私人一样遵守规则，减少压迫性规则通过的可能性
4. 分权与司法审查确保行政强制行为受规则约束，防止行政酌情裁量权滥用
5. 当法治成为社会共同理想并持续被追求时，立法与司法趋向于接近法治理想，从而保障个人自由
