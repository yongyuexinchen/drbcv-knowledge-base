# 联邦制分权与司法审核对自由的保障（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：联邦制分权与司法审核对自由的保障.md

## 总体因果图

- 联邦制下主权权力的分割与不同主管当局之间的分权 → 对个人自由的保障（限制政府强制能力）
- 宪法对个人权利的明文列举（权利法案） → 对未列举权利的保护程度（可能导致权利被忽视或侵犯）
- 司法审核（法院宣布违宪法律无效的权力） → 对立法机构的限制与对法治的维护
- 最高法院过度介入立法（以“合理性”审查代替宪法原则） → 最高法院的权威受损及与公众舆论、行政系统的冲突
