# 对个人自由的保障（限制政府强制能力）

> 属于因果簇：[[联邦制分权与司法审核对自由的保障]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 联邦制下主权权力的分割与不同主管当局之间的分权 |
| **DV（因变量）** | 对个人自由的保障（限制政府强制能力） |
| **Chain（传导链）** | 联邦制将主权权力分割，仅将某些界定权力赋予政府 → 不同主管当局相互独立，某些强制需要多种权力配合才能实施 → 由于权力分散在不同人手中，无人能单独实施这些强制 → 因此政府权力受到限制，个人自由得到保障 |
| **Lag（时滞）** | 制度设计即时生效，但效果随时间显现 |
| **Threshold（临界值）** | 无明确量化阈值，但要求权力分割必须使任何单一主体无法同时掌握实施强制所需的所有手段 |
| **前提与约束（Premises）** | 不同主管当局之间必须真正相互独立，而非名义上分权；强制手段（如对人员与货物流动的控制）必须分散在不同主体手中；联邦制政府必须受限于其被授予的权力范围 |
| **Falsification（证伪条件）** | 若存在一个联邦制国家，其中分权未能有效限制政府强制能力，个人自由反而受到严重侵犯，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将一把枪的扳机和子弹分别交由不同人保管，任何单独一方都无法开枪，从而防止滥用武力。

### 🔗 文字版因果链

1. 联邦制将主权权力分割，仅将某些界定权力赋予政府
2. 不同主管当局相互独立，某些强制需要多种权力配合才能实施
3. 由于权力分散在不同人手中，无人能单独实施这些强制
4. 因此政府权力受到限制，个人自由得到保障
