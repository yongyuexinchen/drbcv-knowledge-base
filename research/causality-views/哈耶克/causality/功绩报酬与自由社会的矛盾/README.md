# 功绩报酬与自由社会的矛盾（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：功绩报酬与自由社会的矛盾.md

## 总体因果图

- 根据功绩确定报酬的原则 → 个人选择目标的自由受到侵蚀
- 按功绩奖赏与按结果价值奖赏的混淆 → 社会激励扭曲和同工不同酬
- 社会普遍接受功绩与成功必然联系的观点 → 不成功者更难以忍受社会，社会凝聚力下降
- 政府试图根据功绩或分配公正原则控制收入分配 → 社会走向全面控制，与自由社会对立
- 承认公民因出生或成员资格而有权分享社会财富 → 民族性群体排他性增强，国际摩擦加剧
