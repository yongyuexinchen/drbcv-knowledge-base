# 政府货币政策控制与通货膨胀的因果机制

> **领域**：宏观经济学　|　**来源**：哈耶克_chapter_85_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府控制货币政策并主导货币供给 |
| **DV（因变量）** | 通货膨胀成为主要威胁，且政府是通货贬值的主要根源 |
| **Chain（传导链）** | 政府开支占国民收入比重超过约25%后，政府面临沉重的固定财政负担（如养老保障） → 政府倾向于通过通货膨胀（货币贬值）来减轻这些负担的实际价值 → 累进税制下，通货膨胀使税收增长快于收入增长，进一步强化政府通胀动机 → 通货膨胀一旦发生，其刺激作用仅在未预期时有效，预期形成后需持续加速才能维持繁荣 → 持续通胀导致成本核算失真、资本侵蚀，并强化对福利措施的需求，形成通胀与福利国家的恶性循环 |
| **Lag（时滞）** | 通货膨胀的刺激作用即时显现，但有害后果（如成本核算失效、资本侵蚀）在预期适应后（数月到数年）显现；长期累积效应在数十年内显著（如储蓄价值损失） |
| **Threshold（临界值）** | 政府提取的国民收入份额超过约25%后，政府倾向于求助通货膨胀 |
| **前提与约束（Premises）** | 现代经济高度依赖信用货币制度，货币供给与信用紧密相关；政府开支占国民收入的大部分，货币政策无法独立于财政政策；工会工资压力与充分就业政策相互配合，助长通胀倾向 |
| **Falsification（证伪条件）** | 若存在政府开支占比超过25%但长期保持价格稳定的国家案例，或政府能有效控制通胀而不损害经济增长，则该断言可被削弱 |
| **Data（定量佐证）** | 1913-1958年45年间，小储蓄者按4%固定利率投资，实际价值保留比例：瑞士70%，美加58%，英联邦约50%，德国7%，法意11-12%；1914年前英国金本位下价格水平围绕不变水平波动，波动幅度不超过平均水平三分之一 |
| **Conflicts（观点冲突）** | 与货币主义或自由银行学派观点冲突，如弗里德曼主张货币规则而非相机抉择，或哈耶克自身主张货币非国家化 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 通货膨胀如同吸毒：初吸时兴奋，但需要不断加大剂量才能维持快感，一旦停止就会经历痛苦的戒断反应（衰退）。

### 🔗 文字版因果链

1. 政府开支占国民收入比重超过约25%后，政府面临沉重的固定财政负担（如养老保障）
2. 政府倾向于通过通货膨胀（货币贬值）来减轻这些负担的实际价值
3. 累进税制下，通货膨胀使税收增长快于收入增长，进一步强化政府通胀动机
4. 通货膨胀一旦发生，其刺激作用仅在未预期时有效，预期形成后需持续加速才能维持繁荣
5. 持续通胀导致成本核算失真、资本侵蚀，并强化对福利措施的需求，形成通胀与福利国家的恶性循环
