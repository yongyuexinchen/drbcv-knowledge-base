## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工业区位选择的决策机制（市场自由竞争 vs 中央计划） |
| **DV（因变量）** | 工业区位选择的合理性和社会效益 |
| **Chain（传导链）** | 市场通过价格反映分散知识，使个人考虑不直接了解的事实，引导区位选择，其自由力量发挥有利作用 → 中央计划者无法像市场那样利用分散知识，难以改进区位选择，且可能更差 |
| **Lag（时滞）** | 长期（区位决策影响深远，但市场调整相对灵活） |
| **Threshold（临界值）** | 当市场存在外部性时，价格机制不完全，但中央计划改进的可能性更低 |
| **前提与约束（Premises）** | 价格机制虽不完全，但不可或缺；中央计划者缺乏分散知识，难以预见所有发展 |
| **Falsification（证伪条件）** | 若中央计划能持续优于市场引导区位选择，则断言被推翻 |
| **Data（定量佐证）** | 引用A.洛希分析结论：自由力量发挥有利作用的程度令人吃惊 |
| **Conflicts（观点冲突）** | 与主张中央计划改进工业区位选择的观点冲突 |
| **Confidence（确信度）** | well-established |
