# 法治与自由经济的相容性因果断言（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：法治与自由经济的相容性因果断言.md

## 总体因果图

- 政府强制行动受一般性法律规则约束（法治） → 自由经济令人满意地运行
- 政府实施物价管制与数量管制 → 自由制度无法运行（市场失灵）
- 政府活动性质（与自由制度相容或不相容） → 对市场经济力量的损害程度
