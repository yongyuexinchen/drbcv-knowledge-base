## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 宪法制度（成文宪法对政府权力的限制） |
| **DV（因变量）** | 个人自由免受专断强制的保障 |
| **Chain（传导链）** | 宪法以更高法律约束立法机关，防止其因眼前目的违反普遍原则 → 分权与制衡机制限制任何单一权力机构的专断行为 → 权利法案明确列出不可侵犯的个人权利，提供具体保护 → 宪法作为更高法律，使具体法律必须符合普遍原则，从而保障自由 |
| **Lag（时滞）** | 长期（宪法实施后持续生效，但效果需通过司法实践逐步显现） |
| **Threshold（临界值）** | 宪法必须包含实质性规则（如权利法案），且设有独立机构强制执行 |
| **前提与约束（Premises）** | 宪法需有明确成文形式，且被民众普遍认同为最高法律；存在独立的司法或制宪机构来监督宪法执行；社会存在对基本自由原则的共识 |
| **Falsification（证伪条件）** | 若宪法存在但政府仍能任意侵犯个人权利（如无有效司法审查），则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与霍布斯主权观及法律实证主义冲突（认为主权者权力无限） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 宪法如同游戏规则，确保裁判不能随意改变规则来偏袒一方，从而保护所有玩家的公平自由

### 🔗 文字版因果链

1. 宪法以更高法律约束立法机关，防止其因眼前目的违反普遍原则
2. 分权与制衡机制限制任何单一权力机构的专断行为
3. 权利法案明确列出不可侵犯的个人权利，提供具体保护
4. 宪法作为更高法律，使具体法律必须符合普遍原则，从而保障自由
