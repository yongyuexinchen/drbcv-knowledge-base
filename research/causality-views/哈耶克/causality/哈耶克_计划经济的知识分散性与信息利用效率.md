# 哈耶克：计划经济的知识分散性与信息利用效率

> **领域**：宏观经济学、政治哲学　|　**来源**：哈耶克_chapter_11_part_02_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济决策中知识的分散性（即知识分散于无数个体，无法被中央计划者完全收集） |
| **DV（因变量）** | 中央计划经济的低效与失败（导致资源配置扭曲、生产力下降，最终走向奴役） |
| **Chain（传导链）** | 知识（尤其是特定时空下的局部知识）分散于无数个体，无法被集中汇总 → 中央计划者试图集中控制经济，但无法获取和利用分散知识 → 计划者不得不依赖简化信息和自上而下的指令，导致信息失真与决策失误 → 资源配置偏离实际需求，生产效率下降，经济陷入混乱 → 为维持计划运行，政府不得不扩大强制权力，压制个人自由，最终走向奴役 |
| **Lag（时滞）** | 短期（数年至数十年）内显现经济效率下降，长期（数十年）导致政治自由丧失 |
| **Threshold（临界值）** | 当经济规模或复杂性超过中央计划者信息处理能力时（无明确量化阈值，但可视为知识分散度与计划集中度之比超过临界点） |
| **前提与约束（Premises）** | 知识本质上是分散的、隐性的，且依赖于具体时空背景；市场机制能够有效利用分散知识，而计划机制不能；排除完全信息假设和完美计算能力的情形；适用于复杂现代经济，而非简单静态经济 |
| **Falsification（证伪条件）** | 若存在一个大型复杂经济体，在长期内中央计划能够实现与市场相当或更高的资源配置效率，且未导致政治自由受限，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（哈耶克未提供具体统计数据，但可参照苏联计划经济长期低效与短缺现象作为历史佐证） |
| **Conflicts（观点冲突）** | 与奥斯卡·兰格等市场社会主义者（认为计划可通过试错模拟市场）冲突；与凯恩斯主义对政府干预的积极态度部分冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个厨师试图用一份简化的菜谱指挥一个拥有无数食材和烹饪技巧的庞大厨房，他无法掌握每样食材的新鲜度和每位厨师的独特手艺，最终做出的菜必然难吃，只能靠强制手段让所有人接受

### 🔗 文字版因果链

1. 知识（尤其是特定时空下的局部知识）分散于无数个体，无法被集中汇总
