# 传统道德与扩展秩序的因果关系

> **领域**：宏观经济学、社会哲学　|　**来源**：哈耶克_chapter_47_part_01_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵守传统道德（私有财产、节俭、交换、诚实守信、履行契约等） |
| **DV（因变量）** | 扩展秩序的维持与繁荣（群体人财两旺） |
| **Chain（传导链）** | 传统道德规则在进化中被选择，因为它们使遵守的群体更有效地合作 → 这些规则协调了分散的知识，超越了任何个人或组织的理解力 → 遵守规则的群体在竞争中胜过其他群体，从而人口和财富增长 → 扩展秩序得以维持并扩展，带来文明成长 |
| **Lag（时滞）** | 长期，跨越数代人（规则的效果在个人行为很久之后才显现） |
| **Threshold（临界值）** | 无明确量化阈值，但要求群体规模足够大，超越本能秩序 |
| **前提与约束（Premises）** | 传统道德无法通过理性主义标准证明，但并非因此无效；扩展秩序是自发自组织的过程，非人为设计；个人无法预知或理解规则的全部后果；排除建构论理性主义或社会主义的干预 |
| **Falsification（证伪条件）** | 如果能够证明理性设计的道德体系在同等条件下能产生更繁荣的扩展秩序，或证明传统道德导致群体衰败，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与建构论理性主义、社会主义（如孔德、凯恩斯等）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同自然生态系统中的共生规则，虽然无人设计，但遵循这些规则的物种繁荣，而试图用人工设计替代自然选择的尝试往往导致生态崩溃。

### 🔗 文字版因果链

1. 传统道德规则在进化中被选择，因为它们使遵守的群体更有效地合作
2. 这些规则协调了分散的知识，超越了任何个人或组织的理解力
3. 遵守规则的群体在竞争中胜过其他群体，从而人口和财富增长
4. 扩展秩序得以维持并扩展，带来文明成长
