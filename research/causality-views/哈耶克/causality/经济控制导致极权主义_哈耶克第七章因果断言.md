## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对经济活动的集中控制（中央计划） |
| **DV（因变量）** | 极权主义与个人自由的丧失 |
| **Chain（传导链）** | 对相互关联的经济活动进行有意识的指导需要由专家和总指挥集中决策 → 集中计划意味着由社会（或其代表）决定各种需要的相对重要性，而非由个人决定 → 控制一切经济活动的人同时控制了实现所有目标的手段 → 对手段的唯一控制权必然决定哪些目标被认可、哪些被贬低，从而决定人们应当相信和追求什么 → 经济控制扩展至消费、职业、闲暇等全部生活领域，最终形成极权主义控制 |
| **Lag（时滞）** | 无明确时滞；随着计划范围扩大而逐步显现，可能是数年到数十年 |
| **Threshold（临界值）** | 当局对经济活动拥有唯一且全面的控制权；一旦“任何控制一切经济活动的人”出现，因果链启动 |
| **前提与约束（Premises）** | 现代社会高度分工，个人生活几乎都依赖于他人的经济活动；中央计划取代竞争性市场机制；计划当局的权力不受民主程序约束 |
| **Falsification（证伪条件）** | 若能证明中央计划可以与政治民主和个人自由长期共存，或集中控制经济不会导致对目标与价值的全面决定，则可证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人若控制了你的钱包和所有谋生渠道，就实际上决定了你能追求什么梦想；就像水闸控制水流，也决定了哪块田地能灌溉。

### 🔗 文字版因果链

1. 对相互关联的经济活动进行有意识的指导需要由专家和总指挥集中决策
2. 集中计划意味着由社会（或其代表）决定各种需要的相对重要性，而非由个人决定
3. 控制一切经济活动的人同时控制了实现所有目标的手段
4. 对手段的唯一控制权必然决定哪些目标被认可、哪些被贬低，从而决定人们应当相信和追求什么
5. 经济控制扩展至消费、职业、闲暇等全部生活领域，最终形成极权主义控制

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划当局对生产的控制 |
| **DV（因变量）** | 对消费和私人生活的有效控制 |
| **Chain（传导链）** | 在一个有计划的社会中，当局通过控制生产成为唯一的商品和劳务供给者 → 消费者面对垄断者时没有转向其他供给者的自由 → 当局决定可供支配的商品、劳务、数量、分配和条件 → 即使消费者名义上可自由花费收入，实际选择范围已被当局决定，私人生活因而受控 |
| **Lag（时滞）** | 在计划体制建立后即可能显现，随着生产垄断程度加深而增强 |
| **Threshold（临界值）** | 当局成为整个经济体系的唯一垄断者时 |
| **前提与约束（Premises）** | 不存在竞争性生产者和替代性供给渠道；生产与消费无法完全分割；当局有能力阻挠逃避其控制的努力 |
| **Falsification（证伪条件）** | 如果存在多个独立的生产者可供消费者选择，或消费者能通过黑市、退出等方式逃避当局的生产控制，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 即使食堂不强迫你吃哪道菜，但只要它是唯一的食堂且决定每天做什么，你的“选择自由”只是从既定菜单里挑。

### 🔗 文字版因果链

1. 在一个有计划的社会中，当局通过控制生产成为唯一的商品和劳务供给者
2. 消费者面对垄断者时没有转向其他供给者的自由
3. 当局决定可供支配的商品、劳务、数量、分配和条件
4. 即使消费者名义上可自由花费收入，实际选择范围已被当局决定，私人生活因而受控

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以非经济激励（公开表彰、特权、实物分配等）取代金钱报酬 |
| **DV（因变量）** | 个人选择权的丧失与权威控制的增强 |
| **Chain（传导链）** | 金钱作为一种通用工具，给穷人提供广泛的选择机会 → 若报酬采取非货币形式，接受者无法自行选择使用方式 → 分配者不仅决定报酬大小，还决定报酬的具体形式与享受方式 → 个人对自身目标的自主权被削弱，权威对生活的控制增强 |
| **Lag（时滞）** | 一旦普遍实行非经济报酬制度，控制效果立即出现 |
| **Threshold（临界值）** | 所有或大部分报酬都由中央权威以非货币形式分配 |
| **前提与约束（Premises）** | 报酬分配权集中在计划者或当局手中；个人无法将非经济报酬自由转换为其他形式 |
| **Falsification（证伪条件）** | 如果能设计一种非经济激励体系，使接受者可以自由选择所希望的回报形式，或分配者不决定具体享受方式，则可证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 发给你一张只能在指定商店兑换指定商品的奖券，而不是现金；发奖人决定的不只是奖赏大小，还包括你的消费方向。

### 🔗 文字版因果链

1. 金钱作为一种通用工具，给穷人提供广泛的选择机会
2. 若报酬采取非货币形式，接受者无法自行选择使用方式
3. 分配者不仅决定报酬大小，还决定报酬的具体形式与享受方式
4. 个人对自身目标的自主权被削弱，权威对生活的控制增强

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集中计划代替个人决策 |
| **DV（因变量）** | 个人不再能决定自己认为重要或次要的边际需要 |
| **Chain（传导链）** | 在竞争性经济中，经济得失通过价格影响边际需要，个人可自由决定什么重要 → 集中计划要求社会或代表决定不同需要的相对重要性 → 个人宣布具体目的时必须获得计划者批准，否则受控 → 于是个人在所有事情上都被控制，连“什么是边际需要”也由计划者决定 |
| **Lag（时滞）** | 随计划对资源配置的介入而同步发生 |
| **Threshold（临界值）** | 计划当局一旦介入资源配置，并有权批准或拒绝个人具体目的 |
| **前提与约束（Premises）** | 不存在纯粹的经济目的；经济因素只是追求其他目标的条件；计划当局掌握有限手段的配置权 |
| **Falsification（证伪条件）** | 如果中央计划只影响物质边际而不触及个人价值判断，或计划者不决定个人目的的优先次序，则该断言可被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 旅行社不仅决定你住哪家酒店，还替你决定什么是“值得看的风景”；你以为是自己在旅行，其实只是按行程单走。

### 🔗 文字版因果链

1. 在竞争性经济中，经济得失通过价格影响边际需要，个人可自由决定什么重要
2. 集中计划要求社会或代表决定不同需要的相对重要性
3. 个人宣布具体目的时必须获得计划者批准，否则受控
4. 于是个人在所有事情上都被控制，连“什么是边际需要”也由计划者决定

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划当局对职业选择、行业进入和报酬条件的控制 |
| **DV（因变量）** | 职业自由的丧失和个人沦为工具 |
| **Chain（传导链）** | 计划当局必须控制对各行各业的进入或报酬条件以推行计划 → 通过规定报酬和客观考试，某些非常规但适合的人被排除在行业之外 → 个人无法与雇主达成适合自己特殊需要的协议，也没有脱身之路 → 多样的人类能力被简化成标准单位，个人意志被忽视，人成为实现“社会福利”的工具 |
| **Lag（时滞）** | 随着计划当局普遍推行就业控制而逐步显现 |
| **Threshold（临界值）** | 单一计划当局普遍控制行业进入和报酬条件 |
| **前提与约束（Premises）** | 计划范围涵盖整个就业体系；不同个人具有多样性和非标准性，不能被完全标准化；不存在可供选择的非计划部门 |
| **Falsification（证伪条件）** | 如果集中计划能够在不控制职业进入和报酬的条件下进行，或非标准个人仍可通过协商获得工作机会，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 所有职业都像只有统一规格的制服，身材特殊的人再适合某个岗位也穿不进这身制服；你喜欢的“工作自由”只是尺码表上的几个标准号。

### 🔗 文字版因果链

1. 计划当局必须控制对各行各业的进入或报酬条件以推行计划
2. 通过规定报酬和客观考试，某些非常规但适合的人被排除在行业之外
3. 个人无法与雇主达成适合自己特殊需要的协议，也没有脱身之路
4. 多样的人类能力被简化成标准单位，个人意志被忽视，人成为实现“社会福利”的工具

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对“潜在丰裕”的虚幻信念（认为不存在经济问题、无需选择） |
| **DV（因变量）** | 支持并走向中央计划与极权主义 |
| **Chain（传导链）** | 人们因害怕痛苦的选择而希望不存在经济问题 → “潜在丰裕”的说法让人相信选择并非必要 → 这一虚幻希望推动人们接受中央计划作为解决方案 → 而集中计划必然要求集中控制，最终走向极权主义 |
| **Lag（时滞）** | 长期存在的思想影响；可能经过数代人的政治动员后才显现制度后果 |
| **Threshold（临界值）** | 当多数人被“无需选择”的承诺吸引并接受计划体制时 |
| **前提与约束（Premises）** | “潜在丰裕”在事实上不成立，迄今没有可行的增产计划来消除稀缺；资源稀缺和选择不可避免 |
| **Falsification（证伪条件）** | 如果“潜在丰裕”被证实且存在无需牺牲自由的计划方案能消除稀缺，或计划可以不通过集中控制实现，则该断言被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 相信只要发明一种“万能药”就不需要医生诊断；这种幻觉让你心甘情愿把健康决策交给一个统一开药的权威。

### 🔗 文字版因果链

1. 人们因害怕痛苦的选择而希望不存在经济问题
2. “潜在丰裕”的说法让人相信选择并非必要
3. 这一虚幻希望推动人们接受中央计划作为解决方案
4. 而集中计划必然要求集中控制，最终走向极权主义
