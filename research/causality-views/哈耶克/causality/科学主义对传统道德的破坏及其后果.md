# 科学主义对传统道德的破坏及其后果

> **领域**：宏观经济学、伦理学、科学哲学　|　**来源**：哈耶克_chapter_46_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 科学主义（唯科学主义）观点，即认为只有科学可验证的才是真理，否定传统道德的价值 |
| **DV（因变量）** | 传统道德规范的瓦解，进而导致社会秩序的破坏和长期经济问题 |
| **Chain（传导链）** | 科学主义宣称只有科学可验证的命题才是真理，传统道德缺乏科学根据 → 人们据此拒绝传统道德规范，认为其非理性、无根据 → 传统道德作为扩展秩序的基石被削弱，社会依赖的长期规则被忽视 → 短期功利主义行为盛行，如凯恩斯'从长远看我们终有一死'，忽视长远后果 → 导致宏观经济政策失误（如凯恩斯经济学引发通胀和失业），以及社会凝聚力下降 |
| **Lag（时滞）** | 数十年（如凯恩斯理论的影响在20世纪下半叶显现） |
| **Threshold（临界值）** | 当科学主义成为主流知识精英的共识，且传统道德被系统性否定时 |
| **前提与约束（Premises）** | 仅当科学主义被广泛接受并应用于伦理领域时；仅当传统道德被错误地视为无科学根据而抛弃时；排除那些能认识到传统道德功能并加以保护的情况 |
| **Falsification（证伪条件）** | 如果存在一个社会，科学主义盛行但传统道德未瓦解，或经济未出现长期问题，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与哈耶克本人观点一致，但与莫诺、凯恩斯、爱因斯坦等科学主义者的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同拆毁古桥的基石，只因无法用现代工程学证明其合理性，结果桥塌了

### 🔗 文字版因果链

1. 科学主义宣称只有科学可验证的命题才是真理，传统道德缺乏科学根据
2. 人们据此拒绝传统道德规范，认为其非理性、无根据
3. 传统道德作为扩展秩序的基石被削弱，社会依赖的长期规则被忽视
4. 短期功利主义行为盛行，如凯恩斯'从长远看我们终有一死'，忽视长远后果
5. 导致宏观经济政策失误（如凯恩斯经济学引发通胀和失业），以及社会凝聚力下降
