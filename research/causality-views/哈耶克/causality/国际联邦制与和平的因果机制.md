# 国际联邦制与和平的因果机制

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 建立具有消极性权力（制止损害行为）的国际政治主管机构（联邦制） |
| **DV（因变量）** | 维持持久和平与国家间秩序 |
| **Chain（传导链）** | 国际机构拥有制止各国加害邻国行为的权力，而非指挥各国行动的权力 → 通过联邦制分权原则，限制国际机构与各国的权力，防止暴政 → 法制严格限制国际机构权力，确保其不用于其他目的 → 减少国家间经济摩擦与冲突风险，从而降低战争可能性 |
| **Lag（时滞）** | 长期（战后数十年逐步显现） |
| **Threshold（临界值）** | 国际机构必须拥有对限制性措施说'不'的消极权力，且其权力受法制严格限制 |
| **前提与约束（Premises）** | 各国保持合理的独立愿望，不追求不受限制的政治主权；国际机构不参与经济角逐，保持公平；联邦制范围起初可能限于文化、看法和标准相似的国家（如西欧局部地区），可逐步扩展；不试图一举创立全球性永久组织，避免过度雄心导致失败 |
| **Falsification（证伪条件）** | 如果建立区域性联邦后，集团间战争频率未降低，或国际机构权力被滥用导致暴政，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张世界性集权或无限权力超级国家的观点冲突（如某些国际联盟支持者的全能组织设想） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同小区物业：物业有权制止住户损害公共设施（如乱扔垃圾），但不能指挥住户如何装修自家房屋；若物业权力过大且无规则约束，反而可能成为新的麻烦源。

### 🔗 文字版因果链

1. 国际机构拥有制止各国加害邻国行为的权力，而非指挥各国行动的权力
2. 通过联邦制分权原则，限制国际机构与各国的权力，防止暴政
3. 法制严格限制国际机构权力，确保其不用于其他目的
4. 减少国家间经济摩擦与冲突风险，从而降低战争可能性
