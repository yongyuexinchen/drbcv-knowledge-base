### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高等教育补贴（针对科学家和学者） |
| **DV（因变量）** | 社会整体知识进步和公共利益增加 |
| **Chain（传导链）** | 补贴支持有潜力的人才从事科研和学术 → 研究成果免费公开，惠及全社会 → 知识扩散促进技术创新和文明发展 |
| **Lag（时滞）** | 长期（10年以上） |
| **Threshold（临界值）** | 补贴对象为从事基础研究或知识传播者，且成果具有公共品性质 |
| **前提与约束（Premises）** | 研究成果难以通过市场定价回收成本；社会重视长期知识积累；补贴机制能有效筛选人才 |
| **Falsification（证伪条件）** | 如果补贴导致人才浪费或科研效率低下，则此断言需修正 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与完全市场化教育观点冲突 |
| **Confidence（确信度）** | well-established |
