# 社会保险制度从救济向再分配工具的转变及其对自由的威胁（因果簇）

## 总体因果图

- 国家建立统一、垄断性的社会保险组织并强制个人参保 → 社会保险制度演变为收入再分配工具，威胁个人自由
- 社会保险领域的专家垄断和制度复杂性 → 政策发展自动加速，偏离公众真实意愿
