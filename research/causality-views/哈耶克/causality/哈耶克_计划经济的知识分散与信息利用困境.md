## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划者试图集中控制经济决策 |
| **DV（因变量）** | 经济效率下降与通往奴役之路 |
| **Chain（传导链）** | 经济知识分散于无数个体，无法被中央计划者完全收集 → 中央计划者缺乏具体时空下的局部知识，只能依赖抽象统计信息 → 计划决策偏离实际需求，导致资源配置扭曲 → 为维持计划目标，需要强制统一个体行为，压制自发秩序 → 强制与压制逐步扩展，最终走向极权与奴役 |
| **Lag（时滞）** | 长期，跨越数十年，随计划体制的持续而逐渐显现 |
| **Threshold（临界值）** | 当计划范围超出简单统计汇总，试图替代市场价格机制时，因果链条启动 |
| **前提与约束（Premises）** | 知识本质上是分散的、默会的，无法完全集中；市场价格是传递分散知识的最有效机制；个体追求自身目标的自发秩序优于人为设计；排除完全信息与完美理性的假设 |
| **Falsification（证伪条件）** | 若存在一个中央计划体制在长期内持续实现比市场经济更高的效率且未出现政治压制，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义政府干预理论、苏联计划经济的实践者（如列宁、斯大林）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像试图用一张地图指挥整个城市的交通，但地图永远无法包含每个司机当下的意图和路况，最终只能强制所有车走同一条路，导致拥堵和自由丧失

### 🔗 文字版因果链

1. 经济知识分散于无数个体，无法被中央计划者完全收集
2. 中央计划者缺乏具体时空下的局部知识，只能依赖抽象统计信息
3. 计划决策偏离实际需求，导致资源配置扭曲
4. 为维持计划目标，需要强制统一个体行为，压制自发秩序
5. 强制与压制逐步扩展，最终走向极权与奴役
