# 哈耶克对计划经济的批判

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划经济（政府集中控制经济资源与决策） |
| **DV（因变量）** | 通往奴役之路（个人自由丧失、极权主义兴起） |
| **Chain（传导链）** | 中央计划试图用单一理性设计替代分散的市场知识 → 计划者无法获取和整合分散在无数个体中的具体知识（如价格信号） → 为执行计划，必须统一目标并压制不同意见，导致信息扭曲和资源错配 → 经济效率下降引发社会不满，计划者加强强制手段以维持秩序 → 逐步扩大政府权力，侵蚀个人自由，最终走向极权主义 |
| **Lag（时滞）** | 长期（数十年，随计划体制的持续而逐渐显现） |
| **Threshold（临界值）** | 当政府控制超过一定比例的经济活动（如生产资料国有化、价格管制全面化）时，因果链条启动 |
| **前提与约束（Premises）** | 适用于大规模、复杂经济体的中央计划；假设计划者无法获得完全信息且缺乏有效反馈机制；排除小规模、简单经济中的局部计划（如企业内部计划） |
| **Falsification（证伪条件）** | 若存在一个长期运行且保持高水平个人自由的中央计划经济案例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（但可参考苏联计划经济的历史经验作为案例） |
| **Conflicts（观点冲突）** | 与凯恩斯主义、苏联计划经济支持者（如斯大林）的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 中央计划试图用单一理性设计替代分散的市场知识
2. 计划者无法获取和整合分散在无数个体中的具体知识（如价格信号）
3. 为执行计划，必须统一目标并压制不同意见，导致信息扭曲和资源错配
4. 经济效率下降引发社会不满，计划者加强强制手段以维持秩序
5. 逐步扩大政府权力，侵蚀个人自由，最终走向极权主义
