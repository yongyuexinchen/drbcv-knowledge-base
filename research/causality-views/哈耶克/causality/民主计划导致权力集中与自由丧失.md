# 民主计划导致权力集中与自由丧失

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_19_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 民主政体试图实施全面的经济计划 |
| **DV（因变量）** | 权力集中和自由丧失（最终走向独裁） |
| **Chain（传导链）** | 民主政体试图实施全面经济计划，但缺乏一致的具体目标 → 议会无法就具体计划达成一致，导致决策效率低下 → 为推进计划，议会将权力授予专家或行政机构 → 授权导致专断决定，进一步削弱民主控制 → 最终需要独裁者来执行计划，民主被破坏，自由丧失 |
| **Lag（时滞）** | 中期（数年，如德国在希特勒上台前已陷入民主破产） |
| **Threshold（临界值）** | 当国家直接控制资源超过国民收入的一定比例（如德国1928年53%）时，国家行为间接控制整个经济，个人自由受压制 |
| **前提与约束（Premises）** | 存在一个试图指导所有经济活动的单一计划；社会缺乏完整的伦理准则来统一价值排序；民主议会无法在具体计划上达成真正多数一致 |
| **Falsification（证伪条件）** | 如果存在一个民主国家成功实施全面经济计划而保持自由和民主，且没有走向独裁，则该断言被推翻 |
| **Data（定量佐证）** | 德国1928年中央和地方当局直接控制53%国民收入，导致间接控制整个经济生活 |
| **Conflicts（观点冲突）** | 与支持民主计划的理论冲突，如卡尔·曼海姆认为议会最高权力可保持民主控制 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一群人决定一起旅行，但目的地不一致，最终被迫去一个大多数人不想去的地方，类似民主计划导致被迫接受独裁目标

### 🔗 文字版因果链

1. 民主政体试图实施全面经济计划，但缺乏一致的具体目标
2. 议会无法就具体计划达成一致，导致决策效率低下
3. 为推进计划，议会将权力授予专家或行政机构
4. 授权导致专断决定，进一步削弱民主控制
5. 最终需要独裁者来执行计划，民主被破坏，自由丧失
