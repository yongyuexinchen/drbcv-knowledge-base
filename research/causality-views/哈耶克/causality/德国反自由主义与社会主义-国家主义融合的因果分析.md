## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 德国在一战中战败及对西方自由主义（尤其英国式商业自由主义）的敌视 |
| **DV（因变量）** | 德国社会主义者与保守主义者结成共同战线，推动国家社会主义（纳粹主义）兴起 |
| **Chain（传导链）** | 德国在一战中战败，归咎于西方自由主义（英国式商业统治） → 普鲁士主义与社会主义共同反对英国式自由主义，形成思想共识 → 知识分子（如施本格勒、缪勒·范·登·布鲁克）将自由主义定义为首要敌人 → 德国青年运动接受社会主义与国家主义融合，形成“保守的社会主义”思潮 → 该思潮在20世纪20年代后期汇聚于《行动报》等团体，为纳粹上台提供思想土壤 |
| **Lag（时滞）** | 约10-15年（一战结束至纳粹上台，1918-1933） |
| **Threshold（临界值）** | 当自由主义被普遍视为战败根源且青年一代集体排斥时，融合思潮成为主流 |
| **前提与约束（Premises）** | 仅当德国社会普遍接受战败归因于自由主义的叙事；仅在德国知识分子和青年运动活跃的特定历史时期（魏玛共和国）；排除德国国内亲自由主义或亲西方民主的力量（如部分社会民主党人） |
| **Falsification（证伪条件）** | 若发现德国社会主义者与保守主义者长期对立、或青年运动主流转向自由主义，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由主义者（如哈耶克）认为社会主义与纳粹主义本质不同的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 德国在一战中战败，归咎于西方自由主义（英国式商业统治）
2. 普鲁士主义与社会主义共同反对英国式自由主义，形成思想共识
3. 知识分子（如施本格勒、缪勒·范·登·布鲁克）将自由主义定义为首要敌人
4. 德国青年运动接受社会主义与国家主义融合，形成“保守的社会主义”思潮
5. 该思潮在20世纪20年代后期汇聚于《行动报》等团体，为纳粹上台提供思想土壤
