# 社会主义计划导致极权主义

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_14_p1　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会主义政策的推行（集体主义计划） |
| **DV（因变量）** | 极权主义（法西斯主义/纳粹主义）的兴起 |
| **Chain（传导链）** | 社会主义政策要求中央计划和控制经济 → 中央计划需要集中权力并压制个人自由 → 权力集中导致少数人决策并排斥异见 → 为维持计划目标，逐步扩大强制和镇压 → 最终演变为极权主义体制 |
| **Lag（时滞）** | 15至25年（从社会主义政策推行到极权主义显现） |
| **Threshold（临界值）** | 当中央计划覆盖经济主要部门，且个人自由受到系统性限制时 |
| **前提与约束（Premises）** | 仅当社会主义政策被广泛接受并持续推行时；在民主国家中，若公众未能及时认识危险并修正方向；排除德国特有的普鲁士传统因素，但该因素非必要条件 |
| **Falsification（证伪条件）** | 若存在长期推行社会主义政策而未出现极权主义的案例，或极权主义在无社会主义政策的国家兴起，则可推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为法西斯主义是对社会主义的反动的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同温水煮青蛙，逐渐升温的中央控制最终导致自由丧失，而青蛙（社会）在初期未察觉危险。

### 🔗 文字版因果链

1. 社会主义政策要求中央计划和控制经济
2. 中央计划需要集中权力并压制个人自由
3. 权力集中导致少数人决策并排斥异见
4. 为维持计划目标，逐步扩大强制和镇压
5. 最终演变为极权主义体制
