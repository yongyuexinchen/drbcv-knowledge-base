# 计划经济必然导致极权主义

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 追求计划经济 |
| **DV（因变量）** | 极权主义 |
| **Chain（传导链）** | 计划经济要求中央统一分配资源，消除市场自发调节 → 为执行统一计划，政府必须控制生产、分配和消费的细节 → 控制范围扩大导致个人经济自由被剥夺 → 经济自由的丧失进一步侵蚀政治自由和个人自由 → 最终形成全面的极权主义体制 |
| **Lag（时滞）** | 长期过程，随计划实施逐步显现 |
| **Threshold（临界值）** | 当计划覆盖整个经济体系，且政府拥有强制分配权时 |
| **前提与约束（Premises）** | 仅当计划是全面的、覆盖整个经济时；仅当政府拥有强制执行计划的权力时；排除混合经济或有限政府干预的情况 |
| **Falsification（证伪条件）** | 若存在一个全面计划经济国家，其政治体制保持高度自由、无极权倾向，则可推翻此断言 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义及福利国家支持者的观点冲突，他们认为计划与自由可兼容 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 计划经济要求中央统一分配资源，消除市场自发调节
2. 为执行统一计划，政府必须控制生产、分配和消费的细节
3. 控制范围扩大导致个人经济自由被剥夺
4. 经济自由的丧失进一步侵蚀政治自由和个人自由
5. 最终形成全面的极权主义体制
