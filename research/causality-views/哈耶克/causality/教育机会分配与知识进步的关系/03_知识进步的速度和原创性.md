# 知识进步的速度和原创性

> 属于因果簇：[[教育机会分配与知识进步的关系]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 独立的研究中心和多元资助来源 |
| **DV（因变量）** | 知识进步的速度和原创性 |
| **Chain（传导链）** | 多个独立中心允许研究者自由选择问题 → 非正统思想有机会获得支持 → 意外结合和跨学科接触产生突破性进展 → 知识进步整体加快 |
| **Lag（时滞）** | 长期（数年甚至数十年） |
| **Threshold（临界值）** | 存在足够多的独立中心和资助来源，且非正统思想有获得支持的可能 |
| **前提与约束（Premises）** | 研究需要大量物质手段；资助来源分散，不集中于单一计划；研究者已证明能力并获职位保障 |
| **Falsification（证伪条件）** | 若集中规划的研究体系在长期内持续产生更多原创性突破，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持科学规划和组织化的观点（如某些马克思主义者）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多个独立的花园，各自种植不同作物，比一个统一规划的农场更可能发现新的杂交品种，因为意外组合更多。

### 🔗 文字版因果链

1. 多个独立中心允许研究者自由选择问题
2. 非正统思想有机会获得支持
3. 意外结合和跨学科接触产生突破性进展
4. 知识进步整体加快
