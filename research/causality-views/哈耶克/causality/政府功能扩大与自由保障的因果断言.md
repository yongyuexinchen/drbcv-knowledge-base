# 政府功能扩大与自由保障的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府成为人民意志的有组织表达机构 |
| **DV（因变量）** | 对政府权力的怀疑态度转变为扩大政府功能的主张 |
| **Chain（传导链）** | 政府从代表王室和特定阶级利益转变为代表人民意志 → 人民对政府的信任增强，不再视其为压迫工具 → 怀疑政府权力的旧观念被视为过时 → 主张扩大政府功能以有益地发挥作用 |
| **Lag（时滞）** | 长期（从旧制度到新制度的转变过程） |
| **Threshold（临界值）** | 政府必须真正成为人民意志的表达机构，而非名义上的 |
| **前提与约束（Premises）** | 政府确实代表人民意志，而非特定阶级利益；人民有组织的表达意愿的机制存在；政府功能扩大不会导致权力滥用 |
| **Falsification（证伪条件）** | 如果政府扩大功能后导致自由受损或权力滥用，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与穆勒（1848年）反对扩大政府功能的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同信任的管家：当管家从只为主人服务变为代表全家利益时，家人会从提防转为放心让他管理更多事务。

### 🔗 文字版因果链

1. 政府从代表王室和特定阶级利益转变为代表人民意志
2. 人民对政府的信任增强，不再视其为压迫工具
3. 怀疑政府权力的旧观念被视为过时
4. 主张扩大政府功能以有益地发挥作用
