# 保守主义缺乏原则导致其无法提供替代方向

> **领域**：政治哲学　|　**来源**：哈耶克_chapter_89_part_01_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 保守主义缺乏政治原则（没有自己的目标，仅反对变化） |
| **DV（因变量）** | 保守主义无法提供替代发展方向，只能被拖在非自己选择的道路上 |
| **Chain（传导链）** | 保守主义本质上是对剧烈变化的反对态度，缺乏自身的目标和原则 → 由于没有原则，保守主义只能根据现存趋势调整立场，倾向于跟随社会主义而非自由主义 → 因此，保守主义只能减缓不期望的发展速度，但不能改变发展方向 → 最终，保守主义被拖在一个不是由自己选择的道路上，无法提供替代选择 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 无明确量化阈值，但需保守主义长期缺乏原则且面对持续的社会变革 |
| **前提与约束（Premises）** | 保守主义缺乏自身政治原则，仅依赖对变化的反对；社会发展趋势长期偏向社会主义或集体主义；保守主义与自由主义、社会主义的三角关系中，保守主义倾向于跟随社会主义 |
| **Falsification（证伪条件）** | 如果保守主义能够提出并实施一套独立于现存趋势的替代性社会蓝图，且成功改变发展方向，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与保守主义自我认知冲突，保守主义者可能认为自身有原则（如传统、秩序） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 保守主义像一辆没有方向盘的汽车，只能踩刹车减速，但无法转弯，最终只能被道路带着走。

### 🔗 文字版因果链

1. 保守主义本质上是对剧烈变化的反对态度，缺乏自身的目标和原则
2. 由于没有原则，保守主义只能根据现存趋势调整立场，倾向于跟随社会主义而非自由主义
3. 因此，保守主义只能减缓不期望的发展速度，但不能改变发展方向
4. 最终，保守主义被拖在一个不是由自己选择的道路上，无法提供替代选择
