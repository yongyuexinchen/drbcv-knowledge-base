## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律实证主义等反法治理论的兴起（否认超法律原则、将法律等同于立法者意志） |
| **DV（因变量）** | 法治衰落并最终导致极权主义（如纳粹德国） |
| **Chain（传导链）** | 法律实证主义否认存在超法律的规则，认为法律只是立法者的命令，从而取消了限制立法权的原则 → 法治的实质概念（要求法律具有普遍、抽象、明确特征）被形式概念取代，仅要求国家行动有立法授权 → 行政与司法自由裁量权扩大，法律与行政命令界限模糊，个人自由失去保障 → 多数人权力不受限制，为专制独裁铺平道路，最终导致极权主义（如希特勒上台） |
| **Lag（时滞）** | 数十年（19世纪末理论兴起，20世纪20-30年代产生政治后果） |
| **Threshold（临界值）** | 当法律实证主义成为主流，且法治的实质概念被形式概念完全取代时 |
| **前提与约束（Premises）** | 法律实证主义在思想界占据主导地位；政治环境（如德国统一、社会改革压力）加速了反法治理论的传播；缺乏其他制衡力量（如自然法传统） |
| **Falsification（证伪条件）** | 若存在一个法律实证主义占主导但未走向极权主义的国家，或法治衰落但自由未受严重侵害的案例，则可证伪 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自然法传统冲突；与哈耶克自由宪章理念冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 法律实证主义否认存在超法律的规则，认为法律只是立法者的命令，从而取消了限制立法权的原则
2. 法治的实质概念（要求法律具有普遍、抽象、明确特征）被形式概念取代，仅要求国家行动有立法授权
3. 行政与司法自由裁量权扩大，法律与行政命令界限模糊，个人自由失去保障
4. 多数人权力不受限制，为专制独裁铺平道路，最终导致极权主义（如希特勒上台）
