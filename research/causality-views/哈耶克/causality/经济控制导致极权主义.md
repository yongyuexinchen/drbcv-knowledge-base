## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对经济活动的集中计划与控制 |
| **DV（因变量）** | 极权主义（对个人生活全面控制，丧失自由） |
| **Chain（传导链）** | 集中计划要求对经济活动进行有意识的指导，需要由专家和总指挥进行决策，其行动不受民主程序束缚 → 经济控制不仅控制经济事务，而且控制实现所有目标的手段，因为经济因素是实现其他目标的条件 → 控制一切经济活动的人控制了用于所有目标的手段，从而决定哪些需要被满足，哪些不被满足，进而决定价值排序 → 当局对生产的控制使其成为垄断者，能够决定提供什么商品和劳务以及分配方式，从而控制消费和私人生活 → 计划当局控制职业选择和报酬条件，限制个人选择自由，使个人成为实现抽象社会目标的工具 → 最终，个人在生活的各个方面都受当局控制，导致极权主义 |
| **Lag（时滞）** | 长期（随着计划实施逐步显现，但趋势必然） |
| **Threshold（临界值）** | 当经济活动被集中计划时，即达到临界点，无需特定量化条件 |
| **前提与约束（Premises）** | 经济活动是追求其他目标的条件，不存在纯粹的经济目的；现代社会个人依赖他人提供手段，经济计划涉及生活各个方面；计划当局必须控制生产、分配和职业选择以实现其目标 |
| **Falsification（证伪条件）** | 如果存在一个集中计划的经济体，但个人自由（包括消费选择、职业选择、价值判断）并未受到显著限制，且民主程序仍然有效，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的观点冲突，如蔡斯认为政治民主能在有计划社会中保持 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个管家不仅管理你的财务，还决定你该买什么、穿什么、做什么工作，最终你生活的每个决定都由他做出，你失去了自主权

### 🔗 文字版因果链

1. 集中计划要求对经济活动进行有意识的指导，需要由专家和总指挥进行决策，其行动不受民主程序束缚
2. 经济控制不仅控制经济事务，而且控制实现所有目标的手段，因为经济因素是实现其他目标的条件
3. 控制一切经济活动的人控制了用于所有目标的手段，从而决定哪些需要被满足，哪些不被满足，进而决定价值排序
4. 当局对生产的控制使其成为垄断者，能够决定提供什么商品和劳务以及分配方式，从而控制消费和私人生活
5. 计划当局控制职业选择和报酬条件，限制个人选择自由，使个人成为实现抽象社会目标的工具
6. 最终，个人在生活的各个方面都受当局控制，导致极权主义
