# 经济计划导致极权主义与个人自由丧失

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_21_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以集中计划代替竞争（经济计划） |
| **DV（因变量）** | 个人自由的全面丧失（极权主义） |
| **Chain（传导链）** | 分工深化使个人活动高度依赖社会过程，经济控制范围扩大 → 计划要求对生活进行集中管理，超出经济活动领域 → 计划剥夺个人选择权，强制按计划时间与形式满足需要 → 外汇管制等工具切断个人对外联系，压制舆论 → 最终个人屈服于国家专制，自由丧失 |
| **Lag（时滞）** | 渐进过程，从经济控制扩展到全面控制，时滞可能为数年至数十年 |
| **Threshold（临界值）** | 当经济计划扩展到外汇管制等关键领域时，成为决定性一步 |
| **前提与约束（Premises）** | 分工高度发达，个人生活几乎全部依存于他人经济活动；计划者意图集体满足需要，并利用计划作为政治教育工具；国家具备实施集中管理的能力 |
| **Falsification（证伪条件）** | 若存在经济计划但个人自由未受压制，或计划与自由并存的国家实例 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的观点冲突，如兰格市场社会主义；与克拉克关于生产问题的观点部分冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将一个人的饮食完全交给营养师安排，起初只是控制吃什么，但最终连何时吃、如何吃、甚至思想口味都被规定，失去自主选择的能力。

### 🔗 文字版因果链

1. 分工深化使个人活动高度依赖社会过程，经济控制范围扩大
2. 计划要求对生活进行集中管理，超出经济活动领域
3. 计划剥夺个人选择权，强制按计划时间与形式满足需要
4. 外汇管制等工具切断个人对外联系，压制舆论
5. 最终个人屈服于国家专制，自由丧失
