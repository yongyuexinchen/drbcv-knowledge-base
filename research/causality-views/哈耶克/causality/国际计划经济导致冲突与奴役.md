# 国际计划经济导致冲突与奴役

> **领域**：宏观经济学、国际政治经济学　|　**来源**：哈耶克_chapter_29_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 各国独立实施经济计划，阻断外来影响 |
| **DV（因变量）** | 国际摩擦加剧，持久和平无望 |
| **Chain（传导链）** | 各国为实施计划而限制人员和货物流动 → 各国资源被视为本国独占财产，国际经济关系变成整体国家间关系 → 国家间以谈判代替市场竞争，形成强力争夺 → 各国作为自身行为的最高评判者，经济交易导致权力冲突 → 国际摩擦加剧，持久和平无望 |
| **Lag（时滞）** | 短期可见，但长期效应更严重 |
| **Threshold（临界值）** | 无明确量化阈值，但计划范围越大，冲突越烈 |
| **前提与约束（Premises）** | 各国以自身眼前利益为优先，不考虑对他国损害；存在多个独立主权国家，无更高法律约束 |
| **Falsification（证伪条件）** | 若各国独立计划能通过国际协调实现持久和平，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张国际协调计划可减少摩擦的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多个邻居各自筑墙堵路，最终导致社区冲突不断，无法安宁。

### 🔗 文字版因果链

1. 各国为实施计划而限制人员和货物流动
2. 各国资源被视为本国独占财产，国际经济关系变成整体国家间关系
3. 国家间以谈判代替市场竞争，形成强力争夺
4. 各国作为自身行为的最高评判者，经济交易导致权力冲突
5. 国际摩擦加剧，持久和平无望

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国际性经济计划（超国家机构集中指导） |
| **DV（因变量）** | 强力统治、道德败坏、民族仇恨 |
| **Chain（传导链）** | 计划规模扩大，价值标准差异增大，意见一致程度减少 → 需要借重强力与强迫来执行计划 → 计划者必须对不同民族的要求排序，优先某些而置后其他 → 被置后者感到不公，仇恨指向计划当局 → 计划当局为推行计划而动用强力，道德败坏，民族仇恨加剧 |
| **Lag（时滞）** | 计划实施后逐渐显现，但一旦显现则难以逆转 |
| **Threshold（临界值）** | 计划范围超出小社区（如家庭、小社区）时，强力必要性增大 |
| **前提与约束（Premises）** | 计划涉及多个民族，价值标准差异大；计划者需有意识平衡不同民族的要求；无公认的公平分配标准 |
| **Falsification（证伪条件）** | 若国际计划能在不诉诸强力的情况下获得各民族自愿同意并公平执行，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持国际计划（如世界性计划）的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像试图用一个食谱为口味迥异的多个家庭做饭，最终只能强迫大家吃同样的菜，引发众怒。

### 🔗 文字版因果链

1. 计划规模扩大，价值标准差异增大，意见一致程度减少
2. 需要借重强力与强迫来执行计划
3. 计划者必须对不同民族的要求排序，优先某些而置后其他
4. 被置后者感到不公，仇恨指向计划当局
5. 计划当局为推行计划而动用强力，道德败坏，民族仇恨加剧

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 控制重要原材料或特定经济领域的国际机构 |
| **DV（因变量）** | 成为主宰各国命运的暴虐权力 |
| **Chain（传导链）** | 控制原材料供应者决定是否增加供给、降低价格或生产者收入 → 决定是否允许国家创立新工业或禁止 → 控制所有重要原材料时，无批准则无新工业、新投资 → 该权力不受更高政治权力约束，难以有效质询 → 成为最暴虐和不负责任的权力 |
| **Lag（时滞）** | 权力一旦赋予，立即生效 |
| **Threshold（临界值）** | 控制所有重要原材料时，权力达到极致 |
| **前提与约束（Premises）** | 国际机构不受单一最高政治权力约束；机构可借口技术需要或人道理由辩护其行为 |
| **Falsification（证伪条件）** | 若国际机构能自我约束并公正行使权力，不滥用，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为国际技术机构可客观公正管理的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人控制全城的水源，他决定谁有水喝，谁没水喝，自然成为所有人的主宰。

### 🔗 文字版因果链

1. 控制原材料供应者决定是否增加供给、降低价格或生产者收入
2. 决定是否允许国家创立新工业或禁止
3. 控制所有重要原材料时，无批准则无新工业、新投资
4. 该权力不受更高政治权力约束，难以有效质询
5. 成为最暴虐和不负责任的权力
