# 进化过程不可公正化（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：进化过程不可公正化.md

## 总体因果图

- 对自然进化过程（如文明、市场秩序）施加公正要求 → 破坏进化过程本身的功能，导致文明进化不可能
- 传统选择过程（筛选非理性信念） → 信奉这些传统的人繁荣兴旺
- 分散的知识和权力（通过个人自由和分立的财产） → 更有效地利用信息，形成扩展秩序，提高生产力
- 个体差异（多样性） → 增强合作群体的力量，促进文明发展
- 遵守抽象规则（而非追求具体利他目标） → 产生利他主义结果，形成扩展秩序
