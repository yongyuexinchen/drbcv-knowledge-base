## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划经济（政府集中控制经济资源与决策） |
| **DV（因变量）** | 奴役（个人自由丧失，社会走向极权主义） |
| **Chain（传导链）** | 中央计划要求政府掌握所有经济信息并做出统一决策 → 由于信息分散且无法有效集中，计划者必须依赖强制手段推行计划 → 强制推行计划导致个人经济自由被剥夺，进而扩展到政治和社会自由 → 权力集中使反对意见被压制，最终形成极权主义，个人沦为计划的工具 |
| **Lag（时滞）** | 长期过程，可能跨越数十年，随着计划范围扩大而逐步显现 |
| **Threshold（临界值）** | 当政府控制超过经济活动的关键领域（如生产资料、价格、分配）时，奴役趋势不可逆转 |
| **前提与约束（Premises）** | 仅当经济计划是全面的、强制性的，而非局部或自愿协调时成立；假设社会缺乏自发秩序（如市场）的有效替代机制；排除民主监督和法治约束下的有限干预情况 |
| **Falsification（证伪条件）** | 如果存在一个长期运行的中央计划经济体，其公民自由和政治权利未受显著侵蚀，且经济效率持续优于市场经济，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（但可参考苏联、东欧等历史案例作为间接证据） |
| **Conflicts（观点冲突）** | 与凯恩斯主义、社会主义计划经济理论冲突（如奥斯卡·兰格的市场社会主义模型） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人试图用一张地图精确规划整个城市的每一步行动，但地图永远无法涵盖所有细节，最终只能靠强制命令来维持秩序，人们失去自由行走的权利。

### 🔗 文字版因果链

1. 中央计划要求政府掌握所有经济信息并做出统一决策
2. 由于信息分散且无法有效集中，计划者必须依赖强制手段推行计划
3. 强制推行计划导致个人经济自由被剥夺，进而扩展到政治和社会自由
4. 权力集中使反对意见被压制，最终形成极权主义，个人沦为计划的工具
