## 总体因果图

- 中央计划（政府对经济的集中控制） → 个人自由丧失（通往奴役）
- 法治（rule of law，而非人治） → 个人自由与繁荣
- 传统与道德规范（自发秩序的基础） → 文明存续与扩展秩序
