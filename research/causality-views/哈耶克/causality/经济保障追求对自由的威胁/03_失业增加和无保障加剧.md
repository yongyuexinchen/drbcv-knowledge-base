# 失业增加和无保障加剧

> 属于因果簇：[[经济保障追求对自由的威胁]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府干预市场以提供特定收入保障（限制主义） |
| **DV（因变量）** | 失业增加和无保障加剧 |
| **Chain（传导链）** | 政府通过限制产量、控制价格或工资来保障特定集团收入 → 这种限制减少了行业外的机会，排挤其他更差境遇者 → 受保护集团人数增加，可供选择的机会减少 → 需求下跌行业的人无路可走，每次变动成为大规模失业根源 → 最终，失业和无保障增加 |
| **Lag（时滞）** | 中期（数年至数十年，随政策累积） |
| **Threshold（临界值）** | 当限制措施覆盖多个行业，且受保护集团人数增多时，效果显著 |
| **前提与约束（Premises）** | 市场机制下，价格和工资应反映供需；限制措施扭曲市场信号；存在其他行业可供选择 |
| **Falsification（证伪条件）** | 如果限制措施能稳定特定收入而不减少他人机会或增加失业，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持产业保护或价格管制的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像堵住河流的一段，让上游水位升高，但下游却干涸，最终整个生态系统失衡。

### 🔗 文字版因果链

1. 政府通过限制产量、控制价格或工资来保障特定集团收入
2. 这种限制减少了行业外的机会，排挤其他更差境遇者
3. 受保护集团人数增加，可供选择的机会减少
4. 需求下跌行业的人无路可走，每次变动成为大规模失业根源
5. 最终，失业和无保障增加
