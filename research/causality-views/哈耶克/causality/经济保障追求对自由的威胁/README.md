# 经济保障追求对自由的威胁（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：经济保障追求对自由的威胁.md

## 总体因果图

- 普遍追求绝对经济保障（特定收入保障） → 对自由的严重威胁（自由受限）
- 政府提供最低收入保障（有限度的保障） → 普遍自由不受威胁
- 政府干预市场以提供特定收入保障（限制主义） → 失业增加和无保障加剧
