# 计划导致极权与自由丧失

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_22_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府实行经济计划（集中管理经济） |
| **DV（因变量）** | 个人自由丧失，社会走向极权主义 |
| **Chain（传导链）** | 政府开始计划经济活动，决定生产与分配 → 计划者必须决定不同个人和集团的收入与地位 → 个人命运由当权者有意决定，而非非人为的市场力量 → 人们意识到命运取决于当权者，不满增长，转而争夺控制权 → 经济问题政治化，唯一重要的是谁掌握强制权力 → 最终形成极权主义，个人自由被全面控制 |
| **Lag（时滞）** | 长期，随着计划范围扩展而逐步显现 |
| **Threshold（临界值）** | 当市场自由运作受到阻碍超过一定限度，计划者被迫扩展管制范围直至无所不包 |
| **前提与约束（Premises）** | 生产资料集中于单一权力（国家或独裁者）手中；计划者追求某种公平分配理想；社会存在不同利益集团，计划需要统一价值标准 |
| **Falsification（证伪条件）** | 若存在一个实行全面经济计划但个人自由未受损害、未走向极权的实例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的观点冲突，如列宁的'谁跟谁'所体现的社会主义计划理念 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人如果完全依赖另一个人的施舍生活，他必须讨好施舍者，失去自主权；如果经济命脉掌握在政府手中，个人自由也必然受制于政府。

### 🔗 文字版因果链

1. 政府开始计划经济活动，决定生产与分配
2. 计划者必须决定不同个人和集团的收入与地位
3. 个人命运由当权者有意决定，而非非人为的市场力量
4. 人们意识到命运取决于当权者，不满增长，转而争夺控制权
5. 经济问题政治化，唯一重要的是谁掌握强制权力
6. 最终形成极权主义，个人自由被全面控制
