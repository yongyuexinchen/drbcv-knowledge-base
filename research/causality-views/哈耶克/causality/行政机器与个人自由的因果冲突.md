# 行政机器与个人自由的因果冲突

> **领域**：政治哲学　|　**来源**：哈耶克_chapter_81_part_01_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 行政机器被授予排他性权力 |
| **DV（因变量）** | 个人自由受到威胁 |
| **Chain（传导链）** | 行政当局急于实现眼前直接目标 → 以错误的眼光看待自身职能 → 认为宪法限制和个人权利必须让位于首要政府目标 → 导致个人自由被侵蚀 |
| **Lag（时滞）** | 短期至中期，随行政权力扩张而逐步显现 |
| **Threshold（临界值）** | 当行政权力超越宪法约束时 |
| **前提与约束（Premises）** | 行政当局拥有排他性执行权；行政当局以公共物品为优先目标；存在宪法限制和个人权利保障制度 |
| **Falsification（证伪条件）** | 若行政当局在拥有排他性权力时仍能有效维护个人自由，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张行政效率优先的专家治国论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个司机被赋予绝对路权，容易忽视交通规则，最终危及行人安全

### 🔗 文字版因果链

1. 行政当局急于实现眼前直接目标
2. 以错误的眼光看待自身职能
3. 认为宪法限制和个人权利必须让位于首要政府目标
4. 导致个人自由被侵蚀

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 福利管理机构扩张 |
| **DV（因变量）** | 行政机器专断且不可监督 |
| **Chain（传导链）** | 福利管理机构规模扩大 → 部长监督失效，议会监督成为神话 → 机构日益具有主权当局色彩 → 个人在机构面前无助 |
| **Lag（时滞）** | 长期，随福利国家发展而逐渐形成 |
| **Threshold（临界值）** | 当福利管理超出民主监督能力时 |
| **前提与约束（Premises）** | 福利国家政策持续扩张；民主监督机制薄弱或流于形式；行政官员被视为不可或缺的专家 |
| **Falsification（证伪条件）** | 若福利管理机构在扩张中仍能保持透明和可监督性，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与福利国家支持者的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个庞大的官僚机构像巨兽般难以驾驭，个人如同蚂蚁面对巨象

### 🔗 文字版因果链

1. 福利管理机构规模扩大
2. 部长监督失效，议会监督成为神话
3. 机构日益具有主权当局色彩
4. 个人在机构面前无助
