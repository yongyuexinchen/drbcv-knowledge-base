# 法律从身份到契约的转变

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会法律体系从身份（status）向契约（contract）的转变 |
| **DV（因变量）** | 个人自由与市场效率的提升 |
| **Chain（传导链）** | 身份关系基于先赋地位，限制个人选择 → 契约关系基于自由合意，赋予个人自主权 → 契约自由促进资源有效配置与个体能动性 → 法律框架从身份转向契约，扩大个人自由空间并提升经济效率 |
| **Lag（时滞）** | 长期（数十年至数代） |
| **Threshold（临界值）** | 法律体系明确承认契约自由、财产不可侵犯及过错赔偿原则 |
| **前提与约束（Premises）** | 法律体系具备形式规则，而非实质干预；政府仅规定禁止事项，不指定具体行为；个人具备理性判断自身利益的能力 |
| **Falsification（证伪条件）** | 若法律体系从身份转向契约后，个人自由或经济效率未提升或反而下降，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同从固定轨道行驶的火车变为自由驾驶的汽车，前者路线固定，后者可自主选择路径，但需遵守交通规则。

### 🔗 文字版因果链

1. 身份关系基于先赋地位，限制个人选择
2. 契约关系基于自由合意，赋予个人自主权
3. 契约自由促进资源有效配置与个体能动性
4. 法律框架从身份转向契约，扩大个人自由空间并提升经济效率
