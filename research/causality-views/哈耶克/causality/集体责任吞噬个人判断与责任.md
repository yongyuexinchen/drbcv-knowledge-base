# 集体责任吞噬个人判断与责任

> **领域**：社会学　|　**来源**：哈耶克_chapter_69_p3　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体责任感的扩散（‘集体’一词对个人判断的吞噬） |
| **DV（因变量）** | 个人判断力与责任感的丧失，以及群众行动的不负责任程度加剧 |
| **Chain（传导链）** | 个体在集体中产生‘共同负责’的认知，导致个人判断被集体意见淹没 → 个人因感到责任由集体分担而降低自我审查与独立决策的动力 → 责任分散使个体行为缺乏个人问责机制，进而加剧群众行动的鲁莽与不负责任 |
| **Lag（时滞）** | 短期至中期（集体决策情境中即时显现，长期累积形成群体行为模式） |
| **Threshold（临界值）** | 当集体规模达到使个体感知‘责任不可归因于个人’的临界点（如大型集会、匿名化群体） |
| **前提与约束（Premises）** | 仅当个体认同‘集体共同负责’的观念时成立；在缺乏明确个人问责机制的组织或群体中有效；排除具有强个人主义文化或明确责任分工的群体 |
| **Falsification（证伪条件）** | 若在大型集体行动中观察到个体因个人责任感而主动纠正集体错误，或责任分散并未导致行为鲁莽，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与涂尔干‘集体意识增强社会整合’的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一锅汤里每个人都觉得‘少放点盐没关系’，结果整锅汤咸得无法入口——责任分摊让每个人都觉得‘不差我这一勺’，最终集体酿成恶果。

### 🔗 文字版因果链

1. 个体在集体中产生‘共同负责’的认知，导致个人判断被集体意见淹没
2. 个人因感到责任由集体分担而降低自我审查与独立决策的动力
3. 责任分散使个体行为缺乏个人问责机制，进而加剧群众行动的鲁莽与不负责任
