## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国宪法制度（分权、制衡、法治原则） |
| **DV（因变量）** | 自由秩序的维护与扩展 |
| **Chain（传导链）** | 宪法通过分权与制衡限制政府权力 → 法治原则确保法律面前人人平等，防止专断 → 稳定的制度框架保护个人自由与财产权 → 自由秩序得以在长期内维持并促进社会繁荣 |
| **Lag（时滞）** | 长期（数十年至数百年，制度效果随实践累积显现） |
| **Threshold（临界值）** | 宪法制度必须有效约束政府权力，且司法独立能够执行违宪审查 |
| **前提与约束（Premises）** | 仅当宪法条文被实际执行且司法系统独立时成立；在缺乏法治传统或权力制衡失效的社会中不适用；排除革命或外部征服导致制度崩溃的情况 |
| **Falsification（证伪条件）** | 若某国采用类似宪法制度但自由秩序恶化（如政府权力扩张、个人权利受侵），则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张中央集权或全能政府更有效率的观点冲突（如某些发展型国家理论） |
| **Confidence（确信度）** | well-established |
