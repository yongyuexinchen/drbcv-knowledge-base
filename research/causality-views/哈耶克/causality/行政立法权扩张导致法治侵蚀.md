# 行政立法权扩张导致法治侵蚀

> **领域**：法学、政治学　|　**来源**：哈耶克_chapter_80_part_02_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 行政官员（非议会）拥有制定条例并据此监禁的权力 |
| **DV（因变量）** | 法治原则被侵蚀，个人自由受威胁 |
| **Chain（传导链）** | 行政官员获得制定条例的权力，可对法律无明文规定的行为施以监禁 → 这种权力超越了议会立法的民主正当性，使行政权凌驾于法律之上 → 法律确定性被破坏，公民无法预见行为后果，自由失去保障 → 法治（法律至上）原则被削弱，趋向极权国家 |
| **Lag（时滞）** | 中长期，数年至数十年 |
| **Threshold（临界值）** | 当行政条例可独立于议会立法设定刑罚时，法治即开始实质受损 |
| **前提与约束（Premises）** | 该断言适用于行政权扩张且缺乏司法有效审查的体制；前提是议会立法本应作为唯一刑罚来源的法治传统 |
| **Falsification（证伪条件）** | 若行政条例虽多但司法审查严格且公民权利实际未受侵害，则可质疑该断言 |
| **Data（定量佐证）** | 1948年英国有300名官员有权制定条例并施以监禁；1947年城乡规划法案赋予部长决定发展费用的权力 |
| **Conflicts（观点冲突）** | 与行政国家理论支持者（如沃尔多所描述的）观点冲突，他们认为行政效率优于严格法治 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同小区保安擅自制定罚款规则并执行，虽方便管理却破坏了法治秩序

### 🔗 文字版因果链

1. 行政官员获得制定条例的权力，可对法律无明文规定的行为施以监禁
2. 这种权力超越了议会立法的民主正当性，使行政权凌驾于法律之上
3. 法律确定性被破坏，公民无法预见行为后果，自由失去保障
4. 法治（法律至上）原则被削弱，趋向极权国家
