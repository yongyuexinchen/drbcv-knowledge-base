# 为什么最坏者当政：哈耶克关于极权主义与集体主义的因果断言（因果簇）

> 因果簇索引：7 个子因果卡。父卡文件：为什么最坏者当政_哈耶克关于极权主义与集体主义的因果断言.md

## 总体因果图

- 极权主义制度（以单一计划为核心的集体主义） → 最坏者当政（残酷无情、寡廉鲜耻之人占据权力）
- 个体教育和知识水平提高 → 观念多样性增加，形成高度一致追随者的可能性减少
- 消极纲领（对敌人憎恨、对富人嫉妒、集团对立） → 极权主义领导人获得广大群众无保留的支持
- 集体主义（社会主义）从理论付诸实践 → 变成强烈的民族主义甚至帝国主义
- 集体主义制度中的权力集中（以政治权力代替经济权力） → 权力无限扩张，个人依附性增强，近似奴隶制
- 集体主义道德（以共同目标为唯一标准，目的证明手段正当） → 个人良心和普遍道德规则被取消，残酷行为被视为责任
- 极权主义机器中需要执行恶劣工作（残忍、欺诈、间谍、镇压） → 愿意做坏事的人升官得势，最坏者占据最高领导地位
