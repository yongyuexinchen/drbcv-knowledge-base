# 福利国家作为收入再分配工具与自由社会公正原则的冲突

> **领域**：政治经济学、社会政策　|　**来源**：哈耶克_chapter_83_part_01_p3　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政治家将贝弗里奇计划等福利制度转变为收入再分配工具 |
| **DV（因变量）** | 福利制度与自由社会的公正原则互不相容，导致非理性要求和制度性负担 |
| **Chain（传导链）** | 政治家将原本非再分配性质的福利计划转变为收入再分配工具 → 为贫困者提供同等最低福利需以经济情况调查为前提，但人们非理性反对调查 → 反对导致要求人人享有福利而不论需要，以便真正需要者不感到低人一等 → 结果社会扶助贫困者却使其误以为所得是自身努力或功绩，掩盖了再分配实质 → 这种制度与法律面前人人平等的公正原则无关，且引入后难以取消，成为日益沉重的包袱 |
| **Lag（时滞）** | 短期（政治转化迅速）至长期（制度负担累积，数代显现） |
| **Threshold（临界值）** | 当福利制度从“最低保障”转向“普遍权利”且缺乏需要证明时，冲突显现 |
| **前提与约束（Premises）** | 自由社会存在先入为主的公正观念，强调个人责任和权利平等；福利提供需以经济情况调查为基础，否则无法确保公正；民主政体下政治过程可能扭曲制度初衷 |
| **Falsification（证伪条件）** | 若能证明无需经济情况调查的普遍福利制度仍能维持公正且不产生非理性要求，或证明福利国家可轻易取消而不造成负担，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持普遍福利（如贝弗里奇报告）或认为福利国家可促进社会公正的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同不分青红皂白地给所有人发药，却让真正生病的人觉得药是自己挣来的，最终药厂负担加重，而病未治好。

### 🔗 文字版因果链

1. 政治家将原本非再分配性质的福利计划转变为收入再分配工具
2. 为贫困者提供同等最低福利需以经济情况调查为前提，但人们非理性反对调查
3. 反对导致要求人人享有福利而不论需要，以便真正需要者不感到低人一等
4. 结果社会扶助贫困者却使其误以为所得是自身努力或功绩，掩盖了再分配实质
5. 这种制度与法律面前人人平等的公正原则无关，且引入后难以取消，成为日益沉重的包袱
