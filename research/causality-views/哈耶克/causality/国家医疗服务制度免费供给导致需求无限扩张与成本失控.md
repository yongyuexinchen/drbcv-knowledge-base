# 国家医疗服务制度免费供给导致需求无限扩张与成本失控

> **领域**：卫生经济学、公共政策　|　**来源**：哈耶克_chapter_83_part_02_p2　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家医疗服务制度提供免费（零价格）的全面医疗服务 |
| **DV（因变量）** | 医疗服务需求无限扩张，成本远超预期，导致资源分配困境 |
| **Chain（传导链）** | 国家提供免费医疗服务，患者支付价格为零 → 在零价格下，患者对医疗服务的需求近乎无限 → 医疗供给无法无限增加，成本曲线快速上升 → 若不采用定量配给，则出现排队、延误治疗等非价格配给现象 → 最终导致资源分配不公和整体福利损失 |
| **Lag（时滞）** | 短期（需求立即增加）至长期（成本持续上升，数十年内显现） |
| **Threshold（临界值）** | 当服务价格为零且供给弹性有限时，需求超过供给的临界点出现 |
| **前提与约束（Premises）** | 医疗服务被视为基本权利，免费提供；医疗资源供给有限，无法随需求无限扩张；缺乏有效的价格机制或定量配给措施；适用于全民覆盖的单一支付体系 |
| **Falsification（证伪条件）** | 如果存在证据表明在免费医疗制度下需求得到有效控制，成本稳定，且无显著排队或延误，则该断言被推翻 |
| **Data（定量佐证）** | 贝弗里奇报告估计年度开支1.7亿英镑，实际远超4.5亿英镑（1956年数据） |
| **Conflicts（观点冲突）** | 与支持全民免费医疗的观点冲突，如贝弗里奇报告本身及克罗斯兰《社会主义的未来》 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 免费自助餐：当食物免费且无限供应时，人们会大量取食，导致食物迅速耗尽，后来者无食可用，造成浪费和分配不公。

### 🔗 文字版因果链

1. 国家提供免费医疗服务，患者支付价格为零
2. 在零价格下，患者对医疗服务的需求近乎无限
3. 医疗供给无法无限增加，成本曲线快速上升
4. 若不采用定量配给，则出现排队、延误治疗等非价格配给现象
5. 最终导致资源分配不公和整体福利损失
