# 进化过程不可公正化

> **领域**：宏观经济学、社会哲学　|　**来源**：哈耶克_chapter_47_part_01_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对自然进化过程（如文明、市场秩序）施加公正要求 |
| **DV（因变量）** | 破坏进化过程本身的功能，导致文明进化不可能 |
| **Chain（传导链）** | 人们厌恶试错过程的盲目结果，希望用当前愿望塑造进化 → 由此产生的道德提出自相矛盾的要求，成为冲突根源 → 试图让进化变得公正，会压制由运气造成的差异 → 压制差异破坏了发现新机会的信息传递，使文明进化停滞 |
| **Lag（时滞）** | 长期，非即时可见 |
| **Threshold（临界值）** | 当公正要求（如平均主义）被全面贯彻时，进化过程即被终止 |
| **前提与约束（Premises）** | 进化过程仍在进行中，其结果不取决于任何人的知识；文明是进化的产物，通过普遍规则和个人自由继续进化；个人可通过道德行为增加机会，但整体进化不满足所有道德愿望 |
| **Falsification（证伪条件）** | 若能证明在全面贯彻公正原则（如罗尔斯式）下，文明仍能持续进化并产生新机会，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与罗尔斯《正义论》中的公正原则冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 试图让自然选择变得公平，就像要求进化过程必须符合人类道德标准，否则就停止进化，这如同要求天气必须按人的意愿变化，否则就取消天气系统。

### 🔗 文字版因果链

1. 人们厌恶试错过程的盲目结果，希望用当前愿望塑造进化
2. 由此产生的道德提出自相矛盾的要求，成为冲突根源
3. 试图让进化变得公正，会压制由运气造成的差异
4. 压制差异破坏了发现新机会的信息传递，使文明进化停滞

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 传统选择过程（筛选非理性信念） |
| **DV（因变量）** | 信奉这些传统的人繁荣兴旺 |
| **Chain（传导链）** | 大部分知识来自对学习得到的传统进行筛选的过程 → 个人承认并服从无法用理性证明的道德传统 → 这些信念超出个人知识范围，但有助于信奉者繁荣 → 传统在某些方面比人类理性更优越 |
| **Lag（时滞）** | 长期，跨代际 |
| **Threshold（临界值）** | 无明确阈值，但需个人服从传统 |
| **前提与约束（Premises）** | 传统选择过程利用的实际条件超出个人认知范围；个人无法完全理解传统，但能从中受益 |
| **Falsification（证伪条件）** | 若能证明不遵循传统而仅凭理性决策的个人或群体能持续繁荣，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与建构论理性主义（认为理性可设计社会秩序）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同语言的发展，人们遵循语法规则但未必能解释规则，却因此能有效沟通。

### 🔗 文字版因果链

1. 大部分知识来自对学习得到的传统进行筛选的过程
2. 个人承认并服从无法用理性证明的道德传统
3. 这些信念超出个人知识范围，但有助于信奉者繁荣
4. 传统在某些方面比人类理性更优越

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 分散的知识和权力（通过个人自由和分立的财产） |
| **DV（因变量）** | 更有效地利用信息，形成扩展秩序，提高生产力 |
| **Chain（传导链）** | 个人按自己的决定运用知识，使分散知识得到利用 → 市场通过价格信号传递局部信息，适应未知条件 → 分权使更多信息被利用，配置资源更有效 → 扩展秩序使所有人的知识得到最大限度利用，惠及所有人 |
| **Lag（时滞）** | 即时且持续 |
| **Threshold（临界值）** | 需要许多个人拥有财产，而非全部或无人拥有 |
| **前提与约束（Premises）** | 知识本质上是分散的，无法集中；个人自由和分立的财产是分散知识利用的前提；市场是唯一能提供相关信息的方法 |
| **Falsification（证伪条件）** | 若能证明集中计划能更有效利用分散知识并产生更高生产力，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与社会主义计划经济理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大脑通过无数神经元分散处理信息，而非由一个中央处理器集中控制，才能高效应对复杂环境。

### 🔗 文字版因果链

1. 个人按自己的决定运用知识，使分散知识得到利用
2. 市场通过价格信号传递局部信息，适应未知条件
3. 分权使更多信息被利用，配置资源更有效
4. 扩展秩序使所有人的知识得到最大限度利用，惠及所有人

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 个体差异（多样性） |
| **DV（因变量）** | 增强合作群体的力量，促进文明发展 |
| **Chain（传导链）** | 个体差异使技能多样化，促进劳动分工 → 协调合作让独特天赋发挥作用，超出个人努力总和 → 多样性产生新力量，提高秩序的价值 → 更大的秩序又提高多样性价值，使合作秩序扩展 |
| **Lag（时滞）** | 长期，跨代际 |
| **Threshold（临界值）** | 需要足够多的个体差异，否则劳动分工无意义 |
| **前提与约束（Premises）** | 秩序需要以构成因素之间的差异为前提；个体差异通过文化进化（如学习期延长）得到增强 |
| **Falsification（证伪条件）** | 若能证明同质化群体在复杂环境中能更有效合作并产生更高生产力，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与平均主义（强调一致性）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同生态系统，物种多样性越高，系统越稳定和富有生产力；单一物种则脆弱。

### 🔗 文字版因果链

1. 个体差异使技能多样化，促进劳动分工
2. 协调合作让独特天赋发挥作用，超出个人努力总和
3. 多样性产生新力量，提高秩序的价值
4. 更大的秩序又提高多样性价值，使合作秩序扩展

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵守抽象规则（而非追求具体利他目标） |
| **DV（因变量）** | 产生利他主义结果，形成扩展秩序 |
| **Chain（传导链）** | 个人无法知道其努力为谁服务，无法用利他主义指导生产 → 遵守抽象规则（如市场道德）使行为惠及他人 → 规则约束谋生活动，同时贡献超出个人了解范围的好处 → 扩展秩序弥补个人无知，产生利他主义结果 |
| **Lag（时滞）** | 即时且持续 |
| **Threshold（临界值）** | 需要规则被广泛遵守，且个人行为超出直接知觉范围 |
| **前提与约束（Premises）** | 在扩展秩序中，个人无法知道具体受益者；利他主义本能仅适用于小群体，在扩展秩序中会阻碍秩序形成 |
| **Falsification（证伪条件）** | 若能证明仅凭利他主义动机（不依赖抽象规则）也能维持大规模合作秩序，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与强调利他主义动机的伦理学（如某些功利主义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则，司机遵守规则并非为了具体行人，但整体上保障了所有人的安全。

### 🔗 文字版因果链

1. 个人无法知道其努力为谁服务，无法用利他主义指导生产
2. 遵守抽象规则（如市场道德）使行为惠及他人
3. 规则约束谋生活动，同时贡献超出个人了解范围的好处
4. 扩展秩序弥补个人无知，产生利他主义结果
