# 哈耶克对计划经济的因果批判

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划经济的实施 |
| **DV（因变量）** | 通往奴役之路（个人自由丧失与极权主义） |
| **Chain（传导链）** | 中央计划要求统一目标，压制个人分散知识的使用 → 计划者需要强制推行其目标，导致权力集中 → 权力集中使反对意见无法表达，思想控制加强 → 最终个人自由被剥夺，社会走向极权主义 |
| **Lag（时滞）** | 长期，通常跨越数十年，随着计划深入而逐步显现 |
| **Threshold（临界值）** | 当计划覆盖经济决策的绝大部分领域，且缺乏市场自发秩序时 |
| **前提与约束（Premises）** | 知识分散于个体，无法被中央计划者完全掌握；社会目标多元，不存在单一可强加的集体目标；计划权力不受制衡，且缺乏法治约束 |
| **Falsification（证伪条件）** | 若存在中央计划经济长期保持高经济增长且个人自由指数不降反升的案例，则此断言可被质疑 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义及计划经济支持者（如奥斯卡·兰格）的市场社会主义理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同让一个厨师为所有人决定菜单，最终众口难调，只能强制大家吃同一种菜，导致饮食自由丧失

### 🔗 文字版因果链

1. 中央计划要求统一目标，压制个人分散知识的使用
2. 计划者需要强制推行其目标，导致权力集中
3. 权力集中使反对意见无法表达，思想控制加强
4. 最终个人自由被剥夺，社会走向极权主义
