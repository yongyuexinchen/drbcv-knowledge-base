# 法治对个人自由的保障机制

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法治（以一般性、非歧视性、事先公布的法律规则约束政府权力） |
| **DV（因变量）** | 个人自由（免受专断强制，享有可预期的行动空间） |
| **Chain（传导链）** | 法治要求政府干预个人权利必须依据一般性法律，而非针对特定个人或特定情况的特别法令 → 一般性法律事先公布且适用于无限未来个案，使个人能够预见政府行为，从而规划自身行动 → 排除立法追溯既往和专断裁量，限制政府权力，防止权力滥用 → 个人因此获得免受非法强制的自由，即自由权得到保障 |
| **Lag（时滞）** | 长期（法治的保障效果需在制度稳定运行中逐步显现） |
| **Threshold（临界值）** | 法律必须具有一般性、非歧视性、事先公布、不溯及既往；政府干预必须援引此类法律 |
| **前提与约束（Premises）** | 法律体系以一般性规则为主，特别立法受到严格限制；司法独立且有权审查政府行为是否符合法治原则；社会存在对法治原则的普遍认同和尊重 |
| **Falsification（证伪条件）** | 若在法治国家中，个人自由仍被专断权力侵犯，或一般性法律无法有效限制政府干预，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与法律实证主义（如耶利内克认为自由是不受非法强制的自由，即凡法律不禁止的强制皆可）存在冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法治如同交通规则：红灯停、绿灯行，所有司机都事先知道规则，因此能安全驾驶；若每个路口临时指挥，司机无法预期，必然混乱。

### 🔗 文字版因果链

1. 法治要求政府干预个人权利必须依据一般性法律，而非针对特定个人或特定情况的特别法令
2. 一般性法律事先公布且适用于无限未来个案，使个人能够预见政府行为，从而规划自身行动
3. 排除立法追溯既往和专断裁量，限制政府权力，防止权力滥用
4. 个人因此获得免受非法强制的自由，即自由权得到保障
