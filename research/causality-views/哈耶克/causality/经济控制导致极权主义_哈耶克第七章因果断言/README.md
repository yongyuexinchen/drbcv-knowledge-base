# 经济控制导致极权主义：哈耶克第七章因果断言（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：经济控制导致极权主义_哈耶克第七章因果断言.md

## 总体因果图

- 对经济活动的集中控制（中央计划） → 极权主义与个人自由的丧失
- 计划当局对生产的控制 → 对消费和私人生活的有效控制
- 以非经济激励（公开表彰、特权、实物分配等）取代金钱报酬 → 个人选择权的丧失与权威控制的增强
- 集中计划代替个人决策 → 个人不再能决定自己认为重要或次要的边际需要
- 计划当局对职业选择、行业进入和报酬条件的控制 → 职业自由的丧失和个人沦为工具
- 对“潜在丰裕”的虚幻信念（认为不存在经济问题、无需选择） → 支持并走向中央计划与极权主义
