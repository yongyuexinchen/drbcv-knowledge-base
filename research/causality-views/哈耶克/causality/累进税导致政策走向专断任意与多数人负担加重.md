# 累进税导致政策走向专断任意与多数人负担加重

> **领域**：宏观经济学、政治哲学　|　**来源**：哈耶克_chapter_84_part_01_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实行累进税（作为整体税制的累进） |
| **DV（因变量）** | 政策走向专断任意，且最终多数人（中产及以下）负担加重 |
| **Chain（传导链）** | 累进税缺乏客观标准，支持理由可无限延伸，导致税率不断攀升 → 高税率主要影响高收入阶层，但高收入阶层税收贡献占总税收比例很小 → 由于民主政体中多数选民为中等收入群体，累进税实际使该群体税负相对较轻，而最贫困和最富裕群体税负较重 → 通货膨胀使货币收入上升，多数人进入更高税率等级，成为歧视性税率的牺牲品 → 最终累进税成为多数对少数（富人）的歧视工具，政策失去原则约束，走向专断任意 |
| **Lag（时滞）** | 一代人（约30年）内税率从低累进升至惩罚性水平（如英国从8.25%升至97.5%） |
| **Threshold（临界值）** | 无明确阈值，累进税一旦实施，税率可无限上升直至没收性税率 |
| **前提与约束（Premises）** | 民主政体下，多数群体有权力通过税收政策影响少数群体；累进税作为整体税制，而非仅用于平衡间接税的个别税种；存在通货膨胀，使名义收入上升 |
| **Falsification（证伪条件）** | 如果存在证据表明累进税在长期内保持适度且未导致税率大幅上升，或累进税显著减轻最贫困阶层负担且未加重多数人负担，则该断言可被推翻 |
| **Data（定量佐证）** | 英国1936-37年：年收入100英镑家庭总税负18%，350英镑家庭11%，1000英镑家庭19%；美国1956年累进税贡献占个人所得税17%，联邦税收8.5%；英国附加税收入仅占公共收入2.5% |
| **Conflicts（观点冲突）** | 与支持累进税作为公平再分配工具的观点冲突（如马克思、恩格斯主张累进税） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 累进税如同一个无刹车的斜坡，一旦开始下滑，速度会越来越快，最终无法控制，且最初受益者可能后来成为受害者。

### 🔗 文字版因果链

1. 累进税缺乏客观标准，支持理由可无限延伸，导致税率不断攀升
2. 高税率主要影响高收入阶层，但高收入阶层税收贡献占总税收比例很小
3. 由于民主政体中多数选民为中等收入群体，累进税实际使该群体税负相对较轻，而最贫困和最富裕群体税负较重
4. 通货膨胀使货币收入上升，多数人进入更高税率等级，成为歧视性税率的牺牲品
5. 最终累进税成为多数对少数（富人）的歧视工具，政策失去原则约束，走向专断任意
