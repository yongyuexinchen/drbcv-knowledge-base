# 计划经济因无知与产权缺失导致资源配置无效率

> **领域**：宏观经济学　|　**来源**：哈耶克_chapter_61_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划经济（政府集中计划配置资源） |
| **DV（因变量）** | 资源配置无效率 |
| **Chain（传导链）** | 政府官员或官僚无法掌握分散在无数个人头脑中的全部知识 → 缺乏明确界定的产权，导致经济计算无法进行 → 无法进行有效的经济计算，资源配置偏离最优 → 最终导致资源配置无效率 |
| **Lag（时滞）** | 即时显现，但长期累积恶化 |
| **Threshold（临界值）** | 当计划范围超出单一官员或官僚的知识能力时，无效率必然发生 |
| **前提与约束（Premises）** | 知识分散在无数个人中，无法被集中收集；缺乏明确界定的产权；计划经济的范围涉及整个社会 |
| **Falsification（证伪条件）** | 若存在一个计划经济案例，其资源配置效率高于市场经济，且能持续运行，则可推翻此断言 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持计划经济的理论（如兰格市场社会主义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同让一个人独自规划整个城市的交通，他无法知道每个司机的实时意图，必然导致拥堵和混乱。

### 🔗 文字版因果链

1. 政府官员或官僚无法掌握分散在无数个人头脑中的全部知识
2. 缺乏明确界定的产权，导致经济计算无法进行
3. 无法进行有效的经济计算，资源配置偏离最优
4. 最终导致资源配置无效率
