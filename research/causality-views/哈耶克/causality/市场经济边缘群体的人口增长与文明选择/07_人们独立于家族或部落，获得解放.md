# 人们独立于家族或部落，获得解放

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第7块/15块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本主义采用从生产中获取收入的新方式 |
| **DV（因变量）** | 人们独立于家族或部落，获得解放 |
| **Chain（传导链）** | 资本主义提供个人收入来源，不依赖家族或部落 → 个人因此获得经济独立 → 独立使人们解放，包括后代 → 但工会垄断可能阻碍某些人利用此机会 |
| **Lag（时滞）** | 短期至中期（个人获得收入后立即独立） |
| **Threshold（临界值）** | 无明确阈值，但需要存在就业机会 |
| **前提与约束（Premises）** | 资本主义提供非家族依赖的收入方式；工会不垄断就业机会；个人愿意参与市场 |
| **Falsification（证伪条件）** | 如果资本主义下个人仍依赖家族或部落，或工会完全阻止独立，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为资本主义加剧家庭依赖或部落束缚的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同年轻人通过工作获得工资，不再依赖父母经济支持

### 🔗 文字版因果链

1. 资本主义提供个人收入来源，不依赖家族或部落
2. 个人因此获得经济独立
3. 独立使人们解放，包括后代
4. 但工会垄断可能阻碍某些人利用此机会
