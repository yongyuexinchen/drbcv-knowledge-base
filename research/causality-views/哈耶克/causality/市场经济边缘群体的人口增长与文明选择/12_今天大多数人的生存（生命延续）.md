# 今天大多数人的生存（生命延续）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第12块/15块）

## 因果断言 12

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场秩序的存在 |
| **DV（因变量）** | 今天大多数人的生存（生命延续） |
| **Chain（传导链）** | 市场秩序提供生存条件（食物、工作等） → 大多数人依赖市场秩序生存 → 如果市场秩序崩溃，人口将减少到无法维持文明 → 因此，市场秩序是生命延续的必要条件 |
| **Lag（时滞）** | 即时（生存依赖持续） |
| **Threshold（临界值）** | 无明确阈值，但需要市场秩序有效运行 |
| **前提与约束（Premises）** | 市场秩序提供基本生存资源；人口规模依赖市场秩序；没有替代秩序能维持当前人口 |
| **Falsification（证伪条件）** | 如果市场秩序崩溃但人口生存未受影响，或替代秩序能维持人口，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为非市场秩序（如计划经济）能更好维持生存的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同现代城市依赖电网，停电则生活瘫痪

### 🔗 文字版因果链

1. 市场秩序提供生存条件（食物、工作等）
2. 大多数人依赖市场秩序生存
3. 如果市场秩序崩溃，人口将减少到无法维持文明
4. 因此，市场秩序是生命延续的必要条件
