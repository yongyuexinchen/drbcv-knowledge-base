# 人类生命总体风险降低（通过牺牲少数人）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第10块/15块）

## 因果断言 10

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 生命核算（在拯救更多人和更少人之间选择） |
| **DV（因变量）** | 人类生命总体风险降低（通过牺牲少数人） |
| **Chain（传导链）** | 在决策中，未知生命被作为单位计算 → 为避免别处成本，不采取最大限度减少致命事故的措施 → 例如，应急救治原则：牺牲一人以救三人 → 因此，总体生命风险降低 |
| **Lag（时滞）** | 即时（决策立即影响） |
| **Threshold（临界值）** | 无明确阈值，但需在拯救人数上比较 |
| **前提与约束（Premises）** | 资源有限，无法拯救所有人；生命价值可比较（如医生比病人更重要）；决策者愿意进行生命核算 |
| **Falsification（证伪条件）** | 如果生命核算导致总体风险增加或更多人死亡，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为每个生命绝对平等的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同医生在灾难现场优先救治存活率高的伤员，以拯救更多生命

### 🔗 文字版因果链

1. 在决策中，未知生命被作为单位计算
2. 为避免别处成本，不采取最大限度减少致命事故的措施
3. 例如，应急救治原则：牺牲一人以救三人
4. 因此，总体生命风险降低
