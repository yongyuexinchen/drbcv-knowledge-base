# 哪种规则体系占优势

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第5块/15块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 依赖不同规则体系的人数（核心群体遵循的体系） |
| **DV（因变量）** | 哪种规则体系占优势 |
| **Chain（传导链）** | 核心群体遵循特定规则体系 → 越来越多的人聚集在核心群体周围，分享总产品收益 → 依赖该体系的人数增加，使其占优势 → 即使多数人未完全接受，核心群体的规则仍占主导 |
| **Lag（时滞）** | 长期（人口聚集和体系扩散需要时间） |
| **Threshold（临界值）** | 无明确阈值，但核心群体需足够大以吸引更多人 |
| **前提与约束（Premises）** | 核心群体能提供收益；人们愿意聚集并分享收益；规则体系具有适应性 |
| **Falsification（证伪条件）** | 如果核心群体人数增加但体系未占优势，或相反，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为多数人选择决定体系的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一种语言因核心使用者的影响力而成为通用语言，即使多数人非母语者

### 🔗 文字版因果链

1. 核心群体遵循特定规则体系
2. 越来越多的人聚集在核心群体周围，分享总产品收益
3. 依赖该体系的人数增加，使其占优势
4. 即使多数人未完全接受，核心群体的规则仍占主导
