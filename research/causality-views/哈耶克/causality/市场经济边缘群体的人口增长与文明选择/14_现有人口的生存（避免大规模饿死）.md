# 现有人口的生存（避免大规模饿死）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第14块/15块）

## 因果断言 14

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵守相同的普遍原则（如私有财产制度） |
| **DV（因变量）** | 现有人口的生存（避免大规模饿死） |
| **Chain（传导链）** | 普遍原则确保市场秩序运行 → 市场秩序维持现有人口生存 → 如果摧毁这些原则，人口将饿死 → 因此，有责任反对摧毁这些原则的信条 |
| **Lag（时滞）** | 长期（原则破坏后影响逐渐显现） |
| **Threshold（临界值）** | 无明确阈值，但需要原则被普遍遵守 |
| **前提与约束（Premises）** | 普遍原则是市场秩序的基础；市场秩序是生存的必要条件；存在威胁原则的信条 |
| **Falsification（证伪条件）** | 如果摧毁普遍原则但人口生存未受影响，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为私有财产制度可被替代的观点冲突 |
| **Confidence（确信度）** | well-established |
