# 取代静态的亚里士多德观点，形成进化观的突破

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 亚当·斯密和亚当·弗格森对自发秩序和选择进化观点的系统运用 |
| **DV（因变量）** | 取代静态的亚里士多德观点，形成进化观的突破 |
| **Chain（传导链）** | 斯密和弗格森系统运用自发秩序和进化概念 → 这些概念逐渐取代静态的亚里士多德观点 → 形成进化观的突破，影响后续多个学科 |
| **Lag（时滞）** | 数十年至数百年（从18世纪到19世纪达尔文突破） |
| **Threshold（临界值）** | 无明确量化阈值 |
| **前提与约束（Premises）** | 自发秩序和选择进化概念在休谟和曼德维尔著作中已有雏形；斯密和弗格森的工作是系统运用的关键 |
| **Falsification（证伪条件）** | 若能证明斯密和弗格森之前已有更系统的运用，或进化观并非由他们取代亚里士多德观点，则断言不成立 |

### 🧩 生活类比

> 如同一个种子在休谟和曼德维尔那里萌芽，斯密和弗格森将其培育成大树，最终取代了旧有的静态森林。

### 🔗 文字版因果链

1. 斯密和弗格森系统运用自发秩序和进化概念
