# 阻碍了对价格指导作用的理解，导致边际革命产生爆炸性效果

> 属于因果簇：[[自发秩序与进化观的形成及其影响]]（第9块/18块）

## 因果断言 9

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 约翰·穆勒的教条主义信念（价值规律无需再澄清） |
| **DV（因变量）** | 阻碍了对价格指导作用的理解，导致边际革命产生爆炸性效果 |
| **Chain（传导链）** | 穆勒持有教条主义信念，认为价值规律无需再澄清 → 这一信念阻碍了他对价格指导作用的理解 → 20年后边际革命到来时，产生爆炸性效果 |
| **Lag（时滞）** | 20年（从穆勒1848年出版到边际革命1870年代） |
| **Threshold（临界值）** | 无明确量化阈值 |
| **前提与约束（Premises）** | 穆勒的信念长期影响经济学界；边际革命是对穆勒教条的反动 |
| **Falsification（证伪条件）** | 若能证明穆勒的信念未阻碍理解，或边际革命并非因穆勒而爆炸性，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与边际革命的观点冲突 |
| **Confidence（确信度）** | well-established |
