# 人类合作中不断扩展的秩序（文明 资本主义）的起源与维持

> 属于因果簇：[[哈耶克对社会主义与扩展秩序的因果断言]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 群体无意中遵守某些传统道德做法 |
| **DV（因变量）** | 人类合作中不断扩展的秩序（文明/资本主义）的起源与维持 |
| **Chain（传导链）** | 群体无意遵守某些传统道德做法 → 这些做法使其共同扩大利用一切有价值信息的机会 → 人口和财富相对增加 → 通过进化选择过程，这些做法迅速传播 → 形成并维持扩展秩序（文明） |
| **Lag（时滞）** | 长期，跨代际的进化过程 |
| **Threshold（临界值）** | 人口和财富的相对增加足以让该群体在竞争中胜出 |
| **前提与约束（Premises）** | 这些道德传统并非人类设计或意图的结果；群体通常不理解其含义，有时甚至不喜欢这些做法；存在群体间的选择竞争 |
| **Falsification（证伪条件）** | 如果能够证明扩展秩序是某个人或组织有意设计出来的，且无需遵守非理性的道德传统就能维持文明，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同蚂蚁社群并非每只蚂蚁规划而成，但通过遵循简单规则却形成复杂高效的巢穴结构

### 🔗 文字版因果链

1. 群体无意遵守某些传统道德做法
2. 这些做法使其共同扩大利用一切有价值信息的机会
3. 人口和财富相对增加
4. 通过进化选择过程，这些做法迅速传播
5. 形成并维持扩展秩序（文明）
