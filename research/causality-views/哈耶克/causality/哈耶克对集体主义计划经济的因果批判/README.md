## 总体因果图

- 集体主义计划经济（中央计划） → 通往奴役之路（极权主义）
- 传统道德（包括财产、公正、家庭等） → 扩展秩序（文明）的存续与繁荣
- 知识分子对理性主义的推崇（特别是社会主义思想） → 社会对传统价值的破坏和向计划经济的转变
