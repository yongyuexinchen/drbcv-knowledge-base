## 总体因果图

- 私有财产制度（竞争制度） → 穷人致富的可能性（个人通过自身努力致富的机会）
- 法治（the Rule of Law） → 真正的自由
- 自由放任（laissez faire）理念 → 自由与法治事业（的损害）
- 民主（作为手段） → 自由与国内和平（的保障）
