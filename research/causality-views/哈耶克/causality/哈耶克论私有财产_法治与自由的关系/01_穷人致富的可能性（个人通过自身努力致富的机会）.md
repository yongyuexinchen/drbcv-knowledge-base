# 穷人致富的可能性（个人通过自身努力致富的机会）

> 属于因果簇：[[哈耶克论私有财产、法治与自由的关系]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 私有财产制度（竞争制度） |
| **DV（因变量）** | 穷人致富的可能性（个人通过自身努力致富的机会） |
| **Chain（传导链）** | 私有财产制度确立个人对劳动成果的支配权 → 竞争制度允许个人自由参与市场交换 → 个人凭自身努力而非掌权者恩惠获取财富 → 穷人致富的可能性虽低于遗产继承者，但依然存在且不受权力阻挠 |
| **Lag（时滞）** | 长期（代际累积效应） |
| **Threshold（临界值）** | 无明确量化阈值，但需存在竞争性市场制度 |
| **前提与约束（Premises）** | 竞争制度有效运行；不存在掌权者任意阻挠个人致富的干预；法律框架保障财产权 |
| **Falsification（证伪条件）** | 若在竞争制度下穷人致富的可能性为零或低于非竞争制度，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张消灭私有财产以实现收入平等的进步人士观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同赛跑，虽然起跑线不同，但规则公平，穷人也能凭努力冲刺，而非被裁判随意取消资格。

### 🔗 文字版因果链

1. 私有财产制度确立个人对劳动成果的支配权
2. 竞争制度允许个人自由参与市场交换
3. 个人凭自身努力而非掌权者恩惠获取财富
4. 穷人致富的可能性虽低于遗产继承者，但依然存在且不受权力阻挠
