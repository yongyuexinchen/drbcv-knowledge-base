## 主传导链

```text
知识分散于无数个体 → 中央计划者无法收集全部知识 → 中央计划经济必然低效 → 资源配置扭曲、生产率下降 → 政府为执行计划强化强制力 → 个人自由丧失 → 通往奴役之路（极权主义；最坏者当政）
    ↳ 关键时滞：错误观念被立法采纳约需 20–30 年（思想→政策滞后）

传统道德规则（私有财产、诚信、契约、交换、竞争） → 通过学习而非本能传承 → 基于价格机制的分工与协作 → 扩展秩序/文明形成与扩张 → 人口增长与生产率提高
    ↳ 关键时滞：文化进化是数百年以上的长期过程；人口密度与分工存在正反馈时滞（每轮需一代以上）

法治（一般性、确定性、平等性法律规则约束行政权力） → 个人免于专断强制 → 个人自由 → 个体利用分散知识、尝试新目标 → 文明创造力与进步
    ↳ 关键时滞：法治理想从舆论承认到政策完全实现约需 20–30 年

政府干预（福利国家、社会保障、累进税、住房补贴、农业政策、工会特权、垄断许可） → 价格信号扭曲 + 激励机制扭曲 + 行政裁量扩张 → 经济效率下降 + 个人依赖与依附 → 分配正义/功绩报酬取代市场报酬 → 选择自由被侵蚀 → 社会主义/集体主义经济计划 → 极权主义
```

## 不变式

- 知识分散于无数个体，任何中央计划者都无法集成全部情境知识。
- 自发秩序（语言、道德、市场）通过遵循抽象规则演化而成，不可被理性全盘设计。
- 法治＝一般性、确定性、平等性的规则之治，是自由社会的制度前提。
- 传统道德（私有财产、诚信、契约、交换）是扩展秩序的文化基础。
- 自由是文明进化的必要条件；强制通过缩小试错空间降低文明进步速度。
