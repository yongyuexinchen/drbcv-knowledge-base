## 主传导链

```
资产价格暴跌（地产/股票泡沫破裂）
        │
        ▼
企业资产负债表受损（资产<负债，资不抵债但未破产）
        │
        ▼
企业目标从"利润最大化"转为"负债最小化"（无视零利率拒绝借贷）
        │
        ▼
集体偿债 → 合成谬误 → 总需求萎缩 → 收入下降
        │
        ├──→ 恶性通缩循环（价格↓→实际债务↑→更努力偿债）
        │
        └──→ 流动性陷阱（问题在借贷方不愿借，不是放贷方不愿贷）
              │
              ▼
货币政策失效（零利率也无效）→ 财政政策必要（政府借贷填补缺口）
              │
              ▼
政府支出 → 货币供应回升 → 经济复苏 → 税收增长（良性循环）
```

## 不变式

1. **企业目标函数会切换**：正常期利润最大化，衰退期负债最小化——同一个变量（企业行为）两个世界
2. **合成谬误是放大器**：个体理性（偿债）在宏观层面是非理性（通缩）
3. **货币 vs 财政的分工**：资产负债表衰退中货币失效、财政必行——与明斯基"大政府"呼应

## 跨作者交叉点

- **与达里奥**：达里奥说"去杠杆有四种方式"，辜朝明解释了**为什么私人部门去杠杆必然伴随财政扩张**（否则通缩螺旋）——两人的"美丽去杠杆"和"财政必要"是同一机制的两面
- **与明斯基**：明斯基说"稳定孕育不稳定"（信贷扩张期），辜朝明说"崩溃后企业拒贷"——**信贷周期的上行由明斯基描述，下行由辜朝明描述，合起来才是完整周期**
