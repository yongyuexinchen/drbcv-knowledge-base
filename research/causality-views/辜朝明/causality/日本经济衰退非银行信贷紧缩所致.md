# 日本经济衰退非银行信贷紧缩所致

> **领域**：宏观经济学　|　**来源**：chapter_09.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 日本银行体系存在不良贷款问题（银行放贷能力低下） |
| **DV（因变量）** | 日本企业无法获得足够信贷，导致经济衰退持续 |
| **Chain（传导链）** | 银行因不良资产和呆坏账而减少对企业放贷 → 企业因缺乏信贷而无法进行投资和生产活动 → 投资和生产下降导致经济衰退持续 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 银行不良贷款率显著上升，导致银行资本充足率低于监管要求 |
| **前提与约束（Premises）** | 企业缺乏替代融资渠道（如债券市场或外资银行）；银行是唯一或主要的信贷供给方；信贷需求方多于供给方，导致利率上升 |
| **Falsification（证伪条件）** | 如果观察到企业债券发行量显著增加、外资银行放贷大幅扩张、或贷款利率显著上升，则该断言不成立。实际数据中这三者均未出现，因此该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像说一个水管堵了导致下游没水，但如果下游还有多个其他水源（债券市场、外资银行）都在正常供水甚至增加供水，那说明水管堵塞不是缺水的真正原因。

### 🔗 文字版因果链

1. 银行因不良资产和呆坏账而减少对企业放贷
2. 企业因缺乏信贷而无法进行投资和生产活动
3. 投资和生产下降导致经济衰退持续
