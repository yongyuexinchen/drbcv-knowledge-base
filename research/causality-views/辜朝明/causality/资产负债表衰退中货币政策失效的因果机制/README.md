# 资产负债表衰退中货币政策失效的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：资产负债表衰退中货币政策失效的因果机制.md

## 总体因果图

- 银行借贷人破产导致银行资不抵债 → 银行危机持续且央行注资无效
- 私营部门（86.4%企业）忙于削减债务（资产负债表衰退） → 整体经济陷入恶性通货紧缩且货币政策（推绳子）失效
- 金本位制度（或对金本位的担忧） → 美联储未增加准备金（货币政策紧缩）
