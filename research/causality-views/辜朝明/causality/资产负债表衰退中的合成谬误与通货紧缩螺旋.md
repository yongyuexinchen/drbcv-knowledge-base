# 资产负债表衰退中的合成谬误与通货紧缩螺旋

> **领域**：宏观经济学　|　**来源**：chapter_13.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全国性资产价格下跌导致企业债务遗留，所有企业同时转向债务偿还（负债最小化） |
| **DV（因变量）** | 经济陷入恶性循环通货紧缩（资产负债表衰退） |
| **Chain（传导链）** | 资产价格下跌使企业资产价值低于债务，形成债务遗留 → 企业为修复资产负债表而集体偿债，减少借贷 → 无人借贷导致储蓄无法转化为投资，总需求下降 → 收入下降，消费减少，进一步减少储蓄和投资 → 经济持续萎缩，资产价格进一步下跌，加剧偿债压力 → 形成通货紧缩螺旋，经济陷入长期衰退 |
| **Lag（时滞）** | 中期（数月到数年，日本持续15年） |
| **Threshold（临界值）** | 当企业债务净偿付额和个人净储蓄额之和导致总需求缩减超过GDP的20%时，衰退显著 |
| **前提与约束（Premises）** | 企业以负债最小化为目标而非利润最大化；利率接近零仍无法刺激借贷；银行无法找到借贷方，资金滞留银行系统；经济中存在大量债务遗留（资产负债表问题） |
| **Falsification（证伪条件）** | 如果企业即使有债务遗留仍继续借贷投资，或者零利率能有效刺激借贷，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同所有观众同时踮脚看比赛，虽然个人看得更清楚，但整体视野并未改善，反而导致集体疲劳；企业集体偿债看似理性，却导致经济整体萎缩。

### 🔗 文字版因果链

1. 资产价格下跌使企业资产价值低于债务，形成债务遗留
2. 企业为修复资产负债表而集体偿债，减少借贷
3. 无人借贷导致储蓄无法转化为投资，总需求下降
4. 收入下降，消费减少，进一步减少储蓄和投资
5. 经济持续萎缩，资产价格进一步下跌，加剧偿债压力
6. 形成通货紧缩螺旋，经济陷入长期衰退
