# 哲学/思想类知识吸收流水线 v2（认知压缩型）

> 2026-08-05 用户定稿｜取代"读书→卡片"存储型流程
> 核心目标：建立跨学科认知模型，快速投入表达和实践（视频/判断/写作）

## 总原则（最高优先级）

```
不要试图保存整本书。
目标不是成为这本书的搬运工。
目标是建立一个能够调用的思想模型。
一本500页哲学书，最终应该压缩成：
一个作者，一个时代，一个问题，一个答案，
一张概念地图，一场思想战争。
```

**为什么 v2**：输入→输出转化率 > 知识库完整度。制作视频本身就是第二次阅读（Hermes提炼→用户听/改/剪→评论纠错，三次闭环比看40张卡效率高一个量级）。

**两条路线并存**：
- 课程/技术类（计组/计网/FastAPI）→ DRBCV 卡片（30-80 张，学习考试用）
- 哲学/思想类（德勒兹/哈耶克/弗洛伊德）→ 本流程压缩（5-10 张，表达输出用）
- **但压缩 ≠ 丢卡片**：DRBCV/CAO 卡片保留为**全量底账**（对账用，防遗漏），v2 压缩卡是**调用层**（表达用）。**对账机制**：压缩卡里的每个概念/论证/反方，必须能在底账卡片里找到对应——压缩卡=索引，卡片=详情，缺卡即补。产出顺序：先底账后压缩，两者互相引用

## 总流程（15 步）

```
原书 → 作者画像 → 时代坐标 → 人生冲突 → 核心问题(一句话)
→ 核心命题(一句话) → 概念地图(5-10个) → 论证链(前提→结论)
→ 攻击对象 → 反方最强反驳 → 现实验证(个人/社会/技术)
→ 作者局限 → 知识压缩卡(5-10张) → 视频寓言 → 语音复盘 → 评论纠错
```

## 1. 作者画像（先看人，不先看书）
思想是人在特定时代解决自己问题的方式。
```
作者/出生/时代/阶级位置/职业/代表身份/人生重大事件
影响最大的3个经历：发生什么 → 造成什么心理问题 → 如何影响思想
```
例：德勒兹——纳粹占领巴黎 → 看到权力机器碾压个体 → 终身关注"权力如何让人主动服从"
例：瓜塔里——精神病院工作 → 看到病人痛苦不是个人问题 → 反对把人的问题心理化

## 2. 时代坐标
为什么这个思想会在这个时间出现？政治/经济/技术环境、主流思想、正在发生的危机、作者回应的问题。
例：《反俄狄浦斯》1972 → 1968五月风暴失败 → 为什么人民没有推翻压迫？为什么他们甚至欲望自己的奴役？

## 3. 人生冲突
作者内心/生活的核心张力（并入作者画像）。

## 4. 核心问题（必须一句话）
- 弗洛伊德：为什么人的欲望会产生痛苦？
- 马克思：为什么创造财富的人越来越贫困？
- 德勒兹：为什么追求自由的欲望会被权力吸收？

## 5. 核心命题（一句，普通人能听懂）
- 弗洛伊德：人的欲望来自缺失。
- 德勒兹：人不是因为缺少才欲望，而是在欲望中创造。
- 马克思：社会关系决定人的处境，而不是孤立个人决定社会。

## 6. 概念地图（5-10 个核心概念，不做几十张卡）
每个：名称/原定义/白话解释/生活例子/和其他概念关系。关系必须画链：欲望机器→生产→社会机器→资本机器。

## 7. 论证链（最重要：记推理，不记观点）
```
前提A：欲望不是缺失
前提B：社会可以组织欲望
所以：统治不是简单压迫
而是：让人主动欲望某种秩序
结论：革命必须改变欲望生产方式
```

## 8. 攻击对象（所有思想都是在打别人）
作者攻击谁/核心批判/为什么攻击/攻击有效在哪里/攻击漏洞。
例：德勒兹攻击精神分析——把社会问题缩小成家庭问题——漏洞：是否过度低估心理结构？

## 9. 反方最强反驳（找最强敌人，不找弱鸡靶子）
反方/为什么反/最强攻击/如果成立作者失败在哪里。
例：齐泽克——你说释放欲望，但资本主义最擅长释放欲望——你的革命可能成为消费主义燃料。

## 10. 现实验证（今天为什么还值得讲）
个人（手机成瘾）/ 社会（消费主义）/ 技术（算法推荐）三层级。

## 11. 作者局限（必须加，避免变传教）
作者解决了什么/没解决什么/历史证明哪里正确/哪里失败。
例：德勒兹——成功：解释资本如何吸收反抗；失败：没有清晰政治组织方案。

## 12. 知识压缩卡（一本书最终产物，5-10 张，每张 300-600 字）
作者/作品/一句话/解决的问题/核心概念/论证链/攻击对象/最大反驳/现实意义/视频意象

## 13. 视频寓言
知识模型→寓言化（抽象→童话意象）；理论冲突→角色冲突（反方→第二个声音）。
例：欲望机器（欲望不是缺失）→ 寓言：永远告诉孩子"你缺糖"的机器 → 现实：推荐算法

## 14. 语音复盘吸收（第二次阅读）
用户听语音、改稿、剪视频。Hermes 等反馈迭代（v1→v10），纠错沉淀进技能。

## 15. 评论反馈纠错（第三次阅读）
发布后评论区质疑=第三次阅读，收集强反驳反哺压缩卡和后续集。

## 验收标准
- [ ] 核心问题/核心命题各一句话且普通人能听懂
- [ ] 概念地图 5-10 个
- [ ] 论证链完整（前提→结论，非观点罗列）
- [ ] 反方是最强反驳
- [ ] 作者局限栏存在（不传教）
- [ ] 知识压缩卡 ≤10 张
- [ ] 视频寓言三步转换齐全

## 陷阱
- 不要把 v2 用在课程/技术书（计组拆卡流程不动）
- 论证链≠观点列表；作者局限必须具体；反方必须最强
- 用户每次纠错 → 及时 patch 进技能，形成记忆闭环
