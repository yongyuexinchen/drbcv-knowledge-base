# 付鹏宏观因果分析：供应链错配与美联储政策风险

> **领域**：宏观经济学、大宗商品市场　|　**来源**：fupeng_2021_gold_end.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 疫情导致的供应链错配 |
| **DV（因变量）** | 大宗商品价格上涨（尤其铜、铁矿石等） |
| **Chain（传导链）** | 疫情冲击导致供应中断，上游投资周期长，供应恢复慢 → 欧美财政补贴刺激总需求率先恢复，需求曲线快速回升 → 供应曲线跟不上需求曲线，形成供需缺口 → 上游行业经历去产能和垄断整合，供应弹性降低 → 库存低位、流动性过剩，投机资金放大价格波动 → 大宗商品价格大幅上涨 |
| **Lag（时滞）** | 数月到一年（从疫情冲击到价格显著上涨） |
| **Threshold（临界值）** | 铜价8000美元/吨以上，价格脱离基本面支撑 |
| **前提与约束（Premises）** | 全球疫情持续，供应恢复受阻；欧美维持宽松财政货币政策；上游行业存在垄断和投资不足；库存处于低位 |
| **Falsification（证伪条件）** | 如果疫情缓解后供应快速恢复，价格大幅回落，则供应链错配导致涨价的因果链被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像水管堵塞，水龙头开大（需求）但出口小（供应），水压（价格）自然升高

### 🔗 文字版因果链

1. 疫情冲击导致供应中断，上游投资周期长，供应恢复慢
2. 欧美财政补贴刺激总需求率先恢复，需求曲线快速回升
3. 供应曲线跟不上需求曲线，形成供需缺口
4. 上游行业经历去产能和垄断整合，供应弹性降低
5. 库存低位、流动性过剩，投机资金放大价格波动
6. 大宗商品价格大幅上涨

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美联储提前收紧流动性（加息缩表预期） |
| **DV（因变量）** | 黄金价格见顶回落，市场波动率上升 |
| **Chain（传导链）** | 美联储释放收紧信号，市场预期实际利率上升 → 黄金作为实际利率的敏感资产，价格提前反应 → 中长端利率上升，黄金持有成本增加 → 黄金价格从高点回落，波动率放大 |
| **Lag（时滞）** | 预期先行，实际政策落地时黄金可能已见底 |
| **Threshold（临界值）** | 美联储实际开始加息缩表时，黄金可能已跌到底部 |
| **前提与约束（Premises）** | 美联储政策转向快于市场预期；实际利率上升；通胀预期未能持续 |
| **Falsification（证伪条件）** | 如果美联储持续宽松，实际利率下降，黄金价格创新高，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像天气预报说台风要来，人们提前囤货，等台风真正来时，抢购潮已过

### 🔗 文字版因果链

1. 美联储释放收紧信号，市场预期实际利率上升
2. 黄金作为实际利率的敏感资产，价格提前反应
3. 中长端利率上升，黄金持有成本增加
4. 黄金价格从高点回落，波动率放大

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 商品价格见顶信号（结构转弱） |
| **DV（因变量）** | 周期股先于商品价格下跌 |
| **Chain（传导链）** | 商品价格高位横盘，但远期结构转弱（如backwardation收窄） → 交易员感知到上涨动力减弱，率先平仓权益头寸 → 周期股因盈利预期下降而下跌 → 商品价格因基本面支撑仍维持高位，但股票已先行调整 |
| **Lag（时滞）** | 数周到数月 |
| **Threshold（临界值）** | 商品价格停止上涨或结构转弱时，股票开始下跌 |
| **前提与约束（Premises）** | 市场参与者对商品价格见顶有预期；权益市场反应快于商品市场；基本面仍支撑商品价格 |
| **Falsification（证伪条件）** | 如果商品价格继续上涨且股票同步上涨，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像赛跑，股票是短跑选手先冲线，商品是长跑选手后停步

### 🔗 文字版因果链

1. 商品价格高位横盘，但远期结构转弱（如backwardation收窄）
2. 交易员感知到上涨动力减弱，率先平仓权益头寸
3. 周期股因盈利预期下降而下跌
4. 商品价格因基本面支撑仍维持高位，但股票已先行调整
