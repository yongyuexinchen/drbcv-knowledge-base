# 全球化逆转与资产定价逻辑变化

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球化逆转（逆全球化） |
| **DV（因变量）** | 资产定价逻辑改变（政治因子放大，定性影响定价） |
| **Chain（传导链）** | 全球化逆转导致政治要素排在前头 → 政治要素阻碍资本、货物和经济的流动 → 资产定性（如是否按市场经济定价）发生变化 → 定性变化导致定价逻辑改变 |
| **Lag（时滞）** | 5-10年（中长期） |
| **Threshold（临界值）** | 全球化进入分持阶段，两帮势力斗争激烈 |
| **前提与约束（Premises）** | 全球化发展至历史必然的转折点；政治因素在资产定价中的权重显著增加；适用于中长期投资框架 |
| **Falsification（证伪条件）** | 若全球化重新加速，或政治因素对资本流动的影响减弱，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像婚姻破裂后，夫妻双方不再基于感情和共同利益分配财产，而是基于法律和政治立场，导致财产分割逻辑完全改变。

### 🔗 文字版因果链

1. 全球化逆转导致政治要素排在前头
2. 政治要素阻碍资本、货物和经济的流动
3. 资产定性（如是否按市场经济定价）发生变化
4. 定性变化导致定价逻辑改变

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 央行被动性驱动利率变动（非主动） |
| **DV（因变量）** | 市场波动更剧烈且持续时间更长 |
| **Chain（传导链）** | 深层次社会、政治、国家关系等大要素作用于短端通胀偏离 → 央行被动应对，无法完全掌控变量 → 被动性导致政策周期和维度扩大 → 市场波动加剧且持续时间延长 |
| **Lag（时滞）** | 周期维度较长（可能数年） |
| **Threshold（临界值）** | 当通胀偏离由非经济因素驱动时 |
| **前提与约束（Premises）** | 央行面临被动性约束；全球格局处于巨变节点 |
| **Falsification（证伪条件）** | 若央行能主动控制利率且市场波动迅速平息，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人被推着走，无法控制方向，只能被动应对，导致路程更长更颠簸。

### 🔗 文字版因果链

1. 深层次社会、政治、国家关系等大要素作用于短端通胀偏离
2. 央行被动应对，无法完全掌控变量
3. 被动性导致政策周期和维度扩大
4. 市场波动加剧且持续时间延长

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美联储加息（高温80度） |
| **DV（因变量）** | 经济层面（房子、就业、居民储蓄）受损 |
| **Chain（传导链）** | 美联储维持高利率（约4%-4.5%） → 利率通过抑制总需求传导至经济 → 传导需要时间（约两个季度） → 经济层面开始出现压力 |
| **Lag（时滞）** | 约两个季度 |
| **Threshold（临界值）** | 利率维持在4%-4.5%并持续两到三个季度 |
| **前提与约束（Premises）** | 利率不会高到导致严重衰退（80度而非100度）；持续时间是关键变量 |
| **Falsification（证伪条件）** | 若高利率持续但经济未受影响，或利率快速下降，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 温水煮青蛙：80度水温青蛙能扛，但长时间高温最终会煮熟。

### 🔗 文字版因果链

1. 美联储维持高利率（约4%-4.5%）
2. 利率通过抑制总需求传导至经济
3. 传导需要时间（约两个季度）
4. 经济层面开始出现压力

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国指数编制问题（权重稀释） |
| **DV（因变量）** | 上证指数不能反映经济真实表现 |
| **Chain（传导链）** | 大量权重为国有企业，不可替代 → 新市值企业只能稀释指数 → 指数无法优胜劣汰 → 指数与经济表现脱节 |
| **Lag（时滞）** | 长期存在 |
| **Threshold（临界值）** | 经济总量增速下滑时 |
| **前提与约束（Premises）** | 指数编制规则不变；经济结构转型 |
| **Falsification（证伪条件）** | 若指数编制改革或经济总量恢复高增长，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一锅汤里加了很多水，即使食材再好，汤的味道也变淡了。

### 🔗 文字版因果链

1. 大量权重为国有企业，不可替代
2. 新市值企业只能稀释指数
3. 指数无法优胜劣汰
4. 指数与经济表现脱节

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政策扶持（远期投资回报） |
| **DV（因变量）** | 特定行业（如新能源）估值提升 |
| **Chain（传导链）** | 国家政策引导和支持特定行业 → 市场形成未来增长预期 → 预期兑付过程中估值提升 → 在低利率环境下估值进一步推高 |
| **Lag（时滞）** | 预期形成后1-3年 |
| **Threshold（临界值）** | 政策明确且利率环境宽松 |
| **前提与约束（Premises）** | 政策持续支持；资金成本低；经济总量增长放缓 |
| **Falsification（证伪条件）** | 若政策转向或利率上升导致估值回落，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像政府扶持的种子企业，在政策雨露和低息贷款下快速成长，但一旦政策变化或资金收紧，成长可能受阻。

### 🔗 文字版因果链

1. 国家政策引导和支持特定行业
2. 市场形成未来增长预期
3. 预期兑付过程中估值提升
4. 在低利率环境下估值进一步推高
