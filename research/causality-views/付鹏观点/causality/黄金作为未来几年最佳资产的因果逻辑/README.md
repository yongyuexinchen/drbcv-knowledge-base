# 黄金作为未来几年最佳资产的因果逻辑（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：黄金作为未来几年最佳资产的因果逻辑.md

## 总体因果图

- 全球分工分配的核心问题长期得不到解决 → 美联储和财政政策无力退出宽松，货币政策失效
- 货币政策失效，利率趴在地板上 → 黄金成为表现最好的资产
- 疫情激化部分国家内部矛盾 → 货币政策进一步扩张，黄金看涨
- 股市结构变化（权重股集中） → 指数上涨但经济表现不佳
