# 资产定价逻辑改变（政治因子放大，定性影响定价）

> 属于因果簇：[[全球化逆转与资产定价逻辑变化]]（第1块/8块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球化逆转（逆全球化） |
| **DV（因变量）** | 资产定价逻辑改变（政治因子放大，定性影响定价） |
| **Chain（传导链）** | 全球化逆转导致政治要素排在前头 → 政治要素阻碍资本、货物和经济的流动 → 资产定性（如是否按市场经济定价）发生变化 → 定性变化导致定价逻辑改变 |
| **Lag（时滞）** | 5-10年（中长期） |
| **Threshold（临界值）** | 全球化进入分持阶段，两帮势力斗争激烈 |
| **前提与约束（Premises）** | 全球化发展至历史必然的转折点；政治因素在资产定价中的权重显著增加；适用于中长期投资框架 |
| **Falsification（证伪条件）** | 若全球化重新加速，或政治因素对资本流动的影响减弱，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像婚姻破裂后，夫妻双方不再基于感情和共同利益分配财产，而是基于法律和政治立场，导致财产分割逻辑完全改变。

### 🔗 文字版因果链

1. 全球化逆转导致政治要素排在前头
2. 政治要素阻碍资本、货物和经济的流动
3. 资产定性（如是否按市场经济定价）发生变化
4. 定性变化导致定价逻辑改变
