# 付鹏宏观因果分析：供应链错配与美联储政策风险（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：付鹏宏观因果分析_供应链错配与美联储政策风险.md

## 总体因果图

- 疫情导致的供应链错配 → 大宗商品价格上涨（尤其铜、铁矿石等）
- 美联储提前收紧流动性（加息缩表预期） → 黄金价格见顶回落，市场波动率上升
- 商品价格见顶信号（结构转弱） → 周期股先于商品价格下跌
