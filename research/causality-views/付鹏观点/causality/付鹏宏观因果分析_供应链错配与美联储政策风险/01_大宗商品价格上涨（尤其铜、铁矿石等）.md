# 大宗商品价格上涨（尤其铜、铁矿石等）

> 属于因果簇：[[付鹏宏观因果分析：供应链错配与美联储政策风险]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 疫情导致的供应链错配 |
| **DV（因变量）** | 大宗商品价格上涨（尤其铜、铁矿石等） |
| **Chain（传导链）** | 疫情冲击导致供应中断，上游投资周期长，供应恢复慢 → 欧美财政补贴刺激总需求率先恢复，需求曲线快速回升 → 供应曲线跟不上需求曲线，形成供需缺口 → 上游行业经历去产能和垄断整合，供应弹性降低 → 库存低位、流动性过剩，投机资金放大价格波动 → 大宗商品价格大幅上涨 |
| **Lag（时滞）** | 数月到一年（从疫情冲击到价格显著上涨） |
| **Threshold（临界值）** | 铜价8000美元/吨以上，价格脱离基本面支撑 |
| **前提与约束（Premises）** | 全球疫情持续，供应恢复受阻；欧美维持宽松财政货币政策；上游行业存在垄断和投资不足；库存处于低位 |
| **Falsification（证伪条件）** | 如果疫情缓解后供应快速恢复，价格大幅回落，则供应链错配导致涨价的因果链被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像水管堵塞，水龙头开大（需求）但出口小（供应），水压（价格）自然升高

### 🔗 文字版因果链

1. 疫情冲击导致供应中断，上游投资周期长，供应恢复慢
2. 欧美财政补贴刺激总需求率先恢复，需求曲线快速回升
3. 供应曲线跟不上需求曲线，形成供需缺口
4. 上游行业经历去产能和垄断整合，供应弹性降低
5. 库存低位、流动性过剩，投机资金放大价格波动
6. 大宗商品价格大幅上涨
