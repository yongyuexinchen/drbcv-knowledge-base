# 重商主义国家干预创造国内贸易与全国性市场（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：重商主义国家干预创造国内贸易与全国性市场.md

## 总体因果图

- 重商主义时期国家干预（打破地方贸易与远程贸易的隔绝，废除地方保护主义） → 全国性市场的形成与国内贸易的创造
- 将劳动力、土地和货币作为虚拟商品纳入市场机制 → 社会毁灭（人的堕落、环境破坏、商业周期性危机）
