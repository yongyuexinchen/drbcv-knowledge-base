# 斯品汉姆兰法令对劳动力市场与古典经济学的因果影响

> **领域**：经济史、政治经济学　|　**来源**：波兰尼_chapter_17_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法令（教区对低工资劳动者的补贴制度） |
| **DV（因变量）** | 劳动者工资被压低至生存水平以下，形成“工资铁律”的假象，并奠定古典经济学自然主义基础 |
| **Chain（传导链）** | 教区补贴补足工人工资与生存收入之间的差额，使雇主可以支付低于生存水平的工资 → 接受教区救济的工人愿意为更低工资工作，使未获救济的勤奋工人无法与之竞争 → 工资被普遍压低，劳动者生活水平无法改善，甚至恶化 → 这种普遍贫困被古典经济学家（马尔萨斯、李嘉图）误读为工资铁律（人口规律与土地报酬递减）作用的证据 → 经济法则被归因于自然（动植物繁殖、土地肥力），而非人类行为，形成自然主义基础 |
| **Lag（时滞）** | 法令实施后数十年（1795年至滑铁卢战役后二十年），贫困化与理论误读长期持续 |
| **Threshold（临界值）** | 当教区补贴使工资低于劳动者维持生存所需的最低水平时，因果链条启动 |
| **前提与约束（Premises）** | 存在竞争性市场经济但缺乏真正的劳动力市场（劳动领域受父爱式规制）；雇主和农场主依赖教区补足工资差额；劳动者接受微薄补贴并愿意降低工资要求；反结社法等其他制度条件未改变这一格局 |
| **Falsification（证伪条件）** | 若历史证据表明斯品汉姆兰法令实施地区工资未下降，或劳动者生活水平未恶化，或古典经济学理论可基于人类行为规则而非自然事实解释贫困，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中引用芒图描述，但无具体数字） |
| **Conflicts（观点冲突）** | 与亚当·斯密“普遍富裕必然渗透到民众”的观点冲突；与欧文“社会应通过立法干预平抑市场倾向”的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像政府给企业补贴，企业反而压低员工工资——补贴本意是救济，却成了雇主压价的工具，最终让整个行业工资水平下降，还被误认为是“市场规律”

### 🔗 文字版因果链

1. 教区补贴补足工人工资与生存收入之间的差额，使雇主可以支付低于生存水平的工资
2. 接受教区救济的工人愿意为更低工资工作，使未获救济的勤奋工人无法与之竞争
3. 工资被普遍压低，劳动者生活水平无法改善，甚至恶化
4. 这种普遍贫困被古典经济学家（马尔萨斯、李嘉图）误读为工资铁律（人口规律与土地报酬递减）作用的证据
5. 经济法则被归因于自然（动植物繁殖、土地肥力），而非人类行为，形成自然主义基础

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场组织（按获利原则组织社会） |
| **DV（因变量）** | 人类性格的退化与悲惨（传统特征毁灭，形成迁移、飘荡、缺少自尊和纪律的新类型人） |
| **Chain（传导链）** | 制造业在全国范围扩散，按获利原则组织生产 → 劳动者生存完全依赖于工厂成功 → 定居人群的传统特征被摧毁，转变为新类型人（粗鲁麻木、缺乏自尊和纪律） → 产生不利于个体与普遍幸福的持久罪恶 |
| **Lag（时滞）** | 制造业扩散后数十年内（欧文1817年观察，影响持续一个世纪） |
| **Threshold（临界值）** | 当制造业成为居民生存的唯一依赖时，退化效应显著 |
| **前提与约束（Premises）** | 市场制度的内在倾向未被立法干预所阻遏；获利原则成为社会组织的核心原则；劳动者失去其他生存来源 |
| **Falsification（证伪条件）** | 若制造业扩散地区劳动者性格未发生退化，或生活水平显著提高且幸福感增强，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典经济学家（马尔萨斯、李嘉图）将贫困归因于自然法则的观点冲突；与自由放任主义（伯克、汤森）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像流水线工厂让农民变成机器上的螺丝钉——一旦生存完全依赖工厂，人的独立性和尊严就被磨灭，变成麻木的“工具人”

### 🔗 文字版因果链

1. 制造业在全国范围扩散，按获利原则组织生产
2. 劳动者生存完全依赖于工厂成功
3. 定居人群的传统特征被摧毁，转变为新类型人（粗鲁麻木、缺乏自尊和纪律）
4. 产生不利于个体与普遍幸福的持久罪恶
