# 国家采取保护性关税和建立殖民地的帝国主义政策

> 属于因果簇：[[金本位制压力下的保护主义与帝国主义因果链]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家面临黄金储备枯竭（金本位制下国际收支赤字） |
| **DV（因变量）** | 国家采取保护性关税和建立殖民地的帝国主义政策 |
| **Chain（传导链）** | 金本位制下，赤字国黄金外流，货币贬值，经济收缩，工资和农业收入下降，失业增加，企业和银行破产 → 工人、农民、工商界无法忍受调整代价，社会联合起来消解金本位制的冲击 → 各国首先增强对农产品和工业产品的保护性关税，降低贸易流对价格变化的敏感度，减少对黄金外流的脆弱性 → 保护主义兴起后，殖民开发的得失计算反转，新获得的殖民地受宗主国关税壁垒保护，宗主国获得市场和原材料特权 → 帝国主义竞争加剧了英国和德国等列强的政治、军事和经济敌对，最终导致第一次世界大战 |
| **Lag（时滞）** | 金本位制压力显现后，保护主义措施在19世纪最后四分之一世纪内逐步升级，帝国主义竞赛在数十年内积累并最终导致一战（1914年） |
| **Threshold（临界值）** | 当货币价值下降到金点（gold point）之下，国际银行家有利可图地用贬值货币购买黄金并运往国外出售时，黄金外流机制启动 |
| **前提与约束（Premises）** | 金本位制作为国际货币体系的核心制度有效运作；各国经济通过国际贸易相互联系，存在国际收支赤字国和盈余国；国内各阶层（工人、农民、工商界）对经济收缩的承受力有限；存在可供争夺的海外市场和原材料来源 |
| **Falsification（证伪条件）** | 如果存在金本位制下长期赤字的国家能够通过国内调整（如工资和价格灵活下降）恢复平衡而不采取保护主义或帝国主义政策，且未出现帝国主义竞争加剧和战争，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及19世纪最后四分之一世纪欧洲列强、美国和日本争相建立殖民地，但未提供具体贸易数据或战争伤亡数字） |
| **Conflicts（观点冲突）** | 与列宁的帝国主义理论冲突——列宁认为帝国主义冲突是资本主义发展最后阶段金融资本膨胀的产物，而波兰尼认为金融资本家可以是阻止战争的主要力量 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人欠债后，不是通过节衣缩食（国内调整）来还债，而是去抢邻居的财产（殖民扩张）来弥补亏空，结果引发邻里大战。

### 🔗 文字版因果链

1. 金本位制下，赤字国黄金外流，货币贬值，经济收缩，工资和农业收入下降，失业增加，企业和银行破产
2. 工人、农民、工商界无法忍受调整代价，社会联合起来消解金本位制的冲击
3. 各国首先增强对农产品和工业产品的保护性关税，降低贸易流对价格变化的敏感度，减少对黄金外流的脆弱性
4. 保护主义兴起后，殖民开发的得失计算反转，新获得的殖民地受宗主国关税壁垒保护，宗主国获得市场和原材料特权
5. 帝国主义竞争加剧了英国和德国等列强的政治、军事和经济敌对，最终导致第一次世界大战
