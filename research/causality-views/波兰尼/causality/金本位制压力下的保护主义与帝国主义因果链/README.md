# 金本位制压力下的保护主义与帝国主义因果链（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：金本位制压力下的保护主义与帝国主义因果链.md

## 总体因果图

- 国家面临黄金储备枯竭（金本位制下国际收支赤字） → 国家采取保护性关税和建立殖民地的帝国主义政策
- 新自由主义全球化（拆除贸易和资本流动障碍、减少政府干预） → 社会解体、饥荒、内战、军国主义政权、宗教原教旨主义武装冲突
- 市场自由主义（将人类目标从属于非人市场机制的逻辑） → 经济危机、威权主义政权、攻击性政权重现
- 民主政治规制（通过民主手段控制经济，保护个人和自然免于市场威胁） → 前所未有的自由（法律和实际自由更广泛、更普遍，民权自由扩展）
