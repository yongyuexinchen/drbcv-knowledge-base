# 前所未有的自由（法律和实际自由更广泛、更普遍，民权自由扩展）

> 属于因果簇：[[金本位制压力下的保护主义与帝国主义因果链]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 民主政治规制（通过民主手段控制经济，保护个人和自然免于市场威胁） |
| **DV（因变量）** | 前所未有的自由（法律和实际自由更广泛、更普遍，民权自由扩展） |
| **Chain（传导链）** | 社会通过民主政治决定经济规制机制（如社会保险、劳动法） → 规制机制使人类与自然摆脱市场强力造成的压力 → 政府角色增强，但并非压制性，而是保护性 → 法律和实际自由以更广泛、更普遍的方式存在 → 不服从的权利被制度化保护，个体能自由遵从良心行事 |
| **Lag（时滞）** | 民主规制建立后，自由扩展在数年至数十年内逐步实现（如罗斯福新政后美国社会保障制度建立） |
| **Threshold（临界值）** | 当民主政治成功使经济从属于社会目标，且规制机制有效保护个人和自然时，自由扩展成为可能 |
| **前提与约束（Premises）** | 民主政治制度有效运作；政府角色实质性增强但不走向压制；国际合作与各国自主选择经济模式并存；全球性规制结构对市场力量施加限制 |
| **Falsification（证伪条件）** | 如果民主规制导致经济效率严重下降或走向压制性政权，且自由未扩展反而受限，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及斯堪的纳维亚地区1940-1980年代的社会民主成就作为例证，但未提供具体自由指数或福利数据） |
| **Conflicts（观点冲突）** | 与新自由主义观点冲突——新自由主义者认为更大政府将不可避免地导致不好的经济后果和国家对社会生活的过度控制 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像给湍急的河流修建堤坝和水闸，不是要困住水，而是让水能安全地灌溉农田、发电，让两岸的人都能自由地生活，而不是被洪水冲走。

### 🔗 文字版因果链

1. 社会通过民主政治决定经济规制机制（如社会保险、劳动法）
2. 规制机制使人类与自然摆脱市场强力造成的压力
3. 政府角色增强，但并非压制性，而是保护性
4. 法律和实际自由以更广泛、更普遍的方式存在
5. 不服从的权利被制度化保护，个体能自由遵从良心行事
