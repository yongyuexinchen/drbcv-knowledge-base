# 欧文主义社会保护与英国工人阶级地位变迁的因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：欧文主义社会保护与英国工人阶级地位变迁的因果分析.md

## 总体因果图

- 欧文主义的社会方法（拒绝经济与政治分离，强调整体社会调整） → 英国工人阶级在工业化中的道德与文化灾难（地位降低）
- 英国中产阶级对工人阶级选举权的拒绝（直到工人接受资本主义经济原则） → 英国工人阶级政治地位低下，无法通过政治手段改善自身处境
- 欧洲大陆工业化晚于英国（约半个世纪）且工人阶级未经历圈地运动 → 欧洲大陆工人阶级的社会政治地位相对提升，形成阶级意识
- 社会保护措施（立法或工会）干预劳动力市场 → 劳动力市场无法按古典经济学假设运作，但保护了劳动力的人性特质
