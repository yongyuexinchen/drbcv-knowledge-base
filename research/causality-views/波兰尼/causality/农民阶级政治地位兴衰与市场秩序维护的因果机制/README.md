# 农民阶级政治地位兴衰与市场秩序维护的因果机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：农民阶级政治地位兴衰与市场秩序维护的因果机制.md

## 总体因果图

- 农民阶级在战后紧急状态下成为唯一能维持法律与秩序（市场经济规则）的阶级 → 农民阶级获得与其经济重要性不相称的政治优势地位，并持续向城市
- 农业自足在军事上的重要性（因一战暴露的粮食安全战略需求） → 大土地所有者的影响力持久不衰，中欧'重新农业化'完成
- 工人阶级处于可能产生毁灭性干预的位置（而非实际革命威胁） → 对布尔什维克主义的恐惧持续潜伏，最终在法西斯主义中爆发
- 商品货币（金本位）的使用导致价格水平下跌（通货紧缩） → 生产组织解体、资本破坏、商业停业清偿、大量失业
- 中央银行缓冲通货紧缩的干预措施 → 金本位制的自动调节功能降低到徒有其表，市场自我调控机制陷入瘫
