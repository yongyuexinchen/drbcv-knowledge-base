# 对布尔什维克主义的恐惧持续潜伏，最终在法西斯主义中爆发

> 属于因果簇：[[农民阶级政治地位兴衰与市场秩序维护的因果机制]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工人阶级处于可能产生毁灭性干预的位置（而非实际革命威胁） |
| **DV（因变量）** | 对布尔什维克主义的恐惧持续潜伏，最终在法西斯主义中爆发 |
| **Chain（传导链）** | 工人阶级及其工会和政党可能漠视契约自由和私有财产神圣性 → 这种潜在干预必然挫伤投资、阻止资本积累、危及通货、破坏国际信用 → 即使实际革命威胁已过，潜在恐惧仍因危险根源未消除而持续 → 恐惧在关键当口爆发，成为法西斯主义上台的心理基础 |
| **Lag（时滞）** | 长期（从战后初期到法西斯主义上台，约十年） |
| **Threshold（临界值）** | 工人阶级处于能产生毁灭性干预的位置时，恐惧持续存在；即使实际威胁已过，只要根源未除，恐惧不消 |
| **前提与约束（Premises）** | 工人阶级确实处于能产生毁灭性干预的位置；市场法则（契约自由、私有财产神圣性）被视为绝对；危险根源未被消除 |
| **Falsification（证伪条件）** | 如果工人阶级实际威胁已过而恐惧消失，或法西斯主义上台时恐惧已不存在，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及罢工浪潮在进军罗马前一年多已平息，但未给出具体数字） |
| **Conflicts（观点冲突）** | 与法西斯主义批评者认为法西斯主义是'完全没有政治理性的畸形物'的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人曾被蛇咬过，即使蛇已离开，只要草丛中仍有沙沙声，恐惧就不会消失，最终可能导致过度反应。

### 🔗 文字版因果链

1. 工人阶级及其工会和政党可能漠视契约自由和私有财产神圣性
2. 这种潜在干预必然挫伤投资、阻止资本积累、危及通货、破坏国际信用
3. 即使实际革命威胁已过，潜在恐惧仍因危险根源未消除而持续
4. 恐惧在关键当口爆发，成为法西斯主义上台的心理基础
