# 市场模式与交换原则的因果关系

> **领域**：经济史与经济社会学　|　**来源**：波兰尼_chapter_10_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场模式的存在 |
| **DV（因变量）** | 交换原则的有效性 |
| **Chain（传导链）** | 市场模式为交换或交易提供场所和制度框架 → 交换原则依赖于市场模式才能产生价格 → 没有市场模式，交换秉性无法充分施展，价格无法形成 |
| **Lag（时滞）** | 即时 |
| **Threshold（临界值）** | 市场模式至少局部存在 |
| **前提与约束（Premises）** | 交换原则的有效性以市场模式为前提；市场模式可能在社会中居于从属地位；交换原则与其他原则（互惠、再分配、家计）不同，能创生特定制度 |
| **Falsification（证伪条件）** | 如果发现交换原则在无市场模式的社会中能有效运作并产生价格，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典经济学认为个体交换秉性自然导致市场形成的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同电流需要闭合电路才能流动，交换原则需要市场模式作为其电路

### 🔗 文字版因果链

1. 市场模式为交换或交易提供场所和制度框架
2. 交换原则依赖于市场模式才能产生价格
3. 没有市场模式，交换秉性无法充分施展，价格无法形成

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场控制经济体系 |
| **DV（因变量）** | 社会组织从属于经济体系 |
| **Chain（传导链）** | 市场模式创生出特定制度（市场） → 经济体系通过分立制度运转，社会必须按经济体系法则形塑自身 → 社会关系被嵌入经济体系，而非经济嵌入社会关系 |
| **Lag（时滞）** | 长期过程 |
| **Threshold（临界值）** | 市场从孤立市场转变为整合的市场经济 |
| **前提与约束（Premises）** | 经济因素对社会存续具有生死攸关的重要性；市场经济只有在市场社会中才能运转；自发调节市场的形成是人为刺激物（如机器）的效应 |
| **Falsification（证伪条件）** | 如果发现市场控制经济体系但社会关系仍保持主导，或市场经济能在非市场社会中运转，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与19世纪认为市场扩张是自然结果的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将心脏移植到体内，身体必须适应新器官的节律，否则排斥反应

### 🔗 文字版因果链

1. 市场模式创生出特定制度（市场）
2. 经济体系通过分立制度运转，社会必须按经济体系法则形塑自身
3. 社会关系被嵌入经济体系，而非经济嵌入社会关系

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 远距离贸易 |
| **DV（因变量）** | 市场的形成 |
| **Chain（传导链）** | 远距离贸易源于货物地理分布和地域分工 → 远距离贸易经常产生市场，包含以物易物或买卖 → 市场为个体提供讨价还价的机会，但非必然 |
| **Lag（时滞）** | 历史长期过程 |
| **Threshold（临界值）** | 存在地理上货物分布不均和运输可能性 |
| **前提与约束（Premises）** | 贸易起源与经济体内部组织无关，属于外部领域；远距离贸易最初更接近冒险、狩猎、海盗而非以物易物；市场并非主要在经济体内部运转，而是外部汇聚场所 |
| **Falsification（证伪条件）** | 如果发现市场先于远距离贸易出现，或远距离贸易不产生市场，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与正统经济学认为个体交换秉性导致贸易和市场形成的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同河流冲刷形成三角洲，远距离贸易冲刷出市场

### 🔗 文字版因果链

1. 远距离贸易源于货物地理分布和地域分工
2. 远距离贸易经常产生市场，包含以物易物或买卖
3. 市场为个体提供讨价还价的机会，但非必然

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家干预 |
| **DV（因变量）** | 国内市场的创造 |
| **Chain（传导链）** | 地方市场是邻里市场，不导致国内贸易 → 对外贸易市场与国内市场功能、起源不同 → 西欧国内市场由国家干预创造，如重商制度 |
| **Lag（时滞）** | 商业革命时期 |
| **Threshold（临界值）** | 国家政策支持国内市场形成 |
| **前提与约束（Premises）** | 地方市场不构成国内贸易起点；汉泽同盟等贸易组织并非国内市场前身；国内市场本质上是竞争性的 |
| **Falsification（证伪条件）** | 如果发现国内市场在无国家干预下自然形成，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与市场自发扩展的古典观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同国家修建公路网，而非自然小径，才能形成全国交通系统

### 🔗 文字版因果链

1. 地方市场是邻里市场，不导致国内贸易
2. 对外贸易市场与国内市场功能、起源不同
3. 西欧国内市场由国家干预创造，如重商制度
