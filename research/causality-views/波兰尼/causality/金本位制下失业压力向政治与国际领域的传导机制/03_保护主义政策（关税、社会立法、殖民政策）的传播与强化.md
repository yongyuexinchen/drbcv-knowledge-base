# 保护主义政策（关税、社会立法、殖民政策）的传播与强化

> 属于因果簇：[[金本位制下失业压力向政治与国际领域的传导机制]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制的引入（国际金本位制作为市场经济扩张的工具） |
| **DV（因变量）** | 保护主义政策（关税、社会立法、殖民政策）的传播与强化 |
| **Chain（传导链）** | 金本位制将汇率系于黄金，固定汇率政策对国内经济形成沉重约束 → 为应对固定汇率带来的调整压力，各国引入保护性措施（关税、工厂法令、殖民政策） → 保护主义制度成为稳定对外货币的前提条件 → 保护主义进一步干扰市场机制，削弱自发调节能力 |
| **Lag（时滞）** | 中期（金本位制引入后数年，保护主义政策逐步出台） |
| **Threshold（临界值）** | 当固定汇率政策的负担超过国内经济承受能力时，保护主义政策开始普及 |
| **前提与约束（Premises）** | 该国实行金本位制；市场经济扩张需要保护性措施作为配套；各国面临类似的国际贸易调整压力 |
| **Falsification（证伪条件）** | 若某国引入金本位制后未出现保护主义政策增强，且汇率稳定、经济调整顺利，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与传统自由主义观点冲突——后者认为保护主义是政客无知或利益集团操纵的结果，而非金本位制的必然产物 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像穿了一双太紧的鞋（金本位），为了走路不疼，你不得不加鞋垫和绷带（保护主义），但这些附加物又让鞋子更不灵活（干扰市场机制）。

### 🔗 文字版因果链

1. 金本位制将汇率系于黄金，固定汇率政策对国内经济形成沉重约束
2. 为应对固定汇率带来的调整压力，各国引入保护性措施（关税、工厂法令、殖民政策）
3. 保护主义制度成为稳定对外货币的前提条件
4. 保护主义进一步干扰市场机制，削弱自发调节能力
