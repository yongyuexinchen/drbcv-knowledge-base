# 金本位制下失业压力向政治与国际领域的传导机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：金本位制下失业压力向政治与国际领域的传导机制.md

## 总体因果图

- 金本位制（稳定汇兑的紧迫要求） → 银行信贷扩张受限，进而无法缓解失业
- 失业压力（无论通过工资通缩还是公共工程缓解） → 汇率下跌、通货贬值压力，进而导致外部紧张或帝国主义竞争
- 金本位制的引入（国际金本位制作为市场经济扩张的工具） → 保护主义政策（关税、社会立法、殖民政策）的传播与强化
- 市场自发调节机制的建立（尤其是劳动力市场的形成） → 社会保护主义反向运动（对劳动、土地、货币市场的干预）
- 保护主义政策（关税、垄断组织） → 市场自发调节机制被削弱，最终导致经济崩溃
