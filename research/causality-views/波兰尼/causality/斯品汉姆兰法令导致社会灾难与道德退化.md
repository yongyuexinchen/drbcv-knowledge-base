# 斯品汉姆兰法令导致社会灾难与道德退化

> **领域**：经济史与社会学　|　**来源**：波兰尼_chapter_14_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法令（1795年实施） |
| **DV（因变量）** | 社会灾难（道德退化、劳动力市场扭曲、阶级结构破坏） |
| **Chain（传导链）** | 法令实施所外救济和工资补助，使工资水平降至生存线以下 → 雇主受益于低工资，但无需补偿低工资与贫困线之间的差额，榨取超额利润 → 劳动者被剥夺了通过自身劳动谋生和形成独立经济阶级的机会，沦为赤贫者 → 济贫所中不同类别穷人（有劳动能力者与老弱儿童）不加区分，导致道德退化、逃避工作、假装匮乏等行为滋生 → 乡村中产阶级被削弱，地主和教士的至高无上性加强，社会结构失衡 → 长期来看，劳动生产率下降，工资标准被压低，最终导致社会灾难 |
| **Lag（时滞）** | 约10-25年（法令实施后，到1815-1830年间斯品汉姆兰标准缩减约三分之一，社会后果全面显现） |
| **Threshold（临界值）** | 当工资补助使工资水平降至生存线以下，且济贫支出占地区总收入比例超过3.3%时（南部英格兰为例），灾难性后果加剧 |
| **前提与约束（Premises）** | 仅当劳动力市场缺失或竞争不充分时（如安居法仍在发挥作用）；在乡村统治利益（地主阶层）主导政治决策的背景下；排除有劳动能力者与老弱儿童的有效区分机制缺失时；在工业革命初期，乡村文明缺乏城市环境和中产阶级同化外来务工者的条件下 |
| **Falsification（证伪条件）** | 如果能够证明在斯品汉姆兰法令实施期间，劳动生产率未下降、工资水平未低于生存线、劳动者能够自由形成独立经济阶级，且道德退化现象未普遍发生，则该断言被推翻 |
| **Data（定量佐证）** | 1818年济贫总费用800万英镑，到1826年降至不足600万英镑；南部英格兰济贫支出占总收入不足3.3%；1815-1830年间斯品汉姆兰标准缩减约三分之一 |
| **Conflicts（观点冲突）** | 与克拉彭（J.H. Clapham）的观点冲突——他认为济贫负担本身并非灾难性，问题在于工资补助对劳动生产力的经济后果；与后世自由主义者的观点冲突——他们忽视马蒂诺对济贫法道德效应的批评 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 这就像政府给所有失业者发放无条件补贴，导致企业压低工资、劳动者失去工作动力，最终整个社会陷入依赖救济的恶性循环，如同一个家庭因长期接受施舍而丧失自立能力，最终导致家庭解体。

### 🔗 文字版因果链

1. 法令实施所外救济和工资补助，使工资水平降至生存线以下
2. 雇主受益于低工资，但无需补偿低工资与贫困线之间的差额，榨取超额利润
3. 劳动者被剥夺了通过自身劳动谋生和形成独立经济阶级的机会，沦为赤贫者
4. 济贫所中不同类别穷人（有劳动能力者与老弱儿童）不加区分，导致道德退化、逃避工作、假装匮乏等行为滋生
5. 乡村中产阶级被削弱，地主和教士的至高无上性加强，社会结构失衡
6. 长期来看，劳动生产率下降，工资标准被压低，最终导致社会灾难
