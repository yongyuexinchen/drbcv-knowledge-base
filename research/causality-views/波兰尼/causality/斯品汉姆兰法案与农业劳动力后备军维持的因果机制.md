# 斯品汉姆兰法案与农业劳动力后备军维持的因果机制

> **领域**：经济史、劳动经济学　|　**来源**：波兰尼_chapter_34_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法案及济贫补贴制度的存在 |
| **DV（因变量）** | 乡村雇主手中拥有一支可随时动用的顺良的农业劳动力后备军 |
| **Chain（传导链）** | 济贫补贴使穷人获得基本生存保障，即使工资低于生存水平也能维持生活 → 定居法限制穷人迁移，使其依附于地方教区，无法自由流动 → 济贫所规章允许对赤贫者进行惩罚甚至秘密惩罚，强化了穷人的顺从性 → 实物工资和强制劳动义务使雇工必须随时响应领主需求 → 多重依赖关系（村舍、土地租期）使劳动者无法独立，只能依赖农场主 → 结果：农场主在需要时（如春耕秋收）可随时获得劳动力，不需要时可将工人抛回教区 |
| **Lag（时滞）** | 即时生效（制度存在期间持续维持） |
| **Threshold（临界值）** | 无明确量化阈值，制度本身即构成条件 |
| **前提与约束（Premises）** | 仅当济贫补贴足以维持穷人基本生存时；仅当定居法限制劳动力流动时；仅当存在农业季节性劳动力需求波动时；排除：当工业城镇提供更高工资吸引劳动力时，该机制可能被削弱 |
| **Falsification（证伪条件）** | 如果废除济贫补贴后，农场主仍能轻易获得充足劳动力，或如果补贴制度下农场主仍面临劳动力短缺，则该断言被推翻 |
| **Data（定量佐证）** | 1834年济贫法委员会报告中农场主证词：'只要济贫线岿然不同，他们就总能在有额外需要的时候得到人手，而当天下起雨来，他们则可以将他们再次扔给教区'；'补贴制度意味着便宜的劳动力，迅速的收割' |
| **Conflicts（观点冲突）** | 与古典自由主义经济学家（如亚当·斯密）认为自由市场能自动调节劳动力供给的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像水库蓄水——济贫补贴如同水库大坝，将劳动力蓄积在乡村，农场主需要时开闸放水（雇佣），不需要时关闸蓄水（抛回教区），确保随时有水可用。

### 🔗 文字版因果链

1. 济贫补贴使穷人获得基本生存保障，即使工资低于生存水平也能维持生活
2. 定居法限制穷人迁移，使其依附于地方教区，无法自由流动
3. 济贫所规章允许对赤贫者进行惩罚甚至秘密惩罚，强化了穷人的顺从性
4. 实物工资和强制劳动义务使雇工必须随时响应领主需求
5. 多重依赖关系（村舍、土地租期）使劳动者无法独立，只能依赖农场主
6. 结果：农场主在需要时（如春耕秋收）可随时获得劳动力，不需要时可将工人抛回教区

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰补贴制度在工业城镇的扩散 |
| **DV（因变量）** | 工业资本家对斯品汉姆兰制度的反对与1834年济贫法改革 |
| **Chain（传导链）** | 补贴制度向北方工业城镇扩散，形成城镇产业后备军 → 补贴导致劳动者低效率（四五个补贴领取者才抵得上一个任务工作者） → 补贴造成不同地区间生产成本差异，威胁城市工厂主的市场竞争地位 → 补贴助长乡村劳动力滞留，减少城市劳动力供给，增强城市工人垄断劳动力市场的倾向 → 这些因素使工业资本家作为一个阶级认识到补贴制度的集体危害 → 最终凝聚成全国性改革力量，推动1834年济贫法改革 |
| **Lag（时滞）** | 长期效应（数十年，从1795年法案到1834年改革） |
| **Threshold（临界值）** | 当补贴制度扩散到工业城镇并开始影响工业资本家利益时，反对力量才凝聚成形 |
| **前提与约束（Premises）** | 仅当工业资本家认识到个体利益与集体利益的冲突时；仅当补贴制度对劳动生产率的负面影响足够显著时；仅当城市劳动力需求旺盛（如1820年代末）时 |
| **Falsification（证伪条件）** | 如果1834年改革并非由工业资本家的反对推动，而是由其他因素（如政治意识形态）主导，则该断言被削弱 |
| **Data（定量佐证）** | 济贫法委员会报告：'一个马克莱斯菲尔德制造业主可能会发现，他被低价倾销所打垮，这种倾销是艾塞克斯郡的济贫法管理不当所造成的结果'；1824年特别委员会报告：补贴领取者'四五个才抵得上一个任务工作者' |
| **Conflicts（观点冲突）** | 与认为1834年改革是纯粹人道主义或意识形态驱动的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像多个工厂共用一条被污染的河流——单个工厂排污有利可图，但所有工厂都排污时，大家都受害，最终联合起来治理污染。

### 🔗 文字版因果链

1. 补贴制度向北方工业城镇扩散，形成城镇产业后备军
2. 补贴导致劳动者低效率（四五个补贴领取者才抵得上一个任务工作者）
3. 补贴造成不同地区间生产成本差异，威胁城市工厂主的市场竞争地位
4. 补贴助长乡村劳动力滞留，减少城市劳动力供给，增强城市工人垄断劳动力市场的倾向
5. 这些因素使工业资本家作为一个阶级认识到补贴制度的集体危害
6. 最终凝聚成全国性改革力量，推动1834年济贫法改革

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 英国城乡统一的济贫法管理 |
| **DV（因变量）** | 劳动力在城乡之间的'振荡'流动而非单向的乡村人口枯竭 |
| **Chain（传导链）** | 济贫法在城乡教区一视同仁地推行，不存在管理断裂 → 劳动力可以在城乡之间自由流动而不失去救济资格 → 乡村教区支付户外救济给在城镇工作的非定居穷人 → 制造业城镇向在本城镇无住所的定居穷人支付救济金 → 结果：劳动力在城乡之间'振荡'流动，避免了大陆国家常见的乡村人口枯竭（landflucht） |
| **Lag（时滞）** | 长期制度效应（数十年至数百年） |
| **Threshold（临界值）** | 无明确量化阈值 |
| **前提与约束（Premises）** | 仅当济贫法在城乡统一执行时；仅当城乡地理距离较近（英国港口众多、布局紧凑）时；排除：大规模遣返运动（如1841-1843年）是例外情况 |
| **Falsification（证伪条件）** | 如果英国出现类似中欧的乡村人口枯竭现象，或劳动力流动呈现不可逆的单向性，则该断言被推翻 |
| **Data（定量佐证）** | 1841-1843年遣返运动中，从19个北方制造业城镇遣返的12,628个穷人中，只有1%在9个农业地区拥有住所 |
| **Conflicts（观点冲突）** | 与大陆国家（如德国）的乡村人口枯竭现象形成对比，与认为济贫法阻碍劳动力流动的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像两个连通的水池——水位差会让水在两个池子间来回流动，而不是一个池子干涸，另一个池子溢出。

### 🔗 文字版因果链

1. 济贫法在城乡教区一视同仁地推行，不存在管理断裂
2. 劳动力可以在城乡之间自由流动而不失去救济资格
3. 乡村教区支付户外救济给在城镇工作的非定居穷人
4. 制造业城镇向在本城镇无住所的定居穷人支付救济金
5. 结果：劳动力在城乡之间'振荡'流动，避免了大陆国家常见的乡村人口枯竭（landflucht）
