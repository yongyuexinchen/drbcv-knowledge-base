# 济贫费用增长与贫困化加剧的因果分析

> **领域**：宏观经济学、社会政策　|　**来源**：波兰尼_chapter_16_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口增长（120年间约增加两倍） |
| **DV（因变量）** | 济贫费用急剧增加（增加20倍） |
| **Chain（传导链）** | 人口增长导致贫困人口绝对数量增加 → 济贫体系覆盖范围扩大，支出相应增加 → 费用增长速度远超人口增长速度，表明贫困化程度加深 |
| **Lag（时滞）** | 120年（长期累积效应） |
| **Threshold（临界值）** | 费用增长20倍 vs 人口增长3倍，比例严重失衡 |
| **前提与约束（Premises）** | 济贫制度维持不变或未进行根本改革；贫困人口未能通过其他途径（如就业）脱离救济 |
| **Falsification（证伪条件）** | 若人口增长的同时济贫费用增长比例接近或低于人口增长比例，则此断言不成立 |
| **Data（定量佐证）** | 费用总数接近800万英镑；120年间人口增加约两倍，济贫费用增加20倍 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家庭人口增加3倍，但食物开支却增加20倍，说明不是单纯人口问题，而是更深层的贫困结构恶化。

### 🔗 文字版因果链

1. 人口增长导致贫困人口绝对数量增加
2. 济贫体系覆盖范围扩大，支出相应增加
3. 费用增长速度远超人口增长速度，表明贫困化程度加深

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 饥饿作为自然惩戒机制（汤森的山羊与狗法则） |
| **DV（因变量）** | 穷人被迫劳动、服从社会秩序 |
| **Chain（传导链）** | 食物数量限制人口数量，饥饿成为自然约束 → 饥饿驱使穷人为了生存而接受任何劳动条件 → 无需政府强制，市场自然形成劳动纪律和社会秩序 |
| **Lag（时滞）** | 即时生效（持续压力） |
| **Threshold（临界值）** | 食物供给不足，饥饿压力持续存在 |
| **前提与约束（Premises）** | 财产权得到保障，穷人无法通过其他途径获得生存资源；市场机制能够有效配置劳动力；排除政府干预和济贫法救济 |
| **Falsification（证伪条件）** | 若在缺乏政府强制的情况下，穷人并未因饥饿而自愿接受劳动，或社会秩序崩溃，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与亚当·斯密的人道主义经济学观点冲突；与霍布斯认为需要强权政府维持秩序的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同野狗追逐山羊，自然平衡无需猎人管理——汤森认为社会秩序也无需政府干预，饥饿自会驱使穷人劳动。

### 🔗 文字版因果链

1. 食物数量限制人口数量，饥饿成为自然约束
2. 饥饿驱使穷人为了生存而接受任何劳动条件
3. 无需政府强制，市场自然形成劳动纪律和社会秩序

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 济贫法废除（自由放任政策） |
| **DV（因变量）** | 劳动力成为市场商品，贫困由市场机制调节 |
| **Chain（传导链）** | 废除伊丽莎白时代的济贫法，取消工资评估和最低工资保障 → 劳动力不再受法律保护，必须作为商品在市场上定价 → 饥饿成为最有效的惩戒者，迫使穷人接受市场工资 → 市场自然调节劳动力供需，无需政府干预 |
| **Lag（时滞）** | 短期至中期（政策实施后逐步显现） |
| **Threshold（临界值）** | 完全废除济贫法，不设替代性保障措施 |
| **前提与约束（Premises）** | 市场体系完善，劳动力自由流动；财产权安全，雇主有雇佣意愿；排除政府最低工资和救济干预 |
| **Falsification（证伪条件）** | 若废除济贫法后，劳动力并未有效市场化，或导致社会动荡、贫困加剧而非秩序稳定，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张保留济贫法、保障穷人基本生存权的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同拆除安全网后让高空作业者自行负责——支持者认为这能激发潜能，反对者认为会导致坠落。

### 🔗 文字版因果链

1. 废除伊丽莎白时代的济贫法，取消工资评估和最低工资保障
2. 劳动力不再受法律保护，必须作为商品在市场上定价
3. 饥饿成为最有效的惩戒者，迫使穷人接受市场工资
4. 市场自然调节劳动力供需，无需政府干预

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 贫困作为社会自然选择机制（边沁的功利主义视角） |
| **DV（因变量）** | 社会繁荣达到最高阶段 |
| **Chain（传导链）** | 贫困使大多数公民仅靠每日劳动维持生存 → 贫困边缘状态迫使公民持续劳动，避免懈怠 → 饥饿的肉体惩罚比政治惩罚更有效，激励工业生产力 → 社会整体生产效率提高，实现繁荣 |
| **Lag（时滞）** | 持续存在（贫困作为常态机制） |
| **Threshold（临界值）** | 大多数公民处于贫困边缘，仅靠每日劳动维持生存 |
| **前提与约束（Premises）** | 社会繁荣需要持续劳动供给；饥饿惩罚比法律惩罚更有效；排除对穷人的人道主义救济干预 |
| **Falsification（证伪条件）** | 若消除贫困后社会繁荣程度反而提高，或贫困并未激励劳动而是导致社会不稳定，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张消除贫困、保障基本生存权的社会福利观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同认为运动员在饥饿状态下训练更刻苦——但长期饥饿可能导致崩溃而非更好成绩。

### 🔗 文字版因果链

1. 贫困使大多数公民仅靠每日劳动维持生存
2. 贫困边缘状态迫使公民持续劳动，避免懈怠
3. 饥饿的肉体惩罚比政治惩罚更有效，激励工业生产力
4. 社会整体生产效率提高，实现繁荣
