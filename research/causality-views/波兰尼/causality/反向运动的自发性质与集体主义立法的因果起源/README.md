# 反向运动的自发性质与集体主义立法的因果起源（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：反向运动的自发性质与集体主义立法的因果起源.md

## 总体因果图

- 自我调节市场体系的扩张（19世纪自由放任政策的推进） → 反向运动（保护性立法、集体主义干预措施）的自发产生，而非由意
- 经济自由主义信条的坚持（尤其在1930-1940年代） → 民主国家（英国、美国）应对战争与经济危机的准备不足，加剧灾难
- 经济自由主义者在工会法与反托拉斯法问题上的立场转变 → 经济自由主义被迫采用“集体主义”干预手段，证明干预在工业社会
