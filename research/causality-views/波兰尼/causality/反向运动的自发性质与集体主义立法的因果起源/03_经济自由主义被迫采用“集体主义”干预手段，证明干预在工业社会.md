# 经济自由主义被迫采用“集体主义”干预手段，证明干预在工业社会

> 属于因果簇：[[反向运动的自发性质与集体主义立法的因果起源]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济自由主义者在工会法与反托拉斯法问题上的立场转变 |
| **DV（因变量）** | 经济自由主义被迫采用“集体主义”干预手段，证明干预在工业社会中的不可避免性 |
| **Chain（传导链）** | 工会联合限制劳动力市场，托拉斯联合限制商品市场，均利用契约自由限制贸易 → 经济自由主义者（如劳埃德·乔治、西奥多·罗斯福、李普曼）发现自由放任原则与自发调节市场相冲突 → 为维护自发调节市场，他们转而支持管制和限制，即“集体主义”手段 → 工会法与反托拉斯法的制定表明，即使最激进的经济自由主义者也必须求助于国家干预 → 结论：干预与市场体系并非相互排斥，干预是建立和维持市场体系的必要手段 |
| **Lag（时滞）** | 无明确时滞，立场转变随问题出现而即时发生 |
| **Threshold（临界值）** | 当契约自由被用于限制贸易、威胁自发调节市场时，干预即被采用（无量化阈值） |
| **前提与约束（Premises）** | 仅当工会或托拉斯滥用契约自由限制市场竞争时，经济自由主义者才转向干预；经济自由主义的核心原则是自发调节市场，而非自由放任本身；排除：干预被用于非市场目的（如纯粹再分配）的情况 |
| **Falsification（证伪条件）** | 若能证明经济自由主义者从未支持任何干预措施，或干预并非为维护市场体系所必需，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引用工会法与反托拉斯法案例） |
| **Conflicts（观点冲突）** | 与将干预主义视为自由放任对立面的传统自由主义观点冲突 |

### 🧩 生活类比

> 就像一位园艺师为了保持花园的整洁，必须修剪杂草——修剪（干预）看似违背“自然生长”（自由放任），但却是维持花园（市场）健康所必需的

### 🔗 文字版因果链

1. 工会联合限制劳动力市场，托拉斯联合限制商品市场，均利用契约自由限制贸易
2. 经济自由主义者（如劳埃德·乔治、西奥多·罗斯福、李普曼）发现自由放任原则与自发调节市场相冲突
3. 为维护自发调节市场，他们转而支持管制和限制，即“集体主义”手段
4. 工会法与反托拉斯法的制定表明，即使最激进的经济自由主义者也必须求助于国家干预
5. 结论：干预与市场体系并非相互排斥，干预是建立和维持市场体系的必要手段
