# 冲突加剧（社会动荡、内战、军国主义与原教旨主义武装冲突）

> 属于因果簇：[[波兰尼《大转型》核心因果断言提取]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新自由主义全球市场乌托邦（无国界、自由流动、减少政府干预） |
| **DV（因变量）** | 冲突加剧（社会动荡、内战、军国主义与原教旨主义武装冲突） |
| **Chain（传导链）** | 新自由主义政策要求缩减政府、取消贸易和资本管制 → 全球市场自发调节引发周期性经济剧烈波动 → 普通人每隔约五到十年被迫承受收入减半的长期萧条 → 人们无法忍受经济震荡，动员起来保护自己 → 社会不满加剧，秩序问题凸显 → 政治领袖通过寻找国内或国际敌人转移不满 → 最终导致冲突加剧而非和平 |
| **Lag（时滞）** | 大约5至10年一个周期，长期积累后爆发 |
| **Threshold（临界值）** | 普通人收入下降至原来的一半或更少，且反复发生 |
| **前提与约束（Premises）** | 人类缺乏长期承受剧烈经济波动的韧性；全球层面缺少强有力的规制机构（如最终借款人）；政治机会主义分子可利用不满情绪 |
| **Falsification（证伪条件）** | 如果新自由主义全球化普遍带来和平与繁荣，且没有出现大规模抗议或冲突，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同把所有人赶上没有安全网的高空钢丝，每隔几年就剧烈晃动一次，人们迟早会因恐惧而互相推搡，最终酿成踩踏。

### 🔗 文字版因果链

1. 新自由主义政策要求缩减政府、取消贸易和资本管制
2. 全球市场自发调节引发周期性经济剧烈波动
3. 普通人每隔约五到十年被迫承受收入减半的长期萧条
4. 人们无法忍受经济震荡，动员起来保护自己
5. 社会不满加剧，秩序问题凸显
6. 政治领袖通过寻找国内或国际敌人转移不满
7. 最终导致冲突加剧而非和平
