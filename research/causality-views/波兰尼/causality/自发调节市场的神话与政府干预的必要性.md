# 自发调节市场的神话与政府干预的必要性

> **领域**：宏观经济学　|　**来源**：波兰尼_chapter_01_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自发调节的市场体系（缺乏政府干预） |
| **DV（因变量）** | 经济与社会灾难（如贫困增加、社会资本侵蚀、政治动荡） |
| **Chain（传导链）** | 自发调节的市场体系从未真正存在，其运行依赖政府干预 → 市场失灵（信息不完备、外部性、过度波动）导致资源配置无效率和公平问题 → 快速转型破坏旧有社会安全网和应对机制，而新机制尚未建立 → 社会关系崩溃，社会资本侵蚀，产生不利经济效应（如资本外逃、投资减少） → 最终导致贫困增加、社会动荡、经济萎缩等灾难性后果 |
| **Lag（时滞）** | 短期至中期（快速转型中效果迅速显现，如俄罗斯改革后经济萎缩、贫困率上升） |
| **Threshold（临界值）** | 当市场失灵或转型速度过快，超出社会适应能力时，负面效应显著 |
| **前提与约束（Premises）** | 市场存在信息不完备和失灵，本质上是常态；社会需要有效的安全网和应对机制，否则转型会破坏社会整合；政府干预在历史上和现实中都是必要的，尤其在转型期 |
| **Falsification（证伪条件）** | 如果能证明存在一个完全自发调节的市场体系，在无政府干预下长期保持经济稳定、社会公平且无重大危机，则该断言被推翻 |
| **Data（定量佐证）** | 俄罗斯改革后经济萎缩约一半，贫困比例从2%上升到接近50%；印尼危机中取消食品补助导致政治社会骚乱；东亚国家政府积极干预实现增长和减贫 |
| **Conflicts（观点冲突）** | 与自由市场原教旨主义（如华盛顿共识、赛伊定律）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像没有交通规则和交警的十字路口，车辆自发调节看似自由，但必然导致混乱和事故，政府干预如同交通管理，虽不完美但必不可少

### 🔗 文字版因果链

1. 自发调节的市场体系从未真正存在，其运行依赖政府干预
2. 市场失灵（信息不完备、外部性、过度波动）导致资源配置无效率和公平问题
3. 快速转型破坏旧有社会安全网和应对机制，而新机制尚未建立
4. 社会关系崩溃，社会资本侵蚀，产生不利经济效应（如资本外逃、投资减少）
5. 最终导致贫困增加、社会动荡、经济萎缩等灾难性后果
