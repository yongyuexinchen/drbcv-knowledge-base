## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工业革命中经济的剧烈重组 |
| **DV（因变量）** | 儿童陷入赤贫状态并成为类似奴隶的'碎片' |
| **Chain（传导链）** | 工业革命在英格兰率先发生，经济结构剧烈重组 → 重组过程造成社会混乱，部分儿童陷入赤贫 → 赤贫儿童被转化为'碎片'，即被剥削的童奴 → 对童奴制度的辩护与对奴隶贸易的辩护相似 |
| **Lag（时滞）** | 工业革命期间（长期过程） |
| **Threshold（临界值）** | 经济重组剧烈程度超过社会承受能力时 |
| **前提与约束（Premises）** | 仅当工业革命发生在经济领先地区（如英格兰）；社会缺乏足够保障机制时；排除有完善劳动保护的社会 |
| **Falsification（证伪条件）** | 若工业革命期间儿童贫困率未显著上升，或童奴制度未出现，则断言不成立 |

### 🔗 文字版因果链

1. 工业革命在英格兰率先发生，经济结构剧烈重组
2. 重组过程造成社会混乱，部分儿童陷入赤贫
3. 赤贫儿童被转化为'碎片'，即被剥削的童奴
