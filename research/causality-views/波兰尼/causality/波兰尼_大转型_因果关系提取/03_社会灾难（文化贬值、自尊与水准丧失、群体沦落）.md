# 社会灾难（文化贬值、自尊与水准丧失、群体沦落）

> 属于因果簇：[[波兰尼《大转型》因果关系提取]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 文化环境的解体（即社会制度与价值体系的破坏，或文化真空） |
| **DV（因变量）** | 社会灾难（文化贬值、自尊与水准丧失、群体沦落） |
| **Chain（传导链）** | 社会制度与观念体系受到外部冲击或内部急剧变化（如工业革命、殖民接触） → 人们原有的生活方式、社会角色和尊严维护机制被摧毁 → 文化目标丧失，个体陷入‘文化真空’ → 即使经济水平未恶化，群体也经历社会性堕落（如卡菲尔人、早期英国工人） → 社会灾难表现为自尊丧失、技能荒废、厌倦绝望等文化后果 |
| **Lag（时滞）** | 通常在不超过半个世纪的时间内发生（工业革命为例），但文本说明“不会经常发生” |
| **Threshold（临界值）** | 未明确量化；当制度设置遭受“致命创伤”且无法继续提供社会整合目标时 |
| **前提与约束（Premises）** | 社会灾难首先是文化现象，而不是经济现象；经济剥削或收入下降不是社会灾难的直接原因，但可能为文化解体提供工具；类似情况出现在同一社会内部阶级变迁及跨文化接触中 |
| **Falsification（证伪条件）** | 若能证明纯粹的经济恶化（而没有文化制度解体）可以导致同等的社会灾难，或证明工业革命期间劳工阶级仅因收入提升而未发生文化灾变，则该断言被削弱。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 鱼被换到干净的鱼缸里不会死，但如果把鱼缸的原生环境（水草、底砂、同伴）全部拿走，鱼即使有食物也会因失去生态位而衰竭——文化环境就是人的生态位。

### 🔗 文字版因果链

1. 社会制度与观念体系受到外部冲击或内部急剧变化（如工业革命、殖民接触）
2. 人们原有的生活方式、社会角色和尊严维护机制被摧毁
3. 文化目标丧失，个体陷入‘文化真空’
4. 即使经济水平未恶化，群体也经历社会性堕落（如卡菲尔人、早期英国工人）
5. 社会灾难表现为自尊丧失、技能荒废、厌倦绝望等文化后果
