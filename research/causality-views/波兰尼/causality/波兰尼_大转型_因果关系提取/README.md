# 波兰尼《大转型》因果关系提取（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：波兰尼_大转型_因果关系提取.md

## 总体因果图

- 自发调节的市场经济的扩张（将土地、劳动力、货币商品化） → 社会各阶层的自我保护运动（‘集体主义’干预与保护立法）
- 社会整体状况（由外在原因如气候变化、战争、新敌人、新发明等决定的挑战） → 阶级的兴衰、奋斗目标及其实现程度、阶级间合作或对立
- 文化环境的解体（即社会制度与价值体系的破坏，或文化真空） → 社会灾难（文化贬值、自尊与水准丧失、群体沦落）
- 市场扩张对社会性利益（身份、安全、生活稳定、社区环境等）的普遍威胁 → 跨阶层广泛参与的保护主义干预（包括非经济性的立法如卫生、公共
