# 大转型机制卡14_第八章前奏与后果

## 历史背景

18世纪末的英国正处于工业革命高歌猛进时期，旧的劳工法律体系（工匠法、济贫法、安居法）仍以教区为单位实行管制和父爱主义，限制劳动力流动。1795年，在安居法部分取消、劳动力流动恢复的同时，斯品汉姆兰法令被引入，试图以教区补助工资的方式保证“生存权”，却成为劳动力全国性市场形成的重大障碍，最终导致贫困化加剧和社会保护的激烈冲突。1834年《济贫法修正案》废除了斯品汉姆兰体系，才使竞争性劳动力市场在英国真正形成。

## 机制描述

斯品汉姆兰法令最初只是权宜之计，但极少有哪个制度如它这般决定性地塑造了整个文明的命运。法令的核心是：不论劳动者收入多少，教区都按家计补足其家庭生存所需，且以“所外救济”形式发放，不要求住进济贫所。这实际上是“对规制主义和家长制变本加厉的回归”，其背景是“蒸汽机呼唤着劳动者的自由、机器渴求人手”的时刻。与安居法退出同步，斯品汉姆兰法令宣称“任何人都不需要恐惧饥饿”，与全国性劳动力市场需要的自由流动形成明显矛盾。

波兰尼指出，这一机制的动力根源于发端环境：地主阶层在无法拒绝劳动力流动的形势下，试图通过收入补助，既接受全国性自由劳动力市场，又避免地方高工资和乡村动荡。其后果是：劳动力市场无法真正形成，隐性失业与贫困化互相强化，赤贫者数量急剧增长；同时，由于贸易波动掩盖了绝对增长，贫困的成因在当时难以被察觉。斯品汉姆兰法令最终被1834年修正案消除，而“19世纪的社会史正是由从1834年《济贫法修正案》中得到解放的市场体系的逻辑所决定的”。

## 波兰尼的分析

波兰尼将斯品汉姆兰法令视为理解19世纪文明降生过程的钥匙。他强调，这项法令不仅具有经济和政治效果，更在无意识层面型塑了现代社会意识：“赤贫者的形象——尽管此后几乎被完全遗忘——支配了当时的讨论。”贫困与富足同时增长的奇特现象，迫使人们去发现“社会”这一新的实在，并通过政治经济学进入意识。由此产生的巨大精神震动，分别表现为“进步与完善”的希望和“决定论与诅咒”的绝望，并在经济自由主义与阶级观念中预先构成矛盾。他还特别指出，欧文独自察觉到“人类可能性是被社会本身的法则所限制”，但他的洞见被遗忘了一个世纪。

## 与当代的类比

- 当代关于“全民基本收入”或“最低收入保障”的讨论，与斯品汉姆兰法令“保证生存权”的尝试面临类似的困境：地方性救济如何与全国性劳动力市场竞争共存？
- 全球化时代的产业转移、乡村“被遗弃”问题，与19世纪英格兰乡村贫困随世界贸易冲击而加剧的机制相似——本地失业往往源于远方市场的波动。
- 现代福利国家的“社会保护”与市场自我调节之间的紧张，仍是移民、福利、贸易政策辩论的核心矛盾。

## 关键数据

| 年份/时段 | 法案/事件 | 要点 |
|---|---|---|
| 1563 | 工匠法 | 强迫劳动、七年学徒期、工资年度评估，构成英国劳工法律的一半 |
| 1601 | 济贫法 | 教区向有劳动能力者提供工作；救济依靠地方税；组成约16000个济贫机构 |
| 1662 | 安居法 | 限制人们在教区外定居，防止教区被赤贫者“挤瘫” |
| 1660 | 王政复辟 | 工资年度评估条款在大部分地区被悬置 |
| 1795 | 斯品汉姆兰法令 | 保证生存权；普遍化工资补助；家庭补助；所外救济 |
| 1813–1814 | 工匠法部分条款废除 | 评估条款取消（1813），工资条款废弃（1814） |
| 1785 | 观察节点 | 英国公众对经济生活主要变化仍毫无察觉 |
| 1834 | 济贫法修正案 | 废除斯品汉姆兰体系，竞争性劳动力市场形成 |
| 至1850 | 不确定时期 | 仍无人敢确认工业革命带来的全面后果 |
