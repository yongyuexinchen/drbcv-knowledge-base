# 社会群体（阶级或民族）的堕落与退化（丧失自尊、水准、文化目标

> 属于因果簇：[[集体主义保护运动是社会自我保护而非阶级阴谋]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 文化环境的解体（社会制度与价值体系被破坏） |
| **DV（因变量）** | 社会群体（阶级或民族）的堕落与退化（丧失自尊、水准、文化目标） |
| **Chain（传导链）** | 外部力量（如市场体系、殖民接触）强加于不同组织方式的社会 → 原有社会制度（如部落结构、乡村共同体）被迅速破坏 → 个体失去文化认同与努力目标，陷入文化真空 → 表现为堕落、厌倦、放荡或社会性死亡，而非单纯的经济贫困 |
| **Lag（时滞）** | 文化接触或社会剧变后，数年至数十年内显现 |
| **Threshold（临界值）** | 当制度破坏达到使原有文化无法提供生存意义与目标时，退化必然发生 |
| **前提与约束（Premises）** | 文化接触发生在强弱不对等的社会之间，或同一社会内部阶级地位剧变时；经济剥削可能提供工具，但非直接原因；文化需求不能由经济满足自动替代 |
| **Falsification（证伪条件）** | 若能证明文化解体后群体仅因经济改善而自动恢复社会功能与自尊，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引用南非卡菲尔人、英国早期工人阶级案例） |
| **Conflicts（观点冲突）** | 与经济主义观点（经济需求会自动填补文化真空）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同拆毁一座古建筑的承重结构（社会制度），即使留下砖瓦（经济资源），建筑整体（社会文化）也会坍塌，而非自动重建

### 🔗 文字版因果链

1. 外部力量（如市场体系、殖民接触）强加于不同组织方式的社会
2. 原有社会制度（如部落结构、乡村共同体）被迅速破坏
3. 个体失去文化认同与努力目标，陷入文化真空
4. 表现为堕落、厌倦、放荡或社会性死亡，而非单纯的经济贫困
