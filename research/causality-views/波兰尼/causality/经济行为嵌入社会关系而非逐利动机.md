# 经济行为嵌入社会关系而非逐利动机

> **领域**：经济人类学、经济社会学　|　**来源**：波兰尼_chapter_32_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会关系结构（互惠、竞争、社会认可、工作享受） |
| **DV（因变量）** | 经济行为模式（劳动供给、交换、分配） |
| **Chain（传导链）** | 社会关系结构提供非经济动机（互惠、竞争、社会认可、工作享受） → 这些动机驱动个体参与劳动和交换，而非单纯逐利 → 经济行为嵌入社会关系网络中，形成互惠链和再分配机制 → 物质货品的分配通过非经济动机保证，经济体系成为社会事务 |
| **Lag（时滞）** | 长期（互惠链在长期中平衡） |
| **Threshold（临界值）** | 无明确量化阈值；互惠链需长期平衡 |
| **前提与约束（Premises）** | 适用于初民社会及前现代经济体系；排除受外来文明影响或现代市场经济主导的情况；社会关系网络完整且对称（结构二重性） |
| **Falsification（证伪条件）** | 若发现初民社会中存在大量以逐利为目的的独立个体交易，且劳动供给严格限于必要最小值，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证；引用多个民族志案例（如毛利人、安达曼岛民、特罗布里恩德岛民） |
| **Conflicts（观点冲突）** | 与曼彻斯特自由主义者的经济人假设冲突；与古典经济学理性逐利模型冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家庭聚餐中，成员做饭洗碗并非为了赚钱，而是出于亲情、互惠和认可，经济行为是社会关系的延伸

### 🔗 文字版因果链

1. 社会关系结构提供非经济动机（互惠、竞争、社会认可、工作享受）
2. 这些动机驱动个体参与劳动和交换，而非单纯逐利
3. 经济行为嵌入社会关系网络中，形成互惠链和再分配机制
4. 物质货品的分配通过非经济动机保证，经济体系成为社会事务

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 互惠与再分配原则 |
| **DV（因变量）** | 经济体系的运行与政治权力结构 |
| **Chain（传导链）** | 互惠原则通过制度对称性（结构二重性）实现 → 再分配原则通过货物向中央集中再分配给共同体成员 → 再分配功能成为中央机构政治权力的主要来源 → 经济体系因此嵌入社会政治结构，而非独立市场 |
| **Lag（时滞）** | 即时至长期（随制度发展） |
| **Threshold（临界值）** | 需要制度对称性和中央集权存在 |
| **前提与约束（Premises）** | 适用于初民社会及古式帝国（如印加、埃及、巴比伦）；社会分层明确，存在领导阶层；排除现代自发调节市场体系 |
| **Falsification（证伪条件）** | 若发现初民社会或古式帝国中经济分配完全通过市场交易而非互惠再分配，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证；引用密克罗尼西亚、波利尼西亚国王分配收益的案例 |
| **Conflicts（观点冲突）** | 与市场自发调节理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同社区合作社，成员轮流贡献农产品，由中心统一分配，分配权成为领导者的权威来源

### 🔗 文字版因果链

1. 互惠原则通过制度对称性（结构二重性）实现
2. 再分配原则通过货物向中央集中再分配给共同体成员
3. 再分配功能成为中央机构政治权力的主要来源
4. 经济体系因此嵌入社会政治结构，而非独立市场

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部接触（贸易、货币、市场引入） |
| **DV（因变量）** | 初民社会内部经济结构的变化 |
| **Chain（传导链）** | 贸易最初发生在共同体之间而非内部 → 货币和市场作为外部现象被引入 → 外部接触逐渐改变内部经济行为，但初期影响有限 → 内部经济仍以互惠和再分配为主，直至外部力量深化 |
| **Lag（时滞）** | 长期（数代至数百年） |
| **Threshold（临界值）** | 外部接触需达到一定强度（如殖民、大规模贸易） |
| **前提与约束（Premises）** | 适用于未受外来文明影响的初民社会；外部接触初期，内部社会关系网络仍主导；排除现代全球化全面渗透的情况 |
| **Falsification（证伪条件）** | 若发现初民社会在无外部接触情况下自发产生市场、货币和逐利劳动，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证；引用提扣皮亚人、中世纪贸易案例 |
| **Conflicts（观点冲突）** | 与古典经济学认为市场是自然演进产物的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同偏远村庄，村民间以物易物和互助为主，外来商人带来货币后，初期仍以人情往来为主，货币仅用于与外人交易

### 🔗 文字版因果链

1. 贸易最初发生在共同体之间而非内部
2. 货币和市场作为外部现象被引入
3. 外部接触逐渐改变内部经济行为，但初期影响有限
4. 内部经济仍以互惠和再分配为主，直至外部力量深化
