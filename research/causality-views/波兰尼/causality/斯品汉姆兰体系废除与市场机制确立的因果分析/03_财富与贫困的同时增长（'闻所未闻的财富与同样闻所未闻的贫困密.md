# 财富与贫困的同时增长（'闻所未闻的财富与同样闻所未闻的贫困密

> 属于因果簇：[[斯品汉姆兰体系废除与市场机制确立的因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场机制的确立（劳动商品化） |
| **DV（因变量）** | 财富与贫困的同时增长（'闻所未闻的财富与同样闻所未闻的贫困密不可分'） |
| **Chain（传导链）** | 市场机制要求人类劳动变成商品，劳动力被置于供需法则之下 → 劳动商品化导致工资由市场决定，而非道德或传统决定 → 市场扩张带来财富积累，但同时也产生大量失业和贫困人口 → 财富与贫困成为同一过程的双面结果，社会分裂为两个国度 |
| **Lag（时滞）** | 数十年（从18世纪末到19世纪中叶） |
| **Threshold（临界值）** | 市场机制全面确立，劳动成为商品 |
| **前提与约束（Premises）** | 工业资本主义已发展成熟；传统社会保护机制（如斯品汉姆兰体系）被废除；政治经济学理论（马尔萨斯、李嘉图等）为市场法则提供合法性 |
| **Falsification（证伪条件）** | 若市场机制确立后财富增长而贫困减少，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典政治经济学认为市场机制能普遍提高福利的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同硬币的两面，市场机制铸造财富的同时也铸造了贫困

### 🔗 文字版因果链

1. 市场机制要求人类劳动变成商品，劳动力被置于供需法则之下
2. 劳动商品化导致工资由市场决定，而非道德或传统决定
3. 市场扩张带来财富积累，但同时也产生大量失业和贫困人口
4. 财富与贫困成为同一过程的双面结果，社会分裂为两个国度
