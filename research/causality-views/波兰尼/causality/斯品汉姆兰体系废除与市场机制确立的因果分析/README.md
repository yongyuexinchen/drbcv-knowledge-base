# 斯品汉姆兰体系废除与市场机制确立的因果分析（因果簇）

## 总体因果图

- 废除斯品汉姆兰体系（1834年济贫法改革） → 劳动大众非人化与所有者阶级道德降格，形成'两个国度'的社会分
- 斯品汉姆兰体系的'生存权'救济政策 → 劳动大众的贫困化与非人化
- 市场机制的确立（劳动商品化） → 财富与贫困的同时增长（'闻所未闻的财富与同样闻所未闻的贫困密
