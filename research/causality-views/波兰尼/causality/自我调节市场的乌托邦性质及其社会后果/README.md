# 自我调节市场的乌托邦性质及其社会后果（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：自我调节市场的乌托邦性质及其社会后果.md

## 总体因果图

- 自我调节市场的理念（作为19世纪制度体系的核心） → 社会与自然环境的毁灭（人类被摧毁、环境变成荒野）
- 国际金融（hautefinance）作为19世纪和平利益的社会机制 → 1815-1914年百年和平的维持
- 势力均衡体系（在19世纪） → 和平（而非战争）
