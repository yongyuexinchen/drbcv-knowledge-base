# 大转型机制卡01_第1块（因果簇）

## 总体因果图

- 私有化缺乏合法性 + 资本外逃恐惧 → 俄罗斯经济崩溃
- 短期资本流释放 → 东亚金融危机 → 新自由主义趁机废除社会契约
- 市场失灵时政府干预 → 市场稳定（香港反例）
