# 大转型机制卡23_第十三章

## 历史背景
19世纪后期至20世纪初，西方殖民扩张与自由贸易将市场经济强加于非西方社会，同时在西方本土工业革命瓦解传统乡村秩序。殖民地社会（非洲、印度、北美原住民）与早期资本主义社会的劳动者均遭遇制度性瓦解，社会学家图恩瓦尔德指出黑人社会的文化灾变与早期白人社会经历惊人相似。

## 机制描述
市场经济不是单纯的经济交换扩展，而是通过强制手段将劳动力、土地、货币转化为虚拟商品，破坏一切非契约的有机社会关系（亲属、邻里、同业、信仰）。具体传导路径：

- **在殖民地**：为迫使土著出卖劳动力，殖民地当局人为制造食物匮乏（砍倒面包树）、征收房屋税，摧毁传统社会组织（如卡菲尔人的村庄土地制度、夸扣特尔人的分配网络）。一旦有机社会崩溃，个体失去共同体保障，只能服从劳动力市场的“饥饿惩罚”。
- **在印度**：英国摧毁村社共同体后，手工织品恰达因机织布竞争而永久滞销，粮食被卷入自由市场，地方粮仓停转，饥荒时穷人无力购买高价粮食。东印度公司垄断时期尚可依靠乡村组织分粮，自由贸易引入后反而“成百万地死去”。
- **在北美**：1887年对印第安人强制土地分配，从经济个体利益看似乎有益，却导致整个种族几近肉体消灭；1890年鬼舞游戏是文化休克的表现。
- **在早期英国**：斯品汉姆兰法令试图保护传统乡村组织，但1834年济贫法修正将其废除，并通过饥饿惩罚逼使劳动者接受工厂工资；地主、教会、托利社会主义者转而支持工厂法，最终促成1847年十小时工作制法案。

## 波兰尼的分析
- **剥削概念不足以解释灾变**：经济定义上的剥削（交换比率长期不平等）在殖民中未必成立，廉价倾销意味着没有高额利润；真正的根源是“制度性破坏”——土地和劳动力商品化瓦解了社会本身。即使剥夺不是暴力、甚至经济生活水平有所改善，这种文化退化依然是灾难。
- **经济主义偏见扭曲视野**：它既催生粗俗剥削理论，也催生否认社会灾变的新自由主义史观。这种“对历史的重新解释”旨在把自由放任体制重建为正义，把所有病症归咎于对经济自由主义的背离。
- **保护运动的根源不是阶级利益，而是社会自我保护**：市场分别攻击人（劳动力）、自然（土地）、生产组织（货币），受威胁的社会整体推动反向运动，只是责任常落到特定群体（如英国地主）肩上。

## 与当代的类比
- **全球南方的结构调整与自由贸易协定**：对传统农业社区造成类似“有机社会解体—饥饿—文化退化”的连锁反应，如粮食市场自由化后地方储备功能丧失。
- **零工经济与福利削减**：平台算法与劳动法“灵活化”重新诉诸“饥饿的鞭策力”，迫使个体脱离社保网络接受任意低工资。
- **“保护主义”污名化**：当代将产业政策、农业补贴、移民限制等自我保护运动一律贬为“反市场”，重演19世纪将保护主义视为“荒唐犯罪”的叙事。

## 关键数据
| 年份/时段 | 事件/法案 | 后果 |
|---|---|---|
| 19世纪下半叶 | 印度兰开夏机织布竞争与饥荒 | 人口缩减一成以上的大饥荒三四次；饥荒根源为粮食市场化与地方收入降低 |
| 1887 | 北美印第安人强制土地分配 | 种族近于从肉体被消灭；半个世纪后科利尔主张恢复部落土地所有制 |
| 1890 | 鬼舞版波尼族游戏 | 记录破坏性文化接触造成的文化休克 |
| 1834 | 济贫法修正法案 | 将工人阶级排除出救济、与赤贫者区分，确立劳动力市场“饥饿惩罚” |
| 1832 | 国会修正法案 | 拒绝工人阶级投票权，从政治上定义工人阶级 |
| 1846 | 反谷物法 | 在斯品汉姆兰废止和工厂壮大后铺平成功道路 |
| 1847 | 十小时工作制法案 | 马克思称为“社会主义首次胜利”；开明保守派之功 |
| 16世纪 | 都铎王朝圈地运动 | 制造成群结队流浪者；类似效果重现于非洲殖民地 |

- “从经济上讲，印度可能——从长期来看情况当然如此——已从经济自由中受益，但从社会上讲，她被解体了，成为苦难和退化的牺牲品。”（第168页）
- “只有饥饿的惩罚而不是高工资的诱惑才创造了有效运行的劳动力市场。”（第173页）
