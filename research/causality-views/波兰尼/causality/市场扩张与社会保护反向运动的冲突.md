# 市场扩张与社会保护反向运动的冲突

> **领域**：宏观经济学、经济社会学　|　**来源**：波兰尼_chapter_18_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自我调节市场的不断扩张（商品化虚构将劳动力、土地和货币视为商品） |
| **DV（因变量）** | 社会反向运动（保护性立法、限制性社团等干涉手段）及其与市场体系的不兼容性，最终导致社会紧张和灾难 |
| **Chain（传导链）** | 市场体系将劳动力、土地和货币商品化，使其从属于供给和需求 → 这种商品化虚构破坏了人的社会环境、邻里关系、自然生态和生产组织 → 社会为自我保护而发起反向运动，通过立法和干预控制市场活动 → 反向运动与市场的自我调节原则不相容，导致经济自由主义与社会保护之间的持续冲突 → 冲突与阶级斗争纠缠，最终可能引发危机甚至法西斯主义等大灾难 |
| **Lag（时滞）** | 数十年至百年尺度（如从19世纪初市场扩张到1914年左右达到全球极限，再到20世纪法西斯主义兴起） |
| **Threshold（临界值）** | 当市场扩张吞没所有空间和时间、达到全球极限（约1914年）时，反向运动的冲突达到临界点 |
| **前提与约束（Premises）** | 仅当市场体系按自我调节原则组织生产、劳动和土地时成立；仅当社会各阶级（土地贵族、中产阶级、工人阶级）利益分化且政治经济功能被作为局部利益武器时；排除市场体系未完全建立或社会保护机制未形成的情况 |
| **Falsification（证伪条件）** | 如果市场扩张未引发持续的社会保护运动，或反向运动能与市场自我调节兼容共存而不产生社会紧张，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及1914年时间点，但无具体数字） |
| **Conflicts（观点冲突）** | 与经济自由主义信条（认为自由放任是自然形成、市场自我调节可自发实现社会最优）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人不断扩张自己的活动范围，挤压他人的生存空间，最终引发邻居们的集体反抗，而这种反抗又使得整个社区陷入持续的紧张和冲突，无法回到原来的和谐状态。

### 🔗 文字版因果链

1. 市场体系将劳动力、土地和货币商品化，使其从属于供给和需求
2. 这种商品化虚构破坏了人的社会环境、邻里关系、自然生态和生产组织
3. 社会为自我保护而发起反向运动，通过立法和干预控制市场活动
4. 反向运动与市场的自我调节原则不相容，导致经济自由主义与社会保护之间的持续冲突
5. 冲突与阶级斗争纠缠，最终可能引发危机甚至法西斯主义等大灾难
