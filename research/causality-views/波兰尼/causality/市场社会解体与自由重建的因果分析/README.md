# 市场社会解体与自由重建的因果分析（因果簇）

> 因果簇索引：7 个子因果卡。父卡文件：市场社会解体与自由重建的因果分析.md

## 总体因果图

- 土地、劳动力和货币被移出市场之外（即废除商品化虚构假象） → 统一市场经济的解体，导致各种新社会的形成，但市场本身并未消失
- 金本位制和立宪政府的存在 → 势力均衡作为和平的推进装置得以运转
- 金本位制自发调节机制的消失 → 各国政府能够放弃绝对主权国在国际经济领域拒绝合作的措施，并容
- 自由主义哲学宣称权力和强制就是罪恶，自由要求它们从人类共同体中消失 → 自由在法西斯主义面前的彻底破灭
- 规制和控制（计划）的使用 → 自由的扩大和加强（而非减少）
- 社会整合的进展和计划的发展 → 自由的增长和个体权利的加强
- 对社会现实的接受（顺应） → 自由的重生（而非终结）
