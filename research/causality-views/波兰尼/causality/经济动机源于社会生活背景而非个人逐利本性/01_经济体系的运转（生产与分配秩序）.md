# 经济体系的运转（生产与分配秩序）

> 属于因果簇：[[经济动机源于社会生活背景而非个人逐利本性]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会结构中的对称和辐辏制度模式（社会组织形式） |
| **DV（因变量）** | 经济体系的运转（生产与分配秩序） |
| **Chain（传导链）** | 社会组织的对称模式促进互惠行为，使个体之间形成成对关系，便于财物与服务的取与予 → 社会组织的辐辏模式为财物与服务的收集、贮存和再分配提供轨迹 → 互惠和再分配原则在对称和辐辏结构中得以实施，无需个体经济动机 → 劳动分工自动得到保证，经济义务必然被履行，经济体系得以运转 |
| **Lag（时滞）** | 即时生效，制度模式与行为原则相互调节，无显著时滞 |
| **Threshold（临界值）** | 社会组织必须符合对称（对偶性）和辐辏（中心性）模式，且群体规模与领土范围需在可协调范围内 |
| **前提与约束（Premises）** | 适用于无文字、无复杂行政管理的初民社会或传统社会；共同体保护所有成员免于饥饿，个人经济利益非至关重要；社会义务具有互惠性，长期来看履行社会义务符合个体利益；排除以市场交换和逐利动机为主导的现代市场经济体系 |
| **Falsification（证伪条件）** | 若发现一个无文字社会中经济体系运转完全不依赖互惠和再分配原则，且无对称或辐辏制度模式支撑，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于特罗布里恩群岛、夸扣特尔人、古埃及等民族志案例） |
| **Conflicts（观点冲突）** | 与古典经济学家（如亚当·斯密）认为人类具有自然交换和交易秉性的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一台精密钟表，齿轮（对称结构）和中心轴（辐辏结构）咬合得当，钟表自然走动，无需每颗齿轮自己“想”着要转动——社会结构就是钟表框架，互惠和再分配就是齿轮传动，经济秩序是钟表走动的结果。

### 🔗 文字版因果链

1. 社会组织的对称模式促进互惠行为，使个体之间形成成对关系，便于财物与服务的取与予
2. 社会组织的辐辏模式为财物与服务的收集、贮存和再分配提供轨迹
3. 互惠和再分配原则在对称和辐辏结构中得以实施，无需个体经济动机
4. 劳动分工自动得到保证，经济义务必然被履行，经济体系得以运转
