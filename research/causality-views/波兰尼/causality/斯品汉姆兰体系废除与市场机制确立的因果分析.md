# 斯品汉姆兰体系废除与市场机制确立的因果分析

> **领域**：经济史与社会学　|　**来源**：波兰尼_chapter_15_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 废除斯品汉姆兰体系（1834年济贫法改革） |
| **DV（因变量）** | 劳动大众非人化与所有者阶级道德降格，形成'两个国度'的社会分裂 |
| **Chain（传导链）** | 斯品汉姆兰体系以'生存权'名义提供所外救济，实则掠夺大众，扭曲劳动市场 → 1834年新济贫法取消工资补助，重新引入习艺所测试，并使其成为耻辱性、心理和道德煎熬的场所 → 济贫管理权从地方治安法官转移到中央监督下的济贫管理员，实行全国性、区别性管理 → 赤贫者葬礼被仪式化地隔离，强化社会排斥，劳动大众被非人化 → 所有者阶级拒绝承担对穷困邻人的责任，传统基督教社会整合瓦解，富裕者与贫困者形成两个对立国度 |
| **Lag（时滞）** | 数十年至数代（从1834年改革到社会结构完全转型） |
| **Threshold（临界值）** | 1834年济贫法改革作为制度性临界点，废除所外救济并重新引入习艺所测试 |
| **前提与约束（Premises）** | 工业资本主义已具备充分发展条件，市场机制需要自由劳动力；斯品汉姆兰体系已深入社会骨髓，其废除是制度转型的必要条件；社会各阶层（包括劳工自身）认同新体系的信念基础 |
| **Falsification（证伪条件）** | 若1834年后劳动大众的社会地位改善、所有者阶级承担更多责任、社会整合增强，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为济贫法改革是进步性人道主义改革的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同拆除旧屋的承重墙，虽然表面上是改善结构，但实际导致整栋建筑（社会）的崩塌和分裂

### 🔗 文字版因果链

1. 斯品汉姆兰体系以'生存权'名义提供所外救济，实则掠夺大众，扭曲劳动市场
2. 1834年新济贫法取消工资补助，重新引入习艺所测试，并使其成为耻辱性、心理和道德煎熬的场所
3. 济贫管理权从地方治安法官转移到中央监督下的济贫管理员，实行全国性、区别性管理
4. 赤贫者葬礼被仪式化地隔离，强化社会排斥，劳动大众被非人化
5. 所有者阶级拒绝承担对穷困邻人的责任，传统基督教社会整合瓦解，富裕者与贫困者形成两个对立国度

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰体系的'生存权'救济政策 |
| **DV（因变量）** | 劳动大众的贫困化与非人化 |
| **Chain（传导链）** | 斯品汉姆兰体系提供所外救济，看似保障生存权，实则使劳工依赖救济而丧失自立能力 → 救济制度掩盖了劳动市场的真实供需，阻碍了劳动力商品化进程 → 劳工被剥夺了通过市场交换获得尊严的机会，沦为救济对象，被非人化 → 贫困化加剧，劳动大众从'人'变为'梦魇中的鬼魂' |
| **Lag（时滞）** | 数十年（从1795年斯品汉姆兰法令到1834年废除） |
| **Threshold（临界值）** | 斯品汉姆兰法令的实施本身即构成贫困化的临界条件 |
| **前提与约束（Premises）** | 救济水平与面包价格挂钩，导致工资被压低；劳工阶层接受救济作为生存手段，形成依赖 |
| **Falsification（证伪条件）** | 若斯品汉姆兰体系下劳工生活水平提高、社会地位改善，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为斯品汉姆兰体系是保护穷人免受市场冲击的正面观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同给溺水者一根稻草，看似救命，实则让他沉得更快

### 🔗 文字版因果链

1. 斯品汉姆兰体系提供所外救济，看似保障生存权，实则使劳工依赖救济而丧失自立能力
2. 救济制度掩盖了劳动市场的真实供需，阻碍了劳动力商品化进程
3. 劳工被剥夺了通过市场交换获得尊严的机会，沦为救济对象，被非人化
4. 贫困化加剧，劳动大众从'人'变为'梦魇中的鬼魂'

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场机制的确立（劳动商品化） |
| **DV（因变量）** | 财富与贫困的同时增长（'闻所未闻的财富与同样闻所未闻的贫困密不可分'） |
| **Chain（传导链）** | 市场机制要求人类劳动变成商品，劳动力被置于供需法则之下 → 劳动商品化导致工资由市场决定，而非道德或传统决定 → 市场扩张带来财富积累，但同时也产生大量失业和贫困人口 → 财富与贫困成为同一过程的双面结果，社会分裂为两个国度 |
| **Lag（时滞）** | 数十年（从18世纪末到19世纪中叶） |
| **Threshold（临界值）** | 市场机制全面确立，劳动成为商品 |
| **前提与约束（Premises）** | 工业资本主义已发展成熟；传统社会保护机制（如斯品汉姆兰体系）被废除；政治经济学理论（马尔萨斯、李嘉图等）为市场法则提供合法性 |
| **Falsification（证伪条件）** | 若市场机制确立后财富增长而贫困减少，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典政治经济学认为市场机制能普遍提高福利的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同硬币的两面，市场机制铸造财富的同时也铸造了贫困

### 🔗 文字版因果链

1. 市场机制要求人类劳动变成商品，劳动力被置于供需法则之下
2. 劳动商品化导致工资由市场决定，而非道德或传统决定
3. 市场扩张带来财富积累，但同时也产生大量失业和贫困人口
4. 财富与贫困成为同一过程的双面结果，社会分裂为两个国度
