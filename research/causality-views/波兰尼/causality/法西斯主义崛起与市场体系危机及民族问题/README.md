# 法西斯主义崛起与市场体系危机及民族问题（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：法西斯主义崛起与市场体系危机及民族问题.md

## 总体因果图

- 市场体系的状况（尤其是1929年后的普遍危机） → 法西斯主义作为一种世界性力量的崛起与掌权
- 未解决的民族问题（德国获取国际平等地位的目标受阻） → 纳粹主义获得大众支持并掌权，将德国引向罪行
- 英国坚持金本位制和保守财政政策 → 英国军事上无准备，在二战初期丧失先手优势
- 世界经济的解体（国际市场无法吸收俄国农产品、势力均衡体系缺失） → 俄国被迫走上自给自足的社会主义道路（集体农庄、一国社会主义）
- 自发调节市场的乌托邦试验（市场社会以自利为基础） → 19世纪文明的解体（社会为自我保护而采取的措施摧毁了市场社会
