# 19世纪文明的解体（社会为自我保护而采取的措施摧毁了市场社会

> 属于因果簇：[[法西斯主义崛起与市场体系危机及民族问题]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自发调节市场的乌托邦试验（市场社会以自利为基础） |
| **DV（因变量）** | 19世纪文明的解体（社会为自我保护而采取的措施摧毁了市场社会） |
| **Chain（传导链）** | 市场社会以经济自利为基础，将劳动力、土地、货币商品化 → 自发调节市场与有组织社会生活的基本要求冲突 → 社会采取保护性措施（立法、工会、关税等）对抗市场破坏 → 这些措施产生典型的紧张和压力，最终摧毁19世纪社会 → 外在战争（一战）只是加速了毁灭 |
| **Lag（时滞）** | 19世纪至20世纪初，约一个世纪 |
| **Threshold（临界值）** | 市场与有组织社会生活基本要求之间的冲突达到不可调和的程度 |
| **前提与约束（Premises）** | 除开拓时代的北美等特例外，市场与社会的冲突是普遍动力；19世纪文明的失败不是由于经济规律（利润率下降、消费不足等）；人类行为并非天然追求经济理性，交换倾向并非通常倾向 |
| **Falsification（证伪条件）** | 若自发调节市场能在长期内与社会生活和谐共存而不产生毁灭性冲突，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由主义经济学认为自发调节市场是自然且进步的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像把身体完全交给一个只追求利润的医生（市场），他为了赚钱不断开刀（商品化），身体最终因过度干预而崩溃。

### 🔗 文字版因果链

1. 市场社会以经济自利为基础，将劳动力、土地、货币商品化
2. 自发调节市场与有组织社会生活的基本要求冲突
3. 社会采取保护性措施（立法、工会、关税等）对抗市场破坏
4. 这些措施产生典型的紧张和压力，最终摧毁19世纪社会
5. 外在战争（一战）只是加速了毁灭
