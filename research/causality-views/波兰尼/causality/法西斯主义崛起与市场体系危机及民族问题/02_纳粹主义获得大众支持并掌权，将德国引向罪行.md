# 纳粹主义获得大众支持并掌权，将德国引向罪行

> 属于因果簇：[[法西斯主义崛起与市场体系危机及民族问题]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 未解决的民族问题（德国获取国际平等地位的目标受阻） |
| **DV（因变量）** | 纳粹主义获得大众支持并掌权，将德国引向罪行 |
| **Chain（传导链）** | 德国在一战后处于不平等国际地位，民族问题悬而未决 → 没有革命性起点，德国无法达成国际平等目标 → 纳粹主义以民族问题为杠杆，汲取大众激进民族主义力量 → 纳粹掌权后，将自由平等的德国变成罪行累累的罪犯 |
| **Lag（时滞）** | 一战后至1933年纳粹掌权，约15年 |
| **Threshold（临界值）** | 民族问题成为未解决的、大众高度关切的议题 |
| **前提与约束（Premises）** | 国家处于弱小和依附性地位；存在大众激进民族主义情绪；传统政治力量无法解决民族问题 |
| **Falsification（证伪条件）** | 若德国在无民族问题的情况下纳粹仍能掌权，或民族问题解决后纳粹仍获大众支持，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |

| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人长期被歧视（民族不平等），积累的愤怒（民族主义）容易被极端分子利用，最终带领他走向毁灭。
