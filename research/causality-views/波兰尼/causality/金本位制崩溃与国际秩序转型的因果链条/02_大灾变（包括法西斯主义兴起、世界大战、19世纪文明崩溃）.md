# 大灾变（包括法西斯主义兴起、世界大战、19世纪文明崩溃）

> 属于因果簇：[[金本位制崩溃与国际秩序转型的因果链条]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自我调节市场体系的乌托邦式努力（以获利动机为基础） |
| **DV（因变量）** | 大灾变（包括法西斯主义兴起、世界大战、19世纪文明崩溃） |
| **Chain（传导链）** | 19世纪文明建立在自我调节市场体系之上，以获利为唯一动机 → 该体系赋予市场近乎神秘的力量，忽视社会保护需求 → 市场经济的扩张导致社会剧烈变迁（如工业革命中的民众流离失所） → 社会为自我保护而反抗市场逻辑，产生各种干预措施 → 干预与市场自我调节的矛盾激化，最终导致制度崩溃和极端政治运动（如法西斯主义） |
| **Lag（时滞）** | 约一个世纪（从19世纪初工业革命到20世纪30年代大危机） |
| **Threshold（临界值）** | 当市场自我调节与社会自我保护之间的张力超过社会承受极限时，体系崩溃 |
| **前提与约束（Premises）** | 社会必须受经济因素限制，但19世纪文明将获利动机提升至前所未有的高度；市场体系需要外部制度（如金本位、势力均衡）支撑；排除非市场经济文明（如传统农业社会）的比较 |
| **Falsification（证伪条件）** | 如果存在一个自我调节市场体系长期稳定运行且未导致社会崩溃的案例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，引用工业革命英国案例及西班牙圈地运动后果，无具体量化数据 |
| **Conflicts（观点冲突）** | 与古典自由主义（如斯密、李嘉图）认为市场自发秩序可促进和谐的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个只追求利润的工厂，忽视工人安全，最终因事故而倒闭；市场体系忽视社会保护，最终导致整个文明崩塌

### 🔗 文字版因果链

1. 19世纪文明建立在自我调节市场体系之上，以获利为唯一动机
2. 该体系赋予市场近乎神秘的力量，忽视社会保护需求
3. 市场经济的扩张导致社会剧烈变迁（如工业革命中的民众流离失所）
4. 社会为自我保护而反抗市场逻辑，产生各种干预措施
5. 干预与市场自我调节的矛盾激化，最终导致制度崩溃和极端政治运动（如法西斯主义）
