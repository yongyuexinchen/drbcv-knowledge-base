# 延缓圈地运动速度，减轻社会紊乱程度

> 属于因果簇：[[圈地运动的社会代价与政府干预的缓冲作用]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 都铎王朝和早期斯图亚特王朝的反圈地立法与王权干预 |
| **DV（因变量）** | 延缓圈地运动速度，减轻社会紊乱程度 |
| **Chain（传导链）** | 国王、枢密院、主教等通过立法和行政手段阻止圈地 → 虽未能完全阻止圈地，但延缓了变迁速度 → 为农民适应新经济条件争取时间，减少即时伤害 → 使英国避免因过快变迁而遭受毁灭性破坏 |
| **Lag（时滞）** | 数十年至一个半世纪（1490-1640年持续作用） |
| **Threshold（临界值）** | 干预有效需以变迁速度超过社会承受能力为前提 |
| **前提与约束（Premises）** | 仅当政府有足够权威执行立法时；在市场经济尚未完全建立、市场法则不适用时成立；排除干预完全失效或干预本身造成更大破坏的情况 |
| **Falsification（证伪条件）** | 若反圈地立法未改变圈地速度或社会后果，或干预导致更严重经济倒退，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及反圈地法规未能阻止圈地但可能延缓进程） |
| **Conflicts（观点冲突）** | 与吉宾斯、英尼斯、盖尔德纳等认为保护性法规徒劳无效的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

4. 使英国避免因过快变迁而遭受毁灭性破坏
