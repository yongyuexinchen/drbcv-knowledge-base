# 交换原则的有效性

> 属于因果簇：[[市场模式与交换原则的因果关系]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场模式的存在 |
| **DV（因变量）** | 交换原则的有效性 |
| **Chain（传导链）** | 市场模式为交换或交易提供场所和制度框架 → 交换原则依赖于市场模式才能产生价格 → 没有市场模式，交换秉性无法充分施展，价格无法形成 |
| **Lag（时滞）** | 即时 |
| **Threshold（临界值）** | 市场模式至少局部存在 |
| **前提与约束（Premises）** | 交换原则的有效性以市场模式为前提；市场模式可能在社会中居于从属地位；交换原则与其他原则（互惠、再分配、家计）不同，能创生特定制度 |
| **Falsification（证伪条件）** | 如果发现交换原则在无市场模式的社会中能有效运作并产生价格，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典经济学认为个体交换秉性自然导致市场形成的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同电流需要闭合电路才能流动，交换原则需要市场模式作为其电路

### 🔗 文字版因果链

1. 市场模式为交换或交易提供场所和制度框架
2. 交换原则依赖于市场模式才能产生价格
3. 没有市场模式，交换秉性无法充分施展，价格无法形成
