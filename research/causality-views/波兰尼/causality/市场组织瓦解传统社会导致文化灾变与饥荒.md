# 市场组织瓦解传统社会导致文化灾变与饥荒

> **领域**：经济社会学、宏观经济学、文化人类学　|　**来源**：波兰尼_chapter_21_p2　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自由市场组织（劳动力、土地、货币的虚拟商品化）的引入 |
| **DV（因变量）** | 传统社会制度（村庄共同体、亲属关系、邻里关系等）的瓦解，进而导致文化灾变、社会解体及大规模饥荒 |
| **Chain（传导链）** | 自由市场原则（如契约自由、自由贸易）被强制推行，破坏非契约关系（亲属、邻里、同业、信仰） → 传统社会制度（如印度村庄共同体、卡菲尔人的土地制度）被摧毁，且无法自发恢复 → 个体失去传统保障，被迫依赖市场为生，饥饿成为迫使劳动力出卖的机制 → 在粮食歉收时，市场高价使穷人无力购买，而旧有地方粮仓已失效，导致饥荒 → 社会解体引发文化退化，如北美印第安人强制土地分配后种族濒临灭绝 |
| **Lag（时滞）** | 数十年至数代（如印度19世纪下半叶饥荒持续；北美印第安人强制分配后近半个世纪才出现逆转） |
| **Threshold（临界值）** | 当市场组织取代传统社会制度，且传统保障机制（如地方粮仓、共同体互助）失效时，灾变发生；无明确量化阈值 |
| **前提与约束（Premises）** | 仅当市场组织被强制引入并破坏传统社会制度时成立；在传统社会制度尚存且能抵御市场冲击时，不成立；排除纯粹自然灾害或经济剥削作为主要原因的情况；适用于从传统社会向市场经济转型的时期 |
| **Falsification（证伪条件）** | 如果发现传统社会制度被破坏后，没有出现文化灾变或饥荒，或者饥荒可完全归因于自然因素或剥削，则该断言被推翻 |
| **Data（定量佐证）** | 印度19世纪下半叶多次大饥荒使人口缩减一成以上；1887年北美印第安人强制土地分配后种族几乎被消灭；定性断言为主，辅以历史案例 |
| **Conflicts（观点冲突）** | 与经济自由主义观点冲突，后者认为自由市场带来持续改善，否认社会灾变的存在 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 自由市场原则（如契约自由、自由贸易）被强制推行，破坏非契约关系（亲属、邻里、同业、信仰）
2. 传统社会制度（如印度村庄共同体、卡菲尔人的土地制度）被摧毁，且无法自发恢复
3. 个体失去传统保障，被迫依赖市场为生，饥饿成为迫使劳动力出卖的机制
4. 在粮食歉收时，市场高价使穷人无力购买，而旧有地方粮仓已失效，导致饥荒
5. 社会解体引发文化退化，如北美印第安人强制土地分配后种族濒临灭绝
