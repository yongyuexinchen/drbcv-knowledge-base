# 势力均衡作为历史法则与政治原则（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：势力均衡作为历史法则与政治原则.md

## 总体因果图

- 国家体系中某一单位的势力增长 → 其他单位的势力削弱
- 势力均衡原则的正式承认（如1648年威斯特伐利亚条约） → 小国独立与存在的维持
- 国际私人贸易往来的存在 → 对违反势力均衡原则行为的有效约束
- 贸易性质的改变（从直接武力依赖到规模与成功不依赖武力） → 商业对外交政策影响的停止（1815-1880年）
- 国际通货与信用体系的建立（金本位制） → 新型跨国商业利益的出现及和平利益增强
