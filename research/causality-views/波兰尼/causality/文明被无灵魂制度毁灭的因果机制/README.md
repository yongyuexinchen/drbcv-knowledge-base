# 文明被无灵魂制度毁灭的因果机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：文明被无灵魂制度毁灭的因果机制.md

## 总体因果图

- 一系列没有灵魂的制度的盲目行为（仅以物质福利自发增长为唯一目的） → 一种文明的毁灭
- 经济与政治领域的分离（劳动力、土地、货币的市场化） → 大众政府问题凸显及政治干涉主义再现
- 金本位制的维持（稳健通货信条） → 工党下台、社会服务削减、汇率下跌
- 与金本位脱钩 → 华尔街政治失势，避免社会灾变
- 劳动力商品化虚构（劳动力被视为可在市场上定价的商品） → 罢工被视为对社会有用工作的轻率干扰，社会面临解体威胁
