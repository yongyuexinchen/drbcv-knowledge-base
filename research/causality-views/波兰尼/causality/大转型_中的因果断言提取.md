# 《大转型》中的因果断言提取

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 竞争性劳动力市场的建立（1834年《济贫法修正案》后） |
| **DV（因变量）** | 工人阶级的形成与工业资本主义的确立 |
| **Chain（传导链）** | 斯品汉姆兰法令被废除，济贫法修正案确立竞争性劳动力市场 → 劳动者必须依靠出卖劳动力为生，不再有生存权保障 → 无情机制的压力迫使劳动者结合成一个阶级 → 工业资本主义作为社会制度由此形成 |
| **Lag（时滞）** | 1834年之后数十年 |
| **Threshold（临界值）** | 1834年《济贫法修正案》的通过并废除斯品汉姆兰法令 |
| **前提与约束（Premises）** | 斯品汉姆兰法令被完全废除；劳动力市场在全国范围内形成；劳动者失去土地等生产资料，只能依赖工资生存 |
| **Falsification（证伪条件）** | 若发现即使没有竞争性劳动力市场工人阶级依然形成，或1834年前工业资本主义已作为社会制度存在，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 好比拆除安全网后，人们被迫联合起来自救，从而形成了新的集体力量。

### 🔗 文字版因果链

1. 斯品汉姆兰法令被废除，济贫法修正案确立竞争性劳动力市场
2. 劳动者必须依靠出卖劳动力为生，不再有生存权保障
3. 无情机制的压力迫使劳动者结合成一个阶级
4. 工业资本主义作为社会制度由此形成

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法令（以救济金补助低收入者，保证生存权） |
| **DV（因变量）** | 社会灾难（贫困化、道德堕落、社会无根性） |
| **Chain（传导链）** | 法令提供普遍化的工资补助，使雇主可以压低工资 → 劳动者收入与劳动贡献脱钩，工作激励下降，生产效率降低 → 贫困人口反而增加，社会道德腐化 → 劳动制度僵化，阻碍劳动力流动，导致社会危机 |
| **Lag（时滞）** | 1795年至1834年间 |
| **Threshold（临界值）** | 补助标准低于生存需要且广泛适用于所有低工资劳动者时 |
| **前提与约束（Premises）** | 法令在工业革命高速发展的背景下实施；与《安居法》的取消同时发生；地方教区执行且缺乏统一标准 |
| **Falsification（证伪条件）** | 若有证据表明斯品汉姆兰法令实际上促进了经济繁荣而未造成社会灾难，则此断言被推翻。 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 给所有孩子发糖果，结果孩子们不再努力吃饭，反而营养不良。

### 🔗 文字版因果链

1. 法令提供普遍化的工资补助，使雇主可以压低工资
2. 劳动者收入与劳动贡献脱钩，工作激励下降，生产效率降低
3. 贫困人口反而增加，社会道德腐化
4. 劳动制度僵化，阻碍劳动力流动，导致社会危机

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农业革命（圈地运动、农地合并、农业技术改进） |
| **DV（因变量）** | 劳动者失去家庭收入与土地背景，依赖货币工资，推动工业革命 |
| **Chain（传导链）** | 圈地和合并农地剥夺了农民对公地、菜园的使用权 → 家庭手工业的两大支柱——家庭收入和农业背景——丧失 → 劳动者对货币收入的依赖变得绝对化 → 家庭经济丧失失业保险功能，劳动者被迫进入工厂工作 → 工业无产阶级形成，工业革命加速推进 |
| **Lag（时滞）** | 数十年（农业革命与工业革命之间） |
| **Threshold（临界值）** | 农业理性化使大多数劳动者无法维持家庭生产时 |
| **前提与约束（Premises）** | 家庭手工业依赖小菜园、放牧权利等补充收入；农业技术变革导致人口向工业部门转移；原有乡村共同体未能提供替代保障 |
| **Falsification（证伪条件）** | 若发现即使没有农业革命工业革命依然发生，或农业革命并未导致劳动者失去土地保障，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 砍掉果树之后，人们只能去买水果，最终完全依赖市场。

### 🔗 文字版因果链

1. 圈地和合并农地剥夺了农民对公地、菜园的使用权
2. 家庭手工业的两大支柱——家庭收入和农业背景——丧失
3. 劳动者对货币收入的依赖变得绝对化
4. 家庭经济丧失失业保险功能，劳动者被迫进入工厂工作
5. 工业无产阶级形成，工业革命加速推进

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 早期贸易的剧烈波动 |
| **DV（因变量）** | 失业与未充分就业的迅速增长（且被掩盖） |
| **Chain（传导链）** | 贸易总量增长带动就业增长，但波动本身造成更大失业 → 波动掩盖了贸易绝对增长的趋势，使观察者忽视长期走向 → 产业后备军的扩充压倒了工业从业者军队的增长 → 失业与贸易总体增长之间的联系被普遍忽视 |
| **Lag（时滞）** | 短期波动即刻影响就业，长期趋势被掩盖数十年 |
| **Threshold（临界值）** | 贸易波动幅度大于贸易增长趋势时 |
| **前提与约束（Premises）** | 当时经济以制造业和商业为主；地区专业分工使劳动者难以跨行业调整；观察者依赖有限统计，未能识别潜在增长 |
| **Falsification（证伪条件）** | 若数据表明失业与贸易波动负相关或无显著相关性，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 贸易总量增长带动就业增长，但波动本身造成更大失业
2. 波动掩盖了贸易绝对增长的趋势，使观察者忽视长期走向
3. 产业后备军的扩充压倒了工业从业者军队的增长
4. 失业与贸易总体增长之间的联系被普遍忽视

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场机制自我调节带来的社会痛苦（源于竞争性劳动力市场） |
| **DV（因变量）** | 社会的自我保护运动（工厂法、社会立法、工人阶级运动） |
| **Chain（传导链）** | 市场机制自我调节造成劳动者失业、贫困和无家可归 → 社会对痛苦作出反应，保护性立法开始出现 → 工厂法和各种社会立法出台，工人阶级组织起来 → 保护行动与市场自我调节原则发生激烈冲突 |
| **Lag（时滞）** | 19世纪上半叶（约1830年代至1870年代） |
| **Threshold（临界值）** | 市场机制的破坏性超过社会的承受阈值时 |
| **前提与约束（Premises）** | 竞争性劳动力市场已经形成；工人阶级开始具备集体行动能力；旧有的父爱主义保护制度已被废除 |
| **Falsification（证伪条件）** | 若发现工厂立法早于济贫法修订，或工人阶级运动并非由市场机制触发，则此断言被推翻。 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 炉子太烫，人自然会缩手，并发明隔热手套来保护自己。

### 🔗 文字版因果链

1. 市场机制自我调节造成劳动者失业、贫困和无家可归
2. 社会对痛苦作出反应，保护性立法开始出现
3. 工厂法和各种社会立法出台，工人阶级组织起来
4. 保护行动与市场自我调节原则发生激烈冲突
