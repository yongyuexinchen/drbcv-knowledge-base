# 斯品汉姆兰法令导致大众赤贫化与劳动力市场扭曲（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：斯品汉姆兰法令导致大众赤贫化与劳动力市场扭曲.md

## 总体因果图

- 斯品汉姆兰法令（工资补贴制度，1795-1834年） → 大众赤贫化、劳动生产率下降、劳动力市场无法建立、最终摧毁受助
- 工厂制度与复杂机器的引入（18世纪末-19世纪） → 劳动力、土地、货币被迫商品化，社会成为经济体系的附属品
- 斯品汉姆兰法令的父爱主义干涉 → 《反结社法》（1799-1800年）的制定
