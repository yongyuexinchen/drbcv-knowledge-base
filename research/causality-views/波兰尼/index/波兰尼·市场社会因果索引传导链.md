## 主传导链

```
[斯品汉姆兰法案（补贴制度）]
  → 劳动力市场的建立受阻
      （补贴改变劳动力供给意愿，劳动者不愿接受市场工资）
  → 1834年《济贫法修正案》废除斯品汉姆兰法令
      [时滞：约40余年政策斗争]
  → 竞争性劳动力市场在全国形成
      （劳动者失去土地等生产资料，只能依赖工资生存）
  → 工人阶级形成与工业资本主义确立
  → 自发调节市场的扩张：土地、劳动力、货币全面商品化
      （自我调节市场理念成为组织原则，即“市场乌托邦”）
  → 社会各阶层自我保护运动：集体主义干预与保护立法
      （市场威胁人性与自然；社会潜在保护本能被唤醒）
  → 市场自我调节受损，工业生活被打乱
  → 金本位制下的国际经济压力积累
      （各国相互依赖，政府优先护本国经济免受黄金外流冲击；殖民地资源只是延缓矛盾）
  → 第一次世界大战
  → 文明危机：自我调节市场乌托邦与保护社会之间的冲突不可调和
```

## 不变式

- 社会具有自我保护本能，不会任由自我调节市场摧毁其基础。
- 劳动力、土地、货币是“虚拟商品”，全面市场化会威胁人性与自然。
- 自发调节的市场是一种乌托邦，现实中不可能完全实现。
- 社会保护运动是自发的，无需理论或意识形态前提。
- 竞争性劳动力市场的前提是劳动者失去生产资料，只能依赖工资生活。
