# 波兰尼 · 前提画像（世界观公理）

> 用途：理解波兰尼全部结论的**地基**。他所有论断（市场脱嵌→社会撕裂、双向运动）都从这五条前提推出。
> **读法**：前提成立 → 结论成立；前提被攻破 → 全楼摇晃。

## 前提体系（五层公理）

| 层 | 前提 | 一句话 |
|---|---|---|
| 人性观 | 人是**社会性存在**，社会关系先于个体 | 没有脱离社会的"经济人"，人先属于社群再属于市场 |
| 社会观 | 市场是**制度建构**（人造物，非自然） | 土地/劳动/货币是"虚拟商品"——本不是商品，被硬变成商品 |
| 历史观 | 19 世纪市场社会是**历史异常**，非自然状态 | 人类历史上大部分时间没有"市场社会"，只有"有市场的社会" |
| 动力观 | **双向运动**：市场扩张 → 社会自我保护（反向运动） | 市场越脱嵌，社会反弹越剧烈 |
| 国家观 | 国家是社会的保护器：福利/管制/工会合法化 | 放任市场 = 社会自杀，国家必须兜底 |

## 推导链（前提 → 结论）

```
人是社会性存在（前提1）→ 纯粹市场违背人性（推论）
     ↓
虚拟商品化（前提2：土地劳动货币被商品化）→ 市场脱嵌（推论）
     ↓
脱嵌撕裂社会（前提1+2）→ 反向运动（前提4：工会/福利/立法）
     ↓
放任的结局：社会剧烈反应 → 极端主义/法西斯（前提5 → 核心结论《大转型》）
```

**核心断言**：自由放任市场不是通向繁荣，而是通向社会解体——19 世纪的欧洲证明了（斯品汉姆兰→济贫法→工会→法西斯）。

## 与其他作者的前提冲突（第 2 集辩论地图）

| 对立面 | 冲突点 | 冲突的层 |
|---|---|---|
| **哈耶克** | 社会建构 vs **自发秩序**（市场不是长出来的是造出来的） | 社会观（最深层） |
| 古典自由放任派 | 虚拟商品论 vs 要素自由流动 | 社会观/人性观 |
| 马克思主义 | 双向运动 vs 阶级斗争（波兰尼温和版"反资本主义"） | 动力观 |
| 佩蕾丝 | 呼应：技术革命也需社会/制度调整接盘 | 动力观（互补） |

## 前提的证据评估（批判性视角）

| 前提 | 支持证据 | 反例/软肋 |
|---|---|---|
| 市场是建构的 | 历史上确实长期无市场社会；斯品汉姆兰案 | "建构"不等于"可随意拆除"——市场一旦建立很难退 |
| 虚拟商品 | 劳动力商品化确实造成社会问题 | 但劳动市场也是繁荣的引擎（一面之词） |
| 双向运动 | 19 世纪工会/福利国家兴起实证 | 反向运动也可能走向封闭/法西斯（他自己承认） |
| 国家兜底 | 北欧福利国家成功案例 | 国家干预过度→低效（哈耶克的批评） |

## 立场底色（政商关系/阶级）
- 学术谱系：经济社会学/制度主义（非主流经济学）；与卡尔·马克思对话但非马克思主义者
- 立场：**劳动者/社会保护**（他的理论为福利国家与工会辩护）
- 政商：学术生涯（牛津/哥伦比亚）；无直接参政，但成为 20 世纪福利国家的理论基石
