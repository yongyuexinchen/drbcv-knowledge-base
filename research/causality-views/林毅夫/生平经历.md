# 林毅夫 · 生平经历

> 用途：理解林毅夫观点的形成土壤。先读此卡，再读 index 与因果卡。

## 早年与家庭
林毅夫1952年10月15日生于台湾宜兰，原名林正义，后改名林正谊，最终改为林毅夫。家境贫苦，母亲以洗衣谋生。父亲林火树在日据时代曾任网球社团宜兰菁英团代表。成长于冷战背景下台湾戒严时期，国民党政权宣传“反攻大陆”与“反共”意识形态。1971年台湾退出联合国，林正义作为台大学生会主席曾发动校园绝食、号召游行抗议，具有强烈的民族主义与政治参与意识。

## 教育与学术成长
- 台湾省立宜兰中学初中部、台湾省立宜兰高级中学毕业
- 1971年考入国立台湾大学农业工程系机械组，大一后投笔从戎
- 陆军军官学校第44期步兵科毕业（1975年，成绩第二名）
- 国立政治大学企业管理研究所硕士（1978年）
- 北京大学经济系政治经济学硕士（1982年）
- 芝加哥大学经济学博士（1986年），导师为诺贝尔经济学奖得主西奥多·舒尔茨
- 耶鲁大学经济发展中心博士后研究（1986—1987年）

学术训练横跨农工技术、企管、马克思主义政治经济学与芝加哥学派新古典经济学，师从舒尔茨（人力资本理论、农业经济学），奠定了以实证和制度分析研究农业与发展问题的基础。

## 所属学派
林毅夫自称其理论为“新结构经济学”，属于发展经济学中的结构主义与新古典经济学的综合。他承继了比较优势战略思想，重视政府在产业升级中的因势利导作用，与华盛顿共识的新自由主义形成对立。可归入：
- 发展经济学（结构主义—新古典综合）
- 制度经济学（关注制度变迁与经济发展）
- 新结构经济学（自创学派）

与芝加哥学派有师承关系，但与弗里德曼式自由放任政策保持距离；其政策主张偏重国家主导下的市场化改革，被视为“国家发展主义”的知识代表。

## 学术谱系与论战
- 导师：西奥多·舒尔茨（1979年诺贝尔经济学奖得主，芝加哥学派农业经济学与人力资本理论奠基人）
- 重要合作者：与易纲、海闻、张维迎、张帆、余明德共同创办北京大学中国经济研究中心；与蔡昉合著《中国经济》
- 论战对象：
  - 与张维迎围绕产业政策、政府作用发生“林张之争”——林毅夫主张有效市场与有为政府结合，张维迎坚持市场自发演化、反对产业政策
  - 与自由主义经济学家关于国有企业改革路径的争论：林强调国企改革需与消除政策性负担配套，而非单纯私有化
  - 与“华盛顿共识”支持者就发展中国家赶超战略的争论
- 学术网络覆盖中国国务院智囊体系、世界银行发展经济学界、北京大学国家发展研究院

## 职业与关键经历
- 1975—1979年：中华民国陆军军官，曾任金门马山连连长（上尉）
- 1979年5月16日：从金门泅渡至厦门，投奔中国大陆，改名林毅夫
- 1979—1982年：入北京大学经济系读硕士，期间为舒尔茨访华担任翻译
- 1982—1986年：芝加哥大学经济系读博，师从舒尔茨
- 1986—1987年：耶鲁大学博士后
- 1987年：回国任北京大学副教授，同时任国务院农村发展研究中心发展研究所副所长
- 1987—1993年：北京大学副教授；1993年升任教授
- 1990—1993年：国务院发展研究中心农村部副部长
- 1994年：与易纲等6人创办北京大学中国经济研究中心，任主任（至2008年）
- 2005年：当选第三世界科学院院士
- 2008—2012年：世界银行高级副行长兼首席经济学家（首位来自发展中国家的此职务担任者）
- 2013年至今：全国政协常委、经济委员会副主任；国务院参事；北京大学新结构经济学研究院院长、南南合作与发展学院院长

关键转折：投笔从戎→叛逃投陆→北大求学→芝加哥博士→海归任职→创办研究中心→世行首席经济学家→提出新结构经济学。每一步都与其“国家发展”问题意识紧密相连。

## 政商关系
- 长期担任中国政府决策智库职务：国务院农村发展研究中心副所长、国务院发展研究中心农村部副部长、国务院参事
- 创办的北大中国经济研究中心成为“中国政府决策部门重要的智库之一”，直接影响中共中央经济政策（如朱镕基改革时期的国企对策）
- 1998—2008年任全国政协委员（经济界），2013年起任全国政协常委、经济委员会副主任
- 2008—2012年任职世界银行，主导发展经济学政策研究，与全球资本和跨国机构深度互动
- 曾任全国工商联副主席（2013—2017年），与民营经济界有制度性联系

林毅夫是“国家—市场”之间的体制内知识分子：既为中央决策提供理论依据，又通过世行等平台参与全球发展政策制定，兼具国家官僚机构与学术精英双重身份。

## 代表阶级与立场
- 自我定位：替发展中国家、特别是中国农村与发展中国家民众发声，主张通过结构转型消除贫困；自称“局内人”向世界解释中国经济奇迹
- 客观定位：其核心政策主张（比较优势战略、有为政府）服务于国家主导的经济发展模式，事实上为中华人民共和国政府的经济政策提供合法性论证，代表国家发展主义的技术官僚—经济学家群体利益，同时也有利于依赖国家产业政策的资本集团
- 对农民问题的关注多从生产效率与制度激励角度切入，而非阶级分析立场；其改革方案并未触及土地产权根本变革，倾向在现有体制内优化资源配置

## 时代背景
- 冷战与两岸对峙（1950—1970年代）：台湾戒严体制、国民党“反共”宣传、金门前线
- 1971年台湾退出联合国、1979年中美建交、大陆十一届三中全会启动改革开放
- 中国从计划经济向市场经济转型（1980—1990年代）：农村改革、国企改革、价格双轨制
- 全球化与新自由主义浪潮（1990—2000年代）：中国加入WTO、东亚金融危机、华盛顿共识盛行
- 2008年全球金融危机：西方模式受质疑，发展中国家崛起成为世界经济重心
- 上述背景塑造了林毅夫从民族主义青年到“中国奇迹”阐释者的问题意识：如何让一个贫穷落后的农业国实现工业化、赶超发达国家。

## 观点形成脉络
- 台湾贫困农村出身、农业工程系训练 → 关注农业技术与农村发展 → 博士论文及早期研究集中于制度、技术与农业增长
- 金门前线从军经历与1979年投陆 → 认同国家统一与大陆现代化 → 选择研究中国经济改革，主张渐进式改革优于休克疗法
- 亲历“文革”后北大政治经济学环境与芝加哥新古典训练 → 意识到马克思主义政治经济学的局限与市场机制的重要性 → 提出“充分信息与国有企业改革”，强调消除政策性负担、完善市场竞争
- 长期担任国务院智囊，观察中国“赶超战略”的失败教训 → 批判重工业优先的违背比较优势战略 → 提出“比较优势发展战略”，主张按要素禀赋结构发展经济
- 2008年任职世界银行，目睹发展中国家政策失败 → 反思华盛顿共识与新自由主义 → 创立“新结构经济学”，主张政府因势利导、推动结构变迁
- 中国崛起为世界第二大经济体 → 以“局内人”身份解读中国经济 → 著《解密中国经济》，预测中国将在2030年前后成为世界最大经济体

## 争议与批评
- 台湾方面：2012年被中华民国国防部列为通缉犯，认定其叛逃行为；部分台湾舆论视其为“投共”典型
- 学术争论：
  - 张维迎批评产业政策是“穿着马甲的计划经济”，认为林毅夫的“有为政府”容易被滥用，导致寻租与权力干预
  - 新自由主义经济学家批评其过度强调国家作用、忽视产权与法治
  - 部分左翼学者批评其代表“新结构主义”实质是为资本积累与国家资本主义辩护，未触及分配与阶级问题
  - 世界银行期间有西方批评者认为其对中国经验的推广过于乐观，忽视制度与政治条件差异
- 争议核心：政府与市场边界、产业政策有效性、中国模式普适性

## 与知识库其他作者的交集
- 师承：西奥多·舒尔茨（芝加哥学派，农业经济学与人力资本理论）
- 合作者：蔡昉（合著《中国经济》）、易纲、海闻、张维迎、张帆、余明德（共同创办北大中国经济研究中心）
- 论战对手：张维迎（产业政策之争）、主张“华盛顿共识”的经济学家
- 关系特征：林毅夫处于中国经济学界“官方经济学家”与“国际主流经济学家”双重身份的交汇点，与政府决策者（朱镕基等）、国际机构（世界银行）有密切关联。
