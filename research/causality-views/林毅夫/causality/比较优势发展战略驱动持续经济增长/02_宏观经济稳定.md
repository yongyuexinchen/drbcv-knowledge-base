# 宏观经济稳定

> 属于因果簇：[[比较优势发展战略驱动持续经济增长]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的发展战略 |
| **DV（因变量）** | 宏观经济稳定 |
| **Chain（传导链）** | 产业发展符合比较优势，企业具有自生能力 → 企业利润取决于管理水平而非政府补贴和保护 → 政府无需对低效企业进行大规模补贴，财政负担减轻 → 财政收入随经济增长动态增加，财政状况良好 → 外部竞争力强，减少货币错配和财政危机，政府有余力实施反周期政策 |
| **Lag（时滞）** | 中期，通常在战略实施若干年后显现 |
| **Threshold（临界值）** | 产业选择与要素禀赋匹配，避免对无自生能力企业的长期补贴 |
| **前提与约束（Premises）** | 政府不采取扭曲性的价格干预或过度补贴政策；经济保持适度开放，参与国际竞争 |
| **Falsification（证伪条件）** | 若遵循比较优势的国家仍频繁发生严重宏观金融危机，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人量入为出、不靠借债度日，经济状况自然稳定；反之，铺张浪费终将陷入财务危机。

### 🔗 文字版因果链

1. 产业发展符合比较优势，企业具有自生能力
2. 企业利润取决于管理水平而非政府补贴和保护
3. 政府无需对低效企业进行大规模补贴，财政负担减轻
4. 财政收入随经济增长动态增加，财政状况良好
5. 外部竞争力强，减少货币错配和财政危机，政府有余力实施反周期政策
