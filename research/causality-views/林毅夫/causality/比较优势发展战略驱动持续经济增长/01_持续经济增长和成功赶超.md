# 持续经济增长和成功赶超

> 属于因果簇：[[比较优势发展战略驱动持续经济增长]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的发展战略 |
| **DV（因变量）** | 持续经济增长和成功赶超 |
| **Chain（传导链）** | 国家根据要素禀赋结构选择具有比较优势的产业 → 企业无需补贴保护即可盈利，具备自生能力 → 经济在国内国际市场具有竞争力，产生最大经济剩余 → 剩余转化为储蓄和投资，推动资本积累和产业升级 → 产业结构随禀赋升级而持续变迁，实现快速增长和人均收入提高 |
| **Lag（时滞）** | 中长期，通常需要数十年（如韩国持续半个世纪） |
| **Threshold（临界值）** | 增长率需达到较高水平并持续较长时间（如增长委员会案例中超过7%且持续25年以上） |
| **前提与约束（Premises）** | 国家拥有运转良好的市场体系，相对价格反映要素稀缺度；政府发挥因势利导作用，提供基础设施并补偿信息外部性；实行开放政策，充分利用全球市场和先进技术；宏观经济保持基本稳定 |
| **Falsification（证伪条件）** | 若发现某些国家长期严重违背比较优势却实现了持续快速增长，或遵循比较优势的国家长期增长失败，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人选择适合自己的职业才能发挥最大潜力，硬要从事不擅长的工作，再努力也难以成功致富。

### 🔗 文字版因果链

1. 国家根据要素禀赋结构选择具有比较优势的产业
2. 企业无需补贴保护即可盈利，具备自生能力
3. 经济在国内国际市场具有竞争力，产生最大经济剩余
4. 剩余转化为储蓄和投资，推动资本积累和产业升级
5. 产业结构随禀赋升级而持续变迁，实现快速增长和人均收入提高
