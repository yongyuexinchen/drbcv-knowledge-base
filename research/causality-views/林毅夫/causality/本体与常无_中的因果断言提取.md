## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 产业政策是否符合要素禀赋结构所决定的比较优势 |
| **DV（因变量）** | 产业政策的成功或失败 |
| **Chain（传导链）** | 要素禀赋结构决定了一个经济的比较优势 → 符合比较优势的产业具有自生能力，企业可以在开放竞争市场中生存 → 不符合比较优势的产业缺乏自生能力，需要政府保护和补贴才能生存 → 因此符合比较优势的产业政策成功，不符合的失败 |
| **Lag（时滞）** | 长期，通常数十年（如日本60年代到成功，中国50年代至今仍依赖保护） |
| **Threshold（临界值）** | 人均收入按购买力平价达到美国40%左右时汽车产业优先发展属比较优势；5%左右时属赶超 |
| **前提与约束（Premises）** | 要素禀赋结构是比较优势的唯一决定因素；企业追求利润、市场机制发挥作用；存在开放竞争的市场环境 |
| **Falsification（证伪条件）** | 如果发现一个不符合比较优势的产业政策能够长期成功且无需政府补贴保护，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 举重比赛按体重分级，轻量级选手非要举重量级的杠铃必然失败，强行拔高只会受伤。

### 🔗 文字版因果链

1. 要素禀赋结构决定了一个经济的比较优势
2. 符合比较优势的产业具有自生能力，企业可以在开放竞争市场中生存
3. 不符合比较优势的产业缺乏自生能力，需要政府保护和补贴才能生存
4. 因此符合比较优势的产业政策成功，不符合的失败

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场供求状况（短缺经济 vs 生产能力过剩） |
| **DV（因变量）** | 乡镇企业的绩效（成功与破产） |
| **Chain（传导链）** | 20世纪80年代中国处于短缺经济，产品供不应求 → 乡镇企业即使技术落后、治理不善，产品也能卖出（皇帝的女儿不愁嫁） → 20世纪90年代末出现生产能力普遍过剩，市场竞争激烈 → 乡镇企业难以与新建立的三资企业、私营企业竞争，纷纷破产 |
| **Lag（时滞）** | 约10至20年（80年代成功，90年代末失败） |
| **Threshold（临界值）** | 从短缺经济转变为生产能力普遍过剩的临界点 |
| **前提与约束（Premises）** | 乡镇企业存在公司治理、技术水平、产品质量等内在弱点；存在外部竞争者（三资企业、私营企业）；市场供求状态变化是外生冲击 |
| **Falsification（证伪条件）** | 若在过剩经济中乡镇企业仍能普遍成功，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 退潮时才知道谁在裸泳——短缺经济的水位掩盖了乡镇企业的内在缺陷。

### 🔗 文字版因果链

1. 20世纪80年代中国处于短缺经济，产品供不应求
2. 乡镇企业即使技术落后、治理不善，产品也能卖出（皇帝的女儿不愁嫁）
3. 20世纪90年代末出现生产能力普遍过剩，市场竞争激烈
4. 乡镇企业难以与新建立的三资企业、私营企业竞争，纷纷破产

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政策性负担 |
| **DV（因变量）** | 预算软约束和公司治理问题 |
| **Chain（传导链）** | 国有企业承担政策性负担（如就业、战略产业） → 政府必须为承担政策性负担的企业提供保护补贴 → 保护补贴导致预算软约束 → 预算软约束使公司治理问题恶化且难以解决 |
| **Lag（时滞）** | 同时或短期（内生关系，政策负担存在则问题随之出现） |
| **Threshold（临界值）** | 企业存在政策性负担 |
| **前提与约束（Premises）** | 国有企业的政策性负担是外生给定的；政府无法承诺不救助承担政策负担的企业 |
| **Falsification（证伪条件）** | 若发现没有政策性负担的国有企业也普遍存在严重的预算软约束和公司治理问题，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人背着沉重包袱跑步，姿势必然变形；不卸下包袱只纠正姿势没有用。

### 🔗 文字版因果链

1. 国有企业承担政策性负担（如就业、战略产业）
2. 政府必须为承担政策性负担的企业提供保护补贴
3. 保护补贴导致预算软约束
4. 预算软约束使公司治理问题恶化且难以解决

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 赶超战略（优先发展不符合比较优势的资本密集型产业） |
| **DV（因变量）** | 收入分配恶化、经济停滞甚至危机 |
| **Chain（传导链）** | 赶超战略优先发展资本密集型产业，创造的就业机会少 → 只有劳动力的穷人无法充分就业，工资难以提高 → 这些产业无自生能力，需政府保护和补贴 → 保护和补贴的资金来自其他产业的税收或价格剪刀差，加重低收入者负担 → 穷人就业减少且被征税补贴富人企业，收入分配更加不平均 → 经济整体缺乏竞争力，最终停滞、危机，穷人受害最大 |
| **Lag（时滞）** | 数十年（产业投资周期长，危机滞后显现） |
| **Threshold（临界值）** | 政府优先发展的产业不符合该国要素禀赋结构 |
| **前提与约束（Premises）** | 政府有能力通过税收、补贴、价格管制进行资源转移；存在资本密集型和劳动密集型产业的分化；穷人的主要资产是劳动力 |
| **Falsification（证伪条件）** | 若实行赶超战略的国家在长期内收入分配改善且经济持续增长，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 拔苗助长——强行使苗长高，反而导致枯死。

### 🔗 文字版因果链

1. 赶超战略优先发展资本密集型产业，创造的就业机会少
2. 只有劳动力的穷人无法充分就业，工资难以提高
3. 这些产业无自生能力，需政府保护和补贴
4. 保护和补贴的资金来自其他产业的税收或价格剪刀差，加重低收入者负担
5. 穷人就业减少且被征税补贴富人企业，收入分配更加不平均
6. 经济整体缺乏竞争力，最终停滞、危机，穷人受害最大

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 制度移植（将发达国家制度照搬到发展中国家） |
| **DV（因变量）** | 制度效果（有效或失败） |
| **Chain（传导链）** | 一个国家的社会政治制度内生于其文化传统、收入分配等 → 不同国家的外生变量不同 → 相同的制度在不同外生变量下产生不同效果 → 移植的先进制度可能变成‘淮南为橘，淮北为枳’ |
| **Lag（时滞）** | 长期（制度效果需长时间显现） |
| **Threshold（临界值）** | 外生变量（文化传统、收入分配等）差异足够大 |
| **前提与约束（Premises）** | 制度是内生变量，由文化传统、收入分配等外生变量决定；法律、文化传统是短期内不可改变的外生变量 |
| **Falsification（证伪条件）** | 若发现文化传统和收入分配差异巨大的国家移植相同制度后产生相同效果，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 橘生淮南则为橘，生于淮北则为枳——种子相同，水土不同，果实不同。

### 🔗 文字版因果链

1. 一个国家的社会政治制度内生于其文化传统、收入分配等
2. 不同国家的外生变量不同
3. 相同的制度在不同外生变量下产生不同效果
4. 移植的先进制度可能变成‘淮南为橘，淮北为枳’

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 按比较优势发展劳动密集型产业 |
| **DV（因变量）** | 穷人收入增加、收入差距缩小 |
| **Chain（传导链）** | 按比较优势发展劳动密集型产业，创造大量就业机会 → 穷人的劳动力得到充分就业 → 劳动力需求增加，工资逐渐上升 → 资本报酬逐渐下降 → 穷人和富人的收入差距随着经济发展逐渐缩小 |
| **Lag（时滞）** | 中期（随经济发展和资本积累逐步显现） |
| **Threshold（临界值）** | 产品和要素市场充分竞争 |
| **前提与约束（Premises）** | 穷人只有劳动力，富人拥有资本；初始禀赋结构为劳动力相对丰富、资本相对稀缺；制度环境允许市场发挥决定性作用 |
| **Falsification（证伪条件）** | 若在充分竞争市场上按比较优势发展后穷人的收入份额没有增加、差距没有缩小，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 授人以渔——给穷人创造就业机会，比直接给鱼更能持续改善其生活。

### 🔗 文字版因果链

1. 按比较优势发展劳动密集型产业，创造大量就业机会
2. 穷人的劳动力得到充分就业
3. 劳动力需求增加，工资逐渐上升
4. 资本报酬逐渐下降
5. 穷人和富人的收入差距随着经济发展逐渐缩小

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 世界经济中心（从英国转移到美国，未来可能转移到中国） |
| **DV（因变量）** | 经济学研究中心与经济学大师产生地 |
| **Chain（传导链）** | 发生在世界经济中心的经济现象对全球经济影响最大 → 解释重要现象的理论被公认为最重要贡献 → 世界经济中心的经济学家有近水楼台之便，更容易观察和理解这些现象 → 因此经济学大师绝大多数在世界经济中心工作，经济学研究中心随经济中心转移 |
| **Lag（时滞）** | 数十年到上百年（经济中心转移后，理论影响力逐步显现） |
| **Threshold（临界值）** | 该国成为世界最大、最强的经济体 |
| **前提与约束（Premises）** | 理论贡献的大小取决于所解释现象的重要性；经济学大师的产生集中在当时世界经济中心；历史经验：工业革命后英国为中心，一次大战后美国为中心 |
| **Falsification（证伪条件）** | 若中国成为世界最大经济体后，世界经济学研究中心未转移到中国，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

1. 发生在世界经济中心的经济现象对全球经济影响最大

4. 因此经济学大师绝大多数在世界经济中心工作，经济学研究中心随经济中心转移

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 没有自生能力企业的数量和规模（小国 vs 大国转型） |
| **DV（因变量）** | 休克疗法的成败 |
| **Chain（传导链）** | 休克疗法一下子消除所有制度扭曲 → 没有自生能力的企业失去保护后破产 → 如果这类企业数量少、规模小，破产造成的社会冲击小，转型可成功（如玻利维亚） → 如果这类企业数量多、规模大，破产冲击超过社会承受力，造成混乱和生产破坏（如苏联东欧） |
| **Lag（时滞）** | 短期（休克疗法实施后立即产生冲击） |
| **Threshold（临界值）** | 无自生能力企业数量多、规模大且超过社会承受能力 |
| **前提与约束（Premises）** | 制度扭曲内生于扶持无自生能力企业的需要；休克疗法直接移除制度扭曲而不解决自生能力问题；社会承受力是有限的 |
| **Falsification（证伪条件）** | 若在无自生能力企业数量多、规模大的国家实施休克疗法而没有造成经济崩溃，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 拆炸弹：小炸弹可以就地拆除，大炸弹直接拆可能引爆，必须先排险。

### 🔗 文字版因果链

1. 休克疗法一下子消除所有制度扭曲
2. 没有自生能力的企业失去保护后破产
3. 如果这类企业数量少、规模小，破产造成的社会冲击小，转型可成功（如玻利维亚）
4. 如果这类企业数量多、规模大，破产冲击超过社会承受力，造成混乱和生产破坏（如苏联东欧）
