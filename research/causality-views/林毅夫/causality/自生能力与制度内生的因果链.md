# 自生能力与制度内生的因果链

> **领域**：发展经济学、转型经济学　|　**来源**：chapter_12.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府实施违背比较优势的赶超型发展战略（优先发展资本密集型重工业） |
| **DV（因变量）** | 形成传统计划经济体制（价格扭曲、计划配置、国有化、剥夺企业自主权） |
| **Chain（传导链）** | 政府优先发展不具有比较优势的产业 → 这些产业中的企业没有自生能力，在开放竞争市场中无法生存 → 为让企业存活，政府压低投入品价格并给予产品市场垄断权 → 价格信号扭曲导致资金、外汇、原材料、生活必需品供不应求 → 为保证稀缺资源按计划配置到优先项目，国家计划与行政配置成为必要 → 为防止私人企业侵占集中起来的剩余，实行国有化以掌握剩余支配权 → 在信息不对称和激励不相容下，为防道德风险剥夺企业经营自主权 |
| **Lag（时滞）** | 在工业化初期逐步形成，长期内不断强化 |
| **Threshold（临界值）** | 当所优先发展的产业中的企业在开放竞争市场中无法获得正常利润时（即企业不具备自生能力） |
| **前提与约束（Premises）** | 经济落后、资本稀缺，与重工业所需资金密集度矛盾；政府追求快速工业化，具有赶超意愿；存在信息不对称和激励不相容问题 |
| **Falsification（证伪条件）** | 如果政府优先发展重工业却没有出现价格扭曲、计划配置和国有化等制度安排，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 好比为了保护一个先天体弱的孩子，父母要限制他的活动、替他做所有决定，形成一套过度保护的家庭制度。

### 🔗 文字版因果链

1. 政府优先发展不具有比较优势的产业
2. 这些产业中的企业没有自生能力，在开放竞争市场中无法生存
3. 为让企业存活，政府压低投入品价格并给予产品市场垄断权
4. 价格信号扭曲导致资金、外汇、原材料、生活必需品供不应求
5. 为保证稀缺资源按计划配置到优先项目，国家计划与行政配置成为必要
6. 为防止私人企业侵占集中起来的剩余，实行国有化以掌握剩余支配权
7. 在信息不对称和激励不相容下，为防道德风险剥夺企业经营自主权

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 企业缺乏自生能力 |
| **DV（因变量）** | 形成预算软约束 |
| **Chain（传导链）** | 企业没有自生能力，在竞争市场中无法生存 → 政府为建立这些企业必须负起保护和补贴责任 → 信息不对称使政府不知道该补贴多少才够 → 企业把经营不善亏损也归因于政府保护补贴不足 → 政府不愿让企业破产且对亏损负有责任 → 于是形成预算软约束现象 |
| **Lag（时滞）** | 在政府开始保护补贴后持续存在 |
| **Threshold（临界值）** | 只要企业缺乏自生能力且政府不愿让其破产 |
| **前提与约束（Premises）** | 政府承担保护和补贴责任；政府与企业之间信息不对称；无法可靠区分政策性亏损与经营性亏损 |
| **Falsification（证伪条件）** | 如果缺乏自生能力的企业在私有化后预算软约束消失，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 类似于父母对长期患病的孩子有求必应，孩子也学会用生病来索取更多照顾。

### 🔗 文字版因果链

1. 企业没有自生能力，在竞争市场中无法生存
2. 政府为建立这些企业必须负起保护和补贴责任
3. 信息不对称使政府不知道该补贴多少才够
4. 企业把经营不善亏损也归因于政府保护补贴不足
5. 政府不愿让企业破产且对亏损负有责任
6. 于是形成预算软约束现象

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以暗含企业有自生能力为前提的新古典理论制定转型政策 |
| **DV（因变量）** | 转型政策失败（达不到预期甚至使问题恶化） |
| **Chain（传导链）** | 新古典经济学假设企业具有自生能力 → 政策聚焦于私有化、市场化、减少政府干预 → 但转型国家实际存在大量无自生能力企业 → 取消保护和补贴导致大量企业破产、失业 → 社会无法承受大规模破产，政府被迫继续补贴 → 出现有休克而无疗法的局面 |
| **Lag（时滞）** | 转型政策实施后数年内显现 |
| **Threshold（临界值）** | 当经济中缺乏自生能力的企业占重要份额时 |
| **前提与约束（Premises）** | 缺乏自生能力的企业在经济中占比高；政府无法容忍大规模破产和失业；改革按新古典理论或华盛顿共识设计 |
| **Falsification（证伪条件）** | 如果休克疗法在存在大量无自生能力企业的国家取得成功并恢复增长，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 让一个不会游泳的人直接跳进深水区，结果只能呛水，还得靠救生圈。

### 🔗 文字版因果链

1. 新古典经济学假设企业具有自生能力
2. 政策聚焦于私有化、市场化、减少政府干预
3. 但转型国家实际存在大量无自生能力企业
4. 取消保护和补贴导致大量企业破产、失业
5. 社会无法承受大规模破产，政府被迫继续补贴
6. 出现有休克而无疗法的局面

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府持续扶持不符合比较优势的无自生能力企业 |
| **DV（因变量）** | 寻租横行、收入分配不公、效率低下、债务危机/金融危机 |
| **Chain（传导链）** | 无自生能力企业需要政府保护补贴才能生存 → 政府干预价格、金融、贸易等资源配置 → 价格扭曲和行政干预创造寻租空间 → 有比较优势的企业受歧视性政策压制难以发展 → 整个经济创造剩余的能力下降，可动员资金枯竭 → 若对外举债则累积外债，最终爆发债务危机或金融危机 |
| **Lag（时滞）** | 长期积累后爆发危机 |
| **Threshold（临界值）** | 无自生能力企业占比高，且保护补贴政策持续存在 |
| **前提与约束（Premises）** | 政府持续干预资源配置；存在寻租和裙带资本主义的空间；经济缺乏新的增长点或依赖外部举债 |
| **Falsification（证伪条件）** | 如果政府扶持无自生能力企业却未出现寻租、分配恶化和经济危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同总给长在盐碱地的树施肥浇水，虽暂时活下来，却浪费资源、荒废良田，最后生态失衡。

### 🔗 文字版因果链

1. 无自生能力企业需要政府保护补贴才能生存
2. 政府干预价格、金融、贸易等资源配置
3. 价格扭曲和行政干预创造寻租空间
4. 有比较优势的企业受歧视性政策压制难以发展
5. 整个经济创造剩余的能力下降，可动员资金枯竭
6. 若对外举债则累积外债，最终爆发债务危机或金融危机

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 按比较优势发展经济（以提升要素禀赋结构为目标） |
| **DV（因变量）** | 经济持续增长并向发达国家收敛 |
| **Chain（传导链）** | 按当前要素禀赋结构决定的比较优势选择产业、产品和技术 → 企业具有自生能力，在开放竞争市场中有竞争力 → 整个经济创造最大剩余 → 资本回报率高，积累意愿强，要素禀赋结构提升快 → 要素禀赋结构提升推动产业、产品、技术升级 → 利用与发达国家的技术差距低成本引进技术，实现收敛 |
| **Lag（时滞）** | 中长期动态过程 |
| **Threshold（临界值）** | 产品和要素价格反映国际市场和资源稀缺性，市场开放竞争，政府提供信息协调和有限补贴 |
| **前提与约束（Premises）** | 开放、竞争的市场环境；政府提供产业政策以解决信息外部性和协调问题；补贴仅用于补偿信息外部性且有限期；土地等自然资源禀赋给定 |
| **Falsification（证伪条件）** | 如果按比较优势发展的国家没有实现更快增长和收敛，则该断言被推翻 |
| **Confidence（确信度）** | well-established |
