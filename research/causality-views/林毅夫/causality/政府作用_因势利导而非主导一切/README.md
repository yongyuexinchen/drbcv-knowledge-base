# 政府作用：因势利导而非主导一切（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：政府作用_因势利导而非主导一切.md

## 总体因果图

- 市场失灵（信息外部性、协调问题、先行者外部性） → 政府必须发挥积极作用，但干预应限于因势利导（提供信息、协调投
- 违背比较优势的政府干预（主导一切、过度保护） → 企业缺乏自生能力，并产生寻租空间
