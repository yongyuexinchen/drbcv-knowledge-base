# 经济稳定与结构转型（工业化与多样化）

> 属于因果簇：[[新结构经济学因果断言集]]（第12块/15块）

## 因果断言 12

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资类型（FDI vs 组合投资）及资源租金的使用方向 |
| **DV（因变量）** | 经济稳定与结构转型（工业化与多样化） |
| **Chain（传导链）** | FDI流向与接受国比较优势一致 → FDI带来技术、管理、市场渠道 → 恐慌期FDI不易逆转，有利稳定 → 组合投资快速进出引发泡沫和波动 → 资源租金若存外国资产则错失国内结构转型 → 资源租金投向人力资本、基础设施和非资源部门可促进多样化 |
| **Lag（时滞）** | 中长期（FDI效果需数年，资源租金转型需数十年） |
| **Threshold（临界值）** | FDI必须与比较优势一致；资源租金应超过维持国内投资所需且投资回报为正 |
| **前提与约束（Premises）** | 接受国具备一定的配套基础设施与制度；资源型产业资本密集、就业有限；自然资源收入需透明管理避免腐-败 |
| **Falsification（证伪条件）** | 如果FDI在多数国家不如组合投资促进增长，或资源租金投资国内普遍导致严重腐败与低效，则断言需修正。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. FDI流向与接受国比较优势一致
2. FDI带来技术、管理、市场渠道
3. 恐慌期FDI不易逆转，有利稳定
4. 组合投资快速进出引发泡沫和波动
5. 资源租金若存外国资产则错失国内结构转型
6. 资源租金投向人力资本、基础设施和非资源部门可促进多样化
