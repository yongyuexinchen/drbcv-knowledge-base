# 实际金融结构对最优金融结构的偏离程度

> 属于因果簇：[[新结构经济学因果断言集]]（第8块/15块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 领导人理念、政策顾问推销、政治联盟利益 |
| **DV（因变量）** | 实际金融结构对最优金融结构的偏离程度 |
| **Chain（传导链）** | 领导人理念（如金融抑制服务于违背比较优势战略） → 政策顾问盲目推销英美模式 → 政治联盟利益（如银行准入限制） → 三者合力使实际金融结构偏离最优 → 导致效率损失、融资难题和收入差距扩大 |
| **Lag（时滞）** | 中长期（数十年） |
| **Threshold（临界值）** | 偏离程度越大，经济效率损失越大（参照第7条的量化：结构缺口每增一个标准差，人均GDP降6%） |
| **前提与约束（Premises）** | 政府拥有金融干预权力；存在利益集团寻租空间；信息不对称使扭曲难以被及时纠正 |
| **Falsification（证伪条件）** | 如果存在领导人理念偏颇、顾问推销、政治利益干扰的情况下实际金融结构仍保持最优，则断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 医生开错药，不是病人不需要药，而是药不对症。

### 🔗 文字版因果链

1. 领导人理念（如金融抑制服务于违背比较优势战略）
2. 政策顾问盲目推销英美模式
3. 政治联盟利益（如银行准入限制）
4. 三者合力使实际金融结构偏离最优
5. 导致效率损失、融资难题和收入差距扩大
