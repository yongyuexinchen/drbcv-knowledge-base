# 新结构经济学因果断言集（因果簇）

> 因果簇索引：15 个子因果卡。父卡文件：新结构经济学因果断言集.md

## 总体因果图

- 要素禀赋结构（劳动/资本/自然资源的相对丰裕度） → 最优产业结构（产业与技术选择）
- 遵循比较优势的发展战略 → 要素禀赋结构升级速度（资本积累）
- 后发国家与发达国家的技术差距 → 技术创新率与经济增长率
- 政府因势利导的干预（信息、协调、外部性补偿、基础设施） → 产业升级成功与经济发展绩效
- 违背比较优势的发展战略（优先发展不具比较优势的资本密集产业） → 系统性经济扭曲与失败（低增长、金融抑制、外债、宏观不稳定、分
- 增长甄别与因势利导六步法（GIFF）的使用 → 产业政策成功率（经济增长与产业升级）
- 产业结构（企业规模、信息透明度、风险类型） → 最优金融结构（中小银行 vs 大银行+证券市场）
- 领导人理念、政策顾问推销、政治联盟利益 → 实际金融结构对最优金融结构的偏离程度
- 改革方式：双轨制渐进改革 vs 休克疗法 → 转型绩效（经济增长、社会稳定）
- 人力资本积累与产业升级的同步性 → 人力资本回报率与就业状况
- 衰退期基础设施投资（财政政策）与降息（货币政策） → 长期经济增长（短期需求+长期供给）
- 外资类型（FDI vs 组合投资）及资源租金的使用方向 → 经济稳定与结构转型（工业化与多样化）
- 技术选择指数（TCI，度量违背比较优势的程度） → 增长绩效（人均GDP增长率、波动性、收入分配、扭曲程度）
- 发展战略（遵循/违背比较优势） → 收入分配平等程度（基尼系数）
- 中国等新兴市场工资上升 → 低收入国家（尤其撒哈拉以南非洲）的工业化速度
