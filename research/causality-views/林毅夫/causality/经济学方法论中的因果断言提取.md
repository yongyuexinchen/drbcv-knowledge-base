# 经济学方法论中的因果断言提取

> **领域**：经济学（发展经济学、宏观经济学、行为经济学、犯罪经济学）　|　**来源**：chapter_02.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发达国家与发展中国家的发展阶段、要素禀赋、制度安排不完全一样 |
| **DV（因变量）** | 发达国家的最优选择在发展中国家不见得是最优的 |
| **Chain（传导链）** | 发达国家和发展中国家的初始条件（发展阶段、要素禀赋、制度安排）不同 → 决策者面临的限制条件和选择的机会成本随之不同 → 因此，在发达国家的最优选择在发展中国家不一定是最优 |
| **Lag（时滞）** | 无明确时滞，为跨情境比较 |
| **Threshold（临界值）** | 当两组国家的条件差异足以改变决策者的限制条件和机会成本时 |
| **前提与约束（Premises）** | 决策者是理性的；最优选择依赖于具体限制条件 |
| **Falsification（证伪条件）** | 如果发达国家的最优选择在发展中国家也被证明是最优的，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 同一把钥匙不能打开所有的锁，不同锁需要不同的钥匙

### 🔗 文字版因果链

1. 发达国家和发展中国家的初始条件（发展阶段、要素禀赋、制度安排）不同
2. 决策者面临的限制条件和选择的机会成本随之不同
3. 因此，在发达国家的最优选择在发展中国家不一定是最优

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 生产决策者都按要素禀赋所决定的比较优势选择产业、产品、技术 |
| **DV（因变量）** | 资本得到最快速积累，上一期的最佳选择到了下一期不再是最佳 |
| **Chain（传导链）** | 决策者按比较优势进行生产选择 → 资本得到最快速积累 → 要素禀赋结构随之改变 → 上一期基于旧禀赋的最佳选择在新条件下不再是最佳 |
| **Lag（时滞）** | 跨期（从上一期到下一期） |
| **Threshold（临界值）** | 资本积累足以改变要素禀赋结构 |
| **前提与约束（Premises）** | 决策者理性；要素禀赋是约束条件；比较优势是动态变化的 |
| **Falsification（证伪条件）** | 如果按比较优势选择后，资本积累并未加快或最佳选择未随禀赋变化而改变，则推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人按照自己的体力选择运动方式，体能增强后，原来的运动强度就不再是合适的锻炼方式

### 🔗 文字版因果链

1. 决策者按比较优势进行生产选择
2. 资本得到最快速积累
3. 要素禀赋结构随之改变
4. 上一期基于旧禀赋的最佳选择在新条件下不再是最佳

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展中国家去发展资本密集的产业（违背比较优势） |
| **DV（因变量）** | 政府不得不进行保护、补贴，市场作用受到干预 |
| **Chain（传导链）** | 发展中国家资本稀缺，资本密集产业生产成本高 → 若强行发展该产业，企业缺乏自生能力 → 为了维持企业生存，政府必须提供保护、补贴 → 市场机制因此受到干预 |
| **Lag（时滞）** | 政策实施后持续存在 |
| **Threshold（临界值）** | 当资本稀缺且产业不符合比较优势时 |
| **前提与约束（Premises）** | 资本是稀缺的；政府有发展资本密集产业的目标；企业无法通过市场自发盈利 |
| **Falsification（证伪条件）** | 如果发展中国家能在无政府扶持的情况下成功发展资本密集产业，则推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 矮个子强行要够高架子上的东西，必须借助梯子（政府扶助），梯子本身改变了空间布局

### 🔗 文字版因果链

1. 发展中国家资本稀缺，资本密集产业生产成本高
2. 若强行发展该产业，企业缺乏自生能力
3. 为了维持企业生存，政府必须提供保护、补贴
4. 市场机制因此受到干预

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 监督更严或惩罚更重 |
| **DV（因变量）** | 犯罪概率降低 |
| **Chain（传导链）** | 监督更严或惩罚更重提高了犯罪成本 → 潜在罪犯在理性权衡成本收益 → 当犯罪成本高于预期收益时，选择不犯罪 → 犯罪概率降低 |
| **Lag（时滞）** | 制度实施后，短期至中期内 |
| **Threshold（临界值）** | 监督或惩罚的变化足以逆转犯罪的成本收益比较 |
| **前提与约束（Premises）** | 罪犯是理性的，追求效用最大化；犯罪决策受成本和收益影响 |
| **Falsification（证伪条件）** | 如果监督和惩罚增加而犯罪率不变或上升，则推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水果摊安装监控和罚款告示后，偷水果的人减少

### 🔗 文字版因果链

1. 监督更严或惩罚更重提高了犯罪成本
2. 潜在罪犯在理性权衡成本收益
3. 当犯罪成本高于预期收益时，选择不犯罪
4. 犯罪概率降低

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务链条（债务紧缩机制） |
| **DV（因变量）** | 投资需求和消费需求下降，经济增长速度为负或接近零 |
| **Chain（传导链）** | 债务链条使部分主体无法偿还债务 → 引发连锁反应，信用收缩 → 投资需求和消费需求下降 → 总需求不足导致经济增长放缓或负增长 |
| **Lag（时滞）** | 债务危机传播需要时间，可能数个季度 |
| **Threshold（临界值）** | 债务链条的连锁反应足以显著压缩总需求 |
| **前提与约束（Premises）** | 经济中存在债务链条；总需求是驱动增长的主要力量 |
| **Falsification（证伪条件）** | 如果债务链条发生但经济增长依然强劲，则推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一串多米诺骨牌，一个倒下引发连锁反应，最终整个系统崩倒

### 🔗 文字版因果链

1. 债务链条使部分主体无法偿还债务
2. 引发连锁反应，信用收缩
3. 投资需求和消费需求下降
4. 总需求不足导致经济增长放缓或负增长

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 直接假定人的偏好是可变的 |
| **DV（因变量）** | 不能增加对行为改变原因的了解，降低预测和改变行为的能力 |
| **Chain（传导链）** | 偏好本身不可直接观察 → 如果偏好可变，任何行为变化都能用“偏好变了”来解释 → 这种解释不具备信息增量，无法形成可检验的预测 → 因此理论解释力和预测力下降 |
| **Lag（时滞）** | 无 |
| **Threshold（临界值）** | 当将偏好作为基本的、终极的行为动机时 |
| **前提与约束（Premises）** | 理论的目标是解释和预测现象；偏好是不可直接观察的 |
| **Falsification（证伪条件）** | 如果能基于偏好变化作出精确且可被验证的预测，则部分推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 用“心情变了”解释一切，等于没有解释

### 🔗 文字版因果链

1. 偏好本身不可直接观察
2. 如果偏好可变，任何行为变化都能用“偏好变了”来解释
3. 这种解释不具备信息增量，无法形成可检验的预测
4. 因此理论解释力和预测力下降
