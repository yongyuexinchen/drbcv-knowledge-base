# 要素禀赋结构内生决定最优产业结构

> **领域**：发展经济学　|　**来源**：_cand2_lin_01.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 要素禀赋结构（劳动/资本/自然资源的相对丰裕度） |
| **DV（因变量）** | 最优产业结构（产业与技术的选择） |
| **Chain（传导链）** | 要素禀赋结构决定各要素的相对价格：丰裕要素价格低，稀缺要素价格高 → 相对价格体系决定成本最小化的产业与技术选择 → 符合禀赋结构的产业能够实现最低成本并获得自生能力 → 因此一国的产业结构由禀赋结构内生决定，外生强加的偏离结构无法持续 |
| **Lag（时滞）** | 要素禀赋结构变化后，产业结构调整通常需要数年至数十年的投资与转型时间；若存在政策扭曲，实际调整可能明显滞后于禀赋变化 |
| **Threshold（临界值）** | 当进入产业的要素密集度与本国禀赋结构的相对丰裕度匹配时（如劳动密集型产业对应劳动力丰裕国），该产业结构即为最优；偏离越远，企业自生能力越低 |
| **前提与约束（Premises）** | 要素市场充分竞争且价格如实反映相对丰裕度；企业以利润最大化为目标，可自由选择技术与产业；技术选择集合给定且各产业生产技术呈要素密集度差异；不存在持续的政府补贴或价格扭曲来掩盖企业亏损 |
| **Falsification（证伪条件）** | 若发现某劳动力丰裕国在无需持续保护与补贴的情况下，长期在资本密集型产业中拥有国际竞争力和高利润率，且其资本禀赋并未发生相应提升，则该因果断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同按照身材量体裁衣：产业选择必须与要素禀赋合身，强行套用不适合的产业结构就像穿不合身的衣服，行动困难且难以持久

### 🔗 文字版因果链

1. 要素禀赋结构决定各要素的相对价格：丰裕要素价格低，稀缺要素价格高
2. 相对价格体系决定成本最小化的产业与技术选择
3. 符合禀赋结构的产业能够实现最低成本并获得自生能力
4. 因此一国的产业结构由禀赋结构内生决定，外生强加的偏离结构无法持续
