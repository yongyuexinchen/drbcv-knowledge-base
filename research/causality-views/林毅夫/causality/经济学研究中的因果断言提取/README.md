# 经济学研究中的因果断言提取（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：经济学研究中的因果断言提取.md

## 总体因果图

- 主要约束条件的变化 → 现有理论解释和预测能力的失效
- 发展中国家技术相对落后 → 进口（中间品和机器设备）对生产率提升有显著促进作用，且大于出
- 理想数据缺乏 → 中国问题研究难以发表在顶级经济学期刊上
- 研究带来的新的经济学洞见 → 研究成为一流经济学研究
