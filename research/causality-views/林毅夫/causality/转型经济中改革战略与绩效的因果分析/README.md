# 转型经济中改革战略与绩效的因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：转型经济中改革战略与绩效的因果分析.md

## 总体因果图

- 违背比较优势的重工业优先发展战略 → 经济扭曲、无效率与技术落后
- 休克疗法（大爆炸式改革） → 经济崩溃、大规模失业和社会政治不稳定
- 渐进双轨制改革（对旧产业暂时保护，放开新产业） → 经济稳定、持续增长和成功转型
- 家庭联产承包责任制（农业产权激励改革） → 农业产出大幅增长
