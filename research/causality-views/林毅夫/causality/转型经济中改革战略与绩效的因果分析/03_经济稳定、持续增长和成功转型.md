# 经济稳定、持续增长和成功转型

> 属于因果簇：[[转型经济中改革战略与绩效的因果分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 渐进双轨制改革（对旧产业暂时保护，放开新产业） |
| **DV（因变量）** | 经济稳定、持续增长和成功转型 |
| **Chain（传导链）** | 保留对优先部门中无自生能力企业的临时保护，维持政治经济稳定 → 同时放开私营企业和外商直接投资进入符合比较优势的产业 → 新产业在竞争中获得增长，发挥后发优势，资本持续积累 → 经济增长带来财政资源和就业机会 → 新产业增长使旧企业逐渐变得有自生能力，可以通过卡尔多改进方式逐步退出保护、消除扭曲 |
| **Lag（时滞）** | 持续增长在改革后几年内显现，并可持续数十年（如中国1978年后年均增长9.9%，持续32年） |
| **Threshold（临界值）** | 政府需能甄别出潜在比较优势的产业，并有能力提供阶段性保护与开放新产业的基础设施和激励 |
| **前提与约束（Premises）** | 转型经济体存在多重扭曲，但政府具备较强的执行能力和政治控制力；选择的新产业确实符合本国的比较优势；改革过程中保持社会基本稳定，避免大规模动荡 |
| **Falsification（证伪条件）** | 如果采用渐进双轨制的转型经济体长期增长乏力、未能完成改革或最终崩溃，则可推翻该断言 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 边跑步边换轮胎——不停车，先装上新轮胎再松开旧轮胎，虽然过程颠簸，但车始终在前进

### 🔗 文字版因果链

1. 保留对优先部门中无自生能力企业的临时保护，维持政治经济稳定
2. 同时放开私营企业和外商直接投资进入符合比较优势的产业
3. 新产业在竞争中获得增长，发挥后发优势，资本持续积累
4. 经济增长带来财政资源和就业机会
5. 新产业增长使旧企业逐渐变得有自生能力，可以通过卡尔多改进方式逐步退出保护、消除扭曲
