# 新结构经济学中的因果断言（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：新结构经济学中的因果断言.md

## 总体因果图

- 遵循比较优势的产业和技术选择 → 经济持续增长与结构转型
- 软硬件基础设施质量的改善 → 企业的交易成本及国际竞争力
- 政府主动提供或协调软硬件基础设施改善 → 产业升级顺利实现与经济发展
- 发展中国家基于比较优势从发达国家引进成熟技术（后发优势） → 技术变迁率高于发达国家，资本快速积累，缩小发展差距
