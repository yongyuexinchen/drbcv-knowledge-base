# 企业的交易成本及国际竞争力

> 属于因果簇：[[新结构经济学中的因果断言]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 软硬件基础设施质量的改善 |
| **DV（因变量）** | 企业的交易成本及国际竞争力 |
| **Chain（传导链）** | 基础设施影响企业获取投入品和出售产出的交易成本 → 糟糕的基础设施导致频繁停电、物流不畅、港口效率低下、官僚作风盛行 → 企业交易成本上升，抵消低工资优势 → 企业在国际市场上缺乏竞争力，经济发展受限 |
| **Lag（时滞）** | 短期至中期显现，不一定存在固定时滞 |
| **Threshold（临界值）** | 无量化阈值；基础设施需与产业升级阶段相匹配 |
| **前提与约束（Premises）** | 要素禀赋在给定时间内不变；对企业而言，大部分硬件和几乎全部软件基础设施是外生的；在低收入国家劳动密集型产业中尤为显著 |
| **Falsification（证伪条件）** | 若发现基础设施较差但企业仍具备国际竞争力并维持增长，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同开餐馆，菜做得好但水电不通、道路难行，顾客不来，竞争力不如基础设施完善的对手

### 🔗 文字版因果链

1. 基础设施影响企业获取投入品和出售产出的交易成本
2. 糟糕的基础设施导致频繁停电、物流不畅、港口效率低下、官僚作风盛行
3. 企业交易成本上升，抵消低工资优势
4. 企业在国际市场上缺乏竞争力，经济发展受限
