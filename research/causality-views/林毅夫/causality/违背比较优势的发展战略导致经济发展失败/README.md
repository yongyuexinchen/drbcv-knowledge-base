# 违背比较优势的发展战略导致经济发展失败（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：违背比较优势的发展战略导致经济发展失败.md

## 总体因果图

- 违背比较优势的资本密集型产业发展战略（在资本稀缺、劳动力充裕的经济中优先发展重工业） → 经济发展失败（企业无自生能力、政府补贴负担、宏观经济危机、增
- 政府对无自生能力企业提供持续补贴和保护 → 宏观经济扭曲（财政赤字、外债累积、国际收支失衡、高通胀、金融
- 因保护无自生能力企业而引入的扭曲措施（补贴、垄断、信贷配给、外汇控制等） → 扭曲的长期持续存在，即使其危害已充分显现
- 华盛顿共识式改革（仅强调消除扭曲、私有化、自由化，而不解决企业自生能力问题） → 经济增长依然缓慢或失败，未实现预期繁荣
