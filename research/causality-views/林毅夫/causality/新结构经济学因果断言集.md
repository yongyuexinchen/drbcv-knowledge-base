## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 要素禀赋结构（劳动/资本/自然资源的相对丰裕度） |
| **DV（因变量）** | 最优产业结构（产业与技术选择） |
| **Chain（传导链）** | 要素禀赋结构决定要素相对价格 → 相对价格决定成本最低的产业与技术选择 → 偏离该结构的产业中企业无自生能力 → 因此最优产业结构由禀赋结构内生决定 |
| **Lag（时滞）** | 即时（要素价格与成本比较在当期即可决定） |
| **Threshold（临界值）** | 任何偏离禀赋结构所决定的产业选择都会导致企业无自生能力 |
| **前提与约束（Premises）** | 经济处于开放、自由、竞争性市场环境；要素可流动且技术有现成选择；企业追求利润最大化 |
| **Falsification（证伪条件）** | 如果一国在偏离其要素禀赋结构的产业中，企业无需政府补贴即可在开放市场中持续盈利，则该断言被推翻。 |

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 后发国家与发达国家的技术差距 |
| **DV（因变量）** | 技术创新率与经济增长率 |
| **Chain（传导链）** | 发展中国家可从发达国家引进成熟技术 → 引进成本远低于前沿研发成本 → 技术差距越大，可供模仿的技术存量越多 → 技术创新率可数倍于发达国家 → 经济增长率因此数倍于发达国家 |
| **Lag（时滞）** | 引进技术后数年内即可显现，持续数十年 |
| **Threshold（临界值）** | 技术差距存在且所选技术与本国禀赋结构匹配；差距越大潜力越大 |
| **前提与约束（Premises）** | 发展中国家具备基本吸收能力（教育、基础设施、制度）；技术引进渠道畅通（贸易、FDI、许可证）；政治稳定且市场机制有效 |
| **Falsification（证伪条件）** | 如果大量发展中国家在存在技术差距且渠道畅通的情况下长期无法实现数倍于发达国家的增长，则该断言需要增加前提条件。 |
| **Confidence（确信度）** | well-established |

5. 经济增长率因此数倍于发达国家

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 产业结构（企业规模、信息透明度、风险类型） |
| **DV（因变量）** | 最优金融结构（中小银行 vs 大银行+证券市场） |
| **Chain（传导链）** | 低收入国产业劳动密集、企业小、信息不透明 → 小银行擅长处理本地软信息、建立长期关系 → 故最优金融结构以中小地方银行为基础 → 高收入国产业资本密集、接近前沿、创新分歧大 → 大银行适合大企业，证券市场适合创新项目并容纳分歧 → 故最优金融结构为大银行+证券市场 |
| **Lag（时滞）** | 随产业结构升级而长期演变 |
| **Threshold（临界值）** | 金融结构缺口每增加一个标准差，人均真实GDP降低6% |
| **前提与约束（Premises）** | 存在信息不对称；不同金融中介处理信息的能力差异显著；金融结构内生于实体经济的需求 |
| **Falsification（证伪条件）** | 如果低收入国以大银行主导金融结构也能实现同等增长，或高收入国以中小银行主导也表现更优，则断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

### 🔗 文字版因果链

1. 低收入国产业劳动密集、企业小、信息不透明
2. 小银行擅长处理本地软信息、建立长期关系
3. 故最优金融结构以中小地方银行为基础
4. 高收入国产业资本密集、接近前沿、创新分歧大
5. 大银行适合大企业，证券市场适合创新项目并容纳分歧
6. 故最优金融结构为大银行+证券市场
