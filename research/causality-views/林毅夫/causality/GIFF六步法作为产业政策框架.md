# GIFF六步法作为产业政策框架

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 采用增长甄别与因势利导六步法（GIFF）作为产业政策框架 |
| **DV（因变量）** | 产业政策成功（避免'选优'沦为'选劣'） |
| **Chain（传导链）** | 政府运用GIFF方法确定潜在比较优势产业 → 选择禀赋相似、人均收入约为本国一倍、高速增长20年以上的国家作为参照 → 模仿参照国的成熟贸易品作为目标产业 → 政府因势利导提供配套支持，使目标产业符合本国潜在比较优势 → 产业顺利发展，实现产业政策预期目标 |
| **Lag（时滞）** | 数年至数十年（取决于产业生命周期与基础设施建设） |
| **Threshold（临界值）** | 参照国与本国人均收入差距适中：本国人均收入为参照国的40%-75%（约为参照国的一半）；参照国须已实现20年以上高速增长 |
| **前提与约束（Premises）** | 参照国与本国资源禀赋相似；目标产业应为成熟、可贸易的产品；政府具备因势利导的治理能力与政策工具；国内存在相应的市场或可开拓国际市场 |
| **Falsification（证伪条件）** | 若按照GIFF选定参照国并模仿其产业后，出现产业持续衰退、竞争力低下或与本国禀赋明显不符，或出现大量违背该方法的成功反例，则削弱该断言 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 政府运用GIFF方法确定潜在比较优势产业
2. 选择禀赋相似、人均收入约为本国一倍、高速增长20年以上的国家作为参照
3. 模仿参照国的成熟贸易品作为目标产业
4. 政府因势利导提供配套支持，使目标产业符合本国潜在比较优势
5. 产业顺利发展，实现产业政策预期目标
