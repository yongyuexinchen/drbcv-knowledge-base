# 国有企业自生能力与政策性负担的因果链条

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国有企业承担的政策性负担 |
| **DV（因变量）** | 预算软约束 |
| **Chain（传导链）** | 政策性负担导致企业出现政策性亏损 → 政策性亏损的责任被归咎于政府，政府有责任给予补贴 → 信息不对称使政府无法区分政策性亏损与经营性亏损 → 企业将所有亏损都归因于政策性负担 → 政府为避免企业破产而背负所有亏损责任，形成预算软约束 |
| **Lag（时滞）** | 持续存在，贯穿国有企业存续期间 |
| **Threshold（临界值）** | 存在政策性负担且政府无法让企业破产，同时信息不对称 |
| **前提与约束（Premises）** | 国有企业处于开放竞争的市场经济环境中；大型企业两权分离，存在激励不相容和信息不对称；政府承担无限责任，不能放任企业破产 |
| **Falsification（证伪条件）** | 若观察到承担政策性负担的国有企业没有出现预算软约束，即企业亏损由自身承担并无政府补贴接力，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个孩子因为有“先天不足”的证明，父母不管他犯什么错都归结为病根，只好不断掏钱买单，孩子也就越来越依赖这个理由。

### 🔗 文字版因果链

1. 政策性负担导致企业出现政策性亏损
2. 政策性亏损的责任被归咎于政府，政府有责任给予补贴
3. 信息不对称使政府无法区分政策性亏损与经营性亏损
4. 企业将所有亏损都归因于政策性负担
5. 政府为避免企业破产而背负所有亏损责任，形成预算软约束

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国有企业缺乏自生能力 |
| **DV（因变量）** | 股市投机和庄家操纵问题 |
| **Chain（传导链）** | 缺乏自生能力的企业无法在开放竞争市场中获得预期利润率 → 投资者不能从长期持有股票获得满意回报 → 散户只能靠短期价格涨跌投机获利 → 机构投资者同样无法长期投资，只能依靠价格波动获利 → 监管不严时，机构投资者利用资金优势坐庄、操纵股价 |
| **Lag（时滞）** | 国有企业上市后即显现，投资者持股回报长期无望 |
| **Threshold（临界值）** | 企业改制后仍保持高资金密集度，自生能力问题未解决，且资本市场监管不严 |
| **前提与约束（Premises）** | 国有企业上市前仅剥离社会性负担，未解决资金密集度过高的自生能力问题；投资者追求可接受的回报，企业利润无法满足时转向投机；机构投资者资金量大且可主动影响价格 |
| **Falsification（证伪条件）** | 若缺乏自生能力的国企上市后，股民和机构投资者均长期持有并获得满意回报，股市无投机操纵现象，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一家不赚钱的店，股东不想长期经营，只能倒卖铺位赚差价；大资本甚至直接造势抬价坑散户。

### 🔗 文字版因果链

1. 缺乏自生能力的企业无法在开放竞争市场中获得预期利润率
2. 投资者不能从长期持有股票获得满意回报
3. 散户只能靠短期价格涨跌投机获利
4. 机构投资者同样无法长期投资，只能依靠价格波动获利
5. 监管不严时，机构投资者利用资金优势坐庄、操纵股价

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国有企业的政策性负担 |
| **DV（因变量）** | 银行商业化与利率市场化改革难以落实 |
| **Chain（传导链）** | 国有企业存在政策性负担，需要政府补贴 → “拨改贷”后补贴手段变为银行低息贷款 → 政府必须继续通过银行低息贷款支持国有企业 → 银行信贷配置受政策干预而非商业原则 → 利率无法由市场供求决定，商业化改革难以推进 |
| **Lag（时滞）** | 自“拨改贷”政策实施后持续存在，改革进程受阻 |
| **Threshold（临界值）** | 国有企业仍有政策性负担，政府依赖银行低息贷款作为补贴渠道 |
| **前提与约束（Premises）** | 国有企业无法破产，政府必须给予补贴；银行体系承担政策性补贴功能；利率市场化会提高国企融资成本，与补贴目标冲突 |
| **Falsification（证伪条件）** | 若国有企业仍然承担政策性负担，但银行商业化、利率市场化改革仍能实质性推进且国企无需低息贷款补贴，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 病人离不开呼吸机，医生不敢轻易拔管；银行就是那台维持生命的呼吸机。

### 🔗 文字版因果链

1. 国有企业存在政策性负担，需要政府补贴
2. “拨改贷”后补贴手段变为银行低息贷款
3. 政府必须继续通过银行低息贷款支持国有企业
4. 银行信贷配置受政策干预而非商业原则
5. 利率无法由市场供求决定，商业化改革难以推进

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国有企业的政策性负担 |
| **DV（因变量）** | 贪污腐败现象屡禁不绝 |
| **Chain（传导链）** | 政策性负担迫使政府给予国有企业补贴和保护 → 政府必须干预价格和市场准入以提供保护 → 干预赋予政府官员配置资源的权力 → 官员利用权力寻租，获取私人利益 → 贪污腐败现象滋生且难以根除 |
| **Lag（时滞）** | 长期存在，随政府干预的持续而不断出现 |
| **Threshold（临界值）** | 政府需要对价格、市场准入进行干预以补贴和保护国有企业 |
| **前提与约束（Premises）** | 政府掌握补贴和保护资源的分配权；官员是自利的经济人，存在寻租动机；监管制度不完善 |
| **Falsification（证伪条件）** | 若国有企业存在政策性负担且政府依然干预市场，但贪污腐败现象完全消失，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 手握审批章的人，自然有企业排队送礼，因为章能带来真金白银的补贴。

### 🔗 文字版因果链

1. 政策性负担迫使政府给予国有企业补贴和保护
2. 政府必须干预价格和市场准入以提供保护
3. 干预赋予政府官员配置资源的权力
4. 官员利用权力寻租，获取私人利益
5. 贪污腐败现象滋生且难以根除

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展战略从违反比较优势转向遵循比较优势 |
| **DV（因变量）** | 国有企业改革完成并建立透明、无寻租、无腐败的市场经济体系 |
| **Chain（传导链）** | 遵循比较优势发展经济，企业进入具有比较优势的产业 → 企业具有自生能力，不依赖政府补贴即可正常获利 → 政府无需再为企业提供政策性优惠和补贴 → 政府不再干预市场运作，政企分离 → 银行商业化、利率市场化、股市规范化和公司治理改革得以落实 → 形成透明、无寻租、无腐败、无扭曲的社会主义市场经济体系 |
| **Lag（时滞）** | 中长期，需经过产业结构调整和制度转型逐步实现 |
| **Threshold（临界值）** | 彻底转变赶超战略思想，所有产业选择均按要素禀赋决定的比较优势进行 |
| **前提与约束（Premises）** | 放弃优先发展不具备比较优势的资金密集型产业的目标；国家不再对非国防必需且无自生能力的企业给予保护；社会性负担通过资金筹集妥善剥离 |
| **Falsification（证伪条件）** | 若采取遵循比较优势的发展战略后，国有企业仍然没有自生能力、政府干预依旧、腐败寻租不退，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 治病先除根；以前逼瘦子干重活，现在让他做擅长的事，身体自然强壮，不再需要不断打针吃药（补贴）。

### 🔗 文字版因果链

1. 遵循比较优势发展经济，企业进入具有比较优势的产业
2. 企业具有自生能力，不依赖政府补贴即可正常获利
3. 政府无需再为企业提供政策性优惠和补贴
4. 政府不再干预市场运作，政企分离
5. 银行商业化、利率市场化、股市规范化和公司治理改革得以落实
6. 形成透明、无寻租、无腐败、无扭曲的社会主义市场经济体系
