## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国等新兴市场劳动密集型产业工人工资持续上升 |
| **DV（因变量）** | 撒哈拉以南非洲等低收入国家快速工业化（制造业就业与出口显著增长） |
| **Chain（传导链）** | 新兴市场（如中国）经济持续增长，劳动工资上升，劳动密集型产业成本优势削弱 → 企业为维持利润，寻求更低劳动力成本的生产地，劳动密集型产业开始向外转移（如中国释放8500万个岗位） → 低收入国家（尤其撒哈拉以南非洲）拥有充裕廉价劳动力，具备承接劳动密集型产业的要素禀赋 → 承接国通过提供政治稳定承诺、劳动法保障、物流改善和产业特区等条件，打消企业外迁顾虑 → 产业转移落地：非洲制造业就业与出口增加（如1%的中国服装生产转移即可使非洲服装出口增加47%） → 制造业扩张带动资本积累、技术学习与结构升级，最终实现快速工业化 |
| **Lag（时滞）** | 5-20年（参照日本60年代释放970万岗位、韩国80年代释放230万岗位的历时；中国8500万岗位的释放将更为漫长且渐进） |
| **Threshold（临界值）** | 中国劳动密集型产业工资上涨至使国内外生产成本差异足以覆盖转移成本（政策磨合、物流、基础设施建设等）的临界点；且转移规模超过一定比例（如中国服装生产转移1%即对非洲出口产生显著影响） |
| **前提与约束（Premises）** | 中国等新兴市场工资持续上升且无重大政策逆转（如产业大规模自动化替代或政府强力补贴挽留）；低收入国家（尤其撒哈拉以南非洲）能提供稳定政局、可预期的劳动法环境、基础物流设施或产业特区；全球贸易体系维持开放，多极增长格局下产业转移不受系统性壁垒阻断；承接国确实具备与劳动密集型产业匹配的要素禀赋结构（劳动力充裕、成本显著低于中国） |
| **Falsification（证伪条件）** | 若观测到中国工资水平显著上升但劳动密集型产业就业与出口份额并未下降（例如自动化全面抵消成本压力），或非洲国家即使设立产业特区仍无法吸引大规模产业转移（如因政治冲突、物流成本高企、劳动生产率过低），则“非洲可承接并快速工业化”的断言将被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同候鸟迁徙：当北方栖息地变冷（中国工资上涨），候鸟（劳动密集型产业）会成群飞往南方温暖湿地（非洲低成本国家）；但若南方湿地干涸或布满猎网（政局不稳、设施缺失），候鸟宁可原地适应或另寻他处。

### 🔗 文字版因果链

1. 新兴市场（如中国）经济持续增长，劳动工资上升，劳动密集型产业成本优势削弱
2. 企业为维持利润，寻求更低劳动力成本的生产地，劳动密集型产业开始向外转移（如中国释放8500万个岗位）
3. 低收入国家（尤其撒哈拉以南非洲）拥有充裕廉价劳动力，具备承接劳动密集型产业的要素禀赋
4. 承接国通过提供政治稳定承诺、劳动法保障、物流改善和产业特区等条件，打消企业外迁顾虑
5. 产业转移落地：非洲制造业就业与出口增加（如1%的中国服装生产转移即可使非洲服装出口增加47%）
6. 制造业扩张带动资本积累、技术学习与结构升级，最终实现快速工业化
