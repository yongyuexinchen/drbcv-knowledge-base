# 国有企业自生能力与政策性负担的因果链条（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：国有企业自生能力与政策性负担的因果链条.md

## 总体因果图

- 国有企业承担的政策性负担 → 预算软约束
- 国有企业缺乏自生能力 → 股市投机和庄家操纵问题
- 国有企业的政策性负担 → 银行商业化与利率市场化改革难以落实
- 国有企业的政策性负担 → 贪污腐败现象屡禁不绝
- 发展战略从违反比较优势转向遵循比较优势 → 国有企业改革完成并建立透明、无寻租、无腐败的市场经济体系
