# 制度效果（有效或失败）

> 属于因果簇：[[《本体与常无》中的因果断言提取]]（第5块/8块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 制度移植（将发达国家制度照搬到发展中国家） |
| **DV（因变量）** | 制度效果（有效或失败） |
| **Chain（传导链）** | 一个国家的社会政治制度内生于其文化传统、收入分配等 → 不同国家的外生变量不同 → 相同的制度在不同外生变量下产生不同效果 → 移植的先进制度可能变成‘淮南为橘，淮北为枳’ |
| **Lag（时滞）** | 长期（制度效果需长时间显现） |
| **Threshold（临界值）** | 外生变量（文化传统、收入分配等）差异足够大 |
| **前提与约束（Premises）** | 制度是内生变量，由文化传统、收入分配等外生变量决定；法律、文化传统是短期内不可改变的外生变量 |
| **Falsification（证伪条件）** | 若发现文化传统和收入分配差异巨大的国家移植相同制度后产生相同效果，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 橘生淮南则为橘，生于淮北则为枳——种子相同，水土不同，果实不同。

### 🔗 文字版因果链

1. 一个国家的社会政治制度内生于其文化传统、收入分配等
2. 不同国家的外生变量不同
3. 相同的制度在不同外生变量下产生不同效果
4. 移植的先进制度可能变成‘淮南为橘，淮北为枳’
