> 属于因果簇：[[《本体与常无》中的因果断言提取]]（第3块/8块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政策性负担 |
| **DV（因变量）** | 预算软约束和公司治理问题 |
| **Chain（传导链）** | 国有企业承担政策性负担（如就业、战略产业） → 政府必须为承担政策性负担的企业提供保护补贴 → 保护补贴导致预算软约束 → 预算软约束使公司治理问题恶化且难以解决 |
| **Lag（时滞）** | 同时或短期（内生关系，政策负担存在则问题随之出现） |
| **Threshold（临界值）** | 企业存在政策性负担 |
| **前提与约束（Premises）** | 国有企业的政策性负担是外生给定的；政府无法承诺不救助承担政策负担的企业 |
| **Falsification（证伪条件）** | 若发现没有政策性负担的国有企业也普遍存在严重的预算软约束和公司治理问题，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 国有企业承担政策性负担（如就业、战略产业）
2. 政府必须为承担政策性负担的企业提供保护补贴
3. 保护补贴导致预算软约束
4. 预算软约束使公司治理问题恶化且难以解决
