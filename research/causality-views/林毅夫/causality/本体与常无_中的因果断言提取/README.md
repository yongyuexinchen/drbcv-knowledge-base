# 《本体与常无》中的因果断言提取（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：本体与常无_中的因果断言提取.md

## 总体因果图

- 产业政策是否符合要素禀赋结构所决定的比较优势 → 产业政策的成功或失败
- 市场供求状况（短缺经济 vs 生产能力过剩） → 乡镇企业的绩效（成功与破产）
- 政策性负担 → 预算软约束和公司治理问题
- 赶超战略（优先发展不符合比较优势的资本密集型产业） → 收入分配恶化、经济停滞甚至危机
- 制度移植（将发达国家制度照搬到发展中国家） → 制度效果（有效或失败）
- 按比较优势发展劳动密集型产业 → 穷人收入增加、收入差距缩小
- 世界经济中心（从英国转移到美国，未来可能转移到中国） → 经济学研究中心与经济学大师产生地
- 没有自生能力企业的数量和规模（小国 vs 大国转型） → 休克疗法的成败
