# 货币国际化的可持续性

> 属于因果簇：[[货币国际化的因果断言]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国内金融改革与资本账户开放的先后次序 |
| **DV（因变量）** | 货币国际化的可持续性 |
| **Chain（传导链）** | 先改革后开放，国内金融体制理顺后放开资本项目 → 开放后市场能够有效吸收外部资本且避免制度套利 → 货币国际化稳步推进并获得长期红利 → 反之，以开放代改革导致资本流动套利和金融泡沫，最终危机爆发损害货币信用 |
| **Lag（时滞）** | 中短期到长期（泡沫形成需数年，崩溃后影响持续数十年） |
| **Threshold（临界值）** | 国内利率市场化、债券市场改革、废黜主银行体制等基本完成后再放开资本项目；未完成则开放必然带来套利循环 |
| **前提与约束（Premises）** | 存在资本管制和金融抑制的初始条件；政府有政策自主性，不被外部压力主导；货币国际化需要微观金融主体健康 |
| **Falsification（证伪条件）** | 若找到一个国家以开放代改革却实现了可持续的货币国际化，或先改革后开放却失败，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 学游泳要先学会换气再下深水，否则必然呛水；金融改革没做好就开资本账户，等于拿泡沫当救生圈。

### 🔗 文字版因果链

1. 先改革后开放，国内金融体制理顺后放开资本项目
2. 开放后市场能够有效吸收外部资本且避免制度套利
3. 货币国际化稳步推进并获得长期红利
4. 反之，以开放代改革导致资本流动套利和金融泡沫，最终危机爆发损害货币信用
