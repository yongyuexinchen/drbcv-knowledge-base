# 中美贸易逆差扩大

> 属于因果簇：[[人民币汇率波动的政治经济博弈中的因果断言]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国对华技术禁运和出口限制 |
| **DV（因变量）** | 中美贸易逆差扩大 |
| **Chain（传导链）** | 美国限制高技术产品对华出口 → 中国无法从美国购买所需产品，转向其他市场或减少进口 → 美国对华出口额受限，中国对美出口保持增长 → 贸易逆差因此扩大 |
| **Lag（时滞）** | 长期、持续 |
| **Threshold（临界值）** | 若放宽到巴西标准，逆差将减小25% |
| **前提与约束（Premises）** | 中国对美国产品存在需求；美国实施有选择性的出口管制 |
| **Falsification（证伪条件）** | 如果美国放宽出口限制后逆差未缩小，或者逆差主要由汇率或其他因素造成，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像一个商店老板拒绝把顾客想要的商品卖给顾客，却抱怨顾客只买我的便宜货导致自己生意不好

### 🔗 文字版因果链

1. 美国限制高技术产品对华出口
2. 中国无法从美国购买所需产品，转向其他市场或减少进口
3. 美国对华出口额受限，中国对美出口保持增长
4. 贸易逆差因此扩大
