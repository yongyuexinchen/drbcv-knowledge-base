# 人民币汇率波动的政治经济博弈中的因果断言（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：人民币汇率波动的政治经济博弈中的因果断言.md

## 总体因果图

- 人民币汇率低估与固定汇率政策 → 中国快速工业化与民众财富向外部转移
- 持续的经常项目和资本项目双顺差 → 国内基础货币扩张与金融抑制
- 国际国内政治经济压力（美国施压、国内产业和央行诉求） → 2005年人民币汇率一次性升值2.1%并开启渐进升值路径
- 人民币汇率单向升值预期及套利机会 → 热钱流入、贸易顺差虚高和升值预期自我强化
- 美国对华技术禁运和出口限制 → 中美贸易逆差扩大
- 市场贬值预期与资本外逃 → 外汇储备消耗和人民币贬值压力持续
