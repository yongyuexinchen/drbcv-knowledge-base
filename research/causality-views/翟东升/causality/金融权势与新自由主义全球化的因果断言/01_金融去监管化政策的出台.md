# 金融去监管化政策的出台

> 属于因果簇：[[金融权势与新自由主义全球化的因果断言]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融业的政治捐赠和人员旋转门 |
| **DV（因变量）** | 金融去监管化政策的出台 |
| **Chain（传导链）** | 巨额竞选献金和旋转门使政客与金融业利益捆绑 → 金融利益集团成功游说监管者 → 政府放松对金融业的管制（利率、混业、衍生品） |
| **Lag（时滞）** | 20世纪70年代到90年代，持续约二十年 |
| **Threshold（临界值）** | 金融业成为最大竞选献金方，白宫重要职位华尔街背景占比超过一半 |
| **前提与约束（Premises）** | 美国选举民主允许利益集团游说；三权分立和舆论独立为利益集团提供多元化通道 |
| **Falsification（证伪条件）** | 如果金融业的政治投入增加而金融监管并未放松，或反而加强，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大金主通过赞助政客和安排自己人进入政府，让监督者变成保护伞

### 🔗 文字版因果链

1. 巨额竞选献金和旋转门使政客与金融业利益捆绑
2. 金融利益集团成功游说监管者
3. 政府放松对金融业的管制（利率、混业、衍生品）
