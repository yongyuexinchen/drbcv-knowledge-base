# 银行过度承担风险、金融系统脆弱性增加

> 属于因果簇：[[金融权势与新自由主义全球化的因果断言]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府为大型金融机构提供救助安全网（大到不能倒） |
| **DV（因变量）** | 银行过度承担风险、金融系统脆弱性增加 |
| **Chain（传导链）** | 政府明确不会让大金融机构破产 → 储户和债权人失去监督激励 → 银行有动机选择高风险高收益项目 → 风险累积，最终由纳税人承担损失 |
| **Lag（时滞）** | 从1984年大陆银行救助到2008年危机，约二十年 |
| **Threshold（临界值）** | 金融机构规模达到系统重要性（如AIG） |
| **前提与约束（Premises）** | 政府无法承受系统性风险；存在存款保险或政府兜底预期；金融机构与政治联系密切 |
| **Falsification（证伪条件）** | 如果大而不能倒政策存在而银行没有增加风险承担，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家长承诺为孩子的全部债务兜底，孩子就会大胆借高利贷

### 🔗 文字版因果链

1. 政府明确不会让大金融机构破产
2. 储户和债权人失去监督激励
3. 银行有动机选择高风险高收益项目
4. 风险累积，最终由纳税人承担损失
