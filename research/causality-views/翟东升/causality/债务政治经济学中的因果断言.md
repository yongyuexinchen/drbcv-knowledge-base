# 债务政治经济学中的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济增长与财富扩张 |
| **DV（因变量）** | 债务的永久增长 |
| **Chain（传导链）** | 经济总量扩张使财产权总量增加且多样化 → 财产权可拆解为股权和债权，债权债务对应守恒 → 人们财富增加导致债权债务关系快速扩张 → 最终债务人（央行）资产负债表扩张，总债务持续增长 |
| **Lag（时滞）** | 长期自然过程，无特定时滞 |
| **Threshold（临界值）** | 无量化阈值；只要经济持续增长且货币无硬锚，债务即扩张 |
| **前提与约束（Premises）** | 债权与债务必然对应且总量守恒；经济持续扩张；处于无锚货币时代（金本位已取代） |
| **Falsification（证伪条件）** | 若经济持续增长而总债务规模长期下降或停滞，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 财富像膨胀的气球，债务是气球表面的张力；气球越大，张力（债务）必然越大。

### 🔗 文字版因果链

1. 经济总量扩张使财产权总量增加且多样化
2. 财产权可拆解为股权和债权，债权债务对应守恒
3. 人们财富增加导致债权债务关系快速扩张
4. 最终债务人（央行）资产负债表扩张，总债务持续增长

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球货币体系脱离黄金硬锚（无锚货币制度） |
| **DV（因变量）** | 政府债务空间无限化及债务率持续上升 |
| **Chain（传导链）** | 1972年布雷顿森林体系向牙买加体系转变，央行货币发行锚住通胀而非黄金 → 央行成为最终债务人，可无限扩张货币基础 → 政府本币债务可借新还旧且利率部分自定 → 政府债务率得以持续上升而不必然违约 |
| **Lag（时滞）** | 20世纪70年代后逐步显现，长期效应 |
| **Threshold（临界值）** | 以1972年为起点；无明确债务率阈值 |
| **前提与约束（Premises）** | 政府债务以本币计价；央行具有货币发行自主权；通胀目标制容忍温和通胀 |
| **Falsification（证伪条件）** | 若在无锚货币体系下政府债务率长期下降且无法扩张，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 从金库取钱变成自己印钞，钱包容量不再受黄金储备限制，自然可以越借越多。

### 🔗 文字版因果链

1. 1972年布雷顿森林体系向牙买加体系转变，央行货币发行锚住通胀而非黄金
2. 央行成为最终债务人，可无限扩张货币基础
3. 政府本币债务可借新还旧且利率部分自定
4. 政府债务率得以持续上升而不必然违约

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济体的信用状况（经济强势、市场信心） |
| **DV（因变量）** | 高债务率与坚挺汇率并存 |
| **Chain（传导链）** | 只有强势有信用的经济体才能从市场上借到更多钱 → 因此高债务率是市场信任的结果 → 高信用支撑货币信用，汇率坚挺 → 债务率与汇率呈正相关 |
| **Lag（时滞）** | 长期关系，时滞未明确 |
| **Threshold（临界值）** | 无量化阈值；以信用状况为条件 |
| **前提与约束（Premises）** | 排除中东产油国等特殊样本；市场自由定价汇率；债务可持续借新还旧 |
| **Falsification（证伪条件）** | 若低信用经济体能够长期维持高债务率且汇率坚挺，则断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 银行更愿意贷款给富人，富人负债越多反而说明银行信任他；信用是负债的基础。

### 🔗 文字版因果链

1. 只有强势有信用的经济体才能从市场上借到更多钱
2. 因此高债务率是市场信任的结果
3. 高信用支撑货币信用，汇率坚挺
4. 债务率与汇率呈正相关

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 周期错配或币种错配 |
| **DV（因变量）** | 债务违约或巨大损失 |
| **Chain（传导链）** | 周期错配：借短投长，融资链条断裂时不得不违约或低价抛售资产 → 币种错配：负债与资产币种不同，汇率波动或兑换受限时承受损失 → 两种错配造成现金流或资产负债表失衡 → 最终引发违约或危机 |
| **Lag（时滞）** | 取决于融资期限或汇率波动，通常中期显现 |
| **Threshold（临界值）** | 无明确数量阈值；当错配超过债务人承受能力时爆发 |
| **前提与约束（Premises）** | 排除经营失利亏掉资本的情形；对于国家主体，本币债务不存在周期错配，风险主要在外币债务 |
| **Falsification（证伪条件）** | 若存在严重错配但无任何损失或违约，且非因外部救助，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用短期存款投资长期房产，存款到期时房子没卖就资金链断裂；或借美元买人民币资产，汇率一变就亏损。

### 🔗 文字版因果链

1. 周期错配：借短投长，融资链条断裂时不得不违约或低价抛售资产
2. 币种错配：负债与资产币种不同，汇率波动或兑换受限时承受损失
3. 两种错配造成现金流或资产负债表失衡
4. 最终引发违约或危机

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务主体的信用状况和偿债能力 |
| **DV（因变量）** | 杠杆水平与风险的关系（信用强则高杠杆低风险，信用弱则高杠杆高风险） |
| **Chain（传导链）** | 政府有主权信用、偿债能力强且无倒闭风险，高杠杆风险不大 → 非金融企业和居民信用较弱，高杠杆风险较大 → 国企有政府隐性担保，高杠杆风险可控 → 民企小企业缺乏担保，高杠杆风险很高 → 金融部门高杠杆因信息一体化易引发危机 |
| **Lag（时滞）** | 未明确 |
| **Threshold（临界值）** | 无明确数值；以信用等级和担保为条件 |
| **前提与约束（Premises）** | 金融市场存在担保和隐性担保机制；不同部门信用特征差异显著 |
| **Falsification（证伪条件）** | 若高杠杆无担保的民企风险很低，或低杠杆政府风险很高，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 同样的负债，对高薪公务员是月供，对无业者是深渊；关键在还款能力而非欠款数额。

### 🔗 文字版因果链

1. 政府有主权信用、偿债能力强且无倒闭风险，高杠杆风险不大
2. 非金融企业和居民信用较弱，高杠杆风险较大
3. 国企有政府隐性担保，高杠杆风险可控
4. 民企小企业缺乏担保，高杠杆风险很高
5. 金融部门高杠杆因信息一体化易引发危机

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外围国家的选票民主制度 |
| **DV（因变量）** | 财政赤字扩张与债务高企 |
| **Chain（传导链）** | 政客为获取选票承诺高福利开支 → 福利开支具有刚性，削减会遭选举惩罚 → 福利开支超出现有财源，政府只能扩大财政赤字 → 外围国家缺乏工业化支撑，高福利导致资本积累不足或外债依赖 |
| **Lag（时滞）** | 选举周期内显现，长期累积 |
| **Threshold（临界值）** | 无明确阈值；以福利扩张超过经济承受力为条件 |
| **前提与约束（Premises）** | 仅适用于体系外围国家；外围国家以中低端制造业或资源型经济为主；资源型国家受大宗商品价格周期影响 |
| **Falsification（证伪条件）** | 若外围国家实行选票民主却长期保持财政盈余或低债务，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 没有家底的人为了讨好邻居不断请客，最后只能借钱过日子。

### 🔗 文字版因果链

1. 政客为获取选票承诺高福利开支
2. 福利开支具有刚性，削减会遭选举惩罚
3. 福利开支超出现有财源，政府只能扩大财政赤字
4. 外围国家缺乏工业化支撑，高福利导致资本积累不足或外债依赖

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 少子老龄化（生育率长期下降） |
| **DV（因变量）** | 总需求不足、通缩与负利率 |
| **Chain（传导链）** | 生育率下降导致少子老龄化 → 劳动力减少但被科技进步替代，不构成瓶颈 → 老龄社会总需求不足，产能过剩 → 通胀率持续走低直至通缩 → 通缩将利率压至负值 |
| **Lag（时滞）** | 漫长滞后期（数十年） |
| **Threshold（临界值）** | 无具体老龄化率阈值；长期趋势下出现通缩和负利率 |
| **前提与约束（Premises）** | 科技进步能够替代劳动力；社会处于后工业化阶段；存在产能过剩 |
| **Falsification（证伪条件）** | 若老龄化社会出现持续通胀和利率上升，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 人老胃口变小，饭做多了吃不完，物价越来越低；钱没人借，利息也降到零以下。

### 🔗 文字版因果链

1. 生育率下降导致少子老龄化
2. 劳动力减少但被科技进步替代，不构成瓶颈
3. 老龄社会总需求不足，产能过剩
4. 通胀率持续走低直至通缩
5. 通缩将利率压至负值
