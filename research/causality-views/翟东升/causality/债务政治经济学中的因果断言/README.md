# 债务政治经济学中的因果断言（因果簇）

> 因果簇索引：7 个子因果卡。父卡文件：债务政治经济学中的因果断言.md

## 总体因果图

- 经济增长与财富扩张 → 债务的永久增长
- 全球货币体系脱离黄金硬锚（无锚货币制度） → 政府债务空间无限化及债务率持续上升
- 经济体的信用状况（经济强势、市场信心） → 高债务率与坚挺汇率并存
- 周期错配或币种错配 → 债务违约或巨大损失
- 债务主体的信用状况和偿债能力 → 杠杆水平与风险的关系（信用强则高杠杆低风险，信用弱则高杠杆高
- 外围国家的选票民主制度 → 财政赤字扩张与债务高企
- 少子老龄化（生育率长期下降） → 总需求不足、通缩与负利率
