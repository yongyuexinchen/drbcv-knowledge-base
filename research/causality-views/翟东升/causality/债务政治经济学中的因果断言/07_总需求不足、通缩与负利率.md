# 总需求不足、通缩与负利率

> 属于因果簇：[[债务政治经济学中的因果断言]]（第7块/7块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 少子老龄化（生育率长期下降） |
| **DV（因变量）** | 总需求不足、通缩与负利率 |
| **Chain（传导链）** | 生育率下降导致少子老龄化 → 劳动力减少但被科技进步替代，不构成瓶颈 → 老龄社会总需求不足，产能过剩 → 通胀率持续走低直至通缩 → 通缩将利率压至负值 |
| **Lag（时滞）** | 漫长滞后期（数十年） |
| **Threshold（临界值）** | 无具体老龄化率阈值；长期趋势下出现通缩和负利率 |
| **前提与约束（Premises）** | 科技进步能够替代劳动力；社会处于后工业化阶段；存在产能过剩 |
| **Falsification（证伪条件）** | 若老龄化社会出现持续通胀和利率上升，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 人老胃口变小，饭做多了吃不完，物价越来越低；钱没人借，利息也降到零以下。

### 🔗 文字版因果链

1. 生育率下降导致少子老龄化
2. 劳动力减少但被科技进步替代，不构成瓶颈
3. 老龄社会总需求不足，产能过剩
4. 通胀率持续走低直至通缩
5. 通缩将利率压至负值
