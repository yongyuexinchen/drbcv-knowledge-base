# 金融权势与新自由主义全球化的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融业的政治捐赠和人员旋转门 |
| **DV（因变量）** | 金融去监管化政策的出台 |
| **Chain（传导链）** | 巨额竞选献金和旋转门使政客与金融业利益捆绑 → 金融利益集团成功游说监管者 → 政府放松对金融业的管制（利率、混业、衍生品） |
| **Lag（时滞）** | 20世纪70年代到90年代，持续约二十年 |
| **Threshold（临界值）** | 金融业成为最大竞选献金方，白宫重要职位华尔街背景占比超过一半 |
| **前提与约束（Premises）** | 美国选举民主允许利益集团游说；三权分立和舆论独立为利益集团提供多元化通道 |
| **Falsification（证伪条件）** | 如果金融业的政治投入增加而金融监管并未放松，或反而加强，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大金主通过赞助政客和安排自己人进入政府，让监督者变成保护伞

### 🔗 文字版因果链

1. 巨额竞选献金和旋转门使政客与金融业利益捆绑
2. 金融利益集团成功游说监管者
3. 政府放松对金融业的管制（利率、混业、衍生品）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融去监管化 |
| **DV（因变量）** | 经济虚拟化，金融部门压倒实体部门 |
| **Chain（传导链）** | 解除利率管制和混业经营限制 → 金融机构跨界扩张和金融产品创新 → 金融部门利润和GDP占比持续上升 → 资本从制造业流向金融业 → 制造业就业和利润占比下降 |
| **Lag（时滞）** | 20世纪80年代至2008年金融危机，约二十余年 |
| **Threshold（临界值）** | 金融部门利润占比长期高于制造业；制造业就业占比从1946年的35%降至2008年的8% |
| **前提与约束（Premises）** | 美国金融部门利润率高；全球化使制造业可外包；美元储备货币地位为金融业提供便利 |
| **Falsification（证伪条件）** | 如果去监管化后金融部门占比没有上升且制造业部门没有萎缩，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同取消网吧限制，网吧越开越多，原本的图书馆却因人流减少而萎缩

### 🔗 文字版因果链

1. 解除利率管制和混业经营限制
2. 金融机构跨界扩张和金融产品创新
3. 金融部门利润和GDP占比持续上升
4. 资本从制造业流向金融业
5. 制造业就业和利润占比下降

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元全球储备货币地位 |
| **DV（因变量）** | 美国制造业就业和产出占比下降（去工业化） |
| **Chain（传导链）** | 全球储备美元导致美国必须保持国际收支逆差 → 逆差和美元高估损害制造业出口竞争力 → 制造业企业为降低成本将生产外包至东亚 → 国内制造业就业占比持续下降 |
| **Lag（时滞）** | 二战后逐渐显现，20世纪70年代起加速 |
| **Threshold（临界值）** | 美国持续存在综合逆差，美元汇率长期高估 |
| **前提与约束（Premises）** | 各国愿意持有美元作为储备；东亚拥有低成本劳动力；技术标准化使外包成为可能 |
| **Falsification（证伪条件）** | 如果美元储备地位增强而美国制造业占比没有下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个拥有全球通用货币发行权的国家，靠印钞就能换取商品，本国的工厂反而敌不过进口货

### 🔗 文字版因果链

1. 全球储备美元导致美国必须保持国际收支逆差
2. 逆差和美元高估损害制造业出口竞争力
3. 制造业企业为降低成本将生产外包至东亚
4. 国内制造业就业占比持续下降

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美式季度资本主义（以股票市值为指挥棒） |
| **DV（因变量）** | 大型制造业长期投资不足、竞争力下降 |
| **Chain（传导链）** | 上市公司需要按季度报告盈利 → 管理层收入和职业前途与股票市值挂钩 → 为满足短期目标削减研发和长期项目开支 → 长期竞争力下降，如波音事件 |
| **Lag（时滞）** | 数年至数十年（取决于企业寿命） |
| **Threshold（临界值）** | 80%的CFO愿意削减研发等开支以满足短期目标；50%将延迟新项目 |
| **前提与约束（Premises）** | 美国企业依赖资本市场融资；资产管理公司要求短期盈利；成熟制造企业需要长期战略投资 |
| **Falsification（证伪条件）** | 如果美国大型制造业在季度资本主义下仍保持长期竞争力，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同为了每次月考的排名而熬夜刷题，放弃系统学习，最终高考失利

### 🔗 文字版因果链

1. 上市公司需要按季度报告盈利
2. 管理层收入和职业前途与股票市值挂钩
3. 为满足短期目标削减研发和长期项目开支
4. 长期竞争力下降，如波音事件

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府为大型金融机构提供救助安全网（大到不能倒） |
| **DV（因变量）** | 银行过度承担风险、金融系统脆弱性增加 |
| **Chain（传导链）** | 政府明确不会让大金融机构破产 → 储户和债权人失去监督激励 → 银行有动机选择高风险高收益项目 → 风险累积，最终由纳税人承担损失 |
| **Lag（时滞）** | 从1984年大陆银行救助到2008年危机，约二十年 |
| **Threshold（临界值）** | 金融机构规模达到系统重要性（如AIG） |
| **前提与约束（Premises）** | 政府无法承受系统性风险；存在存款保险或政府兜底预期；金融机构与政治联系密切 |
| **Falsification（证伪条件）** | 如果大而不能倒政策存在而银行没有增加风险承担，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家长承诺为孩子的全部债务兜底，孩子就会大胆借高利贷

### 🔗 文字版因果链

1. 政府明确不会让大金融机构破产
2. 储户和债权人失去监督激励
3. 银行有动机选择高风险高收益项目
4. 风险累积，最终由纳税人承担损失
