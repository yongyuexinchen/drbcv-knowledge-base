# 美元体系风险与结构性缺陷的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：美元体系风险与结构性缺陷的因果机制.md

## 总体因果图

- 美元作为全球储备货币的特权 → 美国制造业就业占比下降及霸权基础削弱
- 全球对美元体系/美国信心的变化（信心下降） → 黄金长期价格（上涨）
- 无锚货币和浮动汇率制度 → 国际贸易面临额外交易成本（汇率风险溢价）
- 亚洲及外围国家大规模积累外汇储备（美元资产） → 美国公私债务膨胀并引发2008年全球金融危机
