# 去依附与三农化解危机的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国试图维持完全的主权独立国家、实现“去依附”的强制性制度变迁 |
| **DV（因变量）** | 六七十年代的普遍贫困 |
| **Chain（传导链）** | 中国为维持完全主权独立而拒绝依附红利 → 被迫承担独立自主带来的制度成本 → 制度成本表现为经济效率损失和资源匮乏 → 最终形成六七十年代的普遍贫困 |
| **Lag（时滞）** | 长期（六七十年代持续显现） |
| **Threshold（临界值）** | 无明确量化阈值，以主权独立优先于经济增长为条件 |
| **前提与约束（Premises）** | 冷战背景下中国面临外部封锁，无法通过对外转嫁制度成本；工业化原始积累只能内部提取农业剩余 |
| **Falsification（证伪条件）** | 若能证明中国在维持完全主权独立的同时未出现普遍贫困，或贫困另有完全无关的原因，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人为了彻底独立而放弃高薪依附工作，省吃俭用，生活质量大幅下降。

### 🔗 文字版因果链

1. 中国为维持完全主权独立而拒绝依附红利
2. 被迫承担独立自主带来的制度成本
3. 制度成本表现为经济效率损失和资源匮乏
4. 最终形成六七十年代的普遍贫困

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 70年代初期引进外来技术和设备调整工业结构 |
| **DV（因变量）** | 120多亿美元的对外负债及“再依附”压力加剧 |
| **Chain（传导链）** | 1971年西方放松封锁，中国开始引进外资技术设备 → 引进形成“依附红利”但也需偿还本息 → 七十年代亚非拉发展中国家普遍借债引发债务危机 → 中国对外负债达120多亿美元，财政需承担偿还责任 → 外债压力转化为“再依附”压力 |
| **Lag（时滞）** | 20世纪70年代（1974年财政赤字超100亿元，1979年突破200亿元） |
| **Threshold（临界值）** | 对外负债超过120亿美元，财政赤字超过100亿元（1974年）、200亿元（1979年） |
| **前提与约束（Premises）** | 发展中国家引进外资时普遍面临债务陷阱；中国外债只能由国家财政偿还，缺乏对外转嫁能力 |
| **Falsification（证伪条件）** | 如果能证明70年代引进外资未造成对外负债或再依附压力，或者负债未触发财政赤字危机，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像穷人借钱买奢侈品，表面风光，随后陷入还债泥潭。

### 🔗 文字版因果链

1. 1971年西方放松封锁，中国开始引进外资技术设备
2. 引进形成“依附红利”但也需偿还本息
3. 七十年代亚非拉发展中国家普遍借债引发债务危机
4. 中国对外负债达120多亿美元，财政需承担偿还责任
5. 外债压力转化为“再依附”压力

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对外负债造成的财政赤字危机（1974年超100亿元、1979年突破200亿元） |
| **DV（因变量）** | 城市产业资本投资不足、就业不足及失业危机爆发 |
| **Chain（传导链）** | 外债必须由国家财政偿还，形成巨额赤字 → 财政赤字挤占城市产业资本投资 → 城市产业资本无法进行扩大再生产，连简单再生产投资也不够 → 城市就业岗位不足，出现大面积就业不足 → 1979-1980年知青大返城进一步增加劳动力供给 → 失业危机集中爆发 |
| **Lag（时滞）** | 1974年至1980年期间逐步显现 |
| **Threshold（临界值）** | 财政赤字超过100亿元（1974年）、200亿元（1979年）；城市产业资本投资低于简单再生产需要 |
| **前提与约束（Premises）** | 外债只能由财政偿还，无法转移给私人部门；知青回城政策增加了城市劳动力供给 |
| **Falsification（证伪条件）** | 如果能证明财政赤字高企时城市就业仍然充分，或失业危机与财政赤字无关联，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 家庭财政被债务吞噬，无力维修店铺，伙计纷纷失业，又逢家人回乡找工作，失业潮爆发。

### 🔗 文字版因果链

1. 外债必须由国家财政偿还，形成巨额赤字
2. 财政赤字挤占城市产业资本投资
3. 城市产业资本无法进行扩大再生产，连简单再生产投资也不够
4. 城市就业岗位不足，出现大面积就业不足
5. 1979-1980年知青大返城进一步增加劳动力供给
6. 失业危机集中爆发

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 1980年知青大返城引发的失业危机（城市人群承载危机“硬着陆”代价） |
| **DV（因变量）** | 以“放权让利”为主要内涵的经济体制改革 |
| **Chain（传导链）** | 知青回城后无业、无房、无社保、无对象 → 城市首次由人群直接承载大危机硬着陆的代价 → 硬着陆引发社会不稳定压力 → 为避免危机硬着陆，决策层推出“放权让利”对策 → 经济体制改革由此产生 |
| **Lag（时滞）** | 1980年前后 |
| **Threshold（临界值）** | 失业危机爆发且城市无法自行消化 |
| **前提与约束（Premises）** | 改革是对危机的应对，而非精英设计；必须防止危机硬着陆，否则社会动荡 |
| **Falsification（证伪条件）** | 如果能证明1980年失业危机并未导致“放权让利”改革，或者改革另有其他根本原因，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 房子漏水严重，不得不动手改造管道，虽然当初没计划，但危机逼出了修整方案。

### 🔗 文字版因果链

1. 知青回城后无业、无房、无社保、无对象
2. 城市首次由人群直接承载大危机硬着陆的代价
3. 硬着陆引发社会不稳定压力
4. 为避免危机硬着陆，决策层推出“放权让利”对策
5. 经济体制改革由此产生

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 邓小平领导的“第二次土改”（给农民重新分地，实行家庭承包制） |
| **DV（因变量）** | 80年代内需拉动型高增长和农村减贫 |
| **Chain（传导链）** | 分地到户，家庭承包制释放农民生产积极性 → 解放农民这个第一生产力要素 → 过剩劳动力进入乡村工业化和城镇化 → 农村百业复兴，农产品和轻工业品出口创汇 → 农民收入连续4年快于城市，城乡收入差别缩小至2.4:1 → 农村大面积减贫，县以下城镇化发展 → 形成唯一一次内需拉动型黄金增长 |
| **Lag（时滞）** | 80年代初期至中期（约1980-1985） |
| **Threshold（临界值）** | 农民人口占85%；政府财政对三农支出占比降至低于3%；乡镇企业数量达2000多万家 |
| **前提与约束（Premises）** | 中国仍是城乡二元体制结构，农民占人口多数；农村已有集体化时期社队企业的工业经验；政府放权让利并实行“双轨制”放开原材料市场 |
| **Falsification（证伪条件）** | 如果能证明分地后未出现内需拉动型增长，或增长主要是其他因素导致（如城市改革），则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 把土地和自由还给农民，就像松开绳索，千军万马立刻奔向市场，粮食和工厂都活了。

### 🔗 文字版因果链

1. 分地到户，家庭承包制释放农民生产积极性
2. 解放农民这个第一生产力要素
3. 过剩劳动力进入乡村工业化和城镇化
4. 农村百业复兴，农产品和轻工业品出口创汇
5. 农民收入连续4年快于城市，城乡收入差别缩小至2.4:1
6. 农村大面积减贫，县以下城镇化发展
7. 形成唯一一次内需拉动型黄金增长

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 21世纪初中国面临的输入型危机、污染与金融异化压力 |
| **DV（因变量）** | 国家生态文明转型战略及乡村振兴作为“第三次救中国”路径 |
| **Chain（传导链）** | 中国污染物排放世界第一，发展主义道路难以为继 → 金融异化导致虚拟部门扩张和股灾（2007年、2015年） → 国家被迫从2007年起强调生态文明，2012年确立战略 → 生态文明要求自然多样性与社会文化多样性整合 → 城市无法体现自然多样性，乡村社会最有条件承载多样业态 → 2017年提出乡村振兴战略作为生态文明转型载体 → 通过生态资源价值化、生态资本深化实现“绿水青山就是金山银山” → 推动货币换锚，缓解美元外储依附，化解大危机 |
| **Lag（时滞）** | 2003年提出科学发展观至2017年乡村振兴战略正式推出，约15年 |
| **Threshold（临界值）** | 几乎所有污染物排放世界第一；金融总量世界第一但人民币非国际结算货币；2015年股灾蒸发21万亿元财富 |
| **前提与约束（Premises）** | 中国无法走美国式金融资本扩张道路；城市缺乏自然多样性条件；乡村尚未被激进发展主义完全摧毁，仍有生态资源可货币化 |
| **Falsification（证伪条件）** | 如果能证明生态文明转型不需要乡村振兴也能实现，或者乡村生态资源货币化不能缓解金融依附和危机，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 船漏了又遇风暴，只能靠乡土这个压舱石稳住，把债务这个锚换成土地和生态的锚。

### 🔗 文字版因果链

1. 中国污染物排放世界第一，发展主义道路难以为继
2. 金融异化导致虚拟部门扩张和股灾（2007年、2015年）
3. 国家被迫从2007年起强调生态文明，2012年确立战略
4. 生态文明要求自然多样性与社会文化多样性整合
5. 城市无法体现自然多样性，乡村社会最有条件承载多样业态
6. 2017年提出乡村振兴战略作为生态文明转型载体
7. 通过生态资源价值化、生态资本深化实现“绿水青山就是金山银山”
8. 推动货币换锚，缓解美元外储依附，化解大危机
