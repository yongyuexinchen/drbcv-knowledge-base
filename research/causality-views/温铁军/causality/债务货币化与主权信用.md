## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 核心国（美国）过度负债 |
| **DV（因变量）** | 不承担还债义务（主权信用丧失） |
| **Chain（传导链）** | 核心国（美国）过度负债 → 增发货币购买增发的债务 → 债务演变为资产交易 → 不承担还债义务 |
| **Lag（时滞）** | 长周期、慢变量，可能为数年至数十年 |
| **Threshold（临界值）** | 当区域“去美元化”（如石油欧元、人民币湖、亚投行）形成规模，美元霸权受损时 |
| **前提与约束（Premises）** | 该国货币是全球结算与储备货币；有军事强权支撑货币信用；有外部转嫁对象（半边缘+边缘国） |
| **Falsification（证伪条件）** | 如果美国在过度负债后仍始终履行偿债义务，或去美元化虽形成规模但美债估值逻辑并未重估，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个长期靠拆东墙补西墙的信用卡用户，只要银行和商家都接受他的卡，他就能一直透支；一旦大家开始拒收这张卡，他的信用崩塌便无法继续维持。
