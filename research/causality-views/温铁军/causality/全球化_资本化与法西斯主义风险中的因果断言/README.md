# 全球化、资本化与法西斯主义风险中的因果断言（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：全球化_资本化与法西斯主义风险中的因果断言.md

## 总体因果图

- 中国农村劳动力严重过剩（农村劳动年龄人口5亿，农业劳动多由半劳力承担） → 劳动力价格极低且长期不上涨（如沿海低层劳动力价格10年不涨）
- 全球经济市场化和一体化 → 发展中国家劳工价格与生存条件同一化到最低程度
- 资本全球化 → 大城市超前繁荣、传统农区衰败
- 发展中国家没有新的资源可供资本化 → 世界法西斯主义的复苏（全球性重大危机）
- 印度缺乏新的可资本化资源（没有新的资源带来资本收益） → 印度或南亚次大陆可能出现法西斯主义
- 美国没有新的资源可供资本饕餮转化为资本收益 → 美国最可能向法西斯化转变
- 资本流出（或担心资本流出） → 美国 英国垄断资本反对资本流动并进行干预（如美国当裁判，英国
- 中国存在部门垄断且大部分资源仍处于自然状态（有待资本化） → 中国集全球化过程中各种内外矛盾于一身
