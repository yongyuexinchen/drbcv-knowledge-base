# 去依附与三农化解危机的因果断言（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：去依附与三农化解危机的因果断言.md

## 总体因果图

- 中国试图维持完全的主权独立国家、实现“去依附”的强制性制度变迁 → 六七十年代的普遍贫困
- 70年代初期引进外来技术和设备调整工业结构 → 120多亿美元的对外负债及“再依附”压力加剧
- 对外负债造成的财政赤字危机（1974年超100亿元、1979年突破200亿元） → 城市产业资本投资不足、就业不足及失业危机爆发
- 1980年知青大返城引发的失业危机（城市人群承载危机“硬着陆”代价） → 以“放权让利”为主要内涵的经济体制改革
- 邓小平领导的“第二次土改”（给农民重新分地，实行家庭承包制） → 80年代内需拉动型高增长和农村减贫
- 21世纪初中国面临的输入型危机、污染与金融异化压力 → 国家生态文明转型战略及乡村振兴作为“第三次救中国”路径
