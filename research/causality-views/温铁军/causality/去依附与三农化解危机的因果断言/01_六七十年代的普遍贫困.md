# 六七十年代的普遍贫困

> 属于因果簇：[[去依附与三农化解危机的因果断言]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国试图维持完全的主权独立国家、实现“去依附”的强制性制度变迁 |
| **DV（因变量）** | 六七十年代的普遍贫困 |
| **Chain（传导链）** | 中国为维持完全主权独立而拒绝依附红利 → 被迫承担独立自主带来的制度成本 → 制度成本表现为经济效率损失和资源匮乏 → 最终形成六七十年代的普遍贫困 |
| **Lag（时滞）** | 长期（六七十年代持续显现） |
| **Threshold（临界值）** | 无明确量化阈值，以主权独立优先于经济增长为条件 |
| **前提与约束（Premises）** | 冷战背景下中国面临外部封锁，无法通过对外转嫁制度成本；工业化原始积累只能内部提取农业剩余 |
| **Falsification（证伪条件）** | 若能证明中国在维持完全主权独立的同时未出现普遍贫困，或贫困另有完全无关的原因，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人为了彻底独立而放弃高薪依附工作，省吃俭用，生活质量大幅下降。

### 🔗 文字版因果链

1. 中国为维持完全主权独立而拒绝依附红利
2. 被迫承担独立自主带来的制度成本
3. 制度成本表现为经济效率损失和资源匮乏
4. 最终形成六七十年代的普遍贫困
