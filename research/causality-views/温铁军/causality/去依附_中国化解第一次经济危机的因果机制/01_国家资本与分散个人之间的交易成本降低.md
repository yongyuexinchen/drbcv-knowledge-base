# 国家资本与分散个人之间的交易成本降低

> 属于因果簇：[[去依附：中国化解第一次经济危机的因果机制]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地改革 |
| **DV（因变量）** | 国家资本与分散个人之间的交易成本降低 |
| **Chain（传导链）** | 土地改革提高了社会再组织化程度 → 组织化动员使国家资本占有利益的实质隐身于国家任务的宏大叙事中 → 国家资本与分散个人之间的交易成本被有效降低 |
| **Lag（时滞）** | 土改完成后1-3年内（1949-1952年） |
| **Threshold（临界值）** | 必须实现对农民的全员动员和组织覆盖，而非仅分配土地 |
| **前提与约束（Premises）** | 国家资本利益需要隐藏于集体目标中；农村社会以分散小农经济为主；存在土地改革与抗美援朝等重大国家动员任务 |
| **Falsification（证伪条件）** | 如果土地改革后国家资本与农民的交易成本没有显著下降或动员失败，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 小区成立业委会后集体与物业谈判，比每家单独找物业省力得多

### 🔗 文字版因果链

1. 土地改革提高了社会再组织化程度
2. 组织化动员使国家资本占有利益的实质隐身于国家任务的宏大叙事中
3. 国家资本与分散个人之间的交易成本被有效降低
