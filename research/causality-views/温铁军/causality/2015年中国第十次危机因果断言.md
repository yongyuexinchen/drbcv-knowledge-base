## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 2013年后去工业化与外资流出 |
| **DV（因变量）** | 2015年第十次危机（生产过剩与输入型叠加） |
| **Chain（传导链）** | 2013年后去工业化导致实体经济利润率下降，外资流出 → 实体经济全面不景气，资金从实体经济中析出 → 析出资金流入股市，推高股市泡沫 → 2015年6-8月股市泡沫破裂，股灾爆发，市值蒸发超25万亿 → 811汇改引发人民币贬值预期，资本外逃加剧 → 外储从近4万亿降至3.22万亿，损失约1/4，最终形成第十次危机 |
| **Lag（时滞）** | 约2年（2013年至2015年） |
| **Threshold（临界值）** | 外储损失超过1/4（8325亿美元）且股市市值蒸发超25万亿（相当于2015年GDP的1/3以上） |
| **前提与约束（Premises）** | 中国经济处于对外开放状态，资本流动相对自由；存在股市泡沫和汇率高估；实体经济已出现生产过剩和去工业化趋势 |
| **Falsification（证伪条件）** | 如果2015年股灾和汇改后资本外逃没有导致系统性危机，或者危机由其他独立因素引发，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同堰塞湖：去工业化堵塞了实体经济泄洪通道，资金涌入股市形成堰塞湖，汇改引爆溃坝，洪水（资本外逃）冲垮了外汇储备的堤坝。

### 🔗 文字版因果链

1. 2013年后去工业化导致实体经济利润率下降，外资流出

3. 析出资金流入股市，推高股市泡沫
4. 2015年6-8月股市泡沫破裂，股灾爆发，市值蒸发超25万亿
5. 811汇改引发人民币贬值预期，资本外逃加剧
6. 外储从近4万亿降至3.22万亿，损失约1/4，最终形成第十次危机
