# 中等收入陷阱的依附性根源：国际制度权不对称下的资本倒流

> **领域**：国际政治经济学 / 宏观经济学　|　**来源**：_cand_wtj_04.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国际货币金融权与制度话语权集中于核心国（国际制度权不对称） |
| **DV（因变量）** | 新兴国家陷入“中等收入陷阱”（依附性陷阱，经济增长被“打回原形”） |
| **Chain（传导链）** | 核心国掌握国际货币发行权、金融规则制定权和国际制度话语权 → 新兴国家融入以核心国为中心的国际货币金融体系，处于依附地位 → 核心国通过货币政策和制度规则主导全球资本流向 → 当核心国进入紧缩或避险周期，资本大规模从新兴市场流出 → 新兴国家货币贬值、流动性收缩、债务与增长承压 → 大宗商品“超级周期”消退后，新兴国家失去外部红利，增速跌破发达国家水平，落入中等收入陷阱 |
| **Lag（时滞）** | 制度性因素长期累积形成结构性依附；短期内资本大规模流出约在13个月内产生冲击，增长拐点以年度数据观察（如2015年） |
| **Threshold（临界值）** | 新兴经济体（不含中国）GDP增速降至发达国家以下（2015年：1.92% < 1.98%，1999年以来首次）；资本净流出规模达到或超过约1万亿美元/13个月（接近金融危机期间的两倍） |
| **前提与约束（Premises）** | 研究对象是融入现有国际货币金融体系、缺少独立货币金融权和制度议价权的新兴经济体；排除中国等拥有较强资本管制和自主工业体系、能抵御外部制度压力的国家；核心国在国际货币发行、金融规则和制度话语权上占据垄断或主导地位；大宗商品“超级周期”等一次性外部红利已经消退 |
| **Falsification（证伪条件）** | 若能证明在国际制度权不对称条件下仍有新兴国家实现持续自主增长并跨越中等收入陷阱；或资本大规模流出后新兴国家增速并未跌破发达国家水平；或新兴国家增速下滑完全可由国内制度因素解释而与国际货币金融权无关，则该断言可被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个小区由房东和物业制定全部缴费规则，租客在行情好时能靠外快赚一笔，但房东一旦加息或提高管理费，租客的存款就被吸走，永远攒不下买房钱——表面看是租客“挣得少”，实则是规则权掌握在别人手里。

### 🔗 文字版因果链

1. 核心国掌握国际货币发行权、金融规则制定权和国际制度话语权
2. 新兴国家融入以核心国为中心的国际货币金融体系，处于依附地位
3. 核心国通过货币政策和制度规则主导全球资本流向
4. 当核心国进入紧缩或避险周期，资本大规模从新兴市场流出
5. 新兴国家货币贬值、流动性收缩、债务与增长承压
6. 大宗商品“超级周期”消退后，新兴国家失去外部红利，增速跌破发达国家水平，落入中等收入陷阱
