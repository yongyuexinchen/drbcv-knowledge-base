# 农业无法自我积累成为独立产业，缺乏市场竞争力，成为财政包袱

> 属于因果簇：[[发达地区农村改革中的因果断言]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以工补农形成的农业高投入（特别是粮食生产） |
| **DV（因变量）** | 农业无法自我积累成为独立产业，缺乏市场竞争力，成为财政包袱 |
| **Chain（传导链）** | 通过转移乡镇企业收益‘以工补农’，形成农业高投入 → 高投入农业成本高昂，计算折旧和资金利率后经济上不合算 → 粮食生产无法参与市场竞争 → 农业不能自我积累，长期依赖外部补贴 → 最终成为财政负担，农业无法成为独立产业 |
| **Lag（时滞）** | 在乡镇企业完成原始积累、市场化程度提高后逐渐暴露，时间滞后较长 |
| **Threshold（临界值）** | 农业成本超过市场收益，即计算折旧和资金利率后无利可图 |
| **前提与约束（Premises）** | 宏观上国家粮食市场体制和经营机制改革不到位；微观上小农经济不适应现代市场经济，缺少明确市场主体；适用于发达地区及大城市郊区的高投入农业 |
| **Falsification（证伪条件）** | 如果高投入农业在无补贴条件下仍能盈利并自我积累，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个靠输血维持的病人，输血一停就生命垂危，永远无法自己造血恢复健康

### 🔗 文字版因果链

1. 通过转移乡镇企业收益‘以工补农’，形成农业高投入
2. 高投入农业成本高昂，计算折旧和资金利率后经济上不合算
3. 粮食生产无法参与市场竞争
4. 农业不能自我积累，长期依赖外部补贴
5. 最终成为财政负担，农业无法成为独立产业
