# 乡镇企业负担增大、负债率推高，资金紧张

> 属于因果簇：[[发达地区农村改革中的因果断言]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 乡镇企业收益大量向地方政府和社区转移 |
| **DV（因变量）** | 乡镇企业负担增大、负债率推高，资金紧张 |
| **Chain（传导链）** | 乡镇企业资产形成依赖社区环境（土地级差地租、劳动力剩余价值、历史性负利率贷款） → 因此企业收益必须向社区转移，承担公共品开支和社区消费 → 企业负担逐渐增大，效益被转移 → 企业只能依靠贷款维持生产经营，负债率推高 → 有限效益又交给银行，加剧银行头寸减少和贷款困难 |
| **Lag（时滞）** | 渐进累积，随着原始积累完成而逐步显现，约数年至十数年 |
| **Threshold（临界值）** | 非生产性占用资金达20%以上，乡镇企业负债率普遍达60%以上 |
| **前提与约束（Premises）** | 乡镇企业实行社区化制度，收益转移依赖乡村社区环境；国家宏观政策‘一刀切’导致资金供给紧张的外部背景；投资主体不明、投向分散同时存在 |
| **Falsification（证伪条件）** | 如果乡镇企业收益大量转移但企业负担未增加、负债率未升高，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人把每月工资大部分交给大家庭盖房修路，自己花销只能靠信用卡救急，债越欠越多，银行再也不敢借给他

### 🔗 文字版因果链

1. 乡镇企业资产形成依赖社区环境（土地级差地租、劳动力剩余价值、历史性负利率贷款）
2. 因此企业收益必须向社区转移，承担公共品开支和社区消费
3. 企业负担逐渐增大，效益被转移
4. 企业只能依靠贷款维持生产经营，负债率推高
5. 有限效益又交给银行，加剧银行头寸减少和贷款困难
