# 小城镇‘有城无市’，发展难以为继

> 属于因果簇：[[发达地区农村改革中的因果断言]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 小城镇制度‘门槛’过高（户籍、宅基地、非农用地等制度限制） |
| **DV（因变量）** | 小城镇‘有城无市’，发展难以为继 |
| **Chain（传导链）** | 制度门槛过高阻碍农民和乡镇企业进入城镇 → 农村非农就业人口滞留乡下，仍是自给自足的农业人口而非商品消费人口 → 城镇人口规模和消费规模偏小，经济聚集程度过低 → 没有规模消费，就不可能发展发达的第三产业 → 没有第三产业支撑，再现代化的城镇也是空城，最终投资大、占地多、包袱重，难以为继 |
| **Lag（时滞）** | 长期，政策实施十几年仍未见效，需要较长时间的人口聚集过程 |
| **Threshold（临界值）** | 城镇人口和消费规模需达到足以支撑第三产业的临界规模（文本未给出具体数字） |
| **前提与约束（Premises）** | 农民收入水平尚未达到城镇消费水平，传统观念亦有一定影响；主要障碍是制度门槛，而非单纯经济因素；适用于发达地区小城镇建设 |
| **Falsification（证伪条件）** | 如果降低制度门槛后农民仍不进城，或小城镇依然没有形成繁荣市场，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像水库的泄洪闸被焊死了，再大的水库也养不了鱼，水不流动，池塘永远干涸

### 🔗 文字版因果链

1. 制度门槛过高阻碍农民和乡镇企业进入城镇
2. 农村非农就业人口滞留乡下，仍是自给自足的农业人口而非商品消费人口
3. 城镇人口规模和消费规模偏小，经济聚集程度过低
4. 没有规模消费，就不可能发展发达的第三产业
5. 没有第三产业支撑，再现代化的城镇也是空城，最终投资大、占地多、包袱重，难以为继
