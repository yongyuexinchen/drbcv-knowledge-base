# 发达地区农村改革中的因果断言（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：发达地区农村改革中的因果断言.md

## 总体因果图

- 农村生产力要素从实物形态向价值形态转化（要素价值化） → 农村资源配置优化，市场经济体制建立，农村现代化实现
- 乡镇企业收益大量向地方政府和社区转移 → 乡镇企业负担增大、负债率推高，资金紧张
- 小城镇制度‘门槛’过高（户籍、宅基地、非农用地等制度限制） → 小城镇‘有城无市’，发展难以为继
- 以工补农形成的农业高投入（特别是粮食生产） → 农业无法自我积累成为独立产业，缺乏市场竞争力，成为财政包袱
