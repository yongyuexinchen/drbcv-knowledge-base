# 双重成本转嫁维持金融资本寄生性生存

> **领域**：国际政治经济学　|　**来源**：_cand_wtj_02.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 核心国实施双重成本转嫁（经济上利用货币金融制度权转嫁金融风险，政治上推行去国家化颠覆异见政权） |
| **DV（因变量）** | 金融资本寄生性生存的维持 |
| **Chain（传导链）** | 核心国凭借国际货币金融制度权，在经济危机时实施大规模量化宽松（QE） → QE放水导致全球能源、粮食等大宗商品价格上涨 → 依赖进口的非核心国遭受输入型通胀，经济恶化、民生受困 → 经济恶化引发社会不满，群体事件与政治动荡频发，催生颜色革命土壤 → 核心国同时利用软实力/巧实力进行政治干预，策动去国家化，颠覆妨碍其战略利益的国家政权 → 被颠覆或陷入动荡的国家丧失自主发展能力，资源、市场与金融命脉更易被核心国资本控制 → 经济转嫁与政治转嫁共同将危机成本外部化，核心国金融资本避免了自身危机，得以继续维持寄生性生存 |
| **Lag（时滞）** | 经济转嫁的输入型通胀通常在QE后6-18个月显现；社会动荡和政权更迭等政治效应常在1-3年内逐步显现 |
| **Threshold（临界值）** | 当全球大宗商品价格（尤其粮食和能源）同比涨幅超过20%并持续一年以上，且核心国政治干预频率上升时，非核心国发生输入型通胀、社会动荡乃至政权更迭的概率显著增大 |
| **前提与约束（Premises）** | 核心国拥有国际储备货币地位和全球金融制度主导权；非核心国高度依赖进口粮食和能源，且缺乏价格缓冲机制；国际资本跨境自由流动，金融全球化处于较高水平；存在与核心国战略利益相悖且政治结构脆弱的国家政权；该机制主要在全球经济失衡或系统性危机时期显著生效 |
| **Falsification（证伪条件）** | 如果出现以下任一证据，该断言可被证伪：核心国实施大规模QE后全球大宗商品价格未持续上涨；或非核心国物价飙升但未出现社会动荡及政权更迭；或核心国的政治干预未能推翻目标政权，且金融资本收益水平未提升甚至下降 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 这就像一个大房东发行白条付账，导致整个社区物资涨价，穷人买不起粮食，然后房东又找打手去威胁那些不听话的租户搬家，最终房东继续靠收租过上寄生生活，而社区里的穷人越来越穷。

### 🔗 文字版因果链

1. 核心国凭借国际货币金融制度权，在经济危机时实施大规模量化宽松（QE）
2. QE放水导致全球能源、粮食等大宗商品价格上涨
3. 依赖进口的非核心国遭受输入型通胀，经济恶化、民生受困
4. 经济恶化引发社会不满，群体事件与政治动荡频发，催生颜色革命土壤
5. 核心国同时利用软实力/巧实力进行政治干预，策动去国家化，颠覆妨碍其战略利益的国家政权
6. 被颠覆或陷入动荡的国家丧失自主发展能力，资源、市场与金融命脉更易被核心国资本控制
7. 经济转嫁与政治转嫁共同将危机成本外部化，核心国金融资本避免了自身危机，得以继续维持寄生性生存
