# 集建入市的交易成本与垫底制度中的因果断言

> **领域**：土地制度经济学/社会稳定性　|　**来源**：chapter_11.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府与农民之间在土地问题上的交易成本升高 |
| **DV（因变量）** | 政府改变土地制度 |
| **Chain（传导链）** | 农民缺乏正常利益表达渠道，只能通过上访、包围政府等政治化方式维权 → 交易成本上升到影响政治稳定 → 制度给政府带来的收益被高昂成本抵消，制度难以为继 → 政府必须修订或改变土地制度 |
| **Lag（时滞）** | 从交易成本累积到制度被迫调整，通常需要数年甚至更长 |
| **Threshold（临界值）** | 交易成本“高到政治化的程度”，即影响社会稳定时 |
| **前提与约束（Premises）** | 政府是土地制度的供给者，制度由政府主导修订；农民没有正常的利益表达渠道；制度成本超过其收益并威胁稳定 |
| **Falsification（证伪条件）** | 如果交易成本极高但土地制度长期不变，且政府未受到明显威胁，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像房东与租客纠纷不断，租客天天闹事，房东最终不得不修改合同。

### 🔗 文字版因果链

1. 农民缺乏正常利益表达渠道，只能通过上访、包围政府等政治化方式维权
2. 交易成本上升到影响政治稳定
3. 制度给政府带来的收益被高昂成本抵消，制度难以为继
4. 政府必须修订或改变土地制度

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地资源稀缺程度提高 |
| **DV（因变量）** | 土地交易困难程度提高，进而决定政府采取不同的土地制度供给 |
| **Chain（传导链）** | 土地越稀缺，交易双方在交易过程中的摩擦越大 → 农民对征地价格和补偿的要求越高，交易越困难 → 政府为降低交易成本，必须设计适应本地资源条件的制度 → 形成各地不同的土地制度安排 |
| **Lag（时滞）** | 资源约束长期存在，制度差异在数年内逐步形成 |
| **Threshold（临界值）** | 土地资源相对宽松（如河南）与严重短缺（如苏南）形成对比 |
| **前提与约束（Premises）** | 要素稀缺性决定价格；不同资源条件影响交易双方行为；政府需要根据交易成本调整制度供给 |
| **Falsification（证伪条件）** | 如果土地稀缺程度与制度形式无关，例如稀缺地区也采用与宽松地区相同的制度且实施成功，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 水越稀缺，交易越难，自然形成不同的分水规则。

### 🔗 文字版因果链

1. 土地越稀缺，交易双方在交易过程中的摩擦越大
2. 农民对征地价格和补偿的要求越高，交易越困难
3. 政府为降低交易成本，必须设计适应本地资源条件的制度
4. 形成各地不同的土地制度安排

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农村非农就业水平提高 |
| **DV（因变量）** | 土地交易成本降低 |
| **Chain（传导链）** | 农民从非农就业中获得更多收益，收入对土地依赖下降 → 农民对征地价格敏感度降低 → 政府征地或获取土地的摩擦减少 → 土地交易成本降低 |
| **Lag（时滞）** | 随着非农就业比重变化，相对短期内显现 |
| **Threshold（临界值）** | 非农就业比重较大时，效果显著 |
| **前提与约束（Premises）** | 非农就业能提供足够收入替代土地收益；农民可稳定获得非农就业机会 |
| **Falsification（证伪条件）** | 如果非农就业水平很高但农民仍因土地问题强烈抗争，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像打零工收入稳定后，对自家菜园被征用的抵触情绪就减小。

### 🔗 文字版因果链

1. 农民从非农就业中获得更多收益，收入对土地依赖下降
2. 农民对征地价格敏感度降低
3. 政府征地或获取土地的摩擦减少
4. 土地交易成本降低

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 乡镇企业私有化改制 |
| **DV（因变量）** | 土地问题上的争议增加 |
| **Chain（传导链）** | 政府经济下的乡镇企业以就业最大化为目标，解决大量农村就业 → 乡镇企业高负债（负债率高达80%以上，其中政府开支占30%多）无法继续经营 → 90年代末企业普遍私有化改制 → 私有化企业以利润最大化为目标，不再解决农村就业 → 原在乡镇企业就业的农民回家，重新依赖土地 → 土地争议增加 |
| **Lag（时滞）** | 90年代末私有化改制后数年内 |
| **Threshold（临界值）** | 乡镇企业负债率高达80%以上，其中借债用于政府开支约占30% |
| **前提与约束（Premises）** | 乡镇企业曾是政府经济，承担政府公益开支和就业功能；企业私有化后目标转为利润最大化；农村集体没有其他收入来源，只能靠地租维持 |
| **Falsification（证伪条件）** | 如果私有化后企业仍大量雇佣农村劳动力，且土地争议未增加，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像国企改制后裁员，员工回老家种地，地就变得金贵了。

### 🔗 文字版因果链

1. 政府经济下的乡镇企业以就业最大化为目标，解决大量农村就业
2. 乡镇企业高负债（负债率高达80%以上，其中政府开支占30%多）无法继续经营
3. 90年代末企业普遍私有化改制
4. 私有化企业以利润最大化为目标，不再解决农村就业
5. 原在乡镇企业就业的农民回家，重新依赖土地
6. 土地争议增加

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农民离开社区并失去土地财产身份 |
| **DV（因变量）** | 流动人口犯罪增加，社会控制成本升高 |
| **Chain（传导链）** | 农民在社区稳定生活，有土地财产约束，基本不犯罪 → 农民一旦离开社区，失去可获得财产的身份 → 城市无法为流动人口提供同等保障和约束 → 流动人口犯罪比例上升（城市犯罪70%以上是流动人口犯罪） → 社会控制成本升高 |
| **Lag（时滞）** | 离开社区后短期至数年 |
| **Threshold（临界值）** | 无地农民增加时期，社会不安定显著加剧 |
| **前提与约束（Premises）** | 集体土地以社区成员权为基本权利依据；城市就业和社保体系无法覆盖流动人口；土地是农民安身立命的最后保障 |
| **Falsification（证伪条件）** | 如果大量离开土地的农民在城市犯罪率很低且社会稳定，则断言不成立 |

### 🔗 文字版因果链

1. 农民在社区稳定生活，有土地财产约束，基本不犯罪

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体建设用地入市增值收益全部用于当年分配（不建立社保基金） |
| **DV（因变量）** | 国家长期稳定受到威胁 |
| **Chain（传导链）** | 集体土地入市产生增值收益 → 若收益全部用于当年分配，农民当年消费掉 → 农民未来失去可持续的社会保障来源 → 农民只能继续依赖土地或陷入无保障状态 → 社会不安定因素积累，威胁国家长期稳定 |
| **Lag（时滞）** | 长期，可能在多年后显现 |
| **Threshold（临界值）** | 收益未定向安排用于农村社会保障基金 |
| **前提与约束（Premises）** | 政府无法为8亿农民建立现代意义的社会保障；集体土地的保障功能大于生产功能；集体土地收益归集体，由政府做制度安排 |
| **Falsification（证伪条件）** | 如果入市收益当年分配但未来农民有其它途径获得充分保障且社会稳定，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像中彩票后全花光，没留养老金，晚年风险高。

### 🔗 文字版因果链

1. 集体土地入市产生增值收益
2. 若收益全部用于当年分配，农民当年消费掉
3. 农民未来失去可持续的社会保障来源
4. 农民只能继续依赖土地或陷入无保障状态
5. 社会不安定因素积累，威胁国家长期稳定
