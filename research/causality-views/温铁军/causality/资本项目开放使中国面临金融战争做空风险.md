# 资本项目开放使中国面临金融战争做空风险

> **领域**：国际金融/宏观经济学　|　**来源**：_cand_wtj_11.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国开放资本项目（资本账户自由化） |
| **DV（因变量）** | 中国遭遇国际资本做空，引发货币危机与国民财富被劫掠 |
| **Chain（传导链）** | 中国通过战略与经济对话等推进汇率自由化与资本项目开放，放宽外汇管制和资本跨境流动限制 → 国际金融资本（特别是核心国资本）获得自由进出中国市场的条件，可借助衍生工具建立空头头寸 → 国际资本利用美元加息周期或地缘军事冲突等外部冲击，大规模抛售人民币资产、做空汇率 → 本币汇率暴跌、资本外逃，外汇储备耗尽，实体经济利润被核心国资本低价占有，国民财富被劫掠 |
| **Lag（时滞）** | 从资本项目开放到做空冲击显现，通常在开放后的数月至数年之间，具体取决于外部冲击（如美联储加息）的触发时机 |
| **Threshold（临界值）** | 当资本项目开放达到使国际资本可短期内大规模跨境流动的程度（如资本账户全面可兑换），且外部出现诱因（如美国加息、军事冲突）时，做空机制激活；例如美国启动加息可导致目标国货币一夜暴跌（如比索暴跌41%） |
| **前提与约束（Premises）** | 存在有意图占有边缘国实体经济利润的核心国金融资本；目标国货币有潜力挑战美元霸权，或目标国被认为有重要经济价值；资本项目开放放松管制，使国际资本可自由进出；不适用于资本管制严格、金融防火墙完整的国家；仅在金融战争被发动的情况下成立，不排除和平时期的正常资本流动 |
| **Falsification（证伪条件）** | 若中国在资本项目开放后，国际资本做空行为未造成汇率暴跌或财富损失，或者有证据表明开放资本项目反而促进了经济增长且未引发金融危机，则该因果断言可被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 这如同在船上拆掉护甲和隔水舱，然后把船开进海盗出没的水域——海盗（国际金融资本）不需要打仗就能登船抢走货物；资本项目开放就是撤去金融防火墙，使国家财富暴露在金融攻击之下

### 🔗 文字版因果链

1. 中国通过战略与经济对话等推进汇率自由化与资本项目开放，放宽外汇管制和资本跨境流动限制
2. 国际金融资本（特别是核心国资本）获得自由进出中国市场的条件，可借助衍生工具建立空头头寸
3. 国际资本利用美元加息周期或地缘军事冲突等外部冲击，大规模抛售人民币资产、做空汇率
4. 本币汇率暴跌、资本外逃，外汇储备耗尽，实体经济利润被核心国资本低价占有，国民财富被劫掠
