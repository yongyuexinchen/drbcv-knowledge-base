## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 采用先读绪论/结语、按三组对照七国案例、精读指定附录专题、并与《八次危机》配套的阅读方法 |
| **DV（因变量）** | 对成本转嫁论、微笑曲线、三阶段划分及两大理论创新的更快、更深内化 |
| **Chain（传导链）** | 先读绪论，获得全书钥匙：成本转嫁论、微笑曲线、三阶段划分 → 再读结语，把握两大理论创新，形成整体框架 → 回头精读第一章中国部分，作为最贴近当下、最厚的案例 → 将七国案例按三组对照读，在组内对比中快速凸显成本转嫁机制的不同运作方式 → 精读附录四个指定专题（六方货币同盟、TPP、2015股灾、人民币国际化），与正文第一章互证 → 与《八次危机》配套读，将中国部分视为分析框架在金融资本阶段的延伸，从而深化理解 |
| **Lag（时滞）** | 数天至数周，取决于阅读速度与每日投入时间（若每天阅读2小时，约1-2周显效） |
| **Threshold（临界值）** | 必须完成绪论、结语、第一章中国部分、至少两组案例对照，并精读至少两个附录专题才能产生显著内化效应 |
| **前提与约束（Premises）** | 读者具备基本宏观经济学或政治经济学常识；核心文本为书中正文与附录专题，且《八次危机》存在可作为配套；读者有连续阅读时间和专注条件；案例之间具有可比性，能按三组划分进行对照 |
| **Falsification（证伪条件）** | 如果读者严格按上述顺序阅读并完成对照，但在合上书后无法概括成本转嫁论，或不能用该机制分析一个新出现的类似案例，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同组装宜家家具：先看总图纸（绪论），再确认成品图（结语），然后按零件类别分组拼装（三组对照），关键配件单独核对（专题精读），最后借用旧家具经验（八次危机）——阅读方法决定了组装的速度和牢固度，而这正是因果链条的体现。
