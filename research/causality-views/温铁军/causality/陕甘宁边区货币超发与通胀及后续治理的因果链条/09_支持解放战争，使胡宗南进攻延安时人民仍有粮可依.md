# 支持解放战争，使胡宗南进攻延安时人民仍有粮可依

> 属于因果簇：[[陕甘宁边区货币超发与通胀及后续治理的因果链条]]（第9块/9块）

## 因果断言 9

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 边区实现生产发展（“耕三余一”）、储备充足 |
| **DV（因变量）** | 支持解放战争，使胡宗南进攻延安时人民仍有粮可依 |
| **Chain（传导链）** | 边区提倡“耕三余一”，即耕三年余一年粮 → 农民积极响应，粮食储备充足 → 1947年胡宗南进攻延安，中共撤出后在陕北打游击 → 即使在最艰苦的横山山区，老百姓家存粮满缸满仓 → 依靠百姓存粮支撑解放战争，胡宗南部无可奈何 |
| **Lag（时滞）** | 长期（三年以上） |
| **Threshold（临界值）** | 实现“耕三余一”，即三年耕作节余一年粮食 |
| **前提与约束（Premises）** | 边区相对稳定的生产环境；农民有生产积极性；前期成功治理通胀，经济稳定 |
| **Falsification（证伪条件）** | 如果边区生产发展但百姓无存粮，或胡宗南进攻时无法支撑战争，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 蚂蚁夏天储备粮食，冬天才能安然度过。
