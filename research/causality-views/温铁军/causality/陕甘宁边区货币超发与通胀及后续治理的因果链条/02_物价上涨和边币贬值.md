# 物价上涨和边币贬值

> 属于因果簇：[[陕甘宁边区货币超发与通胀及后续治理的因果链条]]（第2块/9块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币发行量过快增长 |
| **DV（因变量）** | 物价上涨和边币贬值 |
| **Chain（传导链）** | 银行增大边币发行量，1941年3月至6月月平均递增率31.9% → 市场上货币供给量超过实际物资基础 → 延安物价递增率由3月的12.9%增至6月的26.7% → 边币与法币比价递增率由6.6%增至14.6% → 边币对内购买力下降，对外汇率贬值 |
| **Lag（时滞）** | 约1-3个月，货币增发后物价和汇率在数月内明显变化 |
| **Threshold（临界值）** | 边币月平均递增率超过18%时，物价递增大幅上涨；7-8月紧缩至月递增率7%-8.5%后通胀压力有所缓解 |
| **前提与约束（Premises）** | 货币增发缺乏相应的物资增长支撑；边区经济封闭，物资供给有限；法币作为参照货币存在比价关系 |
| **Falsification（证伪条件）** | 如果货币发行量大幅增长但物价稳定或下跌，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 往一杯水里不断加糖，水越来越甜，糖就是货币，甜度就是物价。

### 🔗 文字版因果链

1. 银行增大边币发行量，1941年3月至6月月平均递增率31.9%
2. 市场上货币供给量超过实际物资基础
3. 延安物价递增率由3月的12.9%增至6月的26.7%
4. 边币与法币比价递增率由6.6%增至14.6%
5. 边币对内购买力下降，对外汇率贬值
