# 银行增发货币（边币）以弥补财政空缺

> 属于因果簇：[[陕甘宁边区货币超发与通胀及后续治理的因果链条]]（第1块/9块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 财政赤字严重，财政入不敷出 |
| **DV（因变量）** | 银行增发货币（边币）以弥补财政空缺 |
| **Chain（传导链）** | 边区财政每月入不敷出，需要17万元而尚差4万多元 → 政府无法依靠常规收入弥补缺口 → 银行放款成为政府解决财政空缺的重要方式 → 财政机关款占银行放款比例大幅上升，1940年达69.2% → 边区中央局直接要求银行增发钞票交财政厅使用 |
| **Lag（时滞）** | 短期，财政缺口出现后即需增发 |
| **Threshold（临界值）** | 财政机关款占银行放款比例从1938年的21.6%升至1940年的69.2%；直接财政放款占93.1% |
| **前提与约束（Premises）** | 战争环境下税收等正常财政收入不足；政府具有货币发行权且银行受政府控制；缺乏其他融资渠道 |
| **Falsification（证伪条件）** | 如果财政赤字扩大但银行货币发行量没有相应增加，则该因果断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个家庭入不敷出时，只能靠刷信用卡度日，欠款越滚越大。

### 🔗 文字版因果链

1. 边区财政每月入不敷出，需要17万元而尚差4万多元
2. 政府无法依靠常规收入弥补缺口
3. 银行放款成为政府解决财政空缺的重要方式
4. 财政机关款占银行放款比例大幅上升，1940年达69.2%
5. 边区中央局直接要求银行增发钞票交财政厅使用
