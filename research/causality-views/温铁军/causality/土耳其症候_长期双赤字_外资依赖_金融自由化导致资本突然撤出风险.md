# 土耳其症候：长期双赤字+外资依赖+金融自由化导致资本突然撤出风险

> **领域**：宏观经济学/国际金融　|　**来源**：_cand_wtj_18.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期双赤字（贸易与经常账户赤字）、外资依赖与金融自由化并存 |
| **DV（因变量）** | 资本突然撤出引发的本币崩盘与资产泡沫破裂 |
| **Chain（传导链）** | 贸易与经常账户长期赤字导致外债持续攀升 → 外债攀升使经济依赖外资流入来为经常账户赤字融资 → 金融自由化与资本项目开放允许外资自由进出 → 美联储进入紧缩周期，全球流动性收紧 → 外资因追逐更高收益率或避险而集体撤出 → 资本骤停引发本币崩盘，同时刺破以基建/房地产为主的资产泡沫 |
| **Lag（时滞）** | 长期赤字积累至危机爆发通常需5-10年；但美联储收紧等外部冲击触发后，资本撤出可能在数月至一年内发生 |
| **Threshold（临界值）** | 外债/GDP>50%、经常账户赤字/GDP>5%、外资依赖度高（如外资持有国债或股市市值占比>30%）且外资集中于流动性差的资产时，资本突然撤出风险显著上升 |
| **前提与约束（Premises）** | 长期贸易逆差且非储备货币国；资本项目开放、无外汇管制；外资集中于基建/房地产等流动性差资产 |
| **Falsification（证伪条件）** | 若满足前提条件的高外债、高赤字国家在美联储收紧时未出现资本外流或本币崩盘，或者资本管制国家也发生类似资本突然撤出危机，则该断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人长期入不敷出（双赤字），靠借新还旧（外资依赖），且家里没有围墙（金融自由化），一旦债主们同时上门逼债（美联储收紧），他只能破产

### 🔗 文字版因果链

1. 贸易与经常账户长期赤字导致外债持续攀升
2. 外债攀升使经济依赖外资流入来为经常账户赤字融资
3. 金融自由化与资本项目开放允许外资自由进出
4. 美联储进入紧缩周期，全球流动性收紧
5. 外资因追逐更高收益率或避险而集体撤出
6. 资本骤停引发本币崩盘，同时刺破以基建/房地产为主的资产泡沫
