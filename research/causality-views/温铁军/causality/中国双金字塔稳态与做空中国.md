# 中国双金字塔稳态与做空中国

> **领域**：宏观经济学/国际金融　|　**来源**：_cand_wtj_19.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地革命（农村土地均分制度） |
| **DV（因变量）** | 外部做空中国资产（A股、人民币）的高成本低胜率 |
| **Chain（传导链）** | 土地革命使约60%国民成为小资产所有者，并持有实体资产 → 分散化的实体资产产权结构构成社会与经济双金字塔的坚实底座 → 双金字塔稳态使得内部结构与外部冲击高度隔离，外部压力难以从内部瓦解 → 因此外部做空行为难以利用内部断裂带，仅能造成表层波动 → 最终导致做空中国资产成本高昂、胜率低下 |
| **Lag（时滞）** | 长期制度形成（数十年）；外部做空事件中稳态的缓冲效应在数月内显现 |
| **Threshold（临界值）** | 小资产所有者占人口比例达到约60%，且其资产以实体资产为底座；低于该比例或资产虚拟化则稳态松动 |
| **前提与约束（Premises）** | 不推进农村土地货币化/金融化改革，否则稳态基础瓦解；保持资本项目管制与货币主权；维持国家对金融资本的约束（反腐、金融安全上升到国家安全） |
| **Falsification（证伪条件）** | 若出现以下任一证据可推翻断言：推进农村土地货币化/金融化改革导致小资产所有者比例跌破60%；资本项目开放或货币主权丧失引发大规模资本外逃；国家对金融资本约束失效导致金融风险失控；外部空头成功做空A股或人民币（如汇率/股指出现趋势性大幅下跌） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个由大量小石块紧密砌成的拱桥，每块石头都是独立承重体，外部撞击只能崩落几块而无法令整桥坍塌；若把石块换成可转让的金融票据，结构便会一推即倒。

### 🔗 文字版因果链

1. 土地革命使约60%国民成为小资产所有者，并持有实体资产
2. 分散化的实体资产产权结构构成社会与经济双金字塔的坚实底座
3. 双金字塔稳态使得内部结构与外部冲击高度隔离，外部压力难以从内部瓦解
4. 因此外部做空行为难以利用内部断裂带，仅能造成表层波动
5. 最终导致做空中国资产成本高昂、胜率低下
