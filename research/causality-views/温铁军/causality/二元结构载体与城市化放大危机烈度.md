# 二元结构载体与城市化放大危机烈度

> **领域**：发展经济学/政治经济学　|　**来源**：_cand_wtj_12.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 二元结构的缓冲能力（非正规部门/乡土社会对危机的吸纳程度）与城市化水平（反向指标） |
| **DV（因变量）** | 输入型危机的后果烈度（软着陆或政治颠覆） |
| **Chain（传导链）** | 边缘国家遭受输入型危机（资本外流、出口萎缩、债务冲击等） → 城市正规经济首先承压，就业和福利恶化 → 存在二元结构时，失业劳动力可回流乡土社会或转入非正规部门，生存压力被分散吸收 → 危机冲击被缓冲和稀释，经济减速但社会政治保持稳定，实现“软着陆” → 高度城市化则缺少该缓冲层，冲击直接传导至城市贫民窟和正规就业人群，引发社会动荡甚至政治颠覆 |
| **Lag（时滞）** | 数月到数年（输入型危机传导至社会政治后果通常需1-3年） |
| **Threshold（临界值）** | 城市化率超过约80%且伴随贫民窟化（如巴西、委内瑞拉）时，危机后果由可控转向政治颠覆；二元结构有效时需保持可承接失业的乡土空间或非正规就业规模（如中国持续向农村投入约2万亿美元） |
| **前提与约束（Premises）** | 国家处于全球资本主义体系边缘，危机性质为外部输入型冲击；二元结构中乡土社会/非正规部门具有实际吸纳失业人口的社会与经济功能；政府维持城乡二元分割或非正规经济存在，而非彻底消除缓冲层；城市化国家中贫民窟不能替代乡土社会提供同等强度的风险吸收能力 |
| **Falsification（证伪条件）** | 若发现某个城市化率超过80%的边缘国家在输入型危机中通过城市正规经济和社会保障实现软着陆，没有出现政治颠覆；或某个二元结构发达的国家在相同冲击下反而发生严重社会政治危机，则该断言被证伪或削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同海绵与水泥地面——二元结构像海绵，泼水时吸走冲击力；高度城市化像水泥地，水直接四溅飞散，破坏力更强。

### 🔗 文字版因果链

1. 边缘国家遭受输入型危机（资本外流、出口萎缩、债务冲击等）
2. 城市正规经济首先承压，就业和福利恶化
3. 存在二元结构时，失业劳动力可回流乡土社会或转入非正规部门，生存压力被分散吸收
4. 危机冲击被缓冲和稀释，经济减速但社会政治保持稳定，实现“软着陆”
5. 高度城市化则缺少该缓冲层，冲击直接传导至城市贫民窟和正规就业人群，引发社会动荡甚至政治颠覆
