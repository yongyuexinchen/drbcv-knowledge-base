# 重复欧美现代化经验的不可复制性（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：重复欧美现代化经验的不可复制性.md

## 总体因果图

- 后发国家试图复制欧美殖民化—现代化道路 → 现代化道路失败（不可重复）
- 中国在改革进程中存在尚未完全资本化的资源 → 中国成为全球经济增长最快、资源向资本转移收益最高的国家
- 美国维持金融霸权地位（军事强国、世界最安全投资国度） → 美元保持强势，大量外资流入美国，GDP的80%以上来源于金融
- 欧元威胁美元成为世界第一货币 → 美国通过发动战争（如巴尔干战争）打压欧元
- 日本试图重复美国用军事霸权维护金融霸权的经验 → 此路不通（日本无法重复）
- 区域一体化（如欧盟东扩、亚洲区域化整合） → 后发国家实现经济增长的可行出路
