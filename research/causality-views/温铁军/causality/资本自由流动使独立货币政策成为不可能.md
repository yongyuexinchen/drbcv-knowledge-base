# 资本自由流动使独立货币政策成为不可能

> **领域**：国际金融/宏观经济学　|　**来源**：_cand_wtj_05.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本可自由跨境流动 |
| **DV（因变量）** | 无法维持独立的货币政策（丧失货币政策自主权） |
| **Chain（传导链）** | 核心国（如美国）货币政策变动形成全球金融周期 → 资本在利润驱动下跨国自由流动，将核心国利率与流动性冲击传导至外围国 → 外围国国内资产价格、汇率和信贷条件随之波动 → 外围国若试图实行与核心国方向相反的独立货币政策，会遭遇更大资本流动压力 → 最终任何汇率制度下独立货币政策均告失效，只有资本管制才能切断传导 |
| **Lag（时滞）** | 数月至一个季度左右（如2013年5-9月资本流出冲击） |
| **Threshold（临界值）** | 资本流动达到“完全自由跨境流动”的程度，即不存在任何资本项目管制 |
| **前提与约束（Premises）** | 存在一个主导全球金融周期的核心国（如美国）；外围国经济开放且深度融入国际金融市场；资本流动对利率、风险偏好等信号敏感，能够迅速跨境套利；该断言不包括实行资本管制或货币非自由兑换的经济体 |
| **Falsification（证伪条件）** | 如果发现一个资本账户完全开放、汇率制度任意（固定或浮动）但能长期保持独立于核心国货币政策的经济体，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 这就像多个水池用连通管相连：只要管子畅通，各水池水位必然趋于一致；想保持自己水位不同，唯一的办法就是在管子上装闸门（资本管制）。

### 🔗 文字版因果链

1. 核心国（如美国）货币政策变动形成全球金融周期
2. 资本在利润驱动下跨国自由流动，将核心国利率与流动性冲击传导至外围国
3. 外围国国内资产价格、汇率和信贷条件随之波动
4. 外围国若试图实行与核心国方向相反的独立货币政策，会遭遇更大资本流动压力
5. 最终任何汇率制度下独立货币政策均告失效，只有资本管制才能切断传导
