# 去依附：中国化解第一次经济危机的因果机制

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地改革 |
| **DV（因变量）** | 国家资本与分散个人之间的交易成本降低 |
| **Chain（传导链）** | 土地改革提高了社会再组织化程度 → 组织化动员使国家资本占有利益的实质隐身于国家任务的宏大叙事中 → 国家资本与分散个人之间的交易成本被有效降低 |
| **Lag（时滞）** | 土改完成后1-3年内（1949-1952年） |
| **Threshold（临界值）** | 必须实现对农民的全员动员和组织覆盖，而非仅分配土地 |
| **前提与约束（Premises）** | 国家资本利益需要隐藏于集体目标中；农村社会以分散小农经济为主；存在土地改革与抗美援朝等重大国家动员任务 |
| **Falsification（证伪条件）** | 如果土地改革后国家资本与农民的交易成本没有显著下降或动员失败，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 小区成立业委会后集体与物业谈判，比每家单独找物业省力得多

### 🔗 文字版因果链

1. 土地改革提高了社会再组织化程度
2. 组织化动员使国家资本占有利益的实质隐身于国家任务的宏大叙事中
3. 国家资本与分散个人之间的交易成本被有效降低

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 恢复性重建（修复战争部分损毁的基础设施） |
| **DV（因变量）** | 国家账面经济收益快速增长 |
| **Chain（传导链）** | 民国遗留基础设施仅部分损毁 → 国家财政只需支付部分修复成本即可恢复全部设施功能 → 低成本获得高收益，导致账面经济收益增长迅速 |
| **Lag（时滞）** | 1949-1952年期间 |
| **Threshold（临界值）** | 基础设施损毁率为部分而非全部，修复成本低于重置成本 |
| **前提与约束（Premises）** | 战前已有较完整的基础设施体系；战争只造成部分破坏而不及根本；国家有能力组织修复工作 |
| **Falsification（证伪条件）** | 如果修复成本等于或高于新建成本，或基础设施已完全损毁，则账面收益不会快速增长 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 旧房翻新比推倒重建省钱，同样的钱能获得更大面积

### 🔗 文字版因果链

1. 民国遗留基础设施仅部分损毁
2. 国家财政只需支付部分修复成本即可恢复全部设施功能
3. 低成本获得高收益，导致账面经济收益增长迅速

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 重化产业以中间产品为主的生产结构 |
| **DV（因变量）** | 市场交易成本较低 |
| **Chain（传导链）** | 国家资本集中于重工业部门 → 生产的是中间产品而非终端消费品 → 无需直接面对高度分散的农村终端市场 → 市场交易成本因此较低 |
| **Lag（时滞）** | 即时（产业结构决定） |
| **Threshold（临界值）** | 重工业比重足够高，且产品主要面向工业链条而非终端消费 |
| **前提与约束（Premises）** | 国家资本主导重工业；中间产品有稳定的计划调配渠道；农村终端市场高度分散且信息化水平低 |
| **Falsification（证伪条件）** | 如果重工业企业仍需大量直接销售给终端散户，或中间产品交易成本同样高昂，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 批发商只对几家大客户发货，比开零售店应对成百上千顾客更省成本

### 🔗 文字版因果链

1. 国家资本集中于重工业部门
2. 生产的是中间产品而非终端消费品
3. 无需直接面对高度分散的农村终端市场
4. 市场交易成本因此较低

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期高通胀环境 |
| **DV（因变量）** | 私人资本从实体经济转向投机（脱实向虚） |
| **Chain（传导链）** | 长期高通胀使实体经济利润预期不稳定 → 私人资本逐利本能驱使其寻求保值增值 → 资金从生产领域析出，进入投机领域 → 民国时期平津行庄96.6%资金用于投机，生产投入仅1.7%-3.4% |
| **Lag（时滞）** | 通胀持续多年后逐渐明显（如民国13年通胀期） |
| **Threshold（临界值）** | 通胀率持续超过工商业正常利润率的某个临界值 |
| **前提与约束（Premises）** | 自由市场经济条件下私人资本顺周期行为；政府缺乏有效逆周期调节能力；存在可投机的资产市场（如黄金、外汇、实物） |
| **Falsification（证伪条件）** | 如果长期高通胀下私人资本仍持续投入实体经济而非投机，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 下雨天路上都是积水，没人愿意在雨中干活，都往屋檐下躲

### 🔗 文字版因果链

1. 长期高通胀使实体经济利润预期不稳定
2. 私人资本逐利本能驱使其寻求保值增值
3. 资金从生产领域析出，进入投机领域
4. 民国时期平津行庄96.6%资金用于投机，生产投入仅1.7%-3.4%

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以农村实体经济为基础的物资本位货币制度 |
| **DV（因变量）** | 成功遏制恶性通胀并建立主权货币信用 |
| **Chain（传导链）** | 国家确立以主食农产品为主要币值计量标准 → 锁定农产品与主权货币的对应关系，稳定浮动预期 → 以农村实体经济的稳定增长支撑货币信用 → 推行“折实”制度保障基本民生品价值 → 人民币成为城乡普遍接受的国家信用工具，恶性通胀被根治 |
| **Lag（时滞）** | 1949-1952年约三年内 |
| **Threshold（临界值）** | 必须锁定基本农产品与货币的对应关系，且农村生产保持稳定增长 |
| **前提与约束（Premises）** | 国家拥有独立主权，不依赖外援；外部封锁条件下农村经济自成体系；土地改革后农村高度组织化；货币发行以国内实体经济（尤其农产品）为锚 |
| **Falsification（证伪条件）** | 如果农村实体经济增长但货币仍大幅贬值，或锁定农产品后并未稳定物价，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 用“大米本位”发货币，只要米仓充实，纸币就不会变成废纸

### 🔗 文字版因果链

1. 国家确立以主食农产品为主要币值计量标准
2. 锁定农产品与主权货币的对应关系，稳定浮动预期
3. 以农村实体经济的稳定增长支撑货币信用
4. 推行“折实”制度保障基本民生品价值
5. 人民币成为城乡普遍接受的国家信用工具，恶性通胀被根治
