# 去依附文本中的宏观因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 在传统农业国家实行“耕者有其田”式的土地改革（均田免赋/城乡二元结构基本体制） |
| **DV（因变量）** | 国家长期政治稳定 |
| **Chain（传导链）** | 土地改革实现土地这一农民最重要财产的平均化再分配，形成“耕者有其田” → 农民获得基本生存保障，形成对政权的内部国民动员 → 乡土社会成为“海绵社会”，吸纳城市资本转嫁的危机与负外部性 → 东亚儒家文化圈国家和地区（中日韩朝越及中国台湾地区）均因类似体制维持长期稳定 |
| **Lag（时滞）** | 文本未明确量化，但中国历史上大凡搞了“均田免赋”的朝代都能保持较为长期的稳定；1949年土改后短期内即见效 |
| **Threshold（临界值）** | 必须实现“耕者有其田”的平均化再分配；对亚洲“儒家文化圈”国家具有普遍意义，无特定数值阈值 |
| **前提与约束（Premises）** | 适用于传统农业国家或亚洲“儒家文化圈”国家；需要以城乡二元结构基本体制为前提；排除已完成工业化、农业人口占比极小的国家 |
| **Falsification（证伪条件）** | 若某实行了类似土地改革的国家未能维持长期稳定，或者未实行土改的国家也能长期稳定，则该断言被削弱或推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给每个家庭成员都分了宅基地和自留地，大家都有了安身立命的根基，自然不愿破坏秩序，整个社会就像打了地基的房子一样稳固。

### 🔗 文字版因果链

1. 土地改革实现土地这一农民最重要财产的平均化再分配，形成“耕者有其田”
2. 农民获得基本生存保障，形成对政权的内部国民动员
3. 乡土社会成为“海绵社会”，吸纳城市资本转嫁的危机与负外部性
4. 东亚儒家文化圈国家和地区（中日韩朝越及中国台湾地区）均因类似体制维持长期稳定

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展中国家通过非暴力谈判获得政治主权 |
| **DV（因变量）** | 陷入“发展陷阱”且难以自拔（经济上和政治上继续依附原宗主国） |
| **Chain（传导链）** | 非暴力谈判形成主权是一个与宗主国之间的“交易过程” → 交易双方存在“信息不对称”和“实力不对称”，导致收益格局结构性失衡 → 被殖民国家不得不向宗主国部分让渡经济资源和/或财政金融权益，以换取独立的政治认可 → 新独立国家在经济上和政治上继续依附于原宗主国，即存在“主权负外部性” → 继续延续殖民地时期的单一经济结构，形成路径依赖 → 在“主权负外部性”下，随时可能堕入“发展陷阱”且难以自拔 |
| **Lag（时滞）** | 宣布独立后不久，往往同时与原宗主国签订经济领域合同；依附关系持续存在 |
| **Threshold（临界值）** | 只要是通过非暴力谈判形成主权，就内生具有普遍性的“主权负外部性”；无特定量化条件 |
| **前提与约束（Premises）** | 仅适用于通过非暴力谈判（而非暴力革命）获得独立的发展中国家；原宗主国仍占有殖民化利益并能持续转嫁代价；排除通过土改和暴力革命彻底打断依附关系的国家（如中国） |
| **Falsification（证伪条件）** | 若某个通过谈判独立的发展中国家没有出现“主权负外部性”，或成功摆脱了对原宗主国的依附，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像买房时向高利贷借款，虽然拿到了房产证，却背上了永远还不清的债，房子名义上归你，但主动权一直在债主手里。

### 🔗 文字版因果链

1. 非暴力谈判形成主权是一个与宗主国之间的“交易过程”
2. 交易双方存在“信息不对称”和“实力不对称”，导致收益格局结构性失衡
3. 被殖民国家不得不向宗主国部分让渡经济资源和/或财政金融权益，以换取独立的政治认可
4. 新独立国家在经济上和政治上继续依附于原宗主国，即存在“主权负外部性”
5. 继续延续殖民地时期的单一经济结构，形成路径依赖
6. 在“主权负外部性”下，随时可能堕入“发展陷阱”且难以自拔

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高通胀压力 |
| **DV（因变量）** | 经济萧条（高通胀之后必然继之以工商业衰退） |
| **Chain（传导链）** | 高通胀压力下大部分实体产业无利可图 → 私人资本在“经济理性”下大量从实体经济析出 → 资本转向投机领域，实体经济空心化 → 扭转高通胀后紧跟着发生通缩，导致工商业衰退 → 若没有政府干预或政府无实力做“逆周期调节”，则会出现“断崖式崩塌” |
| **Lag（时滞）** | 通胀危机之后接着只能是萧条，时滞较短且具有周期性规律 |
| **Threshold（临界值）** | 高通胀须达到使大部分实体产业无利可图的程度；文本未给出具体数值阈值 |
| **前提与约束（Premises）** | 适用于实行市场经济的资本主义经济体；私人资本占主体且追求“经济理性”；若政府有能力做“逆周期调节”，可避免“断崖式崩塌”，但无法消除资本原始积累的内在矛盾 |
| **Falsification（证伪条件）** | 若某经济体在高通胀被治理后并未出现经济萧条，或者私人资本未从实体经济转向投机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像锅里的水烧得滚烫，油花（资本）都浮到表面，锅底的食物（实业）却糊了；等火一停，表面的油花也迅速冷却凝固，整个锅都变得萧条。

### 🔗 文字版因果链

1. 高通胀压力下大部分实体产业无利可图
2. 私人资本在“经济理性”下大量从实体经济析出
3. 资本转向投机领域，实体经济空心化
4. 扭转高通胀后紧跟着发生通缩，导致工商业衰退
5. 若没有政府干预或政府无实力做“逆周期调节”，则会出现“断崖式崩塌”
