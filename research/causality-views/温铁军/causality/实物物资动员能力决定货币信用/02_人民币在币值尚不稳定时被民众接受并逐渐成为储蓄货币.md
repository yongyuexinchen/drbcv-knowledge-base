# 人民币在币值尚不稳定时被民众接受并逐渐成为储蓄货币

> 属于因果簇：[[实物物资动员能力决定货币信用]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 折实制度（折实公债、折实工资、折实储蓄）以粮棉煤等实物为计价单位 |
| **DV（因变量）** | 人民币在币值尚不稳定时被民众接受并逐渐成为储蓄货币 |
| **Chain（传导链）** | 人民币币值不稳定，民众不愿储藏人民币 → 政府推出折实公债、折实工资、折实储蓄，将货币价值与实物价格挂钩 → 民众在存取、储蓄和领取工资时获得实物价值保障，购买力不受物价波动侵蚀 → 人民币信用获得实物信用支撑，民众逐渐接纳人民币作为储蓄货币 |
| **Lag（时滞）** | 折实制度从1949年底开始实施，至1950年初物价风潮平息后人民币才获得足够信用 |
| **Threshold（临界值）** | 折实单位（如“分”）由六大城市大米、面粉、白布、煤炭的平均批发价计算，需定期公布并随物价调整 |
| **前提与约束（Premises）** | 政府掌握充足的实物物资作为折实后盾；物价虽有波动但未失控，政府有能力维持折实兑现；民众对实物价值的信任高于对纸币的信任 |
| **Falsification（证伪条件）** | 若折实制度实施后民众仍大量抛售人民币或拒绝折实储蓄，人民币信用未提升，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 类似于今天将存款与黄金或通胀指数挂钩，用实物价值为人民提供“定心丸”

### 🔗 文字版因果链

1. 人民币币值不稳定，民众不愿储藏人民币
2. 政府推出折实公债、折实工资、折实储蓄，将货币价值与实物价格挂钩
3. 民众在存取、储蓄和领取工资时获得实物价值保障，购买力不受物价波动侵蚀
4. 人民币信用获得实物信用支撑，民众逐渐接纳人民币作为储蓄货币
