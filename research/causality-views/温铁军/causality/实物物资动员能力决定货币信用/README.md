# 实物物资动员能力决定货币信用（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：实物物资动员能力决定货币信用.md

## 总体因果图

- 政府通过全国性动员在短期内掌握绝对优势数量的基本物资（粮、棉、煤等实物） → 人民币通货地位的确立（物价稳定、投机被遏制、民众接受人民币）
- 折实制度（折实公债、折实工资、折实储蓄）以粮棉煤等实物为计价单位 → 人民币在币值尚不稳定时被民众接受并逐渐成为储蓄货币
