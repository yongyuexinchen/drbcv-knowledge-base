# 亚洲金融危机对中国影响不显著（金融风险防范表现相对较好）

> 属于因果簇：[[公司治理结构与金融风险相关性质疑]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国国有企业公司治理原则尚未建立（微观制度问题严重） |
| **DV（因变量）** | 亚洲金融危机对中国影响不显著（金融风险防范表现相对较好） |
| **Chain（传导链）** | 中国国有企业微观治理机制不完善 → 但中国金融体系未完全市场化开放，资本流动受限 → 亚洲金融危机的传导机制主要通过资本账户与金融市场冲击 → 中国宏观金融防火墙使外部危机难以直接传导 → 结果表现为危机影响不显著，与公司治理水平无关 |
| **Lag（时滞）** | 危机影响评估为事后观察，无明显时滞；但宏观隔离导致影响延迟或减弱 |
| **Threshold（临界值）** | 当国家资本管制强度与金融市场开放度达到某种临界值时，外部危机传导被阻断；文中未具体量化 |
| **前提与约束（Premises）** | 中国属于转轨经济体，存在国家资本向部门垄断资本转化的特殊产权背景；中国金融体系未完全与全球市场接轨；该比较只针对亚洲金融危机期间的表现 |
| **Falsification（证伪条件）** | 若发现中国企业治理水平的改善与金融风险抵御能力显著相关，或中国在资本账户开放后仍因治理缺陷导致严重危机，则可削弱该断言 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 一个房子电路老化（治理差）但位于地震带之外（宏观隔离），地震时安然无恙；不能反过来证明电路老化能抗震。

### 🔗 文字版因果链

1. 中国国有企业微观治理机制不完善
2. 但中国金融体系未完全市场化开放，资本流动受限
3. 亚洲金融危机的传导机制主要通过资本账户与金融市场冲击
4. 中国宏观金融防火墙使外部危机难以直接传导
5. 结果表现为危机影响不显著，与公司治理水平无关
