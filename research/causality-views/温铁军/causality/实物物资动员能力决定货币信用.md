# 实物物资动员能力决定货币信用

> **领域**：宏观经济学、货币金融史　|　**来源**：chapter_08.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段                      | 内容                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **IV（自变量）**             | 政府通过全国性动员在短期内掌握绝对优势数量的基本物资（粮、棉、煤等实物）                                                                                             |
| **DV（因变量）**             | 人民币通货地位的确立（物价稳定、投机被遏制、民众接受人民币）                                                                                                   |
| **Chain（传导链）**          | 物价飞涨引发投机商囤积居奇，人民币贬值压力增大 → 政府利用严密组织体系从全国调集远超市场投机量的粮棉等物资 → 在投机商资金链最紧张时选择统一时机集中抛售 → 物价稳中有降，投机商被迫贱价抛售，物价下跌 → 人民币币值趋于稳定，民众信心增强，通货地位确立 |
| **Lag（时滞）**             | 从1949年7月物价上涨到11月25日统一抛售，约4个月；抛售后10天内见效                                                                                           |
| **Threshold（临界值）**      | 政府手中集中的实物价值需超过社会资本总量，且主要物资（如棉纱）掌握量需达到全国产量的一半以上                                                                                   |
| **前提与约束（Premises）**     | 政府具备全国范围物资动员和调度能力，如中共依靠土地革命战争形成的举国动员体制；市场以实物（粮食、棉布等）作为价值尺度，纸币信用尚未建立；政府能与政治力量（如逮捕投机粮商）和金融手段（税收、信贷控制）协同配合                          |
| **Falsification（证伪条件）** | 若政府掌握大量物资并在全国统一抛售后，物价仍持续上涨或投机继续，或人民币信用未能确立，则该断言被推翻。                                                                              |
| **Confidence（确信度）**     | well-established                                                                                                                 |

### 🧩 生活类比

> 就像银行必须有足够的现金储备才能应对挤兑；政府必须有足够的实物物资才能稳定币值。

### 🔗 文字版因果链

1. 物价飞涨引发投机商囤积居奇，人民币贬值压力增大
2. 政府利用严密组织体系从全国调集远超市场投机量的粮棉等物资
3. 在投机商资金链最紧张时选择统一时机集中抛售
4. 物价稳中有降，投机商被迫贱价抛售，物价下跌
5. 人民币币值趋于稳定，民众信心增强，通货地位确立

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 折实制度（折实公债、折实工资、折实储蓄）以粮棉煤等实物为计价单位 |
| **DV（因变量）** | 人民币在币值尚不稳定时被民众接受并逐渐成为储蓄货币 |
| **Chain（传导链）** | 人民币币值不稳定，民众不愿储藏人民币 → 政府推出折实公债、折实工资、折实储蓄，将货币价值与实物价格挂钩 → 民众在存取、储蓄和领取工资时获得实物价值保障，购买力不受物价波动侵蚀 → 人民币信用获得实物信用支撑，民众逐渐接纳人民币作为储蓄货币 |
| **Lag（时滞）** | 折实制度从1949年底开始实施，至1950年初物价风潮平息后人民币才获得足够信用 |
| **Threshold（临界值）** | 折实单位（如“分”）由六大城市大米、面粉、白布、煤炭的平均批发价计算，需定期公布并随物价调整 |
| **前提与约束（Premises）** | 政府掌握充足的实物物资作为折实后盾；物价虽有波动但未失控，政府有能力维持折实兑现；民众对实物价值的信任高于对纸币的信任 |
| **Falsification（证伪条件）** | 若折实制度实施后民众仍大量抛售人民币或拒绝折实储蓄，人民币信用未提升，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 类似于今天将存款与黄金或通胀指数挂钩，用实物价值为人民提供“定心丸”

### 🔗 文字版因果链

1. 人民币币值不稳定，民众不愿储藏人民币
2. 政府推出折实公债、折实工资、折实储蓄，将货币价值与实物价格挂钩
3. 民众在存取、储蓄和领取工资时获得实物价值保障，购买力不受物价波动侵蚀
4. 人民币信用获得实物信用支撑，民众逐渐接纳人民币作为储蓄货币
