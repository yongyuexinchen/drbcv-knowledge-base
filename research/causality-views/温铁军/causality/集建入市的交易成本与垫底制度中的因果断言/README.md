# 集建入市的交易成本与垫底制度中的因果断言（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：集建入市的交易成本与垫底制度中的因果断言.md

## 总体因果图

- 政府与农民之间在土地问题上的交易成本升高 → 政府改变土地制度
- 土地资源稀缺程度提高 → 土地交易困难程度提高，进而决定政府采取不同的土地制度供给
- 农村非农就业水平提高 → 土地交易成本降低
- 乡镇企业私有化改制 → 土地问题上的争议增加
- 人均耕地低于0.5亩 → 家庭主动节育
- 农民离开社区并失去土地财产身份 → 流动人口犯罪增加，社会控制成本升高
- 政府征地不再对应解决农民就业和社保 → 农民不愿意“农转非”，征地摩擦增大
- 集体建设用地入市增值收益全部用于当年分配（不建立社保基金） → 国家长期稳定受到威胁
