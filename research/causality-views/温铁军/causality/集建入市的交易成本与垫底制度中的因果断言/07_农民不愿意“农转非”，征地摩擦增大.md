# 农民不愿意“农转非”，征地摩擦增大

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第7块/8块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府征地不再对应解决农民就业和社保 |
| **DV（因变量）** | 农民不愿意“农转非”，征地摩擦增大 |
| **Chain（传导链）** | 计划经济时代政府每征一份土地就对应解决依赖土地生存人口的就业，农民愿意被征地 → 现在城市有6000万人下岗，政府无法为失地农民解决就业和社保 → 城市户口对农民失去吸引力 → 农民的生存只能依存于土地，不愿放弃土地 → 征地摩擦增大 |
| **Lag（时滞）** | 伴随国企改革和城市下岗潮，在90年代后逐渐显现 |
| **Threshold（临界值）** | 城市下岗人数达6000万，社保体系无法覆盖新增农民 |
| **前提与约束（Premises）** | 农民理性选择生存保障；外部制度环境变化使土地保障功能大于生产功能；政府财力无法为8亿农民提供现代社保 |
| **Falsification（证伪条件）** | 如果政府能为失地农民提供充分的就业和社保，但农民仍强烈反对征地，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像旧公司福利好，跳槽有人接盘；现在跳槽没人管，自然不愿走。

### 🔗 文字版因果链

1. 计划经济时代政府每征一份土地就对应解决依赖土地生存人口的就业，农民愿意被征地
2. 现在城市有6000万人下岗，政府无法为失地农民解决就业和社保
3. 城市户口对农民失去吸引力
4. 农民的生存只能依存于土地，不愿放弃土地
5. 征地摩擦增大
