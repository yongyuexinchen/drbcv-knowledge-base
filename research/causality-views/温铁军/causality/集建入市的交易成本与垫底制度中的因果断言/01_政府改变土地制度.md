# 政府改变土地制度

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第1块/8块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府与农民之间在土地问题上的交易成本升高 |
| **DV（因变量）** | 政府改变土地制度 |
| **Chain（传导链）** | 农民缺乏正常利益表达渠道，只能通过上访、包围政府等政治化方式维权 → 交易成本上升到影响政治稳定 → 制度给政府带来的收益被高昂成本抵消，制度难以为继 → 政府必须修订或改变土地制度 |
| **Lag（时滞）** | 从交易成本累积到制度被迫调整，通常需要数年甚至更长 |
| **Threshold（临界值）** | 交易成本“高到政治化的程度”，即影响社会稳定时 |
| **前提与约束（Premises）** | 政府是土地制度的供给者，制度由政府主导修订；农民没有正常的利益表达渠道；制度成本超过其收益并威胁稳定 |
| **Falsification（证伪条件）** | 如果交易成本极高但土地制度长期不变，且政府未受到明显威胁，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像房东与租客纠纷不断，租客天天闹事，房东最终不得不修改合同。

### 🔗 文字版因果链

1. 农民缺乏正常利益表达渠道，只能通过上访、包围政府等政治化方式维权
2. 交易成本上升到影响政治稳定
3. 制度给政府带来的收益被高昂成本抵消，制度难以为继
4. 政府必须修订或改变土地制度
