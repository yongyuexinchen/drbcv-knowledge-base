# 皮凯蒂增长与不平等因果断言集

> **领域**：宏观经济学/财富分配　|　**来源**：chapter_13_part_01.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 较低的年增长率持续相当长的时期 |
| **DV（因变量）** | 总量（人口或产出）出现巨大的倍数增长 |
| **Chain（传导链）** | 每期增长额按同一比例叠加在上一期总量上 → 复利效应使总量随时间指数扩张 → 即使年增长率很低，时间足够长后乘数也会变得巨大 |
| **Lag（时滞）** | 数十年至数百年以上 |
| **Threshold（临界值）** | 年增长率大于0且持续不变；如1%的年增长率持续300年导致约20倍增长，持续1000年超过2万倍 |
| **前提与约束（Premises）** | 增长率在考察期内保持稳定为正；时间跨度足够长；不存在中断或负增长抵消累积效应 |
| **Falsification（证伪条件）** | 若某段时期内年增长率持续为正，但长期总量增长远远偏离复利计算的结果，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 雪球滚下山坡，每滚一圈都按半径变大，滚得越久体积越庞大

### 🔗 文字版因果链

1. 每期增长额按同一比例叠加在上一期总量上
2. 复利效应使总量随时间指数扩张
3. 即使年增长率很低，时间足够长后乘数也会变得巨大

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 强劲的人口增长（高生育率或大量移民） |
| **DV（因变量）** | 财富不平等程度降低（继承财富的地位被削弱） |
| **Chain（传导链）** | 高生育率使家庭财富在更多子女间分割，或移民带来大量不携带旧财富的新人口 → 前代积累的财富相对于当代新创造的财富比例下降 → 人们更多依靠自身劳动和储蓄而非继承财富 → 继承财富的主导地位被弱化，财富不平等程度降低 |
| **Lag（时滞）** | 一代人以上（约30年或更长） |
| **Threshold（临界值）** | 人口增长率显著高于零增长/负增长状态，如每对夫妇生育多个子女或持续大规模移民 |
| **前提与约束（Premises）** | 其他条件相同；继承财富需要在代际间分割；移民进入时没有携带大量财富；财富主要来自继承和储蓄，而非其他非人口因素 |
| **Falsification（证伪条件）** | 如果人口高增长的同时财富不平等反而加剧，或继承财富的相对地位没有因人口增长而下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一块蛋糕分给更多的孩子，每个孩子得到的份额自然变小

### 🔗 文字版因果链

1. 高生育率使家庭财富在更多子女间分割，或移民带来大量不携带旧财富的新人口
2. 前代积累的财富相对于当代新创造的财富比例下降
3. 人们更多依靠自身劳动和储蓄而非继承财富
4. 继承财富的主导地位被弱化，财富不平等程度降低

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 持续的经济增长（人均产出增长） |
| **DV（因变量）** | 社会流动性提高，财富不平等的代际复制被限制 |
| **Chain（传导链）** | 增长带来新的功能和职业，要求每一代人掌握新技能 → 技能和偏好无法像资本那样完全机械地代际传递 → 非精英家庭出身的人获得新机会 → 社会流动性提高 → 长期内财富不平等的复制和加剧受到制约 |
| **Lag（时滞）** | 一代人至数代人的时间 |
| **Threshold（临界值）** | 人均产出年增长率即使只有0.5%、1%或1.5%也能产生效果；零增长或极低增长则无效 |
| **前提与约束（Premises）** | 职业结构随增长发生持续变化；代际间技能传递不完全；机会获取相对开放，不因出身完全排斥 |
| **Falsification（证伪条件）** | 若经济持续增长但社会流动性没有提高，或精英阶层完全固化，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 不断上涨的潮水会冲开一些障碍，让更多小船浮起来

### 🔗 文字版因果链

1. 增长带来新的功能和职业，要求每一代人掌握新技能
2. 技能和偏好无法像资本那样完全机械地代际传递
3. 非精英家庭出身的人获得新机会
4. 社会流动性提高
5. 长期内财富不平等的复制和加剧受到制约

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本收益率（r）持续高于经济增长率（g） |
| **DV（因变量）** | 财富不平等与社会不平等长期加剧 |
| **Chain（传导链）** | r>g意味着资本积累速度超过整体经济增长速度 → 资本收入在国民收入中的占比持续上升 → 资本所有者积累的财富增长快于劳动者收入增长 → 继承财富的地位越来越重要 → 财富分配和不平等结构在长期内趋于恶化 |
| **Lag（时滞）** | 数十年至数百年（长期效应） |
| **Threshold（临界值）** | 资本收益率与经济增长率之间存在“明显而细小”的正向差距，即r>g并持续存在 |
| **前提与约束（Premises）** | 资本收益不断用于再投资；资本所有者消费比例较低（相对于社会增长率）；低增长环境使该差距更易出现且更持久 |
| **Falsification（证伪条件）** | 若在r持续大于g的时期内，财富不平等没有加剧反而缩小，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 跑得快的资本利滚利，跑得慢的劳动者收入被越拉越远

### 🔗 文字版因果链

1. r>g意味着资本积累速度超过整体经济增长速度
2. 资本收入在国民收入中的占比持续上升
3. 资本所有者积累的财富增长快于劳动者收入增长
4. 继承财富的地位越来越重要
5. 财富分配和不平等结构在长期内趋于恶化
