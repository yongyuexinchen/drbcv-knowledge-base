# 遏制财富不平等的无限扩大，同时保护竞争和激励

> 属于因果簇：[[资本主义核心矛盾及其政策回应]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施年度累进资本税（对高额财富征收更高比例税收） |
| **DV（因变量）** | 遏制财富不平等的无限扩大，同时保护竞争和激励 |
| **Chain（传导链）** | 对不同规模财富设置累进税率（如100万以下0.1%~0.5%，100~500万1%，500~1000万2%，数千万以上5%~10%） → 高额财富每年缴纳可观税收，财富累积速度放缓 → 初始资本优势被削减，财富传递的赢家通吃效应被抑制 → 不平等螺旋得到控制，同时中等以下财富税率温和，激励犹存 |
| **Lag（时滞）** | 中长期（数年至数十年，取决于税率设计和资产结构） |
| **Threshold（临界值）** | 累进税率足够高（尤其对超大财富达5%~10%），但又不至于扼杀资本积累 |
| **前提与约束（Premises）** | 需要高水平的国际协作和区域政治一体化，否则资本外逃；税制是累进的而非一刀切重税；需保护新型原始积累的竞争和激励 |
| **Falsification（证伪条件）** | 若累进资本税实施后财富不平等仍以不可持续速度扩大，或企业家精神与增长显著受损，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 对不同规模财富设置累进税率（如100万以下0.1%~0.5%，100~500万1%，500~1000万2%，数千万以上5%~10%）
2. 高额财富每年缴纳可观税收，财富累积速度放缓
3. 初始资本优势被削减，财富传递的赢家通吃效应被抑制
4. 不平等螺旋得到控制，同时中等以下财富税率温和，激励犹存
