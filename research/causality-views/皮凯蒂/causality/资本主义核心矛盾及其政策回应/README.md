# 资本主义核心矛盾及其政策回应（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：资本主义核心矛盾及其政策回应.md

## 总体因果图

- 私人资本收益率r长期高于经济增长率g（r>g） → 财富不平等加剧，社会分化严重
- 对资本收入征收过重的税（不分青红皂白地狠下重手） → 资本积累动力下降，经济增长率进一步降低
- 实施年度累进资本税（对高额财富征收更高比例税收） → 遏制财富不平等的无限扩大，同时保护竞争和激励
- 经济增长率g的提高（例如通过教育、技术、无污染技术投资） → 资本收益率r也相应提高，r–g缺口不必然缩小
- 收入和财富分配的变化（如价格、工资、财富的涨跌） → 政治观念、制度规则和政策形成，最终导致社会与经济变迁
- 20世纪两次世界大战的冲击（大规模破坏资本存量） → 资本收益显著降低，制造了r g已经被克服的假象
