# 地租（土地收益）下降至接近零

> 属于因果簇：[[21世纪资本论中的因果断言提取]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地（资本）供给量增加，超过临界点 |
| **DV（因变量）** | 地租（土地收益）下降至接近零 |
| **Chain（传导链）** | 某个地区土地（资本）供给极为丰饶 → 土地数量超过临界点，价格效应超过数量效应 → 土地价格和地租下降至接近零的水平 → 资本（土地）泛滥导致资本收益被扼杀 |
| **Lag（时滞）** | 长期（历史上跨数个世纪，如18-19世纪新大陆与旧世界对比） |
| **Threshold（临界值）** | 资本数量超过临界点，即供给丰饶到价格效应压倒数量效应 |
| **前提与约束（Premises）** | 资本是劳动的替代方式，土地是传统农业社会的主要资本形式；该地区土地供给相对人口而言极为充裕（如新大陆）；不存在其他推高地租的管制或需求冲击 |
| **Falsification（证伪条件）** | 若在某土地供给极丰饶的地区地租依然居高不下，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像一杯水里加太多糖，糖无法再溶解，反而沉在杯底——资本太多，收益反而被稀释。

### 🔗 文字版因果链

1. 某个地区土地（资本）供给极为丰饶
2. 土地数量超过临界点，价格效应超过数量效应
3. 土地价格和地租下降至接近零的水平
4. 资本（土地）泛滥导致资本收益被扼杀
