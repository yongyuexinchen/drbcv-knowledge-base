# 财富不平等程度更高（由于r-g差值增大）

> 属于因果簇：[[21世纪资本论中的财富不平等因果机制]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 低人口增长率（导致经济增长率g结构性偏低） |
| **DV（因变量）** | 财富不平等程度更高（由于r-g差值增大） |
| **Chain（传导链）** | 人口增长停滞或下降，总经济增长率g走低 → 给定资本收益率r相对稳定（4%-5%），r-g缺口扩大 → 资本积累速度相对整体收入增长进一步领先 → 财富分配失衡加剧，尤其有利于继承财富的存量持有者 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 当g低于1%时，r-g缺口显著且结构性扩大 |
| **前提与约束（Premises）** | 资本收益率r保持相对稳定（不受人口下降直接影响）；没有高税收等抑制财富集中的力量；人口下降导致对财富继承的重视程度上升 |
| **Falsification（证伪条件）** | 若低人口增长率下财富不平等并未加剧甚至降低，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 泳池进水速度（资本收益）不变，但出水口（经济增长）变小，水位（财富集中度）只会不断上升

### 🔗 文字版因果链

1. 人口增长停滞或下降，总经济增长率g走低
2. 给定资本收益率r相对稳定（4%-5%），r-g缺口扩大
3. 资本积累速度相对整体收入增长进一步领先
4. 财富分配失衡加剧，尤其有利于继承财富的存量持有者
