# 21世纪资本论中的财富不平等因果机制（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：21世纪资本论中的财富不平等因果机制.md

## 总体因果图

- 资本收益率r持续高于经济增长率g（即r>g） → 财富分配不平等程度加剧（如前1%人群财富占比上升）
- 资本/收入比不断上升 → 资本收益率r下降（长期调节机制）
- 1914-1945年系列冲击（战争、政治动荡、资本摧毁、国有化、高累进税） → 财富不平等程度大幅减少（前1%人群财富占比从60%-70%降
- 对资本及其收入征收较高累进税（如30%有效税率） → 财富集中度降低（前1%人群财富占比显著下降）
- 长子继承制（限定继承权）相对于均分继承制 → 财富分配更加集中（前10%或前1%财富占比更高）
- 低人口增长率（导致经济增长率g结构性偏低） → 财富不平等程度更高（由于r-g差值增大）
