# 21世纪资本论中的资本与劳动划分因果断言

> **领域**：宏观经济学　|　**来源**：chapter_18_part_01.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 增长率g |
| **DV（因变量）** | 长期资本/收入比β |
| **Chain（传导链）** | 增长率下降（如人口增长或技术进步放缓） → 国民收入增速降低 → 在给定储蓄率下，资本存量相对于国民收入积累更快 → 长期资本/收入比β上升 |
| **Lag（时滞）** | 长期（数十年以上） |
| **Threshold（临界值）** | β=s/g，即增长率越低，β越高 |
| **前提与约束（Premises）** | 储蓄率s保持不变；经济处于长期均衡状态；资本和收入的定义稳定 |
| **Falsification（证伪条件）** | 如果观察到的长期资本/收入比不随增长率下降而上升，或增长率与β无稳定关系，该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 储蓄率像往水池里注水，增长率像水池的排水量，水位（资本/收入比）取决于注水与排水的相对速度。

### 🔗 文字版因果链

1. 增长率下降（如人口增长或技术进步放缓）
2. 国民收入增速降低
3. 在给定储蓄率下，资本存量相对于国民收入积累更快
4. 长期资本/收入比β上升

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本存量（资本/收入比β）增加 |
| **DV（因变量）** | 资本收益率r |
| **Chain（传导链）** | 资本存量增加 → 每单位新增资本对应的边际生产率递减 → 在竞争条件下，资本收益率r趋向于下降 |
| **Lag（时滞）** | 短期至中期（随资本积累逐渐显现） |
| **Threshold（临界值）** | 资本边际生产率递减；当资本相对劳动稀缺程度降低时，r下降 |
| **前提与约束（Premises）** | 技术水平不变；资本边际生产率递减规律成立；市场近似完全竞争或议价能力不变 |
| **Falsification（证伪条件）** | 如果资本存量大幅增加而资本收益率长期不变或上升，且不是因为技术进步或垄断议价能力提高，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 当果园里的果树太多时，每增加一棵树多结的果子会越来越少，单位果树的收益（收益率）也会下降。

### 🔗 文字版因果链

1. 资本存量增加
2. 每单位新增资本对应的边际生产率递减
3. 在竞争条件下，资本收益率r趋向于下降

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本/收入比β增加（且替代弹性大于1） |
| **DV（因变量）** | 资本收入比重α |
| **Chain（传导链）** | β增加 → 资本收益率r下降，但下降比例小于β上升比例 → 根据α=r×β，α上升 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 替代弹性>1（历史估计在1.3~1.6） |
| **前提与约束（Premises）** | 资本收益率等于资本边际生产率；资本与劳动的替代弹性大于1；没有大规模资本税或再分配政策干预 |
| **Falsification（证伪条件）** | 如果在替代弹性>1的时期，观察到β上升而α稳定或下降，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 你投资的资金池扩大，虽然每笔钱回报率略降，但总回报占比反而增加了，因为池子扩容的速度超过回报率下降的速度。

### 🔗 文字版因果链

1. β增加
2. 资本收益率r下降，但下降比例小于β上升比例
3. 根据α=r×β，α上升

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 通货膨胀 |
| **DV（因变量）** | 财富在不同资产类别间的再分配 |
| **Chain（传导链）** | 通货膨胀率上升 → 名义资产（现金、储蓄账户、非指数化债券）的实际价值缩水 → 实际资产（房产、股票）价格随通胀上升 → 财富从名义资产持有者转移向实际资产持有者 |
| **Lag（时滞）** | 中短期（随通胀持续显现） |
| **Threshold（临界值）** | 通胀率超过名义资产利率（实际收益为负） |
| **前提与约束（Premises）** | 资产类型分为名义资产和实际资产；名义资产没有完全通胀指数化；实际资产价格至少与消费价格指数同步上涨 |
| **Falsification（证伪条件）** | 如果所有资产均完全通胀指数化，或实际资产价格不随通胀上涨，则财富再分配效应减弱或消失 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 通货膨胀像一场隐形的税，它悄悄从存款人口袋里拿走购买力，送给持有房产和股票的人。

### 🔗 文字版因果链

1. 通货膨胀率上升
2. 名义资产（现金、储蓄账户、非指数化债券）的实际价值缩水
3. 实际资产（房产、股票）价格随通胀上升
4. 财富从名义资产持有者转移向实际资产持有者
