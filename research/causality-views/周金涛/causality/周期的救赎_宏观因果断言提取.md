## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 原材料库存指数触底回升 |
| **DV（因变量）** | 库存周期底部出现（2012年第二季度） |
| **Chain（传导链）** | 原材料库存指数是生产领域的冷暖指标，领先产成品库存累计同比约2~3个季度 → 原材料库存指数触底回升，表明生产企业预期需求将好转并开始增加原材料采购 → 经约两个季度传导，产成品库存累计同比增速企稳见底，库存周期进入底部 |
| **Lag（时滞）** | 2~3个季度（按2个季度计算） |
| **Threshold（临界值）** | 原材料库存指数持续回升，且领先关系保持稳定 |
| **前提与约束（Premises）** | 需求仍处于疲弱或调整阶段，无突发重大政策或外部冲击改变库存行为；量价关系遵循被动去库存→主动去库存→被动补库存→主动补库存的经典库存周期规律 |
| **Falsification（证伪条件）** | 如果2012年第二季度产成品库存累计同比增速未企稳见底，或原材料库存指数回升后产成品库存继续恶化，则该因果断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 春天不会在日历一到就立刻到来，但最早感知地温回暖的蚯蚓开始活动后，再过一段时间冰雪才会真正消融；预兆领先于现象，但预兆也可能失灵。

### 🔗 文字版因果链

1. 原材料库存指数是生产领域的冷暖指标，领先产成品库存累计同比约2~3个季度
2. 原材料库存指数触底回升，表明生产企业预期需求将好转并开始增加原材料采购
3. 经约两个季度传导，产成品库存累计同比增速企稳见底，库存周期进入底部

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 房地产销售见底 |
| **DV（因变量）** | 房地产投资见底、房价见底 |
| **Chain（传导链）** | 销售端首先出现需求变化，销售见底意味着需求不再恶化 → 需求的企稳传导至供给端，住宅投资约滞后1个季度见底 → 价格对供需的反应更慢，房价约滞后销售2~3个季度见底 |
| **Lag（时滞）** | 房地产投资滞后1个季度；房价滞后2~3个季度 |
| **Threshold（临界值）** | 房地产销售需持续回升而不是单月反弹，否则后续见底过程可能被延后或打断 |
| **前提与约束（Premises）** | 历史房地产周期规律（销售→投资→价格依次见底）继续成立；无重大政策调控方向转变或极端外部冲击干扰；房地产调整是政策纠偏性质，而非系统性金融崩溃 |
| **Falsification（证伪条件）** | 若房地产销售见底后，投资和价格未按预期滞后节奏见底，或销售再次显著回落，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 多米诺骨牌依次倒下，销售是第一块被推倒的牌，投资和价格随后相继倒下；但如果手突然挡住后面的牌，顺序就会被打乱。

### 🔗 文字版因果链

1. 销售端首先出现需求变化，销售见底意味着需求不再恶化
2. 需求的企稳传导至供给端，住宅投资约滞后1个季度见底
3. 价格对供需的反应更慢，房价约滞后销售2~3个季度见底

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元持续大幅升值与中国去泡沫过程共振 |
| **DV（因变量）** | 资本外流、资产价格下降，中国经济增长受到冲击 |
| **Chain（传导链）** | 美国经济基本面相对更好，美元资产吸引力增强，资本有回流美国的趋势 → 中国正处于增长中枢下移的去泡沫过程中，经济前景不确定性高 → 美元持续升值进一步压低人民币资产吸引力，海外资金和国内资金流向美国 → 资本外流导致国内资产价格下降，去泡沫加速，进而抑制投资和消费，冲击经济增长 |
| **Lag（时滞）** | 未来两年（中长期影响，共振形成后持续显现） |
| **Threshold（临界值）** | 美元出现长时间、较大幅度的升值；中国同时处于去泡沫/去杠杆进程中 |
| **前提与约束（Premises）** | 中国本身处于增长中枢下移的去泡沫过程中；美国私人部门去杠杆较充分，经济相对更具弹性；资本逐利，且投资美国风险显著小于投资中国 |
| **Falsification（证伪条件）** | 如果美元大幅升值期间，中国资本外流不明显、资产价格未显著下降，或经济未受到明显冲击，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 两股波浪单独看都能越过堤坝，但当它们在同一地点叠加时，会形成一面更高的浪墙，对堤坝的破坏远超各自简单相加。

### 🔗 文字版因果链

1. 美国经济基本面相对更好，美元资产吸引力增强，资本有回流美国的趋势
2. 中国正处于增长中枢下移的去泡沫过程中，经济前景不确定性高
3. 美元持续升值进一步压低人民币资产吸引力，海外资金和国内资金流向美国
4. 资本外流导致国内资产价格下降，去泡沫加速，进而抑制投资和消费，冲击经济增长

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济中枢下移中的政府救赎模式（注重结构转型 vs 延续旧模式） |
| **DV（因变量）** | 资本市场表现与长期经济转型成败 |
| **Chain（传导链）** | 经济增长中枢下移后，政府必然采取刺激政策进行救赎 → 若刺激政策延续旧有投资主导模式，则经济走向过热→泡沫破裂→衰退，资本市场大幅震荡 → 若刺激政策转向结构转型和产业升级，则经济成功转型，第三产业崛起，资本市场走出慢牛 |
| **Lag（时滞）** | 约5~10年（日本、韩国案例体现的中长期过程） |
| **Threshold（临界值）** | 救赎政策中结构转型的力度是否超过对旧模式的依赖 |
| **前提与约束（Premises）** | 日本和韩国的历史经验具有可比性；在第一次中枢下移后，经济体对旧模式有依赖心理，需要经历二次冲击才真正改变；资本市场是经济基本面和政策取向的映射 |
| **Falsification（证伪条件）** | 若一个经济体在救赎中注重结构转型却未能实现慢牛或长期增长，或延续旧模式却避免了泡沫破裂和衰退，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 走同一条路会再次掉进同一个坑；另辟蹊径虽然起初慢，但最终能绕开深渊，看到更稳定的风景。

### 🔗 文字版因果链

1. 经济增长中枢下移后，政府必然采取刺激政策进行救赎
2. 若刺激政策延续旧有投资主导模式，则经济走向过热→泡沫破裂→衰退，资本市场大幅震荡
3. 若刺激政策转向结构转型和产业升级，则经济成功转型，第三产业崛起，资本市场走出慢牛

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 第三产业崛起与主导产业在继承中更迭 |
| **DV（因变量）** | 中国经济在增长中枢下移中实现成功转型 |
| **Chain（传导链）** | 旧主导产业（重化工业）高速增长期结束，经济增长动力减弱 → 第三产业占比上升，就业吸纳能力增强，弥补第二产业增长放缓的缺口 → 制造业通过升级换代焕发新活力，主导产业在电力、汽车、化工、钢铁等基础上提升为高端装备、信息等 → 需求结构变化与投资结构调整相互配合，形成新增长结构，推动经济走向新中枢 |
| **Lag（时滞）** | 约10~20年的长周期转型过程 |
| **Threshold（临界值）** | 第三产业在GDP中占比超过第二产业，且制造业竞争力不因转型而下降 |
| **前提与约束（Premises）** | 城市化率进入50%以后的放缓阶段，房地产直线式发展时期结束；政府有意识地调整投资格局，金融资源向第三产业倾斜；顺应需求结构变化，做大第三产业同时做强第二产业 |
| **Falsification（证伪条件）** | 如果第三产业占比上升但经济未能企稳或增长质量持续恶化，或制造业升级失败导致国际竞争力下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一棵大树在主干生长变慢时，把养分输送给新的分支，让树枝长粗长大以承接更多阳光；只要旧树干不空心，整棵树依然能枝繁叶茂。

### 🔗 文字版因果链

1. 旧主导产业（重化工业）高速增长期结束，经济增长动力减弱
2. 第三产业占比上升，就业吸纳能力增强，弥补第二产业增长放缓的缺口
3. 制造业通过升级换代焕发新活力，主导产业在电力、汽车、化工、钢铁等基础上提升为高端装备、信息等
4. 需求结构变化与投资结构调整相互配合，形成新增长结构，推动经济走向新中枢
