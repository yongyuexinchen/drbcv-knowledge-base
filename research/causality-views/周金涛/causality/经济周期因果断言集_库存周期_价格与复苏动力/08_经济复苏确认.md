# 经济复苏确认

> 属于因果簇：[[经济周期因果断言集：库存周期、价格与复苏动力]]（第8块/13块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 从业人员指数好转（生产改善的滞后结果） |
| **DV（因变量）** | 经济复苏确认 |
| **Chain（传导链）** | 生产改善 → 1~2个月后从业人员指数反弹 → 就业人数增加 → 经济复苏得到确认 |
| **Lag（时滞）** | 1~2个月 |
| **Threshold（临界值）** | 从业人员指数结束连续下降并反弹 |
| **前提与约束（Premises）** | 历史规律稳定；无极端外部冲击 |
| **Falsification（证伪条件）** | 若生产改善后2个月从业人员指数未反弹，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 产量回升后，企业才会招人

### 🔗 文字版因果链

1. 生产改善
2. 1~2个月后从业人员指数反弹
3. 就业人数增加
4. 经济复苏得到确认
