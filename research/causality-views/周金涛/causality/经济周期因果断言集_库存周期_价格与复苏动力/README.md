# 经济周期因果断言集：库存周期、价格与复苏动力（因果簇）

> 因果簇索引：13 个子因果卡。父卡文件：经济周期因果断言集_库存周期_价格与复苏动力.md

## 总体因果图

- 工业增加值季调趋势项环比见底（量的底部） → 产出缺口底部出现
- 需求回升（新订单增加） → 经济复苏确认
- 房地产销售见底回升 → 房地产投资回升
- M1出现周期性复苏 → 经济复苏（产出缺口反弹）
- 量的底部和价格的底部出现 → 企业利润见底
- 库存周期下行时间达到17个月 → 库存周期底部出现（产出缺口见底）
- CRB工业现货指数环比显著下跌 → PPI环比在12月后或有所反复
- 从业人员指数好转（生产改善的滞后结果） → 经济复苏确认
- 非制造业投资周期性复苏 → 经济短周期复苏确认
- 房地产股价指数变化 → 房地产销售变化
- 价格上升、成本降低、利润向好 → 加速器启动并自我膨胀（周期复苏）
- 美国库存周期调整（未来半年） → A股市场受到冲击
- 产成品库存指数反弹（同时伴随生产、新订单、原材料库存指数反弹） → 经济向好判断不受影响（生产商预期积极）
