# 加速器启动并自我膨胀（周期复苏）

> 属于因果簇：[[经济周期因果断言集：库存周期、价格与复苏动力]]（第11块/13块）

## 因果断言 11

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 价格上升、成本降低、利润向好 |
| **DV（因变量）** | 加速器启动并自我膨胀（周期复苏） |
| **Chain（传导链）** | 价格上升、成本降低、利润向好 → 加速器启动 → 边际利润向好 → 加速器自我膨胀 → 经济周期进入复苏阶段 |
| **Lag（时滞）** | 未明确，通常短中期 |
| **Threshold（临界值）** | 价格止跌回升、利润回升 |
| **前提与约束（Premises）** | 加速器机制适用于经济周期驱动；价格弹性存在 |
| **Falsification（证伪条件）** | 若价格利润回升但经济周期未复苏，则加速器机制失效 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同雪球在顺坡上会越滚越大，一旦坡度、雪质合适就会自行加速

### 🔗 文字版因果链

1. 价格上升、成本降低、利润向好
2. 加速器启动
3. 边际利润向好
4. 加速器自我膨胀
5. 经济周期进入复苏阶段
