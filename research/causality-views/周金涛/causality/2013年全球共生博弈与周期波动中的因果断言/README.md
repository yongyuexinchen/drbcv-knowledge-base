# 2013年全球共生博弈与周期波动中的因果断言（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：2013年全球共生博弈与周期波动中的因果断言.md

## 总体因果图

- 美元主导的纵向一体化共生模式 → 全球经济的金融失衡与2008年金融危机
- 全球流动性反危机政策的边际效应递减 → 资源国长期增长趋势回落与美元中期升值
- 美国库存周期与建筑业周期的阶段转换 → 美国经济增长走势（先抑后扬）
- 中国经济周期状态（库存周期触底启动） → 国际资本净流动方向（流出或流入）
- 中美两国经济周期的时序关系（中国先于美国探底） → A股市场走势（上半年反弹，下半年系统性上升）
