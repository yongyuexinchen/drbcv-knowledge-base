# 第三库存周期的开启（强度和时间长度不同）

> 属于因果簇：[[周金涛周期理论中的因果断言提取]]（第7块/8块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国中周期步入中后段（就业增速高位震荡或回落） |
| **DV（因变量）** | 第三库存周期的开启（强度和时间长度不同） |
| **Chain（传导链）** | 美国中周期运行7年后进入中后段，接近充分就业 → 就业增速高位震荡或回落，标志着第二库存周期进入中后段 → 历史规律显示此后仍可开启第三库存周期 → 中周期自身特质（房地产、美元、康波位置）决定第三库存周期强度与时长 |
| **Lag（时滞）** | 就业增速见顶回落后约1-2年开启下一库存周期 |
| **Threshold（临界值）** | 失业率接近但难以低于4.4%（前轮低点）；非农就业增速高位回落 |
| **前提与约束（Premises）** | 中周期未因危机而终止；消费仍能支撑经济，房地产周期提供支撑；货币政策不至于过度紧缩 |
| **Falsification（证伪条件）** | 若美国中周期结束前未能开启第三个库存周期，直接进入衰退，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同汽车在高速路上行驶，即使过了最高时速，仍能靠惯性行驶一段距离，但能续航多久取决于路况（大周期）。

### 🔗 文字版因果链

1. 美国中周期运行7年后进入中后段，接近充分就业
2. 就业增速高位震荡或回落，标志着第二库存周期进入中后段
3. 历史规律显示此后仍可开启第三库存周期
4. 中周期自身特质（房地产、美元、康波位置）决定第三库存周期强度与时长
