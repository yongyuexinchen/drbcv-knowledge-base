# 周期的救赎：宏观因果断言提取（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：周期的救赎_宏观因果断言提取.md

## 总体因果图

- 原材料库存指数触底回升 → 库存周期底部出现（2012年第二季度）
- 房地产销售见底 → 房地产投资见底、房价见底
- 美元持续大幅升值与中国去泡沫过程共振 → 资本外流、资产价格下降，中国经济增长受到冲击
- 经济中枢下移中的政府救赎模式（注重结构转型 vs 延续旧模式） → 资本市场表现与长期经济转型成败
- 第三产业崛起与主导产业在继承中更迭 → 中国经济在增长中枢下移中实现成功转型
