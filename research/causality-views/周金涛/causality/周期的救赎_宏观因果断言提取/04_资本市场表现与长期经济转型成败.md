# 资本市场表现与长期经济转型成败

> 属于因果簇：[[周期的救赎：宏观因果断言提取]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济中枢下移中的政府救赎模式（注重结构转型 vs 延续旧模式） |
| **DV（因变量）** | 资本市场表现与长期经济转型成败 |
| **Chain（传导链）** | 经济增长中枢下移后，政府必然采取刺激政策进行救赎 → 若刺激政策延续旧有投资主导模式，则经济走向过热→泡沫破裂→衰退，资本市场大幅震荡 → 若刺激政策转向结构转型和产业升级，则经济成功转型，第三产业崛起，资本市场走出慢牛 |
| **Lag（时滞）** | 约5~10年（日本、韩国案例体现的中长期过程） |
| **Threshold（临界值）** | 救赎政策中结构转型的力度是否超过对旧模式的依赖 |
| **前提与约束（Premises）** | 日本和韩国的历史经验具有可比性；在第一次中枢下移后，经济体对旧模式有依赖心理，需要经历二次冲击才真正改变；资本市场是经济基本面和政策取向的映射 |
| **Falsification（证伪条件）** | 若一个经济体在救赎中注重结构转型却未能实现慢牛或长期增长，或延续旧模式却避免了泡沫破裂和衰退，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 走同一条路会再次掉进同一个坑；另辟蹊径虽然起初慢，但最终能绕开深渊，看到更稳定的风景。

### 🔗 文字版因果链

1. 经济增长中枢下移后，政府必然采取刺激政策进行救赎
2. 若刺激政策延续旧有投资主导模式，则经济走向过热→泡沫破裂→衰退，资本市场大幅震荡
3. 若刺激政策转向结构转型和产业升级，则经济成功转型，第三产业崛起，资本市场走出慢牛
