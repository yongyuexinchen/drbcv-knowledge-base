# 周金涛经济周期理论中的因果断言提取（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：周金涛经济周期理论中的因果断言提取.md

## 总体因果图

- 城市化率进入50%之后的放缓 → 房地产从直线增长进入周期性波动
- 房地产销售面积下滑 → 房地产开发投资增速回落进而拖累经济下行
- 非制造业和房地产需求不足 → 制造业资本性支出扩张停止
- 产出缺口下行 → 库存周期进入被动去库存并可能转为主动去库存
- 日元大幅升值（广场协议） → 日本地价非理性泡沫及随后长达20年的调整
- 房地产周期（18年） → 包含两个朱格拉周期和六个基钦周期
