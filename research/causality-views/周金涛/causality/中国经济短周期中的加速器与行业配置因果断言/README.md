# 中国经济短周期中的加速器与行业配置因果断言（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：中国经济短周期中的加速器与行业配置因果断言.md

## 总体因果图

- 经济持续下滑且其他加速器失速 → 市场泥沙俱下式下跌，防御品种相对抗跌，投资品表现不佳
- M1加速器修复和房地产销售转好 → 建筑建材、机械设备、有色金属、房地产等投资品行业获得较大弹性
- 库存加速器复苏 → 交通运输设备、信息设备、采掘、有色金属及机械设备等行业表现上
- 房地产加速器未能启动并叠加外部冲击（美元升值、欧元区冲击、出口受创） → 经济出现更大向下波动，市场先冲击后迎来中期底部与救赎机会
