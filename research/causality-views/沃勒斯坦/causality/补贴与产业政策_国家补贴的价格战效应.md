# 补贴与产业政策：国家补贴的价格战效应

> **领域**：宏观经济学/国际政治经济学　|　**来源**：_wall_卷2_04.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 停滞期国家对本国生产商的出口补贴（如英国1688年谷物补贴金） |
| **DV（因变量）** | 竞争对手被挤出核心市场，本国生产商夺取运输/仓储环节并掌控整条产业链 |
| **Chain（传导链）** | 停滞期国家利用财政能力向本国生产商提供出口补贴，降低其产品有效成本 → 受补贴生产商获得价格优势，能够以低于对手的价格在核心市场销售 → 供给弹性高的竞争对手（如波罗的海粮食生产者）因缺乏补贴无法维持价格竞争，市场份额持续流失 → 竞争对手逐渐被挤出核心市场（如荷兰市场），本国出口量从2500拉斯特激增至42000拉斯特 → 借助链锁效应，本国生产商进一步控制运输和仓储环节，最终取得生产→运输→金融的整条产业链主导权 |
| **Lag（时滞）** | 中期至长期，通常为数年至数十年，取决于补贴强度及竞争对手的财务耐力（历史中出口量跨越数个数量级所需时间） |
| **Threshold（临界值）** | 补贴需足够大且持续，使本国产品价格显著低于竞争对手成本，直至竞争对手无法维持核心市场份额（可参照出口量从2500→42000拉斯特的临界跨越） |
| **前提与约束（Premises）** | 补贴国具备可持续的财政能力（如英国议会税基+荷兰资本流入）；被挤出的竞争对手缺乏同等或更强的补贴支持能力；核心市场存在较高供给弹性竞争，允许价格战改变市场结构 |
| **Falsification（证伪条件）** | 若在类似补贴条件下，竞争对手的市场份额未显著下降，或补贴国未能在运输/仓储环节获得链锁控制权，或补贴中断后市场格局恢复原状，则该因果断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

### 🔗 文字版因果链

1. 停滞期国家利用财政能力向本国生产商提供出口补贴，降低其产品有效成本
2. 受补贴生产商获得价格优势，能够以低于对手的价格在核心市场销售
3. 供给弹性高的竞争对手（如波罗的海粮食生产者）因缺乏补贴无法维持价格竞争，市场份额持续流失
4. 竞争对手逐渐被挤出核心市场（如荷兰市场），本国出口量从2500拉斯特激增至42000拉斯特
5. 借助链锁效应，本国生产商进一步控制运输和仓储环节，最终取得生产→运输→金融的整条产业链主导权
