## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本主义体系处于扩张与巩固期（A阶段） |
| **DV（因变量）** | 下一周期（B阶段/霸权衰退期）中反体系力量的变革能量积蓄与爆发 |
| **Chain（传导链）** | 扩张期利润上升，经济资源向核心区集中 → 统治联盟巩固（英国+美洲定居者 vs 伊比利亚+非白人） → 大众运动（无套裤汉、印第安人、黑奴等）被镇压或被利用 → 失败经验在19世纪转化为完全新的斗争策略 → 失败经验与策略创新积蓄为下一周期体系衰退时的变革能量 |
| **Lag（时滞）** | 从扩张期（A阶段）到下一周期衰退期（B阶段/霸权衰退期），通常为数十年至一个世纪的长周期 |
| **Threshold（临界值）** | 当体系进入A阶段且扩张利润持续上升，同时统治联盟有能力系统性地镇压或收编大众运动时 |
| **前提与约束（Premises）** | 体系处于资本主义扩张与巩固期（A阶段）；存在明确的统治联盟与被压迫大众之间的结构性对抗；大众运动在当轮周期中无法取得根本性胜利 |
| **Falsification（证伪条件）** | 若在扩张期大众运动被镇压或利用后，在随后的B阶段/霸权衰退期并未出现更强或全新的反体系斗争策略，也未形成变革能量的集中爆发，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像反复折叠的弹簧——向下压得越狠，积蓄的能量越大，一旦外部约束松动（霸权衰退），回弹就越猛烈

### 🔗 文字版因果链

1. 扩张期利润上升，经济资源向核心区集中
2. 统治联盟巩固（英国+美洲定居者 vs 伊比利亚+非白人）
3. 大众运动（无套裤汉、印第安人、黑奴等）被镇压或被利用
4. 失败经验在19世纪转化为完全新的斗争策略
5. 失败经验与策略创新积蓄为下一周期体系衰退时的变革能量
