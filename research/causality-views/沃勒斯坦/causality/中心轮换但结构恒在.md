# 中心轮换但结构恒在

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中心国家席位的轮换（塞维利亚→阿姆斯特丹→伦敦式的霸权更替） |
| **DV（因变量）** | 中心-边缘等级结构的持续存在（结构不因轮换而消失） |
| **Chain（传导链）** | 资本主义世界经济是中心-半边缘-边缘的等级体系，国家被定位在不同层级。 → 体系中主要国家为了保持或提升位置展开持续竞争，正如只有“总是追逐野兔的猎犬”才能成为头等猎犬。 → 有竞争力的新国家升入中心，失去竞争力的旧中心降为半边缘或边缘（意大利、西班牙降级，荷兰、英国升入中心）。 → 这种轮换是在资本主义等级逻辑内部进行的更替，竞争本身不断重新确认中心与边缘之间的支配/依附关系。 → 因此，中心的具体席位可以更替，但中心-边缘的等级结构作为体系属性被再生产出来，持续存在。 |
| **Lag（时滞）** | 长周期，通常以数十年至数百年计；例如塞维利亚中心地位向阿姆斯特丹转移约经历一个世纪，阿姆斯特丹向伦敦转移又约一个世纪。 |
| **Threshold（临界值）** | 当一个新竞争者同时在生产力、商业网络、金融信用和军事霸权上全面超越旧中心时，席位轮换发生；但这一超越不足以消解中心-边缘的等级结构，除非出现体系级质变。 |
| **前提与约束（Premises）** | 资本主义世界经济持续存在，且没有体系级替代方案。；中心-边缘结构是该体系的构成性特征，而不是可被单个国家轮换去除的偶然现象。；国家间存在持续竞争，且竞争遵循资本主义积累逻辑。；中心席位轮换并未伴随体系整体组织原则的改变。 |
| **Falsification（证伪条件）** | 若能观察到某次中心席位轮换后，中心-边缘的等级结构被实质消解（如边缘国家整体上升、中心优势消失、形成无中心的多极平等网络），或资本主义世界经济被另一种体系替代，则该断言被证伪；此外，若旧中心衰落并不导致新中心崛起而是体系整体瓦解，也可证伪。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 资本主义世界经济是中心-半边缘-边缘的等级体系，国家被定位在不同层级。
2. 体系中主要国家为了保持或提升位置展开持续竞争，正如只有“总是追逐野兔的猎犬”才能成为头等猎犬。
3. 有竞争力的新国家升入中心，失去竞争力的旧中心降为半边缘或边缘（意大利、西班牙降级，荷兰、英国升入中心）。
4. 这种轮换是在资本主义等级逻辑内部进行的更替，竞争本身不断重新确认中心与边缘之间的支配/依附关系。
5. 因此，中心的具体席位可以更替，但中心-边缘的等级结构作为体系属性被再生产出来，持续存在。
