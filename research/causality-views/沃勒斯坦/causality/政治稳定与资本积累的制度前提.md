# 政治稳定与资本积累的制度前提

> **领域**：政治经济学　|　**来源**：_wall_卷4_07.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政治稳定（强政府 + 改革承诺） |
| **DV（因变量）** | 资本积累 |
| **Chain（传导链）** | 强政府提供法律和秩序的可信保障，降低资本投资的政治风险。 → 改革承诺（如自上而下的福利、银行现代化、经济自由化）表明政府以吸纳而非镇压方式整合社会力量。 → 吸纳性改革增强社会各阶层对体制的认同，维持政治稳定。 → 资本在可预期的制度和稳定环境中投入生产性活动，推动资本积累。 → 积累的资本又为福利和现代化改革提供资源，形成稳定与积累的良性循环。 |
| **Lag（时滞）** | 中期时滞，通常为5至15年，视改革制度化速度而定。 |
| **Threshold（临界值）** | 改革承诺必须制度化并实际兑现（如建立现代银行、通过福利立法），使政治稳定越过单纯秩序维持，达到社会吸纳的临界点；在此之前，稳定可能仅表现为压制性稳定，无法有效促进资本积累。 |
| **前提与约束（Premises）** | 国家处于中心区或准中心区。；改革以吸纳（而非镇压）为主。；自由市场意识形态的宣扬与实际国家干预强度无关，因此意识形态话语不构成该断言的边界条件。 |
| **Falsification（证伪条件）** | 若发现某个中心区/准中心区国家同时满足强政府、改革承诺与吸纳式改革，但资本积累率并未持续上升或反而下降；或存在不满足这些前提却能实现高水平资本积累的案例，则该断言可被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 政治稳定如坚固的河堤，改革承诺如泄洪道；资本如洪流，只有在河堤稳固且泄洪道有效时才会安心灌溉农田。自由市场口号只是水面泡沫，无法改变水流方向。

### 🔗 文字版因果链

1. 强政府提供法律和秩序的可信保障，降低资本投资的政治风险。
2. 改革承诺（如自上而下的福利、银行现代化、经济自由化）表明政府以吸纳而非镇压方式整合社会力量。
3. 吸纳性改革增强社会各阶层对体制的认同，维持政治稳定。
4. 资本在可预期的制度和稳定环境中投入生产性活动，推动资本积累。
5. 积累的资本又为福利和现代化改革提供资源，形成稳定与积累的良性循环。
