# 利润挤压推动资本向边缘区转移

> **领域**：国际政治经济学/世界体系论　|　**来源**：_wall_卷4_02.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中心区工业品相对价格下降（利润挤压） |
| **DV（因变量）** | 成本控制重点从国内转向边缘区（殖民扩张/供应链转移） |
| **Chain（传导链）** | 中心区工业生产能力扩张导致工业品供给增加 → 供给增加使工业品相对价格在长期中趋于下降（增长导致价格下降） → 相对价格下降压缩单位利润，形成利润挤压 → 国内要素成本（工资、地租、环保等）具有刚性，难以同步下降，国内压缩空间缩小 → 为维持利润率，资本将成本控制重点转向要素成本更低且可强制压榨的边缘区，表现为殖民扩张或供应链转移 |
| **Lag（时滞）** | 利润率下行期的累积压力导致的结构性转向；历史案例中价格下降持续约半世纪后（1815~1873年）殖民扩张才成为主要手段，一般时滞为数十年。 |
| **Threshold（临界值）** | 当工业品相对价格下降造成的利润率损失超过国内成本压缩的最大可能幅度（即国内调节空间耗尽）时，转向边缘区成为主要应对手段。 |
| **前提与约束（Premises）** | 中心区处于康德拉基耶夫 B 阶段或利润率下行期；边缘区存在可压榨的要素成本差（劳动力、原材料价格等） |
| **Falsification（证伪条件）** | 若在康德拉基耶夫 B 阶段，中心区通过国内技术革新、产业升级或组织变革等方式成功维持利润率，而未进行殖民扩张或供应链转移；或边缘区要素成本差存在但资本仍主要在国内寻求出路，则该断言可被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同街边餐饮店因菜价下降、竞争激烈导致利润变薄后，不再只靠店内节流，而是把厨房搬到城郊统一配送以降低租金和人工成本。

### 🔗 文字版因果链

1. 中心区工业生产能力扩张导致工业品供给增加
2. 供给增加使工业品相对价格在长期中趋于下降（增长导致价格下降）
3. 相对价格下降压缩单位利润，形成利润挤压
4. 国内要素成本（工资、地租、环保等）具有刚性，难以同步下降，国内压缩空间缩小
5. 为维持利润率，资本将成本控制重点转向要素成本更低且可强制压榨的边缘区，表现为殖民扩张或供应链转移
