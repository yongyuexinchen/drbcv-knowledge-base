# 纳入全球劳动分工对融入方的净效应取决于国内政治结构能否抵抗自由贸易帝国主义

> **领域**：世界体系政治经济学　|　**来源**：_wall_卷3_04.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国内政治结构能否抵抗自由贸易帝国主义（国家能力强弱） |
| **DV（因变量）** | 融入全球劳动分工的净效应（保留部分工业成为半边缘 vs 彻底边缘化） |
| **Chain（传导链）** | 地带被纳入全球劳动分工，面临自由贸易帝国主义的压力 → 国内政治结构决定能否采取保护性政策（如保护关税、军事力量）来抵抗这种压力 → 若能抵抗（国家能力强，如俄国），则保留部分工业，维持半边缘地位 → 若不能抵抗（国家能力弱，如印度/奥斯曼），则被迫专业化于出口导向商品作物，经历非工业化，最终彻底边缘化 |
| **Lag（时滞）** | 长期过程，通常需数十年至数代（如19世纪后半叶的俄国与印度分岔） |
| **Threshold（临界值）** | 当国家能力达到能够自主制定保护关税和维持足够军事力量的水平时，净效应偏向半边缘；低于该水平则偏向彻底边缘化 |
| **前提与约束（Premises）** | 该地带已被纳入全球劳动分工（世界经济）；存在自由贸易帝国主义的外部经济压力；其他条件（如资源禀赋、初始工业基础）假定不变 |
| **Falsification（证伪条件）** | 若发现国家能力弱却成功实现工业化并避免边缘化的案例，或国家能力强却仍被彻底边缘化的案例，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 国家能力就像游泳者的救生圈。全球化如同大海，被纳入劳动分工就是跳入大海。没有救生圈（国家弱）会被淹没（边缘化），有救生圈（国家强）就能浮起来（半边缘化）。

### 🔗 文字版因果链

1. 地带被纳入全球劳动分工，面临自由贸易帝国主义的压力
2. 国内政治结构决定能否采取保护性政策（如保护关税、军事力量）来抵抗这种压力
3. 若能抵抗（国家能力强，如俄国），则保留部分工业，维持半边缘地位
4. 若不能抵抗（国家能力弱，如印度/奥斯曼），则被迫专业化于出口导向商品作物，经历非工业化，最终彻底边缘化
