# 信贷扩张与主权债务违约的因果链

> **领域**：国际金融/宏观经济学　|　**来源**：_wall_卷4_05.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 信贷向弱主权国家过度扩张 |
| **DV（因变量）** | 违约潮并反噬中心区金融体系 |
| **Chain（传导链）** | 竞争性放贷导致信贷标准降低，流向弱主权国家的资本激增 → 弱主权国家借入超过自身偿债能力的债务，加之缺乏政治约束，形成偿债困难 → 外部冲击或到期压力下，债务国集体违约，形成违约潮 → 违约潮令中心区银行和投资者蒙受损失，信用收缩，反噬中心区金融体系 |
| **Lag（时滞）** | 约5-10年（如1860年代放贷至1870年代初违约，随后1873年大萧条） |
| **Threshold（临界值）** | 当信贷增速超过借款国偿债能力且无有效政治约束时，违约风险累积至临界值 |
| **前提与约束（Premises）** | 竞争性放贷降低信贷标准；借款国缺乏偿债能力与政治约束 |
| **Falsification（证伪条件）** | 如果出现信贷向弱主权国家过度扩张但未发生违约潮，或违约潮未对中心区金融体系造成显著影响，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同银行明知借款人无力偿还却因竞争而争先放贷，最终坏账爆发时不仅借款人破产，银行也遭拖累

### 🔗 文字版因果链

1. 竞争性放贷导致信贷标准降低，流向弱主权国家的资本激增
2. 弱主权国家借入超过自身偿债能力的债务，加之缺乏政治约束，形成偿债困难
3. 外部冲击或到期压力下，债务国集体违约，形成违约潮
4. 违约潮令中心区银行和投资者蒙受损失，信用收缩，反噬中心区金融体系
