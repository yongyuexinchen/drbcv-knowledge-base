# 自由贸易作为霸权国结构性武器导致接受方边缘化

> **领域**：国际政治经济学　|　**来源**：_wall_卷3_02.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 霸权国向追赶期国家推行'自由贸易'处方（如伊登条约/巴尔塔利曼条约） |
| **DV（因变量）** | 接受方必然边缘化（本土制造业摧毁、原料出口依赖、财政收入萎缩、主权债务化直至崩溃） |
| **Chain（传导链）** | 霸权国通过政治或军事压力迫使接受方签订自由贸易条约 → 接受方开放市场并降低关税 → 霸权国准垄断产品（如棉布/高端制造）大量涌入 → 接受方本土制造业因无法竞争而破产或摧毁 → 接受方被迫转向原料出口，形成半边缘化经济结构 → 本土制造业税基萎缩导致财政收入下降 → 财政压力迫使接受方举借外债（如土耳其1854年借债） → 债务负担累积，最终引发主权债务危机（如1878年崩溃） |
| **Lag（时滞）** | 从自由贸易条约签订到主权债务危机约数十年（如1838年巴尔塔利曼条约至1854年借债约16年，至1878年崩溃约40年） |
| **Threshold（临界值）** | 关税降至不足以抵消霸权国准垄断产品的成本/技术优势，且本土产业竞争力低于生存临界点（如进口品价格低于本土产品并持续挤占市场至破产） |
| **前提与约束（Premises）** | 接受方工业尚处追赶期，不具备与霸权国准垄断产品相抗衡的产业体系；霸权国已在关键产品（如棉布/高端制造）上形成准垄断地位；自由贸易协议是强制性或不对称的，接受方无法自主设定保护性关税；排除霸权国与接受方产业差距不大或接受方已有替代性技术创新能力的情况 |
| **Falsification（证伪条件）** | 若发现接受方在开放市场后本土制造业实现升级、财政收入增长且未陷入主权债务危机，或霸权国并不具备准垄断产品优势，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 霸权国通过政治或军事压力迫使接受方签订自由贸易条约
2. 接受方开放市场并降低关税
3. 霸权国准垄断产品（如棉布/高端制造）大量涌入
4. 接受方本土制造业因无法竞争而破产或摧毁
5. 接受方被迫转向原料出口，形成半边缘化经济结构
6. 本土制造业税基萎缩导致财政收入下降
7. 财政压力迫使接受方举借外债（如土耳其1854年借债）
8. 债务负担累积，最终引发主权债务危机（如1878年崩溃）
