### 必备技能学习优先级建议

```
第1梯队（必须会，不会没法面试）:
  Python → 大模型/LLM 基础概念 → Prompt Engineering → API开发

第2梯队（面试常问，至少能说清楚原理）:
  RAG（检索增强生成）→ Agent/LangChain → 向量数据库 → Docker

第3梯队（有项目经验更好）:
  FastAPI → SQL → Linux → Git
```
