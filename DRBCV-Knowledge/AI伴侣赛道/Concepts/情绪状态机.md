# 情绪状态机（Emotional State Machine）

## 类型判定
判别型 — 它是取代纯 Prompt 情感控制的状态管理范式。核心问题是「情绪如何触发、如何衰减、如何影响行为」。

## 是什么
情绪状态机是 AI 伴侣人格系统的核心机制：用多维情绪向量（如 valence-arousal）表示角色当前情绪状态，对话交互触发状态转移，情绪影响回复风格和行为选择。区别于 Prompt 注入的情感标签（如「你现在很高兴」），状态机让情绪有了动力学——会触发、会衰减、会复合。

## 输入-输出空间
**输入**：对话事件（用户消息、系统事件、时间流逝）+ 当前情绪状态
**输出**：更新后的情绪状态 + 情感调制的回复生成参数

## 正例（≥2个）
- Shikigami Protocol：情绪 × 能量 × 好感三维状态机，沉默后主动搭话
- Front Porch AI Realism Engine：emotion, trust, needs, memory 四维状态
- Utsuwa 恋爱养成数值系统：好感度 + 关系阶段 + 事件触发

## 反例/边界（≥1个）
- Character.AI 的 Prompt 情感标签：「你现在很高兴」— 无动力学，不会自发变化
- 简单的 if-else 情绪：「用户说好话 → 开心」— 缺乏衰减、复合、惯性
- 情绪 ≠ 脾气暴躁：情绪状态机的目标是「真实感」而非「不可预测」

## 详细解释
Valence-Arousal 模型（最常用的情绪维度模型）：
- **Valence（效价）**：积极 ↔ 消极（-1 到 +1）
- **Arousal（唤醒度）**：兴奋 ↔ 平静（-1 到 +1）

情绪动力学三个核心机制：
1. **触发规则**：什么事件触发什么情绪变化（用户批评 → 效价下降）
2. **衰减曲线**：情绪随时间自然回归基线（不会永远生气）
3. **复合情绪**：多种情绪可以共存（又生气又心疼）

情绪状态机 + 记忆系统的协同：情感峰值事件触发记忆存储，被存储的情感记忆在后续对话中被召回时重新激活类似情绪。

## 细节备注
- v0.1 实现建议：valence-arousal 二维模型 + 3-5 种离散情绪标签，复杂度可控
- 关键陷阱：情绪变化不能太频繁（显得神经质）也不能太迟钝（显得没反应）
- 主动交互：情绪状态机可以驱动「沉默后主动搭话」— 当角色能量高且好感高时触发主动行为
