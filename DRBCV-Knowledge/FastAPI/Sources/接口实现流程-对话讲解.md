# 接口实现流程-对话讲解

> 来源：2026-07-28 Hermes 导师模式对话
> 上下文：用户在 VS Code 中看到 `news.py` 第 10 行注释"接口实现流程"，提问这 4 步是什么意思

## 核心内容

接口实现流程 = FastAPI 开发任何接口都遵循的标准四步：

1. **模块化路由 → API 接口规范文档**：用 `APIRouter(prefix, tags)` 定义接口地址和分组
2. **定义模型类 → 数据库表（数据库设计文档）**：用 SQLAlchemy ORM 类映射数据库表
3. **在 crud 文件夹里面创建文件，封装操作数据库的方法**：写增删改查函数
4. **在路由处理函数里面调用 crud 封装好的方法，响应结果**：路由调 CRUD → return JSON

## 类比（餐厅出菜）

- 第①步 = 决定菜放哪本菜单（川菜/粤菜）
- 第②步 = 画货架图纸（数据库表结构）
- 第③步 = 写标准菜谱（CRUD 函数）
- 第④步 = 服务员接单→喊厨师→端盘子（路由调 CRUD→返回 JSON）

## 关键点

- `@router.get("/categories")` 是"挂牌"，`async def` 里的 `return` 才是返回数据
- 四步顺序不能乱：后面的依赖前面的（CRUD 依赖 models，路由调 CRUD 依赖 CRUD）
- 所有接口（查列表、注册、登录、收藏……）都是这个套路
