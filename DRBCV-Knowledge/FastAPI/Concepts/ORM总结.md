# ORM总结

## 类型判定
discriminant — 全景回顾 ORM 完整知识体系：安装 → 建表 → 会话注入 → 增删改查。

## 类比 ★
### 一句话比喻
学 ORM 就像学开车——装包是拿驾照（有资格开了），建表是买车（有了自己的车），会话注入是拿到车钥匙（每次开都要插钥匙），增删改查就是上路实操（前进=查、入库=增、变道=改、熄火下车=删）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| `pip install sqlalchemy` | 考驾照——获得操作资格 |
| 建表三步（引擎→模型→启动建表） | 买车——有了自己的车才能开 |
| 会话工厂 + 依赖注入 | 每次上车插钥匙点火——启动会话 |
| `select` + `execute` | 挂 D 挡踩油门——前进 |
| `add` + `commit` | 倒车入库——停进去确认 |
| 属性赋值 + `commit` | 变道——换个位置 |
| `delete` + `commit` | 熄火拔钥匙——本次行程结束 |
| 自动时间戳 `onupdate` | 行车记录仪——自动记录时间 |

## 是什么
ORM（SQLAlchemy 2.0 异步版）是 FastAPI 项目中最常用的数据库操作方案。完整知识体系包含四大阶段：安装配置 → 建库建表 → 会话注入 → 增删改查。

## 增删改查速查表

| 操作 | HTTP 方法 | ORM 核心方法 | 关键步骤 | 特殊点 |
|------|----------|-------------|---------|--------|
| **查询** | GET | `select(Model)` | → `db.execute()` → `scalars().all()` | 支持条件/聚合/分页 |
| **新增** | POST | `db.add(obj)` | 创建 ORM 对象 → add → commit | 先转 Pydantic 为 ORM |
| **更新** | PUT/PATCH | 属性赋值 | get 查找 → 改属性 → commit | 必须先查 |
| **删除** | DELETE | `db.delete(obj)` | get 查找 → delete → commit | 必须先查 |

## 正例（≥2 个）
1. **标准 CRUD 服务**：用这四阶段知识，30 分钟内搭出一个完整的图书管理 API（增删改查 + 分页 + 条件搜索）。
2. **企业项目实战**：头条项目中，用户模块、新闻模块、收藏模块、浏览历史模块——全部基于这套 ORM 流程构建，代码结构统一、可维护。
3. **与 FastAPI 异步生态无缝配合**：`async/await` + `AsyncSession` + `aiomysql`——从请求到数据库全程异步，不阻塞事件循环。

## 反例/边界（≥1 个）
1. **不是 Silver Bullet**：ORM 擅长 CRUD，但复杂报表（多表 JOIN + 子查询 + 窗口函数）可能用原生 SQL 更直观——可以在 ORM 项目中混用 `text("SELECT ...")`。
2. **N+1 查询陷阱**：查出一批 Book，然后循环访问 `book.author.name`——每条 book 触发一次额外 SQL。应用 `selectinload` 或 `joinedload` 预加载关联数据。
3. **生产环境必须用迁移工具**：开发时用 `create_all` 建表没问题，但上线后用 Alembic 管理数据库版本——`create_all` 不会修改已有表的结构。

## 详细解释
### ORM 的核心价值回顾
1. **不写 SQL**：`select(Book).where(Book.price > 100)` vs `SELECT * FROM book WHERE price > 100`——Python 语法有 IDE 补全和类型检查。
2. **防注入**：ORM 自动参数化查询，`user_input` 不会被当作 SQL 执行。
3. **数据库无关**：改一行 URL 就能从 MySQL 切到 PostgreSQL——业务代码不用动。
4. **自动事务管理**：依赖注入的 `get_db` 自动处理 commit/rollback/close——程序员不用手写这些模板代码。

### 学习路径建议
```
安装包 → 建表 → 会话注入 → 基本查询(select) → 条件查询(where)
→ 聚合查询(func) → 分页查询(offset/limit)
→ 新增(add+commit) → 更新(get+赋值+commit) → 删除(get+delete+commit)
→ 项目实战（头条项目反复练习）
```
