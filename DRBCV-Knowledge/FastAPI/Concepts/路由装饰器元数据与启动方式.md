# 路由装饰器元数据与启动方式

## 类型判定
procedure — 两步：在装饰器中丰富接口文档元数据（summary/description/tags）→ 选择三种启动方式之一跑起来。

## 类比 ★
### 一句话比喻
路由装饰器里的元数据就像**餐厅菜单上的菜品说明**——菜名（路径）只是基础，加了"微辣/中辣"（summary）、"主料：鲜虾+芦笋"（description）、"川菜区第3页"（tags），顾客一眼就知道这是什么菜、在哪个分类；而三种启动方式就像开店：电脑上点按钮试吃（PyCharm），正式营业走收银系统（uvicorn CLI），或者老板自己写个自动开门脚本（uvicorn.run）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| `summary`（接口概要） | 菜单上菜名旁边的"一句话推荐"——测试接口 |
| `description`（详细描述） | 菜单上的配料和做法说明——程序员看完就知道怎么调 |
| `tags`（分组标签） | 菜单分区——"川菜"、"粤菜"标签，同类接口自动归到一组 |
| `response_description` | 上菜时的摆盘说明——告诉前端"返回的数据长这样" |
| PyCharm 按钮启动 | 后厨试菜——开发时快速验证，生产环境不用 |
| `uvicorn main:app --reload` | 正式开店收银——命令行启动，适合部署 |
| `uvicorn.run(app)` | 老板写自动开门脚本——代码内启动，灵活但非主流 |

## 是什么
FastAPI 路由装饰器除了声明 HTTP 方法和 URL 路径外，还可以传入 **元数据参数**（summary、description、tags、response_description），丰富自动生成的 Swagger 交互式文档。同时 FastAPI 项目有三种启动方式：PyCharm 专业版按钮（开发用）、`uvicorn` CLI 命令（部署常用）、`uvicorn.run()` 代码启动（备用）。

## 输入-输出空间
- **输入**：装饰器中各元数据参数
- **输出**：Swagger 文档 `/docs` 中展示对应的接口描述、分组、响应说明
- **前置条件**：FastAPI 实例已创建，`from fastapi import FastAPI`

## 核心代码
```python
from fastapi import FastAPI

app = FastAPI()

@app.get(
    "/test",
    tags=["测试分组"],                      # 接口分组标签，相同标签归到一组
    summary="测试接口",                     # 接口概要，显示在文档标题旁
    description="这是一个用于测试的接口详细描述",  # 详细描述，展开后可见
    response_description="返回操作结果"      # 响应数据的描述
)
async def test():
    """处理函数"""
    return {"msg": "ok"}
```

### 三种启动方式

| 方式 | 命令/操作 | 适用场景 |
|------|----------|---------|
| ① PyCharm 绿色箭头 | 点击 `▶` 按钮 | 本地开发测试（需 PyCharm 专业版 2021+） |
| ② uvicorn CLI | `uvicorn main:app --reload` | **部署最常用**——`main` 是入口文件名，`app` 是 FastAPI 变量名 |
| ③ 代码内启动 | `uvicorn.run(app, host="127.0.0.1", port=8000)` | 备用方案，写在 `if __name__ == "__main__"` 中 |

> `--reload` 参数使代码变更后自动重启，适合开发；生产环境不加。

## 正例（≥2 个）
1. **多模块项目分组**：100 个接口按功能打 `tags=["用户模块"]`、`tags=["新闻模块"]`，文档中自动折叠分组，找接口像翻文件夹。
2. **前后端联调**：前端开发看 Swagger 文档，每个接口的 summary 和 description 写得清清楚楚，不需要翻后端代码。
3. **生产部署**：服务器上用 `uvicorn main:app --host 0.0.0.0 --port 80` 启动，监听所有 IP 的 80 端口。

## 反例/边界（≥1 个）
1. **tags 写成字符串而非列表**：`tags="用户模块"` → 应该写 `tags=["用户模块"]`，否则每个字符都会被当作一个标签。
2. **uvicorn 命令写错变量名**：FastAPI 实例叫 `application`，命令却写 `uvicorn main:app` → 报错找不到 `app` 属性。
3. **--reload 用于生产**：生产环境加 `--reload` 会导致代码变更时服务器重启，正在处理的请求全部中断。

## 详细解释
路由的本质是**请求路径 + 请求方法 + 处理函数**的三元映射。元数据参数全部是可选的，不影响接口功能，只影响文档展示。`summary` 和 `description` 的区别：summary 是标题级别的概要，始终可见；description 是展开后的详细说明。

停止 uvicorn：在终端按 `Ctrl + C`。
