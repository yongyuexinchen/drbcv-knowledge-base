# 请求参数校验规则全景

## 类型判定
procedure — 三种参数（Path/Query/Body）共用一套校验规则：选参数类型 → 在对应注解函数（Path/Query/Field）中设约束 → FastAPI 自动校验并返回 422 错误。

## 类比 ★
### 一句话比喻
FastAPI 的参数校验就像**机场安检通道**——不管你从哪个门进来（路径参数门 / 查询参数门 / 请求体门），过的都是同一套安检设备：名字长度不够？（min_length）拦下！年龄超了？（lt）拦下！格式不对？（regex）拦下！不合规的旅客（参数）当场退回，连登机口（处理函数）都到不了。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| `min_length` / `max_length`（长度限制） | 安检："名字至少 2 个字，最多 10 个字"——单字名不给过 |
| `gt` / `ge` / `lt` / `le`（数值范围） | 身高标尺："不低于 1.2m（ge=1.2），不超过 2.2m（lt=2.2）" |
| `regex`（正则表达式） | 身份证读卡器：格式不对的身份证直接报警 |
| `default`（默认值） | 自助餐默认中辣——你不说我就按默认来 |
| `...`（必填标记） | 登机牌——没它根本不让进 |
| 422 校验错误 | 安检不合格——退回，附带原因说明 |

## 是什么
FastAPI 的参数校验规则通过 `Path()`、`Query()`、`Field()` 函数中的参数来声明，适用于所有参数类型。包括：**默认值设置**（`default`）、**字符串长度**（`min_length` / `max_length`）、**正则表达式**（`regex`）、**数值范围**（`gt` / `ge` / `lt` / `le`）。规则通用，只是宿主函数不同。

## 核心代码

### 校验规则速查表
| 规则 | 参数名 | 示例 | 说明 |
|------|-------|------|------|
| 默认值 | `default` | `Query(default=0)` | 不传就用默认值 |
| 必填 | `...` | `Query(...)` | 省略号 = 必须传 |
| 字符串最小长度 | `min_length` | `Query(min_length=6)` | 仅对 `str` 有效 |
| 字符串最大长度 | `max_length` | `Query(max_length=15)` | 仅对 `str` 有效 |
| 正则匹配 | `regex` | `Query(regex=r"^[a-zA-Z_]\\w{5,15}$")` | 复杂格式校验（如用户名） |
| 大于 | `gt` | `Path(gt=0)` | greater than |
| 大于等于 | `ge` | `Path(ge=18)` | greater or equal |
| 小于 | `lt` | `Path(lt=60)` | less than |
| 小于等于 | `le` | `Path(le=100)` | less or equal |
| 描述 | `description` | `Query(description="员工ID")` | 显示在 Swagger 文档 |

### 综合示例（Query）
```python
from fastapi import Query

@router.get("/search")
async def search(
    # 字符串长度校验：6-15 位
    name: str = Query(..., min_length=6, max_length=15, description="员工名字"),
    # 正则校验：以字母或下划线开头，只含数字字母下划线，6-16位
    username: str = Query(
        ..., regex=r"^[a-zA-Z_]\w{5,15}$",
        description="用户名，以字母开头，6-16位"
    ),
    # 数值范围校验：18-59 岁
    age: int = Query(..., ge=18, lt=60, description="年龄")
):
    return {"name": name, "username": username, "age": age}
```

### 正则校验用户名详解
```python
regex = r"^[a-zA-Z_]\w{5,15}$"
# ^           以...开头
# [a-zA-Z_]   首字符必须是字母或下划线（不能以数字开头）
# \w{5,15}    后续 5-15 个单词字符（字母/数字/下划线）
# $           以...结尾
# 总长度：1 + 5~15 = 6~16 位
```

## 正例（≥2 个）
1. **用户注册**：`username: str = Query(..., min_length=6, max_length=16, regex=r"^[a-zA-Z_]\w{5,15}$")` → 用户名格式不合规直接拒绝。
2. **分页参数**：`skip: int = Query(0, ge=0)` + `limit: int = Query(10, ge=1, le=100)` → 防止负数偏移和一次拉取过多数据。
3. **邮箱校验**：`email: str = Query(..., regex=r"^[\w.-]+@[\w.-]+\.\w+$")` → 邮箱格式不正确 422 返回。

## 反例/边界（≥1 个）
1. **字符串校验规则用在 int 上**：`age: int = Query(..., min_length=6)` → `min_length` 只对 `str` 有效，int 上用无意义但不报错。
2. **正则写错导致所有合法值被拒**：`regex=r"^\d{11}$"` 想校验手机号，但忘了允许 `+86` 前缀 → 带区号的合法号码被拒绝。
3. **gt 和 ge 混淆**：`age: int = Query(gt=18)` 想表达"18岁以上"，但 `gt=18` 是"大于18"即 19 起 → 18 岁被拒绝，应该用 `ge=18`。

## 详细解释
**三个注解函数的校验参数完全通用**：
- `Path()` — 路径参数校验
- `Query()` — URL 查询参数校验
- `Field()` — 请求体字段校验（来自 `pydantic`）

所有规则都是**声明式**的——你只管写约束，FastAPI + Pydantic 自动执行校验。校验失败统一返回 HTTP 422，响应体里明确告知哪个字段、什么原因失败。
