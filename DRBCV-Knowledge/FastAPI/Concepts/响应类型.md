# 响应类型

## 类型判定
mixed — 既对比三种响应类型（JSON/HTML/文件）的特点和适用场景，又包含各自的操作步骤，是"辨识 + 操作"混合型知识。

## 类比 ★
### 一句话比喻
响应类型就像**餐厅的三种出餐方式**——JSON 是标准打包盒（默认，啥菜都能装），HTML 是堂食摆盘（浏览器直接渲染出漂亮页面），文件响应是寄一份密封档案（图片/PDF 原样交付，不拆封不加工）。客人点什么菜，厨房就用对应的容器上菜。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| JSON 响应（默认） | 标准打包盒——FastAPI 自动把 Python 对象装进去，前台/外卖都兼容 |
| `content-type: application/json` | 盒子上贴的标签——告诉客户端"里面是 JSON" |
| HTML 响应 | 堂食摆盘——装饰器里指定 `response_class=HTMLResponse`，浏览器直接渲染 |
| 文件响应（FileResponse） | 密封档案袋——return 文件对象，图片/PDF/音频原样交给客户 |
| `response_class` 参数 | 在订单上备注"用特定容器"——装饰器里指定响应类 |
| return 响应对象 | 厨师亲手交件——`return FileResponse(path)` 直接返回文件 |

## 是什么
响应类型决定了服务器返回给客户端的数据格式。FastAPI **默认支持 JSON 格式**（自动将 Python 对象转为 JSON），同时也支持 HTML、纯文本、文件、流媒体和重定向等格式。设置非 JSON 响应有两种方式：**装饰器中指定 `response_class`**（适合固定类型）或 **return 响应对象**（适合动态/文件类型）。

## 三种响应类型对比

| 维度 | JSON 响应 | HTML 响应 | 文件响应 |
|------|----------|----------|---------|
| 默认支持 | ✅ 无需配置 | ❌ 需手动设置 | ❌ 需手动设置 |
| 设置方式 | 无需设置，FastAPI 自动转换 | 装饰器中 `response_class=HTMLResponse` | `return FileResponse(path)` |
| content-type | `application/json` | `text/html` | 取决于文件类型（`image/jpeg` 等） |
| 典型场景 | API 接口、前后端分离 | 服务端渲染页面、富文本 | 图片、PDF、Excel 下载 |
| 灵活性 | 低（固定 JSON） | 低（固定 HTML） | 高（可动态指定文件） |

## 核心代码
```python
from fastapi import FastAPI
from fastapi.responses import HTMLResponse, FileResponse

app = FastAPI()

# ① JSON 响应（默认，无需配置）
@app.get("/json")
async def get_json():
    return {"msg": "Hello"}                    # Python 对象 → 自动转 JSON

# ② HTML 响应（装饰器中指定）
@app.get("/html", response_class=HTMLResponse)
async def get_html():
    return "<h1>这是一级标题</h1>"              # 返回 HTML 字符串

# ③ 文件响应（return 响应对象）
@app.get("/file")
async def get_file():
    path = "./files/cat.jpg"
    return FileResponse(path)                  # 直接返回文件对象
```

| 步骤 | 代码 | 说明 |
|------|------|------|
| ① JSON 默认 | `return {"msg": "Hello"}` | 无需任何配置，FastAPI 自动装箱 |
| ② HTML 装饰器方式 | `response_class=HTMLResponse` | 先导入，然后在装饰器中指定 |
| ③ HTML return 内容 | `return "<h1>标题</h1>"` | 必须是合法的 HTML 字符串 |
| ④ 文件 import | `from fastapi.responses import FileResponse` | 文件响应类从 responses 模块导入 |
| ⑤ 文件 return 对象 | `return FileResponse(path)` | 传入文件路径，构造响应对象返回 |

## 正例（≥2 个）
1. **API 接口返回数据**：`GET /news/list` → 自动返回 JSON 格式新闻列表，前端 `fetch` 直接解析。
2. **服务端渲染页面**：`GET /about` → `response_class=HTMLResponse`，返回完整 HTML 页面，浏览器直接显示。
3. **图片/文件下载**：`GET /download/report` → `return FileResponse("report.pdf")`，浏览器触发下载。
4. **用户头像接口**：`GET /avatar/{user_id}` → `return FileResponse(f"avatars/{user_id}.jpg")`，动态返回对应头像。

## 反例/边界（≥1 个）
1. **装饰器写死 HTML 后想返回 JSON**：一旦在装饰器中指定了 `response_class=HTMLResponse`，该接口就只能返回 HTML，改返回 `dict` 会出问题。
2. **文件路径不存在**：`FileResponse("nonexistent.jpg")` → 服务器 500 错误，应先检查文件是否存在。
3. **HTML 字符串未闭合标签**：`return "<h1>标题"`（缺少 `</h1>`）→ 浏览器渲染可能异常，但不报错。

## 详细解释
**两种设置方式的适用场景**：
- **`response_class`（装饰器中指定）**：适合返回类型固定且简单的场景（HTML、纯文本）。一旦指定，该接口的所有返回都必须符合该类型。
- **return 响应对象**：适合返回类型动态变化的场景（文件、流媒体），可以在函数内部根据条件 `return` 不同类型的响应对象。更灵活但代码稍多。

其他常用响应类型速查：`PlainTextResponse`（纯文本）、`StreamingResponse`（流式响应，适合大文件）、`RedirectResponse`（重定向）。
