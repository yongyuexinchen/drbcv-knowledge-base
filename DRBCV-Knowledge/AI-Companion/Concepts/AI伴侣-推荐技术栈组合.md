# AI伴侣-推荐技术栈组合

## 是什么（What）

基于6个开源项目的深度调研，给出3套可行方案：方案A"搭积木"（1周原型，¥10-30/月）、方案B"魔改精英"（1-2月完整版，¥0-50/月+¥3K硬件）、方案C"从零造轮子"（6-12月终极控制权）。**推荐路径：A→C，先验证再迭代**。

这就像造房子：A是买现成组合板房（1周入住），B是买毛坯房装修（1-2月入住，但得会装修），C是自己买地盖楼（6-12月，完全按你的设计）。

## 为什么重要（Why）

- 用户核心约束：Python初学、存款~25万、不需要训练基础模型、本地优先
- 推荐路径：先方案A验证"永月"可行性（1周）→ 积累经验后方案C从零搭建（6-12月）
- **不要直接冲Letta** — 过度设计（25MB源码），初学者会淹死在代码里
- 方案A的关键价值不是产品本身，而是快速建立"我能做AI应用"的信心

## 怎么做（How）

### 三方案对比

| 方案 | 代号 | 难度 | 时间 | 月费 | 技术栈 | 推荐 |
|------|------|------|------|------|--------|------|
| A | 搭积木 | ⭐⭐ | 1周 | ¥10-30 | ST+Memobase+DeepSeek+edge-tts | ⭐⭐⭐⭐⭐ 现在开始！ |
| B | 魔改精英 | ⭐⭐⭐ | 1-2月 | ¥0-50 | Open-LLM-VTuber+Letta+ST角色卡 | ⭐⭐⭐⭐ 中长期目标 |
| C | 从零造轮子 | ⭐⭐⭐⭐⭐ | 6-12月 | ¥0 | FastAPI+ChromaDB+自建四层记忆 | ⭐⭐⭐⭐⭐ 终极控制权 |

### 方案A（推荐第一步）

```
SillyTavern (前端/角色卡)
    ↕
Memobase (记忆后端：Profile提取)
    ↕
DeepSeek API (LLM，¥1/百万token)
    +
edge-tts (免费TTS) + sherpa-onnx (本地STT)
```

第一周就能跑起来，验证"永月"的对话质量。

### 方案C（终极目标）

```
FastAPI + WebSocket (后端)
ChromaDB (向量记忆)
自建四层记忆: Persona → Profile → Episodic → World
DeepSeek API + 本地备用LLM
sherpa-onnx TTS/STT + Live2D 视觉
```
