# 插入排序（Insertion Sort）

## 类型判定
程序型 — 具体的排序算法，含代码实现和复杂度分析。包含**直接插入排序**和**折半插入排序**两种变体。

## 是什么
插入排序的核心思想：每次将一个待排序的记录按关键字大小**插入到前面已排好序的子序列**中，直到全部记录插入完成。从第二个元素开始处理，认为第一个元素天然有序。

- **直接插入排序**：用顺序查找找插入位置
- **折半插入排序**：用折半查找找插入位置（因为前面已有序，可用二分加速查找）

## 输入-输出空间
- **输入**：数组 A[0..n-1]（或带哨兵的 A[1..n]），n 个元素
- **输出**：递增有序的数组
- **前置条件**：无

## 正例（≥2 个）
1. **序列基本有序时效率极高**：`[1, 2, 3, 5, 4]` → 前4个已有序，只需把4插入到5前面，移动1次
2. **打扑克理牌**：摸到一张牌，插到手里已有牌的正确位置——天然就是插入排序

## 反例/边界（≥1 个）
1. **逆序序列性能最差**：`[5, 4, 3, 2, 1]` → 每趟都要把当前元素和前面所有元素比较并后移，总计 $O(n^2)$
2. **折半插入排序不减少移动次数**：虽然比较次数减少到 $O(n\log n)$，但移动元素次数依然是 $O(n^2)$，整体时间复杂度还是 $O(n^2)$

## 详细解释

### 核心代码（直接插入排序，带哨兵）
```c
void InsertSort(int A[], int n) {
    int i, j;
    for (i = 2; i <= n; i++) {       // A[1]已有序，从第2个开始
        if (A[i] < A[i-1]) {          // 只有当前元素较小时才需移动
            A[0] = A[i];              // 哨兵：暂存当前元素
            for (j = i-1; A[j] > A[0]; j--)
                A[j+1] = A[j];        // 比当前元素大的全部右移
            A[j+1] = A[0];            // 插入到正确位置
        }
    }
}
```

### 关键注意事项
- **哨兵 A[0]** 的作用：省去 `j >= 1` 的边界判断，每轮循环少一次比较——效率提升微小但存在
- 只有 `A[i] < A[i-1]` 时才进入内循环，若序列已有序 → 每趟只比较1次，$O(n)$

### 折半插入排序的折半查找逻辑
折半查找会因 `low > high` 而停止，此时 `low` 就是插入位置。**稳定性保证**：当 `A[mid] == A[0]` 时，继续在右半区查找（`low = mid + 1`），保证相同关键字相对位置不变。

```c
// 折半查找插入位置（while 循环部分）
while (low <= high) {
    mid = (low + high) / 2;
    if (A[mid] > A[0])
        high = mid - 1;
    else
        low = mid + 1;    // 包含相等情况——保证稳定性
}
// 最终 low 就是插入位置
```

### 时间复杂度
| 情况 | 比较次数 | 移动次数 | 复杂度 |
|------|---------|---------|--------|
| 最好（已有序） | n-1 | 0 | $O(n)$ |
| 最坏（逆序） | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ | $O(n^2)$ |
| 平均 | — | — | $O(n^2)$ |

- 空间复杂度：**$O(1)$**（仅需常数个辅助变量）
- 稳定性：**稳定**（相等时不移动）
- 适用存储：顺序表（折半查找需随机访问）、链表（只能顺序查找）

## 类比 ★

### 一句话比喻
**插入排序就是打扑克时理牌——手里已经有了几张排好序的牌（比如 3、5、7），摸到一张 6，从右往左比：7 比 6 大，7 往后挪；5 比 6 小，停！把 6 插到 5 和 7 之间。最爽的是摸到的牌刚好比手里最大的还大——直接放最后，一趟搞定。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 当前处理元素 A[i] | 刚摸到手里的那张牌 |
| A[0]（哨兵） | 把这张牌先记在脑子里 |
| 内层 for 循环（右移） | 把比新牌大的牌都往右挪一格 |
| A[j+1] = A[0] | 把新牌放进挪出来的空位 |
| 最好情况（已有序） | 摸到的牌刚好比手里最大的还大——秒插 |
| 最坏情况（逆序） | 摸到的牌比手里最小的还小——全挪一遍 |
| 折半查找 | 从中间开始比，快速定位该插哪 |
