# 栈的顺序实现（Sequential Stack）

## 类型判定
程序型 — 栈的**顺序存储实现**，用静态数组 + 栈顶指针来实现栈的 `Push` / `Pop` 等操作。

## 是什么
用一个**静态数组** `data[MaxSize]` 存放栈中元素，用一个**整型变量 `top`** 作为栈顶指针（记录数组下标），实现 LIFO 操作。这种实现方式称为**顺序栈**。

## 输入-输出空间
- **初始化**：`top = -1`（top 指向栈顶元素）或 `top = 0`（top 指向下一插入位置）
- **Push(S, x)**：top++ → data[top] = x
- **Pop(S, &x)**：x = data[top] → top--
- **GetTop(S, &x)**：x = data[top]（top 不动）
- **前置条件**：栈不满（Push）、栈不空（Pop）

## 正例（≥2 个）
1. **初始化 top=-1**：top 指栈顶元素 → Push 用 `++top`，Pop 用 `top--`
2. **初始化 top=0**：top 指下一插入位置 → Push 用 `top++`，Pop 用 `--top`（与上面刚好相反）

## 反例/边界（≥1 个）
1. **`++top` 写成 `top++`**：Push 时若用 `top++` 会先把元素放入当前 top 位置（覆盖原栈顶），再让 top+1 → 数据错乱
2. **栈满后继续 Push**：静态数组容量固定，top == MaxSize-1 时再 Push 会溢出（上溢）

## 详细解释

### 结构体定义
```c
#define MaxSize 10
typedef struct {
    ElemType data[MaxSize];  // 静态数组存放元素
    int top;                  // 栈顶指针
} SqStack;                   // Sq = Sequence
```

### 两种 top 设计方案

| | 方案一：top 指向栈顶元素 | 方案二：top 指向下一插入位置 |
|---|---|---|
| **初始化** | `top = -1` | `top = 0` |
| **判空** | `top == -1` | `top == 0` |
| **判满** | `top == MaxSize - 1` | `top == MaxSize` |
| **进栈 Push** | `data[++top] = x` | `data[top++] = x` |
| **出栈 Pop** | `x = data[top--]` | `x = data[--top]` |

### 核心代码（方案一：top 指向栈顶元素）

```c
// 初始化
void InitStack(SqStack &S) {
    S.top = -1;
}

// 判空
bool StackEmpty(SqStack S) {
    return S.top == -1;
}

// 进栈
bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) return false;  // 栈满
    S.data[++S.top] = x;                      // 先 +1 再放入
    return true;
}

// 出栈
bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) return false;            // 栈空
    x = S.data[S.top--];                      // 先取值再 -1
    return true;
}

// 读栈顶
bool GetTop(SqStack S, ElemType &x) {
    if (S.top == -1) return false;
    x = S.data[S.top];
    return true;
}
```

### 共享栈
两个栈共享同一片存储空间，从两端向中间生长：
- 0 号栈：`top0 = -1`，从下往上增长
- 1 号栈：`top1 = MaxSize`，从上往下增长
- **判满**：`top0 + 1 == top1`

### 时间复杂度

| 操作 | 复杂度 |
|------|--------|
| Push | $O(1)$ |
| Pop | $O(1)$ |
| GetTop | $O(1)$ |
| 判空/判满 | $O(1)$ |

## 类比

### 一句话比喻
**顺序栈就像酒店门前的固定车位带——总共 10 个位置（MaxSize），停一辆进去，车位号就 +1（Push）；开走一辆，车位号就 -1（Pop）。满了？对不起，谢绝入内。车位号错了（++top 写成 top++）？那你的车直接砸在前一辆车上了。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| `data[MaxSize]` | 10 个固定停车位，一字排开 |
| `top` | 车位号牌——告诉你下一辆该停哪儿 |
| `++top`（先移再放） | 先把"空位"牌子挪一格，再停车 |
| `top++`（先放再移） | 先把车停在当前位置（压到别人的车），再挪牌子 |
| 栈满 `top==MaxSize-1` | 停车场爆满，门口立牌"车位已满" |
| 出栈（仅逻辑删除） | 车开走了，但轮胎印还在——数据残留，但 top 已下移 |
| 共享栈 | 一个停车场两头都能进：A 区从东进，B 区从西进 |
