# 图（Graph）

## 类型判定
判别型 — 图是「多对多」关系的逻辑结构，区分于线性表（一对一）和树（一对多）。`is_a` 数据结构三要素之逻辑结构。

## 是什么
图 $G$ 由**顶点集 $V$** 和**边集 $E$** 组成，记为 $G = (V, E)$。

三个关键约束：
- **$V$ 非空**：图不可以是空图（顶点集必须有元素），但 $E$ 可以为空
- **边必须两端有顶点**：任何一条边连接的 $u, v$ 必须在 $V$ 中
- **数据结构课只讨论简单图**：无重复边、无顶点到自身的边

## 输入-输出空间
- **输入**：无（逻辑结构，不涉及输入输出）
- **输出**：无
- **核心约束**：顶点间多对多关系，通过边连接

## 正例（≥2 个）
1. **铁路网络**：各车站 = 顶点，铁路线路 = 边 → 无向图
2. **微信好友关系**：每个用户 = 顶点，加好友 = 无向边（互加才能聊）→ 无向图
3. **微博粉丝关系**：每个用户 = 顶点，A 关注 B = 有向边（A→B）→ 有向图

## 反例/边界（≥1 个）
1. **边悬空**：一条边的某一端没有连接任何顶点 → 不符合图的定义，不是图
2. **空图**：$V = \emptyset$ → 图不允许为空，顶点集必须非空

## 详细解释

### 图的分类
| 类型 | 边的方向 | 表示法 | 示例 |
|------|----------|--------|------|
| 无向图 | 无方向 | $(u, v)$ 圆括号 | 微信好友 |
| 有向图 | 有方向（弧） | $\langle u, v \rangle$ 尖括号 | 微博关注 |

- **弧尾**：无箭头端；**弧头**：有箭头端
- $\langle A, B \rangle \neq \langle B, A \rangle$（方向相反的两条弧）

### 核心术语速查

**顶点相关**：
- **度 $TD(v)$**（无向图）：依附于该顶点的边数
- **入度 $ID(v)$**（有向图）：箭头指向该顶点的弧数
- **出度 $OD(v)$**（有向图）：从该顶点射出的弧数
- **度 $TD(v) = ID(v) + OD(v)$**（有向图）
- **重要公式**：无向图 $\sum TD = 2|E|$；有向图 $\sum ID = \sum OD = |E|$

**连通性**：
- **路径**：顶点序列 $v_1 \to v_2 \to \cdots \to v_k$
- **回路/环**：起点 = 终点的路径
- **简单路径**：顶点不重复的路径
- **路径长度**：路径上边的条数
- **距离**：两顶点间最短路径的长度（无路径则 $\infty$）
- **连通**（无向图）：两顶点间存在路径
- **强连通**（有向图）：两顶点间既有正向路径也有逆向路径

**图的整体性质**：
| 概念 | 适用 | 含义 |
|------|------|------|
| 连通图 | 无向图 | 任意两顶点连通 |
| 强连通图 | 有向图 | 任意两顶点强连通 |
| 连通分量 | 无向图 | 极大连通子图 |
| 强连通分量 | 有向图 | 极大强连通子图 |
| 生成树 | 连通无向图 | 包含全部顶点的极小连通子图（$n$ 个顶点 $n-1$ 条边） |
| 生成森林 | 非连通无向图 | 各连通分量的生成树集合 |

**考点**：
- $n$ 个顶点的连通图最少 $n-1$ 条边
- $n$ 个顶点的强连通图最少 $n$ 条边（形成回路）
- $n$ 个顶点的无向完全图最多 $C_n^2$ 条边
- $n$ 个顶点的有向完全图最多 $2 \times C_n^2$ 条边

**带权图（网）**：
- 每条边赋予权值 → 带权图/网
- **带权路径长度**：路径上各边权值之和

**特殊形态**：
- **树**（无向）：连通 + 无回路 → $n$ 个顶点 $n-1$ 条边
- **有向树**：一个顶点入度为 0（根），其余入度均为 1
- **稀疏图 vs 稠密图**：$|E| < |V|\log|V|$ 视为稀疏（相对概念）

## 类比

### 一句话比喻
**图就像城市的交通地图——每个路口是顶点，每条道路是边。单向道是有向边（只能顺箭头走），双向道是无向边（来回都行）。你从家到公司可以走多条路线，每条路线由一连串的路段组成——这就是路径。一个城市如果从任意路口都能到达任意其他路口，这个城市的道路网就是连通图。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 顶点（Vertex） | 城市/路口/人 |
| 边（Edge） | 道路/好友关系 |
| 有向边（Arc） | 单行道 / 微博关注 |
| 无向边 | 双行道 / 微信好友 |
| 权值（Weight） | 距离（km）/ 时间（min）/ 花费 |
| 度（Degree） | 与一个城市直接相连的道路数 |
| 路径 | 一次完整的行车路线 |
| 路径长度 | 这段路经过了几条路段 |
| 距离 | 最短路线经过了几段路 |
| 连通 | 从 A 城能开车到 B 城 |
| 连通分量 | 海南岛的路网（与大陆不通） |
| 生成树 | 用最少的道路把所有村子连起来的修路方案 |
| 完全图 | 每个城市之间都修了直达高速 |
