# 栈在括号匹配中的应用

## 类型判定
程序型 — 栈的经典应用算法，「左括号入栈、右括号出栈匹配」的线性扫描流程。

## 是什么
给定一个包含 `(){}[]` 的括号序列，判断括号是否合法配对。算法：**从左往右扫描**，遇到左括号入栈，遇到右括号则弹出栈顶左括号，检查是否类型匹配。最后栈空才匹配成功。

## 输入-输出空间
- **输入**：字符数组 `str[]`，长度 `length`
- **输出**：`bool` — 匹配成功/失败
- **失败条件**：① 右括号单身（遇到右括号但栈空）；② 类型不匹配（`(` vs `]`）；③ 左括号单身（扫描完栈非空）

## 正例（≥2 个）
1. **`((()))`**：左右一一匹配，扫描完栈空 → 成功
2. **`{[()]}`**：不同类型嵌套匹配，同样成功

## 反例/边界（≥1 个）
1. **`([)]`**：第三个字符 `)` 弹出栈顶 `[` → 类型不匹配 → 失败
2. **`(()`**：扫描完栈里还剩一个 `(` → 左括号单身 → 失败
3. **`())`**：第二个 `)` 遇到时栈已空 → 右括号单身 → 失败

## 详细解释

### 算法流程

```
从左往右扫描每个字符 ch：
  if ch 是左括号：
      Push(ch)
  else if ch 是右括号：
      if 栈空： return false (右括号单身)
      弹出栈顶 top
      if ch 和 top 不匹配： return false (类型不匹配)

扫描结束后：
  if 栈非空： return false (左括号单身)
  else： return true
```

### 核心代码

```c
bool BracketCheck(char str[], int length) {
    SqStack S;
    InitStack(S);

    for (int i = 0; i < length; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{') {
            Push(S, str[i]);                      // 左括号入栈
        } else {
            if (StackEmpty(S)) return false;      // 右括号单身

            char topElem;
            Pop(S, topElem);                      // 弹出栈顶

            if (str[i] == ')' && topElem != '(') return false;
            if (str[i] == ']' && topElem != '[') return false;
            if (str[i] == '}' && topElem != '{') return false;
        }
    }
    return StackEmpty(S);                         // 左括号单身检查
}
```

### 为什么用栈？

越晚出现的左括号，越先被匹配——这正是 LIFO 特性。扫描到右括号时，它要匹配的正是**最近出现的、尚未被匹配的**左括号。

### 关键注意事项
- 栈可能溢出：若括号序列很长，顺序栈可能满 → 实际开发建议用链栈
- IDE 的括号匹配高亮、编译器的语法检查，底层用的就是这个算法

### 时间复杂度
| 情况 | 复杂度 |
|------|--------|
| 最好（一上来就不匹配） | $O(1)$ |
| 最坏 | $O(n)$ |
| 平均 | $O(n)$ |

空间复杂度：$O(n)$（栈的深度）

## 类比

### 一句话比喻
**括号匹配就像检查你家所有打开的柜门是否都关上了——你从左往右巡视房间（扫描），看到柜门开着（左括号）就记在小本本上（入栈），看到一个柜门关着（右括号）就翻小本本看最近开的是哪个柜门，对不上号就报错。巡视完毕如果小本本上还记着没关的柜门——完蛋，有门忘了关。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 左括号 `({[` | 打开的柜门——得记住开了哪些 |
| 右括号 `)}]` | 关上的柜门——得核对关的是不是对的 |
| Push 入栈 | 在小本本上写"客厅柜子开了" |
| Pop 出栈 | 划掉小本本上最近写的那条 |
| 右括号单身（栈空） | 明明没开柜门，却看到一扇门关上了——闹鬼了 |
| 左括号单身（扫完栈非空） | 巡视完发现小本本上还有记录——有门忘了关 |
| 类型不匹配 | 关的是厨房柜门，本子上记的却是"客厅柜子"——对不上 |
| 栈的 LIFO | 越晚打开的门越早被关上——后开的先关 |
