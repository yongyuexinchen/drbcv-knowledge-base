# 算法（Algorithm）

## 类型判定
判别型 — 算法的定义、五特性和四特质是408选择题的高频考点，也是后续所有算法分析的概念基础。

## 是什么
**算法是对特定问题求解步骤的一种描述，它是指令的有限序列，其中每条指令表示一个或多个操作。** 说白了：数据结构是「食材」，算法是「菜谱」——描述怎么一步步处理这些食材。程序 = 数据结构 + 算法。

## 输入-输出空间
- **输入**：0 个或多个（来自某个数据对象的特定集合）
- **输出**：1 个或多个（与输入有特定关系）
- **本质**：算法就是一个「映射函数」—— $y = f(x)$，x 是输入，f 是处理步骤，y 是输出

## 正例（≥2 个）
1. **番茄炒蛋算法**：输入：鸡蛋4个、西红柿2个… → 步骤①西红柿切块 ②鸡蛋打匀 ③炒蛋 ④加西红柿翻炒 → 输出：一盘番茄炒蛋
2. **年龄排序算法**：输入：5个人的年龄数据 → 步骤①扫描所有人找最小年龄放第1位 ②扫描剩余4人找最小年龄放第2位… → 输出：按年龄递增排列的结果

## 反例/边界（≥1 个）
1. **微信不是一个算法**：微信可以一直运行下去永不停止 → 算法必须有穷（在有限步内结束），而微信是「程序」（可无穷运行）→ 程序 ≠ 算法
2. **死循环不是算法**：`while(true){}` 永远不终止 → 不满足有穷性 → 不是算法
3. **含有歧义的步骤描述不是算法**：如果排序时说「扫描剩下的元素找到年龄最小的那个」——当两人年龄相同时（如两个49岁），没规定谁排前面 → 不满足确定性 → 严格说不是算法

## 详细解释

### 算法的五大必备特性（缺一不可）

| 特性 | 含义 | 不满足的例子 |
|------|------|------------|
| **有穷性** | 必须在执行有穷步后结束，每步在有穷时间内完成 | 死循环、微信（一直运行） |
| **确定性** | 每条指令必须有明确的含义；相同输入 → 相同输出 | 「找最小的那个」——两人年龄相同时不确定谁排前面 |
| **可行性** | 能用代码实现（C语言/Java等） | 「把所有的素数都找出来」——集合无限，不可行 |
| **输入** | 0个或多个输入，取自特定数据对象 | Hello World 就是0个输入 |
| **输出** | 至少1个输出，与输入有特定关系 | 不能没有任何输出结果 |

### 好算法的四大特质（精益求精）

| 特质 | 含义 | 反面教材 |
|------|------|---------|
| **正确性** | 能正确解决问题 | 排序后年轻的人排到后面去了 |
| **可读性** | 代码好懂，有注释，团队可协作 | 「这谁写的 shit，我自己也看不懂」 |
| **健壮性** | 对非法输入能做出反应（报错/处理），不死机不崩 | 来了个年龄=-100岁的，算法视而不见将错就错 |
| **高效率 + 低存储** | 时间开销少、内存占用小 | 用 $O(n^2)$ 算法处理几十万用户 → 线上崩了 |

> 最后一个特质「高效率 + 低存储」就是**时间复杂度**和**空间复杂度**要解决的问题——接下来两小节的核心内容。

### 算法与程序的关系
- 算法 = 解决问题的**思想/步骤**（必须是有穷的）
- 程序 = 算法用某一种编程语言的**具体实现**（可以是无穷的）
- **程序 = 数据结构 + 算法**（经典公式）

### 算法描述方式
1. **自然语言**：容易有歧义（「找最小的」不精确）
2. **伪代码**：介于自然语言和代码之间，适合教材讲解
3. **程序代码**：用 C/Java/Python 等实现，无歧义

## 类比

### 一句话比喻
**算法就像你的外卖骑手路线——如果他先把餐全接了再挨家送一遍（$O(n)$），那是正常的。但如果你发现他每送一单前都要回一次商家确认餐还在不在（$O(n^2)$），那你在家等着吃夜宵吧，夜宵变早饭。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 算法步骤 | 菜谱里的步骤①→②→③ |
| 数据结构 | 食材（鸡蛋、西红柿、油盐…） |
| 输入 | 食材 + 调料 |
| 输出 | 一盘番茄炒蛋 |
| 有穷性 | 菜谱步骤有限，做完就结束（不可能一直炒下去） |
| 确定性 | 「盐少许」不精确 → 「盐3克」才精确 |
| 可行性 | 你可以实际照做 → 如果步骤里写「用意念加热」，那就不可行 |
| 健壮性 | 食材少了鸡蛋？（算法检测到并报错：「鸡蛋数量不足！」）而不是继续硬炒 |
| 高效率和低存储 | 你能用1个锅10分钟做完 vs 用5个锅2小时做完 |
| 正确性 | 端上来确实是番茄炒蛋，不是黑暗料理 |
