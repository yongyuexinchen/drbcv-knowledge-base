# 特殊矩阵的压缩存储

## 类型判定
程序型 — 将多种特殊矩阵（对称 / 三角 / 三对角 / 稀疏）压缩到一维数组的策略与**下标映射公式**，核心是「给定矩阵行列号 i,j → 算出在一维数组中的下标 k」。

## 是什么
对于元素有规律可循的矩阵，不必存储全部 $n^2$ 个元素，而是利用对称性、三角恒定性或稀疏性，**只存储必要元素**到一个一维数组中，并通过**映射函数**实现随机存取。

## 输入-输出空间
- **输入**：矩阵行列号 `(i, j)`，矩阵阶数 `n`
- **输出**：一维数组下标 `k`（从 0 或 1 开始）
- **前置条件**：$1 \le i, j \le n$（矩阵行列号通常从 1 开始）；需明确数组下标起始值（0 还是 1）和存储策略（行优先/列优先、存上三角/下三角）

## 正例（≥2 个）
1. **对称矩阵，行优先存下三角**：$n=4$，元素 $a_{32}$（i=3, j=2, i≥j）→ $k = \frac{3\times 2}{2} + 2 - 1 = 4$（数组下标从0起）
2. **稀疏矩阵用三元组**：存 `(行, 列, 值)` 的列表，只存非零元素

## 反例/边界（≥1 个）
1. **对称矩阵访问上三角时忘了转置**：$a_{23}$ 在上三角区（i<j），应映射到 $a_{32}$（下三角区）的位置去找 → 直接套公式会取到错误位置
2. **三对角矩阵中 i 和 j 差值的绝对值 > 1**：该位置必为 0，不必去一维数组里找——直接返回 0

## 详细解释

### 矩阵存储的基本策略

二维数组在内存中拉成一维存放，有两种方式：
- **行优先**：一行一行存，`LOC(a_ij) = LOC(a_00) + (i×n + j) × size`
- **列优先**：一列一列存，`LOC(a_ij) = LOC(a_00) + (j×m + i) × size`

### 对称矩阵的压缩存储

特点：$a_{ij} = a_{ji}$，$n×n$ 方阵。

**策略**：只存主对角线 + 下三角区（或上三角区）。

**存储元素个数**：$\frac{n(n+1)}{2}$

**下标映射公式**（行优先，存下三角，数组下标 k 从 0 开始）：

$$k = \begin{cases} \frac{i(i-1)}{2} + j - 1, & i \ge j \text{（下三角区+主对角线）} \\ \frac{j(j-1)}{2} + i - 1, & i < j \text{（上三角区，转置到 a_ji）} \end{cases}$$

**推导**：$a_{ij}$ 前面有前 $i-1$ 行的元素：$1 + 2 + \cdots + (i-1) = \frac{i(i-1)}{2}$，加上本行前 $j-1$ 个 = $\frac{i(i-1)}{2} + j$，再减 1 得到数组下标。

### 三角矩阵的压缩存储

**下三角矩阵**：下三角区非恒定，上三角区全为同一常量 C。
- 存储元素个数：$\frac{n(n+1)}{2} + 1$（多一个存常量）
- i≥j 时用对称矩阵公式；i<j 时直接返回常量位置 $k = \frac{n(n+1)}{2}$

**上三角矩阵**：上三角区非恒定，下三角区全为常量。
- 类推，需要重新推导行优先公式

### 三对角矩阵（带状矩阵）

特点：$|i-j| > 1$ 时 $a_{ij} = 0$。每行最多 3 个非零元素（除首尾行 2 个）。

**存储元素个数**：$3n - 2$

**下标映射公式**（行优先，数组下标 k 从 0 开始，$|i-j| \le 1$）：

$$k = 2i + j - 3$$

推导：前 $i-1$ 行共 $3(i-1)-1$ 个元素，本行 $a_{ij}$ 是第 $j-i+2$ 个 → $k = 3(i-1)-1 + (j-i+2) - 1 = 2i+j-3$

**从 k 反推行列号**：$i = \lfloor (k+1)/3 \rfloor + 1$，$j = k - 2i + 3$

### 稀疏矩阵的压缩存储

特点：非零元素个数远少于总数。

**方法一：三元组顺序表**
```c
typedef struct {
    int i, j;      // 行号、列号
    ElemType v;    // 值
} Triple;
Triple data[MAXSIZE];  // 按行优先存
```
缺点：失去随机存取特性，访问某个位置需遍历。

**方法二：十字链表法**
每个非零结点含 `(行, 列, 值)` + 向右指针（同行下一非零）+ 向下指针（同列下一非零），外加行/列头指针数组。

### 四种矩阵对比

| 矩阵类型 | 压缩后大小 | 映射公式复杂程度 | 是否保留随机存取 |
|----------|----------|----------------|----------------|
| 对称矩阵 | $\frac{n(n+1)}{2}$ | ★★ | 是（公式 $O(1)$） |
| 三角矩阵 | $\frac{n(n+1)}{2}+1$ | ★★ | 是 |
| 三对角矩阵 | $3n-2$ | ★★★ | 是 |
| 稀疏矩阵（三元组） | 非零元个数 × 3 | ★ | **否**（需遍历） |

### 时间复杂度

| 操作 | 对称/三角/三对角 | 稀疏（三元组） |
|------|:---:|:---:|
| 随机访问 $a_{ij}$ | $O(1)$（公式） | $O(t)$（t = 非零元个数） |
| 获取全矩阵 | $O(n^2)$ | $O(n^2)$ |

## 类比

### 一句话比喻
**矩阵压缩存储就像整理衣柜——对称矩阵 = 你的袜子都是成对的（左=右），只放一只，拿的时候翻面就是另一只。三角矩阵 = 一堆 T 恤全是黑色（常量），不用每件都叠，叠一件贴上"此处全是黑色T恤"的标签就行。三对角矩阵 = 你的鞋架每层只放 3 双，旁边全是空位不用管。稀疏矩阵 = 一本 1000 页的字典里只有 5 个词——直接撕下那 5 页做成小卡片（三元组），比抱着字典走省力多了。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 对称矩阵 $a_{ij}=a_{ji}$ | 镜子——看左边和看右边是一个东西 |
| 上三角区转置访问 | 柜子太高够不着，拿个镜子反射一下从下面看 |
| 三角矩阵常量区 | 一整面墙刷了同色油漆——记一次"这面墙是白色"就够了 |
| 三对角矩阵非零带 | 三条车道的高速公路——只有这三条上有车，路肩全空 |
| 稀疏矩阵三元组 | 空白卷子上只有 3 处写了字——拿张便签记下(行,列,答案) |
| 十字链表法 | 地铁换乘图——每个站（非零元素）知道自己横向和纵向的下一站在哪 |
| 行优先 vs 列优先 | 读书习惯：中国人一行行读（行优先），古书竖排一列列读（列优先） |
