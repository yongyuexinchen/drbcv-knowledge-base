# 单链表的建立

## 类型判定
程序型 — 具体的算法操作步骤，含代码和复杂度分析。分为尾插法和头插法两种策略，头插法具有「逆置」特性，是考研高频考点。

## 是什么
给定 $n$ 个数据元素，逐个插入到单链表中，构建一个完整的单链表。两种策略：
- **尾插法**：每次插入到表尾 → 元素顺序与输入顺序一致
- **头插法**：每次插入到表头（头结点之后） → 元素顺序与输入顺序**相反**（逆置）

## 输入-输出空间
- **输入**：$n$ 个数据元素（如从键盘读取整数，以 9999 结束）
- **输出**：带头结点的单链表 L
- **前置条件**：链表已初始化（头结点已分配，`L->next = NULL`）

## 正例（≥2 个）
1. **尾插法输入 10, 16, 27** → 链表：10 → 16 → 27（顺序一致）
2. **头插法输入 10, 16, 27** → 链表：27 → 16 → 10（顺序相反，天然逆置）

## 反例/边界（≥1 个）
1. **尾插法每次从头遍历**：如果每次 `ListInsert(&L, length+1, e)`，则每次插入都从表头走到表尾 → 总时间复杂度 $O(n^2)$，非常低效。正确做法是维护尾指针 $r$，$O(n)$。
2. **忘记初始化 `L->next = NULL`**：头结点的 next 可能指向脏数据，导致后续指针操作出错。

## 详细解释

### 核心代码：尾插法（$O(n)$）

```c
LinkList List_TailInsert(LinkList &L) {
    int x;                           // 暂存输入值
    L = (LinkList)malloc(sizeof(LNode));  // 初始化：创建头结点
    L->next = NULL;                  // 必须初始化！防止脏数据

    LNode *s, *r = L;                // r 始终指向表尾结点
    scanf("%d", &x);                 // 读取第一个元素

    while (x != 9999) {              // 9999 作为结束标志
        s = (LNode *)malloc(sizeof(LNode));  // ① 创建新结点
        s->data = x;                 // ② 填充数据
        r->next = s;                 // ③ 表尾结点指向新结点
        r = s;                       // ④ r 移到新表尾
        scanf("%d", &x);
    }
    r->next = NULL;                  // 表尾置空
    return L;
}
```

**关键技巧**：维护尾指针 `r`，每次在 $r$ 之后插入新结点，再将 $r$ 后移。**没有尾指针的尾插法是 $O(n^2)$，考场大忌！**

### 核心代码：头插法（$O(n)$，天然逆置）

```c
LinkList List_HeadInsert(LinkList &L) {
    LNode *s;
    int x;
    L = (LinkList)malloc(sizeof(LNode));  // 创建头结点
    L->next = NULL;                  // 必须初始化！

    scanf("%d", &x);
    while (x != 9999) {
        s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;           // ① 新结点指向原首结点
        L->next = s;                 // ② 头结点指向新结点
        scanf("%d", &x);
    }
    return L;
}
```

### 头插法 = 链表的逆置

头插法的核心价值在于**逆置**：
- 给定一个已存在的链表 L，遍历 L 中的每个结点，依次用头插法插入到一个新链表 → 新链表是 L 的逆序
- 也可以原地逆置：依次摘下结点，重新头插入原链表

```c
// 原地逆置单链表
void Reverse(LinkList &L) {
    LNode *p = L->next;              // p 指向第一个数据结点
    LNode *q;
    L->next = NULL;                  // 断开，重新做头插
    while (p != NULL) {
        q = p->next;                 // 暂存后继
        p->next = L->next;           // 头插
        L->next = p;
        p = q;                       // 处理下一个
    }
}
```

### 时间复杂度

| 方法 | 每插入一个 | 总复杂度 | 关键 |
|------|-----------|---------|------|
| 尾插法（有尾指针） | $O(1)$ | $O(n)$ | 维护尾指针 r |
| 尾插法（无尾指针） | $O(k)$ | $O(n^2)$ | ❌ 每次从头遍历到表尾 |
| 头插法 | $O(1)$ | $O(n)$ | 始终对头结点后插 |

## 类比

### 一句话比喻
**尾插法就像排队买奶茶——新来的人老老实实排在队伍最后面，先来的人先买到（先进先出）。头插法就像食堂打饭时不断有人插队到最前面——最后一个来的人反而排到了第一个，整个队伍完全颠倒。头插法的逆置效果就跟你把一排人倒过来重新排一模一样。**

### 生活映射
| 代码世界 | 排队现场 |
|---|---|
| 尾插法 + 尾指针 r | 队尾有个引导员，新来的人直接找他就行 |
| 头插法 `s->next = L->next` | 新人直接挤到队伍最前面，拉住原来的第一个人 |
| 头插法形成逆序 | 一队人反过来排，最后一个变第一个 |
| 尾插法无尾指针 → $O(n^2)$ | 每次新人来都从队头走到队尾找位置 |
| `L->next = NULL` 初始化 | 确保队伍是干净的，没有"幽灵人" |
| 9999 结束标志 | 排队截止时间到了，关门 |
