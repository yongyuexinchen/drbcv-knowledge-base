# 最佳归并树（Optimal Merge Tree）

## 类型判定
程序型 — 外部排序中用于确定**最优归并顺序**的算法，本质是构造一棵带权路径长度最小的**K叉哈夫曼树**，使磁盘 I/O 次数最少。

## 是什么
已知 R 个初始归并段，每段长度（磁盘块数）不同。归并过程形成一棵归并树：叶子结点为初始段（权值 = 段长），非叶结点为一次归并的结果。**磁盘 I/O 总次数 = 2 × 归并树的带权路径长度 (WPL)**。因此，构造 WPL 最小的归并树 = 磁盘 I/O 最少 → **最佳归并树**。

- 二路归并 → 最佳归并树 = **哈夫曼树**
- K 路归并 → 最佳归并树 = **K 叉哈夫曼树**

## 输入-输出空间
- **输入**：R 个初始归并段的长度（各占几个磁盘块）
- **输出**：最优的归并顺序（树的形态）
- **前置条件**：可能需要补充长度为零的"虚段"

## 正例（≥2 个）
1. **二路归并**：5个段长 `[2, 5, 1, 6, 2]` → 构造哈夫曼树 → WPL=34 → I/O=68次（vs 不优化的88次）
2. **三路归并需补虚段**：8个段 → 8-1=7, 对 K-1=2 取余得 1 → 补 2-1=1 个虚段 → 再构造三叉哈夫曼树

## 反例/边界（≥1 个）
1. **不补虚段导致非严格 K 叉树**：最后一趟可能变成二路归并而非三路 → 不是最优 → I/O 次数更多
2. **K=2 时永远不需补虚段**：二路归并中 n0 个叶子总是能构成严格二叉树

## 详细解释

### 构造方法（K 叉哈夫曼树）
1. **判断是否需要补虚段**：
   - 若 $(n_0 - 1) \bmod (K - 1) = 0$ → 不需补
   - 若 $(n_0 - 1) \bmod (K - 1) = u \neq 0$ → 补 $(K-1) - u$ 个长度为 0 的虚段

2. **构造 K 叉哈夫曼树**：
   - 每次选取 K 棵根结点权值最小的树，合并为一棵新树（新根权值 = K 个子树权值之和）
   - 重复直到只剩一棵树

### 为什么 WPL = 磁盘 I/O 次数？
每个叶子结点的 WPL = 权值 × 到根的距离。权值 = 该段磁盘块数，到根的距离 = 该段数据被读写的总次数（每次归并都读一次写一次）。因此 WPL = 读次数 = 写次数，总 I/O = 2 × WPL。

### 虚段的含义
长度为 0 的归并段 → 对应的输入缓冲区为空 → 相当于该路已归并完。补虚段纯粹是为了凑出严格 K 叉树。

### 示例：三路归并，需补几个虚段？
- 19 个段，K=8（八路归并）：$(19-1) \bmod 7 = 18 \bmod 7 = 4 \neq 0$ → 补 $7-4=3$ 个虚段
- 8 个段，K=3（三路归并）：$(8-1) \bmod 2 = 7 \bmod 2 = 1 \neq 0$ → 补 $2-1=1$ 个虚段

### 时间复杂度
- 构造 K 叉哈夫曼树：可用堆实现，$O(R \log R)$
- 磁盘 I/O 减少效果显著

## 类比 ★

### 一句话比喻
**最佳归并树就像搬家时决定先合并哪几堆东西——各堆大小不一样（有的5箱、有的1箱），如果把最大的堆留到最后搬（让它参与最多次的合并搬运），那它就要被搬来搬去好多次。哈夫曼树告诉你：最小的两堆先合并！这样最重的堆参与搬运的次数最少，总搬运量最小。如果堆数不能刚好分成每次 K 堆一组合并，就加几个"空箱子"（虚段）凑数。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 叶子结点权值（段长） | 每堆的箱子数 |
| 归并 = 合并两堆 | 把两堆东西搬到一起重新整理 |
| 带权路径长度 WPL | 每个箱子被搬运的总次数 |
| 哈夫曼树规则 | 最小的两堆先合并！ |
| 虚段 | 加几个空箱子凑数——不需要真搬 |
| 严格 K 叉树 | 每次必须刚好 K 堆合并 |
| 补虚段公式 | $(n_0-1) \bmod (K-1) = 0$ → 刚好凑齐 |
