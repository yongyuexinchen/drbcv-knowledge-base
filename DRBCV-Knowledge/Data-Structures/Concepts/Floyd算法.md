# Floyd算法（弗洛伊德）

## 类型判定
程序型 — 带权图**多源最短路径**（每一对顶点之间的最短路径），动态规划思想。代码极简洁（6 行核心代码），时间复杂度 $O(|V|^3)$。

## 是什么
求**所有顶点对**之间的最短路径。核心思想：逐步允许更多中间顶点——从「不允许任何中转」到「允许 $v_0, v_1, \ldots, v_{n-1}$ 依次作为中转」，每个阶段基于上一阶段的最优解递推。

## 输入-输出空间
- **输入**：带权图 $G$（邻接矩阵形式）
- **输出**：`A[i][j]` = 顶点 $i$ 到 $j$ 的最短路径长度；`path[i][j]` = 最短路径上 $i$ 和 $j$ 之间的中转点
- **限制**：❌ 不能处理负权回路（负权值边组成的环）

## 正例（≥2 个）
1. **全国城市间最短路线表**：计算所有城市两两之间的最短距离，Floyd 一步到位
2. **处理负权值边**：Floyd 可以处理负权边（Dijkstra 不行），只要不存在负权回路

## 反例/边界（≥1 个）
1. **负权回路**：图中存在一个环，环的总权值为负 → 每多绕一圈路径更短，不存在「最短」→ 算法失效

## 详细解释

### 核心代码（仅 6 行！）
```c
// 初始化：A = 邻接矩阵, path = 全部 -1
for (int k = 0; k < n; k++)           // 逐步允许以 v_k 为中转点
    for (int i = 0; i < n; i++)       // 起点
        for (int j = 0; j < n; j++)   // 终点
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;       // 记录中转点
            }
```

### 动态规划递推公式
$$A^{(k)}[i][j] = \min\left(A^{(k-1)}[i][j],\; A^{(k-1)}[i][k] + A^{(k-1)}[k][j]\right)$$

- $A^{(-1)}$：初始状态 = 邻接矩阵（不允许任何中转）
- $A^{(0)}$：允许以 $v_0$ 为中转
- $A^{(1)}$：允许以 $v_0, v_1$ 为中转
- …
- $A^{(n-1)}$：最终结果

### 回溯完整路径
```c
// 递归找 i 到 j 的完整路径
void FindPath(int i, int j) {
    if (path[i][j] == -1) {
        // 无中转点，直接输出 i→j
    } else {
        int k = path[i][j];
        FindPath(i, k);  // i → k
        printf("→%d", k);
        FindPath(k, j);  // k → j
    }
}
```

### 复杂度
| 指标 | 值 |
|------|-----|
| 时间复杂度 | $O(|V|^3)$ |
| 空间复杂度 | $O(|V|^2)$（两个 $n\times n$ 矩阵） |

### 与 Dijkstra 对比
|                | Dijkstra | Floyd        |          |     |     |      |
| -------------- | -------- | ------------ | -------- | --- | --- | ---- |
| 问题             | 单源最短路径   | 所有顶点对最短路径    |          |     |     |      |
| 策略             | 贪心       | 动态规划         |          |     |     |      |
| 负权边            | ❌ 失效     | ✅ 可用（无负权回路时） |          |     |     |      |
| 负权回路           | ❌        | ❌            |          |     |     |      |
| 时间复杂度          | $O(      | V            | ^2)$     | $O( | V   | ^3)$ |
| 做 N 次 Dijkstra | $O(      | V            | ^3)$（等价） | $O( | V   | ^3)$ |

### 考点提示
- Floyd 手动模拟通常只考 3~4 阶矩阵
- 考试核心：会迭代填表，会回溯路径

## 类比

### 一句话比喻
**Floyd 算法就像计算全国所有城市之间的最短航线。第一轮：「只允许在北京中转，哪些航线可以缩短？」第二轮：「北京和上海都可以中转……」，第三轮、第四轮……每轮多开放一个中转城市。经过 N 轮，你就得到了全国所有城市之间的最短航线表——而且所有算出来的距离都是「可以经过任意城市中转」后的最优结果。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| $A[i][j]$ | 城市 i 到城市 j 的最短航线距离 |
| $path[i][j] = k$ | i 到 j 需要经过中转城市 k |
| 外层 $k$ 循环 | 第 k 轮：现在开放第 k 个城市作为中转 |
| `A[i][k] + A[k][j] < A[i][j]` | 经停 k 会不会比直飞更近？ |
| 三重循环 | 穷举所有起点-中转-终点组合 |
| $O(|V|^3)$ | 300 个城市 → 2700 万次比较 |
| 负权回路 | 一个无限白嫖的闭环航线 → 越飞越便宜 → 不存在最短 |
| 回溯路径 | 航班经停信息 → 还原完整飞行路线 |
