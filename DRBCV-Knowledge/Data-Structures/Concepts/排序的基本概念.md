# 排序的基本概念（Sorting）

## 类型判定
判别型 — 排序是所有排序算法的前置概念，定义排序是什么、分类方式、以及评判排序算法的三个核心指标（时间复杂度、空间复杂度、稳定性）。

## 是什么
排序就是将一组数据元素按照**关键字**递增或递减的顺序重新排列，最终保证所有关键字有序。评判一个排序算法好坏的三大指标：**时间复杂度**、**空间复杂度**、**稳定性**。

排序算法分为两大类：
- **内部排序**：所有数据都能一次性放入内存，关注时间/空间复杂度
- **外部排序**：数据量大到无法全部放入内存（如超大文件），还需关注**读写磁盘次数**（内存读写~60GB/s vs 机械硬盘~100MB/s，差600倍）

## 输入-输出空间
- **输入**：n 个待排序记录（含关键字）
- **输出**：按关键字有序排列的 n 个记录
- **核心概念**：稳定性、内部/外部排序

## 正例（≥2 个）
1. **王者荣耀排行榜**：按荣耀战力排序，战力高的排前面——可能出现两个玩家战力相同的情况（稳定性问题由此产生）
2. **富豪榜**：按个人财富值排序，2019年国内前十有五个是互联网创始人

## 反例/边界（≥1 个）
1. **稳定性不是绝对的优点**：如果场景中所有关键字都不重复，稳定和不稳定算法结果完全一样；如果场景不关心相同关键字的相对顺序，选不稳定算法也完全OK——不能一概而论"稳定的更好"

## 详细解释

### 稳定性（Stability）
关键字相同的元素，排序后它们的**相对位置保持不变** → 稳定；否则 → 不稳定。考试中选择题高频考点。

例：原始序列 `[3₁, 3₂]`（下标区分两个相同的3），排序后：
- 稳定：`[3₁, 3₂]` ✓
- 不稳定：`[3₂, 3₁]` ✗

### 内部排序 vs 外部排序
| | 内部排序 | 外部排序 |
|---|---|---|
| 数据位置 | 全在内存 | 在磁盘，分批读入 |
| 瓶颈 | CPU计算 | 磁盘I/O |
| 关注点 | 时间/空间复杂度 | 读写磁盘次数 + 时间/空间 |
| 本章比重 | 8.2~8.5 | 8.7 |

内存读写 60GB/s，机械硬盘 100MB/s —— 差约600倍，所以外部排序要把"减少磁盘读写次数"作为核心优化目标。

## 类比 ★

### 一句话比喻
**排序就像给一沓考试卷按分数从高到低排好——你可以一张张比对着排（插入排序），也可以先按及格线分成两摞再各自排（快速排序），但如果卷子多到桌子放不下（外部排序），就只能一摞一摞搬进来排好再搬出去。至于稳不稳定？看你对同分的人——是按原座次保持先后，还是不管三七二十一乱塞。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 排序 | 给考试卷按分数排好 |
| 关键字（key） | 考试分数 |
| 稳定性 | 同分的两个人，原来坐前排的排完后还在前排 |
| 内部排序 | 卷子少，全摊桌上一次排完 |
| 外部排序 | 卷子太多，分批搬进来排好再搬出去 |
| 时间复杂度 | 你排完所有卷子花了多少分钟 |
| 空间复杂度 | 你借了旁边几张桌子来辅助 |
