# 线性表（Linear List）

## 类型判定
判别型 — 线性表是数据结构中最基础的逻辑结构，区分于树（一对多）和图（多对多），核心特征是元素间「一对一」的前驱后继关系。

## 是什么
线性表是 **具有相同数据类型的 n 个数据元素的有限序列**。记为 $L = (a_1, a_2, \ldots, a_n)$。

三个关键点：
- **相同数据类型**：各元素占用存储空间相同，便于随机定位
- **有限序列**：元素个数 n 有限，且有序——有先后次序
- **位序从 1 开始**：$a_1$ 是第一个元素（注意数组下标从 0 开始，区分）

## 输入-输出空间
- **输入**：无（逻辑结构，不涉及输入输出）
- **输出**：无
- **核心约束**：除第一个元素外，每个元素有唯一直接前驱；除最后一个元素外，每个元素有唯一直接后继

## 正例（≥2 个）
1. **学生成绩表**：每行是一个学生的成绩记录，所有行类型相同（struct student），按学号排列——典型的线性表
2. **英文单词字母序列**："hello" 的 5 个字符构成线性表，每个元素是 char 型，h→e→l→l→o 有明确前后关系

## 反例/边界（≥1 个）
1. **所有整数按递增排列**：满足「同类型」和「有序」，但整数集合是**无限**的 → 不满足「有限序列」→ 不是线性表
2. **树形结构**（如公司组织架构）：一个 CEO 对应多个部门经理 → 一对多，不是线性表

## 详细解释

### 为什么叫「表」？
英文术语 Linear List，List 本身就有「列表」含义（如 to-do list）。当每个数据元素包含多个数据项时，看起来就是一张表格。

### 基本操作（9 个）
| 操作 | 含义 |
|------|------|
| `InitList(&L)` | 初始化，分配内存 |
| `DestroyList(&L)` | 销毁，释放内存 |
| `ListInsert(&L, i, e)` | 在第 i 位插入 e |
| `ListDelete(&L, i, &e)` | 删除第 i 位，用 e 返回 |
| `LocateElem(L, e)` | 按值查找，返回位序 |
| `GetElem(L, i)` | 按位查找，返回值 |
| `Length(L)` | 求表长 |
| `PrintList(L)` | 输出 |
| `Empty(L)` | 判空 |

### 数据结构三要素视角
- **逻辑结构**：线性（一对一）
- **物理结构**：顺序存储（顺序表）或链式存储（链表）——后续章节展开
- **数据运算**：上述 9 个基本操作，不同存储结构下实现方式不同

## 类比

### 一句话比喻
**线性表就像一串糖葫芦——每个山楂是数据元素，竹签是逻辑结构，把所有元素串成「一条线」。竹签可以是笔直的木签（顺序存储，连续空间），也可以是软绳（链式存储，结点分散但指针串连）。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 数据元素 | 一节火车车厢 |
| 直接前驱 / 直接后继 | 前一节车厢 / 后一节车厢 |
| 顺序存储 | 所有车厢停在编号连续的轨道上（C1→C2→C3…） |
| 链式存储 | 每节车厢自带一个钩子，只钩住下一节（位置可以乱序） |
| 表头（$a_1$） | 火车头 |
| 表尾（$a_n$） | 最后一节车厢 |
