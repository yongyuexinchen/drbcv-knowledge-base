# 散列函数的构造

## 类型判定
程序型 — 四种构造方法：除留余数法（最常考）、直接定址法、数字分析法、平方取中法。

## 是什么
设计一个函数 $H(key)$ 将关键字映射到散列地址。**核心目标**：地址分布均匀，减少冲突。

## 设计散列函数的四个要求
1. **定义域覆盖全部关键字**：如负数不能开根号
2. **值域不超表长**：$H(key)$ 必须在合法地址范围
3. **地址均匀分布**：别全映射到同一个位置
4. **计算简单快速**：别用阶乘之类花时间的操作

## 正例（≥2 个）
1. **除留余数法**：$H(key) = key \bmod 13$（13 是不大于表长的最大质数）→ 最通用
2. **直接定址法**：学号连续 201901~201930 → $H(key) = key - 201901$ → 映射到 0~29
3. **数字分析法**：手机号前 7 位不均匀，后 4 位均匀 → 取后 4 位作散列地址

## 反例/边界（≥1 个）
1. **$H(key) = key \bmod 8$**（8 是合数）：若关键字全是偶数 → 只映射到 0,2,4,6 → 一半地址浪费，冲突暴增
2. **直接定址法用于不连续关键字**：学号稀疏（1, 5, 100, 200）→ 大量空位，浪费空间

## 详细解释

### 四种构造方法对比

| 方法 | 公式/做法 | 适用场景 | 优点 | 缺点 |
|---|---|---|---|---|
| **除留余数法** | $H(key) = key \bmod p$（p 是不大于表长的**最大质数**） | 通用 | 简单，分布均匀 | p 要选质数 |
| **直接定址法** | $H(key) = a \cdot key + b$ | 关键字**连续**分布 | 无冲突 | 不连续时空位多 |
| **数字分析法** | 选取分布均匀的数码位 | 关键字集合**已知**，某几位均匀 | 针对性强 | 需预知关键字分布 |
| **平方取中法** | 先平方，取中间几位 | 关键字每位分布都**不均匀** | 散列地址受每位影响 | 需要平方运算 |

### 为什么除留余数法的 p 要取质数？
- 合数有因子，关键字与合数有公因子时 → 余数只落在部分地址
- 例：$key \bmod 8$，关键字全是偶数 → 公因子 2 → 只映射到偶数地址
- 质数没有（非 1 非自身）因子 → 减少"共振"

### 平方取中法原理
$985^2 = 970225$，取中间两位 "02"。乘法运算中，乘积的中间位受到**每一位**的影响 → 即便原始关键字各位不均匀，中间的数码位也能均匀。

### 复杂度
- 散列函数计算：$O(1)$

## 类比 ★

### 一句话比喻
**除留余数法就像分班——全校 1000 人分 13 个班，"学号除以 13，余几去几班"。13 是质数，保证各班人数差不多（均匀）。如果是 12 个班（合数），学号末位是偶数的全分到偶数班——奇数班门可罗雀。直接定址法就是"按学号排队"——前排 1 号、2 号、3 号依次坐，插班生另说。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 除留余数法 | 学号除以班数取余——最公平的分班法 |
| p 是质数 | 班数是质数 → 避免"偶数号全去偶数班" |
| 直接定址法 | 按学号依次分配座位——没人的座位空着 |
| 数字分析法 | 手机号取后 4 位——前 7 位（运营商+区号）太雷同 |
| 平方取中法 | 把身份证号平方后取中间几位——每个数字都对结果有贡献 |
| 散列函数计算简单 | 分班公式必须心算——不能让学生站操场算半小时阶乘 |
