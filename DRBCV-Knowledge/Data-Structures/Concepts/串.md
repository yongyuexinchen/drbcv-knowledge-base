# 串（String）

## 类型判定
判别型 — 串是**操作对象为子串的特殊线性表**，`is_a` [[线性表]]，核心区别：① 数据元素限定为字符；② 增删改查以「子串」而非单个元素为操作对象。

## 是什么
串（字符串）是由零个或多个**字符**组成的**有限序列**。记为 $S = `a_1 a_2 \ldots a_n'$（$n \ge 0$）。

三个关键点：
- **字符型**：每个数据元素只能是字符（字母、数字、标点、空格等），不同于线性表可以存任意类型
- **有限序列**：n 有限，元素有先后次序，位序从 1 开始
- **子串为操作单位**：查找/插入/删除通常以连续的一段字符（子串）为对象，而非单个字符

## 输入-输出空间
- **输入**：无（逻辑结构定义）
- **核心概念**：串名 S、串长 n、空串（n=0）、子串、主串、字符在主串中的位置、子串在主串中的位置

## 正例（≥2 个）
1. **"hello world"**：12 个字符（含空格）的有序序列，'h'→'e'→'l'→'l'→'o'→' '→'w'→…，空格也是合法字符
2. **搜索引擎查询**：你在搜索框输入 `"KMP算法"`，搜索引擎在网页文本（长字符串）中寻找包含该子串的内容 → 典型的子串定位操作

## 反例/边界（≥1 个）
1. **空串 ≠ 空格串**：`""`（长度=0）是空串；`"   "`（三个空格，长度=3）是空格串——空格字符占 1 字节（ASCII 00100000），屏幕上看不见 ≠ 不存在
2. **字符的无限集合**：如「世界上所有的汉字」是无界的 → 不满足「有限序列」→ 不是串
3. **线性表的任意类型存储**：`[42, 3.14, "hello", true]` 是线性表但不是串——串的元素只能全是字符

## 详细解释

### 串 vs 线性表
| | 线性表 | 串 |
|---|---|---|
| 数据元素类型 | ElemType（任意） | char（字符） |
| 操作对象 | 单个元素 | 子串（连续多个字符） |
| 逻辑结构 | 线性（一对一） | 线性（一对一，相同！） |
| 典型操作 | Insert/Delete 单个元素 | 定位子串、取子串、串比较 |

### 基本操作（9 个）
| 操作 | 含义 |
|------|------|
| `StrAssign(&T, chars)` | 赋值——把 chars 赋给 T |
| `StrCopy(&T, S)` | 复制——把 S 复制给 T |
| `StrEmpty(S)` | 判空——length==0? |
| `StrLength(S)` | 求串长 |
| `ClearString(&S)` | 清空——逻辑清空，不释放空间 |
| `DestroyString(&S)` | 销毁——归还内存 |
| `Concat(&T, S1, S2)` | 连接——T = S1 + S2 |
| `SubString(&Sub, S, pos, len)` | 求子串——从 pos 起取 len 个字符 |
| `Index(S, T)` | 定位——找 T 在 S 中首次出现的位置（核心！后续 KMP 的目标） |
| `StrCompare(S, T)` | 比较——逐字符比大小，S>T 返正值，S=T 返 0，S<T 返负值 |

### 串比较规则
逐字符对比，先出现更大字符的串更大；前缀相同则更长的更大。本质是 ASCII/Unicode 二进制值的大小比较。

### 字符集编码
- 字符集 = 定义域（有哪些字符），编码 = 映射规则 f(x) → 二进制数
- ASCII：每个字符 1 字节（8bit → 256 种状态）
- Unicode（UTF-8）：中文等字符占 3 字节
- 乱码原因：写入用编码 A，读取用编码 B → $f_B^{-1}(f_A(x)) \neq x$

## 类比

### 一句话比喻
**串就是排队的人组成的字符串——每个人是一个字符，一串人站成一排就是一个字符串。线性表里你可以塞进各种东西（人、狗、自行车），但字符串里只能排队站人（字符）。你想找的不是某一个人，而是「连着三个穿红衣服的」这种连续片段（子串）。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 串（String） | 一排站好的人（每个人是一个字符） |
| 子串 | 这排人中连续几个人的片段 |
| 主串 | 整排人 |
| 空串 | 一个人都没有的空队列 |
| 空格串 | 队里站着几个穿隐身衣的人——你看不见但确实占位置 |
| 串比较 | 两个人名按拼音序比大小（张伟 > 李四，因为 Z > L） |
| 子串定位（Index） | 在一排人中找「连着三个穿红衣服的」从哪开始 |
| 字符集 | 允许来排队的人的「国籍集合」（ASCII=只能来美国人，Unicode=全世界都能来） |
| 编码 | 每个人领的号码牌规则（同一批人，发牌规则不同号码就不同） |
