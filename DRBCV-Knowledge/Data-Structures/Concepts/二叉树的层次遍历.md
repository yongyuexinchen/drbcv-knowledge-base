# 二叉树的层次遍历（Level Order Traversal）

## 类型判定
程序型 — 广度优先遍历（BFS），借助队列一层一层地访问二叉树结点。

## 是什么
从根结点开始，按从上到下、从左到右的顺序逐层访问每个结点。与先/中/后序遍历（深度优先 DFS）不同，层次遍历是**广度优先（BFS）**策略。

## 输入-输出空间
- **输入**：二叉树的根结点指针 `BiTree T`
- **输出**：层序遍历序列
- **前置条件**：需要一个**辅助队列**存储待访问结点的指针

## 正例（≥2 个）
1. **完全二叉树的层序**：层序序列恰好是按编号 1→2→3→…→n 的顺序
2. **树的层次遍历**：对普通树同样适用（根入队 → 出队访问 → 所有孩子入队），等同于「广度优先遍历」

## 反例/边界（≥1 个）
1. **空树**：队列初始为空，直接返回，不访问任何结点
2. **只有单链的二叉树**：虽然形态退化，但层序遍历依然正确——因为每个结点至多一个孩子，按层输出就是根→孩子→孙子...

## 详细解释

### 算法思想

1. 根结点入队
2. 队列非空时循环：
   - 队头结点出队并**访问**
   - 若该结点有左孩子，左孩子入队
   - 若该结点有右孩子，右孩子入队
3. 队列为空时结束

### 核心代码

```c
void LevelOrder(BiTree T) {
    LinkQueue Q;
    InitQueue(Q);                    // 初始化辅助队列
    BiTree p;
    EnQueue(Q, T);                   // 根结点入队
    while (!IsEmpty(Q)) {
        DeQueue(Q, p);               // 队头出队
        visit(p);                    // 访问出队结点
        if (p->lchild != NULL)
            EnQueue(Q, p->lchild);   // 左孩子入队
        if (p->rchild != NULL)
            EnQueue(Q, p->rchild);   // 右孩子入队
    }
}
```

> **注意**：队列中存储的是结点**指针**（`BiTree`），不是结点本身——节省空间。

### 时间复杂度

| 情况 | 复杂度 |
|------|--------|
| 时间 | $O(n)$（每个结点入队出队各一次） |
| 空间 | $O(n)$（队列最大长度 = 最宽层的结点数，最坏可达 n） |

### 深度优先 vs 广度优先

| | DFS（先/中/后序） | BFS（层序） |
|---|---|---|
| 实现 | 递归/栈 | 队列 |
| 策略 | 优先往深处钻 | 一层一层横向扫 |
| 空间 | $O(h)$ | $O(w)$，w 为最宽层宽度 |

## 类比

### 一句话比喻
**层次遍历就像公司发月饼——老大（根结点）先领，然后老大把他两个下属（左孩子、右孩子）推到领月饼的队伍后面排队。轮到下属时，下属领完又把自己的下属推到队尾。不管公司层级多深，月饼一层一层往下发，谁先排队谁先领。**

### 生活映射
| 数据结构世界 | 发月饼现场 |
|---|---|
| 队列 | 领月饼的队伍 |
| 根结点入队 | 老大第一个排进队伍 |
| 出队 + 访问 | 轮到你，签字领月饼 |
| 左右孩子入队 | 领完月饼把你两个下属推去排队 |
| 队列为空 | 所有人都领完了 |
| BFS（层序） | 大领导先领，然后中层，然后基层——按层级发 |
| DFS（先/中/后序） | 老大领完直接冲到他部门最底层发——先深后广 |
