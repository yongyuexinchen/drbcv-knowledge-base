# 朴素模式匹配算法（Brute-Force String Matching）

## 类型判定
程序型 — 字符串模式匹配的暴力枚举算法。核心操作：枚举主串中所有长度为 $m$ 的子串，逐一与模式串比较。

## 是什么
在主串 $S$（长度 $n$）中寻找模式串 $T$（长度 $m$）首次出现的位置。思想极简：从 $S$ 的第 1 位开始，依次取每一个长度为 $m$ 的子串与 $T$ 对比，找到就返回起始位序，全找不到返回 0。

## 输入-输出空间
- **输入**：主串 S（长度 n），模式串 T（长度 m）
- **输出**：int — T 在 S 中首次出现的位序（从 1 开始），找不到返回 0
- **前置条件**：$1 \le m \le n$

## 正例（≥2 个）
1. **S="GOOGLEGOOGLE", T="GOOGLE"**：从位序 1 开始匹配 → 第 1 个子串完全匹配 → 返回 1
2. **S="AAAAAB", T="AAAB"**：第 1 个子串 "AAAA"≠"AAAB"；第 2 个 "AAAA"≠"AAAB"；第 3 个 "AAAB"="AAAB" → 返回 3

## 反例/边界（≥1 个）
1. **S="HELLO", T="WORLD"**：所有 $n-m+1=1$ 个子串都不匹配 → 返回 0
2. **最坏情况陷阱**：S="AAAAAAAAAB", T="AAAAB" → 每个子串的前 4 个字符都匹配，直到第 5 个才发现失败 → 大量无效对比 → 时间复杂度 $O(nm)$

## 详细解释

### 算法思想
主串中长度为 $m$ 的子串共有 $n - m + 1$ 个。算法逐一取出这些子串与模式串比对：
- 相等 → 返回当前子串的起始位序 `i`
- 不等 → 取下一个子串（`i++`）
- 全部取完都不等 → 返回 0

### 核心代码（不调用基本操作，直接操作数组）

```c
int Index(SString S, SString T) {
    int i = 1, j = 1;                    // i: 主串指针, j: 模式串指针
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {        // 当前字符匹配
            i++; j++;                    // 继续比较后续字符
        } else {                         // 失配
            i = i - j + 2;               // i 回溯到下一个子串的起始位置
            j = 1;                       // j 回到模式串头部
        }
    }
    if (j > T.length)
        return i - T.length;             // 匹配成功，返回起始位置
    else
        return 0;                        // 匹配失败
}
```

### 关键：指针回溯公式
当失配时，`i = i - j + 2` 的含义：
- `i - j`：回到当前子串起始位置**的前一个位置**
- `+ 2`：跳到**下一个子串**的起始位置
- `j = 1`：模式串指针回到头部

### 与调用基本操作的版本对比
上一节 `Index` 调用 `SubString` + `StrCompare`，本质相同，但直接操作数组版本：
- 更高效（不需要每次取子串复制数据）
- 能清晰地展示 `i` 和 `j` 的回溯逻辑
- 是后续 [[KMP算法]] 的改造基础

### 时间复杂度
| 情况 | 复杂度 | 说明 |
|------|--------|------|
| 最好 | $O(m)$ 或 $O(n)$ | 第一个字符就不匹配，i 直接++ |
| 最坏 | $O(nm)$ | 每个子串前 $m-1$ 个字符都匹配，最后一个才失配 |
| 平均 | $O(n+m)$ | 实际应用中大部分情况较快 |

最坏情况示例：`S = "AAAAAAAAAB"`, `T = "AAAAB"`
- 共 $n-m+1$ 个子串，每个需要对比 $m$ 次
- 总对比次数 $\approx (n-m+1) \times m = O(nm)$

## 类比

### 一句话比喻
**朴素模式匹配就像暴力试密码——你有一串数字锁，不知道密码，就从 0000 开始一个不落地试：0000 不对 → 0001 不对 → 0002……每次失败就换下一个，完全不记上次试到哪儿失败了。笨，但简单粗暴，一定能找到（如果存在的话）。**

### 生活映射
| 代码世界 | 密码锁暴力破解现场 |
|---|---|
| 主串 S | 整个数字键盘序列 |
| 模式串 T | 你要找的正确密码 |
| `i` 指针 | 你当前从键盘的哪一位开始试 |
| `j` 指针 | 你正在核对密码的第几位 |
| `i = i - j + 2`（回溯） | 「不对！重来！从下一位开始，再从第一位核对」 |
| `j = 1` | 「密码第一位，重新看」 |
| 最坏 $O(nm)$ | 每次试到密码最后一位才发现不对 → 试得你怀疑人生 |
| 匹配成功 | 「BINGO！密码对了！」 → 返回这个密码串的起始位置 |
