# 图的基本操作

## 类型判定
判别型 — 图的数据结构三要素之**数据运算**，核心操作在不同存储结构下实现效率差异显著。考研重点：`FirstNeighbor` 和 `NextNeighbor` 是遍历算法的基础。

## 是什么
图的基本操作是操作图的标准化接口，具体实现依赖于存储结构（邻接矩阵 / 邻接表）。

## 输入-输出空间
各操作独立，详见下方。

## 正例（≥2 个）
1. **判断边是否存在** `Adjacent(G, x, y)`：邻接矩阵 $O(1)$ 秒出答案
2. **找第一个邻接点** `FirstNeighbor(G, x)`：邻接表只需取边链表头 → $O(1)$

## 反例/边界（≥1 个）
1. **邻接表存储有向图时找入边**：需遍历整个邻接表 → $O(|E|)$，极低效
2. **邻接表删除顶点**：除了删自己的边表，还要去别人的边表里删指向自己的结点 → 最坏 $O(|E|)$

## 详细解释

### 核心操作复杂度速查表

| 操作 | 邻接矩阵 | 邻接表（无向图） | 邻接表（有向图） |
|------|---------|-----------------|-----------------|
| `Adjacent(G, x, y)` 判断边 | $O(1)$ | $O(1) \sim O(|V|)$ | $O(1) \sim O(|V|)$ |
| `Neighbors(G, x)` 列出邻接边 | $O(|V|)$ | $O(1) \sim O(|V|)$ | 出边 $O(1) \sim O(|V|)$; 入边 $O(|E|)$ |
| `InsertVertex(G, x)` 插入顶点 | $O(1)$ | $O(1)$ | $O(1)$ |
| `DeleteVertex(G, x)` 删除顶点 | $O(|V|)$ | $O(|E|)$ | $O(|E|)$ |
| `AddEdge(G, x, y)` 添加边 | $O(1)$ | $O(1)$（头插法） | $O(1)$（头插法） |
| `FirstNeighbor(G, x)` 第一个邻接点 | $O(1) \sim O(|V|)$ | $O(1)$ | $O(1)$ |
| `NextNeighbor(G, x, y)` 下一个邻接点 | $O(1) \sim O(|V|)$ | $O(1)$ | $O(1)$ |
| `GetEdgeWeight(G, x, y)` | $O(1)$ | 同 Adjacent | 同 Adjacent |
| `SetEdgeWeight(G, x, y, w)` | $O(1)$ | 同 Adjacent | 同 Adjacent |

### 考研关键操作：FirstNeighbor + NextNeighbor
这两个操作是 BFS 和 DFS 遍历算法的核心依赖——遍历时通过它们逐一遍历当前顶点的所有邻接点。

**邻接矩阵实现思路**：扫描第 $i$ 行，找第一个/下一个值为 1 的元素。
**邻接表实现思路**：从 `vertices[i].first` 开始，顺链表后移。

### 插入顶点为何是 $O(1)$？
插入时只需在顶点数组末尾写入新数据。邻接矩阵中对应的行/列初始化时已置零，不需要额外操作。邻接表同理——新顶点边指针置空即可。

### 邻接矩阵删顶点的巧妙处理
与其移动大量元素，不如在顶点结构体中增加一个 `bool isEmpty` 标记，删除后只将该顶点对应的行和列置零 + 标记为空。这样只需 $O(|V|)$ 而非 $O(|V|^2)$。

## 类比

### 一句话比喻
**图的基本操作就像你在不同手机 App 里查联系人——微信（邻接表）：打开通讯录，第一个好友直接显示（$O(1)$），往下滑依次看（NextNeighbor $O(1)$）。但要查「谁加了我」就得把全公司所有人手机抢过来一个个翻（入边 $O(|E|)$）。企业微信后台（邻接矩阵）：直接查数据库表格，行和列交叉就是答案（$O(1)$），但要列出所有好友得扫一整行。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| `Adjacent(G, A, B)` | 查航班公告牌：北京到上海有没有直飞？ |
| `Neighbors(G, A)` | 列出所有从北京出发的直飞城市 |
| `InsertVertex(G, X)` | 新增一个城市 X，暂不通航 |
| `DeleteVertex(G, X)` | 撤销城市 X，抹掉所有相关航线 |
| `AddEdge(G, A, B)` | 开通北京-上海直飞航线 |
| `FirstNeighbor(G, A)` | 北京直飞的第一个城市 |
| `NextNeighbor(G, A, 上海)` | 北京直飞的下一个城市（上海之后） |
| 入边查找慢 | 查「哪些城市有飞北京的航班」→ 公告牌得全扫一遍 |
