# 树的存储结构（Storage of Tree）

## 类型判定
判别型 — 区分普通树（非二叉树）的三种存储方式：双亲表示法、孩子表示法、孩子兄弟表示法，各有适用场景。

## 是什么
普通树（每个结点可有任意多个孩子）有三种存储方式：
- **双亲表示法**：顺序存储，每个结点记录其父结点的数组下标——找父亲快
- **孩子表示法**：顺序+链式，每个结点用链表记录所有孩子的下标——找孩子快
- **孩子兄弟表示法**：纯链式，每个结点两个指针（第一个孩子 + 右兄弟）——与二叉树统一

## 输入-输出空间
- **输入**：树的逻辑结构
- **输出**：对应的物理存储表示

## 正例（≥2 个）
1. **双亲表示法 → 并查集**：并查集只需要找根（一路向北找 parent）和合并（一个根指向另一个根），双亲表示法最合适
2. **孩子表示法 → 客服电话流程树**：用户从根开始一路选「找孩子」（按 1→按 3→按 2），孩子表示法找孩子极快

## 反例/边界（≥1 个）
1. **双亲表示法找孩子**：需要遍历整个数组，找出所有 parent 指向该结点的元素 → $O(n)$，效率极低
2. **孩子表示法找父亲**：需要遍历所有链表查找 → 很不方便

## 详细解释

### 双亲表示法（Parent Representation）

```c
#define MAX_TREE_SIZE 100
typedef struct {
    ElemType data;
    int parent;          // 双亲在数组中的下标（根为 -1）
} PTNode;
typedef struct {
    PTNode nodes[MAX_TREE_SIZE];
    int n;               // 结点总数
} PTree;
```

**特点**：找父亲 $O(1)$，找孩子 $O(n)$。也可存储森林——每棵树的根 parent 都设为 -1。

### 孩子表示法（Child Representation）

```c
// 孩子链表结点
typedef struct CTNode {
    int child;                        // 孩子结点在数组中的下标
    struct CTNode *next;              // 下一个孩子
} *ChildPtr;

// 数组元素
typedef struct {
    ElemType data;
    ChildPtr firstchild;              // 第一个孩子的链表头指针
} CTBox;

typedef struct {
    CTBox nodes[MAX_TREE_SIZE];
    int n, r;                         // 结点数 + 根的位置
} CTree;
```

**特点**：找孩子 $O(1)$（直接沿着链表走），找父亲 $O(n)$。

### 孩子兄弟表示法（Child-Sibling Representation）

```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild;        // 第一个孩子
    struct CSNode *nextsibling;       // 右兄弟
} CSNode, *CSTree;
```

**特点**：
- 与二叉链表同构（`firstchild` ↔ `lchild`，`nextsibling` ↔ `rchild`）
- 可用于存储森林（将各树的根视为兄弟，用 `nextsibling` 串起来）
- 这是**树/森林 ↔ 二叉树转换**的本质

### 三种存储方式对比

| | 双亲表示法 | 孩子表示法 | 孩子兄弟表示法 |
|---|---|---|---|
| 存储方式 | 纯顺序（数组） | 顺序+链式 | 纯链式（二叉链表） |
| 找父亲 | $O(1)$ ✅ | $O(n)$ ❌ | $O(n)$ ❌ |
| 找孩子 | $O(n)$ ❌ | $O(1)$ ✅ | 找第一个孩子 $O(1)$ |
| 适用场景 | 并查集 | 服务流程树 | 树↔二叉树转换 |
| 存森林 | ✅ 可行 | ✅ 可行 | ✅ 根结点串成兄弟 |

## 类比

### 一句话比喻
**三种存储方式就像三种记族谱的方式——
双亲表示法是「每个人只记他爸是谁」（查祖宗快，找儿子得翻遍全族谱）；
孩子表示法是「每个人记他所有儿子是谁」（查儿子快，找爸得挨家挨户问）；
孩子兄弟表示法是「每人只记自己的大儿子和下一个兄弟」（像链表一样串起来，变成一棵歪脖子二叉树）。**

### 生活映射
| 数据结构世界 | 族谱记录方式 |
|---|---|
| 双亲表示法 | 户口本——每页只写「父亲是谁」 |
| parent = -1 | 老祖宗——父亲栏空白 |
| 孩子表示法 | 幼儿园花名册——老师记录「我班里有哪些孩子」 |
| 孩子链表 | 老师手上的点名表 |
| 孩子兄弟表示法 | 微信家族群——每个人只加「大儿子」和「二弟」 |
| firstchild / nextsibling | 「加我大儿子」/ 「加我下一个弟弟」 |
| 森林存储 | 多个家族群——群主之间互加好友（视为兄弟） |
