# 平衡二叉树（AVL 树）

## 类型判定
程序型 — 含平衡因子定义、四种旋转调整（LL/RR/LR/RL）、插入与删除的调整策略、高度与结点数关系。

## 是什么
在 BST 基础上增加**平衡约束**：任意结点的左右子树高度差 ≤ 1。通过旋转操作维持平衡，保证树高 $O(\log n)$，从而查找/插入/删除均为 $O(\log n)$。

## 输入-输出空间
- **插入**：先按 BST 插入，再从插入点向上找最小不平衡子树 → 旋转调整
- **删除**：先按 BST 删除，再从删除点向上找最小不平衡子树 → 旋转调整（可能向上传导）
- **平衡因子**：`bf = 左子树高 - 右子树高`，取值仅 -1 / 0 / 1

## 正例（≥2 个）
1. **插入 67 导致 70 不平衡（LL型）**：70 的左孩子 68 右旋 → 68 成为新根，70 变右孩子 → 恢复平衡
2. **插入 63 导致 50 不平衡（RL型）**：先右旋 66（变 68 的父），再左旋 66（变 50 的父）→ 66 成新根

## 反例/边界（≥1 个）
1. **删除导致不平衡向上传导**：调整完最小不平衡子树后高度变矮 → 上层祖先可能新产生不平衡 → 需循环处理（如删除 32 后调整 44，又导致 33 不平衡）

## 详细解释

### 四种旋转（核心！）

| 类型 | 插入位置 | 操作 | 口诀 |
|---|---|---|---|
| **LL** | A 的左孩子的左子树 | **右单旋** B | B 右旋转，A 变 B 的右孩子 |
| **RR** | A 的右孩子的右子树 | **左单旋** B | B 左旋转，A 变 B 的左孩子 |
| **LR** | A 的左孩子的右子树 | **先左旋 C，后右旋 C** | C 先左旋替 B，再右旋替 A |
| **RL** | A 的右孩子的左子树 | **先右旋 C，后左旋 C** | C 先右旋替 B，再左旋替 A |

**记忆规律**：只有左孩子才能右旋，只有右孩子才能左旋。LR = 右孩子(C)先左旋再右旋；RL = 左孩子(C)先右旋再左旋。

### 右旋操作（LL）
```
     A              B
    / \            / \
   B   AR   →    BL   A
  / \                / \
 BL  BR            BR   AR
```
- B 的右子树 BR → 变成 A 的左子树
- A → 变成 B 的右孩子

### 左旋操作（RR，对称）
```
   A                B
  / \              / \
 AL  B     →      A   BR
    / \          / \
   BL  BR      AL  BL
```

### 删除五步法
1. 按 BST 规则删除结点（三种情况）
2. **一路向北**：从删除位置向上找最小不平衡子树
3. 找到**个头最高的儿子和孙子**
4. 根据孙子位置（LL/RR/LR/RL）→ 旋转调整
5. 检查**不平衡是否向上传导** → 若是，回到第 2 步

### 高度为 h 的最少结点数
$$N_h = N_{h-1} + N_{h-2} + 1, \quad N_0 = 0, N_1 = 1, N_2 = 2$$

| h | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $N_h$ | 0 | 1 | 2 | 4 | 7 | 12 | 20 |

推论：n 个结点的 AVL 树最大高度 = $O(\log n)$

### 复杂度
- 查找/插入/删除：均为 $O(\log n)$

## 类比 ★

### 一句话比喻
**AVL 树就像跷跷板——左右两边重量差不能超过 1。左边太重（LL）？让左边的人（B）往上坐（右旋），原来坐中间的人（A）滑到右边去。右边太重（RR）？同理左旋。如果是因为跷跷板左边的人往右歪了（LR），那先让他往左倒（左旋），再往上坐（右旋）——两次调整。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 平衡因子 bf | 跷跷板两边高度差读数 |
| bf ∈ {-1, 0, 1} | 正常范围：左边高一点、平的、右边高一点 |
| \|bf\| > 1 | 跷跷板"嘎吱"——要翻了！ |
| LL → 右旋 | 左边太重 → 左边人往中间挪 |
| RR → 左旋 | 右边太重 → 右边人往中间挪 |
| LR → 先左后右 | 左边人的右手太重 → 先把右手抬起，再整个人往中间坐 |
| 最小不平衡子树 | 只需要调整最下面那个要翻的跷跷板 |
| 删除后向上传导 | 底下调好了，但上面又歪了——连锁反应 |
| 高度 $O(\log n)$ | 跷跷板层数再多，也比直线排开矮得多 |
