# 树、森林与二叉树的转换与遍历

## 类型判定
程序型 — 树/森林与二叉树可互相转换（本质 = 孩子兄弟表示法），且转换后遍历序列有等价关系。

## 是什么
利用**孩子兄弟表示法**的规则，可将任意树或森林转换为唯一的二叉树，反之亦然。
- **树 → 二叉树**：左指针 = 第一个孩子，右指针 = 右兄弟
- **森林 → 二叉树**：先将各树根用右指针串成兄弟，再按同样规则处理
- 转换后的遍历序列有固定的等价关系。

## 输入-输出空间
- **输入**：树的逻辑结构（或森林）
- **输出**：对应的二叉树（或反向还原）

## 正例（≥2 个）
1. **树的先根遍历 = 二叉树的先序遍历**：对同一棵树，先根遍历序列与转换后二叉树的先序序列完全相同
2. **树的后根遍历 = 二叉树的中序遍历**：对同一棵树，后根遍历序列与转换后二叉树的中序序列完全相同

## 反例/边界（≥1 个）
1. **二叉树 → 树 vs 二叉树 → 森林**：如果二叉树的根结点有右子树，则转换回的是**森林**而非单棵树（因为根的右指针指向的是另一棵树的根）
2. **森林的遍历**有递归嵌套，容易乱——建议直接用「依次先根/后根遍历每棵树」或「先转成二叉树再遍历」

## 详细解释

### 树 → 二叉树的转换口诀

**「左孩子，右兄弟」**——按层次顺序依次处理每个结点：
1. 画出树的根结点
2. 按层次顺序处理每个结点：
   - 把该结点**所有孩子用右指针串成糖葫芦**
   - 把**第一个孩子**挂在结点的左指针下
3. 重复直到处理完所有结点

### 森林 → 二叉树的转换口诀

1. 先把森林中**所有树的根用右指针串成兄弟**（视为平级）
2. 再按「树 → 二叉树」规则依次处理每个结点

### 二叉树 → 树的还原口诀

**「拆糖葫芦」**——按层次顺序恢复：
1. 画出树的根（=二叉树的根）
2. 按层次处理：若结点有左孩子，则把左孩子及其右指针连起来的一整串（糖葫芦）**拆下来**，分别挂为当前结点的孩子
3. 注意：若根结点有右子树，转换的是森林——右指针串起来的是多棵树的根

### 遍历等价关系

| 树的遍历 | 森林的遍历 | 二叉树的遍历 |
|----------|-----------|-------------|
| **先根遍历** | **先序遍历** | **先序遍历**（三者等价） |
| **后根遍历** | **中序遍历** | **中序遍历**（三者等价） |
| 层次遍历 | — | 层次遍历 |

> **记忆诀窍**：树的先根 = 二叉树的先序；树的后根 = 二叉树的中序。森林的先序 = 依次对每棵树先根遍历；森林的中序 = 依次对每棵树后根遍历。

### 树的先根遍历（代码）

```c
void PreOrder(Tree T) {
    if (T != NULL) {
        visit(T);                         // 访问根
        while (T 还有下一棵子树)            // 依次先根遍历各子树
            PreOrder(下一棵子树);
    }
}
```

### 树的后根遍历（代码）

```c
void PostOrder(Tree T) {
    if (T != NULL) {
        while (T 还有下一棵子树)            // 依次后根遍历各子树
            PostOrder(下一棵子树);
        visit(T);                         // 最后访问根
    }
}
```

### 树的层次遍历

同二叉树的层次遍历——用**队列**辅助：
1. 根入队
2. 队头出队访问，该结点的**所有孩子**依次入队
3. 重复直到队列空

## 类比

### 一句话比喻
**树转二叉树就像把一棵枝繁叶茂的大树「压扁」——原本一个爹有三个儿子，转换后变成：大儿子站爹的左手边，二儿子站大儿子的右边（像兄弟连），三儿子站二儿子的右边。整棵树被「拧」成了一条左斜右平的结构——左手牵大儿子，右手搭兄弟肩。**

### 生活映射
| 数据结构世界 | 家庭合影 |
|---|---|
| 树 → 二叉树 | 为了横着站一排拍照，把原本的「祖-父-子」竖排拧成横排 |
| 左指针 = 第一个孩子 | 「来，大儿子站我左手边」 |
| 右指针 = 右兄弟 | 「二弟，你站大哥右边」 |
| 根的右指针非空 | 「我旁边还站着另一个家族的老大」→ 这是森林！ |
| 先根遍历 = 先序遍历 | 按「进门就点名」的方式逛——横排和竖排名单一样 |
| 后根遍历 = 中序遍历 | 按「从左边绕」的方式逛——横排和竖排名单一样 |
| 糖葫芦串 | 把一家人从大到小排成一排手拉手 |
