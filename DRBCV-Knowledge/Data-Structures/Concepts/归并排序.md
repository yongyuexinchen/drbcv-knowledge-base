# 归并排序（Merge Sort）

## 类型判定
程序型 — 基于**分治法**的排序算法，核心是将两个有序序列合并为一个有序序列（二路归并）。同时也是外部排序的理论基础。

## 是什么
归并排序将待排序序列不断从中间拆分为两个子序列，分别递归排序，当左右子序列都有序后，用 **merge** 操作合并为一个整体有序序列。二路归并：把两个有序序列合二为一，每选一个最小元素只需比较 1 次关键字。

## 输入-输出空间
- **输入**：数组 A[low..high]
- **输出**：该区间递增有序
- **前置条件**：需要辅助数组 B[n]

## 正例（≥2 个）
1. **任意序列**：无论初始有序还是逆序，归并排序的比较次数和趟数都一样 → 最坏 = 最好 = 平均 = $O(n \log n)$
2. **稳定排序的首选**：当需要 $O(n \log n)$ 且必须稳定时，选归并排序（快排和堆排都不稳定）

## 反例/边界（≥1 个）
1. **空间复杂度 $O(n)$**：需要等长的辅助数组，是内部排序中空间开销最大的——内存敏感场景慎用
2. **M 路归并**：每选一个元素需比较 M-1 次关键字（不过可用败者树优化）

## 详细解释

### 核心代码（二路归并的 merge 操作）
```c
int *B = (int *)malloc((n + 1) * sizeof(int));  // 辅助数组

void Merge(int A[], int low, int mid, int high) {
    int i, j, k;
    for (k = low; k <= high; k++)         // 复制到辅助数组
        B[k] = A[k];
    i = low; j = mid + 1; k = low;
    while (i <= mid && j <= high) {
        if (B[i] <= B[j])                 // ≤ 而非 <：保证稳定性
            A[k++] = B[i++];
        else
            A[k++] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];     // 左半剩余
    while (j <= high) A[k++] = B[j++];    // 右半剩余
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);           // 递归排序左半
        MergeSort(A, mid + 1, high);      // 递归排序右半
        Merge(A, low, mid, high);         // 归并
    }
}
```

### 关键注意事项
- **`B[i] <= B[j]` 用 `<=` 而非 `<`**：优先取左边的 → 保证稳定性
- **归并树**：归并过程形成一棵倒立的二叉树，树高 $h = \lceil \log_2 n \rceil + 1$，归并趟数 $= h - 1 = \lceil \log_2 n \rceil$

### 时间复杂度
| 情况 | 复杂度 |
|------|--------|
| 最好 | $O(n \log n)$ |
| 最坏 | $O(n \log n)$ |
| 平均 | $O(n \log n)$ |

- 空间复杂度：**$O(n)$**（辅助数组）
- 稳定性：**稳定**
- 适用存储：顺序表（需辅助数组）

## 类比 ★

### 一句话比喻
**归并排序就像两摞已排好的扑克牌合成一摞——左手指着左边牌堆顶，右手指着右边牌堆顶，每次比较两张，小的放中间。如果左右都是 3，左手那张先放（稳定！）。当一摞放完了，另一摞剩下的直接全倒进去。分到只剩一张牌时天然有序，然后一层层往回合并——这就是分治。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 递归拆分（分治） | 把一摞乱牌不断对半分，直到每摞只有一张 |
| merge 合并 | 两摞已排好的牌合成一摞 |
| 两个指针 i, j | 左右手指向两摞牌顶 |
| `B[i] <= B[j]` | 两张一样大 → 左手那张先放（稳定） |
| 归并树 | 合并过程像倒立的树，依次往上合 |
| $O(n \log n)$ 固定 | 不管初始有多乱或多齐，一样的工作量 |
