# 顺序表的插入删除

## 类型判定
程序型 — 具体的算法操作步骤，含代码实现和复杂度分析。插入和删除是顺序表最核心也最"昂贵"的操作。

## 是什么
在顺序表的第 $i$ 个位置插入元素 $e$（插入后原第 $i$ 到第 $n$ 个元素依次后移），或删除第 $i$ 个位置的元素并用 $e$ 返回删除值（原第 $i+1$ 到第 $n$ 个元素依次前移）。

## 输入-输出空间
- **输入**：顺序表 L，位序 i（1 ≤ i ≤ length+1 插入 / 1 ≤ i ≤ length 删除），元素 e（插入时）
- **输出**：bool（成功/失败），e 引用返回删除值（删除时）
- **前置条件**：表未满（插入时），位序合法

## 正例（≥2 个）
1. **i=3 中间插入**：在位置 3 插入，位置 3~n 的元素依次后移一位 → 平均移动 n/2 次
2. **i=1 删除表头**：删除第一个元素，位置 2~n 的元素依次前移一位 → $n-1$ 次移动

## 反例/边界（≥1 个）
1. **i 越界**：$i < 1$ 或 $i > \text{length}+1$（插入）/ $i > \text{length}$（删除）→ 返回 false
2. **表满时插入**：$\text{length} = \text{MaxSize}$ → 返回 false（静态分配）
3. **移动方向错误**：插入时要**从后往前**移元素（先移最后一个），删除时要**从前往后**移（先移最靠近删除位置的）——方向搞反会导致数据被覆盖

## 详细解释

### 核心代码：插入操作

```c
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1)   // 位序非法
        return false;
    if (L.length >= MaxSize)          // 表满
        return false;

    for (int j = L.length; j >= i; j--)   // 从后往前移
        L.data[j] = L.data[j - 1];

    L.data[i - 1] = e;                    // 位序→数组下标: i-1
    L.length++;
    return true;
}
```

### 核心代码：删除操作

```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length)       // 位序非法
        return false;

    e = L.data[i - 1];               // 取出被删元素

    for (int j = i; j < L.length; j++)    // 从前往后移
        L.data[j - 1] = L.data[j];

    L.length--;
    return true;
}
```

### 关键注意事项

**① 插入时移动方向：从后往前！**
```c
for (int j = L.length; j >= i; j--)   // 正确：先移最后的元素
    L.data[j] = L.data[j - 1];
```
如果从前往后移，后面的元素会被前面覆盖而导致数据丢失。

**② 删除时移动方向：从前往后！**
```c
for (int j = i; j < L.length; j++)    // 正确：先移靠近删除位置的元素
    L.data[j - 1] = L.data[j];
```

**③ 位序与数组下标的转换**：位序 $i$（从 1 开始）对应数组下标 `i-1`（从 0 开始）。这是考试中最容易丢分的地方！

**④ 引用参数 `&`**：`L` 和 `e`（删除时）必须加引用，否则函数内修改的是副本，调用者看不到变化。

**⑤ 代码健壮性**：返回 bool 让调用者知道操作是否成功，是一种良好的工程实践。

### 时间复杂度

| 操作 | 最好 | 最坏 | 平均 |
|------|------|------|------|
| **插入** | $O(1)$（表尾，i=length+1） | $O(n)$（表头，i=1） | $O(n)$（移动 n/2 次） |
| **删除** | $O(1)$（表尾，i=length） | $O(n)$（表头，i=1） | $O(n)$（移动 (n-1)/2 次） |

平均移动次数推导（插入）：设插入到每个位置概率均为 $\frac{1}{n+1}$，移动次数期望 $= \frac{1}{n+1}(n + (n-1) + \cdots + 0) = \frac{n}{2}$。

## 类比

### 一句话比喻
**顺序表插入就像春运火车上插队——你想挤到第 3 排和第 4 排中间，整列车厢从第 3 排往后的所有人都得站起来，逐个往后挪一个位置，最后一个人甚至可能被挤出车厢（表满）。删除就是反过来——有人中途下车，后面的所有人往前补位，避免留下空洞。**

### 生活映射
| 代码世界 | 春运车厢现场 |
|---|---|
| `L.data[0..length-1]` | 车厢座位，必须坐满前面 |
| `ListInsert(&L, 3, e)` | 第 3 排有人要插进来 |
| `for (j=length; j>=3; j--)` | 最后一排的人先站起来往后挪 |
| `L.length++` | 车厢多了一个人 |
| ❌ 从前往后移 | 前面的人先站起挪到后面 → 把后排的人挤没了 |
| 表满返回 false | 车厢满员，列车长拒绝加人 |
| `ListDelete(&L, 2, &e)` | 第 2 排的人下车了 |
| `for (j=2; j<length; j++)` | 第 3 排补第 2 排，第 4 补第 3… |
