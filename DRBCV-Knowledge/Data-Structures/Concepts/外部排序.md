# 外部排序（External Sorting）

## 类型判定
程序型 — 处理**数据量大到无法全部装入内存**时的排序方法。基于归并排序思想，核心优化目标是**减少磁盘读写次数**。

## 是什么
外部排序分为两大步骤：
1. **生成初始归并段**：分批读入数据到内存，内部排序后写回磁盘，形成若干有序片段
2. **多路归并**：对初始归并段进行 K 路归并，逐趟合并，直到全局有序

核心时间开销 = **读写磁盘时间**（占大头）+ 内部排序时间 + 内部归并时间。

## 输入-输出空间
- **输入**：外存中的大文件（如16块 × 每块3条记录 = 48条记录）
- **输出**：外存中的有序文件
- **前置条件**：内存中至少需分配 K 个输入缓冲区 + 1 个输出缓冲区（每块大小与磁盘块一致）

## 正例（≥2 个）
1. **8GB文件排序**：内存只有1GB，必须用外部排序分批处理
2. **二路归并的最小内存配置**：只需 3 块缓冲区（2输入 + 1输出）即可完成任意大文件的排序

## 反例/边界（≥1 个）
1. **K 并非越大越好**：K 路归并 → K 个输入缓冲区 → 内存开销增加；且每选一个最小元素需 K-1 次关键字对比（可用败者树优化）
2. **K路平衡归并的严格定义**：必须满足"每趟若有 M 个归并段参与，归并后得到 $\lceil M/K \rceil$ 个新段"（课本定义有瑕疵）

## 详细解释

### 过程：二路归并外部排序（16块文件）
```
Step 1: 构造8个初始归并段（每次读2块→内部排序→写回2块）
        磁盘读写：16×2 = 32次

Step 2: 第一趟归并（8段 → 4段）
        磁盘读写：16×2 = 32次

Step 3: 第二趟归并（4段 → 2段）
        磁盘读写：16×2 = 32次

Step 4: 第三趟归并（2段 → 1段）
        磁盘读写：16×2 = 32次

总磁盘读写：32 × 4 = 128次
```

### 时间开销公式
$$T_{外部排序} = T_{读写磁盘} + T_{内部排序} + T_{内部归并}$$

其中 $T_{读写磁盘}$ 占主导（机械硬盘 ~100MB/s，内存 ~60GB/s）。

### 归并趟数公式
R 个初始归并段，K 路归并：
$$S = \lceil \log_K R \rceil$$

**优化方向**：
- **增大 K**（多路归并）：减少趟数 → 减少磁盘读写 → 但增加内部归并比较开销
- **减少 R**（更长的初始归并段）：通过置换-选择排序突破内存工作区大小限制

### 时间复杂度
- **总磁盘 I/O 次数** = $2 \times \text{文件总块数} \times (\text{初始归并段读写趟数} + \text{归并趟数})$
- 关键是减少归并趟数 S

## 类比 ★

### 一句话比喻
**外部排序就像搬家——你的东西太多，一趟搬不完。于是分批搬：每次搬两箱到新家（读入内存），在新家整理好（内部排序），再放回房间对应位置（写回磁盘）。等所有箱子都分类整理好（初始归并段），再把相邻两堆合并（归并）——原来堆A和堆B的箱子一个个对比，合成一堆更大的。分批搬的次数（磁盘读写）决定了搬家总耗时，所以核心就是减少搬运趟数。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 磁盘块 | 一个搬家纸箱 |
| 内存缓冲区 | 新家地上的暂存区（一次只能放几个箱子） |
| 内部排序 | 在新家把箱子里的东西整理好 |
| 归并段 | 整理好的一堆东西 |
| K路归并 | 把 K 堆整理好的东西合并成更大一堆 |
| 读写磁盘 | 搬一箱东西的新家↔旧家来回 |
| 优化 K ↑ | 一次合并更多堆 → 减少来回趟数 |
| 优化 R ↓ | 每堆整得更大 → 总堆数少 → 趟数少 |
