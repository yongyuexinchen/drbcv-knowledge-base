# 队列的顺序实现（循环队列）

## 类型判定
程序型 — 队列的**顺序存储实现**，用静态数组 + 队头/队尾指针 + **模运算**实现存储空间的循环利用，称为**循环队列**。

## 是什么
用静态数组存放队列元素，设 `front`（队头指针）和 `rear`（队尾指针）。通过 `(rear+1) % MaxSize` 的方式让指针在数组范围内循环移动，将线性的数组空间在逻辑上变成环状。**必须牺牲一个存储单元**（或用辅助变量）来区分队空和队满。

## 输入-输出空间
- **EnQueue(Q, x)**：先判满 → `Q.data[Q.rear] = x` → `Q.rear = (Q.rear+1) % MaxSize`
- **DeQueue(Q, &x)**：先判空 → `x = Q.data[Q.front]` → `Q.front = (Q.front+1) % MaxSize`
- **前置条件**：入队需未满，出队需非空

## 正例（≥2 个）
1. **rear 指向队尾后一位置（常用方案）**：初始化 `front = rear = 0`，判空 `front == rear`，判满 `(rear+1)%MaxSize == front`
2. **增加 size 变量**：不牺牲存储单元，用 `size` 记录元素个数 → 判满 `size == MaxSize`，判空 `size == 0`

## 反例/边界（≥1 个）
1. **不取模直接 `rear++`**：rear 跑出数组边界后无法回到前面空闲位置 → 假溢出
2. **不用辅助变量还不牺牲单元**：队空和队满都是 `front == rear`，无法区分 → 逻辑错误
3. **rear 指向队尾元素（而非后一位置）**：初始化、判空、入队逻辑全部要改——`front=0, rear=n-1`，入队先 `rear=(rear+1)%MaxSize` 再放数据

## 详细解释

### 结构体定义（rear 指向队尾元素的后一位置）
```c
#define MaxSize 10
typedef struct {
    ElemType data[MaxSize];
    int front, rear;   // 队头指针，队尾指针
} SqQueue;
```

### 核心代码（方案一：牺牲一个存储单元）

```c
// 初始化
void InitQueue(SqQueue &Q) {
    Q.front = Q.rear = 0;
}

// 判空
bool QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;
}

// 判满（牺牲一个单元）
bool QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MaxSize == Q.front;
}

// 入队
bool EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;  // 队满
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}

// 出队
bool DeQueue(SqQueue &Q, ElemType &x) {
    if (Q.front == Q.rear) return false;                  // 队空
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
```

### 三种判空/判满方案

| 方案 | 判空 | 判满 | 代价 |
|------|------|------|------|
| **牺牲一个单元** | `front == rear` | `(rear+1)%MaxSize == front` | 浪费 1 个位置 |
| **增加 size 变量** | `size == 0` | `size == MaxSize` | 多 4 字节 |
| **增加 tag 变量** | `front==rear && tag==0` | `front==rear && tag==1` | 多 1 字节，tag 标记上次是插入(1)还是删除(0) |

### 队长计算公式
$$(rear + MaxSize - front) \% MaxSize$$

### rear 指向队尾元素 vs 后一位置的区别

| | rear 指后一位置（标准） | rear 指队尾元素 |
|---|---|---|
| 初始化 | `front = rear = 0` | `front = 0, rear = n-1` |
| 判空 | `front == rear` | `(rear+1)%MaxSize == front` |
| 入队 | 先放再移：`data[rear]=x; rear=(rear+1)%M` | 先移再放：`rear=(rear+1)%M; data[rear]=x` |
| 判满 | `(rear+1)%M == front` | `(rear+2)%M == front` |

### 时间复杂度

| 操作 | 复杂度 |
|------|--------|
| EnQueue | $O(1)$ |
| DeQueue | $O(1)$ |
| GetHead | $O(1)$ |
| 判空/判满 | $O(1)$ |
| 求队长 | $O(1)$ |

## 类比

### 一句话比喻
**循环队列就像一条环形跑道——跑到终点（数组末尾）不用停，绕个弯继续回到起点跑。只要后面的选手没追尾你（rear 没撞上 front），就一直有位置。赛道上永远空着一个身位——教练说"追尾和停下不动看起来一样，但我必须能分清"。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 循环数组 | 环形跑道，跑到头绕回来继续 |
| `% MaxSize`（模运算） | 绕弯的规则——到终点自动回起点 |
| rear 追尾 front | 后排选手撞上前排——爆满，不能再上人 |
| 牺牲一个单元 | 跑道上永远留一个空位做标记 |
| size 变量 | 计数器——不看位置，看人数 |
| tag 变量 | 裁判举牌：刚才有人上场（1）还是下场（0）？ |
| front == rear | 两个指针凑在一起——要么全场没人，要么挤爆了 |
