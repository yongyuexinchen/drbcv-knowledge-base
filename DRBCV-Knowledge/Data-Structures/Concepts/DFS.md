# DFS（深度优先遍历）

## 类型判定
程序型 — 图的遍历算法，递归实现。`analogous_to` 树的先根遍历。与 BFS 并列，时空复杂度相同但空间开销来源不同（递归栈 vs 辅助队列）。

## 是什么
DFS（Depth-First Search）从起始顶点出发，沿一条路径走到底，无路可走时回溯，再试其他分支。核心：递归 + visited 标记数组。

## 输入-输出空间
- **输入**：图 $G$，起始顶点 $v$
- **输出**：遍历序列（所有顶点被访问一次）
- **前置条件**：无，非连通图通过外层 for 循环处理

## 正例（≥2 个）
1. **连通图一次 DFS**：从 2 出发 → 2 → 1 → 5 → …（邻接矩阵顺序唯一）
2. **迷宫求解**：DFS 就是走迷宫的经典策略——遇岔路选一条走到底，死胡同就退回来试另一条

## 反例/边界（≥1 个）
1. **递归深度过大**：像链状图，DFS 递归栈深度 = $|V|$ → 空间 $O(|V|)$，可能栈溢出
2. **非连通图忘记外层 for**：同 BFS，只能遍历一个连通分量

## 详细解释

### 核心代码
```c
bool visited[MAX_VERTEX_NUM];

void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;

    for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
        if (!visited[w]) {
            DFS(G, w);        // 递归深入
        }
    }
}

// 处理非连通图
void DFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++)
        visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i])
            DFS(G, i);
}
```

### 复杂度分析
| 存储结构 | 时间复杂度 | 空间复杂度 |
|----------|-----------|-----------|
| 邻接矩阵 | $O(|V|^2)$ | $O(|V|)$（递归栈最坏深度） |
| 邻接表 | $O(|V| + |E|)$ | $O(|V|)$ |

**来源对比**：BFS 空间来自辅助队列，DFS 空间来自递归调用栈。

### DFS 调用次数
与 BFS 完全一致：
- 无向图：调用次数 = 连通分量个数
- 有向强连通图：1 次

### 深度优先生成树
DFS 过程中首次访问某顶点时所经过的边 → 深度优先生成树。
- 邻接矩阵：唯一
- 邻接表：不唯一（取决于边链表顺序）

### 遍历序列与存储结构的关系
- **邻接矩阵**：表示唯一 → DFS 序列唯一
- **邻接表**：边结点顺序可变 → DFS 序列不唯一（选择题高频考点！）

### 用 DFS 实现逆拓扑排序
在 DFS 过程中，**当一个顶点的所有邻接点都访问完毕、即将退出递归时**输出该顶点，得到的序列就是逆拓扑排序序列。
```c
void DFS_InverseTopo(Graph G, int v) {
    visited[v] = true;
    for (w = FirstNeighbor(G, v); ...) {
        if (!visited[w]) DFS_InverseTopo(G, w);
    }
    print(v);  // 退出递归前输出 → 逆拓扑排序
}
```
此方法处理回路时需增加判断逻辑（判断是否正在访问回路上的顶点）。

## 类比

### 一句话比喻
**DFS 就像走迷宫——你站在入口，面前有三条岔路。你选了左边那条，走到尽头发现是堵墙（无路可走），退回来走中间那条，又遇到岔路，继续选一条走到底……直到把所有可能的路都探过一遍。这就是 DFS：一条道走到黑，撞墙了才回头。**

**对比 BFS：BFS 是「叫上一大帮朋友，一层一层往外搜」；DFS 是「孤身一人，死磕一条路」。找人时 BFS 更快（找到的一定最短），探迷宫时 DFS 更有探险精神。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 递归调用 | 你在迷宫里的每一步决策——深入时记下当前路口 |
| 递归栈 | 你身后的面包屑/记号——让你能原路返回 |
| visited 标记 | 走过的路口做标记——不再走回头路 |
| 回溯 | 走到死胡同，退回上一个路口试别的路 |
| 空间 $O(|V|)$ 最坏 | 一条直路走到黑，身后留了 $N$ 个路标 |
| DFS 序列不唯一 | 同一个迷宫，先走左边和先走右边结果不同 |
| 逆拓扑排序 | 退出迷宫时从最深的岔路往外汇报 |
| 处理回路 | 发现标记过的路口 → 你在绕圈！ |
