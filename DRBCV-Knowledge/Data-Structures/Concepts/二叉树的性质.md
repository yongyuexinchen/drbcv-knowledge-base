# 二叉树的性质（Binary Tree Properties）

## 类型判定
定理型 — 二叉树区别于普通树，有一系列精确的数学性质，主要围绕结点数、度、层数和高度之间的关系。

## 是什么
二叉树是 n（n≥0）个结点的有限集合，每个结点最多有两棵子树（左子树和右子树），且左右子树有次序之分。以下性质针对二叉树（包括满二叉树和完全二叉树）展开。

## 定理陈述与证明思路

### 性质 1：叶子结点与二分支结点的关系
**定理**：对于非空二叉树，叶子结点数 $n_0$ = 度为 2 的结点数 $n_2$ + 1。

**证明**：
- 设总结点数 $n = n_0 + n_1 + n_2$ …（1）
- 树的结点数 = 总度数 + 1，且二叉树中度 1 结点贡献 1，度 2 结点贡献 2：
  $n = n_1 + 2n_2 + 1$ …（2）
- （2）−（1）得：$n_0 = n_2 + 1$

此性质**高频考点**，选择题中经常直接使用。

### 性质 2：第 i 层最多结点数
**定理**：二叉树第 i 层至多有 $2^{i-1}$ 个结点（i ≥ 1）。

**证明**：每层结点数 = 上一层结点数 × 2（每个结点至多 2 个孩子），递推得等比数列。

### 性质 3：高度为 h 的二叉树最多结点数
**定理**：高度为 h 的二叉树至多有 $2^h - 1$ 个结点（此时为满二叉树）。

**证明**：等比数列求和 $\sum_{i=1}^{h} 2^{i-1} = 2^h - 1$。

### 性质 4：完全二叉树的高度
**定理**：具有 n 个结点的完全二叉树的高度为 $\lceil \log_2 (n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$。

**推导**：
- 高度为 h 的满二叉树最多 $2^h - 1$ 个结点 → $n \le 2^h - 1$
- 前 h−1 层满，至少 $2^{h-1}$ 个结点 → $n \ge 2^{h-1}$
- 得 $2^{h-1} \le n < 2^h$，取对数得两种等价格式

### 性质 5：完全二叉树的度分布
**定理**：已知完全二叉树结点总数 n，可唯一确定 $n_0, n_1, n_2$。
- 若 n 为**偶数**：$n_1 = 1$（必有一个单分支结点）
- 若 n 为**奇数**：$n_1 = 0$（没有单分支结点）
- 再由 $n_0 = n_2 + 1$ 和 $n = n_0 + n_1 + n_2$，可解出全部。

**推论**：$n_0 + n_2$ 必为奇数（因为 $n_0 + n_2 = 2n_2 + 1$）。

### 性质 6：完全二叉树中编号 i 的结点
若按层序编号（根为 1），则：
- 左孩子编号：$2i$
- 右孩子编号：$2i + 1$
- 父结点编号：$\lfloor i/2 \rfloor$
- 所在层次：$\lfloor \log_2 i \rfloor + 1$
- 是叶子结点的条件：$i > \lfloor n/2 \rfloor$

## 输入-输出空间
- **输入**：二叉树的结点总数 n 或结点编号 i
- **输出**：对应性质的计算结果

## 正例（≥2 个）
1. **满二叉树 h=3**：$n=7$，$n_0=4$，$n_2=3$，$n_0 = n_2 + 1$ ✓
2. **完全二叉树 n=12（偶数）**：$n_1=1$，$n_0=6$，$n_2=5$ ✓

## 反例/边界（≥1 个）
1. **只有根结点的二叉树（n=1）**：$n_0=1$，$n_2=0$，$1 = 0 + 1$ 仍成立
2. **所有结点只有左孩子（单链树）**：$n_2=0$，$n_0=1$，$1 = 0 + 1$ ✓

## 类比

### 一句话比喻
**二叉树的 $n_0 = n_2 + 1$ 就像一棵苹果树——你每多长一个树杈（度为 2 的结点），就一定会多结一个苹果（叶子结点）。因为每个树杈分两支，最终每条"死路"都是一片叶子。树杈越多，苹果越多，永远比树杈多一个。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| $n_0$（叶子结点） | 苹果（树梢末端） |
| $n_2$（二分支结点） | 分叉的树枝 |
| $n_1$（单分支结点） | 只往一个方向长的「偏枝」 |
| $n_0 = n_2 + 1$ | 苹果数 = 分叉数 + 1 |
| 满二叉树 | 完美修剪的果树——每层都挤满了 |
| 完全二叉树 | 从顶层开始一层层坐满的阶梯教室——最后一层可以不全满，但必须靠左坐 |
| 编号 $2i$ 找孩子 | 电影院座位——你坐 i 号，你孩子坐 2i 号（左边）和 2i+1 号（右边） |
