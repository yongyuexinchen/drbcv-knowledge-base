# 交易者方程（Trader's Equation）

## 类型判定
判别 — PA Agent下单前的最终数学裁定：胜率×预期回报>败率×预期风险，不通过则不下单，是交易决策的"一票否决权"

## 类比 ★
### 一句话比喻
**交易者方程 = 赌场老板的算盘**——赌场从来不赌"这一局开大还是开小"。赌场算的是：轮盘赌赢的概率是48.6%，赢了赔1倍——48.6%×1 < 51.4%×1，期望值为负。所以赌场不开轮盘（不交易），只开21点（胜率×赔率>败率×损失）。PA Agent就是赌场老板——任何一笔"下注"都要先打算盘：赢的钱×赢的概率 必须大于 输的钱×输的概率，否则宁可这把不开。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 胜率×回报 > 败率×风险 | 赌场算盘——不赌单局运气，只赌数学优势 |
| 三价（entry/stop/target） | 赌注三要素——押多少、最多输多少、赢了拿多少 |
| 方程不通过→不下单 | 赌场老板说"这把不开"——不是胆怯，是数学不站在我这边 |

## 是什么
PA Agent最终交易裁定的数学公式：**胜率 × 预期回报（TP1） > 败率 × 预期风险（stop距离）**，且RR（盈亏比）≥1.0。阶段一不得执行此检验——必须在阶段二确定了三价（entry/stop/take_profit）之后，在§10.3执行。这是下单前的最后一关：通过了→允许下单；不通过→不下单（不管信号多漂亮）。

## 正例（≥2 个）
1. **通过**：normal_channel做多，entry=100.00，stop=99.50（风险0.50），TP1=100.75（回报0.75），RR=1.5，胜率估计≈55%（通道顺势中等置信度）→ 55%×0.75=0.4125 > 45%×0.50=0.225 → 通过，允许下单
2. **不通过**：宽通道做多，entry=100.00，stop=98.50（风险1.50，接近通道宽度50%），TP1=101.00（回报1.00），RR=0.67<1.0 → 不通过，即使信号棒再好也不下单。优先收紧stop至更近结构失效位，或调整entry；仍无法≥1.0→reject

## 反例/边界（≥1 个）
1. **常见误解**：信号棒很漂亮就跳过方程直接下单——PA Agent系统中最常见的错误。信号棒质量≠数学优势。即使质量=strong、胜率估60%，如果回报不如风险（RR<1.0），方程仍然不通过。漂亮信号+差方程=不下单。**程序只认§10.3方程结果**。
2. **边界**：RR>1.0时程序会自动向外扩stop直至RR≤1.0或达到结构允许最宽失效位。但向外扩stop有上限（尖峰场景不超过尖峰高度50%）。**禁止缩小TP1来迎合RR**——结构目标有磁力效应。

## 详细解释

### 公式与执行顺序
```
1. 定entry（结构位/边界/回撤位）
2. 定TP1（最近有效结构目标）
3. 定TP2（更远结构目标：MM、通道对边等，必填但不参与方程）
4. 定stop（结构失效位）
5. 计算RR = 回报÷风险
6. 执行方程：胜率%×回报 > (100-胜率)%×风险
```

### RR处理规则
| RR | 处理 |
|----|------|
| >1.0 | 保持TP1/TP2，程序自动向外扩stop直至RR≤1.0 |
| =1.0~1.5 | 理想区间，直接检验方程 |
| <1.0 | 收紧stop或调整entry；**禁止**向外扩stop；仍<1.0→reject |

### 为什么阶段一禁止执行方程？
阶段一还没有确定三价。没有entry/stop/target就谈不上"风险"和"回报"。在阶段一就做数值检验等于用想象的数据算数学题——结果毫无意义。§0.3只是原则提醒，真正的数值检验必须在阶段二§10.3。

### 常见方程失败场景
- 止损过大（信号棒过长→止损>通道宽度40%→§10.2判"是"→放弃）
- 目标太近（区间中部入场→目标取不到足够距离→RR必然<1.0）
- 高波动环境（宽通道中即使方向对，止损距离可能超过通道宽度50%→放弃）
