# 普通交易区间（Trading Range）

## 类型判定
判别 — HH+HL交替出现的经典震荡，上下边界清晰（各≥2次测试），EMA水平，方向不确定，80%的突破失败

## 类比 ★
### 一句话比喻
**普通交易区间 = 菜市场的砍价大战**——买家说"太贵了，5块！"，卖家说"不行，至少8块！"——价格在5块和8块之间来回拉锯。每次有人想突破这个区间（比如有人喊"我出10块！"），所有人沉默两秒，然后继续回到5~8块的范围里砍。你在8块追买？下一秒就有人喊"其实只值5块"。聪明人在5块附近（下边界）顺着大方向买，在中间站着看戏。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| HH+HL交替无方向 | 菜市场买卖双方来回拉锯——没有谁占绝对上风 |
| 80%突破失败 | 每次有人喊高价/低价想打破僵局，市场的"惯性共识"两秒内就把他拉回来 |
| 仅顺direction一侧边界入场 | 只在方向偏多时在下边界买，偏空时在上边界卖；方向中性时看戏——不站队就不下单 |

## 是什么
周期频谱中最经典的双向震荡状态。无清晰方向偏好，上下边界各至少被测试2次，EMA几乎水平，K线大量重叠。方向判断为bullish时仅下边界做多，bearish时仅上边界做空，neutral时不下单。区间中部的入场基本等于抛硬币。

## 正例（≥2 个）
1. **标准交易区间+偏多**：上下边界清晰（各测试3次），EMA水平，K线在边界间来回→`trading_range`+`direction=bullish`，仅在下边界等做多信号，上边界不做空，中部不交易
2. **标准交易区间+偏空**：上边界测试2次、下边界测试3次，方向轻微偏空→`trading_range`+`direction=bearish`，仅在上边界等做空信号，下边界不做多

## 反例/边界（≥1 个）
1. **常见误解**：在区间中间追突破——这是区间交易中最经典的亏损模式。80%的区间突破会失败，在中间追等于在随机波动中下注。正确做法：永远只在边界等待，且方向必须与direction一致。neutral时任何突破都不追。
2. **边界**：方向完全丧失+EMA纠缠+任意入场期望为负→应输出extreme_tr而非trading_range。宁可多观察几根K线确认，也不要把extreme_tr误判为trading_range（后者对边界信号仍有交易价值）。

## 详细解释

### 判定条件（统一判定树→第三步区间态）
- 无满足3组的HH+HL或LL+LH序列
- 上下边界至少各测试2次
- EMA水平或斜率≤15°
- 大量K线重叠

### 核心交易逻辑
```
direction=bullish → 仅下边界/回撤做多（包括做多信号棒+§10.3通过）
direction=bearish → 仅上边界/反弹做空（包括做空信号棒+§10.3通过）
direction=neutral → 不下单（禁止双边刮头皮）
中间1/3位置 → 不交易，等价格到边界
突破 → 80%失败，不追（除非尖峰级突破+回踩测试成功+与direction一致）
```

### 为什么80%突破失败？
区间代表市场的均衡状态。突破需要足够强的外力（尖峰级突破=连续3~5根强趋势棒）才能打破均衡。普通的1~2根趋势棒突破，只是区间内的噪声，市场共识会迅速把价格拉回区间。
