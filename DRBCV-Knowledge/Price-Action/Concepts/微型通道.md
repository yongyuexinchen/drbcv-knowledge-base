# 微型通道（Micro Channel）

## 类型判定
判别 — 2~10根K线组成的极紧凑推进，回撤极小或没有，是尖峰在即时窗口上的临近状态

## 类比 ★
### 一句话比喻
**微型通道 = 地铁站里的窄扶梯**——只能并排站两个人，所有人都朝同一个方向走。你想逆着人流往回走？连转身的空间都没有。你唯一的选择是等人流走完（突破失败），再顺着人流的方向前进。第一个人试图逆行（第一个突破）99%被挤回去。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 微型通道的连续推进（2~10根） | 扶梯上紧密排列的人——间距极小、方向一致、没人停下 |
| 第一个突破尝试（80%失败） | 有人在扶梯上突然想逆行——立刻被后面的人推回去，根本没有空间 |
| 突破失败后顺势入场 | 等人群走完扶梯后，你顺着人流方向轻松走过去——阻力最小 |

## 是什么
周期频谱中紧挨尖峰的高强度状态，由2~10根K线组成，斜率极大，每根K线高低点连续同向推进，极少出现影线。与尖峰的关键区别：微型通道未达尖峰实体重叠<30%或创新极值标准。第一个突破尝试失败率>80%。

## 正例（≥2 个）
1. **5根连续小阳线紧贴EMA上倾**：实体重叠极少，不见阴线反弹→`cycle_position=micro_channel`，必填`spike_stage`，只做顺势，等第一个向下突破失败后做多
2. **3根紧凑阴线下跌**：斜率极大，每根收盘接近低点→micro_channel，禁止抢反弹；等向上突破失败后顺势做空

## 反例/边界（≥1 个）
1. **常见误解**：看到微型通道就追趋势——但微型通道中第一个突破尝试失败率>80%，追突破等于在高点买入后被假突破打止损。正确做法是**等突破失败后再顺势入场**。
2. **边界**：同时满足尖峰最低标准（2根+实体重叠<30%）时，**优先spike而非micro_channel**。微型通道是尖峰在即时信号窗口上的表现，但裁决优先级低于尖峰。

## 详细解释

### 裁决规则（spike vs micro_channel）
```
同时满足尖峰最低标准 → 优先 cycle_position=spike
仅2~10根紧凑推进但未达尖峰标准 → micro_channel + 必填 spike_stage
禁止同一窗口既标spike又标micro_channel为主状态
```

### 核心交易逻辑
- 上涨微型通道：向下突破失败后做多
- 下跌微型通道：向上突破失败后做空
- 止损：突破极点外1跳动
- 目标：微型通道高度或尖峰测量移动（MM）
- **绝对不逆势**，不在微型通道中做反转

### 为什么第一个突破80%失败？
微型通道代表极强的方向共识。第一次反向突破只是少数交易者试图逆流，共识力量远大于个别反抗。只有当反向力量累积到足以形成有效跟随（2根以上反向趋势棒+收盘确认），才能考虑方向可能改变。
