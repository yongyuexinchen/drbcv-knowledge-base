# 闸门机制（Gate Mechanism）

## 类型判定
程序 — PA Agent阶段一的诊断闸门，定义了"市场能不能被分析/交易"的三道关卡（§0~§2），任何一道卡住就wait不进入阶段二，并内置四条全局硬禁令作为全库最高优先级约束

## 类比 ★
### 一句话比喻
**闸门机制 = 机场安检三道关卡**——第一道：你带了身份证吗（数据够吗 §1.1）？没带？回家。第二道：行李能过X光机吗（能识别周期吗 §1.2）？东西太乱看不清？退回去。第三道：你身上有可疑物品吗（极端混乱吗 §1.3）？有警报？直接扣下。三道全过了才让你登机（进入阶段二）。另外还有四条"全机场禁烟"的告示贴在墙上（四条全局禁令）——从进门到登机，任何地方违反都不行。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| §1.1 数据足够吗？K线<20根→wait | 没带身份证——连安检门都进不去 |
| §1.2 能识别周期吗？unknown→wait | 行李过X光模糊不清——看不清就不让进，不瞎猜 |
| §1.3 极端混乱吗？extreme_tr→wait | 安检门报警——不管是什么原因，先退回去再查 |
| 四条全局禁令 | 全机场禁烟——任何时间任何地点违反都不行，覆盖所有其他规则 |

## 是什么
PA Agent阶段一（读懂市场）的诊断闸门，按顺序执行§0~§2三个大章节，每一步只有"是/否"两个出口。§0做总原则定性判断（看得懂/具备分析条件），§1做三个硬性闸门（数据/周期/极端混乱），§2做多空方向判断（惯性/背景/Always In/惯性强度）。任何闸门卡住→`gate_result=wait`，不进入阶段二。四条全局禁令作为全库最高优先级约束，覆盖所有专篇。

## 正例（≥2 个）
1. **阶段一全部通过**：K线≥20根（§1.1通过）→识别为normal_channel（§1.2通过）→不是extreme_tr（§1.3通过）→EMA上倾+HH+HL+bullish（§2通过）→`gate_result=proceed`，进入阶段二按通道策略找入场
2. **§1.3卡住**：K线充足、周期识别为trading_range，但方向完全丧失、EMA纠缠、任意入场期望为负→§1.3"是"→`gate_result=wait`，不进入阶段二，输出"不下单，等待市场选择方向"

## 反例/边界（≥1 个）
1. **最常见的AI错误**：阶段一`gate_result=proceed`，但§2.5判断惯性不足——AI错误地把gate_result改成wait。**正确做法**：§2.5答"否"仍应proceed，只是阶段二提高门槛做谨慎入场，不能直接阻断。惯性暂时中断不构成gate=wait的条件——只有§1.1/§1.2/§1.3真正卡住时才wait。

## 详细解释

### 完整的闸门序列
```
§0 总原则
  ├─ 0.1 看得懂吗？
  ├─ 0.2 具备分析条件吗？
  └─ 0.3 交易者方程（原则提醒，不在此执行）

§1 是否可以决策（三道硬闸门）
  ├─ 1.1 数据够吗？（K线≥20根，程序判定）
  ├─ 1.2 能识别周期吗？（必须归入8种状态之一）
  └─ 1.3 极端混乱吗？（extreme_tr → wait）

§2 多空方向（非硬闸门，不阻断）
  ├─ 2.1 有明确惯性方向吗？
  ├─ 2.2 长程背景 vs 近期方向？
  ├─ 2.3 当前方向判断
  ├─ 2.4 Always In
  └─ 2.5 惯性强度（否≠wait，阶段二提高门槛）
```

### 四条全局硬禁令（全库最高优先级）
闸门机制内置以下四条禁令，覆盖所有专篇和策略文件：
1. **禁止逆势**：order_direction不得逆direction/Always In/近期主方向。禁止反手单、MTR反转单、通道边界逆势刮头皮
2. **禁止追高潮**：climax_risk预警/触发后，禁止追原方向（含SCS尖峰追单、市价追突破）
3. **禁止仓位管理**：不输出手数、仓位比例、加仓减仓、移止损、跟踪止损
4. **不依赖成交量**：成交量不作为识别或下单必要条件；无成交量或不可比时完全忽略

### 关键执行规则
- 阶段一gate_result=proceed之前，不得进入阶段二逻辑
- §0.3交易者方程在阶段一只是原则提醒——真正的数值检验在阶段二§10.3
- §2.5惯性不足≠gate=wait；只有§1.1/§1.2/§1.3卡住才wait
- §14禁止行为扫描是阶段二的最后一道关——即使§10.3通过了，§14触发任一条→立即改成不下单
