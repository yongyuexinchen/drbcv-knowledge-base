# 变量自动发现（Variable Discovery）

## 类型判定
程序型 — 系统的自学习机制：自动生成候选交互变量，用 XGBoost + SHAP 筛选真正有预测力的新特征，持续扩展传导图谱。

## 类比 ★
### 一句话比喻
你开了一家侦探社，专门分析「什么线索能破案」。最初你只记录了5个线索：指纹、DNA、监控、动机、不在场证明。变量自动发现就是自动生成新线索：指纹×DNA 的交叉项、指纹在案发前3天的变化、指纹+监控同时出现时的权重——然后用300个已破案件训练XGBoost，SHAP值告诉你「指纹+监控同时出现的组合」对破案贡献度排第一，于是把它加进常规线索库。系统就这样自己发现新规律。

### 生活映射
| 概念世界       | 现实世界                                  |
| ---------- | ------------------------------------- |
| 交互项生成      | 侦探自动尝试线索组合——「指纹×DNA」「动机×不在场证明」        |
| 滞后矩阵构建     | 不仅看案发当时的线索，还看案发前1~30天每条线索的变化轨迹        |
| XGBoost 预测 | 用300个已破案子训练模型——哪个线索组合最能预测凶手           |
| SHAP 筛选    | 排名——所有线索/组合按对破案的贡献度排序，只留前10名          |
| 时间序列交叉验证   | 不能拿未来的案子训练模型去预测过去的案子——时间上先训练前面的，预测后面的 |
| 稳定性评分      | 这个线索组合在3个不同时间段都排前10吗？不是的话可能只是巧合       |
| 淘汰机制       | 每周重新跑一次，一个月内3次排不进前10的组合自动淘汰           |

## 是什么
变量自动发现（Variable Discovery）是宏观传导发现引擎的自学习模块。流程：① 生成候选特征——交互项（板块A收益率 × 板块B收益率）、滞后交叉项（板块A lag N × 板块B）、最优滞后搜索（1~30天扫描）；② 用 XGBoost 预测每个目标板块的未来收益率；③ SHAP 值筛选最具信息量的特征；④ 时间序列交叉验证防止过拟合。新变量可加入传导图谱，定期回测淘汰失效变量。

## 输入-输出空间
- **输入**: 各板块日收益率序列 {sector: pd.Series}；指定的 max_lag、n_features、n_splits
- **输出**: 每个目标板块的 top-K 新变量列表，每个变量含 name、importance、cv_score、stability、source_assets
- **前置条件**: 足够的时序长度（建议 >500 个交易日）；板块收益率已对齐

## 正例（≥2 个）
1. **发现「黄金×能源」交互项**: 系统自动发现 `gold_lag3 × energy_lag1` 对预测 A 股防御板块收益率的信息量超过单变量黄金或能源——这揭示了一种「避险+通胀」双信号触发模式。
2. **最优滞后自动搜索**: 系统扫描 1~30 天滞后，发现「美债10Y收益率 lag 12」对预测A股北向资金净流入的预测力最强——比固定 lag 3 好 40%，更新传导图边属性。

## 反例/边界（≥1 个）
1. **过拟合风险**: 交互项 + 滞后扫描的组合爆炸（12板块 × 12板块 × 30 lags = 4320 个候选特征）远超样本量，如果不做时间序列交叉验证和 SHAP 筛选，会选出纯噪音特征。系统用 `TimeSeriesSplit(n_splits=3)` + 稳定性评分（3个时间窗口的一致排名）双重防护。
2. **发现 ≠ 因果**: 变量发现只是说「A lag3 × B 能很好地预测 C」，不说明 A→B 存在因果传导。这是预测模型，需要 PCMCI 来确认因果方向——两者互补。
3. **计算代价**: 12个板块 × XGBoost 训练 = 每次运行约 2-5 分钟。所以 Orchestrator 中 `run_variable_discovery=False` 为默认，每周运行一次。

## 详细解释

### 四步流程
```
Step 1: 生成候选
  - 交互项: sector_i × sector_j (∀ i≠j)
  - 滞后交互项: sector_i_lag(k) × sector_j (k=1..max_lag)
  - 最优滞后搜索: 对每个 (source, target) 扫描 lag 1~30

Step 2: 训练 XGBoost
  - 目标: target_sector(t+1) 的未来收益率
  - 特征: 全部候选变量 + 原始板块收益率

Step 3: SHAP 筛选
  - 计算每个特征的 mean(|SHAP|)
  - 取 top N 个特征作为「新发现变量」

Step 4: 稳定性验证
  - 将数据按时间切为 3 段
  - 新变量需在 ≥ 2 段中均排进 top N
```

### 淘汰机制
- 每周运行一次完整发现
- 已加入图谱的边缘变量，连续 4 周稳定性 < 0.5 则标记为 inactive
- 防止图谱无限膨胀
