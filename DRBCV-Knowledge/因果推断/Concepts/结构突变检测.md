# 结构突变检测（Structural Break Detection）

## 类型判定
判别型 — 用 CUSUM 和 Chow 检验检测时间序列关系中的结构性断裂，判断因果传导的稳定性与时变特征。

## 类比 ★
### 一句话比喻
一对情侣的吵架频率每月统计一次。前 3 年稳定在月均 2 次，搬到一起住之后突然月均 8 次，再过半年又回落。结构突变检测就是那个八卦的朋友，在时间轴上画一条红线：「你们的关系结构在搬家那个月发生了显著断裂，之前和之后的吵架模式是两个完全不同的世界。」如果不用这个方法，你会把 3 年的数据混在一起算平均，得出「月均 4 次」——既低估了甜蜜期，也掩盖了同居危机的暴烈。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 结构突变点 (break point) | 搬家的那个月——在那之前和之后，关系的统计规律完全不同 |
| CUSUM 累积和 | 每月检查「累计吵架数偏离预期的程度」，一旦偏离累积到超过警戒线，报警 |
| Chow 断点检验 | 搬家后回头检验：「把数据在搬家那个月切成两段，两段的回归线是不是差太多了？」 |
| 传导稳定性 | 关系模式是否一致——如果前 3 年「他生气→她冷战」的规律在搬家后变成了「他生气→她直接吵」，传导链已经断了 |
| 时效性 | 用 5 年前的数据建的模型，现在还准吗？如果不准，可能发生过结构突变 |

## 是什么
结构突变检测是检验时间序列关系（包括因果传导链）是否在某未知或已知时间点发生结构性断裂的方法。CUSUM（累积和检验）通过监测递归残差的累积和是否超出置信区间来自动检测突变点；Chow 断点检验在候选断点处将样本分为两段，用 F 检验比较两段回归系数是否显著不同。在因果推断中用于验证传导关系的稳定性与时效性。

## 输入-输出空间
- **输入**: 包含可能突变的回归/因果模型残差序列；已知或未知的候选断点日期
- **输出**: 是否存在结构突变（是/否）；突变点位置 τ；突变前后模型参数的对比
- **前置条件**: 有足够的突变前后样本量；残差满足基本假设（CUSUM 需 i.i.d.，Chow 需同方差）

## 正例（≥2 个）
1. **金融危机前后因果链变化**: 检验「美债利率→新兴市场资本流动」的 Granger 因果在 2008 年前后是否发生结构性断裂——2008 年后传导强度和方向可能完全不同。
2. **政策出台前后的传导机制变化**: 检验「央行逆回购利率→银行间拆借利率」的传导系数在利率市场化改革前后是否发生结构突变——衡量改革的实质效果。

## 反例/边界（≥1 个）
1. **渐变而非突变**: 如果传导关系是缓慢漂移的（如全球化进程中贸易弹性逐年变化），Chow 检验的「单点断裂」假设不适用——需改用时变参数模型或滚动窗口检验。
2. **多重突变**: CUSUM 和 Chow 的单断点假设在面对多次突变（如多次政策干预）时可能识别假断点或漏检——需用 Bai-Perron 多断点检验。
3. **断点内生性**: 如果断点是基于数据特征选定的（而非外生事件），Chow 检验的 p 值会被严重低估——需用 Andrews 未知断点检验修正。

## 详细解释

### CUSUM 累积和检验
递归估计模型，计算标准化递归残差 ω_t 的累积和 W_t = (1/σ̂) · Σ_{i=k+1}^{t} ω_i，绘制 W_t 随时间变化的曲线，超出 ±λ·√(T-k) 置信边界即报警。不需要预设断点位置，适合探索性分析。

### Chow 断点检验
在候选断点 τ 处：
1. 全样本回归，得 RSS（残差平方和）
2. 分两段回归（1~τ 和 τ+1~T），得 RSS₁ + RSS₂
3. F = [(RSS - (RSS₁+RSS₂))/k] / [(RSS₁+RSS₂)/(T-2k)]
4. 显著 → 拒绝「无结构突变」原假设

### 两者配合使用
CUSUM 扫描 → 定位候选断点 → Chow 检验确认 → 分段时间序列分析
