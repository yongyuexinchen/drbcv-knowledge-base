# Granger 因果检验（Granger Causality Test）

## 类型判定
判别型 — 基于 VAR 模型的统计检验，判断一个时间序列的历史值是否能显著改善对另一个序列的预测。

## 类比 ★
### 一句话比喻
天气预报员有两套方案预测明天会不会下雨：方案 A 只看历史降雨数据，方案 B 额外加上昨天的湿度数据。如果方案 B 的预测误差明显更小，湿度就「Granger-导致」了降雨预测的改善。注意：这不等于湿度「导致」了下雨——云层才是物理原因，湿度只是比雨先变化而已。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| VAR 模型 | 一个联立方程系统——同时用温度、湿度、气压互相预测对方明天会怎样 |
| F 检验 | 比较两个预测模型的误差——不是比谁准，是比「加入新变量后改善是否大到不可能是巧合」 |
| 滞后阶数 | 用过去几天的数据来预测——用昨天还是用过去一周，结论可能完全不同 |
| 「Granger 因果 ≠ 真正因果」 | 公鸡打鸣「Granger-导致」日出——因为它总在日出前叫，但打鸣不是日出的物理原因 |
| 预测误差方差 | 衡量「猜得有多不准」——方差越小，预测越靠谱 |

## 是什么
Granger 因果检验基于向量自回归（VAR）模型，通过 F 检验比较两个嵌套模型的预测误差：受限模型只用 Y 的自身历史预测 Y，非受限模型额外加入 X 的历史值。如果加入 X 后预测误差显著降低，则认为「X Granger-导致 Y」。注意这是预测性因果（predictive causality），不等同于结构性因果（structural causality）。

## 输入-输出空间
- **输入**: 两个（或多个）平稳时间序列 X(t), Y(t)；选定的滞后阶数 p
- **输出**: F 统计量、p 值——判断 X→Y 和 Y→X 两个方向的 Granger 因果性
- **前置条件**: 序列必须平稳（否则需先差分）；关系为线性；滞后阶数 p 需事先选定（AIC/BIC 辅助）

## 正例（≥2 个）
1. **货币供应→通胀**: 检验 M2 增速的历史值是否能显著改善 CPI 的预测——经典宏观经济学 Granger 因果场景。
2. **舆情→股价**: 检验微博情绪指数（X）是否 Granger-导致次日个股收益率（Y）——看情绪是否包含股价自身历史之外的预测信息。

## 反例/边界（≥1 个）
1. **遗漏变量导致伪因果**: 如果 X 和 Y 同时受 Z 驱动（且 Z 未被纳入 VAR），可能检测出显著的 Granger 因果，但实际上 Z 才是源头。
2. **非线性关系漏检**: 如果 X 通过「阈值触发」影响 Y（如 X>0 时 Y 跳变），线性 VAR 的 F 检验可能不显著——Granger 因果只测线性预测改善。
3. **非平稳序列陷阱**: 对带趋势的序列直接做 Granger 检验会产生伪回归——必须先差分至平稳。

## 详细解释
两步：① 估计 VAR(p) 模型——Y_t = α + Σβ_i·Y_{t-i} + Σγ_j·X_{t-j} + ε_t；② F 检验 H0: 所有 γ_j = 0（即 X 的历史对预测 Y 无贡献）。拒绝 H0 即认为 X Granger-导致 Y。核心直觉：如果未来不能被过去预测，那就没有 Granger 因果。滞后阶数 p 的选择对结果敏感——常用 AIC 或 BIC 准则辅助。
