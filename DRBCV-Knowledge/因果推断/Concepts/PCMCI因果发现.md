# PCMCI 因果发现（PC + MCI）

## 类型判定
程序型 — 两阶段因果发现算法：PC 阶段构建因果骨架，MCI 阶段用条件独立性检验精炼，能区分直接因果、中介因果和混淆关系。

## 类比 ★
### 一句话比喻
刑警队调查 5 个嫌疑人之间的信息传递链：第一阶段（PC）——逐个排查「A 和 B 有没有直接联系」，把明显无关的线剪掉，得到一个粗糙的关系网；第二阶段（MCI）——对每根剩下的线做终审：「在控制其他所有人的情况下，A 和 B 还有联系吗？」如果控制 C 后 A-B 断了，说明 A-B 是经过 C 的间接关系。最终报告精确到「A 直接影响 B」「C 是中介」「D 只是和 A、B 共享一个幕后黑手」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| PC 算法 | 第一轮排查——让每个嫌疑人和其余人两两对质，剪掉「明显不认识」的边 |
| MCI 阶段 | 第二轮终审——对剩余的边，控制「其他所有人」后检验是否还有独立关联 |
| 条件独立性检验 | 控制嫌疑人 C 后，A 和 B 还有关系吗？有→直接因果，没有→间接/混淆 |
| 直接因果 (direct) | A→B，没有中间商赚差价 |
| 中介因果 (mediated) | A→C→B，C 是传话筒——控制 C 后 A-B 关联消失 |
| 混淆关系 (confounded) | 幕后黑手 Z 同时操纵 A 和 B——控制 Z 后 A-B 关联消失，但不是因果 |

## 是什么
PCMCI（Peter-Clark + Momentary Conditional Independence）是 Runge et al. (2019) 提出的两阶段因果发现算法，专为时间序列设计。第一阶段 PC 算法以迭代方式移除不显著的条件独立性边，构建因果骨架；第二阶段 MCI 对每条保留的边做严格的条件独立性检验，条件集包含所有相关变量的父节点，有效控制假阳性。能区分三类关系：直接因果（direct link）、中介因果（indirect/mediated path）、混淆驱动（common driver / confounded）。

## 输入-输出空间
- **输入**: 多变量时间序列数据集 {X₁(t), X₂(t), ..., Xₙ(t)}；最大滞后阶数 τ_max；显著性水平 α
- **输出**: 有向图 G，每条边标注为 direct / mediated / confounded，以及因果效应强度
- **前置条件**: 因果充分性（所有混淆变量已观测）；无反馈环在单步内完成；忠实性假设

## 正例（≥2 个）
1. **气候系统因果网**: 从厄尔尼诺指数、海温、气压、降水等多变量时序中，区分哪些是直接因果关系、哪些是经海洋-大气耦合的中介路径——PCMCI 的标准应用场景。
2. **宏观经济传导链**: 分析利率→信贷→投资→GDP 的传导路径——PCMCI 可区分「利率直接影响投资」和「利率经信贷中介影响投资」。

## 反例/边界（≥1 个）
1. **计算代价高**: 变量数 N > 50 时，PC 阶段的条件独立性检验组合爆炸——需先用领域知识或 LASSO 做变量预筛选。
2. **未观测混淆假设**: PCMCI 假设所有混淆变量已观测（因果充分性），如果存在隐藏的混淆因子，可能错误标记 direct 边。
3. **线性条件独立性默认**: 标准 PCMCI 用偏相关做条件独立性检验，只能检测线性条件独立——对非线性依赖需替换为基于互信息的检验（如 CMIknn）。

## 详细解释

### 阶段一：PC 算法（构建骨架）
```
1. 初始化：所有变量间全连接（包括跨时间的自回归边）
2. for p = 0, 1, 2, ..., p_max:
      for 每条边 (X_{t-τ}, Y_t):
          对 Y_t 的父节点集合中的每个大小为 p 的子集 S：
              条件独立性检验：X_{t-τ} ⟂ Y_t | S
              如果独立 → 移除此边
3. 定向规则（利用 v-结构：X→Z←Y）
```

### 阶段二：MCI（矩条件独立性）
对 PC 保留的每条边 X_{t-τ} → Y_t：
- 条件集 = X 的父节点 ∪ Y 的父节点（包括 Y 自身的自回归项）
- 检验：X_{t-τ} ⟂ Y_t | (父节点(X) ∪ 父节点(Y))
- 如果仍显著 → **direct**（直接因果）
- 如果 PC 阶段显著但 MCI 阶段不显著 → **mediated** 或 **confounded**

### 关键参数选择
| 参数 | 建议 | 影响 |
|------|------|------|
| τ_max | 基于互信息衰减选定 | 太小遗漏长滞后因果，太大增加假阳性 |
| α | 0.05（标准） | 更小→更保守（少边但假阳性少） |
| p_max | 默认 = τ_max | 控制最大条件集大小 |
