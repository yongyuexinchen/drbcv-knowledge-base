# 传递熵（Transfer Entropy）

## 类型判定
判别型 — 基于信息论的非参数方法，度量从一个时间序列到另一个时间序列的定向信息流，不依赖线性假设。

## 类比 ★
### 一句话比喻
你去看双人花样滑冰比赛，想知道「是男选手在引领女选手，还是反过来」。你不假设他们遵循任何固定舞步（不建参数模型），只是观察：知道男选手上一秒的动作，能让你少猜错女选手下一秒动作多少？减少的「猜错量」就是传递熵。如果男→女的传递熵远大于女→男，那男的就是领舞者。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 信息流（比特） | 「猜错量」的减少——知道 A 的过去让我少猜错 B 多少，单位是 bit |
| kNN 互信息估计器 | 不用尺子量距离，而是「看邻居」——在数据点周围找最近的 k 个邻居来估算概率密度 |
| 非参数 | 不预设舞步——不假设数据服从正态分布、线性关系等任何特定模型 |
| 非高斯鲁棒 | 金融数据经常出现「肥尾」（极端值比正态分布多得多），传递熵不会被几个暴涨暴跌带偏 |
| 方向性 | TE_{X→Y} ≠ TE_{Y→X}——信息流有方向，和 Granger 因果一样是非对称的 |

## 是什么
传递熵（Transfer Entropy）是 Schreiber (2000) 提出的信息论度量，量化从 X 到 Y 的定向信息流：TE_{X→Y} = I(Y_t ; X_{t-1}, ..., X_{t-p} | Y_{t-1}, ..., Y_{t-p})，即在已知 Y 自身历史的条件下，X 的历史能额外提供多少关于 Y_t 的信息。用 Kozachenko-Leonenko kNN 估计器实现互信息计算，无需假设数据分布，可捕获非线性依赖。

## 输入-输出空间
- **输入**: 两个时间序列 X(t), Y(t)；滞后阶数 p；kNN 参数 k（邻居数，通常 3-10）
- **输出**: TE_{X→Y} 和 TE_{Y→X} 的值（单位：bit 或 nat），以及显著性水平（通过代理数据检验）
- **前置条件**: 序列需平稳（或去趋势）；k 的选择影响偏差-方差权衡

## 正例（≥2 个）
1. **金融风险传导**: 检验美股波动率（X）→ A 股波动率（Y）的信息流——传递熵能捕捉「美股大跌时 A 股恐慌加剧」的非线性放大效应，而 Granger 可能漏检。
2. **高频交易信号**: 检验订单流不均衡指标（X）是否向中间价变动（Y）传递信息——捕获非线性超前-滞后关系。

## 反例/边界（≥1 个）
1. **小样本不可靠**: kNN 估计器在样本量 < 200 时偏倚严重——传递熵需要较长的时序数据才能给出稳定估计。
2. **不区分直接/间接**: 如果 X→Z→Y 是真实因果链，TE_{X→Y} 可能显著，但不代表 X 直接作用于 Y——这是传递熵的核心局限，PCMCI 正是为解决此问题设计的。
3. **滞后阶数敏感**: p 选太小遗漏信息，选太大引入噪声——需配合互信息滞后分析选定。

## 详细解释
核心公式：TE_{X→Y} = Σ p(y_t, y_{t-1}^{(p)}, x_{t-1}^{(p)}) · log₂[p(y_t | y_{t-1}^{(p)}, x_{t-1}^{(p)}) / p(y_t | y_{t-1}^{(p)})]，即条件 KL 散度。Kozachenko-Leonenko 估计器通过数据点间的 kNN 距离估计局部概率密度，避免了直方图估计的维度灾难。显著性检验用代理数据（shuffle X 的时间顺序）生成零分布。对金融数据的优势：① 不假设线性/正态；② 对异常值的敏感度低于 Pearson 相关。
