# 因果推断方法概述（用户提供）

## 偏互相关 (Partial Cross-Correlation)
在时间偏移后计算 Pearson 相关系数，并用 Fisher z-变换构建置信区间。通过回归残差法排除第三方变量的混淆效应。适合检测线性关联的滞后模式。

## Granger 因果检验
基于 VAR 模型的 F 检验。检验加入 X 的历史值后，Y 的预测误差是否显著降低。适合检测线性因果方向，但无法处理非线性关系。

## 传递熵 (Transfer Entropy)
基于 Kozachenko-Leonenko kNN 的互信息估计器，度量从 X 到 Y 的信息流。非参数方法，可捕获非线性依赖，对金融时序的非高斯特性更鲁棒。

## PCMCI (PC + MCI)
PC 算法构建因果骨架 → MCI 阶段条件独立性检验。能区分直接因果（direct）、中介因果（mediated）和混淆关系（confounded），是最严格的因果发现方法。

## 结构突变检测
CUSUM 累积和检验 + Chow 断点检验，检测传导关系的稳定性。揭示传导链是否在市场环境变化时发生结构性断裂，帮助判断关系的时效性。
