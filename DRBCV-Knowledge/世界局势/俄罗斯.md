# 俄罗斯（国家总览）

## 基本情况
- 政治体制：总统制联邦（"主权民主"，实际个人集权）
- 执政党：统一俄罗斯党（普京领导）
- 2026年现状：对乌战争第5年，经济靠军工维持正增长（战争凯恩斯主义），西方制裁持续

## 权力结构（2026）
```
普京（总统，1952年生，可执政至2036）
  ├─ 西罗维基（强力部门派）：绍伊古/帕特鲁舍夫/格拉西莫夫
  ├─ 文官派：米舒斯京（总理）/拉夫罗夫（外长）
  ├─ 轮庄派：梅德韦杰夫（安全会议副主席）
  ├─ 地方封臣：卡德罗夫（车臣）
  └─ 失控资产：普里戈任（瓦格纳，2023坠机）
```

## 核心立场
- 对北约：视东扩为生存威胁（2022年战争的首要叙事）
- 对乌克兰：乌东四州已写入宪法（宪法第67条），不承认可让渡
- 对西方：制裁下的"转向东方"（中俄经贸+金砖+去美元化）

## 2026年关键变量
- 战争消耗 vs 军工经济可持续性
- 普京健康与"后普京时代"布局（帕特鲁舍夫之子、米舒斯京等接班人梯队）
- 中俄关系深度（俄对华能源依赖加深）
