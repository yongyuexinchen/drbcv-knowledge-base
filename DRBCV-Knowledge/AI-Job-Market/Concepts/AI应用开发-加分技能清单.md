# AI应用开发-加分技能清单

## 是什么（What）

加分技能指出现在 JD「加分项/优先条件」中的技能 — 不是你必须有，但有了就能从 20K 跳到 35K+。核心逻辑：**基础技能决定能不能进门，加分技能决定进门后的楼层**。

这就像玩游戏：必备技能是你的"等级"（等级不够进不了副本），加分技能是你的"装备"（等级一样，装备好的人DPS高3倍）。

## 为什么重要（Why）

- **高薪三要素**（来自高薪组 vs 低薪组的技能频率分析）：
  1. 系统工程能力（分布式/微服务/C++/Go）→ 薪资 +50%以上
  2. 模型工程化（推理优化/模型部署/量化/微调）→ 薪资 +30-50%
  3. 多模态 + 复杂Agent编排 → 薪资 +20-30%

- 用户策略：先稳住基础盘（RAG+Agent+Prompt=20-25K），入行1年后再补加分技能冲40K+

## 怎么做（How）

### 加分技能投资优先级

```
优先投入（性价比高，学了立刻有竞争力）:
  多模态（语音/图像+LLM）→ 模型微调 LoRA/SFT → 推理优化

按需投入（看目标公司技术栈）:
  Java/Go/C++ → K8s → 分布式 → React/Vue

暂缓投入（占坑但初级岗不太要求）:
  模型量化 → 模型蒸馏 → Rust → 消息队列
```
