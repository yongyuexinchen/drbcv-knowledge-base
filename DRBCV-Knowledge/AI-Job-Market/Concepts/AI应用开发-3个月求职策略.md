# AI应用开发-3个月求职策略

## 是什么（What）

3个月求职策略是一个针对"Python初学者+无AI岗位经验"背景、目标深圳AI应用开发工程师（目标薪资20-25K）的冲刺计划。核心逻辑：**基础技能决定能不能进门（第1-2月），加分技能决定进门后的楼层（第3月），作品决定议价权（贯穿全程）**。

这就像准备一场演出：第1个月练基本功（不掉链子），第2个月排节目（有东西可演），第3个月彩排+登台（真的演给别人看）。

## 为什么重要（Why）

- 用户现状：Python+SQL基础、Docker入门、正在学黑马V6.5、存款~25万
- 核心缺口：RAG(51%岗位要)、Agent/LangChain(70%)、Prompt Engineering(40%)、向量数据库、FastAPI
- 删除计划中的Java基础（3个月学不到面试水平，Python路线薪资高一档 — 25-38K vs 15-24K）
- 调研数据：深圳AI应用开发岗中位22K、P25-P75: 16K-38K；经验不限岗中位38K；1-3年岗中位20K

## 怎么做（How）

### 三阶段冲刺框架

```
第1-4周：地基搭建
  删除: Java基础
  新增: Prompt工程 + RAG全流程项目（个人知识库问答系统）
  要点: Docker够用即可(1周)，Prompt是所有AI开发的基础
  里程碑: GitHub仓库 personal-rag-qa，有README+测试

第5-8周：技能深化
  核心: Agent编排（智能客服系统）+ API工程化
  要点: LangGraph多Agent协作 + 异常处理/限流/降级
  里程碑: GitHub仓库 multi-agent-cs，能演示完整路由

第9-12周：整合冲刺
  核心: AI伴侣MVP + 简历打磨 + 面试冲刺
  要点: 简历写3个项目(RAG问答+Agent客服+永月MVP)，每个能口述3分钟
  里程碑: 一段演示视频 + 投递10-15份简历
```

### 投递策略（第12周）

```python
# 这就像钓鱼：不同钓竿钓不同的鱼

首选（薪资20-35K）:
  AI创业公司 → Python路线 → RAG+Agent匹配度最高
  量化金融 → 数据背景加分

次选（薪资18-28K）:
  互联网公司AI部门 → 流程规范 → 成长空间大

排除:
  传统企业Java路线 → 薪资低(15-20K) → 且你的Java达不到要求
```

### 面试自检清单（每一项要能流畅回答3分钟）

- [ ] RAG完整流程？每个环节的优化手段？
- [ ] 你的RAG项目遇到了什么问题？怎么解决的？
- [ ] Agent路由逻辑怎么实现？怎么防止Agent跑偏？
- [ ] FastAPI依赖注入、异常处理怎么设计？
- [ ] Docker Compose怎么编排多服务？
- [ ] AI伴侣项目的记忆系统怎么设计的？为什么这样设计？

### 学习原则

1. **每天200行手写Python**：面试没有AI辅助
2. **先出效果，再学原理**：先用API搭出RAG，再理解Embedding
3. **产出导向**：每学一个模块=一个可展示的GitHub仓库
4. **黑马是课本，自己是习题**：等黑马讲完再动手=来不及
5. **不做前端**：curl+Swagger够用，前端花时间且面试不考
