# AI应用开发-必备技能清单

## 是什么（What）

基于深圳 70 条 AI 应用开发 JD 的统计分析，"必备技能"指出现在「任职要求」中、不满足就无法过简历关的技能。按覆盖率排序，**Python + LLM + Agent + RAG + Prompt 工程构成了核心五件套**。

这就像考驾照：科目一（Python基础）不过就没资格上路，科目二（RAG+Agent）决定了你能不能开，科目三（Prompt工程）决定了你开得好不好。

## 为什么重要（Why）

- 用户目前会 SQL + Python 基础，但缺的是中间层 — RAG (51%岗位要)、Agent/LangChain (70%)、Prompt Engineering (40%)
- 好消息：这三个都不需要数学，只需要 Python + 看文档 + 动手做项目，3个月够
- 第1梯队（不会没法面试）：Python → LLM基础概念 → Prompt Engineering → API开发
- 第2梯队（面试常问）：RAG → Agent/LangChain → 向量数据库 → Docker
- 第3梯队（加分）：FastAPI → SQL → Linux → Git

## 怎么做（How）

### 核心五件套详解

| 排名 | 技能 | 覆盖率 | 一句话解释 |
|------|------|--------|-----------|
| 1 | 大模型/LLM | 100% | 理解Transformer/Embedding/RAG概念，不用训练模型 |
| 2 | Python | 71% | 独立写项目，不只是调API |
| 3 | Agent/LangChain | 70% | 用LangChain/LangGraph编排多步骤AI任务 |
| 4 | SQL | 56% | 数据查询 + NL2SQL项目 |
| 5 | RAG | 51% | 文档→检索→生成的完整流程 |

### 技能缺口对照

```
你已会的：SQL ✅、Python ✅、大模型基础概念（学习中）

找工作前必须补的：
  RAG ❌（51%岗位要）
  Agent/LangChain ❌（70%）
  Prompt Engineering ❌（40%）
  向量数据库 ❌（~30%）
  FastAPI ❌（写API是日常）

学了就领先的：
  多模态、模型微调、Go/Java、K8s
```
