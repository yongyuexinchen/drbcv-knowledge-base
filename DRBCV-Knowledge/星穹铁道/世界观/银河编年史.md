# 银河编年史

> ⚠ 本卡为原始设定；创作向改编见 Video-Creation

## 核心概念

《银河编年史》并非一本实体的史书，而是星穹铁道宇宙中用以锚定时空、衡量文明进程的**基础认知框架**。它将浩渺的虚数宇宙拆解为可被记录的物理单位（琥珀纪、开拓历）、重大事件坐标（寰宇蝗灾）、乃至社会技术演进的关键节点（联觉信标）。简而言之，它是描述“我们从哪来、现在处于何时、宇宙如何运作”的**底层时间轴与世界观地基**。

设定中以七个核心条目勾勒出银河的骨架：
- **琥珀纪**——由星神「克里珀」挥锤敲击的世界脉动作为全球通用纪年基准；
- **开拓历**——源自「开拓」星神阿基维利家乡裴迦纳的历法，象征以脚步丈量未知的文明自觉；
- **寰宇蝗灾**——由「繁育」星神塔伊兹育罗斯引发的宇宙级生态/文明浩劫，是古史与近代史的分水岭；
- **虚数之树**——解释宇宙结构的世界观级理论模型，将一切现实视为巨树的分枝；
- **星际旅行**——基于虚数能量的航行技术框架，定义文明与他者接触的可能；
- **联觉信标**——从技术层面瓦解语言壁垒的发明，却意外强化了隔阂，堪称“巴别塔悖论”。

## 关键机制

| 机制 | 说明 | 例子 |
|------|------|------|
| **克里珀挥锤纪年（琥珀纪）** | 以星神克里珀每挥锤锻造一次封印记为1纪；因锤击间隔并不均等，1纪长度在76~240年间浮动。星历法由此具有“极大尺度上的不均匀刻度”属性。 | 星穹列车于**2157纪**起航，这一纪元至今仍是探索与开拓的“现在时”坐标。 |
| **开拓历（裴迦纳历法）** | 源自阿基维利故乡裴迦纳的历法，被开拓者与无名客广泛使用。它与琥珀纪互为参照，强调“旅行的进程”而非“世界的心跳”。 | 在列车客舱、开拓任务简报中常见双历并记，如“星历2157纪·开拓历第XXX天”。 |
| **寰宇蝗灾（塔伊兹育罗斯之劫）** | 「繁育」星神塔伊兹育罗斯登神后在宇宙尺度上疯狂增殖，造成的生态吞噬与文明断层事件。其陨落标志着“繁育”路径的终结，也划定了“古代-近代”的史观边界。 | 后世将任何无节制扩张、吞噬资源的灾难性趋势都称为“蝗灾式风险”，用于警示。 |
| **虚数之树（宇宙结构理论）** | 将多元宇宙解释为虚数之树：主干为“虚数能”的绝对根基，各世界/星域是树冠上的叶片或枝桠。树状结构决定了世界间既同源又隔绝的辩证关系。 | 用于解释为何不同星系存在“引力断层”与“通信延迟”，也让“跨越世界”成为史诗级工程。 |
| **星际旅行（虚数能量导航）** | 虚数能量在星系间形成高密度“隔绝层”，普通航行不可穿越；唯借由特殊引擎、或“令使”级存在以构想扭曲现实，方能跃迁。 | 星穹列车可穿行星海即因其引擎能“撬动虚数”；「令使」则能以一己之念“让构想成真”，实现物理法则级的折跃。 |
| **联觉信标（巴别塔悖论）** | 由天才俱乐部#56以利亚萨拉斯发明、星际和平公司普及的同步翻译/感知装置。它让语言与文化“大同”，但理解的趋同反而令深层理念冲突更加赤裸，矛盾不降反升。 | 公司商路沿线可即时翻译百语，但自由贸易区内的民族冲突与市场纠纷远比闭塞星系更频繁。 |

## 时间线/纪年

| 纪年体系 | 基准 | 当前参考 | 备注 |
|----------|------|----------|------|
| **琥珀纪** | 克里珀每次挥锤封印虚空 | 星穹列车于2157纪启航 | 1纪=76~240年，单位不均匀 |
| **开拓历** | 阿基维利家乡裴迦纳 | 与琥珀纪并行使用 | 象征探索与迁徙的“子午线” |
| **寰宇蝗灾纪元** | 塔伊兹育罗斯登神至陨落 | 属前2157纪的上古史 | 划定古代史与近代史的分水岭 |
| **公司纪年/商路历** | 星际和平公司扩张里程碑 | 联觉信标普及后进入“大同纪元” | 以技术与贸易节点划分时代 |

## 与视频创作的映射

> **《托帕的金融小课堂》衍生用法：**

- **琥珀纪 → 托帕的“投资财年”**：琥珀纪长达76~240年，弹幕可玩梗“托帕的KPI考核周期按琥珀纪算，难怪她不急”。类比上市公司“以一个世纪为单位做季报”。
- **联觉信标 → 同声传译陷阱**：视频中可演绎为“公司给全宇宙装了同声传译，结果托帕用‘债务违约’翻译成‘有缘再会’，导致催账失败”。
- **寰宇蝗灾 → 金融风暴影射**：塔伊兹育罗斯的增殖灾难可直接谐音“资金蝗灾”（热钱无节制扩张），用于讽刺过度杠杆与无限印钞。
- **虚数之树 → 资产隔离结构**：将托帕的“信托架构”类比虚数之树的分枝，解释“为什么钱在世界树不同枝杈间转移就不用还税”。
- **开拓历 → 折旧年限**：开拓历以“旅程”为刻度，视频中可用来计算“固定资产折旧”：星穹列车跑一年等于裴迦纳的七年，直接折旧到零。
