# 技能画布编排

## 类型判定
通过可视化拖拽和连接组件来构建 AI 应用工作流的低代码编排方式，是必胜项目的核心能力。

## 类比 ★
### 一句话比喻
就像搭乐高——你不用写代码，只需要从零件箱里挑出"大模型积木""提示词积木""记忆积木""知识库积木"，按正确的接口拼在一起，一个 AI 应用就搭好了。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 画布（Canvas） | 乐高底板 |
| 组件（LLM / Prompt / Memory） | 不同功能的乐高积木 |
| 连接线 | 积木之间的卡扣 |
| 红心标记（必填项） | 不插这个积木就散架的关键接口 |
| 技能（Skill） | 拼好的完整乐高作品 |
| 提示词（Prompt） | 贴在积木上的使用说明 |

## 是什么
技能画布编排是必胜（Bisheng）项目提供的低代码 AI 应用构建方式。用户从左侧组件库拖出"大模型（LLM）""提示词（Prompt）""记忆（Memory）""知识库检索"等工作流组件，通过连线定义数据流向（红心标记为必填项），在可视化画布上拼装出完整的 AI 技能。编辑完成后保存、上线，即可在"应用"页面使用该技能进行对话。

## 正例（≥2 个）
1. **基础大模型对话**：LLM 组件 + Prompt 组件 + 工作链路组件 = 一个可对话的 AI 助手。Prompt 中通过 {input} 变量占位用户输入。
2. **带记忆的对话**：LLM + Prompt（含 {chat_history}）+ Memory 组件 = 能记住聊天历史的 AI 助手。
3. **联网搜索技能**：LLM + 搜索工具（Bing/Google）+ Agent 代理组件 = 能查询实时信息的 AI 助手。

## 反例/边界（≥1 个）
1. 纯代码开发：如果需要极其复杂的业务逻辑或自定义算法，画布编排不如直接手写代码灵活。画布适合"积木组合"型场景，不适合精细化算法定制。

## 详细解释
技能画布的核心操作流程：
1. **新建技能** → 进入高级配置 → 进入可视化画布
2. **拖入组件**：从左侧组件面板拖出所需组件到画布上
3. **配置参数**：点击组件填入 API Key、提示词、模型选择等参数
4. **连线**：用连接线定义组件间的数据流（LLM 红心连线为必填项）
5. **检查**：点击检查按钮验证工作流是否畅通
6. **保存 → 上线**：退出画布、保存技能、在应用页面刷新后即可使用

关键组件及变量：
- **Prompt Template**：提示词模板，{input} 代表用户输入，{context} 代表文件/知识库检索内容，{chat_history} 代表对话历史
- **Memory**：对话记忆组件，连接到 LLM 的 memory 接口
- **知识库检索链**：用户问题 → 向量化 → 向量数据库检索 → 返回相关内容 → LLM 综合回答

技能可导入导出，技能市场提供预设模板（合同审核、招股书分析）供下载使用。
