# SillyTavern(酒馆)

## 类型判定
**系统型** — 组织多个组件（前端+提示词系统+插件+API）形成角色扮演系统

## 是什么
SillyTavern是一个开源的AI角色扮演前端系统。它把系统提示、角色卡、世界书、预设参数和用户输入五层组织成结构化提示词，发送给外部AI模型。

## 系统架构
1. **前端层**: 用户交互界面
2. **提示词工程层**: 五层提示词组织（系统提示→预设→角色卡→世界书→输入）
3. **集成层**: API Key管理、上下文管理、扩展插件
4. **参数层**: Temperature、Top-P、重复惩罚控制输出风格
