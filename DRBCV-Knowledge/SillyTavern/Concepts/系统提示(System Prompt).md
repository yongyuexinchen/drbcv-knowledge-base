# ⬜ 系统提示(System Prompt)

## 类型判定
**判别型** — 回答「它属于什么？」——归类/识别

## 是什么
定义AI身份、行为边界的基础提示

## 输入-输出空间
- **输入**: AI的行为规范描述（身份、底线、格式要求）
- **输出**: {"符合规范的行为", "不符合规范的行为"}
- **映射关系**: 从属关系——每条AI输出都被判定边界

## 正例
1. **场景A**: 系统提示="专业医疗顾问，不提供诊断"。用户问"头疼怎么办"→"可能原因包括...建议咨询医生"（合规），不会说"吃布洛芬"（违规被抑制）。
2. **场景B**: 系统提示="只说文言文"。"你好"→"阁下安好"。白话文被判定违规。

## 反例/边界
1. **常见误解**: 不是"建议"——最高优先级，是AI行为的"宪法"。
2. **边界**: 太长会占用上下文窗口，挤压对话历史容量。

## 详细解释
系统提示（System Prompt）是发送给AI的最高优先级指令，定义AI的身份和行为底线。例如"你是一个专业医疗顾问，绝不提供诊断建议"。在每次对话中都排在第一位，角色卡和用户输入都不能覆盖它。它是AI行为的"宪法"。


## 细节备注

### 设计原则
| 原则 | 说明 |
|------|------|
| 永远排第一 | 角色卡和用户输入都不能覆盖 |
| 简洁 | 太长占用上下文窗口 |
| 底线优先 | 先定义"绝对不能做什么" |

### 典型写法
"你是一个专业的XX。你的职责是YY。你绝不ZZ。"
