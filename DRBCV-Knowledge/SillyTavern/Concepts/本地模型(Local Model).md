# ⬜ 本地模型(Local Model)

## 类型判定
**判别型** — 判断「这个模型是否运行在本地硬件上」

## 是什么
部署在本地硬件上的AI模型。方案：Ollama（简单）、KoboldCPP（功能强）、TextGen WebUI（功能最全）。核心卖点：免费+隐私。核心代价：效果有限+硬件门槛。

## 输入-输出空间
- **输入**: 模型部署方式的描述
- **输出**: {"云端API模型", "本地部署模型"}
- **映射关系**: 从属关系——根据部署位置归类

## 正例
1. **场景A**: Ollama+Qwen2.5 7B→8G显存可跑，日常对话勉强够用，完全免费。
2. **场景B**: 本地模型vs API成本——一张16G显卡（3000-4000元）≈DeepSeek API 3-5年费用。已有高配显卡才划算。

## 反例/边界
1. **常见误解**: 本地≠免费。硬件成本（显卡3000-4000元）可能超过多年API费用。除非已有高配显卡。
2. **边界**: 本地模型能力有限——7B/13B模型无法驾驭酒馆的五层提示词结构。

## 详细解释
本地方案对比：Ollama（简单，8G显存）< KoboldCPP（功能强，8G显存）< TextGen WebUI（最全，12G+显存）。推荐策略：日常本地跑（免费），关键场景切API（效果好）。
