# ⬜ 扩展插件(Extensions)

## 类型判定
**判别型** — 回答「它属于什么？」——归类/识别

## 是什么
酒馆的功能扩展机制

## 输入-输出空间
- **输入**: 用户启用的功能需求
- **输出**: {"有此功能", "无此功能"}
- **映射关系**: 从属关系——功能↔插件

## 正例
1. **场景A**: 装"表情包插件"→对话中自动插表情。没装→无此功能。
2. **场景B**: 装"TTS语音插件"→AI回复可朗读。插件让酒馆从文本变多媒体。

## 反例/边界
1. **常见误解**: 不是越多越好——每个插件消耗资源，不用会拖慢速度。

## 详细解释
扩展插件（Extensions）是酒馆的功能扩展机制。用户可以安装第三方插件来增加功能，如TTS语音朗读、表情包插入、自动翻译等。插件本质上是在酒馆的前端框架上叠加额外处理逻辑，不改变核心的提示词组织流程。


## 细节备注

### 常见插件类型
| 插件 | 功能 |
|------|------|
| TTS语音 | AI回复朗读为语音 |
| 表情包 | 对话中自动插入表情 |
| 自动翻译 | 检测英文输出自动转中文 |
| 正则脚本 | 文本后处理（已有独立概念卡） |

### 使用原则
- 不是越多越好——每个插件消耗资源
- 不用的插件会拖慢酒馆启动和运行速度
