# CPU的功能和基本结构

## 类型判定
判别型 — 回答"CPU由哪些部件组成、每个部件做什么、部件之间如何连线"，属于硬件架构类概念。

## 类比 ★
**一句话比喻：** 像霸道总裁府邸的日常运转——总裁夫人（CU）拍板指挥全家，跑腿小哥（IR）传单子，总管（PC）记日程，临时仓库（ACC）和新货仓库（X）放货，普通加工车间（ALU）和特殊加工车间（MQ）干活，菜鸟驿站（MAR/MDR）收发快递——CPU 就是这么一座"府邸+车间+驿站"的合体。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 控制器（CU/IR/PC） | 府邸管理层：夫人拍板（CU）、跑腿小哥传单（IR）、总管记日程（PC） |
| 运算器（ALU/ACC/X/MQ） | 加工车间：普通车间（ALU）、特殊车间（MQ）、临时仓库（ACC）、新货仓库（X） |
| 用户可见寄存器（通用寄存器/PSW） | 府邸公开账本，客人也能看到——程序员可见的寄存器 |

## 是什么
CPU 由**运算器**和**控制器**两大部件组成，在逻辑上可细分为 ALU、CU、寄存器和中断系统四部分。CPU 必须实现五大功能：**指令控制**（自动顺序执行指令序列）、**操作控制**（发出微操作信号驱动各部件）、**时间控制**（控制信号按时序逐一发出）、**数据加工**（算术/逻辑运算）、**中断处理**（响应突发信号，暂停当前程序转去执行中断处理程序后再返回）。

## 输入-输出空间
- **输入**：主存中的指令序列（经地址总线/数据总线）、外部中断信号、PSW 标志位
- **输出**：微操作控制信号（控制各寄存器/ALU/总线）、访存地址（经 MAR → 地址总线）、运算结果
- **核心通路**：控制器根据 IR 中的操作码 + 时序信号 + PSW 标志位 → 微操作信号发生器 → 发出各控制信号

## 正例（≥2 个）
1. **执行加法指令**：IR 的操作码送给指令译码器 → CU 确定微操作序列 → 依次发出 R0 out + Y in（把操作数放入暂存寄存器）→ R1 out + ALU in（另一操作数进 ALU）→ ALU 执行加法 → Z out + R0 in（结果写回），每个节拍对应一组控制信号。
2. **PC 自动加一**：每条指令取指结束后，PC 自动 +1 指向下一条指令地址。这个功能可以由专用加法电路实现，也可以交给 ALU——说明 CPU 内部部件分工并非绝对固定。

## 反例/边界（≥1 个）
1. **"所有寄存器都用户可见"是错的**：MAR、MDR、IR、暂存寄存器（Y/Z）等对程序员透明，不能用汇编语言直接读写。PC、PSW、ACC、通用寄存器才是用户可见的。408 高频考点：哪些寄存器对用户透明。
2. **专用数据通路≠永远最优**：专用通路性能高但连线复杂、成本高、不易扩展；CPU 内部单总线结构连线简单但同一时刻只能一组部件传输数据，ALU 必须配合暂存寄存器使用。性能和成本是永恒的矛盾。

## 详细解释
### 运算器结构
- **ALU**：核心运算部件，组合逻辑电路，两个输入（A/B）一个输出，需两个操作数同时稳定才能正确运算。
- **通用寄存器组**（R0~R3 等 + SP 堆栈指针）：存放操作数和中间结果。
- **暂存寄存器**（Y/Z）：单总线结构必需——先把一个操作数暂存到 Y，再通过总线送另一个操作数到 ALU。可扩展为移位寄存器或累加寄存器 ACC。
- **PSW（程序状态字/标志寄存器）**：记录溢出 OF、符号 SF、进位 CF 等状态，影响后续微操作序列。
- **移位器 + 计数器**：辅助乘除法运算。

### 控制器结构
- **PC**：程序计数器，存放下条指令地址，有自动 +1 功能。
- **IR**：指令寄存器，存放当前指令。操作码部分送指令译码器 → CU，地址码部分送总线。
- **指令译码器（ID）**：将操作码译为一根选通线，告诉 CU 是哪条指令。
- **微操作信号发生器**：根据操作码 + 时序信号 + PSW 标志 → 发出具体控制信号。
- **MAR/MDR**：集成在 CPU 内部，分别连接地址总线和数据总线。MDR in（内部总线输入）与 MDR inE（外部总线输入）是两个不同的控制信号。
- **时序系统**：产生节拍信号 T0/T1/T2...，控制微操作先后顺序。

### 寄存器用户可见性（408 高频考点）
| 用户可见 | 用户不可见（透明） |
|---------|-----------------|
| PC、PSW、ACC、通用寄存器 R0~Rn | MAR、MDR、IR、暂存寄存器 Y/Z |

## 备注
- 408 高频：MAR/MDR/IR/暂存寄存器对用户透明；PC/PSW/ACC/通用寄存器用户可见
- CPU 五大功能：指令控制→操作控制→时间控制→数据加工→中断处理（口诀："指操时数中"）
- 单总线结构的代价：ALU 必须配暂存寄存器；专用数据通路结构的代价：连线复杂成本高
- 中断处理：CPU 收到中断信号→保存断点（记录当前 PC）→转中断处理程序→返回原程序继续执行
