# 函数调用的机器级表示

## 类型判定
程序型 — 描述函数调用/返回在汇编层面如何实现（call/ret 指令、栈帧结构、参数传递），属于"过程"类概念。

## 类比 ★
**一句话比喻：** 像公司里层层外包业务——call 是"经理出门办事前先把手机号留给前台"（压栈 IP 旧址再跳走），ret 是"回来时前台报出手机号找到原工位"（弹栈恢复 IP），栈帧就是每个外包团队在办公区画出来的格子间。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| call 指令（压 IP + 跳转） | 出差前把回程车票交给前台保管，然后出发去新地点 |
| ret 指令（弹 IP 返回） | 回来时从前台取回车票，按票回到原来的工位 |
| 栈帧（EBP 基址 + ESP 栈顶） | 每个团队的格子间——用围栏（EBP/ESP）标出自己地盘的范围 |
| 参数/返回值（栈顶/EAX） | 跨部门交接文件放在门口约定位置，结果用固定快递柜（EAX）送回 |

## 是什么
函数调用在机器级由 **call 和 ret 两条指令**完成：call 先把当前 IP（x86 叫 IP，即 PC）压栈保存，再无条件转移到被调函数第一条指令；ret 从栈顶弹出保存的 IP 旧址写回 IP，回到 call 的下一条指令。每个函数运行时在**函数调用栈**上占据一片区域叫**栈帧**，由 EBP（栈底基址）和 ESP（栈顶指针）标记范围。栈向低地址方向增长（教材画图常把栈顶画在上面）。

## 输入-输出空间
- **输入**：call 的目标标号（被调函数名）、调用参数（写入当前栈帧顶部）
- **输出**：函数返回值（放入 EAX 寄存器带回）；栈帧被压入/弹出
- **前置条件**：栈帧 16 字节对齐（GCC 规定，为数据对齐）；调用前参数写入栈顶区域

## 正例（≥2 个）
1. **main → P → Q 的嵌套调用**：每次调用把新函数栈帧压栈顶，返回时弹栈回上一层——当前正在执行的函数一定在栈顶。
2. **color 调用 add 传参**：color 的栈帧顶部写入两个参数 X、Y；add 用 EBP+8 和 EBP+12 访问它们（EBP 指向 add 栈底，参数在上一函数栈帧顶部）。
3. **enter/leave 等价展开**：函数开头 `push EBP; move ESP→EBP` 可简写为 `enter`；结尾 `move EBP→ESP; pop EBP` 可简写为 `leave`——每个函数 return 前例行 leave。

## 反例/边界（≥1 个）
1. **"call 只是跳转"是错的**：call = 压栈 IP 旧址 + 跳转两步；只跳转不保存返回地址，ret 就回不来——"过得去还得回得来"缺一不可。
2. **"参数通过寄存器传"不准确**：x86 函数调用参数默认放在栈帧顶部（EBP+8 起），不是寄存器；返回值才用 EAX 寄存器。
3. **栈顶画法迷惑**：x86 栈向低地址增长，教材把栈顶画上面、栈底画下面，与数据结构课程习惯相反——看清 EBP/ESP 指向再分析。

## 详细解释
### 栈帧结构（从低地址到高地址）
| 位置 | 内容 |
|------|------|
| 栈顶（低地址，ESP 指向） | 参数区（EBP+8、+12...）：调用参数，先出现参数越靠近顶部 |
| 中部 | 可能存在的空闲区（凑 16 字节对齐的零头） |
| 靠近底部 | 局部变量区（EBP-4、-8、-12...）：C 里越靠后定义的变量越靠底部 |
| 栈底（EBP 指向） | 上一层函数的 EBP 旧址（恢复用） |
| 再往上（高地址） | 返回地址 IP 旧址（call 压入，ret 弹出） |

### call / ret 的完整动作
- **call 标号**：① push IP（当前 IP 即 call 下一条指令地址，压栈保存返回地址）→ ② IP = 标号地址（无条件转移）。
- **ret**：① pop IP（从栈顶弹出返回地址写回 IP）→ ② 回到 call 后第一条指令继续执行。

### 栈帧切换四部曲（每个函数例行）
1. `push EBP`：保存上一层函数栈底地址（栈帧底部存它，返回时可恢复）
2. `move ESP, EBP`：EBP 指向当前函数新栈底（等价 `enter`）
3. `sub ESP, N`：为局部变量腾出 N 字节空间
4. 返回前：`move EBP, ESP; pop EBP` 恢复上一层（等价 `leave`），再 `ret`

### 局部变量与参数的访问规律（读汇编必会）
- `EBP - 4 / -8 / -12` → 当前函数的第 1/2/3 个局部变量（越靠后定义越靠底部）
- `EBP + 8 / +12` → 当前函数收到的第 1/2 个参数（参数在栈帧顶部）
- 返回值放 EAX：add 函数 `move EAX, 结果`，caller 调用后从 EAX 取

## 备注
- 读汇编速记：**EBP 减 = 局部变量，EBP 加 = 参数**（EBP-4 第一个局部变量，EBP+8 第一个参数）
- 栈帧 16 字节对齐是 GCC 规则：只要函数还要调下一层函数，栈帧必须凑齐 16 的倍数
- 栈向低地址增长：push 先 ESP-4 再写，pop 先读再 ESP+4——顺序别搞反
- call/ret 常考选择题：call 压栈保存的是什么？答：IP 旧址（返回地址），不是 EBP
