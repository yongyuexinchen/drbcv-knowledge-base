# 定点数除法运算

## 类型判定
程序型 — 描述无符号整数和带符号整数（补码）除法的电路实现、上商规则、恢复余数法原理，以及除零异常和商溢出异常的判断条件，属于"过程 + 异常处理"类概念。

## 类比 ★
**一句话比喻：** 像分糖果——每次从一堆糖里尝试分给 N 个人相同数量，如果不够分就不分这轮（商 0），够分就给每人分一轮（商 1），剩下的糖留着下轮继续分（余数右移一位再补新糖）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 上商规则：中间余数 ≥ 除数则商 1 | 糖果够每人分满一份 → 这轮就分（商 1）；不够就不分（商 0） |
| 恢复余数法：商 0 时"减错→加回来" | 想从 3 颗糖里给 10 个人分，发现不够，赶紧把准备分的糖放回盘子里 |
| 商溢出（第一位商 = 1） | 盒子只能装 4 颗糖，你算出要 5 颗——盒子装不下，溢出了 |

## 是什么
**定点数除法运算**是计算机通过硬件电路模拟手算"逐位上商、错位相减"的过程，将 2N 比特被除数除以 N 比特除数，得到 N 比特商和 N 比特余数。无符号除法采用**恢复余数法**：每轮先让中间余数减去除数，根据结果 ≥ 0（商 1）或 < 0（商 0 并恢复余数），然后整体左移一位继续下一轮。补码除法电路结构相同但上商规则不同：根据余数与除数符号是否相同来决定加法/减法及商值；最终若被除数与除数异号则对商取补。除法可能触发两类异常：①除数为零异常；②商溢出异常（无符号看第一位商是否 = 1，补码看是否绝对值最大负数 ÷ -1）。

## 输入-输出空间
- **输入**：被除数（2N 比特，高 N 比特在 R，低 N 比特在 Q）、除数（N 比特在 Y）
- **输出**：N 比特商（在 Q）+ N 比特余数（在 R）
- **前置条件**：被除数若非 2N 比特需位扩展（无符号→零扩展，补码→符号扩展）；计数器 CN = N；控制逻辑初始化时检查除零和商溢出

## 正例（≥2 个）
1. **无符号除法 15÷2=7 余 1**：被除数 8 位 00001111 放入 R+Q（R=0000, Q=1111），除数 Y=0010。先判商溢出：第一位商=0，继续 N=4 轮处理，最终 Q=0111（商 7），R=0001（余 1）→ 7×2+1=15 ✓。
2. **补码除法 -7÷3=-2 余 -1**：-7=1001（补码）→ Q=1001，符号扩展后 R=1111（高 4 位），除数 Y=0011。4 轮处理（根据余数符号 vs 除数符号决定加减和上商），最终商 Q=0010，因被除数与除数异号取补→1110（-2），R=1111（-1）→ -2×3+(-1)=-7 ✓。
3. **单精度除法不会溢出**：N 位 ÷ N 位（如 4 位无符号 9÷3=3），被除数高位补 0 扩展为 8 位，第一位商必然为 0 → 不可能溢出。C 语言 int x=985, y=211; int z=x/y; 底层用 32 位补码除法器，高位符号扩展后 N 位 ÷ N 位不可能溢出。

## 反例/边界（≥1 个）
1. **双精度除法可能商溢出**：2N 位 ÷ N 位，若第一位商 = 1 → 商溢出。例：255（8 位）÷15（4 位）= 17，商 17 的二进制 10001，用 4 位只能存 0001 → 错误！
2. **补码唯一的溢出情况**：绝对值最大的负数 ÷ -1。如 4 位补码 -8（1000）÷ -1（1111），结果 +8 超出了 4 位补码范围 -8~+7 → 商溢出异常。
3. **除数为零在任何整数除法中都触发异常**：被除数 3，除数 0 → 控制逻辑初始化后立即检测 Y=0，抛出"除数为零异常"，调用操作系统异常处理程序，不进行后续 N 轮处理。x86 中除零异常和商溢出异常统称"除法错异常"（2025 年 408 真题考点）。

## 详细解释
### 无符号除法电路（恢复余数法）
| 步骤 | 操作 |
|------|------|
| 初始化 | R←被除数高 N 位（零扩展）, Q←被除数低 N 位, Y←除数, CN←N |
| 异常检测 | ① Y=0 → 除零异常；② 被除数绝对值 < 除数绝对值 → 直接返回商=0, 余数=被除数；③ 否则计算第一位商：R-Y，若 ≥0 且第一位商=1 → 商溢出 |
| 每轮 | ① R+Q 整体左移 1 位；② R-Y → 若 ≥0 商 1 且保留 R-Y；若 <0 商 0 且 R+Y 恢复余数；③ CN-- |
| 结束 | CN=0，商在 Q，余数在 R |

### 补码除法电路（上商规则不同）
| 步骤 | 操作 |
|------|------|
| 初始化 | R←被除数符号扩展的高 N 位, Q←被除数低 N 位, Y←除数, CN←N |
| 异常检测 | ① Y=0 → 除零异常；② |被除数| < |除数| → 商=0, 余数=被除数；③ 若被除数为绝对值最大负数且除数为 -1 → 商溢出 |
| 每轮 | ① R+Q 整体左移 1 位；② 若 R 与 Y 同号 → R-Y，否则 R+Y；③ 新 R 与旧 R 符号不同 → 商 0 + 恢复余数；符号相同 → 商 1 |
| 结束 | CN=0，若被除数与除数异号 → Q 取补（按位取反+1）；商在 Q，余数在 R |

## 备注
- **408 考点 — 除法异常两类**：①除数为零异常（Y=0）；②商溢出异常（无符号：第一位商=1；补码：绝对值最大负数 ÷ -1）。x86 中统称"除法错异常"（2025 真题）。
- **408 考点 — 寄存器初终值**：C 语言 int x=985211, y=666; int q=x/y, r=x%y; → 各寄存器初值：R=0（符号扩展高 32 位全 0），Q=x 的 32 位二进制，Y=y 的 32 位二进制；终值：Q=商 q 的 32 位补码，R=余数 r 的 32 位补码
- **408 考点 — 单精度 vs 双精度除法**：N 位 ÷ N 位（单精度）不可能商溢出（第一位商必为 0）；2N 位 ÷ N 位（双精度）可能溢出
- **恢复余数法核心**：商 0 时把减错的余数加回去（R+Y 恢复）；不恢复余数法更快但不直观，第一轮复习不必深究
