# 选择与循环语句的机器级表示

## 类型判定
程序型 — 描述如何使用汇编指令（JMP 无条件转移 + CMP 比较 + Jxx 条件转移 + LOOP 循环）将 C 语言的 if-else 分支和 for/while 循环翻译为机器级代码，包含具体的指令执行流程和从标志位到跳转决策的硬件逻辑，属于"编译过程"类概念。

## 类比 ★
**一句话比喻：** 像古代镖局的押镖路线——顺序寻址是"一路直走不拐弯"，JMP 是"朝廷急令，改道走岔路口"（不管之前怎么走，直接跳），CMP+Jxx 是"前方探子回报：如果遇到土匪（条件满足），就绕小路；如果路上平安（条件不满足），继续走大路"，LOOP 是"飞鸽传书说我绕完第 N 座山头就回归主路"。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| PC/IP（程序计数器） | 你手指着地图上的"当前位置"——下一条路从哪走 |
| CMP 比较 + 标志位（OF/ZF/CF/SF） | 探子回报的情报——减法的结果如何，决定下一步判断依据 |
| Jxx 条件转移 | "如果前方有土匪就改道"——条件满足才跳，不满足继续走 |
| LOOP 指令（ECX 自动减一） | "我数到第 5 个山头就归队"——每次过山头暗暗记一笔，到 0 就停 |

## 是什么
**选择与循环语句的机器级表示**是指将 C 语言的 if-else 分支、for/while 循环翻译为 x86 汇编指令序列的方法。核心机制是**通过修改 PC（程序计数器）来打破指令的顺序执行**：JMP 无条件修改 PC 实现 goto 式跳转；CMP 做减法设标志位，Jxx 根据标志位条件性地修改 PC 实现分支；LOOP 自动递减 ECX 并判断是否归零，实现计数型循环。三者的本质都是对 PC 值的修改——转移 = 改写 PC。

## 输入-输出空间
- **输入**：C 语言 if-else 分支结构 或 for/while 循环结构的逻辑
- **输出**：等价的 x86 汇编指令序列（含标号、CMP、Jxx、JMP、LOOP）
- **核心硬件**：PC/IP 寄存器（存下一条指令地址）、PSW/标志寄存器（存 OF/ZF/CF/SF 标志位）、ALU（执行减法产生标志位）

## 正例（≥2 个）
1. **if-else 分支——取否命题法**：C 语言 `if (a > b) c = a; else c = b;`，假设 a→EAX，b→EBX，c→ECX。
   ```asm
   cmp EAX, EBX        ; 比较 a 和 b（做 EAX-EBX，设标志位）
   JLE L_else           ; 如果 a≤b（取 a>b 的否命题），跳到 else
   mov ECX, EAX        ; a>b 时：c = a
   jmp L_end            ; 跳过 else 部分
   L_else:
   mov ECX, EBX        ; a≤b 时：c = b
   L_end:
   ```
   JLE 是"Jump when Less than or Equal"——取了 a>b 的否命题 `a≤b`，条件满足时跳到 else，条件不满足时自然"掉入"下方 if 体。最后用 JMP 跳过 else 部分。

2. **for 循环——四段式结构**（`for(i=1; i<=100; i++) result += i;`）：
   ```asm
   mov EDX, 1          ; ①初始化：i=1
   mov EAX, 0          ;          result=0
   cmp EDX, 100        ; ②循环前判断：i > 100？
   JG L_end             ;    若 i>100 直接跳过循环
   L_start:             ; ③循环体起点标号
   add EAX, EDX        ;    result += i
   inc EDX              ;    i++
   cmp EDX, 100        ; ④循环尾判断：i ≤ 100？
   JLE L_start          ;    若是，跳回循环体起点
   L_end:
   ```
   四段式：初始化 → 提前判断是否跳过 → 循环体 → 循环尾判断。循环尾用 JLE（小于等于时继续），循环前判断用 JG（大于时跳过）保护空循环情况。

3. **LOOP 指令——ECX 自动倒计数**：
   ```asm
   mov ECX, 500        ; 计数器=500
   L_loop:
   ...                  ; 循环体
   loop L_loop          ; ECX--（自动）; if ECX≠0 goto L_loop
   ```
   LOOP 等价于 `dec ECX` + `cmp ECX, 0` + `JNE L_loop`，但更简洁。ECX 是 LOOP 指令的**专用计数器**，不可用其他寄存器替代。

## 反例/边界（≥1 个）
1. **JMP 无条件跳转不能替代 CMP+Jxx**：`jmp 128` 是永远跳——如果程序中用 JMP 实现 if-else，条件判断逻辑会丢失。条件转移 = CMP（产生标志位）+ Jxx（根据标志位判断是否跳），两者必须配合使用。
2. **相对寻址的偏移量基于"下一条指令地址"**：`jmp L_next` 中的标号 L_next 对应的偏移量是相对于 PC 取指后已经递增的值。如果手工计算跳转地址时误以"当前指令地址"为基准，会偏移一个指令字长，408 易错。
3. **条件转移的两种实现方式不可混用**：if-else 可以用"满足条件时跳转"（如 JG）或"取否命题时跳转"（如 JLE）两种写法。混用会导致 if 体和 else 体执行顺序颠倒。
4. **LOOP 指令只认 ECX，且不会跳过空循环**：如果循环前 ECX=0，LOOP 会先 decrement 变为 0xFFFFFFFF（回绕到最大），导致循环执行 2^32 次而非 0 次——所以 LOOP 不能直接用于 ECX 可为 0 的场景，需要循环前用 `jecxz` 或 CMP+Jxx 提前判断。

## 详细解释
### CMP 指令的底层硬件实现
```
CMP A, B      →  硬件实际做：A - B 的减法运算，但只设标志位、不存差值

产生的四个关键标志位：
  CF（进位/借位标志）  = 1 表示 A-B 借位（无符号数 A<B 时置 1）
  ZF（零标志）        = 1 表示 A-B=0（即 A=B）
  SF（符号标志）       = 1 表示 A-B 结果为负数（最高位为 1）
  OF（溢出标志）       = 1 表示 A-B 发生有符号溢出

结果存入 PSW（程序状态字寄存器），x86 中又称"标志寄存器"。
每次 ALU 运算（加减乘除等）都会覆盖这四个标志位。
```

### 条件转移指令速查表（结合标志位）
| 指令 | 全称 | 跳转条件 | 底层判断的标志位 |
|------|------|---------|----------------|
| JE | Jump if Equal | A = B | ZF = 1 |
| JNE | Jump if Not Equal | A ≠ B | ZF = 0 |
| JG | Jump if Greater | A > B（有符号） | ZF=0 且 SF=OF |
| JGE | Jump if Greater or Equal | A ≥ B（有符号） | SF = OF |
| JL | Jump if Less | A < B（有符号） | SF ≠ OF |
| JLE | Jump if Less or Equal | A ≤ B（有符号） | ZF=1 或 SF≠OF |
| JA | Jump if Above | A > B（无符号） | CF=0 且 ZF=0 |
| JB | Jump if Below | A < B（无符号） | CF = 1 |

> 408 主要考有符号比较（JG/JL 系列）。"Greater/Less"用于有符号数，"Above/Below"用于无符号数——英文区分不容易记混。

### 循环的四段式结构（条件转移实现）
```
① 初始化       → 循环前给循环变量赋初值
② 判断是否跳过 → CMP + Jxx 判断是否需要直接跳过整个循环（处理循环 0 次的情况）
③ 循环体       → 循环要执行的实际操作
④ 循环尾判断   → CMP + Jxx 判断是否继续下一轮，满足则跳回 ③ 的起始标号
```

### LOOP 系列指令
| 指令 | 操作 | 额外条件 |
|------|------|---------|
| LOOP label | ECX--; if ECX≠0 goto label | 无 |
| LOOPZ label | ECX--; if ECX≠0 **且** ZF=1 goto label | 最近运算结果为 0 |
| LOOPNZ label | ECX--; if ECX≠0 **且** ZF=0 goto label | 最近运算结果非 0 |

### JMP 无条件转移的四种写法
| 写法 | 示例 | 说明 |
|------|------|------|
| 直接常量 | `jmp 128` | 写死地址，不灵活 |
| 寄存器间接 | `jmp EAX` | PC ← EAX 的值 |
| 主存间接 | `jmp [999]` | PC ← 主存 999 号单元的内容 |
| 标号 | `jmp L_next` | PC ← 标号 L_next 对应的指令地址（最常用，最灵活） |

## 备注
- 408 高频题型：给 C 语言代码 + 对应的汇编代码，让你填空缺的操作数或判断跳转逻辑——先根据 C 语言逆推条件判断的语义，再对照汇编指令确认
- CMP 底层做减法但不保存差值——只设标志位，速度快且不破坏原操作数
- 条件转移中有符号（G=Greater / L=Less）与无符号（A=Above / B=Below）的标志位判断逻辑不同——408 默认考有符号，但遇到 `unsigned int` 类型的 C 代码要立刻切换为 JA/JB 系列
- LOOP 等价于 `dec ECX; cmp ECX,0; JNE`，但如果 ECX 初始为 0，LOOP 会回绕执行 2^32 次——真实编程中循环前需加 `jecxz` 判断
