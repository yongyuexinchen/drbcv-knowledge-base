# 数据通路

## 类型判定
构型 — 描述 CPU 内部各功能部件（寄存器、ALU、主存）之间数据传送的物理路径与连线方式，以及控制信号如何驱动数据流动，属于硬件架构类概念。

## 类比 ★
**一句话比喻：** 像车库的单车道 vs 多专用通道——单总线是所有车（数据）排一条车道，一次只过一辆；专用通路是每个目的地修一条专线，多辆车同时飙，但修路成本爆炸。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 单总线结构 | 老旧小区单车道，A→B 过车时 C→D 必须排队等 |
| 专用数据通路 | 每个部门之间修一条专项高速，同时跑但造价惊人 |
| 三态门 / 多路选择器 | 匝道口的红绿灯/汇流闸——决定哪路车的信号能通过 |

## 是什么
**数据通路**是数据在 CPU 内部各功能部件之间传送的路径，由控制单元 CU 发出的控制信号决定数据从哪儿流出（out 有效）、经过什么通路（总线或专线）、流入哪个部件（in 有效）。数据流动分三类：寄存器↔寄存器、寄存器↔主存、寄存器↔ALU。实现方式分为**单总线结构**（所有部件共享一条内部总线）和**专用数据通路结构**（每对有数据交换的部件之间建立专用连线）。多总线结构是二者的折中。

## 输入-输出空间
- **输入**：CU 发出的控制信号（XX out / XX in / MEMR / MEMW）、各部件的当前数据内容
- **输出**：目标寄存器/主存中写入的新数据、ALU 运算结果
- **关键约束**：单总线结构同一时刻只允许一组部件使用总线传送数据；专用通路可并行传送多组数据但连线复杂度随部件数平方增长

## 正例（≥2 个）
1. **单总线取指过程**：T0: PC out + MAR in（地址送 MAR）；T1: MAR out + MEMR + MDR inE（读主存取指令到 MDR）；T2: MDR out + IR in（指令送 IR）+ PC 自动 +1。每一步占用总线一次，共 3 个时钟周期。
2. **专用通路加法执行**：ADD 指令执行时，可同时让 ACC → ALU（一条通路）和 MDR → ALU（另一条通路）并行传送，控制器同时发出两条通路的控制信号 + ALU 加法控制信号，结果直接写回 ACC——比单总线少用一个暂存寄存器且更快。

## 反例/边界（≥1 个）
1. **单总线做运算必须配暂存寄存器**：ALU 要求两个操作数同时稳定，但单总线同一时刻只能传一个数。因此必须先把一个操作数暂存到 Y 寄存器（通过专用连线直连 ALU，不占总线），再通过总线送第二个数进 ALU。若采用双总线或多总线则可不设暂存寄存器。
2. **寄存器间数据流向≠所有方向都通**：专用通路结构看似全连接，但实际连线是单向的——如 ACC→MDR 有通路但 MDR→ACC 可能没有直接通路（需绕道 ALU），做题时需像走迷宫一样找"可行路径"。

## 详细解释

### 三种数据流动类型（以单总线为例）

**① 寄存器 → 寄存器**：如 PC → MAR。令源寄存器的 out 信号有效（数据送上总线）+ 目的寄存器的 in 信号有效（总线数据存入）。

**② 寄存器 ↔ 主存**：
- 读主存：先送地址（PC out + MAR in）→ CU 发出 MEMR 读信号 → 主存将数据经数据总线送入 MDR（MDR inE 有效）→ MDR out + IR in 完成取指令。
- 写主存：MAR out（给出地址）+ MDR out（给出数据）+ MEMW 写信号 → 数据写入主存。
- **容易漏写**：读/写主存时，MEMR 或 MEMW 控制信号不可省略。

**③ 寄存器 ↔ ALU**（单总线）：
1. 第一个操作数 → 暂存寄存器 Y（通过内部总线，Y in 有效），Y 与 ALU 有专用直连通路
2. 第二个操作数 → 内部总线 → ALU in 有效（此时 ALU 两个输入同时就绪）
3. CU 发出 ALU 运算控制信号（加法/减法等）
4. 运算结果 → 暂存寄存器 Z，稳定后 Z out + 目标寄存器 in 写回

### 单总线 vs 专用通路 对比

| 维度 | 单总线结构 | 专用数据通路 |
|------|-----------|------------|
| 连线复杂度 | 低，所有部件挂一条总线 | 高，N 个部件需要 O(N²) 条专用线 |
| 并行性 | 同一时刻仅一组部件传输 | 多组不冲突的部件可同时传输 |
| ALU 使用 | 必须配合暂存寄存器 Y/Z | 可通过多通路同时送两个操作数 |
| 成本 | 低 | 高（连线 + 多路选择器 / 三态门） |
| 扩展性 | 好（加部件只需挂总线） | 差（加部件需拉专用线） |
| 速度 | 慢（串行传送） | 快（并行传送） |

### 控制信号机制
- **out 信号**：控制数据从寄存器流出送上通路（总线或专线）
- **in 信号**：控制通路上的数据流入寄存器
- **多输入处理**：专用通路中一个部件可能被多条通路输入，需要多路选择器（多个输入选一个通过）或三态门（每个输入独立控制通断）来避免冲突
- **答题关键**：描述微操作序列时需注明每个步骤哪些控制信号有效

## 备注
- 大题高频考点：给一条完整指令（如 ADD (R0), R1），要求写出取指/间址/执行各阶段的微操作序列及控制信号；注意 R0 带括号 = 寄存器间接寻址(先将 R0 内容送 MAR)，不带括号 = 直接取寄存器内容
- 单总线 ALU 必配暂存寄存器 Y；多总线/专用通路可不配——这是考试判断有无暂存寄存器的核心依据
- 内部总线（CPU 内部寄存器间）vs 系统总线（CPU-主存-IO 间）是两个不同概念，别混
- 专用通路做题技巧：先看连线箭头方向（单向/双向），像走迷宫一样规划"起点→通路→终点"的可行路径
