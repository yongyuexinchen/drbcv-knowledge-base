# 总线概述

## 类型判定
判别型 — 回答"什么是总线、总线如何分类、总线有哪些特性、如何评价总线的性能"，属于系统互连类概念。

## 类比 ★
**一句话比喻：** 像一条城市主干道——所有车辆（数据）共享同一条路，同一时刻只能有一辆车占道行驶（分时），但路边所有店铺都能同时看到这辆车经过（共享）；道路有单行道和双行道之分（传输方向），宽度决定一次能并排几辆车（总线宽度），红绿灯节奏决定通行频率（时钟频率）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 分时共享 | 同一时刻只能一辆车占用主干道，其他车排队等——谁先申请、仲裁给谁 |
| 串行总线 vs 并行总线 | 单车道（一次一辆车）vs 多车道（一次多辆车并排）——多车道看似快，但车道太密互相干扰容易出事故（信号跳变） |
| 数据/地址/控制总线 | 货车拉货（数据）、导航指明目的地（地址）、交警打手势（控制） |

## 是什么
总线是一组为**多个部件分时共享**的公共信息传送线路。它有两个核心特点：**分时**（同一时刻只允许一个部件发送数据）和**共享**（所有部件都能接收总线上的信号）。设计总线时需要关注四大特性：机械特性（尺寸/管脚）、电气特性（传输方向/有效电平范围）、功能特性（每根线传什么信号）、时间特性（信号时序）。总线按数据传输格式分为**串行总线**（一次传 1 bit）和**并行总线**（一次传多位）；按连接功能部件分为**片内总线**（CPU 内部）、**系统总线**（连接 CPU/主存/IO）和**通信总线**（连接不同计算机系统）。系统总线又分为数据总线（双向）、地址总线（CPU→设备，单向）和控制总线（逐根单向，整体双向）。

## 输入-输出空间
- **输入**：发送方将高低电平信号放到总线信号线上
- **输出**：所有挂在总线上的部件都能检测到信号线上的电信号——但只有被地址选中的从设备才会响应
- **前提条件**：获得总线控制权（经仲裁）、给出地址信息、发出读写命令

## 正例（≥2 个）
1. **CPU 通过数据总线向主存写入 32 位数据**：CPU 拿到总线控制权后，往数据总线的 32 根信号线上加高低电平 → 主存检测到这些电平信号 → 写入对应存储单元。同一时刻，硬盘和打印机也能"看到"这些信号，但它们不是目标设备，不会响应。
2. **USB 串行传输**：鼠标通过 USB 一根数据线每次只发 1 bit → 接收方需拆卸/装配数据包 → 虽然每次只传 1 bit，但工作频率可以很高（几百 MHz），实际速度可能超过某些并行总线。
3. **总线带宽计算**：总线时钟频率 66 MHz，每个时钟周期传送 2 次数据（上升沿+下降沿各一次），总线宽度 32 bit → 工作频率 = 66×2 = 132 MHz → 带宽 = 132M × 32 bit = 4224 Mbps = 528 MB/s。

## 反例/边界（≥1 个）
1. **"并行总线一定比串行总线快"是错的**：并行总线信号线间距近、互相干扰，工作频率有上限；串行总线无此干扰，频率可以做得很高，实际传输速度可能反超并行总线。USB 3.0（串行，5 Gbps）就比许多旧式并行接口快。
2. **"总线宽度 = 地址线根数 + 数据线根数 + 控制线根数"不准确**：通常说"总线宽度 32 bit"默认指**数据总线宽度**。地址总线宽度取决于主存地址空间大小（如 MAR 位数），控制总线根数则取决于需要多少种控制信号。
3. **总线周期 ≠ 总线时钟周期**：多数情况下一个总线周期包含多个时钟周期，但也可能出现一对一甚至一个时钟周期包含多个总线周期（上升沿+下降沿各传一次）。做题必须审题。

## 详细解释
### 总线的分类
| 分类维度 | 类型 | 特点 |
|---------|------|------|
| 数据传输格式 | 串行总线 | 每次传 1 bit，成本低、抗干扰强、适合长距离、频率可很高 |
| | 并行总线 | 每次传多位，逻辑简单、但线间干扰导致频率受限、布线成本高 |
| 连接功能部件 | 片内总线 | CPU 芯片内部，连接寄存器与 ALU 等 |
| | 系统总线 | 连接 CPU/主存/IO 接口，含数据/地址/控制三类 |
| | 通信总线 | 连接不同计算机系统（如网线） |

### 系统总线的三种子总线
| 类型 | 传输方向 | 宽度设计依据 |
|------|---------|------------|
| 数据总线（DB） | 双向 | 机器字长或存储字长 |
| 地址总线（AB） | CPU→设备（单向） | 主存地址空间 + IO 设备编号（统一编址时） |
| 控制总线（CB） | 单根单向，整体双向 | 所需控制信号种类数 |

### 总线性能指标（8 个）
| 指标 | 含义 |
|------|------|
| 总线周期 | 传输一组数据所需时间（含申请/寻址/传输/结束四阶段） |
| 总线时钟周期 | 总线时钟信号的一个节拍，通常 = 机器时钟周期 |
| 总线工作频率 | 1 / 总线周期，每秒传几次数据 |
| 总线时钟频率 | 1 / 总线时钟周期，每秒几个时钟节拍 |
| 总线宽度 | 同时传输的数据位数（通常指数据总线） |
| 总线带宽 | 每秒最多传输的比特数 = 工作频率 × 宽度 |
| 总线复用 | 地址线和数据线共用一组线，分时传送（省成本、降速度） |
| 信号线数 | 地址线 + 数据线 + 控制线的总根数 |

> **有效数据传输率**：总线带宽是理论峰值。实际有效数据需扣除校验位、起始位、结束位等开销。

### 系统总线的经典结构
| 结构 | 连接方式 | 特点 |
|------|---------|------|
| 单总线 | CPU/主存/IO 全挂一组总线 | 结构简单、成本低、带宽低、不支持并发 |
| 双总线 | 主存总线（CPU+主存+通道）+ IO 总线（通道+IO设备） | 引入通道管理 IO，快慢总线分离 |
| 三总线 | 主存总线 + DMA 总线（高速 IO）+ IO 总线（低速 IO） | 高速外设通过 DMA 直连主存，吞吐量大 |

## 备注
- 408 高频：总线定义的两大特点——**分时**（同一时刻只允许一个部件发送）+ **共享**（所有部件都能接收）
- 串行 vs 并行：并行不一定快——并行总线频率有上限，串行总线频率可以做高，实际速度可能反超
- 总线带宽公式：工作频率 × 总线宽度（bit）→ 除以 8 得字节/秒。注意"每个时钟周期传几次"这个陷阱
- 突发（猝发）传输：送一个地址后可连续读/写多个地址连续的数据，常见于主存总线
