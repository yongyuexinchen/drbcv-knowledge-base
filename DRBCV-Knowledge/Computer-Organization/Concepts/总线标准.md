# 总线标准

## 类型判定
判别型 — 回答"总线标准是什么、按位置分哪三类、常见标准有哪些"，属于标准/规范类概念。

## 类比 ★
**一句话比喻：** 像手机充电口统一成 Type-C——总线标准就是硬件界的"通用接口协议"：各家厂商按同一张图纸造零件，造出来的东西插上就能用，不用管对方内部长啥样。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 制定总线标准 | 国家标准局规定充电口/插头统一规格，各家照做 |
| 系统总线/局部总线/设备总线 | 干线公路/支线道路/小区门口小路——离 CPU 越近等级越高 |
| 按标准造硬件 | 各电器厂按国标生产，插头通用不用改装 |

## 是什么
总线标准规定总线的传输方式（并行/串行）、数据线根数、仲裁方式、定时方式、工作频率、电气特性（高低电平范围）等细节，让各硬件厂商能独立制造互相兼容的部件。制定总线的思想类似软件开发中定义模块接口——两端只遵守规范，不关心对方内部实现。

按在计算机系统中的位置分为**三级**：
- **系统总线**：直接与 CPU 相连（CPU-北桥/CPU-主存），速度最快（ISA/EISA/FSB/QPI）。
- **局部总线**：不直接连 CPU，连高速北桥芯片（VESA/PCI/AGP/PCIe），连接显卡/网卡/SSD 等高速部件。
- **设备总线**：连慢速南桥芯片（USB/SCSI/IDE/SATA），接鼠标键盘等慢速外设；有的也叫通信总线（如连接打印机的）。

## 输入-输出空间
- **输入**：总线标准名称（选择题判断它是系统/局部/设备总线）
- **输出**：该总线的层级归类 + 关键特性（并行/串行、速度量级）
- **前置条件**：只需记住英文缩写和大致特性，408 大纲已删此节，了解即可

## 正例（≥2 个）
1. **系统总线 ISA**：1984 年 IBM 16 位机用的并行总线，8/16 位数据、8MHz 频率、16MB/s，由 CPU 直接控制——和 CPU 直连，属系统总线。
2. **局部总线 PCI**：速度比 VESA 快得多，且工作不依附于 CPU（由北桥控制），CPU 提速后 PCI 仍能适应——很快取代 VESA 成为局部总线主流。
3. **设备总线 USB**：由南桥芯片控制，接鼠标/键盘等慢速外设——设备总线连南桥、速度慢、距离"远"。

## 反例/边界（≥1 个）
1. **"PCI 一定是局部总线"不绝对**：PCI 早期也曾作为系统总线直接连接 CPU，某些教材称其为系统总线也不算错——按"当前主要用于连接什么"判断。
2. **"系统总线=最快，设备总线=最慢"是相对 CPU 距离的定性**：具体数值随技术演进变化（如 PCIe 已远超旧系统总线），不必背速度数值。
3. **VESA 的致命缺陷**：工作频率受 CPU 时钟控制，CPU 一提速 VESA 就跟不上——所以被不依赖 CPU 的 PCI 取代。

## 详细解释
### 三级总线与代表标准
| 层级 | 连接对象 | 典型标准 | 特征 |
|------|---------|---------|------|
| 系统总线 | CPU ↔ 北桥/主存 | ISA、EISA、FSB、QPI | 主板上最快，CPU 直接控制 |
| 局部总线 | 北桥 ↔ 高速部件 | VESA、PCI、AGP、PCIe | 连显卡/网卡/SSD，不依赖 CPU |
| 设备总线 | 南桥 ↔ 慢速外设 | USB、SCSI、IDE/PATA、SATA、RS232C | 慢速 IO，南桥控制；也称通信总线 |

### 总线标准包含的内容（制定一张"图纸"要规定什么）
1. **传输方式**：并行（多少根数据线，如 32 根一次传 32 位）vs 串行
2. **数据/地址线复用**：先传地址再传数据，减少线数
3. **仲裁方式**：链式查询 / 计数器定时查询 / 独立请求
4. **定时方式**：同步（固定时钟，设备必须跟得上）/ 异步（不互锁/半互锁/全互锁）
5. **工作频率与时钟频率**：给出上限，设备必须能跟上
6. **电气特性**：高/低电平的电压范围定义（如 0-0.5V 低电平、4.8-5.2V 高电平）

### 记忆策略
- 系统总线三兄弟：**ISA（老）→ EISA（扩展）→ FSB（前端）→ QPI（现代）**
- 局部总线：**VESA（图形专用，被淘汰）→ PCI（取代 VESA）→ AGP/PCIe（现代）**
- 设备总线：**USB（通用串行）、SCSI（服务器磁盘）、SATA（硬盘）、IDE/PATA（老硬盘）**
