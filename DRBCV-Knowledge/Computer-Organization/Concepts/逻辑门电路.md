# 逻辑门电路

## 类型判定
判别型 — 回答"与或非三种基本逻辑运算和与非、或非、异或、同或四种复合逻辑运算各自是什么、真值表长什么样、门电路符号怎么画"，是数字电路的基础概念。

## 类比 ★
**一句话比喻：** 像工厂流水线上的质检站——与门是"全票通过制"（全部条件满足才放行），或门是"宽松准入制"（任意一人点头就过），非门是"叛逆翻面机"（进来的全翻面），异或门是"找茬检测器"（两个不一样才报警）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 与门（全1才1） | 合租房签约：必须所有室友都签字，合同才生效 |
| 或门（有1则1） | 公司门禁：刷工卡或人脸识别任一通过就能进门 |
| 异或门（相异为1） | 双胞胎辨识器：两个人长得不一样，检测器才响 |
| 非门（取反） | 跷跷板：这头压下去那头翘起来，输入输出总是相反的 |

## 是什么
逻辑门电路是用晶体管实现的、处理二进制逻辑值（0/1）的电路单元。**三种基本逻辑运算**：与（AND，A·B，全1则1）、或（OR，A+B，有1则1）、非（NOT，Ā，取反）。由基本逻辑组合出**四种复合逻辑**：与非（NAND，先与后非）、或非（NOR，先或后非）、异或（XOR，相异为1）、同或（XNOR，相同为1，即异或再取非）。用门电路图形符号在电路图中表示，遵循"封装"思想屏蔽内部细节。

## 输入-输出空间
- **输入**：1个或2个二进制逻辑值（0/1），多输入门电路可接收更多
- **输出**：1个二进制逻辑值（0/1）
- **前置条件**：理解逻辑值真=1、假=0的对应关系

## 正例（≥2 个）
1. **A=1, B=0 输入与门**：输出 = 0（不同时为1，结果为0）
2. **A=1, B=0 输入或门**：输出 = 1（有1则1）
3. **A=1, B=0 输入异或门**：输出 = 1（相异为1）；同一对输入同或门：输出 = 0（异或取反）
4. **三个比特 1,1,1,0 连续异或**：共3个1（奇数）→ 最终异或结果 = 1（奇偶校验原理）

## 反例/边界（≥1 个）
1. **运算优先级搞错**：A·B+C 应先算与再算或（优先级：非 > 与 > 或），若误先算或会得到完全不同结果。类比算术：乘除先于加减。
2. **长横线覆盖多个变量**：\(\overline{AB}\) 是先与后非，不是先非后与——横线下方隐含括号。
3. **或门画法混淆**：或门输入端是弧线，与门输入端是直线。若只看输出端形状容易搞混。

## 详细解释
**七种逻辑运算真值表与符号特征**：

| 门电路 | 真值表口诀 | 符号特征 | 逻辑表达式 |
|--------|-----------|---------|-----------|
| 与门 AND | 全1才1 | 输入端：直线 | Y = A·B |
| 或门 OR | 有1则1 | 输入端：弧线 | Y = A+B |
| 非门 NOT | 1变0，0变1 | 输出端：小圆圈 | Y = Ā |
| 与非门 NAND | 全1则0（与门取反） | 与门+输出端小圆圈 | Y = \(\overline{A·B}\) |
| 或非门 NOR | 全0则1（或门取反） | 或门+输出端小圆圈 | Y = \(\overline{A+B}\) |
| 异或门 XOR | 相异为1 | 或门+输入端前加弧线 | Y = A⊕B = A·B̄ + Ā·B |
| 同或门 XNOR | 相同为1 | 异或门+输出端小圆圈 | Y = A⊙B = \(\overline{A⊕B}\) |

**异或门的分解**：异或 = (¬A·B) + (A·¬B)，可用2个非门+2个与门+1个或门实现。多个比特异或：奇数个1 → 结果1，偶数个1 → 结果0。

**封装思想**：复杂门电路（如异或门内部有5个门）对外简化为一个图形符号，只暴露输入输出引脚——和写程序调用 printf() 不关心底层实现是同一道理。

**逻辑表达式化简的现实意义**：A·C + A·D = A·(C+D)（分配律），等号右边少用一个与门 → 节省制造成本。

## 备注
- **408考点**：门电路符号识别（与门=直线、或门=弧线、非门=小圆圈）、异或=相异为1、多比特异或的奇偶性
- **跨考注意**：逻辑运算优先级：非 > 与 > 或（和算术的乘除先于加减类比记忆）
- **繁衍律（德摩根律）**：\(\overline{A·B} = \bar{A}+\bar{B}\)，\(\overline{A+B} = \bar{A}·\bar{B}\)，选择题常考化简
- **"储存"→"存储"** 等转录错别字原文已修正，不影响概念理解
