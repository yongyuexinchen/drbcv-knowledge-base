# 定点数的编码表示

## 类型判定
判别型 — 回答"原码、反码、补码、移码各自怎么定义、怎么转换、表示范围多少、各自解决什么问题"，是数据表示的核心概念。

## 类比 ★
**一句话比喻：** 像四种不同的记账方式——原码是"自然记账法"（正负号分开写，直观但算账麻烦），补码是"信用卡记账法"（把花出去的钱变成正向还款额，统一用加法算），移码是"排行榜编号法"（编号越大排名越前，方便一眼比大小），反码是"中间草稿纸"（原码变补码时的过渡步骤）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 原码（符号位+绝对值） | 账本上直接写"+100元"和"-50元"，清楚但加减要分别处理 |
| 补码（模运算，减法变加法） | 信用卡账单：花了50元不是"-50"而是"需还50元"，所有账都用加法算 |
| 移码（符号位取反的补码） | 考试排名：分数越高的编号越大，两个编号一比就知道谁在前 |
| 反码（中间过渡） | 草稿纸上的中间计算步骤，最终要誊写到正式账本（补码）上 |

## 是什么
定点数指小数点位置固定的数——定点整数（小数点隐含在最低位之后）和定点小数（小数点隐含在符号位之后）。计算机用四种编码表示定点数：**原码**（符号位 + 绝对值，直观但加减需处理符号）、**反码**（负数尾数取反，是原码→补码的中间态）、**补码**（负数尾数取反+1，核心作用是让减法变成等价的加法运算）、**移码**（补码符号位取反，只能表示整数，方便硬件比较大小）。

## 输入-输出空间
- **输入**：真值（带正负号的十进制数）+ 机器字长
- **输出**：四种编码的二进制表示
- **前置条件**：明确是定点整数还是定点小数（移码仅用于整数）

## 正例（≥2 个）
1. **正数 +50（8位机器字长）**：原码 = 反码 = 补码 = 0 0110010（50=32+16+2）；移码 = 1 0110010（符号位取反即可）
2. **负数 -100（8位）**：100=64+32+4 → 原码 = 1 1100100；反码 = 1 0011011（尾数取反）；补码 = 1 0011100（反码+1）；移码 = 0 0011100（补码符号位取反）
3. **-100 补码 → +100 补码快速求法**：已知(-100)补 = 1 0011100，把全部位取反得 0 1100011，末位+1得 0 1100100，即(+100)补
4. **真值0的表示**：原码有 [+0]=0 0000000 和 [-0]=1 0000000（两种）；补码只有 0 0000000（一种）

## 反例/边界（≥1 个）
1. **补码可多表示一个负数**：8位原码/反码范围 [-127, +127]，8位补码范围 [-128, +127]。1 0000000 在补码中表示 -128（不是-0），这是移码范围独有的优势。
2. **补码转换时符号位不变**：原码→补码时"符号位不变，尾数取反+1"，若误把符号位也取反会得到另一个数。而补码→原码方法相同：符号位不变，尾数取反+1。
3. **移码不能表示小数**：移码是在补码基础上符号位取反，只能用于定点整数。若问"小数能用移码表示吗"，答案是不能。
4. **原码做加减会错误**：14的原码(0 0001110) + (-14)的原码(1 0001110)，直接二进制加法得 1 0011100 ≠ 0，仅当两数符号相同时才能直接加。

## 详细解释
**四种码的定义与转换规则**（8位定点整数为例）：

| 编码 | 正数表示 | 负数表示 | 0的表示 | 8位范围 | 核心作用 |
|------|---------|---------|--------|---------|---------|
| 原码 | 符号位0+绝对值 | 符号位1+绝对值 | [+0]/[-0]两种 | [-127, +127] | 最直观，但加减需特殊处理 |
| 反码 | 同原码 | 符号位1+尾数取反 | [+0]/[-0]两种 | [-127, +127] | 原码↔补码的中间过渡 |
| 补码 | 同原码 | 符号位1+尾数取反后+1 | 仅一种(全0) | [-128, +127] | 减法变加法，硬件只做加法 |
| 移码 | 符号位取反的补码 | 符号位取反的补码 | 仅一种(1000000) | [-128, +127] | 方便硬件对比大小 |

**补码原理（为什么能"减法变加法"）**：假设计算机字长8位，寄存器天然实现模256（8位全1=255，再+1回0）。对于-14，它的补数=256-14=242，二进制=11110010（补码）。14+(-14)=14+242=256→高位移出，保留8位全零=0。因此：补码 = 模 − |负数|，用补码做加法等价于原数做减法。

**补码快速求法**：给出 X的补码，求 (-X)的补码：全部位（含符号位）取反后末位+1。

**移码的排序特性**：移码全0对应真值最小（-128），移码全1对应真值最大（+127），移码的无符号比较结果 = 真值的大小比较结果，硬件从最高位开始依次比较即可判定大小。

## 备注
- 补码→原码和原码→补码方法相同：符号位不变，尾数取反+1；也可以"从右往左找第一个1，左边取反"
- 反码只是中间态，几乎不直接参与运算，考试只考"反码-原码-补码"三者转换
- 移码 = 补码符号位取反，全0时真值最小（不是0最小），这个特性选择题常考
- 补码表示范围比原码/反码多一个负数（如8位：[-128,+127] vs [-127,+127]），408必考
