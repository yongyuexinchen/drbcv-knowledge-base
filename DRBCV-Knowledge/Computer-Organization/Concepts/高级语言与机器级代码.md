# 高级语言与机器级代码

## 类型判定
框架型 — 描述 C 语言等高级语言如何被翻译为 x86 汇编语言/机器语言，涵盖 x86 八大寄存器、汇编指令格式（操作数三大来源）、常用指令分类，以及 AT&T 与 Intel 两种汇编格式的区别，属于"语言映射框架"类概念。

## 类比 ★
**一句话比喻：** 高级语言是"把菜端上桌"（你说"来盘红烧肉"），汇编语言是"把猪肉从冰箱第3格拿出来→开火→倒油→翻炒→装盘"——前者只管结果，后者精确到每一步对哪个储物柜干什么。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| C 语言 → 编译器 → 汇编语言 → 汇编器 → 机器语言 | 菜单 → 厨师翻译为操作步骤 → 发给洗菜/切菜/炒菜的执行者 |
| 操作数来源：寄存器 / 主存 / 立即数 | 食材在厨师手边托盘（寄存器）/ 冷库里（主存）/ 菜谱本身就写着"盐5克"（立即数） |
| AT&T 格式 vs Intel 格式 | 中文菜谱写"加盐、翻炒"（目的左）vs 英文菜谱写"fry, with salt added"（目的右） |

## 是什么
**机器级代码**包括汇编语言指令和机器语言指令（二进制），两者一一对应。高级语言（如 C）经过编译器编译为汇编语言，再经汇编器翻译为机器语言。一条机器级指令 = 操作码（做什么）+ 地址码（对谁做）。操作数来自三个位置：**寄存器**（直接写寄存器名，如 `EAX`）、**主存**（中括号括地址，如 `[AF996H]`，前加 `dword ptr`/`word ptr`/`byte ptr` 指明读写长度）、**立即数**（直接写常量，十进制或十六进制以 H 结尾）。408 考试只要求认识 x86 汇编，不需要手写。

## 输入-输出空间
- **输入**：高级语言程序（如 C 语言源码）
- **输出**：汇编语言程序 → 机器语言程序（二进制 0101）
- **汇编指令格式**：`操作码 [目的操作数,] [源操作数]`，操作数组合受约束（不允许两个操作数都在主存）

## 正例（≥2 个）
1. **mov 指令三来源实战**：`mov EAX, EBX`→ 寄存器→寄存器（寄存器寻址）；`mov EAX, dword ptr [AF996H]`→ 主存→寄存器（直接寻址）；`mov EAX, 5`→ 立即数→寄存器（立即寻址）。三种来源特征一目了然。
2. **算术指令链实现累加**：`mov EAX, 0`（初始化 result=0）→ `add EAX, EBX`（result += i）→ `inc EDX`（i++）。一条 C 语句 `result += i++` 可能对应多条汇编指令。
3. **AT&T vs Intel 格式对照**：`movl %ebx, %eax`（AT&T：源在左、目的在右、寄存器前加 `%`、指令后缀 `l` 表示 32 位）等同于 `mov eax, ebx`（Intel：目的在左、源在右、寄存器直接写、用 `dword ptr` 标识长度）。同一行左右对比即知等价关系。

## 反例/边界（≥1 个）
1. **两个操作数都在主存是不允许的**：x86 不允许 `mov [addr1], [addr2]`——两个操作数都必须来自主存的指令会导致一条指令多次访存，降低执行效率。至少一个操作数必须是寄存器或立即数。
2. **目的操作数不能是立即数**：`add 5, EAX` 非法——因为加法结果 5+EAX 需要写回目的地，立即数 5 只是一个常量值，不是可以写入的"位置"。目的操作数必须是寄存器或主存地址。
3. **除法指令的被除数隐含在 EDX:EAX**：`div EBX` 只有一个操作数 S=EBX（除数），被除数由 EDX（高32位）:EAX（低32位）拼接为 64 位——这是隐含寻址，初学者常遗忘被除数的隐含来源。
4. **AT&T 格式的多级地址计算容易误读**：`movl -4(%ebx, %esi, 4), %eax` → 基址 EBX + 变址 ESI × 比例因子 4 + 偏移量 -4。看不懂表达式结构时，先拆成：括号内=基址,变址,比例因子，括号外左边=偏移量。

## 详细解释
### x86 八大核心寄存器（均为 32 位，以 E 开头）
| 寄存器 | 类别 | 作用 |
|-------|------|------|
| EAX | 通用（GP） | 累加器 —— 最常用，存放运算结果 |
| EBX | 通用（GP） | 基址 —— 常用于基址寻址 |
| ECX | 通用（GP） | 计数 —— LOOP 指令默认计数器 |
| EDX | 通用（GP） | 数据 —— 除法时与 EAX 拼接为 64 位被除数 |
| ESI | 变址 | 源变址 —— 字符串/数组操作 |
| EDI | 变址 | 目的变址 —— 字符串/数组操作 |
| EBP | 堆栈 | 栈基指针 —— 指向当前栈帧底部 |
| ESP | 堆栈 | 栈顶指针 —— push/pop 操作自动调整 |

> 四个通用寄存器可以灵活使用低 16 位（去掉 E，如 `AX`）或低 8 位（`AL`/`AH`）。变址寄存器和堆栈寄存器只能按 32 位使用。

### 操作数的三种来源表示法
| 来源 | Intel 格式写法 | 特征 |
|------|--------------|------|
| 寄存器 | `EAX`, `EBX`, ... | 以 E 开头的名字，前面无特殊符号 |
| 主存 | `dword ptr [AF996H]` | 有中括号 `[]`，前面有 `byte ptr` / `word ptr` / `dword ptr` |
| 立即数 | `5`, `0AH` | 纯数字（十进制或带 H 的十六进制），无括号 |

> 中括号内可写表达式：`[EBX + 8]` = EBX + 偏移量 8；`[EBX + ESI*4]` = EBX + ESI × 4。不指明长度时默认 32 位（dword）。

### 常用 x86 汇编指令分类
| 类别 | 指令 | 格式 | 说明 |
|------|------|------|------|
| 数据传输 | mov | `mov D, S` | S→D（复制） |
| 算术 | add / sub | `add D, S` / `sub D, S` | D = D+S / D-S |
| 算术 | mul / imul | `mul S` 或 `imul D, S` | 无符号乘 / 有符号乘 |
| 算术 | div / idiv | `div S` | D: (EDX:EAX) ÷ S，商→EAX，余数→EDX |
| 算术 | inc / dec | `inc D` | D++ / D-- |
| 逻辑 | and / or / not / xor | `and D, S` 等 | 逐位与/或/非/异或 |
| 移位 | shl / shr | `shl D, S` | D 逻辑左移/右移 S 位 |
| 控制 | cmp / test | `cmp A, B` | 比较 A 和 B（实际做 A-B，设标志位） |
| 控制 | jmp / jxx | `jmp addr` / `je addr` | 无条件跳转 / 条件跳转 |
| 栈 | push / pop | `push S` / `pop D` | 压栈 / 出栈 |
| 循环 | loop | `loop label` | ECX--; if ECX≠0 goto label |

### AT&T 格式 vs Intel 格式对照表
| 区别项 | Intel 格式（Windows） | AT&T 格式（Unix/Linux） |
|-------|---------------------|----------------------|
| 操作数顺序 | `op 目的, 源` | `op 源, 目的` |
| 寄存器标记 | 直接写 `EAX` | 前加 `%`：`%eax` |
| 立即数标记 | 直接写 `5`, `0AH` | 前加 `$`：`$5`, `$0xA` |
| 主存地址 | 中括号 `[addr]` | 小括号 `(addr)` |
| 读写长度标记 | `byte ptr` / `word ptr` / `dword ptr` | 指令后缀 `b` / `w` / `l`（如 `movb` / `movw` / `movl`） |
| 偏移量写法 | `[EBX+8]` | `8(%ebx)`（偏移量写在小括号左边） |
| 复杂地址 | `[EBX+ESI*4-8]` | `-8(%ebx, %esi, 4)` |

> 408 真题全部使用 Intel 格式。如果遇到 AT&T 格式（有 `%`、`$`、小括号），按表左右对比翻译即可。

## 备注
- 408 考试只考 Intel 格式（Windows 世界的格式），但王道书两种格式都可能出现——遇到 `%` 和 `$` 就切换为 AT&T 思维
- ECX 是 LOOP 指令的专用计数器——循环次数必须放在 ECX 中，不能用其他寄存器替代
- 除法指令 `div` 的被除数来源是隐含寻址（EDX:EAX），这是和加减乘指令最大的不同——单操作数不等于只有一个操作数
- 中括号表示主存地址，"没指明长度默认为 32 位"只在 Intel 格式有效——AT&T 格式没有默认值，必须靠后缀 `b/w/l` 指明
