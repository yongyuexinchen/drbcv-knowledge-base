# 定点数乘法运算

## 类型判定
程序型 — 描述无符号整数和带符号整数（补码）乘法的电路实现原理、流程与溢出判断，以及三种不同速度等级的乘法实现方式，属于"过程 + 对比"类概念。

## 类比 ★
**一句话比喻：** 像餐厅后厨配菜——无符号乘法是"每道菜按菜单逐份加料再往前挪一格"（逐位相乘、错位相加），补码乘法是"多请一个助手看前一位和当前位的组合来决定加料还是减料"（Booth 算法加辅助位），实现方式则像三种厨房——最慢的用基础调料现做（软件模拟）、中等的用半自动料理机（ALU+移位器）、最快的整条流水线一出锅就全好（阵列乘法器一个时钟搞定）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 逐位相乘 + 错位相加 | 做奶茶：每种小料依次倒入杯中，每次倒完把杯子往前推一格再倒下一种 |
| Booth 乘法辅助位 | 请个助手看你上一步和这一步的动作组合，告诉你"接着加糖"还是"把糖撤回来" |
| 阵列乘法器 vs ALU+移位器 | 全自动饺子机（一次出全部）vs 手工一个个包（N 轮才包完） |

## 是什么
**定点数乘法运算**是计算机通过硬件电路模拟手算"逐位相乘、错位相加"的过程，将两个 N 比特定点数相乘得到 2N 比特乘积。无符号乘法：每轮根据乘数最低位决定"加被乘数"或"加零"，然后逻辑右移实现错位相加；补码（带符号）乘法（Booth 一位乘法）：在乘数寄存器末尾增加辅助位，每轮取最低位 + 辅助位共两比特决定"加 X / 减 X / 加零"，完成后整体算术右移，符号位参与运算。实现方式分三个速度等级：阵列乘法器（1 个时钟）> ALU + 移位器 + 寄存器（多时钟，每轮 1 比特）> 纯软件用加减移位等效（最慢，32 轮 × K 条指令）。

## 输入-输出空间
- **输入**：被乘数 X（N 比特，放入寄存器 X）、乘数 Y（N 比特，放入寄存器 Y）
- **输出**：2N 比特乘积（高 N 比特在寄存器 P，低 N 比特在寄存器 Y）；多数架构最终只保留低 N 比特 → 可能溢出
- **前置条件**：乘积寄存器 P 初始化为全 0；补码乘法辅助位初始化为 0；计数器 CN = N；若被乘数或乘数为全 0 则结果直接为 0

## 正例（≥2 个）
1. **无符号 4 位乘法**：13（1101）× 11（1011）= 143（10001111）。电路：4 轮处理，每轮取 Y 最低位 → 为 1 则 P += X，为 0 则不动；然后 P+Y 整体逻辑右移 1 位，CN 减 1，CN=0 时结束，P 和 Y 拼接为 8 比特正确结果。
2. **补码 Booth 乘法**：-3（1101）× 6（0110）= -18（11101110）。带辅助位（初值 0），每轮取 Y 最低位 + 辅助位两比特：00/11 → 加 0；01 → 加 X；10 → 减 X；整体算术右移。4 轮后得到正确 8 位补码乘积。
3. **人类视角溢出判断**：R2=-112（8 位补码 10010000）× R3=252（8 位补码 11111100）= 1568，超过 8 位补码范围 -128~127 → 溢出（2010 年 408 真题 13 题选 B）。

## 反例/边界（≥1 个）
1. **无符号电路直接算补码乘法会错**：-3（1101 补码）× -5（1011 补码），若丢给无符号乘法器得到 10001111=143（十进制），但补码解读为 -113，而正确答案是 +15。
2. **乘法溢出不是用 CF 而是用 OF**：CF 标志位只用于无符号加减法的溢出检测；无论无符号还是带符号整数的乘法溢出，都用 OF 标志位置 1 记录。
3. **无符号溢出判断 ≠ 补码溢出判断**：无符号看高 N 位是否全 0（不全 0 → 溢出）；补码看高 N+1 位是否完全相同（不完全相同 → 溢出）。

## 详细解释
### 无符号乘法电路（ALU+移位器+寄存器）
| 步骤 | 操作 |
|------|------|
| 初始化 | X←被乘数, Y←乘数, P←全0, CN←N |
| 每轮 | ① 查 Y 最低位：=1 → P+=X；=0 → 不操作（加 0）；② P+Y+进位触发器 C 整体逻辑右移一位；③ CN-- |
| 结束 | CN=0，乘积 = P‖Y（2N 比特），最终只保留低 N 比特（寄存器 Y） |

### 补码 Booth 一位乘法
| 步骤 | 操作 |
|------|------|
| 初始化 | X←被乘数, Y←乘数, P←全0, 辅助位←0, CN←N |
| 每轮 | ① 取 Y 最低位 + 辅助位两比特查表：00/11 → 加 0；01 → P+=X；10 → P-=X；② P+Y+辅助位整体算术右移一位；③ CN-- |
| 结束 | CN=0，乘积 = P‖Y（2N 比特补码） |

### 三种实现方式对比
| 方式 | 速度 | 特点 |
|------|------|------|
| 软件模拟（无乘法指令） | 最慢：32K 个时钟（K 条指令/轮 × 32 轮） | 只用加减、移位、逻辑运算等效乘法 |
| ALU+移位器+寄存器（乘法指令） | 中等：N 个时钟（一位乘法）或 N/2（两位乘法） | CPU 执行一条乘法指令，激活该电路 |
| 阵列乘法器（快速乘法器） | 最快：1 个时钟 | 输入被乘数和乘数，输出直接出结果 |

## 备注
- **408 考点 — 溢出判断**：无符号乘法溢出看高 N 位是否全 0（不全 0 → OF=1）；补码乘法溢出看高 N+1 位是否完全相同（不同 → OF=1）
- **408 考点 — Booth 乘法**：辅助位的作用是在 Y 最低位之后增加一位观测，00/11 不加不减，01 加 X，10 减 X = P-=X
- **408 考点 — 溢出处理**：①直接忽略（摆烂）；②乘法指令后插入溢出自陷指令（如 x86 的 INTO），检测 OF=1 则触发操作系统异常处理程序
- **术语**："补码一位乘法"= Booth 乘法；"快速乘法器"≈ 阵列乘法器 ≈ 1 个时钟完成 N 比特乘法
