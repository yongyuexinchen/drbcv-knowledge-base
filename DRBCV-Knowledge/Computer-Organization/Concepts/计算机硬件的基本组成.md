# 计算机硬件的基本组成

## 类型判定
判别型 — 回答"计算机由哪些硬件部件组成、各部件的内部结构和工作原理"，属于系统构成类概念。

## 类比 ★
**一句话比喻：** 像一座霸道总裁府邸——CU 是霸道总裁夫人（全家她拍板），IR 是外卖跑腿小哥（拿着当前这单到处传话），PC 是总管（记着下一步要办啥），MAR 是菜鸟驿站前台小姐（报取件号），MDR 是前台提货区（包裹取放都在这），ACC 是临时仓库（先放着的货），X 是新来货物仓库（新到的货），ALU 是普通加工车间（日常加工），MQ 是特殊加工车间（乘除这种大活专用）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 控制器（CU + IR + PC） | 总裁府邸管理层：夫人拍板（CU）、跑腿小哥传单（IR）、总管记日程（PC，办完一件自动翻下一件） |
| 主存储器接口（MAR + MDR） | 菜鸟驿站：前台小姐报取件号（MAR）、提货区放包裹（MDR）——CPU 报号取货 |
| 运算器（ALU + MQ + ACC + X） | 加工车间：普通加工车间（ALU）、特殊加工车间（MQ）、临时仓库（ACC）、新来货物仓库（X） |

## 是什么
计算机硬件由**五大部件**组成：**输入设备、输出设备、主存储器、运算器、控制器**。其中主存储器、运算器和控制器构成**主机**（计组意义上的主机 = CPU + 主存，不含硬盘等外设）。运算器和控制器集成在同一芯片上即为 **CPU**。冯·诺依曼结构的核心思想是**存储程序**——程序指令和数据以同等地位预先存入主存，计算机自动逐条执行。现代计算机从"以运算器为中心"（数据必须经运算器中转）演进为"以存储器为中心"（输入/输出设备直接与主存交换数据，解放运算器）。

## 输入-输出空间
- **输入**：通过输入设备进入的原始数据与程序（以二进制电信号形式传输）
- **输出**：经运算器处理后的结果，通过输出设备呈现
- **前置条件**：程序和数据已存入主存；控制器通过控制总线协调各部件；数据通过数据总线传输，地址通过地址总线传输

## 正例（≥2 个）
1. **主存储器 = 菜鸟驿站**：CPU 把想访问的地址写入 MAR（报取件号），主存根据 MAR 去存储体找到数据放进 MDR（包裹放柜台），CPU 从 MDR 取走（取包裹）。MDR 位数 = 存储字长，MAR 位数决定了最多支持多少个存储单元。
2. **Y = A × B + C 的执行全程**：C 语言一行代码经编译后变成 5 条机器指令存放在主存 0-4 号单元。PC 从 0 开始逐条取出，CU 分析操作码后指挥各部件——取数指令把 A 放进 ACC，乘法指令把 B 放进 MQ、A 放进 X、ALU 做乘法写回 ACC，加法指令把 C 放进 X、ALU 做加法写回 ACC，存数指令把 ACC 结果写入 Y 的地址——最终 Y = 7。全程取指和分析阶段各指令完全一致，只有执行阶段因操作码不同而异。

### CPU 部件角色对照（霸道总裁府邸版）
| 部件 | 全称 | 府邸角色 | 职责 |
|------|------|---------|------|
| CU | 控制单元 | 霸道总裁夫人 | 分析指令、发出控制信号指挥全家——真正的掌权者 |
| IR | 指令寄存器 | 外卖跑腿小哥 | 手里拿着当前指令（这单），传话给 CU 分析 |
| PC | 程序计数器 | 总管 | 记着下一步要办啥（下条指令地址），办完自动翻页 +1 |
| MAR | 存储器地址寄存器 | 菜鸟驿站前台小姐 | 收 CPU 报的取件号（地址），转告驿站 |
| MDR | 存储器数据寄存器 | 前台提货区 | 数据取放的中转柜台，包裹都在这交接 |
| ACC | 累加器 | 临时仓库 | 暂存运算结果/中间值，下个运算接着用 |
| X | 通用寄存器 | 新来货物仓库 | 暂存新到的操作数，等着进车间加工 |
| ALU | 算术逻辑单元 | 普通加工车间 | 日常加减/逻辑运算的主战场 |
| MQ | 乘商寄存器 | 特殊加工车间 | 乘除法专用——存乘数/商，普通车间干不了的大活 |

## 反例/边界（≥1 个）
1. **"主机 = 整个机箱"是错的**：计组里的"主机"只含 CPU + 主存（内存），不含硬盘（辅存/外存）。硬盘属于 I/O 设备。手机宣传页里"8GB + 128GB"中，8GB 是主存（内存），128GB 是辅存（机身存储）。
2. **"MAR 和 MDR 一定只在主存里"不准确**：逻辑上 MAR 和 MDR 属于主存储器，但现代计算机通常把它们集成在 CPU 内部，所以看到框图里 MAR/MDR 画在 CPU 里不必奇怪。
3. **"冯·诺依曼结构 = 现代计算机结构"不精确**：传统冯·诺依曼结构以运算器为中心（数据必须经运算器中转），现代计算机结构以存储器为中心（I/O 直连主存）。

## 详细解释
### 五大部件的内部构造
| 部件 | 核心子部件 | 作用 |
|------|----------|------|
| **主存储器** | 存储体（存储元阵列）+ MAR（地址寄存器）+ MDR（数据寄存器） | 按地址存取数据；MAR 位数决定存储单元数量上限，MDR 位数 = 存储字长 |
| **运算器** | ALU（算术逻辑单元）+ ACC（累加器）+ MQ（乘商寄存器）+ X（通用寄存器） | 执行算术/逻辑运算；ALU 是核心（制造成本最高），ACC/MQ/X 在不同运算中角色不同 |
| **控制器** | CU（控制单元）+ IR（指令寄存器）+ PC（程序计数器） | CU 分析指令并发出控制信号（核心）；IR 存放当前指令；PC 存放下一条指令地址，取指后自动 +1 |

### 冯·诺依曼结构的六大特点
1. 计算机由五大部件组成（I/O 统称 I/O 设备）
2. 指令和数据以同等地位（二进制形式）存放在存储器中，按地址寻访
3. 指令和数据均用二进制表示（高电平 = 1，低电平 = 0）
4. 指令由**操作码**（做什么）和**地址码**（操作数在哪）组成
5. **存储程序**：指令和数据在程序运行前预先存入主存
6. 以运算器为中心（传统结构）/ 以存储器为中心（现代结构）

### 一条指令执行的三个阶段
1. **取指**：PC → MAR → 主存 → MDR → IR（PC 自动 +1）
2. **分析**：IR 操作码 → CU，CU 译码确定指令类型
3. **执行**：CU 发控制信号，协调各部件完成具体操作（取数/存数/运算/转移）

### 关键术语
- **存储字（word）**：每个存储单元中存放的一串二进制代码
- **存储字长**：每个存储字包含的二进制位数（常见 8/16/32/64 bit）
- **存储元**：存储一个 bit 的电子元件（利用电容充放电原理）
- **字节（Byte，大 B）** = 8 bit（小 b）——大 B ≠ 小 b，宽带 100Mbps 的下载速度 ≈ 12.5 MB/s
- **字（word）≠ 字节（byte）**：一个字多少 bit 取决于计算机结构设计

## 备注
- 软件和硬件在逻辑功能上**等价**：乘法可用硬件乘法电路（一条指令、快）实现，也可用多次加法指令（软件模拟、慢）实现——硬件实现性能高成本高，软件实现性能低成本低
- 大 B（Byte）= 8 个小 b（bit）；字（word）≠ 字节（byte），一个字多少位取决于机器字长
- 宽带宣传 100M（小 b）的下载速度最多约 12.5 MB/s（大 B）——没有运营商骗你，是单位换算问题
- 408 高频考点：MAR 位数 → 存储单元数量 = 2^MAR位数；MDR 位数 = 存储字长；总容量 = 存储单元数 × 存储字长
