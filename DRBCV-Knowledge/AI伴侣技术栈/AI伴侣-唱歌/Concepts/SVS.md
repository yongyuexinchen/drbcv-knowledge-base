# SVS（Singing Voice Synthesis，歌声合成）

## 类型判定
判别型 — 歌词 + 旋律 → 歌声，让 AI 伴侣不仅能「说话」，还能「唱歌」。

## 类比 ★
### 一句话比喻
SVS 像一个拿到乐谱的歌手——你给她歌词和旋律（简谱+音符时长），她就张嘴唱出来。难点在于：唱歌不是把歌词「念出来」，而是要在音高、颤音、气息之间找到「人味」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| SVS 歌词+旋律→歌声 | 歌手拿到乐谱——词和曲都有了，张嘴就唱 |
| 音高 + 颤音控制 | 歌唱技巧训练——不是把音唱准就行，还要有颤音、滑音、气息感 |
| TTS vs SVS | 说话 vs 唱歌——同一张嘴，但唱歌需要额外的「旋律轨道」|

## 是什么
歌声合成（SVS）是将歌词文本和旋律信息（音高序列、音符时长）转化为自然歌声的技术。与 TTS 的核心区别：TTS 只需「说得自然」，SVS 需要「唱得准 + 唱得有感情」。传统 SVS 使用拼接+参数合成（如 UTAU、VOCALOID），现代 SVS 使用神经网络端到端建模（如 DiffSinger、VISinger）。在 AI 伴侣场景中，SVS 赋予伴侣「为你说情歌」的能力。

## 输入-输出空间
- **输入**: 歌词文本 + 乐谱信息（MIDI：音高 + 时长 + 休止符）
- **输出**: 歌声音频（含旋律、颤音、呼吸）
- **与 TTS 的关键区别**: 多了「音高序列」这一控制维度

## 正例（≥2 个）
1. **DiffSinger**: 基于扩散模型的歌声合成，自然度超过传统拼接方案，支持多种演唱风格
2. **ACE Studio / Synthesizer V**: 商业 SVS 引擎，AI 虚拟歌手，音色逼真、可调参数丰富

## 反例/边界（≥1 个）
1. **TTS 念歌词**: 虽然能「念」出歌词文字，但没有旋律控制——念出来的不是歌，是带节奏的朗诵——这不是 SVS
2. **边界 — 高音/极端音域**: SVS 模型在训练数据覆盖的音域内表现好，超出训练范围（如超高音）合成质量急剧下降，出现破音

## 详细解释
SVS 的技术演进：
```
传统: 音素库拼接（VOCALOID）→ 参数合成（UTAU）
      ↓
神经: 自回归模型 → GAN-based → Diffusion-based
```
DiffSinger 的核心思路：用扩散模型在 Mel 频谱空间去噪，通过 score-based 方式建模歌声的复杂分布。相比自回归模型（逐帧预测），扩散模型可以并行去噪，且对音高偏差更鲁棒。

在 AI 伴侣中，SVS 的典型调用链：
```
用户: "给我唱一首生日快乐歌"
LLM → 生成歌词 → MIDI 生成旋律 → SVS → 歌声 → 播放
```

### → 指向

- [[TTS]] — TTS 是 SVS 的技术基座，SVS 可视为「加了旋律轨道的 TTS」

### ← 被指向
- [[Music Generation]] — 音乐生成的整体流程中，SVS 负责人声部分
- [[Voice Cloning]] — 声音克隆技术让 SVS 可以用特定歌手音色唱歌
