# DiffSinger

## 类型判定
判别型 — 基于扩散模型的歌声合成系统，用「去噪」的方式生成自然歌声，代表 SVS 的技术前沿。

## 类比 ★
### 一句话比喻
DiffSinger 像一个用「逐步去噪」画画的画家——先在画布上泼满白噪声（随机乱码），然后一拳一拳地擦除噪声，最后浮现出清晰的自然歌声。每一步去噪都在说「这里应该高一点」「这里加颤音」，比传统「一笔画到底」的方式更有控制力。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 扩散模型逐步去噪 | 雕塑家从大理石里「去掉不属于作品的部分」——去掉噪声，留下歌声 |
| 音高条件引导 | 卡拉 OK 的字幕提示——告诉你下一个音要唱多高 |
| 自回归 vs 扩散 | 串行念稿 vs 并行修图——扩散模型可以同时修正整首歌 |

## 是什么
DiffSinger（2021，浙江大学 & 网易）是第一个将扩散概率模型应用于歌声合成的系统。核心思想：前向过程向干净的 Mel 频谱逐步加噪（直到变成纯噪声），反向过程学习从噪声中逐步恢复频谱——用音高、歌词等条件信号引导去噪方向。相比自回归模型（逐帧生成，错误会累积），扩散模型可并行去噪，对音高偏差更鲁棒，且生成的颤音和滑音更自然。

## 输入-输出空间
- **输入**: 歌词（音素序列）+ 音高序列（f0 曲线）+ 音符时长
- **输出**: Mel 频谱 → HiFi-GAN → 歌声波形
- **生成方式**: 从随机噪声出发，在条件引导下多步去噪（通常 50-100 步）

## 正例（≥2 个）
1. **高质量虚拟歌手**: DiffSinger 生成的颤音、滑音比传统 VOCALOID 自然得多——网易云音乐已有商用
2. **风格化演唱**: 通过条件信号（音高偏差、能量曲线）控制演唱风格——从「甜美」到「嘶吼」都可调节

## 反例/边界（≥1 个）
1. **拼接式 SVS（VOCALOID / UTAU）**: 从音素片段库拼接——音高固定、缺少颤音、机械感强，完全达不到 DiffSinger 的流畅度
2. **边界 — 推理速度**: 扩散模型需要多步去噪（50-100 步/秒音频），实时性不如 RVC 这类自回归+检索方案——更适合「生成后播放」而非「实时演唱」

## 详细解释
DiffSinger 的扩散过程：
```
前向 (加噪): x_0 (干净频谱) → x_1 → … → x_T (纯噪声)
                    ↓
反向 (去噪): x_T → … → x_1 → x_0
           条件: [音高 | 歌词 | 时长]
```
去噪网络（Denoiser）学习预测每一步加入的噪声，通过音高 embedding 和歌词 embedding 引导去噪方向。关键技巧：
- **Pitch Diffusion**: 先扩散生成 f0 曲线，再以此为条件扩散生成频谱
- **Shallow Diffusion**: 先用快速模型生成粗略频谱，扩散模型只做「精修」（Refiner），减少采样步数

## 关系
### → 指向
- [[SVS]] — DiffSinger 是 SVS 的扩散模型实现，代表歌声合成的最高自然度
- [[Voice Conversion]] — DiffSinger 生成的歌声可通过 VC 转换为其他歌手风格

### ← 被指向
- [[Music Generation]] — 全链路音乐生成中，DiffSinger 可负责人声轨道的专业级合成
- [[RVC]] — 两者常协同使用：DiffSinger 生成歌声 + RVC 换音色
