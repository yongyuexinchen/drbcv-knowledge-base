# LLM（Large Language Model，大型语言模型）

## 类型判定
判别型 — AI 伴侣的「大脑」，负责理解、推理和生成自然语言。

## 类比 ★
### 一句话比喻
LLM 像一个读过全人类书籍的实习生——你问什么它都能答，但它没有自己的记忆，每次对话都是从零开始翻阅它的「知识」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| LLM 本身 | 读过全人类书的实习生——知识渊博但没记忆，每次对话从零开始 |
| Context Window | 实习生一次能记住的对话页数——超出就翻篇 |
| Token | 阅读的最小单位——不是按字读，是按词块读 |

## 是什么
大型语言模型是基于 Transformer 架构的深度学习模型，通过在海量文本上预训练（Predict the Next Token）获得语言理解和生成能力。它本身是**无状态的**——没有记忆、没有目标、没有持续的身份。AI 伴侣需要围绕 LLM 构建记忆系统、人格系统和工具调用能力，才能从「问答机器」升级为「数字陪伴体」。

## 输入-输出空间
- **输入**: 文本序列（prompt），可包含系统指令、对话历史、工具调用结果
- **输出**: 文本序列（completion），按 token 逐个生成
- **核心约束**: Context Window 限制一次能处理的总 token 数；生成是自回归的（每次预测下一个 token）

## 正例（≥2 个）
1. **GPT-4 / Claude / DeepSeek**: 通用 LLM，可作为 AI 伴侣的认知核心，通过 System Prompt 设定人格
2. **LLaMA / Qwen 等开源模型**: 可本地部署，适合对隐私和延迟有要求的个人 AI 场景

## 反例/边界（≥1 个）
1. **传统 NLP 模型（BERT）**: 只能理解不能生成，不适合对话型 AI 伴侣
2. **纯规则引擎**: 没有泛化能力，无法处理开放域对话——这不是 LLM
3. **边界**: LLM 不包含记忆——记忆系统（如 Mem0、Memobase）是外挂组件，LLM 只负责「当场理解+生成」

## 详细解释
LLM 的核心机制是 **自回归语言建模**：给定前文 $x_1, x_2, ..., x_{t-1}$，预测下一个 token $x_t$ 的概率分布 $P(x_t | x_{<t})$。这个看似简单的任务，在大规模数据和参数下涌现出了推理、翻译、编码等能力。

在 AI 伴侣架构中，LLM 的位置是：
```
用户输入 → Memory检索 → Prompt组装 → LLM推理 → 响应生成 → Memory写入
```
LLM 是管道中间的「推理引擎」，但它依赖外部的记忆系统和工具层来获得上下文和行动能力。
