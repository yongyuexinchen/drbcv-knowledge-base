# Long-term Memory（长期记忆）

## 类型判定
判别型 — AI 伴侣的「持久化档案库」，跨越会话保存用户经历、偏好和重要事件。

## 类比 ★
### 一句话比喻
长期记忆像你家的阁楼储藏室——每次聊天的重要片段都被打包成箱子存进去。下次你说「还记得上次聊的那个吗」，AI 不是从脑里翻而是派管理员（RAG）去阁楼里翻箱子，翻到了就说「啊找到了！」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Long-term Memory 存储 | 阁楼储藏室——跨越多年的箱子堆，重要物品才存进去 |
| Memory Retrieval（检索） | 管理员拿着手电筒翻箱子——按语义找，不是按时间顺序翻 |
| Memory Consolidation（写入） | 决定哪些东西值得放进阁楼——日常闲聊不上架，人生大事进保险箱 |

## 是什么
长期记忆是 AI 伴侣跨越会话边界保留用户信息的能力。与 LLM 的无状态不同，长期记忆系统在对话结束后将关键信息持久化存储（向量数据库 + 结构化存储），下次对话时通过检索将相关记忆注入 Prompt。它是 AI 从「每次重新认识你」进化到「记得你的过去」的关键组件。

## 输入-输出空间
- **输入**: 对话中提取的记忆片段（经 Memory Consolidation 筛选后）
- **输出**: 检索到的相关记忆上下文（注入 LLM 的 Prompt）
- **存储形式**: 向量嵌入（语义检索）+ 结构化字段（精确查询）+ 原始文本（回看详情）
- **关键操作**: 写入（Consolidation → Store）、检索（Query → Embed → Top-K）、更新（覆盖旧记忆）、衰减（降低权重）

## 正例（≥2 个）
1. **Mem0 / Memobase**: 开源记忆层，自动从对话中提取用户偏好和事件，支持语义检索和时序衰减
2. **ChatGPT Memory**: OpenAI 的内置长期记忆——用户说「记住我喜欢简洁回答」，后续对话自动应用

## 反例/边界（≥1 个）
1. **Context Window 内的历史**: 当前对话的上下文不是长期记忆——关了窗口就消失，这是 Short-term Memory
2. **边界 — 检索遗漏**: 如果用户的旧记忆未被检索到（embedding 相似度不够），LLM 就不知道那段历史，表现为「AI 忘了」

## 详细解释
长期记忆不等同于「把所有聊天记录存起来」。有效的长期记忆系统需要：
1. **提取（Extraction）**: 从对话中识别值得记忆的信息（偏好、事实、事件）
2. **去重与更新（Dedup & Update）**: 新信息覆盖旧信息（「我换工作了」→ 更新职业记忆）
3. **衰减（Decay）**: 非重要信息随时间降低权重
4. **检索（Retrieval）**: 对话时按语义相关性检索 top-k 条记忆

在 AI 伴侣架构中的位置：
```
Short-term Memory → 提取 → Memory Consolidation → Long-term Memory
                                                        ↓
用户提问 → Memory Retrieval → Prompt组装 → LLM → 回应
```

## 关系
### → 指向
- [[Memory Consolidation]] — 记忆巩固决定哪些信息进入长期记忆
- [[Memory Decay]] — 记忆衰减管理长期记忆中信息的生命周期
- [[Memory Retrieval]] — 检索是从长期记忆中提取相关信息的机制（在 RAG 中体现）
- [[User Model]] — 长期记忆是构建用户模型的数据来源
- [[LLM]] — 长期记忆为 LLM 提供跨会话的个性化上下文

### ← 被指向
- [[Short-term Memory]] — 短期记忆中的有价值信息经提取后写入长期记忆
- [[Working Memory]] — 工作记忆处理当前任务时从长期记忆中检索相关背景
- [[RAG]] — RAG 是长期记忆在 AI 伴侣中的核心技术实现
- [[AI Agent]] — Agent 依赖长期记忆获取用户背景来个性化其行为
