# Memory Consolidation（记忆巩固）

## 类型判定
过程型 — 类比人脑从海马体到皮层的记忆转移过程，将短期记忆中的有价值信息筛选、强化并写入长期记忆。

## 类比 ★
### 一句话比喻
记忆巩固像你睡前躺在床上回想今天发生的事——「今天面试失败了，这个很重要得记住」「中午吃了什么来着？算了不重要不记了」。大脑自动把重要事件从「临时缓存」转移到「永久储藏室」，琐事就让它随风飘散。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 从短期→长期的筛选 | 睡前回想——重要的事反复记，琐事直接遗忘 |
| 重要性评分 | 大脑的自动优先级——面试失败(高) > 中午吃啥(低) |
| 记忆强化（重复巩固） | 反复回想同一件事——越想越清晰，越想越牢固 |

## 是什么
Memory Consolidation 是 AI 伴侣记忆系统中的**信息筛选与强化流水线**。它的核心任务：① 从当前对话中识别值得长期保存的信息；② 判断新信息与已有记忆的关系（新增/更新/合并）；③ 分配重要性评分决定记忆的持久度和检索优先级。它像一道质量闸门——不是所有对话都进长期记忆，只有通过巩固筛选的才被写入。

## 输入-输出空间
- **输入**: Short-term Memory（完整对话） + 已有 Long-term Memory（查重和更新用）
- **输出**: 待写入的 Memory Entry（提取后的事实/事件/偏好） + 操作类型（create/update/merge/ignore）
- **关键判断维度**: 情感强度（高兴/沮丧时说的话更重要）、信息新颖性（新信息 vs 已知重复）、用户显式标记（「记住这个」）
- **处理时机**: 对话结束后异步执行，或对话中实时增量巩固

## 正例（≥2 个）
1. **Mem0 的自动记忆提取**: 每轮对话后异步调用 LLM 提取「本次对话值得记住的事实」，去重后写入向量库——实现了 Consolidation 的自动化
2. **用户手动触发**: 用户说「记住我下周五有面试」→ Consolidation 识别为高重要性事件 → 写入长期记忆并设置提醒权重

## 反例/边界（≥1 个）
1. **全量保存（不筛选）**: 把所有对话不加筛选地存入长期记忆——这不是 Consolidation，这是「聊天记录归档」。没有筛选就没有记忆质量
2. **边界 — 过度筛选**: 重要性阈值设得过高导致几乎所有信息都被丢弃——AI 伴侣变得「什么都记不住」。需要在「记得太少」和「记得太多」间平衡

## 详细解释
Consolidation 在记忆体系中的核心流程：

```
Short-term Memory（本轮对话）
        ↓
   [Extraction] — LLM 提取候选记忆项
        ↓
   [Dedup & Update] — 与已有 Long-term Memory 对比
        ↓
   [Importance Scoring] — 评估重要性和衰减曲线
        ↓
   [Write / Merge / Ignore] — 决策
        ↓
Long-term Memory（持久化存储）
```

关键设计决策：
- **同步 vs 异步**: 实时巩固（对话中立即写入）vs 延迟巩固（对话结束后批量处理）——前者响应快但增加延迟，后者不影响对话流畅度但可能遗漏
- **自动 vs 手动**: 完全自动提取 vs 支持用户显式记忆指令——最佳实践是两者结合

## 关系
### → 指向
- [[Long-term Memory]] — 巩固后的信息写入长期记忆
- [[Episodic Memory]] — 事件类信息巩固后形成情景记忆条目
- [[Semantic Memory]] — 跨事件的模式识别触发语义记忆的生成或更新
- [[Memory Decay]] — 巩固时分配的重要性评分决定后续衰减曲线的陡峭程度

### ← 被指向
- [[Short-term Memory]] — 短期记忆是 Consolidation 的唯一信息源
- [[Working Memory]] — 工作记忆中的关键推理结果可触发即时巩固
- [[User Model]] — 用户模型的更新需求反向驱动 Consolidation 的提取策略（比如用户模型缺「职业信息」时优先提取职业相关内容）
