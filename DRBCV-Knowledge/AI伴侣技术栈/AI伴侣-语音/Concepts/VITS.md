# VITS（Variational Inference Text-to-Speech）

## 类型判定
判别型 — 端到端神经语音合成模型，用单一模型同时完成声学建模和波形生成。

## 类比 ★
### 一句话比喻
VITS 像一个不需要配音导演的万能声优——拿到台词自己揣摩语气，张嘴就能演，而且第一次演出就比传统流水线里的「写稿→定调→录音→修音」四组人配合还自然。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 端到端（文字→波形） | 一条龙服务的配音公司——编剧写完台词，出来就是成品音频 |
| 变分推理 + 对抗训练 | 考生做模拟考（生成）后让老师（判别器）打分，不断修正直到老师也分不清真假 |
| 隐变量建模韵律多样性 | 同一个台词本让演员即兴发挥——每次语气略有不同但都自然 |

## 是什么
VITS（2021，Kakao Enterprise）是第一个真正意义上的端到端 TTS 模型。它用条件变分自编码器（CVAE）+ 对抗训练框架，将文本直接映射为音频波形，省掉了传统 TTS 两步走（声学模型 + 声码器）中的信息损失。同时通过隐变量 $z$ 捕捉同一句话的多种自然表达方式（韵律多样性）。

## 输入-输出空间
- **输入**: 文本序列（音素或字符）
- **输出**: 音频波形（单次推理输出一整句）
- **特色**: 隐变量 $z$ 控制韵律变化——同一个文本，不同 $z$ 产生不同语调

## 正例（≥2 个）
1. **AI 伴侣 TTS 引擎**: VITS 生成的语音自然度极高（MOS 可达 4.3+），适合追求「像真人」的陪伴场景
2. **多说话人 TTS**: 在 VITS 基础上加入 speaker embedding，单一模型支持多种音色切换

## 反例/边界（≥1 个）
1. **Tacotron2 + WaveGlow**: 虽然是经典组合但需要独立训练两个模型——声学模型推断 + 声码器生成，中间有频谱信息损失，自然度不如 VITS
2. **边界 — 实时性**: VITS 生成一句话需要全句文本——不适合逐 token 流式输出的场景，需要 Streaming TTS 变体

## 详细解释
VITS 的核心架构：
```
文本 → Text Encoder → 隐变量 z（CVAE 采样）
                          ↓
          Duration Predictor → 对齐 → Decoder → 波形
                          ↑
                  [判别器] ——对抗训练
```
VITS 的三大创新：
1. **归一化流（Normalizing Flow）**: 改善隐变量先验分布，让采样更稳定
2. **对抗训练**: 引入判别器判断生成音频的真假，推动 Generator 生成更自然的波形
3. **单调对齐搜索（MAS）**: 自动学习文本-音频的对齐关系，无需外部对齐器
