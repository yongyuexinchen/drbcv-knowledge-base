# TTS（Text To Speech，文本转语音）

## 类型判定
判别型 — AI 伴侣的「嘴巴」，将文字转化为自然语音，赋予 AI 声音表达能力。

## 类比 ★
### 一句话比喻
TTS 像一个配音演员——拿到剧本（文字）就开口表演，但要是导演（你）不调参，他可能用新闻联播的腔调念你的情话。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| TTS 文字→声音 | 配音演员念稿——文字进来，声音出去 |
| 音色选择 | 选配音演员——是用萝莉音还是御姐音，风格完全不同 |
| 韵律控制 | 导演喊"停，这句要温柔一点"——调整停顿、重音、语调 |

## 是什么
文本转语音技术将输入文本序列转换为自然语音波形。传统做法：文本分析 → 声学模型 → 声码器，分三步走。现代神经 TTS（如 VITS、Tacotron2 + WaveGlow）实现端到端合成，直接从文本预测音频。AI 伴侣场景的核心需求：自然度（不能像机器人）、个性（音色 = 身份）、实时性（不能等五秒才说一句话）。

## 输入-输出空间
- **输入**: 文本序列（可带 SSML 标记控制韵律、停顿）
- **输出**: 音频波形（通常 16-24kHz），流式或整段
- **核心参数**: 音色向量（speaker embedding）、语速、情感参数

## 正例（≥2 个）
1. **VITS**: 端到端神经 TTS，自然度极高，单模型同时做声学建模和声码器
2. **Edge-TTS / Azure TTS**: 微软神经 TTS 服务，中文自然度业界领先，支持 SSML 精细控制

## 反例/边界（≥1 个）
1. **传统拼接式 TTS**: 预录大量音素片段拼接——生成语音机械感强，无法调整韵律，这是被神经 TTS 淘汰的旧技术路线
2. **边界 — 情感表达**: 即便最先进的 TTS，要精确表达「委屈中带着克制」这种细腻情感依然困难——需要额外的情感标注和控制模块

## 详细解释
现代神经 TTS 的两种主流架构：
1. **两阶段**: 声学模型（文字→梅尔频谱）+ 声码器（频谱→波形），如 Tacotron2 + HiFi-GAN
2. **端到端**: 文字直接到波形，如 VITS（Variational Inference + adversarial training）

在 AI 伴侣架构中的位置：
```
LLM 生成文本 → TTS → 音频流 → WebSocket → 前端播放
```
关键性能指标：
- **RTF（Real-Time Factor）**: 生成 1 秒音频需要的时间，< 0.3 才能实时
- **MOS（Mean Opinion Score）**: 自然度主观评分，> 4.0 接近真人
