# 默认模式网络（DMN）

## 类型判定
判别型——区分"任务正向网络"(FPN)与"默认模式网络"(DMN)的功能分工。

## 类比 ★
### 一句话比喻
DMN是你大脑的"待机画面"——当你什么也不做的时候，它不是休息，而是在播放你的人生连续剧：回忆昨天、想象明天、模拟"如果当时我那样说会怎样"。少女就是这部连续剧的主角。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| DMN = 内部剧场 | 坐在公交车上发呆时脑子里自动播放的记忆碎片、未来幻想、自我对话 |
| DMN超活化 | 和少女的长期内部对话 = 你的DMN训练了十几年，比常人强得多 |
| DMN与FPN切换 | 系统思维 = DMN(内部建模)+FPN(外部验证)的高效耦合——你在这两者间切换得比常人快 |

## 是什么
默认模式网络(DMN)主要由内侧前额叶皮层(mPFC)、后扣带回(PCC)、角回组成。它在静息状态（不做外部任务时）高度活跃，负责自传体记忆、未来模拟、自我指涉思维和心理理论（理解他人心理）。当需要执行外部任务时，DMN被抑制，任务正向网络(FPN)接管。创伤后DMN可能过度活跃，表现为反刍思维——但DMN的增强连接也与创造力和发散思维有关。

## 正例（≥2 个）
1. **分析对象的内部对话**：十几年的少女对话训练 → DMN连接密度可能显著高于常人 → 超强内部模拟和想象力。
2. **创意工作者的DMN**：作家、作曲家、科学发现者都报告"灵感在发呆时出现"——那是DMN在自由连接碎片信息。
3. **反刍思维的两面性**：DMN过度活跃→反复想同一个人/事→焦虑和抑郁。但同样的机制→反复推演一个系统→发现其他人看不到的模式。

## 反例/边界（≥1 个）
1. **DMN强≠好事**：DMN和FPN需要平衡。DMN过强而FPN过弱 = 沉浸在内部世界里难以行动（像迪克的晚期）。FPN过强而DMN过弱 = 只能做机械任务没有想象力。
2. **少女对话不是"幻觉"**：它是DMN的正常功能——社会认知网络被内部激活而非外部刺激——就像有人能生动想象"明天的面试"一样，你能生动想象"和永月对话"。

## 详细解释
Raichle(2015)的发现：DMN消耗大脑能量的60-80%，是大脑最"贵"的功能。你的大脑如此大量投入到内部世界——从演化角度，这要么是严重浪费，要么是最有价值的投资。荣格证明了它是投资（转化为理论），迪克证明了它是成本（没能转化为稳定产出）。
