# 多巴胺预测误差信号

## 类型判定
判别型——区分多巴胺作为"快乐物质"（错误理解）与"预期误差信号"（正确理解）。

## 类比 ★
### 一句话比喻
多巴胺不是吃糖时的甜味，而是"居然有糖？"的惊喜。如果你每次打开冰箱都有糖，吃多了就无聊了。但如果糖有时有时无——打开那一刻比吃糖本身更爽。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 预期误差 = 更好的信号 | 部队新兵营每天进步一点点 = 每次都"比预期好一点"→ 多巴胺持续释放 → 越练越爽 |
| 预期误差 = 更差的信号 | 下连队后发现"比预期还差" → 多巴胺暴跌 → 动力断崖 |
| 间歇性不可预测奖赏 | 你"在可解释的高风险中更勇敢"——因为可解释=可预测，风险=高回报，多巴胺最优组合 |

## 是什么
Schultz(2016)的研究颠覆了对多巴胺的传统理解：多巴胺不是"快乐物质"（它不编码奖赏本身），而是"预期误差信号"(reward prediction error)。当实际结果**好于**预期时释放（让你学习"这个行为值得重复"），当结果**差于**预期时抑制（让你避免重复）。这就是为什么不确定性本身可以成为强大的驱动力——间歇性不可预测的奖赏比持续可预测的奖赏产生更强的多巴胺反应。

## 正例（≥2 个）
1. **创业者/赌徒的多巴胺**：高风险高回报的行为刺激多巴胺不是因为钱，是因为"不确定性本身"在激活系统。创业和赌博用的是同一条神经回路——区别在于前者有策略。
2. **分析对象的新兵营vs下连**：新兵营 = 正向预测误差（每天超出预期）→ 多巴胺充足 → 爆发。下连 = 负向预测误差（每天低于预期）→ 多巴胺断供 → 摆烂。
3. **即时反馈需求**："需要即时反馈才能维持动力" = 你需要高频的预测误差信号来维持学习回路。

## 反例/边界（≥1 个）
1. **多巴胺≠快感**：多巴胺是"想要"(wanting)的信号，不是"喜欢"(liking)的信号。你可以多巴胺很高但不快乐——比如刷手机停不下来。
2. **多巴胺耗竭**：如果长期只有负向预测误差（持续失败无反馈），多巴胺系统会进入"节能模式"——什么都不想做了。这就是为什么无反馈的环境让你摆烂。

## 详细解释
Fiorillo等人(2003)的经典实验：训练猴子看一个信号后得到果汁。当果汁100%可预测时，多巴胺神经元在信号出现时激活（预期），果汁出现时无反应。当果汁50%可预测时——多巴胺持续在信号和果汁之间波动。不确定性本身是更强的多巴胺驱动器。

这解释了：你的"可解释高风险偏好" = 大脑在追求最优的预测误差区间——足够可预测以保持安全感，足够不确定以保持兴奋。
