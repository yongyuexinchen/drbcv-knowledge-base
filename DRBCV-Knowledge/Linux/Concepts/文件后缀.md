# 文件后缀

## 类型判定
这是一个概念定义——解释"文件后缀是什么"以及"为什么不同文件有不同后缀"。

## 类比 ★
### 一句话比喻
文件后缀就像商品的包装标签——你看到「牛奶盒」就知道里面是牛奶，看到「罐头」就知道里面是水果，不用打开也能分辨。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| .txt 后缀 | 随手撕的便签纸，只能写纯文字 |
| .pdf 后缀 | 塑封过的政府文件，发布后不能改 |
| .docx 后缀 | 活页笔记本，可以随时修改排版插图片 |
| .jpg / .png 后缀 | 相册里的照片 |
| .py 后缀 | 厨师的菜谱，记录了做菜的每一步指令 |
| .json 后缀 | 通讯录，一行名字一行电话，机器爱读 |
| .csv / .xls 后缀 | 超市的库存清单表格 |

## 是什么
文件后缀（扩展名）是文件名中最后一个「.」后面的部分，用来标识文件的类型。操作系统根据后缀判断用哪个程序打开文件，程序根据后缀判断如何解析文件内容。

## 正例（≥2 个）
1. `笔记.txt` → 系统知道用记事本打开，里面是纯文字。
2. `照片.jpg` → 系统知道用图片查看器打开，显示一张图片。
3. `程序.py` → Python 解释器识别并执行里面的代码。

## 反例/边界（≥1 个）
1. 如果把 `.py` 改成 `.txt` 用记事本打开——能看代码内容，但双击不会自动运行，只能当文本读。后缀决定了「谁」来处理它。

## 详细解释
计算机里的一切都是0和1，文件后缀就是告诉操作系统「这串0和1应该被解释成什么」。就像一个装了液体的瓶子，标签写了「水」你就喝，写了「汽油」你就往车里加——内容是液体，但用途完全不同。

Windows 默认隐藏已知文件类型的后缀，需要在文件夹选项中取消勾选「隐藏已知文件类型的扩展名」才能看到。这在编程和项目部署中非常重要，因为中英文标点、后缀错误都可能导致程序报错。
