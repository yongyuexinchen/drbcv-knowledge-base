# Linux文件系统导航

## 类型判定
这是一个概念定义——解释Linux中 `ls`（查看）、`cd`（进入）、`mkdir`（创建）、`rm`（删除）四组核心文件系统操作指令的含义与区别。

## 类比 ★
### 一句话比喻
`ls` 是趴在窗户上看屋里有什么家具，`cd` 是推门走进去，`mkdir` 是加盖一间新屋子，`rm` 是把屋子炸掉——四个动作，四个后果。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| ls | 透过窗户看房间里有什么 |
| ls -a | 不仅是看——连床底下的东西都翻出来（显示隐藏文件） |
| cd 目录名 | 推开门走进这个房间 |
| cd .. | 退出房间，回到走廊（上一级目录） |
| cd / | 直接瞬移到整个大楼的一楼大厅（根目录） |
| mkdir 目录名 | 请工人加盖一个新房间 |
| rm 文件名 | 把一件家具扔进垃圾桶 |
| rm -r 目录名 | 整个房间连同里面所有东西一起拆掉 |

## 是什么
Linux 中所有操作都基于命令行，没有图形界面来双击文件夹。因此需要四组基本指令：
- **ls**：列出当前目录下的文件和子目录。
- **cd**：切换当前工作目录。
- **mkdir**：创建新目录（文件夹）。
- **rm**：删除文件；加 `-r` 参数可递归删除整个目录及其内容。

## 正例（≥2 个）
1. 登录服务器后执行 `ls`，看到当前目录下有 `project` 文件夹 → `cd project` 进入 → `ls` 查看项目文件 → `cd ..` 返回上级。
2. `mkdir test` 创建 test 目录 → `cd test` 进入 → `rm -r test` 删除（需先退出到上级）。

## 反例/边界（≥1 个）
1. `rm -r /` 会删除整个系统的根目录——相当于把整栋大楼炸掉。Linux 不会问你「确定吗」，删了就真没了。**极度危险，永远不要执行。**

## 详细解释
Linux 文件系统是一棵倒置的树，根目录 `/` 是最顶层。用户登录后通常在 `/home/用户名/` 下工作，root 用户在 `/root/` 下。

关键路径符号：
- `/` 根目录（绝对路径起点）
- `..` 上一级目录
- `~` 当前用户的 home 目录
- `.` 当前目录（隐藏文件以 `.` 开头）

`cd /root/snap/test` 表示从根目录出发，依次进入 root → snap → test。

绝对路径 vs 相对路径：绝对路径从 `/` 开始写全程，相对路径从当前位置出发。`cd project` 进入当前目录下的 project，`cd /home/ubuntu/project` 不管当前在哪都能到达。
