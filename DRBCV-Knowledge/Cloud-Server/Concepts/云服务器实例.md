# 云服务器实例

## 类型判定
这是一个概念定义——解释云服务器「实例」是什么，以及创建实例时需要配置的关键参数：地域、配置规格、镜像、系统盘、公网IP、密钥对。

## 类比 ★
### 一句话比喻
实例就是你跟网吧老板说「开一台机子」——你说清楚要什么配置（显卡型号、CPU核心数）、装什么系统（Windows还是Ubuntu）、硬盘多大、坐哪个区（北京还是新加坡），老板就照单给你配好。这台为你量身准备、正在运行的电脑，就是你的「实例」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 实例（Instance） | 网吧里给你开好的一台电脑 |
| 地域（Region） | 网吧在哪个城市（北京/新加坡/孟买） |
| 配置规格（vCPU + 内存） | CPU是几核的，内存是多大 |
| 镜像（Image） | 电脑预装什么操作系统（Windows 11 / Ubuntu 22.04） |
| 系统盘 | C盘的大小 |
| 公网IP | 这台电脑的上网门牌号 |
| 密钥对 | 上网吧的会员卡——刷卡才能用 |
| 按量付费 | 按小时计费，跟网吧一样 |
| 释放实例 | 下机走人，电脑还给老板 |
| 节省停机模式 | 暂离吃饭——机子释放但数据还在，回来继续 |

## 是什么
云服务器实例（如阿里云ECS、腾讯云CVM）是用户在云平台上创建的一台虚拟服务器的具体运行实体。创建实例时需要选择：地域（物理位置）、配置（vCPU/内存）、镜像（操作系统）、存储（系统盘大小）、网络（公网IP/带宽）、安全组（端口规则）、登录凭证（密码/密钥对）。

## 正例（≥2 个）
1. 在阿里云创建一个新加坡地域、2核CPU+2GB内存、Ubuntu 22.04镜像、40GB系统盘、按量付费的ECS实例 → 支付后几十秒就启动运行。
2. 用密钥对登录刚创建的实例：远程连接 → 上传 `.pem` 密钥文件 → 成功进入命令行终端。

## 反例/边界（≥1 个）
1. 实例创建后如果不主动「释放」，即使关机也在持续扣费（普通停机模式）。只有选择「节省停机模式」或直接「释放」才能停费。就像网吧里你去吃饭了但没结账——机子给你留着，照样计费。

## 详细解释
创建实例的关键步骤和每个参数的含义：

**1. 付费模式：**
- 包年包月 = 长租，价格打折（适合企业）
- 按量付费 = 按小时计费，随时释放（适合学习和测试）

**2. 地域：**
- 服务器实际摆放的物理位置
- 选择离用户近的地域可降低网络延迟
- 测试用途推荐亚太地区（如新加坡）

**3. 实例配置：**
- `2核4G` = 2个CPU核心 + 4GB内存
- 简单网站2核2G足够，AI推理需要GPU机型

**4. 镜像（操作系统）：**
- 推荐 Ubuntu 22.04（稳定、社区活跃、教程多）
- GPU机型需额外选择GPU驱动版本

**5. 公网IP：**
- 必须分配公网IP才能从互联网访问
- 带宽计费：按流量或按固定带宽

**6. 登录凭证：**
- 密钥对（推荐）：更安全，下载 `.pem` 文件保管好
- 自定义密码：简单但有被暴力破解风险
