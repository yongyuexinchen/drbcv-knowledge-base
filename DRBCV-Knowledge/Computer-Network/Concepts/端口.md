# 端口（Port）

## 类型判定
判别 — 同一台服务器上区分不同服务的编号，范围 0-65535。IP 地址找到服务器，端口号找到服务器上的具体服务。

## 类比 ★
### 一句话比喻
IP 地址 = 写字楼的地址。端口 = 写字楼里的房间号。你到了正确的楼（IP），还需要知道去几楼几号房（端口）才能找到对应的人——22 号房是前台（SSH），443 号房是加密通道（HTTPS），80 号房是普通大厅（HTTP）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| IP 地址 192.255.128.175 | 写字楼的门牌号 |
| 端口 22/80/443/10000 | 楼内不同房间号 |
| 一个端口只能一个服务占用 | 一个房间不能同时租给两家公司 |

## 是什么
端口是 TCP/UDP 协议中用于标识特定应用或服务的 16 位数字。服务器上的每个网络服务绑定一个端口，客户端通过 "IP:端口" 连接特定服务。1024 以下的端口是"知名端口"（如 80=HTTP, 443=HTTPS, 22=SSH）。

## 正例
1. **VPS 端口分配**：SSH:22, Xray:10000, ttyd:7681, 3X-UI:20321——同一 IP 地址 `192.255.128.175`，不同端口提供不同服务。
2. **Hysteria2 的 UDP 443**：使用 UDP 443 端口——客户端发送 UDP 包到 `192.255.128.175:443/UDP`，服务端 Hysteria2 监听这个端口。

## 反例/边界
1. **端口冲突**：两个服务不能同时监听同一端口。nginx 和 Xray 如果都配 `listen 443`，后启动的会报 `address already in use`。
2. **TCP 和 UDP 可以共享端口**：TCP 443 和 UDP 443 是两个独立的名字空间——这就是为什么 Hysteria2 (UDP 443) 和之前 Xray (TCP 443) 可以不冲突。
3. **防火墙可以封端口**：运营商可以封特定端口（如封 22 防止 SSH），但不封其他端口——端口封锁比 IP 封锁粒度更细。

## 详细解释
本项目的端口规划：
| 端口 | 协议 | 服务 | 访问方式 |
|:--:|------|------|------|
| 22 | TCP | SSH | 直连 |
| 80 | TCP | Xray VLESS（曾用） | CF CDN → VPS |
| 443 | UDP | Hysteria2 | 直连 |
| 443 | TCP | Xray（曾用 TLS） | 直连/CF |
| 3128 | TCP | tinyproxy（曾用） | CF Tunnel |
| 7681 | TCP | ttyd 网页终端 | CF Tunnel |
| 10000 | TCP | Xray SS+WS | CF Tunnel |
| 20321 | TCP | 3X-UI 面板 | 直连 |

端口设计经验：Cloudflare Tunnel 对外统一走 443（HTTPS），内部按功能分发到不同端口——这是反向代理的核心价值。
