# 奈奎斯特定理与香农定理

## 类型判定
连接型 — 回答"信道的极限数据传输速率是多少"，给出奈奎斯特定理（无噪声信道）和香农定理（有噪声信道）的公式输入→输出关系，并包含算例。

## 是什么
**信道的极限容量**指一条信道所能达到的最高数据传输速率，受**带宽**和**噪声**两个关键因素制约。两个经典定理给出了定量计算方法：
- **奈奎斯特定理**（奈氏准则）——求解无噪声理想信道的极限波特率和极限比特率
- **香农定理**——求解有噪声信道的极限比特率

## 输入-输出空间
- **输入**: 信道带宽 W（Hz）、信噪比 S/N 或 SNR(dB)、信号状态数 K（仅奈奎斯特）
- **输出**: 极限波特率（Baud）或极限比特率（b/s）
- **映射关系**: 公式代入计算

## 正例（≥2个）
1. **奈奎斯特算例**：一条 200KHz 的无噪声信道，采用4个幅值的ASK调制（K=4→log₂4=2比特/码元）。极限波特率 = 2×200K = 400K Baud；极限比特率 = 400K × 2 = 800K b/s。（2022年真题）
2. **香农算例**：一条 8KHz 带宽的信道，信噪比 30dB（→ S/N = 1000）。极限比特率 = 8K × log₂(1+1000) ≈ 80K b/s。若实际为理论最大值的50%，则实际速率 = 40K b/s。（2016年真题）

## 反例/边界（≥1个）
1. **有噪声信道不能套奈奎斯特**：当题目给出信噪比或明确说"有噪声"时，只能使用香农定理。奈奎斯特的前提是"无噪声"或"理想低通信道"。

## 详细解释

### 奈奎斯特定理（无噪声信道）
**极限波特率**（每秒钟最多传输的码元数）：
```
极限波特率 = 2W（Baud）
```
其中 W 为信道带宽（Hz）。

**极限比特率**（每秒钟最多传输的比特数）：
```
极限比特率 = 2W × log₂K（b/s）
```
其中 K 为信号状态数（一个码元可能取值的种类）。

> **使用条件**：信道无噪声，或题目描述为"理想低通信道"。
> 若实际波特率超过 2W，码元间会产生串扰，接收方无法识别。

### 香农定理（有噪声信道）
**极限比特率**：
```
极限比特率 = W × log₂(1 + S/N)（b/s）
```
其中 S/N 为信噪比（无单位比值，信号功率 ÷ 噪声功率）。

### 信噪比的两种记法
| 记法 | 公式 | 说明 |
|------|------|------|
| 无单位比值 | S/N | 信号功率 / 噪声功率，代入香农定理 |
| 分贝（dB） | SNR(dB) = 10 × log₁₀(S/N) | 方便记录大数值 |

**转换关系**：给定 SNR(dB) = d，则 S/N = 10^(d/10)

例：30dB → S/N = 10^(30/10) = 1000

### 两大定理的核心区别
| 维度 | 奈奎斯特定理 | 香农定理 |
|------|-------------|---------|
| 适用条件 | 无噪声/理想低通信道 | 有噪声信道 |
| 输出单位 | 波特率（Baud）→ 可转比特率 | 直接输出比特率（b/s） |
| 关注点 | 码元传输的上限 | 信息传输的上限 |
| 关键参数 | W（带宽）、K（信号状态数） | W（带宽）、S/N（信噪比） |

### 两大定理的联合意义
对于带宽和信噪比确定的信道，一个码元能携带的比特数也有上限：
- 奈奎斯特说：码元速率 ≤ 2W
- 香农说：比特率 ≤ W×log₂(1+S/N)
- 结合可得：一个码元携带的比特数 ≤ log₂(1+S/N)/2

不可能无限增加一个码元携带的比特数——增加信号状态数 K 会要求更高的信号功率，而噪声限制了能可靠区分的状态数。

## 生活类比
奈奎斯特定理就像快递站的**收货速度**：传送带（信道）每分钟最多处理 2W 个包裹（码元），这是物理极限。每个包裹里装几件商品（比特）由包装方式（信号状态数K）决定。香农定理则像**在嘈杂环境中听人说话**：环境噪音（N）越大，你（信号接收方）越难听清对方说的话。对方提高音量（增大信号功率S）或让环境安静下来（降低N），都能提高信息传递的效率。但即便把音量提到最大，信息传递速率也有上限——这就是香农给出的极限。
