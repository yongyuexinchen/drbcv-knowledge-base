# 数据链路层

## 类型判定
判别型 — 回答"数据链路层是什么"以及它承担哪些功能，属于OSI五层/七层模型中第二层的功能定义类概念。

## 是什么
数据链路层是计算机网络体系结构中位于物理层之上、网络层之下的第二层。它在相邻节点之间以**帧**为单位传输数据，基于物理层提供的比特传输服务，实现**逻辑上无差错的数据链路**。核心功能包括：**组帧**（封装成帧）、**差错控制**（检测/纠正位错误）、**可靠传输**（解决帧丢失/重复/失序）、**流量控制**（控制发送速率）和**介质访问控制**（管理广播信道使用权）。

## 输入-输出空间
- **输入**：网络层交下来的IP数据报（分组）
- **输出**：封装后的帧（添加首部和尾部控制信息），交由物理层传输
- **映射关系**：从属关系—数据链路层是OSI模型中的一层，为网络层提供服务

## 正例（至少2个）
1. **以太网交换机转发帧**：当主机A向主机B发送数据时，数据到达交换机（工作在数据链路层），交换机会检查帧的MAC地址、进行差错校验，然后从对应端口转发出去——全程以帧为单位处理。
2. **Wi-Fi无线帧传输**：笔记本电脑通过无线路由器上网时，数据在数据链路层被封装成802.11帧格式，包含MAC地址、帧校验序列（FCS）等字段，接收方校验无误后拆帧交付上层。

## 反例/边界（至少1个）
1. **物理层只传比特，不处理帧**：物理层负责传输原始比特流（如电压高低、光信号有无），它不知道哪些比特属于同一个帧，也不能区分帧的边界——这些是数据链路层的职责。不能说物理层实现了"帧传输"。

## 详细解释
数据链路层的核心价值在于将物理层提供的"有差错的比特传输通道"提升为"逻辑上无差错的帧传输通道"。具体功能分解如下：

| 功能 | 说明 |
|------|------|
| **组帧（封装成帧）** | 给网络层IP数据报添加首部和尾部，确定帧的边界，实现透明传输 |
| **差错控制** | 使用检错编码（奇偶校验、CRC）检测位错误，或使用纠错编码（海明码）纠正位错误 |
| **可靠传输** | 解决帧丢失、帧重复、帧失序问题，通常通过确认+重传机制实现 |
| **流量控制** | 控制发送方的发送速率，确保接收方来得及处理 |
| **介质访问控制** | 在广播信道中协调多个节点对共享介质的访问（CSMA/CD、令牌传递等） |

**物理链路 vs 逻辑链路**：物理链路是相邻节点间实实在在的物理连接（网线、光纤），只保证比特传输；数据链路层在此基础上建立逻辑链路，通过差错控制等手段让上层"看到"一条无差错的链路。即使物理链路上有噪声导致比特跳变（0变1或1变0），数据链路层也能发现并处理这些问题。

## 细节备注

### 帧的基本结构
帧一般由**首部**（控制信息如地址、帧类型）、**数据部分**（网络层IP数据报）和**尾部**（校验码FCS）三部分组成。

### 数据链路层设备
- **网卡（NIC）**：工作在数据链路层，负责帧的封装/拆封
- **交换机**：工作在数据链路层，基于MAC地址转发帧
- **网桥**：早期的数据链路层设备，功能类似交换机

### 使用原则
- 点对点信道（如PPP协议）不需要介质访问控制
- 广播信道（如以太网）需要介质访问控制协议解决争用问题
