# 网络层协议总览

## 类型判定
混合型 — 汇总网络层涉及的所有协议，涵盖 IP 核心协议、路由协议族、辅助协议和移动 IP，既是概念目录也是关系网。

## 类比
**一句话比喻：** 网络层就像一个快递公司的全国调度中心——确定每个包裹（分组）从哪个分拣中心（路由器）走、走哪条路（路由选择）、线路堵了怎么绕（拥塞控制）、地址写不清楚怎么补充（ARP/DHCP）、包裹有问题怎么通知（ICMP）。

| 维度 | 生活映射 |
|------|---------|
| IP 协议 + 编址 | 快递单上的收件/寄件地址（IP 地址），CIDR 就像"XX 省 XX 市"聚合地址 |
| 路由协议 | 全国物流路线规划会议——各分拣中心定期开会更新最优路线表 |
| ARP | "张三是 XX 市 XX 区 XX 路 3 号" → 翻译成经纬度坐标（MAC 地址）才能实际导航 |
| ICMP | 快递员打电话："您好，包裹太大放不进快递柜"（差错通知）或"在吗？测一下你家到我这多久"（ping/traceroute） |

## 是什么
网络层是 OSI 模型的第三层，负责**源主机到目的主机的端到端分组传输**。其协议族可划分为五大类：**IP 核心协议**（IPv4/IPv6 + 编址方案）、**路由协议**（内部网关 RIP/OSPF + 外部网关 BGP）、**辅助协议**（ARP/DHCP/NAT/ICMP/IGMP）、**移动 IP** 和**网络层设备**（路由器）。

## 一、IP 核心协议与编址

### IPv4 分组

| 字段 | 长度 | 说明 |
|------|------|------|
| 版本 | 4 bit | IPv4 = 4 |
| 首部长度 | 4 bit | 以 4 字节为单位，最小 5（=20字节），最大 15（=60字节） |
| 总长度 | 16 bit | 首部+数据，最大 65535 字节 |
| TTL（生存时间） | 8 bit | 每经过一个路由器减 1，减到 0 丢弃；防止分组在网络中无限循环 |
| 协议 | 8 bit | 上层协议：TCP=6，UDP=17，ICMP=1 |
| 首部校验和 | 16 bit | **只校验首部**，每跳路由器重新计算 |
| 源/目的 IP 地址 | 各 32 bit | 标识发送方和接收方 |

> 详细内容 → [[IPv4分组结构]]

### IP 编址（分类 → 子网划分 → CIDR）

| 阶段 | 核心方法 | 特点 |
|------|---------|------|
| **分类编址** | A/B/C/D/E 五类 | A 类 0.0.0.0~127.255.255.255（126 个网络），B 类 128~191，C 类 192~223；**浪费严重** |
| **子网划分** | 从主机号借位做子网号 | 细粒度分配，子网掩码标识网络位和主机位 |
| **CIDR（无分类编址）** | IP/前缀长度（如 192.168.1.0/24） | **路由聚合**，消除分类边界，当今实际使用方案 |

> 详细内容 → [[IP地址（分类编址）]]、[[子网划分与子网掩码]]、[[无分类编址 CIDR]]、[[特殊IP地址]]、[[路由聚合]]

### NAT（网络地址转换）

| 概念 | 说明 |
|------|------|
| **目的** | 节省 IPv4 地址，让内网私有 IP 主机访问外网 |
| **原理** | 路由器在转发分组时，将内网 IP+端口 → 外网 IP+新端口，**修改 IP 首部和传输层端口号** |
| **关键推论** | NAT 路由器工作在网络层和传输层（因为要改端口号） |

> 详细内容 → [[网络地址转换 NAT]]

## 二、路由协议族

### 路由算法分类

| 分类维度 | 类型 | 代表协议 |
|---------|------|---------|
| **按算法** | 距离向量（DV） | RIP |
| | 链路状态（LS） | OSPF |
| **按范围** | 内部网关协议（IGP） | RIP、OSPF |
| | 外部网关协议（EGP） | BGP |

### 三大路由协议对比（考研核心）

| 维度 | RIP | OSPF | BGP |
|------|-----|------|-----|
| **类型** | IGP、距离向量 | IGP、链路状态 | EGP、路径向量 |
| **传输层** | **UDP**（端口 520） | 直接封装在 **IP** 数据报中（协议号 89） | **TCP**（端口 179） |
| **算法** | 跳数最少（Bellman-Ford） | Dijkstra 最短路径（SPF） | 路径向量（非最短） |
| **度量值** | 跳数（最大 15 跳） | 链路代价（带宽/延迟等） | 路径属性（AS_PATH 等） |
| **收敛速度** | 慢（好消息传得快，坏消息传得慢） | 快（全网 LSA 洪泛） | 慢（重在稳定） |
| **更新方式** | 周期性广播完整路由表 | 触发式洪泛 LSA | 增量更新（仅变化部分） |
| **适用规模** | 小型网络 | 中大型网络（自治系统内部） | **自治系统之间**（互联网骨干） |

> 详细内容 → [[路由算法分类]]、[[距离向量vs链路状态对比]]、[[RIP协议]]、[[RIP工作过程]]、[[OSPF协议]]、[[OSPF工作原理]]、[[OSPF分组类型]]、[[OSPF路由器类型（ASBR-ABR-内部路由器）]]、[[LSA-LSDB-LSI（链路状态三件套）]]、[[迪杰斯特拉算法(Dijkstra)]]、[[BGP协议]]、[[BGP路由信息与工作原理]]、[[BGP路由选择]]

## 三、辅助协议

| 协议 | 全称 | 作用 | 层归属 |
|------|------|------|--------|
| **ARP** | 地址解析协议 | IP 地址 → MAC 地址（查表/广播请求+单播应答） | 网络层（封装在帧中） |
| **ICMP** | 网际控制报文协议 | 差错报告（目的不可达/超时）+ 网络探测（ping/traceroute） | 网络层（封装在 IP 数据报中） |
| **DHCP** | 动态主机配置协议 | 自动分配 IP 地址、子网掩码、默认网关、DNS | **应用层**（基于 UDP） |
| **IGMP** | 网际组管理协议 | 多播组管理：主机加入/离开多播组 | 网络层（封装在 IP 数据报中） |

> 详细内容 → [[地址解析协议 ARP]]、[[ICMP网际控制报文协议]]、[[动态主机配置协议 DHCP]]、[[IP多播]]

## 四、移动 IP

解决移动节点在网络间切换时保持通信不中断的问题。核心机制：**归属代理+外地代理+转交地址**。通信对方始终向归属网络发送数据报，归属代理通过隧道转发到移动节点当前所在地。

> 详细内容 → [[移动IP通信过程]]

## 五、网络层设备

**路由器**：工作在网络层，根据 IP 地址转发分组。核心结构：路由表（控制平面）+ 转发表（数据平面）。能隔离广播域和冲突域。

## 正例（≥2个）

1. **ARP 解析过程**：主机 A（192.168.1.1）要给主机 B（192.168.1.2）发数据 → A 查 ARP 表未命中 → A 广播 ARP 请求"谁是 192.168.1.2？告诉我你的 MAC" → B 单播应答"我是，我的 MAC 是 BB:BB:BB:BB:BB:BB" → A 存入 ARP 表，封装帧发送。
2. **ICMP 差错报告**：路由器收到一个 TTL=1 的分组 → TTL 减 1 后为 0 → 路由器丢弃该分组 → 向源主机发送 ICMP"时间超过"差错报文。这就是 `traceroute` 的工作原理——依次发 TTL=1,2,3,... 的分组来探测每一跳。

## 反例/边界（≥1个）

1. **ARP 请求不跨路由器（广播域边界）**：ARP 请求是广播帧，路由器不转发广播。主机 A 在局域网内广播"谁是 192.168.2.1？"，若该 IP 在另一个网段，路由器不会转发这个 ARP 请求——主机 A 会被告知"目的不可达"。
