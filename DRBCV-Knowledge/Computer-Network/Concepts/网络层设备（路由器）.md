# 网络层设备（路由器）

## 类型判定
判别型 — 回答"网络层设备是什么、路由器的组成结构如何"的问题，核心是对路由器两大组成部分（控制平面+数据平面）和两大功能（路由选择+分组转发）的定性描述。

## 是什么
路由器是网络层核心设备，实现两大功能：**路由选择**（确定最佳路径）和**分组转发**（将IP分组从输入端口送到输出端口）。路由器在逻辑上由**控制平面**（Control Plane）和**数据平面**（Data Plane）组成。控制平面负责运行路由协议、生成路由表；数据平面负责查转发表、快速转发分组。**路由表**（控制平面用）和**转发表**（数据平面用）严格来说有区别，但绝大多数考试场景下可混用。

## 输入-输出空间
- **输入**：从一个输入端口接收IP分组（由物理层→链路层剥去帧头帧尾后得到）
- **输出**：根据转发表确定输出端口，IP分组经交换结构到达输出端口，封装帧后发出
- **映射关系**：从属关系 — 路由器属于网络层设备，它的输入/输出端口分别对应物理层、链路层、网络层的处理

## 正例（至少2个）
1. **园区网接入路由器**：一台思科路由器有24个千兆电口（铜口/RJ45）和4个万兆光口（光纤口）。24个电口连接多个子网，4个光口上联到核心网络。路由器运行OSPF协议，通过控制平面学习到网络拓扑，生成路由表，再精简为转发表供数据平面高速转发。
2. **家用路由器**（虽功能混合）：虽然没有商用路由器专业，但基本架构相同。WAN口接收来自ISP的数据，LAN口连接家里的电脑/手机。路由器查路由表确定内网和外网的转发，同时还集成了NAT、DHCP等功能。

## 反例/边界（至少1个）
1. **路由器 ≠ 交换机**：交换机工作在数据链路层（基于MAC地址转发帧），路由器工作在网络层（基于IP地址转发分组）。交换机不自学习网络拓扑（只是学习MAC表），路由器通过路由协议自学习网络拓扑并计算路径。家用路由器虽内置了交换功能，但那是集成的，功能上依然是两个独立设备。

## 详细解释

### 路由器的两大组成部分

```
┌────────────────────────────────────────────┐
│              控制平面                        │
│  ┌──────────────┐                          │
│  │ 路由选择处理机  │ ← 运行路由协议进程        │
│  │ (路由器CPU)    │    (RIP/OSPF/BGP)       │
│  └──────┬───────┘                          │
│         ↓                                  │
│   ┌──────────┐                             │
│   │  路由表   │ ← 含目的网络/下一跳/出接口    │
│   │          │   以及协议附加信息             │
│   │          │    (RIP:跳数, OSPF:代价,      │
│   │          │     BGP:AS_PATH/本地偏好)    │
│   └──────────┘                             │
├────────────────────────────────────────────┤
│              数据平面                        │
│  ┌──────────┐     ┌──────────────┐         │
│  │  转发表   │ ←──│  交换结构     │         │
│  │ (精简版)  │     │  (硬件/软件)  │         │
│  └──────────┘     └──────┬───────┘         │
│                          │                  │
│ 输入端口 ── 网络层 ──     │     ── 网络层 ── 输出端口│
│  (物理层→链路层→网络层)   │     (网络层→链路层→物理层)│
│                          │                  │
│   输入缓冲区 (队列)       │      输出缓冲区   │
└────────────────────────────────────────────┘
```

### 控制平面（路由选择功能）

**核心组件**：路由选择处理机（路由器的CPU/内存）

**工作内容**：
1. 运行路由协议（RIP/OSPF/BGP中的一个或多个）
2. 与邻居路由器交换路由信息
3. 通过路由协议的计算生成**路由表**

**路由表格式比较**：

| 协议 | 路由表核心字段 | 特有字段 |
|------|--------------|---------|
| RIP | 目的网络前缀、下一跳IP、出接口 | 跳数 |
| OSPF | 目的网络前缀、下一跳IP、出接口 | 代价(Cost)、区域ID |
| BGP | 目的网络前缀、下一跳IP、出接口 | AS_PATH、本地偏好值 |

所有路由表至少包含：**目的网络前缀 + 下一跳路由器IP + 输出接口编号**。

**路由表典型结构**：
| 网络前缀 | 下一跳IP | 接口 |
|---------|---------|------|
| 202.114.0.0/16 | — (直连) | E1 |
| 202.114.2.0/24 | 202.114.2.2 | E1 |
| 0.0.0.0/0 (默认) | 202.114.1.1 | E0 |

### 数据平面（分组转发功能）

**核心组件**：转发表 + 交换结构 + 输入/输出端口

**工作流程**：
1. 输入端口物理层接收比特流，链路层去除帧头帧尾得到IP分组
2. 若交换结构繁忙，IP分组暂存于**输入缓冲区**
3. 查**转发表**确定输出端口
4. 通过**交换结构**将分组送到对应输出端口
5. 若链路繁忙，分组暂存于**输出缓冲区**
6. 输出端口：网络层→链路层（封装帧）→物理层（发送比特流）

### 路由表 vs 转发表

| 对比 | 路由表（Routing Table） | 转发表（Forwarding Table） |
|------|----------------------|------------------------|
| 所属平面 | 控制平面 | 数据平面 |
| 信息完整度 | 包含协议附加字段（跳数/代价/AS_PATH等） | 只保留网络前缀+下一跳+出接口 |
| 生成方式 | 由路由协议动态生成或手工配置 | 从路由表精简得到 |
| 查找速度 | 较慢（信息多） | 较快（常用硬件加速） |
| 功能 | 用于路由选择决策 | 用于分组快速转发 |

**在绝大多数考试/教材场景中，路由表和转发表可以混用。** 如果特意区分，记住"路由表是控制平面，转发表是数据平面"即可。

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 端口/接口 | 两者在路由器中同义，电口（铜口/RJ45）和光口（光纤接口）|
| 输入缓冲区 | 暂存来不及处理的IP分组，队列存满则丢包（拥塞） |
| 输出缓冲区 | 暂存因链路带宽不足而无法发出的分组 |
| 交换结构 | 硬件（如Crossbar）或软件实现，将输入端口映射到输出端口 |

### 使用原则
- 控制平面需要多台路由器**相互配合**（运行相同的路由协议）
- 数据平面**只涉及本路由器自身**的查表和转发
- 路由表包含的信息比转发表更丰富
