# 计算机网络性能指标

## 类型判定
连接型 — 回答"如何量化度量计算机网络性能"，核心是七个指标的定义、计算公式和互相之间的关系。包含公式推导和算例分析。

## 是什么
计算机网络性能指标是用于定量评价网络性能的七项核心度量：**速率、带宽、吞吐量、时延、时延带宽积、往返时延(RTT)、信道利用率**。其中时延是考研最高频考点，带宽有两种含义需注意区分。这些指标从不同角度刻画了网络的数据传输能力和效率。

## 输入-输出空间
- **输入**：网络设备参数（带宽、速率）、数据传输参数（数据量、链路长度、传播速度）
- **输出**：各项指标的具体数值（bps、s、bit、%）
- **映射关系**：映射关系 — 通过公式将输入参数映射为性能度量值

## 正例（≥2个）
1. **家庭宽带测速**：运营商宣传"1000兆宽带"——下行带宽 1000Mbps，理论上最高下载速度 125MB/s（1000÷8）。若网线是五类线（仅支持 100Mbps），则实际带宽被网线限制到 100Mbps，下载速度最高仅 12.5MB/s。
2. **游戏延迟（RTT）**：打游戏时显示的"延迟 50ms"，本质是手机到游戏服务器的往返时延。你按下按键 → 数据封装发给服务器 → 服务器处理并返回结果 → 手机更新画面。RTT 越高，操作越卡顿。

## 反例/边界（≥1个）
1. **混淆大B和小B**：速率 1.8MB/s ≠ 1.8Mbps。大 B=Byte（字节）=8bit，小 b=bit（比特）。换算：1.8MB/s = 1.8×8 = 14.4Mbps。考试计算时必须统一单位。
2. **混淆发送时延和传播时延**：发送时延是"数据推向信道的时间"（数据长度÷发送速率），传播时延是"电磁波在信道上传的时间"（信道长度÷传播速度）。两者是完全不同的概念，不要混淆。

## 详细解释

### 七项性能指标详解

#### 1. 速率（Rate / Data Rate）
连接到网络上的节点在信道上传输数据的速率，也称**数据率**、**比特率**。

- **单位**：比特每秒（b/s、bps），可加前缀 K(10³)、M(10⁶)、G(10⁹)、T(10¹²)
- **注意**：在计算机网络中，K/M/G/T 以 10³ 为倍数递增（区别于组成原理中的 2¹⁰）
- **大B与小B**：1 Byte = 8 bit，1 MB/s = 8 Mbps

#### 2. 带宽（Bandwidth）
**计算机网络含义**：某个信道所能传送的**最高数据率**，单位 bps。
**通信原理含义**：某个信道允许通过的**信号频带范围**，单位 Hz（赫兹）。

两种含义本质上都反映信道的数据传输能力——带宽越大，传输能力越强。光纤带宽（约 500MHz）远大于电话线带宽（约 3kHz），故光纤的数据率远高于电话线。

> **算例**：主机A的网卡速率 1Gbps，链路带宽 100Mbps，主机B的网卡速率 10Mbps。则A→B的最高理论速率为 min(1G, 100M, 10M) = **10Mbps**（受限于B的网卡）。

#### 3. 吞吐量（Throughput）
单位时间内通过某个网络/信道/接口的**实际数据量**，单位 bps。

- 反映网络的实际综合负载
- 总吞吐量 = 双向数据速率之和（发送 + 接收）
- 考研中极少涉及，了解即可

#### 4. 时延（Delay / Latency）
数据从网络中 A 点传送到 B 点所需的总时间，由四部分组成：

```
总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
```

| 时延类型 | 计算公式 | 影响因素 | 说明 |
|----------|---------|---------|------|
| **发送时延**（传输时延） | 数据长度 ÷ 发送速率 | 数据大小、接口速率 | 节点把数据"推"到信道上的时间 |
| **传播时延** | 信道长度 ÷ 电磁波传播速度 | 距离、介质材质 | 电磁波在信道中跑的时间 |
| **处理时延** | 无固定公式 | 路由器性能 | 路由器检查首部、决定转发路径的时间 |
| **排队时延** | 无固定公式 | 网络负载 | 分组排队进入/发出路由器的时间 |

> **经典算例**：H1→H2 经一个路由器，分组大小 1000B，H1 发送速率 100Mbps，路由器→H2 速率 80Mbps，链路A传播时延 0.01ms，链路B传播时延 0.05ms，忽略处理/排队时延。
>
> 解：
> - 发送时延A = 1000×8 bit ÷ 100×10⁶ bps = 0.08ms
> - 发送时延B = 1000×8 bit ÷ 80×10⁶ bps = 0.1ms
> - 传播时延A = 0.01ms
> - 传播时延B = 0.05ms
> - **总时延 = 0.01 + 0.08 + 0.05 + 0.1 = 0.24ms**

#### 5. 时延带宽积（Bandwidth-Delay Product）
```
时延带宽积 = 单向传播时延 × 带宽  （单位：bit）
```

**物理意义**：某条链路上**已经从发送端发出、但尚未到达接收端的最大比特数**。

类比：把链路看作水管，带宽是水管的横截面积，传播时延是水管的长度。横截面积越大、水管越长，管内可容纳的水量（比特数）就越多。

> **算例**（2023年真题）：链路带宽 100Mbps，时延带宽积 1000bit。求单向传播时延。
>
> 解：传播时延 = 时延带宽积 ÷ 带宽 = 1000bit ÷ 100×10⁶ bps = 0.01ms

#### 6. 往返时延（RTT, Round-Trip Time）
从**发送方发送完数据**开始，到发送方接收到来自接收方的确认为止所经历的时间。

```
RTT = 传播时延(去) + 接收方处理时间 + 确认帧发送时间 + 传播时延(回)
```

注意：RTT 不计入发送方的发送时间（从发完开始计时），以谢希仁教材定义为准。

#### 7. 信道利用率（Channel Utilization）
一条信道中有百分之多少的时间有数据通过：

```
信道利用率 = 有数据通过的时间 ÷ 总时间
```

信道利用率太低会浪费资源，太高易导致网络拥塞。

> **算例**：蓝牙连接 60 秒，以 80Mbps 传输 20 张 10MB 照片。
>
> 解：数据总量 = 20×10×8 = 1600Mbit；传输时间 = 1600÷80 = 20s
> 信道利用率 = 20÷60 ≈ **33.3%**

### 单位换算速查

| 前缀 | 计算机网络（×10³） | 组成原理/OS（×2¹⁰） |
|------|-------------------|-------------------|
| K | 10³ = 1000 | 2¹⁰ = 1024 |
| M | 10⁶ = 1,000,000 | 2²⁰ = 1,048,576 |
| G | 10⁹ | 2³⁰ |
| T | 10¹² | 2⁴⁰ |

## 生活类比
带宽就像**高速公路的最高限速**（能跑多快），吞吐量就像**你实际开到均速**（实际多快），时延中的发送时延就像**车辆排队通过收费站的时间**（把车推上路的时间），传播时延就像**车在路上跑的时间**（路长÷限速）。RTT 就像你从发快递到收到对方回执的总时长。信道利用率就像高速公路某时段有车在跑的时间比例——太低浪费、太高堵车。
