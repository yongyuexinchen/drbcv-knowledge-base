# TCP报文段

## 类型判定
判别型 — 回答"TCP报文段首部有哪些字段，各有什么作用"，属于对TCP首部字段的识别归类和功能记忆。

## 是什么
TCP报文段（TCP Segment）是传输层TCP协议的数据单元，由**TCP首部**和**数据部分**组成。TCP首部**最小20字节，最大60字节**（固定部分20字节 + 可变选项部分最多40字节），包含源/目的端口号、序号、确认号、标志位、窗口、校验和、紧急指针等字段。TCP协议通过这些字段实现可靠传输、流量控制和连接管理。

## 输入-输出空间
- **输入**：应用层交下来的字节流 + 控制信息（端口、标志等）
- **输出**：TCP首部 + 数据部分（封装为一个TCP段，交给IP层）
- **映射关系**：从属关系 — 各字段的值由TCP协议根据传输状态计算和设置

## 正例（至少2个）
1. **数据传输中的TCP段**：承载数据的TCP段首部包含源端口(3666)、目的端口(9888)、序号(600)、确认号(603)、ACK=1、窗口=5等字段，接收方根据这些字段确认数据已收到并告知剩余接收能力。
2. **连接请求SYN段**：握手一（SYN=1, ACK=0）用于发起连接请求，首部包含客户端设置的初始序号；握手二（SYN=1, ACK=1）表示同意连接。

## 反例/边界（至少1个）
1. **TCP首部不含总长度字段**：与IP数据报不同，TCP报文段没有"总长度"字段。TCP段长度通过IP数据报的总长度减去IP首部长度推算得到，再减去TCP首部长度（数据偏移字段指示）得到TCP数据部分长度。

### 核心字段详解（考试重点）

#### 端口号（各16比特）
- **源端口**：发送方进程的端口号
- **目的端口**：接收方进程的端口号

#### 序号 — SEQ（32比特）⭐高频
- 标记当前TCP段中**数据部分的第一个字节**在原始字节流中的位置
- 起始序号由发送方自行设定（不一定从0开始）
- 即使握手一/握手二不携带数据，也要消耗一个序号

#### 确认号 — ACK sequence（32比特）⭐高频
- 与**大写ACK标志位**配合：ACK=1时确认号有效（除握手一外均有效）
- 含义：**确认号之前的所有字节都已正确接收**
- 具有**累计确认**特性：可一次确认多个报文段

#### 数据偏移（4比特）
- 表示TCP首部长度，**以4字节为单位**
- 取值范围0~15 → 首部长度 = 值×4，范围20~60字节
- 首部必须是4字节的整数倍（填充字段用于补齐）

#### 标志位（各1比特）⭐高频
| 标志 | 全称 | 含义 | 启用条件 |
|------|------|------|---------|
| **URG** | Urgent | 紧急数据，应尽快发送 | 紧急指针有效 |
| **ACK** | Acknowledgment | 确认号有效 | **除握手一外，所有TCP段都为1** |
| **PSH** | Push | 推送，希望接收方尽快交付给应用层 | 交互式通信 |
| **RST** | Reset | 复位连接，出现严重差错 | 主机崩溃、拒绝非法段 |
| **SYN** | Synchronize | 同步，连接请求/接受 | **只有握手一和握手二为1** |
| **FIN** | Finish | 终止，数据已发送完 | **只有挥手一和挥手三为1** |

#### 窗口（16比特）⭐高频
- 表示**接收窗口（RWND）** 的大小，单位字节
- 接收方告知发送方自己还能接收多少字节
- **流量控制**的关键字段

#### 校验和（16比特）
- 与UDP校验和算法完全相同
- 也要添加12字节伪首部，但协议字段改成6（TCP）
- 考研大纲未要求重点掌握TCP校验

#### 紧急指针（16比特）
- 与URG标志配合，指向紧急数据的序号
- 紧急数据有自己的独立编号系统

### 选项字段
- 可变长度，可为空
- 最重要作用：在握手一和握手二中**协商MSS（最大段长）**
  - MSS：一个TCP段中最多可携带的有效数据字节数
  - 通信双方可设置不同的MSS值

### 常用缩写在考题中的表示

| 缩写 | 含义 | 说明 |
|------|------|------|
| **SEQ** | 序号字段 | 32比特 |
| **ACK seq** / 小写ack | 确认号字段 | 32比特 |
| **大写ACK** | ACK标志位 | 1比特 |
| **SYN** | 同步标志位 | 1比特 |
| **FIN** | 终止标志位 | 1比特 |
| **RWND / RCVWND** | 接收窗口 | 16比特 |

### 考试优先级
1. ⭐高频：序号、确认号、窗口、ACK/SYN/FIN标志位
2. 中频：URG+紧急指针、PSH、RST、数据偏移
3. 低频：校验和、保留位、选项字段（只需知道MSS协商）

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| SYN段 | SYN=1的TCP段（握手一或握手二） |
| FIN段 | FIN=1的TCP段（挥手一或挥手三） |
| ACK段 | ACK=1的TCP段（除握手一外的几乎所有段） |
| MSS协商 | 在握手一、握手二选项字段中协商，通常为1KB |
| 数据偏移 | 其实就是TCP首部长度，以4字节为单位 |
