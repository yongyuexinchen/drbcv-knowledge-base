# IP多播

## 类型判定
判别型 — 回答"IP多播是什么、有什么基本概念和特点"的问题，核心是对IP多播技术及相关概念的定性描述。

## 是什么
IP多播（IP Multicast）是一种**一对多**的通信方式，源主机只发送**一份**IP数据报，目的地址填写**多播地址（D类地址）**，由多播路由器在转发过程中复制分发，最终送达加入该多播组的**所有**接收主机。IP多播地址像**QQ群号**（多个主机加入同一个"群"），而单播地址像**个人QQ号**（一对一通信）。

## 输入-输出空间
- **输入**：源主机发送的目的地址为D类多播地址的IP分组
- **输出**：多播路由器将分组复制并转发到所有包含该多播组成员的接口
- **映射关系**：从属关系 — IP多播属于一类通信模式（与单播、广播并列），使用D类地址实现

## 正例（至少2个）
1. **网络电视（IPTV）**：CCTV1绑定多播地址224.0.0.1。当你家的电视调到CCTV1时，机顶盒通过IGMP协议告知路由器"我要加入224.0.0.1这个组"。视频服务器只需发一份IP多播分组，家庭路由器复制分发，所有看CCTV1的家庭都能收到。**换台 = 退出旧群 + 加入新群**。
2. **视频会议/直播**：一场在线直播有10万观众，服务器只需发送一份IP多播分组，沿途路由器逐级复制转发。如果是单播，服务器需要发送10万份相同内容，网络带宽压力巨大。

## 反例/边界（至少1个）
1. **IP多播 ≠ IP广播**：广播（如ARP广播）将所有分组发送给同一广播域内的所有主机；多播只发送给**加入特定组**的主机。不感兴趣的主机不会被骚扰，效率更高。
2. **IP多播 ≠ 可靠交付**：多播和单播一样是"尽最大努力交付"，不保证可靠。接收方收到多播分组后不会返回ACK。

## 详细解释

### 多播地址（D类地址）
- 前4位固定为**1110**
- 范围：224.0.0.0 ~ 239.255.255.255
- **只能作为目的地址，不能作为源地址**（选择题常考！）
- 不能分配给特定主机，一个多播地址对应一个"多播组"

### 多播与单播的对比

| 对比 | IP单播 | IP多播 |
|------|-------|-------|
| 地址类型 | A/B/C类地址 | D类地址（1110开头） |
| 类比 | 个人QQ号 | QQ群号 |
| 90人看直播 | 服务器发90份 | 服务器只发1份 |
| 分组复制 | 源端重复发送 | 沿途路由器复制转发 |

### 关键协议

#### IGMP（互联网组管理协议）
- **作用**：管理主机和路由器之间的多播组成员关系（加群/退群）
- 主机通过IGMP告知**直连路由器**要加入/离开哪个多播组
- **协议层次**：网络层（虽然使用IP协议传输，IGMP报文封装在IP分组中，协议字段=2）
- 考研要求：仅需了解作用和层次

#### 多播路由协议
- **作用**：在多播路由器之间交换多播组成员信息
- 让路由器知道"哪个接口后面有哪个多播组的成员"
- 考研要求：仅需了解其存在和作用

### IP多播的三个特点

1. **尽最大努力交付**：同IP单播一样，不保证可靠交付，接收方不返回ACK
2. **多播IP只能做目的地址**：不能作为源IP地址写入IP分组源地址字段（必考选择题）
3. **不产生ICMP差错报文**：多播分组转发过程中出错（如TTL超时），路由器直接丢弃，不返回ICMP差错报告

### 多播路由器的工作流程

1. 源主机发IP分组，目的地址=多播地址（如224.0.0.1）
2. 多播路由器检查与该多播地址关联的接口列表
3. 将分组复制转发到所有关联接口（每个接口只发一份）
4. 下一跳路由器重复相同过程
5. 最终所有加入该组的接收主机都收到分组

### 子特性
| 特性 | 说明 |

| 地址前缀 | 1110（D类） |
| 用途 | 一对多通信（直播、电视、会议） |
| IGMP层次 | 网络层 |
