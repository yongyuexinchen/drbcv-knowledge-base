# IEEE 802.11 无线局域网

## 类型判定
混合型 — 判别部分回答"802.11无线局域网是什么"（基本概念、体系结构、帧分类），连接部分回答"如何工作"（数据帧在AP与移动站之间的流转、地址字段的切换逻辑）。

## 是什么
IEEE 802.11是无线局域网（Wi-Fi）的国际标准，定义了无线链路上的物理层和数据链路层规范。它有两种分类：(1) **有固定基础设施**的无线局域网（即家用/企业Wi-Fi），使用AP（接入点）作为中心基站；(2) **无固定基础设施**的移动自组织网络（Ad Hoc，如苹果AirDrop、华为分享），节点间平等互联，无需中心节点。考试重点是有固定基础设施的802.11无线局域网。

## 输入-输出空间
- **输入**：移动站要发送的数据（IP分组），封装成802.11帧
- **输出**：经由AP中转后送达目标移动站的802.11帧
- **映射关系**：从属关系（概念定义） + 映射关系（帧在移动站→AP→移动站的两段式流转过程）

## 正例（至少2个）
1. **家庭Wi-Fi上网**：手机连接家中无线路由器（AP），手机发送的HTTP请求先封装成802.11帧发给AP，AP拆帧后通过有线以太网上传互联网；返回数据到达AP后重新封装成802.11帧发给手机。
2. **全屋Wi-Fi（子母路由）**：华为子母路由器方案中，三个子路由（AP）通过分配系统（DS）连接到母路由，组成扩展服务集（ESS）。手机在书房连子路由A，走到客厅自动切换到子路由B（漫游），过程中通信不中断。

## 反例/边界（至少1个）
1. **移动站不能直接通信**：在802.11有基础设施模式下，两个移动站之间不能直接发送数据帧，必须经过AP转发。这与以太网（有线）中任意节点可直接通信的模式不同。

## 详细解释

### 基本概念（术语对照生活场景）

| 术语 | 英文 | 生活对应 |
|------|------|---------|
| AP（接入点） | Access Point | 无线路由器发出的Wi-Fi热点 |
| BSS（基本服务集） | Basic Service Set | 一个Wi-Fi热点 + 连接该热点的所有设备 |
| SSID（服务集标识符） | Service Set Identifier | Wi-Fi名称（不超过32字节） |
| BSA（基本服务区） | Basic Service Area | Wi-Fi信号的覆盖范围 |
| ESS（扩展服务集） | Extended Service Set | 全屋Wi-Fi（多个AP覆盖更大范围） |
| 漫游 | Roaming | 手机从一个AP自动切换到另一个AP且不中断通信 |

### 硬件架构：家用路由器 = 路由器 + 以太网交换机 + 无线AP
AP通过**门户（Portal）**与有线802.3局域网相连。门户本质上是网桥，实现802.11帧 ↔ 以太网帧的**格式转换**。

### CSMA/CA的应用
802.11无线局域网使用CSMA/CA协议进行介质访问控制，因为无线环境中无法做到"边发边听"（信号冲突无法通过电压变化检测）。CSMA/CA通过**RTS/CTS握手机制**预约信道，解决**隐藏站问题**（两个移动站都在AP覆盖范围内但彼此不在对方信号范围内，同时发送导致冲突）。

### 802.11帧的三种类型
| 类型 | 比特标识 | 例子 |
|------|---------|------|
| 管理帧 | 00 | 探测请求/响应（发现Wi-Fi） |
| 控制帧 | 01 | RTS、CTS、ACK |
| 数据帧 | 10 | 实际传输的数据 |

### 数据帧格式——口诀记忆
**"30N4手术验，首部3+1地址；90比特表去来，帧的中转靠AP；去往AP中起止，来自AP止中起"**

- **30N4**：首部30字节 + 可变数据N字节 + 校验4字节
- **3+1地址**：重点前3个地址（各6字节），第4个地址与有线局域网无关
- **90比特**：帧控制字段的第9、10比特：
  - `10` = 去往AP（移动站 → AP）
  - `01` = 来自AP（AP → 移动站）
- **地址含义切换**：
  | 状态 | 地址1 | 地址2 | 地址3 |
  |------|-------|-------|-------|
  | 去往AP(10) | AP的MAC（中） | 发送站MAC（起） | 目的站MAC（止） |
  | 来自AP(01) | 目的站MAC（止） | AP的MAC（中） | 发送站MAC（起） |

### 隐藏站问题与RTS/CTS
隐藏站问题：站A和站C都能与AP通信，但彼此不在无线信号范围内。A发送时C检测不到载波，C也发送就会在AP处冲突。

RTS/CTS解决流程：
1. A发RTS（含持续期）→ AP
2. AP广播CTS（含持续期）→ 所有站
3. C收到CTS知道信道被预约，暂停发送（即使C听不到A的RTS）
4. A发数据帧 → AP
5. AP回复ACK → A
6. 持续期满后信道释放

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| AP的帧格式转换 | AP收到802.11帧后转为以太网帧再通过有线链路传给路由器 |
| 有线vs无线链路 | AP与移动站间用无线（802.11帧）；AP间/AP与路由器/AP与交换机间用有线（以太网帧） |
| 控制帧持续期字段 | RTS、CTS、ACK帧均含持续期字段（微秒），用于信道预约时间 |

### 与以太网的区别
| 维度 | 以太网（802.3） | 无线局域网（802.11） |
|------|----------------|---------------------|
| 介质访问控制 | CSMA/CD | CSMA/CA（RTS/CTS） |
| 节点通信 | 任意节点可直接通信 | 必须通过AP中转 |
| 帧格式 | 662N4 | 30N4 + 4个地址字段 |
| 冲突检测 | 可边发边听 | 无法可靠检测冲突 |
