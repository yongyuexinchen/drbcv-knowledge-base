# RIP协议

## 类型判定
判别型 — 回答"RIP是什么、有什么基本规定、如何交换信息"的问题，核心是对RIP协议的定性描述。

## 是什么
RIP（Routing Information Protocol，路由信息协议）是一种基于**距离向量路由算法**的**内部网关协议（IGP）**，适用于小型自治系统。RIP使用**跳数（Hop Count）**作为路径度量，规定一条合法路径的最大跳数为15（16表示不可达）。RIP属于**应用层**协议，基于UDP的**520端口**传输。

## 输入-输出空间
- **输入**：邻居路由器发来的RIP响应报文（包含邻居的完整路由表）
- **输出**：本路由器的路由表（目的网络、距离、下一跳路由器三个核心字段）
- **映射关系**：映射关系 — 邻居的距离向量经过Bellman-Ford计算，映射为本地路由表

## 正例（至少2个）
1. **小型校园网**：一个学校内有3-4台路由器、4-5个网络，使用RIP协议。管理员只需启动RIP进程，路由器自动交换路由信息，无需手工配置。
2. **家庭-企业边界**：小型分支机构接入总部网络，分支机构内使用RIP。网络规模小（跳数不超过15），配置简单、维护成本低。

## 反例/边界（至少1个）
1. **RIP ≠ 适用于大型网络**：RIP规定最大跳数15，16表示不可达。如果两台主机之间需要经过20台路由器，RIP就会认为它们不可达，无法通信。大型自治系统应选用OSPF。

## 详细解释

### RIP在协议栈中的位置
- **所属层次**：应用层（但功能上属于路由协议，辅助网络层工作）
- **传输方式**：使用UDP协议，端口号**520**
- **报文类型**：Request（请求）和Response（响应/更新）

### RIP的基本规定

1. **路径长度的定义**：使用"跳数"度量。每经过一台路由器距离+1，路由器到直连网络的距离为1。好的路由就是**跳数最少**的路由。

2. **最大跳数限制**：合法距离不超过15，16表示目的网络不可达。这限定了RIP只适用于小型网络。

3. **路由表格式**：每个表项至少包含三个字段：
   - **目的网络**（用CIDR记法表示网络前缀）
   - **距离**（到达目的网络的跳数）
   - **下一跳路由器**（用IP地址标识）

4. **路由表示例**：
   | 目的网络 | 距离 | 下一跳路由器 |
   |---------|------|------------|
   | net1    | 1    | 直接交付 |
   | net2    | 16   | —（不可达） |
   | net3    | 2    | R6 |
   | net4    | 2    | R9 |

### RIP的信息交换机制

路由器之间通过三个维度（Who/What/When）交换信息：

- **Who（和谁交换）**：只和**直连的邻居**路由器交换
- **What（交换什么）**：交换自己的**完整路由表**（封装在RIP响应报文中）
- **When（何时交换）**：**每30秒**定期发送一次，另外可引入**触发更新**（拓扑变化时立即发送）

### 触发更新
- 常规更新：每30秒周期性地发
- 触发更新：一发现路由表变化就立即发，可加快收敛速度
- 类比：常规更新像闺蜜间30天交换一次八卦；触发更新像憋不住话的闺蜜，一有新消息就说

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 协议栈层次 | 应用层（使用UDP 520端口） |
| 算法基础 | 距离向量路由算法（Bellman-Ford） |
| 路径度量 | 跳数（Hop Count） |
| 最大跳数 | 15（16=不可达） |
| 更新周期 | 30秒 |
| 超时判定 | 180秒未收到邻居更新→认为邻居不可达 |
| 适用范围 | 小型自治系统 |

### 使用原则
- 只适用于小型网络（跳数≤15）
- 简单配置即可运行，适合初学者理解和部署


### 一句话：
路由协议的一种
RIP的跳数 每进过一个路由距离1
RIP认为最好的网络：跳数最少
一条合法路径不超过15，超过直接丢
RIP路由表有目的网络，距离（15以上直接丢），下一跳路由器
底层是由距离向量信息包含在路由表中，30秒共享给邻居一次路由表（RIP响应报文），路由表发生变化触发更新机制，直接同步,180秒没收到邻居RIP响应报文，则认为邻居不可达了，改16跳
好消息传的快（新路由），坏消息（某个路由挂了）传的慢，人类社会的消息变化的传递也差不多
