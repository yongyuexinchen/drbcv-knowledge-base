# 特殊IP地址

## 类型判定
判别型 — 回答"哪些IP地址是特殊的、它们各自的用途和适用场景"，需要记忆并区分各类特殊地址的规则。

## 是什么
在IPv4地址空间中，有若干种特殊用途的IP地址**不能指派给主机或路由器**使用。它们用于表示网络本身、广播地址、本地回环等特殊场景，包括：**主机号全0**（网络本身）、**主机号全1**（广播地址）、**网络号全0**（本网络上的主机）、**全0地址**（本网络本主机）、**全1地址**（本网络广播）、**127开头**（环回自检地址）。

## 输入-输出空间
- **输入**：一个IP地址及其所处网络
- **输出**：该地址所属的特殊类型及可用的源/目的角色
- **映射关系**：从属关系 — 根据模式匹配识别特殊地址类型

## 正例（至少2个）
1. **主机号全0 — 表示网络本身**：B类网络166.1.0.0中，前16位为网络号166.1，后16位全0。该地址表示"166.1.0.0整个网络"，只能用于路由表和转发表，不能作为IP分组的源地址或目的地址。
2. **主机号全1 — 广播地址**：C类网络200.1.1.0中，目的地址200.1.1.255表示向该网络内所有主机广播，只能作为目的地址使用。

## 反例/边界（至少1个）
1. **127.0.0.1不是A类地址**：虽然127在数值上紧挨A类范围，但127.x.x.x被保留作环回自检地址，不属于A类，不能分配给任何网络接口。

## 详细解释

### 特殊地址一览表

| 模式 | IP地址示例 | 含义 | 可用作源地址 | 可用作目的地址 |
|------|-----------|------|:----------:|:------------:|
| 网络号固定，主机号全0 | 166.1.0.0 | 表示某网络本身 | ✗ | ✗ |
| 网络号固定，主机号全1 | 200.1.1.255 | 某网络内的广播地址 | ✗ | ✓ |
| 网络号全0，主机号非0 | 0.0.0.1 | 本网络内某台主机 | ✓ | ✗ |
| 网络号全0，主机号全0 | 0.0.0.0 | 本网络上的本主机 | ✓ | ✗ |
| 全1 | 255.255.255.255 | 本网络广播 | ✗ | ✓ |
| 127开头 | 127.0.0.1 | 环回自检（localhost） | ✓ | ✓ |

### 各特殊地址详解
- **主机号全0**：表示某一个具体的网络，如路由表条目中的目的网络号
- **主机号全1**：定向广播，向指定网络的所有主机广播
- **网络号全0 + 主机号非0**：本网络中某台主机，典型用于DHCP过程中旧配置的源地址
- **0.0.0.0**：表示"本网络上的本主机"，DHCP新入网主机暂无IP时使用
- **255.255.255.255**：有限广播，只在本网络内广播（路由器不转发）
- **127.0.0.1**：数据报在本地环回，不会发送到网络上，用于本地软件开发和测试

### 主机数计算公式
对于一个网络，若主机号占N个比特，则该网络最多支持的主机数 = **2^N - 2**（减掉主机号全0和全1两个特殊地址）。

| 地址类 | 主机号比特 | 最大主机数 |
|------|----------|----------|
| A类 | 24 | 2^24 - 2 ≈ 1677万 |
| B类 | 16 | 2^16 - 2 = 65534 |
| C类 | 8 | 2^8 - 2 = 254 |

## 生活类比
- **全0地址（0.0.0.0）**：就像一个人刚搬进新小区还没有门牌号，只能告诉别人"我是这个新来的住户"（I am nobody），而不是"我是XX栋XX号"。
- **环回地址（127.0.0.1）**：就像给自己写信测试笔好不好使——信不会真的寄出去，写完之后自己拆开看。软件开发者用127.0.0.1测试本机客户端和服务器的通信。
