# 海明校验码

## 类型判定
连接型 — 回答"海明码如何构建/如何使用"，核心是一套完整的分组偶校验+校验位位置规则+纠错计算流程。

## 是什么
海明校验码（Hamming Code）是一种**纠错编码**技术，可以检测并定位帧内的比特错误，并自动纠正单比特错误。它基于偶校验思想进行扩展：将N个信息位分为K个分组，每个分组独立进行偶校验，产生K个校验位。这K个校验位不仅能报告"有错误"，还能通过**综合各位的校验结果**唯一确定出错位置。在海明码基础上增加一个**全校验位**后，还能区分单比特错误和双比特错误。

## 输入-输出空间
- **输入**：N位信息位（有效率据）
- **输出**：N+K位海明校验码（信息位+校验位+可选的全校验位）
- **映射关系**：映射关系 — 校验位位置固定（2ⁱ⁻¹位），具体值由所属分组的信息位通过偶校验（异或）确定

## 正例（至少2个）
1. **4位信息位求海明码**：信息位D₁D₂D₃D₄=1011。确定K=3（2³≥4+3+1），校验位P₁（放1位）、P₂（放2位）、P₃（放4位）。P₁所在分组含D₁D₂D₄（3,5,7位），异或得0；P₂分组含D₁D₃D₄（3,6,7位），异或得1；P₃分组含D₂D₃D₄（5,6,7位），异或得0。最终海明码为：P₁(0)+P₂(1)+D₁(1)+P₃(0)+D₂(0)+D₃(1)+D₄(1)=0110011。
2. **海明码纠错**：收到码字中H₂位出错（P₂从1变0），各分组偶校验结果S₁=0（分组1没问题）、S₂=1（分组2出错）、S₃=0（分组3没问题），S₃S₂S₁=010即十进制2→指明H₂位出错，直接取反即可纠正。

## 反例/边界（至少1个）
1. **双比特错误区分的需要**：如果P₁和P₂同时出错，S₃S₂S₁=011即十进制3，会误判为H₃（D₁）出错。因此实际海明码通常在最前面加一个**全校验位**——对整段码字做偶校验。当S≠0且全校验失败→单比特错误可纠正；当S≠0且全校验成功→双比特错误需重传。

## 详细解释

### 校验位数量确定
海明码的核心不等式（确定K的最小值）：
```
2ᴷ ≥ N + K + 1
```
- K个校验位有2ᴷ种状态
- 1种状态表示"正确"
- 其余N+K种状态对应N+K个位的错误位置

### 校验位位置（重要规则）
海明码规定：所有校验位Pᵢ必须放在编号为 **2ⁱ⁻¹** 的位置上（即第1、2、4、8…位）。

| 校验位 | 位置编号 | 二进制权值 |
|--------|---------|-----------|
| P₁ | H₁（2⁰） | 权重1 |
| P₂ | H₂（2¹） | 权重2 |
| P₃ | H₄（2²） | 权重4 |
| P₄ | H₈（2³） | 权重8 |

### 分组规则
每个校验位Pᵢ负责的分组：**将该位位置编号的二进制展开中、第i位为1的所有数据位**归入该组。

示例（信息位D₁~D₄，位置编号3~7）：
| 信息位 | 位置 | 二进制 | 所属分组 |
|--------|------|--------|---------|
| D₁ | H₃ | 011 | P₁组、P₂组 |
| D₂ | H₅ | 101 | P₁组、P₃组 |
| D₃ | H₆ | 110 | P₂组、P₃组 |
| D₄ | H₇ | 111 | P₁组、P₂组、P₃组 |

### 校验位计算
```
P₁ = D₁ ⊕ D₂ ⊕ D₄
P₂ = D₁ ⊕ D₃ ⊕ D₄
P₃ = D₂ ⊕ D₃ ⊕ D₄
```

### 检错纠错过程
1. 对每个分组做偶校验，得到S₁、S₂、…、Sₖ
2. 将Sₖ…S₂S₁组成二进制数（S₁是最低位）
3. 该二进制数的十进制值即**出错位置编号**
4. 将该位取反即完成纠错

### 全校验位（可选，用于区分单/双比特错误）
- 添加在码字最高位，对全体做偶校验
- S=0且全校验通过 → 无误
- S≠0且全校验失败 → 单比特错误，纠正
- S≠0且全校验通过 → 双比特错误，请求重传

## 海明码计算速查表（N≤7）
| 信息位数N | 校验位数K | 总位数 |
|----------|----------|-------|
| 1 | 2 | 3 |
| 2~4 | 3 | 5~7 |
| 5~7 | 4 | 9~11 |

## 生活类比
就像用3个天平砝码找出8个硬币中的假币——每个砝码能告诉你一个子集是否平衡。三个砝码的"平衡/不平衡"组合正好能定位1个假币的精确位置。但如果同时有两个假币，天平的组合结果可能会"撞车"——这时需要额外一个万能天平来区分情况。
