# 无分类编址 CIDR

## 类型判定
连接型 — 回答"给定CIDR地址块和子网需求，如何计算网络前缀、划分子网（定长/变长）、确定可分配IP地址数"，涉及从原始CIDR块到子网规划的完整映射推导。

## 是什么
CIDR（无分类域间路由）是1993年推出的IP地址分配方案，**取消了传统的A/B/C类地址分类**。IP地址简化为两级结构：**网络前缀**（可变长）+ **主机号**。用**斜杠记法**（如192.168.1.0/24）表示网络前缀的位数。CIDR使IP地址分配更灵活高效，一定程度上缓解了IPv4地址枯竭问题。

## 输入-输出空间
- **输入**：CIDR地址块（IP/前缀长度）、子网规划需求（子网数量或规模要求）
- **输出**：各子网的网络前缀、子网掩码、可用IP地址范围、可分配主机数
- **映射关系**：映射关系 — 从原始网络前缀逐步取出更多高位作为子网号，生成子网前缀

## 正例（至少2个）
1. **分配2000台主机的单位**：传统方案需要分配B类地址（浪费6万+地址），CIDR方案分配/21地址块（主机号11位，2^11=2048），正好覆盖2000台主机，地址利用率大幅提高。
2. **定长子网划分**：学校获得/16地址块（16位网络前缀，16位主机号），取7位作子网号→128个定长子网。每个子网主机号9位，可分配2^9-2=510个IP地址。

## 反例/边界（至少1个）
1. **变长子网划分子网号可以不同长度**：定长划分的缺陷是所有子网大小相等，导致大需求不够用、小需求浪费。变长划分允许子网大小不同，灵活匹配实际需求——如铁柱网吧需要12台主机（/28，16个地址），旺财家需要5台（/29，8个地址），狗剩家点对点链路（/30，4个地址）。

## 详细解释

### CIDR记法
```
IP地址/网络前缀位数
例如：128.14.32.0/27
→ 前27位为网络前缀，后5位为主机号
→ 该地址块包含2^5=32个IP地址
```

### 定长子网划分
- 从主机号取出K个比特作为**定长子网号**
- 划分出2^K个大小相等的子网
- 每个子网主机号 = N-K位，可用地址数 = 2^(N-K)-2

### 变长子网划分（重点/难点）
- 各子网大小可以不同，子网号长度可变
- **核心解题技巧：从根到叶构造二叉树**
  - 根节点 = 原始CIDR地址块（含H个可分配主机位）
  - 每次拆分为左右两半（对应0和1）
  - 叶子节点 = 最终子网
  - 树高不超过H-1（因为最小的子网需保留2位主机号）
  - 任何一个子网的网络前缀不能是其他子网网络前缀的前缀（类似哈夫曼编码）

### 示例：闲鱼电信的变长子网划分

原始地址块：/27（5位主机号，32个地址）

```
                /27 (32个地址)
               /       \
          /28 (16)    /28 (16)
         铁柱网吧     /       \
                 /29 (8)   /29 (8)
                 旺财家    /     \
                       /30 (4) /30 (4)
                       狗剩家  空闲
```

| 用户 | 需求 | 网络前缀 | 子网大小 | 可分配地址 |
|------|------|---------|---------|-----------|
| 铁柱网吧 | 12台 | /28 | 16 | 14 |
| 旺财家 | 5台 | /29 | 8 | 6 |
| 狗剩家 | 1台（点对点） | /30 | 4 | 2 |

### 点对点链路特殊说明
- 路由器与主机直连，需占用4个IP地址（/30子网）
- 可用地址仅2个（主机号01和10），分别分配给路由器和主机
- 主机号00（子网本身）和11（广播地址）不可用

## 生活类比
- **变长子网划分（二叉树法）**：就像家族分家产——原始地皮（CIDR地址块）由老祖宗留下。大儿子家人口多分大块（/28），二儿子家人口少分小块（/29），三儿子还没结婚先分迷你块（/30）。关键在于每一刀切下去都必须对半分（左0右1），但谁拿大块谁拿小块可以灵活安排。
- **CIDR记法**：就像是快递地址不再写"某省某市某区"（固定分类），而是直接写"几环以内"（可变前缀）——更灵活，不浪费。
