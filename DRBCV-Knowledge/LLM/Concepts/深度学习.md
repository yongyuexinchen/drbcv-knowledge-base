# 深度学习

## 类型判定
深度学习是机器学习的一个子集，使用多层（"深"）神经网络处理海量数据，自动学习高级特征，是当前 AI 大模型的核心技术。

## 类比 ★
### 一句话比喻
传统机器学习像实习生——你告诉他"圆的水果是苹果、长的是香蕉"，他才敢分类；深度学习像天才儿童——你扔给他一百万张水果照片，他自己就能悟出"圆的红的是苹果、弯的黄的是香蕉"，甚至能发现你都没说过的规律。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 传统机器学习 | 实习生需要师傅手把手教规则 |
| 深度学习 | 天才儿童自己从海量例子中悟规律 |
| 浅层网络（1-2 层） | 只看到颜色和形状 |
| 深层网络（几十上百层） | 看到纹理、品种、新鲜度等深层特征 |
| 训练数据 | 扔给天才儿童的一百万张水果照片 |

## 是什么
深度学习 = 深层神经网络 + 海量数据 + 自动特征提取。与浅层机器学习的核心区别：深度学习不需要人工设计特征（如"圆的、红的"），而是通过多层神经网络的层层抽象，自动从原始数据中提取从低级到高级的特征。第一层识别边缘，第二层识别形状，第三层识别物体……越深越抽象。ChatGPT 就是深度学习在 NLP 领域的产物。

## 正例（≥2 个）
1. 图像识别：CNN 通过几十层网络，从像素 → 边缘 → 纹理 → 部件 → 完整物体，自动学会识别猫和狗。
2. 自然语言处理：Transformer 的多层网络从字词 → 语法 → 语义 → 语境 → 意图，逐步理解人类语言。

## 反例/边界（≥1 个）
1. 决策树、支持向量机（SVM）——这些是传统机器学习算法，不是深度学习。它们的层数浅、特征靠人工设计，不是自动学出来的。
2. 单一隐藏层的神经网络——严格来说不算"深度"学习，"深度"通常指三层以上隐藏层。

## 详细解释
深度学习的三大要素：①数据——量越大越好（GPT-3 训练用了互联网几乎所有公开文本）；②算力——GPU/TPU 大规模并行计算；③算法——反向传播 + 梯度下降更新参数。深度学习并非层数越多一定越好，存在过拟合、梯度消失等问题。目前深度学习的主要架构：CNN（图像）、RNN/LSTM（序列）、Transformer（NLP 和越来越多的多模态任务）。
