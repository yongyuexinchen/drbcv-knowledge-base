# 人工智能

## 类型判定
人工智能（AI）是使计算机模拟人类智能行为的科学，包含学习、推理和自我改进三大能力。

## 类比 ★
### 一句话比喻
传统计算机程序像是严格执行菜谱的厨房机器——你给它什么指令它就做什么，绝不会多放一粒盐；人工智能像是会自己尝味道、改良菜谱的大厨——给个目标，它自己琢磨怎么做得更好。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 传统程序 | 按菜谱精准执行的炒菜机 |
| 人工智能 | 会品菜、改良菜谱的大厨 |
| 机器学习 | 大厨通过试吃不断改进手艺 |
| 深度学习 | 大厨的"味觉神经网络"越来越灵敏 |
| AGI（通用人工智能） | 大厨什么菜系都会做，还能发明新菜 |

## 是什么
人工智能是计算机科学的一个分支，目标是让机器具备类似人类的智能：学习（从数据中获取知识）、推理（基于已有知识做判断）、自我改进（根据反馈优化行为）。AI 的层级关系：人工智能（AI）⊃ 机器学习（ML）⊃ 深度学习（DL）。ChatGPT 等大语言模型是深度学习在自然语言处理（NLP）领域的产物。

## 正例（≥2 个）
1. ChatGPT：通过深度学习从海量文本中学会理解和生成人类语言，属于 NLP 领域的 AI。
2. 自动驾驶：通过 CNN（卷积神经网络）识别道路上的车辆、行人、交通标志，并做出驾驶决策。

## 反例/边界（≥1 个）
1. Excel 里的 IF 函数判断"分数>60 则及格"——这不是 AI，这只是预设规则，没有学习和自我改进能力。
2. 扫地机器人沿着固定路线清扫——如果没有传感器学习和路径优化，就不算真正的 AI。

## 详细解释
AI 的分层结构：最外层是 AI（所有智能程序），中间是机器学习（通过数据学习而非手动编程），最内层是深度学习（使用多层神经网络）。目前我们所说的"大模型"都属于深度学习范畴。AI 发展经历了符号主义（规则引擎）→ 统计学习 → 深度学习三个阶段，现在正迈向多模态和 AGI。
