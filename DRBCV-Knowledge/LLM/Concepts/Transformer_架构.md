# Transformer 架构

## 类型判定
Transformer 是当前主流大语言模型（ChatGPT 等）的底层神经网络架构，核心由编码器（Encoder）和解码器（Decoder）两部分组成。

## 类比 ★
### 一句话比喻
你给一个翻译官说一句中文，他先在脑子里把中文的意思"消化吸收"（编码），再结合你们之前的对话上下文，用英文逐词"说出来"（解码）——Transformer 就是按照这个"先理解、再生成"的逻辑工作的。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 输入文字 | 你说的中文 |
| Embedding | 翻译官将中文转为内部思维语言 |
| 编码器（Encoder） | 翻译官消化理解你这句话的深层含义 |
| 解码器（Decoder） | 翻译官结合上下文，逐词输出英文 |
| 聊天记录输入 | 翻译官回忆你们之前聊了什么 |
| 逐词预测输出 | 翻译官每说出一个词，就在想下一个词该说什么 |

## 是什么
Transformer 架构分为两大模块：①编码器——接收经过 Embedding 的输入，通过自注意力机制理解每个词在上下文中的含义；②解码器——接收编码器的理解结果 + 历史聊天记录（也经过 Embedding），逐词预测输出。模型不是一次性输出整段话，而是一个词一个词预测——输出第一个词后，用它来预测第二个词，依次类推，每个词都是当前概率最高的选择。

## 正例（≥2 个）
1. GPT 系列（GPT-3 / GPT-4 / ChatGPT）：只使用 Transformer 的解码器部分，擅长文本生成。
2. BERT：只使用 Transformer 的编码器部分，擅长文本理解和分类任务。

## 反例/边界（≥1 个）
1. CNN（卷积神经网络）处理图像、RNN（循环神经网络）处理序列——它们不是 Transformer。Transformer 相比 RNN 的核心优势是"自注意力"机制，可以同时关注整个句子中所有词的关系，而非按顺序逐个处理。
2. 不是所有 NLP 模型都用 Transformer——早期的 word2vec、LSTM 等不是 Transformer 架构，但已逐渐被取代。

## 详细解释
Transformer 的完整流程：输入文字 → Embedding 向量化 → 位置编码（标记词序） → 编码器（多层自注意力 + 前馈网络）→ 解码器（自注意力 + 编码-解码注意力 + 前馈网络）→ 线性层 + Softmax → 输出下一个词的概率分布 → 逐词输出。GPT-3 有 96 层 Transformer 解码器，每层有大量参数。"GPT" 中的 "T" 就是 Transformer。
