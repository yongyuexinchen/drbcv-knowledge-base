# AI Agent（智能体）

## 类型判定
AI Agent 是以大语言模型为核心的自主软件程序，能感知环境、做出决策、使用工具，自主完成一系列复杂任务——是通向 AGI（通用人工智能）的关键方向。

## 类比 ★
### 一句话比喻
普通 AI 像个话痨朋友——你问他"怎么订酒店"，他会给你 10 条建议；Agent 像个全能助理——你对他说"帮我订个酒店"，他就自己去搜索、比价、下单、付款，搞定后只告诉你"订好了"。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 普通 LLM 对话 | 问朋友"怎么订酒店"，得到一堆建议 |
| AI Agent | 给助理下命令"帮我订北京的酒店" |
| Agent 的决策反思 | 助理思考选哪家酒店最合适 |
| Agent 使用工具 | 助理打开携程搜索、比价 |
| Agent 执行动作 | 助理完成预订和支付 |

## 是什么
AI Agent 是一种设计用来感知环境、做出决策并且自主行动以实现特定目标的软件程序。它以 LLM 为核心大脑，具备四个关键组件：①记忆（存储历史交互和知识）；②工具使用（搜索引擎、计算器、代码解释器等）；③决策反思（分解任务、评估方案、纠错）；④行动执行（真正完成操作，不只是给建议）。

## 正例（≥2 个）
1. 用户说"帮我订一个北京的酒店"，Agent 自动拆分任务：搜索酒店列表 → 比较价格和评价 → 选择最优 → 调用支付工具完成预订。
2. 程序员说"帮我写一个登录页面并部署"，Agent 先写代码 → 运行测试 → 修复 bug → 部署到服务器，全程自主完成。

## 反例/边界（≥1 个）
1. 你问 ChatGPT"怎么订酒店"，它给出一段文字建议——这只是普通 LLM 对话，不是 Agent。Agent 的核心区别在于"执行"而非仅仅"建议"。
2. Agent 不等于 AGI——Agent 是目前通向 AGI 的中间形态，AGI 是终极目标（在所有智力任务上达到人类水平）。

## 详细解释
Agent 工作流程：接收任务 → 决策反思（拆分任务为子任务）→ 检查记忆/知识库是否有相关信息 → 若无则调用工具（搜索、计算等）→ 工具返回数据 → 继续决策 → 执行行动 → 完成。核心差异：普通 LLM 是"一问一答"，Agent 是"目标→规划→执行→反馈→调整"的闭环系统。Agent 的底层架构常用 LangChain 等框架实现。
