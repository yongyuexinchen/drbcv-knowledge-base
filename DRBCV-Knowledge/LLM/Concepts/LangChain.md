# LangChain

## 类型判定
LangChain 是连接大语言模型与外部数据/工具的工程框架——它不是一个模型或软件，而是一套让 LLM 能"查资料、用工具、做多步骤任务"的架构。

## 类比 ★
### 一句话比喻
大模型像一个百科全书式的天才——但他被关在屋里，只有脑子里的知识，看不到外面、不会用工具。LangChain 就是给他装上电话、电脑和万能钥匙——让他能联网查资料、调数据库、发邮件、订酒店。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 裸 LLM（只有自身知识） | 被关在屋里的天才 |
| LangChain | 给天才配的全套装备（电话+电脑+钥匙） |
| 链式调用（Chain） | 天才按步骤做事：先查→再分析→后执行 |
| 数据输入通道 | 天才的"眼睛"（能看文档、数据库） |
| 分析引擎 | 天才的"大脑"（分类、情感分析、主题提取） |
| 输出层 | 天才的"嘴巴"（报告、图表、交互界面） |

## 是什么
LangChain = Language + Chain（语言 + 链式处理），是一个专门用于构建 LLM 应用的工程框架。核心三步：①数据输入——支持手动输入、文件上传（PDF/Excel/Word）、数据库连接，输入前先进行数据清洗（去噪）；②数据分析——分析引擎（算法集合）进行文本分类、情感分析、主题建模；③数据输出——以图表、文字报告或交互界面的形式呈现结果。LangChain 是构建 AI 知识库和 AI Agent 的底层架构。

## 正例（≥2 个）
1. 企业内部知识库：通过 LangChain 将公司文档导入 → 分析引擎处理 → 连接 LLM，员工用自然语言提问即可获取精准答案。
2. AI Agent：LangChain 作为 Agent 的"骨架"，串联 LLM（大脑）+ 工具调用 + 记忆管理 + 多步骤任务执行。

## 反例/边界（≥1 个）
1. 直接打开 ChatGPT 问问题——这是裸用 LLM，没有用到 LangChain。LangChain 解决的是 LLM 无法访问外部数据的问题。
2. LangChain 不是数据库、不是向量数据库——它不存储数据，它是"连接器"和"编排器"，把 LLM、数据库、工具串成工作流。

## 详细解释
LangChain 的核心价值：让 LLM 能突破自身训练数据的限制，访问企业内部私有数据，从而在专业领域给出精准回答。它通过"链（Chain）"的概念将多个步骤串联：读取文档 → 文本切割 → Embedding → 存入向量库 → 用户提问 → 检索相似内容 → 拼接提示词 → LLM 回答。LangChain 支持多种 LLM（OpenAI、ChatGLM 等）和多种向量数据库，是当前最成熟的 LLM 应用开发框架。
