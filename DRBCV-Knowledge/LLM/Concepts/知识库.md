# 知识库

## 类型判定
知识库是储存和组织知识的数据库，AI 知识库与传统知识库的核心区别在于与大语言模型（LLM）的结合。

## 类比 ★
### 一句话比喻
传统知识库是尘封的档案室——你只能翻到固定的页码；AI 知识库是一个随身老专家——你问他什么，他不仅翻给你看，还嚼碎了喂到你嘴里。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 传统知识库 | 公司档案柜，只能按编号查文件原文 |
| AI 知识库 | 雇佣了一位会查档案还能讲解的新员工 |
| 向量检索 | 新员工用"感觉"找到最相关的文件段落 |
| LLM 回答 | 新员工把档案内容翻译成大白话讲给你听 |

## 是什么
知识库是储存知识和信息的数据库。传统知识库只做静态检索——用户输入关键词，返回写死的文档段落。AI 知识库则将知识文档向量化后存储，用户提问时先检索相关内容，再将检索到的内容与 LLM 拼接，由 LLM 用自然语言生成易懂的回答，支持追问和深度解释。

## 正例（≥2 个）
1. 产品维修手册导入 AI 知识库后，新维修工可以问"气缸怎么修"，AI 直接解释步骤，还能追问细节。
2. 企业内部规章制度做成 AI 知识库，员工用自然语言问"年假怎么申请"即可得到精准回答，而不需要翻阅整本员工手册。

## 反例/边界（≥1 个）
1. 传统 PDF/Word 文档存在文件夹里，靠 Ctrl+F 搜索关键词——这是传统知识库，不是 AI 知识库。AI 知识库的核心在于"检索 + LLM 生成回答"的闭环。

## 详细解释
AI 知识库的构建流程：本地文档 → 非结构化处理（提取文字） → 文本切分（切成小块） → Embedding（向量化） → 存入向量数据库。用户提问时：问题向量化 → 向量相似性检索 → 得到相关文本块 → 与提示词模板拼接 → 发送给 LLM → 生成回答。整个过程中，知识库"变活了"，不再是死文档，而是可对话的智能体。
