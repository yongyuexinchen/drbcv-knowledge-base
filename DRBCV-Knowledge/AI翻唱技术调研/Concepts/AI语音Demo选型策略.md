# AI语音Demo选型策略

## 类型判定
过程型——从约束条件到最终方案的操作流程和决策框架。

## 类比
**一句话比喻：** Demo 选型像相亲——不是找最漂亮的（Fish-Speech SOTA 但 4B 太重），也不是找最有钱的（GPT-SoVITS 60k stars 最火），而是找最合适的（CosyVoice 3 的 LLM 架构天然匹配你的 AI 伴侣方向）。

| 维度 | 生活映射 |
|------|---------|
| CosyVoice 3 技术深度 | 985 毕业 + 18 种方言加分（业界独有） |
| GPT-SoVITS 稳定度 | 老实人，社区最大最靠谱，但没那么酷 |
| RVC 视听冲击 | 颜值担当，实时变声 90ms 炸场 |
| 三方案组合 | 主攻 + 替补 + 加分项，像球队战术 |

## 是什么
面向面试 Demo 场景的 AI 语音方案选型框架。约束条件：RTX 4060 8GB + Python 基础 + 几天时间 + AI 伴侣方向。6 个候选方案中，CosyVoice 3 综合评分 9.2/10 为最佳选择（LLM 架构对齐 + 18 方言 WOW 点 + 流式 150ms），GPT-SoVITS 8.8/10 为保底（整合包最快），RVC 8.1/10 为加分项（实时变声）。

## 输入-输出空间
- **输入**：用户约束（硬件/技能/时间/方向）+ 6 个候选方案的技术参数
- **输出**：推荐方案 + 操作清单 + 面试叙事脚本 + 避坑指南
- **决策维度**：技术前沿性、硬件适配、学习曲线、WOW 效应、未来复用性

## 正例（≥2个）
1. 选 CosyVoice 3 的主要路径——2 小时环境配置 → 测试零样本 → 准备方言展示 → 写技术讲解稿
2. 选 GPT-SoVITS 的保底路径——30 分钟下载整合包 → 双击 bat → 5 秒出效果

## 反例/边界（≥1个）
- ❌ Fish-Speech S2：SOTA 音质但 4B 参数，RTX 4060 8GB 跑不动——选型不只看效果好，要看能不能跑
- ❌ so-vits-svc：2023 年已 Archive——技术调研要关注维护状态

## 详细解释
选型方法论：不追 Star 数，追技术对齐度。CosyVoice 3 的核心优势不在 Star（22k < GPT-SoVITS 60k），而在技术路线与用户未来目标的匹配——LLM 架构 ↔ AI 伴侣对话系统，流式输出 ↔ 实时交互，Apache 2.0 ↔ 商用友好。面试叙事三锚点：范式转变（训练式→零样本）、中文差异化（18 方言）、选型即产品思维。

## 操作清单
1. 2h：conda 环境 + git clone CosyVoice + 下载模型 + 跑通 WebUI
2. 30min：下载 GPT-SoVITS 整合包做保底
3. 1h：准备 3 种方言展示文本 + 录制参考音频 + 撰写技术讲解稿
