# DRBCV 数学公式规范（Grok 建卡时必读）

> 此文件仅在处理数学类 vault（微积分/线代/概率论）时注入 Grok prompt。
> 非数学 vault 不加载，节省 token。

---

## 规则 1：单反斜杠，禁止双反斜杠

Obsidian LaTeX 使用标准单反斜杠。**禁止** `\\int`、`\\frac`、`\\ln` 等双反斜杠写法。

```
❌ $\\int x^2 \\, dx = \\frac{x^3}{3} + C$
✅ $\int x^2 \, dx = \frac{x^3}{3} + C$
```

---

## 规则 2：禁止在 Markdown 表格内使用含 `|` 的 LaTeX 公式

Markdown 表格用 `|` 做列分隔符。LaTeX 中的绝对值 `|x|`、行列式 `|A|`、条件概率 `P(A|B)` 会被表格语法错误解析。

**方案 A（推荐）**：数学公式多的卡片不用表格，改用编号列表。

**方案 B**：表格内用 `\lvert...\rvert` 替代 `|...|`。

```
表格内 ❌ $\ln|x|$          →  ✅ $\ln\lvert x\rvert$
表格内 ❌ $\left|\frac{a}{b}\right|$  →  ✅ $\left\lvert\frac{a}{b}\right\rvert$
列表内 ✅ $\ln|x|$          →  可以直接用
```

---

## 规则 3：所有绝对值、行列式、范数统一用 `\lvert...\rvert`

即使不在表格内，**整张卡统一用 `\lvert...\rvert`** 可避免后续表格重排时遗漏。

```
❌ \int \frac{1}{x} dx = \ln|x| + C
✅ \int \frac{1}{x} dx = \ln\lvert x\rvert + C
```

---

## 规则 4：积分公式的完整写法

```latex
$\displaystyle\int f(x) \, dx = F(x) + C$

要点:
- \displaystyle 使积分号在行内保持正常大小（Obsidian 兼容）
- \, 在 dx 前加小间距
- 不定积分末尾必须有 +C
- 定积分用 \int_a^b
```

---

## 规则 5：验证/推导公式用小字，不喧宾夺主

每条基本公式后紧跟一行小字验证：
```
→ 验证：$(\ln\lvert x\rvert)' = \frac{1}{x}$
→ 推导：$\int \frac{\sin x}{\cos x}dx = -\int \frac{d(\cos x)}{\cos x}$
```

---

## 规则 6：分段函数的写法

```latex
$$
f(x) = \begin{cases}
x^2, & x \geq 0 \\
-x^2, & x < 0
\end{cases}
$$
```

---

## 规则 7：矩阵和行列式

```latex
$$
\begin{vmatrix}           ← 行列式用 vmatrix
a & b \\
c & d
\end{vmatrix}
$$

$$
\begin{bmatrix}           ← 矩阵用 bmatrix
a & b \\
c & d
\end{bmatrix}
$$
```

## 规则 8：常见易错对照

| 错误 | 正确 | 原因 |
|------|------|------|
| `\\int` | `\int` | 单反斜杠 |
| `\\frac` | `\frac` | 同上 |
| `\\ln` | `\ln` | 同上 |
| `\\lvert` | `\lvert` | 同上 |
| 表格内 `\|x\|` | `\lvert x\rvert` | pipe 冲突 |
| `dx` | `\,dx` | 加间距 |
| 漏 `+C` | `+ C` | 不定积分必须 |
| `\displaystyle` 漏 | 加 `\displaystyle` | 积分号大小正常 |
