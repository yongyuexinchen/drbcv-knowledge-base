# 矩阵的公式（转置/逆/伴随/行列式 — 六组公式统一记忆）

## 类型判定
定理型 — 利用"操作顺序可交换""整体操作要对调""重复操作会还原"等口诀，将转置、逆、伴随、行列式四类运算的所有公式串联记忆。

## 是什么

矩阵运算的四类核心操作及其公式体系：

- **转置**（$A^{\mathrm{T}}$）
- **逆**（$A^{-1}$）
- **伴随**（$A^*$）
- **行列式**（$\lvert A \rvert$）

六组公式覆盖了这四类操作之间的全部交互规则。

## 正例（≥2 个）

1. **第二组：整体操作要对调**
   $$
   (AB)^{-1} = B^{-1}A^{-1},\quad
   (AB)^{\mathrm{T}} = B^{\mathrm{T}}A^{\mathrm{T}},\quad
   (AB)^* = B^*A^*
   $$
   三个公式同一规律：对乘积整体操作 → 因子顺序反转。

2. **第一组：操作顺序可交换**
   $$
   (A^{-1})^* = (A^*)^{-1},\quad
   (A^{\mathrm{T}})^* = (A^*)^{\mathrm{T}},\quad
   (A^{-1})^{\mathrm{T}} = (A^{\mathrm{T}})^{-1}
   $$
   **转置、逆、伴随这三种操作两两之间的先后顺序可以互换——结果相同。**

3. **第六组：伴随 = 行列式 × 逆**
   $$
   A^* = \lvert A \rvert \cdot A^{-1}
   $$
   这是推导伴随矩阵所有公式的"万能钥匙"。

## 反例/边界（≥1 个）

1. **转置的优良性质是独有的**：
   - $(\;A + B\;)^{\mathrm{T}} = A^{\mathrm{T}} + B^{\mathrm{T}}$ ✅
   - $(\;A + B\;)^{-1} \neq A^{-1} + B^{-1}$ ❌
   - $(\;A + B\;)^* \neq A^* + B^*$ ❌
   只有转置对加法有分配律！

2. **伴随的伴随 ≠ 原矩阵**：
   - $(A^{\mathrm{T}})^{\mathrm{T}} = A$ ✅
   - $(A^{-1})^{-1} = A$ ✅
   - $(A^*)^* \neq A$ ❌（而是 $= \lvert A \rvert^{n-2} A$）

3. **$(kA)^*$ 的阶数陷阱**：
   $(kA)^* = k^{n-1} A^*$（不是 $k^n$，因为 $A^*$ 每个元素是 $n-1$ 阶行列式）。

4. **$\lvert A^* \rvert$ 公式**：
   $\lvert A^* \rvert = \lvert A \rvert^{n-1}$（不是 $\lvert A \rvert^n$）。

## 详细解释

### 六组公式速记表

**第一组：操作顺序可交换**

| 公式 | 含义 |
|------|------|
| $(A^{-1})^* = (A^*)^{-1}$ | 先取逆再伴随 = 先伴随再取逆 |
| $(A^{\mathrm{T}})^* = (A^*)^{\mathrm{T}}$ | 先转置再伴随 = 先伴随再转置 |
| $(A^{-1})^{\mathrm{T}} = (A^{\mathrm{T}})^{-1}$ | 先取逆再转置 = 先转置再取逆 |

**第二组：整体操作要对调**

$$(AB)^{-1} = B^{-1}A^{-1},\quad (AB)^{\mathrm{T}} = B^{\mathrm{T}}A^{\mathrm{T}},\quad (AB)^* = B^*A^*$$

三式统一规律：因子顺序反转。

**第三组：重复操作会还原**

| 操作 | 结果 |
|------|------|
| $(A^{\mathrm{T}})^{\mathrm{T}}$ | $= A$ |
| $(A^{-1})^{-1}$ | $= A$ |
| $(A^*)^*$ | $= \lvert A \rvert^{n-2} A$（⚠️ 不还原！） |

**第四组：转置的独有性质**

| 公式 | 说明 |
|------|------|
| $\lvert A^{\mathrm{T}} \rvert = \lvert A \rvert$ | 转置不改变行列式 |
| $(\;A + B\;)^{\mathrm{T}} = A^{\mathrm{T}} + B^{\mathrm{T}}$ | 只有转置对加法有分配律 |

**第五组：逆与行列式**

| 公式 | 推导 |
|------|------|
| $\lvert A^{-1} \rvert = \frac{1}{\lvert A \rvert}$ | 对 $AA^{-1} = I$ 两边取行列式 |
| $A^{-1} = \frac{1}{\lvert A \rvert} A^*$ | 逆的伴随矩阵求法 |

**第六组：伴随万能公式**

核心：$A^* = \lvert A \rvert \cdot A^{-1}$（"伴随 = 行列式 × 逆"）

衍生推导：

- $(kA)^* = \lvert kA \rvert (kA)^{-1} = k^n\lvert A \rvert \cdot \frac{1}{k}A^{-1} = k^{n-1} \lvert A \rvert A^{-1} = k^{n-1} A^*$
- $\lvert A^* \rvert = \lvert \lvert A \rvert A^{-1} \rvert = \lvert A \rvert^n \cdot \frac{1}{\lvert A \rvert} = \lvert A \rvert^{n-1}$
- $(A^*)^* = \lvert A^* \rvert (A^*)^{-1} = \lvert A \rvert^{n-1} \cdot \frac{1}{\lvert A \rvert} A = \lvert A \rvert^{n-2} A$

### 速记法总结

| 口诀 | 覆盖范围 |
|------|---------|
| **操作顺序可交换** | 第一组：转置/逆/伴随两两交换 |
| **整体操作要对调** | 第二组：乘积取操作 → 因子反转 |
| **重复操作会还原** | 第三组：两次转置或两次逆 = 自身（伴随例外！） |
| **伴随等于行列式乘逆** | 第六组：全部伴随公式的钥匙 |
| **只有转置爱加法** | 第四组：$(A+B)^{\mathrm{T}} = A^{\mathrm{T}} + B^{\mathrm{T}}$ 是独有性质 |

## 类比 ★ 必须

### 一句话比喻
**这六组公式就像手机上的四种操作——转置 = 横屏竖屏切换（内容不变，视角变），逆 = 撤回键（做了能撤销），伴随 = 逆的半成品（差一个系数），行列式 = 一个压缩评分。第一组说"先横屏再撤回"和"先撤回再横屏"结果一样（操作顺序可交换）；第二组说"拍两张照片再撤回"等于"先撤回第二张再撤回第一张"（整体操作要对调）；第六组的"伴随 = 行列式 × 逆"就像是说"半成品 = 成品评分 × 成品"——知道评分和成品，半成品自动出来。**

### 生活映射

| 概念世界 | 现实世界 |
|---------|---------|
| 转置 $A^{\mathrm{T}}$ | 把表格横过来看——数据没变，行列互换了 |
| 逆 $A^{-1}$ | Ctrl+Z 撤销——乘法意义上回到原位 |
| 伴随 $A^*$ | 逆矩阵的"预制件"——差一个 $\lvert A \rvert$ 就能组装成逆 |
| 行列式 $\lvert A \rvert$ | 方阵的"综合评分"——一个数字总结全部 |
| $(AB)^{-1} = B^{-1}A^{-1}$ | 穿鞋袜——先穿袜子再穿鞋 → 脱的时候先脱鞋再脱袜子 |
| 操作顺序可交换 | 洗澡时先洗头再洗身体 vs 先洗身体再洗头——最后都是洗干净 |
| $(A+B)^{\mathrm{T}} = A^{\mathrm{T}}+B^{\mathrm{T}}$ | 两笔账分别转置再相加 = 先加起来再转置——转置对加法"随和" |
| $(A+B)^{-1} \neq A^{-1}+B^{-1}$ | $\frac{1}{2+3} \neq \frac{1}{2} + \frac{1}{3}$——逆对加法"不随和" |
