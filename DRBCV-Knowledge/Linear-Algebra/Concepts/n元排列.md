# n 元排列（全排列）

## 类型判定
判别型 — n 元排列是理解行列式定义的前置概念，核心是逆序数的**奇偶性**（而非大小），因为它直接决定了行列式展开式中每一项的正负号。

## 是什么

把 $1,2,\ldots,n$ 这 $n$ 个数**不重不漏**地按一定顺序排成一行，称为一个 **n 元排列**。

- 总共有 $n!$ 个不同的 n 元排列，它们的集合记为 $S_n$
- 例如 $S_3 = \{123, 132, 213, 231, 312, 321\}$

**逆序**：在一个排列中，如果一个大数排在一个小数的**前面**，则这两个数构成一个逆序。

**逆序数 $\tau$**：排列中逆序的总个数。$\tau(123)=0$，$\tau(321)=3$。

## 输入-输出空间
- **输入**：一个 n 元排列 $p_1p_2\ldots p_n$
- **输出**：逆序数 $\tau(p_1p_2\ldots p_n)$，以及奇偶性

## 正例（≥2 个）

1. **$\tau(1423)=3$**：用依次连线法——
   - $1$：后面全比它大 → 0
   - $4$：后面 $2,3$ 比它小 → 42, 43 → 2 个逆序
   - $2$：后面 $3$ 比它大 → 0
   - $3$：最后 → 0
   - 总逆序数 $=0+2+0+0=3$ → 奇排列

2. **$\tau(35214)=5$**：
   - $3$：$32 + 31 = 2$
   - $5$：$52 + 51 + 54 = 3$
   - $2$：$21 = 1$
   - 总 $=2+3+1=5$ → 奇排列

3. **$\tau(n, n-1, \ldots, 2, 1) = \frac{n(n-1)}{2}$**（完全逆序排列）：
   - $n$ 后面有 $n-1$ 个比它小
   - $n-1$ 后面有 $n-2$ 个
   - ……
   - $2$ 后面有 $1$ 个
   - 总和 $=(n-1)+(n-2)+\cdots+1= \frac{n(n-1)}{2}$

## 反例/边界（≥1 个）

1. **顺序排列的逆序数恒为 0**：$\tau(123\ldots n)=0$，因为每个数后面都比它大 → 偶排列（标准排列）

2. **我们只关心奇偶性，不关心大小**：$\tau=1$ 和 $\tau=999$ 在我们眼中是一样的——都是奇排列。行列式只看正负，不看数值。这跟「$(-1)^1$ 和 $(-1)^{999}$ 都是 $-1$」一个道理。

## 详细解释

### 逆序数求法：依次连线法

**规则**：从第一个位置开始，依次看当前位置的数后面有**几个比它小的**，每个画一条连线，最后数总共有多少条线。

**优点**：
- 不回头看（不用重复比较）
- 不遗漏（每个逆序只在第一个数出现时被计入一次）
- 适合 5-6 个数的排列（考试不会出太长）

```
3 5 2 1 4
↓ ↓ ↓ ↓ ↓
2+3+1+0+0 = 6
```

### 对换定理（核心）

> **在一个排列中，交换任意两个数的位置，逆序数的奇偶性一定改变。**

证明步骤：
1. 先证**相邻对换**：交换相邻两数 $A,B$ → 只改变 $A,B$ 间的关系（顺序变逆序 +1，或逆序变顺序 -1），其余数的相对顺序全不变 → 逆序数 ±1 → 奇偶性翻转
2. 再推广到**任意对换**：交换 $A$ 和 $B$（中间隔 $k$ 个数）→ 用 $2k+1$ 次相邻对换等效完成 — $A$ 向右移 $k+1$ 步，$B$ 向左移 $k$ 步 → 共 $2k+1$ 次（奇数）→ 奇偶性翻转

**推论**：奇排列经过一次对换变偶排列，偶排列变奇排列。这意味着 $S_n$ 中奇排列和偶排列各占一半（各 $\frac{n!}{2}$ 个）。

### 为什么学这个？

n 元排列的奇偶性直接决定了行列式展开式每项的符号：

$$D = \sum_{(p_1p_2\ldots p_n) \in S_n} (-1)^{\tau(p_1p_2\ldots p_n)} a_{1p_1}a_{2p_2}\ldots a_{np_n}$$

每一项前面的 $(-1)^\tau$ —— 排列是偶排列 = 正号，奇排列 = 负号。**我们不在意 $\tau$ 多大，只在意它是奇数还是偶数。**

## 类比

### 一句话比喻
**n 元排列就像全班同学排队照相——n 个人站一排，有 $n!$ 种站法。逆序就是「高个子站矮个子前面」——每出现一次就是一次逆序。逆序数是奇数还是偶数，决定了这张照片在行列式里是正片还是负片。**

### 生活映射
| 线代世界 | 现实世界 |
|---|---|
| n 元排列 | n 个人按顺序站一排 |
| 逆序 | 高个子站在矮个子前面 |
| 逆序数 $\tau$ | 总共有几对「高前矮后」 |
| 奇排列 / 偶排列 | 逆序总数是奇数还是偶数 |
| 对换 | 让两个人交换位置 |
| 对换改变奇偶性 | 只要换一次位置，「高前矮后」的总对数就从奇数变偶数（或反过来）|
| 相邻对换 | 相邻两个人换位 → 逆序数 ±1 |
| 任意对换 = 奇数个相邻对换 | 隔 10 个人换位 = 跨 10 步，步数必为奇数 |
| $\tau(n,n-1,\ldots,1)=\frac{n(n-1)}{2}$ | 完全倒着站：所有人都比后面的人高 |
| 奇偶各占一半（$\frac{n!}{2}$） | 全班站队，刚好一半人逆序数为奇数，一半为偶数 |
