# 二次型与标准形

## 是什么

**二次型**是含 $n$ 个变量、不含常数项、**每一项变量次数和均为2**的齐次多项式。用矩阵可以简洁地表示为：

$$f(x_1, x_2, \ldots, x_n) = x^T A x$$

其中 $A$ 是**对称矩阵**，且与二次型一一对应。

**标准形**：只含平方项、不含交叉项（如 $x_1 x_2$）的二次型：

$$f = k_1 y_1^2 + k_2 y_2^2 + \cdots + k_n y_n^2$$

**规范形**：特殊的标准形，平方项系数只能是 $1, -1, 0$。

> 一句话：二次型就是"多元二次函数"，标准形就是把它化简到只剩纯平方项，方便一眼看出正负。

## 正例

- **例1**（写二次型的矩阵）：
  $$f = x_1^2 - 4x_1x_2 + x_2^2 + x_2x_3 - 3x_3^2$$
  对应的对称矩阵：
  $$A = \begin{bmatrix} 1 & -2 & 0 \\ -2 & 1 & \frac{1}{2} \\ 0 & \frac{1}{2} & -3 \end{bmatrix}$$

  规则：
  - 平方项系数 → 主对角线（$a_{ii}$ = $x_i^2$ 的系数）
  - 交叉项系数 → **对半劈**到对称位置（$a_{ij} = a_{ji}$ = 交叉项系数的一半）

- **例2**（标准形）：$f = 2y_1^2 + 3y_2^2 - 5y_3^2$，矩阵为 $\begin{bmatrix}2 & 0 & 0 \\ 0 & 3 & 0 \\ 0 & 0 & -5\end{bmatrix}$

- **例3**（规范形）：$f = z_1^2 - z_2^2$，矩阵为 $\begin{bmatrix}1 & 0 \\ 0 & -1\end{bmatrix}$

## 反例/边界

- **不是二次型**：$f = x_1^2 + 3x_1x_2 + 5$ — 有**常数项** $5$，不是齐次多项式
- **不是二次型**：$f = x_1^3 + x_2^2$ — $x_1^3$ 次数为 3，不满足"次数和均为2"
- **不可逆的线性变换**：若变换矩阵 $C$ 不可逆（如 $C$ 有全零行），则二次型退化为更低维 → 信息损失，无用
- 标准形**不唯一**（系数依赖于所用的变换方法），但**规范形唯一**
- 坐标变换必须是**可逆线性变换**（$X = CY$，且 $\lvert C \rvert \neq 0$）

## 详细解释

### 二次型 → 矩阵的写法（画表格法）

```
        X₁   X₂   X₃
      ┌─────────────┐
  X₁  │ a₁₁  a₁₂  a₁₃ │  ← 平方项系数→对角线，交叉项系数→对半劈
  X₂  │ a₂₁  a₂₂  a₂₃ │
  X₃  │ a₃₁  a₃₂  a₃₃ │
      └─────────────┘
```

- 找 $x_i^2$ → 系数放 $a_{ii}$（主对角线）
- 找 $x_i x_j$（$i \neq j$）→ 系数除以2，放 $a_{ij}$ 和 $a_{ji}$ 两个位置

### 合同变换

若 $X = CY$（$C$ 可逆），则：

$$f = X^T A X = (CY)^T A (CY) = Y^T (C^T A C) Y$$

令 $B = C^T A C$，称 $A$ 与 $B$ **合同**。

> 合同 = 二次型经过**可逆线性变换**后，新旧矩阵的关系。

### 合同对角化

由对称矩阵的正交对角化可知：存在正交矩阵 $Q$ 使 $Q^T A Q = \Lambda$（对角矩阵）。

在二次型语境中：令 $X = QY$（**正交变换**），则：

$$f = X^T A X = Y^T \Lambda Y = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2$$

这就化成了**标准形**（系数就是特征值）。

### 惯性定理（可逆变换的不变量）

二次型经过**任意可逆线性变换**，正负惯性指数不变：

- **正惯性指数 $p$**：标准形中正平方项的个数 = 正特征值个数 = 规范形中 $+1$ 的个数
- **负惯性指数 $q$**：标准形中负平方项的个数 = 负特征值个数 = 规范形中 $-1$ 的个数
- **秩 $r = p + q$**：二次型的秩 = 矩阵 $A$ 的秩

> $\Updownarrow$ 不同方法化出的标准形系数可能不同，但**正号个数、负号个数、零号个数永远不变**。

### 正交变换 vs 一般可逆变换

| | 正交变换 ($X = QY$) | 一般可逆变换 ($X = PY$) |
|---|---|---|
| 矩阵要求 | $Q$ 正交 ($Q^T = Q^{-1}$) | $P$ 可逆即可 |
| 标准形系数 | 特征值 | 与特征值同正负，数值不同 |
| 效果 | 保距（不改变图形形状，只是旋转） | 可拉伸变形 |
| 能否化规范形 | ❌ 只能到特征值 | ✅ 可调系数到 $\pm 1, 0$ |

## 类比 ★ 必须

### 一句话比喻

二次型 $x^T A x$ 是**一碗高维的"变形鸡汤"**：每个点 $(x_1, \ldots, x_n)$ 都有一个"高度" $f$，矩阵 $A$ 决定了这碗汤的弯曲方式。标准形就是把汤碗**转正**，让它的弯曲只沿坐标轴方向，不再有歪斜的交叉纹路。规范形则是**标准化**到只有"上凸"($+1$)、"下凹"($-1$)、"平坦"($0$) 三种口味。

### 生活映射

| 概念世界 | 现实世界 |
|---------|---------|
| 二次型 $f = x^T A x$ | 高维的抛物面/鞍面/碗形曲面 |
| 对称矩阵 $A$ | 碗的"弯曲配方"——决定了哪里向上凸、哪里向下凹 |
| 标准形 $k_1 y_1^2 + \cdots$ | 把碗**摆正**到坐标轴上，弯曲变得纯净 |
| 规范形 $\pm y_1^2 \pm \cdots$ | 碗的"口味标签"——$+1$ 是甜（向上）, $-1$ 是酸（向下）, $0$ 是无味（平坦） |
| 正惯性指数 $p$ | 碗有 $p$ 个方向是"甜"（向上开口） |
| 负惯性指数 $q$ | 碗有 $q$ 个方向是"酸"（向下开口） |
| 合同 $B = C^T A C$ | 同一个碗，换个角度看——形状的本质（正负惯性指数）不变 |
