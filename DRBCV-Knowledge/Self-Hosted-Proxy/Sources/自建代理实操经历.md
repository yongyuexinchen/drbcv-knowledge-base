# 自建代理实操经历

## 来源
2026-07-24 至 2026-07-27，搭建自建 VPS 代理的完整实操经历。

## 涉及概念
- Cloudflare Tunnel 反向隧道
- Layer 4 vs Layer 7 代理
- cloudflared 仪表盘模式限制
- 代理协议透传兼容性 (VLESS vs Shadowsocks)
- Hysteria2 (QUIC/UDP)
- Shadowsocks (无握手加密流)
- DNS 污染
- ISP IP 封锁
- WebSocket 传输
- 反向代理架构

## 最终架构
- 笔记本/手机: Hysteria2 直连 VPS IP (UDP 443, 低延迟)
- 任意设备: Shadowsocks+WebSocket 通过 Cloudflare Tunnel (绕过 ISP 封锁)
- 浏览器 SSH: ttyd + Cloudflare Tunnel + Access 认证
