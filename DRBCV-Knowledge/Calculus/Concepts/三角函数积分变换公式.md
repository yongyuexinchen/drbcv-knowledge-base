# 三角函数积分变换公式

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
五个重要公式：
(1) $\int_0^{\pi/2} f(\sin x) \, dx = \int_0^{\pi/2} f(\cos x) \, dx$（区间再现）
(2) $\int_0^{\pi} f(\sin x) \, dx = 2\int_0^{\pi/2} f(\sin x) \, dx$
(3) $\int_0^{\pi} x f(\sin x) \, dx = \frac{\pi}{2} \int_0^{\pi} f(\sin x) \, dx$
(4) 华里士公式（点火公式）：$\int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx$，正偶数 $n$ 时为 $\frac{(n-1)!!}{n!!}\cdot\frac{\pi}{2}$，正奇数 $n$ 时为 $\frac{(n-1)!!}{n!!}$
(5) $\int_0^{2\pi} \sin^n x \, dx = \begin{cases} 0 & n\text{为奇} \\ 4\int_0^{\pi/2} \sin^n x\,dx & n\text{为偶} \end{cases}$

## 输入-输出空间
- **输入**: 含三角函数的定积分
- **输出**: 简化后的积分值
- **映射关系**: 区间变换+对称性化简

## 正例（至少2个）
1. **场景1**: $\int_0^{\pi} x\sin^4 x \, dx = \frac{\pi}{2}\int_0^{\pi}\sin^4 x\,dx = \frac{\pi}{2}\cdot 2\int_0^{\pi/2}\sin^4 x\,dx = \pi\cdot\frac{3\pi}{16} = \frac{3\pi^2}{16}$
2. **场景2**: $\int_0^{\pi/2}\sin^4 x\cos^2 x\,dx$ 用华里士公式

## 反例/边界（至少1个）
1. **常见误解/边界**: 公式(3)只适用于 $\int_0^{\pi}xf(\sin x)\,dx$，不能用于 $\int_0^{\pi}xf(\cos x)\,dx$（因为 $\cos x$ 在 $[0,\pi]$ 上有正有负，不能简单地看成 $f(\sin x)$）。只有 $\cos$ 的偶次幂才能化成 $f(\sin x)$ 形式。

## 详细解释
公式(3)的证明：区间再现 $x \to \pi-x$ 得 $I = \int_0^{\pi}(\pi-x)f(\sin x)\,dx$，与原式相加得 $2I = \pi\int_0^{\pi}f(\sin x)\,dx$。

### 推导过程（★ 数学卡必须）
**公式(1)的证明**：
$$\int_0^{\pi/2}f(\sin x)\,dx \xrightarrow{x\to\frac{\pi}{2}-x} \int_0^{\pi/2}f(\sin(\frac{\pi}{2}-x))\,dx = \int_0^{\pi/2}f(\cos x)\,dx$$

**公式(3)的证明**：
设 $I=\int_0^{\pi}xf(\sin x)\,dx$。区间再现令 $x\to\pi-x$：
$$I = \int_0^{\pi}(\pi-x)f(\sin(\pi-x))\,dx = \int_0^{\pi}(\pi-x)f(\sin x)\,dx$$

与原式相加：
$$2I = \pi\int_0^{\pi}f(\sin x)\,dx \Rightarrow I = \frac{\pi}{2}\int_0^{\pi}f(\sin x)\,dx$$

**华里士（点火公式）的记忆法**：
从次数倒数到1，"发射成功"乘 $\frac{\pi}{2}$；倒数到0，"发射失败"不乘 $\frac{\pi}{2}$。
例：$\sin^4 x$ → 倒数 $4,3,2,1$ → 发射成功 → $\frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2}=\frac{3\pi}{16}$

### 重要推论（★ 数学卡必须）
1. 公式(1)：$[0,\pi/2]$ 上 $\sin$ 和 $\cos$ 可互换（图形对称性）
2. 公式(2)：$[0,\pi]$ 上 $f(\sin x)$ 的积分 = $2\times[0,\pi/2]$ 上的积分
3. 公式(3)：$[0,\pi]$ 上 $x\cdot f(\sin x)$ 的积分 = $\frac{\pi}{2}\times f(\sin x)$ 的积分（$x$ 被"提出"变成 $\frac{\pi}{2}$）
4. 华里士公式只适用于 $[0,\pi/2]$ 上 $\sin^n x$ 或 $\cos^n x$ 的积分
5. 公式(5)：完整周期上 $\sin$ 的奇次幂积分为0

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int_0^{\pi}x\sin^4 x\,dx$
**解**：用公式(3)：
$$\int_0^{\pi}x\sin^4 x\,dx = \frac{\pi}{2}\int_0^{\pi}\sin^4 x\,dx = \frac{\pi}{2}\cdot 2\int_0^{\pi/2}\sin^4 x\,dx$$

华里士：$\sin^4 x$ 从4倒数 4,3,2,1 发射成功：
$$\int_0^{\pi/2}\sin^4 x\,dx = \frac{3!!}{4!!}\cdot\frac{\pi}{2} = \frac{3\cdot 1}{4\cdot 2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$$

$$\Rightarrow \pi\cdot\frac{3\pi}{16} = \frac{3\pi^2}{16}$$

**例题2**
**题目**：求 $\int_0^{\pi}\frac{x\sin x}{1+\cos^2 x}\,dx$
**解**：用公式(3)（$f(\sin x)=\frac{\sin x}{1+\cos^2 x}=\frac{\sin x}{2-\sin^2 x}$）：
$$\int_0^{\pi}\frac{x\sin x}{1+\cos^2 x}\,dx = \frac{\pi}{2}\int_0^{\pi}\frac{\sin x}{1+\cos^2 x}\,dx$$

后者用凑微分：$\sin x\,dx=-d\cos x$：
$$\int_0^{\pi}\frac{\sin x}{1+\cos^2 x}\,dx = -\int_1^{-1}\frac{d\cos x}{1+\cos^2 x} = \int_{-1}^{1}\frac{du}{1+u^2} = 2\arctan 1 = \frac{\pi}{2}$$

$$\Rightarrow \frac{\pi}{2}\cdot\frac{\pi}{2} = \frac{\pi^2}{4}$$

## 类比

### 一句话比喻
三角函数积分变换公式就像"舞台换位"—— $\sin$ 和 $\cos$ 在 $[0,\pi/2]$ 上可以互换角色，$x$ 在 $[0,\pi]$ 上可以被"提出"变成 $\frac{\pi}{2}$。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $\sin/\cos$互换 | 两个演员互换角色 |
| $x$提出变$\frac{\pi}{2}$ | 主角退场换成固定道具 |
| 华里士公式 | 标准化台词模板 |
| $[0,\pi/2]$ | 最佳舞台区间 |
