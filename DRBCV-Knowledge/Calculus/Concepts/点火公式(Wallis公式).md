# 点火公式（Wallis公式）

## 类型判定
**连接型** — 输入正整数 n，输出 $\int_0^{\pi/2} \sin^n x\,dx$ 的精确值

## 是什么
计算以下两类定积分的递推公式：

$$I_n = \int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx$$

- 当 n 为**正偶数**时：$I_n = \frac{(n-1)!!}{n!!} \cdot \frac{\pi}{2}$（"发射成功"）
- 当 n 为**正奇数**时：$I_n = \frac{(n-1)!!}{n!!}$（"发射失败"）

其中 $n!!$ 表示双阶乘：偶数时 $n!! = n(n-2)(n-4)\cdots 2$，奇数时 $n!! = n(n-2)(n-4)\cdots 1$。

## 输入-输出空间
- **输入**: 正整数 n + 区间 $[0, \pi/2]$
- **输出**: 定积分的精确数值
- **映射关系**: n 的奇偶性 → 是否乘 $\frac{\pi}{2}$

## 正例
1. **偶数，发射成功**: 
   $$\int_0^{\pi/2} \sin^4 x\,dx = \frac{3\cdot1}{4\cdot2}\cdot\frac{\pi}{2} = \frac{3\pi}{16}$$
   倒数：4 → 3 → 2 → 1，数到 1 点火了，乘 $\pi/2$。

2. **奇数，发射失败**: 
   $$\int_0^{\pi/2} \cos^5 x\,dx = \frac{4\cdot2}{5\cdot3\cdot1} = \frac{8}{15}$$
   倒数：5 → 4 → 3 → 2，数不到 1，不乘 $\pi/2$。

3. **高次偶数**: 
   $$\int_0^{\pi/2} \sin^6 x\,dx = \frac{5\cdot3\cdot1}{6\cdot4\cdot2}\cdot\frac{\pi}{2} = \frac{5\pi}{32}$$

## 反例/边界
1. **常见误解**: 点火公式只能用于 $[0, \pi/2]$。其他区间要先利用周期/对称性转化
2. **边界**: $\sin^n x$ 与 $\cos^m x$ 混合出现时，通常要先化为同一种三角函数再用公式

## 详细解释

### 推导过程
设 $I_n = \int_0^{\pi/2} \sin^n x\,dx$。

**第一步**：由区间再现公式知
$$I_n = \int_0^{\pi/2} \cos^n x\,dx$$
（在 $[0, \pi/2]$ 上把 x 换成 $\frac{\pi}{2}-x$）

**第二步**：对 $I_n$ 使用分部积分法
$$I_n = \int_0^{\pi/2} \sin^{n-1} x \cdot \sin x\,dx$$
令 $u = \sin^{n-1} x$，$dv = \sin x\,dx$，则 $du = (n-1)\sin^{n-2}x\cos x\,dx$，$v = -\cos x$。

$$I_n = \left[-\sin^{n-1}x\cos x\right]_0^{\pi/2} + (n-1)\int_0^{\pi/2} \sin^{n-2}x\cos^2x\,dx$$

边界项为 0，且 $\cos^2x = 1 - \sin^2x$：

$$I_n = (n-1)\int_0^{\pi/2} \sin^{n-2}x\,dx - (n-1)\int_0^{\pi/2} \sin^n x\,dx$$

即：

$$I_n = (n-1)I_{n-2} - (n-1)I_n$$

移项得递推公式：

$$I_n = \frac{n-1}{n} I_{n-2}$$

**第三步**：反复递推
- 若 n 为偶数，递推到底为 $I_0 = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$
- 若 n 为奇数，递推到底为 $I_1 = \int_0^{\pi/2} \sin x\,dx = 1$

由此得到点火公式的最终形式。

### "点火"口诀
从 n 开始倒数：
- 偶数：n → n-1 → ... → 2 → 1，数到 1 就"点火"发射成功，最后乘 $\pi/2$
- 奇数：n → n-1 → ... → 3 → 2，数不到 1 就"发射失败"，不乘 $\pi/2$

## 经典例题

**例题1** 求 $\int_0^{\pi/2} \sin^3 x\,dx$

解：n=3 为奇数，发射失败：
$$\int_0^{\pi/2} \sin^3 x\,dx = \frac{2}{3}\cdot 1 = \frac{2}{3}$$

---

**例题2** 求 $\int_0^{\pi/2} \sin^2 x\,dx$

解：n=2 为偶数，发射成功：
$$\int_0^{\pi/2} \sin^2 x\,dx = \frac{1}{2}\cdot\frac{\pi}{2} = \frac{\pi}{4}$$

（验证：用降幂公式 $\sin^2x = \frac{1-\cos2x}{2}$ 也得 $\pi/4$）

## 类比

### 一句话比喻
**点火公式像俄罗斯套娃**：每往下一步（递推一次），幂次减 2；偶数套到最后一个娃娃是 $\pi/2$，奇数套到最后一个娃娃是 1。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $I_n = \int \sin^n x\,dx$ | n 层衰减振动的总能量 |
| 递推 $I_n = \frac{n-1}{n}I_{n-2}$ | 每多一层，能量按 $\frac{n-1}{n}$ 衰减 |
| $\pi/2$ 或 1 的终止项 | 最内层"核心"的能量 |
