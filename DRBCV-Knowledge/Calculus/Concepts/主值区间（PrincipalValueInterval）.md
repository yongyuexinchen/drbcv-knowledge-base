# 主值区间（Principal Value Interval）

## 类型判定
判别型 — 区分/定义概念，建立判断标准

## 是什么
为了使三角函数在其整个定义域上有反函数，人为限定一个单调区间，称为主值区间。只有在主值区间上，三角函数与反三角函数才满足 $f^{-1}(f(X)) = X$。

## 输入-输出空间
- **输入**: 三角函数的某个单调区间
- **输出**: 该区间为主值区间时的反函数
- **映射关系**: 限制定义域 → 使函数成为一一映射 → 反函数存在

## 正例（至少2个）
1. **场景1**: $\sin x$ 在 $x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ 上单调递增且值域为 $[-1,1]$，此为主值区间。在此区间外，如 $x = \frac{5\pi}{6}$，有 $\arcsin(\sin \frac{5\pi}{6}) = \arcsin(\frac{1}{2}) = \frac{\pi}{6} \neq \frac{5\pi}{6}$。
2. **场景2**: $\arctan 1 = \frac{\pi}{4}$（主值），但 $\tan(\frac{5\pi}{4}) = 1$ 也成立，而 $\arctan 1$ 只能返回 $\frac{\pi}{4}$，因为 $\frac{5\pi}{4} \notin (-\frac{\pi}{2}, \frac{\pi}{2})$。主值区间确保了反函数的唯一性。

## 反例/边界（至少1个）
1. **常见误解/边界**: 
   - **误区**：认为 $\arcsin(\sin x) = x$ 恒成立。这是错的！只有 $x$ 在主值区间 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 时才成立。
   - **边界**：$\arccos$ 的主值区间 $[0,\pi]$ 与 $\arcsin$ 的 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 不同，"反正（arc + sin/tan）取中间，反余（arccos/arccot）取半边"。
   - **极限**：$\arctan x$ 和 $\operatorname{arccot} x$ 的主值区间是开区间，端点只能趋近不能取到。

## 详细解释
各三角函数的主值区间：
- $\sin X$ 主值区间：$[-\frac{\pi}{2}, \frac{\pi}{2}]$
- $\cos X$ 主值区间：$[0, \pi]$
- $\tan X$ 主值区间：$(-\frac{\pi}{2}, \frac{\pi}{2})$
- $\cot X$ 主值区间：$(0, \pi)$
口诀：「反正（arc）取中间，反余（arcc）取半边」。

### 推导过程（★ 数学卡必须）
**为什么需要主值区间？**

三角函数都是周期函数，一个 $y$ 值（如 $y = \frac{1}{2}$）对应无穷多个 $x$ 满足 $\sin x = \frac{1}{2}$：
$$x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{13\pi}{6}, \frac{17\pi}{6}, \dots$$

反函数要求一一对应，因此必须将定义域限制到一个单调区间。

**主值区间的选择原则**：

1. **单调性**：区间上函数严格单调（确保一一对应）。
2. **包含零点附近**：尽可能靠近原点，便于计算和连续性。
3. **覆盖整个值域**：限制后的值域仍能覆盖原函数的完整值域。

**各主值区间的验证**：

- $\sin x$ 在 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 上：$\sin' x = \cos x \ge 0$（严格递增），值域 $[-1,1]$。此为包含 0 的完整单调区间。
- $\cos x$ 在 $[0,\pi]$ 上：$\cos' x = -\sin x \le 0$（严格递减），值域 $[-1,1]$。
- $\tan x$ 在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 上：$\tan' x = \sec^2 x > 0$（严格递增），值域 $\mathbb{R}$。
- $\cot x$ 在 $(0,\pi)$ 上：$\cot' x = -\csc^2 x < 0$（严格递减），值域 $\mathbb{R}$。

**口诀验证**："反正取中间"——$\arcsin$ 和 $\arctan$ 的主值区间都关于原点对称（中心区间）；"反余取半边"——$\arccos$ 的主值区间是 $[0,\pi]$（右半边），$\operatorname{arccot}$ 的主值区间是 $(0,\pi)$（同样是右半边）。

### 重要推论（★ 数学卡必须）
1. **正反函数复合的正确使用**：
   - $\arcsin(\sin x) = x \iff x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$
   - $\arccos(\cos x) = x \iff x \in [0,\pi]$
   - $\arctan(\tan x) = x \iff x \in (-\frac{\pi}{2}, \frac{\pi}{2})$
2. **奇偶性与值域的对应关系**：
   - 对称主值区间 → 反函数是奇函数（$\arcsin$、$\arctan$）
   - 非对称主值区间 → 反函数不是奇函数也不是偶函数（$\arccos$、$\operatorname{arccot}$）
3. **导数公式的统一记忆**：所有反三角函数的导数都可以通过主值区间的反函数求导法则推导：
   - $\arcsin' x = \frac{1}{\sqrt{1-x^2}}$（定义域 $(-1,1)$）
   - $\arccos' x = -\frac{1}{\sqrt{1-x^2}}$（定义域 $(-1,1)$）
   - $\arctan' x = \frac{1}{1+x^2}$（定义域 $\mathbb{R}$）
   - $\operatorname{arccot}' x = -\frac{1}{1+x^2}$（定义域 $\mathbb{R}$）

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\arcsin(\sin \frac{5\pi}{6})$ 的值。

**解**：首先 $\sin \frac{5\pi}{6} = \frac{1}{2}$。

问题是求一个角度 $x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$（$\arcsin$ 的主值区间），使得 $\sin x = \frac{1}{2}$。

$\sin \frac{\pi}{6} = \frac{1}{2}$ 且 $\frac{\pi}{6} \in [-\frac{\pi}{2}, \frac{\pi}{2}]$。

$$\arcsin(\sin \frac{5\pi}{6}) = \arcsin(\frac{1}{2}) = \frac{\pi}{6}$$

注意 $\frac{5\pi}{6} \notin [-\frac{\pi}{2}, \frac{\pi}{2}]$，因此原式 $\neq \frac{5\pi}{6}$。主值区间将角度"拉回"到了 $\frac{\pi}{6}$。

**例题2**
**题目**：求 $\arctan(\tan \frac{3\pi}{4})$ 的值。

**解**：$\tan \frac{3\pi}{4} = \tan(\pi - \frac{\pi}{4}) = -\tan \frac{\pi}{4} = -1$。

在 $\arctan$ 的主值区间 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 内，$\tan(-\frac{\pi}{4}) = -1$。

$$\arctan(\tan \frac{3\pi}{4}) = \arctan(-1) = -\frac{\pi}{4}$$

$\frac{3\pi}{4}$ 不在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 内，主值区间将输出修正为 $-\frac{\pi}{4}$。

## 类比

### 一句话比喻
主值区间就像给每个人规定了一个"法定户籍地址"——三角函数值（如身高）可以对应多个角度（不同的人），但反函数只认主值区间内的那一个（只看登记在册的那个地址）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 主值区间 | 规定角度计量的"标准范围"（如经纬度主经在 $-180°$ 到 $180°$） |
| $\arcsin x$ 值域 $[-\frac{\pi}{2},\frac{\pi}{2}]$ | 倾角测量仪表读数限制在 ±90° 之内 |
| $\arccos x$ 值域 $[0,\pi]$ | 夹角始终在 0° 到 180° 之间的物理规定 |
| 反函数的唯一性 | 每个测量值只对应一个标准读数（消除歧义） |
