# 取整函数（向下取整）

## 类型判定
判别型 — 区分/定义概念，建立判断标准

## 是什么
对于任意实数 $X$，$\lfloor X \rfloor$ 表示不超过 $X$ 的最大整数。

## 输入-输出空间
- **输入**: 定义域内的自变量值
- **输出**: 对应的函数值（在值域内）
- **映射关系**: $x \mapsto f(x)$，定义域到值域的单值映射

## 正例（至少2个）
1. **场景1**: $\lfloor 1.2 \rfloor = 1$
2. **场景2**: $\lfloor \pi \rfloor = 3$
3. **场景3**: $\lfloor 6 \rfloor = 6$
4. **场景4**: $\lfloor -0.32 \rfloor = -1$

## 反例/边界（至少1个）
1. **常见误解/边界**: 负数取整不是简单地取整数部分。如 $\lfloor -0.32 \rfloor = -1$（向左看，不是 0）。负数取整向左看到的第一个整数才是取整值。又如 $\lfloor -3.14 \rfloor = -4$，而直觉上可能误以为 $-3$。

## 详细解释
取整函数在大学数学中通常特指向下取整（floor），而非向上取整或四舍五入。负数取整时要向左看，不是简单地取整数部分。

### 推导过程（★ 数学卡必须）
取整函数的核心推导围绕三个层面：

**1. 定义层面**：$\lfloor x \rfloor = \max\{n \in \mathbb{Z} \mid n \leq x\}$，即不超过 x 的最大整数。

**2. 基本不等式（去取整符号的核心公式）**：
$$\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1$$

等价地：$$x - 1 < \lfloor x \rfloor \leq x$$

推导：$x - \lfloor x \rfloor$ 是 x 的小数部分 $\{x\}$，满足 $0 \leq \{x\} < 1$。移项即得。

**3. 整数的跨越性质**：$\lfloor x + n \rfloor = \lfloor x \rfloor + n$（n 为整数）。证明：将 x 分解为整数部分加小数部分，x + n = $\lfloor x \rfloor + \{x\} + n$，取整后整数部分相加。

这个不等式在数列极限 ε-N 定义证明中至关重要：当我们解出 $n > M$ 后，取 $N = \lfloor M \rfloor + 1$，确保 $N > M$ 且 N 为正整数。

### 重要推论（★ 数学卡必须）
1. **万能模板 N 的构造**：若解出 $n > M$（M 为正数），则 $N = \lfloor M \rfloor + 1$ 可由取整函数构造。因为 $\lfloor M \rfloor + 1 > M$ 恒成立，且 $\lfloor M \rfloor + 1 \geq 1$。

2. **取整与小数部分的关系**：$\{x\} = x - \lfloor x \rfloor$，$0 \leq \{x\} < 1$。小数部分函数以 1 为周期，在每个 $[n, n+1)$ 上单调递增。

3. **单调性**：取整函数是单调不减的（但非严格单调）。

4. **不连续性**：取整函数在所有整数点处存在跳跃间断点（第一类间断点）。这是典型的阶梯函数。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：$\lfloor 1.2 \rfloor = 1$
**解**：$1.2$ 向左看，不超过它的最大整数是 $1$，故 $\lfloor 1.2 \rfloor = 1$。

**例题2**
**题目**：求 $\lfloor \pi \rfloor$
**解**：$\pi \approx 3.14$，不超过它的最大整数是 $3$，故 $\lfloor \pi \rfloor = 3$。

**例题3**
**题目**：已知 $n > N$ 时必有 $n > \frac{1}{\varepsilon}$，求 N 的表达式
**解**：这要求 $N \geq \frac{1}{\varepsilon}$。但 N 必须是正整数，取 $N = \left\lfloor \frac{1}{\varepsilon} \right\rfloor + 1$。证明：
$$\left\lfloor \frac{1}{\varepsilon} \right\rfloor \leq \frac{1}{\varepsilon} < \left\lfloor \frac{1}{\varepsilon} \right\rfloor + 1 = N$$
故 $N > \frac{1}{\varepsilon}$。当 $n > N$ 时，$n \geq N+1 > \frac{1}{\varepsilon}$，条件满足。
