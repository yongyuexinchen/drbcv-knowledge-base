# 函数的单调性与极值


## 是什么

设 f(x) 在 [a,b] 连续，在 (a,b) 可导。若在 (a,b) 内 f'(x) ≥ 0（且等号只在有限个点成立），则 f(x) 在 [a,b] 上单调递增；若 f'(x) ≤ 0（且等号只在有限个点成立），则 f(x) 单调递减。


## 一、函数单调性的判定

### 定理（导数判定法）

若 $f(x)$ 在 $[a,b]$ 上连续，$(a,b)$ 内可导：

- $f'(x) > 0$（或 $\ge 0$，等号只在有限点成立）$\Rightarrow$ $f(x)$ **单调递增**
- $f'(x) < 0$（或 $\le 0$，等号只在有限点成立）$\Rightarrow$ $f(x)$ **单调递减**

> **证明**：用拉格朗日中值定理
> $$f(x_2)-f(x_1) = f'(\xi)(x_2-x_1)$$
> 若 $f'(\xi)>0$，则 $f(x_2)>f(x_1)$（$x_2>x_1$），即单调递增。

## 二、函数极值的判定

### 2.1 极值的概念

- **极小值**：存在 $\delta>0$，使 $\forall x\in U(x_0,\delta)$ 有 $f(x) \ge f(x_0)$
- **极大值**：存在 $\delta>0$，使 $\forall x\in U(x_0,\delta)$ 有 $f(x) \le f(x_0)$

> **极值 = 局部的最值**

### 2.2 可能的极值点（必要条件）

可能取得极值的点**只有两种**：

1. **驻点**：$f'(x)=0$ 的点
2. **导数不存在的点**

> **注意**：
> - 可导函数的极值点**一定**是驻点（费马引理）
> - 驻点**不一定**是极值点（如 $f(x)=x^3$ 在 $x=0$）

### 2.3 极值的充分条件

#### 第一充分条件（看一阶导数变号）

$f(x)$ 在 $x_0$ 处连续，在 $x_0$ 的去心邻域可导：

| 左侧 $f'$ | 右侧 $f'$ | 结论 |
|-----------|-----------|------|
| $>0$ | $<0$ | **极大值**（由增变减） |
| $<0$ | $>0$ | **极小值**（由减变增） |
| 不变号 | 不变号 | **无极值** |

**适用**：驻点 + 导数不存在的点

#### 第二充分条件（看二阶导数正负）

若 $f'(x_0)=0$ 且 $f''(x_0)$ 存在：

| $f''(x_0)$ | 结论 |
|------------|------|
| $<0$ | **极大值** |
| $>0$ | **极小值** |
| $=0$ | **无法判定**，需用第一充分条件 |

**适用**：仅限驻点（要求二阶导数存在）

## 三、函数的最值

### 3.1 连续函数在闭区间上的最值

**三步法**：

1. **找候选点**：找出 $(a,b)$ 内部所有可能极值点（驻点 + 不可导点）
2. **算函数值**：计算候选点及端点 $f(a), f(b)$ 的函数值
3. **比大小**：最大值 = 最大者，最小值 = 最小者

### 3.2 实际应用（优化问题）

**步骤**：
1. **建立目标函数**：将待求最值的量表示为某变量的函数
2. **确定定义域**：根据实际意义确定变量的取值范围
3. **按最值方法求解**
4. **验证合理性**

> **提示**：建立目标函数是关键，不同变量选取可能带来不同计算复杂度，应选择使表达式最简单的变量。

---

## 四、单调性证明不等式

**方法**：
1. 将要证不等式化为 $f(x) > 0$（或 $<0$）形式
2. 若能验证 $f(x_0)=0$ 且 $f'(x)>0$（单调递增）
3. 则 $x>x_0$ 时 $f(x)>0$，证毕

**例**：证 $x>0$ 时 $\sin x < x$

令 $f(x)=x-\sin x$，$f(0)=0$，$f'(x)=1-\cos x \ge 0$，故 $f(x)>0$。

## 五、单调性与极值关系总结

```
一阶导数 f'(x)
    ├─ >0 → 单调递增
    ├─ <0 → 单调递减
    └─ =0 → 可能为极值点（需进一步判定）
                ├─ f''(x)<0 → 极大值
                ├─ f''(x)>0 → 极小值
                └─ f''(x)=0 → 需看一阶导数变号
```

## 类比

### 一句话比喻
**导数正 → 上坡，导数负 → 下坡，导数零 → 平路。** 你骑车看坡度：正坡你喘气上，负坡你爽滑下，平路你歇脚。极值点就是坡顶或坡底——到了那里坡度归零，再往前就反向。

### 物理映射
| 导数符号 | 函数行为 | 物理类比 |
|---------|---------|---------|
| f'(x) > 0 | 单调递增 | 前进（正速度） |
| f'(x) < 0 | 单调递减 | 倒退（负速度） |
| f'(x) = 0 | 驻点 | 停下来的一瞬间 |

## 正例
**例1**：$f(x)=x^3$，$f'(x)=3x^2\geq0$，在 $(-\infty,+\infty)$ 上单调递增。
**例2**：$f(x)=e^x-x$，$f'(x)=e^x-1$，在 $(-\infty,0)$ 上单调递减，在 $(0,+\infty)$ 上单调递增。
