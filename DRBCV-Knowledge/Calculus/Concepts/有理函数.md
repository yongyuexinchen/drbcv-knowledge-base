# 有理函数 (Rational Function)

## 类型判定
定义型 — 明确术语的数学定义

## 是什么
形如 $R(x) = \frac{P_n(x)}{Q_m(x)}$ 的函数，其中 $P_n(x)$ 和 $Q_m(x)$ 都是多项式，称为有理函数（有理分式）。$Q_m(x)\ne 0$。

## 输入-输出空间
- **输入**: 定义域内的自变量值（$Q_m(x)\ne 0$）
- **输出**: 对应的函数值
- **映射关系**: $x \mapsto \frac{P_n(x)}{Q_m(x)}$

## 正例（至少2个）
1. **场景1**: $\frac{x^4+2x^2+4}{x^2+1}$（假分式，分子4次≥分母2次）
2. **场景2**: $\frac{x-3}{(x-1)^2(x+1)}$（真分式，分子1次<分母3次）
3. **场景3**: $\frac{x^5+x^4-8}{x^3-x}$（假分式）

## 反例/边界（至少1个）
1. **常见误解/边界**: $f(x)=\frac{\sin x}{x}$ 不是有理函数——分子是三角函数而非多项式。有理函数要求分子分母都是**多项式**（反对幂指三中只有幂函数的组合）。

## 详细解释
有理函数积分是唯一被彻底攻克的积分类型——有一整套系统化方法确保100%可以积分。研究的对象是分母可以因式分解为一次因式和二次因式乘积的有理函数。

### 推导过程（★ 数学卡必须）
有理函数的层次结构：

$$\text{有理函数 } R(x)=\frac{P_n(x)}{Q_m(x)}$$

- 若 $\deg P_n \ge \deg Q_m$（假分式）→ 多项式除法 → 多项式 + 真分式
- 若 $\deg P_n < \deg Q_m$（真分式）→ 分母质因式分解 → 部分分式分解 → 逐项积分

### 重要推论（★ 数学卡必须）
1. 有理函数积分是微积分中唯一有确定性保证的积分类型——100%能积出初等函数。
2. 处理步骤：化假为真 → 分母因式分解 → 部分分式分解 → 逐项积分。
3. 分母只能分解为一次因式 $(x-a)^k$ 和二次质因式 $(x^2+px+q)^l$（判别式 $<0$）。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：将假分式 $\frac{x^4+2x^2+4}{x^2+1}$ 化为多项式+真分式
**解**：多项式除法：$x^4+2x^2+4 = (x^2+1)(x^2+1)+3$
$$\frac{x^4+2x^2+4}{x^2+1} = x^2+1+\frac{3}{x^2+1}$$
积分：$\int\frac{x^4+2x^2+4}{x^2+1}\,dx = \frac{x^3}{3}+x+3\arctan x+C$

**例题2**
**题目**：求 $\int\frac{x-3}{(x-1)^2(x+1)}\,dx$
**解**：部分分式分解：
$$\frac{x-3}{(x-1)^2(x+1)} = \frac{A}{x-1}+\frac{B}{(x-1)^2}+\frac{D}{x+1}$$

用留数法求系数：
- $B$：删 $(x-1)^2$，代 $x=1$：$B=\frac{1-3}{1+1}=-1$
- $D$：删 $(x+1)$，代 $x=-1$：$D=\frac{-1-3}{(-1-1)^2}=\frac{-4}{4}=-1$
- $A$：乘 $x$ 求极限，$A=1$

$$\int\left(\frac{1}{x-1}-\frac{1}{(x-1)^2}-\frac{1}{x+1}\right)dx = \ln|x-1|+\frac{1}{x-1}-\ln|x+1|+C$$

## 类比

### 一句话比喻
有理函数就像"一筐苹果"——虽然筐里什么种类都有，但按品种分拣后，每种都有确定的处理方法。

### 物理映射

|---------|---------|
| $P(x)/Q(x)$ | 一筐混合水果 |
| 多项式除法 | 先挑出整箱的好果 |
| 部分分式分解 | 按品种分拣 |
| 逐项积分 | 每种有确定的加工方法 |
