# 基本初等函数导数公式

## 类型判定
程序型 — 数学公式/计算方法

## 是什么
1. $(C)' = 0$（常数）
2. $(x^\alpha)' = \alpha x^{\alpha-1}$（幂函数）
3. $(a^x)' = a^x\ln a$，$(e^x)' = e^x$（指数函数）
4. $(\log_a x)' = \frac{1}{x\ln a}$，$(\ln|x|)' = \frac{1}{x}$（对数函数）
5. $(\sin x)' = \cos x$
6. $(\cos x)' = -\sin x$
7. $(\tan x)' = \sec^2 x = \frac{1}{\cos^2 x}$
8. $(\cot x)' = -\csc^2 x = -\frac{1}{\sin^2 x}$
9. $(\sec x)' = \sec x \tan x$
10. $(\csc x)' = -\csc x \cot x$
11. $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$
12. $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$
13. $(\arctan x)' = \frac{1}{1+x^2}$
14. $(\text{arccot } x)' = -\frac{1}{1+x^2}$

## 输入-输出空间
- **输入**: 定义域内的自变量值
- **输出**: 对应的函数值（在值域内）
- **映射关系**: $x \mapsto f(x)$，定义域到值域的单值映射

## 正例（至少2个）
1. **场景1**: $(x^3)' = 3x^2$，$(\frac{1}{x})' = -\frac{1}{x^2}$，$(\sqrt{x})' = \frac{1}{2\sqrt{x}}$
2. **场景2**: $(\arctan x)' = \frac{1}{1+x^2}$，$(\ln x)' = \frac{1}{x}$（$x>0$），$(e^x)' = e^x$
3. **场景3**: $(\sec x)' = \sec x \tan x$ 可由 $\sec x = \frac{1}{\cos x}$ 结合商的求导法则验证

## 反例/边界（至少1个）
1. **幂函数的定义域限制**: $x^\alpha$ 的导数公式 $(x^\alpha)' = \alpha x^{\alpha-1}$ 要求 $x>0$（一般情况下）。特例：当 $\alpha$ 为正整数时有 $x\in\mathbb{R}$。
2. **对数函数的绝对值**: $(\ln|x|)' = \frac{1}{x}$ 对所有 $x \neq 0$ 成立。推导：$x>0$ 时 $(\ln x)'=\frac{1}{x}$；$x<0$ 时 $\ln(-x)$ 求导为 $\frac{1}{-x} \cdot (-1) = \frac{1}{x}$。
3. **反三角函数的定义域**: $\arcsin x$ 和 $\arccos x$ 的导数仅对 $|x|<1$ 定义（端点不可导）。

## 详细解释
这是求导运算的"九九乘法表"，必须熟练掌握。所有基本初等函数导数可用定义推导，但实际解题时直接使用公式。

### 推导过程（★ 数学卡必须）

所有基本初等函数导数公式均可由导数定义推导：

**幂函数 $(x^\alpha)' = \alpha x^{\alpha-1}$**（$x>0$）：
$$f'(x_0) = \lim_{\Delta x \to 0} \frac{(x_0+\Delta x)^\alpha - x_0^\alpha}{\Delta x} = \lim_{\Delta x \to 0} x_0^\alpha \cdot \frac{(1+\frac{\Delta x}{x_0})^\alpha - 1}{\Delta x}$$
利用等价无穷小 $(1+t)^\alpha - 1 \sim \alpha t$（$t\to 0$）：
$$= x_0^\alpha \cdot \frac{\alpha \cdot \frac{\Delta x}{x_0}}{\Delta x} = \alpha x_0^{\alpha-1}$$

**指数函数 $(e^x)' = e^x$**：
$$(e^x)' = \lim_{\Delta x \to 0} \frac{e^{x+\Delta x} - e^x}{\Delta x} = e^x \lim_{\Delta x \to 0} \frac{e^{\Delta x} - 1}{\Delta x} = e^x \cdot 1 = e^x$$

**正弦函数 $(\sin x)' = \cos x$**：
$$(\sin x)' = \lim_{\Delta x \to 0} \frac{\sin(x+\Delta x) - \sin x}{\Delta x} = \lim_{\Delta x \to 0} \frac{2\sin\frac{\Delta x}{2}\cos(x+\frac{\Delta x}{2})}{\Delta x} = \cos x$$

**正切函数 $(\tan x)' = \sec^2 x$**（商的导数法则）：
$$\tan x = \frac{\sin x}{\cos x},\quad (\tan x)' = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x$$

**反三角函数 $(\arcsin x)'$**（反函数求导法则）：
令 $y = \arcsin x$，则 $x = \sin y$，由反函数求导法则：
$$\frac{dy}{dx} = \frac{1}{\frac{dx}{dy}} = \frac{1}{\cos y} = \frac{1}{\sqrt{1-\sin^2 y}} = \frac{1}{\sqrt{1-x^2}}$$

其余公式可类似推导，关键工具是定义、四则法则、反函数法则和链式法则。

### 重要推论（★ 数学卡必须）

1. **所有基本初等函数在其定义域内可导**（除边界点和个别特殊点外）。
2. **初等函数在定义区间内处处可导**：因为初等函数由基本初等函数经四则运算和复合构成，而可导性对四则运算和复合封闭。
3. **导数公式的对称性**：
   - $\sin \leftrightarrow \cos$：导数相差一个负号
   - 指数与对数：互为反函数，导数关系 $(\ln x)' = 1/x$ vs $(e^x)' = e^x$
   - $\arctan$ 与 $\text{arccot}$：仅差负号
4. **求导化简技巧**：$\ln|x|$ 的导数统一为 $1/x$（不必分段讨论），计算中 $\ln$ 的绝对值常可忽略。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**: 求 $y = x^3 + 2^x + \sin x - \ln x$ 的导数。
**解**: 逐项使用基本求导公式：
$$y' = (x^3)' + (2^x)' + (\sin x)' - (\ln x)' = 3x^2 + 2^x\ln 2 + \cos x - \frac{1}{x}$$
各项所用公式：幂函数 $(x^3)'=3x^2$，指数函数 $(2^x)'=2^x\ln 2$，正弦 $(\sin x)'=\cos x$，对数 $(\ln x)'=\frac{1}{x}$。

**例题2**
**题目**: 求 $y = \arctan x - \arcsin x + e^x \ln x$（$x>0$）的导数。
**解**: 
前两项直接使用反三角函数公式：
$$(\arctan x)' = \frac{1}{1+x^2},\quad (\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$$
第三项 $e^x\ln x$ 使用乘积法则：
$$(e^x\ln x)' = (e^x)'\ln x + e^x(\ln x)' = e^x\ln x + e^x \cdot \frac{1}{x} = e^x\left(\ln x + \frac{1}{x}\right)$$
综上：
$$y' = \frac{1}{1+x^2} - \frac{1}{\sqrt{1-x^2}} + e^x\left(\ln x + \frac{1}{x}\right)$$

**例题3**（补充）
**题目**: 求 $y = x\sqrt{x} - \frac{1}{x}$ 的导数。
**解**: $x\sqrt{x}=x^{3/2}$，$(x^{3/2})'=\frac{3}{2}x^{1/2}=\frac{3}{2}\sqrt{x}$，$(-\frac{1}{x})'=-(-x^{-2})=x^{-2}=\frac{1}{x^2}$。因此 $y' = \frac{3}{2}\sqrt{x} + \frac{1}{x^2}$。

## 类比

### 一句话比喻
基本初等函数导数公式就像乘法口诀表——不是靠查字典用的，而是要刻在肌肉记忆里，做题时随手就能写出来。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $(e^x)'=e^x$ | 自身繁殖：变化率等于当前值，就像放射性衰变或复利增长 |
| $(\sin x)'=\cos x$ | 正弦波的速度 = 余弦波（简谐振动的速度函数） |
| $(x^\alpha)'=\alpha x^{\alpha-1}$ | 幂次降一级，类似降维打击——次数减1，原次数乘到前面 |
