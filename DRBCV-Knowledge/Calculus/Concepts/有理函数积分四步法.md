# 有理函数积分四步法 (Four-Step Method for Rational Function Integration)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
1. 假分式化多项式+真分式（多项式除法/凑分母法）。2. 分母因式分解确定质因式。3. 真分式化最简有理分式之和（留数法/特值法/方程组求系数）。4. 逐项积分（幂函数/对数/反正切/组合法）。

## 输入-输出空间
- **输入**: 有理函数 $\frac{P(x)}{Q(x)}$
- **输出**: 原函数族 $F(x)+C$
- **映射关系**: 系统化流程确保100%可积

## 正例（至少2个）
1. **场景1**: $\int\frac{x-3}{(x-1)^2(x+1)}\,dx$ 完整四步流程
2. **场景2**: $\int\frac{x^4+2x^2+4}{x^2+1}\,dx$ 从假分式开始的四步流程

## 反例/边界（至少1个）
1. **常见误解/边界**: 四步法虽是通法，但不一定是最简方法。例如 $\int\frac{x}{(x-1)(x+1)}\,dx$ 用四步法要分解再逐项积分，但如果直接观察 $\frac{x}{x^2-1}$ 可以用凑微分更快。遇到具体问题应结合观察灵活处理。

## 详细解释
确保100%可以积分出初等函数的系统性方法，是微积分中少数被彻底攻克的问题类型。

### 推导过程（★ 数学卡必须）
**四步法完整流程**：

**第一步：化假为真**
$$\frac{P_n(x)}{Q_m(x)} = S(x) + \frac{R(x)}{Q_m(x)} \quad (\deg R < \deg Q)$$
方法：凑分母法或长除法。

**第二步：分母因式分解**
$$Q_m(x) = (x-a_1)^{k_1}\cdots(x^2+p_1x+q_1)^{l_1}\cdots$$
要求二次因式 $\Delta=p^2-4q<0$（质因式）。

**第三步：部分分式分解**
$$\frac{R(x)}{Q_m(x)} = \sum\text{最简有理分式}$$
求系数：留数法（最快）+极限法（补充）。

**第四步：逐项积分**
四种最简分式的积分方法：
1. $\frac{A}{x-a}$ → $A\ln|x-a|+C$
2. $\frac{A}{(x-a)^n}$ → $\frac{-A}{(n-1)(x-a)^{n-1}}+C$
3. $\frac{Bx+C}{x^2+px+q}$ → 组合法：分子凑分母导数，拆为 $\frac{1}{2}\ln|x^2+px+q|$ + $\arctan$ 形式
4. $\frac{Bx+C}{(x^2+px+q)^n}$ → 递推法

### 重要推论（★ 数学卡必须）
1. 有理函数积分是100%确定性的——一定能积出初等函数结果。
2. 但通法未必是最简方法——具体问题应结合观察。
3. 组合法处理 $\frac{Bx+C}{x^2+px+q}$：
   - 分子凑分母导数：$Bx+C = \frac{B}{2}(2x+p) + (C-\frac{Bp}{2})$
   - 第一项：$\frac{B}{2}\ln|x^2+px+q|+C_1$
   - 第二项：$(C-\frac{Bp}{2})\cdot\frac{1}{a}\arctan\frac{x+\frac{p}{2}}{a}+C_2$（配方后 $a=\sqrt{q-\frac{p^2}{4}}$）

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int\frac{x-3}{(x-1)^2(x+1)}\,dx$
**解**：
**步骤1**：已是真分式，无需化假为真。
**步骤2**：分母已分解。
**步骤3**：部分分式分解：
$$\frac{x-3}{(x-1)^2(x+1)} = \frac{1}{x-1}-\frac{1}{(x-1)^2}-\frac{1}{x+1}$$
**步骤4**：逐项积分：
$$\int\frac{1}{x-1}\,dx = \ln|x-1|$$
$$\int\frac{-1}{(x-1)^2}\,dx = \frac{1}{x-1}$$
$$\int\frac{-1}{x+1}\,dx = -\ln|x+1|$$
$$\Rightarrow \ln|x-1|+\frac{1}{x-1}-\ln|x+1|+C$$

**例题2**
**题目**：求 $\int\frac{x+1}{x^2-4x+13}\,dx$
**解**：
**组合法**：分子凑分母导数。$x^2-4x+13$ 的导数为 $2x-4$。
$$\frac{x+1}{x^2-4x+13} = \frac{\frac{1}{2}(2x-4)+3}{x^2-4x+13} = \frac{1}{2}\cdot\frac{2x-4}{x^2-4x+13}+\frac{3}{x^2-4x+13}$$

第一项：$\frac{1}{2}\ln|x^2-4x+13|$

第二项分母配方：$x^2-4x+13=(x-2)^2+9$，$a=3$：
$$\int\frac{3}{(x-2)^2+9}\,dx = 3\cdot\frac{1}{3}\arctan\frac{x-2}{3} = \arctan\frac{x-2}{3}$$

$$\Rightarrow \frac{1}{2}\ln(x^2-4x+13)+\arctan\frac{x-2}{3}+C$$
