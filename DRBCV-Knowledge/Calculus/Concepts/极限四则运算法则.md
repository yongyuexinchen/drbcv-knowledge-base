## 类型判定

这是一个 **连接级 (connection)** 概念卡。极限四则运算法则是对极限进行代数运算的核心工具，它将复杂极限拆解为简单极限的组合，是整个极限计算的骨架。正确理解运算法则的适用条件是避免计算错误的关键。

## 是什么

**极限四则运算法则**：设 \\(\lim f(x) = A\\)，\\(\lim g(x) = B\\)（A、B 为有限实数），则有：

| 运算 | 公式 | 条件 |
|------|------|------|
| **加法** | \\(\lim [f(x) \pm g(x)] = A \pm B\\) | A、B 均存在 |
| **乘法** | \\(\lim [f(x) \cdot g(x)] = A \cdot B\\) | A、B 均存在 |
| **数乘** | \\(\lim [c \cdot f(x)] = c \cdot A\\) | c 为常数 |
| **除法** | \\(\lim \frac{f(x)}{g(x)} = \frac{A}{B}\\) | A、B 均存在，**且 B ≠ 0** |
| **幂指运算** | \\(\lim f(x)^{g(x)} = A^B\\) | A > 0，A、B 均存在 |

**核心原则**：**各部分极限必须都存在**，才能进行拆分和组合。

## 输入-输出空间

| 维度 | 说明 |
|------|------|
| **输入** | 若干个函数的代数组合（和差积商、幂指） |
| **输出** | 组合后的极限值（或判定为未定式） |
| **适用对象** | 数列极限、函数极限（有限值）均适用 |
| **不适用** | 未定式（7种）：0/0, ∞/∞, 0·∞, ∞-∞, 1^∞, 0^0, ∞^0 |

### 7 种未定式一览

| 类型 | 例子 | 说明 |
|------|------|------|
| **0/0** | x→0, sin x / x | 最常见，需等价代换、洛必达等 |
| **∞/∞** | n→∞, (n²+1)/(2n²) | 抓大头或洛必达 |
| **0·∞** | x→0, x·ln x | 化为 0/0 或 ∞/∞ |
| **∞-∞** | x→0, 1/x² - 1/sin²x | 通分化为 0/0 |
| **1^∞** | x→∞, (1+1/x)^x | 重要极限或取对数法 |
| **0^0** | x→0⁺, x^x | 取对数法 |
| **∞^0** | x→∞, x^(1/x) | 取对数法 |

## 正例

**例 1**（存在+存在=存在）：\\(\lim_{x \to 0} \frac{\sin x}{x} + \frac{\cos x - 1}{x} = 1 + 0 = 1\\)

拆开检查：前项极限 = 1（重要极限），后项极限 = 0（1-cos x ~ ½x²），两个极限都存在，故可拆。

**例 2**（存在×存在=存在）：\\(\lim_{x \to 0} \cos x \cdot \frac{\sin x}{x} = 1 \cdot 1 = 1\\)
- cos x → 1（非零，可直接提前求极限）
- sin x / x → 1
- 乘积极限 = 1

**例 3**（商的法则）：\\(\lim_{x \to 1} \frac{x-3}{x^2-9} = \frac{-2}{-8} = \frac{1}{4}\\)
- 分子极限 = -2，分母极限 = -8 ≠ 0
- 商的极限 = (-2)/(-8) = 1/4

## 反例/边界

**反例 1**（不能拆——都不存在）：\\(\lim_{x \to 0} \left(\frac{1}{x^2} - \frac{\cos x}{x^2}\right)\\)
- 拆开：前项 ∞，后项 ∞，两者极限都不存在
- 拆开会破坏原极限！正确做法是通分后使用等价代换

**反例 2**（不能拆——分母极限为零）：\\(\lim_{x \to 3} \frac{x-3}{x^2-9}\\)
- 分母极限 = 0，不符合商的法则
- 需约去零因子后变为 1/(x+3) 再代入

**反例 3**（不能提前代入非零——不是乘除因子）：x → 1 时 \\(\frac{x\ln x - (x-1)}{(x-1)\ln x}\\)
- 不能把 ln x 等价为 x-1（不是整个函数的乘除因子）
- 需先换元 t = x-1，再拆分为两项处理

## 详细解释

### 拆极限的终极原则

**原则一**：若拆开后**两项极限都存在** → 可以拆（\"存在+存在=存在\"）

**原则二**：若拆开后**两项极限都不存在** → **不可以拆**（可能破坏原极限）

**原则三**：若拆开后**一项存在，另一项未知** → **可以拆**（\"看到存在就拆出\"）
- 理论依据：若 f 存在，g 不存在，则 f+g 一定不存在
- 操作：拆出存在项，剩下那项若存在就算出，若不存在则答案即为\"不存在\"

**原则四**：**非零的乘除因子**可以提前求极限并代入
- 本质：乘法的运算法则，极限非零保证了安全性
- 必须是被乘除的因子，不能是加减项中的一部分

### 抓大头法（∞/∞ 型）

当 n → ∞（或 x → ∞）时，分子分母都是无穷大，极限取决于最高次项：
\\[
\lim_{n \to \infty} \frac{a_m n^m + a_{m-1} n^{m-1} + \cdots}{b_k n^k + b_{k-1} n^{k-1} + \cdots} =
\begin{cases}
0, & m < k \\\\
\frac{a_m}{b_k}, & m = k \\\\
\infty, & m > k
\end{cases}
\\]

## 细节备注

| 子特性 | 说明 |
|--------|------|
| 四则运算的推广 | 可推广到有限个函数的和积（数学归纳法） |
| 幂指运算的条件 | 底数极限 > 0 且存在，指数极限存在 |
| 数列与函数 | 四则运算法则对数列极限和函数极限均成立 |
| 复合运算 | 若外层函数连续，极限符号可穿过：\\\\(\lim f(g(x)) = f(\lim g(x))\\\\) |
| 抓大头的严格证明 | 分子分母同除以最高次项，低次项趋于 0 |

### 使用原则

1. **先判断类型**：代入趋近值，看是否为 7 种未定式之一
2. **非未定式**：直接代入求值（初等函数在其定义域内连续）
3. **未定式**：先变形（约分、通分、等价代换、洛必达等）化为非未定式
4. **拆极限时**：遵循\"看到存在就拆出\"原则，不内耗
5. **乘除因子**：非零的因子可提前求极限

## 经典例题

### 例题 1（原文：期末救急速讲-拆极限辨析 圈1）

判断是否能拆：\\(\lim_{x \to 0} \frac{x - \sin x}{x^3}\\)

**分析**：
- 拆成 \\(\lim \frac{x}{x^3} - \lim \frac{\sin x}{x^3}\\) = \\(\lim \frac{1}{x^2} - \lim \frac{\sin x}{x^3}\\)
- 前项极限 = ∞（不存在），后项极限 = ∞（不存在）
- **拆开后两个极限都不存在，不能拆！**

**正确做法**：
\\[
\lim_{x \to 0} \frac{x - \sin x}{x^3} = \lim_{x \to 0} \frac{\frac{1}{6}x^3}{x^3} = \frac{1}{6}
\\]
（使用等价代换：x - sin x ~ x³/6）

### 例题 2（原文：期末救急速讲-拆极限辨析 圈2）

判断是否能拆：\\(\lim_{x \to 0} \frac{\sin x}{x} + \frac{x \sin \frac{1}{x}}{x}\\)

**分析**：
- 前项 \\(\lim \frac{\sin x}{x} = 1\\)（存在）
- 后项 \\(\lim \frac{x \sin \frac{1}{x}}{x} = \lim \sin \frac{1}{x}\\)（0·有界 = 0，存在）
- **两项都存在，可以拆！** 结果 = 1 + 0 = 1

### 例题 3（原文：期末救急速讲-非零因子提前求）

\\(\lim_{x \to 0} \frac{\cos x \cdot \sin x}{x}\\)
- cos x → 1（非零的乘除因子，可提前求）
- 原式 = \\(1 \cdot \lim_{x \to 0} \frac{\sin x}{x} = 1 \cdot 1 = 1\\)

## 类比

**分拣流水线类比** 🏭

想象一个快递分拣流水线，有多个工位：

- 工位 A 每分钟处理 10 件（lim f = A）
- 工位 B 每分钟处理 5 件（lim g = B）
- **加法规**：两个工位串联，总处理量 = 10 + 5 = 15
- **乘法规**：A 和 B 合作打包，每分钟组合件数 = 10 × 5 = 50
- **除法规则**：A/B，要求 B ≠ 0——若 B 工位停机（极限为 0），整个除法就非法
- **未定式**：如果 A 和 B 都显示为\"机器故障\"（未定式），你不能直接相加——得先修好机器（化简）
