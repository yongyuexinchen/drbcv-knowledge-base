# 分部积分中u和dv的选取原则（反对幂指三）(LIATE Rule for Integration by Parts)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
当被积函数为两类不同函数相乘时，选取 $u$ 的优先级（从难积分到易积分）：反三角函数(A) > 对数函数(L) > 幂函数(P) > 指数函数(E) > 三角函数(T)。幂函数×指数函数/三角函数：指数/三角函数凑入 $dv$；幂函数×对数函数/反三角函数：幂函数凑入 $dv$；指数函数×三角函数：可任意选择，通常需两次分部后还原。

## 输入-输出空间
- **输入**: 两类不同函数相乘的被积函数
- **输出**: 原函数族 $F(x)+C$
- **映射关系**: 乘法求导法则的逆运算

## 正例（至少2个）
1. **场景1**: $\int x e^x\,dx$：取 $u=x, dv=e^x\,dx$（幂×指：指凑dv）
2. **场景2**: $\int x\ln x\,dx$：取 $u=\ln x, dv=x\,dx$（幂×对：对取u）
3. **场景3**: $\int e^x\sin x\,dx$：取 $u=\sin x, dv=e^x\,dx$，两次分部后移项

## 反例/边界（至少1个）
1. **常见误解/边界**: $\int x^2 e^x\,dx$ 若取 $u=e^x$、$dv=x^2\,dx$，则 $v=\frac{x^3}{3}$，$du=e^x\,dx$，新积分 $\int\frac{x^3}{3}e^x\,dx$ 比原来更复杂！这就是选错了——指数函数应凑入 $dv$，因为 $e^x$ 积分不变复杂度，而 $x^2$ 求导会降次。

## 详细解释
口诀"反对幂指三"是选取 $u$ 的优先级顺序。幂函数相对中立，既可做 $u$ 也可做 $dv$；反三角函数和对数函数求导后变简单，故取为 $u$；指数和三角函数积分不改变复杂度，故凑入 $dv$。

### 推导过程（★ 数学卡必须）
**分部积分公式**：$\int u\,dv = uv - \int v\,du$

选取原则的核心是让 $\int v\,du$ 比 $\int u\,dv$ 更容易：

1. **$u$ 的选取**：选求导后变简单的函数（反三角→对数→幂），因为 $du$ 比 $u$ 简单。
2. **$dv$ 的选取**：选积分后复杂度不变的函数（指→三），因为 $v$ 容易求出。

**典型组合的处理**：
- $x^n\cdot e^x$：$u=x^n$（求导降次），$dv=e^x\,dx$（积分不变）
- $x^n\cdot \ln x$：$u=\ln x$（求导变 $\frac{1}{x}$），$dv=x^n\,dx$
- $x^n\cdot\arctan x$：$u=\arctan x$（求导变 $\frac{1}{1+x^2}$），$dv=x^n\,dx$
- $e^x\cdot\sin x$：$u$ 任选，两次分部后还原

### 重要推论（★ 数学卡必须）
1. **反对幂指三口诀**：$u$ 优先选"反、对"，$dv$ 优先凑"指、三"，幂函数居中灵活。
2. 幂函数×指数：幂取 $u$，分部 $n$ 次可完成（$x^n$ 每次求导降一次）。
3. 幂函数×对数/反三角：对数/反三角取 $u$，一次分部即可。
4. 指数×三角：需两次分部积分后移项解方程。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int xe^x\,dx$
**解**：取 $u=x$，$dv=e^x\,dx$，则 $v=e^x$，$du=\,dx$：
$$\int xe^x\,dx = xe^x - \int e^x\,dx = xe^x - e^x + C = e^x(x-1)+C$$

**例题2**
**题目**：求 $\int x\ln x\,dx$
**解**：取 $u=\ln x$，$dv=x\,dx$，则 $v=\frac{x^2}{2}$，$du=\frac{1}{x}\,dx$：
$$\int x\ln x\,dx = \frac{x^2}{2}\ln x - \int\frac{x^2}{2}\cdot\frac{1}{x}\,dx = \frac{x^2}{2}\ln x - \frac{1}{2}\int x\,dx$$
$$= \frac{x^2}{2}\ln x - \frac{x^2}{4} + C = \frac{x^2}{4}(2\ln x-1)+C$$

**例题3**
**题目**：求 $\int\arctan x\,dx$
**解**：取 $u=\arctan x$，$dv=\,dx$，则 $v=x$，$du=\frac{1}{1+x^2}\,dx$：
$$\int\arctan x\,dx = x\arctan x - \int\frac{x}{1+x^2}\,dx = x\arctan x - \frac{1}{2}\ln(1+x^2)+C$$

## 类比

### 一句话比喻
反对幂指三就像"团队分工"——谁容易积分（活泼）就去搬砖（凑dv），谁难积分但好求导（惰性）就去当指挥（取u）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $u$（反/对） | 指挥官——求导变简单 |
| $dv$（指/三） | 搬砖工——积分不变 |
| 幂函数 | 中立角色——可指挥可搬砖 |
| 分部积分公式 | 团队协作：指挥×搬砖=成果-换位再干 |
