# 第一类换元积分法（凑微分法）(First Substitution Rule / Integration by Differential)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
若 $\int f(u)\,du = F(u) + C$，且 $u = \varphi(x)$ 可导，则 $\int f(\varphi(x))\varphi'(x)\,dx = \int f(\varphi(x))\,d\varphi(x) = F(\varphi(x)) + C$。核心操作：将被积函数中一部分看作 $\varphi'(x)\,dx = d\varphi(x)$，凑成关于 $\varphi(x)$ 的微分形式。

## 输入-输出空间
- **输入**: 被积函数 $f[\varphi(x)]\cdot\varphi'(x)$
- **输出**: 原函数 $F[\varphi(x)]+C$
- **映射关系**: 复合函数求导的逆运算

## 正例（至少2个）
1. **场景1**: $\int \cos(2x+3)\,dx = \frac{1}{2}\int \cos(2x+3)\,d(2x+3) = \frac{1}{2}\sin(2x+3) + C$
2. **场景2**: $\int \frac{\ln^2 x}{x}\,dx = \int \ln^2 x\,d(\ln x) = \frac{1}{3}\ln^3 x + C$
3. **场景3**: $\int \tan x\,dx = \int \frac{\sin x}{\cos x}\,dx = -\int \frac{1}{\cos x}\,d(\cos x) = -\ln|\cos x| + C$

## 反例/边界（至少1个）
1. **常见误解/边界**: 凑微分时"前后必须统一"——若被积函数中 $\varphi(x)$ 出现了，$dx$ 后面必须凑成 $d\varphi(x)$ 才能整体换元。例如 $\int\frac{1}{\sqrt{1-(x/a)^2}}\,dx$ 不能只把前面看成整体而 $dx$ 不配套，必须同时凑 $d(x/a)$。

## 详细解释
第一类换元法是复合函数求导的逆运算。凑微分时，要求被积函数的一部分是另一部分内层的导数（相差常数倍也可）。变量无需显式换掉，熟练后直接凑微分即可。

### 推导过程（★ 数学卡必须）
设 $F'(u)=f(u)$，即 $\int f(u)\,du = F(u)+C$。

令 $u=\varphi(x)$，由复合函数求导链式法则：
$$[F(\varphi(x))]' = F'(\varphi(x))\cdot\varphi'(x) = f(\varphi(x))\cdot\varphi'(x)$$

故 $F(\varphi(x))$ 是 $f(\varphi(x))\varphi'(x)$ 的原函数，即：
$$\int f(\varphi(x))\varphi'(x)\,dx = F(\varphi(x)) + C$$

操作层面：将 $\varphi'(x)\,dx$ 看成 $d\varphi(x)$（凑微分），把 $\varphi(x)$ 看成整体 $u$。

### 重要推论（★ 数学卡必须）
**常见凑微分模式**（务必熟记）：
1. $dx = \frac{1}{a}\,d(ax+b)$
2. $x\,dx = \frac{1}{2}\,d(x^2)$
3. $\frac{1}{x}\,dx = d(\ln|x|)$
4. $e^x\,dx = d(e^x)$
5. $\sin x\,dx = -d(\cos x)$
6. $\cos x\,dx = d(\sin x)$
7. $\sec^2 x\,dx = d(\tan x)$
8. $\frac{1}{\sqrt{x}}\,dx = 2\,d(\sqrt{x})$
9. $\frac{1}{1+x^2}\,dx = d(\arctan x)$

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int \cos(2x+3)\,dx$
**解**：令 $u=2x+3$，则 $du=2\,dx$，$dx=\frac{1}{2}du$。
$$\int \cos(2x+3)\,dx = \frac{1}{2}\int\cos u\,du = \frac{1}{2}\sin u + C = \frac{1}{2}\sin(2x+3)+C$$

**例题2**
**题目**：求 $\int \frac{\ln^2 x}{x}\,dx$
**解**：注意到 $\frac{1}{x}\,dx = d(\ln x)$，令 $u=\ln x$：
$$\int \frac{\ln^2 x}{x}\,dx = \int u^2\,du = \frac{1}{3}u^3 + C = \frac{1}{3}\ln^3 x + C$$

**例题3**
**题目**：求 $\int \frac{dx}{\sqrt{x}(1+x)}$
**解**：注意到 $\frac{1}{\sqrt{x}}\,dx = 2\,d(\sqrt{x})$，令 $u=\sqrt{x}$：
$$\int \frac{dx}{\sqrt{x}(1+x)} = 2\int \frac{du}{1+u^2} = 2\arctan(\sqrt{x})+C$$

## 类比

### 一句话比喻
凑微分就像"快递打包"——把散落的零件按特定方式打包成一箱，外层包装一拆就还原了。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $\varphi'(x)\,dx$ | 零件散落状态 |
| $d\varphi(x)$ | 打包成一箱 |
| $u=\varphi(x)$ | 贴上标签便于处理 |
| $F(\varphi(x))+C$ | 处理完拆箱还原 |
