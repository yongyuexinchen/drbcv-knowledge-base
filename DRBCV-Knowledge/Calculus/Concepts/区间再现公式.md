# 区间再现公式

## 类型判定
**连接型** — 输入定积分∫_a^b f(x)dx，通过换元 x = a+b-t 构造等式，进而求解原积分

## 是什么
对任意连续函数 f(x)，有：

$$\int_a^b f(x)\,dx = \int_a^b f(a+b-x)\,dx$$

本质是定积分换元法：令 x = a+b-t，则 dx = -dt；当 x=a 时 t=b，当 x=b 时 t=a，负号与上下限颠倒相消，积分线保持不变，只有被积函数中的 x 被换成 a+b-x。

几何意义：y=f(x) 与 y=f(a+b-x) 的图像关于直线 x=(a+b)/2 对称，因此在 [a,b] 上两块面积相等。

## 输入-输出空间
- **输入**: 定积分 ∫_a^b f(x)dx
- **输出**: 与之相等的另一个定积分 ∫_a^b f(a+b-x)dx
- **映射关系**: 积分变量 x → a+b-x（积分线不变）

## 正例
1. **三角分式型**: 求 $I = \int_0^{\pi/2} \frac{\sin^n x}{\sin^n x + \cos^n x}\,dx$
   - 用区间再现：$x \to \frac{\pi}{2}-x$，分子 $\sin^n x$ 变成 $\cos^n x$，分母不变
   - 于是 $I = \int_0^{\pi/2} \frac{\cos^n x}{\sin^n x + \cos^n x}\,dx$
   - 两式相加：$2I = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$，所以 $I = \frac{\pi}{4}$

2. **对数+正切型**: 求 $I = \int_0^{\pi/4} \ln(1+\tan x)\,dx$
   - 用区间再现：$x \to \frac{\pi}{4}-x$，$\tan(\frac{\pi}{4}-x) = \frac{1-\tan x}{1+\tan x}$
   - 化简得 $I = \int_0^{\pi/4} [\ln 2 - \ln(1+\tan x)]\,dx = \frac{\pi}{4}\ln 2 - I$
   - 移项：$2I = \frac{\pi}{4}\ln 2$，所以 $I = \frac{\pi}{8}\ln 2$

3. **变限积分极限**: $\lim_{x\to0^+} \frac{\int_0^x \sqrt{x-t}\,e^t\,dt}{x^{3/2}}$
   - 本质就是区间再现：令 $t = x - u$，把 x 从被积函数中分离

## 反例/边界
1. **常见误解**: 区间再现不是万能钥匙，只对"换元后能化简"的结构有效
2. **边界**: 若 $f(x)+f(a+b-x)$ 相加后没有简化（例如仍是复杂式子），则此法失效

## 详细解释

### 证明
令 $x = a + b - t$，则 $dx = -dt$：

$$\int_a^b f(x)\,dx = \int_b^a f(a+b-t)(-dt) = \int_a^b f(a+b-t)\,dt = \int_a^b f(a+b-x)\,dx$$

（最后一步只是改积分变量名，不影响定积分值）

### 为什么它能推导三角函数积分变换？
区间再现把 $\sin x$ 和 $\cos x$ 互换（在 $[0, \pi/2]$ 上 $\sin(\frac{\pi}{2}-x) = \cos x$）。因此：

$$\int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx$$

这个等式说明：在 $[0, \pi/2]$ 上，$\sin^n x$ 与 $\cos^n x$ 的定积分值完全相同。把它与**分部积分法**结合，就能得到**点火公式（Wallis公式）**的递推关系 $I_n = \frac{n-1}{n} I_{n-2}$。

## 经典例题

**例题1** 求 $I = \int_0^{\pi/2} \frac{\sin x}{\sin x + \cos x}\,dx$

解：区间再现得 $I = \int_0^{\pi/2} \frac{\cos x}{\sin x + \cos x}\,dx$

相加：$2I = \int_0^{\pi/2} 1\,dx = \frac{\pi}{2}$，所以 $I = \frac{\pi}{4}$。

---

**例题2** 求 $I = \int_0^{\pi} x\sin x\,dx$

解：区间再现 $x \to \pi - x$：

$$I = \int_0^{\pi} (\pi - x)\sin(\pi - x)\,dx = \int_0^{\pi} (\pi - x)\sin x\,dx = \pi\int_0^{\pi} \sin x\,dx - I$$

移项：$2I = \pi \cdot 2 = 2\pi$，所以 $I = \pi$。

## 类比

### 一句话比喻
**区间再现像照镜子**：把函数关于区间中点翻转，虽然函数长相变了，但面积不变；如果原函数和镜像函数相加能凑出简单结果，就能直接算出答案。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 区间 [a,b] | 一段从 a 到 b 的路程 |
| f(x) | 沿路程的速度分布 |
| f(a+b-x) | 把路程倒过来看的速度分布 |
| 区间再现等式 | 正走和倒走的总里程相同 |
