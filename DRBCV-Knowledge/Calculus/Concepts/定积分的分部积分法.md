# 定积分的分部积分法

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
$$\int_a^b u(x) \, dv(x) = [u(x)v(x)]_a^b - \int_a^b v(x) \, du(x)$$ 与不定积分的分部积分法相同，只需每一步带上积分上下限。

## 输入-输出空间
- **输入**: 被积函数可分解为 $u(x)$ 和 $dv(x)$ 的形式
- **输出**: 定积分的数值结果
- **映射关系**: 分部积分 → 换序求积 + 边界项 $[uv]_a^b$

## 正例（至少2个）
1. **场景1**: $\int_1^e x \ln x \, dx = \left[\frac{x^2}{2}\ln x\right]_1^e - \int_1^e \frac{x^2}{2} \cdot \frac{1}{x} \, dx$
2. **场景2**: $\int_0^{\pi} x \sin x \, dx$，取 $u=x$, $dv=\sin x\,dx$，则 $du=dx$, $v=-\cos x$。$\int_0^\pi x\sin x\,dx = [-x\cos x]_0^\pi + \int_0^\pi \cos x\,dx = \pi + 0 = \pi$

## 反例/边界（至少1个）
1. **常见误解/边界**: 选择 $u$ 和 $dv$ 不当会导致越积越繁。遵循"反对幂指三"顺序（反三角函数 > 对数 > 幂函数 > 指数 > 三角），排前面的选为 $u$，排后面的凑入 $dv$。另一个常见错误：忘了算边界项 $[uv]_a^b$，直接代成了不定积分的分部积分。

## 详细解释
也可先求不定积分（原函数），再代入上下限。反对幂指三的排序规则同样适用。

### 推导过程（★ 数学卡必须）
分部积分法来源于乘积求导法则的积分形式。

由乘积求导公式：$(uv)' = u'v + uv'$，即 $uv' = (uv)' - u'v$。

两边在 $[a,b]$ 上积分：

$$\int_a^b u(x)v'(x) dx = \int_a^b (u(x)v(x))' dx - \int_a^b u'(x)v(x) dx$$

由牛顿-莱布尼茨公式，$\int_a^b (uv)' dx = u(b)v(b) - u(a)v(a) = [u(x)v(x)]_a^b$。

记 $dv = v'(x)dx$，$du = u'(x)dx$，即得：

$$\int_a^b u \, dv = [uv]_a^b - \int_a^b v \, du$$

### 重要推论（★ 数学卡必须）
1. **循环积分型**：当分部积分后出现与原积分相同的项时，可通过移项解方程求得积分值。例如 $\int_0^{\pi/2} e^x \sin x \, dx$。
2. **定积分分部积分的两种做法**：
   - **方法一（一步一限）**：每一步都带着积分上下限。
   - **方法二（先积后代）**：先做不定积分求出原函数，最后再将上下限代入。
3. **反对幂指三选 u 口诀**：排前面的优先作 $u$（放到微分号外面），排后面的优先作 $dv$（放到微分号里面）。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：$\int_1^e x \ln x \, dx$

**解**：取 $u = \ln x$，$dv = x\,dx$，则 $du = \frac{1}{x}dx$，$v = \frac{x^2}{2}$。

$$\int_1^e x\ln x \, dx = \left[\frac{x^2}{2}\ln x\right]_1^e - \int_1^e \frac{x^2}{2} \cdot \frac{1}{x} \, dx$$

$$= \left(\frac{e^2}{2} \cdot 1 - \frac{1}{2} \cdot 0\right) - \frac{1}{2}\int_1^e x \, dx$$

$$= \frac{e^2}{2} - \frac{1}{2}\left[\frac{x^2}{2}\right]_1^e = \frac{e^2}{2} - \frac{1}{2}\left(\frac{e^2}{2} - \frac{1}{2}\right) = \frac{e^2}{2} - \frac{e^2}{4} + \frac{1}{4} = \frac{e^2 + 1}{4}$$

**例题2**
**题目**：$\int_0^1 \arctan x \, dx$

**解**：取 $u = \arctan x$，$dv = dx$，则 $du = \frac{1}{1+x^2}dx$，$v = x$。

$$\int_0^1 \arctan x \, dx = [x \arctan x]_0^1 - \int_0^1 \frac{x}{1+x^2} dx$$

$$= (1 \cdot \frac{\pi}{4} - 0) - \frac{1}{2}\int_0^1 \frac{2x}{1+x^2} dx$$

$$= \frac{\pi}{4} - \frac{1}{2}[\ln(1+x^2)]_0^1 = \frac{\pi}{4} - \frac{1}{2}(\ln 2 - \ln 1) = \frac{\pi}{4} - \frac{\ln 2}{2}$$

## 类比

### 一句话比喻
分部积分就像搬家时拆家具——把复杂的积分拆成两部分，先处理好外面那层（边界项），再处理里面嵌套的部分（新积分）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $u$（保留在外的函数） | 搬运时先不拆的框架（如柜体） |
| $dv$（放到微分号内） | 搬运时先拆的零件（如抽屉） |
| $[uv]_a^b$（边界项） | 先处理完的部件（已就位） |
| $-\int v\,du$（新积分） | 剩下的需要继续处理的零件 |
