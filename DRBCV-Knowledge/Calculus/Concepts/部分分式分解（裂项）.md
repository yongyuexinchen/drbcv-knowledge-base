# 部分分式分解（裂项）(Partial Fraction Decomposition)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
将有理真分式按分母的质因式分解结果，拆分为若干个最简有理分式之和。规则：每个 $(x-a)^k$ 产生 $k$ 项：$\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k}$。每个二次质因式 $(x^2+px+q)^l$（判别式 $<0$）产生 $l$ 项：$\frac{B_1x+C_1}{x^2+px+q} + \cdots + \frac{B_lx+C_l}{(x^2+px+q)^l}$。

## 输入-输出空间
- **输入**: 有理真分式 $\frac{P(x)}{Q(x)}$
- **输出**: 最简分式之和
- **映射关系**: 复杂真分式 → 简单分式之和

## 正例（至少2个）
1. **场景1**: $\frac{x-3}{(x-1)^2(x+1)} = \frac{1}{x-1}-\frac{1}{(x-1)^2}-\frac{1}{x+1}$
2. **场景2**: $\frac{3x+6}{(x-1)^2(x^2+x+1)} = \frac{-2}{x-1}+\frac{3}{(x-1)^2}+\frac{2x+1}{x^2+x+1}$

## 反例/边界（至少1个）
1. **常见误解/边界**: 二次因式必须先检查能否继续分解——$\Delta=p^2-4q<0$ 时才是质因式。例如 $x^2-1=(x-1)(x+1)$ 不是质因式（$\Delta=4>0$），必须继续分解为一次因式。如果直接把 $x^2-1$ 当作二次质因式处理，分解就是错误的。

## 详细解释
这是有理函数积分最关键的一步。注意二次质因式的判别式必须小于0，且分子为一次式 $Bx+C$。

### 推导过程（★ 数学卡必须）
**分解规则详解**：

设 $Q(x) = (x-a_1)^{k_1}\cdots(x-a_s)^{k_s}(x^2+p_1x+q_1)^{l_1}\cdots(x^2+p_tx+q_t)^{l_t}$

则 $\frac{P(x)}{Q(x)}$ 可唯一分解为：

**一次因式 $(x-a)^k$ 对应**：$\frac{A_1}{x-a}+\frac{A_2}{(x-a)^2}+\cdots+\frac{A_k}{(x-a)^k}$

**二次质因式 $(x^2+px+q)^l$ 对应**：$\frac{B_1x+C_1}{x^2+px+q}+\cdots+\frac{B_lx+C_l}{(x^2+px+q)^l}$

**求系数的三种方法**：
1. **方程组法**：通分后对比系数，解方程组（最通用但最繁琐）
2. **特值法**：通分后代入特殊值消项（比方程组法快捷）
3. **留数法**：求谁删谁代谁——删掉对应因式，代让因式为零的值（最快）

### 重要推论（★ 数学卡必须）
1. 部分分式分解只适用于**真分式**——假分式必须先化假为真。
2. 数法口诀：**求谁删谁代谁**。求系数 $A_k$（最高次项），删对应因式 $(x-a)^k$，代 $x=a$。
3. 四种最简有理分式及其积分：
   - $\frac{A}{x-a}$ → $A\ln|x-a|+C$
   - $\frac{A}{(x-a)^n}$ → $\frac{-A}{(n-1)(x-a)^{n-1}}+C$（$n\ge 2$）
   - $\frac{Bx+C}{x^2+px+q}$ → 组合法：分子凑分母导数 + 常数
   - $\frac{Bx+C}{(x^2+px+q)^n}$ → 递推法（较少见）

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：分解 $\frac{x-3}{(x-1)^2(x+1)}$
**解**：
$$\frac{x-3}{(x-1)^2(x+1)} = \frac{A}{x-1}+\frac{B}{(x-1)^2}+\frac{D}{x+1}$$

留数法：
- $B$：删 $(x-1)^2$，代 $x=1$：$B=\frac{1-3}{1+1}=-1$
- $D$：删 $(x+1)$，代 $x=-1$：$D=\frac{-1-3}{(-1-1)^2}=-1$
- $A$：两端乘 $x$，令 $x\to+\infty$：极限左边为0，右边 $A+D=0$，故 $A=-D=1$

$$\frac{x-3}{(x-1)^2(x+1)} = \frac{1}{x-1}-\frac{1}{(x-1)^2}-\frac{1}{x+1}$$

**例题2**
**题目**：分解 $\frac{x}{(x-1)(x+1)}$
**解**：
$$\frac{x}{(x-1)(x+1)} = \frac{A}{x-1}+\frac{B}{x+1}$$

留数法：
- $A$：删 $(x-1)$，代 $x=1$：$A=\frac{1}{2}$
- $B$：删 $(x+1)$，代 $x=-1$：$B=\frac{-1}{-2}=\frac{1}{2}$

$$\frac{x}{(x-1)(x+1)} = \frac{1}{2(x-1)}+\frac{1}{2(x+1)}$$

## 类比

### 一句话比喻
部分分式分解就像"拆快递"——一个打包好的大箱子，拆开成若干小件，每件都有固定的处理方法。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 真分式 | 打包好的大快递 |
| 分母质因式分解 | 知道箱子里装了几类东西 |
| 部分分式分解 | 拆开成小件 |
| 数法求系数 | 不拆箱直接称出每件重量 |
| 四种最简分式 | 四种标准小件各有处理方法 |
