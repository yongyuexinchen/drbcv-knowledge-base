## 类型判定

这是一个 **连接级 (connection)** 概念卡。夹逼定理（也叫夹逼准则、三明治定理）是极限的两大存在准则之一。它不直接计算极限，而是通过构造不等式确定极限的存在性和值，是处理复杂形式极限（特别是数列 N 项和、N 次根号等）的核心方法。

## 是什么

**夹逼定理（数列形式）**：若存在正整数 N₀，当 n > N₀ 时有 yₙ ≤ xₙ ≤ zₙ（或 yₙ < xₙ < zₙ），且 \\\\(\\lim_{n\\\to\\infty} y_n = \\lim_{n\\\to\\infty} z_n = A\\\\)，则 \\\\(\\lim_{n\\\to\\infty} x_n = A\\\\)。

**夹逼定理（函数形式）**：若在 x₀ 的某去心邻域内有 g(x) ≤ f(x) ≤ h(x)，且 \\\\(\\lim_{x\\\to x_0} g(x) = \\lim_{x\\\to x_0} h(x) = A\\\\)，则 \\\\(\\lim_{x\\\to x_0} f(x) = A\\\\)。

**两个条件缺一不可**：
1. **夹住**：从某项开始，xₙ（或 f(x)）介于 yₙ 和 zₙ 之间
2. **相等**：yₙ 和 zₙ 的极限都存在且相等

## 输入-输出空间

| 维度 | 说明 |
|------|------|
| **输入** | 待求极限的数列 {xₙ} 或函数 f(x) |
| **操作** | 构造上下界数列 {yₙ}, {zₙ}，使 yₙ ≤ xₙ ≤ zₙ |
| **输出** | 极限值 A（当 yₙ、zₙ 极限相等时） |
| **适用场景** | 形式复杂无法直接计算时，特别是 N 项和、N 次根号、含阶乘等 |

## 正例

**例 1**（N 项和——原文例1）：求 \\\\(\\lim_{n\\\to\\infty} \\left(\\frac{1}{n^2+n+1} + \\frac{2}{n^2+n+2} + \\cdots + \\frac{n}{n^2+n+n}\\right)\\\\)

**放缩→夹逼→取极限三步法**：

*放缩*（统一分母，全军出击）：
- **放大**：分母缩小→每一项 ≤ \\\\(\\frac{k}{n^2+n+1}\\\\)
- **缩小**：分母放大→每一项 ≥ \\\\(\\frac{k}{n^2+n+n} = \\frac{k}{n^2+2n}\\\\)

\\\\[
\\frac{1+2+\\cdots+n}{n^2+2n} \\\leq x_n \\\leq \\frac{1+2+\\cdots+n}{n^2+n+1}
\\\\]

*求极限*：
\\\\[
\\frac{n(n+1)/2}{n^2+2n} = \\frac{n^2+n}{2(n^2+2n)} \\\to \\frac{1}{2},\\\quad
\\frac{n(n+1)/2}{n^2+n+1} = \\frac{n^2+n}{2(n^2+n+1)} \\\to \\frac{1}{2}
\\\\]

*夹逼*：上下极限均为 1/2，故原极限 = 1/2。

**例 2**（N 次根号型）：求 \\\\(\\lim_{n\\\to\\infty} \\sqrt[n]{2^n + 3^n + 5^n}\\\\)

*放缩*：删去较小项 \\\\(\\sqrt[n]{5^n} \\\leq \\sqrt[n]{2^n+3^n+5^n} \\\leq \\sqrt[n]{3\\cdot 5^n}\\\\)

*求极限*：左边 = 5，右边 = \\\\(5\\cdot\\sqrt[n]{3} \\\to 5\\\\)（\\\\(\\sqrt[n]{3} \\\to 1\\\\)）

*夹逼*：原极限 = 5。

## 反例/边界

**经典反例**（原文概念辨析题）：xₙ = n，yₙ = n - 1/n，zₙ = n + 1/n

- yₙ ≤ xₙ ≤ zₙ ✓（夹住了）
- yₙ - zₙ = -2/n → 0（无限接近 ✓）
- 但 **yₙ 和 zₙ 的极限都不存在**（都趋于 ∞）
- 条件不满足 → 不能推出 xₙ 极限存在
- 事实上 xₙ = n 发散

**教训**：两个数列无限接近 ≠ 它们极限都存在且相等。极限存在是必要条件！

## 详细解释

### 放缩的两大原则

**原则一：全军出击**
- 若干项求和：每个都放大到最大值，缩小到最小值
  - \\\\(\\sum_{k=1}^n a_k \\\leq n \\cdot \\\max\\\\{a_k\\\\}\\，\\\\(\\sum_{k=1}^n a_k \\\geq n \\cdot \\\min\\\\{a_k\\\\}\\)
- 若干个正数连乘积：每个都放大到最大值，缩小到最小值
  - \\\\(\\\prod_{k=1}^n a_k \\\leq (\\\max\\\\{a_k\\\\})^n\\)，\\\\(\\\prod_{k=1}^n a_k \\\geq (\\\min\\\\{a_k\\\\})^n\\)

**原则二：略去局部**
- 若干项求和：删去正项→缩小，删去负项→放大
- 若干正数连乘：删去小于 1 的因子→放大，删去大于 1 的因子→缩小
- 分式：缩小分母→整体放大，放大分母→整体缩小

### 夹逼定理的 ε-N 证明（理解性，不要求记忆）

由 yₙ → A：∀ ε > 0，∃ N₁，n > N₁ 时 |yₙ - A| < ε ⇒ yₙ > A - ε
由 zₙ → A：∀ ε > 0，∃ N₂，n > N₂ 时 |zₙ - A| < ε ⇒ zₙ < A + ε
由夹逼：∃ N₃，n > N₃ 时 yₙ ≤ xₙ ≤ zₙ
取 N = max{N₁, N₂, N₃}，则 n > N 时：
A - ε < yₙ ≤ xₙ ≤ zₙ < A + ε ⇒ |xₙ - A| < ε
故 xₙ → A。

## 细节备注

| 子特性 | 说明 |
|--------|------|
| 不等号方向 | 放大时保持不等号方向一致（放大→变大，缩小→变小） |
| 放缩的克制 | 放缩要适度——上下界的极限必须相等，否则夹不住 |
| 从某项开始 | 前有限项不符合夹逼条件不影响结论 |
| N 项和的关键 | 分母中变化项是\\\"弟弟\\\"（非最高次）时，放缩不影响极限 |
| N 次根号的关键 | 抓大头——最大的底数决定最终极限 |

### 使用原则

1. **先看形式**：N 项和 → 放缩统一分母；N 次根号 → 抓大头或删去小项
2. **放缩要克制**：过度放缩会导致上下极限不相等，夹不住
3. **验证极限**：必须验证上下极限相等且存在
4. **方向感**：构造下界常通过删项、缩小分母等；构造上界常通过放大到最大值、缩小分母等

## 经典例题

### 例题 1（原文：夹逼定理文章-例2 根式求和）

求 \\\\(\\lim_{n\\\to\\infty} \\left(\\frac{1}{\\sqrt{n^2+1}} + \\frac{1}{\\sqrt{n^2+2}} + \\cdots + \\frac{1}{\\sqrt{n^2+n}}\\right)\\\\)

**解**：

*放缩*（全军出击 + 统一分母）：
\\\\[
\\frac{n}{\\sqrt{n^2+n}} \\\leq x_n \\\leq \\frac{n}{\\sqrt{n^2+1}}
\\\\]

*求极限*：
\\\\[
\\lim_{n\\\to\\infty} \\frac{n}{\\sqrt{n^2+n}} = \\lim_{n\\\to\\infty} \\frac{n}{\\sqrt{n^2(1+1/n)}} = \\lim_{n\\\to\\infty} \\frac{1}{\\sqrt{1+1/n}} = 1
\\\\]
\\\\[
\\lim_{n\\\to\\infty} \\frac{n}{\\sqrt{n^2+1}} = \\lim_{n\\\to\\infty} \\frac{n}{n\\sqrt{1+1/n^2}} = 1
\\\\]

*夹逼*：上下极限均为 1，原极限 = 1。

### 例题 2（原文：夹逼定理文章-例3 低次项求和）

求 \\\\(\\lim_{n\\\to\\infty} \\left(\\frac{1}{(n+1)^2} + \\frac{1}{(n+2)^2} + \\cdots + \\frac{1}{(n+n)^2}\\right)\\\\)

**解**：

*放缩*（全军出击）：
- 每项分母最小的是 (n+1)²，最大的是 (n+n)² = (2n)²
\\\\[
\\frac{n}{(n+n)^2} \\\leq x_n \\\leq \\frac{n}{(n+1)^2}
\\\\]

*求极限*：
\\\\[
\\lim_{n\\\to\\infty} \\frac{n}{4n^2} = \\lim_{n\\\to\\infty} \\frac{1}{4n} = 0,\\\quad
\\lim_{n\\\to\\infty} \\frac{n}{n^2} = \\lim_{n\\\to\\infty} \\frac{1}{n} = 0
\\\\]

*夹逼*：上下极限均为 0，原极限 = 0。

> **注**：此处分母次数（二次）高于分子次数（一次），放缩后的上下界自然趋于 0，因此即使 I（求和下标）和 N 同阶，依然夹得住。

### 例题 3（原文：夹逼定理文章-例5 含阶乘）

求 \\\\(\\lim_{n\\\to\\infty} \\sqrt[n^2]{n!}\\\\)

**解**：

*放缩*：n! ≤ nⁿ（每个因子 ≤ n），且 n! ≥ 1（删去小于 1 的因子不成立，但 n! ≥ 1 显然）
\\\\[
1 \\\leq \\sqrt[n^2]{n!} \\\leq \\sqrt[n^2]{n^n} = n^{1/n}
\\\\]

*求极限*：
左右极限均为 1（\\\\(\\lim_{n\\\to\\infty} \\sqrt[n]{n} = 1\\\\)，故 \\\\(n^{1/n} \\\to 1\\\\)）

*夹逼*：原极限 = 1。

## 类比

**三明治类比** 🥪

你是三明治主厨，要做一份完美的三明治：

- 下层面包片 = yₙ（下界）——比如 5cm 厚
- 中间的火腿/生菜 = xₙ（待求极限的数列或函数）
- 上层面包片 = zₙ（上界）——也是 5cm 厚
- 上下层面包片 **必须一样厚**（极限相等），这样三明治（中间变量）才能被精确固定住
- 如果上下层面包片厚度不同（极限不等），三明治就会歪斜——夹不住中间变量

**核心道理**：上下界要像面包片一样精确对齐，中间的馅料才会被稳稳夹住。对齐不了？那就换一种放缩方式！

# 夹逼定理（夹逼准则）

## 类型判定
关联型 — 定理/命题，揭示条件与结论的逻辑关系

## 是什么
极限的两大存在准则之一。条件：(1) 从某一项开始，$y_n \le x_n \le z_n$（等号可有可无）；(2) $\lim\limits_{n \to \infty} y_n = \lim\limits_{n \to \infty} z_n = A$。结论：$\lim\limits_{n \to \infty} x_n = A$ 存在且等于A。

## 输入-输出空间
- **输入**: 满足条件的函数 $f(x)$（如连续、可导等）
- **输出**: 存在性结论（如存在 $\xi$ 满足等式）
- **映射关系**: 条件到结论的逻辑蕴含关系

## 正例（至少2个）
1. **场景1**: 求 $\lim\limits_{n \to \infty} \sum_{i=1}^{n} \frac{i}{n^2+n+i}$：通过放缩夹逼，极限为 $\frac{1}{2}$
2. **场景2**: 求 $\lim\limits_{n \to \infty} \sqrt[n]{1+2^n+5^n} = 5$

## 反例/边界（至少1个）
1. **常见误解/边界**: $x_n = n$ 介于 $y_n = n-\frac{1}{n}$ 和 $z_n = n+\frac{1}{n}$ 之间，且 $y_n-z_n \to 0$，但 $x_n$ 极限不存在（因为 $y_n,z_n$ 极限都不存在）

## 详细解释
也叫三明治定理。关键：两个条件缺一不可——不仅YN和ZN要无限接近，且它们的极限都必须存在且相等。反例说明$y_n-z_n \to 0$ 不能推出 $y_n,z_n$ 极限存在。

### 推导过程（★ 数学卡必须）
夹逼定理可从数列极限的 ε-N 定义直接证明：

设 $\lim y_n = \lim z_n = A$。由 ε-N 定义：
- $\forall \varepsilon > 0$，$\exists N_1$，$n > N_1$ 时 $|y_n - A| < \varepsilon$，即 $y_n > A - \varepsilon$
- $\exists N_2$，$n > N_2$ 时 $|z_n - A| < \varepsilon$，即 $z_n < A + \varepsilon$
- 由条件，$\exists N_3$，$n > N_3$ 时 $y_n \leq x_n \leq z_n$

取 $N = \max\{N_1, N_2, N_3\}$，则当 $n > N$ 时：
$$A - \varepsilon < y_n \leq x_n \leq z_n < A + \varepsilon$$
即 $|x_n - A| < \varepsilon$。由 ε-N 定义，$\lim x_n = A$。∎

这个证明的精妙之处在于利用极限存在的 ε-N 条件把三个分界点取最大值，同时满足所有不等式。

### 重要推论（★ 数学卡必须）
也叫三明治定理。关键：两个条件缺一不可——不仅YN和ZN要无限接近，且它们的极限都必须存在且相等。反例说明$y_n-z_n \to 0$ 不能推出 $y_n,z_n$ 极限存在。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\lim\limits_{n \to \infty} \sum_{i=1}^{n} \frac{i}{n^2+n+i}$：通过放缩夹逼，极限为 $\frac{1}{2}$
**解**：
$$x_n = \sum_{i=1}^{n} \frac{i}{n^2 + n + i}$$

**放缩**（统一分母，全军出击）：
- 放大：分母取最小 $n^2+n+1$，每项 $\frac{i}{n^2+n+i} \leq \frac{i}{n^2+n+1}$
- 缩小：分母取最大 $n^2+n+n = n^2+2n$，每项 $\frac{i}{n^2+n+i} \geq \frac{i}{n^2+2n}$

$$\frac{1+2+\cdots+n}{n^2+2n} \leq x_n \leq \frac{1+2+\cdots+n}{n^2+n+1}$$

**求极限**：由求和公式 $\sum_{i=1}^n i = \frac{n(n+1)}{2}$，
$$\lim_{n\to\infty} \frac{n(n+1)/2}{n^2+2n} = \lim_{n\to\infty} \frac{n^2+n}{2n^2+4n} = \frac{1}{2}$$
$$\lim_{n\to\infty} \frac{n(n+1)/2}{n^2+n+1} = \lim_{n\to\infty} \frac{n^2+n}{2n^2+2n+2} = \frac{1}{2}$$

**夹逼**：上下极限均为 $\frac{1}{2}$，由夹逼定理，原极限 $= \frac{1}{2}$。

### 一句话比喻
微分中值定理就像高速公路测速——不查每时每刻的速度，只查全程平均速度，就知道至少有一刻的瞬时速度等于平均速度。
