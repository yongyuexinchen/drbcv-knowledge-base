# 可微与可导的关系

## 类型判定
关联型 — 定理/命题，揭示逻辑关系

## 是什么
函数 $f(x)$ 在 $x_0$ 处可微的**充要条件**是 $f(x)$ 在 $x_0$ 处可导，并且 $\mathrm{d}y|_{x=x_0} = f'(x_0)\mathrm{d}x$。

**证明概要**：
- （可微 $\Rightarrow$ 可导）由 $\Delta y = A\Delta x + o(\Delta x)$ 得 $\frac{\Delta y}{\Delta x} \to A = f'(x_0)$
- （可导 $\Rightarrow$ 可微）由 $\lim_{\Delta x\to0}\frac{\Delta y}{\Delta x} = f'(x_0)$ 得 $\frac{\Delta y}{\Delta x} = f'(x_0)+\alpha$（$\alpha\to0$），即 $\Delta y = f'(x_0)\Delta x + \alpha\Delta x$，$\alpha\Delta x = o(\Delta x)$

## 输入-输出空间
- **输入**: 概念适用的对象/前提条件
- **输出**: 概念产生的结果/结论
- **映射关系**: 从输入到输出的对应关系

## 正例（至少2个）
1. **场景1**: $f(x)=x^2$ 在 $x=1$ 处：$f'(1)=2$，故可微，微分 $\mathrm{d}y = 2\mathrm{d}x$
2. **场景2**: $f(x)=|x|$ 在 $x=0$ 处：不可导 $\Rightarrow$ 不可微（角点处没有微分）
3. **场景3**: $f(x)=x^{1/3}$ 在 $x=0$ 处：$f'(0)=\infty$（不存在），故不可导 $\Rightarrow$ 不可微

## 反例/边界（至少1个）
1. **可微 $\iff$ 可导仅适用于一元函数**: 在多元函数中，可微是比偏导数存在更强的条件（可微 $\Rightarrow$ 偏导数存在，但偏导存在 $\nRightarrow$ 可微）。
2. **微分和导数是不同概念**: 导数 $f'(x_0)$ 是变化率（一个数值），微分 $\mathrm{d}y = f'(x_0)\mathrm{d}x$ 是 $\mathrm{d}x$ 的线性函数（一个无穷小量）。不要把 $\mathrm{d}y$ 和 $y'$ 混为一谈。
3. **$\mathrm{d}x$ 是自变量的微分**: 规定 $\mathrm{d}x = \Delta x$，这是一个含混但必需的记号约定。

## 详细解释
该定理有两大意义：① 将可微性的判定归结为可导性的判定；② 将微分的计算归结为导数的计算。但导数与微分是两个不同的概念：导数是变化率（比值极限），微分是函数改变量的线性主部（一个无穷小量）。

### 推导过程（★ 数学卡必须）

**方向一：可微 $\Rightarrow$ 可导**

已知 $f$ 在 $x_0$ 处可微，即存在常数 $A$ 使：
$$\Delta y = A\Delta x + o(\Delta x) \quad (\Delta x \to 0)$$

两边同除以 $\Delta x$（$\Delta x \neq 0$）：
$$\frac{\Delta y}{\Delta x} = A + \frac{o(\Delta x)}{\Delta x}$$

由于 $\lim_{\Delta x \to 0} \frac{o(\Delta x)}{\Delta x} = 0$（高阶无穷小的定义），取极限得：
$$\lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = A$$

这说明 $f'(x_0)$ 存在且等于 $A$，故 $f$ 在 $x_0$ 处可导，且 $f'(x_0) = A$。

**方向二：可导 $\Rightarrow$ 可微**

已知 $f$ 在 $x_0$ 处可导，即：
$$\lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = f'(x_0)$$

根据"极限等于常数的等价刻画"，存在一个无穷小 $\alpha = \alpha(\Delta x)$（$\alpha \to 0$ when $\Delta x \to 0$）使得：
$$\frac{\Delta y}{\Delta x} = f'(x_0) + \alpha$$

两边同乘 $\Delta x$：
$$\Delta y = f'(x_0)\Delta x + \alpha \Delta x$$

验证 $\alpha\Delta x = o(\Delta x)$：
$$\lim_{\Delta x \to 0} \frac{\alpha \Delta x}{\Delta x} = \lim_{\Delta x \to 0} \alpha = 0$$

因此 $\Delta y = f'(x_0)\Delta x + o(\Delta x)$，形式完全符合可微定义（$A = f'(x_0)$），故 $f$ 在 $x_0$ 处可微，且 $\mathrm{d}y = f'(x_0)\mathrm{d}x$。

**结论**：两个方向合在一起，证明了**一元函数中可微与可导完全等价**。

### 重要推论（★ 数学卡必须）

1. **可微性判定归约为可导性判定**：判断 $f$ 在一点是否可微，直接判断该点是否可导即可。这大大简化了可微性的验证。

2. **微分计算归约为导数计算**：要计算 $\mathrm{d}y$，只需算出 $f'(x)$，然后乘上 $\mathrm{d}x$。例如：$\mathrm{d}(\sin x) = \cos x \,\mathrm{d}x$，$\mathrm{d}(e^x) = e^x \,\mathrm{d}x$。

3. **导数记号 $\frac{\mathrm{d}y}{\mathrm{d}x}$ 的正当性**：由于 $\mathrm{d}y = f'(x)\mathrm{d}x$，反过来有 $f'(x) = \frac{\mathrm{d}y}{\mathrm{d}x}$。因此可以把导数看作微分的商（微商），这一记号的分数形式在数学上获得了正当性。

4. **不可导必然不可微**：这是可微可导等价的逆否命题，用于判定函数在尖点、角点等不可导点处同样不可微。

5. **微分概念的实际应用**：求近似值（$\Delta y \approx \mathrm{d}y$）、误差估计、微分方程的建立等，都是利用微分 $\mathrm{d}y = f'(x)\mathrm{d}x$ 作为增量的线性近似。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**: 验证 $f(x)=x^2+3x$ 在 $x=1$ 处可微，并求 $\mathrm{d}y$。
**解**: 
可导性：$f'(x)=2x+3$，$f'(1)=5$。由可微 $\iff$ 可导定理，$f$ 在 $x=1$ 处可微。
微分：$\mathrm{d}y|_{x=1} = f'(1)\mathrm{d}x = 5\,\mathrm{d}x$。
增量验证：$\Delta y = f(1+\Delta x) - f(1) = (1+\Delta x)^2 + 3(1+\Delta x) - 4 = 5\Delta x + (\Delta x)^2$，即 $\Delta y = 5\Delta x + o(\Delta x)$，与定理预测一致。

**例题2**
**题目**: 讨论 $f(x)=|x|$ 在 $x=0$ 处是否可微。
**解**:
先判断可导性：左导数 $f'_-(0)=-1$，右导数 $f'_+(0)=1$，不相等，故 $f'(0)$ 不存在。
由可微 $\iff$ 可导定理，$f'(0)$ 不存在 $\Rightarrow$ $f$ 在 $x=0$ 处不可微。
几何解释：$y=|x|$ 在 $x=0$ 处有角点，切线不唯一，不存在唯一的线性逼近，故不可微。

## 类比

### 一句话比喻
可导和可微就像一个硬币的两面（在一元函数中）——可导告诉你"变化有多快"（速度），可微告诉你"会变化多少"（路程）。它们通过 $\mathrm{d}y = f'(x)\mathrm{d}x$ 完美绑定：速度 $\times$ 时间 = 路程。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 导数 $f'(x_0)$ | 瞬时速度（路程对时间的瞬时变化率） |
| 微分 $\mathrm{d}y = f'(x)\mathrm{d}x$ | 以该速度在 $\mathrm{d}t$ 内走过的微位移 |
| 可微 $\iff$ 可导（一元） | 能写出微位移 $\iff$ 能测出瞬时速度 |
| $\Delta y \approx \mathrm{d}y$ | 小时间内的实际位移 $\approx$ 用瞬时速度估算的位移 |
