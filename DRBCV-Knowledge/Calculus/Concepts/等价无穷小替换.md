## 类型判定

这是一个 **连接级 (connection)** 概念卡。等价无穷小替换是极限计算中最高效、最常用的化简工具之一。它利用无穷小量之间的等价关系，将复杂函数替换为简单的幂函数，从而快速求解极限。理解其使用规则（何时能用、何时不能用）是正确使用的关键。

## 是什么

**等价无穷小**：设 α(x)、β(x) 是 x → x₀ 时的无穷小量（极限均为 0），若

\lim \frac{\alpha(x)}{\beta(x)} = 1

则称 α 与 β 是等价无穷小，记作 α ~ β（x → x₀）。

**核心思想**：等价的两个无穷小在趋近于 0 时的\"速度\"一样快，因此在乘除运算中可以互相替换而不改变极限。

**使用规则**：等价无穷小替换只能用于**整个函数的乘除因子**，不能直接用于加减项。

## 输入-输出空间

| 维度 | 说明 |
|------|------|
| **输入** | 极限中的复杂函数部分（如 sin x, tan x, ln(1+x), e^x-1 等） |
| **操作** | 识别 → 判断是否为乘除因子 → 替换为等价形式 → 简化计算 |
| **输出** | 简化为幂函数形式的极限 |
| **适用场景** | 0/0 型、0·∞ 型等含有无穷小量的未定式 |

## 常见等价无穷小表（x → 0 时）

### 第一组：基本等价到 x

| 原函数 | 等价形式 | 记忆口诀 |
|--------|----------|----------|
| sin x | ~ x | sin ↔ x |
| tan x | ~ x | tan ↔ x |
| arcsin x | ~ x | arcsin ↔ x |
| arctan x | ~ x | arctan ↔ x |
| e^x - 1 | ~ x | 指数减一↔自身 |
| ln(1 + x) | ~ x | 对数加一↔内部 |

### 第二组：指数/幂型

| 原函数 | 等价形式 | 说明 |
|--------|----------|------|
| a^x - 1 | ~ x·ln a | a > 0, a ≠ 1 |
| (1 + x)^α - 1 | ~ α·x | α 为任意实数（≠ 0） |
| √(1 + x) - 1 | ~ x/2 | α = 1/2 的特例 |
| (1 + x)^k - 1 | ~ kx | k 为正整数的特例 |

### 第三组：高阶等价

| 原函数 | 等价形式 | 说明 |
|--------|----------|------|
| 1 - cos x | ~ x²/2 | 涉及二阶无穷小 |
| x - ln(1 + x) | ~ x²/2 | 常用的加減组合 |
| ln(1 + x) - x | ~ -x²/2 | 同上，符号相反 |

### 第四组：三阶等价（进阶）

| 原函数 | 等价形式 |
|--------|----------|
| x - sin x | ~ x³/6 |
| arcsin x - x | ~ x³/6 |
| x - arcsin x | ~ -x³/6 |
| x - tan x | ~ -x³/3 |
| tan x - x | ~ x³/3 |
| arctan x - x | ~ -x³/3 |

### 广义化原则

以上的 x 都可以替换为任意**趋近于 0 的函数** □（称为\"框框\"或\"广义变量\"）：


\sin \square \sim \square,\quad e^{\square} - 1 \sim \square,\quad \ln(1 + \square) \sim \square,\quad \text{等等}


例如：x → 0 时，sin(x³) ~ x³，e^{x²} - 1 ~ x²。

## 正例

**例 1**（乘除因子，直接换）：

\lim_{x \to 0} \frac{\sin x \cdot \tan x}{x(1 - \cos x)} = \lim_{x \to 0} \frac{x \cdot x}{x \cdot (x²/2)} = \lim_{x \to 0} \frac{x²}{x³/2} = \infty


**例 2**（整体是乘除因子）：

\lim_{x \to 0} \frac{x - \sin x}{x³} = \lim_{x \to 0} \frac{x³/6}{x³} = \frac{1}{6}

x - sin x 作为**整体**是分子（整个函数的乘除因子），可用第四组公式代换。

## 反例/边界

**反例 1**（加减项直接换——典型错误）：

\lim_{x \to 0} \frac{\sin x - \tan x}{x³} \xrightarrow{\text{错误}} \lim_{x \to 0} \frac{x - x}{x³} = 0

**错误原因**：sin x 和 tan x 单独看都是加减项的一部分，不能各自等价到 x 后相减（精度不够，丢失了高阶项）。

**正确做法**：\frac{\sin x - \tan x}{x³} = \frac{\tan x(\cos x - 1)}{x³} = \frac{x \cdot (-x²/2)}{x³} = -\frac{1}{2}

**反例 2**（加减项中的因子——不能换）：

\lim_{x \to 0} \left(\frac{1}{x²} - \frac{\cos x}{x²}\right) \text{ 中的 cos x 不能换成 1}

因为 cos x/x² 中的 cos x 不是整个函数的乘除因子，它是加减项的一部分。

**正确的间接思路**：先通分 → \$\frac{1-\cos x}{x²} → \frac{x²/2}{x²} = 1/2\$，这不涉及在加减项中直接代换。

## 详细解释

### 为什么加减项不能直接换？

等价代换的本质是用一个更简单的函数代替原函数，这个替换在**比值趋近于 1** 的意义上\"误差很小\"。但在加减运算中，这个\"小误差\"可能被放大：

- 乘除中：\$\sin x = x + o(x)\$，小误差 o(x) 在乘除中仍是\"小量\"，不影响主项
- 加减中：\$\sin x - \tan x = (x + o(x)) - (x + o(x)) = o(x)\$，主项 x 被抵消，只剩小误差——此时用等价等于只看误差、丢了主项

**例外情况**：如果加减项在替换后**不相互抵消**（即替换后的各阶项不完全相同），则可以换。但稳妥做法是——**先拆极限，再分别对乘除因子做代换**。

### 拆极限 + 等价代换的配合策略

当遇到含加减项的分子或分母时：

1. **先判断是否能拆**：若拆开后的两项极限都存在，则拆开后分别对乘除因子做等价
2. **不能拆时**：提取公因子，或将加减组合视为整体（如 x - sin x 整体可用公式）

例如：

\lim_{x \to 0} \frac{\ln(1+2x²) + \ln(1-x²)}{x²}

直接看：ln(1+2x²) ~ 2x²，ln(1-x²) ~ -x²，二者是加减项。但可以拆开：

= \lim\frac{\ln(1+2x²)}{x²} + \lim\frac{\ln(1-x²)}{x²} = \lim\frac{2x²}{x²} + \lim\frac{-x²}{x²} = 2 - 1 = 1


### 提前求非零因子

**非零乘除因子的极限可以提前求出**：

\lim_{x \to 0} \frac{\cos x \cdot \sin x}{x} = \lim_{x \to 0} \cos x \cdot \lim_{x \to 0} \frac{\sin x}{x} = 1 \cdot 1 = 1

cos x → 1（非零），作为乘除因子可提前求极限。

## 细节备注

| 子特性 | 说明 |
|--------|------|
| 等价关系是比值极限为 1 | ~ 定义基于比值趋近 1，不是差值趋近 0 |
| 自反性/对称性/传递性 | ~ 是等价关系：α~α；α~β ⇒ β~α；α~β, β~γ ⇒ α~γ |
| 高阶无穷小截断 | 等价代换本质是取泰勒展开的第一项（最低阶项） |
| α ~ β ⇒ α - β = o(α) | 这是等价关系的等价刻画，常用于证明 |
| 加法抵消问题 | 替换后若主项抵消，则需展开到更高阶（泰勒公式） |

### 使用原则

1. **乘除因子才能替换**——这是金标准，任何时候不要违反
2. **广义化**——框框趋于 0，所有公式都适用
3. **高阶代换**——需要更高精度时用第三/四组公式
4. **先拆后换**——遇到加减项，先判断能否拆开再分别代换
5. **整体代换**——x - sin x, 1 - cos x 等组合可以作为整体代换

## 经典例题

### 例题 1（原文：期末救急速讲-例2）

求 \lim_{x \to 0} \frac{x - \sin x}{\tan x \cdot (1 - \cos x)}\\

**解**：

类型鉴定：x→0，分子→0，分母→0，0/0 型未定式。

使用等价代换（注意检查每个因子是否为乘除因子）：

- x - sin x ~ x³/6（整体是分子的乘除因子 ✓）
- tan x ~ x（整体是分母的乘除因子 ✓）
- 1 - cos x ~ x²/2（整体是分母的乘除因子 ✓）


原式 = \lim_{x \to 0} \frac{x³/6}{x \cdot (x²/2)} = \lim_{x \to 0} \frac{x³/6}{x³/2} = \frac{1/6}{1/2} = \frac{1}{3}


### 例题 2（原文：期末救急速讲-通分+等价代换）

求 \lim_{x \to 0} \frac{1}{x²} - \frac{1}{x \sin x}\\

**解**：

类型鉴定：∞ - ∞ 型未定式。

*第一步——通分*：

原式 = \lim_{x \to 0} \frac{\sin x - x}{x² \sin x}


*第二步——等价代换*：sin x ~ x，x - sin x ~ x³/6（注意这里 sin x - x ~ -x³/6）


原式 = \lim_{x \to 0} \frac{-x³/6}{x² \cdot x} = \lim_{x \to 0} \frac{-x³/6}{x³} = -\frac{1}{6}


### 例题 3（原文：期末救急速讲-拆开后换——例5 求k）

求 \lim_{x \to 1} \frac{x \ln x - (x-1)}{(x-1) \ln x}\\

**解**：

x→1 不趋于 0，令 t = x - 1 → 0：


原式 = \lim_{t \to 0} \frac{(1+t)\ln(1+t) - t}{t \cdot \ln(1+t)}


**关键一步——拆开**（检查：两项极限都存在吗？）：


= \lim_{t \to 0} \frac{t \cdot \ln(1+t)}{t \cdot \ln(1+t)} + \lim_{t \to 0} \frac{\ln(1+t) - t}{t \cdot \ln(1+t)}


前项：\$\lim \frac{t \ln(1+t)}{t \ln(1+t)} = 1\$（存在 ✓）

后项：\$\frac{\ln(1+t) - t}{t \cdot \ln(1+t)} \sim \frac{-t²/2}{t \cdot t} = -\frac{1}{2}\$（存在 ✓）

原式 = 1 + (-1/2) = 1/2。

## 类比

**杂技演员的替身类比** 🤹

想象一个杂技团拍宣传照：

- 主角（原函数 sin x）和替身（替身 x）在\"微距\"（x 极小时）看起来几乎一模一样
- 在**全景照片**中（整个函数是乘除关系），用替身代替主角，照片效果一样——观众看不出区别
- 但在**特写对比照**中（加减关系），主角和替身的微小差异就会暴露——比如 sin x 和 x 站在一起比身高，替身稍微矮一点点的差异就被看出来了
- **结论**：全场（整体乘除）可以用替身，但特写对比（加减）不能用，因为差异会被放大

## 类比

### 一句话比喻
**等价无穷小替换像找替身演员——在极限这场戏里，当 x 非常小的时候，sin x 和 x 长得几乎一模一样，可以互相替演，不影响结局（极限值）。**

### 物理映射
小角度近似：单摆在 θ→0 时 sinθ ≈ θ ——这就是等价无穷小在物理中的直接应用。
