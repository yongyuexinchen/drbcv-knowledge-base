# 不定积分 (Indefinite Integral)

## 类型判定
定义型 — 明确术语的数学定义

## 是什么
不定积分是微分的逆运算。对于函数 $f(x)$，其全体原函数 $F(x)+C$ 称为 $f(x)$ 的不定积分，记为 $\int f(x)\,dx = F(x) + C$。其中 $\int$ 为积分号，$f(x)$ 为被积函数，$x$ 为积分变量，$dx$ 为微分符号，$C$ 为任意常数。

## 输入-输出空间
- **输入**: 函数 $f(x)$（被积函数）
- **输出**: 原函数族 $F(x)+C$（不定积分）
- **映射关系**: 微分运算的逆映射

## 正例（至少2个）
1. **场景1**: $\int 2x\,dx = x^2 + C$
2. **场景2**: $\int e^x\,dx = e^x + C$

## 反例/边界（至少1个）
1. **常见误解/边界**: 忘记加 $C$ 是严重错误——不加 $C$ 意味着只写出了一个原函数，几乎漏掉了所有解。另外，$\int x^{-1}\,dx = \ln|x|+C$（不是 $\ln x+C$），因为 $x$ 可能为负。

## 详细解释
不定积分从英文 anti-derivative 理解更清晰：anti（反）+ derivative（导数）= 反导数/反求导。不定积分和微分才是真正的运算-逆运算对子：$\int f(x)\,dx$ 应理解为"谁的微分是 $f(x)\,dx$"。

### 推导过程（★ 数学卡必须）
**基本积分公式的推导**（由求导公式逆推）：

1. 由 $(x^{n+1})'=(n+1)x^n$，逆推得 $\int x^n\,dx = \frac{x^{n+1}}{n+1}+C$（$n\neq -1$）
2. 由 $(\ln|x|)'=\frac{1}{x}$，逆推得 $\int \frac{1}{x}\,dx = \ln|x|+C$
3. 由 $(e^x)'=e^x$，逆推得 $\int e^x\,dx = e^x+C$
4. 由 $(\sin x)'=\cos x$，逆推得 $\int \cos x\,dx = \sin x+C$
5. 由 $(\arctan x)'=\frac{1}{1+x^2}$，逆推得 $\int \frac{1}{1+x^2}\,dx = \arctan x+C$

### 重要推论（★ 数学卡必须）
1. **线性性**：$\int[kf(x)+lg(x)]\,dx = k\int f(x)\,dx + l\int g(x)\,dx$
2. **先积分再求导**：$\frac{d}{dx}\left[\int f(x)\,dx\right] = f(x)$
3. **先求导再积分**：$\int F'(x)\,dx = F(x)+C$（即 $\int dF = F+C$）
4. 积分号与微分号 $d$ 具有"抵消感"：$\int dF = F+C$

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int(\sqrt{x}\cdot x^2 - 5)\,dx$
**解**：
$$\int(\sqrt{x}\cdot x^2 - 5)\,dx = \int(x^{5/2} - 5x^{1/2})\,dx$$
$$= \frac{x^{7/2}}{7/2} - 5\cdot\frac{x^{3/2}}{3/2} + C = \frac{2}{7}x^{7/2} - \frac{10}{3}x^{3/2} + C$$

**例题2**
**题目**：求 $\int(2e^x + \frac{3}{x})\,dx$
**解**：
$$\int(2e^x + \frac{3}{x})\,dx = 2\int e^x\,dx + 3\int\frac{1}{x}\,dx = 2e^x + 3\ln|x| + C$$

## 类比

### 一句话比喻
不定积分就像"收租倒推"——知道每套房收了多少租金，要反推这些钱来自哪几套房，反向操作比正向难。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $f(x)$ | 瞬时速度 |
| $\int f(x)\,dx$ | 由速度还原位移 |
| $F(x)$ | 一个可能的位移函数 |
| $C$ | 位移的起始位置不确定 |
| $f(x)\,dx$ | 无穷小位移的累加 |
