# 牛顿-莱布尼茨公式

## 类型判定
系统型 — 它不是单一技巧，而是微积分的**基本定理**，把定积分（黎曼和的极限）和不定积分（原函数）这两个看似无关的概念钉在了一起。

## 是什么

若 $f(x)$ 在 $[a,b]$ 上连续，$F(x)$ 是它的任意一个原函数（$F'(x)=f(x)$），则：

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

常用记法：

$$\int_a^b f(x)\,dx = F(x)\Big|_a^b = \big[F(x)\big]_a^b$$

**一句话**：求曲边梯形面积 → 找原函数 → 上限减下限。无限分割求和变成两个点的函数值相减。

## 输入-输出空间

| 输入 | 输出 |
|------|------|
| $f(x)$（被积函数）+ $[a,b]$（积分区间） | 一个数值 = 曲边梯形面积 |
| 需要找到 $F(x)$ 满足 $F'=f$ | $F(b)-F(a)$ |

## 正例（≥2个）

1. $\int_0^1 x^2\,dx$：原函数 $F(x)=\frac{1}{3}x^3$，$F(1)-F(0)=\frac{1}{3}-0=\frac{1}{3}$。抛物线 $y=x^2$ 在 $[0,1]$ 下的面积是 $1/3$。

2. $\int_0^\pi \sin x\,dx$：原函数 $F(x)=-\cos x$，$F(\pi)-F(0)=(-\cos\pi)-(-\cos 0)=1+1=2$。正弦波一个半拱的面积恰好是 2。

## 反例/边界（≥1个）

- $f(x)$ 必须有原函数且可积。$\int_{-1}^1 \frac{1}{x}\,dx$ 不能用牛莱公式直接代，因为 $x=0$ 处函数无定义——这是**反常积分**，要取极限。
- 原函数不是唯一的——$F(x)+C$ 都是一族，但牛莱公式里常数 $C$ 会抵消：$(F(b)+C)-(F(a)+C)=F(b)-F(a)$。选哪个原函数都一样。

## 详细解释

### 为什么这个公式是革命性的？

在牛莱之前，求面积只能靠分割→近似→求和→取极限（黎曼和的四步法），每次都要重新做这个极限过程。牛顿和莱布尼茨发现：**这个极限过程的结果，恰好等于原函数在两端点的差值**。

证明思路（微积分基本定理的两部分）：

**第一部分**：定义变上限积分 $\Phi(x)=\int_a^x f(t)\,dt$。可以证明 $\Phi'(x)=f(x)$。也就是说，变上限积分本身就是 $f$ 的一个原函数。

**第二部分**：设 $F(x)$ 是 $f(x)$ 的任一原函数，则 $F(x)=\Phi(x)+C$。于是 $\int_a^b f(x)\,dx=\Phi(b)-\Phi(a)=F(b)-F(a)$。

### 物理直觉

$$
\begin{aligned}
\text{速度函数 } v(t) &\xrightarrow{\text{积分}} \text{位移 } s(t) \quad (\text{不定积分}) \\
\int_{t_1}^{t_2} v(t)\,dt &= s(t_2)-s(t_1) \quad (\text{牛莱公式})
\end{aligned}
$$

定积分求总位移 = 路程函数在终点和起点的差值。不需要把每一秒的速度加起来。

## 细节备注

### 子特性

| 特性 | 说明 |
|------|------|
| 原函数不唯一 | $F(x)+C$ 都是原函数，但代入牛莱公式后 $C$ 抵消 |
| 连续性条件 | $f$ 在 $[a,b]$ 上连续是充分条件（不是必要条件） |
| 记法 | $F(x)\big|_a^b$ 或 $[F(x)]_a^b$，先代上限再减下限 |

### 使用原则
- 第一步永远是找原函数（不定积分的基本功）
- 上下限代入时注意符号：$F(b)-F(a)$，先上后下
- 如果 $f$ 有间断点，拆成多段分别算

## 经典例题

**例 1**：计算 $\int_0^2 (3x^2-2x+1)\,dx$

解：原函数 $F(x)=x^3-x^2+x$。
$$F(2)-F(0)=(8-4+2)-(0-0+0)=6$$

**例 2**：计算 $\int_0^{\pi/2} \cos x\,dx$

解：原函数 $F(x)=\sin x$。
$$F(\tfrac{\pi}{2})-F(0)=\sin\tfrac{\pi}{2}-\sin 0=1-0=1$$

**例 3**：计算 $\int_1^e \frac{1}{x}\,dx$

解：原函数 $F(x)=\ln|x|$。在 $[1,e]$ 上 $x>0$，所以 $F(x)=\ln x$。
$$F(e)-F(1)=\ln e-\ln 1=1-0=1$$

## 类比

### 物理映射

| 物理 | 数学 |
|------|------|
| 速度函数 $v(t)$ | 被积函数 $f(x)$ |
| 路程函数 $s(t)$（$s'=v$） | 原函数 $F(x)$（$F'=f$） |
| 总位移 = $\int_{t_1}^{t_2}v(t)dt$ | 定积分 = $\int_a^b f(x)dx$ |
| $s(t_2)-s(t_1)$ | $F(b)-F(a)$ |

### 一句话比喻

**牛莱公式是微积分的「$E=mc^2$」——一个简洁到不可思议的减法，替代了无限分割求和的极限噩梦。** 就像你不用一帧一帧数监控录像来算走了多远，直接看终点里程减起点里程。

# ⬜ 牛顿-莱布尼茨公式(Newton-Leibniz)

## 类型判定
**连接型** — 输入连续函数f在[a,b]上的原函数F→输出定积分值F(b)-F(a)

## 是什么
定积分计算的基本公式。如果f(x)在[a,b]上连续，F(x)是f(x)的一个原函数，则∫_a^b f(x)dx = F(b) - F(a)。把定积分转化为"求原函数再代值"。

## 输入-输出空间
- **输入**: 被积函数f + 原函数F + 区间[a,b]
- **输出**: 一个确定的数值
- **映射关系**: 函数→原函数→区间端点代入相减

## 正例
1. **场景A**: ∫_0^√3a dx/(a²+x²) = (1/a)arctan(x/a)|_0^√3a = (1/a)(π/3 - 0) = π/(3a)
2. **场景B**: 先求不定积分∫x ln x dx = (1/4)x²(2ln x - 1)，再代上下限1到e

## 反例/边界
1. **常见误解**: 不是"先算不定积分再加C"——C会被上下限抵消，原函数只取一个即可。
2. **边界**: 被积函数在区间内不连续时（如瑕积分）不能直接用，需用反常积分处理。

## 详细解释
牛莱公式把"求面积"这个几何问题转化为"求原函数"这个代数问题。是微积分基本定理的核心内容。使用条件：f在[a,b]上连续。定积分的三大基本方法：牛莱公式、换元法、分部积分法。
