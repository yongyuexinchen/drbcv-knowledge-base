# 微分方程的特解

## 类型判定
连接型 — 输入微分方程 + 初始条件，输出唯一确定的函数，是从一族曲线中选出特定的那一条。

## 是什么
特解（Particular Solution）是满足微分方程**且满足特定初始条件**（或边界条件）的唯一解。它从通解族中通过代入初始条件确定所有任意常数的值，从而锁定一条具体的函数曲线。**第一步求通解，第二步代初始条件定常数。**

## 输入-输出空间
- **输入**：微分方程 + 初始条件（如 $y(0)=1$、$y'(0)=0$）
- **输出**：唯一确定的函数（所有常数已被具体数值取代）

## 正例（≥2个）
1. **一阶 + 一个初始条件**：$\begin{cases} y' = 2x \\ y(1) = 3 \end{cases}$ → 通解 $y = x^2 + C$ → 代入 $3 = 1^2 + C$ → $C=2$ → 特解 $y = x^2 + 2$
2. **二阶 + 两个初始条件**：$\begin{cases} y'' + y = 0 \\ y(0) = 1, y'(0) = 0 \end{cases}$ → 通解 $y = C_1\cos x + C_2\sin x$ → 代入得 $C_1=1, C_2=0$ → 特解 $y = \cos x$
3. **物理场景**：自由落体 $\frac{d^2s}{dt^2} = -g$，初始位置 $s(0)=h$，初速度 $v(0)=0$ → 特解 $s = h - \frac{1}{2}gt^2$

## 反例/边界（≥1个）
- 初始条件个数不够 → 常数定不完 → 仍是通解，不是特解
- 初始条件个数超过阶数 → 可能无解（过约束）
- 初始条件与方程矛盾 → 无特解（如 $y' = \frac{1}{x}$ 且要求 $y(0)=1$，在 $x=0$ 无定义）

## 详细解释

### 从通解到特解的两步法
```
第一步：求通解（含 n 个任意常数）
    ↓
第二步：代入 n 个初始条件 → 列方程组 → 解出常数值 → 特解
```

### 几何含义
通解 $y = x^2 + C$ 是一族抛物线。初始条件 $y(1)=3$ 的意思是"曲线必须经过点 $(1,3)$"，这在平面上**唯一确定**了一条曲线——即 $y = x^2 + 2$。

### 特解 vs 通解 vs 奇解

| 概念 | 常数 | 个数 | 说明 |
|------|------|------|------|
| 通解 | 任意常数 | 一族（无穷多） | 微分方程的"全部正规解" |
| 特解 | 定值 | 一个 | 满足初始条件的唯一解 |
| 奇解 | 无 | 可能一个 | 不在通解族中，但满足方程（非线性方程才可能出现） |

### 生活类比
特解像**从一叠同款 T 恤中挑出你的尺码**——通解是所有尺码（S/M/L/XL），初始条件就是你的身材数据，特解是刚好合身的那一件。没有初始条件，你拿到的是一叠衣服（通解）；有了身材数据，裁缝（两步法）给你唯一那件（特解）。
