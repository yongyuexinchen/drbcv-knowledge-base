# 基本求导公式

## 类型判定
连接模型 — 输入自变量值，输出该点导数值，是基本初等函数的求导映射规则。

## 是什么
基本求导公式是指五类基本初等函数（幂函数、指数函数、对数函数、三角函数、反三角函数）的导数公式。它们是整个微积分求导运算的基础，如同乘法口诀表之于算术。

## 输入-输出空间
- **输入**: 自变量 x（在定义域内）
- **输出**: 导函数值
- **映射关系**: 映射关系 — 每个基本初等函数对应唯一的求导规则

## 正例
1. **幂函数求导**: $f(x) = x^3$ ⇒ $f'(x) = 3x^2$，即指数下移一位\n2. **指数函数求导**: $f(x) = 2^x$ ⇒ $f'(x) = 2^x \ln 2$，特别地 $e^x$ 导数为其自身

## 反例/边界
1. **常见误解**: 幂指函数（底数和指数都变）不能直接用幂函数公式或指数公式，需化为 $e^{\text{指数}\cdot\ln(\text{底数})}$ 或用对数求导法。

## 详细解释

### 基本初等函数求导公式表

| 函数 | 导数 | 备注 |
|------|------|------|
| $C$（常数） | $0$ | 常数的变化率为零 |
| $x^\alpha$（幂函数） | $\alpha x^{\alpha-1}$ | $\alpha$ 可为任意实数 |
| $a^x$（指数函数） | $a^x \ln a$ | 特别 $e^x$ 导数为自身 |
| $\log_a x$（对数函数） | $\dfrac{1}{x\ln a}$ | $\ln \lvertx\rvert$ 导数同为 $\dfrac{1}{x}$ |
| $\sin x$ | $\cos x$ | |
| $\cos x$ | $-\sin x$ | |
| $\tan x$ | $\sec^2 x = \dfrac{1}{\cos^2 x}$ | 由 $\dfrac{\sin x}{\cos x}$ 用商法则推导 |
| $\cot x$ | $-\csc^2 x = -\dfrac{1}{\sin^2 x}$ | |
| $\sec x$ | $\sec x \tan x$ | $\sec x = \dfrac{1}{\cos x}$ |
| $\csc x$ | $-\csc x \cot x$ | $\csc x = \dfrac{1}{\sin x}$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ | $x \in (-1,1)$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ | $x \in (-1,1)$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ | |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$ | |

### 公式推导思路

基本初等函数公式的依赖链：
- 指数函数 $a^x$ 和 $\sin x$ 可由导数**定义**直接推导
- 对数函数 $\log_a x$ 可由指数函数的**反函数求导法则**得出
- $\cos x$ 可由 $\sin(x+\frac{\pi}{2})$ 的**链式法则**得出
- 其余三角函数的导数可由 $\sin x$、$\cos x$ 经**四则运算法则**得出
- 反三角函数的导数可由对应三角函数的**反函数求导法则**得出

## 细节备注

### 对数函数导数的记忆
幂函数公式 $x^\alpha$ 的导数中，只需记住 $(\ln x)' = \frac{1}{x}$，而 $\log_a x = \frac{\ln x}{\ln a}$ 可由商法则推导。

### $\ln|x|$ 的导数
对 $x<0$，$\ln(-x)$ 复合求导得 $\frac{1}{-x}\cdot(-1) = \frac{1}{x}$，故 $\ln|x|$ 的导数恒为 $\frac{1}{x}$。

## 类比

### 一句话比喻
**基本求导公式像乘法口诀表——背下来就能快速口算，不用每次都从定义推导。** 看到 x³ 求导就脱口而出 3x²，就像看到 7×8 脱口而出 56。

### 物理映射
| 函数 | 导数 | 物理含义 |
|------|------|---------|
| x² | 2x | 匀加速运动的位移→速度 |
| sin x | cos x | 简谐振动的位置→速度 |
| eˣ | eˣ | 指数增长：增长的速度等于当前的值 |
| ln x | 1/x | 对数增长：增速越来越慢 |
