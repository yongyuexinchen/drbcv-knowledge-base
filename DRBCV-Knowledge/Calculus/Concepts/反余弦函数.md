# 反余弦函数 $\arccos X$

## 类型判定
判别型 — 区分/定义概念，建立判断标准

## 是什么
$Y = \arccos X$ 是 $Y = \cos X$ 在 $X \in [0, \pi]$（主值区间）上的反函数。输入余弦值 $X \in [-1, 1]$，输出对应弧度 $Y \in [0, \pi]$。

## 输入-输出空间
- **输入**: $X \in [-1, 1]$（余弦值）
- **输出**: $Y \in [0, \pi]$（对应弧度）
- **映射关系**: $\arccos: [-1,1] \to [0,\pi]$，余弦值 $\mapsto$ 角度

## 正例（至少2个）
1. **场景1**: $\arccos 1 = 0$
2. **场景2**: $\arccos(-1) = \pi$
3. **场景3**: $\arccos 0 = \frac{\pi}{2}$

## 反例/边界（至少1个）
1. **常见误解/边界**: 
   - **值域陷阱**：$\arccos(\cos x) = x$ 仅当 $x \in [0,\pi]$ 时成立。例如 $\arccos(\cos(-\frac{\pi}{3})) = \arccos(\frac{1}{2}) = \frac{\pi}{3} \neq -\frac{\pi}{3}$。
   - **单调性**：$\arccos x$ 严格单调递减（$\arccos' x = -\frac{1}{\sqrt{1-x^2}}$），这一点与 $\arcsin$ 不同。
   - **非奇非偶**：$\arccos(-x) = \pi - \arccos x \neq \pm \arccos x$，$\arccos x$ 不是奇函数也不是偶函数。

## 详细解释
$\arccos$ 的主值区间为 $[0, \pi]$，与 $\arcsin$ 的 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 不同。

### 推导过程（★ 数学卡必须）
**反函数定义推导**：

$\cos x$ 在 $[0,\pi]$ 上严格单调递减（$\cos' x = -\sin x < 0$），值域为 $[-1, 1]$。

$\arccos y$ 定义为：唯一的 $x \in [0,\pi]$ 使 $\cos x = y$。

**导数推导**（反函数求导法则）：

设 $y = \arccos x$，则 $x = \cos y$，$y \in [0,\pi]$。

$$\frac{\,dy}{\,dx} = \frac{1}{\frac{\,dx}{\,dy}} = \frac{1}{-\sin y}$$

由 $\sin^2 y + \cos^2 y = 1$，$\sin y = \sqrt{1 - \cos^2 y} = \sqrt{1 - x^2}$

（当 $y \in [0,\pi]$ 时 $\sin y \ge 0$，取正号）

$$\therefore \boxed{\frac{d}{\,dx}\arccos x = -\frac{1}{\sqrt{1-x^2}}}$$

**与 $\arcsin$ 的关系**：

由 $\sin y = \cos(\frac{\pi}{2} - y)$ 可证：$\arcsin x + \arccos x = \frac{\pi}{2}$

由此可得：$\arccos' x = -\arcsin' x$。

### 重要推论（★ 数学卡必须）
1. **恒等式**：
   - $\cos(\arccos x) = x$（$x \in [-1,1]$）
   - $\arccos(\cos x) = x$（仅当 $x \in [0,\pi]$）
2. **对称性**：$\arccos(-x) = \pi - \arccos x$
3. **与 $\arcsin$ 互补**：$\arcsin x + \arccos x = \frac{\pi}{2}$（核心关系）
4. **不定积分**：$\int -\frac{1}{\sqrt{1-x^2}}\,dx = \arccos x + C$

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\arccos 1$ 的值。

**解**：在 $[0,\pi]$ 上，$\cos(0) = 1$，且 $0$ 是此区间内唯一满足条件的值。

$$\arccos 1 = 0$$

**例题2**
**题目**：求 $\arccos(-1)$ 的值。

**解**：在 $[0,\pi]$ 上，$\cos(\pi) = -1$。

$$\arccos(-1) = \pi$$

**例题3**
**题目**：求 $\arccos(\cos \frac{5\pi}{3})$ 的值。

**解**：$\cos \frac{5\pi}{3} = \cos(2\pi - \frac{\pi}{3}) = \cos \frac{\pi}{3} = \frac{1}{2}$

在 $[0,\pi]$ 上，$\cos(\frac{\pi}{3}) = \frac{1}{2}$。

$$\arccos(\cos \frac{5\pi}{3}) = \arccos \frac{1}{2} = \frac{\pi}{3}$$

注意输出值是 $\frac{\pi}{3}$（在 $[0,\pi]$ 内），而原输入 $\frac{5\pi}{3}$ 不在主值区间内。

## 类比

### 一句话比喻
$\arccos$ 就像从影子推算太阳的角度——已知地面上一个影子（余弦值），反推出太阳在 $0$ 到 $180°$ 这个范围内处于哪个位置。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $\arccos x$ | 已知力在位移方向上的投影比分（$x = \cos\theta$），求夹角 $\theta$ |
| 值域 $[0,\pi]$ | 夹角限制在 $0°$ 到 $180°$ 之间 |
| $\arccos x + \arcsin x = \frac{\pi}{2}$ | 直角三角形两锐角互余 |
| 导数负号 $-\frac{1}{\sqrt{1-x^2}}$ | 余弦值增大 → 角度减小（单调递减） |
