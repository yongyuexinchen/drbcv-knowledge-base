# 三角函数的积分

## 类型判定
程序模型 — 输入包含三角函数幂、乘积或有理式的被积函数（如 $\sin^m x \cos^n x$、$\tan^m x \sec^n x$、$R(\sin x, \cos x)$），利用三角恒等式化简后逐项积分。

## 是什么
三角函数的积分（Integration of Trigonometric Functions）是运用三角恒等式（倍角公式、降幂公式、和差化积等）将复杂的三角函数表达式化简为标准形式，再使用基本积分公式或凑微分法求积分的方法体系。

核心策略是**降次降幂**与**统一变量**——通过恒等式将高次幂转为低次幂，或将不同三角函数的乘积转化为单一函数的形式。

## 输入-输出空间
- **输入**: 三角函数表达式 $\sin^m x \cos^n x$、$\tan^m x \sec^n x$、$\cot^m x \csc^n x$、$R(\sin x, \cos x)$ 等
- **输出**: 原函数（通常含三角函数、对数函数等组合）+ $C$
- **变换**: 变换过程 — 复杂三角函数表达式 $\xrightarrow{\text{恒等式化简}}$ 可积分形式 $\xrightarrow{\text{基本公式/凑微分}}$ 原函数

## 正例
1. **余弦的平方**：
   $$ \int \cos^2 x \, dx = \int \frac{1 + \cos 2x}{2} \, dx = \frac{x}{2} + \frac{\sin 2x}{4} + C $$
   使用降幂公式 $\cos^2 x = \frac{1+\cos 2x}{2}$。

2. **正弦立方**：
   $$ \int \sin^3 x \, dx = \int \sin x (1 - \cos^2 x) \, dx = \int (\sin x - \sin x \cos^2 x) \, dx = -\cos x + \frac{1}{3}\cos^3 x + C $$
   使用 $\sin^2 x = 1 - \cos^2 x$ 后凑微分。

3. **$\sec x$ 的积分（重要结果）**：
   $$ \int \sec x \, dx = \ln|\sec x + \tan x| + C $$
   巧法：分子分母同乘 $(\sec x + \tan x)$，凑微分得 $\int \frac{d(\sec x + \tan x)}{\sec x + \tan x}$。

4. **$\tan^3 x \sec^3 x$ 型**：
   $$ \int \tan^3 x \sec^3 x \, dx = \int \tan^2 x \sec^2 x \cdot (\tan x \sec x \, dx) $$
   $$ = \int (\sec^2 x - 1) \sec^2 x \, d(\sec x) = \frac{\sec^5 x}{5} - \frac{\sec^3 x}{3} + C $$

## 反例/边界
1. **万能代换的代价**：万能代换 $t = \tan\frac{x}{2}$ 可以统一处理所有三角有理式 $R(\sin x, \cos x)$，但常导致较复杂的有理函数积分，应优先考虑更简单的方法。
2. **降幂公式方向选择**：对 $\int \cos^4 x \, dx$，反复使用降幂公式虽然可行但过程冗长，可结合 $\cos^4 x = (\cos^2 x)^2$ 用两次降幂公式。
3. **$\sec x$ 和 $\csc x$ 积分容易遗忘**：$\int \sec x \, dx$ 和 $\int \csc x \, dx$ 的结果不是初等简单函数，需要特殊技巧记忆。

## 详细解释

### 三角积分的主要方法分类

#### 类型1：$\int \sin^m x \cos^n x \, dx$（正弦和余弦的幂积）

| 情况 | 处理方法 | 例子 |
|:----:|---------|------|
| $m$ 为奇数 | 拆分一个 $\sin x$ 因子，剩余 $\sin^{m-1} x$ 用 $\sin^2 = 1-\cos^2$ 化为 $\cos$ 函数，再凑微分 $d(\cos x) = -\sin x \, dx$ | $\int \sin^3 x \cos^2 x \, dx$ |
| $n$ 为奇数 | 拆分一个 $\cos x$ 因子，剩余 $\cos^{n-1} x$ 用 $\cos^2 = 1-\sin^2$ 化为 $\sin$ 函数，再凑微分 $d(\sin x) = \cos x \, dx$ | $\int \sin^2 x \cos^3 x \, dx$ |
| $m,n$ 均为偶数 | 使用降幂公式 $\sin^2 x = \frac{1-\cos 2x}{2}$、$\cos^2 x = \frac{1+\cos 2x}{2}$ | $\int \sin^2 x \cos^2 x \, dx$ |

#### 类型2：$\int \tan^m x \sec^n x \, dx$（正切和正割的幂积）

| 情况 | 处理方法 |
|:----:|---------|
| $n$ 为偶数 | 拆分 $\sec^2 x$ 凑 $d(\tan x)$，剩余 $\sec^{n-2} x$ 用 $\sec^2 = 1+\tan^2$ 化为 $\tan$ 函数 |
| $m$ 为奇数 | 拆分 $\sec x \tan x$ 凑 $d(\sec x)$，剩余 $\tan^{m-1} x$ 用 $\tan^2 = \sec^2 - 1$ 化为 $\sec$ 函数 |
| $m$ 偶 $n$ 奇 | 化为 $\sin$ 和 $\cos$ 的形式或用递推公式 |

#### 类型3：万能代换 $t = \tan\frac{x}{2}$

万能代换适用于一般的三角有理式 $R(\sin x, \cos x)$：

$$ \sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2}{1+t^2} dt $$

代入后原积分变为 $t$ 的有理函数积分。

### 常用三角恒等式速查

| 名称 | 公式 |
|------|------|
| 降幂公式 | $\sin^2 x = \frac{1-\cos 2x}{2}$，$\cos^2 x = \frac{1+\cos 2x}{2}$ |
| 降幂进阶 | $\sin^3 x = \frac{3\sin x - \sin 3x}{4}$，$\cos^3 x = \frac{3\cos x + \cos 3x}{4}$ |
| 平方关系 | $\sin^2 x + \cos^2 x = 1$，$\tan^2 x + 1 = \sec^2 x$，$1 + \cot^2 x = \csc^2 x$ |
| 倍角公式 | $\sin 2x = 2\sin x \cos x$，$\cos 2x = \cos^2 x - \sin^2 x$ |
| 积化和差 | $\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$ |
| 和差化积 | $\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$ |

### 生活类比：乐器合奏的乐谱改编

想象你是乐团指挥（积分计算者），面对一首复杂的合奏曲谱（三角函数的积分表达式）：

- **幂次太高**：就像小提琴手需要演奏超高把位的音符——你使用降幂公式，就像把高八度的音符降低到正常音域（$\sin^2 x = \frac{1-\cos 2x}{2}$就是把二次变成一次）。**高音太刺耳，降一个八度就好听了。**

- **不同乐器混响**：$\sin x$ 和 $\cos x$ 就像小提琴和长笛的不同音色——通过恒等式（$\sin^2 x + \cos^2 x = 1$等），你将合奏转化为单一乐器的独奏。

- **万能代换**：就像把所有乐器都换成钢琴——虽然能统一处理所有乐谱，但钢琴谱可能很复杂（万能代换后的有理函数积分），不如直接保留原乐器简单。

### 另一种类比：拼图

处理三角函数积分就像完成一幅拼图：

1. **观察形状**（识别类型）——是 $\sin^m \cos^n$ 还是 $\tan^m \sec^n$？
2. **分类整理**（用恒等式改写）——把拼图按颜色分类，把复杂的形状整理成标准块
3. **拼合**（代入公式积分）——把标准块拼到正确位置

每次用恒等式降次，就像把一块难拼的异形图块变成了标准矩形拼图块。

## 细节备注

### 需要特殊记忆的三角积分结果

以下三个积分结果在各种练习和考试中频繁出现，建议单独记忆：

$$ \int \sec x \, dx = \ln|\sec x + \tan x| + C $$
$$ \int \csc x \, dx = \ln|\csc x - \cot x| + C $$
$$ \int \sec^3 x \, dx = \frac{1}{2}(\sec x \tan x + \ln|\sec x + \tan x|) + C $$

### \(\sec x\) 积分的推导技巧

$$ \int \sec x \, dx = \int \frac{\sec x(\sec x + \tan x)}{\sec x + \tan x} \, dx = \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x} \, dx = \int \frac{d(\sec x + \tan x)}{\sec x + \tan x} = \ln|\sec x + \tan x| + C $$

这被称为"最巧妙的凑微分"之一。

### 三角积分解题步骤总结

1. **看奇偶**：检查 $\sin$ 和 $\cos$（或 $\tan$ 和 $\sec$）的幂次奇偶性
2. **选方法**：
   - 奇数幂 → 拆分补偶后凑微分
   - 偶数幂 → 降幂公式或倍角公式
3. **若失效**：考虑积化和差（对乘积型）或万能代换（最后手段）

## 类比

### 一句话比喻
**三角函数积分像乐器合奏——降幂是把高音降到中音区（sin²x → (1-cos2x)/2），万能代换是把所有乐器统一换成钢琴弹（t = tan(x/2)），化成有理函数后再积。**

### 物理映射
| 技巧 | 公式 | 物理类比 |
|------|------|---------|
| sin 奇次幂 | 拆一个 sin x 凑微分 | 从合唱中分离出领唱 |
| cos 偶次幂 | 用 cos²x = (1+cos2x)/2 | 把和弦分解成单音 |
| sin·cos 混合 | 积化和差 | 把两种乐器合奏变成一种 |

### 区间再现与点火公式

对于 $\int_0^{\pi/2} \sin^n x\,dx$ 或 $\int_0^{\pi/2} \cos^n x\,dx$ 这类定积分，三角函数积分还有两件利器：

| 工具 | 作用 | 来源 |
|------|------|------|
| [[区间再现公式]] | 证明 $\int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx$ | 定积分换元法 |
| [[点火公式(Wallis公式)]] | 直接给出 $\int_0^{\pi/2} \sin^n x\,dx$ 的精确值 | 区间再现 + 分部积分 |

**关系链**：三角恒等式 → 区间再现 → 分部积分 → 点火公式递推 → 精确数值
