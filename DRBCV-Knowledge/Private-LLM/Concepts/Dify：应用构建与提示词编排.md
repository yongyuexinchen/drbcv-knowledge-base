# Dify：应用构建与提示词编排

## 类型判定
[Procedure — 核心是「怎么在 Dify 上构建对话型和文本生成型应用」，包含完整的编排步骤和配置方法]

## 类比 ★
### 一句话比喻
> 在 Dify 上构建应用就像「给工厂设置两条生产线」——对话型应用是「一对一接待台」（来一个客户聊一轮，但记得上次聊了啥），文本生成型应用是「批量印刷车间」（你给一叠订单模板，它一口气全印完，但每次印刷彼此独立）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 对话型应用 (Chat) | 接待台——有记忆，你问啥它回啥，可以连续聊 |
| 文本生成型应用 (Text Gen) | 印刷车间——一次交互，批量产出，无历史上下文 |
| System 提示词 | 员工岗位说明书——定义「你是谁、你的工作流程」 |
| User 提示词 | 客户当天点的菜单——每次对话都不同 |
| 变量（Variable） | 菜单上的填空栏——「把[]翻译成[]」两个空让用户填 |
| 下拉选项变量 | 预设菜单——不用手填，点选「中→英」「中→日」即可 |
| 知识库上下文 | 员工背后的参考资料架——回答问题前先去翻一下 |
| 批量运行 | 给印刷机塞一叠订单，它全部印完再还给你 |

## 是什么
Dify 提供了两种应用构建模式——对话型应用（Chat）和文本生成型应用（Text Generation）。通过提示词编排界面，用户可以设置 System 提示词（角色和工作流）、User 提示词（单次交互内容）、自定义变量（文本/段落/下拉选项），并结合知识库（RAG）和功能开关（内容审查、语音转文字、引用归属等）构建完整的 AI 应用。文本生成型应用还支持批量运行——上传 CSV 模板后一次性处理多条数据。

## 输入-输出空间
- **输入**: 创建应用时输入提示词 + 变量定义 + 知识库绑定；运行时输入用户问题 / 批量 CSV 模板
- **输出**: 对话型返回流式回复（含引用来源）；文本生成型返回单次结果或批量 CSV 输出
- **前置条件**: 模型 API 已配置；知识库已创建并向量化；应用已点击「发布」

## 正例（≥2 个）
1. **翻译官应用**: 创建对话型应用，System 提示词 =「你是友好翻译官，请将用户语言翻译成目标语言」，设两个下拉变量「源语种」「目标语种」，用户选「英语→日语」后输入文本即可翻译。变量用下拉选项替代手动输入，用户体验极佳。
2. **批量保密合同审核**: 创建文本生成型应用，System 提示词 =「你是资深律师，阅读合同后从合同范围、保密义务、期限、违约责任、争议解决五个维度回答」，下载模板填入 5 份合同 → 上传批量运行 → 一次性输出全部审核报告。

## 反例/边界（≥1 个）
1. **滥用 User 提示词导致对话干扰**: User 提示词每次都会和用户输入拼接后发给模型，如果在 User 里写了很长的限制条件，可能干扰用户的实际输入——原则是：角色和工作流程放 System，单次特殊要求才放 User。
2. **文本生成型应用不适合多轮对话**: 文本生成型每次交互是独立的，没有历史记忆。如果企业需要「用户先问 A，再基于 A 的答案追问 B」的场景，必须用对话型——文本生成型只适合 SOP 固定的一次性任务。
3. **知识库检索阈值设置不当**: 阈值设太高（如 0.9）可能检索不到相关段落，设太低（如 0.1）会返回大量噪音段落——建议 0.5 左右，并开启 Top-K=3 控制返回段落数。

## 详细解释

### 两种应用模式对比

| 维度 | 对话型应用 (Chat) | 文本生成型应用 (Text Gen) |
|------|-------------------|--------------------------|
| 交互模式 | 多轮对话，有历史上下文 | 单次交互，每轮独立 |
| 适用场景 | 智能客服、知识库问答、翻译 | 批量文档生成、合同审核、SOP 标准化流程 |
| 数据输入 | 用户逐句输入 | 用户填写变量或上传 CSV 批量 |
| 核心优势 | 灵活、有记忆 | 标准化、可批量、符合企业 SOP |
| 企业价值 | To C 客服、内部问答 | To B 流程自动化 |

### 提示词编排核心组件

```
┌─────────────────────────────────────┐
│  System 提示词（角色+工作流+限定）    │
│  "你是一个友好的翻译官..."           │
├─────────────────────────────────────┤
│  变量 {{K1}} {{K2}}                  │
│  类型: 文本 / 段落 / 下拉选项        │
├─────────────────────────────────────┤
│  上下文（知识库检索结果，可选）        │
│  {{#context#}}                      │
├─────────────────────────────────────┤
│  功能开关:                           │
│  ☑ 开场白  ☑ 引用归属               │
│  ☐ 内容审查  ☐ 语音转文字           │
│  ☐ 下一步问题建议                    │
└─────────────────────────────────────┘
```

### 知识库配置要点

| 参数 | 含义 | 建议值 |
|------|------|--------|
| 分段方式 | 自动/自定义分段 | 不熟悉文档用自动；熟悉用自定义（设分段标识符如 `\n`） |
| 分段最大长度 | 每段最多多少字 | 500（默认） |
| 块重叠 | 相邻块重叠字数 | 50（保证语义连续性） |
| Top-K | 检索返回几个最相似段落 | 3 |
| 阈值 (Score) | 相似度最低分数 | 0.5 |
| 检索方式 | 向量/全文/混合 | 无梯子用向量；有梯子用混合+Rerank |

### 批量运行流程（文本生成型独有）
1. 创建应用并配置变量 → 发布
2. 在应用页面点击「批量运行」→ 下载 CSV 模板
3. 按模板列名填入多条数据 → 上传
4. 系统逐行处理，完成后可下载结果 CSV
