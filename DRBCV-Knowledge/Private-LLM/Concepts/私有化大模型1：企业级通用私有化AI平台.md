# 私有化大模型1：企业级通用私有化AI平台

## 类型判定
[Mixed — 既是「是什么」（一个完整的私有化大模型框架）也是「怎么用」（部署+配置+交付全流程）]

## 类比 ★
### 一句话比喻
> 给每个部门配一个「只读自家档案柜的 AI 秘书」——财务部的秘书只能翻财务档案，市场部的秘书只能翻市场档案，彼此隔离不串台，老板在统一的可视化面板上管理所有秘书。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 私有化大模型框架 | 公司内部的 AI 秘书团队管理系统 |
| 多机器人（按部门/业务） | 每个部门配一名专属秘书，各自掌管不同档案柜 |
| 知识库（数据集投喂） | 秘书手里的档案柜——只装本部门的文件 |
| 可视化交互界面（拖拽操作） | 老板的管理面板——不用敲代码，点几下就配好秘书 |
| 嵌入第三方平台（企微/官网/电报） | 把秘书外派到客户接待大厅，直接跟客户对话 |
| OpenAI API + 数据集密钥 | 秘书的大脑 + 档案柜的钥匙 |

## 是什么
私有化大模型1 是一个面向企业的通用型私有化 AI 平台。它以 OpenAI API（ChatGPT）为底座，支持企业按不同部门/业务场景创建多个独立的知识库机器人，每个机器人只基于该部门的数据集进行问答，互不干扰。平台自带可视化交互界面（无需前端定制），支持文档上传和网站链接两种数据集导入方式，并可将机器人嵌入企业微信、官网、电报等第三方平台。

## 输入-输出空间
- **输入**: OpenAI API 密钥 + 数据集密钥 + 云服务器（阿里云/腾讯云国外节点） + 企业文档（Q&A 格式：问题-答案一行）
- **输出**: 可通过公网 IP:3000 访问的私有化大模型平台，支持多机器人创建、知识库管理、第三方嵌入
- **前置条件**: 云服务器必须选海外节点（国内无法访问 OpenAI 接口）；数据集格式必须为「问题+\t+答案」逐行排列

## 正例（≥2 个）
1. **多部门企业场景**: 一家制造企业，财务部、市场部、HR 各有独立的 SOP 文档。三个部门分别创建三个机器人，各自投喂本部门文档，财务机器人在官网回答报销流程，市场机器人在企微回复产品参数——数据完全隔离，不会串台。
2. **智能客服外包**: 某电商公司将产品 FAQ 文档上传，创建一个「产品顾问」机器人嵌入官网，24 小时回答客户关于退换货、尺寸、材质的专业问题，无需真人客服值守。

## 反例/边界（≥1 个）
1. **文档格式错误导致问答失效**: 如果上传一整篇长篇报告而非逐行 Q&A 格式，大模型无法理解文档结构，回答质量极差——因为该框架不内置 LangChain 式的自动语义切分，必须人工预处理数据集。
2. **国内服务器节点不可用**: 如果贪便宜选择国内节点的免费服务器，无法访问 OpenAI 接口，整个平台形同虚设——必须选新加坡/美国等海外节点。
3. **不适合开放域闲聊**: 机器人被提示词限定「只根据文本回答」，问天气等无关问题会直接拒绝——这是企业的需求（不闲聊），但如果客户期待 GPT 式自由对话会失望。

## 详细解释

### 核心架构
```
用户/客户 → 第三方平台(企微/官网/电报) → 机器人(前端UI) → OpenAI API
                                                    ↕
                                              知识库(向量检索)
```

### 部署流程（4 步）
| 步骤 | 操作 | 关键点 |
|------|------|--------|
| 1. 准备阶段 | 领取 OpenAI API 密钥 + 申请数据集密钥 | API 初始额度 5-10 美金，有效期 1-2 个月 |
| 2. 服务器选配 | 阿里云 ECS，按量付费，新加坡节点，计算型 C7，鲁班兔 22.04，带宽 5Mbps | 必须海外节点；安全组放行 HTTP/HTTPS 和 3000 端口 |
| 3. 部署 | SSH 登录 → git clone 项目 → 编辑 .env 配置两个 API 密钥 → 安装 Docker + docker-compose → 启动服务 | 部署后公网 IP:3000 访问，初始账号密码均为 ADMIN |
| 4. 使用 | 创建机器人 → 上传文档/粘贴链接 → 选嵌入模型 → 配置提示词 → 可嵌入第三方 | 提示词已预设为最优，不建议修改 |

### 商业价值
- 无需前端定制（省 2-3 万前端费用），完整框架交付
- 收费建议：10 万左右（根据企业体量调整）
- 可视化操作界面让企业零门槛使用
