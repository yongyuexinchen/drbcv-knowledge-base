# AI Agent：从辅助工具到数字劳动力

> 体系级相变点（与就业市场级的 [[AI岗位-会用转会造Agent]] 分工：本卡监控"AI 生产关系中 Agent 的地位"，那张卡监控"岗位结构"）。交叉引用。

## 前提（Premises）

- Agent 可靠性越过"生产可用线"（连续运行/错误率可控）——技术前提
- 企业从"买工具"转向"买产能"——商业前提（按结果付费模式成立）
- 监管允许任务委托（无强制人类在环）——制度前提

## 现状（状态机依据）

- **status: observing**（2026-08-06 判定）
- 依据：Agent 从演示走向生产（早期信号），但三触发指标均未达阈值；企业采购仍以软件许可为主；JD 仍以"会用 AI"为主（"管理AI系统"尚未成主流）
- 当前形态：`工具 + 人类监督`——未来形态：`任务委托 + Agent执行 + 人类验收`

## 压力（Pressure）

### 来源

模型能力提升（一阶↑）+ 推理成本下降（二阶↓）+ 企业降本压力（利润驱动）+ 组织数字化成熟

### 指标

- [ ] Agent 生产环境连续运行时长（企业案例/平台报告）
- [ ] 企业采购模式变化（软件许可 vs 按产能/结果付费）
- [ ] JD 表述变化（"会用AI"→"管理AI系统"占比）
- [ ] Agent 平台营收结构（订阅 vs 结果分成）

### 影响

- 初级执行岗（重复认知劳动）被委托化——岗位从"做事"转向"验收"
- 软件从"卖许可"变"卖结果"——商业模式重构
- 记忆/状态管理成为 Agent 产能的基础设施（价值迁移落点）

## 触发阈值

- 主触发：三指标中 ≥2 个同时满足
- 部分触发：单指标出现趋势性变化（连续 2 期增强）→ strengthening

## 转换方向

- 当前：工具 + 人类监督（Agent=高级工具）
- 相变后：任务委托 + Agent 执行 + 人类验收（Agent=数字劳动力，人类=管理者/验收者）
- 价值迁移：模型层 → 应用层 → **数据/工作流/记忆层**——记忆系统是相变后的基础设施（25-50K 目标岗所在）

## 时间窗口

- 判断：主窗口 12-24 个月；若 Agent 可靠性突破（连续生产运行），窗口提前
- 1998 类比护栏：AI 已有真实营收，泡沫破裂机制可能与互联网不同——此卡只监控劳动力化，不预测泡沫

## 失效条件

1. Agent 可靠性长期不达生产标准（2 年无实质进展）→ 劳动力化证伪，维持工具定位
2. 企业退回"工具+人"模式（委托任务因事故/成本被收回）→ 转换反向
3. 监管强制人类在环（法律禁止无监督委托）→ 相变被制度阻断
4. 若 2028 年三指标仍无 ≥2 项达标 → 本卡 invalidated，复盘前提
