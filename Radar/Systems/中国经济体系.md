# 中国经济体系

> 边界：**经济机器怎么转**（实体+政策）。钱往哪流（价格+资金）→ [[资本市场体系]]。
> 利率政策属于本体系；DR007 资金面属于资本市场体系。

## 存在目的（Purpose）

通过资产价格扩张与要素投入维持财政可持续与经济增长。
人口下降导致土地财政无法持续——不是"房地产不好了"，而是**原本解决经济增长问题的机制失效**。

## 核心矛盾（Contradiction）

旧增长引擎（土地财政/出口）动力衰减 vs 新引擎（创新/消费）未成形。
转换判断基准：新引擎能否在旧引擎熄火前接棒（接力赛逻辑）。

## 外部混沌（Disruption）

- 人口结构逆转——攻击"资产价格扩张"的实现前提（没人接盘）
- 技术革命（AI）——提升生产率但同步冲击就业结构，消费引擎承压
- 外部脱钩——压缩出口引擎空间
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **土地财政**：土地收入 → 财政 → 基建 → 增长的旧引擎
- **银行信用**：房地产抵押品价值支撑信贷扩张
- **地方政府债务**：隐性债务累积，化债是长期主题
- **居民资产配置**：房产占居民资产大头，房价影响消费与信心
- **人口结构**：人口逆转，储蓄率下行 → 利率中枢长期下移（古德哈特）

## 稳定机制（旧）

房价上涨 → 土地收入 → 财政 → 基建 → 经济增长 → 房价上涨（自我强化）

## 弱点（脆弱点积累，Pressure 前兆）

1. **房地产**：增量转存量，直接+间接占 GDP 约 20%（macro-05）
2. **人口下降**：长期压制储蓄、投资、房地产需求（古德哈特）
3. **地方债**：化债压力限制财政扩张空间
4. **利率政策空间**：降息通道接近尾声，政策工具逼近约束
- 积累路径（明斯基式）：资产价格扩张依赖杠杆 → 人口拐点 → 接盘力量减弱 → 土地收入下滑 → 财政承压 → 风险暴露

## 同级系统（替代性对比）

| 引擎 | 现状 | 替代性 |
|------|------|--------|
| 土地财政（旧） | 动力衰减 | 被替代中 |
| 出口/制造 | 承压（脱钩） | 产能出海转型 |
| 股权财政（科创/国资收益） | 未成形 | 候选新引擎 |
| 内需消费 | 结构性问题（分配/信心） | 候选新引擎 |

## 上级系统（当前状态 + 短期预测）

**全球政治经济体系**（三级分工：消费国/生产国/资源国）
- 当前状态：分工重构中——美国再工业化、中国产能出海（东南亚/中东）、资源国博弈
- 短期预测：再平衡窗口 3-5 年（可证伪：贸易结构/产业链迁移数据）
- 方向性：旧分工（中国=世界工厂）不可逆地松动，新位置未定——中国的位置决定本体系约束

## 高维观察（当前状态 + 短期预测，可证伪）

视角：**接力赛**——旧引擎熄火前新引擎能否接棒，是增长体系转换的核心判据。
- 当前状态：接力区（增速换挡，旧引擎衰减明确，新引擎仍在培育）
- 短期预测：若 3 年内新引擎（研发产出/消费占比）未明显上升 → 接力失败风险，增长中枢再下移（可证伪：消费占GDP比、全要素生产率数据）
- 失效条件：若旧引擎回光返照（房地产刺激再起效）或新引擎提前成熟 → 本观察作废

## 泰勒展开（结构比较 + 调研报告）

- 结构比较对象：**日本 90 年代资产泡沫破裂 vs 中国当前**——同构：资产价格扩张→人口拐点→接盘减弱；差异：中国有资本管制/产业升级空间/政策工具更多，日本当年无——**这是最值得深挖的对比，调研优先**
- 状态变量（可求导）：房地产投资增速（一阶）/人口结构（二阶）/财政模式可持续性（三阶）
