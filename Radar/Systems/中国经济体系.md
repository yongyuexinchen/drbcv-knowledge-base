# 中国经济体系

> 边界：**经济机器怎么转**（实体+政策）。钱往哪流（价格+资金）→ [[资本市场体系]]。
> 利率政策属于本体系；DR007 资金面属于资本市场体系。

## 存在目的（Purpose）

通过资产价格扩张与要素投入维持财政可持续与经济增长。
人口下降导致土地财政无法持续——不是"房地产不好了"，而是**原本解决经济增长问题的机制失效**。

## 核心矛盾（Contradiction）

旧增长引擎（土地财政/出口）动力衰减 vs 新引擎（创新/消费）未成形。
转换判断基准：新引擎能否在旧引擎熄火前接棒（接力赛逻辑）。

## 外部混沌（Disruption）

- 人口结构逆转——攻击"资产价格扩张"的实现前提（没人接盘）
- 技术革命（AI）——提升生产率但同步冲击就业结构，消费引擎承压
- 外部脱钩——压缩出口引擎空间
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **土地财政**：土地收入 → 财政 → 基建 → 增长的旧引擎
- **银行信用**：房地产抵押品价值支撑信贷扩张
- **地方政府债务**：隐性债务累积，化债是长期主题
- **居民资产配置**：房产占居民资产大头，房价影响消费与信心
- **人口结构**：人口逆转，储蓄率下行 → 利率中枢长期下移（古德哈特）

## 稳定机制（旧）

房价上涨 → 土地收入 → 财政 → 基建 → 经济增长 → 房价上涨（自我强化）

## 脆弱点（Pressure 清单）

1. **房地产**：增量转存量，直接+间接占 GDP 约 20%（macro-05）
2. **人口下降**：长期压制储蓄、投资、房地产需求（古德哈特）
3. **地方债**：化债压力限制财政扩张空间
4. **利率政策空间**：降息通道接近尾声，政策工具逼近约束

## 监控指标

- 房地产销售/投资月度数据
- 人口数据（出生/老龄化）
- 财政收支、地方债发行
- 政策利率与降息节奏

## 转换点（Transitions/）

- 待建候选：房地产-增量转存量、降息通道-转平稳、土地财政-转新引擎
