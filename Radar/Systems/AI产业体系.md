# AI产业体系

## 存在目的（Purpose）

降低信息处理成本，让组织以更低成本获得智能决策与内容生产能力。
判断基准：当"智能成本"不再下降（模型能力停滞+API 涨价），目的受威胁 → 体系要变。

## 核心矛盾（Contradiction）

智能供给成本快速下降 vs 组织消化能力滞后。AI 替代白领不是单一缺口，而是：
模型能力提升 + 成本下降 + 企业利润压力 + 组织结构调整 四股力量叠加。

## 外部混沌（Disruption）

- 完全自主 Agent 替代编码/决策流程——攻击本体系"人类在回路"的实现方式
- 开源模型颠覆闭源商业模式——攻击模型层收费结构
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **模型层**：API 成本持续下降、开源模型逼近闭源；本地部署门槛降低
- **应用层**：Agent 开发（73%）+ RAG（66%）是岗位实际工作内容主力；记忆系统是差异化方向
- **就业市场**：深圳 AI 应用开发 20-25K；"需给 Agent 加记忆的公司"25-50K（目标岗）
- **基础设施**：本地优先（Private-LLM）、Docker、云演进

## 稳定机制

模型能力提升 → 应用层产品化 → 企业采用 → 岗位需求 → 人才供给 → 反哺应用

## 弱点（脆弱点积累，Pressure 前兆）

1. **模型商品化**：API 成本趋零 → "调模型"技能贬值、"定义问题"技能升值
2. **Agent 成熟度**：可靠性未过线，ROI 未兑现 → 泡沫风险（明斯基式：繁荣期杠杆和预期积累）
3. **记忆系统空白**：多数 Agent 无跨会话记忆 → 机会缺口
4. **本地 vs 云端**：隐私/成本 vs 能力差距，阈值未到
5. **个人技能缺口**：Python 薄弱 + 无前后端 → 竞争中下风（跨体系：[[个人成长体系]]）

## 同级系统（替代性对比）

| 系统 | 承接需求 | 与AI产业的替代关系 |
|------|---------|-------------------|
| 传统IT外包 | 标准化开发/运维 | 低端被 Agent 平台挤压，高端转向"AI落地" |
| 咨询公司 | 企业AI转型规划 | 吃转型预算，与AI应用开发互补竞争 |
| 企业内部IT | 日常数字化需求 | 消化常规需求，AI 团队做增量 |

## 上级系统（当前状态 + 短期预测）

**全球技术-经济体系**
- 当前状态：技术革命早期——基础设施（模型/算力）投资高峰，应用层产品化刚开始
- 短期预测：2-3 年内 Agent 产品化加速，应用层价值上移（可证伪：主流云厂商默认 Agent 产品 + 企业采用率）
- 方向性：革命不可逆，但具体路径（开源vs闭源/云vs本地）未定——这正是监控点

## 高维观察（当前状态 + 短期预测，可证伪）

视角：**技术革命生命周期**——基础设施期 → 应用爆发期 → 平台固化期。
- 当前状态：基础设施晚期 / 应用早期（类比互联网 1998-2000）
- 短期预测：应用层价值上移，"定义问题+编排工作流"能力升值（可证伪：JD 关键词率 + 初级调API岗薪资）
- 失效条件：若模型能力停滞（无新范式突破），革命进入平台期，应用层机会收窄

## 泰勒展开（结构比较 + 调研报告）

- 结构比较对象：**互联网革命（1995-2005）vs AI革命**——同构结构：基础设施→应用→平台三层展开；差异：AI 的"应用"直接替代认知劳动而非仅是信息分发
- 状态变量（可求导）：模型能力 / API成本 / 企业采用率 / 岗位结构——当前：一阶上升（能力）、二阶加速（成本下降）
