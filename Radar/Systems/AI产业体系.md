# AI产业体系

## 存在目的（Purpose）

降低信息处理成本，让组织以更低成本获得智能决策与内容生产能力。
判断基准：当"智能成本"不再下降（模型能力停滞+API 涨价），目的受威胁 → 体系要变。

## 核心矛盾（Contradiction）

智能供给成本快速下降 vs 组织消化能力滞后。AI 替代白领不是单一缺口，而是：
模型能力提升 + 成本下降 + 企业利润压力 + 组织结构调整 四股力量叠加。

## 外部混沌（Disruption）

- 完全自主 Agent 替代编码/决策流程——攻击本体系"人类在回路"的实现方式
- 开源模型颠覆闭源商业模式——攻击模型层收费结构
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **模型层**：API 成本持续下降、开源模型逼近闭源；本地部署门槛降低
- **应用层**：Agent 开发（73%）+ RAG（66%）是岗位实际工作内容主力；记忆系统是差异化方向
- **就业市场**：深圳 AI 应用开发 20-25K；"需给 Agent 加记忆的公司"25-50K（目标岗）
- **基础设施**：本地优先（Private-LLM）、Docker、云演进

## 稳定机制

模型能力提升 → 应用层产品化 → 企业采用 → 岗位需求 → 人才供给 → 反哺应用

## 脆弱点（Pressure 清单）

1. **模型商品化**：API 成本趋零 → "调模型"技能贬值、"定义问题"技能升值
2. **Agent 成熟度**：可靠性未过线，ROI 未兑现 → 泡沫风险
3. **记忆系统空白**：多数 Agent 无跨会话记忆 → 机会缺口
4. **本地 vs 云端**：隐私/成本 vs 能力差距，阈值未到
5. **个人技能缺口**：Python 薄弱 + 无前后端 → 竞争中下风（跨体系：[[个人成长体系]]）
