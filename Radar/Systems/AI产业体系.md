# AI产业体系

## 结构（当前认知）

- **模型层**：API 成本持续下降、开源模型能力逼近闭源；本地部署门槛降低
- **应用层**：Agent 开发（73%）+ RAG（66%）是岗位实际工作内容主力；记忆系统是差异化方向
- **就业市场**：深圳 AI 应用开发 20-25K；"需给 Agent 加记忆的公司"25-50K（目标岗）
- **基础设施**：本地优先（Private-LLM）、Docker 部署、云服务演进

## 已知缺口（裂缝清单）

1. **岗位结构迁移**：JD 从"会用工具/调 API"转向"会造 Agent/工作流" → 已建转换点卡
2. **模型商品化**：API 成本趋零 → 应用层价值上移，"调模型"技能贬值、"定义问题"技能升值
3. **记忆系统空白**：多数 Agent 无跨会话记忆，"给 Agent 加记忆"是真实缺口（你的目标岗）
4. **本地 vs 云端**：本地优先的隐私/成本优势 vs 云端能力差距，阈值未到
5. **个人技能缺口**：Python 薄弱 + 无前后端经验 → 在 AI 应用岗竞争中处于下风

## 监控指标

- Boss直聘 JD 关键词出现率（Agent/RAG/记忆），全文扫描非标题匹配
- API 价格变动（主流模型每百万 token 成本）
- Agent 框架成熟度（LangGraph 等）、主流云厂商 Agent 产品发布
- 记忆系统相关公司岗位数量（25-50K 区间）
