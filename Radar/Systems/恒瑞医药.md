# 恒瑞医药（v1.0 个股投资体系卡）

> 2026-08-07 定稿（个股调研第三批）。非持仓（观察清单）。引用 [04:§x] = 04_恒瑞医药_调研.md。审查核查 222 引用 0 虚构。🔴 本卡是 [[创新药投资体系]] 的个股落地层（S1-S3 对齐母卡）。

## 本质 [04:§1]
仿制药现金牛反哺创新药研发飞轮——仿制药现金流 → 创新药研发 → 管线放量 → 出海授权。

## 核心矛盾 [04:§5]
仿制药集采（覆盖 >70%）vs 创新药放量；医保单一买方 vs 出海；高研发 vs 短期利润——三重矛盾。

## 周期定位 [04:§6]
出清末期→普及前期过渡（与创新药母卡一致）；产业时钟领先 + 资本时钟滞后错位。

## 监控信号（S1-S5）[04:§7]
S1-S3 对齐创新药母卡（创新药占比/出海授权/管线）；S4-S5 恒瑞专属（BD 合作/集采影响）。

## 持仓裁决（审查定稿）
