# 个人成长体系

> 观察者即系统：世界演化 → 你演化，两套演化必须同步读。

## 存在目的（Purpose）

把"我"转化为目标状态：AI工程师（就业）+ 认知优势（AI认知OS）。
判断基准：目标状态有明确验收（2027 前进入 AI 应用开发岗带 Agent 实战）；目的无法推进（长期零进展）= 体系失效信号。

## 核心矛盾（Contradiction）

目标状态 vs 当前约束：学历门槛 + 经验不足 + Python 薄弱 + 四线并行精力有限。
转换判断基准：约束能否在窗口期内解除（跟课完成→项目→求职的接力）。

## 外部混沌（Disruption）

- AI 让"非科班转 AI"窗口提前关闭（转换太快）或突然打开（需求爆发）
- 考研政策变化（非全招生变动）
- 行业寒潮（AI 岗收缩）
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **学历通道**：备考中山大学非全大数据研究生
- **技能通道**：SQL（还行）> Python（薄弱）→ FastAPI 跟课中（今日头条项目 day03-06）
- **项目通道**：今日头条项目（跟课）→ 待升级为展示项目
- **求职通道**：深圳 AI 应用开发 20-25K → 目标 25-50K 记忆系统岗
- **认知通道**：KOS（记忆层）+ Radar（前瞻层）+ Self（反思层）

## 稳定机制（反馈回路版，2026-08-06 定稿）

> 职业系统与普通体系不同：不是"目标→执行→成功"，而是**反馈驱动**。
> AI 时代铁律：**学习方向错误比学习速度慢更致命**。

```
输入：知识学习
  ↓
转化：代码/项目（作品）
  ↓
外部反馈：面试 / 开源 / 用户
  ↓
修正：重新选择学习方向
  ↓
能力增长
  ↑_________（回到输入，循环）
```

正循环：学习 → 技能 → 项目 → 求职 → 岗位实战 → 反馈学习。
风险：任何一环断掉（只学不产出 / 只产出无反馈 / 有反馈不修正）= 循环停转。

## 弱点（脆弱点积累，Pressure 前兆）

- **学历门槛**：非科班（本科动画）+ 本科背景 vs 计算机科班竞争者
- **经验不足**：工作 1 年，无前后端/AI 工程实战
- **代码基础薄弱**：Python 弱是最短木板
- **四线并行**：备考 + 学代码 + 做项目 + 找工作，精力是硬约束
- 积累路径（明斯基式）：不会 Python → 还能靠 SQL 工作 → AI 岗位要求提高 → 竞争力下降 → 职业风险暴露

## 同级系统（替代性对比）

| 路线 | 成本 | 信号 | 状态 |
|------|------|------|------|
| 非全考研 | 时间 2-3 年 + 学费 | 学历信号保值（但 AI 岗权重未定） | 进行中（观察期） |
| 培训班 | 快（数月） | 信号弱（泛滥） | 未选 |
| 自学历程 | 慢但真实 | 作品/项目可验证 | 进行中（跟课） |

成本曲线判断：考研+项目并行 = 双信号叠加，但精力是硬约束——需在 2027 出分时结算。

## 上级系统（当前状态 + 短期预测）

**就业市场体系**（[[AI产业体系]] + [[软件工程体系]]）
- 当前状态：岗位结构迁移中——Agent 开发 73%/RAG 66% 成为工作内容主力；技能关键词（Python 72%）≠ 工作内容
- 短期预测：窗口 12-24 个月——现在入场仍是早期，两年后是红海
- 方向性：学历权重 vs 项目权重正在挪移（观察中，未定方向）

## 高维观察（当前状态 + 短期预测，可证伪）

视角：**技能投资组合**——把时间/金钱当资本配置到技能上，回报=就业竞争力。
- 当前状态：组合中代码能力是最大短板（SQL>Python>无前后端），配置比例失衡
- 短期预测：**若 6 个月内 Python 达可写完整项目水平 + 1 个可展示项目，竞争力斜率显著改善**（可证伪：以"能否独立完成一个 FastAPI+RAG 项目"为验收）
- 失效条件：若岗位需求转向其他技能（如纯工程化部署），则组合需再平衡

- 同构结构假设：转行成功的共同点 = ①作品可验证 ②外部反馈闭环 ③窗口期内完成信号叠加
