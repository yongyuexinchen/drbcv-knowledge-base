# 半导体投资体系（v1.0 调研定稿）

> v1.0 基于 2026-08-07 投资体系卡调研第二轮（双 Agent + 写卡 + 审查）定稿——Radar 第二张投资体系卡。携带 2026-07-30 教训（韩国 HBM 金融围猎）升级：全球联动检查 + 反向利益追踪已入流程。purpose 三层嵌套（审查标注 L3 假深度风险——监控以 L1/L2 为主）。引用编号 [A-x]/[B-x] 真实可追溯（审查核查 20/20 可定位 0 虚构）。

## 存在目的（Purpose）

**三层嵌套（[B:§2]）：**

```
L1 技术层：降低算力/电子成本（摩尔定律延续）     ← 可证伪：算力成本停止下降
L2 产业层：产业链定价权（设计/制造/设备/材料/封测） ← 可证伪：国产替代率停滞
L3 地缘层：芯片主权化（出口管制/国产替代）        ← ⚠️ 背景框架非监控主轴（审查标注）
```

## 产业链五层与价值捕获（[B:§3]）

```
价值金字塔（收税者）：
  英伟达（设计/GPU）→ ASML（设备/EUV）→ 台积电（制造）→ EDA（美国）→ 材料（日系 55%）

中国卡点排序：制造(EUV) > EDA > 设备 > 材料 > 设计 > 封测
  封测 ~25% 全球份额已突破（传统封测，先进封装落后 3-5 年）
```

## 全球联动脉络（🔴 2026-07-30 教训复盘 [B:§4]）

```
6 国节点矩阵：
  韩国 HBM 79%（风暴眼——SK海力士 -43%）
  台湾先进制程 90%+（台积电避风港 +2.6%）
  美国 EDA + 设备（出口管制源头）
  日本设备材料（硅片 55%/光刻胶）

韩国金融围猎三段式：做空 → 汇率引爆（韩元 -30%）→ 杠杆爆破（30万账户归零）
A股半导体 = 全球 β 的 3-5 倍放大版（芯片ETF 3月 -45.8%）——非独立行情 [A:§4]
```

## 反向利益追踪（🔴 [B:§5]）

```
结构性赢家（收税者）：英伟达 / ASML / 台积电 / EDA / 对冲基金（做空获利）
国产替代受益者：设备/材料/封测（政策红利）
下跌阶段赢家：做空韩国 HBM 的资本（围猎获利方）
```

## 核心矛盾（Contradiction）

**一阶**：国产替代决心 vs 技术代差（EUV/EDA 短期不可突破）
**二阶**：AI 算力需求指数 vs 半导体产能扩张线性 → 供给瓶颈→涨价→过热→Ponzi

## 明斯基周期定位（[B:§6]）

- 🔴 台积电砍单/降价 = 第三阶段全面确认（关键观察点）
