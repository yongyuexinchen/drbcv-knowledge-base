# 资本市场体系

> 边界：**钱往哪流**（价格+资金）。经济机器怎么转 → [[中国经济体系]]。
> DR007 资金面属于本体系；利率政策属于中国经济体系。

## 存在目的（Purpose）

为储蓄者配置资本、为融资者发现价格。核心矛盾：资本逐利 vs 实体回报下行。
当回报率系统性下行时，市场不消失，但**行为方式改变**（资产荒→抱团→泡沫→闪崩）。

## 核心矛盾（Contradiction）

资本逐利要求回报 vs 实体回报率下行（利率中枢下移）→ 资产荒与泡沫化。
明斯基：稳定期越长，杠杆越隐蔽——稳定本身就是不稳定的来源。

## 外部混沌（Disruption）

- 流动性突然转向（政策混沌）——攻击"资本逐利"的运行前提
- 技术革命改变资产定价基准（AI 重新定义哪些资产有未来现金流）
- 地缘冲突冲击风险偏好
- 只录攻击目的实现方式的变量，其他不录

## 组成

- **流动性**：超储率五因子（外汇占款/对其他存款性公司债权/财政支出/现金需求/法定存款准备金）联动 M2 社融（macro-07）
- **资金面**：DR007 是中国"联邦基金利率"，利率走廊约束短端（macro-10）
- **周期**：库存周期/朱格拉周期定位（周金涛）；金融不稳定周期（明斯基）
- **资产迁移**：股/债/房/金/币之间的资金轮动

## 稳定机制

流动性宽松 → 资产价格上涨 → 财富效应 → 信用扩张 → 通胀/泡沫 → 政策收紧 → 周期反转（明斯基）

## 弱点（脆弱点积累，Pressure 前兆）

1. **流动性转向**：财政发力项退坡时资金面收紧信号
2. **周期位置**：当前位置与周期拐点的距离（周金涛框架）
3. **资产泡沫化**：明斯基时刻风险（稳定期越长，杠杆越隐蔽）
4. **持仓集中**：创新药 35% 单板块暴露
- 积累路径（明斯基式）：稳定 → 风险积累 → 杠杆增加 → 脆弱性暴露 → 崩溃

## 同级系统（替代性对比）

| 配置渠道 | 特征 | 与股市的替代关系 |
|---------|------|----------------|
| 存款 | 低收益低风险 | 无风险利率=机会成本 |
| 房产 | 流动性差 | 存量时代吸引力下降 |
| 黄金 | 避险 | 风险偏好切换时流入 |
| 加密资产 | 高波动 | 高风险偏好资金分流 |

## 上级系统（当前状态 + 短期预测）

**中国经济体系 + 全球金融体系**
- 当前状态：国内利率下行通道接近尾声，全球流动性转向在即（美联储路径+国内政策空间）
- 短期预测：资金面进入敏感期，拐点信号密集（可证伪：DR007 与政策利率利差收窄/倒挂）
- 方向性：实体回报率下行是长期约束，市场在"资产荒"中反复寻找出口

## 高维观察（当前状态 + 短期预测，可证伪）

视角：**明斯基周期**——稳定滋生不稳定，脆弱性在繁荣期积累。
- 当前状态：杠杆积累期（资产荒→抱团→估值抬升，风险偏好偏高）
- 短期预测：流动性拐点前，高杠杆/高估值资产先承压（可证伪：信用利差走阔/融资余额变化）
- 失效条件：若政策无限托底（流动性永不收紧），明斯基周期被推迟——但推迟不等于消除

## 泰勒展开（结构比较 + 调研报告）

- 结构比较对象：**历次流动性拐点**——2013 钱荒 / 2018 去杠杆 / 2020 宽松——同构：政策转向 → 资金面收紧 → 资产重定价；差异：触发源（同业/资管/疫情）与传导路径
