# 创新药投资体系（v1.0 调研定稿）

> v1.0 基于 2026-08-07 投资体系卡调研第一轮（双 Agent + 写卡 + 审查）定稿——Radar 首张投资体系卡。purpose 按 B 报告"专利垄断激励"抽象（审查修正为"激励相容"措辞，非犬儒表述）；持仓决策 25%+10% 为审查定稿（驳回"不动等信号"）。引用编号 [A-x]/[B-x] 全部真实可追溯（审查核查 58 次引用 0 虚构）。

## 存在目的（Purpose）

**以专利垄断为激励（激励相容机制），把科学知识转化为可商业化治疗方案。**

三级抽象（[B:§2]）：
```
直接目的：研发并销售创新药（专利保护期内的独占利润）
中间目的：以利润激励持续研发（激励相容——专利是创新的对价）
最终目的：将科学知识转化为可商业化治疗方案（健康改善是机制的自然结果，非慈善目标）
```

**可证伪**：ROIC 长期 < 资本成本 → 体系退化（专利垄断失效）→ 目的受威胁。

## 产业链五层（谁创造价值谁捕获价值）[B:§2]

```
上游原料药（分润 5-10%）→ CXO（卖水人，稳定）→ 创新药企（唯一超额价值创造者）
→ 终端医院药店（处方流量）→ 支付方医保（垄断买方定价权——中国特殊变量）
```

**核心洞察**：中国医保局作为单一买方压制了创新药企的价值捕获能力 → **出海是必然路径**（逃离单一买方垄断）→ S1（License-out 金额）是全体系权重最高的监控信号。

## 核心矛盾（Contradiction）

**一阶三重**：
1. 研发长周期高投入（临床 I 期→获批成功率 7-10% [B:§3]）vs 资本耐心短（投资组合要求 ≥30% 项目退出）
2. 集采压价 vs 创新激励（医保单一买方）
3. 出海 vs 地缘（FDA 准入/实体清单/关税）

**二阶**：科学创新指数级可能 vs 支付体系线性扩容（医保基金增速 < 支出增速 [B:§2]）

**CLD 双环路**：
```
R1 良性：出海授权 → 收入 → 研发投入 → 更多管线 → 更多出海
R2 恶性：集采降价 → 利润压缩 → 研发缩减 → 管线枯竭 → 创新退化
```

## 明斯基周期定位（2026-08-07 调研）[B:§4]

**出清末期 → 普及前期**（2025-2026 过渡区，相变窗口）：
- 头部 ~10%（百济/信达/康方/再鼎）已进入对冲融资（盈利或接近盈利）
- ~40% 僵尸企业仍待出清
- 当前处于"出清尾部 + 普及初期"的转换带
