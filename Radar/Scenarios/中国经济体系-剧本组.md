```
先验概率（历史样本基准）：
  日本式长期停滞：40%
  危机式出清修复：20%
  调整式转型：    40%
```

## 剧本A：主路径（日本式长期停滞，45%）

> 当前趋势延续——泄压式冷却 + 人口不可逆

### 核心冲突
增长目标（5%+）vs 人口/债务天花板——旧引擎动力衰减，新引擎未接棒。

### 关键角色
地方政府（土地财政依赖者）/ 居民（杠杆承担者+购房预期）/ 国有银行（风险承接者）/ 中央政府（化债与兜底者）/ 产业资本（新引擎培育者）

### 演化链
```
房价阴跌延续（无断崖）
  ↓
居民资产负债表缓慢缩水 → 消费降级
  ↓
土地出让收入低位 → 地方"吃饭财政"
  ↓
增长中枢下移至 2-3% → 低利率+低通胀常态
  ↓
政策反复托底（降息/化债）但边际递减（日本30年验证）
```

### 关键节点（→ 引用转换卡，不复制）
- 银行不良率突破 2%→3%→5% 阶梯（S1 监控）
- 消费倾向跌破 60%（S2）
- 转换点：[[AI岗位-会用转会造Agent]] 的窗口与就业结构变化（连锁）

### 证伪条件
- S1-S5 三年内全部未触发 → 软着陆成功，本剧本概率归零
- 新引擎（消费占GDP提升≥2个百分点）接棒 → 转型剧本接管

## 剧本B：压力路径（危机式出清修复，10%→保底5%）

> 系统出现阻力——某个压力变量突破阈值，被动出清

### 核心冲突
债务问题从"可腾挪"变为"不可腾挪"——信用收缩触发连锁。

### 演化链
```
某个开发商/城投平台公开违约（超预期）
  ↓
信用利差跳升 → 融资冻结
  ↓
银行不良快速暴露（S1 突破 5%）
  ↓
中央注资兜底（国有银行不倒）但财政消耗巨大
  ↓
强刺激+债务重组 → 2-3 年修复 → 与美国 2008 路径趋同
```

### 关键节点
- S1 银行不良率 > 5%（季度）
- 城投公开违约事件
- 汇率急贬（S4，12个月>30%）——注意：S4 触发说明走的是**非日本路径**

### 证伪条件
- 资本管制有效（S4 未触发）+ 国有银行兜底 → 危机路径被制度阻断

## 剧本C：混沌路径（黑天鹅，15%）

> 混沌变量入场，改变规则空间——不做预测，只列入场后走向

### 混沌变量候选
- 地缘冲突升级（台海/南海）→ 资本管制被迫放开/供应链断裂
- 激进政策转向（一次性债务重组/大规模转移支付）
- 人口政策极限逆转（5年内激进生育激励+大规模移民——当前力度远不足）
- 技术革命（AI）生产率爆发改变就业与财政结构

### 演化链（示例：债务重组路径）
```
中央宣布一次性债务重组（削减存量）
  ↓
短期信用冲击 → 中期预期反转
  ↓
居民/企业资产负债表一次性出清
  ↓
新财政模式（股权财政）起步——日本没做过的事
```

### 证伪条件
- 无——黑天鹅剧本天然不可证伪，只作为"规则空间变化"的提醒层存在
