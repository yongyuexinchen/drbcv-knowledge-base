## 概率生成机制

### 第一步：历史结构先验（样本集声明）

历史样本集：技术革命（生产力跃迁）的资本-应用周期

| 历史案例 | 结局路径 | 结果 |
|---------|---------|------|
| 互联网 1998-2003 | 资本涌入→预期膨胀→泡沫破裂→出清→真正应用留下 | 泡沫后成长 |
| 移动互联网 2010-2015 | 技术成熟+资本→应用爆发→平台固化 | 平稳爆发 |
| 自动化/工业革命史 | 技术替代劳动力→结构转型→社会消化滞后 | 转型阵痛 |
| 区块链 2017-2022 | 叙事先行→资本涌入→证伪→大部分归零 | 叙事崩溃 |

```
先验概率（历史样本基准）：
  泡沫后成长（出清后爆发）：40%
  平稳应用爆发：           30%
  叙事崩溃（证伪归零）：    30%
```

### 第二步：压力变量修正（2026-08-06 首算）

| 压力变量 | 方向 | 修正量 | 依据 |
|---------|------|--------|------|
| AI 已有真实营收（API/订阅，区别于1998互联网） | +平稳爆发 | +10 | 商业模式已存在（1998类比护栏） |
| 资本涌入速度>组织吸收速度 | +泡沫 | +10 | 明斯基周期：预期>吸收 |
| 推理成本快速下降（二阶↓） | +泡沫后成长 | +5 | 成本曲线交叉判据（刀4） |
| Agent 可靠性未过生产线 | +泡沫 | +5 | 转换卡未触发（observing） |

```
修正后（2026-08-06）：
  泡沫后成长：40 +5  = 45%
  平稳应用爆发：30 +10 = 40%
  叙事崩溃：  30 +10+5 = 45% → 归一化后：崩溃 15% 让渡给成长（技术真实性兜底）
  
  最终：泡沫后成长 50% / 平稳爆发 35% / 叙事崩溃 15%
```

## 剧本A：主路径（泡沫后成长，50%）

> 资本预期透支 → 局部出清 → 真正应用留下（互联网 2000 剧本的温和版）

### 核心冲突
智能生产能力指数增长 vs 组织吸收能力线性增长（二阶矛盾）。

### 关键角色
模型公司 / 企业用户 / 开发者（你）/ 监管机构 / 劳动力市场

### 演化链
```
资本涌入→应用投资激增（2024-2026 现状）
  ↓
ROI 验证开始：大量"AI 原生"项目证伪
  ↓
资本收缩→估值出清（不是技术死亡，是预期出清）
  ↓
幸存者：有真实营收+场景壁垒的应用层
  ↓
Agent 越过生产可用线 → 价值迁移到数据/工作流/记忆层
```

### 关键节点（→ 引用转换卡）
- [[AI Agent-从辅助工具到数字劳动力]]：三触发指标（Agent连续运行/按产能采购/JD管理AI系统）
- [[AI岗位-会用转会造Agent]]：JD 关键词率 >70%
- 记忆系统岗位数量上升（价值迁移落点=机会窗口）

### 证伪条件
- 模型能力停滞（无新范式）→ 泡沫后成长退化为平台固化
- 记忆层商业化失败 → 价值迁移判断作废

## 剧本B：压力路径（平稳应用爆发，35%）

> 组织消化跟上了——AI 像移动互联网一样被平稳吸收

### 演化链
```
企业预算从"试验"转向"生产"（预算科目变化）
  ↓
Agent 产品化成熟（可靠性过线）
  ↓
岗位结构平稳迁移（工具使用者→定义问题者）
  ↓
应用层百花齐放，无大出清
```

### 关键节点
- 云厂商 Agent 工作流产品成为默认配置
- 企业 IT 预算中 AI 占比持续上升（无回撤）

### 证伪条件
- 组织吸收速度被证伪（采用率停滞）→ 转回剧本A

---

## 剧本C：混沌路径（叙事崩溃或范式跃迁，15%）

### 混沌变量候选
- AGI 级突破（规则空间改变：从"辅助"到"替代"）
- 监管重击（训练/部署禁令，如欧盟级立法收紧）
- 算力中断（地缘冲突切断供应链）
- 重大安全事件（Agent 自主决策事故 → 强制人类在环）

### 演化链（示例：AGI 突破路径）
```
能力跃迁（超出当前函数定义域）
  ↓
原剧本全部失效——不是概率调整，是函数换掉
  ↓
新剧本：劳动力替代速度远超社会消化
```

### 证伪条件
- 无——混沌剧本天然不可证伪，只作规则空间提醒
