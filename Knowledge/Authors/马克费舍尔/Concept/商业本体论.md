# 商业本体论（Business Ontology）

> "过去三十年里，资本主义现实主义已成功安装了一套'商业本体论'——社会中的一切，包括医疗保健和教育，都理所当然地应该像企业一样运作。"

## 核心定义

**商业本体论 = 一切目的和目标只能用商业术语理解的资本主义意识形态**。社会领域（医疗/教育/公共服务）被强制按企业逻辑运行。

## 原文引文

> "Over the past thirty years, capitalist realism has successfully installed a 'business ontology' in which it is simply obvious that everything in society, including healthcare and education, should be run as a business."
>
> 中译："在过去三十年里，资本主义现实主义已成功安装了一套'商业本体论'，在这套本体论中，社会中的一切——包括医疗保健和教育——都理所当然地应该像企业一样运作。"

## 标志性反问

> "If businesses can't be run as businesses, why should public services?"
> "如果企业都不能按企业的方式运作，公共服务凭什么可以？"

## 机制

- 教育市场化悖论："学生是服务的消费者还是产品？"（费舍尔质疑这个类比本身）
- 医院要"盈利"、大学要"产出"、公共服务要"效率"——本体论层面被企业化

## 备注

- 与哈耶克/新自由主义"一切市场化"对线素材
- 卡芙卡线"教育官僚化"主题核心
