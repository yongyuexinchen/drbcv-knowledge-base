# 反思性无能导致集体行动瘫痪

> "知道事情糟，但知道无能为力"——自我实现的预言，资本主义现实主义的心理引擎。

## 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 反思性无能（认知到问题+确认无力改变） |
| **DV（因变量）** | 集体行动瘫痪、政治替代方案消失 |
| **Chain（传导链）** | 认识到资本主义缺陷 → 相信无手段改变 → 不采取行动 → 现状持续 → "没有替代方案"被现实确认 → 进一步强化无力感（闭合循环） |
| **Premises（前提）** | 行动信念需要"替代方案可行"的想象支撑；无力感具有传染性 |
| **Falsification（证伪）** | 若存在大规模集体行动在无力感氛围中爆发并成功（如2011占领运动），则此断言需限定 |
| **Confidence** | 中（与齐泽克"犬儒主义"模型竞争性解释） |

## 🔗 文字版因果链

1. 人们认识到资本主义的缺陷
2. 但相信没有任何手段可以改变
3. 不行动 → 现状不被挑战
4. 现状持续被解读为"没有替代方案"
5. 无力感自我实现 → 集体行动瘫痪固化

## 备注

- 与齐泽克"他们知道但仍在做"区分：齐泽克=犬儒，费舍尔=想做但确认做不到
- 中国"躺平"的精确因果解释
