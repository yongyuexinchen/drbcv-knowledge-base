# 新自由主义治理导致审计文化繁荣

> 表面反官僚的新自由主义，实际产生了更多官僚——市场斯大林主义的生成机制。

## 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新自由主义治理术（市场逻辑进入公共部门） |
| **DV（因变量）** | 审计文化繁荣、官僚机构膨胀（市场斯大林主义） |
| **Chain（传导链）** | 新自由主义承诺"去官僚化" → 但不可量化的劳动（教学/护理/创作）无法用市场定价 → 需要额外管理层来"审计"价值 → 官僚机构反而膨胀 → 绩效指标取代真实目标 |
| **Premises（前提）** | 公共部门劳动存在大量不可量化成分；绩效文化被强制引入 |
| **Falsification（证伪）** | 若新自由主义确实减少了官僚（如某些国家公务员占比下降），则此断言弱化 |
| **Confidence** | 中（基于费舍尔文本论证，无实证数据） |

## 🔗 文字版因果链

1. 新自由主义承诺削减官僚、引入市场效率
2. 但教学/护理/创作等劳动的本质价值不可量化
3. 为了"证明"价值，必须引入审计系统（KPI/考核/排名）
4. 审计系统自身成为新的官僚层
5. 绩效符号取代真实成就 → 市场斯大林主义

## 备注

- 中国"内卷"的直接理论解释：人人都追符号性成就（学历/绩效），真实价值被置换
- 与韦伯"理性化铁笼"对读
