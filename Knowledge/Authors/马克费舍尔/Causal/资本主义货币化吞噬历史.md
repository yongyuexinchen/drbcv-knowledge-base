# 资本主义货币化吞噬历史

> 资本主义现实主义的力量部分来源于资本主义吞噬并消费一切既往历史的方式。

## 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本主义的等价系统（一切皆可定价） |
| **DV（因变量）** | 全部历史被消费化、反资本主义符号被对象化 |
| **Chain（传导链）** | 等价系统给一切文化对象定价（宗教圣像/色情/《资本论》） → 反资本主义符号（马克思像/革命海报）成为收藏品 → 信仰被客观化反讽 → 历史全盘消费化 → 文化失去"外部"参照点 |
| **Premises（前提）** | 市场能对任何文化对象定价；消费主义接受一切 |
| **Falsification（证伪）** | 若存在无法被商品化的文化实践持续存在，则此断言需限定 |
| **Confidence** | 中高 |

## 🔗 文字版因果链

1. 资本主义等价系统给一切文化对象定价
2. 反资本主义符号（马克思像/革命艺术）→ 收藏品
3. 信仰被客观化反讽（"买马克思T恤=反资本主义？"）
4. 历史全盘消费化
5. 文化失去"外部"参照点 → 资本主义现实主义氛围强化
