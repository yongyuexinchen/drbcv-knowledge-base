# 后福特主义弹性工作瓦解工人组织

> 工人原子化 + 工会瓦解 → 资本单方面制定规则 → 政治议程被商业利益支配。

## 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 后福特主义弹性工作制（零工/外包/灵活用工） |
| **DV（因变量）** | 工人组织瓦解、政治议程被商业利益支配 |
| **Chain（传导链）** | 弹性工作制 → 工人原子化（无共同场所/时间） → 工会组织基础瓦解 → 资本单方面制定规则 → 工人"感到越来越无助和无力" → 政治议程完全受商业利益支配 |
| **Premises（前提）** | 工会力量依赖稳定共同体的存在；弹性化削弱共同体 |
| **Falsification（证伪）** | 若零工经济中出现了新型工人组织并成功谈判（如外卖骑手工会），则此断言需修正 |
| **Confidence** | 中高（与大量劳动社会学研究一致） |

## 🔗 文字版因果链

1. 后福特主义推行弹性工作制（零工/外包）
2. 工人失去共同工作场所与时间 → 原子化
3. 工会组织基础瓦解
4. 资本单方面制定劳动规则
5. 政治议程被商业利益支配 → 工人无力感

## 备注

- 与中国"外卖骑手困在系统里"现象精确对应
- 费舍尔原文："影响教育领域政治人物和管理者的唯一强大力量就是商业利益"
