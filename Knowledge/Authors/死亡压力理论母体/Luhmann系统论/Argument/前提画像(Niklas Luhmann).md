# Niklas Luhmann · 前提画像（世界观公理）

> 用途：理解 Luhmann 系统论全部论断的**地基**。他所有概念（自创生/操作封闭/双重偶然性）都从这五条前提推出。
> **读法**：前提成立 → 系统论成立；前提被攻破（如系统无边界）→ 全楼摇晃。

## 前提体系（五层公理）

| 层 | 前提 | 一句话 |
|---|---|---|
| 本体观 | 社会=**沟通系统**（非人/非行动/非意识） | 人不是社会的组成部分——人是环境 |
| 自生观 | 系统**自创生**（autopoiesis）——自己生产自己的部件 | 公司/国家/文明=自我维持的存在体 |
| 封闭观 | 系统**操作封闭**——只能用自己语言处理环境扰动 | 银行看不懂 AI=编码失效的前兆 |
| 观察观 | 观察者**二阶**——系统只能观察自己的观察 | 没有上帝视角，一切观察是系统内操作 |
| 反批判观 | 社会学**描述**社会而非**批判**社会（反 Habermas） | 系统没有好坏，只有演化成功/失败 |

## 立场画像

- 功能主义 + **反人本主义**（人=环境，颠覆人文传统）——读"社会没有人"论断时注意
- 反意识形态/反批判理论（与 Habermas 1970s 大论战：共识 vs 操作封闭）
- Zettelkasten 卡片盒方法论者（9 万张卡产出 70 本书）——"只做容易的"生产力哲学
- 保守主义政治底色（系统维持自身=默认正当）——对"系统压迫人"的批判天然免疫

## 推导链（前提 → 结论）

```
社会=沟通系统（前提1）→ 系统边界=沟通边界
     ↓
系统自创生（前提2）→ 存在体=自我维持的结构（公司的"求生"=自创生）
     ↓
操作封闭（前提3）→ 环境只被"翻译"为系统内操作（认知边界）
     ↓
双重偶然性 → 社会结构起源（互猜需要稳定化）
     ↓
二阶观察（前提4）→ 社会学=观察观察者（描述非批判，前提5）
```

## 与用户理论关系

- **自创生 = 用户"存在体"定义的系统论版**（生存半径的系统论表述）
- **操作封闭 = 逃逸 C1 不可通约性的系统论版**（系统只能用自己的价值体系换算）
- **复杂度化约 = 生存半径链条的认知边界环**
- 用户理论补 Luhmann 缺的：死亡压力作为系统演化的筛选变量（他有无目的的演化，用户给方向）
