# Autopoiesis（自创生）

## 标签

---

## 一、定义

**Autopoiesis**（自创生，又译"自我生产"）是 Luhmann 系统论的核心操作概念，借自智利神经生物学家 Humberto Maturana 和 Francisco Varela。原义指生命系统通过其构成要素的网络，持续生产这些构成要素本身——细胞生产蛋白质，蛋白质维持细胞。Luhmann 将其激进地转用于社会系统：**社会系统通过自己的操作（即沟通）生产自己的构成要素（即沟通），并在这一自我指涉的过程中维持自身**。

关键公式：
- 系统 = 操作的自我生产网络
- 社会系统的构成要素 = 沟通（Kommunikation）
- 沟通生产沟通 → 系统在操作中自创生

Luhmann 强调：Autopoiesis 不是目的论概念（系统不是为了某个目的而存在），而是描述性概念——系统只要还在操作，就在自创生；一旦操作停止，系统就消亡。

## 二、Luhmann 的论证

### 2.1 从生物学到社会学的转用
Reese-Schäfer 在第三章"三个关键概念"中指出，Luhmann 将自创生概念引入社会学是第二个重大范式转换（第一个是系统/环境的区分取代整体/部分范式）。传统社会学（如 Parsons）将系统理解为维持既有结构的功能实体；Luhmann 则把重点从"结构维持"（Bestandserhaltung）转向"操作的自我再生产"——系统不需要维持任何固定的实质，只需要持续操作。

### 2.2 自创生 = 操作封闭（Operationelle Schließung）
自创生系统是操作上封闭的：系统只能用自己内部的操作来指涉自己内部的操作。但这不等于能量或信息上的封闭——系统对环境开放（通过"结构耦合"，strukturelle Kopplung），但操作逻辑上是闭合的。意识系统（心理系统）用思想生产思想；社会系统用沟通生产沟通。一个沟通不能直接"进入"一个意识，反之亦然——它们彼此是对方的 Umwelt。

### 2.3 自创生与结构的关系
Luhmann 在《社会系统》（Soziale Systeme, 1984）中阐明：结构不是系统存在的条件，而是自创生操作中涌现的期望（Erwartungen）的沉淀。自创生先于结构——"功能先于结构"（Funktion vor Struktur）。这一翻转使 Luhmann 摆脱了 Parsons 的结构功能主义困境：社会变迁不再需要解释"结构如何改变"，因为结构的改变本身就是自创生系统操作的常态产物。

### 2.4 Autopoiesis 的三个维度
Reese-Schäfer 归纳：
1. **时间维度**：自创生操作是瞬间性的事件（Ereignis），一旦发生就消失，但通过与前/后操作的"衔接"（Anschluss）维持系统连续性；
2. **社会维度**：社会系统的自创生操作是沟通，沟通必须被理解（Verstehen）才能衔接——因此 Alter 和 Ego 的双重偶然性（doppelte Kontingenz）是自创生的内置张力；
3. **事实维度**：自创生系统通过"意义"（Sinn）选择性地处理环境信息，不是被动反映环境，而是主动建构。

## 三、与用户理论的连接

### 3.1 自创生 = 生存半径的系统论表述
用户的"生存半径"概念——每个存在体都有一个可维持自身连续性的操作半径——在 Luhmann 框架中找到了精确的系统论对应：**生存半径 = 自创生系统的操作域**。系统能自创生的范围就是它的生存半径。一旦环境扰动超出系统结构耦合的承受范围（即"过载"），自创生停止，系统消亡。

连接标注：[[自创生]] ⇄ [[生存半径]] — 系统自创生的边界即生存半径的边界。企业自创生（通过决策/支付沟通）停止 = 破产；国家自创生（通过权力/法律沟通）停止 = 崩溃；个体心理系统自创生（通过意识/思想）停止 = 死亡。

### 3.2 自创生 = 维持自身连续性 = [[正常行为是死亡恐惧的日常化]]
用户的"正常行为"理论指出：人类的一切"正常行为"（工作、社交、消费、生育）本质上都是对死亡恐惧的日常化处理——通过维持连续性的行为来遮蔽死亡的绝对断裂。Luhmann 的自创生给出了这一理论的形式化表达：**一切操作都是自创生操作，自创生操作的深层驱动力是维持系统连续性以对抗系统消亡**。

一个社会系统的"正常性"就是其自创生操作的稳定衔接模式。当衔接断裂（如金融危机中支付沟通中断），系统面临"死亡"威胁——此时"不正常"的行为（紧急救助、量化宽松）出现，以恢复自创生。这恰恰证明了：正常行为之所以"正常"，是因为它维持了自创生 = 维持了系统对死亡的屏蔽。

### 3.3 自创生的暗面：系统为何不能"自杀"
Luhmann 没有明确讨论——但 Reese-Schäfer 在第十三章暗示——自创生系统不能主动停止自创生：只要操作还在继续，系统就还在。这对应了用户理论中一个关键疑难：**逃逸的可能性**。系统能否主动终止自创生？如果可以，是什么使"自杀"（企业主动解散、国家主动解体、个人主动结束意识）成为可能？如果不能，则系统是自创生的囚徒——这与[[死亡恐惧]]的不可逃逸性形成同构。

### 3.4 文明锚点与自创生的嵌套
用户的[[人类文明锚点理论]]认为，文明通过一系列"锚点"（语言、货币、法律、宗教）固定意义并使大规模协作可能。在 Luhmann 框架中，这些锚点 = 社会系统自创生的**结构耦合节点**（通过 symbolisch generalisierte Kommunikationsmedien）。语言是沟通自创生的基础媒介；货币是经济系统自创生的媒介；法律是法律系统自创生的媒介。文明崩溃 = 这些结构耦合节点的同时断裂 = 自创生操作的大规模中断。

## 四、补充：自创生的"硬核"条件

Luhmann 为自创生设定了三个严格条件（据 Maturana/Varela 的原始框架改造）：

1. **要素的自生产**：系统要素（沟通）只能由系统自己生产。一个沟通不能被"导入"社会系统——外部刺激（如地震）产生的是社会系统内部"关于地震的沟通"，不是"地震本身"。新闻 ≠ 地震，新闻是关于地震的沟通。这一条件确保了系统的操作封闭。

2. **结构的自组织**：系统自己决定哪些沟通模式沉淀为结构。没有外部权威能"命令"一个社会系统改变其结构——只能 Irritation。这就是为什么"制度改革"如此困难：制度不是可替换的零件，而是系统自组织的产物。外部强制（如殖民统治、军事占领）可以破坏结构，但很难"建设"新结构——新结构必须由系统自己产生。

3. **边界的自确定**：系统自己决定系统/环境的边界。经济系统自己决定什么是"经济的"（支付/非支付）；法律系统自己决定什么是"合法的"。边界不是由外部观察者划定的——尽管外部观察者（如统计局）可以做出自己的边界定义，但那是在另一个系统中（科学系统）的操作，不影响被观察系统的自创生。

这三个条件也是**系统消亡的三个可能断裂点**：要素生产停止、自组织失灵、边界模糊化。对应用户理论：企业的"死亡"发生在支付沟通（要素）停止、组织无法自我决策（自组织失灵）、或"什么是本企业的业务"变得无法确定（边界崩溃）时。
