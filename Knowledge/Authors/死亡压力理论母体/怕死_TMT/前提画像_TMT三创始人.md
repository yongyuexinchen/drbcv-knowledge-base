# TMT 三创始人 · 前提画像（实证公理）

> 用途：理解恐惧管理理论全部实验设计的**地基**。三创始人（Solomon/Greenberg/Pyszczynski）把 Becker 哲学操作化为可实验的科学。
> **读法**：前提成立 → 300+ 实验证据有效；前提被攻破 → 实验解释全部失效。

## 前提体系（五层公理）

| 层 | 前提 | 一句话 |
|---|---|---|
| 意识观 | 人类是**唯一能预知其死亡的动物**——死亡意识是演化代价 | 智力的副产品=知道自己会死 |
| 焦虑观 | 死亡焦虑是**潜在可爆发**的（潜能，非持续状态） | 平时被压制，提醒即引爆（mortality salience） |
| 防御观 | 双层防御：**近端**（压制想法/转移）→ **远端**（文化世界观加固） | 刷手机=近端；更爱国/更努力=远端 |
| 缓冲观 | **文化世界观 + 自尊 = 焦虑缓冲器** | 世界观给你"我的活法有意义"，自尊给你"我活得好" |
| 实证观 | 死亡焦虑效应**可实验测量**（300+ 实验：法官判案/911/消费） | 哲学命题→实验证据（TMT 的贡献） |

## 立场画像

- 实验社会心理学传统（非哲学思辨）——Becker 理论的操作化
- 继承 Becker（三人在 Becker 去世后读到《Denial of Death》受启发）
- 1970s-80s 学界被拒（死亡主题不受待见）→ 300+ 实验后成为主流理论
- 对文化多样性的尊重（各文化都是不同缓冲结构——文化相对主义立场）

## 推导链（前提 → 结论）

```
人知道自己会死（前提1）→ 死亡焦虑潜能（前提2）
     ↓
死亡提醒（实验操作）→ 焦虑引爆（mortality salience）
     ↓
近端防御：压制（前提3）→ 失败后转远端
     ↓
远端防御：世界观加固（更爱国/更信教/更消费/更敌异族）（前提4）
     ↓
实验验证（前提5）→ 死亡显著性改变价值判断（法官保释金 9 倍）
```

## 与用户理论关系

- **mortality salience 实验 = "时代范式砸在每个人头上"的实验室证据**
- **双防御模型 = 用户"逃逸二型"的心理学机制**（近端=麻醉型/远端=反抗型）
- 用户理论补 TMT 缺的：结构尺度（跨文明/跨时代）+ 逃逸的不可转换性判据
