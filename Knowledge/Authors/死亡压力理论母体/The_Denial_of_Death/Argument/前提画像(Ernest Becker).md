# Ernest Becker · 前提画像（世界观公理）

> 用途：理解 Becker 全部结论的**地基**。他所有论断（英雄工程/关键谎言/恶的来源）都从这五条前提推出。
> **读法**：前提成立 → 结论成立；前提被攻破 → 全楼摇晃（如：若死亡焦虑非人类底色，则英雄工程论失效）。

## 前提体系（五层公理）

| 层 | 前提 | 一句话 |
|---|---|---|
| 人性观 | 人是**唯一知道自己会死的动物**——死亡意识是行为的终极发动机 | 不是性/权力，是死亡焦虑驱动一切 |
| 动机观 | 一切人类行为（善与恶）都是**死亡否认的变体** | 英雄工程=建造"我不死"的证明；恶=他人的英雄工程威胁我的 |
| 文明观 | 文明=**集体死亡否认装置**（hero systems） | 宗教/国家/事业=共享的永生工程 |
| 心理观 | 心理健康=**有效否认**（vital lie 的必要性） | 揭开谎言=直面死亡恐怖=崩溃风险；治疗是危险的 |
| 伦理观 | 接受**被造性**（creatureliness）是成熟 | 不靠英雄工程自欺，承认自己会死且渺小 |

## 立场画像

- 存在主义 + 精神分析（**Otto Rank 高于 Freud**——Freud 停滞于焦虑承认，Rank 走完圆圈）
- Kierkegaard 为精神先辈（焦虑学校——穿越焦虑而非逃离）
- 世俗人文主义 + **反越战**（解放集中营经历→对"英雄主义"的警惕：英雄工程是恶的温床）
- 1960s 美国学术边缘人（Berkeley 未续聘）——反主流立场

## 推导链（前提 → 结论）

```
人知道自己会死（前提1）→ 死亡焦虑不可承受（推论）
     ↓
需要否认（前提4：vital lie）→ 建造英雄工程（前提2）
     ↓
英雄工程互相冲突 → 恶/暴力（前提2 扩展：《Escape from Evil》）
     ↓
文明=集体英雄工程（前提3）→ 文明兴衰=英雄体系兴衰
     ↓
成熟=接受被造性（前提5）→ 真正超越死亡焦虑（《Denial of Death》结论）
```

## 与用户理论关系

- **Becker 的英雄工程 = 用户"反抗型逃逸"的心理学版**（系统学术语↔心理学术语）
- **vital lie = 用户"正常行为=最佳可用策略"**（v2 的 Becker 版）
- 用户理论补 Becker 缺的：系统尺度（Luhmann）+ 逃逸结构分析（C1-C4）
