# 接受国的经济稳定性与长期发展质量

> 属于因果簇：[[FDI优于组合投资，资源租金应投资于本国结构转型]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外商直接投资（FDI）与组合投资（热钱）的构成差异 |
| **DV（因变量）** | 接受国的经济稳定性与长期发展质量 |
| **Chain（传导链）** | FDI流向与接受国比较优势一致，带来技术、管理经验和市场渠道 → FDI具有长期性，恐慌期不易逆转，有助于稳定投资和增长 → 组合投资追求短期收益，快速进出引发资产泡沫和汇率波动 → 热钱流动加剧宏观经济不稳定性，损害长期发展 |
| **Lag（时滞）** | 短期（组合投资影响）至长期（FDI收益显现） |
| **Threshold（临界值）** | 当外资中以FDI为主且与比较优势匹配时，收益为正；组合投资占比过高则风险累积 |
| **前提与约束（Premises）** | 接受国具备基本的基础设施和制度能力以吸收FDI技术溢出；比较优势是动态的，需要配合结构转型政策；排除FDI集中于不可贸易部门或资源开采但无本地关联的情况 |
| **Falsification（证伪条件）** | 若发现FDI流入大量导致资本迅速外逃、技术溢出为负，或组合投资占比高但经济更稳定，则断言可被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> FDI像长期婚姻，热钱像一夜情：前者带来共同成长，后者留下混乱和损失。

### 🔗 文字版因果链

1. FDI流向与接受国比较优势一致，带来技术、管理经验和市场渠道
2. FDI具有长期性，恐慌期不易逆转，有助于稳定投资和增长
3. 组合投资追求短期收益，快速进出引发资产泡沫和汇率波动
4. 热钱流动加剧宏观经济不稳定性，损害长期发展
