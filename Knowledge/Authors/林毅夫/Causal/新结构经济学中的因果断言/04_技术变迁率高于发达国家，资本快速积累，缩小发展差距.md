# 技术变迁率高于发达国家，资本快速积累，缩小发展差距

> 属于因果簇：[[新结构经济学中的因果断言]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展中国家基于比较优势从发达国家引进成熟技术（后发优势） |
| **DV（因变量）** | 技术变迁率高于发达国家，资本快速积累，缩小发展差距 |
| **Chain（传导链）** | 发展中国家基于比较优势发展，主要依赖引进成熟技术 → 进口技术成本远低于发达国家自主研发成本 → 技术变迁率提高，资本回报率上升 → 高回报刺激资本积累热情，储蓄率上升 → 资本积累速度高于发达国家，要素禀赋结构差距缩小，实现经济收敛 |
| **Lag（时滞）** | 数十年，如东亚新兴工业化经济体维持几十年的快速增长 |
| **Threshold（临界值）** | 需要保持比发达国家更高的技术变迁率，且国内储蓄率相对较高 |
| **前提与约束（Premises）** | 发展中国家与发达国家都遵循各自的比较优势；存在可供引进的成熟技术和可进入的现有产业；发展中国家具备吸收技术所需的基本人力资本和基础设施条件 |
| **Falsification（证伪条件）** | 若发展中国家长期依赖技术进口却未能提高增长率或缩小与发达国家差距，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同学生站在巨人肩膀上学习现成知识，比老师自己探索新知识进步更快，只要方向正确就能逐步赶超

### 🔗 文字版因果链

1. 发展中国家基于比较优势发展，主要依赖引进成熟技术
2. 进口技术成本远低于发达国家自主研发成本
3. 技术变迁率提高，资本回报率上升
4. 高回报刺激资本积累热情，储蓄率上升
5. 资本积累速度高于发达国家，要素禀赋结构差距缩小，实现经济收敛
