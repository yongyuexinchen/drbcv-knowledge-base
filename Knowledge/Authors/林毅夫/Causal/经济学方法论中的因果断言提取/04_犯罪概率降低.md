# 犯罪概率降低

> 属于因果簇：[[经济学方法论中的因果断言提取]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 监督更严或惩罚更重 |
| **DV（因变量）** | 犯罪概率降低 |
| **Chain（传导链）** | 监督更严或惩罚更重提高了犯罪成本 → 潜在罪犯在理性权衡成本收益 → 当犯罪成本高于预期收益时，选择不犯罪 → 犯罪概率降低 |
| **Lag（时滞）** | 制度实施后，短期至中期内 |
| **Threshold（临界值）** | 监督或惩罚的变化足以逆转犯罪的成本收益比较 |
| **前提与约束（Premises）** | 罪犯是理性的，追求效用最大化；犯罪决策受成本和收益影响 |
| **Falsification（证伪条件）** | 如果监督和惩罚增加而犯罪率不变或上升，则推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水果摊安装监控和罚款告示后，偷水果的人减少

### 🔗 文字版因果链

1. 监督更严或惩罚更重提高了犯罪成本
2. 潜在罪犯在理性权衡成本收益
3. 当犯罪成本高于预期收益时，选择不犯罪
4. 犯罪概率降低
