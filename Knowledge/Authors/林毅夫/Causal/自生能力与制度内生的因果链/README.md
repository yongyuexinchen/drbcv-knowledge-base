# 自生能力与制度内生的因果链（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：自生能力与制度内生的因果链.md

## 总体因果图

- 政府实施违背比较优势的赶超型发展战略（优先发展资本密集型重工业） → 形成传统计划经济体制（价格扭曲、计划配置、国有化、剥夺企业自
- 企业缺乏自生能力 → 形成预算软约束
- 以暗含企业有自生能力为前提的新古典理论制定转型政策 → 转型政策失败（达不到预期甚至使问题恶化）
- 政府持续扶持不符合比较优势的无自生能力企业 → 寻租横行、收入分配不公、效率低下、债务危机 金融危机
- 按比较优势发展经济（以提升要素禀赋结构为目标） → 经济持续增长并向发达国家收敛
