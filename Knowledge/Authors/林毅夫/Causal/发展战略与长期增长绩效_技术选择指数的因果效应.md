# 发展战略与长期增长绩效：技术选择指数的因果效应

> **领域**：发展经济学 / 宏观经济学　|　**来源**：_cand2_lin_13.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 技术选择指数（TCI）提高，即更大程度地违背比较优势的发展战略 |
| **DV（因变量）** | 经济长期增长绩效恶化（人均GDP增长率下降）；经济波动性增大；收入分配不平等加剧；制度与市场扭曲增加（黑市溢价上升、经济自由度下降、征用风险上升、企业自主权下降、开放度下降） |
| **Chain（传导链）** | 政府通过产业政策等干预手段，将资源配置到违背比较优势的资本密集型部门，导致TCI上升 → 要素价格和资源配置发生系统性扭曲，经济中的市场机制受到抑制，寻租与黑市交易增多 → 企业自主决策权被压缩，开放度降低，制度质量恶化（如征用风险上升、经济自由度下降） → 总资源配置效率和生产效率下降，长期人均GDP增长率降低 → 经济结构趋向刚性和非均衡，对外部冲击的适应能力减弱，宏观经济波动性增大 → 政策偏向少数受保护的资本密集型行业，收入分配向特权集团倾斜，基尼系数上升 |
| **Lag（时滞）** | 长期，通常5-10年及以上；实证基于1962-1999年面板数据反映的长期效应，转型期ΔTCI的影响在1%-0.13%的增长率变化上亦有显现 |
| **Threshold（临界值）** | TCI每提高10% → 人均GDP年增长率下降约0.1个百分点；TCI每提高10% → 经济波动性提高4%-6%；TCI系数对基尼系数在1%水平显著为正；转型期ΔTCI每降低10% → 增长率上升0.1-0.13个百分点 |
| **前提与约束（Premises）** | 适用于以比较优势为基础分析框架的市场经济或多体制混合经济体，且TCI能有效度量违背比较优势程度；需控制制度质量、开放度、地理与市场规模等混杂因素，并使用工具变量处理内生性；因果关系在长期增长维度成立，短期冲击或政策逆周期干预可能暂时掩盖效应；样本范围基于122国1962-1999年面板数据，外推到其他时期或国家群需谨慎 |
| **Falsification（证伪条件）** | 若在类似或更大样本中发现TCI提高后人均GDP增长率未下降、波动性未上升或基尼系数不显著为正；或当更严格地控制其他变量时TCI系数失去统计显著性；或存在证据表明因果方向由增长绩效反向决定TCI，则可推翻该断言 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人如果长期违背自己的天赋优势，硬去从事不擅长的职业，虽然可能靠外部扶持短期维持，但长期来看职业成就更差、收入起伏更大、并且资源分配会更偏向少数有特权的人，最终整体状况反而不如顺应天赋发展

### 🔗 文字版因果链

1. 政府通过产业政策等干预手段，将资源配置到违背比较优势的资本密集型部门，导致TCI上升
2. 要素价格和资源配置发生系统性扭曲，经济中的市场机制受到抑制，寻租与黑市交易增多
3. 企业自主决策权被压缩，开放度降低，制度质量恶化（如征用风险上升、经济自由度下降）
4. 总资源配置效率和生产效率下降，长期人均GDP增长率降低
5. 经济结构趋向刚性和非均衡，对外部冲击的适应能力减弱，宏观经济波动性增大
6. 政策偏向少数受保护的资本密集型行业，收入分配向特权集团倾斜，基尼系数上升
