# 经济崩溃、大规模失业和社会政治不稳定

> 属于因果簇：[[转型经济中改革战略与绩效的因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 休克疗法（大爆炸式改革） |
| **DV（因变量）** | 经济崩溃、大规模失业和社会政治不稳定 |
| **Chain（传导链）** | 休克疗法瞬间消除所有价格扭曲和政府对无自生能力企业的保护 → 大型转型经济中存在大量无自生能力的企业，重新暴露于市场竞争 → 这些企业大规模破产，引发产出崩溃和大量失业 → 失业和产出下降导致社会和政治动荡 → 政府为避免彻底崩溃，重新引入变相保护和补贴，成本往往高于原有扭曲 |
| **Lag（时滞）** | 价格放开和私有化后数月到数年（如俄罗斯1992年初放开价格，当年经济即剧烈下滑） |
| **Threshold（临界值）** | 当无自生能力企业在经济中占比较高（如大型社会主义国家），休克疗法必然导致剧烈转型衰退；若企业规模小（如波罗的海小国），则转型成本较小 |
| **前提与约束（Premises）** | 转型前计划经济已形成大量依赖保护的无自生能力重工业；资本和劳动力不能快速跨部门转移；不存在完善的市场机制和足够多的新产业就业岗位 |
| **Falsification（证伪条件）** | 如果某个大型转型经济体在存在大量无自生能力企业的情况下实施休克疗法，却实现了平稳增长且无大规模失业和崩溃，则可推翻该断言 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 给缠着厚绷带的骨折病人动大手术，一刀剪掉所有绷带后让他立刻跑步，结果伤口撕裂、人摔倒在地

### 🔗 文字版因果链

1. 休克疗法瞬间消除所有价格扭曲和政府对无自生能力企业的保护
2. 大型转型经济中存在大量无自生能力的企业，重新暴露于市场竞争
3. 这些企业大规模破产，引发产出崩溃和大量失业
4. 失业和产出下降导致社会和政治动荡
5. 政府为避免彻底崩溃，重新引入变相保护和补贴，成本往往高于原有扭曲
