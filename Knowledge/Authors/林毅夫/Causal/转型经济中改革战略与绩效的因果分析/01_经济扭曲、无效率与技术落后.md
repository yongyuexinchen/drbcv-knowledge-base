# 经济扭曲、无效率与技术落后

> 属于因果簇：[[转型经济中改革战略与绩效的因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的重工业优先发展战略 |
| **DV（因变量）** | 经济扭曲、无效率与技术落后 |
| **Chain（传导链）** | 政府优先发展资本密集型重工业，与低收入经济的要素禀赋结构不一致 → 重工业企业缺乏自生能力，必须依靠政府保护与补贴 → 政府财政能力有限，转而采用行政扭曲（低利率、高估汇率、压低工资和原材料价格）来降低成本 → 扭曲导致信贷、外汇、原材料和生活必需品短缺 → 政府通过计划配给和行政控制分配稀缺资源，国有企业丧失自主权 → 激励机制被削弱，企业效率持续下降，最终导致经济停滞和全要素生产率下降 |
| **Lag（时滞）** | 初期增长可能持续一二十年，但效率衰减在数十年内逐步显现（如苏联约50年，中国20余年） |
| **Threshold（临界值）** | 当重工业项目所需资本密度与人均资本禀赋差距足够大，且政府缺乏充足财政补贴能力时，扭曲必然产生并累积 |
| **前提与约束（Premises）** | 经济处于低收入、资本稀缺、外汇匮乏的农业社会；政府拥有强力干预经济的意愿和能力；企业为国有或受政府控制，价格由行政决定 |
| **Falsification（证伪条件）** | 如果存在一个违背比较优势发展战略的国家，长期保持高效率增长且未出现系统性扭曲、企业亏损和资源错配，则可推翻该断言 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 政府优先发展资本密集型重工业，与低收入经济的要素禀赋结构不一致
2. 重工业企业缺乏自生能力，必须依靠政府保护与补贴
3. 政府财政能力有限，转而采用行政扭曲（低利率、高估汇率、压低工资和原材料价格）来降低成本
4. 扭曲导致信贷、外汇、原材料和生活必需品短缺
5. 政府通过计划配给和行政控制分配稀缺资源，国有企业丧失自主权
6. 激励机制被削弱，企业效率持续下降，最终导致经济停滞和全要素生产率下降
