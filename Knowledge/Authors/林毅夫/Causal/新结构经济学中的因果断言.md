# 新结构经济学中的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的产业和技术选择 |
| **DV（因变量）** | 经济持续增长与结构转型 |
| **Chain（传导链）** | 一个国家的要素禀赋结构（资本劳动比）决定其比较优势 → 根据比较优势选择劳动/资源密集型向资本密集型升级的产业 → 企业在国内外市场具有竞争力，产生尽可能大的经济剩余 → 经济剩余再投资使资本积累加快，提升人力资本和技术水平 → 要素禀赋结构升级，推动产业结构升级，实现持续增长 |
| **Lag（时滞）** | 长期过程，可能需一两代人的时间 |
| **Threshold（临界值）** | 无明确量化临界值；需保持与要素禀赋结构一致的比较优势，不可超过最优升级速度 |
| **前提与约束（Premises）** | 存在竞争性市场经济，价格体系反映要素相对稀缺性；政府发挥因势利导作用，协调提供基础设施；适用于低收入、中等收入和高收入国家；除矿产品和农场外，生产初期缺乏规模经济，由小家户经营 |
| **Falsification（证伪条件）** | 若能发现遵循比较优势却长期停滞，或违背比较优势却持续增长的国家案例，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同根据自身身高体重选择适合的运动项目，而不是硬练不适合自己的项目，才能发挥优势，持续进步

### 🔗 文字版因果链

1. 一个国家的要素禀赋结构（资本劳动比）决定其比较优势
2. 根据比较优势选择劳动/资源密集型向资本密集型升级的产业
3. 企业在国内外市场具有竞争力，产生尽可能大的经济剩余
4. 经济剩余再投资使资本积累加快，提升人力资本和技术水平
5. 要素禀赋结构升级，推动产业结构升级，实现持续增长

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 软硬件基础设施质量的改善 |
| **DV（因变量）** | 企业的交易成本及国际竞争力 |
| **Chain（传导链）** | 基础设施影响企业获取投入品和出售产出的交易成本 → 糟糕的基础设施导致频繁停电、物流不畅、港口效率低下、官僚作风盛行 → 企业交易成本上升，抵消低工资优势 → 企业在国际市场上缺乏竞争力，经济发展受限 |
| **Lag（时滞）** | 短期至中期显现，不一定存在固定时滞 |
| **Threshold（临界值）** | 无量化阈值；基础设施需与产业升级阶段相匹配 |
| **前提与约束（Premises）** | 要素禀赋在给定时间内不变；对企业而言，大部分硬件和几乎全部软件基础设施是外生的；在低收入国家劳动密集型产业中尤为显著 |
| **Falsification（证伪条件）** | 若发现基础设施较差但企业仍具备国际竞争力并维持增长，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同开餐馆，菜做得好但水电不通、道路难行，顾客不来，竞争力不如基础设施完善的对手

### 🔗 文字版因果链

1. 基础设施影响企业获取投入品和出售产出的交易成本
2. 糟糕的基础设施导致频繁停电、物流不畅、港口效率低下、官僚作风盛行
3. 企业交易成本上升，抵消低工资优势
4. 企业在国际市场上缺乏竞争力，经济发展受限

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府主动提供或协调软硬件基础设施改善 |
| **DV（因变量）** | 产业升级顺利实现与经济发展 |
| **Chain（传导链）** | 产业升级要求更大的市场、更高的资本规模、更复杂的交易 → 需要金融、法律、通信、港口等软硬件基础设施同步改善 → 私人企业无法内部化基础设施改善成本，自发协调往往失败 → 政府必须提供或协调集体行动，否则基础设施成为发展瓶颈 → 基础设施改善降低交易成本，支持新产业达到规模经济，推动经济发展 |
| **Lag（时滞）** | 中长期间，基础设施建设周期长且效果有滞后性 |
| **Threshold（临界值）** | 当基础设施需求超过私人企业供给能力时，政府介入成为必要 |
| **前提与约束（Premises）** | 产业升级过程中对基础设施的需求会不断变化；存在搭便车问题，导致集体行动失败；政府有能力承担或协调基础设施改善 |
| **Falsification（证伪条件）** | 若发现政府不协调而私人自发解决了基础设施并实现产业升级，或政府干预反而阻碍升级，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同社区要通道路和管道，单家独户修不了，需要物业或政府统一规划建设

### 🔗 文字版因果链

1. 产业升级要求更大的市场、更高的资本规模、更复杂的交易
2. 需要金融、法律、通信、港口等软硬件基础设施同步改善
3. 私人企业无法内部化基础设施改善成本，自发协调往往失败
4. 政府必须提供或协调集体行动，否则基础设施成为发展瓶颈
5. 基础设施改善降低交易成本，支持新产业达到规模经济，推动经济发展

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展中国家基于比较优势从发达国家引进成熟技术（后发优势） |
| **DV（因变量）** | 技术变迁率高于发达国家，资本快速积累，缩小发展差距 |
| **Chain（传导链）** | 发展中国家基于比较优势发展，主要依赖引进成熟技术 → 进口技术成本远低于发达国家自主研发成本 → 技术变迁率提高，资本回报率上升 → 高回报刺激资本积累热情，储蓄率上升 → 资本积累速度高于发达国家，要素禀赋结构差距缩小，实现经济收敛 |
| **Lag（时滞）** | 数十年，如东亚新兴工业化经济体维持几十年的快速增长 |
| **Threshold（临界值）** | 需要保持比发达国家更高的技术变迁率，且国内储蓄率相对较高 |
| **前提与约束（Premises）** | 发展中国家与发达国家都遵循各自的比较优势；存在可供引进的成熟技术和可进入的现有产业；发展中国家具备吸收技术所需的基本人力资本和基础设施条件 |
| **Falsification（证伪条件）** | 若发展中国家长期依赖技术进口却未能提高增长率或缩小与发达国家差距，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同学生站在巨人肩膀上学习现成知识，比老师自己探索新知识进步更快，只要方向正确就能逐步赶超

### 🔗 文字版因果链

1. 发展中国家基于比较优势发展，主要依赖引进成熟技术
2. 进口技术成本远低于发达国家自主研发成本
3. 技术变迁率提高，资本回报率上升
4. 高回报刺激资本积累热情，储蓄率上升
5. 资本积累速度高于发达国家，要素禀赋结构差距缩小，实现经济收敛
