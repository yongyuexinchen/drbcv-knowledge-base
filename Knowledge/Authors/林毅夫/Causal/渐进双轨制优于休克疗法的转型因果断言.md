# 渐进双轨制优于休克疗法的转型因果断言

> **领域**：转型经济学/宏观经济学　|　**来源**：_cand2_lin_09.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 改革策略：从严重扭曲经济出发，选择渐进双轨制（先放开符合比较优势但被压制的部门，同时对旧优先部门无自生能力企业提供临时保护并逐步退出），而非休克疗法（一次性全面放开、立即取消保护） |
| **DV（因变量）** | 经济转型绩效：能否实现“没有输家的改革”、避免社会动荡、形成持续增长（而非“有休克无疗效”的L形衰退） |
| **Chain（传导链）** | 严重扭曲经济中存在大量依赖保护、缺乏自生能力的旧优先部门企业； → 若选择休克疗法：一次性放开市场和取消保护，大量无自生能力企业集中破产，失业骤增，引发社会动荡，经济急剧下跌后长期无法恢复，落入L形增长； → 若选择渐进双轨制：先放开被压制但符合比较优势的新部门，释放增长潜力，创造就业和税收； → 同时对旧优先部门无自生能力企业提供临时保护，避免其瞬间破产造成社会冲击； → 随着新部门成长壮大，逐步降低和退出对旧企业的保护，使资源从旧部门平稳转向新部门； → 最终在增长中创造改革可信度，实现“没有输家”的转型，经济保持可持续增长。 |
| **Lag（时滞）** | 休克疗法的破坏性冲击通常在1-3年内显现；双轨制的增长效果需要新部门成长和保护逐步退出的时间，显著见效常在数年至十余年；L形衰退的恢复期可能超过十年。 |
| **Threshold（临界值）** | 当旧优先部门中无自生能力企业比重高到一旦集中破产就会引发系统性失业和社会动荡时，改革必须采用双轨制；若此类企业很少（如玻利维亚情形），休克疗法有可能成功。 |
| **前提与约束（Premises）** | 经济处于严重扭曲状态，存在大量缺乏自生能力的旧优先部门企业；；存在一批之前被压制但符合比较优势、放开后能迅速发展的新部门；；政府具备区分有自生能力与无自生能力企业、提供临时保护并能逐步退出的制度能力；；改革过程需要保持政治稳定，使双轨制保护不会退化为永久补贴。 |
| **Falsification（证伪条件）** | 如果在存在大量无自生能力企业的扭曲经济中，休克疗法仍能带来持续增长且无严重社会动荡；或者双轨制导致旧部门保护永久化、新部门增长停滞，最终转型失败，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 改造一栋住满人的老楼：不能一次性拆掉所有承重墙（休克疗法），否则楼塌人伤；应一边加盖或加固新单元，一边逐步替换旧墙、让住户搬入新居后再拆除旧结构（双轨制），才能做到无人流离失所。

### 🔗 文字版因果链

1. 严重扭曲经济中存在大量依赖保护、缺乏自生能力的旧优先部门企业；
2. 若选择休克疗法：一次性放开市场和取消保护，大量无自生能力企业集中破产，失业骤增，引发社会动荡，经济急剧下跌后长期无法恢复，落入L形增长；
3. 若选择渐进双轨制：先放开被压制但符合比较优势的新部门，释放增长潜力，创造就业和税收；
4. 同时对旧优先部门无自生能力企业提供临时保护，避免其瞬间破产造成社会冲击；
5. 随着新部门成长壮大，逐步降低和退出对旧企业的保护，使资源从旧部门平稳转向新部门；
6. 最终在增长中创造改革可信度，实现“没有输家”的转型，经济保持可持续增长。
