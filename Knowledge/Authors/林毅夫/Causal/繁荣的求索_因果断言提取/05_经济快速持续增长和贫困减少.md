# 经济快速持续增长和贫困减少

> 属于因果簇：[[繁荣的求索：因果断言提取]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的因势利导型产业政策 |
| **DV（因变量）** | 经济快速持续增长和贫困减少 |
| **Chain（传导链）** | 政府甄别与本国禀赋结构相符、且已在类似高增长国家成功的产业 → 消除产业发展的基础设施和制度约束 → 为先行企业提供暂时性激励 → 私营企业进入并形成竞争力 → 资本快速积累、产业升级 → 实现持续增长和减贫 |
| **Lag（时滞）** | 数年可见产业成长，数十年可见整体经济转型 |
| **Threshold（临界值）** | 参照国人均收入约为本国的两倍（100%），且目标产业过去20年增长良好 |
| **前提与约束（Premises）** | 市场在资源配置中起基础作用；政府有甄别和执行能力；激励是暂时性且小规模的 |
| **Falsification（证伪条件）** | 若多个国家严格遵循该战略却长期未能实现增长，或违背该战略的国家反而成功，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 政府甄别与本国禀赋结构相符、且已在类似高增长国家成功的产业
2. 消除产业发展的基础设施和制度约束
3. 为先行企业提供暂时性激励
4. 私营企业进入并形成竞争力
5. 资本快速积累、产业升级
6. 实现持续增长和减贫
