# 产业发展失败，即“挑选失败者”

> 属于因果簇：[[繁荣的求索：因果断言提取]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的产业发展战略（如过于激进地选择过先进产业） |
| **DV（因变量）** | 产业发展失败，即“挑选失败者” |
| **Chain（传导链）** | 目标产业与国家的禀赋结构不一致 → 优先产业中的企业在开放竞争市场中没有自生能力 → 政府不得不通过补贴和保护维持企业生存 → 造成资源错配、寻租和腐败 → 最终导致结构失衡和发展失败 |
| **Lag（时滞）** | 初期可能短期增长，但危机和停滞在数年至数十年内显现 |
| **Threshold（临界值）** | 产业要素密集度与禀赋结构偏离达到某种程度，企业无法在无扭曲市场生存 |
| **前提与约束（Premises）** | 存在开放或竞争性市场环境；政府有动机扶持优先产业（如政治目标） |
| **Falsification（证伪条件）** | 如果一些国家长期严重违背比较优势却实现了持续经济和产业升级，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同让矮个子强行打篮球职业联赛，没有天赋却硬上，只能靠不断输血维持，最终球队瘫痪

### 🔗 文字版因果链

1. 目标产业与国家的禀赋结构不一致
2. 优先产业中的企业在开放竞争市场中没有自生能力
3. 政府不得不通过补贴和保护维持企业生存
4. 造成资源错配、寻租和腐败
5. 最终导致结构失衡和发展失败
