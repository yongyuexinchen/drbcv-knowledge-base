# 繁荣的求索：因果断言提取（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：繁荣的求索_因果断言提取.md

## 总体因果图

- 为国家繁荣做出贡献 → 政治领导人继续掌权和在历史上获得好名声
- 制定并实施国家层面可行的经济政策 → 国家实现持续经济增长
- 政府帮助克服产业升级中固有的协调性和外部性问题 → 经济结构从农业向现代产业成功转型
- 违背比较优势的产业发展战略（如过于激进地选择过先进产业） → 产业发展失败，即“挑选失败者”
- 遵循比较优势的因势利导型产业政策 → 经济快速持续增长和贫困减少
- 全球化 → 发展中国家通过专业化实现工业化
