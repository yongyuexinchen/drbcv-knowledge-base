# 银行商业化与利率市场化改革难以落实

> 属于因果簇：[[国有企业自生能力与政策性负担的因果链条]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国有企业的政策性负担 |
| **DV（因变量）** | 银行商业化与利率市场化改革难以落实 |
| **Chain（传导链）** | 国有企业存在政策性负担，需要政府补贴 → “拨改贷”后补贴手段变为银行低息贷款 → 政府必须继续通过银行低息贷款支持国有企业 → 银行信贷配置受政策干预而非商业原则 → 利率无法由市场供求决定，商业化改革难以推进 |
| **Lag（时滞）** | 自“拨改贷”政策实施后持续存在，改革进程受阻 |
| **Threshold（临界值）** | 国有企业仍有政策性负担，政府依赖银行低息贷款作为补贴渠道 |
| **前提与约束（Premises）** | 国有企业无法破产，政府必须给予补贴；银行体系承担政策性补贴功能；利率市场化会提高国企融资成本，与补贴目标冲突 |
| **Falsification（证伪条件）** | 若国有企业仍然承担政策性负担，但银行商业化、利率市场化改革仍能实质性推进且国企无需低息贷款补贴，则此断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 病人离不开呼吸机，医生不敢轻易拔管；银行就是那台维持生命的呼吸机。

### 🔗 文字版因果链

1. 国有企业存在政策性负担，需要政府补贴
2. “拨改贷”后补贴手段变为银行低息贷款
3. 政府必须继续通过银行低息贷款支持国有企业
4. 银行信贷配置受政策干预而非商业原则
5. 利率无法由市场供求决定，商业化改革难以推进
