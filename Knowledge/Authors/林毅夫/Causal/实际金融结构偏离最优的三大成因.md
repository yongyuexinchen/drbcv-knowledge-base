# 实际金融结构偏离最优的三大成因

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 领导人理念（金融抑制服务于违背比较优势的战略）、政策顾问盲目推销英美模式、政治联盟利益（银行准入限制） |
| **DV（因变量）** | 实际金融结构偏离最优 |
| **Chain（传导链）** | 领导人出于优先发展重工业等违背比较优势的战略目标，选择金融抑制工具 → 金融抑制通过人为压低利率、管制信贷，将廉价资金配置到优先发展部门 → 专制体制下银行信贷集中于政府和精英关联企业，普通部门融资被挤压 → 同时，政策顾问脱离本土条件推销英美金融模式，误导金融结构改革方向 → 政治联盟为维护既得利益，设置银行准入限制，阻碍竞争性金融结构形成 → 以上因素共同导致金融结构与本国要素禀赋决定的最优结构系统性偏离 |
| **Lag（时滞）** | 长期（数十年），如中国50年代重工业优先战略到70年代末银行体系完全并入央行；改革后数十年四大国有银行主导格局持续存在 |
| **Threshold（临界值）** | 当领导人战略违背比较优势且政治联盟有能力维持准入限制时，偏离程度显著加大；不存在单一量化拐点，但可观察金融结构指标（如信贷集中度、中小企业融资占比）与最优结构持续脱节 |
| **前提与约束（Premises）** | 金融抑制确实服务于领导人认定的优先部门融资需求；政策顾问的建议对实际政策制定具有实质性影响力；政治联盟能够维护银行准入限制并抵制放开；存在一个可由要素禀赋决定的“最优金融结构”作为参照基准 |
| **Falsification（证伪条件）** | 若能证明即使领导人理念完全符合比较优势、且无外部顾问误导、政治联盟无准入限制，实际金融结构仍系统性偏离最优，则本断言被推翻；或者若发现上述三大因素与金融结构偏离之间无显著相关或因果方向相反 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人明明适合穿38码鞋，但领导者偏爱大鞋、鞋店老板只卖名牌小鞋、利益集团还垄断进货渠道，最后他脚上穿的鞋必然不合脚——不是脚的问题，是制度与理念共同扭曲了选择。

### 🔗 文字版因果链

1. 领导人出于优先发展重工业等违背比较优势的战略目标，选择金融抑制工具
2. 金融抑制通过人为压低利率、管制信贷，将廉价资金配置到优先发展部门
3. 专制体制下银行信贷集中于政府和精英关联企业，普通部门融资被挤压
4. 同时，政策顾问脱离本土条件推销英美金融模式，误导金融结构改革方向
5. 政治联盟为维护既得利益，设置银行准入限制，阻碍竞争性金融结构形成
6. 以上因素共同导致金融结构与本国要素禀赋决定的最优结构系统性偏离
