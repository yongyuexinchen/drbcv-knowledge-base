# 企业缺乏自生能力，并产生寻租空间

> 属于因果簇：[[政府作用：因势利导而非主导一切]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的政府干预（主导一切、过度保护） |
| **DV（因变量）** | 企业缺乏自生能力，并产生寻租空间 |
| **Chain（传导链）** | 政府主导资源配置，扶持不符合比较优势的产业。 → 企业无法在开放竞争中独立生存，依赖补贴、关税和保护。 → 企业为维持特殊利益而进行寻租，扭曲市场信号。 → 资源错配加剧，产业效率低下，长期难以升级。 |
| **Lag（时滞）** | 干预实施后数月到数年开始出现依赖，长期（10年以上）形成路径锁定。 |
| **Threshold（临界值）** | 当政府干预强度超过“弥补市场失灵”的边界，且产业明显偏离比较优势时。 |
| **前提与约束（Premises）** | 政府试图替代市场而不是补充市场。；所选产业在要素禀赋结构上不具备比较优势。；缺乏退出机制，企业可长期依靠保护生存。 |
| **Falsification（证伪条件）** | 如果存在违背比较优势的产业在无长期补贴条件下成功自生、且未出现明显寻租，则该断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 拔苗助长：因急于求成而用力过度，结果反而让禾苗枯萎；强行扶持劣势产业往往适得其反。

### 🔗 文字版因果链

1. 政府主导资源配置，扶持不符合比较优势的产业。
2. 企业无法在开放竞争中独立生存，依赖补贴、关税和保护。
3. 企业为维持特殊利益而进行寻租，扭曲市场信号。
4. 资源错配加剧，产业效率低下，长期难以升级。
