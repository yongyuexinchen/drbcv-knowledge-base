# 转型绩效（经济增长、社会稳定）

> 属于因果簇：[[新结构经济学因果断言集]]（第9块/15块）

## 因果断言 9

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 改革方式：双轨制渐进改革 vs 休克疗法 |
| **DV（因变量）** | 转型绩效（经济增长、社会稳定） |
| **Chain（传导链）** | 从严重扭曲经济出发 → 双轨制先放开符合比较优势但被压制的部门 → 同时对旧优先部门无自生能力企业提供临时保护 → 逐步退出保护，实现没有输家的改革 → 在增长中创造改革可信度；休克疗法突然取消保护 → 大量无自生能力企业破产，社会动荡 → 陷入“有休克无疗效”的L形增长 |
| **Lag（时滞）** | 休克疗法立即引发崩溃；双轨制在数年内见效 |
| **Threshold（临界值）** | 扭曲严重、无自生能力企业多时双轨制更优；扭曲程度低（如玻利维亚）时休克疗法也可成功 |
| **前提与约束（Premises）** | 转型前存在大量背离比较优势的产业；政府有能力实施渐进式保护并逐步退出；社会对短期阵痛的容忍度有限 |
| **Falsification（证伪条件）** | 如果休克疗法在严重扭曲国家也持续产生高增长，或双轨制在类似国家普遍失败，则断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 从严重扭曲经济出发
2. 双轨制先放开符合比较优势但被压制的部门
3. 同时对旧优先部门无自生能力企业提供临时保护
4. 逐步退出保护，实现没有输家的改革
5. 在增长中创造改革可信度；休克疗法突然取消保护
6. 大量无自生能力企业破产，社会动荡
7. 陷入“有休克无疗效”的L形增长
