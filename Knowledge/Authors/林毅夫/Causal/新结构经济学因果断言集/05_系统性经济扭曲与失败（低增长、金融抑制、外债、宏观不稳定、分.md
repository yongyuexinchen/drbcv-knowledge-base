# 系统性经济扭曲与失败（低增长、金融抑制、外债、宏观不稳定、分

> 属于因果簇：[[新结构经济学因果断言集]]（第5块/15块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的发展战略（优先发展不具比较优势的资本密集产业） |
| **DV（因变量）** | 系统性经济扭曲与失败（低增长、金融抑制、外债、宏观不稳定、分配恶化） |
| **Chain（传导链）** | 优先发展资本密集重工业但不具比较优势 → 企业无自生能力 → 政府被迫给予补贴和保护 → 利率、汇率等价格被扭曲 → 产生寻租和预算软约束 → 导致金融抑制、外债积累、宏观不稳定、收入分配恶化 |
| **Lag（时滞）** | 长期（数十年积累，扭曲与危机逐渐显性化） |
| **Threshold（临界值）** | 偏离程度越大，扭曲越深；人均收入水平与目标产业所需禀赋差距过大（如人均收入仅为目标国5%-30%）时几乎必败 |
| **前提与约束（Premises）** | 信息不对称使政府无法区分政策性负担与经营不善；企业会以政策性负担为借口索取更多补贴；政府有资源且愿意持续补贴 |
| **Falsification（证伪条件）** | 如果有国家长期严重违背比较优势却实现了持续增长和结构升级，则该断言需要修正。 |
| **Confidence（确信度）** | well-established |

3. 政府被迫给予补贴和保护

5. 产生寻租和预算软约束
6. 导致金融抑制、外债积累、宏观不稳定、收入分配恶化
