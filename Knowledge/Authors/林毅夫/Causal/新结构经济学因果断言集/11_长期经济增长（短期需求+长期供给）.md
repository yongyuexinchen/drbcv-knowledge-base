# 长期经济增长（短期需求+长期供给）

> 属于因果簇：[[新结构经济学因果断言集]]（第11块/15块）

## 因果断言 11

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 衰退期基础设施投资（财政政策）与降息（货币政策） |
| **DV（因变量）** | 长期经济增长（短期需求+长期供给） |
| **Chain（传导链）** | 基础设施是发展中国家增长的紧约束 → 衰退期公共投资成本低 → 短期增加需求、长期提高生产率 → 基础设施降低私人交易成本、提高私人回报 → 未来税收足以偿还投资成本，避免李嘉图等价陷阱 → 发展中国家不易陷入流动性陷阱，降息刺激生产率投资 |
| **Lag（时滞）** | 短期需求效应即时，长期供给效应数年至数十年 |
| **Threshold（临界值）** | 公共项目回报率需高于成本：通信项目平均回报30%-40%、发电超40%、道路超200% |
| **前提与约束（Premises）** | 基础设施存在明显缺口；经济处于衰退期有闲置资源；政府财政可持续且税收能力足以覆盖长期成本 |
| **Falsification（证伪条件）** | 如果衰退期基础设施投资导致债务危机且无显著增长效果，则断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 基础设施是发展中国家增长的紧约束
2. 衰退期公共投资成本低
3. 短期增加需求、长期提高生产率
4. 基础设施降低私人交易成本、提高私人回报
5. 未来税收足以偿还投资成本，避免李嘉图等价陷阱
6. 发展中国家不易陷入流动性陷阱，降息刺激生产率投资
