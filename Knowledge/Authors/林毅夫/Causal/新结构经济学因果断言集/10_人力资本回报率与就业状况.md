# 人力资本回报率与就业状况

> 属于因果簇：[[新结构经济学因果断言集]]（第10块/15块）

## 因果断言 10

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人力资本积累与产业升级的同步性 |
| **DV（因变量）** | 人力资本回报率与就业状况 |
| **Chain（传导链）** | 人力资本是禀赋的组成部分 → 新产业要求新技能 → 人力资本必须与物质资本积累和产业升级齐头并进 → 过度超前投资导致高学历劳动力超出产业吸收能力 → 出现高学历失业和“沮丧的年轻一代” → 人力资本投资浪费 |
| **Lag（时滞）** | 中期（5-10年，教育周期后显现） |
| **Threshold（临界值）** | 人力资本增速超过产业升级对技能的需求即为“超前” |
| **前提与约束（Premises）** | 人力资本与物质资本互补而非替代；学习内容必须与发展水平相适应；劳动力市场存在摩擦 |
| **Falsification（证伪条件）** | 如果大量高学历人才在低发展阶段被高效吸收并显著推动增长，则断言需要修正。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 跳高横杆要随着能力提高才升，一开始就放在世界纪录高度只能撞杆。

### 🔗 文字版因果链

1. 人力资本是禀赋的组成部分
2. 新产业要求新技能
3. 人力资本必须与物质资本积累和产业升级齐头并进
4. 过度超前投资导致高学历劳动力超出产业吸收能力
5. 出现高学历失业和“沮丧的年轻一代”
6. 人力资本投资浪费
