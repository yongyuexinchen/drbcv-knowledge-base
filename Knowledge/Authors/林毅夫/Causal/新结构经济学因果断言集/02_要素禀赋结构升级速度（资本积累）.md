# 要素禀赋结构升级速度（资本积累）

> 属于因果簇：[[新结构经济学因果断言集]]（第2块/15块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的发展战略 |
| **DV（因变量）** | 要素禀赋结构升级速度（资本积累） |
| **Chain（传导链）** | 遵循比较优势使企业最有竞争力 → 有竞争力的企业占有最大市场份额 → 最大市场份额创造最大经济剩余 → 剩余再投资回报最高 → 储蓄与积累最快 → 禀赋结构升级最快 |
| **Lag（时滞）** | 中长期（数十年持续积累） |
| **Threshold（临界值）** | 需持续遵循比较优势，无单一阈值；自我强化循环启动后增速可达8%-10% |
| **前提与约束（Premises）** | 存在开放竞争的市场；企业利润可自由再投资；政府不扭曲价格信号 |
| **Falsification（证伪条件）** | 如果遵循比较优势的国家在长期内资本积累速度和禀赋结构升级慢于违背比较优势的国家，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 顺水行舟，看似慢，实则比逆水划桨更快到达。

### 🔗 文字版因果链

1. 遵循比较优势使企业最有竞争力
2. 有竞争力的企业占有最大市场份额
3. 最大市场份额创造最大经济剩余
4. 剩余再投资回报最高
5. 储蓄与积累最快
6. 禀赋结构升级最快
