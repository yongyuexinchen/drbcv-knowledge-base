# 产业政策成功率（经济增长与产业升级）

> 属于因果簇：[[新结构经济学因果断言集]]（第6块/15块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 增长甄别与因势利导六步法（GIFF）的使用 |
| **DV（因变量）** | 产业政策成功率（经济增长与产业升级） |
| **Chain（传导链）** | 政府选优失败源于缺乏甄别标准 → 正确方法是以禀赋相似、人均收入约为本国100%、高速增长20年以上的国家为镜 → 学习其成熟贸易品产业 → 清除私企进入障碍、吸引FDI、设立产业特区等六步支持 → 将潜在比较优势转化为实际比较优势 → 实现产业升级与增长 |
| **Lag（时滞）** | 中期至长期（10-20年） |
| **Threshold（临界值）** | 模仿对象人均收入应约为本国的100%（或差距在40%-75%左右）；若选择人均收入差距过大（<10%）的先进产业则多失败 |
| **前提与约束（Premises）** | 存在禀赋相似且曾高速增长的先行国；目标产业是可贸易品且技术可获取；政府有执行力且政治稳定 |
| **Falsification（证伪条件）** | 如果严格按照GIFF选择产业的国家普遍失败，而反其道行之的产业政策成功，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 跟着跑在前面的同龄人学步，而不是直接挑战世界纪录。

### 🔗 文字版因果链

1. 政府选优失败源于缺乏甄别标准
2. 正确方法是以禀赋相似、人均收入约为本国100%、高速增长20年以上的国家为镜
3. 学习其成熟贸易品产业
4. 清除私企进入障碍、吸引FDI、设立产业特区等六步支持
5. 将潜在比较优势转化为实际比较优势
6. 实现产业升级与增长
