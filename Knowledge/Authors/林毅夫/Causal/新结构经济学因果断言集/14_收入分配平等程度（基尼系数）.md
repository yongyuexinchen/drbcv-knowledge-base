# 收入分配平等程度（基尼系数）

> 属于因果簇：[[新结构经济学因果断言集]]（第14块/15块）

## 因果断言 14

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展战略（遵循/违背比较优势） |
| **DV（因变量）** | 收入分配平等程度（基尼系数） |
| **Chain（传导链）** | 遵循比较优势的战略促进劳动密集型产业发展 → 劳动密集型产业创造大量就业 → 穷人最重要的资产是劳动力，工资上升 → 收入不平等缩小 → 违背比较优势的战略偏向资本密集型产业 → 就业有限，补贴流向资本所有者 → 收入不平等扩大 |
| **Lag（时滞）** | 中长期（10-20年） |
| **Threshold（临界值）** | TCI与初始GINI是收入分配最重要的两个决定因素；GDPPC及其平方项不显著（拒绝倒U假说） |
| **前提与约束（Premises）** | 穷人主要依赖劳动力收入；劳动密集型产业在低收入阶段占主导地位；经济处于开放竞争环境 |
| **Falsification（证伪条件）** | 如果存在显著库兹涅茨倒U曲线，或遵循比较优势的国家不平等持续恶化，则断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 授人以渔，让穷人靠劳动力致富，而不是把鱼都分给资本。

### 🔗 文字版因果链

1. 遵循比较优势的战略促进劳动密集型产业发展
2. 劳动密集型产业创造大量就业
3. 穷人最重要的资产是劳动力，工资上升
4. 收入不平等缩小
5. 违背比较优势的战略偏向资本密集型产业
6. 就业有限，补贴流向资本所有者
7. 收入不平等扩大
