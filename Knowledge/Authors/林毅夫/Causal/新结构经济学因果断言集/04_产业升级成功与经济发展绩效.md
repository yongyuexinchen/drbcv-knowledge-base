# 产业升级成功与经济发展绩效

> 属于因果簇：[[新结构经济学因果断言集]]（第4块/15块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府因势利导的干预（信息、协调、外部性补偿、基础设施） |
| **DV（因变量）** | 产业升级成功与经济发展绩效 |
| **Chain（传导链）** | 市场失灵存在（信息外部性、协调问题、先行者外部性） → 政府需要发挥积极作用 → 干预限于因势利导：提供信息、协调投资、补偿先驱企业外部性、改善软硬基础设施 → 帮助私人部门进入潜在比较优势产业 → 实现产业升级和经济成功 |
| **Lag（时滞）** | 中期（政策实施后数年可见效果） |
| **Threshold（临界值）** | 干预必须与比较优势一致，且不能越界为直接主导生产 |
| **前提与约束（Premises）** | 市场失灵确实制约产业发展；政府具备信息收集和执行能力；政府不被既得利益集团俘获 |
| **Falsification（证伪条件）** | 如果多数国家在政府因势利导干预下比完全自由放任表现更差，或干预普遍变成寻租工具，则该断言被削弱。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 助产士帮助婴儿出生，但不替代母亲怀胎。

### 🔗 文字版因果链

1. 市场失灵存在（信息外部性、协调问题、先行者外部性）
2. 政府需要发挥积极作用
3. 干预限于因势利导：提供信息、协调投资、补偿先驱企业外部性、改善软硬基础设施
4. 帮助私人部门进入潜在比较优势产业
5. 实现产业升级和经济成功
