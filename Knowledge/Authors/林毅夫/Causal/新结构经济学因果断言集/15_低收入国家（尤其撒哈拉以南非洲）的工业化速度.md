# 低收入国家（尤其撒哈拉以南非洲）的工业化速度

> 属于因果簇：[[新结构经济学因果断言集]]（第15块/15块）

## 因果断言 15

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国等新兴市场工资上升 |
| **DV（因变量）** | 低收入国家（尤其撒哈拉以南非洲）的工业化速度 |
| **Chain（传导链）** | 中国等新兴市场工资上升 → 劳动密集型产业利润空间收窄 → 企业向外转移产业 → 中国释放8500万个劳动密集型制造业岗位 → 低收入国家可承接这些产业实现快速工业化 → 中国企业外迁顾虑可通过接受国承诺和产业特区解决 |
| **Lag（时滞）** | 中期至长期（10-20年） |
| **Threshold（临界值）** | 即使1%的中国服装生产转移即可使非洲服装出口增加47% |
| **前提与约束（Premises）** | 接受国政局稳定；劳动法灵活、物流基础设施改善；产业特区有效运转 |
| **Falsification（证伪条件）** | 如果中国劳动密集型产业大部分被自动化替代而非外移，或非洲承接后未能实现工业化，则断言需修正。 |
| **Confidence（确信度）** | well-established |
