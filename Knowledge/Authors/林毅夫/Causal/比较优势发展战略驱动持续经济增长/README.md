# 比较优势发展战略驱动持续经济增长（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：比较优势发展战略驱动持续经济增长.md

## 总体因果图

- 遵循比较优势的发展战略 → 持续经济增长和成功赶超
- 遵循比较优势的发展战略 → 宏观经济稳定
- 遵循比较优势的发展战略 → 高储蓄率和投资率
- 运转良好的市场机制 → 企业遵循比较优势并实现资源有效配置
- 守信、可靠且有能力的政府（因势利导型政府） → 克服市场失灵，促进产业升级和结构变迁
- 违背比较优势的产业政策 → 增长失败和经济停滞
