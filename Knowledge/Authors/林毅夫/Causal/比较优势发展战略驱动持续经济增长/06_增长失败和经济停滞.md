# 增长失败和经济停滞

> 属于因果簇：[[比较优势发展战略驱动持续经济增长]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的产业政策 |
| **DV（因变量）** | 增长失败和经济停滞 |
| **Chain（传导链）** | 在资本稀缺的低收入国家优先发展资本密集型重工业 → 企业缺乏自生能力，依赖政府补贴、保护和价格扭曲得以生存 → 政府财政负担加重，资源严重错配 → 产业缺乏国际竞争力，出口创汇能力弱 → 内源性财政危机和货币危机频发，经济无法持续增长 |
| **Lag（时滞）** | 中期至长期，错误产业政策的恶果逐渐显现 |
| **Threshold（临界值）** | 产业选择严重偏离要素禀赋结构，且政府长期维持大规模扶持 |
| **前提与约束（Premises）** | 发展中国家处于资本相对稀缺、劳动力或资源相对丰富的阶段；政府无法无限期提供补贴和保护而避免危机 |
| **Falsification（证伪条件）** | 若发现一些国家长期严重违背比较优势却实现了持续快速增长，且没有严重危机，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 让一个瘦弱的人去当举重冠军，强行训练只能导致受伤和失败，无法真正强壮起来。

### 🔗 文字版因果链

1. 在资本稀缺的低收入国家优先发展资本密集型重工业
2. 企业缺乏自生能力，依赖政府补贴、保护和价格扭曲得以生存
3. 政府财政负担加重，资源严重错配
4. 产业缺乏国际竞争力，出口创汇能力弱
5. 内源性财政危机和货币危机频发，经济无法持续增长
