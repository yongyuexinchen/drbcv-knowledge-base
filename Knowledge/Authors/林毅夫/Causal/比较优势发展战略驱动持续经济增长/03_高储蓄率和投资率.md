# 高储蓄率和投资率

> 属于因果簇：[[比较优势发展战略驱动持续经济增长]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的发展战略 |
| **DV（因变量）** | 高储蓄率和投资率 |
| **Chain（传导链）** | 具有比较优势的产业在国内国际市场上有竞争力，产生大量经济盈余 → 高额投资回报为储蓄提供强有力激励 → 企业和居民将盈余转化为储蓄 → 储蓄通过金融体系配置为投资，形成高储蓄率和高投资率 |
| **Lag（时滞）** | 中期，如韩国在20世纪60年代储蓄率约10%，70年代后上升到30%以上 |
| **Threshold（临界值）** | 现有产业能产生足够高的利润和投资回报；储蓄率出现显著持续上升 |
| **前提与约束（Premises）** | 金融体系能够有效吸收储蓄并配置投资；文化或社会习惯不构成长期根本障碍（作者反对文化决定论） |
| **Falsification（证伪条件）** | 若发现遵循比较优势的国家在长期内储蓄率和投资率依然低下，则该断言被证伪。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 做自己擅长的工作赚钱多，自然能存下钱；做不擅长的事总是亏损，谈不上储蓄和投资。

### 🔗 文字版因果链

1. 具有比较优势的产业在国内国际市场上有竞争力，产生大量经济盈余
2. 高额投资回报为储蓄提供强有力激励
3. 企业和居民将盈余转化为储蓄
4. 储蓄通过金融体系配置为投资，形成高储蓄率和高投资率
