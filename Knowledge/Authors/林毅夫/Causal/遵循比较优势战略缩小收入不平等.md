# 遵循比较优势战略缩小收入不平等

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势战略（发展劳动密集型产业） |
| **DV（因变量）** | 收入不平等程度（缩小） |
| **Chain（传导链）** | 遵循比较优势战略，选择符合要素禀赋的劳动密集型产业 → 劳动密集型产业扩张，创造大量就业机会 → 穷人依靠劳动力这一主要资产获得工资收入 → 劳动力需求上升推动穷人工资提高 → 穷人收入增长快于资本所有者，收入不平等缩小 |
| **Lag（时滞）** | 中期至长期（取决于产业结构调整和就业吸纳速度） |
| **Threshold（临界值）** | 战略选择必须与要素禀赋结构一致，即优先发展具有比较优势的产业；违背该战略则效果相反 |
| **前提与约束（Premises）** | 穷人最重要的资产是劳动力；劳动力市场能够有效匹配就业机会；劳动密集型产业具有足够的规模以吸收剩余劳动力；初始收入分配状况（初始GINI）既定且作为重要条件 |
| **Falsification（证伪条件）** | 若发现遵循比较优势战略的经济体在较长时期内收入不平等反而扩大，或违背比较优势战略的经济体不平等显著缩小，则该因果断言被削弱或推翻 |
| **Confidence（确信度）** | well-established |
