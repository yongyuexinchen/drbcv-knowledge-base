# 产业政策的成功或失败

> 属于因果簇：[[《本体与常无》中的因果断言提取]]（第1块/8块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 产业政策是否符合要素禀赋结构所决定的比较优势 |
| **DV（因变量）** | 产业政策的成功或失败 |
| **Chain（传导链）** | 要素禀赋结构决定了一个经济的比较优势 → 符合比较优势的产业具有自生能力，企业可以在开放竞争市场中生存 → 不符合比较优势的产业缺乏自生能力，需要政府保护和补贴才能生存 → 因此符合比较优势的产业政策成功，不符合的失败 |
| **Lag（时滞）** | 长期，通常数十年（如日本60年代到成功，中国50年代至今仍依赖保护） |
| **Threshold（临界值）** | 人均收入按购买力平价达到美国40%左右时汽车产业优先发展属比较优势；5%左右时属赶超 |
| **前提与约束（Premises）** | 要素禀赋结构是比较优势的唯一决定因素；企业追求利润、市场机制发挥作用；存在开放竞争的市场环境 |
| **Falsification（证伪条件）** | 如果发现一个不符合比较优势的产业政策能够长期成功且无需政府补贴保护，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 举重比赛按体重分级，轻量级选手非要举重量级的杠铃必然失败，强行拔高只会受伤。

### 🔗 文字版因果链

1. 要素禀赋结构决定了一个经济的比较优势
2. 符合比较优势的产业具有自生能力，企业可以在开放竞争市场中生存
3. 不符合比较优势的产业缺乏自生能力，需要政府保护和补贴才能生存
4. 因此符合比较优势的产业政策成功，不符合的失败
