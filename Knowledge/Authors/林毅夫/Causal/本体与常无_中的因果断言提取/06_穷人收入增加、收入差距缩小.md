# 穷人收入增加、收入差距缩小

> 属于因果簇：[[《本体与常无》中的因果断言提取]]（第6块/8块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 按比较优势发展劳动密集型产业 |
| **DV（因变量）** | 穷人收入增加、收入差距缩小 |
| **Chain（传导链）** | 按比较优势发展劳动密集型产业，创造大量就业机会 → 穷人的劳动力得到充分就业 → 劳动力需求增加，工资逐渐上升 → 资本报酬逐渐下降 → 穷人和富人的收入差距随着经济发展逐渐缩小 |
| **Lag（时滞）** | 中期（随经济发展和资本积累逐步显现） |
| **Threshold（临界值）** | 产品和要素市场充分竞争 |
| **前提与约束（Premises）** | 穷人只有劳动力，富人拥有资本；初始禀赋结构为劳动力相对丰富、资本相对稀缺；制度环境允许市场发挥决定性作用 |
| **Falsification（证伪条件）** | 若在充分竞争市场上按比较优势发展后穷人的收入份额没有增加、差距没有缩小，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 授人以渔——给穷人创造就业机会，比直接给鱼更能持续改善其生活。

### 🔗 文字版因果链

1. 按比较优势发展劳动密集型产业，创造大量就业机会
2. 穷人的劳动力得到充分就业
3. 劳动力需求增加，工资逐渐上升
4. 资本报酬逐渐下降
5. 穷人和富人的收入差距随着经济发展逐渐缩小
