# 增长绩效（人均GDP增长率、波动性、收入分配、扭曲程度）

> 属于因果簇：[[新结构经济学因果断言集]]（第13块/15块）

## 因果断言 13

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 技术选择指数（TCI，度量违背比较优势的程度） |
| **DV（因变量）** | 增长绩效（人均GDP增长率、波动性、收入分配、扭曲程度） |
| **Chain（传导链）** | TCI越高表示产业结构越偏离禀赋结构 → 偏离产生扭曲：黑市溢价上升、经济自由下降、征用风险上升、企业自主权下降、开放度下降 → 扭曲恶化了资源配置效率 → 导致增长越差、波动越大、分配越不平等 |
| **Lag（时滞）** | 长期（10年以上，面板数据覆盖1962-1999） |
| **Threshold（临界值）** | TCI提高10%→人均GDP年增长率下降约0.1个百分点；TCI提高10%→波动性提高4%-6%；ΔTCI每降10%→增长率升0.1-0.13个百分点 |
| **前提与约束（Premises）** | 数据为122国1962-1999年面板数据；已控制制度质量、开放度、地理与市场规模；使用工具变量处理内生性 |
| **Falsification（证伪条件）** | 如果TCI与增长、波动、分配无显著关系或方向相反，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 胆固醇指数越高，心血管病风险越大。

### 🔗 文字版因果链

1. TCI越高表示产业结构越偏离禀赋结构
2. 偏离产生扭曲：黑市溢价上升、经济自由下降、征用风险上升、企业自主权下降、开放度下降
3. 扭曲恶化了资源配置效率
4. 导致增长越差、波动越大、分配越不平等
