# 发展中国家通过专业化实现工业化

> 属于因果簇：[[繁荣的求索：因果断言提取]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球化 |
| **DV（因变量）** | 发展中国家通过专业化实现工业化 |
| **Chain（传导链）** | 全球化降低运输成本和贸易壁垒 → 扩大产品市场规模 → 使小国也能实现大规模生产 → 各国按比较优势专业分工 → 在后发优势下实现工业化 |
| **Lag（时滞）** | 全球化趋势下通常一二十年 |
| **Threshold（临界值）** | 全球市场可及性使得规模经济超过国内市场规模限制 |
| **前提与约束（Premises）** | 国家遵循比较优势战略；存在开放的贸易体系和全球供应链；优良的软硬基础设施支撑交易成本 |
| **Falsification（证伪条件）** | 如果全球化不断深化但遵循比较优势的国家未能通过专业化实现工业化，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同小店在电商平台上能把特色手工艺品卖到全国，依靠平台带来的广阔市场做大做强

### 🔗 文字版因果链

1. 全球化降低运输成本和贸易壁垒
2. 扩大产品市场规模
3. 使小国也能实现大规模生产
4. 各国按比较优势专业分工
5. 在后发优势下实现工业化
