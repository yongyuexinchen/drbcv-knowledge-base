# 经济持续增长并向发达国家收敛

> 属于因果簇：[[自生能力与制度内生的因果链]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 按比较优势发展经济（以提升要素禀赋结构为目标） |
| **DV（因变量）** | 经济持续增长并向发达国家收敛 |
| **Chain（传导链）** | 按当前要素禀赋结构决定的比较优势选择产业、产品和技术 → 企业具有自生能力，在开放竞争市场中有竞争力 → 整个经济创造最大剩余 → 资本回报率高，积累意愿强，要素禀赋结构提升快 → 要素禀赋结构提升推动产业、产品、技术升级 → 利用与发达国家的技术差距低成本引进技术，实现收敛 |
| **Lag（时滞）** | 中长期动态过程 |
| **Threshold（临界值）** | 产品和要素价格反映国际市场和资源稀缺性，市场开放竞争，政府提供信息协调和有限补贴 |
| **前提与约束（Premises）** | 开放、竞争的市场环境；政府提供产业政策以解决信息外部性和协调问题；补贴仅用于补偿信息外部性且有限期；土地等自然资源禀赋给定 |
| **Falsification（证伪条件）** | 如果按比较优势发展的国家没有实现更快增长和收敛，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 顺着水流划船比逆水行舟更快更省力，更易抵达目的地。

### 🔗 文字版因果链

1. 按当前要素禀赋结构决定的比较优势选择产业、产品和技术
2. 企业具有自生能力，在开放竞争市场中有竞争力
3. 整个经济创造最大剩余
4. 资本回报率高，积累意愿强，要素禀赋结构提升快
5. 要素禀赋结构提升推动产业、产品、技术升级
6. 利用与发达国家的技术差距低成本引进技术，实现收敛
