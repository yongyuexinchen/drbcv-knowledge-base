# 政府作用：因势利导而非主导一切

> **领域**：发展经济学　|　**来源**：_cand2_lin_04.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场失灵（信息外部性、协调问题、先行者外部性） |
| **DV（因变量）** | 政府必须发挥积极作用，但干预应限于因势利导（提供信息、协调投资、补偿先驱企业外部性、改善软硬基础设施） |
| **Chain（传导链）** | 市场存在信息外部性、协调问题和先行者外部性，导致私人部门无法单独实现产业升级。 → 若不干预，市场失灵持续，企业难以进入有潜在比较优势的新产业。 → 政府通过提供信息、协调投资、补偿先行者外部性、改善基础设施，降低交易成本和风险。 → 企业得以顺应比较优势发展，产业成功升级，经济实现增长。 |
| **Lag（时滞）** | 政策实施后短期内见效，但产业升级效果需中长期（5-20年）显现。 |
| **Threshold（临界值）** | 干预必须严格限定于弥补明确的市场失灵，且不偏离本国比较优势。 |
| **前提与约束（Premises）** | 存在真实且可识别的市场失灵（信息外部性、协调问题、先行者外部性）。；政府有能力制定并执行针对性干预政策。；干预方向不违背比较优势原则。 |
| **Falsification（证伪条件）** | 如果政府完全不干预但市场自发解决了协调与外部性问题，或政府因势利导干预后产业仍然失败，则该断言被削弱。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 政府像助产士：帮助产妇顺利分娩，但不替她生孩子。只应在关键时刻扶持，而不是永久包办。

### 🔗 文字版因果链

1. 市场存在信息外部性、协调问题和先行者外部性，导致私人部门无法单独实现产业升级。
2. 若不干预，市场失灵持续，企业难以进入有潜在比较优势的新产业。
3. 政府通过提供信息、协调投资、补偿先行者外部性、改善基础设施，降低交易成本和风险。
4. 企业得以顺应比较优势发展，产业成功升级，经济实现增长。

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 违背比较优势的政府干预（主导一切、过度保护） |
| **DV（因变量）** | 企业缺乏自生能力，并产生寻租空间 |
| **Chain（传导链）** | 政府主导资源配置，扶持不符合比较优势的产业。 → 企业无法在开放竞争中独立生存，依赖补贴、关税和保护。 → 企业为维持特殊利益而进行寻租，扭曲市场信号。 → 资源错配加剧，产业效率低下，长期难以升级。 |
| **Lag（时滞）** | 干预实施后数月到数年开始出现依赖，长期（10年以上）形成路径锁定。 |
| **Threshold（临界值）** | 当政府干预强度超过“弥补市场失灵”的边界，且产业明显偏离比较优势时。 |
| **前提与约束（Premises）** | 政府试图替代市场而不是补充市场。；所选产业在要素禀赋结构上不具备比较优势。；缺乏退出机制，企业可长期依靠保护生存。 |
| **Falsification（证伪条件）** | 如果存在违背比较优势的产业在无长期补贴条件下成功自生、且未出现明显寻租，则该断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 拔苗助长：因急于求成而用力过度，结果反而让禾苗枯萎；强行扶持劣势产业往往适得其反。

### 🔗 文字版因果链

1. 政府主导资源配置，扶持不符合比较优势的产业。
2. 企业无法在开放竞争中独立生存，依赖补贴、关税和保护。
3. 企业为维持特殊利益而进行寻租，扭曲市场信号。
4. 资源错配加剧，产业效率低下，长期难以升级。
