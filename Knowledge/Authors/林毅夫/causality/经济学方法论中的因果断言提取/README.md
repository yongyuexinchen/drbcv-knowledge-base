# 经济学方法论中的因果断言提取（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：经济学方法论中的因果断言提取.md

## 总体因果图

- 发达国家与发展中国家的发展阶段、要素禀赋、制度安排不完全一样 → 发达国家的最优选择在发展中国家不见得是最优的
- 生产决策者都按要素禀赋所决定的比较优势选择产业、产品、技术 → 资本得到最快速积累，上一期的最佳选择到了下一期不再是最佳
- 发展中国家去发展资本密集的产业（违背比较优势） → 政府不得不进行保护、补贴，市场作用受到干预
- 监督更严或惩罚更重 → 犯罪概率降低
- 债务链条（债务紧缩机制） → 投资需求和消费需求下降，经济增长速度为负或接近零
- 直接假定人的偏好是可变的 → 不能增加对行为改变原因的了解，降低预测和改变行为的能力
