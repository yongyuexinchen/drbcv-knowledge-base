# 农业产出大幅增长

> 属于因果簇：[[转型经济中改革战略与绩效的因果分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 家庭联产承包责任制（农业产权激励改革） |
| **DV（因变量）** | 农业产出大幅增长 |
| **Chain（传导链）** | 农民获得固定期限的土地承包权，可保留剩余产出 → 农民生产激励与努力程度直接挂钩 → 劳动积极性提高，农业资源配置效率改善 → 农业生产率上升，总产出显著增加 |
| **Lag（时滞）** | 1978年试点，1983年基本普及，农业产出在约5年内实现一倍以上增长 |
| **Threshold（临界值）** | 土地承包期足够稳定（从1年到后来15年、30年），确保农民有长期投资和生产预期 |
| **前提与约束（Premises）** | 农村人口占绝对多数，农业是经济主体；国家仍保留农产品统购统销制度，但允许农民保留剩余；土地分配相对公平，农民具有独立经营决策权 |
| **Falsification（证伪条件）** | 如果农业增长主要来自化肥价格放开、技术进步等其他改革，而非家庭承包责任制的激励效应，该断言将被削弱；若在未实行承包制的情况下农业同样高速增长，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 农民获得固定期限的土地承包权，可保留剩余产出
2. 农民生产激励与努力程度直接挂钩
3. 劳动积极性提高，农业资源配置效率改善
4. 农业生产率上升，总产出显著增加
