# 违背比较优势战略导致系统性扭曲与失败

> **领域**：发展经济学/宏观经济学　|　**来源**：_cand2_lin_05.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 优先发展资本密集重工业（不具比较优势）的战略 |
| **DV（因变量）** | 系统性扭曲与失败（企业无自生能力、政府补贴保护、利率汇率扭曲、寻租、预算软约束、金融抑制、外债积累、宏观不稳定、收入分配恶化） |
| **Chain（传导链）** | 政府优先发展资本密集重工业，背离本国要素禀赋所决定的比较优势 → 资本密集企业在开放竞争市场中缺乏自生能力，难以盈利 → 政府为维持企业生存被迫提供补贴与保护（压低利率、高估汇率、行政垄断等） → 价格信号被扭曲，资源配置偏离实际要素结构 → 信息不对称下政府难以甄别政策性负担与经营不善，企业以政策性负担为借口索取更多补贴 → 预算约束软化，经理人缺乏提高生产率的激励，寻租蔓延 → 持续补贴保护导致金融抑制、外债积累、宏观不稳定 → 经济缺乏持续增长动力，收入分配恶化，最终系统性失败 |
| **Lag（时滞）** | 中长期显现，通常在数年至数十年间逐步暴露（如埃及50年代工业化、拉美/非洲/南亚进口替代案例） |
| **Threshold（临界值）** | 当政府持续将资本密集型产业置于比较优势之上，且需以长期扭曲利率、汇率、信贷等价格进行补贴保护时，因果链启动并强化 |
| **前提与约束（Premises）** | 经济体的要素禀赋为劳动丰富、资本稀缺；存在信息不对称使政府无法区分政策性负担与经营不善；政府具备干预价格和配置资源的行政能力且不愿退出保护；该断言适用于封闭或半封闭的赶超型经济体（如进口替代阶段） |
| **Falsification（证伪条件）** | 如果存在一个优先发展资本密集重工业的国家，在无扭曲补贴情况下企业仍能盈利并提升全要素生产率，且未出现金融抑制、外债危机、宏观不稳定及收入分配恶化，则该断言被推翻；或相反，若去掉政府保护后系统未崩溃，则因果中介不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 好比让一个农民不种地非去造火箭：火箭造不出来，还要政府不断给补贴、免息贷款，最后钱越补越多，自家地也荒了，全村欠一屁股债

### 🔗 文字版因果链

1. 政府优先发展资本密集重工业，背离本国要素禀赋所决定的比较优势
2. 资本密集企业在开放竞争市场中缺乏自生能力，难以盈利
3. 政府为维持企业生存被迫提供补贴与保护（压低利率、高估汇率、行政垄断等）
4. 价格信号被扭曲，资源配置偏离实际要素结构
5. 信息不对称下政府难以甄别政策性负担与经营不善，企业以政策性负担为借口索取更多补贴
6. 预算约束软化，经理人缺乏提高生产率的激励，寻租蔓延
7. 持续补贴保护导致金融抑制、外债积累、宏观不稳定
8. 经济缺乏持续增长动力，收入分配恶化，最终系统性失败
