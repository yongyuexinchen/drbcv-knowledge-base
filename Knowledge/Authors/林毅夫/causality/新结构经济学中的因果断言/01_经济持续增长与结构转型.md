# 经济持续增长与结构转型

> 属于因果簇：[[新结构经济学中的因果断言]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循比较优势的产业和技术选择 |
| **DV（因变量）** | 经济持续增长与结构转型 |
| **Chain（传导链）** | 一个国家的要素禀赋结构（资本劳动比）决定其比较优势 → 根据比较优势选择劳动/资源密集型向资本密集型升级的产业 → 企业在国内外市场具有竞争力，产生尽可能大的经济剩余 → 经济剩余再投资使资本积累加快，提升人力资本和技术水平 → 要素禀赋结构升级，推动产业结构升级，实现持续增长 |
| **Lag（时滞）** | 长期过程，可能需一两代人的时间 |
| **Threshold（临界值）** | 无明确量化临界值；需保持与要素禀赋结构一致的比较优势，不可超过最优升级速度 |
| **前提与约束（Premises）** | 存在竞争性市场经济，价格体系反映要素相对稀缺性；政府发挥因势利导作用，协调提供基础设施；适用于低收入、中等收入和高收入国家；除矿产品和农场外，生产初期缺乏规模经济，由小家户经营 |
| **Falsification（证伪条件）** | 若能发现遵循比较优势却长期停滞，或违背比较优势却持续增长的国家案例，则该断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同根据自身身高体重选择适合的运动项目，而不是硬练不适合自己的项目，才能发挥优势，持续进步

### 🔗 文字版因果链

1. 一个国家的要素禀赋结构（资本劳动比）决定其比较优势
2. 根据比较优势选择劳动/资源密集型向资本密集型升级的产业
3. 企业在国内外市场具有竞争力，产生尽可能大的经济剩余
4. 经济剩余再投资使资本积累加快，提升人力资本和技术水平
5. 要素禀赋结构升级，推动产业结构升级，实现持续增长
