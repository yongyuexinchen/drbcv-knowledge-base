## 主传导链

```
要素禀赋结构（劳动/资本/自然资源相对丰裕度）
  → 决定比较优势（价格信号系：开放竞争市场中的要素相对稀缺度）
  → 发展战略选择（遵循 VS 违背比较优势）
  → 企业自生能力（有/无）与市场扭曲程度（价格/配置/所有制）
  → 技术选择（劳动密集型 VS 资本密集型）与产业升级路径
  → 资本积累速度与禀赋结构升级（最快路径：遵循比较优势）
  → 产业结构转型（从劳动密集到资本密集的梯度升级）
  → 经济增长绩效（人均GDP增长、波动性、危机频率）
  → 收入分配（穷人的劳动力是否被充分吸纳）
  → 政治可持续性（领导人掌权与历史名声）
  
  关键时滞：① 禀赋结构升级需要数十年连续投资（一代人以上）；② 违背比较优势的扭曲成本在5-10年后以财政/金融危机显现；③ 人力资本过度超前于产业升级在3-5年内表现为人才失业；④ 产业转移（领头龙）需10-20年工资上升积累才触发。

  违背比较优势的反向链：
  重工业优先战略 → 企业无自生能力 → 政府补贴保护（价格扭曲/金融抑制/贸易保护） → 预算软约束与寻租 → 宏观经济波动与经济停滞 → 收入不平等扩大 → 制度扭曲固化 → 转型时需渐进双轨（新部门放开+旧部门保护）
```

## 不变式

1. **禀赋决定论**：要素禀赋结构（劳动/资本/自然资源）是产业结构与技术选择的唯一最终决定因素，市场均衡价格必须反映要素相对稀缺度。
2. **自生能力前提**：任何企业只有在开放竞争市场中无需外部保护即可获得社会可接受的利润，才具备自生能力——这是所有扭曲分析的隐含基准。
3. **比较优势动态性**：比较优势随禀赋结构升级而动态变化，产业政策必须随之调整（GIFF六步法嵌入此动态）。
4. **因势利导的政府边界**：政府干预只应针对可识别的市场失灵（信息外部性、协调问题、先行者外部性），且不得违背比较优势方向。
5. **渐进转型铁律**：从扭曲经济出发，任何改革必须保证没有输家（新部门放开+旧部门暂时保护），否则必然失败。
