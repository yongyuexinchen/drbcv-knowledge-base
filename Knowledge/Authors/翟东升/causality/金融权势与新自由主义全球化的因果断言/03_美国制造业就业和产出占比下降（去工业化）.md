# 美国制造业就业和产出占比下降（去工业化）

> 属于因果簇：[[金融权势与新自由主义全球化的因果断言]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元全球储备货币地位 |
| **DV（因变量）** | 美国制造业就业和产出占比下降（去工业化） |
| **Chain（传导链）** | 全球储备美元导致美国必须保持国际收支逆差 → 逆差和美元高估损害制造业出口竞争力 → 制造业企业为降低成本将生产外包至东亚 → 国内制造业就业占比持续下降 |
| **Lag（时滞）** | 二战后逐渐显现，20世纪70年代起加速 |
| **Threshold（临界值）** | 美国持续存在综合逆差，美元汇率长期高估 |
| **前提与约束（Premises）** | 各国愿意持有美元作为储备；东亚拥有低成本劳动力；技术标准化使外包成为可能 |
| **Falsification（证伪条件）** | 如果美元储备地位增强而美国制造业占比没有下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个拥有全球通用货币发行权的国家，靠印钞就能换取商品，本国的工厂反而敌不过进口货

### 🔗 文字版因果链

1. 全球储备美元导致美国必须保持国际收支逆差
2. 逆差和美元高估损害制造业出口竞争力
3. 制造业企业为降低成本将生产外包至东亚
4. 国内制造业就业占比持续下降
