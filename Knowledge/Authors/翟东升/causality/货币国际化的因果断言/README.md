# 货币国际化的因果断言（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：货币国际化的因果断言.md

## 总体因果图

- 中央银行的政治独立性高低 → 货币国际化的成功程度
- 工业竞争力（特别是细分领域企业的定价权） → 本币在国际贸易中的计价结算地位
- 政治独立性及承担国际责任的意愿 → 货币国际化能否获得他国政治支持和长期信任
- 国内金融改革与资本账户开放的先后次序 → 货币国际化的可持续性
- 是否抓住国际货币体系危机产生的机会窗口 → 货币国际化的初始突破与份额跳升
