# 美国公私债务膨胀并引发2008年全球金融危机

> 属于因果簇：[[美元体系风险与结构性缺陷的因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 亚洲及外围国家大规模积累外汇储备（美元资产） |
| **DV（因变量）** | 美国公私债务膨胀并引发2008年全球金融危机 |
| **Chain（传导链）** | 外围国家为防范金融危机和稳定出口，大量买入美国国债作为储备 → 持续购买美债压低了美国国内利率水平 → 低利率刺激美国过度投资和消费，公私债务不断累积 → 债务积累到不可持续水平，最终引发2008年全球金融危机 |
| **Lag（时滞）** | 长期（约10~15年，1995—2008年） |
| **Threshold（临界值）** | 世界外汇储备总量从1.2万亿美元增至12万亿美元；美元资产占储备60%以上 |
| **前提与约束（Premises）** | 美元是最重要的储备货币，美国国债被视为安全资产；存在全球资本账户开放与跨境资本自由流动；美国财政和货币政策缺乏外部纪律约束 |
| **Falsification（证伪条件）** | 若外汇储备大规模积累的同时美国国内利率未下降、债务率未上升，且未发生金融危机，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像世界把积蓄都存在美国这家银行，银行钱多了就拼命放贷和消费，最后坏账爆发，大家都受害。

### 🔗 文字版因果链

1. 外围国家为防范金融危机和稳定出口，大量买入美国国债作为储备
2. 持续购买美债压低了美国国内利率水平
3. 低利率刺激美国过度投资和消费，公私债务不断累积
4. 债务积累到不可持续水平，最终引发2008年全球金融危机
