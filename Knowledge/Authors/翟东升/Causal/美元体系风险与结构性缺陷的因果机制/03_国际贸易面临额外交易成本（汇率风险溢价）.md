# 国际贸易面临额外交易成本（汇率风险溢价）

> 属于因果簇：[[美元体系风险与结构性缺陷的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 无锚货币和浮动汇率制度 |
| **DV（因变量）** | 国际贸易面临额外交易成本（汇率风险溢价） |
| **Chain（传导链）** | 主要货币汇率自由浮动且波动剧烈 → 跨境交易商面临未来收付汇价的不确定性 → 交易商需向金融机构购买汇率保险或进行衍生品对冲 → 汇率保险和交易费用形成国际贸易的额外成本，相当于征税 → 养肥了精通汇率预测与货币交易的金融子行业 |
| **Lag（时滞）** | 短期至中期（单笔交易周期内） |
| **Threshold（临界值）** | 当汇率波动幅度超过商业可承受范围，导致对冲成本显著上升 |
| **前提与约束（Premises）** | 存在大量以不同货币计价的国际贸易；汇率缺少硬锚，波动频繁且难以预测；市场参与者厌恶汇率风险，需要风险管理工具 |
| **Falsification（证伪条件）** | 如果浮动汇率下国际贸易总量减少、但贸易商无需支付任何额外费用，或者汇率波动未能影响贸易成本，则该断言被削弱 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 浮动汇率像没有固定标尺的世界，每次交易都要请人量尺寸，量尺寸的师傅还收费，这费就是贸易的过路税。

### 🔗 文字版因果链

1. 主要货币汇率自由浮动且波动剧烈
2. 跨境交易商面临未来收付汇价的不确定性
3. 交易商需向金融机构购买汇率保险或进行衍生品对冲
4. 汇率保险和交易费用形成国际贸易的额外成本，相当于征税
5. 养肥了精通汇率预测与货币交易的金融子行业
