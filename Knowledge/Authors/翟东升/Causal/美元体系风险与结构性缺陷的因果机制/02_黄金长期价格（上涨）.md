# 黄金长期价格（上涨）

> 属于因果簇：[[美元体系风险与结构性缺陷的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球对美元体系/美国信心的变化（信心下降） |
| **DV（因变量）** | 黄金长期价格（上涨） |
| **Chain（传导链）** | 美国遭受地缘政治失败、经济危机或相对实力下降等负面冲击 → 国际市场对美元体系可持续性的信心动摇 → 储蓄者和投资者将资产配置转向黄金作为避险工具 → 黄金需求增加，推动黄金长期价格上涨 |
| **Lag（时滞）** | 长期（数年，如1970年代和21世纪初十年） |
| **Threshold（临界值）** | 信心出现转折性事件（如战争失败、金融危机、苏联挑战等），无明显量化阈值 |
| **前提与约束（Premises）** | 美元与黄金已脱钩，黄金成为非货币化后的价值储藏；黄金被全球储蓄者视为终极避险资产；存在开放的黄金市场和跨境资本流动 |
| **Falsification（证伪条件）** | 若在美元体系信心显著下降的时期黄金价格没有出现持续上涨甚至下跌，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 黄金像世界对美元投出的信任票的反面：美元信用阴天，黄金伞就涨价。

### 🔗 文字版因果链

1. 美国遭受地缘政治失败、经济危机或相对实力下降等负面冲击
2. 国际市场对美元体系可持续性的信心动摇
3. 储蓄者和投资者将资产配置转向黄金作为避险工具
4. 黄金需求增加，推动黄金长期价格上涨
