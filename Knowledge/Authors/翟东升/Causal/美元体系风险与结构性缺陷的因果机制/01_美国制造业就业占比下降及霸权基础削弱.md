# 美国制造业就业占比下降及霸权基础削弱

> 属于因果簇：[[美元体系风险与结构性缺陷的因果机制]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元作为全球储备货币的特权 |
| **DV（因变量）** | 美国制造业就业占比下降及霸权基础削弱 |
| **Chain（传导链）** | 全球各国央行持续增加美元储备资产，导致美元汇率高估 → 美元高估使美国制造业成本相对亚洲廉价劳动力地区上升 → 美国制造商将工厂外迁或外包至东亚等低成本地区 → 美国制造业就业占总就业比例持续下滑（从二战后35%下降） → 贸易和制造能力是全球化时代权力基础，制造业流失削弱美国霸权 |
| **Lag（时滞）** | 长期（数十年，自1970年代起） |
| **Threshold（临界值）** | 全球外汇储备中美元资产占比持续超过60%，累计经常账户逆差达数万亿美元 |
| **前提与约束（Premises）** | 美元是主要国际储备货币，外国央行对美元资产需求持续存在；制造业可以跨境转移，存在成本套利空间；贸易和制造能力构成国家权力的基础 |
| **Falsification（证伪条件）** | 如果美元储备货币地位提升的同时美国制造业就业占比保持稳定或上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像拥有印钞权的国家，大家拼命持有它的钞票，导致本国制造业因币值高估而空心化，最终靠印钞度日，实力被掏空。

### 🔗 文字版因果链

1. 全球各国央行持续增加美元储备资产，导致美元汇率高估
2. 美元高估使美国制造业成本相对亚洲廉价劳动力地区上升
3. 美国制造商将工厂外迁或外包至东亚等低成本地区
4. 美国制造业就业占总就业比例持续下滑（从二战后35%下降）
5. 贸易和制造能力是全球化时代权力基础，制造业流失削弱美国霸权
