# 金融权势与新自由主义全球化的因果断言（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：金融权势与新自由主义全球化的因果断言.md

## 总体因果图

- 金融业的政治捐赠和人员旋转门 → 金融去监管化政策的出台
- 金融去监管化 → 经济虚拟化，金融部门压倒实体部门
- 美元全球储备货币地位 → 美国制造业就业和产出占比下降（去工业化）
- 美式季度资本主义（以股票市值为指挥棒） → 大型制造业长期投资不足、竞争力下降
- 政府为大型金融机构提供救助安全网（大到不能倒） → 银行过度承担风险、金融系统脆弱性增加
- 华尔街金融权势的崛起 → 新自由主义全球化的推行
