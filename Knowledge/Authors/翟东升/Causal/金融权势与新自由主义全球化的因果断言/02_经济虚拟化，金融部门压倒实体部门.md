# 经济虚拟化，金融部门压倒实体部门

> 属于因果簇：[[金融权势与新自由主义全球化的因果断言]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融去监管化 |
| **DV（因变量）** | 经济虚拟化，金融部门压倒实体部门 |
| **Chain（传导链）** | 解除利率管制和混业经营限制 → 金融机构跨界扩张和金融产品创新 → 金融部门利润和GDP占比持续上升 → 资本从制造业流向金融业 → 制造业就业和利润占比下降 |
| **Lag（时滞）** | 20世纪80年代至2008年金融危机，约二十余年 |
| **Threshold（临界值）** | 金融部门利润占比长期高于制造业；制造业就业占比从1946年的35%降至2008年的8% |
| **前提与约束（Premises）** | 美国金融部门利润率高；全球化使制造业可外包；美元储备货币地位为金融业提供便利 |
| **Falsification（证伪条件）** | 如果去监管化后金融部门占比没有上升且制造业部门没有萎缩，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

### 🔗 文字版因果链

1. 解除利率管制和混业经营限制
2. 金融机构跨界扩张和金融产品创新
3. 金融部门利润和GDP占比持续上升
4. 资本从制造业流向金融业
5. 制造业就业和利润占比下降
