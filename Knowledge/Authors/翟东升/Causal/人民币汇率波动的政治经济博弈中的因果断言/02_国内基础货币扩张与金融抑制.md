# 国内基础货币扩张与金融抑制

> 属于因果簇：[[人民币汇率波动的政治经济博弈中的因果断言]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 持续的经常项目和资本项目双顺差 |
| **DV（因变量）** | 国内基础货币扩张与金融抑制 |
| **Chain（传导链）** | 中国加入WTO后出现双顺差，大量美元流入 → 央行为了维持人民币汇率稳定，买入美元，投放人民币（外汇占款） → 基础货币扩张，存在通胀压力 → 央行采取发行央票、提高存款准备金率、财政存款等手段冲销流动性 → 冲销成本最终由商业银行、企业和居民分摊，压低储蓄利率，形成金融抑制 |
| **Lag（时滞）** | 短期至中期（随双顺差持续积累） |
| **Threshold（临界值）** | 持续的双顺差且汇率存在低估压力 |
| **前提与约束（Premises）** | 央行实行固定或高度管理汇率的制度；资本账户存在管制但仍大量流入；国内金融体系以国有银行为主 |
| **Falsification（证伪条件）** | 如果双顺差持续但基础货币扩张没有引起冲销或金融抑制，或者冲销成本完全由外部承担，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像水池不断进水，为了保持水位不变，一边抽水一边向池内注入消毒液，最后水里的鱼（居民）深受其害

### 🔗 文字版因果链

1. 中国加入WTO后出现双顺差，大量美元流入
2. 央行为了维持人民币汇率稳定，买入美元，投放人民币（外汇占款）
3. 基础货币扩张，存在通胀压力
4. 央行采取发行央票、提高存款准备金率、财政存款等手段冲销流动性
5. 冲销成本最终由商业银行、企业和居民分摊，压低储蓄利率，形成金融抑制
