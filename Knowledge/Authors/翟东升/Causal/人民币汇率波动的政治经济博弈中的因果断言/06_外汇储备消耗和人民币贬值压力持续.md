## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场贬值预期与资本外逃 |
| **DV（因变量）** | 外汇储备消耗和人民币贬值压力持续 |
| **Chain（传导链）** | 市场形成人民币贬值的一致预期 → 富人和中产阶级恐慌性换汇 → 资本外逃加剧，人民币汇率下跌 → 政府动用外储干预但未能扭转预期 → 贬值预期得到强化，形成自我实现 |
| **Lag（时滞）** | 短期至中期（2014-2016年） |
| **Threshold（临界值）** | 人民币兑美元接近7:1关键点位 |
| **前提与约束（Premises）** | 资本账户存在开放通道；美元加息预期等外部环境；国内资产泡沫和财富配置需求 |
| **Falsification（证伪条件）** | 如果市场预期贬值但未出现资本外逃，或政府干预迅速稳定汇率，则断言不成立 |
| **Confidence（确信度）** | well-established |
