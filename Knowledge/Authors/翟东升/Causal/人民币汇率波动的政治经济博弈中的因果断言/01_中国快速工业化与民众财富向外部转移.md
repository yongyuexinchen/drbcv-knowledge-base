# 中国快速工业化与民众财富向外部转移

> 属于因果簇：[[人民币汇率波动的政治经济博弈中的因果断言]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人民币汇率低估与固定汇率政策 |
| **DV（因变量）** | 中国快速工业化与民众财富向外部转移 |
| **Chain（传导链）** | 中国实行人民币贬值并固定汇率，提供廉价出口优势 → 吸引外资和扩大出口，推动工业制造快速增长 → 为维持汇率稳定，央行收购外汇并增发货币，形成外汇占款 → 通过冲销和利率压低等机制，将成本转嫁给国内民众 → 民众权益和劳动成果被输送给全球投资者、消费者和政府 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 无明确单一阈值，但存在持续汇率低估 |
| **前提与约束（Premises）** | 中国处于融入美国主导的全球化体系的过程中；外资和外部市场对中国开放；政府能够实施外汇管制和金融抑制 |
| **Falsification（证伪条件）** | 如果人民币汇率低估但中国未出现快速工业化，或民众实际生活水平显著提升且未受损，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个工厂用低价补贴吸引订单，却让工人超时加班、薪资微薄，利润被外国客户拿走

### 🔗 文字版因果链

1. 中国实行人民币贬值并固定汇率，提供廉价出口优势
2. 吸引外资和扩大出口，推动工业制造快速增长
3. 为维持汇率稳定，央行收购外汇并增发货币，形成外汇占款
4. 通过冲销和利率压低等机制，将成本转嫁给国内民众
5. 民众权益和劳动成果被输送给全球投资者、消费者和政府
