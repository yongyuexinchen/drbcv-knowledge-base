# 热钱流入、贸易顺差虚高和升值预期自我强化

> 属于因果簇：[[人民币汇率波动的政治经济博弈中的因果断言]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人民币汇率单向升值预期及套利机会 |
| **DV（因变量）** | 热钱流入、贸易顺差虚高和升值预期自我强化 |
| **Chain（传导链）** | 政府隐性担保带来人民币可预测的渐进升值 → 投机者借入美元换成人民币，获得利差和汇差收益 → 实体企业伪造贸易数据将资金带入人民币资产 → 热钱流入推高贸易顺差统计值 → 更高的顺差强化升值预期，吸引更多套利资金 |
| **Lag（时滞）** | 短期（数日内可完成一轮交易，全年累积） |
| **Threshold（临界值）** | 每次交易收益约5%，且汇改后人民币持续单向升值 |
| **前提与约束（Premises）** | 汇率形成机制存在可预测性；中美利差和升值预期同时存在；贸易结算监管存在漏洞 |
| **Falsification（证伪条件）** | 如果升值预期存在但未出现热钱流入或顺差未虚高，或者升值预期消退后套利停止，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像有人在赌场发现一个稳赢的轮盘，不断下注，赌场统计显示轮盘更热门，引来更多人下注，其实热门是赌徒自己造成的

### 🔗 文字版因果链

1. 政府隐性担保带来人民币可预测的渐进升值
2. 投机者借入美元换成人民币，获得利差和汇差收益
3. 实体企业伪造贸易数据将资金带入人民币资产
4. 热钱流入推高贸易顺差统计值
5. 更高的顺差强化升值预期，吸引更多套利资金
