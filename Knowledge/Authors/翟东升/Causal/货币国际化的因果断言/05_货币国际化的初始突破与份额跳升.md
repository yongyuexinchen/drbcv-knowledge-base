# 货币国际化的初始突破与份额跳升

> 属于因果簇：[[货币国际化的因果断言]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 是否抓住国际货币体系危机产生的机会窗口 |
| **DV（因变量）** | 货币国际化的初始突破与份额跳升 |
| **Chain（传导链）** | 原有国际主流货币出现危机，信用受损 → 全球公私部门急切寻找替代货币 → 本国货币适时升值并适度放开资本账户，吸收替代需求 → 本币在全球储备和贸易计价中的份额跃升，国际化启动 |
| **Lag（时滞）** | 短中期（危机出现后数年内） |
| **Threshold（临界值）** | 在国际主流货币信用崩溃时及时行动；货币使用具有黏性，窗口期结束前行动方可占先 |
| **前提与约束（Premises）** | 国际货币体系处于结构性转变时期；本国经济基本面良好且货币具有升值预期；政策当局对时机有自主把握能力而非被迫行动 |
| **Falsification（证伪条件）** | 若发现货币国际化在缺乏机会窗口时也能成功，或抓住窗口却未能提升份额，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 货币国际化像雨天卖伞，原有大伞破洞漏雨，你的新伞如果及时摆摊，就能被抢购。

### 🔗 文字版因果链

1. 原有国际主流货币出现危机，信用受损
2. 全球公私部门急切寻找替代货币
3. 本国货币适时升值并适度放开资本账户，吸收替代需求
4. 本币在全球储备和贸易计价中的份额跃升，国际化启动
