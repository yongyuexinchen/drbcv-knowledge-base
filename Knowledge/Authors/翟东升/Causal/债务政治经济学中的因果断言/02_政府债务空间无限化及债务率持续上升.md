# 政府债务空间无限化及债务率持续上升

> 属于因果簇：[[债务政治经济学中的因果断言]]（第2块/7块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球货币体系脱离黄金硬锚（无锚货币制度） |
| **DV（因变量）** | 政府债务空间无限化及债务率持续上升 |
| **Chain（传导链）** | 1972年布雷顿森林体系向牙买加体系转变，央行货币发行锚住通胀而非黄金 → 央行成为最终债务人，可无限扩张货币基础 → 政府本币债务可借新还旧且利率部分自定 → 政府债务率得以持续上升而不必然违约 |
| **Lag（时滞）** | 20世纪70年代后逐步显现，长期效应 |
| **Threshold（临界值）** | 以1972年为起点；无明确债务率阈值 |
| **前提与约束（Premises）** | 政府债务以本币计价；央行具有货币发行自主权；通胀目标制容忍温和通胀 |
| **Falsification（证伪条件）** | 若在无锚货币体系下政府债务率长期下降且无法扩张，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 1972年布雷顿森林体系向牙买加体系转变，央行货币发行锚住通胀而非黄金
2. 央行成为最终债务人，可无限扩张货币基础
3. 政府本币债务可借新还旧且利率部分自定
4. 政府债务率得以持续上升而不必然违约
