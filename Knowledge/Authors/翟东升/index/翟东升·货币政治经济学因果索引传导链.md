## 主传导链

```
[起点] 布雷顿森林体系崩溃（1971）
  → 美元进入无锚货币时代（金本位被取代）
  → 外国央行对美元资产的需求持续存在
  → 美元取得全球储备货币特权（长期，数十年）

[美元特权] 美元特权确立，制造业可跨境转移（成本套利空间存在）
  → 美国制造业就业占比下降（时滞：20-30年）
  → 美国霸权基础削弱（贸易与制造能力构成国家权力）

[金融权势] 美元特权 + 霸权基础削弱（中期，5-10年）
  → 金融业在美国政治与经济中的权势上升
  → 金融业通过政治捐赠与人员旋转门影响立法（选举民主、三权分立前提）
  → 金融去监管化政策出台
  → 新自由主义全球化深化，资本跨境流动加速

[中国承接] 中国融入美国主导的全球化（外资与外部市场开放）
  → 政府有能力实施外汇管制与金融抑制
  → 人民币汇率低估+固定汇率政策（持续数十年）
  → 中国快速工业化（出口导向）
  → 民众财富向外部转移（通过出口顺差与美元资产沉淀）
  → 出口部门积累巨额贸易盈余

[人民币国际化] 贸易盈余 + 资本项目部分放开（三元悖论约束）
  → 出口部门形成政治压力
  → 央行政治独立性成为关键变量（独立性高低决定货币信用与政策取向）
  → 央行独立性高 → 国际信誉强 → 货币国际化成功
  → 央行独立性低 → 易受出口部门俘获 → 货币国际化受阻

[债务永久增长] 无锚货币时代，债权与债务总量守恒
  → 经济增长与财富扩张必然伴随债务的永久增长（信用扩张机制）
  → 债务增长支撑美元体系，但也累积结构性风险

[收敛] 美元特权 → 制造业外流 → 金融权势 → 去监管化 → 新自由主义全球化
  → 中国低估汇率工业化 + 美国霸权基础削弱 + 债务永久增长
  → 美元体系风险与结构性缺陷显性化（长期，数十年）
  → 人民币国际化与美元体系风险形成双向互动
```

## 不变式

- 债权与债务总量守恒，无锚货币时代债务可无限扩张。
- 贸易与制造能力是国家权力的物质基础。
- 全球化本质是美国主导的美元-金融体系与新自由主义秩序。
- 国家货币权力受制于国内政治经济结构（出口部门、金融利益集团、央行独立性）。
- 三元悖论是开放经济体不可回避的硬约束。

## 跨作者交叉点

- **与沃勒斯坦（世界体系理论）**：同一变量为“中心-边缘分工下的财富转移”。翟东升认为中国通过低估汇率实现快速工业化，但民众财富向外部转移；沃勒斯坦强调半边缘国家崛起但受制于中心。张力：翟东升强调国家汇率政策的自主性，沃勒斯坦强调结构性依附。嵌套：人民币低估是半边缘国家利用体系内不对称依赖的战术动作，长期仍落入中心国主导的利益分配结构。

- **与明斯基（金融不稳定假说）**：同一变量为“债务扩张的必然性”。翟东升从无锚货币与债权债务守恒推出债务永久增长；明斯基从繁荣期乐观预期与投机融资推出金融脆弱性。张力：翟东升侧重政治经济学与货币制度，明斯基侧重心理与金融周期；翟东升认为债务增长是常态，明斯基认为最终以危机逆转。嵌套：美元特权为全球投机融资提供安全资产抵押，使明斯基式过程在美元体系内被放大。

- **与达里奥（储备货币周期）**：同一变量为“美元特权与霸权更替”。翟东升认为美元特权导致制造业流失与霸权削弱；达里奥认为储备货币有生命周期，过度债务终将削弱帝国。张力：翟东升强调政治权力分配与产业基础，达里奥强调经济周期与货币信用机制。嵌套：翟东升的“美元特权→制造业流失→债务增长”可视为达里奥大国生命周期模型的政治经济学微观基础。

- **与辜朝明（资产负债表衰退）**：同一变量为“债务在宏观中的角色”。翟东升看到经济增长必然导致债务永久增长；辜朝明看到私人部门在泡沫破裂后主动修复资产负债表导致衰退。张力：翟东升认为债务是增长的结果与推动力，辜朝明认为债务收缩是衰退的原因。嵌套：美元体系下的债务永久增长使全球私人部门杠杆化，一旦美元信用收缩，就会触发辜朝明式资产负债表衰退。
