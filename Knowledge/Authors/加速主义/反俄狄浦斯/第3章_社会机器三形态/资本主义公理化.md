# 资本主义公理化（解码 + 公理化）

## 类型判定
资本主义不是"解码一切"（那样会自毁），而是**用一只手解码，另一只手公理化**——把解码之流重新纳入抽象量化体系（价值/价格/资本逻辑）。核心命题：**资本主义=相对界限，精神分裂=绝对界限**。

## 类比 ★
### 一句话比喻
像大坝泄洪——资本主义把水闸打开（解码/解辖域化），但又马上修一条水泥渠（公理化/再领土化）让水只能按它规定的路线流。水自由了，但只能在渠道里自由。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 解码 | 打开水闸 |
| 公理化 | 修水泥渠 |
| 相对界限 | 渠道的边界（可以扩，不消失） |
| 绝对界限（精神分裂） | 水漫金山（超出一切渠道） |
| 符码（质） | 水的"种类" |
| 公理（量） | 水的"流量参数" |

## 是什么
解码≠资本主义：需要解码之流的**合取**（自由劳动者之流×货币-资本之流的不期而遇）才是资本诞生。资本主义"从根本上不识字"（书写属于专制）——它用公理化（抽象量化）替代符码。相对界限=资本主义能不断扩张的界限（重新公理化）；绝对界限=精神分裂——解码之流的极限运行，超出一切再领土化能力。"用一只手解码，另一只手公理化"——这是资本的双重运动。

## 正例（≥2 个）
1. **劳动力商品化**：自由劳动者（被解辖域化的流）× 货币资本（另一条解码流）——合取诞生资本主义
2. **金融衍生品**：极致的解码（把一切风险做成可交易流）+ 极致的公理化（定价/评级/监管）

## 反例/边界（≥1 个）
1. 公理化≠符码：符码是质的（图腾/名字），公理是量的（价格/价值）——资本主义用量替代质
2. 边界：资本主义≠"无限解码"——它同时公理化（再领土化），否则自我解体

## 详细解释
资本主义公理化 ↔ [[解辖域化与再领土化]]（解码+再领土化的经济形态）↔ [[精神分裂分析]]（绝对界限=精神分裂=资本主义的内在界限）。左翼加速主义的命题从这里来：资本在"撞墙"前不断公理化推迟——加速到极限就是撞穿绝对界限（[[counter/加速即共谋_夏莹]]会质疑：加速=帮资本扫清障碍）。
