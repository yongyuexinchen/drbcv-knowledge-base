# 解辖域化与再领土化

## 类型判定
把流从地盘上拔起（解辖域化/解码）与重新圈地（再领土化/再编码）的双重运动。核心命题：**资本主义 = 解辖域化的双重运动 + 粗暴的再领土化**——它把一切连根拔起，又用国家、家庭、消费身份重新圈地。这是德勒兹最被加速主义引用的概念。

## 类比 ★
### 一句话比喻
资本主义像一场龙卷风：它把你连根拔起（解辖域化），再把你卷进新的笼子（再领土化）——你以为的自由迁徙，只是从土地挪进房贷。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 领土化 | 土地改革：把农民固定在土地上 |
| 解辖域化 | 城市化：把农民连根拔起 |
| 再领土化 | 房贷：把他绑回新的笼子 |
| 编码 | 原始社会给每件事一个名字（图腾） |
| 超符码化 | 帝国给所有名字盖个印章（皇帝/货币） |
| 解码 | 资本主义说"别管名字，看价格" |

## 是什么
三个时代三种"记账的皮"（社会集群）：原始社会编码流（图腾命名一切）、专制社会超符码化（皇帝在一切之上盖印）、资本主义解码流（抽象量化公理替代符码）。资本主义的双重运动：一切连根拔起（去领土化）+ 重新圈地（再领土化——国家、政党、家庭"一切都会再回来"）。它的内在界限是[[精神分裂分析|精神分裂]]——那个"比资本家更资本主义"的主体。

## 正例（≥2 个）
1. **城市化→房贷**：农民被从土地拔起（解辖域化），又被房贷绑回城市笼子（再领土化）
2. **算法时代的身份**：传统身份（乡土/职业）被解码，新身份（粉丝/消费标签/圈层）被再领土化

## 反例/边界（≥1 个）
1. 去增长派（[[counter/加速即共谋_夏莹]]）：解辖域化的无尽增殖=生态灾难的哲学化——"生产的生产"听起来像超级生产主义
2. 边界：解辖域化 ≠ 单纯"解放"——资本主义的解辖域化永远伴随再领土化（解放的下一步就是新笼子）

## 详细解释
德勒兹的"界限"概念：精神分裂=资本主义的界限——资本不断制造再领土化来推迟撞墙（把界限内化为新市场）。左翼加速主义继承的正是这个"撞墙"视角：真正的选择不是加速/刹车二选一，而是"**流被谁截断**"。去增长派要的"刹车"在德勒兹语境里是"过程的中断"（中断=神经症/独裁）。
