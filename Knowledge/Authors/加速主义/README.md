## 卡片类型体系

| 位置 | 类型 | 定义 | 节目用途 |
|------|------|------|---------|
| 书/章节/ | **知识卡**（concept） | 有明确定义的概念——DRBCV 范式 | 讲解主体 |
| counter/ | **反例卡**（counter） | 知识卡的对头——攻击/反驳 | 碰撞弹药 |
| causality/ | **CAO 因果卡**（cao） | 因果断言（IV/DV/Chain/Premises/Falsification） | 研判/深度 |
| 书/作者卡 | **作者卡**（author） | 人格/生成链/争议/故事钩子 | 叙事张力 |

## ⭐ 碰撞机制

**每张知识卡必须配对至少一张反例卡**——"有碰撞才有收视率"：
- 概念卡底部必链对头反例卡，反例卡必链被攻击的概念卡
- 反例卡需含：攻击论点→攻击依据→正方如何回应（真碰撞，不单方面打靶）

## 卡片格式（DRBCV 五要素 + 范式）

```yaml
---
name: 欲望机器
type: concept
status: core
source: "德勒兹×瓜塔里《反俄狄浦斯》第一章"
domain: 加速主义
---
```

**概念卡范式**：类型判定 → 类比★（一句话比喻+生活映射表）→ 是什么 → 正例≥2 → 反例/边界≥1 → 详细解释 → 关系（双链）
**CAO卡范式**：🔬结构表（IV/DV/Chain/Lag/Threshold/Premises/Falsification/Confidence）+ 🧩生活类比 + 🔗文字版因果链
**类比栏是铁律**（DRBCV 特色：每张卡必须有生活类比）
