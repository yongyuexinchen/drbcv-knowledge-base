# 对象小a
## 一句话定义
欲望的对象-原因——不是你欲望的那个东西，而是你之所以欲望它的那个"说不清的东西"：比对象本身还多出来的、让对象变得"可欲望"的神秘X。拉康的核心概念，齐泽克用它锁定德勒兹准原因的精确等价物。

## 类比 ★
你追的不是那个人，是那个人身上"比TA本人还多的东西"——那个X一旦消失，同一个人站在你面前你也毫无感觉。这就是对象小a：不是欲望的目标，是欲望的引擎。

## 核心公式/要点
- 对象小a = 准原因（卷1明言等价） = 欲望的对象-原因
- 它不是"我想要X"，而是"X身上的那个a让我想要X"
- 柴郡猫消失后独自存留的微笑 = 对象小a的形象：脱离身体的"比身体更多的部分"
- 卡普格拉妄想（感觉亲人被冒名顶替）= 对象小a的位置空了：人还在，但让他"是那个人"的a消失了

## 边界
不是欲望对象本身（那只是经验的"好东西"），而是让对象可欲望的结构性X。不是超验理想（不在彼岸），而是内在于对象又不可化约为对象的"过度"。

## 关系
- → 指向[[准原因]]——同一枚硬币的两面：德勒兹用准原因解释事件之过度，拉康用对象小a解释欲望之过度
- → 指向[[阴影剧场]]——对象小a是阴影剧场中那个"比现实更真实"的幻象核
- ← 被指向：象征阉割——被阉割切下来的"多余部分"就是对象小a
