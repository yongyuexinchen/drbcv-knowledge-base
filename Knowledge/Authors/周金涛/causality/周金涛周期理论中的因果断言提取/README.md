# 周金涛周期理论中的因果断言提取（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：周金涛周期理论中的因果断言提取.md

## 总体因果图

- 全球中周期高点确认（美国中周期高点） → 全球风险偏好收缩与风险资产回落
- 第三库存周期开启（2016年前后全球主要经济体） → 大宗商品价格率先反弹、风险偏好回升
- 宽松货币政策（欧洲、日本QE及中国降准降息） → 无风险收益率下行与“股债双牛”
- 债务-通缩困境下长期流动性宽松 → 资产价格泡沫化与“类滞胀”逻辑对流动性的边际敏感
- 美元强势周期（2014年开始的美元牛市） → 新兴市场国家受到冲击（资金外流、金融市场下跌）
- 康波周期运行至衰退向萧条过渡阶段 → 价格体系出现冲高回落（走向滞胀）
- 美国中周期步入中后段（就业增速高位震荡或回落） → 第三库存周期的开启（强度和时间长度不同）
- 全球短周期共振下行后（2015-2016年） → 商品率先反弹、美元走弱
