## 主传导链

```text
【长波背景】康波衰退期后半段（长波位置制约中周期强度）
→ （约10年尺度）全球中周期高点确认（美国中周期高点）
→ （此前流动性宽松已将风险资产估值推至泡沫化）全球风险偏好收缩与风险资产回落

【美元体系】后布雷顿森林体系：美元主导 + 外围出口导向 + 美国最终消费
→ 全球金融失衡
→ （2008年）金融危机
→ 加剧中周期与短周期调整

【人口/城市化】劳动力无限供给终结（刘易斯拐点）
→ 工资内生性加速上涨
→ 推升生产成本 → 价格上涨中出现投机需求与成本重新回升（通胀）
→ （产业链传导有滞后，价格是观测指标）需求增速回落 + 资金成本提高 → 二次去库存严重且持续

【房地产】城市化率过50%后放缓（类似日本1967/韩国1976）
→ 房地产从直线增长进入周期性波动
→ 房地产销售尚未见底
→ （政府投资主要投向非制造业，其他加速器反向抑制）经济持续下滑且其他加速器失速
→ 市场泥沙俱下，防御品种相对抗跌，投资品不佳

【库存周期】库存达到高点 → 主动去库存
→ （非资产价格泡沫冲击性破灭）约一个季度末出现库存周期低点
→ 原材料库存指数触底回升
→ （量价关系：被动去库→主动去库→被动补库→主动补库）2012年第二季度库存周期底部出现
→ 工业增加值季调趋势项环比见底（量的底部）
→ 产出缺口底部出现
```

## 不变式

- 周期嵌套：康波→中周期→库存周期，长波位置制约中周期强度，中周期动能衰落不影响短周期库存行为。
- 无重大外部冲击或资产价格泡沫破裂时，库存周期遵循量价四阶段规律（被动去库→主动去库→被动补库→主动补库）。
- 后布雷顿森林体系下美元主导权是理解全球金融失衡与危机的前提。
- 中国城市化率与劳动力转移的结构性变化是房地产和工资周期的长期决定因素。
- 周期行为在无重大冲击下可预测，政策与外部冲击只改变形态不改变方向。

## 跨作者交叉点

### 与达里奥（债务周期）
- 同一变量：去杠杆/去库存。周金涛的库存周期底部来自主动去库存的完成；达里奥的债务周期底部来自去杠杆完成。
- 张力：周金涛认为短周期库存调整是常态，可在几个季度内自然出清；达里奥认为长期债务周期下行可能持续十年以上。
- 嵌套：康波衰退期叠加债务周期顶点时，库存周期底部的反弹可能仅是技术性，难以改变中周期下行。

### 与明斯基（金融不稳定假说）
- 同一变量：风险偏好/金融脆弱性。周金涛指出流动性宽松将风险资产估值推至泡沫化后中周期高点确认；明斯基认为稳定期借贷扩张内生积累脆弱性。
- 张力：明斯基强调金融内部动态，周金涛强调外部长波位置与美元体系约束。
- 嵌套：中周期高点的风险偏好收缩正是明斯基"金融不稳定"在周期顶部的表现，长波衰退期放大这一过程。

### 与辜朝明（资产负债表衰退）
- 同一变量：私人部门去杠杆 vs 库存调整。周金涛关注企业库存行为；辜朝明关注企业资产负债表修复导致的需求不足。
- 张力：周金涛认为只要不是资产价格泡沫破灭，库存周期会按量价规律自行见底；辜朝明认为资产泡沫破裂后私人部门即使零利率也不借贷，形成长期衰退。
- 嵌套：周金涛的非泡沫前提对应辜朝明的泡沫破裂后场景，两者适用于不同周期阶段。

### 与佩蕾丝（技术革命与康波）
- 同一变量：康波/长波。周金涛的康波衰退期与佩蕾丝的技术革命展开期后段对应。
- 张力：周金涛更侧重金融与资产价格周期，佩蕾丝侧重技术-经济范式与社会制度匹配。
- 嵌套：康波衰退期的风险资产回落可理解为佩蕾丝所说"技术泡沫破灭后的转折期"。
