# 周期救赎与库存低点因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：周期救赎与库存低点因果分析.md

## 总体因果图

- 库存达到高点并开始主动去库存 → 库存周期低点在第一季度末出现
- 库存周期低点带来的经济企稳预期 → 早周期行业（地产、金融、汽车）配置领涨与周期救赎行情
- 美国进入建筑业周期且美元升值 → 中国去泡沫与股市真正中期低点出现
