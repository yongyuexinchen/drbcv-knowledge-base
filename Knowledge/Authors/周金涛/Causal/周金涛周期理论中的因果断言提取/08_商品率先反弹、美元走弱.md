# 商品率先反弹、美元走弱

> 属于因果簇：[[周金涛周期理论中的因果断言提取]]（第8块/8块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球短周期共振下行后（2015-2016年） |
| **DV（因变量）** | 商品率先反弹、美元走弱 |
| **Chain（传导链）** | 美国第二库存周期2016年中期触底，欧洲稍晚触底 → 中国2016年初出现第三库存周期启动点 → 库存周期交替决定了美元指数阶段性走弱 → 大宗商品在金融抑制因素解除后价格触底反弹 → 商品率先反弹领先于权益资产 |
| **Lag（时滞）** | 2015年第三四季度至2016年中期触底，商品反弹领先权益约1-2个季度 |
| **Threshold（临界值）** | 短周期下行期持续约20个月；美国第二库存周期运行至36个月左右 |
| **前提与约束（Premises）** | 全球主要经济体库存周期不同步但收敛；美元强势弱于前两轮周期；去产能与去库存接近尾声 |
| **Falsification（证伪条件）** | 若全球共振下行使商品继续暴跌且美元持续走强，未出现商品率先反弹，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同风暴中心过后，海面先出现平静（商品筑底），随后波浪才逐渐平复（权益资产企稳）。

### 🔗 文字版因果链

1. 美国第二库存周期2016年中期触底，欧洲稍晚触底
2. 中国2016年初出现第三库存周期启动点
3. 库存周期交替决定了美元指数阶段性走弱
4. 大宗商品在金融抑制因素解除后价格触底反弹
5. 商品率先反弹领先于权益资产
