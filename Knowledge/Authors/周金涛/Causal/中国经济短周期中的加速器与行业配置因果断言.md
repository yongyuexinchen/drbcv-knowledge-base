## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济持续下滑且其他加速器失速 |
| **DV（因变量）** | 市场泥沙俱下式下跌，防御品种相对抗跌，投资品表现不佳 |
| **Chain（传导链）** | 经济持续下滑，其他加速器（M1、房地产销售、库存等）仍处反向抑制阶段 → 政府虽加大非制造业投资，但规模不足以对冲其他加速器的失速 → 经济下行趋势未扭转，市场风险偏好下降 → 资金流向防御性板块（医药生物、公用事业、信息服务、金融服务、食品饮料），抛售有色金属、房地产、机械设备等投资品 |
| **Lag（时滞）** | 约2-6个月（如2008年4月至10月） |
| **Threshold（临界值）** | 经济下滑程度达到政府加大投资仍无法托底的水平（文本未给定量阈值） |
| **前提与约束（Premises）** | 其他加速器仍处于反向抑制阶段；房地产销售尚未见底；政府投资主要投向非制造业领域 |
| **Falsification（证伪条件）** | 若政府在非制造业投资加大的同时，经济能够止跌回升，则原断言‘泥沙俱下式下跌’不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像重感冒时只吃维生素C，免疫力仍弱，病毒继续扩散，人体只能先保证要害器官不垮

### 🔗 文字版因果链

1. 经济持续下滑，其他加速器（M1、房地产销售、库存等）仍处反向抑制阶段
2. 政府虽加大非制造业投资，但规模不足以对冲其他加速器的失速
3. 经济下行趋势未扭转，市场风险偏好下降
4. 资金流向防御性板块（医药生物、公用事业、信息服务、金融服务、食品饮料），抛售有色金属、房地产、机械设备等投资品

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | M1加速器修复和房地产销售转好 |
| **DV（因变量）** | 建筑建材、机械设备、有色金属、房地产等投资品行业获得较大弹性表现 |
| **Chain（传导链）** | 非制造业投资持续回暖 → 货币转向，M1加速器开始修复 → 房地产销售转好，市场对经济预期改善 → 估值修复与预期好转，资金重新配置投资品 → 建筑建材、机械设备、有色金属、房地产等行业需求预期提升，股价和景气弹性变大 |
| **Lag（时滞）** | 从货币转向到投资品表现约1-2个季度（文本未精确） |
| **Threshold（临界值）** | M1增速止跌回升，且房地产销售面积/金额增速转正 |
| **前提与约束（Premises）** | 经济周期进入第二阶段；非制造业投资仍在回暖；货币环境趋于宽松 |
| **Falsification（证伪条件）** | 若M1和房地产销售好转后，上述投资品行业并未跑赢防御板块，则本断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 汽车引擎重新点火后，车身（重资产行业）才开始加速，而驾驶者（市场）需要先看到转速表（M1/地产销售）回升

### 🔗 文字版因果链

1. 非制造业投资持续回暖
2. 货币转向，M1加速器开始修复
3. 房地产销售转好，市场对经济预期改善
4. 估值修复与预期好转，资金重新配置投资品
5. 建筑建材、机械设备、有色金属、房地产等行业需求预期提升，股价和景气弹性变大

## 因果断言 3

| **IV（自变量）** | 库存加速器复苏 |
| **DV（因变量）** | 交通运输设备、信息设备、采掘、有色金属及机械设备等行业表现上佳 |
| **Chain（传导链）** | 经济复苏信号明显，非制造业投资、房地产销售、制造业投资、M1、库存等驱动因素修复 → 库存加速器由去库存转为补库存 → 企业增加原材料、设备采购以补充库存 → 交通运输设备、信息设备、采掘、有色、机械等行业需求增加 → 这些行业盈利能力及市场表现提升 |
| **Lag（时滞）** | 滞后于经济复苏信号约一个季度（根据周期阶段推断） |
| **Threshold（临界值）** | 库存增速由降转升，出现明确的补库存拐点 |
| **前提与约束（Premises）** | 经济处于短周期复苏第三阶段；其他加速器均已进入修复阶段；房地产、建筑建材等行业发展仍有赖于房地产投资恢复 |
| **Falsification（证伪条件）** | 若库存加速器回升后，上述行业没有相对收益甚至跑输大盘，则本断言不成立 |

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 房地产加速器未能启动并叠加外部冲击（美元升值、欧元区冲击、出口受创） |
| **DV（因变量）** | 经济出现更大向下波动，市场先冲击后迎来中期底部与救赎机会 |
| **Chain（传导链）** | 房地产加速器无法如期启动，其他加速器难以推动经济复苏 → 经济底部不稳，第一季度的底部可能只是幻觉 → 外部冲击（美元升值资本外流、欧元区冲击、出口受打击）袭来 → 经济面临更大幅度下行，市场再次遭受冲击 → 冲击后市场迎来中期重要底部 → 政府被迫彻底打开刺激空间或走向增长质量提升之路，形成救赎性大机会或牛市格局 |
| **Lag（时滞）** | 从加速器失速到外部冲击显现约数个月至一年（文中未精确） |
| **Threshold（临界值）** | 房地产投资增速未能实现预期中的见底回升，且外部冲击同时发生 |
| **前提与约束（Premises）** | 路径2是对路径1的否定，即经济不是温和复苏而是大落；政府因制约因素不放松房地产政策；外部冲击（资本外流、出口打击等）真实发生 |
| **Falsification（证伪条件）** | 若房地产加速器未启动且外部冲击发生，但经济未出现更大下探，且没有中期底部和救赎行情，则本断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 本就体弱的人再淋一场冷雨，病来如山倒；但病倒后家人才能下决心送大医院，彻底治愈后身体反而脱胎换骨

### 🔗 文字版因果链

1. 房地产加速器无法如期启动，其他加速器难以推动经济复苏
2. 经济底部不稳，第一季度的底部可能只是幻觉
3. 外部冲击（美元升值资本外流、欧元区冲击、出口受打击）袭来
4. 经济面临更大幅度下行，市场再次遭受冲击
5. 冲击后市场迎来中期重要底部
6. 政府被迫彻底打开刺激空间或走向增长质量提升之路，形成救赎性大机会或牛市格局
