# 市场对周期性行业抛弃，中周期景气预期缺失

> 属于因果簇：[[二次去库存的因果机制与时间判断]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 固定资产投资被政策刺激透支后的中枢下移 |
| **DV（因变量）** | 市场对周期性行业抛弃，中周期景气预期缺失 |
| **Chain（传导链）** | 刺激政策提前透支未来固定资产投资需求 → 市场预期投资中枢下移 → 周期性行业（房地产产业链、基建类投资）被市场抛弃 → 市场整体缺乏中周期景气预期 |
| **Lag（时滞）** | 中期预期形成，持续存在直至新的投资中枢确立并出现波动 |
| **Threshold（临界值）** | 新的投资中枢确立后，投资波动仍可带来中周期繁荣 |
| **前提与约束（Premises）** | 在工业化后期或转型阶段；市场理性反应投资中枢下移；中周期景气核心驱动力来自设备投资和产业升级 |
| **Falsification（证伪条件）** | 若在投资中枢下移后，周期性行业仍持续获得市场高估值且固定资产投资强力反弹，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一块土地过度施肥后肥力下降，农民知道下一季收成必然减少，于是不再购买农具，整个农业设备市场陷入低迷。

### 🔗 文字版因果链

1. 刺激政策提前透支未来固定资产投资需求
2. 市场预期投资中枢下移
3. 周期性行业（房地产产业链、基建类投资）被市场抛弃
4. 市场整体缺乏中周期景气预期
