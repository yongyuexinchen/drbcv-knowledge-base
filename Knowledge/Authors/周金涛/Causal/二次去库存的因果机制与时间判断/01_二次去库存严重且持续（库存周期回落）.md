# 二次去库存严重且持续（库存周期回落）

> 属于因果簇：[[二次去库存的因果机制与时间判断]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 价格上涨中的投机需求和由此带来的成本重新回升（通货膨胀问题） |
| **DV（因变量）** | 二次去库存严重且持续（库存周期回落） |
| **Chain（传导链）** | 价格上涨诱发投机性需求 → 投机需求推高原材料和资金成本 → 成本回升抑制实际需求增速 → 需求增速回落导致企业被动去库存 → 二次去库存过程开始并沿产业链传导 → 价格持续回落直至通胀底部，去库存进入尾声 |
| **Lag（时滞）** | 主要下降阶段经历3~5个季度，最早2010年第四季度进入尾声 |
| **Threshold（临界值）** | 通货膨胀的阶段底部即为二次去库存的底部 |
| **前提与约束（Premises）** | 适用于库存周期框架下的经济回落阶段；需求增速回落和资金成本提高是表象，通胀是根源；产业链传导存在时间，价格是观测指标 |
| **Falsification（证伪条件）** | 若在2010年第四季度之前价格止跌并需求持续回升，且未出现产业链传导的明显价格回落，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同感冒发烧：发烧（通胀）是症状而非病因，退烧（价格回落）才意味着病情接近尾声，整个过程需经历数周而非一两天。

### 🔗 文字版因果链

1. 价格上涨诱发投机性需求
2. 投机需求推高原材料和资金成本
3. 成本回升抑制实际需求增速
4. 需求增速回落导致企业被动去库存
5. 二次去库存过程开始并沿产业链传导
6. 价格持续回落直至通胀底部，去库存进入尾声
