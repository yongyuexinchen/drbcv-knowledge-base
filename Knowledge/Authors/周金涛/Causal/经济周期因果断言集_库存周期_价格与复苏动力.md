## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工业增加值季调趋势项环比见底（量的底部） |
| **DV（因变量）** | 产出缺口底部出现 |
| **Chain（传导链）** | 工业增加值季调趋势项环比在4月见底 → 经过3~4个月的传导 → 产出缺口在7月见底 |
| **Lag（时滞）** | 3~4个月 |
| **Threshold（临界值）** | 工业增加值季调趋势项环比见底后，产出缺口滞后3~4个月见底 |
| **前提与约束（Premises）** | 基于历史周期规律；数据经季调处理；不发生重大外部冲击 |
| **Falsification（证伪条件）** | 如果工业增加值季调趋势项环比见底后超过4个月产出缺口仍未见底，则断言不成立 |
| **Confidence（确信度）** | well-established |

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 量的底部和价格的底部出现 |
| **DV（因变量）** | 企业利润见底 |
| **Chain（传导链）** | 量的底部在7月出现 → PPI底部在9月出现 → 利润同比底部最早在量的底部出现，最晚在价的底部出现 → 因此第三季度为工业企业利润最低时期 |
| **Lag（时滞）** | 利润底部滞后量的底部，领先或同步于价的底部 |
| **Threshold（临界值）** | 量的底部与价的底部之间的区间对应利润底部 |
| **前提与约束（Premises）** | 不发生重大外部冲击导致第二次量价齐跌 |
| **Falsification（证伪条件）** | 若在量价底部之间利润未出现底部，或第三季度利润继续大幅下滑，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同企业收入（量）先降到底，售价（价）后降到底，利润在这两者之间触底

### 🔗 文字版因果链

1. 量的底部在7月出现
2. PPI底部在9月出现
3. 利润同比底部最早在量的底部出现，最晚在价的底部出现
4. 因此第三季度为工业企业利润最低时期

## 因果断言 13

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 产成品库存指数反弹（同时伴随生产、新订单、原材料库存指数反弹） |
| **DV（因变量）** | 经济向好判断不受影响（生产商预期积极） |
| **Chain（传导链）** | 产成品库存指数略有反弹 → 但生产、新订单、原材料库存指数同时反弹 → 企业存在补库存动机 → 产成品库存指数仍低于50% → 总体库存仍下降，经济仍可乐观 |
| **Lag（时滞）** | 0（同步指标） |
| **Threshold（临界值）** | 产成品库存指数仍低于50% |
| **前提与约束（Premises）** | 产成品库存反弹不是单独出现；生产和新订单等同步改善；基于历史经验（如2008—2009年） |
| **Falsification（证伪条件）** | 若产成品库存反弹而生产新订单未同步改善，且库存指数超过50%，则不应乐观 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 商店补货是因为生意好，而不是滞销，前提是其他销售指标也好

### 🔗 文字版因果链

1. 产成品库存指数略有反弹
2. 但生产、新订单、原材料库存指数同时反弹
3. 企业存在补库存动机
4. 产成品库存指数仍低于50%
5. 总体库存仍下降，经济仍可乐观
