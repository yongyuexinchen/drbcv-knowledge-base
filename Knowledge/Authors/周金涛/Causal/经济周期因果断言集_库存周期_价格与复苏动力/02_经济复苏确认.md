# 经济复苏确认

> 属于因果簇：[[经济周期因果断言集：库存周期、价格与复苏动力]]（第2块/13块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 需求回升（新订单增加） |
| **DV（因变量）** | 经济复苏确认 |
| **Chain（传导链）** | 需求回升 → 生产改善 → 采购增加 → 雇员增加 → 部分企业库存回补 → 复苏确认 |
| **Lag（时滞）** | 未明确，但根据从业人员滞后生产1~2个月，整体链条约数月 |
| **Threshold（临界值）** | 产成品库存指数持续低于50%，且生产、新订单、原材料库存同时反弹 |
| **前提与约束（Premises）** | 排除季节性因素；不发生重大外部冲击 |
| **Falsification（证伪条件）** | 如果需求回升后企业采购、生产、雇员未依次改善，或库存持续积压，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同餐厅客人增多后，厨房先多备料，再增加人手，最后翻台率上升

5. 部分企业库存回补
