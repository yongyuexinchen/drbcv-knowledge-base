## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元主导的纵向一体化共生模式 |
| **DV（因变量）** | 全球经济的金融失衡与2008年金融危机 |
| **Chain（传导链）** | 布雷顿森林体系崩溃后，美国利用美元本位垄断国际货币发行，形成中心-外围共生模式 → 资源国、制造国、消费国按比较优势纵向一体化分工，制造国积累贸易顺差和高储蓄，美国积累贸易逆差和资本项目盈余 → 美国双赤字和负债不断增长，透支美元信用，经济金融失衡加剧 → 2008年美国次贷危机爆发，终结长波繁荣，共生模式走向衰落 |
| **Lag（时滞）** | 数十年（自20世纪70年代共生模式建立至2008年金融危机） |
| **Threshold（临界值）** | 美国经常项目逆差极度扩张，美元信用被严重透支 |
| **前提与约束（Premises）** | 后布雷顿森林体系下美元占据国际货币主导权；外围国家坚持出口导向策略，美国作为最终消费市场 |
| **Falsification（证伪条件）** | 如果美国贸易逆差持续扩大而未引发金融危机或美元信用危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个家庭长期靠借债维持高消费，债务不断累积，最终爆发财务危机

### 🔗 文字版因果链

1. 布雷顿森林体系崩溃后，美国利用美元本位垄断国际货币发行，形成中心-外围共生模式
2. 资源国、制造国、消费国按比较优势纵向一体化分工，制造国积累贸易顺差和高储蓄，美国积累贸易逆差和资本项目盈余
3. 美国双赤字和负债不断增长，透支美元信用，经济金融失衡加剧
4. 2008年美国次贷危机爆发，终结长波繁荣，共生模式走向衰落

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球流动性反危机政策的边际效应递减 |
| **DV（因变量）** | 资源国长期增长趋势回落与美元中期升值 |
| **Chain（传导链）** | 2008年后各国竞相释放流动性反危机，但边际效应逐渐达到高点 → 流动性边际效应递减导致资源价格长期顶部出现，大宗商品价格回落 → 资源国出口收入下降，增长趋势回落 → 美元作为避险资产升值，为未来消灭通胀做准备 |
| **Lag（时滞）** | 约2-3年（2011年底流动性边际高点出现，2012年起显现） |
| **Threshold（临界值）** | 流动性边际效应到达高点，第三轮量化宽松后大宗商品走势趋弱 |
| **前提与约束（Premises）** | 长波处于衰退后半段相对稳定期；美国是全球流动性释放与收缩的最终决定力量 |
| **Falsification（证伪条件）** | 如果流动性释放继续大幅推高资源价格，资源国增长未回落，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一杯水加糖，糖加到一定量后再加也不觉得更甜，甚至开始觉得腻，市场对流动性的反应也一样递减

### 🔗 文字版因果链

1. 2008年后各国竞相释放流动性反危机，但边际效应逐渐达到高点
2. 流动性边际效应递减导致资源价格长期顶部出现，大宗商品价格回落
3. 资源国出口收入下降，增长趋势回落
4. 美元作为避险资产升值，为未来消灭通胀做准备

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国库存周期与建筑业周期的阶段转换 |
| **DV（因变量）** | 美国经济增长走势（先抑后扬） |
| **Chain（传导链）** | 美国经济当前进入库存周期减速阶段，库存调整对GDP产生负面冲击 → 未来几个季度美国将经历库存减速，经济疲弱复苏、逐级小幅向下 → 2013年第三季度左右库存周期由减速向下一轮景气转换，同时建筑业周期拐点来临 → 库存景气回升与房地产复苏合力推动美国经济走向景气 |
| **Lag（时滞）** | 数月至一年（库存周期调整约持续4-6个季度） |
| **Threshold（临界值）** | 库存周期由减速转向景气的时点大约在2013年第三季度；建筑业中长期拐点在2013年第三、四季度 |
| **前提与约束（Premises）** | 美国消费占GDP超70%，但库存波动是经济波动最大来源；2015年前美国房地产主要依赖首次置业，二次置业下行，2013-2014年为购房人口低点 |
| **Falsification（证伪条件）** | 如果美国库存周期未按预期在2013年第三季度回升，或建筑业持续低迷，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像潮汐，库存周期是拍岸的浪，建筑业周期是潮位，浪退到底后潮位慢慢上升，合力让海面整体抬升

### 🔗 文字版因果链

1. 美国经济当前进入库存周期减速阶段，库存调整对GDP产生负面冲击
2. 未来几个季度美国将经历库存减速，经济疲弱复苏、逐级小幅向下
3. 2013年第三季度左右库存周期由减速向下一轮景气转换，同时建筑业周期拐点来临
4. 库存景气回升与房地产复苏合力推动美国经济走向景气

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国经济周期状态（库存周期触底启动） |
| **DV（因变量）** | 国际资本净流动方向（流出或流入） |
| **Chain（传导链）** | 中国经济进入库存周期底部，产出缺口出现向上拐的趋势 → 经济企稳向好预期增强，新兴市场收益率相对提升 → 资本流出放缓，并转为净流入 → 显著的资本流入需要等到2013年第一季度之后 |
| **Lag（时滞）** | 约1-2个季度（2012年8月库存周期见底，2013年第一季度后资本流入显著） |
| **Threshold（临界值）** | 库存周期低点出现，中国经济领先美国探底 |
| **前提与约束（Premises）** | 资本流动由经济周期相对强弱决定，美国经济周期与中国经济周期不同步；外汇储备变化减去贸易顺差代表广义资本流动 |
| **Falsification（证伪条件）** | 如果中国经济见底回升后资本仍持续大规模流出，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像水往低处流，资本总是流向经济景气度高、回报机会多的地方；经济见底就像洼地开始蓄水，吸引水流

### 🔗 文字版因果链

1. 中国经济进入库存周期底部，产出缺口出现向上拐的趋势
2. 经济企稳向好预期增强，新兴市场收益率相对提升
3. 资本流出放缓，并转为净流入
4. 显著的资本流入需要等到2013年第一季度之后

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中美两国经济周期的时序关系（中国先于美国探底） |
| **DV（因变量）** | A股市场走势（上半年反弹，下半年系统性上升） |
| **Chain（传导链）** | 中国短周期在2012年8月见第一低点，美国库存周期仍在向下探底 → 中国经济先于美国探底，在此消彼长下中国相对吸引力增强，资本流入A股 → 2013年上半年市场在复苏预期中运行，预期逐步验证，但经济数据可能反复，股市表现为上涨后调整 → 下半年美国第二库存周期启动，中国经济第二库存周期主升阶段，出口复苏、资本流入持续，A股迎来系统性上升机会 |
| **Lag（时滞）** | 半年左右（上半年调整，下半年启动） |
| **Threshold（临界值）** | 美国第二库存周期启动时间在2013年第二、三季度；中国第二库存周期主升阶段在2013年第二季度后 |
| **前提与约束（Premises）** | 全球再平衡通过此消彼长的周期波动实现，中美是核心；欧债风险和资源国不构成系统性风险 |
| **Falsification（证伪条件）** | 如果中国先探底但资本外逃A股持续下跌，或美国经济复苏未带动全球需求，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像两列火车，中国车先到站，美国车后到站，先到的先启动，乘客（资本）会先涌向先启动的车厢

### 🔗 文字版因果链

1. 中国短周期在2012年8月见第一低点，美国库存周期仍在向下探底
2. 中国经济先于美国探底，在此消彼长下中国相对吸引力增强，资本流入A股
3. 2013年上半年市场在复苏预期中运行，预期逐步验证，但经济数据可能反复，股市表现为上涨后调整
4. 下半年美国第二库存周期启动，中国经济第二库存周期主升阶段，出口复苏、资本流入持续，A股迎来系统性上升机会
