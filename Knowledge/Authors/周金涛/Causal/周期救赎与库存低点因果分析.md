# 周期救赎与库存低点因果分析

> **领域**：宏观经济学　|　**来源**：chapter_36.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 库存达到高点并开始主动去库存 |
| **DV（因变量）** | 库存周期低点在第一季度末出现 |
| **Chain（传导链）** | 库存高点出现，企业进入主动去库存 → 需求不足导致量价齐跌 → 量价齐跌持续约一个季度 → 价格足够低且资金面宽松时，自发的库存行为产生，库存周期达到低点 |
| **Lag（时滞）** | 约一个季度（从库存高点到低点） |
| **Threshold（临界值）** | 价格足够低且资金面宽松，量价齐跌持续一个季度 |
| **前提与约束（Premises）** | 在非资产价格泡沫冲击性破灭的背景下；中周期动能衰落但不影响短周期库存行为 |
| **Falsification（证伪条件）** | 若量价齐跌一个季度后库存未达到低点，或库存低点未在第一季度末出现，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像水库放水，泄洪达到一定时间后水位自然降到最低点，但前提是出水口通畅（资金宽松）且水价（价格）足够低。

### 🔗 文字版因果链

1. 库存高点出现，企业进入主动去库存
2. 需求不足导致量价齐跌
3. 量价齐跌持续约一个季度
4. 价格足够低且资金面宽松时，自发的库存行为产生，库存周期达到低点

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 库存周期低点带来的经济企稳预期 |
| **DV（因变量）** | 早周期行业（地产、金融、汽车）配置领涨与周期救赎行情 |
| **Chain（传导链）** | 库存低点出现使经济触底预期增强 → 早周期行业（地产、金融、汽车）因低估值和触底预期获得配置偏好 → 地产销售和投资回升带动产业链，形成周期救赎行情 |
| **Lag（时滞）** | 未来三个月内（从库存低点到行情展开） |
| **Threshold（临界值）** | 地产销售和投资的不同回落程度决定库存低点未来走多远；救赎向钢铁、水泥和机械延伸需等到真正经济底部 |
| **前提与约束（Premises）** | 不出现地产泡沫冲击性破灭；中国经济弹性仍源于地产产业链；上游资源类品种中期趋势向下，不宜模仿2008年走势 |
| **Falsification（证伪条件）** | 若地产销售和投资未回升而经济仍能反弹，或周期救赎行情未在早周期行业展开，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像生病后先恢复的是最基础的器官功能（早周期），只有核心器官（地产）真正好转，整个身体才能康复。

### 🔗 文字版因果链

1. 库存低点出现使经济触底预期增强
2. 早周期行业（地产、金融、汽车）因低估值和触底预期获得配置偏好
3. 地产销售和投资回升带动产业链，形成周期救赎行情

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国进入建筑业周期且美元升值 |
| **DV（因变量）** | 中国去泡沫与股市真正中期低点出现 |
| **Chain（传导链）** | 美国建筑业复苏和美元升值开始 → 新兴市场面临去泡沫压力和增长模式转换 → 中国去泡沫成为必然事件 → 冲击机制出现时，中国经济二次探底完成 → 股市真正中期低点随之来临 |
| **Lag（时滞）** | 2012年下半年开始的一年内（真正低点出现） |
| **Threshold（临界值）** | 冲击机制一旦出现（如外部危机/资本流动逆转） |
| **前提与约束（Premises）** | 全球利益调整模式带有必然性；中国经济增长中枢下移是趋势；2011-2013年为现金为王年份，但股票市场接近历史转折点 |
| **Falsification（证伪条件）** | 若美国建筑业复苏和美元升值后，中国未出现去泡沫压力或股市低点未在所述时间出现，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像全球潮汐变化，大潮来临必然要退去，只有退到最低点才会重新涨潮，而股市低点就是那退潮后的最低位。

### 🔗 文字版因果链

1. 美国建筑业复苏和美元升值开始
2. 新兴市场面临去泡沫压力和增长模式转换
3. 中国去泡沫成为必然事件
4. 冲击机制出现时，中国经济二次探底完成
5. 股市真正中期低点随之来临
