# 工资内生性加速上涨

> 属于因果簇：[[周金涛消费与周期理论中的因果断言提取]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 劳动力无限供给的终结（刘易斯拐点） |
| **DV（因变量）** | 工资内生性加速上涨 |
| **Chain（传导链）** | 20世纪80年代末90年代初以后人口出生率持续下滑 → 2007-2008年后年满18岁适龄劳动力供给增速持续下降 → 新增劳动力供不应求格局最迟在2009-2010年出现 → 劳动力无限供给状况逐步消失 → 劳动力工资面临内生性加速上涨 |
| **Lag（时滞）** | 未来5年内（从2005年起算，约2008-2010年前后显现） |
| **Threshold（临界值）** | GDP增速保持8%~9%时，新增劳动力供不应求局面在2008年前后出现的可能性最大 |
| **前提与约束（Premises）** | 农村潜在剩余劳动力因受教育年限短（90%以上初中及以下学历）无法有效满足工业部门需求；流量劳动力供需（新增劳动力）比存量供需更重要，是决定劳动力价格的主导因素；工业化中后期二元经济向一元经济转变是普遍规律（如日本、拉尼斯-费景汉三阶段） |
| **Falsification（证伪条件）** | 若未来5年新增劳动力供给仍大于需求，或工资增速未出现加速上升，则该断言被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 当水库的储水量持续下降而用水需求不变时，水价必然上涨——劳动力供给是蓄水池，工资是水价。

### 🔗 文字版因果链

1. 20世纪80年代末90年代初以后人口出生率持续下滑
2. 2007-2008年后年满18岁适龄劳动力供给增速持续下降
3. 新增劳动力供不应求格局最迟在2009-2010年出现
4. 劳动力无限供给状况逐步消失
5. 劳动力工资面临内生性加速上涨
