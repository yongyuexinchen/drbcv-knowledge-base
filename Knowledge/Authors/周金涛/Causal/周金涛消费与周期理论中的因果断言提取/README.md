# 周金涛消费与周期理论中的因果断言提取（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：周金涛消费与周期理论中的因果断言提取.md

## 总体因果图

- 劳动力无限供给的终结（刘易斯拐点） → 工资内生性加速上涨
- 工资（居民收入）增长 → 居民消费支出增长
- 消费结构变化（如交通通信、教育医疗、文化娱乐等支出比重上升） → 产业结构变化（相应产业部门扩张）
- 资源约束导致的成本上升 → 消费品行业利润下降（制造业消费品受冲击大，服务类消费品相对较
