# 居民消费支出增长

> 属于因果簇：[[周金涛消费与周期理论中的因果断言提取]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工资（居民收入）增长 |
| **DV（因变量）** | 居民消费支出增长 |
| **Chain（传导链）** | 工资收入占我国居民收入构成的70%以上 → 工资增长趋势决定居民收入增长状况 → 居民购买力（可支配收入）提高 → 消费支出作为收入的函数随之增长 → 回归分析显示工资增速与居民消费支出增速显著正相关 |
| **Lag（时滞）** | 同期或短期（年度层面） |
| **Threshold（临界值）** | 工资增速与消费支出增速存在显著线性正相关（文中未给出具体系数） |
| **前提与约束（Premises）** | 市场经济中消费实现必须以货币购买力为前提；凯恩斯、杜森贝里、弗里德曼消费理论均将消费视为收入的函数；工资是居民收入的主要构成部分 |
| **Falsification（证伪条件）** | 若工资增速上升而居民消费支出增速没有相应上升，或两者出现背离，则该断言被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水管中的水压增大，水流量必然增大——工资是水压，消费是水流量。

### 🔗 文字版因果链

1. 工资收入占我国居民收入构成的70%以上
2. 工资增长趋势决定居民收入增长状况
3. 居民购买力（可支配收入）提高
4. 消费支出作为收入的函数随之增长
5. 回归分析显示工资增速与居民消费支出增速显著正相关
