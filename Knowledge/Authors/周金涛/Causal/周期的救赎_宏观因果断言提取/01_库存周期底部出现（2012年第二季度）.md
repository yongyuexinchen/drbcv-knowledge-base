# 库存周期底部出现（2012年第二季度）

> 属于因果簇：[[周期的救赎：宏观因果断言提取]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 原材料库存指数触底回升 |
| **DV（因变量）** | 库存周期底部出现（2012年第二季度） |
| **Chain（传导链）** | 原材料库存指数是生产领域的冷暖指标，领先产成品库存累计同比约2~3个季度 → 原材料库存指数触底回升，表明生产企业预期需求将好转并开始增加原材料采购 → 经约两个季度传导，产成品库存累计同比增速企稳见底，库存周期进入底部 |
| **Lag（时滞）** | 2~3个季度（按2个季度计算） |
| **Threshold（临界值）** | 原材料库存指数持续回升，且领先关系保持稳定 |
| **前提与约束（Premises）** | 需求仍处于疲弱或调整阶段，无突发重大政策或外部冲击改变库存行为；量价关系遵循被动去库存→主动去库存→被动补库存→主动补库存的经典库存周期规律 |
| **Falsification（证伪条件）** | 如果2012年第二季度产成品库存累计同比增速未企稳见底，或原材料库存指数回升后产成品库存继续恶化，则该因果断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 原材料库存指数是生产领域的冷暖指标，领先产成品库存累计同比约2~3个季度
2. 原材料库存指数触底回升，表明生产企业预期需求将好转并开始增加原材料采购
3. 经约两个季度传导，产成品库存累计同比增速企稳见底，库存周期进入底部
