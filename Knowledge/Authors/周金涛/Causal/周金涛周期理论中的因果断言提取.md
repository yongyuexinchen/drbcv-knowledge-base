## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球中周期高点确认（美国中周期高点） |
| **DV（因变量）** | 全球风险偏好收缩与风险资产回落 |
| **Chain（传导链）** | 美国固定资产投资占比达到边际高点并出现拐点特征 → 美国经济转向消费拉动、就业接近充分就业，中周期进入后半段 → 主导国中周期高点对应全球中周期高点 → 宽松逻辑推高风险资产价格至高位 → 中周期高点确认后，全球风险偏好收缩 → 风险资产价格回落 |
| **Lag（时滞）** | 约2-3个季度（2015年第二三季度确认高点后风险资产回落） |
| **Threshold（临界值）** | 美国固定资产投资占比出现边际高点；就业率接近充分就业（失业率5.1%附近） |
| **前提与约束（Premises）** | 全球处于康波衰退期后半段，长波位置制约中周期强度；全球资产配置此前围绕宽松逻辑运行；流动性宽松已将风险资产估值推至泡沫化高位 |
| **Falsification（证伪条件）** | 若美国固定资产投资占比持续创新高且就业距离充分就业仍有显著空间，中周期高点未被确认，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同长跑运动员到达体能峰值后，后续速度必然下降，即使能继续跑，但最强劲的阶段已经过去。

### 🔗 文字版因果链

1. 美国固定资产投资占比达到边际高点并出现拐点特征
2. 美国经济转向消费拉动、就业接近充分就业，中周期进入后半段
3. 主导国中周期高点对应全球中周期高点
4. 宽松逻辑推高风险资产价格至高位
5. 中周期高点确认后，全球风险偏好收缩
6. 风险资产价格回落

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 第三库存周期开启（2016年前后全球主要经济体） |
| **DV（因变量）** | 大宗商品价格率先反弹、风险偏好回升 |
| **Chain（传导链）** | 中周期中后段流动性紧缩带来强美元效应 → 强美元冲击美国经济基本面，美国需要推动第三库存周期 → 2016年美国、中国、欧洲等先后开启第三库存周期 → 第三库存周期上行期产出扩张、需求回暖 → 大宗商品价格筑底后缓慢攀升 → 价格体系的回升成为全球风险偏好回升的重要边际变化 |
| **Lag（时滞）** | 2015年下半年筑底，2016年初启动，上行期维持4-6个季度至2017年中期 |
| **Threshold（临界值）** | 库存周期40个月左右运行规律；美国第二库存周期2016年中期触底 |
| **前提与约束（Premises）** | 全球总需求不足但避免立即陷入萧条；美国中周期仍有余力，可开启第三库存周期；各国政策博弈下美元强势弱于前两轮强周期；中国2016年初出现第三库存周期启动点，产能周期第一低点反弹和房地产周期B浪提供动力 |
| **Falsification（证伪条件）** | 若2016年全球主要经济体未出现库存周期上行，或大宗商品持续下跌且无反弹迹象，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同季节轮回：冬季最深时反而孕育春天，但春天何时来取决于多重条件，一旦春风吹起，最先感知的是大地回温（商品反弹）。

### 🔗 文字版因果链

1. 中周期中后段流动性紧缩带来强美元效应
2. 强美元冲击美国经济基本面，美国需要推动第三库存周期
3. 2016年美国、中国、欧洲等先后开启第三库存周期
4. 第三库存周期上行期产出扩张、需求回暖
5. 大宗商品价格筑底后缓慢攀升
6. 价格体系的回升成为全球风险偏好回升的重要边际变化

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 宽松货币政策（欧洲、日本QE及中国降准降息） |
| **DV（因变量）** | 无风险收益率下行与“股债双牛” |
| **Chain（传导链）** | 总需求不足、通货膨胀走低 → 央行实施宽松货币政策（QE、降息降准） → 无风险收益率被压低 → 债券价格上涨；股权估值因贴现率下降而提升 → 资金流入风险资产，形成“股债双牛” |
| **Lag（时滞）** | 政策实施后1-2个季度内显现 |
| **Threshold（临界值）** | 无风险收益率持续下行至极低位置；主要央行基准利率降至历史低位 |
| **前提与约束（Premises）** | 债务-通缩压力下，宽松是唯一选择；未出现大规模资本外流或货币危机（资源国除外）；改革红利或增长预期支撑估值 |
| **Falsification（证伪条件）** | 若宽松货币政策实施后无风险收益率未下降，或股债未能双牛，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同低利率的磁铁，把资金吸向债券和股票两根铁棒，两者同时被吸起。

### 🔗 文字版因果链

1. 总需求不足、通货膨胀走低
2. 央行实施宽松货币政策（QE、降息降准）
3. 无风险收益率被压低
4. 债券价格上涨；股权估值因贴现率下降而提升
5. 资金流入风险资产，形成“股债双牛”

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务-通缩困境下长期流动性宽松 |
| **DV（因变量）** | 资产价格泡沫化与“类滞胀”逻辑对流动性的边际敏感 |
| **Chain（传导链）** | 高债务与通缩持续，各国以债务扩张延续经济 → 长期流动性宽松推高资产价格至高位 → 股债价格对流动性边际变化极为敏感 → 油价等大宗商品筑底反弹引发通胀预期 → 德国国债下跌、A股股灾等表现，显示宽松逻辑达到边际高点 → 资产价格对加息预期或流动收紧高度敏感，形成“类滞胀”式波动 |
| **Lag（时滞）** | 宽松政策累计约6年后（2015年）出现边际效应递减 |
| **Threshold（临界值）** | 无风险利率降至极低；资产估值泡沫化；通胀预期因大宗反弹而抬升 |
| **前提与约束（Premises）** | 全球总需求不足但债务压力高企；宽松不能有效刺激实体增长，仅推高资产价格；美联储面临加息与经济增长的矛盾 |
| **Falsification（证伪条件）** | 若宽松政策继续大幅推高资产价格而未出现边际敏感，或通胀预期持续低迷无反弹，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同不断增加火炉温度，炉子上的水已经烧到100度，再添一根柴也可能让水剧烈沸腾甚至爆沸——对微小温度变化也极其敏感。

### 🔗 文字版因果链

1. 高债务与通缩持续，各国以债务扩张延续经济
2. 长期流动性宽松推高资产价格至高位
3. 股债价格对流动性边际变化极为敏感
4. 油价等大宗商品筑底反弹引发通胀预期
5. 德国国债下跌、A股股灾等表现，显示宽松逻辑达到边际高点
6. 资产价格对加息预期或流动收紧高度敏感，形成“类滞胀”式波动

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元强势周期（2014年开始的美元牛市） |
| **DV（因变量）** | 新兴市场国家受到冲击（资金外流、金融市场下跌） |
| **Chain（传导链）** | 美国经济增速或利率与主要经济体差距扩大 → 国际资本回流美国，美元升值 → 新兴市场国家外债偿还压力增大 → 资本从新兴市场流出 → 新兴市场货币贬值、资金外流与金融市场大幅下跌 |
| **Lag（时滞）** | 美元持续走强后1-2年内（如第一轮1980-1985冲击拉美，第二轮1995-2001冲击东南亚） |
| **Threshold（临界值）** | 美元指数趋势性走强超过6年；美国与主要经济体利差扩大 |
| **前提与约束（Premises）** | 新兴市场依赖外部资本或高外债；美元作为世界货币主导资本流动；美国经济相对强劲或政策紧缩 |
| **Falsification（证伪条件）** | 若美元走强期间新兴市场未出现资金流出和金融动荡，反而汇率稳定，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大潮退去，才发现谁在裸泳——美元走强时，借了大量美元债的新兴市场最先暴露脆弱性。

### 🔗 文字版因果链

1. 美国经济增速或利率与主要经济体差距扩大
2. 国际资本回流美国，美元升值
3. 新兴市场国家外债偿还压力增大
4. 资本从新兴市场流出
5. 新兴市场货币贬值、资金外流与金融市场大幅下跌

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 康波周期运行至衰退向萧条过渡阶段 |
| **DV（因变量）** | 价格体系出现冲高回落（走向滞胀） |
| **Chain（传导链）** | 康波衰退期后半段总需求不足、要素回报率下降 → 各国通过宽松政策避免萧条，债务不断扩张 → 宽松推动资产价格大幅上行 → 价格（商品或通胀）在过渡期出现冲高回落 → 最终以紧缩或泡沫破裂结束中周期，走向萧条 |
| **Lag（时滞）** | 过渡期跨越数年（如当前阶段从2015年前后开始预演） |
| **Threshold（临界值）** | 康波衰退期价格100%剧烈波动；萧条期价格100%冲高回落 |
| **前提与约束（Premises）** | 当前处于第五波康波衰退到萧条的转换点；全球货币大量释放但实体增长不足；历史规律显示衰退期价格必然高波动 |
| **Falsification（证伪条件）** | 若康波进入萧条期时价格持续低迷未出现冲高，或全球成功避免萧条而进入新繁荣，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同秋天的天气，阴晴不定且温差巨大（价格剧烈波动），而冬天真正到来后反而会有一次最后的温暖（冲高）再彻底转冷。

### 🔗 文字版因果链

1. 康波衰退期后半段总需求不足、要素回报率下降
2. 各国通过宽松政策避免萧条，债务不断扩张
3. 宽松推动资产价格大幅上行
4. 价格（商品或通胀）在过渡期出现冲高回落
5. 最终以紧缩或泡沫破裂结束中周期，走向萧条

### 🔗 文字版因果链

1. 美国中周期运行7年后进入中后段，接近充分就业

3. 历史规律显示此后仍可开启第三库存周期
4. 中周期自身特质（房地产、美元、康波位置）决定第三库存周期强度与时长

## 因果断言 8

### 🔬 CAO 结构表

|------|------|

| **Threshold（临界值）** | 短周期下行期持续约20个月；美国第二库存周期运行至36个月左右 |
| **前提与约束（Premises）** | 全球主要经济体库存周期不同步但收敛；美元强势弱于前两轮周期；去产能与去库存接近尾声 |
| **Falsification（证伪条件）** | 若全球共振下行使商品继续暴跌且美元持续走强，未出现商品率先反弹，则该断言不成立 |

> 如同风暴中心过后，海面先出现平静（商品筑底），随后波浪才逐渐平复（权益资产企稳）。

### 🔗 文字版因果链

1. 美国第二库存周期2016年中期触底，欧洲稍晚触底
2. 中国2016年初出现第三库存周期启动点
3. 库存周期交替决定了美元指数阶段性走弱
4. 大宗商品在金融抑制因素解除后价格触底反弹
5. 商品率先反弹领先于权益资产
