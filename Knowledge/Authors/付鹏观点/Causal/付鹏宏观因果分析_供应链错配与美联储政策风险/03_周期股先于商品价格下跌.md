# 周期股先于商品价格下跌

> 属于因果簇：[[付鹏宏观因果分析：供应链错配与美联储政策风险]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 商品价格见顶信号（结构转弱） |
| **DV（因变量）** | 周期股先于商品价格下跌 |
| **Chain（传导链）** | 商品价格高位横盘，但远期结构转弱（如backwardation收窄） → 交易员感知到上涨动力减弱，率先平仓权益头寸 → 周期股因盈利预期下降而下跌 → 商品价格因基本面支撑仍维持高位，但股票已先行调整 |
| **Lag（时滞）** | 数周到数月 |
| **Threshold（临界值）** | 商品价格停止上涨或结构转弱时，股票开始下跌 |
| **前提与约束（Premises）** | 市场参与者对商品价格见顶有预期；权益市场反应快于商品市场；基本面仍支撑商品价格 |
| **Falsification（证伪条件）** | 如果商品价格继续上涨且股票同步上涨，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像赛跑，股票是短跑选手先冲线，商品是长跑选手后停步

### 🔗 文字版因果链

1. 商品价格高位横盘，但远期结构转弱（如backwardation收窄）
2. 交易员感知到上涨动力减弱，率先平仓权益头寸
3. 周期股因盈利预期下降而下跌
4. 商品价格因基本面支撑仍维持高位，但股票已先行调整
