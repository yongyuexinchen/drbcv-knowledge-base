# 黄金价格见顶回落，市场波动率上升

> 属于因果簇：[[付鹏宏观因果分析：供应链错配与美联储政策风险]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美联储提前收紧流动性（加息缩表预期） |
| **DV（因变量）** | 黄金价格见顶回落，市场波动率上升 |
| **Chain（传导链）** | 美联储释放收紧信号，市场预期实际利率上升 → 黄金作为实际利率的敏感资产，价格提前反应 → 中长端利率上升，黄金持有成本增加 → 黄金价格从高点回落，波动率放大 |
| **Lag（时滞）** | 预期先行，实际政策落地时黄金可能已见底 |
| **Threshold（临界值）** | 美联储实际开始加息缩表时，黄金可能已跌到底部 |
| **前提与约束（Premises）** | 美联储政策转向快于市场预期；实际利率上升；通胀预期未能持续 |
| **Falsification（证伪条件）** | 如果美联储持续宽松，实际利率下降，黄金价格创新高，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像天气预报说台风要来，人们提前囤货，等台风真正来时，抢购潮已过

### 🔗 文字版因果链

1. 美联储释放收紧信号，市场预期实际利率上升
2. 黄金作为实际利率的敏感资产，价格提前反应
3. 中长端利率上升，黄金持有成本增加
4. 黄金价格从高点回落，波动率放大
