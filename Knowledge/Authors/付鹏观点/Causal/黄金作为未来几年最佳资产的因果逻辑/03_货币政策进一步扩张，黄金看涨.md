# 货币政策进一步扩张，黄金看涨

> 属于因果簇：[[黄金作为未来几年最佳资产的因果逻辑]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 疫情激化部分国家内部矛盾 |
| **DV（因变量）** | 货币政策进一步扩张，黄金看涨 |
| **Chain（传导链）** | 疫情冲击经济，社会矛盾激化 → 政府为缓解矛盾，加大货币和财政刺激 → 刺激政策导致债务进一步积累 → 债务风险上升，信用受损 → 黄金作为信用风险对冲工具，价格上涨 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 疫情导致经济衰退，政策空间耗尽 |
| **前提与约束（Premises）** | 疫情持续时间长，社会矛盾激化；政策制定者选择扩张而非紧缩 |
| **Falsification（证伪条件）** | 如果疫情迅速结束，经济快速复苏，政策正常化，黄金涨势受阻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像火灾时，人们会抢购灭火器，疫情就是火灾，黄金就是灭火器。

### 🔗 文字版因果链

1. 疫情冲击经济，社会矛盾激化
2. 政府为缓解矛盾，加大货币和财政刺激
3. 刺激政策导致债务进一步积累
4. 债务风险上升，信用受损
5. 黄金作为信用风险对冲工具，价格上涨
