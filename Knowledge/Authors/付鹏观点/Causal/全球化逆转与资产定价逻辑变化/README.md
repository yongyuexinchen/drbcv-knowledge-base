# 全球化逆转与资产定价逻辑变化（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：全球化逆转与资产定价逻辑变化.md

## 总体因果图

- 全球化逆转（逆全球化） → 资产定价逻辑改变（政治因子放大，定性影响定价）
- 央行被动性驱动利率变动（非主动） → 市场波动更剧烈且持续时间更长
- 美联储加息（高温80度） → 经济层面（房子、就业、居民储蓄）受损
- 欧洲经济衰退 → 全球商品型通胀和总需求下降（缓和作用）
- 美元强势（美联储紧缩） → 其他国家经济压力增大（股债汇三杀）
- 欧洲天然气市场结构变化（价差回落） → 欧洲系统性短缺风险降低
- 中国指数编制问题（权重稀释） → 上证指数不能反映经济真实表现
- 政策扶持（远期投资回报） → 特定行业（如新能源）估值提升
