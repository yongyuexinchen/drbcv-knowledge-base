# 上证指数不能反映经济真实表现

> 属于因果簇：[[全球化逆转与资产定价逻辑变化]]（第7块/8块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国指数编制问题（权重稀释） |
| **DV（因变量）** | 上证指数不能反映经济真实表现 |
| **Chain（传导链）** | 大量权重为国有企业，不可替代 → 新市值企业只能稀释指数 → 指数无法优胜劣汰 → 指数与经济表现脱节 |
| **Lag（时滞）** | 长期存在 |
| **Threshold（临界值）** | 经济总量增速下滑时 |
| **前提与约束（Premises）** | 指数编制规则不变；经济结构转型 |
| **Falsification（证伪条件）** | 若指数编制改革或经济总量恢复高增长，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一锅汤里加了很多水，即使食材再好，汤的味道也变淡了。

### 🔗 文字版因果链

1. 大量权重为国有企业，不可替代
2. 新市值企业只能稀释指数
3. 指数无法优胜劣汰
4. 指数与经济表现脱节
