# 其他国家经济压力增大（股债汇三杀）

> 属于因果簇：[[全球化逆转与资产定价逻辑变化]]（第5块/8块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美元强势（美联储紧缩） |
| **DV（因变量）** | 其他国家经济压力增大（股债汇三杀） |
| **Chain（传导链）** | 美联储紧缩，美元利率上升 → 利差扩大，资本流向美国 → 其他国家货币贬值、资产价格下跌 → 经济压力增大 |
| **Lag（时滞）** | 持续至美联储周期结束 |
| **Threshold（临界值）** | 美元指数维持高位（如110） |
| **前提与约束（Premises）** | 美国经济相对强劲；其他国家经济疲弱或被动跟随 |
| **Falsification（证伪条件）** | 若美元走弱或美联储提前转向，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像班里最强者不断加码考试难度，其他同学只能被动应对，压力山大。

### 🔗 文字版因果链

1. 美联储紧缩，美元利率上升
2. 利差扩大，资本流向美国
3. 其他国家货币贬值、资产价格下跌
4. 经济压力增大
