# 中国资本市场提供高回报率

> 属于因果簇：[[2009年后中国产业生命周期与资本市场回报及企业崛起]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 2009年开始的产业转型（从做大到做强、从完整到精细） |
| **DV（因变量）** | 中国资本市场提供高回报率 |
| **Chain（传导链）** | 2008年全球金融危机促使中国主动提出经济转型 → 2009年后产业生命周期从规模扩张转向精细化与创新 → 资本市场配套政策（中小板、创业板、新三板等）支持创新企业 → 创新与领先性提升企业盈利能力，推动资本市场回报率上升 |
| **Lag（时滞）** | 约10年（2009年后逐步显现，过去十年成长） |
| **Threshold（临界值）** | 产业生命周期完成从‘做大’到‘做强’的转折点（2008-2009年） |
| **前提与约束（Premises）** | 中国已具备完善的工业基础和产业链完整度；政策支持创新和资本市场改革；全球经济环境允许中国加速追赶 |
| **Falsification（证伪条件）** | 如果2009年后中国资本市场长期回报率低于其他主要市场，或产业转型未能提升企业盈利能力，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人从青少年期（规模扩张）进入青年期（精细化发展），青年期更有成长潜力，投资回报更高。

### 🔗 文字版因果链

1. 2008年全球金融危机促使中国主动提出经济转型
2. 2009年后产业生命周期从规模扩张转向精细化与创新
3. 资本市场配套政策（中小板、创业板、新三板等）支持创新企业
4. 创新与领先性提升企业盈利能力，推动资本市场回报率上升
