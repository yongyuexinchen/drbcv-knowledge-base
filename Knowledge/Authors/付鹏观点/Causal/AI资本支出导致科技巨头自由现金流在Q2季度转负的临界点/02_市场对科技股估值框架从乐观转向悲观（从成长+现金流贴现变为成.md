# 市场对科技股估值框架从乐观转向悲观（从成长+现金流贴现变为成

> 属于因果簇：[[AI资本支出导致科技巨头自由现金流在Q2季度转负的临界点]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自由现金流转负与AI应用层爆发延迟同时发生 |
| **DV（因变量）** | 市场对科技股估值框架从乐观转向悲观（从成长+现金流贴现变为成长打问号） |
| **Chain（传导链）** | 自由现金流转负，表明公司家底耗尽 → AI应用层大规模爆发迟迟未出现，云服务收入增长与资本支出之比急速走高（投入产出比恶化） → 股东和投资人信心动摇，风险敏感性上升 → 估值框架从基于未来信心的溢价转向对持续烧钱的质疑，导致估值下调 |
| **Lag（时滞）** | 即时（市场提前反应，如谷歌财报后市场反应） |
| **Threshold（临界值）** | 自由现金流为负且云服务收入/资本支出比率持续恶化（具体数值未给出） |
| **前提与约束（Premises）** | 市场是有效的，提前反映预期；投资人关注自由现金流作为真实价值指标；AI应用层收入增长缓慢，无法匹配资本支出 |
| **Falsification（证伪条件）** | 如果AI应用层收入快速增长，使投入产出比改善，或自由现金流转正，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同创业公司烧钱扩张，但收入迟迟不增长，投资人从期待变成怀疑，最终不再愿意给高估值

### 🔗 文字版因果链

1. 自由现金流转负，表明公司家底耗尽
2. AI应用层大规模爆发迟迟未出现，云服务收入增长与资本支出之比急速走高（投入产出比恶化）
3. 股东和投资人信心动摇，风险敏感性上升
4. 估值框架从基于未来信心的溢价转向对持续烧钱的质疑，导致估值下调
