# 美联储和财政政策无力退出宽松，货币政策失效

> 属于因果簇：[[黄金作为未来几年最佳资产的因果逻辑]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球分工分配的核心问题长期得不到解决 |
| **DV（因变量）** | 美联储和财政政策无力退出宽松，货币政策失效 |
| **Chain（传导链）** | 全球分工分配问题导致经济结构失衡 → 经济结构失衡使得利率抬升不可持续 → 美联储和财政在2008年后无力退出宽松 → 疫情冲击下货币和财政政策再次扩张至极限 → 货币政策失效，利率趴在地板上 |
| **Lag（时滞）** | 长期（2008年至今） |
| **Threshold（临界值）** | 债务和信用风险无上限，利率有下限 |
| **前提与约束（Premises）** | 全球经济一体化背景下，分配问题持续存在；政策制定者优先考虑短期稳定而非长期退出 |
| **Falsification（证伪条件）** | 如果美联储成功加息并退出宽松，且经济结构改善，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个病人长期依赖药物，药效越来越差，但病情未根治，最终药物无效。

### 🔗 文字版因果链

1. 全球分工分配问题导致经济结构失衡
2. 经济结构失衡使得利率抬升不可持续
3. 美联储和财政在2008年后无力退出宽松
4. 疫情冲击下货币和财政政策再次扩张至极限
5. 货币政策失效，利率趴在地板上
