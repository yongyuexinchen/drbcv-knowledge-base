# 黄金成为表现最好的资产

> 属于因果簇：[[黄金作为未来几年最佳资产的因果逻辑]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币政策失效，利率趴在地板上 |
| **DV（因变量）** | 黄金成为表现最好的资产 |
| **Chain（传导链）** | 利率降至地板，实际利率极低 → 债务和信用风险上升，主权信用受损 → 黄金作为实际利率的对标物，反映主权信用风险 → 当利率无效时，黄金转向反映政府信用和债务风险 → 黄金价格创历史新高，波动率上升 |
| **Lag（时滞）** | 中期（数年） |
| **Threshold（临界值）** | 利率接近零下限，债务规模突破临界值 |
| **前提与约束（Premises）** | 政府无法重塑信用，债务持续积累；通胀预期不失控，但实际利率维持低位 |
| **Falsification（证伪条件）** | 如果政府成功重塑信用，债务风险下降，黄金价格回落 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像货币贬值时，人们转向实物资产保值，黄金成为最后的避风港。

### 🔗 文字版因果链

1. 利率降至地板，实际利率极低
2. 债务和信用风险上升，主权信用受损
3. 黄金作为实际利率的对标物，反映主权信用风险
4. 当利率无效时，黄金转向反映政府信用和债务风险
5. 黄金价格创历史新高，波动率上升
