# 指数上涨但经济表现不佳

> 属于因果簇：[[黄金作为未来几年最佳资产的因果逻辑]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 股市结构变化（权重股集中） |
| **DV（因变量）** | 指数上涨但经济表现不佳 |
| **Chain（传导链）** | 少数巨头公司市值占比大 → 这些公司受疫情冲击小，业绩稳定 → 资金抱团核心资产，推动指数上涨 → 多数公司表现不佳，经济整体疲弱 → 指数与实体经济背离 |
| **Lag（时滞）** | 短期至中期（数月） |
| **Threshold（临界值）** | 权重股占比达到临界值，如互联网巨头占市值比重显著 |
| **前提与约束（Premises）** | 市场结构以权重股为主导；投资者偏好确定性资产 |
| **Falsification（证伪条件）** | 如果权重股业绩下滑，指数下跌，则背离消失 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像班级平均分被少数尖子生拉高，但大多数学生成绩差。

### 🔗 文字版因果链

1. 少数巨头公司市值占比大
2. 这些公司受疫情冲击小，业绩稳定
3. 资金抱团核心资产，推动指数上涨
4. 多数公司表现不佳，经济整体疲弱
5. 指数与实体经济背离
