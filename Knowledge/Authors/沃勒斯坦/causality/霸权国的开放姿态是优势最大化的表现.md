## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 霸权国的'开放'姿态（非正规帝国） |
| **DV（因变量）** | 霸权国优势最大化（通过经济控制延续霸权，即'非殖民化帝国主义'） |
| **Chain（传导链）** | 霸权国获得霸权地位，不惧怕核心竞争 → 霸权国推行最大程度的开放世界经济政策 → 贸易自由化对霸权国产生净收益（廉价原料+出口市场） → 霸权国放弃政治控制但保留经济控制，形成'非殖民化帝国主义' |
| **Lag（时滞）** | 中期至长期（从霸权确立到开放政策见效，通常为几年到几十年，如英国19世纪转向自由贸易） |
| **Threshold（临界值）** | 霸权国须具备结构性优势，经济/军事/科技实力远超潜在竞争者，能够承受全面开放的冲击且净收益为正 |
| **前提与约束（Premises）** | 该断言仅适用于一国已获得霸权地位、不惧怕核心竞争时；霸权国能够主导国际经济规则，且其产业结构具有竞争优势；霸权国的开放政策是主动选择，而非外部胁迫 |
| **Falsification（证伪条件）** | 如果霸权国在开放政策下产业利益受损、经济主导地位被追赶者取代，或者霸权国没有保留经济控制（如放弃关键贸易优势），则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 赌场庄家制定看似公平的规则：庄家说‘欢迎来赌，规则开放’，但规则设计使庄家的预期收益最大。玩家若相信这是善意而盲目参与，最终会发现自己处于劣势。
