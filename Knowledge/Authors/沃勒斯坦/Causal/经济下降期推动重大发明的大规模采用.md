# 经济下降期推动重大发明的大规模采用

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济周期相位处于下降期 |
| **DV（因变量）** | 重大发明被大规模采用的速度与范围 |
| **Chain（传导链）** | 旧技术资本存量高、惯性大，平时企业缺乏替换动力 → 经济下降期利润压缩，企业生存压力增大 → 企业被迫寻求节约成本的生产方式 → 节约成本型重大发明因能降低单位成本而被大规模采用 → 发明从提出到扩散的时机由经济周期相位决定 |
| **Lag（时滞）** | 约数年至数十年不等，如贝塞麦炼钢法1856年提出，到1870~1880年下降期才被广泛采用 |
| **Threshold（临界值）** | 经济增速持续低于潜在水平或利润率明显下行；且新技术的单位成本/总成本显著低于旧技术 |
| **前提与约束（Premises）** | 该断言适用于‘老技术替代型’重大发明；旧技术资本存量高、惯性大，如英国旧炼钢法；下降期迫使企业采用节约成本的新技术；存在可替代的旧技术且其沉没成本高 |
| **Falsification（证伪条件）** | 若在景气上升期也出现同类型替代技术的广泛采用，或下降期企业宁愿减产/破产也不采用更便宜的新技术，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同搬家前总不扔旧家具，只有房租上涨或被迫搬迁时，才会下定决心更换更省空间、更省成本的新家具——危机是变革的催化剂。

### 🔗 文字版因果链

1. 旧技术资本存量高、惯性大，平时企业缺乏替换动力
2. 经济下降期利润压缩，企业生存压力增大
3. 企业被迫寻求节约成本的生产方式
4. 节约成本型重大发明因能降低单位成本而被大规模采用
5. 发明从提出到扩散的时机由经济周期相位决定
