## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 财政动员能力的差异（英国依赖贸易收入、印度掠夺与农业税；法国依赖借债与包税制） |
| **DV（因变量）** | 大国相对成败，即霸权归属（英国赢得霸权） |
| **Chain（传导链）** | 英国以贸易收入、印度掠夺和农业税为基础，形成可持续的财政动员能力；法国依赖借债与包税制，财政基础脆弱 → 英国能够偿还债务、维持信用；法国国债利息吞噬财政预算，占比高达50% → 法国财政瘫痪，进而触发国内政治危机 → 英国在霸权争夺中胜出，霸权归属英国 |
| **Lag（时滞）** | 长期时滞，通常跨越数十年的霸权争夺期，在康德拉基耶夫扩张期后半段逐渐显现 |
| **Threshold（临界值）** | 当国债利息支出占财政预算的比例达到50%时，财政能力差异转化为财政瘫痪的临界点 |
| **前提与约束（Premises）** | 体系处于康德拉基耶夫扩张期；霸权争夺进入军事化阶段 |
| **Falsification（证伪条件）** | 如果找到反例，即在满足上述前提的条件下，财政动员能力较弱的一方最终赢得霸权争夺，则该断言被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 这就像两个家庭竞争社区地位：一个靠稳定工资和祖传资产积累实力，另一个靠借贷维持体面，最终因利息滚雪球而破产。现代对应物是：国家资产负债表健康度是长周期竞争的核心观察指标。

### 🔗 文字版因果链

1. 英国以贸易收入、印度掠夺和农业税为基础，形成可持续的财政动员能力；法国依赖借债与包税制，财政基础脆弱
2. 英国能够偿还债务、维持信用；法国国债利息吞噬财政预算，占比高达50%
3. 法国财政瘫痪，进而触发国内政治危机
4. 英国在霸权争夺中胜出，霸权归属英国
