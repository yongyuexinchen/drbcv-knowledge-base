## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 通胀加速 |
| **DV（因变量）** | 财富从名义收入刚性群体和政治弱势地区流向弹性群体和政治强势地区 |
| **Chain（传导链）** | 通胀加速导致货币实际购买力下降 → 工资因货币假象、法律固定和支付迟缓而滞后调整，实际工资下降 → 雇主利润相对上升，利润集中于雇主等弹性收入群体 → 政治弱势地区因缺乏议价能力，被迫以名义债务或固定价格提供资金 → 实际财富从固定收入群体和弱势地区向定价权方和强势地区转移 |
| **Lag（时滞）** | 数月到数年，取决于工资调整周期、法律固定期限和支付节奏 |
| **Threshold（临界值）** | 通胀率高于工资调整速度；工资无指数化；债务以名义值计价 |
| **前提与约束（Premises）** | 通胀处于加速阶段；工资没有指数化调整机制；债务以名义货币计价；存在政治权力不对等，弱势地区无法逃避资金征用 |
| **Falsification（证伪条件）** | 若通胀期间实际工资未下降或雇主利润未相对增加，或政治弱势地区未发生资金净流出，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 好比签了固定租金合同，在通货膨胀中房东的租金实际缩水，而租户若拥有定价权产品则获益；弱势地区就像没有合同保护的一方，只能眼睁睁看着财富被通胀和强势方抽走。

### 🔗 文字版因果链

1. 通胀加速导致货币实际购买力下降
2. 工资因货币假象、法律固定和支付迟缓而滞后调整，实际工资下降
3. 雇主利润相对上升，利润集中于雇主等弹性收入群体
4. 政治弱势地区因缺乏议价能力，被迫以名义债务或固定价格提供资金
5. 实际财富从固定收入群体和弱势地区向定价权方和强势地区转移
