## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 初始微弱优势（如地理、制度或技术上的微小领先） |
| **DV（因变量）** | 世界体系中等级位置的结构性固化（中心-边缘差距扩大且后发者难以跃迁） |
| **Chain（传导链）** | 初始微弱优势使地区在跨区域分工中倾向于专业化生产特定商品 → 专业化强化为互补锁死（如东欧谷物出口与西欧工业品交换） → 互补锁死抑制落后地区转向高附加值生产，维持既有分工 → 领先地区通过集聚和优势积累循环（如阿姆斯特丹的贸易-金融优势）进一步扩大差距 → 等级位置因路径依赖和自我强化被固化，后发者难以通过市场自发力量跃迁 |
| **Lag（时滞）** | 长期累积过程，通常跨越数十年至数个世纪 |
| **Threshold（临界值）** | 当初始微弱优势转化为区域间互补性专业化分工并形成路径依赖时，即达到临界点；具体量化阈值因历史情境而异 |
| **前提与约束（Premises）** | 存在跨地区劳动分工；无中央再分配机制；技术扩散速度低于差距固化速度 |
| **Falsification（证伪条件）** | 若观察到后发地区仅依靠市场自发力量实现中心区跃迁，或中心-边缘差距在无干预条件下随时间缩小，则此断言可被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同滚雪球：一旦雪球有了初始体积，滚动时吸附的雪越来越多，优势持续放大；后来的小雪球很难追上前面的巨雪球。

### 🔗 文字版因果链

1. 初始微弱优势使地区在跨区域分工中倾向于专业化生产特定商品
2. 专业化强化为互补锁死（如东欧谷物出口与西欧工业品交换）
3. 互补锁死抑制落后地区转向高附加值生产，维持既有分工
4. 领先地区通过集聚和优势积累循环（如阿姆斯特丹的贸易-金融优势）进一步扩大差距
5. 等级位置因路径依赖和自我强化被固化，后发者难以通过市场自发力量跃迁
