## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 旧霸权资本以债权形式流向新崛起者（荷兰→英国国债；英国→美国1873–1945），且旧霸权国内缺乏高回报工业投资机会、利差存在、新崛起者提供制度可信度 |
| **DV（因变量）** | 旧霸权进入食利状态、进一步放弃生产，最终在货币上为债务人国的扩张买单 |
| **Chain（传导链）** | 旧霸权国内缺乏高回报工业投资机会，资本寻求更高收益 → 新崛起者提供制度可信度（议会担保、央行）且存在正利差（如2.5% vs 6%） → 旧霸权资本以债权形式大规模流入新崛起者，为其提供战争/基建融资 → 旧霸权逐渐依赖利息收入，进一步放弃生产活动与产业升级 → 长期看，债主国在货币和战略上为债务国扩张买单，霸权地位相对衰落 |
| **Lag（时滞）** | 数十年至上百年（如荷兰→英国约17-18世纪，英国→美国1873-1945） |
| **Threshold（临界值）** | 利差存在（如2.5% vs 6%）且旧霸权对外净债权持续上升+制造业份额下降的组合出现 |
| **前提与约束（Premises）** | 新崛起者提供制度可信度（议会担保、央行）；旧霸权国内缺乏高回报工业投资机会；存在正的利差以吸引资本跨境流动 |
| **Falsification（证伪条件）** | 如果旧霸权对外净债权持续上升但制造业份额并未下降，或债主国最终没有为债务国扩张买单（如债务违约导致债权国拒绝继续买单），则该因果断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一位老企业家把积蓄借给年轻创业者吃利息，自己不再经营工厂；年轻人拿钱扩张市场，最终老企业家的财富虽在账面上增加，产业实力和战略主动权却已转移到年轻人手中。

### 🔗 文字版因果链

1. 旧霸权国内缺乏高回报工业投资机会，资本寻求更高收益
2. 新崛起者提供制度可信度（议会担保、央行）且存在正利差（如2.5% vs 6%）
3. 旧霸权资本以债权形式大规模流入新崛起者，为其提供战争/基建融资
4. 旧霸权逐渐依赖利息收入，进一步放弃生产活动与产业升级
5. 长期看，债主国在货币和战略上为债务国扩张买单，霸权地位相对衰落
