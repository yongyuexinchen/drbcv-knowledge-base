# 生态约束与产业链迁移：资源耗竭驱动产业地理迁移

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土壤/资源耗竭（无技术进步抵消） |
| **DV（因变量）** | 整条产业链地理西移/外迁 |
| **Chain（传导链）** | 旧产区资源被持续高强度利用，导致土壤肥力下降、矿藏枯竭或燃料短缺（如木材耗尽） → 在没有技术进步抵消的情况下，旧产区单位产出下降、生产成本上升，利润空间被压缩 → 欧洲新饮品文化等推动需求持续增长，旧产区供给能力无法满足需求且成本劣势凸显 → 生产者寻找可开发的处女地（如巴西→巴巴多斯→牙买加→法属岛屿），同时利用充足劳动力供给（奴隶制） → 整条产业链（种植、加工、运输）逐步迁往新产区，旧产区产业衰败，新产区形成新的生产中心 → 新产区因资源未耗竭、成本较低而获得超额利润（如法国圣多明各1750年糖业反超牙买加） |
| **Lag（时滞）** | 数十年至上百年（蔗糖从巴西到法属岛屿历经约一个多世纪；烟草受25年轮作约束，迁移周期以代际计） |
| **Threshold（临界值）** | 旧产区资源耗竭使单位生产成本上升至高于新产区（含迁移成本）的临界点，或土壤肥力下降到无法维持盈利（如烟草25年轮作上限、蔗糖单产明显下降） |
| **前提与约束（Premises）** | 需求持续增长（欧洲新饮品文化创造稳定且扩大的糖需求）；存在可开发的处女地，且地理上可进入（如新大陆各殖民岛屿）；足够劳动力供给（奴隶制具有供给弹性，可支撑新产区快速扩张）；无技术进步抵消资源耗竭（没有化肥、育种改良或替代燃料）；政治条件允许迁移（殖民垄断或战争未阻断迁入迁出路径） |
| **Falsification（证伪条件）** | 若观察到旧产区在资源严重耗竭后依靠技术进步（如轮作改良、化肥、新作物品种）维持产量且未发生产业迁移，或需求停滞导致新产区开发无利可图，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同手机电池老化后，你不愿更换电池而直接换部新手机；也像一个矿脉采空后，矿工们会转战新矿坑——只要还有新矿山可挖，旧矿废弃只是时间问题

### 🔗 文字版因果链

1. 旧产区资源被持续高强度利用，导致土壤肥力下降、矿藏枯竭或燃料短缺（如木材耗尽）
2. 在没有技术进步抵消的情况下，旧产区单位产出下降、生产成本上升，利润空间被压缩
3. 欧洲新饮品文化等推动需求持续增长，旧产区供给能力无法满足需求且成本劣势凸显
4. 生产者寻找可开发的处女地（如巴西→巴巴多斯→牙买加→法属岛屿），同时利用充足劳动力供给（奴隶制）
5. 整条产业链（种植、加工、运输）逐步迁往新产区，旧产区产业衰败，新产区形成新的生产中心
6. 新产区因资源未耗竭、成本较低而获得超额利润（如法国圣多明各1750年糖业反超牙买加）
