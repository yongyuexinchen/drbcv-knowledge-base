# 货币秩序作为霸权国管理世界经济的手段

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 霸权国建立以自身货币为核心的金本位制度并承担央行最后借款人职能 |
| **DV（因变量）** | 霸权国获得管理世界经济的能力，金融技术背后的权力结构得以维持 |
| **Chain（传导链）** | 霸权国货币成为国际储备与结算货币，各国贸易和金融交易依赖该货币 → 霸权国央行承担最后借款人职能，为全球市场提供流动性支持并稳定金融体系 → 霸权国通过调整货币-财政政策影响全球利率、流动性和价格水平 → 全球流动性周期随霸权国政策波动，小国资产价格被动跟随 → 由此霸权国能够塑造世界经济周期，巩固其经济霸权地位 |
| **Lag（时滞）** | 中期至长期，通常为数年（如全球流动性周期传导和政策效果显现需要时间） |
| **Threshold（临界值）** | 霸权国货币须占据国际储备和结算的主导地位；其央行须具备全球最后借款人的实际能力 |
| **前提与约束（Premises）** | 霸权国货币是国际储备/结算货币；霸权国央行承担最后借款人角色；存在跨国资本流动和全球价格联动机制；小国经济对外开放并融入国际金融市场 |
| **Falsification（证伪条件）** | 若一国建立金本位并承担最后借款人职能，但其货币政策无法影响世界经济，或小国资产价格完全不受其货币政策影响，则该断言被削弱或推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同国际象棋中，谁制定棋子的走法规则并掌控棋盘边界，谁就实际上主导棋局；金融规则看似价值中立，实则是强权意志的体现

### 🔗 文字版因果链

1. 霸权国货币成为国际储备与结算货币，各国贸易和金融交易依赖该货币
2. 霸权国央行承担最后借款人职能，为全球市场提供流动性支持并稳定金融体系
3. 霸权国通过调整货币-财政政策影响全球利率、流动性和价格水平
4. 全球流动性周期随霸权国政策波动，小国资产价格被动跟随
5. 由此霸权国能够塑造世界经济周期，巩固其经济霸权地位
