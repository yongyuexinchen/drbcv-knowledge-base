# 资源型/原料出口型繁荣（合并式增长）不可持续，且伴生强制与债务结构

> **领域**：宏观政治经济学　|　**来源**：_wall_卷3_07.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资源型/原料出口型繁荣（由原料价格上升带动的初级产品出口增长，如俄国小麦、奥斯曼棉花） |
| **DV（因变量）** | 伴生劳动强制与债务依赖结构的财政/债务危机（如土耳其1878年破产） |
| **Chain（传导链）** | 原料价格上升（A阶段），初级产品出口繁荣，出口收入激增 → 出口收入激增促使决策单位（国家/大庄园）集中化，并采用劳动强制与外部债务扩张 → 原料价格反转（B阶段），出口收入骤降，经济缺乏缓冲机制 → 债务到期无法偿还，财政与债务危机爆发 |
| **Lag（时滞）** | 从A阶段价格上升到B阶段价格反转通常为一个商品需求周期（数年至数十年），危机在价格反转后债务到期时显现 |
| **Threshold（临界值）** | 初级产品价格从高位下跌，使出口收入不足以覆盖外债还本付息或维持财政刚性支出时，危机被触发 |
| **前提与约束（Premises）** | 该经济体依赖出口初级产品融入世界市场；价格波动由体系需求周期决定，而非本国基本面；国内缺乏产业多元化和缓冲机制（如庞大储备或主权基金） |
| **Falsification（证伪条件）** | 若发现某个依赖初级产品出口的经济体在原料价格大幅反转后，未出现显著的劳动强制和债务依赖，也未爆发财政/债务危机，而是平滑调整，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像果农遇到水果涨价时借钱扩种、雇工；一旦市场行情反转，水果卖不出去而债务累累，最后破产。繁荣越依赖外部顺风，反转时越无缓冲。

### 🔗 文字版因果链

1. 原料价格上升（A阶段），初级产品出口繁荣，出口收入激增
2. 出口收入激增促使决策单位（国家/大庄园）集中化，并采用劳动强制与外部债务扩张
3. 原料价格反转（B阶段），出口收入骤降，经济缺乏缓冲机制
4. 债务到期无法偿还，财政与债务危机爆发
