## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济霸权国的工业绝对竞争优势（世界垄断地位） |
| **DV（因变量）** | 该国主张自由贸易并将其表述为普适真理 |
| **Chain（传导链）** | 霸权国工业产品具有世界绝对竞争优势，不需要关税保护即可在他国市场获胜 → 自由贸易使霸权国商品更容易进入他国市场，扩大出口和利润，同时获取廉价原料 → 霸权国从自身利益出发，将自由贸易论证为普遍适用的科学经济政策 → 后发工业国若接受自由贸易，国内幼稚产业将无法成长，从而维持霸权国的垄断地位 |
| **Lag（时滞）** | 约30-50年（如英国1815年仍实行保护主义，至1850年代才系统转向自由贸易） |
| **Threshold（临界值）** | 该国工业竞争力达到世界绝对领先，且其对手处于后发追赶阶段（需要保护幼稚工业） |
| **前提与约束（Premises）** | 该国工业处于世界绝对竞争优势；其主要对手为后发工业国；存在开放的世界市场环境 |
| **Falsification（证伪条件）** | 如果发现一个具有工业绝对优势的霸权国长期不主张自由贸易，或其主张自由贸易后发国反而通过开放实现快速赶超，则该断言将被削弱或推翻。 |
| **Confidence（确信度）** | well-established |
