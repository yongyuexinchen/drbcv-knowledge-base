## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地（资本）供给量增加，超过临界点 |
| **DV（因变量）** | 地租（土地收益）下降至接近零 |
| **Chain（传导链）** | 某个地区土地（资本）供给极为丰饶 → 土地数量超过临界点，价格效应超过数量效应 → 土地价格和地租下降至接近零的水平 → 资本（土地）泛滥导致资本收益被扼杀 |
| **Lag（时滞）** | 长期（历史上跨数个世纪，如18-19世纪新大陆与旧世界对比） |
| **Threshold（临界值）** | 资本数量超过临界点，即供给丰饶到价格效应压倒数量效应 |
| **前提与约束（Premises）** | 资本是劳动的替代方式，土地是传统农业社会的主要资本形式；该地区土地供给相对人口而言极为充裕（如新大陆）；不存在其他推高地租的管制或需求冲击 |
| **Falsification（证伪条件）** | 若在某土地供给极丰饶的地区地租依然居高不下，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像一杯水里加太多糖，糖无法再溶解，反而沉在杯底——资本太多，收益反而被稀释。

### 🔗 文字版因果链

1. 某个地区土地（资本）供给极为丰饶
2. 土地数量超过临界点，价格效应超过数量效应
3. 土地价格和地租下降至接近零的水平
4. 资本（土地）泛滥导致资本收益被扼杀

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人力资本的增长（劳动技能与知识在生产中的重要性提升） |
| **DV（因变量）** | 资本收入比重的下降（劳动收入比重上升） |
| **Chain（传导链）** | 技术进步提高了对劳动者技能和知识的要求 → 劳动要素在生产过程中变得更为重要 → 劳动收入比重从60%-65%上升至70%-75% → 流向土地、建筑和金融资本的收入比重相应下降 |
| **Lag（时滞）** | 长期（1800-2010约两个世纪） |
| **Threshold（临界值）** | 无明确量化阈值，表现为劳动收入比重上升约10个百分点 |
| **前提与约束（Premises）** | 该解释基于现有历史数据，且资本收入比重长期下降被确认；技术结构变化有利于劳动，且资本与劳动替代弹性未逆转这一趋势；不排除未来资本收入比重回升至19世纪初期水平 |
| **Falsification（证伪条件）** | 若未来资本收入比重持续上升并超越历史峰值，则人力资本胜利假说被削弱 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同电脑升级后，操作员的技能比重提升，而旧式硬件所占的份额相对缩小。

### 🔗 文字版因果链

1. 技术进步提高了对劳动者技能和知识的要求
2. 劳动要素在生产过程中变得更为重要
3. 劳动收入比重从60%-65%上升至70%-75%
4. 流向土地、建筑和金融资本的收入比重相应下降

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本/收入比（β）增加 |
| **DV（因变量）** | 资本收入比重（α）上升，接近或超越历史峰值 |
| **Chain（传导链）** | 现代技术仍大量使用资本，且资本有多种用途 → 长期资本与劳动替代弹性大于1 → 资本收益率r的下降幅度小于资本/收入比β的上升幅度 → 资本收入比重α=r×β随β增加而上升 |
| **Lag（时滞）** | 长期（数十年至数百年） |
| **Threshold（临界值）** | 若β达到7-8年国民收入，r为4%-5%，则α为30%-40% |
| **前提与约束（Premises）** | 资本与劳动长期替代弹性大于1；技术变革即使有利于劳动，其效应也有限且可能被金融复杂化等反向力量抵消；储蓄率与增长率的组合使得β持续上升 |
| **Falsification（证伪条件）** | 若β上升而α下降（即r下降幅度大于β上升幅度），则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像搅拌蜂蜜和水，蜂蜜比例增大时，即使甜度稍微被稀释，整体甜味仍然更浓。

### 🔗 文字版因果链

1. 现代技术仍大量使用资本，且资本有多种用途
2. 长期资本与劳动替代弹性大于1
3. 资本收益率r的下降幅度小于资本/收入比β的上升幅度
4. 资本收入比重α=r×β随β增加而上升

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济增长率（g）下降至低水平（如1.5%或以下） |
| **DV（因变量）** | 资本/收入比（β）上升，资本存量重要性增大 |
| **Chain（传导链）** | 经济增长率下降，尤其人口零增长或负增长 → 根据第二定律β=s/g，给定储蓄率s，β随g下降而上升 → 此前积累的财富在停滞社会中变得特别重要 → 资本/收入比升至5-6甚至更高，资本在宏观经济中卷土重来 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 当g降至约1.5%时β可达6-7；若g降至1%，β可达10 |
| **前提与约束（Premises）** | 储蓄率s保持为正且大致稳定（约10%）；资本/收入比在长期有较大灵活性；资本与劳动替代弹性长期大于1，收益率不会大幅下降 |
| **Falsification（证伪条件）** | 若在低增长国家中资本/收入比并未上升反而下降，则断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像池塘水流速变慢时，泥沙更容易沉淀下来——经济增长慢了，过往财富存量更显厚重。

### 🔗 文字版因果链

1. 经济增长率下降，尤其人口零增长或负增长
2. 根据第二定律β=s/g，给定储蓄率s，β随g下降而上升
3. 此前积累的财富在停滞社会中变得特别重要
4. 资本/收入比升至5-6甚至更高，资本在宏观经济中卷土重来

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本无限积累（储蓄率s>0且持续） |
| **DV（因变量）** | 资本收益率r下降，最终资本主义自我毁灭 |
| **Chain（传导链）** | 资本家持续积累资本（储蓄率s为正） → 若结构性增长率g为零或接近零，资本/收入比β=s/g趋向无限大 → 为避免资本收入比重α=r×β吞噬全部国民收入，r必须下降至接近零 → 利润率下降引发资本家竞争冲突或无产阶级革命，资本主义被破坏 |
| **Lag（时滞）** | 长期（取决于积累速度和增长停滞） |
| **Threshold（临界值）** | g接近零，s>0，β趋向无限大 |
| **前提与约束（Premises）** | 生产率与人口增长的总和g为零或极低；没有结构性增长来平衡资本积累；储蓄率s为正 |
| **Falsification（证伪条件）** | 若低增长下资本收益率不下降，或资本积累未导致矛盾，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人不停地囤积食物，却没有消耗，最后食物腐烂，反而毁掉储藏室。

### 🔗 文字版因果链

1. 资本家持续积累资本（储蓄率s为正）
2. 若结构性增长率g为零或接近零，资本/收入比β=s/g趋向无限大
3. 为避免资本收入比重α=r×β吞噬全部国民收入，r必须下降至接近零
4. 利润率下降引发资本家竞争冲突或无产阶级革命，资本主义被破坏
