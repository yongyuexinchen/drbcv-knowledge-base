# 财富集中度降低（前1%人群财富占比显著下降）

> 属于因果簇：[[21世纪资本论中的财富不平等因果机制]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对资本及其收入征收较高累进税（如30%有效税率） |
| **DV（因变量）** | 财富集中度降低（前1%人群财富占比显著下降） |
| **Chain（传导链）** | 资本收入被课税，税后净收益率从5%降至约3.5% → 富人财富累积速度减慢，r-g缺口缩小 → 遗产税进一步削减代际传递的财富 → 中产阶层通过劳动收入和储蓄积累相对份额上升 → 长期财富分配更趋分散 |
| **Lag（时滞）** | 长期（数十年至一代人以上） |
| **Threshold（临界值）** | 有效资本税率达到30%左右（纯收益率从5%降至3.5%即足以产生重大长期影响） |
| **前提与约束（Premises）** | 税收制度为累进且覆盖广泛（所得税、遗产税、不动产税）；纳税人难以完全通过避税或资本外流规避；经济长期保持稳定（无战争等极端冲击干扰） |
| **Falsification（证伪条件）** | 若在高累进资本税下财富集中度并未降低甚至继续上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水龙头被关小，水池虽然还在蓄水，但大桶（富人）很难再把水位差距拉得更大

### 🔗 文字版因果链

1. 资本收入被课税，税后净收益率从5%降至约3.5%
2. 富人财富累积速度减慢，r-g缺口缩小
3. 遗产税进一步削减代际传递的财富
4. 中产阶层通过劳动收入和储蓄积累相对份额上升
5. 长期财富分配更趋分散
