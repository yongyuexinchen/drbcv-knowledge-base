## 总体因果图

- 增长率g → 长期资本 收入比β
- 资本存量（资本/收入比β）增加 → 资本收益率r
- 资本/收入比β增加（且替代弹性大于1） → 资本收入比重α
- 通货膨胀 → 财富在不同资产类别间的再分配
