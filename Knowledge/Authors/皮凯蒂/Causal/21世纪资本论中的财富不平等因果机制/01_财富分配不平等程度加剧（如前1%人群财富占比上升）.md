# 财富分配不平等程度加剧（如前1%人群财富占比上升）

> 属于因果簇：[[21世纪资本论中的财富不平等因果机制]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本收益率r持续高于经济增长率g（即r>g） |
| **DV（因变量）** | 财富分配不平等程度加剧（如前1%人群财富占比上升） |
| **Chain（传导链）** | 资本收益率r明显高于经济增长率g，资本积累速度快于整体收入增长 → 富人将资本收入的很大一部分用于再投资（而非消费），使其资本增长快于平均收入 → 资本/收入比不断上升，财富向顶层人群集中 → 长期演化为高度不平等的财富分布（近似帕累托分布），且r-g缺口越大，不平等越严重 |
| **Lag（时滞）** | 数十年甚至上百年（资本积累和集中需要多代人才能显现） |
| **Threshold（临界值）** | 当g≈1%，r≈4%～5%时，r-g缺口足够大；若r-g超过某个临界值，不平等将无限制扩大 |
| **前提与约束（Premises）** | 经济增长率g结构性偏低（人口结构转换完成、处于技术前沿、创新缓慢）；富裕群体具有较高的储蓄率（资本收入大部分用于再投资）；存在代际传承和财产继承制度；没有战争、革命、极端税收等大规模冲击打断积累过程 |
| **Falsification（证伪条件）** | 若在r>g持续存在的条件下，财富不平等没有显著加剧，或长期保持稳定/下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 滚雪球——雪球半径的增长速度（资本收益）大于整个雪球滚动距离的增长（经济增速），雪球会越滚越大，占总雪量的比例也越来越高

### 🔗 文字版因果链

1. 资本收益率r明显高于经济增长率g，资本积累速度快于整体收入增长
2. 富人将资本收入的很大一部分用于再投资（而非消费），使其资本增长快于平均收入
3. 资本/收入比不断上升，财富向顶层人群集中
4. 长期演化为高度不平等的财富分布（近似帕累托分布），且r-g缺口越大，不平等越严重
