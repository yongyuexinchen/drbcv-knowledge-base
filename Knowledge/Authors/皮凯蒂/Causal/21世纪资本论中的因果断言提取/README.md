# 21世纪资本论中的因果断言提取（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：21世纪资本论中的因果断言提取.md

## 总体因果图

- 土地（资本）供给量增加，超过临界点 → 地租（土地收益）下降至接近零
- 人力资本的增长（劳动技能与知识在生产中的重要性提升） → 资本收入比重的下降（劳动收入比重上升）
- 资本/收入比（β）增加 → 资本收入比重（α）上升，接近或超越历史峰值
- 经济增长率（g）下降至低水平（如1.5%或以下） → 资本 收入比（β）上升，资本存量重要性增大
- 资本无限积累（储蓄率s>0且持续） → 资本收益率r下降，最终资本主义自我毁灭
