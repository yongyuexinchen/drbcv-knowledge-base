# 资本收益率r下降，最终资本主义自我毁灭

> 属于因果簇：[[21世纪资本论中的因果断言提取]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本无限积累（储蓄率s>0且持续） |
| **DV（因变量）** | 资本收益率r下降，最终资本主义自我毁灭 |
| **Chain（传导链）** | 资本家持续积累资本（储蓄率s为正） → 若结构性增长率g为零或接近零，资本/收入比β=s/g趋向无限大 → 为避免资本收入比重α=r×β吞噬全部国民收入，r必须下降至接近零 → 利润率下降引发资本家竞争冲突或无产阶级革命，资本主义被破坏 |
| **Lag（时滞）** | 长期（取决于积累速度和增长停滞） |
| **Threshold（临界值）** | g接近零，s>0，β趋向无限大 |
| **前提与约束（Premises）** | 生产率与人口增长的总和g为零或极低；没有结构性增长来平衡资本积累；储蓄率s为正 |
| **Falsification（证伪条件）** | 若低增长下资本收益率不下降，或资本积累未导致矛盾，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人不停地囤积食物，却没有消耗，最后食物腐烂，反而毁掉储藏室。

### 🔗 文字版因果链

1. 资本家持续积累资本（储蓄率s为正）
2. 若结构性增长率g为零或接近零，资本/收入比β=s/g趋向无限大
3. 为避免资本收入比重α=r×β吞噬全部国民收入，r必须下降至接近零
4. 利润率下降引发资本家竞争冲突或无产阶级革命，资本主义被破坏
