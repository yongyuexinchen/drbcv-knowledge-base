# 资本收入比重（α）上升，接近或超越历史峰值

> 属于因果簇：[[21世纪资本论中的因果断言提取]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本/收入比（β）增加 |
| **DV（因变量）** | 资本收入比重（α）上升，接近或超越历史峰值 |
| **Chain（传导链）** | 现代技术仍大量使用资本，且资本有多种用途 → 长期资本与劳动替代弹性大于1 → 资本收益率r的下降幅度小于资本/收入比β的上升幅度 → 资本收入比重α=r×β随β增加而上升 |
| **Lag（时滞）** | 长期（数十年至数百年） |
| **Threshold（临界值）** | 若β达到7-8年国民收入，r为4%-5%，则α为30%-40% |
| **前提与约束（Premises）** | 资本与劳动长期替代弹性大于1；技术变革即使有利于劳动，其效应也有限且可能被金融复杂化等反向力量抵消；储蓄率与增长率的组合使得β持续上升 |
| **Falsification（证伪条件）** | 若β上升而α下降（即r下降幅度大于β上升幅度），则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像搅拌蜂蜜和水，蜂蜜比例增大时，即使甜度稍微被稀释，整体甜味仍然更浓。

### 🔗 文字版因果链

1. 现代技术仍大量使用资本，且资本有多种用途
2. 长期资本与劳动替代弹性大于1
3. 资本收益率r的下降幅度小于资本/收入比β的上升幅度
4. 资本收入比重α=r×β随β增加而上升
