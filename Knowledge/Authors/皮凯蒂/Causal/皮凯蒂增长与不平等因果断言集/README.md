# 皮凯蒂增长与不平等因果断言集（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：皮凯蒂增长与不平等因果断言集.md

## 总体因果图

- 较低的年增长率持续相当长的时期 → 总量（人口或产出）出现巨大的倍数增长
- 强劲的人口增长（高生育率或大量移民） → 财富不平等程度降低（继承财富的地位被削弱）
- 持续的经济增长（人均产出增长） → 社会流动性提高，财富不平等的代际复制被限制
- 资本收益率（r）持续高于经济增长率（g） → 财富不平等与社会不平等长期加剧
