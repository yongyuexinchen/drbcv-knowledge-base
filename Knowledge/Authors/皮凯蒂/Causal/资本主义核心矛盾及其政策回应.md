# 资本主义核心矛盾及其政策回应

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 私人资本收益率r长期高于经济增长率g（r>g） |
| **DV（因变量）** | 财富不平等加剧，社会分化严重 |
| **Chain（传导链）** | 资本收益率r持续高于经济增长率g → 过去的财富积累比产出和工资增长更快 → 资本所有者逐渐变为食利者，支配只有劳动能力的人 → 财富分配差距倍率扩大，财富不平等加剧 |
| **Lag（时滞）** | 长期（数十年以上，代际积累） |
| **Threshold（临界值）** | r > g，即私人资本收益率超过产出的长期增长率 |
| **前提与约束（Premises）** | 基于私人产权的市场经济放任自流；资本一旦形成，其收益率将高于产出增长率；初始资本规模不同导致资本收益率显著不同 |
| **Falsification（证伪条件）** | 若发现长期r>g持续存在但财富不平等未加剧，或r>g消失后不平等仍在加剧，则该断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 资本收益率r持续高于经济增长率g
2. 过去的财富积累比产出和工资增长更快
3. 资本所有者逐渐变为食利者，支配只有劳动能力的人
4. 财富分配差距倍率扩大，财富不平等加剧

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对资本收入征收过重的税（不分青红皂白地狠下重手） |
| **DV（因变量）** | 资本积累动力下降，经济增长率进一步降低 |
| **Chain（传导链）** | 对资本收入征收过重税负 → 私人资本收益率被压低到低于增长率 → 资本所有者失去积累和投资动力 → 资本积累不足，生产性投资减少 → 经济增长率进一步下降 |
| **Lag（时滞）** | 中期（政策实施后数年显现） |
| **Threshold（临界值）** | 税负高到显著削弱资本积累激励的程度，即所谓'狠下重手' |
| **前提与约束（Premises）** | 资本积累是经济增长的重要动力；税收政策不分青红皂白，没有区分存量与合理激励；不存在其他足以弥补增长动力的政策抵消作用 |
| **Falsification（证伪条件）** | 如果高税负下资本积累和增长率没有下降，或下降完全由其他因素导致，则该断言不成立 |
| **Confidence（确信度）** | plausible |

3. 资本所有者失去积累和投资动力
4. 资本积累不足，生产性投资减少
5. 经济增长率进一步下降

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施年度累进资本税（对高额财富征收更高比例税收） |
| **DV（因变量）** | 遏制财富不平等的无限扩大，同时保护竞争和激励 |
| **Chain（传导链）** | 对不同规模财富设置累进税率（如100万以下0.1%~0.5%，100~500万1%，500~1000万2%，数千万以上5%~10%） → 高额财富每年缴纳可观税收，财富累积速度放缓 → 初始资本优势被削减，财富传递的赢家通吃效应被抑制 → 不平等螺旋得到控制，同时中等以下财富税率温和，激励犹存 |
| **Lag（时滞）** | 中长期（数年至数十年，取决于税率设计和资产结构） |
| **Threshold（临界值）** | 累进税率足够高（尤其对超大财富达5%~10%），但又不至于扼杀资本积累 |
| **前提与约束（Premises）** | 需要高水平的国际协作和区域政治一体化，否则资本外逃；税制是累进的而非一刀切重税；需保护新型原始积累的竞争和激励 |
| **Falsification（证伪条件）** | 若累进资本税实施后财富不平等仍以不可持续速度扩大，或企业家精神与增长显著受损，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 给疯长的树枝修剪，既让阳光照到小树，又不把整棵树砍死。

### 🔗 文字版因果链

1. 对不同规模财富设置累进税率（如100万以下0.1%~0.5%，100~500万1%，500~1000万2%，数千万以上5%~10%）
2. 高额财富每年缴纳可观税收，财富累积速度放缓
3. 初始资本优势被削减，财富传递的赢家通吃效应被抑制
4. 不平等螺旋得到控制，同时中等以下财富税率温和，激励犹存

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济增长率g的提高（例如通过教育、技术、无污染技术投资） |
| **DV（因变量）** | 资本收益率r也相应提高，r–g缺口不必然缩小 |
| **Chain（传导链）** | 增长率g上升 → 投资机会和资本需求增加 → 资本边际产出和收益率r被推高 → r与g的差值可能维持甚至扩大 |
| **Lag（时滞）** | 中长期传导 |
| **Threshold（临界值）** | 无固定量化条件；当r随g同比例或更大幅度上升时，r–g缺口不缩小 |
| **前提与约束（Premises）** | g上升通过增加资本需求而推高r；r由资本生产率和稀缺性决定；这是理论逻辑，而非简单经验规律 |
| **Falsification（证伪条件）** | 若找到g上升而r下降且r–g缺口显著缩小的长期实证，则该断言被怀疑 |
| **Confidence（确信度）** | plausible |

| **IV（自变量）** | 收入和财富分配的变化（如价格、工资、财富的涨跌） |
| **DV（因变量）** | 政治观念、制度规则和政策形成，最终导致社会与经济变迁 |
| **Chain（传导链）** | 经济变量（价格、工资、收入、财富）发生变动 → 民众的政治观念和态度随之改变 → 观念演变催生政治制度、规则和政策 → 新政策反作用于社会和经济结构，形成新的变迁 |
| **Lag（时滞）** | 长期（历史演变过程，非即时反应） |
| **Threshold（临界值）** | 无明确阈值；经济变动需累积到足以塑造观念的程度 |
| **前提与约束（Premises）** | 经济不是唯一决定因素，政治和文化具有相对独立性；政治制度并非简单由资产阶级主导；需要把经济、政治、社会、文化结合起来研究 |

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 20世纪两次世界大战的冲击（大规模破坏资本存量） |
| **DV（因变量）** | 资本收益显著降低，制造了r>g已经被克服的假象 |
| **Chain（传导链）** | 两次世界大战将过去的财富配置推倒重来 → 大量实物资本和金融资本被摧毁 → 资本存量锐减，资本收益率显著降低 → r>g的长期规律被暂时掩盖 → 人们误以为资本主义基本矛盾已解决 |
| **Lag（时滞）** | 战争冲击发生后数年乃至持续到战后几十年 |
| **Threshold（临界值）** | 战争破坏达到“推倒重来”的程度，而非边际损失 |
| **前提与约束（Premises）** | 战争是外生冲击，不是市场内生逻辑；战后重建期资本稀缺压低收益率；观察区间限定于20世纪，而非整个历史长河 |
| **Falsification（证伪条件）** | 若没有战争冲击而r>g仍长期失效，或战争后r>g立即恢复常态，则该断言不成立 |
| **Confidence（确信度）** | well-established |
