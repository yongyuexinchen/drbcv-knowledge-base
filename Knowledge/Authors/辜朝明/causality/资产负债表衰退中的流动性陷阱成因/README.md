# 资产负债表衰退中的流动性陷阱成因（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：资产负债表衰退中的流动性陷阱成因.md

## 总体因果图

- 企业资产负债表受损（资产贬值、负债高企） → 企业行为目标从利润最大化转向负债最小化
- 企业追求负债最小化 → 流动性陷阱的形成（利率降至极低仍无法刺激借贷和投资）
- 企业行为从利润最大化转向负债最小化 → 利率政策失效（即使大幅降息也无法刺激经济）
