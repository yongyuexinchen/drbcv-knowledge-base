# 资产负债表衰退中货币政策失效的因果机制

> **领域**：宏观经济学　|　**来源**：chapter_30.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 银行借贷人破产导致银行资不抵债 |
| **DV（因变量）** | 银行危机持续且央行注资无效 |
| **Chain（传导链）** | 借贷人破产导致银行资产质量恶化 → 银行资本充足率下降，陷入资不抵债 → 银行面临挤兑或倒闭风险，但根本问题是偿付能力而非流动性 → 央行注入流动性无法修复银行资产负债表，危机持续 |
| **Lag（时滞）** | 短期至中期（银行破产和挤兑在数年内累积显现） |
| **Threshold（临界值）** | 银行资本充足率低于监管要求或资不抵债时，流动性注入失效 |
| **前提与约束（Premises）** | 银行危机源于借贷方破产而非流动性不足；银行系统存在大量资不抵债的机构；私营部门资金需求急剧下降 |
| **Falsification（证伪条件）** | 若在银行资不抵债情况下，央行注资能显著降低银行倒闭数量并恢复信贷，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个已经破产的公司不断提供短期贷款，无法解决其根本的债务问题，只会拖延时间。

### 🔗 文字版因果链

1. 借贷人破产导致银行资产质量恶化
2. 银行资本充足率下降，陷入资不抵债
3. 银行面临挤兑或倒闭风险，但根本问题是偿付能力而非流动性
4. 央行注入流动性无法修复银行资产负债表，危机持续

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 私营部门（86.4%企业）忙于削减债务（资产负债表衰退） |
| **DV（因变量）** | 整体经济陷入恶性通货紧缩且货币政策（推绳子）失效 |
| **Chain（传导链）** | 企业因资产价格暴跌而资不抵债，开始以收入偿还债务而非支出 → 企业部门整体减少借贷和投资，信贷需求大幅萎缩 → 货币供应量下降，物价下跌，实际债务负担加重 → 企业进一步削减债务，形成通货紧缩恶性循环 → 央行注入流动性无法刺激信贷需求，货币政策如同推绳子 |
| **Lag（时滞）** | 中期（债务削减过程持续数年，通货紧缩螺旋逐步加深） |
| **Threshold（临界值）** | 当削减债务的企业占比超过50%（如86.4%）时，货币政策失效 |
| **前提与约束（Premises）** | 私营部门以资产负债表修复为首要目标；信贷需求不足而非供给不足；存在大量资不抵债的企业 |
| **Falsification（证伪条件）** | 若在资产负债表衰退期间，央行大规模注资能促使企业增加借贷和支出，从而逆转通缩，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人欠债太多，即使银行愿意借钱给他，他也会选择先还债而不是消费，整个经济就像被一根绳子拉着走，推不动。

### 🔗 文字版因果链

1. 企业因资产价格暴跌而资不抵债，开始以收入偿还债务而非支出
2. 企业部门整体减少借贷和投资，信贷需求大幅萎缩
3. 货币供应量下降，物价下跌，实际债务负担加重
4. 企业进一步削减债务，形成通货紧缩恶性循环
5. 央行注入流动性无法刺激信贷需求，货币政策如同推绳子

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制度（或对金本位的担忧） |
| **DV（因变量）** | 美联储未增加准备金（货币政策紧缩） |
| **Chain（传导链）** | 若金本位是制约因素，则准备金需求上升时黄金储备不足会限制货币扩张 → 但实际中准备金需求下降（信贷需求萎缩），黄金流入流出影响甚微 → 美联储不增加准备金是因为缺乏需求，而非金本位制约 → 因此金本位并非大萧条深化的原因 |
| **Lag（时滞）** | 无（同期决策过程） |
| **Threshold（临界值）** | 当准备金需求下降速度快于供给时，金本位约束不生效 |
| **前提与约束（Premises）** | 决策者未提及金本位问题；短期利率下降表明准备金充足；银行从美联储借贷大幅减少 |
| **Falsification（证伪条件）** | 若发现决策者因金本位担忧而拒绝增加准备金，且准备金需求并未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像水管里水压不足，不是因为阀门被卡住，而是因为没人用水，即使打开阀门也流不出多少水。

### 🔗 文字版因果链

1. 若金本位是制约因素，则准备金需求上升时黄金储备不足会限制货币扩张
2. 但实际中准备金需求下降（信贷需求萎缩），黄金流入流出影响甚微
3. 美联储不增加准备金是因为缺乏需求，而非金本位制约
4. 因此金本位并非大萧条深化的原因
