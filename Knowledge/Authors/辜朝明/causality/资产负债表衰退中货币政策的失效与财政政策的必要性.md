# 资产负债表衰退中货币政策的失效与财政政策的必要性

> **领域**：宏观经济学　|　**来源**：chapter_23.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 私营部门（企业）在资产负债表衰退期追求负债最小化（集中偿债） |
| **DV（因变量）** | 货币政策失效，货币供应量收缩，经济活力下降 |
| **Chain（传导链）** | 资产泡沫破裂导致企业资产负债表恶化（资产-负债<0） → 企业从利润最大化转向负债最小化，集中偿还债务 → 企业从银行取款还债，储蓄下降，货币创造乘数变为负值 → 货币供应量因储蓄下降而减少 → 若政府不增加借贷和支出，货币供应量进一步收缩，经济活力下降 → 即使央行注入大量流动性，由于企业无借贷需求，货币供应量不增加，货币政策失效 |
| **Lag（时滞）** | 短期至中期（如日本1998-2006年期间持续约8年） |
| **Threshold（临界值）** | 当私营部门整体出现资产-负债<0，且企业普遍追求负债最小化时 |
| **前提与约束（Premises）** | 经济处于资产负债表衰退期（资产泡沫破裂后）；私营部门（企业）是主要借贷方，且其行为转向负债最小化；传统货币政策传导依赖货币流通总量与货币政策的稳定关系，但此关系已破裂；政府财政政策能够抵消私营部门偿债带来的货币供应量收缩 |
| **Falsification（证伪条件）** | 如果观察到在私营部门集中偿债期间，央行注入流动性后货币供应量显著增加，或经济活力恢复，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人欠债太多时，即使银行降低利率甚至免费给钱，他也不会借钱去消费，而是拼命还债；此时只有政府（如家人）帮忙还债或增加支出，才能防止整个家庭经济萎缩。

### 🔗 文字版因果链

1. 资产泡沫破裂导致企业资产负债表恶化（资产-负债<0）
2. 企业从利润最大化转向负债最小化，集中偿还债务
3. 企业从银行取款还债，储蓄下降，货币创造乘数变为负值
4. 货币供应量因储蓄下降而减少
5. 若政府不增加借贷和支出，货币供应量进一步收缩，经济活力下降
6. 即使央行注入大量流动性，由于企业无借贷需求，货币供应量不增加，货币政策失效
