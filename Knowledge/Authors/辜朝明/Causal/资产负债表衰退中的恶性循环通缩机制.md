# 资产负债表衰退中的恶性循环通缩机制

> **领域**：宏观经济学　|　**来源**：chapter_24.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 企业部门以负债最小化为目标（而非利润最大化） |
| **DV（因变量）** | 经济陷入恶性循环通缩（GDP持续萎缩） |
| **Chain（传导链）** | 资产价格泡沫破裂导致企业资产负债表受损，净资产为负或接近负值 → 企业从利润最大化转向负债最小化，开始大规模偿还债务（R>0） → 企业偿债行为减少总需求，导致收入下降 → 收入下降迫使个人减少储蓄（S下降），企业利润下降，进一步压缩偿债能力 → 总需求持续萎缩，GDP按公式GDPt=GDPt-1(1-S-R)^t 螺旋下降，形成恶性循环通缩 |
| **Lag（时滞）** | 从泡沫破裂到企业大规模偿债约需数年（如日本1990年泡沫破裂，1998年企业转为净储蓄者） |
| **Threshold（临界值）** | 企业净偿债额（R）和储蓄（S）之和超过政府支出（G）和净出口（EX）的抵消能力，即S+R > G+EX时，GDP趋于萎缩 |
| **前提与约束（Premises）** | 存在全国性资产价格泡沫及其破裂；企业部门资产负债表严重受损，净资产为负或接近负值；企业优先修复资产负债表，而非追求利润最大化；货币政策失效，利率调整无法刺激借贷 |
| **Falsification（证伪条件）** | 如果观察到企业在资产负债表受损后仍继续借贷投资，或者货币政策能有效刺激企业借贷，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭在遭遇重大财务损失后，即使利率很低，也会优先还债而不是借钱消费，导致整个社区的经济活动减少，形成恶性循环。

### 🔗 文字版因果链

1. 资产价格泡沫破裂导致企业资产负债表受损，净资产为负或接近负值
2. 企业从利润最大化转向负债最小化，开始大规模偿还债务（R>0）
3. 企业偿债行为减少总需求，导致收入下降
4. 收入下降迫使个人减少储蓄（S下降），企业利润下降，进一步压缩偿债能力
5. 总需求持续萎缩，GDP按公式GDPt=GDPt-1(1-S-R)^t 螺旋下降，形成恶性循环通缩
