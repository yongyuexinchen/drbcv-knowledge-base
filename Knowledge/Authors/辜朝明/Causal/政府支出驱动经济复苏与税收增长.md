# 政府支出驱动经济复苏与税收增长

> **领域**：宏观经济学　|　**来源**：chapter_32.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府借贷和支出的增加 |
| **DV（因变量）** | 货币供应量增长和经济复苏 |
| **Chain（传导链）** | 政府增加借贷和支出，向经济注入资金 → 货币供应量上升，弥补私营部门借贷的萎缩 → 总需求增加，推动国民生产总值增长 → 经济增长带动个人收入和企业利润上升 → 税收收入增加，预算赤字得以控制 |
| **Lag（时滞）** | 约1-3年（1933年政策实施后，1936年经济恢复至1929年水平） |
| **Threshold（临界值）** | 政府支出占GDP比率从6.9%增至10.5%（上升52%）时，经济显著复苏 |
| **前提与约束（Premises）** | 私营部门因债务痛苦而减少借贷，无法自主推动复苏；经济处于萧条期，存在闲置资源；财政刺激政策有效启动经济成长 |
| **Falsification（证伪条件）** | 如果政府支出大幅增加但货币供应量未上升或经济未复苏，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同病人虚弱时，需要外部输血（政府支出）来恢复体力，随着身体好转，自身造血（税收）能力增强，不再依赖外部输血。

### 🔗 文字版因果链

1. 政府增加借贷和支出，向经济注入资金
2. 货币供应量上升，弥补私营部门借贷的萎缩
3. 总需求增加，推动国民生产总值增长
4. 经济增长带动个人收入和企业利润上升
5. 税收收入增加，预算赤字得以控制
