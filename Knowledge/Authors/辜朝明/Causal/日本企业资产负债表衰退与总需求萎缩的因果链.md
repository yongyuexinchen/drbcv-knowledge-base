# 日本企业资产负债表衰退与总需求萎缩的因果链

> **领域**：宏观经济学　|　**来源**：chapter_11.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资产价格暴跌（如商业地产价格下跌87%、高尔夫俱乐部会员权价格下跌95%） |
| **DV（因变量）** | 经济陷入衰退（总需求萎缩） |
| **Chain（传导链）** | 资产价格暴跌导致企业资产价值大幅缩水，而负债不变 → 企业资产负债表出现净负债（资不抵债） → 企业为修复资产负债表，停止借贷并开始偿还债务（负债最小化） → 企业不再将现金流进行再投资，也不借用个人储蓄 → 总需求萎缩，最终导致经济衰退 |
| **Lag（时滞）** | 资产价格暴跌后，企业资产负债表问题显现，随后企业行为转变，最终导致衰退，时滞可能为数年（如1990年泡沫破灭后，1995年起企业加速还贷） |
| **Threshold（临界值）** | 当资产价格跌幅超过一定幅度（如商业地产下跌87%）导致企业资产净值转为负值，即负债超过资产时，企业转向负债最小化 |
| **前提与约束（Premises）** | 企业原本依赖资产抵押贷款，资产价格暴跌前存在大量债务；企业产品仍有市场需求，盈利状况良好（非产品竞争力下降所致）；利率已降至接近零，但企业仍选择还贷；资产价格暴跌幅度足够大，使企业资产负债表出现净负债 |
| **Falsification（证伪条件）** | 如果资产价格暴跌后，企业仍继续增加借贷或投资，或者经济未出现衰退，则该因果断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人原本有100万房产和70万房贷，房产跌到10万，他资不抵债，于是拼命省钱还债，不再消费，导致整个社区经济萧条

### 🔗 文字版因果链

1. 资产价格暴跌导致企业资产价值大幅缩水，而负债不变
2. 企业资产负债表出现净负债（资不抵债）
3. 企业为修复资产负债表，停止借贷并开始偿还债务（负债最小化）
4. 企业不再将现金流进行再投资，也不借用个人储蓄
5. 总需求萎缩，最终导致经济衰退
