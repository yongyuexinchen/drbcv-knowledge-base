# 银行危机持续且央行注资无效

> 属于因果簇：[[资产负债表衰退中货币政策失效的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 银行借贷人破产导致银行资不抵债 |
| **DV（因变量）** | 银行危机持续且央行注资无效 |
| **Chain（传导链）** | 借贷人破产导致银行资产质量恶化 → 银行资本充足率下降，陷入资不抵债 → 银行面临挤兑或倒闭风险，但根本问题是偿付能力而非流动性 → 央行注入流动性无法修复银行资产负债表，危机持续 |
| **Lag（时滞）** | 短期至中期（银行破产和挤兑在数年内累积显现） |
| **Threshold（临界值）** | 银行资本充足率低于监管要求或资不抵债时，流动性注入失效 |
| **前提与约束（Premises）** | 银行危机源于借贷方破产而非流动性不足；银行系统存在大量资不抵债的机构；私营部门资金需求急剧下降 |
| **Falsification（证伪条件）** | 若在银行资不抵债情况下，央行注资能显著降低银行倒闭数量并恢复信贷，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个已经破产的公司不断提供短期贷款，无法解决其根本的债务问题，只会拖延时间。

### 🔗 文字版因果链

1. 借贷人破产导致银行资产质量恶化
2. 银行资本充足率下降，陷入资不抵债
3. 银行面临挤兑或倒闭风险，但根本问题是偿付能力而非流动性
4. 央行注入流动性无法修复银行资产负债表，危机持续
