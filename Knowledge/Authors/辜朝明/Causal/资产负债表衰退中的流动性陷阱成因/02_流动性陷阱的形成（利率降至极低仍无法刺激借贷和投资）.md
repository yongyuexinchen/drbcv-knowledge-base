# 流动性陷阱的形成（利率降至极低仍无法刺激借贷和投资）

> 属于因果簇：[[资产负债表衰退中的流动性陷阱成因]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 企业追求负债最小化 |
| **DV（因变量）** | 流动性陷阱的形成（利率降至极低仍无法刺激借贷和投资） |
| **Chain（传导链）** | 企业追求负债最小化，停止借贷和投资 → 总需求下降，经济低迷 → 央行降息以刺激经济，但企业因负债最小化目标而对利率不敏感 → 利率降至近零，仍无法刺激借贷，经济陷入流动性陷阱 |
| **Lag（时滞）** | 企业行为转变后，经济低迷和央行降息反应存在时滞，但陷阱在企业开始负债最小化时已形成 |
| **Threshold（临界值）** | 当企业普遍以负债最小化为目标时，即使利率降至零，借贷仍不增加 |
| **前提与约束（Premises）** | 企业负债最小化目标占主导，而非利润最大化；央行降息无法改变企业修复资产负债表的意愿；经济中存在大量负债沉重的企业 |
| **Falsification（证伪条件）** | 如果利率降至极低后企业借贷和投资显著增加，经济复苏，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个负债累累的人，即使银行提供零利率贷款，他也不敢借钱消费，而是想尽快还清债务，导致银行再怎么降息也无法刺激他花钱。

### 🔗 文字版因果链

1. 企业追求负债最小化，停止借贷和投资
2. 总需求下降，经济低迷
3. 央行降息以刺激经济，但企业因负债最小化目标而对利率不敏感
4. 利率降至近零，仍无法刺激借贷，经济陷入流动性陷阱
