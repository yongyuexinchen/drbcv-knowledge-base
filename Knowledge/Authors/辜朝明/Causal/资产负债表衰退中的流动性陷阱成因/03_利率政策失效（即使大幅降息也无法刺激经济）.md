# 利率政策失效（即使大幅降息也无法刺激经济）

> 属于因果簇：[[资产负债表衰退中的流动性陷阱成因]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 企业行为从利润最大化转向负债最小化 |
| **DV（因变量）** | 利率政策失效（即使大幅降息也无法刺激经济） |
| **Chain（传导链）** | 企业目标从利润最大化转向负债最小化 → 企业不再对利率变化做出反应，停止借贷和投资 → 央行降息，但企业借贷需求不增加 → 货币政策传导机制失效，经济对降息无动于衷 |
| **Lag（时滞）** | 企业行为转变后，政策失效立即显现，但央行可能因误判而持续降息 |
| **Threshold（临界值）** | 当企业负债最小化目标成为主流时，利率下调幅度再大也无法刺激借贷 |
| **前提与约束（Premises）** | 企业资产负债表受损，负债最小化优先于利润最大化；企业借贷需求对利率弹性极低；经济处于资产负债表衰退阶段 |
| **Falsification（证伪条件）** | 如果大幅降息后企业借贷和投资明显增加，经济回暖，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个只想着还债的人，即使银行把利息降到零，他也不会借钱去投资，而是继续存钱还债，所以降息对他毫无吸引力。

### 🔗 文字版因果链

1. 企业目标从利润最大化转向负债最小化
2. 企业不再对利率变化做出反应，停止借贷和投资
3. 央行降息，但企业借贷需求不增加
4. 货币政策传导机制失效，经济对降息无动于衷
