# 企业行为目标从利润最大化转向负债最小化

> 属于因果簇：[[资产负债表衰退中的流动性陷阱成因]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 企业资产负债表受损（资产贬值、负债高企） |
| **DV（因变量）** | 企业行为目标从利润最大化转向负债最小化 |
| **Chain（传导链）** | 资产价格泡沫破裂导致企业资产大幅贬值，资产负债表恶化 → 企业为修复资产负债表，优先偿还债务，减少借贷 → 企业停止将利润用于再生产，也不再从个人储蓄中借贷 → 企业行为转变导致总需求降低，经济削弱 |
| **Lag（时滞）** | 泡沫破裂后不久，企业迅速调整行为，但外界察觉滞后 |
| **Threshold（临界值）** | 当企业资产贬值到资不抵债或信用评级大幅下降时，行为转变发生 |
| **前提与约束（Premises）** | 企业面临严重的资产负债表问题，而非暂时性流动性短缺；企业以负债最小化为首要目标，而非利润最大化；经济体中企业部门债务负担沉重 |
| **Falsification（证伪条件）** | 如果企业在资产负债表受损后仍积极借贷投资，或对利率下调反应敏感，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭因房贷压力过大，即使银行降息也不愿再贷款消费，而是拼命存钱还债，导致整个社区消费萎缩。

### 🔗 文字版因果链

1. 资产价格泡沫破裂导致企业资产大幅贬值，资产负债表恶化
2. 企业为修复资产负债表，优先偿还债务，减少借贷
3. 企业停止将利润用于再生产，也不再从个人储蓄中借贷
4. 企业行为转变导致总需求降低，经济削弱
