# 银行体系风险增加，风险在糟糕时刻回归银行

> 属于因果簇：[[新金融体系与次贷危机：风险回归与监管缺失]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 商业银行被允许减少资产负债表上的流动性、准备金和资本数量 |
| **DV（因变量）** | 银行体系风险增加，风险在糟糕时刻回归银行 |
| **Chain（传导链）** | 监管放松允许银行减少流动性和资本缓冲 → 银行通过发起-分配模式转移贷款风险 → 风险并未真正转移，而是通过融资便利等保留在银行体系 → 市场困难时，风险集中回归银行 |
| **Lag（时滞）** | 短期至中期（随市场波动显现） |
| **Threshold（临界值）** | 当资产价格大幅下跌或市场遇困时 |
| **前提与约束（Premises）** | 银行采用发起-分配模式；存在商业票据等短期信用放大；银行提供融资便利 |
| **Falsification（证伪条件）** | 若银行减少流动性但风险未回归，或风险完全转移，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同把易燃物堆在仓库但声称已投保，火灾时损失仍由仓库主承担

### 🔗 文字版因果链

1. 监管放松允许银行减少流动性和资本缓冲
2. 银行通过发起-分配模式转移贷款风险
3. 风险并未真正转移，而是通过融资便利等保留在银行体系
4. 市场困难时，风险集中回归银行
