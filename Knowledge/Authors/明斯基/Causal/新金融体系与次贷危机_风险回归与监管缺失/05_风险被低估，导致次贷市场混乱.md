# 风险被低估，导致次贷市场混乱

> 属于因果簇：[[新金融体系与次贷危机：风险回归与监管缺失]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 《巴塞尔协议》风险分类过于宽泛，允许大银行使用内部模型评估风险 |
| **DV（因变量）** | 风险被低估，导致次贷市场混乱 |
| **Chain（传导链）** | 风险分类宽泛，内部模型基于历史数据 → 模型无法反映系统风险 → 银行低估风险，过度承担风险 → 次贷市场崩溃，引发混乱 |
| **Lag（时滞）** | 中期（随模型应用和风险累积） |
| **Threshold（临界值）** | 当内部模型基于不充分历史数据时 |
| **前提与约束（Premises）** | 银行被允许使用内部模型；风险分类宽泛 |
| **Falsification（证伪条件）** | 若内部模型能准确预测风险，或次贷市场未混乱，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用过去天气预测未来风暴，但气候已变，预测失效

### 🔗 文字版因果链

1. 风险分类宽泛，内部模型基于历史数据
2. 模型无法反映系统风险
3. 银行低估风险，过度承担风险
4. 次贷市场崩溃，引发混乱
