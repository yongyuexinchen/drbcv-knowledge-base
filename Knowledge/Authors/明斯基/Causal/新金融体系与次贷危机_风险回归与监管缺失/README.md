# 新金融体系与次贷危机：风险回归与监管缺失（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：新金融体系与次贷危机_风险回归与监管缺失.md

## 总体因果图

- 相对不受管理的市场从商业银行抢去更多市场份额 → 监管当局放松对商业银行的监管和审查
- 商业银行被允许减少资产负债表上的流动性、准备金和资本数量 → 银行体系风险增加，风险在糟糕时刻回归银行
- 金融市场变成仅依据价格运行的现货市场，存在大量不受限制的信用 → 信用需求在任一价格水平上可能无限，导致投机性繁荣
- 银行债务具有明确的公共担保 → 银行权益通过提高杠杆和购买风险资产增加收益，但导致公共资金保
- 《巴塞尔协议》风险分类过于宽泛，允许大银行使用内部模型评估风险 → 风险被低估，导致次贷市场混乱
- 监管放松和竞争压力 → 需要更多国际合作和干预措施恢复监管平衡
