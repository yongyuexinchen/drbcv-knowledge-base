# 金融体系从稳定结构转变为脆弱性增强的结构

> 属于因果簇：[[明斯基金融不稳定假说中的投资、利润与金融脆弱性因果链]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 投资拉动的经济增长 |
| **DV（因变量）** | 金融体系从稳定结构转变为脆弱性增强的结构 |
| **Chain（传导链）** | 投资拉动的经济增长 → 企业债务融资增加 → 金融体系结构从富于活力转向脆弱性增强 → 金融不稳定性和通货膨胀压力上升 |
| **Lag（时滞）** | 中期，随投资周期和债务累积过程显现 |
| **Threshold（临界值）** | 投资持续增长，债务累积超过安全边际 |
| **前提与约束（Premises）** | 存在大政府和最终贷款人干预（制度底线）；政策鼓励投资以扩大总需求；经济主体对未来的乐观预期推动债务融资 |
| **Falsification（证伪条件）** | 如果投资增长但金融体系未变得脆弱，或未出现不稳定性和通胀压力，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同不断给气球充气（投资），气球壁变薄（金融脆弱性），最终可能破裂（金融危机）。

### 🔗 文字版因果链

1. 投资拉动的经济增长
2. 企业债务融资增加
3. 金融体系结构从富于活力转向脆弱性增强
4. 金融不稳定性和通货膨胀压力上升
