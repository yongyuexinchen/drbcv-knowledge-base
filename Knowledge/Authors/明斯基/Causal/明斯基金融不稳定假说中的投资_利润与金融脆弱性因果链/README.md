# 明斯基金融不稳定假说中的投资、利润与金融脆弱性因果链（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：明斯基金融不稳定假说中的投资_利润与金融脆弱性因果链.md

## 总体因果图

- 预期未来盈利能力下降 → 当前投资减少，当前利润低于维持过去预期所需水平
- 投资拉动的经济增长 → 金融体系从稳定结构转变为脆弱性增强的结构
- 美联储试图控制货币供给 → 银行业务创新和非银行融资扩张，最终导致需要最终贷款人干预
- 大政府和大银行的制度约束 → 战后数十年避免债务通缩和大萧条重演
- 制度约束不能适应环境变化或大萧条教训被遗忘 → 经济发展可能引发债务违约雪球，最终打破限制，导致大萧条重演
