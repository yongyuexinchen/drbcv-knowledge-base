# 随后消费支出的爆发式增长（经济复苏中的消费英雄行为）

> 属于因果簇：[[大政府赤字与经济衰退逆转的因果分析]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济衰退期间家庭高储蓄率 |
| **DV（因变量）** | 随后消费支出的爆发式增长（经济复苏中的消费英雄行为） |
| **Chain（传导链）** | 衰退期间家庭因不确定性或信贷收缩而增加储蓄 → 家庭流动性资产积累，债务相对收入下降 → 随着经济稳定，家庭信心恢复 → 家庭支出占可支配收入比例上升，储蓄率下降 → 消费支出激增，推动经济复苏 |
| **Lag（时滞）** | 滞后（衰退后的复苏期） |
| **Threshold（临界值）** | 储蓄率高达8%-9%时，随后储蓄率降至6%左右，消费支出爆发 |
| **前提与约束（Premises）** | 家庭未直接遭受失业的显著影响；消费信贷增长停滞或收缩；可支配收入维持或增长 |
| **Falsification（证伪条件）** | 如果高储蓄率后消费支出未出现爆发式增长，或储蓄率持续高位，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像弹簧被压紧（高储蓄），松开后（经济稳定）会猛烈弹起（消费爆发）。

### 🔗 文字版因果链

1. 衰退期间家庭因不确定性或信贷收缩而增加储蓄
2. 家庭流动性资产积累，债务相对收入下降
3. 随着经济稳定，家庭信心恢复
4. 家庭支出占可支配收入比例上升，储蓄率下降
5. 消费支出激增，推动经济复苏
