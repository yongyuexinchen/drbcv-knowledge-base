# 大政府干预防止金融崩溃的因果机制

> **领域**：宏观经济学　|　**来源**：chapter_25.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大政府的财政政策（经济衰退中的大量政府赤字） |
| **DV（因变量）** | 私人金融承诺得以持久，投资组合结构优化，避免金融崩溃 |
| **Chain（传导链）** | 经济衰退导致收入下降，私人部门偿债能力减弱 → 政府通过增加赤字支出（如转移支付）直接补充居民可支配收入 → 收入稳定使私人部门能够继续履行金融承诺，减少违约 → 投资组合结构因收入稳定而得到优化，避免资产价格螺旋下跌 → 金融混乱被遏制，避免演变为全面金融危机 |
| **Lag（时滞）** | 短期内（衰退期间及随后的复苏阶段，如1975-1976年） |
| **Threshold（临界值）** | 政府赤字规模需足够大，足以抵消私人部门收入下降的冲击 |
| **前提与约束（Premises）** | 政府支出主要通过转移支付影响总需求，而非直接生产；金融因素在传导中起关键作用，需纳入分析框架；适用于存在大政府且金融结构脆弱的经济体 |
| **Falsification（证伪条件）** | 如果政府赤字增加但私人金融承诺仍大量违约，或金融崩溃仍发生，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个漏水的船持续抽水，只要抽水量大于进水量，船就不会沉

### 🔗 文字版因果链

1. 经济衰退导致收入下降，私人部门偿债能力减弱
2. 政府通过增加赤字支出（如转移支付）直接补充居民可支配收入
3. 收入稳定使私人部门能够继续履行金融承诺，减少违约
4. 投资组合结构因收入稳定而得到优化，避免资产价格螺旋下跌
5. 金融混乱被遏制，避免演变为全面金融危机

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 最终贷款人干预（美联储、FDIC及私人金融机构的再融资） |
| **DV（因变量）** | 避免金融恐慌演变为全面金融危机 |
| **Chain（传导链）** | 金融混乱导致短期债务偿付压力上升，资产价格下跌 → 最终贷款人提供再融资，缓解流动性短缺 → 私人部门和公共部门合作，稳定市场信心 → 恐慌被遏制，金融体系维持稳定 |
| **Lag（时滞）** | 及时干预，在金融恐慌全面爆发之前（如1975年） |
| **Threshold（临界值）** | 干预需在金融混乱初期进行，且规模足以覆盖流动性缺口 |
| **前提与约束（Premises）** | 存在有效的最终贷款人机制（如美联储）；私人金融机构愿意合作（如大型商业银行）；干预发生在恐慌尚未全面蔓延时 |
| **Falsification（证伪条件）** | 如果最终贷款人干预后仍发生全面金融危机，或干预本身引发道德风险导致更严重危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像消防队及时扑灭小火，避免火势蔓延烧毁整栋楼

### 🔗 文字版因果链

1. 金融混乱导致短期债务偿付压力上升，资产价格下跌
2. 最终贷款人提供再融资，缓解流动性短缺
3. 私人部门和公共部门合作，稳定市场信心
4. 恐慌被遏制，金融体系维持稳定
