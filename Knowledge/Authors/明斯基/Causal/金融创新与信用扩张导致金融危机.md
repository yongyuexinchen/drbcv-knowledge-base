# 金融创新与信用扩张导致金融危机

> **领域**：宏观经济学　|　**来源**：chapter_11.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融创新（证券化、套期保值、信用违约互换等） |
| **DV（因变量）** | 信用规模扩张和资产价格大幅上涨，进而导致金融危机 |
| **Chain（传导链）** | 金融创新极大程度地扩张了信用规模 → 信用规模扩张大幅推高了资产价格 → 资产价格上涨鼓励更多金融创新以利用利润机会 → 更多金融创新加速债务规模扩张和杠杆水平提高 → 高杠杆和风险偏好导致金融体系脆弱性积累 → 脆弱性积累最终引发金融危机 |
| **Lag（时滞）** | 过去十年（约10年） |
| **Threshold（临界值）** | 信用规模扩张和杠杆水平达到不可持续的高位 |
| **前提与约束（Premises）** | 金融创新未被有效监管；市场参与者对风险偏好增强；存在美联储干预预期（格林斯潘作为） |
| **Falsification（证伪条件）** | 如果金融创新未导致信用规模显著扩张或资产价格大幅上涨，或金融危机未发生，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同不断给气球充气，每次充气（金融创新）都让气球更大（信用扩张），但最终超过极限就会爆炸（金融危机）。

### 🔗 文字版因果链

1. 金融创新极大程度地扩张了信用规模
2. 信用规模扩张大幅推高了资产价格
3. 资产价格上涨鼓励更多金融创新以利用利润机会
4. 更多金融创新加速债务规模扩张和杠杆水平提高
5. 高杠杆和风险偏好导致金融体系脆弱性积累
6. 脆弱性积累最终引发金融危机
