# 新金融体系与次贷危机：风险回归与监管缺失

> **领域**：宏观经济学、金融学　|　**来源**：chapter_14.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 相对不受管理的市场从商业银行抢去更多市场份额 |
| **DV（因变量）** | 监管当局放松对商业银行的监管和审查 |
| **Chain（传导链）** | 不受管理的市场扩大，商业银行面临竞争压力 → 监管当局为促进商业银行竞争，放松监管和审查 → 商业银行得以进行更冒险的资产负债表操作 |
| **Lag（时滞）** | 中期（随市场份额变化逐步显现） |
| **Threshold（临界值）** | 当不受管理市场份额显著增加时 |
| **前提与约束（Premises）** | 存在竞争性金融环境；监管当局以促进竞争为目标 |
| **Falsification（证伪条件）** | 若市场份额增加但监管未放松，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同学校中，若课外补习班（不受管理）盛行，学校为吸引学生可能降低考试标准（放松监管）

### 🔗 文字版因果链

1. 不受管理的市场扩大，商业银行面临竞争压力
2. 监管当局为促进商业银行竞争，放松监管和审查
3. 商业银行得以进行更冒险的资产负债表操作

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 商业银行被允许减少资产负债表上的流动性、准备金和资本数量 |
| **DV（因变量）** | 银行体系风险增加，风险在糟糕时刻回归银行 |
| **Chain（传导链）** | 监管放松允许银行减少流动性和资本缓冲 → 银行通过发起-分配模式转移贷款风险 → 风险并未真正转移，而是通过融资便利等保留在银行体系 → 市场困难时，风险集中回归银行 |
| **Lag（时滞）** | 短期至中期（随市场波动显现） |
| **Threshold（临界值）** | 当资产价格大幅下跌或市场遇困时 |
| **前提与约束（Premises）** | 银行采用发起-分配模式；存在商业票据等短期信用放大；银行提供融资便利 |
| **Falsification（证伪条件）** | 若银行减少流动性但风险未回归，或风险完全转移，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同把易燃物堆在仓库但声称已投保，火灾时损失仍由仓库主承担

### 🔗 文字版因果链

1. 监管放松允许银行减少流动性和资本缓冲
2. 银行通过发起-分配模式转移贷款风险
3. 风险并未真正转移，而是通过融资便利等保留在银行体系
4. 市场困难时，风险集中回归银行

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融市场变成仅依据价格运行的现货市场，存在大量不受限制的信用 |
| **DV（因变量）** | 信用需求在任一价格水平上可能无限，导致投机性繁荣 |
| **Chain（传导链）** | 金融市场以价格为导向，忽视个体信用评估 → 信用供给不受限制，需求对价格不敏感 → 经济周期中信用需求无限膨胀 → 引发投机性繁荣和金融不稳定 |
| **Lag（时滞）** | 周期性（随经济周期显现） |
| **Threshold（临界值）** | 当信用需求在任一价格水平上无限时 |
| **前提与约束（Premises）** | 市场缺乏对信用规模的限制；存在投机性繁荣的倾向 |
| **Falsification（证伪条件）** | 若信用需求对价格敏感且有限，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同自助餐不限量，食客会吃到撑（投机繁荣），最终导致身体不适（金融危机）

### 🔗 文字版因果链

1. 金融市场以价格为导向，忽视个体信用评估
2. 信用供给不受限制，需求对价格不敏感
3. 经济周期中信用需求无限膨胀
4. 引发投机性繁荣和金融不稳定

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 银行债务具有明确的公共担保 |
| **DV（因变量）** | 银行权益通过提高杠杆和购买风险资产增加收益，但导致公共资金保护存款者 |
| **Chain（传导链）** | 公共担保使存款者风险外部化 → 银行股东和管理层有动机提高杠杆和风险资产以增加收益 → 高风险操作增加不良贷款概率 → 需要公共资金救援，保护存款者 |
| **Lag（时滞）** | 中期（随风险累积显现） |
| **Threshold（临界值）** | 当杠杆率和风险资产比例过高时 |
| **前提与约束（Premises）** | 存在明确的公共担保；银行权益面临损失风险有限 |
| **Falsification（证伪条件）** | 若银行不因担保而增加风险，或风险未导致公共救援，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同政府为赛车手提供安全气囊，赛车手可能更冒险驾驶，最终仍需政府救援

### 🔗 文字版因果链

1. 公共担保使存款者风险外部化
2. 银行股东和管理层有动机提高杠杆和风险资产以增加收益
3. 高风险操作增加不良贷款概率
4. 需要公共资金救援，保护存款者

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 《巴塞尔协议》风险分类过于宽泛，允许大银行使用内部模型评估风险 |
| **DV（因变量）** | 风险被低估，导致次贷市场混乱 |
| **Chain（传导链）** | 风险分类宽泛，内部模型基于历史数据 → 模型无法反映系统风险 → 银行低估风险，过度承担风险 → 次贷市场崩溃，引发混乱 |
| **Lag（时滞）** | 中期（随模型应用和风险累积） |
| **Threshold（临界值）** | 当内部模型基于不充分历史数据时 |
| **前提与约束（Premises）** | 银行被允许使用内部模型；风险分类宽泛 |
| **Falsification（证伪条件）** | 若内部模型能准确预测风险，或次贷市场未混乱，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用过去天气预测未来风暴，但气候已变，预测失效

### 🔗 文字版因果链

1. 风险分类宽泛，内部模型基于历史数据
2. 模型无法反映系统风险
3. 银行低估风险，过度承担风险
4. 次贷市场崩溃，引发混乱

| **Falsification（证伪条件）** | 若国际合作未加强但监管仍有效，则断言不成立 |
