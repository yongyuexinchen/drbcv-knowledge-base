# 监管当局放松对商业银行的监管和审查

> 属于因果簇：[[新金融体系与次贷危机：风险回归与监管缺失]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 相对不受管理的市场从商业银行抢去更多市场份额 |
| **DV（因变量）** | 监管当局放松对商业银行的监管和审查 |
| **Chain（传导链）** | 不受管理的市场扩大，商业银行面临竞争压力 → 监管当局为促进商业银行竞争，放松监管和审查 → 商业银行得以进行更冒险的资产负债表操作 |
| **Lag（时滞）** | 中期（随市场份额变化逐步显现） |
| **Threshold（临界值）** | 当不受管理市场份额显著增加时 |
| **前提与约束（Premises）** | 存在竞争性金融环境；监管当局以促进竞争为目标 |
| **Falsification（证伪条件）** | 若市场份额增加但监管未放松，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同学校中，若课外补习班（不受管理）盛行，学校为吸引学生可能降低考试标准（放松监管）

### 🔗 文字版因果链

1. 不受管理的市场扩大，商业银行面临竞争压力
2. 监管当局为促进商业银行竞争，放松监管和审查
3. 商业银行得以进行更冒险的资产负债表操作
