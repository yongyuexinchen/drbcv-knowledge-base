## 主传导链

```text
第一阶段（积累期 3-10年）：
外资流入/资本账户开放 / 战时举债
  → 债务扩张（尤以外币计价）
  → 自我强化的泡沫周期：
      债务/GDP ↑（常见 150%-270%）
      资产价格 ↑（股市年回报 12%-25%，房价年化 10%-20%）
      GDP ↑（4%-8%）
      实际汇率升值
  → 债务质量决定可持续性：
      生产性投资 → 可产生收入支撑偿债（可持续）
      消费性支出/空转 → 债务不可持续（脆弱性↑）

第二阶段（触发与崩塌 1-3年）：
触发因素（外资撤离 / 政策紧缩 / 商品价格崩盘 / 政治冲击）
  → 泡沫破裂
  → 经济萧条 / 国际收支危机 / 货币危机
  → 若债务外币占比高（>50%）+ 依赖外资流入：危机深度更大
      （保加利亚、厄瓜多尔、秘鲁、阿根廷、巴西案例）

第三阶段（去杠杆化 5-10年）：
两种路径：
  A. 通缩性去杠杆（债务削减+财政紧缩+银行重组）
     典型：美国1926-1936、日本1925-1936、英国1927-1936、
           挪威1984-1996、德国2006-2017、英国2005-2015
  B. 通胀性去杠杆（印钞+货币贬值+债务货币化）
     典型：墨西哥、巴西、阿根廷、俄罗斯、印尼、泰国、土耳其
  关键机制：
      高债务+借贷压力 → 决策者倾向压低利率、贬值货币
      允许货币浮动（放弃钉住汇率） → 利率政策灵活性↑
      固定汇率/欧元区无货币自主权 → 政策空间受限，痛苦更久
          （奥地利、希腊、西班牙、葡萄牙案例）

第四阶段（恢复或长期停滞）：
取决于：
  债务质量（是否产生收入）
  央行+财政+债务重组 三工具协调程度
  内部冲突是否爆发（财政困境+财富差距+经济冲击 = 有毒组合）
  外部资本是否重新流入 / 资本战风险是否上升
```
