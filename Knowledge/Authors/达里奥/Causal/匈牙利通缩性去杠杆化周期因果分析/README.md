# 匈牙利通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：匈牙利通缩性去杠杆化周期因果分析.md

## 总体因果图

- 外资流入减少（投资组合流入降幅为GDP的12%） → 货币政策收紧（短期利率上调5%）
- 货币政策收紧（短期利率上调5%） → GDP、股价和房价自我强化式下跌（跌幅分别为7%、73%和1
- 经济刺激政策（M0增幅达GDP的4%，利率降至0%，实际汇率为-6%） → 名义经济增长率高于名义利率（经济增长率平均5%，长期利率2%
- 债务危机及经济萧条 → 维克托·欧尔班上台（民粹主义领导人）
