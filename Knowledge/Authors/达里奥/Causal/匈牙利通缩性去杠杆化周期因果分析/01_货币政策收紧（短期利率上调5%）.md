# 货币政策收紧（短期利率上调5%）

> 属于因果簇：[[匈牙利通缩性去杠杆化周期因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（投资组合流入降幅为GDP的12%） |
| **DV（因变量）** | 货币政策收紧（短期利率上调5%） |
| **Chain（传导链）** | 外资流入减少导致资本外流压力 → 央行为了稳定汇率和抑制资本外流而收紧货币政策 → 短期利率上调 |
| **Lag（时滞）** | 短期内（数月内） |
| **Threshold（临界值）** | 外资流入降幅达到GDP的12%时触发 |
| **前提与约束（Premises）** | 匈牙利存在较大经常账户赤字（占GDP的8%）；债务以外币计价且债权人多为外国人；全球金融危机冲击导致全球资本流动逆转 |
| **Falsification（证伪条件）** | 如果外资流入减少但利率未上调或下调，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人突然失去外部收入，为了维持生活水平不得不提高信用卡利率来借钱，但这样反而加重了负担。

### 🔗 文字版因果链

1. 外资流入减少导致资本外流压力
2. 央行为了稳定汇率和抑制资本外流而收紧货币政策
3. 短期利率上调
