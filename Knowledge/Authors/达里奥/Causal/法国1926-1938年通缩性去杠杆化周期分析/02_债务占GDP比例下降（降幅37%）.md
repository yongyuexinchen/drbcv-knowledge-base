# 债务占GDP比例下降（降幅37%）

> 属于因果簇：[[法国1926-1938年通缩性去杠杆化周期分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者切断法郎与黄金的挂钩并允许通胀率高企 |
| **DV（因变量）** | 债务占GDP比例下降（降幅37%） |
| **Chain（传导链）** | 切断金本位使货币政策获得独立性 → 降低利率至2%，刺激经济增长 → 允许通胀率平均达10%，推高名义GDP → 名义经济增长率（15%）远高于名义利率（4%），减轻实际债务负担 |
| **Lag（时滞）** | 政策实施后1-2年内效果显现 |
| **Threshold（临界值）** | 名义GDP增长率需持续高于名义利率（差值至少5个百分点） |
| **前提与约束（Premises）** | 决策者有能力实施激进的货币政策；通胀预期可控，未引发恶性通胀；金融机构得到有效管控，坏账得到处理 |
| **Falsification（证伪条件）** | 若在类似政策下，债务占比未下降或经济陷入滞胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同通过货币贬值来稀释债务，就像用稀释的溶液降低浓度，但需控制稀释剂本身不破坏容器

### 🔗 文字版因果链

1. 切断金本位使货币政策获得独立性
2. 降低利率至2%，刺激经济增长
3. 允许通胀率平均达10%，推高名义GDP
4. 名义经济增长率（15%）远高于名义利率（4%），减轻实际债务负担
