# 法国1926-1938年通缩性去杠杆化周期分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：法国1926-1938年通缩性去杠杆化周期分析.md

## 总体因果图

- 高债务水平（债务占GDP比例达205%） → 经济脆弱性增加，易受外部冲击伤害
- 决策者切断法郎与黄金的挂钩并允许通胀率高企 → 债务占GDP比例下降（降幅37%）
- 经济萧条和痛苦的去杠杆化 → 政治格局变化，民粹主义领导人上台
