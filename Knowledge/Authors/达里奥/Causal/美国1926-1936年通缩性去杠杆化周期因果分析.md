# 美国1926-1936年通缩性去杠杆化周期因果分析

> **领域**：宏观经济学　|　**来源**：case_us_1929.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务水平高企（债务占GDP达125%） |
| **DV（因变量）** | 经济脆弱性增加，易受冲击伤害 |
| **Chain（传导链）** | 高债务水平使经济主体（政府、企业、家庭）负债累累，偿债压力大 → 当外部冲击（如股市崩盘）发生时，高债务水平导致资产价格下跌和收入下降的恶性循环 → 债务通缩机制启动：物价下跌、实际债务负担加重、借贷减少、支出下降 → 经济陷入自我强化的萧条 |
| **Lag（时滞）** | 冲击发生后立即显现，但持续数年（1929-1933年） |
| **Threshold（临界值）** | 债务占GDP比例超过125%时，经济变得脆弱 |
| **前提与约束（Premises）** | 债务以本币计价，债权人多为国内居民；经济处于泡沫阶段，资产价格高估；决策者采取紧缩政策（如加息） |
| **Falsification（证伪条件）** | 如果高债务水平下经济仍能抵御冲击而不陷入萧条，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人背负过多债务，一旦失业或生病，就很容易陷入财务崩溃；而债务少的人则能更从容应对

### 🔗 文字版因果链

1. 高债务水平使经济主体（政府、企业、家庭）负债累累，偿债压力大
2. 当外部冲击（如股市崩盘）发生时，高债务水平导致资产价格下跌和收入下降的恶性循环
3. 债务通缩机制启动：物价下跌、实际债务负担加重、借贷减少、支出下降
4. 经济陷入自我强化的萧条

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 股市崩盘（1929年） |
| **DV（因变量）** | GDP、股价、房价自我强化式下跌，失业率上升 |
| **Chain（传导链）** | 股市崩盘导致财富效应逆转，投资者和消费者信心崩溃 → 资产价格下跌使抵押品价值缩水，银行收紧信贷 → 企业投资减少，消费者支出下降，导致GDP下降 → 经济萎缩进一步压低资产价格，形成负反馈循环 |
| **Lag（时滞）** | 股市崩盘后立即开始，持续约4年（1929-1933年） |
| **Threshold（临界值）** | 股市崩盘幅度超过一定阈值（如股价下跌84%） |
| **前提与约束（Premises）** | 高债务水平使经济脆弱；存在通缩压力；金融机构面临压力 |
| **Falsification（证伪条件）** | 如果股市崩盘后经济能迅速恢复而不出现长期萧条，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像多米诺骨牌，第一块倒下（股市崩盘）引发连锁反应，导致整个系统崩溃

### 🔗 文字版因果链

1. 股市崩盘导致财富效应逆转，投资者和消费者信心崩溃
2. 资产价格下跌使抵押品价值缩水，银行收紧信贷
3. 企业投资减少，消费者支出下降，导致GDP下降
4. 经济萎缩进一步压低资产价格，形成负反馈循环

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（切断美元与黄金挂钩、增加M0、降低利率至0%） |
| **DV（因变量）** | 痛苦的去杠杆化转变为和谐的去杠杆化，经济复苏 |
| **Chain（传导链）** | 货币政策宽松：切断美元与黄金挂钩，增加货币供应（M0增幅达GDP的6%），降低利率至0% → 财政政策积极：提供流动性，直接购买不良资产，管控金融机构 → 名义经济增长率（8%）高于名义利率（3%），降低实际债务负担 → 实际收入水平提升，债务占GDP比例下降（降幅70%），失业率下降14% → 经济步入通货再膨胀阶段，最终实现复苏 |
| **Lag（时滞）** | 刺激政策实施后约1-2年（1933年开始） |
| **Threshold（临界值）** | 名义经济增长率超过名义利率，且货币供应增加足够大（M0增幅达GDP的6%） |
| **前提与约束（Premises）** | 决策者有能力实施大规模刺激政策；金融机构得到有效管控；使用多个政策工具（9个中的8个） |
| **Falsification（证伪条件）** | 如果刺激政策未能使经济复苏或导致恶性通胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个溺水的人扔救生圈，虽然不能立即救起，但能防止其沉没，并逐渐游回岸边

### 🔗 文字版因果链

1. 货币政策宽松：切断美元与黄金挂钩，增加货币供应（M0增幅达GDP的6%），降低利率至0%
2. 财政政策积极：提供流动性，直接购买不良资产，管控金融机构
3. 名义经济增长率（8%）高于名义利率（3%），降低实际债务负担
4. 实际收入水平提升，债务占GDP比例下降（降幅70%），失业率下降14%
5. 经济步入通货再膨胀阶段，最终实现复苏

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济萧条和痛苦去杠杆化 |
| **DV（因变量）** | 政治格局变化，民粹主义领导人上台（罗斯福） |
| **Chain（传导链）** | 经济萧条导致失业率上升（23%）、收入下降、社会不满情绪积累 → 民众对现有政府和经济体制失去信心 → 民粹主义领导人（罗斯福）提出改革方案，获得广泛支持 → 政治格局发生显著变化 |
| **Lag（时滞）** | 经济萧条持续约4年后（1933年） |
| **Threshold（临界值）** | 失业率上升超过20%，GDP下降超过25% |
| **前提与约束（Premises）** | 经济萧条严重且持续时间长；现有政府应对不力；存在有吸引力的民粹主义替代方案 |
| **Falsification（证伪条件）** | 如果经济萧条后没有出现政治格局变化或民粹主义领导人上台，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像船在风暴中受损，船员们会推翻无能的船长，选出一个他们认为能带领大家脱险的新船长

### 🔗 文字版因果链

1. 经济萧条导致失业率上升（23%）、收入下降、社会不满情绪积累
2. 民众对现有政府和经济体制失去信心
3. 民粹主义领导人（罗斯福）提出改革方案，获得广泛支持
4. 政治格局发生显著变化
