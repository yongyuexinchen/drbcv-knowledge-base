# 墨西哥1991-2005年通胀性去杠杆化周期因果分析

> **领域**：宏观经济学　|　**来源**：chapter_122.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加（尤其外币计价债务占GDP25%） |
| **DV（因变量）** | 自我强化的泡沫周期（债务升至GDP85%，股市年回报25%，GDP增速4%） |
| **Chain（传导链）** | 外资大量流入填补经常账户赤字（占GDP7%） → 债务水平上升，外币债务增加，经济对外资依赖增强 → 高资产回报率鼓励更多借债，刺激经济增长 → 债务和资金增加支撑经济强劲增长，形成自我强化泡沫 |
| **Lag（时滞）** | 约1-3年（1991-1994年泡沫积累） |
| **Threshold（临界值）** | 债务占GDP比例升至85%，外币债务占GDP25% |
| **前提与约束（Premises）** | 经济开放，依赖外国资本流入；存在经常账户赤字（占GDP7%）；外币债务占比较高，易受外资撤出影响 |
| **Falsification（证伪条件）** | 若在类似资本流入和债务水平下，未出现泡沫或债务危机，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠信用卡透支维持高消费，债务越滚越大，一旦银行收紧信贷，就会陷入财务危机

### 🔗 文字版因果链

1. 外资大量流入填补经常账户赤字（占GDP7%）
2. 债务水平上升，外币债务增加，经济对外资依赖增强
3. 高资产回报率鼓励更多借债，刺激经济增长
4. 债务和资金增加支撑经济强劲增长，形成自我强化泡沫

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政治暴力事件爆发（外部冲击） |
| **DV（因变量）** | 自我强化式经济萧条和国际收支危机/货币危机（GDP下跌10%，股价下跌66%，失业率上升3%，货币贬值37%） |
| **Chain（传导链）** | 政治暴力事件引发外资信心下降，资本外流 → 央行动用外汇储备维持货币稳定（外汇储备减少100%） → 外汇储备耗尽，决策者放弃捍卫货币，货币贬值37% → 货币贬值导致通胀上升（最高43%），GDP和股价陷入自我强化式下跌 |
| **Lag（时滞）** | 约1年（1994-1995年） |
| **Threshold（临界值）** | 外汇储备减少100%，货币贬值37% |
| **前提与约束（Premises）** | 高债务水平使经济脆弱，易受冲击；存在约一半导致通胀螺旋式上升的典型风险因素（如长期忽视通胀管控）；钉住汇率制度限制了货币政策独立性 |
| **Falsification（证伪条件）** | 若在类似政治冲击下，未发生货币危机或经济萧条，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一座地基不牢的大楼，一场地震（政治冲击）就足以使其倒塌

### 🔗 文字版因果链

1. 政治暴力事件引发外资信心下降，资本外流
2. 央行动用外汇储备维持货币稳定（外汇储备减少100%）
3. 外汇储备耗尽，决策者放弃捍卫货币，货币贬值37%
4. 货币贬值导致通胀上升（最高43%），GDP和股价陷入自我强化式下跌

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策、积极管控金融机构、IMF援助和结构性改革 |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP下降41%，实际GDP用2年恢复峰值，重新获得竞争力） |
| **Chain（传导链）** | 放弃钉住汇率制度，允许货币贬值，减少进口支出（经常账户余额增幅为GDP7%） → 实施紧缩政策，提高本国货币吸引力 → 积极管控金融机构和处理坏账（使用9个政策工具中的6个，如银行国有化、提供流动性、直接购买不良资产） → IMF援助计划和结构性改革增强劳动力市场灵活性 → 名义收入增加，债务与收入比率下降，实际汇率跌至-26%低点，重新获得竞争力 |
| **Lag（时滞）** | 约2-10年（1995-2005年） |
| **Threshold（临界值）** | 债务占GDP下降41%（年化降幅4%），实际汇率跌至-26% |
| **前提与约束（Premises）** | 决策者采取正确的政策组合（紧缩+金融机构管控+改革）；国际支持（IMF援助）；经济具有调整弹性 |
| **Falsification（证伪条件）** | 若在类似政策下，去杠杆化未实现或经济长期低迷，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像病人通过手术（紧缩政策）和康复训练（改革）逐步恢复健康，虽然痛苦但最终痊愈

### 🔗 文字版因果链

1. 放弃钉住汇率制度，允许货币贬值，减少进口支出（经常账户余额增幅为GDP7%）
2. 实施紧缩政策，提高本国货币吸引力
3. 积极管控金融机构和处理坏账（使用9个政策工具中的6个，如银行国有化、提供流动性、直接购买不良资产）
4. IMF援助计划和结构性改革增强劳动力市场灵活性
5. 名义收入增加，债务与收入比率下降，实际汇率跌至-26%低点，重新获得竞争力
