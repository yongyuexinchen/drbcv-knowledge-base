# 英国1941-1967年战时通缩性去杠杆化周期（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：英国1941-1967年战时通缩性去杠杆化周期.md

## 总体因果图

- 二战期间英国大量借款以填补巨额财政赤字 → 英国债务急剧增加，债务占GDP比例上升
- 战后英国实际收入水平下降且政府继续承担战争开销 → 英国GDP陷入自我强化式下跌，跌幅达15%
- 决策者提供充足的经济刺激（货币政策与财政政策） → 英国从痛苦的去杠杆化转变为和谐的去杠杆化
