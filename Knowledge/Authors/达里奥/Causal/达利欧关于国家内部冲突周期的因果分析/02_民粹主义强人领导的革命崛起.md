# 民粹主义强人领导的革命崛起

> 属于因果簇：[[达利欧关于国家内部冲突周期的因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 民主制度在剧烈冲突时期的功能失调 |
| **DV（因变量）** | 民粹主义强人领导的革命崛起 |
| **Chain（传导链）** | 民主制度依赖协商与妥协，但在立场尖锐对立时陷入瘫痪 → 治理效率低下导致民怨沸腾 → 民众渴望稳定和强有力领导 → 民粹主义强人承诺秩序，迎合大众心理，获得支持 → 最终可能引发革命，颠覆旧秩序 |
| **Lag（时滞）** | 在冲突加剧后，民主瘫痪到强人崛起可能经历数月到数年 |
| **Threshold（临界值）** | 当中间派消失，各方立场不可调和，民主协商机制无法运作时 |
| **前提与约束（Premises）** | 适用于民主国家在危机时期的政治动态；假设存在有魅力的民粹主义领袖；排除民主制度通过改革自我修复的情况 |
| **Falsification（证伪条件）** | 如果民主制度在冲突时期仍能有效运作，通过和平改革解决危机，未出现强人革命，则该断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一艘船在风暴中，如果船员们无法达成一致，船长（强人）就会接管指挥权，即使他可能带领船走向未知方向

### 🔗 文字版因果链

1. 民主制度依赖协商与妥协，但在立场尖锐对立时陷入瘫痪
2. 治理效率低下导致民怨沸腾
3. 民众渴望稳定和强有力领导
4. 民粹主义强人承诺秩序，迎合大众心理，获得支持
5. 最终可能引发革命，颠覆旧秩序
