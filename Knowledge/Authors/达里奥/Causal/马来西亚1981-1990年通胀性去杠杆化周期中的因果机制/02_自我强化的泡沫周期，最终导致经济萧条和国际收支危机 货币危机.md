# 自我强化的泡沫周期，最终导致经济萧条和国际收支危机 货币危机

> 属于因果簇：[[马来西亚1981-1990年通胀性去杠杆化周期中的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务不断增加、经济增长强劲（泡沫阶段） |
| **DV（因变量）** | 自我强化的泡沫周期，最终导致经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 大量资本流入（平均占GDP的14%）填补经常账户赤字（占GDP的10%） → 债务累积至危机前峰值（占GDP的153%，其中外币债务占GDP的42%） → 经济增长强劲（增速7%），GDP缺口达3%峰值，实际汇率升值20% → 竞争力恶化，依赖外资，经济状况脆弱 → 外部冲击（大宗商品价格骤跌）触发资本流入逆转，导致萧条和货币危机 |
| **Lag（时滞）** | 泡沫阶段持续约3-4年（1981-1984年），随后进入萧条阶段（1984-1987年） |
| **Threshold（临界值）** | 债务占GDP比例达到153%，外币债务占GDP的42%，经常账户赤字占GDP的10% |
| **前提与约束（Premises）** | 资本流入以不可持续的方式支撑经济增长；外币计价债务占比高，使国家易受外资撤出影响；外部冲击（如大宗商品价格下跌）发生 |
| **Falsification（证伪条件）** | 如果资本流入减少但未导致货币危机或经济萧条，或债务水平高但未引发泡沫破裂，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同吹气球，不断充气（资本流入）使气球变大（经济繁荣），但气球壁变薄（债务脆弱），一旦针扎（外部冲击）就会爆炸（危机）。

### 🔗 文字版因果链

1. 大量资本流入（平均占GDP的14%）填补经常账户赤字（占GDP的10%）
2. 债务累积至危机前峰值（占GDP的153%，其中外币债务占GDP的42%）
3. 经济增长强劲（增速7%），GDP缺口达3%峰值，实际汇率升值20%
4. 竞争力恶化，依赖外资，经济状况脆弱
5. 外部冲击（大宗商品价格骤跌）触发资本流入逆转，导致萧条和货币危机
