# 马来西亚易受外部冲击伤害，外资流入减少导致货币大幅贬值、股价

> 属于因果簇：[[马来西亚1981-1990年通胀性去杠杆化周期中的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务水平（占GDP的153%，外币债务占GDP的42%） |
| **DV（因变量）** | 马来西亚易受外部冲击伤害，外资流入减少导致货币大幅贬值、股价下跌、失业率上升 |
| **Chain（传导链）** | 高债务水平使经济脆弱，对冲击敏感 → 大宗商品价格骤跌冲击出口，外资流入减少（降幅为GDP的11%） → 货币大幅贬值（实际汇率下降19%），股价下跌56%，失业率上升2% → 金融机构面临压力，央行消耗外汇储备（减少26%）但最终放弃捍卫货币 → 货币贬值导致外币偿债负担加重，债务占GDP比例增加43% |
| **Lag（时滞）** | 冲击发生后1-3年内（1984-1987年） |
| **Threshold（临界值）** | 债务占GDP比例超过150%，外币债务占GDP超过40%，外资流入降幅超过GDP的10% |
| **前提与约束（Premises）** | 债务以外币计价为主；外部冲击（大宗商品价格下跌）发生；央行外汇储备有限，无法持续干预 |
| **Falsification（证伪条件）** | 如果高债务水平下外资流入减少但货币未大幅贬值或债务比例未上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人背负高额外债（外币债务），当收入骤减（出口下降）时，债权人撤资（资本外流），导致货币贬值，债务负担更重，陷入恶性循环。

### 🔗 文字版因果链

1. 高债务水平使经济脆弱，对冲击敏感
2. 大宗商品价格骤跌冲击出口，外资流入减少（降幅为GDP的11%）
3. 货币大幅贬值（实际汇率下降19%），股价下跌56%，失业率上升2%
4. 金融机构面临压力，央行消耗外汇储备（减少26%）但最终放弃捍卫货币
5. 货币贬值导致外币偿债负担加重，债务占GDP比例增加43%
