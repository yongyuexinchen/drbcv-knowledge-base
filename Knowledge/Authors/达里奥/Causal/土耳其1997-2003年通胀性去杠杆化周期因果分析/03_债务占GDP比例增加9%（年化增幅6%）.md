# 债务占GDP比例增加9%（年化增幅6%）

> 属于因果簇：[[土耳其1997-2003年通胀性去杠杆化周期因果分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者放弃捍卫货币，允许货币贬值 |
| **DV（因变量）** | 债务占GDP比例增加9%（年化增幅6%） |
| **Chain（传导链）** | 货币贬值导致以外币计价的偿债负担加重 → 政府需要举借新债应对危机 → 财政赤字占GDP的比例达到11%的峰值 → 债务总额占GDP比例上升 |
| **Lag（时滞）** | 危机期间（2000-2001年） |
| **Threshold（临界值）** | 货币贬值导致外币债务负担加重；财政赤字占GDP的11% |
| **前提与约束（Premises）** | 大部分债务以外币计价；政府需要应对危机支出；央行外汇储备减少100% |
| **Falsification（证伪条件）** | 如果货币贬值但外币债务占比低或政府不举借新债，债务占GDP比例可能不会上升 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用外币贷款买房，本币贬值后，每月还款额突然变高，债务负担加重。

### 🔗 文字版因果链

1. 货币贬值导致以外币计价的偿债负担加重
2. 政府需要举借新债应对危机
3. 财政赤字占GDP的比例达到11%的峰值
4. 债务总额占GDP比例上升
