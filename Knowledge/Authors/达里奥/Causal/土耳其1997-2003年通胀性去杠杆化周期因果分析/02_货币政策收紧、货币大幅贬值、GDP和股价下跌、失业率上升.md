# 货币政策收紧、货币大幅贬值、GDP和股价下跌、失业率上升

> 属于因果簇：[[土耳其1997-2003年通胀性去杠杆化周期因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的10%） |
| **DV（因变量）** | 货币政策收紧、货币大幅贬值、GDP和股价下跌、失业率上升 |
| **Chain（传导链）** | 外资流入减少导致资本外流压力 → 央行提高短期利率（上调157%）以吸引资本 → 高利率抑制经济活动，GDP下跌10% → 货币贬值（实际汇率下降12%） → 进口成本上升，通胀高企（最高62%） → 企业盈利下降，股价下跌78%，失业率上升3% |
| **Lag（时滞）** | 约1-2年（2000-2001年） |
| **Threshold（临界值）** | 资本流入降幅为GDP的10%；短期利率上调157%；实际汇率下降12%；GDP跌幅10%；股价跌幅78% |
| **前提与约束（Premises）** | 存在政治动荡和暴力事件冲击；偿债总额达到GDP的30%；长期忽视对通胀的管控；货币疲软导致通胀螺旋 |
| **Falsification（证伪条件）** | 如果外资流入减少但未导致利率大幅上升或货币大幅贬值，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像抽掉泳池的水，水位下降，游泳者（经济）会挣扎，甚至溺水。

### 🔗 文字版因果链

1. 外资流入减少导致资本外流压力
2. 央行提高短期利率（上调157%）以吸引资本
3. 高利率抑制经济活动，GDP下跌10%
4. 货币贬值（实际汇率下降12%）
5. 进口成本上升，通胀高企（最高62%）
6. 企业盈利下降，股价下跌78%，失业率上升3%
