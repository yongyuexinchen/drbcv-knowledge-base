# 墨西哥1979-1991年通胀性去杠杆化周期因果分析

> **领域**：宏观经济学　|　**来源**：chapter_114.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入与债务增加（以外币计价） |
| **DV（因变量）** | 自我强化的泡沫周期及最终崩溃 |
| **Chain（传导链）** | 大量资本流入导致债务累积，尤其是外币债务 → 债务支撑了强劲的经济增长和资产价格上升 → 经济过热，实际汇率升值，竞争力下降 → 外部条件恶化（如油价下跌）触发资本流入逆转 → 资本外流导致货币贬值、利率上升、经济收缩，形成自我强化的萧条 |
| **Lag（时滞）** | 泡沫阶段持续约2-3年（1979-1981），随后进入萧条阶段（1981-1987） |
| **Threshold（临界值）** | 债务占GDP达65%，其中外币债务占GDP的26%；偿债总额占GDP的31% |
| **前提与约束（Premises）** | 经济高度依赖外国资本流入；存在经常账户赤字（占GDP的6%）；外部冲击（如油价下跌、拉美债务危机）发生 |
| **Falsification（证伪条件）** | 如果资本流入逆转后，经济仍能保持增长或债务水平未显著上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠借外债过度消费，一旦收入中断或利率上升，就会陷入债务螺旋，难以自拔

### 🔗 文字版因果链

1. 大量资本流入导致债务累积，尤其是外币债务
2. 债务支撑了强劲的经济增长和资产价格上升
3. 经济过热，实际汇率升值，竞争力下降
4. 外部条件恶化（如油价下跌）触发资本流入逆转
5. 资本外流导致货币贬值、利率上升、经济收缩，形成自我强化的萧条

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值与财政赤字 |
| **DV（因变量）** | 债务占GDP比例上升（去杠杆化失败） |
| **Chain（传导链）** | 货币贬值导致以外币计价的债务本币价值上升 → 政府为应对危机举借新债，财政赤字扩大 → 债务增速超过GDP增速，债务占GDP比例上升 |
| **Lag（时滞）** | 货币贬值和财政赤字在萧条阶段持续推高债务比例，年化增幅7% |
| **Threshold（临界值）** | 财政赤字占GDP达13%峰值；货币贬值导致债务比例累计增加41% |
| **前提与约束（Premises）** | 存在大量外币债务；政府缺乏财政空间，需借新债应对危机 |
| **Falsification（证伪条件）** | 如果货币贬值后债务比例未上升，或财政赤字未扩大，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用贬值货币还外债，债务越还越多，同时政府还要借钱度日，雪上加霜

### 🔗 文字版因果链

1. 货币贬值导致以外币计价的债务本币价值上升
2. 政府为应对危机举借新债，财政赤字扩大
3. 债务增速超过GDP增速，债务占GDP比例上升

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施紧缩政策与结构性改革（包括IMF援助） |
| **DV（因变量）** | 和谐去杠杆化与经济恢复 |
| **Chain（传导链）** | 紧缩政策减少进口，经常账户改善 → 结构性改革增强劳动力市场灵活性，提升竞争力 → 实际汇率贬值促进出口，经济逐步恢复 → 债务占GDP比例下降，名义收入增加 |
| **Lag（时滞）** | 调整阶段债务比例年化降幅8%，实际GDP用7年恢复至前峰值，股价用6年恢复 |
| **Threshold（临界值）** | 经常账户余额增幅为GDP的10%；实际汇率跌至-44%低点 |
| **前提与约束（Premises）** | 决策者允许货币贬值，不强行捍卫汇率；获得外部支持（IMF援助）；实施结构性改革 |
| **Falsification（证伪条件）** | 如果紧缩政策后经济未恢复或债务比例未下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像节食减肥，虽然痛苦但能恢复健康，而靠暴饮暴食（印钞）只会更糟

### 🔗 文字版因果链

1. 紧缩政策减少进口，经常账户改善
2. 结构性改革增强劳动力市场灵活性，提升竞争力
3. 实际汇率贬值促进出口，经济逐步恢复
4. 债务占GDP比例下降，名义收入增加
