# 汇率下跌和恶性通胀旋涡

> 属于因果簇：[[巴西1987-1995年恶性通胀性去杠杆化周期]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩措施未能带来必要调整 |
| **DV（因变量）** | 汇率下跌和恶性通胀旋涡 |
| **Chain（传导链）** | 紧缩措施不足以恢复国际收支平衡 → 资本外流持续，汇率下跌 → 汇率下跌推高进口价格和通胀预期 → 通胀率螺旋式上升（最高超5000%） → 货币体系崩溃，最终采用新货币 |
| **Lag（时滞）** | 危机后1-3年（通货再膨胀阶段） |
| **Threshold（临界值）** | 实际汇率跌至-16%，通胀率超过5000% |
| **前提与约束（Premises）** | 存在长期忽视通胀管控的历史；未积极管控金融机构和处理坏账；仅使用9个典型政策工具中的2个 |
| **Falsification（证伪条件）** | 若紧缩措施成功稳定汇率和通胀，或未出现恶性通胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用小火救大火，火势不减反增，最终需要彻底重建。

### 🔗 文字版因果链

1. 紧缩措施不足以恢复国际收支平衡
2. 资本外流持续，汇率下跌
3. 汇率下跌推高进口价格和通胀预期
4. 通胀率螺旋式上升（最高超5000%）
5. 货币体系崩溃，最终采用新货币
