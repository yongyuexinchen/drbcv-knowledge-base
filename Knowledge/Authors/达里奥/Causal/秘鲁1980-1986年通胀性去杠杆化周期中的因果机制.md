# 秘鲁1980-1986年通胀性去杠杆化周期中的因果机制

> **领域**：宏观经济学　|　**来源**：chapter_115.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高额外债（占GDP的107%，其中106%为外币计价） |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机（1982-1985年） |
| **Chain（传导链）** | 高额外债使秘鲁易受外部冲击 → 外部冲击（拉美债务危机）导致外资撤出 → 外资撤出引发国际收支危机和货币贬值 → 货币贬值加重偿债负担，财政赤字扩大 → 经济陷入自我强化的衰退，GDP和股价下跌 |
| **Lag（时滞）** | 危机前积累债务，冲击后1-2年内爆发危机 |
| **Threshold（临界值）** | 债务总额占GDP的107%，经常账户赤字占GDP的4% |
| **前提与约束（Premises）** | 债务以外币计价为主；依赖持续的外资流入；外部经济环境恶化（拉美债务危机） |
| **Falsification（证伪条件）** | 如果秘鲁在外部冲击下仍能维持货币稳定、GDP增长，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭背负高额外债，一旦收入来源中断，就会陷入财务危机。

### 🔗 文字版因果链

1. 高额外债使秘鲁易受外部冲击
2. 外部冲击（拉美债务危机）导致外资撤出
3. 外资撤出引发国际收支危机和货币贬值
4. 货币贬值加重偿债负担，财政赤字扩大
5. 经济陷入自我强化的衰退，GDP和股价下跌

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（贬值53%） |
| **DV（因变量）** | 债务占GDP比例增加163%（年化42%） |
| **Chain（传导链）** | 货币贬值导致以外币计价的债务本币价值上升 → 政府为应对危机举借新债，财政赤字扩大 → 债务增速远超GDP增速，导致债务占GDP比例大幅上升 |
| **Lag（时滞）** | 货币贬值后1-2年内债务比例显著上升 |
| **Threshold（临界值）** | 货币贬值53%，财政赤字占GDP峰值5% |
| **前提与约束（Premises）** | 债务以外币计价为主；政府需要通过举债应对危机 |
| **Falsification（证伪条件）** | 如果货币贬值后债务占GDP比例没有上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像你借了美元，本币贬值后，你需要还更多本币，债务负担加重。

### 🔗 文字版因果链

1. 货币贬值导致以外币计价的债务本币价值上升
2. 政府为应对危机举借新债，财政赤字扩大
3. 债务增速远超GDP增速，导致债务占GDP比例大幅上升

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施紧缩政策、管控金融机构、IMF援助和结构性改革 |
| **DV（因变量）** | 债务占GDP比例下降88%，经济恢复增长 |
| **Chain（传导链）** | 紧缩政策减少进口，经常账户改善 → 管控金融机构和坏账处理稳定金融体系 → IMF援助提供外部支持 → 结构性改革增强劳动力市场灵活性 → 名义收入增加，债务比例下降，经济恢复 |
| **Lag（时滞）** | 政策实施后4年GDP恢复峰值，6年股价恢复 |
| **Threshold（临界值）** | 经常账户余额增幅为GDP的13%，实际汇率跌至-46% |
| **前提与约束（Premises）** | 决策者实施足够的紧缩政策；积极管控金融机构；获得IMF援助 |
| **Falsification（证伪条件）** | 如果政策实施后债务比例没有下降或经济持续衰退，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像病人通过节食、治疗和外部援助，逐渐恢复健康。

### 🔗 文字版因果链

1. 紧缩政策减少进口，经常账户改善
2. 管控金融机构和坏账处理稳定金融体系
3. IMF援助提供外部支持
4. 结构性改革增强劳动力市场灵活性
5. 名义收入增加，债务比例下降，经济恢复
