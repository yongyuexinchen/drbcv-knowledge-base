# 意大利政局显著影响，民粹主义领导人上台

> 属于因果簇：[[意大利2005-2017年通缩性去杠杆化周期因果分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期经济萧条和痛苦去杠杆化 |
| **DV（因变量）** | 意大利政局显著影响，民粹主义领导人上台 |
| **Chain（传导链）** | 经济萧条导致失业率上升（上升6%） → 民众对传统政党不满 → 民粹主义领导人获得支持 → 朱塞佩·孔特上台 |
| **Lag（时滞）** | 2008-2018年，约10年 |
| **Threshold（临界值）** | 失业率上升6%，GDP下降9% |
| **前提与约束（Premises）** | 经济萧条持续较长时间（2008-2015）；实际GDP至今未达到之前峰值；以美元计算的股价尚未完全恢复 |
| **Falsification（证伪条件）** | 如果经济萧条但政局稳定，或民粹主义领导人未上台，则此因果链不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同久病不愈的病人会寻求偏方：经济长期不振，民众就会转向激进的政治方案

### 🔗 文字版因果链

1. 经济萧条导致失业率上升（上升6%）
2. 民众对传统政党不满
3. 民粹主义领导人获得支持
4. 朱塞佩·孔特上台
