# GDP、股价和房价自我强化式下跌

> 属于因果簇：[[意大利2005-2017年通缩性去杠杆化周期因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（投资组合流入降幅为GDP的14%） |
| **DV（因变量）** | GDP、股价和房价自我强化式下跌 |
| **Chain（传导链）** | 外资流入减少导致资金紧张 → 资金紧张引发资产价格下跌 → 资产价格下跌导致经济收缩（GDP下降） → 经济收缩进一步减少外资信心，形成自我强化下跌 |
| **Lag（时滞）** | 2008-2015年，持续约7年 |
| **Threshold（临界值）** | 外资流入减少幅度为GDP的14% |
| **前提与约束（Premises）** | 危机前偿债总额达到GDP的58%，使意大利容易受到冲击；冲击来自欧洲债务危机；意大利依赖外资流入 |
| **Falsification（证伪条件）** | 如果外资流入减少但GDP、股价和房价未出现同步下跌，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同抽掉地基的沙子：外资是支撑大厦的沙子，沙子流失，大厦必然坍塌

### 🔗 文字版因果链

1. 外资流入减少导致资金紧张
2. 资金紧张引发资产价格下跌
3. 资产价格下跌导致经济收缩（GDP下降）
4. 经济收缩进一步减少外资信心，形成自我强化下跌
