# 意大利2005-2017年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：意大利2005-2017年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加且经济增长强劲 → 自我强化的泡沫周期
- 外资流入减少（投资组合流入降幅为GDP的14%） → GDP、股价和房价自我强化式下跌
- 欧洲央行提供充足的经济刺激（M0增幅达GDP的16%，利率降至0%） → 和谐的去杠杆化（债务占GDP比例下降36%）
- 长期经济萧条和痛苦去杠杆化 → 意大利政局显著影响，民粹主义领导人上台
