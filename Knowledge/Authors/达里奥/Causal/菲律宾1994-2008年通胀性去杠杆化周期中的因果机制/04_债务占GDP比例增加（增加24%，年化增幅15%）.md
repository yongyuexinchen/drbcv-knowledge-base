# 债务占GDP比例增加（增加24%，年化增幅15%）

> 属于因果簇：[[菲律宾1994-2008年通胀性去杠杆化周期中的因果机制]]（第4块/8块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（导致以外币计价的偿债负担加重） |
| **DV（因变量）** | 债务占GDP比例增加（增加24%，年化增幅15%） |
| **Chain（传导链）** | 货币贬值 → 以外币计价的债务折算成本币后价值上升 → 偿债负担加重 → 债务占GDP比例增加 |
| **Lag（时滞）** | 萧条阶段（1997-1998年） |
| **Threshold（临界值）** | 债务占GDP比例增加24%，年化增幅15% |
| **前提与约束（Premises）** | 很大一部分债务以外币计价（占GDP的51%）；货币贬值幅度大（实际汇率下降29%）；需要去杠杆化但货币贬值抵消了部分努力 |
| **Falsification（证伪条件）** | 如果货币贬值但债务占GDP比例未增加，或增加幅度远低于24%，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像你借了美元，本币贬值后，你需要还更多本币，债务负担加重

### 🔗 文字版因果链

1. 货币贬值
2. 以外币计价的债务折算成本币后价值上升
3. 偿债负担加重
4. 债务占GDP比例增加
