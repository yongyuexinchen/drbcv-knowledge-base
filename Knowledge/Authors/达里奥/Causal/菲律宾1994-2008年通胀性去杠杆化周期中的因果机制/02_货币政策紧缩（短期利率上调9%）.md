# 货币政策紧缩（短期利率上调9%）

> 属于因果簇：[[菲律宾1994-2008年通胀性去杠杆化周期中的因果机制]]（第2块/8块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的19%） |
| **DV（因变量）** | 货币政策紧缩（短期利率上调9%） |
| **Chain（传导链）** | 外资流入减少 → 国际收支压力增大 → 央行被迫收紧货币政策以稳定汇率 → 短期利率上调 |
| **Lag（时滞）** | 危机期间（1997-1998年） |
| **Threshold（临界值）** | 资本流入降幅为GDP的19% |
| **前提与约束（Premises）** | 菲律宾依赖外国资金流入；偿债总额达到GDP的25%，容易受到冲击；面临1997年亚洲金融危机的外部冲击 |
| **Falsification（证伪条件）** | 如果外资流入减少但利率未上调，或利率上调幅度远低于9%，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人突然失去收入来源，不得不削减开支并提高储蓄，以应对财务紧张

### 🔗 文字版因果链

1. 外资流入减少
2. 国际收支压力增大
3. 央行被迫收紧货币政策以稳定汇率
4. 短期利率上调
