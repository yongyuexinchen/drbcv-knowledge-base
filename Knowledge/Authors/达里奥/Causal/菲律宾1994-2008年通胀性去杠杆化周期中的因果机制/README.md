# 菲律宾1994-2008年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：8 个子因果卡。父卡文件：菲律宾1994-2008年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 资本流入强劲且货币回报丰厚（不可持续发展） → 债务达到危机前峰值（占GDP的95%，升幅为GDP的12%）
- 外资流入减少（资本流入降幅为GDP的19%） → 货币政策紧缩（短期利率上调9%）
- 货币大幅贬值（实际汇率下降29%） → 通胀率上升（最高达到10%）
- 货币贬值（导致以外币计价的偿债负担加重） → 债务占GDP比例增加（增加24%，年化增幅15%）
- 放弃钉住汇率制度，允许货币浮动 → 决策者设定利率的灵活性增大
- 实施紧缩政策、管控金融机构和处理坏账、IMF援助、结构性改革 → 债务占GDP比例下降（下降51%，年化降幅5%）
- 货币大幅贬值（实际汇率跌至-24%的低点） → 重新获得竞争力
- 危机对菲律宾政局造成显著影响 → 约瑟夫·埃斯特拉达上台（民粹主义领导人）
