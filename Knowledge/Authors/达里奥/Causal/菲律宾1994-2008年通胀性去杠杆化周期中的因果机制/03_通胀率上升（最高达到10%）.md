# 通胀率上升（最高达到10%）

> 属于因果簇：[[菲律宾1994-2008年通胀性去杠杆化周期中的因果机制]]（第3块/8块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率下降29%） |
| **DV（因变量）** | 通胀率上升（最高达到10%） |
| **Chain（传导链）** | 货币大幅贬值 → 进口商品价格上升 → 国内物价水平上升 → 通胀率上升 |
| **Lag（时滞）** | 萧条阶段（1997-1998年） |
| **Threshold（临界值）** | 实际汇率下降29%，通胀率最高达10% |
| **前提与约束（Premises）** | 货币疲软导致进口成本增加；菲律宾存在约1/4导致更大规模螺旋式通胀的典型风险因素；央行的外汇储备较少 |
| **Falsification（证伪条件）** | 如果货币大幅贬值但通胀率未上升，或通胀率远低于10%，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像本币贬值后，进口商品变贵，超市里的物价随之上涨

### 🔗 文字版因果链

1. 货币大幅贬值
2. 进口商品价格上升
3. 国内物价水平上升
4. 通胀率上升
