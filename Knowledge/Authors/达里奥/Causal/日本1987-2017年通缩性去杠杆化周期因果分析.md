# 日本1987-2017年通缩性去杠杆化周期因果分析

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、经济增长强劲、资产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加刺激经济增长 → 经济增长提高资产回报 → 高资产回报鼓励更多借债 → 更多借债进一步推动经济增长和资产价格，形成正反馈循环 |
| **Lag（时滞）** | 即时反馈，但泡沫积累需数年（1987-1989年） |
| **Threshold（临界值）** | 债务占GDP比例达到307%，增幅为GDP的24% |
| **前提与约束（Premises）** | 债务以日元计价，债权人为日本人；日本为净债权国，汇率坚挺；投资流入较少（平均约占GDP的1%） |
| **Falsification（证伪条件）** | 如果债务增加但经济增长和资产回报没有相应提升，或资产回报未鼓励更多借债，则泡沫周期不成立 |
| **Confidence（确信度）** | well-established |
