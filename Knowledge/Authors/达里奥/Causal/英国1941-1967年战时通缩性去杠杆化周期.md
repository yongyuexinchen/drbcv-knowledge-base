# 英国1941-1967年战时通缩性去杠杆化周期

> **领域**：宏观经济学　|　**来源**：chapter_93.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 二战期间英国大量借款以填补巨额财政赤字 |
| **DV（因变量）** | 英国债务急剧增加，债务占GDP比例上升 |
| **Chain（传导链）** | 战争导致财政赤字扩大，政府大量借款 → 债务以英镑计价，债权人为英国人 → 战争相关开支支撑经济增长，但债务累积 → 战后债务占GDP比例增加102% |
| **Lag（时滞）** | 战争期间至战后初期（约1941-1947年） |
| **Threshold（临界值）** | 财政赤字占GDP比例峰值达31% |
| **前提与约束（Premises）** | 债务以本币计价，债权人为本国居民；英国为战胜国，战后衰退程度较轻；战争期间经济统计不反映典型经济关联性 |
| **Falsification（证伪条件）** | 若战后债务占GDP比例未显著上升，或财政赤字未达峰值，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同家庭因战争或重大事件大量借贷，战后收入下降但债务负担沉重，需长期偿还

### 🔗 文字版因果链

1. 战争导致财政赤字扩大，政府大量借款
2. 债务以英镑计价，债权人为英国人
3. 战争相关开支支撑经济增长，但债务累积
4. 战后债务占GDP比例增加102%

| **Threshold（临界值）** | GDP跌幅达15% |

| **Falsification（证伪条件）** | 若战后GDP未出现持续下跌，或跌幅低于15%，则断言不成立 |

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策与财政政策） |
| **DV（因变量）** | 英国从痛苦的去杠杆化转变为和谐的去杠杆化 |
| **Chain（传导链）** | 英镑对黄金贬值30%，M0实际水平下降 → 利率降至1%，实际汇率平均为-10% → 允许通胀率高企（平均4%），推高名义经济增长率 → 名义经济增长率（7%）远高于名义利率（2%） → 债务占GDP比例下降139%，失业率保持平稳 |
| **Lag（时滞）** | 1947年开始，实际GDP用10年时间达到之前峰值 |
| **Threshold（临界值）** | 名义经济增长率>名义利率（7% vs 2%），通胀率平均4% |
| **前提与约束（Premises）** | 决策者有能力实施货币贬值和财政刺激；通胀率可接受，不引发恶性通胀；债务以本币计价，便于通过通胀稀释 |
| **Falsification（证伪条件）** | 若刺激政策未能降低债务占GDP比例，或失业率上升，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同负债者通过提高收入（通胀）和降低利息（低利率）来减轻债务负担，而非紧缩削减支出

### 🔗 文字版因果链

1. 英镑对黄金贬值30%，M0实际水平下降
2. 利率降至1%，实际汇率平均为-10%
3. 允许通胀率高企（平均4%），推高名义经济增长率
4. 名义经济增长率（7%）远高于名义利率（2%）
5. 债务占GDP比例下降139%，失业率保持平稳
