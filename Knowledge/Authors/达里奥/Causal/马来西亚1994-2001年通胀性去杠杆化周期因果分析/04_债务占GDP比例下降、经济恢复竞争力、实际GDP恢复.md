# 债务占GDP比例下降、经济恢复竞争力、实际GDP恢复

> 属于因果簇：[[马来西亚1994-2001年通胀性去杠杆化周期因果分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策、积极管控金融机构和处理坏账 |
| **DV（因变量）** | 债务占GDP比例下降、经济恢复竞争力、实际GDP恢复 |
| **Chain（传导链）** | 决策者放弃捍卫货币，允许货币贬值，提高出口竞争力 → 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的19%） → 积极管控金融机构（银行国有化、提供流动性、购买问题资产），使用9个政策工具中的7个 → 实际经济增速提升，推动名义收入增加 → 债务占GDP比例下降（41%），实际GDP在2年内恢复至峰值 |
| **Lag（时滞）** | 调整期（1998-2001年） |
| **Threshold（临界值）** | 经常账户余额增幅占GDP 19%，债务占GDP比例下降41%（年化降幅18%），实际汇率跌至-9%低点 |
| **前提与约束（Premises）** | 决策者采取积极干预措施（而非放任不管）；外部环境允许出口增长；金融机构能够被重组和国有化 |
| **Falsification（证伪条件）** | 如果实施紧缩和积极管控后，债务比例没有下降或经济没有恢复，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像清理堵塞的管道（坏账），虽然要花力气（紧缩），但疏通后水流（经济）才能恢复顺畅。

### 🔗 文字版因果链

1. 决策者放弃捍卫货币，允许货币贬值，提高出口竞争力
2. 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的19%）
3. 积极管控金融机构（银行国有化、提供流动性、购买问题资产），使用9个政策工具中的7个
4. 实际经济增速提升，推动名义收入增加
5. 债务占GDP比例下降（41%），实际GDP在2年内恢复至峰值
