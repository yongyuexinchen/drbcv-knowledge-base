# 马来西亚1994-2001年通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：马来西亚1994-2001年通胀性去杠杆化周期因果分析.md

## 总体因果图

- 外部压力下允许货币浮动 → 决策者设定利率的更大灵活性
- 大量资本流入、债务增加、经济增长强劲（泡沫阶段） → 自我强化的泡沫周期和不可持续的发展局势
- 外资流入减少（资本流入降幅为GDP的5%） → 货币政策紧缩、货币大幅贬值、GDP和股价下跌（自我强化式萧条
- 决策者实施紧缩政策、积极管控金融机构和处理坏账 → 债务占GDP比例下降、经济恢复竞争力、实际GDP恢复
