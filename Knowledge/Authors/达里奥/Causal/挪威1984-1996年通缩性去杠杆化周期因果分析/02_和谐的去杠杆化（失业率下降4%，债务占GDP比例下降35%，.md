# 和谐的去杠杆化（失业率下降4%，债务占GDP比例下降35%，

> 属于因果簇：[[挪威1984-1996年通缩性去杠杆化周期因果分析]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（M0增幅达GDP的2%，利率降至4%，银行国有化，提供流动性，结构性改革） |
| **DV（因变量）** | 和谐的去杠杆化（失业率下降4%，债务占GDP比例下降35%，年化降幅7%，实际GDP5年恢复峰值） |
| **Chain（传导链）** | 决策者提供货币和财政刺激，增加流动性，降低利率 → 银行国有化和流动性支持稳定金融体系，处理坏账 → 结构性改革增强劳动力市场灵活性，促进经济增长 → 名义经济增长率接近名义利率（经济增长率6.1%，利率5.5%），收入增加，债务与收入比率下降 |
| **Lag（时滞）** | 刺激措施从1992年开始，去杠杆化效果在1992-1996年间显现，约1-2年 |
| **Threshold（临界值）** | M0增幅达GDP的2%，利率降至4%，实际汇率平均为3%，使用9个典型政策工具中的4个 |
| **前提与约束（Premises）** | 决策者积极管控金融机构和处理坏账；结构性改革旨在增强劳动力市场灵活性；经济刺激足够充足，能够将痛苦的去杠杆化转变为和谐的去杠杆化 |
| **Falsification（证伪条件）** | 如果刺激措施未能使债务占GDP比例下降，或失业率未下降，或实际GDP未恢复，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人负债累累后，通过增加收入（经济刺激）和调整支出结构（改革），逐步还清债务，而不是被迫变卖资产（痛苦的去杠杆化）

### 🔗 文字版因果链

1. 决策者提供货币和财政刺激，增加流动性，降低利率
2. 银行国有化和流动性支持稳定金融体系，处理坏账
3. 结构性改革增强劳动力市场灵活性，促进经济增长
4. 名义经济增长率接近名义利率（经济增长率6.1%，利率5.5%），收入增加，债务与收入比率下降
