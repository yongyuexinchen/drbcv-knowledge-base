# 货币政策收紧、货币贬值、GDP和股价下跌（GDP跌14%，股

> 属于因果簇：[[泰国1993-2004年债务危机因果分析]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的34%） |
| **DV（因变量）** | 货币政策收紧、货币贬值、GDP和股价下跌（GDP跌14%，股价跌87%） |
| **Chain（传导链）** | 外资流入减少，导致国际收支压力 → 央行提高短期利率（上调11%）以维持货币稳定 → 实际汇率下降19%，货币大幅贬值 → 企业/银行因负债过高遭遇亏损潮，GDP和股价陷入自我强化式下跌 |
| **Lag（时滞）** | 约1-2年（1996-1998年） |
| **Threshold（临界值）** | 资本流入降幅为GDP的34%，偿债总额占GDP的49% |
| **前提与约束（Premises）** | 存在大量外币计价债务；央行外汇储备有限（减少100%）；企业/银行负债过高 |
| **Falsification（证伪条件）** | 如果外资流入减少但未导致货币大幅贬值或GDP大幅下跌，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一家公司突然失去主要客户，收入骤减，不得不借高利贷维持运营，最终资不抵债。

### 🔗 文字版因果链

1. 外资流入减少，导致国际收支压力
2. 央行提高短期利率（上调11%）以维持货币稳定
3. 实际汇率下降19%，货币大幅贬值
4. 企业/银行因负债过高遭遇亏损潮，GDP和股价陷入自我强化式下跌
