# 货币政策收紧、货币大幅贬值、GDP和股价下跌

> 属于因果簇：[[印度尼西亚1994-2012年通胀性去杠杆化周期因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的13%） |
| **DV（因变量）** | 货币政策收紧、货币大幅贬值、GDP和股价下跌 |
| **Chain（传导链）** | 外资流入减少，资本外流压力增大 → 央行提高短期利率（上调43%）以吸引资本，但收紧金融环境 → 货币贬值（实际汇率下降110%），导致通胀上升 → 高债务水平使经济脆弱，GDP和股价陷入自我强化式下跌 → 金融机构面临压力，央行动用外汇储备（减少23%）但最终放弃捍卫货币 |
| **Lag（时滞）** | 约1年（1997-1998年萧条阶段） |
| **Threshold（临界值）** | 资本流入降幅为GDP的13%；短期利率上调43%；实际汇率下降110%；GDP跌幅14%，股价跌幅89%；通胀率最高达59% |
| **前提与约束（Premises）** | 高债务水平，尤其是外币计价债务（占GDP的51%）；外部冲击（1997年亚洲金融危机）；央行外汇储备有限，无法长期维持汇率 |
| **Falsification（证伪条件）** | 若外资流入减少但未导致货币大幅贬值或GDP大幅下跌，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人依赖外部输血，一旦输血停止，身体迅速衰竭，即使打强心针（加息）也只能暂时维持，最终仍会崩溃。

### 🔗 文字版因果链

1. 外资流入减少，资本外流压力增大
2. 央行提高短期利率（上调43%）以吸引资本，但收紧金融环境
3. 货币贬值（实际汇率下降110%），导致通胀上升
4. 高债务水平使经济脆弱，GDP和股价陷入自我强化式下跌
5. 金融机构面临压力，央行动用外汇储备（减少23%）但最终放弃捍卫货币
