# 和谐的去杠杆化（经济复苏，债务占GDP比例下降）

> 属于因果簇：[[芬兰1987-2001年通缩性去杠杆化周期中的因果机制]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策宽松、财政刺激、积极处理坏账） |
| **DV（因变量）** | 和谐的去杠杆化（经济复苏，债务占GDP比例下降） |
| **Chain（传导链）** | 决策者提供流动性，将银行国有化，直接购买不良资产 → M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10% → 名义经济增长率（6%）高于名义利率（4%） → 收入增加，债务占GDP比例下降72% → 失业率下降6%，实际GDP在7年内恢复至峰值，股价5年内恢复 |
| **Lag（时滞）** | 约1-2年（1993年开始刺激，随后几年内效果显现） |
| **Threshold（临界值）** | M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10%，使用9个政策工具中的7个 |
| **前提与约束（Premises）** | 决策者积极管控金融机构和处理坏账；刺激政策足够大，能推动名义经济增长率高于名义利率；政策实施及时，避免萧条持续过久 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义增长率仍低于名义利率，或债务占GDP比例未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给一个重病患者输血和手术，虽然痛苦但能恢复健康，债务负担在收入增长中逐渐减轻

### 🔗 文字版因果链

1. 决策者提供流动性，将银行国有化，直接购买不良资产
2. M0增幅达到GDP的7%，利率降至3%，实际汇率平均为-10%
3. 名义经济增长率（6%）高于名义利率（4%）
4. 收入增加，债务占GDP比例下降72%
5. 失业率下降6%，实际GDP在7年内恢复至峰值，股价5年内恢复
