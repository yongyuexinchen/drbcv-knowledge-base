# 自我强化的经济萧条和痛苦的去杠杆化

> 属于因果簇：[[爱尔兰2005-2017年通缩性去杠杆化周期因果分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 形势逆转（外部冲击：欧洲债务危机） |
| **DV（因变量）** | 自我强化的经济萧条和痛苦的去杠杆化 |
| **Chain（传导链）** | 外部冲击导致偿债压力增大 → GDP、股价和房价下跌 → 资产价格下跌导致财富缩水和信贷收缩 → 信贷收缩进一步压低经济活动和资产价格，形成负反馈循环 → 失业率上升，金融机构压力增大 |
| **Lag（时滞）** | 2008-2013年（约5年） |
| **Threshold（临界值）** | 偿债总额达到GDP的77%，GDP跌幅9%，股价跌幅73%，房价跌幅53%，失业率上升9% |
| **前提与约束（Premises）** | 危机前债务水平高；外部冲击（欧洲债务危机）发生；金融机构脆弱 |
| **Falsification（证伪条件）** | 如果外部冲击没有发生，或债务水平较低，或金融机构抗风险能力强，则可能不会出现如此严重的萧条 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像雪崩：积雪（债务）积累到临界点，一声巨响（外部冲击）引发大规模崩塌

### 🔗 文字版因果链

1. 外部冲击导致偿债压力增大
2. GDP、股价和房价下跌
3. 资产价格下跌导致财富缩水和信贷收缩
4. 信贷收缩进一步压低经济活动和资产价格，形成负反馈循环
5. 失业率上升，金融机构压力增大
