# 自我强化的泡沫周期

> 属于因果簇：[[爱尔兰2005-2017年通缩性去杠杆化周期因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、经济增长强劲、房地产市场回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加推动经济增长和房地产回报 → 经济增长和房地产回报吸引更多投资和借贷 → 更多借贷进一步推高债务和资产价格，形成正反馈循环 |
| **Lag（时滞）** | 2005-2008年（约3年） |
| **Threshold（临界值）** | 债务占GDP比例达到271%，增幅为GDP的94% |
| **前提与约束（Premises）** | 债务以欧元计价，爱尔兰对其没有控制权；很大一部分债务的债权人并非爱尔兰人；投资流入强劲，平均约占GDP的95%；经常账户赤字占GDP的5% |
| **Falsification（证伪条件）** | 如果债务增加但经济增长和房地产回报没有相应提升，或者资本流入没有持续，则泡沫周期不会形成 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球：雪球越大，滚得越快，但一旦遇到障碍或温度升高，雪球就会崩塌

### 🔗 文字版因果链

1. 债务增加推动经济增长和房地产回报
2. 经济增长和房地产回报吸引更多投资和借贷
3. 更多借贷进一步推高债务和资产价格，形成正反馈循环
