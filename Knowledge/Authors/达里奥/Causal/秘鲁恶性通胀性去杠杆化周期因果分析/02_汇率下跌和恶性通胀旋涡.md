# 汇率下跌和恶性通胀旋涡

> 属于因果簇：[[秘鲁恶性通胀性去杠杆化周期因果分析]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩措施未能带来必要的调整 |
| **DV（因变量）** | 汇率下跌和恶性通胀旋涡 |
| **Chain（传导链）** | 紧缩措施未能实现经济调整 → 决策者选择印钞弥补资金外流 → 印钞导致通胀率螺旋式上升 → 实际汇率触底至-115%，通胀率超过10000% |
| **Lag（时滞）** | 约1-3年（1987-1990年） |
| **Threshold（临界值）** | 实际短期利率较低，通胀率超过10000% |
| **前提与约束（Premises）** | 存在大多数导致通胀率螺旋式上升的典型风险因素；实际短期利率较低；决策者优先选择印钞而非紧缩 |
| **Falsification（证伪条件）** | 如果决策者采取足够紧缩措施或获得外部支持，可能避免恶性通胀 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个病人拒绝手术（紧缩），只吃止痛药（印钞），最终病情恶化

### 🔗 文字版因果链

1. 紧缩措施未能实现经济调整
2. 决策者选择印钞弥补资金外流
3. 印钞导致通胀率螺旋式上升
4. 实际汇率触底至-115%，通胀率超过10000%
