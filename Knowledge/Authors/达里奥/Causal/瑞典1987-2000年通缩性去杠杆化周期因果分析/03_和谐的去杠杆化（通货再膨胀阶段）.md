# 和谐的去杠杆化（通货再膨胀阶段）

> 属于因果簇：[[瑞典1987-2000年通缩性去杠杆化周期因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（货币政策、财政政策、结构性改革） |
| **DV（因变量）** | 和谐的去杠杆化（通货再膨胀阶段） |
| **Chain（传导链）** | 货币政策宽松：M0增幅达GDP的5%，利率降至3% → 积极管控金融机构：银行国有化、提供流动性、直接购买不良资产 → 结构性改革增强劳动力市场灵活性 → 名义经济增长率高于名义利率 → 收入增加，债务与收入比率下降 |
| **Lag（时滞）** | 1993年开始，实际GDP用3年恢复，股价用4年恢复 |
| **Threshold（临界值）** | 名义经济增长率平均5%，主权长期利率降至4%，债务占GDP比例下降28%（年化降幅4%） |
| **前提与约束（Premises）** | 决策者使用9个典型政策工具中的7个；政策刺激力度足够大；金融机构得到有效处理 |
| **Falsification（证伪条件）** | 如果刺激政策不足或名义增长率低于利率，则去杠杆化仍将痛苦，债务比率不会下降 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像给病人输血：刺激政策是输血，让病人恢复造血功能，而不是一味放血

### 🔗 文字版因果链

1. 货币政策宽松：M0增幅达GDP的5%，利率降至3%
2. 积极管控金融机构：银行国有化、提供流动性、直接购买不良资产
3. 结构性改革增强劳动力市场灵活性
4. 名义经济增长率高于名义利率
5. 收入增加，债务与收入比率下降
