### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 和谐的去杠杆化政策 |
| **DV（因变量）** | 实际GDP恢复至之前峰值（用时5年） |
| **Chain（传导链）** | 经济刺激推动经济增长 → 债务负担减轻，企业和家庭恢复借贷和消费 → 投资和消费增加，推动GDP增长 → 经过5年，实际GDP达到危机前峰值 |
| **Lag（时滞）** | 5年（2009-2014年） |
| **Threshold（临界值）** | 实际GDP用5年时间达到之前的峰值 |
| **前提与约束（Premises）** | 政策持续有效；外部环境不再恶化 |
| **Falsification（证伪条件）** | 如果实际GDP在5年内未恢复至峰值，则政策效果不充分 |
| **Confidence（确信度）** | well-established |
