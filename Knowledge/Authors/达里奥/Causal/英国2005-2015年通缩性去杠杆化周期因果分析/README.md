# 英国2005-2015年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：7 个子因果卡。父卡文件：英国2005-2015年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加与经济增长强劲 → 自我强化的泡沫周期
- 货币和信贷环境收紧及相关国家经济状况恶化 → 不可持续的发展局势
- 2008年全球金融危机冲击 → 自我强化的经济萧条和痛苦的去杠杆化
- 举借新债以支付利息和实际收入减少 → 债务占GDP比例增加34%（年化增幅24%）
- 决策者提供充足的经济刺激 → 将痛苦的去杠杆化转变为和谐的去杠杆化
- 名义经济增长率高于名义利率 → 债务占GDP比例下降73%（年化降幅12%）
- 和谐的去杠杆化政策 → 实际GDP恢复至之前峰值（用时5年）
