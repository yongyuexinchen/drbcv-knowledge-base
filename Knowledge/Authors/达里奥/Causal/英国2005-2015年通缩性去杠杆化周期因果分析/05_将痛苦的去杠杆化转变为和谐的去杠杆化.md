> 属于因果簇：[[英国2005-2015年通缩性去杠杆化周期因果分析]]（第5块/7块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激 |
| **DV（因变量）** | 将痛苦的去杠杆化转变为和谐的去杠杆化 |
| **Chain（传导链）** | 货币政策方面，M0增幅达GDP的10%，利率降至0%，实际汇率平均为-5% → 积极管控金融机构和处理坏账，使用9个典型政策工具中的6个 → 银行国有化、提供流动性、直接购买不良资产 → 实施结构性改革，增强劳动力市场灵活性 → 名义经济增长率高于名义利率，经济增长率平均4%，主权长期利率降至1% |
| **Lag（时滞）** | 2009年开始，持续数年 |
| **Threshold（临界值）** | M0增幅达GDP的10%，利率降至0%，实际汇率平均-5% |
| **前提与约束（Premises）** | 决策者有能力实施大规模刺激；使用至少6个政策工具；结构性改革成功 |
| **Falsification（证伪条件）** | 如果经济刺激未能使名义增长率高于名义利率，则无法实现和谐去杠杆化 |
| **Confidence（确信度）** | well-established |
