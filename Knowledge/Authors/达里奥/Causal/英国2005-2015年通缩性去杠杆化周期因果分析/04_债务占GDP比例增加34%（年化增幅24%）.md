# 债务占GDP比例增加34%（年化增幅24%）

> 属于因果簇：[[英国2005-2015年通缩性去杠杆化周期因果分析]]（第4块/7块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 举借新债以支付利息和实际收入减少 |
| **DV（因变量）** | 债务占GDP比例增加34%（年化增幅24%） |
| **Chain（传导链）** | 经济萧条导致实际收入减少，GDP下降 → 偿债负担沉重，需要举借新债支付利息 → 新债增加债务总额，而GDP下降，导致债务占GDP比例上升 |
| **Lag（时滞）** | 2008-2009年 |
| **Threshold（临界值）** | 债务占GDP比例增加34%，年化增幅24% |
| **前提与约束（Premises）** | 处于去杠杆化过程中；经济萧条，收入减少 |
| **Falsification（证伪条件）** | 如果债务总额下降或GDP增长，则债务占GDP比例不会增加 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像在流沙中挣扎：越挣扎陷得越深，债务越还越多

### 🔗 文字版因果链

1. 经济萧条导致实际收入减少，GDP下降
2. 偿债负担沉重，需要举借新债支付利息
3. 新债增加债务总额，而GDP下降，导致债务占GDP比例上升
