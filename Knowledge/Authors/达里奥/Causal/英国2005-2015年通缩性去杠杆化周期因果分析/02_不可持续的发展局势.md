# 不可持续的发展局势

> 属于因果簇：[[英国2005-2015年通缩性去杠杆化周期因果分析]]（第2块/7块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币和信贷环境收紧及相关国家经济状况恶化 |
| **DV（因变量）** | 不可持续的发展局势 |
| **Chain（传导链）** | 货币和信贷环境收紧，提高借贷成本，抑制债务增长 → 相关国家经济状况恶化，减少外部需求，影响出口 → 债务和资金增加的趋势逆转，导致经济扩张不可持续 |
| **Lag（时滞）** | 短期（2008年危机前） |
| **Threshold（临界值）** | 偿债总额达到GDP的82% |
| **前提与约束（Premises）** | 英国面临2008年全球金融危机冲击；债务和资金增加已形成泡沫 |
| **Falsification（证伪条件）** | 如果货币和信贷环境收紧但经济仍能维持增长，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像吹气球：吹得越大，越接近爆裂点，外部压力一触即发

### 🔗 文字版因果链

1. 货币和信贷环境收紧，提高借贷成本，抑制债务增长
2. 相关国家经济状况恶化，减少外部需求，影响出口
3. 债务和资金增加的趋势逆转，导致经济扩张不可持续
