# 自我强化的泡沫周期

> 属于因果簇：[[荷兰通缩性去杠杆化周期中的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、股市回报丰厚、经济增长强劲 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加和资金流入支撑经济增长 → 经济增长和资产回报率高鼓励更多借债 → 借债增加进一步推高资产价格和经济活力 → 形成自我强化的泡沫周期 |
| **Lag（时滞）** | 约2年（2006-2008年泡沫阶段） |
| **Threshold（临界值）** | 债务占GDP比例达到355%，增幅为GDP的10%；投资流入平均约占GDP的14%；GDP缺口达到5%峰值；股票年化回报率11% |
| **前提与约束（Premises）** | 债务以欧元计价，荷兰对其没有控制权；很大一部分债务的债权人并非荷兰人，易受外资撤出影响；决策者采取温和紧缩政策（短期利率上调约200个基点） |
| **Falsification（证伪条件）** | 如果债务增加但资产价格未上涨或经济未增长，则泡沫周期不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球：雪球越大滚得越快，但一旦遇到障碍（外资撤离）就会碎裂

### 🔗 文字版因果链

1. 债务增加和资金流入支撑经济增长
2. 经济增长和资产回报率高鼓励更多借债
3. 借债增加进一步推高资产价格和经济活力
4. 形成自我强化的泡沫周期
