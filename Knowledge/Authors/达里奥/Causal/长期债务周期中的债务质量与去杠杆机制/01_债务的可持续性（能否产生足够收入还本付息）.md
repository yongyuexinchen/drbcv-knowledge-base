# 债务的可持续性（能否产生足够收入还本付息）

> 属于因果簇：[[长期债务周期中的债务质量与去杠杆机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务资金的使用方式（高效投资 vs 消费性支出） |
| **DV（因变量）** | 债务的可持续性（能否产生足够收入还本付息） |
| **Chain（传导链）** | 债务资金用于高效投资，产生收入流，覆盖本息，债务可持续 → 债务资金用于消费性支出，不产生未来收入，仅推迟偿债压力，最终导致债务不可持续 |
| **Lag（时滞）** | 中长期（取决于投资回报周期或消费耗尽时间） |
| **Threshold（临界值）** | 投资回报率需高于债务利率 |
| **前提与约束（Premises）** | 债务资金的使用是决定债务好坏的关键；消费性支出包括奢侈品购买和财政赤字填补 |
| **Falsification（证伪条件）** | 如果消费性支出能够通过刺激经济间接产生足够税收或收入，使债务可持续，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 借钱上学（投资） vs 借钱买奢侈品（消费）：前者可能提升未来收入，后者只是提前消费，最终可能无法偿还

### 🔗 文字版因果链

1. 债务资金用于高效投资，产生收入流，覆盖本息，债务可持续
2. 债务资金用于消费性支出，不产生未来收入，仅推迟偿债压力，最终导致债务不可持续
