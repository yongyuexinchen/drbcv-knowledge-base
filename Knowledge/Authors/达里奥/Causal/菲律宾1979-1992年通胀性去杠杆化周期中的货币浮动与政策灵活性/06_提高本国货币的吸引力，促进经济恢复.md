# 提高本国货币的吸引力，促进经济恢复

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第6块/7块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实施充足的紧缩政策（减少进口支出，经常账户余额增幅为GDP的7%） |
| **DV（因变量）** | 提高本国货币的吸引力，促进经济恢复 |
| **Chain（传导链）** | 实施紧缩政策，减少进口支出 → 经常账户余额改善，增幅为GDP的7% → 本国货币吸引力提高 → 实际汇率跌至–19%的低点，重获竞争力 → 实际GDP在6年内恢复至之前峰值 |
| **Lag（时滞）** | 政策实施后1-2年经常账户改善，经济恢复需6年 |
| **Threshold（临界值）** | 经常账户余额增幅超过GDP的7%，实际汇率贬值至–19% |
| **前提与约束（Premises）** | 决策者实施紧缩政策；存在IMF援助计划；实施结构性改革（如劳动力市场灵活性） |
| **Falsification（证伪条件）** | 如果紧缩政策没有改善经常账户或提高货币吸引力，或者经济恢复时间更长，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像节衣缩食减少开支，虽然短期痛苦，但能提高信用，最终恢复经济健康

### 🔗 文字版因果链

1. 实施紧缩政策，减少进口支出
2. 经常账户余额改善，增幅为GDP的7%
3. 本国货币吸引力提高
4. 实际汇率跌至–19%的低点，重获竞争力
5. 实际GDP在6年内恢复至之前峰值
