## 总体因果图

- 二战期间大规模借款以填补财政赤字 → 战后经济衰退（GDP下跌13%，失业率上升5%）
- 决策者提供充足的经济刺激（货币政策与财政政策） → 和谐的去杠杆化（债务占GDP比例下降22%，失业率下降2%）
