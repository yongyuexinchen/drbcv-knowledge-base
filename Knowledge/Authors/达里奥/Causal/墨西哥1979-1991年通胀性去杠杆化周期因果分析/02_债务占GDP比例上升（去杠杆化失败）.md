# 债务占GDP比例上升（去杠杆化失败）

> 属于因果簇：[[墨西哥1979-1991年通胀性去杠杆化周期因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值与财政赤字 |
| **DV（因变量）** | 债务占GDP比例上升（去杠杆化失败） |
| **Chain（传导链）** | 货币贬值导致以外币计价的债务本币价值上升 → 政府为应对危机举借新债，财政赤字扩大 → 债务增速超过GDP增速，债务占GDP比例上升 |
| **Lag（时滞）** | 货币贬值和财政赤字在萧条阶段持续推高债务比例，年化增幅7% |
| **Threshold（临界值）** | 财政赤字占GDP达13%峰值；货币贬值导致债务比例累计增加41% |
| **前提与约束（Premises）** | 存在大量外币债务；政府缺乏财政空间，需借新债应对危机 |
| **Falsification（证伪条件）** | 如果货币贬值后债务比例未上升，或财政赤字未扩大，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用贬值货币还外债，债务越还越多，同时政府还要借钱度日，雪上加霜

### 🔗 文字版因果链

1. 货币贬值导致以外币计价的债务本币价值上升
2. 政府为应对危机举借新债，财政赤字扩大
3. 债务增速超过GDP增速，债务占GDP比例上升
