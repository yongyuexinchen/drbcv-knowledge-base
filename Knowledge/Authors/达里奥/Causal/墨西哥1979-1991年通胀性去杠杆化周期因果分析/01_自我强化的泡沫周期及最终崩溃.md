# 自我强化的泡沫周期及最终崩溃

> 属于因果簇：[[墨西哥1979-1991年通胀性去杠杆化周期因果分析]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入与债务增加（以外币计价） |
| **DV（因变量）** | 自我强化的泡沫周期及最终崩溃 |
| **Chain（传导链）** | 大量资本流入导致债务累积，尤其是外币债务 → 债务支撑了强劲的经济增长和资产价格上升 → 经济过热，实际汇率升值，竞争力下降 → 外部条件恶化（如油价下跌）触发资本流入逆转 → 资本外流导致货币贬值、利率上升、经济收缩，形成自我强化的萧条 |
| **Lag（时滞）** | 泡沫阶段持续约2-3年（1979-1981），随后进入萧条阶段（1981-1987） |
| **Threshold（临界值）** | 债务占GDP达65%，其中外币债务占GDP的26%；偿债总额占GDP的31% |
| **前提与约束（Premises）** | 经济高度依赖外国资本流入；存在经常账户赤字（占GDP的6%）；外部冲击（如油价下跌、拉美债务危机）发生 |
| **Falsification（证伪条件）** | 如果资本流入逆转后，经济仍能保持增长或债务水平未显著上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠借外债过度消费，一旦收入中断或利率上升，就会陷入债务螺旋，难以自拔

### 🔗 文字版因果链

1. 大量资本流入导致债务累积，尤其是外币债务
2. 债务支撑了强劲的经济增长和资产价格上升
3. 经济过热，实际汇率升值，竞争力下降
4. 外部条件恶化（如油价下跌）触发资本流入逆转
5. 资本外流导致货币贬值、利率上升、经济收缩，形成自我强化的萧条
