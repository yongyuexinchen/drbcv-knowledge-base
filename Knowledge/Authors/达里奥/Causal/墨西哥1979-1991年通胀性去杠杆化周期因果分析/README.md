## 总体因果图

- 大量资本流入与债务增加（以外币计价） → 自我强化的泡沫周期及最终崩溃
- 货币贬值与财政赤字 → 债务占GDP比例上升（去杠杆化失败）
- 实施紧缩政策与结构性改革（包括IMF援助） → 和谐去杠杆化与经济恢复
