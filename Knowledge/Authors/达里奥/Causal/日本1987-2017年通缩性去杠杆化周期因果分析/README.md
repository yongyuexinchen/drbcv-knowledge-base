# 日本1987-2017年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：日本1987-2017年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加、经济增长强劲、资产回报丰厚 → 自我强化的泡沫周期
- 紧缩政策（短期利率上调约450个基点） → 不可持续的发展局势
- 房地产市场与股市崩盘 → 自我强化的经济萧条和痛苦的去杠杆化
- 央行货币宽松力度不足 → 名义GDP增速低于名义利率，去杠杆化速度缓慢
- 充足的经济刺激（M0增幅达GDP的58%，利率降至0%，实际汇率平均-10%，积极管控金融机构和处理坏账） → 和谐的去杠杆化，经济步入通货再膨胀阶段
