# 日本1925-1936年通缩性去杠杆化周期因果分析

> **领域**：宏观经济学　|　**来源**：chapter_91.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务水平（债务总额达GDP的65%） |
| **DV（因变量）** | 经济萧条和痛苦的去杠杆化（1927-1931年） |
| **Chain（传导链）** | 高债务水平使日本经济脆弱，易受外部冲击 → 1929年全球股市崩盘成为触发冲击 → GDP和股价陷入自我强化式下跌（GDP跌4%，股价跌47%） → 金融机构面临巨大压力，债务占GDP比例反而增加36% → 形成通缩性去杠杆化，经济持续萧条 |
| **Lag（时滞）** | 冲击后约1-2年（1929年冲击，萧条持续至1931年） |
| **Threshold（临界值）** | 债务总额达到GDP的65%时，经济变得脆弱 |
| **前提与约束（Premises）** | 债务以日元计价，债权人为日本人；危机前日本未普遍出现泡沫，但外部关联市场存在泡沫；处于全球股市崩盘的外部环境下 |
| **Falsification（证伪条件）** | 若高债务水平未导致经济萧条，或萧条期间债务占GDP比例下降而非上升，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人背负了过重的债务（相当于收入的65%），一旦遇到意外失业（全球股灾），就会陷入恶性循环，债务越还越多。

### 🔗 文字版因果链

1. 高债务水平使日本经济脆弱，易受外部冲击
2. 1929年全球股市崩盘成为触发冲击
3. GDP和股价陷入自我强化式下跌（GDP跌4%，股价跌47%）
4. 金融机构面临巨大压力，债务占GDP比例反而增加36%
5. 形成通缩性去杠杆化，经济持续萧条

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（切断日元与黄金挂钩、降息至2%、管控金融机构） |
| **DV（因变量）** | 和谐的去杠杆化（1931年后，债务占GDP比例下降18%） |
| **Chain（传导链）** | 政府切断日元与黄金挂钩，允许货币贬值 → 利率降至2%，实际汇率为-26% → 积极管控金融机构和处理坏账 → 名义经济增长率（4.7%）高于名义利率（3.9%） → 收入水平上升，债务与收入比率下降 |
| **Lag（时滞）** | 刺激政策实施后约1-2年（1931年开始，效果在周期内显现） |
| **Threshold（临界值）** | 名义经济增长率超过名义利率（4.7% > 3.9%）时，债务比率下降 |
| **前提与约束（Premises）** | 决策者愿意采取积极干预措施；经济刺激力度足够大（使用9个政策工具中的3个）；金融机构得到有效管控 |
| **Falsification（证伪条件）** | 若刺激政策未能使名义增长率超过利率，或债务比率未下降，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像给一个溺水者扔救生圈（刺激政策），只要救生圈足够大（增长率>利率），就能浮上来，否则会沉得更深。

### 🔗 文字版因果链

1. 政府切断日元与黄金挂钩，允许货币贬值
2. 利率降至2%，实际汇率为-26%
3. 积极管控金融机构和处理坏账
4. 名义经济增长率（4.7%）高于名义利率（3.9%）
5. 收入水平上升，债务与收入比率下降

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期经济萧条和痛苦去杠杆化 |
| **DV（因变量）** | 日本政局显著变化，东条英机上台 |
| **Chain（传导链）** | 经济萧条导致社会不满和民众痛苦 → 民粹主义领导人获得支持 → 东条英机上台，改变政治格局 |
| **Lag（时滞）** | 萧条持续数年后（约1931-1936年） |
| **Threshold（临界值）** | 萧条持续时间超过平均水平（1927-1931年） |
| **前提与约束（Premises）** | 经济萧条持续且未得到及时缓解；民众对现有政治体制失望；存在民粹主义领导人的政治空间 |
| **Falsification（证伪条件）** | 若经济萧条未导致政治格局变化，或东条英机上台与萧条无关，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像长期失业会让人对政府失去信心，转而支持激进的政治人物。

### 🔗 文字版因果链

1. 经济萧条导致社会不满和民众痛苦
2. 民粹主义领导人获得支持
3. 东条英机上台，改变政治格局
