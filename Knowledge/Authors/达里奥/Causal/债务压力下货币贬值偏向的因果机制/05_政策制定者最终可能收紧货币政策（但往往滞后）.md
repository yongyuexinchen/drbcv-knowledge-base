# 政策制定者最终可能收紧货币政策（但往往滞后）

> 属于因果簇：[[债务压力下货币贬值偏向的因果机制]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 弱货币/高通胀问题严重到无法忽视 |
| **DV（因变量）** | 政策制定者最终可能收紧货币政策（但往往滞后） |
| **Chain（传导链）** | 弱货币和高通胀持续恶化 → 经济和社会成本上升，问题无法忽视 → 政策制定者被迫采取紧缩措施 → 但行动往往滞后，因为紧缩带来痛苦 |
| **Lag（时滞）** | 长期（可能数年，如1970-1982周期） |
| **Threshold（临界值）** | 当通胀率或货币贬值幅度超过社会承受极限（如恶性通胀） |
| **前提与约束（Premises）** | 存在货币贬值和通胀的自我强化机制；政策制定者面临外部压力（如国际投资者）；紧缩政策的短期痛苦被长期稳定收益所抵消 |
| **Falsification（证伪条件）** | 如果弱货币和高通胀长期存在但政策制定者从未收紧，且经济未崩溃，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像病人拖延就医，直到病情严重到无法忍受才去看医生，但治疗往往更痛苦。
