# 政策制定者倾向于压低实际利率、贬值货币

> 属于因果簇：[[债务压力下货币贬值偏向的因果机制]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务和借贷水平 |
| **DV（因变量）** | 政策制定者倾向于压低实际利率、贬值货币 |
| **Chain（传导链）** | 债务和借贷过多导致偿债负担加重 → 为减轻债务人负担，政策制定者倾向于压低实际利率 → 压低实际利率导致货币贬值 → 货币贬值对债权人不利，但有利于债务人 |
| **Lag（时滞）** | 短期至中期（政策响应通常较快，但效果显现可能需要数月） |
| **Threshold（临界值）** | 当债务水平高到使偿债压力显著影响经济稳定时 |
| **前提与约束（Premises）** | 存在主权货币和独立的货币政策工具；债务以本币计价为主；政策制定者优先考虑短期经济稳定而非长期货币信誉 |
| **Falsification（证伪条件）** | 如果高债务水平下政策制定者反而加息或维持高利率，且货币升值，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人欠债太多时，倾向于用通货膨胀来‘稀释’债务，相当于用更便宜的货币还债。

### 🔗 文字版因果链

1. 债务和借贷过多导致偿债负担加重
2. 为减轻债务人负担，政策制定者倾向于压低实际利率
3. 压低实际利率导致货币贬值
4. 货币贬值对债权人不利，但有利于债务人
