# 倾向于更多刺激政策（宽松货币政策）

> 属于因果簇：[[债务压力下货币贬值偏向的因果机制]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家元首寻求连任或民众满意 |
| **DV（因变量）** | 倾向于更多刺激政策（宽松货币政策） |
| **Chain（传导链）** | 国家元首面临选举或民众压力 → 为提升民众满意度，倾向于推动金融市场和消费 → 实施更多刺激政策（如降息、增加支出） → 刺激政策可能加剧通胀，直到通胀严重到不得不收紧 |
| **Lag（时滞）** | 选举周期内（通常1-4年） |
| **Threshold（临界值）** | 当通胀严重到民众和元首自身都认为需要收紧时 |
| **前提与约束（Premises）** | 存在民主选举或民众压力机制；短期经济表现影响政治支持率；货币政策具有政治影响力 |
| **Falsification（证伪条件）** | 如果国家元首在非危机时期主动采取紧缩政策，且不追求短期刺激，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像政客在竞选时承诺减税和福利，以赢得选票，但事后可能面临财政赤字问题。

### 🔗 文字版因果链

1. 国家元首面临选举或民众压力
2. 为提升民众满意度，倾向于推动金融市场和消费
3. 实施更多刺激政策（如降息、增加支出）
4. 刺激政策可能加剧通胀，直到通胀严重到不得不收紧
