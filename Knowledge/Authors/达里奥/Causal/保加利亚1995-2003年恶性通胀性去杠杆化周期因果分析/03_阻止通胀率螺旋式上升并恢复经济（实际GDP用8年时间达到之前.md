# 阻止通胀率螺旋式上升并恢复经济（实际GDP用8年时间达到之前

> 属于因果簇：[[保加利亚1995-2003年恶性通胀性去杠杆化周期因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 积极的金融机构管理和坏账处理（使用9个典型政策工具中的5个：银行国有化、提供流动性、直接购买不良资产、IMF援助计划、结构性改革） |
| **DV（因变量）** | 阻止通胀率螺旋式上升并恢复经济（实际GDP用8年时间达到之前峰值） |
| **Chain（传导链）** | 银行国有化稳定金融体系 → 提供流动性缓解资金紧张 → 直接购买不良资产清理银行资产负债表 → IMF援助计划提供外部支持 → 加大结构性改革力度 → 将保加利亚列弗重新定价，与德国马克挂钩，以外汇储备支撑 → 通胀得到控制，经济逐步恢复 |
| **Lag（时滞）** | 约8年（从危机到GDP恢复峰值） |
| **Threshold（临界值）** | 使用5个以上政策工具，列弗与德国马克挂钩 |
| **前提与约束（Premises）** | 需要IMF等外部援助；必须进行结构性改革；政策工具组合需全面 |
| **Falsification（证伪条件）** | 如果保加利亚采取了这些措施但通胀未受控或GDP未恢复，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像治疗重病，需要综合用药（多种政策工具）、手术（结构性改革）和康复训练（时间），才能最终恢复健康。

### 🔗 文字版因果链

1. 银行国有化稳定金融体系
2. 提供流动性缓解资金紧张
3. 直接购买不良资产清理银行资产负债表
4. IMF援助计划提供外部支持
5. 加大结构性改革力度
6. 将保加利亚列弗重新定价，与德国马克挂钩，以外汇储备支撑
7. 通胀得到控制，经济逐步恢复
