# 自我强化的经济萧条和国际收支危机 货币危机（1995-199

> 属于因果簇：[[保加利亚1995-2003年恶性通胀性去杠杆化周期因果分析]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高额外币计价债务（占GDP的82%）和对外资流入的依赖（经常账户赤字占GDP的4%） |
| **DV（因变量）** | 自我强化的经济萧条和国际收支危机/货币危机（1995-1997年） |
| **Chain（传导链）** | 高额外币债务使经济易受冲击 → 企业/银行因负债过高遭遇亏损潮 → 外资流入减少（资本流入降幅为GDP的6%） → 货币政策收紧（短期利率上调228%） → 货币大幅贬值（实际汇率下降96%） → GDP陷入自我强化式下跌（跌幅13%） → 通胀率高企且不断上升 → 金融机构面临巨大压力 → 央行耗尽外汇储备（减少75%）后放弃捍卫货币 |
| **Lag（时滞）** | 约2年（从债务积累到危机爆发） |
| **Threshold（临界值）** | 外币债务占GDP的82%，经常账户赤字占GDP的4%，资本流入降幅达GDP的6% |
| **前提与约束（Premises）** | 危机前没有普遍泡沫，但债务积累严重；债务以外币计价为主；经济依赖持续外资流入；存在忽视通胀管控的历史 |
| **Falsification（证伪条件）** | 如果保加利亚在同等债务和外资依赖水平下，未发生资本流入骤减或货币危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭背负大量外币房贷且依赖海外汇款生活，一旦海外汇款中断，货币贬值，债务负担加重，最终陷入财务崩溃。

### 🔗 文字版因果链

1. 高额外币债务使经济易受冲击
2. 企业/银行因负债过高遭遇亏损潮
3. 外资流入减少（资本流入降幅为GDP的6%）
4. 货币政策收紧（短期利率上调228%）
5. 货币大幅贬值（实际汇率下降96%）
6. GDP陷入自我强化式下跌（跌幅13%）
7. 通胀率高企且不断上升
8. 金融机构面临巨大压力
9. 央行耗尽外汇储备（减少75%）后放弃捍卫货币
