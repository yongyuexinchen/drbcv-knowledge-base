# 自我强化的泡沫周期（债务升至GDP85%，股市年回报25%，

> 属于因果簇：[[墨西哥1991-2005年通胀性去杠杆化周期因果分析]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加（尤其外币计价债务占GDP25%） |
| **DV（因变量）** | 自我强化的泡沫周期（债务升至GDP85%，股市年回报25%，GDP增速4%） |
| **Chain（传导链）** | 外资大量流入填补经常账户赤字（占GDP7%） → 债务水平上升，外币债务增加，经济对外资依赖增强 → 高资产回报率鼓励更多借债，刺激经济增长 → 债务和资金增加支撑经济强劲增长，形成自我强化泡沫 |
| **Lag（时滞）** | 约1-3年（1991-1994年泡沫积累） |
| **Threshold（临界值）** | 债务占GDP比例升至85%，外币债务占GDP25% |
| **前提与约束（Premises）** | 经济开放，依赖外国资本流入；存在经常账户赤字（占GDP7%）；外币债务占比较高，易受外资撤出影响 |
| **Falsification（证伪条件）** | 若在类似资本流入和债务水平下，未出现泡沫或债务危机，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠信用卡透支维持高消费，债务越滚越大，一旦银行收紧信贷，就会陷入财务危机

### 🔗 文字版因果链

1. 外资大量流入填补经常账户赤字（占GDP7%）
2. 债务水平上升，外币债务增加，经济对外资依赖增强
3. 高资产回报率鼓励更多借债，刺激经济增长
4. 债务和资金增加支撑经济强劲增长，形成自我强化泡沫
