# 不可持续的发展局势（债务高企、经常账户赤字、竞争力下降）

> 属于因果簇：[[阿根廷1998-2012年通胀性去杠杆化周期中的因果机制]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本流入强劲且货币回报丰厚 |
| **DV（因变量）** | 不可持续的发展局势（债务高企、经常账户赤字、竞争力下降） |
| **Chain（传导链）** | 资本流入强劲，货币回报丰厚，吸引更多外资 → 债务累积，尤其以外币计价的债务增加 → 实际汇率升值，削弱竞争力 → 经常账户赤字扩大，依赖外资流入 → 外部环境恶化时，外资撤出，导致不可持续局势 |
| **Lag（时滞）** | 数年至泡沫阶段结束（1998-2001年） |
| **Threshold（临界值）** | 债务占GDP的78%，其中外币债务占GDP的47%；实际汇率升值39%；经常账户赤字占GDP的5% |
| **前提与约束（Premises）** | 资本账户开放，允许外资自由流动；实行钉住汇率制度；国内储蓄不足，依赖外资填补经常账户缺口 |
| **Falsification（证伪条件）** | 如果资本流入强劲但债务水平未显著上升，或实际汇率未大幅升值，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭依赖信用卡维持高消费，当信用卡额度收紧时，家庭财务立即陷入困境。

### 🔗 文字版因果链

1. 资本流入强劲，货币回报丰厚，吸引更多外资
2. 债务累积，尤其以外币计价的债务增加
3. 实际汇率升值，削弱竞争力
4. 经常账户赤字扩大，依赖外资流入
5. 外部环境恶化时，外资撤出，导致不可持续局势
