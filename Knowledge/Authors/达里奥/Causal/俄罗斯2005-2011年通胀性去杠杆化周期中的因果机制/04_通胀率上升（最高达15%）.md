# 通胀率上升（最高达15%）

> 属于因果簇：[[俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（实际汇率下降21%） |
| **DV（因变量）** | 通胀率上升（最高达15%） |
| **Chain（传导链）** | 货币贬值导致进口商品价格上升 → 进口成本传递到国内物价 → 通胀率上升 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 实际汇率下降21%，通胀率最高达15% |
| **前提与约束（Premises）** | 存在通胀风险因素（但俄罗斯仅约1/4典型风险因素）；货币贬值幅度较大；长期缺乏通胀管控 |
| **Falsification（证伪条件）** | 如果货币贬值但通胀率未上升或上升幅度小于15%，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像进口商品变贵，就像从国外买水果，汇率一跌，水果价格就涨。

### 🔗 文字版因果链

1. 货币贬值导致进口商品价格上升
2. 进口成本传递到国内物价
3. 通胀率上升
