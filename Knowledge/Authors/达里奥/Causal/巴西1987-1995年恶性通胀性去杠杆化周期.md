# 巴西1987-1995年恶性通胀性去杠杆化周期

> **领域**：宏观经济学　|　**来源**：chapter_120.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加（尤其以外币计价的债务） |
| **DV（因变量）** | 自我强化的泡沫周期（经济增长强劲、股市回报丰厚） |
| **Chain（传导链）** | 债务增加支撑经济增长和资产回报 → 高资产回报鼓励更多借债 → 更多借债进一步刺激经济增长，形成正反馈循环 |
| **Lag（时滞）** | 即时至数年（泡沫阶段持续约3年） |
| **Threshold（临界值）** | 债务占GDP比例达到177%，外币债务占GDP的26% |
| **前提与约束（Premises）** | 存在外资可自由撤出的开放资本账户；实际汇率高估（峰值达35%）；经济活力高位（GDP缺口峰值7%） |
| **Falsification（证伪条件）** | 若债务增加但经济增长和资产回报未同步上升，或外资撤出未引发危机，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用信用卡不断消费，账单越积越高，但当下生活看似富足，直到还款日到来。

### 🔗 文字版因果链

1. 债务增加支撑经济增长和资产回报
2. 高资产回报鼓励更多借债
3. 更多借债进一步刺激经济增长，形成正反馈循环

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务水平（尤其外币债务） |
| **DV（因变量）** | 自我强化的经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 高债务使经济易受冲击（价格管控失灵和通胀） → GDP和股价下跌，失业率上升 → 货币疲软导致通胀高企，金融机构承压 → 央行耗尽外汇储备（减少28%）后放弃捍卫货币，货币贬值19% → 货币贬值加重外币偿债负担，政府举借新债，债务占GDP比例进一步上升 |
| **Lag（时滞）** | 泡沫破裂后1-2年（萧条阶段1990-1991年） |
| **Threshold（临界值）** | 债务占GDP比例177%，外汇储备减少28%，货币贬值19% |
| **前提与约束（Premises）** | 存在外币计价债务；央行外汇储备有限；决策者初期试图捍卫货币 |
| **Falsification（证伪条件）** | 若高债务水平未导致GDP和股价下跌，或央行成功捍卫货币而未贬值，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同背负高额房贷且收入以外币计，一旦本币贬值，还款压力骤增，可能引发断供和资产抛售的恶性循环。

### 🔗 文字版因果链

1. 高债务使经济易受冲击（价格管控失灵和通胀）
2. GDP和股价下跌，失业率上升
3. 货币疲软导致通胀高企，金融机构承压
4. 央行耗尽外汇储备（减少28%）后放弃捍卫货币，货币贬值19%
5. 货币贬值加重外币偿债负担，政府举借新债，债务占GDP比例进一步上升

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩措施未能带来必要调整 |
| **DV（因变量）** | 汇率下跌和恶性通胀旋涡 |
| **Chain（传导链）** | 紧缩措施不足以恢复国际收支平衡 → 资本外流持续，汇率下跌 → 汇率下跌推高进口价格和通胀预期 → 通胀率螺旋式上升（最高超5000%） → 货币体系崩溃，最终采用新货币 |
| **Lag（时滞）** | 危机后1-3年（通货再膨胀阶段） |
| **Threshold（临界值）** | 实际汇率跌至-16%，通胀率超过5000% |
| **前提与约束（Premises）** | 存在长期忽视通胀管控的历史；未积极管控金融机构和处理坏账；仅使用9个典型政策工具中的2个 |
| **Falsification（证伪条件）** | 若紧缩措施成功稳定汇率和通胀，或未出现恶性通胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同用小火救大火，火势不减反增，最终需要彻底重建。

### 🔗 文字版因果链

1. 紧缩措施不足以恢复国际收支平衡
2. 资本外流持续，汇率下跌
3. 汇率下跌推高进口价格和通胀预期
4. 通胀率螺旋式上升（最高超5000%）
5. 货币体系崩溃，最终采用新货币
