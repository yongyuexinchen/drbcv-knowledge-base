# 经济萧条和国际收支危机 货币危机

> 属于因果簇：[[韩国1994-2001年通胀性去杠杆化周期中的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的9%） |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 外资流入减少导致货币政策紧缩（短期利率上调14%） → 货币大幅贬值（实际汇率降至-50%） → GDP、股价和房价陷入自我强化式下跌（跌幅分别为8%、75%和13%） → 失业率上升6% → 金融机构面临巨大压力，央行外汇储备减少24% → 最终放弃捍卫货币，债务占GDP比例增加19% |
| **Lag（时滞）** | 1997-1998年（危机持续约1-2年） |
| **Threshold（临界值）** | 偿债总额达到GDP的42%；资本流入降幅为GDP的9% |
| **前提与约束（Premises）** | 韩国面临外部冲击（1997年亚洲金融危机）；外币计价债务占比较高；央行外汇储备较少 |
| **Falsification（证伪条件）** | 如果外资减少未导致货币大幅贬值或经济未出现同步下跌，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个依赖外部输血的患者，一旦血源中断，身体各器官迅速衰竭。

### 🔗 文字版因果链

1. 外资流入减少导致货币政策紧缩（短期利率上调14%）
2. 货币大幅贬值（实际汇率降至-50%）
3. GDP、股价和房价陷入自我强化式下跌（跌幅分别为8%、75%和13%）
4. 失业率上升6%
5. 金融机构面临巨大压力，央行外汇储备减少24%
6. 最终放弃捍卫货币，债务占GDP比例增加19%
