# 温和的通胀水平（最高7%）

> 属于因果簇：[[韩国1994-2001年通胀性去杠杆化周期中的因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（实际汇率降至-50%） |
| **DV（因变量）** | 温和的通胀水平（最高7%） |
| **Chain（传导链）** | 货币贬值导致进口商品价格上涨 → 但韩国仅存在约1/4的典型风险因素（如央行外汇储备较少） → 因此通胀螺旋式上升的力度有限 → 通胀率保持在温和水平（最高7%） |
| **Lag（时滞）** | 1997-1998年（萧条阶段） |
| **Threshold（临界值）** | 实际汇率贬值至-50%；通胀率最高7% |
| **前提与约束（Premises）** | 央行外汇储备较少；存在其他风险因素但数量有限；经济衰退抑制了需求侧通胀压力 |
| **Falsification（证伪条件）** | 如果货币大幅贬值导致通胀率超过7%或出现恶性通胀，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同往一杯水中加盐，如果盐不多（风险因素少），水不会太咸（通胀温和）。

### 🔗 文字版因果链

1. 货币贬值导致进口商品价格上涨
2. 但韩国仅存在约1/4的典型风险因素（如央行外汇储备较少）
3. 因此通胀螺旋式上升的力度有限
4. 通胀率保持在温和水平（最高7%）
