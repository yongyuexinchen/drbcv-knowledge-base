# 通胀性去杠杆化周期和后续经济恢复

> 属于因果簇：[[韩国1994-2001年通胀性去杠杆化周期中的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者放弃钉住汇率制度，允许货币浮动 |
| **DV（因变量）** | 通胀性去杠杆化周期和后续经济恢复 |
| **Chain（传导链）** | 放弃钉住汇率制度导致货币贬值 → 货币贬值提高出口竞争力，减少进口支出（经常账户余额增幅为GDP的7%） → 决策者实施紧缩政策并积极管控金融机构（使用9个政策工具中的7个） → 银行国有化、提供流动性、直接购买问题资产 → IMF援助计划和结构性改革增强劳动力市场灵活性 → 实际经济增速提升，名义收入增加，债务占GDP比例下降25% → 实际GDP用1.7年恢复至峰值，股价9年内恢复 |
| **Lag（时滞）** | 1998-2001年（通货再膨胀阶段约3年） |
| **Threshold（临界值）** | 实际汇率跌至-17%的低点；债务占GDP比例年化降幅10% |
| **前提与约束（Premises）** | 决策者愿意忍受短期痛苦（紧缩政策）；存在IMF等外部援助；金融机构得到有效管控和重组 |
| **Falsification（证伪条件）** | 如果货币贬值未带来竞争力提升或债务比例未下降，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人放弃硬撑的体面，接受短期痛苦治疗，最终恢复健康。

### 🔗 文字版因果链

1. 放弃钉住汇率制度导致货币贬值
2. 货币贬值提高出口竞争力，减少进口支出（经常账户余额增幅为GDP的7%）
3. 决策者实施紧缩政策并积极管控金融机构（使用9个政策工具中的7个）
4. 银行国有化、提供流动性、直接购买问题资产
5. IMF援助计划和结构性改革增强劳动力市场灵活性
6. 实际经济增速提升，名义收入增加，债务占GDP比例下降25%
7. 实际GDP用1.7年恢复至峰值，股价9年内恢复
