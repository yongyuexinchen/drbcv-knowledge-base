# GDP、股价和房价自我强化式下跌，失业率上升

> 属于因果簇：[[希腊通缩性去杠杆化周期中的因果机制]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币政策收紧（短期利率上调86%） |
| **DV（因变量）** | GDP、股价和房价自我强化式下跌，失业率上升 |
| **Chain（传导链）** | 利率上升增加借贷成本 → 企业和个人减少投资和消费 → GDP下降，企业盈利恶化 → 股价和房价下跌 → 资产价格下跌导致财富缩水，进一步抑制消费和投资 → 企业裁员，失业率上升 → 经济下滑进一步加剧资产价格下跌，形成自我强化循环 |
| **Lag（时滞）** | 2008-2017年（约9年） |
| **Threshold（临界值）** | 短期利率上调86%；GDP跌幅27%；股价跌幅91%；房价跌幅42%；失业率上升15% |
| **前提与约束（Premises）** | 希腊债务负担沉重（偿债总额占GDP的42%）；外资流入减少；金融机构面临压力；缺乏货币宽松政策 |
| **Falsification（证伪条件）** | 如果利率上升但GDP、股价和房价未出现大幅下跌，或失业率未上升，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个已经负债累累的人，突然被银行提高信用卡利率，他只能削减开支、变卖资产，导致生活水平下降，进一步陷入贫困

### 🔗 文字版因果链

1. 利率上升增加借贷成本
2. 企业和个人减少投资和消费
3. GDP下降，企业盈利恶化
4. 股价和房价下跌
5. 资产价格下跌导致财富缩水，进一步抑制消费和投资
6. 企业裁员，失业率上升
7. 经济下滑进一步加剧资产价格下跌，形成自我强化循环
