# 阿莱克西斯·齐普拉斯上台（民粹主义领导人）

> 属于因果簇：[[希腊通缩性去杠杆化周期中的因果机制]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 希腊经济危机和痛苦去杠杆化 |
| **DV（因变量）** | 阿莱克西斯·齐普拉斯上台（民粹主义领导人） |
| **Chain（传导链）** | 经济危机导致失业率上升、生活水平下降 → 民众对传统政党不满 → 民粹主义领导人提出反紧缩、反建制主张 → 民众支持率上升 → 齐普拉斯赢得选举上台 |
| **Lag（时滞）** | 2008-2015年（约7年） |
| **Threshold（临界值）** | 失业率上升15%，GDP跌幅27% |
| **前提与约束（Premises）** | 经济危机持续多年；民众对传统政党失去信心；民粹主义领导人提出吸引选民的政策 |
| **Falsification（证伪条件）** | 如果经济危机未导致民粹主义领导人上台，或齐普拉斯上台但经济未持续恶化，则此因果链不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一个家庭因长期贫困而对现有管理者失去信任，转而支持承诺激进改革的候选人，希望改变现状

### 🔗 文字版因果链

1. 经济危机导致失业率上升、生活水平下降
2. 民众对传统政党不满
3. 民粹主义领导人提出反紧缩、反建制主张
4. 民众支持率上升
5. 齐普拉斯赢得选举上台
