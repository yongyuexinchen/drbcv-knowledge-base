# 去杠杆化未能实现，经济持续萧条

> 属于因果簇：[[希腊通缩性去杠杆化周期中的因果机制]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务占GDP比例增加101%（年化增幅11%） |
| **DV（因变量）** | 去杠杆化未能实现，经济持续萧条 |
| **Chain（传导链）** | 实际收入减少导致GDP下降 → GDP下降使债务占GDP比例被动上升 → 举借新债以支付利息进一步增加债务 → 债务负担加重，经济难以复苏 → 去杠杆化过程痛苦且漫长 |
| **Lag（时滞）** | 2008-2017年 |
| **Threshold（临界值）** | 债务占GDP比例增加101%，年化增幅11% |
| **前提与约束（Premises）** | 实际收入减少；需要举借新债支付利息；缺乏充足的货币宽松政策；名义经济增长率低于名义利率 |
| **Falsification（证伪条件）** | 如果债务占GDP比例下降或经济快速复苏，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个陷入债务陷阱的人，收入减少，但为了还利息不得不借新债，债务越滚越大，永远无法摆脱

### 🔗 文字版因果链

1. 实际收入减少导致GDP下降
2. GDP下降使债务占GDP比例被动上升
3. 举借新债以支付利息进一步增加债务
4. 债务负担加重，经济难以复苏
5. 去杠杆化过程痛苦且漫长
