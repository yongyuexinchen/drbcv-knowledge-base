# 自我强化的泡沫周期

> 属于因果簇：[[希腊通缩性去杠杆化周期中的因果机制]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、经济增长强劲、资产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加和经济增长强劲提高资产回报率 → 高资产回报率鼓励更多借债 → 更多借债进一步刺激经济增长和资产价格 → 形成自我强化的泡沫周期 |
| **Lag（时滞）** | 2005-2008年（约3年） |
| **Threshold（临界值）** | 债务占GDP比例达到206%，增幅为GDP的40%；投资流入平均约占GDP的22%；经常账户赤字占GDP的13%；GDP增速达到3%；GDP缺口峰值10%；股票平均年化回报率19% |
| **前提与约束（Premises）** | 债务以欧元计价，希腊对欧元没有控制权；很大一部分债务的债权人并非希腊人；依赖外资流入；决策者采取温和紧缩政策（短期利率上调约200个基点） |
| **Falsification（证伪条件）** | 如果债务增加但资产回报率未上升，或外资流入未导致经常账户赤字扩大，则泡沫周期不会形成 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭不断借债消费，房价上涨使家庭感觉更富有，于是借更多钱，直到债务负担过重，一旦收入或资产价格下跌，就会陷入财务危机

### 🔗 文字版因果链

1. 债务增加和经济增长强劲提高资产回报率
2. 高资产回报率鼓励更多借债
3. 更多借债进一步刺激经济增长和资产价格
4. 形成自我强化的泡沫周期
