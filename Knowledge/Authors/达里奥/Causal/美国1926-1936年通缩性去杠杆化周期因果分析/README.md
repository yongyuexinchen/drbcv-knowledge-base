# 美国1926-1936年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：美国1926-1936年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务水平高企（债务占GDP达125%） → 经济脆弱性增加，易受冲击伤害
- 股市崩盘（1929年） → GDP、股价、房价自我强化式下跌，失业率上升
- 决策者提供充足的经济刺激（切断美元与黄金挂钩、增加M0、降低利率至0%） → 痛苦的去杠杆化转变为和谐的去杠杆化，经济复苏
- 经济萧条和痛苦去杠杆化 → 政治格局变化，民粹主义领导人上台（罗斯福）
