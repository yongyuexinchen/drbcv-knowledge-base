# 决策者设定利率的灵活性增加

> 属于因果簇：[[哥伦比亚1995-2008年通胀性去杠杆化周期中的因果机制]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部压力下允许货币浮动 |
| **DV（因变量）** | 决策者设定利率的灵活性增加 |
| **Chain（传导链）** | 外部压力导致资本外流和货币贬值压力 → 允许货币浮动而非固定汇率，使汇率成为调整机制 → 汇率调整吸收部分外部冲击，减轻货币政策负担 → 决策者获得更大的利率设定空间 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 货币浮动需在资本账户开放且汇率弹性足够的情况下 |
| **前提与约束（Premises）** | 国家面临外部压力（如资本外流）；决策者选择不捍卫固定汇率；存在通胀容忍度 |
| **Falsification（证伪条件）** | 若允许货币浮动后利率灵活性未增加或经济恶化，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同松开刹车让车自然减速，虽然颠簸但避免刹车失灵

### 🔗 文字版因果链

1. 外部压力导致资本外流和货币贬值压力
2. 允许货币浮动而非固定汇率，使汇率成为调整机制
3. 汇率调整吸收部分外部冲击，减轻货币政策负担
4. 决策者获得更大的利率设定空间
