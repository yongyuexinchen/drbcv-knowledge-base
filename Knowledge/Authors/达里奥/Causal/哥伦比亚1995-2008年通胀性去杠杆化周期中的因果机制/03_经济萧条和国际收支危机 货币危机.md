# 经济萧条和国际收支危机 货币危机

> 属于因果簇：[[哥伦比亚1995-2008年通胀性去杠杆化周期中的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部冲击（1997年亚洲金融危机）导致资本流入减少 |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机 |
| **Chain（传导链）** | 外资流入减少（资本流入降幅为GDP的8%） → 货币政策紧缩（短期利率上调20%） → 货币大幅贬值（实际汇率下降45%） → GDP和股价自我强化式下跌（分别跌7%和66%） → 失业率上升6%，通胀率最高达20% → 金融机构面临压力，央行外汇储备减少37% |
| **Lag（时滞）** | 1998-2003年，持续5年 |
| **Threshold（临界值）** | 资本流入降幅超过GDP的8%，短期利率上调20%，实际汇率下降45% |
| **前提与约束（Premises）** | 高债务水平（尤其外币债务）；依赖外国资金流入；存在约一半典型风险因素（如长期忽视通胀管控） |
| **Falsification（证伪条件）** | 若外部冲击未导致危机或危机程度较轻，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同多米诺骨牌，第一块倒下引发连锁反应

### 🔗 文字版因果链

1. 外资流入减少（资本流入降幅为GDP的8%）
2. 货币政策紧缩（短期利率上调20%）
3. 货币大幅贬值（实际汇率下降45%）
4. GDP和股价自我强化式下跌（分别跌7%和66%）
5. 失业率上升6%，通胀率最高达20%
6. 金融机构面临压力，央行外汇储备减少37%
