# 自我强化的泡沫周期（不可持续发展）

> 属于因果簇：[[哥伦比亚1995-2008年通胀性去杠杆化周期中的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加、经济增长强劲、房地产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期（不可持续发展） |
| **Chain（传导链）** | 资本流入增加，债务累积 → 经济增长强劲，房地产回报高 → 这些因素相互促进，形成正反馈 → 债务达到危机前峰值，占GDP的58%，其中外币债务占GDP的30% → 经济脆弱性增加，对外资依赖加深 |
| **Lag（时滞）** | 约3年（1995-1998） |
| **Threshold（临界值）** | 债务占GDP超过58%，外币债务占GDP的30%，经常账户赤字占GDP的5% |
| **前提与约束（Premises）** | 资本流入持续强劲（平均占GDP的8%）；实际汇率升值（峰值16%）；外部环境稳定（未发生外部冲击） |
| **Falsification（证伪条件）** | 若债务和资本流入增加但未导致泡沫或危机，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同吹气球，越吹越大但终将破裂

### 🔗 文字版因果链

1. 资本流入增加，债务累积
2. 经济增长强劲，房地产回报高
3. 这些因素相互促进，形成正反馈
4. 债务达到危机前峰值，占GDP的58%，其中外币债务占GDP的30%
5. 经济脆弱性增加，对外资依赖加深
