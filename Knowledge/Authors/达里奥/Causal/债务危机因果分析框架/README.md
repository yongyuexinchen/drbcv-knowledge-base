# 债务危机因果分析框架（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：债务危机因果分析框架.md

## 总体因果图

- 债务增长超过收入增长 → 债务危机爆发
- 央行印钞和货币化债务 → 债务危机得到缓解
- 债务危机中的财政紧缩 → 经济衰退加深
- 债务危机中的结构性改革 → 经济长期增长恢复
