# 通胀率高企（最高达117%）

> 属于因果簇：[[土耳其1990-1995年恶性通胀性去杠杆化周期]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率下跌26%） |
| **DV（因变量）** | 通胀率高企（最高达117%） |
| **Chain（传导链）** | 货币贬值导致进口商品价格上涨 → 进口成本上升传导至国内物价 → 通胀预期形成，工资-价格螺旋上升 → 央行独立性弱，缺乏有效紧缩政策 → 通胀率持续攀升至117% |
| **Lag（时滞）** | 贬值后数月内通胀上升，萧条阶段达到峰值 |
| **Threshold（临界值）** | 实际汇率贬值超过26%时，通胀压力显著加剧 |
| **前提与约束（Premises）** | 存在大量进口依赖；央行独立性不足；通胀管控长期被忽视 |
| **Falsification（证伪条件）** | 若货币大幅贬值后通胀率未显著上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同本币贬值后，进口奶粉价格翻倍，超市物价全面上涨，最终形成涨价潮

### 🔗 文字版因果链

1. 货币贬值导致进口商品价格上涨
2. 进口成本上升传导至国内物价
3. 通胀预期形成，工资-价格螺旋上升
4. 央行独立性弱，缺乏有效紧缩政策
5. 通胀率持续攀升至117%
