# 自我强化的泡沫周期

> 属于因果簇：[[美国2004-2014年通缩性去杠杆化周期中的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 债务不断增加、经济增长强劲、资产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期 |
| **Chain（传导链）** | 债务增加推动经济增长 → 经济增长提高资产回报 → 高资产回报鼓励更多借债 → 更多借债进一步刺激经济增长，形成正反馈循环 |
| **Lag（时滞）** | 持续数年（2004-2007年） |
| **Threshold（临界值）** | 债务占GDP比例达到349%，增幅为GDP的38% |
| **前提与约束（Premises）** | 债务以美元计价；大多数债权人为美国人；投资流入强劲（平均约占GDP的8%）；经常账户赤字占GDP的6% |
| **Falsification（证伪条件）** | 如果债务增加但经济增长或资产回报未相应提升，或债务增长未达到临界值，则泡沫周期不会形成 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球：雪球越大，滚得越快，但最终可能因过大而崩溃

### 🔗 文字版因果链

1. 债务增加推动经济增长

3. 高资产回报鼓励更多借债
4. 更多借债进一步刺激经济增长，形成正反馈循环
