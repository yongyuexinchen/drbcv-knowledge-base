# 自我强化的经济萧条和痛苦的去杠杆化

> 属于因果簇：[[美国2004-2014年通缩性去杠杆化周期中的因果机制]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 房地产市场崩盘 |
| **DV（因变量）** | 自我强化的经济萧条和痛苦的去杠杆化 |
| **Chain（传导链）** | 房地产市场崩盘冲击经济 → GDP、股价和房价陷入自我强化式下跌 → 失业率上升 → 金融机构面临巨大压力 → 偿债总额高企使经济脆弱，去杠杆化痛苦 |
| **Lag（时滞）** | 2007-2009年（约2年） |
| **Threshold（临界值）** | 危机前偿债总额达到GDP的68% |
| **前提与约束（Premises）** | 存在前期泡沫阶段积累的债务；债务水平高企；经济面临外部冲击（房地产崩盘） |
| **Falsification（证伪条件）** | 如果房地产崩盘未导致GDP、股价和房价的持续下跌，或失业率未显著上升，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多米诺骨牌：第一块倒下（房地产），引发连锁反应，导致整个系统崩溃

### 🔗 文字版因果链

1. 房地产市场崩盘冲击经济
2. GDP、股价和房价陷入自我强化式下跌
3. 失业率上升
4. 金融机构面临巨大压力
5. 偿债总额高企使经济脆弱，去杠杆化痛苦
