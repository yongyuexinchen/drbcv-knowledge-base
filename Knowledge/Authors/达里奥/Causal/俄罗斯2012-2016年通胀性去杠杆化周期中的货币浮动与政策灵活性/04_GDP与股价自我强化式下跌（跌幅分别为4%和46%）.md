# GDP与股价自我强化式下跌（跌幅分别为4%和46%）

> 属于因果簇：[[俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第4块/8块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币大幅贬值（实际汇率下降30%） |
| **DV（因变量）** | GDP与股价自我强化式下跌（跌幅分别为4%和46%） |
| **Chain（传导链）** | 货币贬值导致进口成本上升，企业利润下降 → 企业投资和消费减少，GDP下滑 → 经济前景恶化，股市投资者信心下降，股价暴跌 → 股价下跌进一步打击财富效应和融资能力，加剧经济下滑 |
| **Lag（时滞）** | 中期（1-2年） |
| **Threshold（临界值）** | 实际汇率下降30% |
| **前提与约束（Premises）** | 经济高度依赖外资流入；存在大量外币债务；货币贬值幅度较大 |
| **Falsification（证伪条件）** | 如果货币大幅贬值但GDP和股价未同步下跌，或下跌幅度远小于预期，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像本币贬值导致进口商品涨价，企业成本上升，利润缩水，股市随之走低，形成恶性循环。

### 🔗 文字版因果链

1. 货币贬值导致进口成本上升，企业利润下降
2. 企业投资和消费减少，GDP下滑
3. 经济前景恶化，股市投资者信心下降，股价暴跌
4. 股价下跌进一步打击财富效应和融资能力，加剧经济下滑
