# 重新获得竞争力

> 属于因果簇：[[俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第8块/8块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 本国货币大幅贬值（实际汇率跌至-17%） |
| **DV（因变量）** | 重新获得竞争力 |
| **Chain（传导链）** | 货币贬值使本国商品在国际市场上更便宜 → 出口增加，进口减少 → 贸易平衡改善 → 经济竞争力提升 |
| **Lag（时滞）** | 中期（1-2年） |
| **Threshold（临界值）** | 实际汇率跌至-17% |
| **前提与约束（Premises）** | 出口产品具有价格弹性；国内生产能力未受严重破坏；贸易伙伴未设置壁垒 |
| **Falsification（证伪条件）** | 如果货币贬值但出口未增加或竞争力未提升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像打折促销，价格降低吸引更多顾客，销量上升，市场份额扩大。

### 🔗 文字版因果链

1. 货币贬值使本国商品在国际市场上更便宜
2. 出口增加，进口减少
3. 贸易平衡改善
4. 经济竞争力提升
