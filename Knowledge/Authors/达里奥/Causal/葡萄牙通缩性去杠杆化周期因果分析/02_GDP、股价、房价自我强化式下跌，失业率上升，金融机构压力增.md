# GDP、股价、房价自我强化式下跌，失业率上升，金融机构压力增

> 属于因果簇：[[葡萄牙通缩性去杠杆化周期因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（投资组合流入降幅为GDP的40%） |
| **DV（因变量）** | GDP、股价、房价自我强化式下跌，失业率上升，金融机构压力增大 |
| **Chain（传导链）** | 外资流入减少导致资金紧张 → 偿债总额高（GDP的48%）使经济易受冲击 → 欧洲债务危机冲击引发资产价格下跌 → 资产价格下跌导致收入减少和进一步去杠杆 → 经济陷入自我强化式萧条 |
| **Lag（时滞）** | 萧条阶段持续约5年（2008-2013年） |
| **Threshold（临界值）** | 外资流入降幅为GDP的40%；GDP跌幅10%，股价跌65%，房价跌18%，失业率上升9% |
| **前提与约束（Premises）** | 危机前偿债总额达到GDP的48%；存在外部冲击（欧洲债务危机）；政府增加借款应对危机，财政赤字占GDP的8% |
| **Falsification（证伪条件）** | 如果外资流入减少但GDP、股价、房价未出现持续下跌，或失业率未上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个依赖外部借款的人，突然借不到钱，但每月还要还高额利息，只能变卖资产，资产价格下跌又让情况更糟。

### 🔗 文字版因果链

1. 外资流入减少导致资金紧张
2. 偿债总额高（GDP的48%）使经济易受冲击
3. 欧洲债务危机冲击引发资产价格下跌
4. 资产价格下跌导致收入减少和进一步去杠杆
5. 经济陷入自我强化式萧条
