## 总体因果图

- 大量资本流入和债务增加（尤其外币债务占GDP的32%） → 自我强化的泡沫周期（股市回报丰厚、经济增长强劲、实际汇率升值
- 外资流入骤减（资本流入降幅为GDP的40%） → 经济萧条和国际收支 货币危机（GDP下跌14%，股市下跌74
- 货币大幅贬值（实际汇率下降50%） → 债务占GDP比例上升（增加73%，年化19%）
- 实施紧缩政策、积极处理坏账、结构性改革（使用9个政策工具中的5个） → 和谐的去杠杆化（债务占GDP下降129%，经常账户改善，竞争
