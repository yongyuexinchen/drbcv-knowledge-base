# 泡沫阶段的经济增长、股市回报和债务不可持续扩张

> 属于因果簇：[[冰岛2005-2016年通胀性去杠杆化周期中的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入和债务积累（以外币计价，占GDP的691%） |
| **DV（因变量）** | 泡沫阶段的经济增长、股市回报和债务不可持续扩张 |
| **Chain（传导链）** | 大量资本流入导致投资强劲（平均占GDP的37%） → 投资填补经常账户缺口，刺激经济增长（增速达7%） → 高资产回报率（股票年化回报12%）鼓励更多借债 → 债务和资金增加进一步推动经济增长，形成自我强化泡沫 |
| **Lag（时滞）** | 泡沫阶段持续约3年（2005-2008年） |
| **Threshold（临界值）** | 债务占GDP达到1173%，其中外币债务占GDP的691% |
| **前提与约束（Premises）** | 经济依赖外资流入；相关国家经济状况恶化；债务以外币计价为主 |
| **Falsification（证伪条件）** | 如果资本流入减少但债务未导致泡沫或经济危机，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人靠借外债过度消费，短期生活水平提高，但债务越滚越大，一旦外部资金断供，就会陷入破产危机。

### 🔗 文字版因果链

1. 大量资本流入导致投资强劲（平均占GDP的37%）
2. 投资填补经常账户缺口，刺激经济增长（增速达7%）
3. 高资产回报率（股票年化回报12%）鼓励更多借债
4. 债务和资金增加进一步推动经济增长，形成自我强化泡沫
