# 和谐的去杠杆化（1931年开始，失业率下降8%，债务占GDP

> 属于因果簇：[[英国1927-1936年通缩性去杠杆化周期因果分析]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者提供充足的经济刺激（切断英镑与黄金挂钩、M0增幅达GDP的2%、利率降至0%、实际汇率平均-8%） |
| **DV（因变量）** | 和谐的去杠杆化（1931年开始，失业率下降8%，债务占GDP比例下降29%） |
| **Chain（传导链）** | 决策者实施刺激性货币政策（切断金本位、增加货币供应、降低利率、贬值汇率） → 名义经济增长率（平均4%）高于名义利率（3%） → 实际收入水平上升，偿还旧债能力增强 → 债务与收入比率下降，失业率下降，经济逐步复苏 → 实际GDP在5年后达到之前峰值，股价在8年内恢复 |
| **Lag（时滞）** | 刺激政策实施后约1-2年显现效果 |
| **Threshold（临界值）** | 名义经济增长率高于名义利率（4% > 3%） |
| **前提与约束（Premises）** | 决策者愿意采取积极的货币政策刺激；英国未积极管控金融机构和处理坏账（仅使用9个政策工具中的1个）；外部环境允许货币贬值和利率下调 |
| **Falsification（证伪条件）** | 如果刺激政策实施后，名义经济增长率未高于名义利率，或债务占GDP比例未下降，或失业率未下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人负债累累时，如果找到高薪工作（高收入增长率），同时降低利息负担（低利率），就能逐步还清债务，而不是陷入债务螺旋。

### 🔗 文字版因果链

1. 决策者实施刺激性货币政策（切断金本位、增加货币供应、降低利率、贬值汇率）
2. 名义经济增长率（平均4%）高于名义利率（3%）
3. 实际收入水平上升，偿还旧债能力增强
4. 债务与收入比率下降，失业率下降，经济逐步复苏
5. 实际GDP在5年后达到之前峰值，股价在8年内恢复
