# 汇率下跌和恶性通胀的旋涡

> 属于因果簇：[[阿根廷恶性通胀性去杠杆化周期的因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩措施未能带来必要的调整 |
| **DV（因变量）** | 汇率下跌和恶性通胀的旋涡 |
| **Chain（传导链）** | 决策者试图通过紧缩措施应对资本外流 → 紧缩措施未能实现必要的经济调整 → 阿根廷陷入汇率下跌和通胀螺旋 → 实际汇率跌至-135%，通胀率超过10000% |
| **Lag（时滞）** | 1987-1990年间逐步显现 |
| **Threshold（临界值）** | 实际汇率跌幅超过135%，通胀率超过10000% |
| **前提与约束（Premises）** | 存在约一半导致通胀率螺旋式上升的典型风险因素；长期忽视对通胀的管控；决策者未能有效使用印钞以外的政策工具 |
| **Falsification（证伪条件）** | 如果紧缩措施成功稳定经济而未引发恶性通胀，或通胀率未超过10000%，则此断言不成立 |
| **Confidence（确信度）** | well-established |

1. 决策者试图通过紧缩措施应对资本外流

3. 阿根廷陷入汇率下跌和通胀螺旋
4. 实际汇率跌至-135%，通胀率超过10000%
