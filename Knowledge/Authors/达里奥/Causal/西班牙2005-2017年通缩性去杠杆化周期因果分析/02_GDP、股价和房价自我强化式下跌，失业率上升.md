# GDP、股价和房价自我强化式下跌，失业率上升

> 属于因果簇：[[西班牙2005-2017年通缩性去杠杆化周期因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（降幅为GDP的16%） |
| **DV（因变量）** | GDP、股价和房价自我强化式下跌，失业率上升 |
| **Chain（传导链）** | 外资流入减少导致资金紧张 → 资金紧张引发资产价格下跌 → 资产价格下跌导致财富缩水和企业盈利下降 → 企业盈利下降引发裁员和失业率上升 → 失业率上升进一步减少消费和投资，加剧经济萎缩 |
| **Lag（时滞）** | 2008-2013年，持续5年 |
| **Threshold（临界值）** | 外资流入降幅为GDP的16%，偿债总额达到GDP的64% |
| **前提与约束（Premises）** | 西班牙面临欧洲债务危机冲击；债务负担沉重，偿债总额高；金融机构脆弱，易受冲击 |
| **Falsification（证伪条件）** | 如果外资流入减少但GDP、股价和房价未出现显著下跌，或失业率未上升，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多米诺骨牌，第一块倒下后，连锁反应导致整个系统崩溃

### 🔗 文字版因果链

1. 外资流入减少导致资金紧张
2. 资金紧张引发资产价格下跌
3. 资产价格下跌导致财富缩水和企业盈利下降
4. 企业盈利下降引发裁员和失业率上升
5. 失业率上升进一步减少消费和投资，加剧经济萎缩
