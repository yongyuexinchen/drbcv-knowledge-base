# 西班牙2005-2017年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：西班牙2005-2017年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加、经济增长强劲、资产回报丰厚 → 自我强化的泡沫周期
- 外资流入减少（降幅为GDP的16%） → GDP、股价和房价自我强化式下跌，失业率上升
- 欧洲央行提供充足的经济刺激（M0增幅达GDP的15%，利率降至-1%） → 和谐的去杠杆化，经济复苏
