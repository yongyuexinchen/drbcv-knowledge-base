# 债务占GDP的比例增加33%（年化增幅7%）

> 属于因果簇：[[阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（导致以外币计价的偿债负担加重）及政府举借新债应对危机 |
| **DV（因变量）** | 债务占GDP的比例增加33%（年化增幅7%） |
| **Chain（传导链）** | 货币贬值导致以外币计价的债务负担加重 → 政府需要举借新债应对危机（财政赤字占GDP的5%） → 总债务占GDP比例上升 |
| **Lag（时滞）** | 约5年（1980-1985年） |
| **Threshold（临界值）** | 财政赤字占GDP的5%峰值 |
| **前提与约束（Premises）** | 存在大量外币债务；政府财政赤字扩大；货币持续贬值 |
| **Falsification（证伪条件）** | 如果货币贬值但债务占GDP比例未上升，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像借外币买房，本币贬值后月供突然增加，债务负担加重

### 🔗 文字版因果链

1. 货币贬值导致以外币计价的债务负担加重
2. 政府需要举借新债应对危机（财政赤字占GDP的5%）
3. 总债务占GDP比例上升
