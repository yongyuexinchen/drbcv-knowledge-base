# 汇率急剧下跌和恶性通胀（通胀率超过1000%）

> 属于因果簇：[[阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 紧缩措施未能带来必要的调整 |
| **DV（因变量）** | 汇率急剧下跌和恶性通胀（通胀率超过1000%） |
| **Chain（传导链）** | 紧缩措施未能有效调整经济 → 资本外流持续，货币贬值加剧 → 实际汇率触底（降至-138%） → 通胀率螺旋式上升，达到峰值超过1000% |
| **Lag（时滞）** | 约5年（1980-1985年） |
| **Threshold（临界值）** | 实际短期利率较低（存在约一半典型风险因素） |
| **前提与约束（Premises）** | 决策者未能有效处理不良资本流动；存在导致通胀率螺旋式上升的风险因素；结构性改革不足 |
| **Falsification（证伪条件）** | 如果紧缩措施成功调整经济而未引发恶性通胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 紧缩措施未能有效调整经济
2. 资本外流持续，货币贬值加剧
3. 实际汇率触底（降至-138%）
4. 通胀率螺旋式上升，达到峰值超过1000%
