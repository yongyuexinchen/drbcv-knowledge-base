# 经济萧条和国际收支危机 货币危机（1980-1985年）

> 属于因果簇：[[阿根廷1977-1988年恶性通胀性去杠杆化周期因果分析]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 高债务水平（尤其以外币计价的债务占GDP的15%） |
| **DV（因变量）** | 经济萧条和国际收支危机/货币危机（1980-1985年） |
| **Chain（传导链）** | 高债务水平使阿根廷容易受到外部冲击伤害 → 20世纪80年代拉丁美洲债务危机导致外资流入减少（资本流入降幅为GDP的9%） → 外资减少迫使货币政策收紧（短期利率上调逾250%） → 货币大幅贬值（实际汇率下降93%） → GDP和股价陷入自我强化式下跌（跌幅分别为14%和91%） → 失业率上升3%，金融机构面临巨大压力 |
| **Lag（时滞）** | 约3年（泡沫阶段1977-1980年，萧条阶段1980-1985年） |
| **Threshold（临界值）** | 债务占GDP的39%（危机前峰值），其中外币债务占GDP的15% |
| **前提与约束（Premises）** | 存在外部冲击（如拉丁美洲债务危机）；依赖外国资金流入；实际汇率高估（峰值达70%） |
| **Falsification（证伪条件）** | 如果高债务水平未导致外资流入大幅减少或货币危机，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人背负高额外债，一旦外部收入中断，就会陷入财务危机

### 🔗 文字版因果链

1. 高债务水平使阿根廷容易受到外部冲击伤害
2. 20世纪80年代拉丁美洲债务危机导致外资流入减少（资本流入降幅为GDP的9%）
3. 外资减少迫使货币政策收紧（短期利率上调逾250%）
4. 货币大幅贬值（实际汇率下降93%）
5. GDP和股价陷入自我强化式下跌（跌幅分别为14%和91%）
6. 失业率上升3%，金融机构面临巨大压力
