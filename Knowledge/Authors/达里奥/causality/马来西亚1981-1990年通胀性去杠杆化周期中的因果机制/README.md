# 马来西亚1981-1990年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：马来西亚1981-1990年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 外部压力下放弃钉住汇率制度，允许货币浮动 → 决策者设定利率的灵活性增加，但暂时出现一定程度的通胀
- 大量资本流入、债务不断增加、经济增长强劲（泡沫阶段） → 自我强化的泡沫周期，最终导致经济萧条和国际收支危机 货币危机
- 高债务水平（占GDP的153%，外币债务占GDP的42%） → 马来西亚易受外部冲击伤害，外资流入减少导致货币大幅贬值、股价
- 决策者实施紧缩政策、积极管控金融机构和处理坏账（通货再膨胀阶段） → 债务占GDP比例下降74%，实际GDP恢复，竞争力重新获得
