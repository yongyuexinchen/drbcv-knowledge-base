# 债务占GDP比例下降74%，实际GDP恢复，竞争力重新获得

> 属于因果簇：[[马来西亚1981-1990年通胀性去杠杆化周期中的因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策、积极管控金融机构和处理坏账（通货再膨胀阶段） |
| **DV（因变量）** | 债务占GDP比例下降74%，实际GDP恢复，竞争力重新获得 |
| **Chain（传导链）** | 放弃钉住汇率后，实施紧缩政策减少进口支出（经常账户余额增幅为GDP的9%） → 提高本国货币吸引力，吸引资本回流 → 银行国有化并提供流动性，积极处理坏账（使用9个政策工具中的5个） → 实际经济增速提升，推动名义收入增加 → 债务占GDP比例下降74%（年化降幅21%），实际汇率跌至-12%低点，竞争力恢复 → 实际GDP用1.8年恢复至峰值，股价6年恢复 |
| **Lag（时滞）** | 调整期约3-4年（1987-1990年），GDP恢复需1.8年，股价恢复需6年 |
| **Threshold（临界值）** | 经常账户余额增幅达到GDP的9%，债务占GDP比例年化降幅21% |
| **前提与约束（Premises）** | 决策者采取积极干预措施（国有化、提供流动性）；紧缩政策得以实施并持续；外部环境不再恶化，出口恢复 |
| **Falsification（证伪条件）** | 如果实施紧缩政策后债务比例未下降或经济未恢复，或银行国有化导致效率低下反而恶化危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同病人经过手术（银行国有化）和节食（紧缩政策），虽然痛苦但最终康复（债务下降、经济恢复），比放任不管更快痊愈。

### 🔗 文字版因果链

1. 放弃钉住汇率后，实施紧缩政策减少进口支出（经常账户余额增幅为GDP的9%）
2. 提高本国货币吸引力，吸引资本回流
3. 银行国有化并提供流动性，积极处理坏账（使用9个政策工具中的5个）
4. 实际经济增速提升，推动名义收入增加
5. 债务占GDP比例下降74%（年化降幅21%），实际汇率跌至-12%低点，竞争力恢复
6. 实际GDP用1.8年恢复至峰值，股价6年恢复
