# 日本1925-1936年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：日本1925-1936年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 高债务水平（债务总额达GDP的65%） → 经济萧条和痛苦的去杠杆化（1927-1931年）
- 决策者提供充足的经济刺激（切断日元与黄金挂钩、降息至2%、管控金融机构） → 和谐的去杠杆化（1931年后，债务占GDP比例下降18%）
- 长期经济萧条和痛苦去杠杆化 → 日本政局显著变化，东条英机上台
