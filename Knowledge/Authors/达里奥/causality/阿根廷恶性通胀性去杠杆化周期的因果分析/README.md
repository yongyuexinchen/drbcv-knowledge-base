# 阿根廷恶性通胀性去杠杆化周期的因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：阿根廷恶性通胀性去杠杆化周期的因果分析.md

## 总体因果图

- 高额外币计价债务（占GDP的39%）与结构性弱点 → 自我强化的经济萧条和国际收支危机 货币危机
- 紧缩措施未能带来必要的调整 → 汇率下跌和恶性通胀的旋涡
- 阿根廷积极管控金融机构和处理坏账，使用9个典型政策工具中的3个，并实施结构性改革 → 阻止通胀率螺旋式上升，经济恢复
- 阿根廷恶性通胀性去杠杆化危机 → 政局显著影响，卡洛斯·梅内姆上台
