# 债务占GDP比例下降、经济恢复竞争力、实际GDP回升

> 属于因果簇：[[冰岛2005-2016年通胀性去杠杆化周期中的因果机制]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者实施紧缩政策、管控金融机构、处理坏账（使用9个政策工具中的6个） |
| **DV（因变量）** | 债务占GDP比例下降、经济恢复竞争力、实际GDP回升 |
| **Chain（传导链）** | 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的13%） → 提高本国货币吸引力 → 银行国有化并提供流动性，处理坏账 → IMF援助计划支持调整 → 实际经济增速提升增加收入，债务全面削减 → 货币大幅贬值（实际汇率跌至-22%）重新获得竞争力 → 实际GDP在8年内达到之前峰值 |
| **Lag（时滞）** | 通货再膨胀阶段持续约6年（2010-2016年） |
| **Threshold（临界值）** | 债务占GDP比例下降1037%（年化降幅170%） |
| **前提与约束（Premises）** | 决策者愿意采取痛苦但必要的紧缩措施；国际援助（IMF）可用；本国货币可自由浮动 |
| **Falsification（证伪条件）** | 如果政策实施后债务未下降或经济未恢复，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像病人经历痛苦的手术和康复训练，虽然过程艰难，但最终恢复健康，重新站起来。

### 🔗 文字版因果链

1. 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的13%）
2. 提高本国货币吸引力
3. 银行国有化并提供流动性，处理坏账
4. IMF援助计划支持调整
5. 实际经济增速提升增加收入，债务全面削减
6. 货币大幅贬值（实际汇率跌至-22%）重新获得竞争力
7. 实际GDP在8年内达到之前峰值
