# 冰岛2005-2016年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：冰岛2005-2016年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 大量资本流入和债务积累（以外币计价，占GDP的691%） → 泡沫阶段的经济增长、股市回报和债务不可持续扩张
- 外资流入减少（资本流入降幅为GDP的49%） → 货币政策收紧、货币大幅贬值、经济自我强化式下跌
- 决策者实施紧缩政策、管控金融机构、处理坏账（使用9个政策工具中的6个） → 债务占GDP比例下降、经济恢复竞争力、实际GDP回升
