# 政治格局变化，民粹主义领导人上台

> 属于因果簇：[[法国1926-1938年通缩性去杠杆化周期分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济萧条和痛苦的去杠杆化 |
| **DV（因变量）** | 政治格局变化，民粹主义领导人上台 |
| **Chain（传导链）** | 长期经济萧条（1929-1936年）导致失业和民生困难 → 民众对现有政府不满情绪积累 → 民粹主义领导人（莱昂·布鲁姆）获得支持 → 1936年上台执政 |
| **Lag（时滞）** | 经济萧条持续数年后（约7年） |
| **Threshold（临界值）** | GDP累计下跌超过15%，且持续时间超过5年 |
| **前提与约束（Premises）** | 民主政治体制允许政权更迭；经济困境未得到及时有效缓解；民粹主义领导人提出有吸引力的替代方案 |
| **Falsification（证伪条件）** | 若经济萧条后执政党仍获连任或民粹主义未上台，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同长期生病的人会尝试偏方，经济长期低迷时民众也倾向于尝试激进的政治方案

### 🔗 文字版因果链

1. 长期经济萧条（1929-1936年）导致失业和民生困难
2. 民众对现有政府不满情绪积累
3. 民粹主义领导人（莱昂·布鲁姆）获得支持
4. 1936年上台执政
