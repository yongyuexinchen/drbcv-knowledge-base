# 秘鲁1980-1986年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：秘鲁1980-1986年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 高额外债（占GDP的107%，其中106%为外币计价） → 经济萧条和国际收支危机 货币危机（1982-1985年）
- 货币贬值（贬值53%） → 债务占GDP比例增加163%（年化42%）
- 实施紧缩政策、管控金融机构、IMF援助和结构性改革 → 债务占GDP比例下降88%，经济恢复增长
- 经济危机 → 政治变革（阿兰·加西亚·佩雷斯上台）
