# 和谐的去杠杆化（债务占GDP比例下降，经济恢复增长）

> 属于因果簇：[[阿根廷1998-2012年通胀性去杠杆化周期中的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者放弃钉住汇率制度并实施紧缩政策 |
| **DV（因变量）** | 和谐的去杠杆化（债务占GDP比例下降，经济恢复增长） |
| **Chain（传导链）** | 放弃钉住汇率，允许货币浮动 → 货币大幅贬值（实际汇率跌至-42%），增强出口竞争力 → 经常账户改善（余额增幅为GDP的7%） → 实施紧缩政策，减少进口支出 → 积极处理坏账、国有化银行、提供流动性 → 获得IMF援助，实施结构性改革 → 名义收入增加，债务占GDP比例下降140% → 实际GDP在5年内恢复至峰值，股价7年内恢复 |
| **Lag（时滞）** | 2002-2007年，约5年 |
| **Threshold（临界值）** | 债务占GDP比例下降140%（年化降幅15%）；实际汇率跌至-42%；经常账户余额增幅为GDP的7% |
| **前提与约束（Premises）** | 决策者愿意放弃钉住汇率；实施足够的紧缩政策；积极管理金融机构和处理坏账；获得外部援助（IMF）；结构性改革增强劳动力市场灵活性 |
| **Falsification（证伪条件）** | 如果放弃钉住汇率后未出现经常账户改善和债务比例下降，则此因果链不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人承认债务问题，削减开支、增加收入，虽然短期痛苦，但长期恢复财务健康。

### 🔗 文字版因果链

1. 放弃钉住汇率，允许货币浮动
2. 货币大幅贬值（实际汇率跌至-42%），增强出口竞争力
3. 经常账户改善（余额增幅为GDP的7%）
4. 实施紧缩政策，减少进口支出
5. 积极处理坏账、国有化银行、提供流动性
6. 获得IMF援助，实施结构性改革
7. 名义收入增加，债务占GDP比例下降140%
8. 实际GDP在5年内恢复至峰值，股价7年内恢复
