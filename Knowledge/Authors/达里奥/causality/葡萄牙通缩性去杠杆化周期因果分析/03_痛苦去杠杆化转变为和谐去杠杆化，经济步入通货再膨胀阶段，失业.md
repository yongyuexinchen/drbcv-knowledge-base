# 痛苦去杠杆化转变为和谐去杠杆化，经济步入通货再膨胀阶段，失业

> 属于因果簇：[[葡萄牙通缩性去杠杆化周期因果分析]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 欧洲央行提供充足经济刺激（M0增幅达GDP的15%，利率降至0%，实际汇率平均-1%） |
| **DV（因变量）** | 痛苦去杠杆化转变为和谐去杠杆化，经济步入通货再膨胀阶段，失业率下降，债务占GDP比例下降 |
| **Chain（传导链）** | 央行提供流动性，降低利率 → 名义经济增长率高于名义利率（增长率2% vs 利率1.7%） → 债务违约和偿还旧债降低债务与收入比率 → 失业率下降，经济恢复增长 |
| **Lag（时滞）** | 通货再膨胀阶段从2013年开始，实际GDP用了9年才达到之前峰值 |
| **Threshold（临界值）** | M0增幅达GDP的15%；利率降至0%；经济增长率平均2%，主权长期利率1.7% |
| **前提与约束（Premises）** | 葡萄牙积极管控金融机构和处理坏账，使用了9个典型政策工具中的4个；受益于IMF援助计划；实施结构性改革增强劳动力市场灵活性 |
| **Falsification（证伪条件）** | 如果央行刺激后名义增长率未超过名义利率，或债务比率未下降，或失业率未下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像给一个溺水的人扔救生圈，先让他浮起来，再慢慢游回岸边，虽然花时间，但最终能上岸。

### 🔗 文字版因果链

1. 央行提供流动性，降低利率
2. 名义经济增长率高于名义利率（增长率2% vs 利率1.7%）
3. 债务违约和偿还旧债降低债务与收入比率
4. 失业率下降，经济恢复增长
