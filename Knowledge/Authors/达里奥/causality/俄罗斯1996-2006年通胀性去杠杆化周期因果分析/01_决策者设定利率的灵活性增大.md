# 决策者设定利率的灵活性增大

> 属于因果簇：[[俄罗斯1996-2006年通胀性去杠杆化周期因果分析]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外部压力下放弃钉住汇率制度，任货币浮动 |
| **DV（因变量）** | 决策者设定利率的灵活性增大 |
| **Chain（传导链）** | 外部压力导致资本外流和货币贬值压力 → 放弃钉住汇率，允许货币自由浮动 → 货币贬值吸收外部冲击，减少外汇储备消耗 → 央行不再受汇率目标约束，可自主调整利率以应对国内经济状况 → 利率设定灵活性增强，有助于实施独立货币政策 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 货币浮动后，外汇储备不再持续大幅下降 |
| **前提与约束（Premises）** | 国家面临外部压力（如资本外流、货币危机）；决策者愿意承受货币贬值的短期通胀后果；存在一定的外汇储备或市场机制支持浮动汇率 |
| **Falsification（证伪条件）** | 如果货币浮动后，利率灵活性未增强，或央行仍受其他约束（如债务美元化）而无法自主设定利率 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像松开刹车让车自然减速，虽然会颠簸，但司机能更灵活地控制方向盘和油门，而不是一直踩着刹车不放。

### 🔗 文字版因果链

1. 外部压力导致资本外流和货币贬值压力
2. 放弃钉住汇率，允许货币自由浮动
3. 货币贬值吸收外部冲击，减少外汇储备消耗
4. 央行不再受汇率目标约束，可自主调整利率以应对国内经济状况
5. 利率设定灵活性增强，有助于实施独立货币政策
