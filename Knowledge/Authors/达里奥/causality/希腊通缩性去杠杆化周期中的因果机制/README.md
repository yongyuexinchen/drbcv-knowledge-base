# 希腊通缩性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：希腊通缩性去杠杆化周期中的因果机制.md

## 总体因果图

- 债务不断增加、经济增长强劲、资产回报丰厚 → 自我强化的泡沫周期
- 外资流入减少（资本流入降幅为GDP的34%） → 货币政策收紧（短期利率上调86%）
- 货币政策收紧（短期利率上调86%） → GDP、股价和房价自我强化式下跌，失业率上升
- 债务占GDP比例增加101%（年化增幅11%） → 去杠杆化未能实现，经济持续萧条
- 希腊经济危机和痛苦去杠杆化 → 阿莱克西斯·齐普拉斯上台（民粹主义领导人）
