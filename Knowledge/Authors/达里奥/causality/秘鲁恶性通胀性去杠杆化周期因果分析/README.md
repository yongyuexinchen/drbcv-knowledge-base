# 秘鲁恶性通胀性去杠杆化周期因果分析（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：秘鲁恶性通胀性去杠杆化周期因果分析.md

## 总体因果图

- 债务水平高且以外币计价（占GDP的182%） → 经济萧条和国际收支危机 货币危机
- 紧缩措施未能带来必要的调整 → 汇率下跌和恶性通胀旋涡
- 银行国有化和提供流动性 → 金融机构压力缓解
- 结构性改革力度不足 → 通胀率螺旋式上升持续
- 放弃印蒂采用索尔 → 经济稳定和恢复
