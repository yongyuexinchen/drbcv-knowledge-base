# 债务占GDP比例增加（年化增幅12%）

> 属于因果簇：[[俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（导致以外币计价的偿债负担加重） |
| **DV（因变量）** | 债务占GDP比例增加（年化增幅12%） |
| **Chain（传导链）** | 货币贬值，本币价值下降 → 以外币计价的债务折算成本币后金额增加 → 债务总额上升，而GDP可能因贬值而下降或增长放缓 → 债务占GDP比例上升 |
| **Lag（时滞）** | 短期至中期（1年内） |
| **Threshold（临界值）** | 货币贬值幅度大，外币债务占GDP的21% |
| **前提与约束（Premises）** | 存在大量外币计价债务；货币贬值幅度显著；GDP增长不足以抵消债务增加 |
| **Falsification（证伪条件）** | 如果货币贬值但债务占GDP比例未增加或增幅小于12%，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用外币贷款买房，本币贬值后，房贷压力瞬间增大。

### 🔗 文字版因果链

1. 货币贬值，本币价值下降
2. 以外币计价的债务折算成本币后金额增加
3. 债务总额上升，而GDP可能因贬值而下降或增长放缓
4. 债务占GDP比例上升
