# 自我强化的泡沫周期（不可持续发展）

> 属于因果簇：[[俄罗斯2005-2011年通胀性去杠杆化周期中的因果机制]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 大量资本流入、债务增加、经济增长强劲、资产回报丰厚 |
| **DV（因变量）** | 自我强化的泡沫周期（不可持续发展） |
| **Chain（传导链）** | 资本流入增加，债务水平上升 → 经济增长强劲，资产回报率高 → 高回报鼓励更多借债和投资，进一步推动增长 → 形成正反馈循环，导致经济过热和泡沫积累 |
| **Lag（时滞）** | 中期（2005-2008年，约3年） |
| **Threshold（临界值）** | 债务占GDP达66%，外币债务占GDP的21%，投资流入占GDP的10%，GDP增速8%，GDP缺口8%，股票年化回报率46% |
| **前提与约束（Premises）** | 依赖外资流入；相关国家经济状况恶化；债务以外币计价为主 |
| **Falsification（证伪条件）** | 如果资本流入、债务和资产价格未形成正反馈循环，或未出现不可持续迹象，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像滚雪球，越滚越大，但内部已出现裂缝，最终会崩解。

### 🔗 文字版因果链

1. 资本流入增加，债务水平上升
2. 经济增长强劲，资产回报率高
3. 高回报鼓励更多借债和投资，进一步推动增长
4. 形成正反馈循环，导致经济过热和泡沫积累
