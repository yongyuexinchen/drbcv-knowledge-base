# 痛苦的去杠杆化阶段持续时间相对较短（实际GDP用1.8年恢复

> 属于因果簇：[[厄瓜多尔1995-2009年通胀性去杠杆化周期因果分析]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 决策者放弃钉住汇率制度并实施紧缩政策 |
| **DV（因变量）** | 痛苦的去杠杆化阶段持续时间相对较短（实际GDP用1.8年恢复） |
| **Chain（传导链）** | 放弃钉住汇率制度允许货币贬值 → 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的11%） → 提高本国货币吸引力，吸引资本回流 → 积极管控金融机构和处理坏账（使用9个政策工具） → 债务占GDP比例下降79%，经济恢复增长 |
| **Lag（时滞）** | 约1.8年（实际GDP恢复至峰值） |
| **Threshold（临界值）** | 经常账户余额增幅达到GDP的11%时，经济恢复加速 |
| **前提与约束（Premises）** | 决策者采取积极干预措施（银行国有化、提供流动性、购买问题资产）；获得IMF援助计划支持；实施结构性改革增强劳动力市场灵活性 |
| **Falsification（证伪条件）** | 若实施紧缩政策但经济恢复时间超过3年或债务比例未下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同病人接受痛苦的手术和严格康复计划，虽然短期痛苦，但比拖延治疗更快恢复健康。

### 🔗 文字版因果链

1. 放弃钉住汇率制度允许货币贬值
2. 实施紧缩政策减少进口支出（经常账户余额增幅为GDP的11%）
3. 提高本国货币吸引力，吸引资本回流
4. 积极管控金融机构和处理坏账（使用9个政策工具）
5. 债务占GDP比例下降79%，经济恢复增长
