# 菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性（因果簇）

> 因果簇索引：7 个子因果卡。父卡文件：菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性.md

## 总体因果图

- 放弃钉住汇率制度，允许货币浮动 → 决策者设定利率的更大灵活性
- 高额外币计价债务（占GDP的56%） → 经济易受外资撤出影响，导致国际收支危机 货币危机
- 外资流入减少（资本流入降幅为GDP的9%） → 货币政策收紧（短期利率上调34%）和货币大幅贬值（实际汇率下
- 货币疲软（实际汇率下降） → 通胀率高企且不断上升（最高达58%）
- 放弃捍卫货币（外汇储备减少100%） → 痛苦的去杠杆化阶段持续时间略短于平均水平
- 实施充足的紧缩政策（减少进口支出，经常账户余额增幅为GDP的7%） → 提高本国货币的吸引力，促进经济恢复
- 积极管控金融机构和处理坏账（使用9个典型政策工具中的7个） → 和谐的去杠杆化（债务占GDP比例下降9%，年化降幅1%）
