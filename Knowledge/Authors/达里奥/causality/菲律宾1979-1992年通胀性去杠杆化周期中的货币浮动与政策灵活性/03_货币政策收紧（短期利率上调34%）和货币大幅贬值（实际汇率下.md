# 货币政策收紧（短期利率上调34%）和货币大幅贬值（实际汇率下

> 属于因果簇：[[菲律宾1979-1992年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第3块/7块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资流入减少（资本流入降幅为GDP的9%） |
| **DV（因变量）** | 货币政策收紧（短期利率上调34%）和货币大幅贬值（实际汇率下降16%） |
| **Chain（传导链）** | 外部冲击导致外资流入减少 → 资本流入降幅达GDP的9% → 为应对资本外流，央行收紧货币政策，短期利率上调34% → 同时货币贬值，实际汇率下降16% |
| **Lag（时滞）** | 短期（冲击后迅速反应） |
| **Threshold（临界值）** | 资本流入降幅超过GDP的9% |
| **前提与约束（Premises）** | 存在高额外币债务和经常账户赤字；央行优先维护汇率稳定或控制通胀；外部冲击（如大宗商品价格下跌）发生 |
| **Falsification（证伪条件）** | 如果外资流入减少但利率和汇率没有相应变化，或者变化幅度远小于预期，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像银行突然抽贷，企业不得不提高借款利率并贱卖资产（货币贬值）来应对

### 🔗 文字版因果链

1. 外部冲击导致外资流入减少
2. 资本流入降幅达GDP的9%
3. 为应对资本外流，央行收紧货币政策，短期利率上调34%
4. 同时货币贬值，实际汇率下降16%
