# 奥地利通缩性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：奥地利通缩性去杠杆化周期中的因果机制.md

## 总体因果图

- 外资依赖（大量债务由非奥地利人持有，且以欧元计价，奥地利无货币控制权） → 经济脆弱性增加，易受外资撤出冲击
- 高资产回报率（股票年化回报率20%） → 债务增加和经济增长（GDP增速3%）
- 2008年全球金融危机（外部冲击） → 奥地利经济自我强化式下跌（GDP下降4%，股价下跌66%）
- 欧洲央行提供充足经济刺激（M0增幅达GDP的19%，利率降至0%，实际汇率平均-2%） → 和谐去杠杆化（债务占GDP比例下降74%，失业率平稳，经济恢
