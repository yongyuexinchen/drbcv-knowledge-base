# 韩国1994-2001年通胀性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：韩国1994-2001年通胀性去杠杆化周期中的因果机制.md

## 总体因果图

- 大量资本流入和债务积累（外币计价债务占GDP的27%） → 自我强化的泡沫周期和不可持续的经济增长
- 外资流入减少（资本流入降幅为GDP的9%） → 经济萧条和国际收支危机 货币危机
- 决策者放弃钉住汇率制度，允许货币浮动 → 通胀性去杠杆化周期和后续经济恢复
- 货币贬值（实际汇率降至-50%） → 温和的通胀水平（最高7%）
