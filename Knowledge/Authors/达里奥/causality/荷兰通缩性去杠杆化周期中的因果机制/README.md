# 荷兰通缩性去杠杆化周期中的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：荷兰通缩性去杠杆化周期中的因果机制.md

## 总体因果图

- 债务不断增加、股市回报丰厚、经济增长强劲 → 自我强化的泡沫周期
- 形势逆转（外资流入停止、货币和信贷环境收紧、相关国家经济恶化） → 自我强化的经济萧条和痛苦的去杠杆化
- 欧洲央行提供充足的经济刺激（M0增幅达GDP的16%，利率降至-1%，实际汇率平均-2%） → 和谐的去杠杆化（债务占GDP比例下降，失业率下降）
