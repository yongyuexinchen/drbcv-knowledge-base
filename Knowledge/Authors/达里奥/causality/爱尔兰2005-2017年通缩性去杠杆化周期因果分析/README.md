# 爱尔兰2005-2017年通缩性去杠杆化周期因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：爱尔兰2005-2017年通缩性去杠杆化周期因果分析.md

## 总体因果图

- 债务不断增加、经济增长强劲、房地产市场回报丰厚 → 自我强化的泡沫周期
- 外资流入依赖、货币和信贷环境收紧、相关国家经济状况恶化 → 不可持续的发展局势
- 形势逆转（外部冲击：欧洲债务危机） → 自我强化的经济萧条和痛苦的去杠杆化
- 欧洲央行提供充足的经济刺激 → 和谐的去杠杆化（通货再膨胀阶段）
