# 外汇储备减少26%

> 属于因果簇：[[俄罗斯2012-2016年通胀性去杠杆化周期中的货币浮动与政策灵活性]]（第6块/8块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 央行动用外汇储备维持货币稳定 |
| **DV（因变量）** | 外汇储备减少26% |
| **Chain（传导链）** | 为捍卫货币，央行在外汇市场抛售外汇储备 → 外汇储备持续消耗 → 最终储备减少26% → 但未能阻止货币贬值，决策者放弃捍卫 |
| **Lag（时滞）** | 短期（数月内） |
| **Threshold（临界值）** | 外汇储备减少26% |
| **前提与约束（Premises）** | 央行拥有充足的外汇储备；资本外流压力持续存在；决策者最初选择干预而非浮动 |
| **Falsification（证伪条件）** | 如果央行干预但外汇储备未显著减少，或储备减少后货币稳定，则该断言不成立 |
| **Confidence（确信度）** | well-established |

> 就像用储蓄罐里的钱去堵漏水的水桶，钱越掏越少，但水还是漏，最终只能放弃。
