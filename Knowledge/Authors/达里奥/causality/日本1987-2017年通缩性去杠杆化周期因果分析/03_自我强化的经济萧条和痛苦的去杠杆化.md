# 自我强化的经济萧条和痛苦的去杠杆化

> 属于因果簇：[[日本1987-2017年通缩性去杠杆化周期因果分析]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 房地产市场与股市崩盘 |
| **DV（因变量）** | 自我强化的经济萧条和痛苦的去杠杆化 |
| **Chain（传导链）** | 房地产和股市价格下跌 → 资产价格下跌导致财富缩水 → 企业和居民减少支出，经济萎缩 → 收入下降导致偿债能力恶化 → 金融机构压力增大，信贷收缩 → 进一步压低资产价格，形成负反馈循环 |
| **Lag（时滞）** | 崩盘后迅速显现，持续多年（1989-2013年） |
| **Threshold（临界值）** | 股价下跌67%，房价下跌43%，失业率上升3% |
| **前提与约束（Premises）** | 危机前偿债总额占GDP的78%，经济脆弱；金融机构面临巨大压力 |
| **Falsification（证伪条件）** | 如果资产价格崩盘后经济未持续萧条，或去杠杆化过程未痛苦，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像多米诺骨牌：第一块倒下后，连锁反应导致全部倒塌

### 🔗 文字版因果链

1. 房地产和股市价格下跌
2. 资产价格下跌导致财富缩水
3. 企业和居民减少支出，经济萎缩
4. 收入下降导致偿债能力恶化
5. 金融机构压力增大，信贷收缩
6. 进一步压低资产价格，形成负反馈循环
