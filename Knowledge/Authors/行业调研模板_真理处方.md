# 行业调研模板《真理处方》

> 适用：创新药/半导体/智能眼镜等任何行业调研
> 讲者人设：真理医生（Dr. Ratio）——"望闻问切，开真理的处方"
> 原则：追求真理，不预测、不下注——**给判断，不给赌注；给验证指标，不给玄学结论**

---

## 一、望——行业全景（数据说话）

| 维度 | 内容 | 中立源 |
|------|------|--------|
| 市场规模 | 总量 + 增速（近3年） | 行业协会/官方统计，交叉两家以上 |
| 渗透率 | 当前 vs 天花板（估算逻辑要写清） | 咨询机构报告（标注口径） |
| 竞争格局 | 集中度 CR5/CR10、头部玩家份额 | 财报交叉 |
| 周期位置 | 行业处于导入/成长/成熟/衰退哪一段 | 产业生命周期框架 |

**铁律**：券商研报的单方乐观数据降级使用；必须找至少一个独立来源交叉验证。

## 二、闻——政策与噪声（识别噪音）

- 政策风向：监管文件/补贴/集采/出口管制（这些是真信号）
- 市场情绪：媒体热度、二级市场炒作（这些是噪声，标注"情绪面"）
- 舆论焦点 vs 基本面事实的差距 = 潜在预期差

## 三、问——产业链拆解（谁在赚谁在亏）

```
上游（材料/设备/算力）→ 中游（制造/集成）→ 下游（品牌/应用/客户）
```

每环节问三个问题：
1. 毛利率趋势（谁在变肥谁在变瘦）
2. 议价权（卡脖子的是谁，被卡的是谁）
3. 产能/库存周期（谁在囤货谁在去库存）

## 四、切——要害诊断（核心结论）

- **行业命门**：这个行业3年后的胜负手是哪一个变量（只列1-2个，不列十项）
- **护城河**：真护城河（成本/专利/网络效应）vs 假护城河（牌照/补贴/情绪）
- **拐点信号**：什么数据出现 = 趋势反转（量化阈值，比如"XX渗透率过30%"）
- **风险清单**：证伪条件（什么情况出现 = 我错了）

## 五、处方——结论与验证（不预测，给判断框架）

| 输出 | 内容 |
|------|------|
| 行业健康度评级 | 🟢健康 / 🟡观察 / 🔴风险（带理由） |
| 关键验证指标 | 未来N个月盯哪几个数（可机器核验） |
| 下期复盘点 | 上期处方是否应验（留档机制） |

**格式约定**：
- 所有断言标注来源等级（✅中立源 / ⚠️单方源 / 📖推测）
- 结论永远带前提条件（Premises）——"在XX前提下，行业是YY"
- 不写"建议买入/卖出"，写"XX数据出现则结论成立/不成立"
