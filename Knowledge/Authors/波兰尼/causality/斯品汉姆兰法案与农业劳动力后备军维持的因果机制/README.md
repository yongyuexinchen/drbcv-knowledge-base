# 斯品汉姆兰法案与农业劳动力后备军维持的因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：斯品汉姆兰法案与农业劳动力后备军维持的因果机制.md

## 总体因果图

- 斯品汉姆兰法案及济贫补贴制度的存在 → 乡村雇主手中拥有一支可随时动用的顺良的农业劳动力后备军
- 斯品汉姆兰法案的补贴制度 → 农村人口过剩的假象
- 斯品汉姆兰补贴制度在工业城镇的扩散 → 工业资本家对斯品汉姆兰制度的反对与1834年济贫法改革
- 英国城乡统一的济贫法管理 → 劳动力在城乡之间的'振荡'流动而非单向的乡村人口枯竭
