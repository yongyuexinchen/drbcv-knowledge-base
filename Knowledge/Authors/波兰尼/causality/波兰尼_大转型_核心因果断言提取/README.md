# 波兰尼《大转型》核心因果断言提取（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：波兰尼_大转型_核心因果断言提取.md

## 总体因果图

- 金本位制造成的经济压力 → 第一次世界大战
- 货币贬值（金本位下国家调节的合法手段） → 工资和农业收入大幅下降、失业增加、企业银行大量破产
- 新自由主义全球市场乌托邦（无国界、自由流动、减少政府干预） → 冲突加剧（社会动荡、内战、军国主义与原教旨主义武装冲突）
- 缺乏全球性规制机构（尤其是‘最终借款人’） → 致命的经济危机
- 民主政治控制经济（规制与调控） → 真正而广泛的自由
