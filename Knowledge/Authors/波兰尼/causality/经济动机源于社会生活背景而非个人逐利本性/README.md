# 经济动机源于社会生活背景而非个人逐利本性（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：经济动机源于社会生活背景而非个人逐利本性.md

## 总体因果图

- 社会结构中的对称和辐辏制度模式（社会组织形式） → 经济体系的运转（生产与分配秩序）
- 互惠原则（reciprocity） → 生产与家庭生计的维持
- 再分配原则（redistribution） → 劳动分工的形成与政治权力的强化
- 社会对慷慨和荣誉的奖赏（非经济动机） → 经济自利意识的消除与生产积极性的维持
