# 人类性格的退化与悲惨（传统特征毁灭，形成迁移、飘荡、缺少自尊

> 属于因果簇：[[斯品汉姆兰法令对劳动力市场与古典经济学的因果影响]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场组织（按获利原则组织社会） |
| **DV（因变量）** | 人类性格的退化与悲惨（传统特征毁灭，形成迁移、飘荡、缺少自尊和纪律的新类型人） |
| **Chain（传导链）** | 制造业在全国范围扩散，按获利原则组织生产 → 劳动者生存完全依赖于工厂成功 → 定居人群的传统特征被摧毁，转变为新类型人（粗鲁麻木、缺乏自尊和纪律） → 产生不利于个体与普遍幸福的持久罪恶 |
| **Lag（时滞）** | 制造业扩散后数十年内（欧文1817年观察，影响持续一个世纪） |
| **Threshold（临界值）** | 当制造业成为居民生存的唯一依赖时，退化效应显著 |
| **前提与约束（Premises）** | 市场制度的内在倾向未被立法干预所阻遏；获利原则成为社会组织的核心原则；劳动者失去其他生存来源 |
| **Falsification（证伪条件）** | 若制造业扩散地区劳动者性格未发生退化，或生活水平显著提高且幸福感增强，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典经济学家（马尔萨斯、李嘉图）将贫困归因于自然法则的观点冲突；与自由放任主义（伯克、汤森）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像流水线工厂让农民变成机器上的螺丝钉——一旦生存完全依赖工厂，人的独立性和尊严就被磨灭，变成麻木的“工具人”

### 🔗 文字版因果链

1. 制造业在全国范围扩散，按获利原则组织生产
2. 劳动者生存完全依赖于工厂成功
3. 定居人群的传统特征被摧毁，转变为新类型人（粗鲁麻木、缺乏自尊和纪律）
4. 产生不利于个体与普遍幸福的持久罪恶
