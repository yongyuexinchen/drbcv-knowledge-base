# 《大转型》中的因果断言提取（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：大转型_中的因果断言提取.md

## 总体因果图

- 竞争性劳动力市场的建立（1834年《济贫法修正案》后） → 工人阶级的形成与工业资本主义的确立
- 斯品汉姆兰法令（以救济金补助低收入者，保证生存权） → 社会灾难（贫困化、道德堕落、社会无根性）
- 农业革命（圈地运动、农地合并、农业技术改进） → 劳动者失去家庭收入与土地背景，依赖货币工资，推动工业革命
- 早期贸易的剧烈波动 → 失业与未充分就业的迅速增长（且被掩盖）
- 市场机制自我调节带来的社会痛苦（源于竞争性劳动力市场） → 社会的自我保护运动（工厂法、社会立法、工人阶级运动）
