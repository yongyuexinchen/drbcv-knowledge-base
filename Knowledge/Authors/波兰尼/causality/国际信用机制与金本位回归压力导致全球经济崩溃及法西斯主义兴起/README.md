# 国际信用机制与金本位回归压力导致全球经济崩溃及法西斯主义兴起（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：国际信用机制与金本位回归压力导致全球经济崩溃及法西斯主义兴起.md

## 总体因果图

- 国际信用机制（日内瓦/国际联盟主导）人为维持东欧国家支付、预算和汇率平衡 → 美国经济崩溃及全球经济大萧条
- 坚持紧缩通货政策（将通货稳定置于收入和就业稳定之上） → 自由市场和自由政体被牺牲，民主力量削弱，法西斯主义上台
- 市场体系崩溃导致社会陷入制度死结（经济与政治领域群体利益冲突瘫痪） → 法西斯主义情势出现，法西斯运动夺取政权
- 社会主义政党的存在及可能干预财产制度的威胁 → 市场信心破坏，经济陷入混乱，加速法西斯主义情势
