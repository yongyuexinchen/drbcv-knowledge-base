# 圈地运动的社会代价与政府干预的缓冲作用（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：圈地运动的社会代价与政府干预的缓冲作用.md

## 总体因果图

- 圈地运动（土地私有化、牧场化） → 社会紊乱（乡村荒凉、人口减少、农民沦为乞丐小偷）
- 都铎王朝和早期斯图亚特王朝的反圈地立法与王权干预 → 延缓圈地运动速度，减轻社会紊乱程度
- 市场经济体系的建立（商品化劳动力与土地） → 社会关系瓦解与人类栖息地破坏（贫民窟、家庭解体、环境恶化）
