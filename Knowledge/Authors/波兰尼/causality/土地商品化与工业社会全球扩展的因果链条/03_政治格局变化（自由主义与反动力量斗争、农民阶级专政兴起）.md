# 政治格局变化（自由主义与反动力量斗争、农民阶级专政兴起）

> 属于因果簇：[[土地商品化与工业社会全球扩展的因果链条]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地流动化与市场体系扩展 |
| **DV（因变量）** | 政治格局变化（自由主义与反动力量斗争、农民阶级专政兴起） |
| **Chain（传导链）** | 土地流动化导致市场体系对骚乱更敏感 → 中产阶级非军人化，无法保障法律与秩序 → 农民被视为唯一能捍卫秩序的阶层，保守力量（军队、教会）重获荣誉 → 在战后危机中，中产阶级排除工人阶级，农民阶级主导经济政策 |
| **Lag（时滞）** | 19世纪至20世纪20年代 |
| **Threshold（临界值）** | 当市场体系面临崩溃威胁时（如战争、失败、社会结构解体） |
| **前提与约束（Premises）** | 仅当存在武装群众暴动风险时；需要农民阶级未受自由主义毒害；前提是工人阶级政党可能无视市场规则 |
| **Falsification（证伪条件）** | 若土地流动化未导致政治格局变化，或农民阶级未获得主导地位，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与赫伯特·斯宾塞'军事主义等同于反动'的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同地震（土地流动）后，旧建筑（封建阶级）反而因抗震加固（保护功能）而幸存，并成为新秩序的一部分

### 🔗 文字版因果链

1. 土地流动化导致市场体系对骚乱更敏感
2. 中产阶级非军人化，无法保障法律与秩序
3. 农民被视为唯一能捍卫秩序的阶层，保守力量（军队、教会）重获荣誉
4. 在战后危机中，中产阶级排除工人阶级，农民阶级主导经济政策
