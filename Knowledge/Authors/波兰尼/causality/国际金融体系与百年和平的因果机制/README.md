# 国际金融体系与百年和平的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：国际金融体系与百年和平的因果机制.md

## 总体因果图

- 国际金融体系的建立与运作（金本位制、国际信贷网络、资本流动） → 欧洲百年和平（1816-1914年间无霸权间全面战争）
- 金本位制的崩溃 → 20世纪30年代世界经济瓦解与文明转变
- 1904-1907年英法、英俄协约的签订（形成两个敌对阵营） → 势力均衡体系的终结与世界大战的临近
