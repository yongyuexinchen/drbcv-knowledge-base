## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制造成的经济压力 |
| **DV（因变量）** | 第一次世界大战 |
| **Chain（传导链）** | 金本位制下黄金外流迫使国家采取保护性关税 → 保护主义兴起使殖民开发的收益计算反转 → 各国争相建立帝国关税壁垒并获得殖民地特权 → 帝国主义竞争加剧英国与德国的政治、军事、经济敌对 → 敌对最终导致第一次世界大战 |
| **Lag（时滞）** | 约19世纪最后四分之一世纪至1914年（数十年） |
| **Threshold（临界值）** | 黄金外流超过“金点”使国家难以承受 |
| **前提与约束（Premises）** | 存在国际金本位体系且各国经济相互依赖；各国政府优先保护本国经济免受黄金外流冲击；殖民地资源被认为能缓解黄金外流压力 |
| **Falsification（证伪条件）** | 如果金本位国家未出现保护主义或帝国主义扩张，或帝国主义敌对未导致战争，则该因果链不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像两只野兽被困在同一个漏水笼子里，各自拼命抓取身边的资源，最终为争夺生存空间互相撕咬，直至笼子破裂。

### 🔗 文字版因果链

1. 金本位制下黄金外流迫使国家采取保护性关税
2. 保护主义兴起使殖民开发的收益计算反转
3. 各国争相建立帝国关税壁垒并获得殖民地特权
4. 帝国主义竞争加剧英国与德国的政治、军事、经济敌对
5. 敌对最终导致第一次世界大战

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（金本位下国家调节的合法手段） |
| **DV（因变量）** | 工资和农业收入大幅下降、失业增加、企业银行大量破产 |
| **Chain（传导链）** | 货币贬值导致进口成本上升 → 国内经济持续收缩 → 工资和农业收入被迫下调 → 消费降至重获外贸平衡的水平 → 收缩过程中失业增加、企业和银行破产 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 贬值幅度足以引发金点以下黄金外流并迫使通货收缩 |
| **前提与约束（Premises）** | 该国处于金本位体系约束下；无法通过其他国际协调手段调整失衡；外贸平衡依赖国内价格和收入下调 |
| **Falsification（证伪条件）** | 如果贬值后外贸平衡快速恢复而未引起大规模失业和破产，则该因果断言被削弱。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人失业后只能靠节衣缩食来维持收支平衡，结果身体因营养不良而垮掉。

### 🔗 文字版因果链

1. 货币贬值导致进口成本上升
2. 国内经济持续收缩
3. 工资和农业收入被迫下调
4. 消费降至重获外贸平衡的水平
5. 收缩过程中失业增加、企业和银行破产

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新自由主义全球市场乌托邦（无国界、自由流动、减少政府干预） |
| **DV（因变量）** | 冲突加剧（社会动荡、内战、军国主义与原教旨主义武装冲突） |
| **Chain（传导链）** | 新自由主义政策要求缩减政府、取消贸易和资本管制 → 全球市场自发调节引发周期性经济剧烈波动 → 普通人每隔约五到十年被迫承受收入减半的长期萧条 → 人们无法忍受经济震荡，动员起来保护自己 → 社会不满加剧，秩序问题凸显 → 政治领袖通过寻找国内或国际敌人转移不满 → 最终导致冲突加剧而非和平 |
| **Lag（时滞）** | 大约5至10年一个周期，长期积累后爆发 |
| **Threshold（临界值）** | 普通人收入下降至原来的一半或更少，且反复发生 |
| **前提与约束（Premises）** | 人类缺乏长期承受剧烈经济波动的韧性；全球层面缺少强有力的规制机构（如最终借款人）；政治机会主义分子可利用不满情绪 |
| **Falsification（证伪条件）** | 如果新自由主义全球化普遍带来和平与繁荣，且没有出现大规模抗议或冲突，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同把所有人赶上没有安全网的高空钢丝，每隔几年就剧烈晃动一次，人们迟早会因恐惧而互相推搡，最终酿成踩踏。

### 🔗 文字版因果链

1. 新自由主义政策要求缩减政府、取消贸易和资本管制
2. 全球市场自发调节引发周期性经济剧烈波动
3. 普通人每隔约五到十年被迫承受收入减半的长期萧条
4. 人们无法忍受经济震荡，动员起来保护自己
5. 社会不满加剧，秩序问题凸显
6. 政治领袖通过寻找国内或国际敌人转移不满
7. 最终导致冲突加剧而非和平

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 缺乏全球性规制机构（尤其是‘最终借款人’） |
| **DV（因变量）** | 致命的经济危机 |
| **Chain（传导链）** | 全球市场依赖自发调节 → 缺乏有力的国际金融监管和最后贷款人 → 资本无序流动和金融投机放大风险 → 一个局部冲击可能演化为全球性经济崩溃 |
| **Lag（时滞）** | 不定，可能在几十年内反复出现 |
| **Threshold（临界值）** | 全球规模的经济遭受系统性冲击时没有可求助的规制机构 |
| **前提与约束（Premises）** | 市场并非自我调节的，需要政府/规制角色；国民经济需要活跃的政府，全球经济也需要类似机构；全球化使各国经济紧密关联 |
| **Falsification（证伪条件）** | 如果全球市场在无规制情况下长期保持稳定且未发生致命危机，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个没有消防队和保险系统的城市，任何一次小火都可能因为无人救援而蔓延成毁灭性大火。

### 🔗 文字版因果链

1. 全球市场依赖自发调节
2. 缺乏有力的国际金融监管和最后贷款人
3. 资本无序流动和金融投机放大风险
4. 一个局部冲击可能演化为全球性经济崩溃

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 民主政治控制经济（规制与调控） |
| **DV（因变量）** | 真正而广泛的自由 |
| **Chain（传导链）** | 社会通过民主手段制定规制机制 → 个人与自然摆脱市场强力造成的压力 → 社会保险、劳动法等制度保护弱势群体 → 法律和实际的自由扩展到所有人 → 同时保障民权自由和不服从的权利 |
| **Lag（时滞）** | 长期（改革逐步展开） |
| **Threshold（临界值）** | 实质性政府角色与民主问责相结合，而非过度控制 |
| **前提与约束（Premises）** | 需要摆脱“市场统治社会”的陈旧观念；政府角色对掌控虚拟商品不可或缺；自由不等于放任市场 |
| **Falsification（证伪条件）** | 如果民主规制导致政治压迫或自由反而减少，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则给所有司机提供了安全行驶的自由，而不是让道路陷入混乱的无规则状态。

### 🔗 文字版因果链

1. 社会通过民主手段制定规制机制
2. 个人与自然摆脱市场强力造成的压力
3. 社会保险、劳动法等制度保护弱势群体
4. 法律和实际的自由扩展到所有人
5. 同时保障民权自由和不服从的权利
