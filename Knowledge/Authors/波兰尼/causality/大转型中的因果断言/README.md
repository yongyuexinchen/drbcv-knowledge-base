# 大转型中的因果断言（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：大转型中的因果断言.md

## 总体因果图

- 斯品汉姆兰法案（补贴制度） → 劳动力市场的建立受阻
- 1834年新济贫法 → 失业者作为新的社会范畴出现
- 不受限制的失业救济（社会服务支出） → 汇率下跌（通货贬值）
- 金本位制 → 社会政策被压缩（工资不能上涨、社会服务必须削减）
- 美国与金本位脱钩（1933年） → 华尔街政治失势，国内社会保护政策得以运行
