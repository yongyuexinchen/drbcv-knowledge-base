# 真正而广泛的自由

> 属于因果簇：[[波兰尼《大转型》核心因果断言提取]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 民主政治控制经济（规制与调控） |
| **DV（因变量）** | 真正而广泛的自由 |
| **Chain（传导链）** | 社会通过民主手段制定规制机制 → 个人与自然摆脱市场强力造成的压力 → 社会保险、劳动法等制度保护弱势群体 → 法律和实际的自由扩展到所有人 → 同时保障民权自由和不服从的权利 |
| **Lag（时滞）** | 长期（改革逐步展开） |
| **Threshold（临界值）** | 实质性政府角色与民主问责相结合，而非过度控制 |
| **前提与约束（Premises）** | 需要摆脱“市场统治社会”的陈旧观念；政府角色对掌控虚拟商品不可或缺；自由不等于放任市场 |
| **Falsification（证伪条件）** | 如果民主规制导致政治压迫或自由反而减少，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则给所有司机提供了安全行驶的自由，而不是让道路陷入混乱的无规则状态。

### 🔗 文字版因果链

1. 社会通过民主手段制定规制机制
2. 个人与自然摆脱市场强力造成的压力
3. 社会保险、劳动法等制度保护弱势群体
4. 法律和实际的自由扩展到所有人
5. 同时保障民权自由和不服从的权利
