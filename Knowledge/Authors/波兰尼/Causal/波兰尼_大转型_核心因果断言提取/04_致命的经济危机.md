# 致命的经济危机

> 属于因果簇：[[波兰尼《大转型》核心因果断言提取]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 缺乏全球性规制机构（尤其是‘最终借款人’） |
| **DV（因变量）** | 致命的经济危机 |
| **Chain（传导链）** | 全球市场依赖自发调节 → 缺乏有力的国际金融监管和最后贷款人 → 资本无序流动和金融投机放大风险 → 一个局部冲击可能演化为全球性经济崩溃 |
| **Lag（时滞）** | 不定，可能在几十年内反复出现 |
| **Threshold（临界值）** | 全球规模的经济遭受系统性冲击时没有可求助的规制机构 |
| **前提与约束（Premises）** | 市场并非自我调节的，需要政府/规制角色；国民经济需要活跃的政府，全球经济也需要类似机构；全球化使各国经济紧密关联 |
| **Falsification（证伪条件）** | 如果全球市场在无规制情况下长期保持稳定且未发生致命危机，则此断言不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个没有消防队和保险系统的城市，任何一次小火都可能因为无人救援而蔓延成毁灭性大火。

### 🔗 文字版因果链

1. 全球市场依赖自发调节
2. 缺乏有力的国际金融监管和最后贷款人
3. 资本无序流动和金融投机放大风险
4. 一个局部冲击可能演化为全球性经济崩溃
