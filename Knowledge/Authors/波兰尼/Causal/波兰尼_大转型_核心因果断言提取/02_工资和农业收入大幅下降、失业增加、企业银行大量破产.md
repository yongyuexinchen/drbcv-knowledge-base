# 工资和农业收入大幅下降、失业增加、企业银行大量破产

> 属于因果簇：[[波兰尼《大转型》核心因果断言提取]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币贬值（金本位下国家调节的合法手段） |
| **DV（因变量）** | 工资和农业收入大幅下降、失业增加、企业银行大量破产 |
| **Chain（传导链）** | 货币贬值导致进口成本上升 → 国内经济持续收缩 → 工资和农业收入被迫下调 → 消费降至重获外贸平衡的水平 → 收缩过程中失业增加、企业和银行破产 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 贬值幅度足以引发金点以下黄金外流并迫使通货收缩 |
| **前提与约束（Premises）** | 该国处于金本位体系约束下；无法通过其他国际协调手段调整失衡；外贸平衡依赖国内价格和收入下调 |
| **Falsification（证伪条件）** | 如果贬值后外贸平衡快速恢复而未引起大规模失业和破产，则该因果断言被削弱。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人失业后只能靠节衣缩食来维持收支平衡，结果身体因营养不良而垮掉。

### 🔗 文字版因果链

1. 货币贬值导致进口成本上升
2. 国内经济持续收缩
3. 工资和农业收入被迫下调
4. 消费降至重获外贸平衡的水平
5. 收缩过程中失业增加、企业和银行破产
