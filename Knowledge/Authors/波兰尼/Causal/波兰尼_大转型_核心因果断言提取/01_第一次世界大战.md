# 第一次世界大战

> 属于因果簇：[[波兰尼《大转型》核心因果断言提取]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制造成的经济压力 |
| **DV（因变量）** | 第一次世界大战 |
| **Chain（传导链）** | 金本位制下黄金外流迫使国家采取保护性关税 → 保护主义兴起使殖民开发的收益计算反转 → 各国争相建立帝国关税壁垒并获得殖民地特权 → 帝国主义竞争加剧英国与德国的政治、军事、经济敌对 → 敌对最终导致第一次世界大战 |
| **Lag（时滞）** | 约19世纪最后四分之一世纪至1914年（数十年） |
| **Threshold（临界值）** | 黄金外流超过“金点”使国家难以承受 |
| **前提与约束（Premises）** | 存在国际金本位体系且各国经济相互依赖；各国政府优先保护本国经济免受黄金外流冲击；殖民地资源被认为能缓解黄金外流压力 |
| **Falsification（证伪条件）** | 如果金本位国家未出现保护主义或帝国主义扩张，或帝国主义敌对未导致战争，则该因果链不成立。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像两只野兽被困在同一个漏水笼子里，各自拼命抓取身边的资源，最终为争夺生存空间互相撕咬，直至笼子破裂。

### 🔗 文字版因果链

1. 金本位制下黄金外流迫使国家采取保护性关税
2. 保护主义兴起使殖民开发的收益计算反转
3. 各国争相建立帝国关税壁垒并获得殖民地特权
4. 帝国主义竞争加剧英国与德国的政治、军事、经济敌对
5. 敌对最终导致第一次世界大战
