# 国际体系的崩溃与19世纪文明的解体（包括自由政权被独裁取代、

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制的恢复与维持（作为19世纪国际经济体系的基石） |
| **DV（因变量）** | 国际体系的崩溃与19世纪文明的解体（包括自由政权被独裁取代、自由市场制度被新经济类型替代） |
| **Chain（传导链）** | 一战后各国试图恢复金本位制，将其视为稳定与秩序的象征 → 恢复过程中，各国为维护货币稳定而采取限制贸易、资本流动等措施（如进口配额、双边协议、外汇管制） → 这些措施本为促进自由贸易，实际却导致各国经济自给自足化，割裂了国际市场 → 美国1927年为支持英镑维持低利率，加剧自身隐性通胀，导致1929年股市崩溃 → 金本位制最终在1933年美国放弃后彻底崩溃，国际信用体系瓦解 → 金本位制的失败迫使各国转向专制经济体制，加速了19世纪国际秩序的全面解体 |
| **Lag（时滞）** | 约10年（从1918年战后恢复努力到1929年崩溃，再到1933年金本位制放弃） |
| **Threshold（临界值）** | 金本位制的维持需要各国利率协调；当美国为支持英镑而放弃自身高利率需求时，隐性通胀积累至临界点，触发崩溃 |
| **前提与约束（Premises）** | 经济已完全货币化，货币成为国家政策支点；各国对金本位制存在普遍共识，将其视为唯一稳定基础；国际信用体系通过资本流动将各国经济紧密连接；排除自给自足的非市场经济体系（如早期苏联的实物经济） |
| **Falsification（证伪条件）** | 如果金本位制崩溃后国际秩序未发生根本性改变（如自由政权得以维持、市场制度未转型），则该断言被推翻 |
| **Data（定量佐证）** | 定性断言为主，辅以历史事件序列（如1927年美联储低利率、1929年股市崩溃、1933年美国放弃金本位），无具体量化指标 |
| **Conflicts（观点冲突）** | 与自由放任经济学派（如米塞斯）认为金本位制是自发秩序且可自我调节的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 一战后各国试图恢复金本位制，将其视为稳定与秩序的象征
2. 恢复过程中，各国为维护货币稳定而采取限制贸易、资本流动等措施（如进口配额、双边协议、外汇管制）
3. 这些措施本为促进自由贸易，实际却导致各国经济自给自足化，割裂了国际市场
4. 美国1927年为支持英镑维持低利率，加剧自身隐性通胀，导致1929年股市崩溃
5. 金本位制最终在1933年美国放弃后彻底崩溃，国际信用体系瓦解
6. 金本位制的失败迫使各国转向专制经济体制，加速了19世纪国际秩序的全面解体
