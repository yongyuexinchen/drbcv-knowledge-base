# 工业资本家对斯品汉姆兰制度的反对与1834年济贫法改革

> 属于因果簇：[[斯品汉姆兰法案与农业劳动力后备军维持的因果机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰补贴制度在工业城镇的扩散 |
| **DV（因变量）** | 工业资本家对斯品汉姆兰制度的反对与1834年济贫法改革 |
| **Chain（传导链）** | 补贴制度向北方工业城镇扩散，形成城镇产业后备军 → 补贴导致劳动者低效率（四五个补贴领取者才抵得上一个任务工作者） → 补贴造成不同地区间生产成本差异，威胁城市工厂主的市场竞争地位 → 补贴助长乡村劳动力滞留，减少城市劳动力供给，增强城市工人垄断劳动力市场的倾向 → 这些因素使工业资本家作为一个阶级认识到补贴制度的集体危害 → 最终凝聚成全国性改革力量，推动1834年济贫法改革 |
| **Lag（时滞）** | 长期效应（数十年，从1795年法案到1834年改革） |
| **Threshold（临界值）** | 当补贴制度扩散到工业城镇并开始影响工业资本家利益时，反对力量才凝聚成形 |
| **前提与约束（Premises）** | 仅当工业资本家认识到个体利益与集体利益的冲突时；仅当补贴制度对劳动生产率的负面影响足够显著时；仅当城市劳动力需求旺盛（如1820年代末）时 |
| **Falsification（证伪条件）** | 如果1834年改革并非由工业资本家的反对推动，而是由其他因素（如政治意识形态）主导，则该断言被削弱 |
| **Data（定量佐证）** | 济贫法委员会报告：'一个马克莱斯菲尔德制造业主可能会发现，他被低价倾销所打垮，这种倾销是艾塞克斯郡的济贫法管理不当所造成的结果'；1824年特别委员会报告：补贴领取者'四五个才抵得上一个任务工作者' |
| **Conflicts（观点冲突）** | 与认为1834年改革是纯粹人道主义或意识形态驱动的观点冲突 |

### 🔗 文字版因果链

1. 补贴制度向北方工业城镇扩散，形成城镇产业后备军
2. 补贴导致劳动者低效率（四五个补贴领取者才抵得上一个任务工作者）
3. 补贴造成不同地区间生产成本差异，威胁城市工厂主的市场竞争地位
4. 补贴助长乡村劳动力滞留，减少城市劳动力供给，增强城市工人垄断劳动力市场的倾向
5. 这些因素使工业资本家作为一个阶级认识到补贴制度的集体危害
6. 最终凝聚成全国性改革力量，推动1834年济贫法改革
