# 农村人口过剩的假象

> 属于因果簇：[[斯品汉姆兰法案与农业劳动力后备军维持的因果机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法案的补贴制度 |
| **DV（因变量）** | 农村人口过剩的假象 |
| **Chain（传导链）** | 补贴制度使穷人即使没有工作也能留在乡村获得救济 → 穷人因依赖救济而缺乏迁往城市寻找工作的动力 → 乡村中滞留的劳动力数量超过实际农业需求，形成表面上的'人口过剩' → 实际上这种过剩是制度性滞留造成的假象，并非真实的人口过剩 |
| **Lag（时滞）** | 制度运行一段时间后显现（数年至数十年） |
| **Threshold（临界值）** | 无明确量化阈值 |
| **前提与约束（Premises）** | 仅当补贴水平足以维持穷人留在乡村时；仅当城市就业机会不足以吸引穷人迁移时 |
| **Falsification（证伪条件）** | 如果废除补贴制度后乡村人口迅速减少，且农业劳动力出现短缺，则证明此前的'过剩'确为假象 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与马尔萨斯人口论中'人口过剩是自然规律'的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像鱼塘里人为投放过多饲料，鱼群聚集看似鱼多，但一旦停止投喂，鱼群就会散去，证明鱼的数量并未真正过剩。

### 🔗 文字版因果链

1. 补贴制度使穷人即使没有工作也能留在乡村获得救济
2. 穷人因依赖救济而缺乏迁往城市寻找工作的动力
3. 乡村中滞留的劳动力数量超过实际农业需求，形成表面上的'人口过剩'
4. 实际上这种过剩是制度性滞留造成的假象，并非真实的人口过剩
