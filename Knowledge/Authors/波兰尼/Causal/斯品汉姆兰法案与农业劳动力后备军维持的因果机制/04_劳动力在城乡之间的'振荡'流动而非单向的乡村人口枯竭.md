# 劳动力在城乡之间的'振荡'流动而非单向的乡村人口枯竭

> 属于因果簇：[[斯品汉姆兰法案与农业劳动力后备军维持的因果机制]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 英国城乡统一的济贫法管理 |
| **DV（因变量）** | 劳动力在城乡之间的'振荡'流动而非单向的乡村人口枯竭 |
| **Chain（传导链）** | 济贫法在城乡教区一视同仁地推行，不存在管理断裂 → 劳动力可以在城乡之间自由流动而不失去救济资格 → 乡村教区支付户外救济给在城镇工作的非定居穷人 → 制造业城镇向在本城镇无住所的定居穷人支付救济金 → 结果：劳动力在城乡之间'振荡'流动，避免了大陆国家常见的乡村人口枯竭（landflucht） |
| **Lag（时滞）** | 长期制度效应（数十年至数百年） |
| **Threshold（临界值）** | 无明确量化阈值 |
| **前提与约束（Premises）** | 仅当济贫法在城乡统一执行时；仅当城乡地理距离较近（英国港口众多、布局紧凑）时；排除：大规模遣返运动（如1841-1843年）是例外情况 |
| **Falsification（证伪条件）** | 如果英国出现类似中欧的乡村人口枯竭现象，或劳动力流动呈现不可逆的单向性，则该断言被推翻 |
| **Data（定量佐证）** | 1841-1843年遣返运动中，从19个北方制造业城镇遣返的12,628个穷人中，只有1%在9个农业地区拥有住所 |
| **Conflicts（观点冲突）** | 与大陆国家（如德国）的乡村人口枯竭现象形成对比，与认为济贫法阻碍劳动力流动的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像两个连通的水池——水位差会让水在两个池子间来回流动，而不是一个池子干涸，另一个池子溢出。

### 🔗 文字版因果链

1. 济贫法在城乡教区一视同仁地推行，不存在管理断裂
2. 劳动力可以在城乡之间自由流动而不失去救济资格
3. 乡村教区支付户外救济给在城镇工作的非定居穷人
4. 制造业城镇向在本城镇无住所的定居穷人支付救济金
5. 结果：劳动力在城乡之间'振荡'流动，避免了大陆国家常见的乡村人口枯竭（landflucht）
