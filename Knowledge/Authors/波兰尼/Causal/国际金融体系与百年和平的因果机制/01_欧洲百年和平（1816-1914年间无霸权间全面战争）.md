# 欧洲百年和平（1816-1914年间无霸权间全面战争）

> 属于因果簇：[[国际金融体系与百年和平的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国际金融体系的建立与运作（金本位制、国际信贷网络、资本流动） |
| **DV（因变量）** | 欧洲百年和平（1816-1914年间无霸权间全面战争） |
| **Chain（传导链）** | 国际金融依赖稳定的国际货币体系，而全面战争会摧毁该体系，使投资者和债权人蒙受巨大损失 → 因此，国际金融利益集团（银行家、债券持有者、商人）成为和平的坚定倡导者，通过其经济影响力向各国政府施压 → 金本位制和立宪主义使各国政府的行为（如预算、外汇政策）受到国际信用市场的约束，迫使它们避免引发战争的冒险政策 → 国际金融通过对半殖民地（如土耳其、埃及、中国等）的财政管理，直接介入并调解霸权间的利益冲突，防止局部冲突升级为全面战争 → 势力均衡体系本身不足以维持和平，但国际金融作为政治与经济组织之间的纽带，为势力均衡提供了具体的运作机制和和平利益的社会载体 |

| **Threshold（临界值）** | 国际金融体系需保持完整（金本位制有效运作、主要霸权间存在多极均势、至少存在三个以上独立霸权集团） |
| **前提与约束（Premises）** | 国际金融体系是高度组织化的，且各国经济相互依赖达到一定程度；存在多个独立主权国家（至少三个以上霸权），使势力均衡机制能够运作；各国（尤其是主要霸权）采纳金本位制和立宪政体，使国际信用约束能够传导至国内政策；国际金融能够作为独立于单一国家利益的行为体发挥调解作用 |

### 🧩 生活类比

> 国际金融体系如同一个复杂的电网系统，只要电网完整，各用户（国家）即使有矛盾也会因断电风险而克制；一旦电网崩溃，黑暗（战争）便迅速降临

### 🔗 文字版因果链

1. 国际金融依赖稳定的国际货币体系，而全面战争会摧毁该体系，使投资者和债权人蒙受巨大损失
2. 因此，国际金融利益集团（银行家、债券持有者、商人）成为和平的坚定倡导者，通过其经济影响力向各国政府施压
3. 金本位制和立宪主义使各国政府的行为（如预算、外汇政策）受到国际信用市场的约束，迫使它们避免引发战争的冒险政策
4. 国际金融通过对半殖民地（如土耳其、埃及、中国等）的财政管理，直接介入并调解霸权间的利益冲突，防止局部冲突升级为全面战争
5. 势力均衡体系本身不足以维持和平，但国际金融作为政治与经济组织之间的纽带，为势力均衡提供了具体的运作机制和和平利益的社会载体
