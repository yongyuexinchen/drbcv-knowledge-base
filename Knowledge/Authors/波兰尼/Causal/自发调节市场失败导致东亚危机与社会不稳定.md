# 自发调节市场失败导致东亚危机与社会不稳定

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 短期资本流的释放（资本账户自由化） |
| **DV（因变量）** | 东亚金融危机及社会政治不稳定 |
| **Chain（传导链）** | 短期资本流被释放，大量美元在全球寻求最高回报 → 资本流动受情绪化的快速理性与非理性变化支配，导致波动性 → 资本突然外逃，引发货币危机和金融体系崩溃 → 经济崩溃导致失业、贫困和社会不安全，削弱社会契约 → 社会契约削弱导致社会政治不稳定，破坏东亚奇迹的必要条件 |
| **Lag（时滞）** | 短期资本流释放后数月到数年（如1990年代东亚危机在资本自由化后不久爆发） |
| **Threshold（临界值）** | 资本流动规模超过经济体吸收能力或监管能力时，危机风险显著增加 |
| **前提与约束（Premises）** | 经济体缺乏有效的资本流动监管；金融市场存在情绪化行为和非理性波动；社会契约提供经济安全是政治稳定的前提；东亚奇迹依赖社会政治稳定 |
| **Falsification（证伪条件）** | 如果资本账户自由化后，东亚经济体未发生金融危机且社会政治稳定，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与新自由主义观点冲突（如认为资本自由流动促进效率与增长） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像放开堤坝让洪水自由奔流，虽然水流看似自由，但会冲毁下游的农田和村庄，导致灾难。

### 🔗 文字版因果链

1. 短期资本流被释放，大量美元在全球寻求最高回报
2. 资本流动受情绪化的快速理性与非理性变化支配，导致波动性
3. 资本突然外逃，引发货币危机和金融体系崩溃
4. 经济崩溃导致失业、贫困和社会不安全，削弱社会契约
5. 社会契约削弱导致社会政治不稳定，破坏东亚奇迹的必要条件
