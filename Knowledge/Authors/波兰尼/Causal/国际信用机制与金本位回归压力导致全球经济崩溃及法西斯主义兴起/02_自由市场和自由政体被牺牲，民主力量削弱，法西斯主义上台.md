# 自由市场和自由政体被牺牲，民主力量削弱，法西斯主义上台

> 属于因果簇：[[国际信用机制与金本位回归压力导致全球经济崩溃及法西斯主义兴起]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 坚持紧缩通货政策（将通货稳定置于收入和就业稳定之上） |
| **DV（因变量）** | 自由市场和自由政体被牺牲，民主力量削弱，法西斯主义上台 |
| **Chain（传导链）** | 国联黄金委员会认为通货紧缩未能带来新均衡，要求政府干预削减垄断价格、工资和租金 → 政府以干预手段推行紧缩，形成'强政府下的自由经济'，实际是政府调整价格与工资 → 紧缩政策使危机进一步扩散，将经济混乱压力置于金融肩上，各国赤字累积 → 国际劳动分工崩溃，经济自由主义者在关键十年顽固坚持紧缩政策 → 紧缩政策支持了独裁主义式干涉主义，造成民主力量致命削弱 → 民主力量无法阻止法西斯主义大灾难 |
| **Lag（时滞）** | 约10年（1920年代紧缩政策至1930年代初法西斯主义兴起） |
| **Threshold（临界值）** | 当通货紧缩无法通过市场自发调整实现均衡，政府干预成为常态时，自由市场机制被实质性替代 |
| **前提与约束（Premises）** | 社会组织问题被完全从属于恢复通货的需要；国内自由市场和自由国家的恢复被推迟；经济自由主义者将稳健货币理想置于非干预理想之上 |
| **Falsification（证伪条件）** | 如果1920年代推行紧缩通货政策的国家成功恢复经济稳定且民主政体未受削弱，或法西斯主义兴起与紧缩政策无系统关联，则该断言被推翻 |
| **Data（定量佐证）** | 1932年国联黄金委员会报告承认十年主要货币成就化为泡影；自由市场未被恢复，自由政体已被牺牲 |
| **Conflicts（观点冲突）** | 与认为紧缩政策是恢复经济秩序必要手段的观点冲突；与认为法西斯主义主要由民族主义或凡尔赛和约导致的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同医生为退烧而给病人大量冰敷，结果病人体温是降了，但整个免疫系统也崩溃了——治标不治本，反而摧毁了身体的自我修复能力

### 🔗 文字版因果链

1. 国联黄金委员会认为通货紧缩未能带来新均衡，要求政府干预削减垄断价格、工资和租金
2. 政府以干预手段推行紧缩，形成'强政府下的自由经济'，实际是政府调整价格与工资
3. 紧缩政策使危机进一步扩散，将经济混乱压力置于金融肩上，各国赤字累积
4. 国际劳动分工崩溃，经济自由主义者在关键十年顽固坚持紧缩政策
5. 紧缩政策支持了独裁主义式干涉主义，造成民主力量致命削弱
6. 民主力量无法阻止法西斯主义大灾难
