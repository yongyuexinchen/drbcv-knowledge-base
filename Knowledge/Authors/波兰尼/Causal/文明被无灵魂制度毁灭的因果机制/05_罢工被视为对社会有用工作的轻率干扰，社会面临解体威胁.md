# 罢工被视为对社会有用工作的轻率干扰，社会面临解体威胁

> 属于因果簇：[[文明被无灵魂制度毁灭的因果机制]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 劳动力商品化虚构（劳动力被视为可在市场上定价的商品） |
| **DV（因变量）** | 罢工被视为对社会有用工作的轻率干扰，社会面临解体威胁 |
| **Chain（传导链）** | 劳动力被设想为只能在市场上找到价格 → 劳动者被要求像商品一样行动，拒绝低于最高价格出售自己 → 逻辑推论是劳动者应持续罢工 → 但劳动力并非真正商品，若持续罢工，社会将因缺乏物质支持而解体 → 工会功能在维护最低生存标准上不可或缺，但干预手段阻碍市场机制 → 市场社会的根源性问题——干预与通货——成为政治中心 |
| **Lag（时滞）** | 即时至长期 |
| **Threshold（临界值）** | 当劳动者试图以商品方式行动并持续罢工时，社会解体风险显现 |
| **前提与约束（Premises）** | 劳动力被商品化对待；存在私有企业制度且无工作稳定保证；社会依赖市场机制分配资源 |
| **Falsification（证伪条件）** | 如果存在劳动力完全商品化但社会未受威胁的案例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为劳动力可完全市场化、罢工是正常市场行为的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将人的呼吸视为可交易商品，若按市场规则定价，人将因无法承受价格而窒息

### 🔗 文字版因果链

1. 劳动力被设想为只能在市场上找到价格
2. 劳动者被要求像商品一样行动，拒绝低于最高价格出售自己
3. 逻辑推论是劳动者应持续罢工
4. 但劳动力并非真正商品，若持续罢工，社会将因缺乏物质支持而解体
5. 工会功能在维护最低生存标准上不可或缺，但干预手段阻碍市场机制
6. 市场社会的根源性问题——干预与通货——成为政治中心
