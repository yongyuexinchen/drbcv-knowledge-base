# 劳动分工的形成与政治权力的强化

> 属于因果簇：[[经济动机源于社会生活背景而非个人逐利本性]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 再分配原则（redistribution） |
| **DV（因变量）** | 劳动分工的形成与政治权力的强化 |
| **Chain（传导链）** | 群体成员将物产（猎物、农产品等）交给头人、首领或中央机构 → 中央机构集中、贮存物品 → 物品被重新分配给非生产者（官员、军人、有闲阶级）或用于公共活动 → 精细的劳动分工从再分配机制中产生 → 再分配过程强化了领导群体的政治权力 |
| **Lag（时滞）** | 中期，取决于收集、贮存和再分配的周期（如古埃及每年农业收成后的集中与分配） |
| **Threshold（临界值）** | 存在辐辏型制度模式（中心性结构），且领土范围越大、物产差异越高，再分配越有效 |
| **前提与约束（Premises）** | 适用于从狩猎部落到古代王国（古埃及、中国、印加、巴比伦等）的各类社会；领导群体有权力和能力集中与分配物品；社会存在一定程度的分层或组织化 |
| **Falsification（证伪条件）** | 若发现一个存在辐辏结构的社会中，物品集中后不进行再分配，且劳动分工未形成，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（古埃及法老仓库系统、夸扣特尔人夸富宴、东非牲畜采邑等案例） |
| **Conflicts（观点冲突）** | 与市场自发秩序理论（如哈耶克认为价格机制是协调分工的唯一有效方式）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像公司里大家把业绩报给总部，总部统一调配资源——虽然每个人不是为“公司利益”而是为“部门荣誉”努力，但整个公司的运转和分工就这样被组织起来了。

### 🔗 文字版因果链

1. 群体成员将物产（猎物、农产品等）交给头人、首领或中央机构
2. 中央机构集中、贮存物品
3. 物品被重新分配给非生产者（官员、军人、有闲阶级）或用于公共活动
4. 精细的劳动分工从再分配机制中产生
5. 再分配过程强化了领导群体的政治权力
