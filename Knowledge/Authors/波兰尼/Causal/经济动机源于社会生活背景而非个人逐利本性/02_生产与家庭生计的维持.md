# 生产与家庭生计的维持

> 属于因果簇：[[经济动机源于社会生活背景而非个人逐利本性]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 互惠原则（reciprocity） |
| **DV（因变量）** | 生产与家庭生计的维持 |
| **Chain（传导链）** | 个体向亲属（如母系亲属）提供收成或劳动成果 → 个体获得社会荣誉和承认，而非直接物质利益 → 互惠的宽泛原则使个体符合社会美德的行为从经济上得到报偿 → 生产得以维持，家庭生计得到保障 |
| **Lag（时滞）** | 短期至中期，取决于互惠交换的周期（如库拉贸易循环一圈可能需十年） |
| **Threshold（临界值）** | 社会存在对称性制度模式（如氏族对偶结构、对等村庄、库拉伙伴关系）以支持互惠行为 |
| **前提与约束（Premises）** | 适用于无文字社会或传统共同体；社会义务具有互惠性，长期来看履行义务符合个体利益；个体重视社会地位和社会资产甚于物质财富 |
| **Falsification（证伪条件）** | 若发现一个无文字社会中生产活动完全由个体自利动机驱动，且无互惠交换行为，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（特罗布里恩岛民案例：男人向姊妹家庭提供收成，库拉贸易中贵重物品环游群岛） |
| **Conflicts（观点冲突）** | 与古典经济学中“经济人”假设（个体行为由自利动机驱动）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像邻里之间互相帮忙照看孩子——今天你帮我接孩子，明天我帮你修水管，谁也不记账，但社区关系维系了，大家的生活都运转正常。

### 🔗 文字版因果链

1. 个体向亲属（如母系亲属）提供收成或劳动成果
2. 个体获得社会荣誉和承认，而非直接物质利益
3. 互惠的宽泛原则使个体符合社会美德的行为从经济上得到报偿
4. 生产得以维持，家庭生计得到保障
