# 经济自利意识的消除与生产积极性的维持

> 属于因果簇：[[经济动机源于社会生活背景而非个人逐利本性]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会对慷慨和荣誉的奖赏（非经济动机） |
| **DV（因变量）** | 经济自利意识的消除与生产积极性的维持 |
| **Chain（传导链）** | 社会通过公共活动（食物分配、战利品分享、仪式性分配）奖赏慷慨无私行为 → 个体为避免成为弃儿、维护社会地位而遵守荣誉和慷慨规范 → 个体从意识中消除经济自利，无法从自利角度理解自身行为 → 劳动的数量和质量达到最高标准，生产积极性得以维持 |
| **Lag（时滞）** | 短期，通过持续的公共活动和仪式强化 |
| **Threshold（临界值）** | 社会对慷慨的奖赏必须大于自利行为的收益，使忘我奉献成为“明显划算”的选择 |
| **前提与约束（Premises）** | 适用于共同体保护成员免于饥饿的社会；社会连结的维系对个体命运攸关；人类激情（好的或坏的）被引向非经济目标 |
| **Falsification（证伪条件）** | 若发现一个社会中个体普遍以经济自利为行为动机，且慷慨行为不受社会奖赏，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（特罗布里恩岛民粮食展示仪式、夸扣特尔人夸富宴等案例） |
| **Conflicts（观点冲突）** | 与功利主义伦理学（认为个体行为以快乐和痛苦计算为基础）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像游戏里玩家为了“声望值”和“成就徽章”拼命打怪升级，而不是为了游戏币——虽然游戏币也能买东西，但真正让人上瘾的是那些虚拟荣誉。

### 🔗 文字版因果链

1. 社会通过公共活动（食物分配、战利品分享、仪式性分配）奖赏慷慨无私行为
2. 个体为避免成为弃儿、维护社会地位而遵守荣誉和慷慨规范
3. 个体从意识中消除经济自利，无法从自利角度理解自身行为
4. 劳动的数量和质量达到最高标准，生产积极性得以维持
