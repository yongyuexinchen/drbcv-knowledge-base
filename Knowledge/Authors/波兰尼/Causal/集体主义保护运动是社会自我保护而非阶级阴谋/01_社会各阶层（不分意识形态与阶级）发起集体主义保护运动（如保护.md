# 社会各阶层（不分意识形态与阶级）发起集体主义保护运动（如保护

> 属于因果簇：[[集体主义保护运动是社会自我保护而非阶级阴谋]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自发调节的市场扩张（市场经济对人性与自然因素的威胁） |
| **DV（因变量）** | 社会各阶层（不分意识形态与阶级）发起集体主义保护运动（如保护主义立法、社会立法） |
| **Chain（传导链）** | 市场经济将劳动力与土地商品化，破坏社会有机结构与文化制度 → 社会各阶层（地主、工人、中产等）感受到生存、地位、安全与文化认同的威胁 → 威胁跨越意识形态与阶级界限，激发普遍的社会自我保护反应 → 保护运动以集体主义手段（立法、关税、社会政策）出现，旨在缓解市场对社会的破坏 |
| **Lag（时滞）** | 19世纪下半叶（1870年代起）市场扩张加速后，保护运动普遍兴起，时滞约数十年 |
| **Threshold（临界值）** | 当市场扩张威胁到社会的基本制度与文化生存（而非仅收入下降）时，保护运动必然发生 |
| **前提与约束（Premises）** | 社会结构本身正在经历变迁（非静态社会）；市场扩张对社会的威胁是系统性的，而非仅针对特定经济群体；阶级利益首先是社会性的（地位、安全、身份）而非纯经济性的；保护运动不需要以理论或意识形态前见为先导 |
| **Falsification（证伪条件）** | 若能证明19世纪保护主义运动主要由单一阶级的经济利益驱动，且与市场扩张的社会破坏无关，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引用历史案例：工会法、反托拉斯法、公共卫生立法、面包房清洗规章等） |
| **Conflicts（观点冲突）** | 与经济自由主义（保护主义是短视利益集团扭曲市场）及通俗马克思主义（保护主义是资本家或特定阶级阴谋）的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同人体免疫系统：当外部病原体（市场扩张）侵入时，全身各器官（各阶级）会自发产生发热、炎症等防御反应（保护运动），而非某个器官的单独阴谋

### 🔗 文字版因果链

1. 市场经济将劳动力与土地商品化，破坏社会有机结构与文化制度
2. 社会各阶层（地主、工人、中产等）感受到生存、地位、安全与文化认同的威胁
3. 威胁跨越意识形态与阶级界限，激发普遍的社会自我保护反应
4. 保护运动以集体主义手段（立法、关税、社会政策）出现，旨在缓解市场对社会的破坏
