# 斯品汉姆兰法案的工资补助对劳动力市场与资本主义运转的因果影响

> **领域**：经济史与劳动经济学　|　**来源**：波兰尼_chapter_33_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法案（1795年）实施的系统性工资补助制度 |
| **DV（因变量）** | 劳动力市场无法自由运转，资本主义制度难以正常运行 |
| **Chain（传导链）** | 斯品汉姆兰法案根据面包价格对工资进行补贴，使雇主可以支付低于生存水平的工资 → 工资补助降低了劳动者寻找更好工作机会的动力，削弱了劳动力的流动性 → 低工资与补贴的结合抑制了工资上涨，扭曲了劳动力市场的供求信号 → 劳动力市场无法形成自由竞争的价格机制，资本主义依赖的自由劳动力市场被破坏 → 因此，资本主义制度无法在缺乏自由劳动力市场的条件下有效运转 |
| **Lag（时滞）** | 短期效应（工资压制）在法案实施后即显现；长期效应（对资本主义运转的根本性破坏）在数十年后才被充分认识 |
| **Threshold（临界值）** | 当工资补助使实际工资低于生存水平，且补贴成为雇主降低成本的主要手段时，因果效应显著 |
| **前提与约束（Premises）** | 仅当劳动力市场处于从传统身份制向契约制转型的时期；仅当存在反结社法等法律限制工人集体谈判能力时；排除劳动力完全自给自足、无雇佣关系的经济形态 |
| **Falsification（证伪条件）** | 如果发现斯品汉姆兰法案实施地区工资水平未低于生存水平，或劳动力流动性未受显著影响，或资本主义在这些地区仍能正常运转，则该断言可被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与克拉彭（Clapham）将斯品汉姆兰法案视为农村农业组织特征、否认其制度性影响的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同给跑步者绑上沙袋却声称在帮助他，斯品汉姆兰法案看似补贴穷人，实则拖累了整个劳动力市场的活力

### 🔗 文字版因果链

1. 斯品汉姆兰法案根据面包价格对工资进行补贴，使雇主可以支付低于生存水平的工资
2. 工资补助降低了劳动者寻找更好工作机会的动力，削弱了劳动力的流动性
3. 低工资与补贴的结合抑制了工资上涨，扭曲了劳动力市场的供求信号
4. 劳动力市场无法形成自由竞争的价格机制，资本主义依赖的自由劳动力市场被破坏
5. 因此，资本主义制度无法在缺乏自由劳动力市场的条件下有效运转
