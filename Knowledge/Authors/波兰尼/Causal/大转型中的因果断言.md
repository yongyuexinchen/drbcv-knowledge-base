## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰法案（补贴制度） |
| **DV（因变量）** | 劳动力市场的建立受阻 |
| **Chain（传导链）** | 法案向劳动者提供补贴，使其不依赖市场工资为生 → 劳动者失去进入市场竞争的动机，劳动力供给萎缩 → 劳动力作为商品的买卖关系无法形成 → 劳动力市场未能建立 |
| **Lag（时滞）** | 从法案实施到1820年代中期持续多年 |
| **Threshold（临界值）** | 补贴水平足以维持基本生活时 |
| **前提与约束（Premises）** | 劳动力市场需要自由流动的劳动者；补贴改变劳动力供给意愿 |
| **Falsification（证伪条件）** | 如果存在补贴制度但劳动力市场仍然正常建立，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像父母长期无条件供养子女，子女就不愿自谋职业，结果独立劳动力市场无法形成

### 🔗 文字版因果链

1. 法案向劳动者提供补贴，使其不依赖市场工资为生
2. 劳动者失去进入市场竞争的动机，劳动力供给萎缩
3. 劳动力作为商品的买卖关系无法形成
4. 劳动力市场未能建立

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 1834年新济贫法 |
| **DV（因变量）** | 失业者作为新的社会范畴出现 |
| **Chain（传导链）** | 新济贫法只救济物质上无助的赤贫者（进入习艺所） → 身体健康但无业者不再获得救济 → 这些人口必须依赖工资劳动，若找不到工作则成为失业者 → 失业者被明确区别于赤贫者，成为社会舞台上的新角色 |
| **Lag（时滞）** | 法案实施后不久（1830年代） |
| **Threshold（临界值）** | 法律将穷人划分为可救济与不可救济两类 |
| **前提与约束（Premises）** | 社会中存在劳动力市场；法律剥夺了对身体健全穷人的救济 |
| **Falsification（证伪条件）** | 如果新济贫法实施后没有产生失业者身份分类，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像学校不再补助考试落榜生，他们便被贴上“待业青年”的标签

### 🔗 文字版因果链

1. 新济贫法只救济物质上无助的赤贫者（进入习艺所）
2. 身体健康但无业者不再获得救济
3. 这些人口必须依赖工资劳动，若找不到工作则成为失业者
4. 失业者被明确区别于赤贫者，成为社会舞台上的新角色

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 不受限制的失业救济（社会服务支出） |
| **DV（因变量）** | 汇率下跌（通货贬值） |
| **Chain（传导链）** | 失业救济增加政府财政支出 → 预算赤字不断扩大 → 市场对主权信用失去信心 → 资本外流，汇率承压下跌 |
| **Lag（时滞）** | 在1920年代经济压力下逐渐显现，至1931年爆发 |
| **Threshold（临界值）** | 失业救济支出导致财政赤字超过市场可承受水平 |
| **前提与约束（Premises）** | 实行金本位或固定汇率制度；政府不能轻易通过印钞弥补赤字（受金本位约束） |
| **Falsification（证伪条件）** | 如果高失业救济未引起赤字和汇率下跌，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一个人承诺按固定价还债，却不断举债消费，最终只能贱卖家产

### 🔗 文字版因果链

1. 失业救济增加政府财政支出
2. 预算赤字不断扩大
3. 市场对主权信用失去信心
4. 资本外流，汇率承压下跌

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制 |
| **DV（因变量）** | 社会政策被压缩（工资不能上涨、社会服务必须削减） |
| **Chain（传导链）** | 金本位要求固定汇率，限制通货膨胀 → 工资上涨或社会支出提高会加大财政负担、削弱出口竞争力 → 贸易逆差和资本外流威胁汇率稳定 → 政府被迫削减社会服务、压低工资以维持金本位 |
| **Lag（时滞）** | 自1925年英国回归金本位到1931年危机 |
| **Threshold（临界值）** | 工资或社会支出水平与稳定汇率所需的竞争力相抵触时 |
| **前提与约束（Premises）** | 经济高度开放，依赖国际贸易；政府将维持金本位置于社会政策之上；存在工会和政党推动社会支出 |
| **Falsification（证伪条件）** | 如果维持金本位的同时社会政策没有受限制且汇率稳定，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像背负固定房贷的人，不得不缩减所有生活开支

### 🔗 文字版因果链

1. 金本位要求固定汇率，限制通货膨胀
2. 工资上涨或社会支出提高会加大财政负担、削弱出口竞争力
3. 贸易逆差和资本外流威胁汇率稳定
4. 政府被迫削减社会服务、压低工资以维持金本位

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国与金本位脱钩（1933年） |
| **DV（因变量）** | 华尔街政治失势，国内社会保护政策得以运行 |
| **Chain（传导链）** | 放弃金本位解除了对外汇兑的硬性约束 → 银行家和金融市场失去了对货币政策的否决权 → 政府不再依赖金融界维持汇兑信心 → 政府得以实施国内干预政策（新政） → 避免了欧洲式社会灾变 |
| **Lag（时滞）** | 1930年代，脱钩后立即产生政治效果 |
| **Threshold（临界值）** | 成功放弃金本位且经济未被外汇危机摧毁 |
| **前提与约束（Premises）** | 美国经济相对独立于世界贸易；美元的国际地位允许浮动汇率；金融利益集团此前通过金本位控制国内政策 |
| **Falsification（证伪条件）** | 如果脱钩后华尔街仍然左右经济政策，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像租客取消了房东的租金约束，终于可以自由装修房子

### 🔗 文字版因果链

1. 放弃金本位解除了对外汇兑的硬性约束
2. 银行家和金融市场失去了对货币政策的否决权
3. 政府不再依赖金融界维持汇兑信心
4. 政府得以实施国内干预政策（新政）
5. 避免了欧洲式社会灾变
