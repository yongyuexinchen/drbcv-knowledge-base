# 农民阶级获得与其经济重要性不相称的政治优势地位，并持续向城市

> 属于因果簇：[[农民阶级政治地位兴衰与市场秩序维护的因果机制]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农民阶级在战后紧急状态下成为唯一能维持法律与秩序（市场经济规则）的阶级 |
| **DV（因变量）** | 农民阶级获得与其经济重要性不相称的政治优势地位，并持续向城市中产阶级勒索赎金 |
| **Chain（传导链）** | 战后欧洲出现高度紧张的法律与秩序需求，市场机制面临被弃置的威胁 → 工人阶级可能漠视市场法则，产生毁灭性干预，引发对市场瘫痪的恐惧 → 农民阶级被证明是市场经济的捍卫者，成为消除威胁的唯一力量 → 农民阶级因此变得在政治上不可缺少，获得高声望和优势地位 → 一旦国家权力巩固或法西斯分子武装城市中产阶级下层，农民阶级的依赖解除，其声望迅速下降 |
| **Lag（时滞）** | 短期（战后头几年内）至中期（直到国家权力巩固或法西斯武装出现） |
| **Threshold（临界值）** | 农民阶级成为唯一能消除市场威胁力量时，其政治地位达到顶峰；当城市中产阶级下层被武装或国家权力巩固后，地位下降 |
| **前提与约束（Premises）** | 存在对市场机制瘫痪的恐惧（而非对无产阶级专政的真实恐惧）；农民阶级确实愿意且能够捍卫市场体制；工人阶级处于可能产生毁灭性干预的位置上；国家权力尚未巩固或法西斯分子尚未武装城市中产阶级下层 |
| **Falsification（证伪条件）** | 如果出现农民阶级在无外部威胁时仍保持高政治地位，或农民阶级不捍卫市场体制而转向破坏市场，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由主义经济学家将农民保护主义视为'浪漫失态'的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个社区在停电时只有某户人家有发电机，这户人家便获得临时的话语权；一旦电力恢复或别人也买了发电机，其地位便迅速回落。

### 🔗 文字版因果链

1. 战后欧洲出现高度紧张的法律与秩序需求，市场机制面临被弃置的威胁
2. 工人阶级可能漠视市场法则，产生毁灭性干预，引发对市场瘫痪的恐惧
3. 农民阶级被证明是市场经济的捍卫者，成为消除威胁的唯一力量
4. 农民阶级因此变得在政治上不可缺少，获得高声望和优势地位
5. 一旦国家权力巩固或法西斯分子武装城市中产阶级下层，农民阶级的依赖解除，其声望迅速下降
