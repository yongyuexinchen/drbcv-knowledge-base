## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农业自足在军事上的重要性（因一战暴露的粮食安全战略需求） |
| **DV（因变量）** | 大土地所有者的影响力持久不衰，中欧'重新农业化'完成 |
| **Chain（传导链）** | 一战使粮食生产能力的战略重要性回到公众意识 → 对'外部敌人'的恐惧取代对'内部敌人'的恐惧，成为农业保护的新理由 → 各国恐慌性地保存粮食生产能力，取代对世界市场的依赖 → 大土地所有者因农业自足的军事价值而获得持久影响力 |
| **Lag（时滞）** | 一战期间至战后持续（长期） |

| **前提与约束（Premises）** | 存在国际体系解体的现实威胁；国家面临战争或外部安全压力；粮食进口依赖被视为战略脆弱性 |
| **Falsification（证伪条件）** | 如果国际体系解体或战争威胁出现时，大土地所有者影响力未上升，或农业自足未被视为战略需要，则该断言被推翻 |

| **Confidence（确信度）** | plausible |
