# 生产组织解体、资本破坏、商业停业清偿、大量失业

> 属于因果簇：[[农民阶级政治地位兴衰与市场秩序维护的因果机制]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 商品货币（金本位）的使用导致价格水平下跌（通货紧缩） |
| **DV（因变量）** | 生产组织解体、资本破坏、商业停业清偿、大量失业 |
| **Chain（传导链）** | 商品货币数量不能随贸易扩张而相应增加 → 生产和贸易扩张导致价格水平下降 → 短期价格下跌因契约固定价格存在时滞，成本不能相应调整 → 价格水平长期下跌导致商业停业清偿、生产组织解体、资本破坏 → 最终导致大量失业和商业全面解体 |
| **Lag（时滞）** | 短期至中期（价格调整的时滞期） |
| **Threshold（临界值）** | 价格水平下跌幅度超过2%-3%的金点范围，达到10%或30%时，灾难性后果显现 |
| **前提与约束（Premises）** | 货币数量不能随贸易需求灵活增加；存在契约固定价格（如劳动力价格）；价格下跌持续相当长时期 |
| **Falsification（证伪条件）** | 如果商品货币制度下价格下跌未导致商业解体，或中央银行缓冲措施完全有效，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及金点波动2%-3%，大幅调整10%或30%） |
| **Conflicts（观点冲突）** | 与休谟货币数量论（认为货币减半不影响商业）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同河流水位因上游水源不足而持续下降，船只（企业）因吃水线固定而搁浅，最终整个航运体系崩溃。

### 🔗 文字版因果链

1. 商品货币数量不能随贸易扩张而相应增加
2. 生产和贸易扩张导致价格水平下降
3. 短期价格下跌因契约固定价格存在时滞，成本不能相应调整
4. 价格水平长期下跌导致商业停业清偿、生产组织解体、资本破坏
5. 最终导致大量失业和商业全面解体
