# 市场自发调节机制被削弱，最终导致经济崩溃

> 属于因果簇：[[金本位制下失业压力向政治与国际领域的传导机制]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 保护主义政策（关税、垄断组织） |
| **DV（因变量）** | 市场自发调节机制被削弱，最终导致经济崩溃 |
| **Chain（传导链）** | 保护主义促使竞争性市场转变为垄断性市场 → 个体被联合成非竞争性群体，经济调整变得缓慢而困难 → 价格与成本结构无法调整，延长萧条；设备无法清算，阻碍投资；价格与收入失衡造成社会紧张 → 各市场压力超出经济领域，平衡需通过政治手段重新获得 → 政治与经济领域的制度化分离被破坏，导致崩溃性压力 |
| **Lag（时滞）** | 长期（保护主义政策累积数十年后，市场机制严重受损） |
| **Threshold（临界值）** | 当保护主义使市场无法自我调节，价格与成本结构僵化到无法清算无利可图的投资时 |
| **前提与约束（Premises）** | 保护主义政策持续存在并累积；市场机制原本依赖自发调节；政治与经济领域的制度化分离对市场社会不可或缺 |
| **Falsification（证伪条件）** | 若保护主义政策长期存在但市场仍能有效自我调节、经济未崩溃，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与新自由主义观点冲突——后者认为保护主义是市场失灵的根源，但认为市场本身可以自我修复 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给机器加太多润滑油（保护主义），一开始转得顺，但油太多反而让齿轮打滑，最后机器卡死（市场崩溃）。

### 🔗 文字版因果链

1. 保护主义促使竞争性市场转变为垄断性市场
2. 个体被联合成非竞争性群体，经济调整变得缓慢而困难
3. 价格与成本结构无法调整，延长萧条；设备无法清算，阻碍投资；价格与收入失衡造成社会紧张
4. 各市场压力超出经济领域，平衡需通过政治手段重新获得
5. 政治与经济领域的制度化分离被破坏，导致崩溃性压力
