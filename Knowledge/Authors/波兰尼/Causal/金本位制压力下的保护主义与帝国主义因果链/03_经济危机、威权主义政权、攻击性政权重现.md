# 经济危机、威权主义政权、攻击性政权重现

> 属于因果簇：[[金本位制压力下的保护主义与帝国主义因果链]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场自由主义（将人类目标从属于非人市场机制的逻辑） |
| **DV（因变量）** | 经济危机、威权主义政权、攻击性政权重现 |
| **Chain（传导链）** | 市场自由主义要求社会从属于市场机制，将劳动、土地、货币视为虚拟商品 → 虚拟商品的市场化导致社会遭受经济震荡和周期性危机 → 社会为自我保护而动员，但缺乏民主规制时，政治领袖通过寻找替罪羊转移不满 → 经济危机和政治动荡为威权主义和攻击性政权提供土壤 → 新自由主义乌托邦愿景导致冲突加剧而非和平 |
| **Lag（时滞）** | 市场自由主义政策实施后，经济危机在数年至数十年内周期性出现，政治后果在危机积累后显现 |
| **Threshold（临界值）** | 当普通大众无法忍受周期性剧烈经济波动（如收入减半、长期萧条）时，社会保护性反应和政治极端化必然发生 |
| **前提与约束（Premises）** | 市场自由主义政策被各国采纳（如1980-1990年代新自由主义大获全胜）；缺乏强有力的国内和国际规制机构；社会各阶层对经济不稳定的承受力有限 |
| **Falsification（证伪条件）** | 如果市场自由主义政策能够长期维持经济稳定和繁荣，且未出现威权主义或攻击性政权，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及1980-1990年代新自由主义胜利，但未提供具体经济危机次数或政权更迭数据） |
| **Conflicts（观点冲突）** | 与哈耶克等市场自由主义者的观点冲突——哈耶克认为政府干预必然走向奴役，而波兰尼认为政府规制是掌控虚拟商品不可或缺的 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 市场自由主义要求社会从属于市场机制，将劳动、土地、货币视为虚拟商品
2. 虚拟商品的市场化导致社会遭受经济震荡和周期性危机
3. 社会为自我保护而动员，但缺乏民主规制时，政治领袖通过寻找替罪羊转移不满
4. 经济危机和政治动荡为威权主义和攻击性政权提供土壤
5. 新自由主义乌托邦愿景导致冲突加剧而非和平
