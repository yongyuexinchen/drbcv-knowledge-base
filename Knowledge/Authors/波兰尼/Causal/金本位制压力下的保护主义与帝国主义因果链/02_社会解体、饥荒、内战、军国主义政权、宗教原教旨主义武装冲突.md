# 社会解体、饥荒、内战、军国主义政权、宗教原教旨主义武装冲突

> 属于因果簇：[[金本位制压力下的保护主义与帝国主义因果链]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新自由主义全球化（拆除贸易和资本流动障碍、减少政府干预） |
| **DV（因变量）** | 社会解体、饥荒、内战、军国主义政权、宗教原教旨主义武装冲突 |
| **Chain（传导链）** | 新自由主义政策要求缩减政府、消除贸易和资本流动限制、减少资本市场管制 → 全球市场自发调节导致经济周期性剧烈波动，普通大众（工人、农民、小生意人）被迫忍受长期萧条和收入减半的困境 → 人们不可避免地动员起来保护自己免受经济震荡之苦，出现遍及全世界的抗议 → 社会秩序越来越成问题，政治领袖通过将国内或国际敌人作为替罪羊转移不满 → 在非洲等地，结构调整政策的灾难性效应使社会解体，制造饥荒和内战；后冷战时代出现军国主义政权，武装冲突与宗教原教旨主义相互纠缠 |
| **Lag（时滞）** | 新自由主义政策实施后，经济震荡和抗议在数年内显现（如1990年代后期），社会解体和武装冲突在更长时间内积累 |
| **Threshold（临界值）** | 当普通大众被迫仅靠从前收入的一半或更少来过活，且每隔五年或十年经历一次相当长期的萧条时，社会动员和保护性反应必然发生 |
| **前提与约束（Premises）** | 全球市场缺乏强有力的规制机构（如最终借款人）；普通大众缺乏忍受周期性剧烈经济波动的韧性；各国政府采纳新自由主义政策并放弃对经济生活的干预；国际金融机构（IMF、世界银行）的结构调整政策在发展中国家实施 |
| **Falsification（证伪条件）** | 如果新自由主义全球化在缺乏全球规制机构的情况下，能够持续带来和平与繁荣，且未出现大规模抗议、社会解体和武装冲突，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及非洲许多地方结构调整政策导致饥荒和内战，但未提供具体死亡人数或冲突数量统计） |
| **Conflicts（观点冲突）** | 与托马斯·弗里德曼的'金色紧身衣'观点冲突——弗里德曼认为遵循全球市场法则将带来繁荣与和平，而波兰尼认为这是危险幻想 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

### 🔗 文字版因果链
