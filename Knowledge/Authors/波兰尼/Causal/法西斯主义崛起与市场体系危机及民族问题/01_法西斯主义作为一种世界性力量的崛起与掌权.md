# 法西斯主义作为一种世界性力量的崛起与掌权

> 属于因果簇：[[法西斯主义崛起与市场体系危机及民族问题]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场体系的状况（尤其是1929年后的普遍危机） |
| **DV（因变量）** | 法西斯主义作为一种世界性力量的崛起与掌权 |
| **Chain（传导链）** | 市场体系在1924-1929年间恢复稳固，法西斯主义隐而不见 → 1930年后市场经济陷入普遍危机，社会失序与阶级冲突加剧 → 危机使既有政治体制无法提供安全与保障，民族问题成为未解决的杠杆 → 法西斯主义以解决工业社会问题和民族平等为号召，获得有产阶级与下层中产阶级支持 → 法西斯主义在德国、意大利等国成功攫取权力，成为替代方案 |
| **Lag（时滞）** | 1929年市场崩溃后数年内（1930-1933年）法西斯主义迅速成为主要政治力量 |
| **Threshold（临界值）** | 市场体系出现普遍性危机（如1929年股市暴跌、金本位崩溃、世界贸易缩水） |
| **前提与约束（Premises）** | 仅存在于弱小、有依附性的国家（如德国、意大利），臣服于外国势力的灵魂成为法西斯主义的财富；在法国、英国等强国，法西斯主义因反爱国主义而被致命削弱；需要存在未解决的民族问题作为杠杆；市场体系的运转只需法律和秩序，危机时政府寻求法西斯帮助 |
| **Falsification（证伪条件）** | 若在市场经济繁荣稳定时期（如1924-1929年）法西斯主义仍能大规模崛起并掌权，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由主义认为法西斯主义是偶然现象或纯粹意识形态运动的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人只有在身体免疫系统崩溃（市场危机）时，潜伏的病毒（法西斯主义）才会爆发成大病；健康时病毒只是隐性存在。

### 🔗 文字版因果链

1. 市场体系在1924-1929年间恢复稳固，法西斯主义隐而不见
2. 1930年后市场经济陷入普遍危机，社会失序与阶级冲突加剧
3. 危机使既有政治体制无法提供安全与保障，民族问题成为未解决的杠杆
4. 法西斯主义以解决工业社会问题和民族平等为号召，获得有产阶级与下层中产阶级支持
5. 法西斯主义在德国、意大利等国成功攫取权力，成为替代方案
