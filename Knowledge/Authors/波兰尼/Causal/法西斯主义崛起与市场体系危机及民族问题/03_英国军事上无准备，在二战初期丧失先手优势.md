# 英国军事上无准备，在二战初期丧失先手优势

> 属于因果簇：[[法西斯主义崛起与市场体系危机及民族问题]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 英国坚持金本位制和保守财政政策 |
| **DV（因变量）** | 英国军事上无准备，在二战初期丧失先手优势 |
| **Chain（传导链）** | 英国经济和金融以稳定汇兑和稳健货币为基础，坚持金本位 → 金本位完整性被视为高于其他考虑，限制重整军备 → 军费预算削减（如1932年达夫·库珀辩护），军事准备不足 → 德国获得先下手为强的好处，英国在战争中处于被动 |
| **Lag（时滞）** | 1930年代初至1939年二战爆发，约7-9年 |
| **Threshold（临界值）** | 金本位制与重整军备需求冲突时，英国选择维护金本位 |
| **前提与约束（Premises）** | 英国领导者（西蒙、诺曼、哈利法克斯等）坚信金本位至上；绥靖政策源于对金本位精神的效忠而非单纯政治妥协；英国作为岛国商业中心，认为海军足以保障安全 |
| **Falsification（证伪条件）** | 若英国在坚持金本位的同时仍能有效重整军备并取得军事优势，则该断言被推翻 |

| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个守财奴为了保住银行里的存款（金本位），拒绝花钱买保险（军备），结果房子被烧了。

### 🔗 文字版因果链

1. 英国经济和金融以稳定汇兑和稳健货币为基础，坚持金本位
2. 金本位完整性被视为高于其他考虑，限制重整军备
3. 军费预算削减（如1932年达夫·库珀辩护），军事准备不足
4. 德国获得先下手为强的好处，英国在战争中处于被动
