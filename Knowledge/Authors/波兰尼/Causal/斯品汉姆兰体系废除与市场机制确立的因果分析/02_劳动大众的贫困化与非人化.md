# 劳动大众的贫困化与非人化

> 属于因果簇：[[斯品汉姆兰体系废除与市场机制确立的因果分析]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 斯品汉姆兰体系的'生存权'救济政策 |
| **DV（因变量）** | 劳动大众的贫困化与非人化 |
| **Chain（传导链）** | 斯品汉姆兰体系提供所外救济，看似保障生存权，实则使劳工依赖救济而丧失自立能力 → 救济制度掩盖了劳动市场的真实供需，阻碍了劳动力商品化进程 → 劳工被剥夺了通过市场交换获得尊严的机会，沦为救济对象，被非人化 → 贫困化加剧，劳动大众从'人'变为'梦魇中的鬼魂' |
| **Lag（时滞）** | 数十年（从1795年斯品汉姆兰法令到1834年废除） |
| **Threshold（临界值）** | 斯品汉姆兰法令的实施本身即构成贫困化的临界条件 |
| **前提与约束（Premises）** | 救济水平与面包价格挂钩，导致工资被压低；劳工阶层接受救济作为生存手段，形成依赖 |
| **Falsification（证伪条件）** | 若斯品汉姆兰体系下劳工生活水平提高、社会地位改善，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为斯品汉姆兰体系是保护穷人免受市场冲击的正面观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同给溺水者一根稻草，看似救命，实则让他沉得更快

### 🔗 文字版因果链

1. 斯品汉姆兰体系提供所外救济，看似保障生存权，实则使劳工依赖救济而丧失自立能力
2. 救济制度掩盖了劳动市场的真实供需，阻碍了劳动力商品化进程
3. 劳工被剥夺了通过市场交换获得尊严的机会，沦为救济对象，被非人化
4. 贫困化加剧，劳动大众从'人'变为'梦魇中的鬼魂'
