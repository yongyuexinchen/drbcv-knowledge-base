# 劳动大众非人化与所有者阶级道德降格，形成'两个国度'的社会分

> 属于因果簇：[[斯品汉姆兰体系废除与市场机制确立的因果分析]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 废除斯品汉姆兰体系（1834年济贫法改革） |
| **DV（因变量）** | 劳动大众非人化与所有者阶级道德降格，形成'两个国度'的社会分裂 |
| **Chain（传导链）** | 斯品汉姆兰体系以'生存权'名义提供所外救济，实则掠夺大众，扭曲劳动市场 → 1834年新济贫法取消工资补助，重新引入习艺所测试，并使其成为耻辱性、心理和道德煎熬的场所 → 济贫管理权从地方治安法官转移到中央监督下的济贫管理员，实行全国性、区别性管理 → 赤贫者葬礼被仪式化地隔离，强化社会排斥，劳动大众被非人化 → 所有者阶级拒绝承担对穷困邻人的责任，传统基督教社会整合瓦解，富裕者与贫困者形成两个对立国度 |
| **Lag（时滞）** | 数十年至数代（从1834年改革到社会结构完全转型） |
| **Threshold（临界值）** | 1834年济贫法改革作为制度性临界点，废除所外救济并重新引入习艺所测试 |
| **前提与约束（Premises）** | 工业资本主义已具备充分发展条件，市场机制需要自由劳动力；斯品汉姆兰体系已深入社会骨髓，其废除是制度转型的必要条件；社会各阶层（包括劳工自身）认同新体系的信念基础 |
| **Falsification（证伪条件）** | 若1834年后劳动大众的社会地位改善、所有者阶级承担更多责任、社会整合增强，则此断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为济贫法改革是进步性人道主义改革的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同拆除旧屋的承重墙，虽然表面上是改善结构，但实际导致整栋建筑（社会）的崩塌和分裂

### 🔗 文字版因果链

1. 斯品汉姆兰体系以'生存权'名义提供所外救济，实则掠夺大众，扭曲劳动市场
2. 1834年新济贫法取消工资补助，重新引入习艺所测试，并使其成为耻辱性、心理和道德煎熬的场所
3. 济贫管理权从地方治安法官转移到中央监督下的济贫管理员，实行全国性、区别性管理
4. 赤贫者葬礼被仪式化地隔离，强化社会排斥，劳动大众被非人化
5. 所有者阶级拒绝承担对穷困邻人的责任，传统基督教社会整合瓦解，富裕者与贫困者形成两个对立国度
