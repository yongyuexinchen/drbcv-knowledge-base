# 全国性市场的形成与国内贸易的创造

> 属于因果簇：[[重商主义国家干预创造国内贸易与全国性市场]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 重商主义时期国家干预（打破地方贸易与远程贸易的隔绝，废除地方保护主义） |
| **DV（因变量）** | 全国性市场的形成与国内贸易的创造 |
| **Chain（传导链）** | 中世纪城镇严格区分地方贸易与远程贸易，并排斥乡村参与贸易，形成非竞争性的地方市场和城镇间远程贸易 → 城镇为保护自身制度，设置障碍阻遏资本主义批发商渴望的全国性市场或国内市场形成 → 15-16世纪，欧洲各国政府有计划地将商业制度强加于具有强烈保护主义倾向的城镇和公国头上 → 国家干预打破地方性贸易和城市间贸易之间的隔阂，摧毁了两种非竞争性商业所体现的特殊化 → 贸易扩展至整个国家疆域，城乡之间、城镇之间和省份之间的差别日益消除，全国性市场出现 |
| **Lag（时滞）** | 15-16世纪（约两百年尺度），从国家干预到全国性市场形成 |
| **Threshold（临界值）** | 国家必须同时打破地方贸易与远程贸易的隔绝，并将管制规模从城镇水平扩展到国家疆域水平 |
| **前提与约束（Premises）** | 仅当国家拥有足够的中央集权能力以将政策推行至全国时成立；仅当商业革命已将经济重心从地中海转移至大西洋沿岸，迫使农业国组织商业贸易时成立；排除完全自由放任的市场经济体制（重商主义仍以管制为特征）；乡村自给自足的家计经济仍作为经济体系的广泛基础，国内市场与家计经济原则兼容 |
| **Falsification（证伪条件）** | 若发现某一国家在无中央集权干预的情况下（如纯粹自发演化）形成了全国性统一市场，或重商主义干预后未出现国内市场整合，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及法国行会国家化、英国《工匠法》等制度案例，但无具体贸易量或市场整合度数字） |
| **Conflicts（观点冲突）** | 与亚当·斯密等古典自由主义认为市场自发演化形成国内贸易的观点冲突；与哈耶克'政府干预必然扭曲市场'的立场冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个村庄里各家各户自给自足、只在村口集市交换，后来中央政府修了一条国道并废除各村关卡，才让全国货物自由流通形成统一大市场

### 🔗 文字版因果链

1. 中世纪城镇严格区分地方贸易与远程贸易，并排斥乡村参与贸易，形成非竞争性的地方市场和城镇间远程贸易
2. 城镇为保护自身制度，设置障碍阻遏资本主义批发商渴望的全国性市场或国内市场形成
3. 15-16世纪，欧洲各国政府有计划地将商业制度强加于具有强烈保护主义倾向的城镇和公国头上
4. 国家干预打破地方性贸易和城市间贸易之间的隔阂，摧毁了两种非竞争性商业所体现的特殊化
5. 贸易扩展至整个国家疆域，城乡之间、城镇之间和省份之间的差别日益消除，全国性市场出现
