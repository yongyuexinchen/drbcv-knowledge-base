# 社会与自然环境的毁灭（人类被摧毁、环境变成荒野）

> 属于因果簇：[[自我调节市场的乌托邦性质及其社会后果]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自我调节市场的理念（作为19世纪制度体系的核心） |
| **DV（因变量）** | 社会与自然环境的毁灭（人类被摧毁、环境变成荒野） |
| **Chain（传导链）** | 自我调节市场理念将劳动力、土地和货币视为完全商品化、受市场供求法则支配 → 这种完全商品化要求社会与自然完全服从市场机制，剥离其非经济属性 → 若完全实施，将摧毁人类的社会关系、生存基础及自然环境 → 社会为自我保护必然采取干预措施（如立法、关税、工会等） → 这些干预措施反过来损害市场的自我调节功能，打乱工业生活，引发深层社会危机 |
| **Lag（时滞）** | 长期（数十年至一个世纪，如19世纪至20世纪初的演变） |
| **Threshold（临界值）** | 市场机制完全支配劳动力、土地和货币（即完全商品化）时，危机不可避免 |
| **前提与约束（Premises）** | 仅在市场机制试图完全支配社会与自然（即完全商品化）时成立；社会具有自我保护的本能反应（如通过立法、政策干预）；排除市场机制仅部分调节、社会仍保留非经济制度约束的情况 |
| **Falsification（证伪条件）** | 若存在一个完全自我调节市场长期运行且未导致社会与自然毁灭的实例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于19世纪工业文明历史分析） |
| **Conflicts（观点冲突）** | 与古典自由主义经济学（如亚当·斯密“看不见的手”的自我调节市场观）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将人体完全交给不受约束的代谢机制，若不加以调节，最终会耗尽器官、破坏整体平衡，身体必然崩溃

### 🔗 文字版因果链

1. 自我调节市场理念将劳动力、土地和货币视为完全商品化、受市场供求法则支配
2. 这种完全商品化要求社会与自然完全服从市场机制，剥离其非经济属性
3. 若完全实施，将摧毁人类的社会关系、生存基础及自然环境
4. 社会为自我保护必然采取干预措施（如立法、关税、工会等）
5. 这些干预措施反过来损害市场的自我调节功能，打乱工业生活，引发深层社会危机
