# 和平（而非战争）

> 属于因果簇：[[自我调节市场的乌托邦性质及其社会后果]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 势力均衡体系（在19世纪） |
| **DV（因变量）** | 和平（而非战争） |
| **Chain（传导链）** | 势力均衡体系本应通过战争维持权力单元独立（如古希腊城邦） → 19世纪出现新的和平利益（由国际金融代表） → 和平利益通过国际金融等机制转化为政治行动 → 强权为避免全面战争（损害金融利益）而局部化冲突、控制小国、调解争端 → 结果：均衡体系产生和平这一非固有结果 |
| **Lag（时滞）** | 短期至中期（如1875年、1877-1878年危机调解） |
| **Threshold（临界值）** | 存在强有力的和平利益（如国际金融）且强权间无根本利益冲突时 |
| **前提与约束（Premises）** | 仅当和平利益（如国际金融）有效作用于政治层面时成立；需要强权间有共同利益（如维持货币稳定）；排除强权间存在不可调和矛盾（如一战前德英对抗）的情况 |
| **Falsification（证伪条件）** | 若存在19世纪强权间全面战争（如一战）且均衡体系未能维持和平，则该断言被部分推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（如百年和平统计：1815-1914年主要战争仅18个月） |
| **Conflicts（观点冲突）** | 与“势力均衡必然导致战争”的传统观点冲突（如古希腊城邦实践） |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一个天平，本应因重量变化而倾斜（战争），但若有人（国际金融）不断微调砝码（外交干预），天平反而保持平衡，但这依赖外部干预

### 🔗 文字版因果链

1. 势力均衡体系本应通过战争维持权力单元独立（如古希腊城邦）
2. 19世纪出现新的和平利益（由国际金融代表）
3. 和平利益通过国际金融等机制转化为政治行动
4. 强权为避免全面战争（损害金融利益）而局部化冲突、控制小国、调解争端
5. 结果：均衡体系产生和平这一非固有结果
