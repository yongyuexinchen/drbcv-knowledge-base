# 重商主义国家干预创造国内贸易与全国性市场

> **领域**：经济史、宏观经济学　|　**来源**：波兰尼_chapter_11_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 重商主义时期国家干预（打破地方贸易与远程贸易的隔绝，废除地方保护主义） |
| **DV（因变量）** | 全国性市场的形成与国内贸易的创造 |
| **Chain（传导链）** | 中世纪城镇严格区分地方贸易与远程贸易，并排斥乡村参与贸易，形成非竞争性的地方市场和城镇间远程贸易 → 城镇为保护自身制度，设置障碍阻遏资本主义批发商渴望的全国性市场或国内市场形成 → 15-16世纪，欧洲各国政府有计划地将商业制度强加于具有强烈保护主义倾向的城镇和公国头上 → 国家干预打破地方性贸易和城市间贸易之间的隔阂，摧毁了两种非竞争性商业所体现的特殊化 → 贸易扩展至整个国家疆域，城乡之间、城镇之间和省份之间的差别日益消除，全国性市场出现 |
| **Lag（时滞）** | 15-16世纪（约两百年尺度），从国家干预到全国性市场形成 |
| **Threshold（临界值）** | 国家必须同时打破地方贸易与远程贸易的隔绝，并将管制规模从城镇水平扩展到国家疆域水平 |
| **前提与约束（Premises）** | 仅当国家拥有足够的中央集权能力以将政策推行至全国时成立；仅当商业革命已将经济重心从地中海转移至大西洋沿岸，迫使农业国组织商业贸易时成立；排除完全自由放任的市场经济体制（重商主义仍以管制为特征）；乡村自给自足的家计经济仍作为经济体系的广泛基础，国内市场与家计经济原则兼容 |
| **Falsification（证伪条件）** | 若发现某一国家在无中央集权干预的情况下（如纯粹自发演化）形成了全国性统一市场，或重商主义干预后未出现国内市场整合，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及法国行会国家化、英国《工匠法》等制度案例，但无具体贸易量或市场整合度数字） |
| **Conflicts（观点冲突）** | 与亚当·斯密等古典自由主义认为市场自发演化形成国内贸易的观点冲突；与哈耶克'政府干预必然扭曲市场'的立场冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个村庄里各家各户自给自足、只在村口集市交换，后来中央政府修了一条国道并废除各村关卡，才让全国货物自由流通形成统一大市场

### 🔗 文字版因果链

1. 中世纪城镇严格区分地方贸易与远程贸易，并排斥乡村参与贸易，形成非竞争性的地方市场和城镇间远程贸易
2. 城镇为保护自身制度，设置障碍阻遏资本主义批发商渴望的全国性市场或国内市场形成
3. 15-16世纪，欧洲各国政府有计划地将商业制度强加于具有强烈保护主义倾向的城镇和公国头上
4. 国家干预打破地方性贸易和城市间贸易之间的隔阂，摧毁了两种非竞争性商业所体现的特殊化
5. 贸易扩展至整个国家疆域，城乡之间、城镇之间和省份之间的差别日益消除，全国性市场出现

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 将劳动力、土地和货币作为虚拟商品纳入市场机制 |
| **DV（因变量）** | 社会毁灭（人的堕落、环境破坏、商业周期性危机） |
| **Chain（传导链）** | 市场经济必须囊括工业生产所需的所有要素，包括劳动力、土地和货币 → 劳动力、土地和货币并非真正商品（劳动力是人类活动的名称，土地是自然的名称，货币是购买力象征），其商品形象是虚构的 → 在虚构商品概念下，市场机制成为人的命运、自然环境及购买力数量和用途的唯一主宰 → 劳动力被推来操去、被弃置不用时，附载其上的人（生理、心理、道德实体）被摧毁，导致社会混乱、堕落、犯罪和饥荒 → 自然界被化约为基本元素，邻里关系、乡间风景被损毁，河流被污染，军事安全受威胁，食物和原材料生产能力被破坏 → 购买力的市场控制周期性地肃清扼杀商业企业，货币供给涨落如同洪水干旱之于原始社会 |
| **Lag（时滞）** | 19世纪市场经济全面确立后，随市场机制扩展而逐步显现（数十年尺度） |
| **Threshold（临界值）** | 当市场机制成为劳动力、土地和货币的唯一主宰，且社会缺乏文化制度保护层时，毁灭性后果必然发生 |
| **前提与约束（Premises）** | 仅当社会被制度性分离为经济与政治两个领域，且经济领域独立运作时成立；仅当劳动力、土地和货币被实际组织为买卖对象时成立；排除社会通过自发保护运动（如工会、环保立法）对虚拟商品市场进行反向干预的情况；该断言基于19世纪市场社会的历史条件，不适用于前市场经济社会 |
| **Falsification（证伪条件）** | 若发现某一市场经济社会在劳动力、土地和货币完全市场化后，未出现社会解体、环境破坏或周期性商业危机，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（文中提及19世纪英国《济贫法》1834年取消、《工匠法》1813-1814年取消等制度节点，但无具体社会损害统计数字） |
| **Conflicts（观点冲突）** | 与新古典经济学认为要素市场化是资源配置最优路径的观点冲突；与自由市场主义'自发调节市场能自我平衡'的信念冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同把人的血液（劳动力）、土地（自然）和信用（货币）当作普通商品在市场上自由买卖，就像把人的器官当猪肉一样出售，最终必然导致人体（社会）崩溃

### 🔗 文字版因果链

1. 市场经济必须囊括工业生产所需的所有要素，包括劳动力、土地和货币
2. 劳动力、土地和货币并非真正商品（劳动力是人类活动的名称，土地是自然的名称，货币是购买力象征），其商品形象是虚构的
3. 在虚构商品概念下，市场机制成为人的命运、自然环境及购买力数量和用途的唯一主宰
4. 劳动力被推来操去、被弃置不用时，附载其上的人（生理、心理、道德实体）被摧毁，导致社会混乱、堕落、犯罪和饥荒
5. 自然界被化约为基本元素，邻里关系、乡间风景被损毁，河流被污染，军事安全受威胁，食物和原材料生产能力被破坏
6. 购买力的市场控制周期性地肃清扼杀商业企业，货币供给涨落如同洪水干旱之于原始社会
