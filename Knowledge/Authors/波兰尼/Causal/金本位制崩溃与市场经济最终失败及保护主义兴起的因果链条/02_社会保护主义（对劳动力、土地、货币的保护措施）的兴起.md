# 社会保护主义（对劳动力、土地、货币的保护措施）的兴起

> 属于因果簇：[[金本位制崩溃与市场经济最终失败及保护主义兴起的因果链条]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自我调节市场机制的内在缺陷（生产要素市场——劳动力、土地、货币——的运行具有毁灭社会的危险） |
| **DV（因变量）** | 社会保护主义（对劳动力、土地、货币的保护措施）的兴起 |
| **Chain（传导链）** | 自我调节的市场体系要求劳动力、土地、货币作为商品自由交易 → 这些要素市场的自由运行具有毁灭社会的危险（如劳动力商品化破坏社会关系、土地商品化破坏自然、货币商品化导致经济不稳定） → 共同体出于自我保存的本能，建立保护措施，要么阻止这些要素市场的建立，要么干扰其自由运行 → 保护主义表现为对劳动力的社会保障（工会、立法）、对土地及其耕作者的保护（关税、农业政策）、对货币的中央银行调节 → 因此，社会保护必然与所谓的自我调节市场如影随形 |
| **Lag（时滞）** | 中期（数十年），从市场机制扩张到保护主义反应显现 |
| **Threshold（临界值）** | 当劳动力、土地、货币的自由供给不再可能（如边疆关闭、移民停止、金本位制引入）时，社会保护启动 |
| **前提与约束（Premises）** | 存在自我调节的市场体系；劳动力、土地、货币被商品化；这些要素市场的自由运行确实会带来毁灭性后果；共同体有自我保存的能力和意愿 |
| **Falsification（证伪条件）** | 如果存在长期运行自我调节市场体系且未出现社会保护的国家或时期，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与经济自由主义认为市场自我调节可以自发实现均衡、无需社会保护的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 自我调节市场像一台高速运转的机器，其零件（劳动力、土地、货币）磨损会毁坏整机（社会），保护主义是工人为机器加装的防护罩

### 🔗 文字版因果链

1. 自我调节的市场体系要求劳动力、土地、货币作为商品自由交易
2. 这些要素市场的自由运行具有毁灭社会的危险（如劳动力商品化破坏社会关系、土地商品化破坏自然、货币商品化导致经济不稳定）
3. 共同体出于自我保存的本能，建立保护措施，要么阻止这些要素市场的建立，要么干扰其自由运行
4. 保护主义表现为对劳动力的社会保障（工会、立法）、对土地及其耕作者的保护（关税、农业政策）、对货币的中央银行调节
5. 因此，社会保护必然与所谓的自我调节市场如影随形
