# 金本位制崩溃与市场经济最终失败及保护主义兴起的因果链条（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：金本位制崩溃与市场经济最终失败及保护主义兴起的因果链条.md

## 总体因果图

- 国际金本位制的维持要求（稳定汇率）与国内价格水平刚性之间的矛盾 → 中央银行（货币保护主义）的建立与强化
- 自我调节市场机制的内在缺陷（生产要素市场——劳动力、土地、货币——的运行具有毁灭社会的危险） → 社会保护主义（对劳动力、土地、货币的保护措施）的兴起
- 金本位制的最终失败（如英国1931年、美国1933年放弃金本位） → 市场经济的最终失败与专制孤立主义力量的爆发
- 货币保护主义（中央银行政策） → 国家认同与经济整合（国家通货作为国家身份象征）
- 贸易保护主义（对货物和人的跨国流动的阻碍） → 国际资本流动和支付自由的增强（货币自由的扩张）
