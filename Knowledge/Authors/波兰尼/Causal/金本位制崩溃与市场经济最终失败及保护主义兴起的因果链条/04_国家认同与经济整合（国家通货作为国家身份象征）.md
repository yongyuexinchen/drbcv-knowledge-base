# 国家认同与经济整合（国家通货作为国家身份象征）

> 属于因果簇：[[金本位制崩溃与市场经济最终失败及保护主义兴起的因果链条]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币保护主义（中央银行政策） |
| **DV（因变量）** | 国家认同与经济整合（国家通货作为国家身份象征） |
| **Chain（传导链）** | 货币保护主义首先出现，如美国联邦储备体系的建立以平衡金本位制与地方需求 → 货币政策创造的效应变幻不定、从不停息，影响共同体中每个人的切身利益 → 货币政策的整合力量超过其他保护主义措施，因为其效应持续且普遍 → 从政治上说，对国家的认同由政府建立；从经济上讲，由中央银行建立 → 国家通货成为国家身份认同的象征，得到空前排他的、绝对的主权保护 |
| **Lag（时滞）** | 中期（数十年），从中央银行建立到国家通货认同巩固 |
| **Threshold（临界值）** | 当通货不稳定、必须做出贬值或升值的致命决定时，货币政策对国家认同的影响达到最大 |
| **前提与约束（Premises）** | 存在民族国家体系；中央银行具有货币政策自主权；通货稳定与否对国内各阶层利益有重大影响 |
| **Falsification（证伪条件）** | 如果存在中央银行但国家通货未能成为国家认同象征的情况，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由主义认为货币仅是交换工具、国家通货无足轻重的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 中央银行像国家的经济心脏，货币政策像血液流动，将国家认同输送到每个公民的日常经济生活中，使国家通货成为国家的经济身份证

### 🔗 文字版因果链

1. 货币保护主义首先出现，如美国联邦储备体系的建立以平衡金本位制与地方需求
2. 货币政策创造的效应变幻不定、从不停息，影响共同体中每个人的切身利益
3. 货币政策的整合力量超过其他保护主义措施，因为其效应持续且普遍
4. 从政治上说，对国家的认同由政府建立；从经济上讲，由中央银行建立
5. 国家通货成为国家身份认同的象征，得到空前排他的、绝对的主权保护
