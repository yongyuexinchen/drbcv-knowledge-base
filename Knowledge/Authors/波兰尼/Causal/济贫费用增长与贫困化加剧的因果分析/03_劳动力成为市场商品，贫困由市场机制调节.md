# 劳动力成为市场商品，贫困由市场机制调节

> 属于因果簇：[[济贫费用增长与贫困化加剧的因果分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 济贫法废除（自由放任政策） |
| **DV（因变量）** | 劳动力成为市场商品，贫困由市场机制调节 |
| **Chain（传导链）** | 废除伊丽莎白时代的济贫法，取消工资评估和最低工资保障 → 劳动力不再受法律保护，必须作为商品在市场上定价 → 饥饿成为最有效的惩戒者，迫使穷人接受市场工资 → 市场自然调节劳动力供需，无需政府干预 |
| **Lag（时滞）** | 短期至中期（政策实施后逐步显现） |
| **Threshold（临界值）** | 完全废除济贫法，不设替代性保障措施 |
| **前提与约束（Premises）** | 市场体系完善，劳动力自由流动；财产权安全，雇主有雇佣意愿；排除政府最低工资和救济干预 |
| **Falsification（证伪条件）** | 若废除济贫法后，劳动力并未有效市场化，或导致社会动荡、贫困加剧而非秩序稳定，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张保留济贫法、保障穷人基本生存权的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同拆除安全网后让高空作业者自行负责——支持者认为这能激发潜能，反对者认为会导致坠落。

### 🔗 文字版因果链

1. 废除伊丽莎白时代的济贫法，取消工资评估和最低工资保障
2. 劳动力不再受法律保护，必须作为商品在市场上定价
3. 饥饿成为最有效的惩戒者，迫使穷人接受市场工资
4. 市场自然调节劳动力供需，无需政府干预
