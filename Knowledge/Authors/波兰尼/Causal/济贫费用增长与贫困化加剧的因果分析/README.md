# 济贫费用增长与贫困化加剧的因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：济贫费用增长与贫困化加剧的因果分析.md

## 总体因果图

- 人口增长（120年间约增加两倍） → 济贫费用急剧增加（增加20倍）
- 饥饿作为自然惩戒机制（汤森的山羊与狗法则） → 穷人被迫劳动、服从社会秩序
- 济贫法废除（自由放任政策） → 劳动力成为市场商品，贫困由市场机制调节
- 贫困作为社会自然选择机制（边沁的功利主义视角） → 社会繁荣达到最高阶段
