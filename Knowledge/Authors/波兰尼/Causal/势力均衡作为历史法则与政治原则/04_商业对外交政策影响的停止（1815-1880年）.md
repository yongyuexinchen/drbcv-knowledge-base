# 商业对外交政策影响的停止（1815-1880年）

> 属于因果簇：[[势力均衡作为历史法则与政治原则]]（第4块/5块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 贸易性质的改变（从直接武力依赖到规模与成功不依赖武力） |
| **DV（因变量）** | 商业对外交政策影响的停止（1815-1880年） |
| **Chain（传导链）** | 19世纪贸易规模扩大，成功不再依赖直接武力 → 传统扩张主义被反帝国主义潮流取代 → 商业利益对外交政策的影响减弱 → 形成私人商业利益排除于外交事务的教条 |
| **Lag（时滞）** | 约半个世纪（1815-1880） |
| **Threshold（临界值）** | 贸易需达到一定规模且不依赖武力保护 |
| **前提与约束（Premises）** | 自由贸易时代开始；国际金本位制建立；殖民帝国阶段逝去 |
| **Falsification（证伪条件）** | 若在贸易不依赖武力时期商业利益仍强烈影响外交政策，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |

| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同商人不再需要保镖保护货物，因此保镖的影响力下降

### 🔗 文字版因果链

1. 19世纪贸易规模扩大，成功不再依赖直接武力
2. 传统扩张主义被反帝国主义潮流取代
3. 商业利益对外交政策的影响减弱
4. 形成私人商业利益排除于外交事务的教条
