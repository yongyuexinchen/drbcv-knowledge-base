## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 势力均衡原则的正式承认（如1648年威斯特伐利亚条约） |
| **DV（因变量）** | 小国独立与存在的维持 |
| **Chain（传导链）** | 1648年条约承认既得利益者地位 → 各国将势力均衡视为共同原则 → 任何重大变动被视为对所有国家利益攸关 → 大国联合防止势力格局改变 → 小国因被吞并会削弱均衡而受到间接保护 |
| **Lag（时滞）** | 长期（约两百年内持续有效） |
| **Threshold（临界值）** | 需有多个强权共同承认并维护该原则 |
| **前提与约束（Premises）** | 存在多个实力相当的大国；大国愿意遵循该原则行事；体系内无单一霸权 |
| **Falsification（证伪条件）** | 若小国在势力均衡体系下仍频繁被吞并，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与现实主义'大国主导'观点部分冲突，但更强调体系保护作用 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同社区中的保安系统，虽无强制力，但通过共同维护规则保护弱者

### 🔗 文字版因果链

1. 1648年条约承认既得利益者地位
2. 各国将势力均衡视为共同原则
3. 任何重大变动被视为对所有国家利益攸关
4. 大国联合防止势力格局改变
5. 小国因被吞并会削弱均衡而受到间接保护
