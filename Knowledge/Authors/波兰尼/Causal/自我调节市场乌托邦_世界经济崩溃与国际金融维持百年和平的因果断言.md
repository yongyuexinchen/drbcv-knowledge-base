# 自我调节市场乌托邦、世界经济崩溃与国际金融维持百年和平的因果断言

> **领域**：历史社会学 / 宏观经济学　|　**来源**：chapter_05.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自我调节市场的理念 |
| **DV（因变量）** | 社会采取保护性措施，损害市场自我调节，打乱工业生活，最终导致文明危机 |
| **Chain（传导链）** | 自我调节市场的理念要求将劳动力、土地和货币完全交由市场机制调节 → 这种制度在现实中会摧毁人类并将环境变成荒野 → 社会为了自我保护，必然采取措施干预市场运作 → 这些保护性措施反过来损害了市场的自我调节，打乱了工业生活 → 该过程最终导致19世纪文明的危机或崩溃 |
| **Lag（时滞）** | 约一个世纪（从19世纪初理念产生到20世纪初危机爆发） |
| **Threshold（临界值）** | 当市场自我调节机制覆盖劳动力、土地和货币这些基本要素时，破坏性开始显现 |
| **前提与约束（Premises）** | 社会不可能真正消灭社会中的人和自然物质；社会具有自我保护的本能，不会任由自我调节市场摧毁其基础 |
| **Falsification（证伪条件）** | 如果能证明自我调节市场可以在不摧毁人类和环境的情况下长期稳定运行，且社会不会产生保护性干预，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个不允许免疫系统反应的生物体，表面上的‘完全自调节’最终会摧毁器官，而免疫反应本身又会干扰原有调节，造成更深的紊乱。

### 🔗 文字版因果链

1. 自我调节市场的理念要求将劳动力、土地和货币完全交由市场机制调节
2. 这种制度在现实中会摧毁人类并将环境变成荒野
3. 社会为了自我保护，必然采取措施干预市场运作
4. 这些保护性措施反过来损害了市场的自我调节，打乱了工业生活
5. 该过程最终导致19世纪文明的危机或崩溃

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 世界经济崩溃 |
| **DV（因变量）** | 势力均衡体系无法确保和平，国际体系突然瓦解 |
| **Chain（传导链）** | 势力均衡体系的存在依赖世界经济作为基础 → 世界经济一旦崩溃，势力均衡体系的运作条件丧失 → 均衡机制无法再通过局部化冲突来维持和平 → 国际体系发生突然断裂和快速瓦解 |
| **Lag（时滞）** | 时间上合拍（文本指出文明的分崩离析与世界经济的崩溃在时间上是同步的） |
| **Threshold（临界值）** | 世界经济崩溃到足以破坏势力均衡体系所依赖的货币与贸易基础 |
| **前提与约束（Premises）** | 势力均衡体系只有在其经济基础稳定时才能发挥维持和平的功能；崩溃一旦发生，不存在其他能够替代该经济基础来支撑均衡机制的即时力量 |
| **Falsification（证伪条件）** | 如果能证明世界经济崩溃后，势力均衡体系依然能够维持和平或阻止国际体系瓦解，则该断言被推翻。 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同一个依靠底座平衡的陀螺，一旦底座碎裂，陀螺便无法保持直立，旋转也会骤然停止。

### 🔗 文字版因果链

1. 势力均衡体系的存在依赖世界经济作为基础
2. 世界经济一旦崩溃，势力均衡体系的运作条件丧失
3. 均衡机制无法再通过局部化冲突来维持和平
4. 国际体系发生突然断裂和快速瓦解

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国际金融（hautefinance）的地位、组织与运作 |
| **DV（因变量）** | 1815-1914年间主要强国之间的百年和平得以维持 |
| **Chain（传导链）** | 国际金融作为独立的跨国机构与各国政府和中央银行保持密切联系 → 国际金融以获利为动机，但全面战争会干扰国际均衡体系的货币基础，损害其生意 → 因此国际金融成为一种强有力的‘和平利益’组织化力量 → 它在欧洲协同体等政治机制不足时，承担起调节强权冲突、遏制全面战争的功能 → 最终促成并维持了百年和平 |
| **Lag（时滞）** | 19世纪后期（尤其是最后30年）至20世纪初，国际金融才成为关键维持因素 |
| **Threshold（临界值）** | 国际金融必须足够强大且独立于任何单一政府，同时与所有主要强权都有金融联系 |
| **前提与约束（Premises）** | 存在势力均衡体系且国际金融需要该体系的货币基础保持稳定；国际金融虽不反对小规模、局部性战争，但必须避免大国间全面战争；强权优先于利润，国际金融的政治效果是意外获得的，而非其设计初衷 |
| **Falsification（证伪条件）** | 如果能证明即使没有国际金融，19世纪长期和平依然会出现，或者国际金融实际推动了大国全面战争，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个跨国商业集团，虽然它本身不追求和平，但为了生意稳定，它会促使各国避免全面冲突，即使它并不介意小规模摩擦。

### 🔗 文字版因果链

1. 国际金融作为独立的跨国机构与各国政府和中央银行保持密切联系
2. 国际金融以获利为动机，但全面战争会干扰国际均衡体系的货币基础，损害其生意
3. 因此国际金融成为一种强有力的‘和平利益’组织化力量
4. 它在欧洲协同体等政治机制不足时，承担起调节强权冲突、遏制全面战争的功能
5. 最终促成并维持了百年和平
