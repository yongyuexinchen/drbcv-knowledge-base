# 社会关系瓦解与人类栖息地破坏（贫民窟、家庭解体、环境恶化）

> 属于因果簇：[[圈地运动的社会代价与政府干预的缓冲作用]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场经济体系的建立（商品化劳动力与土地） |
| **DV（因变量）** | 社会关系瓦解与人类栖息地破坏（贫民窟、家庭解体、环境恶化） |
| **Chain（传导链）** | 专业化机器生产要求所有生产要素（包括劳动力和土地）成为可买卖商品 → 生存动机被获利动机取代，一切交易变成金钱交易 → 社会自然本性和人的本质被转化为商品 → 市场自发调节机制不受干预，导致社会关系瓦解和自然环境破坏 |
| **Lag（时滞）** | 数十年至一个世纪（19世纪工业革命期间全面显现） |
| **Threshold（临界值）** | 当市场体系完全建立并自发调节时，破坏性后果不可避免 |
| **前提与约束（Premises）** | 仅当市场体系完全支配经济生活时；在缺乏外部干预或社会保障机制的情况下成立；排除市场体系部分建立或受其他制度约束的情况 |
| **Falsification（证伪条件）** | 若市场体系建立后未导致社会关系瓦解或环境破坏，或破坏可归因于其他因素，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及工业城镇兴起、贫民窟出现、童工劳作等） |
| **Conflicts（观点冲突）** | 与亚当·斯密及其追随者认为市场自发调节有益的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将水和土都变成商品出售，河流改道、土壤流失是必然结果；无人管理，自然系统必然崩溃

### 🔗 文字版因果链

1. 专业化机器生产要求所有生产要素（包括劳动力和土地）成为可买卖商品
2. 生存动机被获利动机取代，一切交易变成金钱交易
3. 社会自然本性和人的本质被转化为商品
4. 市场自发调节机制不受干预，导致社会关系瓦解和自然环境破坏
