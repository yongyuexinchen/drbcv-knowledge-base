# 阶级的兴衰、奋斗目标及其实现程度、阶级间合作或对立

> 属于因果簇：[[波兰尼《大转型》因果关系提取]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会整体状况（由外在原因如气候变化、战争、新敌人、新发明等决定的挑战） |
| **DV（因变量）** | 阶级的兴衰、奋斗目标及其实现程度、阶级间合作或对立 |
| **Chain（传导链）** | 外在力量改变整个社会的结构条件 → 不同阶级因地理、经济、文化位置差异而受到不同影响 → 各阶级采取适应行动并调整自身利益，试图领导其他群体 → 阶级能否成功取决于其代表其他阶级利益的能力（即能否服务整体） → 阶级的命运（生死、目标实现程度）由社会整体需要而非本阶级利益决定 |
| **Lag（时滞）** | 长期历史进程（文本未给出明确时滞，通常为跨代际） |
| **Threshold（临界值）** | 未明确量化；当社会结构本身处于转变或文明危机阶段时，阶级理论失效 |
| **前提与约束（Premises）** | 阶级利益不是纯经济的，而是社会性的（身份、地位、安全等）；社会结构变迁阶段，旧阶级会解体、新阶级会形成；没有阶级能单靠自身狭隘利益维持长期领导地位 |
| **Falsification（证伪条件）** | 若能证明一个阶级可以仅凭其自身经济利益，不依赖社会整体状况和支持，就决定历史变迁的方向，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一艘船的各个舱室（阶级）无法决定船是否沉没；天气与航向（社会整体状况）决定命运，舱室是否密封良好只是次要因素。

### 🔗 文字版因果链

1. 外在力量改变整个社会的结构条件
2. 不同阶级因地理、经济、文化位置差异而受到不同影响
3. 各阶级采取适应行动并调整自身利益，试图领导其他群体
4. 阶级能否成功取决于其代表其他阶级利益的能力（即能否服务整体）
5. 阶级的命运（生死、目标实现程度）由社会整体需要而非本阶级利益决定
