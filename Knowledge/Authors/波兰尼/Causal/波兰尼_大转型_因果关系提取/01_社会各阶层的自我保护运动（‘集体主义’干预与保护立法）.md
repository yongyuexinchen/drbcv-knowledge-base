# 社会各阶层的自我保护运动（‘集体主义’干预与保护立法）

> 属于因果簇：[[波兰尼《大转型》因果关系提取]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自发调节的市场经济的扩张（将土地、劳动力、货币商品化） |
| **DV（因变量）** | 社会各阶层的自我保护运动（‘集体主义’干预与保护立法） |
| **Chain（传导链）** | 市场经济原则渗透到社会组织的自然与人性基础中 → 劳动关系、土地与货币被赋予虚拟商品属性，破坏社会关系网络和生存安全 → 各类人群（工人、地主、农民、中产等）的社会性利益（身份、稳定、地位）受到威胁 → 社会不同群体不自觉地形成合力，要求国家干预以抵抗市场冲击 → 普遍的保护主义运动（工会法、反托拉斯法、社会立法等）出现 |
| **Lag（时滞）** | 19世纪70年代至1880年代“集体主义”反抗的普遍出现，滞后于市场化扩张数十年（文本未给出精确年限） |
| **Threshold（临界值）** | 未明确量化；当市场扩张对基本社会制度造成可感知的损害时（如劳动力与土地被完全商品化） |
| **前提与约束（Premises）** | 市场经济确会威胁社会中的人性因素和自然因素（即市场是‘乌托邦’原则）；社会保护运动不需要理论或意识形态前提，也不由特定阶级利益唯一决定；存在可观察的不同国家同时发生的近似证据 |
| **Falsification（证伪条件）** | 若能证明经济自由主义主张的‘自由政策从未真正实行而是被外部扭曲’正确，或市场经济扩张没有引发普遍社会保护需求，则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 人体免疫系统对异物入侵产生排斥反应：市场是外来异物，社会自发产生保护机制（炎症、发烧）来隔离和抵御威胁。

### 🔗 文字版因果链

1. 市场经济原则渗透到社会组织的自然与人性基础中
2. 劳动关系、土地与货币被赋予虚拟商品属性，破坏社会关系网络和生存安全
3. 各类人群（工人、地主、农民、中产等）的社会性利益（身份、稳定、地位）受到威胁
4. 社会不同群体不自觉地形成合力，要求国家干预以抵抗市场冲击
5. 普遍的保护主义运动（工会法、反托拉斯法、社会立法等）出现
