## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场体系自我调节的扩张（将劳动、土地、货币商品化） |
| **DV（因变量）** | 社会自我保护运动（如劳工立法、关税、金本位制崩溃） |
| **Chain（传导链）** | 市场体系将劳动、土地、货币视为虚构商品，并试图通过市场机制自我调节 → 这种商品化过程破坏了传统社会关系、自然环境和货币稳定 → 社会各阶层（劳工、地主、企业主、国家）感受到威胁，产生集体反抗 → 国家通过立法（如工厂立法、社会立法）和贸易政策（关税）进行干预 → 干预措施反过来阻碍市场自我调节，导致市场体系与社会保护之间的冲突加剧 → 冲突最终导致金本位制崩溃、法西斯主义兴起等系统性危机 |
| **Lag（时滞）** | 数十年至数代（如19世纪市场扩张到20世纪初的保护立法和危机） |
| **Threshold（临界值）** | 当劳动、土地、货币的商品化程度超过社会承受阈值（如劳工生存条件恶化、土地传统权利被剥夺、货币稳定受威胁）时，保护运动必然兴起 |
| **前提与约束（Premises）** | 市场体系是19世纪以来西方社会的组织核心；社会保护运动是自发反应，不依赖特定意识形态；国家是实施保护的主要载体；该断言适用于工业资本主义国家（如英国、德国、美国） |
| **Falsification（证伪条件）** | 如果存在一个工业资本主义国家，市场体系高度自我调节但未出现任何社会保护立法或运动，且社会保持稳定，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典自由主义（如斯宾塞）认为市场自我调节能自然达到社会和谐的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同人体免疫系统：当外部异物（市场商品化）侵入过多时，身体会产生发热、炎症（社会保护）来抵抗，但过度反应也可能损伤自身（保护措施阻碍市场，导致更大危机）

### 🔗 文字版因果链

1. 市场体系将劳动、土地、货币视为虚构商品，并试图通过市场机制自我调节
2. 这种商品化过程破坏了传统社会关系、自然环境和货币稳定
3. 社会各阶层（劳工、地主、企业主、国家）感受到威胁，产生集体反抗
4. 国家通过立法（如工厂立法、社会立法）和贸易政策（关税）进行干预
5. 干预措施反过来阻碍市场自我调节，导致市场体系与社会保护之间的冲突加剧
6. 冲突最终导致金本位制崩溃、法西斯主义兴起等系统性危机
