# 民主国家（英国、美国）应对战争与经济危机的准备不足，加剧灾难

> 属于因果簇：[[反向运动的自发性质与集体主义立法的因果起源]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 经济自由主义信条的坚持（尤其在1930-1940年代） |
| **DV（因变量）** | 民主国家（英国、美国）应对战争与经济危机的准备不足，加剧灾难 |
| **Chain（传导链）** | 经济自由主义信条强调平衡预算、稳定汇率和金本位制，排斥政府干预 → 该信条使民主政府最晚理解被管理的通货与被指导的贸易的意义 → 正统教条导致英国死守传统战略原则，美国既得利益者（石油、铝工业）以自由商业为借口抵制工业紧急准备 → 结果：国家在总体性战争面前装备不足，无法及时重整军备，可能加速战争并阻碍防备 |
| **Lag（时滞）** | 约10年（1920年代信条巅峰至1930-1940年代失败显现） |
| **Threshold（临界值）** | 当面临总体性战争或经济危机时，若信条坚持不干预，则导致准备不足（无量化阈值） |
| **前提与约束（Premises）** | 仅当国家面临需要大规模动员的紧急状况（如总体性战争）时，该因果链才显著；经济自由主义信条在和平时期可能有效，但在危机中成为障碍；排除：非自由主义国家（如德国）的备战情况不在本断言范围内 |
| **Falsification（证伪条件）** | 若能证明英国或美国在坚持经济自由主义信条的同时仍能有效备战并避免灾难，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及英国死守传统战略、美国石油和铝工业抵制准备） |
| **Conflicts（观点冲突）** | 与经济自由主义辩护者的观点冲突——他们认为困境源于对自由主义原则的不彻底应用，而非信条本身 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像一个人坚信“不借钱”的原则，即使房子着火也不肯贷款买灭火器——原则在平时省钱，但在紧急时刻却导致更大的损失

### 🔗 文字版因果链

1. 经济自由主义信条强调平衡预算、稳定汇率和金本位制，排斥政府干预
2. 该信条使民主政府最晚理解被管理的通货与被指导的贸易的意义
3. 正统教条导致英国死守传统战略原则，美国既得利益者（石油、铝工业）以自由商业为借口抵制工业紧急准备
4. 结果：国家在总体性战争面前装备不足，无法及时重整军备，可能加速战争并阻碍防备
