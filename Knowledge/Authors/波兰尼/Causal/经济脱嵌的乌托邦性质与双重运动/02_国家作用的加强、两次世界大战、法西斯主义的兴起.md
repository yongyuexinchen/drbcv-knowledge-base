# 国家作用的加强、两次世界大战、法西斯主义的兴起

> 属于因果簇：[[经济脱嵌的乌托邦性质与双重运动]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金本位制的全球实施（固定汇率、黄金支撑货币供给、自由国际经济交易） |
| **DV（因变量）** | 国家作用的加强、两次世界大战、法西斯主义的兴起 |
| **Chain（传导链）** | 金本位制意图创造整合的全球市场，减少民族国家作用 → 金本位制将令人无法忍受的经济代价（国内价格与国际价格失衡时的通货紧缩、失业）强加于各国人民 → 各国为应对代价被迫加强国家干预，国家作为统一整体的重要性反而增强 → 当保护性反向运动与自由放任运动都无法解决危机时，社会张力增强 → 法西斯主义获得攫取权力的力量，与自由放任和民主同时决裂，导致战争 |
| **Lag（时滞）** | 中长期（金本位制自1870年代广泛采用至两次世界大战爆发，约40-70年） |
| **Threshold（临界值）** | 当国内价格结构与国际价格水平严重不符，且两种运动（自由放任与保护性反向运动）均无法解决危机时，法西斯主义崛起 |
| **前提与约束（Premises）** | 金本位制是自发调节市场理论的制度创新，其潜在目标对当代市场自由主义者仍有影响力；金本位制下各国必须遵循固定汇率、黄金支撑货币、自由交易三原则；国际金本位制与各国内部政治选择之间存在冲突 |
| **Falsification（证伪条件）** | 如果金本位制实施后国家作用未加强、未导致重大战争或法西斯主义兴起，或各国能和平调整国际收支而不产生社会危机，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引证1870年代金本位制广泛采用至两次世界大战的历史事实） |
| **Conflicts（观点冲突）** | 与市场自由主义认为金本位制能减少国家作用、实现和平全球市场的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同试图用一根细绳捆绑汹涌的洪水：金本位制看似精巧的全球机制，实则将压力传导至各国社会，最终导致堤坝崩溃（战争与法西斯主义）。

### 🔗 文字版因果链

1. 金本位制意图创造整合的全球市场，减少民族国家作用
2. 金本位制将令人无法忍受的经济代价（国内价格与国际价格失衡时的通货紧缩、失业）强加于各国人民
3. 各国为应对代价被迫加强国家干预，国家作为统一整体的重要性反而增强
4. 当保护性反向运动与自由放任运动都无法解决危机时，社会张力增强
5. 法西斯主义获得攫取权力的力量，与自由放任和民主同时决裂，导致战争
