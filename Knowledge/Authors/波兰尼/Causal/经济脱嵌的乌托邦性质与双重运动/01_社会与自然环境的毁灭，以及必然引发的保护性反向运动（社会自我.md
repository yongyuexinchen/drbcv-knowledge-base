# 社会与自然环境的毁灭，以及必然引发的保护性反向运动（社会自我

> 属于因果簇：[[经济脱嵌的乌托邦性质与双重运动]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场自发调节的脱嵌努力（将劳动力、土地、货币虚拟商品化并交由市场机制支配） |
| **DV（因变量）** | 社会与自然环境的毁灭，以及必然引发的保护性反向运动（社会自我保护） |
| **Chain（传导链）** | 市场自由主义试图将经济从社会关系中脱嵌，使社会从属于市场逻辑 → 将劳动力、土地、货币视为真实商品，忽略其虚拟商品本质（劳动力是人类行为、土地是自然、货币是政策产物） → 虚拟商品化导致人类与自然被当作纯粹商品，破坏社会神圣原则与自然可持续性 → 不受限制的市场产生灾难性后果（失业、农民暴露于国际竞争、环境破坏） → 社会各群体（工人、农民、商人、国家）自发抵制，形成保护性反向运动，迫使经济重新嵌入社会 |
| **Lag（时滞）** | 短期至中期（市场脱嵌的破坏性后果在数年至数十年内显现，如1920年代美国投机与不平等加剧） |
| **Threshold（临界值）** | 当市场脱嵌程度超过社会承受极限（如金本位制下国内价格与国际价格严重失衡、失业与不平等危及社会存续时），保护性反向运动必然发生 |
| **前提与约束（Premises）** | 经济在19世纪前始终嵌入于政治、宗教和社会关系之中；完全自发调节的市场经济是乌托邦，不可能长期存在；国家必须持续管理虚拟商品（货币、劳动力、土地），无法真正外在于经济；社会各群体（包括资本家）都会在必要时抵制市场自发调节的不确定性 |
| **Falsification（证伪条件）** | 如果存在一个长期（如数十年）完全自发调节的市场经济体，其运行未导致社会解体或环境毁灭，且未出现任何保护性反向运动，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（但引证了1920年代美国过度投机与不平等、前苏联休克疗法失败等历史案例） |
| **Conflicts（观点冲突）** | 与市场自由主义（如哈耶克的自发秩序理论）冲突；与教条马克思主义的二元选择论（市场资本主义或社会主义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同拉伸一条巨大的橡皮筋：市场脱嵌的努力越强，社会反弹的张力越大；要么橡皮筋绷断（社会解体），要么经济回复到更嵌入的状态。

### 🔗 文字版因果链

1. 市场自由主义试图将经济从社会关系中脱嵌，使社会从属于市场逻辑
2. 将劳动力、土地、货币视为真实商品，忽略其虚拟商品本质（劳动力是人类行为、土地是自然、货币是政策产物）
3. 虚拟商品化导致人类与自然被当作纯粹商品，破坏社会神圣原则与自然可持续性
4. 不受限制的市场产生灾难性后果（失业、农民暴露于国际竞争、环境破坏）
5. 社会各群体（工人、农民、商人、国家）自发抵制，形成保护性反向运动，迫使经济重新嵌入社会
