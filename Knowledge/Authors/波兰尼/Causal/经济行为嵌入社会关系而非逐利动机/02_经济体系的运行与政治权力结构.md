# 经济体系的运行与政治权力结构

> 属于因果簇：[[经济行为嵌入社会关系而非逐利动机]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 互惠与再分配原则 |
| **DV（因变量）** | 经济体系的运行与政治权力结构 |
| **Chain（传导链）** | 互惠原则通过制度对称性（结构二重性）实现 → 再分配原则通过货物向中央集中再分配给共同体成员 → 再分配功能成为中央机构政治权力的主要来源 → 经济体系因此嵌入社会政治结构，而非独立市场 |
| **Lag（时滞）** | 即时至长期（随制度发展） |
| **Threshold（临界值）** | 需要制度对称性和中央集权存在 |
| **前提与约束（Premises）** | 适用于初民社会及古式帝国（如印加、埃及、巴比伦）；社会分层明确，存在领导阶层；排除现代自发调节市场体系 |
| **Falsification（证伪条件）** | 若发现初民社会或古式帝国中经济分配完全通过市场交易而非互惠再分配，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证；引用密克罗尼西亚、波利尼西亚国王分配收益的案例 |
| **Conflicts（观点冲突）** | 与市场自发调节理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同社区合作社，成员轮流贡献农产品，由中心统一分配，分配权成为领导者的权威来源

### 🔗 文字版因果链

1. 互惠原则通过制度对称性（结构二重性）实现
2. 再分配原则通过货物向中央集中再分配给共同体成员
3. 再分配功能成为中央机构政治权力的主要来源
4. 经济体系因此嵌入社会政治结构，而非独立市场
