# 经济行为嵌入社会关系而非逐利动机（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：经济行为嵌入社会关系而非逐利动机.md

## 总体因果图

- 社会关系结构（互惠、竞争、社会认可、工作享受） → 经济行为模式（劳动供给、交换、分配）
- 互惠与再分配原则 → 经济体系的运行与政治权力结构
- 外部接触（贸易、货币、市场引入） → 初民社会内部经济结构的变化
