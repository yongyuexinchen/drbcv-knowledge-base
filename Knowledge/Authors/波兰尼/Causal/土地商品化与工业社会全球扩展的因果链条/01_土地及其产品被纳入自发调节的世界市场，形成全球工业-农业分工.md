# 土地及其产品被纳入自发调节的世界市场，形成全球工业-农业分工

> 属于因果簇：[[土地商品化与工业社会全球扩展的因果链条]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地商品化（废除封建土地制度，使土地成为可交易商品） |
| **DV（因变量）** | 土地及其产品被纳入自发调节的世界市场，形成全球工业-农业分工 |
| **Chain（传导链）** | 第一步：将土地商品化，使封建性土地收益流动化 → 第二步：迫使食物和有机原材料生产服务于全国范围的工业人口需求 → 第三步：将剩余生产体系延伸至海外与殖民地，最终纳入世界市场框架 |
| **Lag（时滞）** | 自14世纪始于西欧，约500年后完成于欧洲革命浪潮 |
| **Threshold（临界值）** | 土地成为可交易货物，抵押成为私人民事权利（如拿破仑法典） |
| **前提与约束（Premises）** | 仅当交通条件具备且法律许可时，土地产品才能流动；需要废除限定继承权、不可转让赠与、公地、赎回权、什一税等封建束缚；前提是存在工业城镇的人口集聚和自由贸易政策 |
| **Falsification（证伪条件）** | 若存在土地商品化但未导致全球工业-农业分工，或土地流动未引发社会保护运动，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与李嘉图'最肥沃土地最先开发'的命题冲突（实际铁路发现更肥沃土地） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将一块冻结的冰块（封建土地）加热融化（商品化），水流（产品）最终汇入全球市场的大河，但沿途会冲垮旧有的河岸（社会结构）

### 🔗 文字版因果链

1. 第一步：将土地商品化，使封建性土地收益流动化
2. 第二步：迫使食物和有机原材料生产服务于全国范围的工业人口需求
3. 第三步：将剩余生产体系延伸至海外与殖民地，最终纳入世界市场框架
