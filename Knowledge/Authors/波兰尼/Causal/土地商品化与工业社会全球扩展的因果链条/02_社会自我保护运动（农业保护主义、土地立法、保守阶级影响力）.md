# 社会自我保护运动（农业保护主义、土地立法、保守阶级影响力）

> 属于因果簇：[[土地商品化与工业社会全球扩展的因果链条]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地流动化（商品化） |
| **DV（因变量）** | 社会自我保护运动（农业保护主义、土地立法、保守阶级影响力） |
| **Chain（传导链）** | 土地流动化导致乡村社会崩溃和城市贫民窟化 → 社会各阶级（地主、农民、工人）遭受市场波动危害 → 引发保护性立法（如谷物法、土地保有权法）和保守阶级（封建贵族、军队、教会）重新获得影响力 |
| **Lag（时滞）** | 19世纪工业城镇兴起后数十年内显现 |
| **Threshold（临界值）** | 当国际自由贸易威胁到农业生产者联合体时，保护主义开始 |
| **前提与约束（Premises）** | 仅当存在政治上组织起来的国家（如欧洲）时，保护才可能；殖民地人民因缺乏独立政府而无法保护自己；需要普通法或成文法发挥保守作用 |
| **Falsification（证伪条件）** | 若土地流动化未引发任何保护性反应，或保守阶级未获得影响力，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由放任主义'市场自发调节'观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同身体受到外伤（土地流动），免疫系统（社会保护）会启动炎症反应（保护主义），但过度反应也可能损伤自身

### 🔗 文字版因果链

1. 土地流动化导致乡村社会崩溃和城市贫民窟化
2. 社会各阶级（地主、农民、工人）遭受市场波动危害
3. 引发保护性立法（如谷物法、土地保有权法）和保守阶级（封建贵族、军队、教会）重新获得影响力
