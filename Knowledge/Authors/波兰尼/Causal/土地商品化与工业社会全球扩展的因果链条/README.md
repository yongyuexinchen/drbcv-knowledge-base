# 土地商品化与工业社会全球扩展的因果链条（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：土地商品化与工业社会全球扩展的因果链条.md

## 总体因果图

- 土地商品化（废除封建土地制度，使土地成为可交易商品） → 土地及其产品被纳入自发调节的世界市场，形成全球工业-农业分工
- 土地流动化（商品化） → 社会自我保护运动（农业保护主义、土地立法、保守阶级影响力）
- 土地流动化与市场体系扩展 → 政治格局变化（自由主义与反动力量斗争、农民阶级专政兴起）
