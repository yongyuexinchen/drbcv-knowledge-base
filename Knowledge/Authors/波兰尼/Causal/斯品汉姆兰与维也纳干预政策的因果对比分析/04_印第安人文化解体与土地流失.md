# 印第安人文化解体与土地流失

> 属于因果簇：[[斯品汉姆兰与维也纳干预政策的因果对比分析]]（第4块/4块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 土地占有形式的改变（如1887年总分配法案） |
| **DV（因变量）** | 印第安人文化解体与土地流失 |
| **Chain（传导链）** | 总分配法案将印第安人土地个人化，破坏部族共有制 → 部族社会组织基础被摧毁，文化认同丧失 → 印第安人失去土地的四分之三（9000万英亩） → 文化解体导致共同体瓦解，社会问题丛生 |
| **Lag（时滞）** | 数十年（1887年至1934年） |
| **Threshold（临界值）** | 当土地个人化政策全面实施且无替代文化保护时 |
| **前提与约束（Premises）** | 仅当土地占有形式是社会组织的直接基础时；仅当政策未伴随文化整合措施时；排除政策被后续法案（如1934年重组法案）纠正的情况 |
| **Falsification（证伪条件）** | 若土地个人化后印第安人文化保持完整且土地未流失，则该断言被推翻 |
| **Data（定量佐证）** | 1887年法案后印第安人失去9000万英亩土地（占四分之三） |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 总分配法案将印第安人土地个人化，破坏部族共有制
2. 部族社会组织基础被摧毁，文化认同丧失
3. 印第安人失去土地的四分之三（9000万英亩）
4. 文化解体导致共同体瓦解，社会问题丛生
