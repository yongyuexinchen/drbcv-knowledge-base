# 土著社会的解体与人口下降

> 属于因果簇：[[斯品汉姆兰与维也纳干预政策的因果对比分析]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 文化接触（殖民者引入货币经济和破坏性制度） |
| **DV（因变量）** | 土著社会的解体与人口下降 |
| **Chain（传导链）** | 殖民者引入货币经济、和平和土地私有化，破坏土著传统制度 → 土著文化无法消化新经济制度，导致价值体系崩溃 → 社会规范消亡，缺乏新行动指南，产生文化间隔 → 土著失去活力，免疫力下降，死亡率上升，人口减少 |
| **Lag（时滞）** | 数年至数十年（取决于接触强度） |
| **Threshold（临界值）** | 当新经济制度与土著文化不可兼容且无替代价值体系时 |
| **前提与约束（Premises）** | 仅当土著社会处于被迫转型过程中时；仅当文化接触具有破坏性且缺乏缓冲时；排除土著社会成功整合新制度的情况 |
| **Falsification（证伪条件）** | 若土著社会在接触后文化保持稳定且人口未下降，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |
