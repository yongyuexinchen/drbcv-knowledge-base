# 斯品汉姆兰与维也纳干预政策的因果对比分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：斯品汉姆兰与维也纳干预政策的因果对比分析.md

## 总体因果图

- 斯品汉姆兰法案的工资补贴制度 → 劳动阶级的贬损与劳动组织危机
- 维也纳市政社会主义政策（租金管制、公共住房、失业救济） → 工人阶级的道德与智识提升及文化成就
- 文化接触（殖民者引入货币经济和破坏性制度） → 土著社会的解体与人口下降
- 土地占有形式的改变（如1887年总分配法案） → 印第安人文化解体与土地流失
