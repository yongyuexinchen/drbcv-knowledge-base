## 主传导链

```text
[全球结构前提]
核心国（美元/军事/制度权） → 双重成本转嫁 → 金融资本寄生性生存
主权国家为竞争单位 → 核心—半边缘—边缘依附结构
       ↓
边缘国/新兴国：资本项目开放 + 外债依赖 + 资源/单一经济
       ↓
美元周期（宽松 2-5 年 → 养肥；加息 6-18 个月 → 剪羊毛）
       ↓
资本流入 → 资产泡沫；资本流出 → 货币危机/股灾/债务危机
       ↓
若无缓冲 → 经济危机政治化（超前城市化 + 无乡土社会）
       ↓

[中国案例]
土地革命/均分 → 双金字塔稳态 → 做空中国高成本低胜率
但 1990s 后金融深化 + 资本项目局部开放 + 汇率高估 + 股市泡沫
       ↓
2013 年后去工业化 + 外资流出 → 2015 年第十次危机（生产过剩 + 输入型）
       ↓
2015 股灾 = 更大危机开始（美联储加息刺破流动性泡沫）
       ↓
若金融化向农村蔓延（土地金融化） → 双金字塔瓦解 → 抗做空能力下降
若粮食自给率下降 → 产业不完整 → 国家主权受损
若继续城市化/削弱二元结构 → 乡土缓冲消失 → 危机烈度放大

[出路]
去依附 + 区域货币/贸易联盟 + 资本管制 + 粮食/产业主权 + 实物物资动员
       ↓
避免中等收入陷阱；复制欧美现代化道路则失败
```

## 不变式

温铁军理论中反复出现、跨时期不变的底层前提——这些前提一旦被改变，其整个因果链就会崩塌：

1. **主权国家为竞争单位**：全球化竞争的基本单位不是企业或个人，而是主权国家；国家间权力与资本实力不对等，形成核心—半边缘—边缘依附结构。（对应卡：全球化竞争的主体是国家导致依附结构）

2. **国际制度权不对称**：核心国垄断货币金融权与制度话语权，可通过双重成本转嫁（经济+政治）维持金融资本寄生性生存；边缘国缺少议价权，融入现有体系即陷入依附陷阱。（对应卡：中等收入陷阱的依附性根源、双重成本转嫁）

3. **实体产业与主权独立性不可让渡**：粮食自给、产业完整、资本管制是国家安全底线；放弃底线则外部危机中受制于人，粮食可被武器化。（对应卡：产业完整性、粮食主权）

4. **乡土社会/二元结构的危机缓冲功能**：土地均分形成的“双金字塔”稳态和乡土社会是危机软着陆的减压阀；城市化和金融化侵蚀这一缓冲，必然放大危机烈度。（对应卡：双金字塔稳态、二元结构与城市化）

5. **金融资本的无祖国性**：金融资本具有流动性、短期性、集中性，对民族国家无忠诚；美元周期（宽松/加息）是边缘国危机的外生节拍器。（对应卡：金融资本新三性、美元周期）

## 演化记录

> 2026-07-31 首建：本期为首次建库。记录 2 条从“去依附（1949）→ 全球化竞争（当代）”的时间演化断言。

1. **建国至改革开放（1949—1978）：去依附与内部隔离期。**
   土地改革 → “去依附” → 城乡二元结构 → 双金字塔稳态 → 工业化原始积累（内部提取农业剩余）→ 国家主权独立与危机软着陆能力并存。此阶段核心逻辑是**去依附**：通过内部制度安排将外部风险隔离在乡土社会缓冲层之外。

2. **融入全球化至当代（1980s—）：再嵌入与依附性加深期。**
   对外开放 → 出口导向 → 外资流入 → 对冲增发 → 货币金融化 → 资本项目局部开放 → 2013年去工业化 → 2015年第十次危机 → 2015年股灾只是更大危机的开始。此阶段核心逻辑是**再嵌入**全球依附结构：金融深化引入外部波动，双金字塔稳态被逐步侵蚀；若金融化蔓延至农村，抗做空能力将瓦解，危机烈度将指数级放大。

## 跨作者交叉点

### 交叉点一：金融不稳定之源——内因 vs 外因

- **温铁军**：新兴市场危机的根源在核心国双重成本转嫁与美元周期（宽松养肥、加息剪羊毛）；边缘国的金融自由化为这种外因提供了入口。
- **明斯基**：金融不稳定内生于资本主义信用体系，“稳定本身孕育不稳定”；融资结构从对冲转向投机再转向庞氏，是危机的主因。

- **张力**：明斯基将金融不稳定视为经济体内生的、与政策周期无关；温铁军则视为核心国刻意转嫁的结果，边缘国是被动承接方。
- **嵌套**：明斯基的“庞氏融资”可描述边缘国外资依赖的脆弱节点；温铁军的“美元周期”可看作是全球尺度上明斯基动态的节拍器。两者互补——明斯基解释“为何脆弱”，温铁军解释“谁制造脆弱、为何此时引爆”。

---

### 交叉点二：长期债务与国运——周期管理 vs 成本转嫁

- **达里奥**：长期债务周期是内生的、可理解的；国家可通过政策协调（债务重组、财政货币宽松）实现“漂亮的去杠杆”，避免崩溃。
- **温铁军**：核心国的债务可通过向半边缘/边缘国转嫁来化解（债务货币化+军事信用+外部转嫁对象）；边缘国没有转嫁空间，只有“去依附+实物物资动员”一条路。

- **张力**：达里奥的政策处方隐含“国家有足够政策自主权”；温铁军否定这一前提——核心国可通过转嫁避免自我调整，边缘国则因不对称地位导致政策空间被锁死。
- **嵌套**：达里奥的“长期债务周期”可纳入温铁军的“核心国成本转嫁”框架——美国是唯一的、拥有全球转嫁能力的债务人，其周期是全球边缘国债务压力的外生变量。

---

### 交叉点三：发展战略——比较优势 vs 依附结构

- **林毅夫**：遵循比较优势是积累资本、升级禀赋结构的最快路径；政府因势利导，后发国可实现数倍增长。产业政策应在市场基础上补短板。
- **温铁军**：在国际制度权不对称下，“比较优势”可能被锁定在低端；简单开放使资本倒流，落入中等收入陷阱。必须用国家力量去依附（土地革命、资本管制、产业完整）才能避免边缘化。

- **张力**：林毅夫强调基于国内禀赋的内生追赶路径；温铁军强调国际权力结构对国内路径的约束。两人都反对极端新自由主义，但分歧在“对外开放的次序与安全边界”。
- **嵌套**：林毅夫的 GIFF 六步法可在“去依附”的总体框架下运行——中国早期（1978—2000s）的产业升级实际上发生在温铁军所说的双金字塔稳态与资本管制保护之内。嵌套关系：**温铁军提供安全前提，林毅夫提供增长路径**。

---

### 交叉点四：美元周期与资本流动——交易视角 vs 制度视角

- **付鹏**：美联储是全球流动性的总闸门，宽松→资本外溢→新兴市场繁荣；加息→美元回流→新兴市场承压。交易员只需跟踪利差、汇率、资本流动信号。
- **温铁军**：美元周期不是中性货币政策，而是“养肥羊—剪羊毛”的收割机制；新兴市场的资产泡沫与崩溃是核心国有意维持不对称地位的副产品。

- **张力**：付鹏将美元周期视为可预测的宏观交易背景，隐含投资者可利用周期获利；温铁军将其视为结构性剥削机制，投资者获利恰是边缘国危机之源。两者对同一现象的价值判断完全不同。
- **嵌套**：付鹏的利差/汇率框架可视为温铁军“美元周期收割”的测量工具；机构投资者按付鹏框架交易，客观上成为温铁军所说“剪羊毛”的传导力量。

---

### 交叉点五：资产负债表衰退——私人部门调整 vs 外部冲击

- **辜朝明**：危机后私人部门转向负债最小化，即使利率为零也不借贷；财政扩张才是唯一出路。
- **温铁军**：新兴市场的资产负债表崩溃往往由外资突然流出触发（土耳其症候：双赤字+外资依赖+金融自由化）；若没有乡土社会缓冲，资产负债表衰退会政治化。

- **张力**：辜朝明聚焦于危机后的行为转变（借款人消失）；温铁军聚焦于危机前的触发结构（资本项目开放+外债依赖）。
- **嵌套**：辜朝明描述的是“被剪羊毛之后”的微观行为，温铁军解释的是“为何被剪羊毛”的宏观结构。两者结合可解释：为什么财政扩张在核心国有效、在边缘国却常演变为债务危机——因为边缘国没有独立货币权和转嫁能力。
