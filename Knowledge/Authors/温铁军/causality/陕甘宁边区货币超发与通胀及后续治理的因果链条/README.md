# 陕甘宁边区货币超发与通胀及后续治理的因果链条（因果簇）

> 因果簇索引：9 个子因果卡。父卡文件：陕甘宁边区货币超发与通胀及后续治理的因果链条.md

## 总体因果图

- 财政赤字严重，财政入不敷出 → 银行增发货币（边币）以弥补财政空缺
- 货币发行量过快增长 → 物价上涨和边币贬值
- 银行采取紧缩发行政策 → 货币增发速度放缓，通胀压力暂时缓解
- 对农业、工业、商业放款采取折实措施（实物贷款、订货办法） → 贷款保本保值、促进生产、农贷可持续周转
- 边区进出口贸易入超（进口大于出口） → 金融波动、物价猛涨、边币币值下跌
- 通过“屯盐斗争”提高盐价、增加出口盈余 → 边区实现贸易出超，稳定边币币值
- 以高于国民党区域的价格抢收棉花、发展本地棉花生产 → 减少棉花、布匹进口，节约外汇，改善贸易收支
- 发行“商业流通券”（盐票）作为本位币，逐步收回边币 → 边币与法币比价从12 1、10 1降至8.5 1并稳定，实现
- 边区实现生产发展（“耕三余一”）、储备充足 → 支持解放战争，使胡宗南进攻延安时人民仍有粮可依
