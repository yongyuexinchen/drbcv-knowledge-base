# 全球化竞争的主体是国家导致依附结构

> **领域**：国际政治经济学　|　**来源**：_cand_wtj_01.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 主权国家作为全球化竞争的基本单位 |
| **DV（因变量）** | 形成核心—半边缘—边缘依附结构，核心国通过不平等交换和制度剥削获取利益 |
| **Chain（传导链）** | 主权国家参与全球化竞争，而非个体，个体通过国家间接参与 → 各国在国家权力、资本实力和制度能力上存在差异 → 核心国利用金融霸权（经常账户逆差+资本账户顺差）和制度优势进行不平等交换 → 核心国将成本和风险转嫁给边缘国家，半边缘国家搭便车，边缘国家承担净损失 → 长期累积形成稳定的核心—半边缘—边缘依附结构，利益不断向核心国输送 |
| **Lag（时滞）** | 长期累积，需数十年甚至更长时间显现 |
| **Threshold（临界值）** | 核心国经常账户逆差与资本账户顺差同时存在，且核心国政府与私人负债总量超过全球GDP两倍时，依附结构强化 |
| **前提与约束（Premises）** | 主权国家体系是全球化竞争的基本框架；全球经济一体化且资本主义生产方式占主导；国家间权力和资本实力不对等；存在可利用的国际制度与不平等交换机制 |
| **Falsification（证伪条件）** | 如果全球化竞争主体是个体企业而非主权国家，或核心国长期出现经常账户顺差且未获利，或边缘国收入持续追平核心国，则此断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像一场由国家充当玩家的牌局，庄家（核心国）制定规则并控制筹码分配，散户（边缘国）总是输家，半边缘玩家偶尔搭便车但最终也难逃被抽水

### 🔗 文字版因果链

1. 主权国家参与全球化竞争，而非个体，个体通过国家间接参与
2. 各国在国家权力、资本实力和制度能力上存在差异
3. 核心国利用金融霸权（经常账户逆差+资本账户顺差）和制度优势进行不平等交换
4. 核心国将成本和风险转嫁给边缘国家，半边缘国家搭便车，边缘国家承担净损失
5. 长期累积形成稳定的核心—半边缘—边缘依附结构，利益不断向核心国输送
