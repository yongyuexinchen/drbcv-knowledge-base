# 美元周期作为“养肥羊—剪羊毛”的收割机制

> **领域**：国际宏观经济学　|　**来源**：_cand_wtj_03.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国利用美元全球结算与储备货币地位进行的货币政策周期（宽松与加息交替） |
| **DV（因变量）** | 新兴市场国家反复遭遇货币贬值、资本外流与经济危机（被“剪羊毛”） |
| **Chain（传导链）** | 美国实行货币宽松政策，美元资本大规模流入新兴市场 → 新兴市场获得廉价资本，推动资产价格上涨与经济过热，形成泡沫 → 美国经济过热或通胀压力上升，美联储转向加息 → 美元走强，全球资本回流美国，新兴市场流动性骤紧 → 新兴市场货币大幅贬值、债务负担加重，最终爆发金融危机 |
| **Lag（时滞）** | 美元周期约为“十年走弱、六年走强”，从宽松到危机一般在周期转向后数月到数年内显现 |
| **Threshold（临界值）** | 美元周期发生转向（如2013年6月QE退出信号）时，触发全球汇率震荡；新兴市场货币贬值幅度达两位数甚至更高（如巴西雷亚尔-73%、土耳其里拉-55%）时危机成立 |
| **前提与约束（Premises）** | 美元必须保持全球结算与储备货币地位；新兴市场国家资本账户开放且对外资/美元债务高度依赖；新兴市场缺乏足够的汇率弹性和外汇储备缓冲 |
| **Falsification（证伪条件）** | 如果美元周期转向后，新兴市场资本外流和货币危机没有普遍发生，或新兴市场能够在不发生危机的情况下平抑汇率波动，则该因果断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 山羊被农夫精心喂养，养肥后剃取羊毛，剃完再养，养肥再剃——美国通过美元周期反复“养肥”新兴市场资产，再在紧缩时“收割”其财富

### 🔗 文字版因果链

1. 美国实行货币宽松政策，美元资本大规模流入新兴市场
2. 新兴市场获得廉价资本，推动资产价格上涨与经济过热，形成泡沫
3. 美国经济过热或通胀压力上升，美联储转向加息
4. 美元走强，全球资本回流美国，新兴市场流动性骤紧
5. 新兴市场货币大幅贬值、债务负担加重，最终爆发金融危机
