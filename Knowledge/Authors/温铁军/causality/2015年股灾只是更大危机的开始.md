# 2015年股灾只是更大危机的开始

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 核心国货币政策转向（美联储加息/缩表）导致全球资本从边缘国流出，刺破由外部流动性吹起的资产泡沫 |
| **DV（因变量）** | 中国2015年股灾只是开始，后续将出现更严重的金融危机或持续经济下行 |
| **Chain（传导链）** | 核心国通过量化宽松向全球注入流动性，资本涌入中国等边缘国，推高资产价格和债务杠杆 → 中国经济出现‘去工业化+资金脱实向虚+企业借新还旧甚至借新还息’的庞氏特征，资产泡沫膨胀 → 核心国政策转向（如2013年QE退出信号、2015年加息），资本流向逆转，中国外汇储备下降 → 资产泡沫越过明斯基时刻，流动性骤然收紧，2015年股灾爆发 → 由于人民币不是全球结算和储备货币，中国无法像核心国那样通过转嫁化解危机，内部金融脆弱性继续积累 → 因此2015年股灾只是系统性危机暴露的开端，后续仍有更深层的调整和危机 |
| **Lag（时滞）** | 从核心国货币政策转向到股灾爆发约1-2年（如2013年退出信号至2015年股灾）；后续危机可能持续数年 |
| **Threshold（临界值）** | 当资产泡沫越过明斯基时刻（庞氏融资主导）且外汇储备下降超过临界水平，金融内爆即发生；该断言在后续危机未出现前需以‘持续下行趋势’为检验 |
| **前提与约束（Premises）** | 中国属于边缘国，人民币不是全球结算和储备货币，无法持续吸引全球资本和利润回流；资本账户开放到一定程度，存在大规模跨境资本流动；国内经济存在高杠杆、脱实向虚和庞氏融资特征；核心国（美国）处于金融资本阶段并进入货币紧缩周期 |
| **Falsification（证伪条件）** | 如果2015年股灾后，中国通过制度性缓冲（如资本管制、国家逆周期投资、乡村振兴）实现软着陆，未发生后续重大危机，且资产价格企稳、经济结构成功转型，则该‘只是开始’的断言被削弱或推翻 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 核心国通过量化宽松向全球注入流动性，资本涌入中国等边缘国，推高资产价格和债务杠杆
2. 中国经济出现‘去工业化+资金脱实向虚+企业借新还旧甚至借新还息’的庞氏特征，资产泡沫膨胀
3. 核心国政策转向（如2013年QE退出信号、2015年加息），资本流向逆转，中国外汇储备下降
4. 资产泡沫越过明斯基时刻，流动性骤然收紧，2015年股灾爆发
5. 由于人民币不是全球结算和储备货币，中国无法像核心国那样通过转嫁化解危机，内部金融脆弱性继续积累
6. 因此2015年股灾只是系统性危机暴露的开端，后续仍有更深层的调整和危机
