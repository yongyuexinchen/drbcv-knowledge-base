# 公司治理结构与金融风险相关性质疑（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：公司治理结构与金融风险相关性质疑.md

## 总体因果图

- 改善公司治理结构（公司治理原则完善） → 有效防范金融风险
- 给经理人股票期权（以期权激励防止内部人控制） → 经理人追求短期股市收益、做信息欺诈，损害公司长期利益
- 金融资本这种宏观制度自身的特性 → 金融风险产生及其能否防范
- 中国国有企业公司治理原则尚未建立（微观制度问题严重） → 亚洲金融危机对中国影响不显著（金融风险防范表现相对较好）
- 外国公司在中国的企业远离其股东（母公司董事会难以控制分公司） → 内部人控制问题、内部人行为不规范、在职消费严重
- 从意识形态出发而非从经济学理念分析金融危机原因 → 把“企业微观机制不好”误作为金融危机的根源，形成过于草率的结
