# 80年代内需拉动型高增长和农村减贫

> 属于因果簇：[[去依附与三农化解危机的因果断言]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 邓小平领导的“第二次土改”（给农民重新分地，实行家庭承包制） |
| **DV（因变量）** | 80年代内需拉动型高增长和农村减贫 |
| **Chain（传导链）** | 分地到户，家庭承包制释放农民生产积极性 → 解放农民这个第一生产力要素 → 过剩劳动力进入乡村工业化和城镇化 → 农村百业复兴，农产品和轻工业品出口创汇 → 农民收入连续4年快于城市，城乡收入差别缩小至2.4:1 → 农村大面积减贫，县以下城镇化发展 → 形成唯一一次内需拉动型黄金增长 |
| **Lag（时滞）** | 80年代初期至中期（约1980-1985） |
| **Threshold（临界值）** | 农民人口占85%；政府财政对三农支出占比降至低于3%；乡镇企业数量达2000多万家 |
| **前提与约束（Premises）** | 中国仍是城乡二元体制结构，农民占人口多数；农村已有集体化时期社队企业的工业经验；政府放权让利并实行“双轨制”放开原材料市场 |
| **Falsification（证伪条件）** | 如果能证明分地后未出现内需拉动型增长，或增长主要是其他因素导致（如城市改革），则该断言被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 把土地和自由还给农民，就像松开绳索，千军万马立刻奔向市场，粮食和工厂都活了。

### 🔗 文字版因果链

1. 分地到户，家庭承包制释放农民生产积极性
2. 解放农民这个第一生产力要素
3. 过剩劳动力进入乡村工业化和城镇化
4. 农村百业复兴，农产品和轻工业品出口创汇
5. 农民收入连续4年快于城市，城乡收入差别缩小至2.4:1
6. 农村大面积减贫，县以下城镇化发展
7. 形成唯一一次内需拉动型黄金增长
