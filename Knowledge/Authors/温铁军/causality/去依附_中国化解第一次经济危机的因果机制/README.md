# 去依附：中国化解第一次经济危机的因果机制（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：去依附_中国化解第一次经济危机的因果机制.md

## 总体因果图

- 土地改革 → 国家资本与分散个人之间的交易成本降低
- 恢复性重建（修复战争部分损毁的基础设施） → 国家账面经济收益快速增长
- 重化产业以中间产品为主的生产结构 → 市场交易成本较低
- 长期高通胀环境 → 私人资本从实体经济转向投机（脱实向虚）
- 以农村实体经济为基础的物资本位货币制度 → 成功遏制恶性通胀并建立主权货币信用
