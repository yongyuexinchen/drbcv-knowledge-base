## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家放弃或弱化农业与粮食自给，导致产业结构不完整（尤其是粮食高度依赖进口） |
| **DV（因变量）** | 国家安全底线被突破，主权受损，在外部危机中受制于人并可能陷入粮食武器化困境 |
| **Chain（传导链）** | 1980年代GDP统计改为按市场交换计算增加值，传统农业等非市场化活动被低估，维持农业的国家在GDP竞赛中落败并被误判为“贫困国家”。 → 这种误判使相关国家承受放弃农业、按比较优势发展工业/金融的外部压力，农业与基础产业萎缩。 → 核心大国（美欧日）自身用巨额财政补贴保护农业，同时操纵大宗农产品期货价格，向开放国倾销低价粮食，摧毁其国内农业产能。 → 进口依赖国逐渐丧失粮食自给能力，粮食安全变成结构性软肋。 → 一旦发生禁运、价格冲击或物资短缺，粮食即武器；依赖国无法自保，出现社会动荡、政府被逼采取军队接管工厂等极端措施。 → 农业与工业基础被破坏后，产业完整性被击穿，国家安全与主权底线随之失守。 |
| **Lag（时滞）** | 从放弃农业到粮食安全危机显现通常为10至30年；但若遭遇突发禁运或全球粮价剧烈波动，短则1至3年内即可触发。 |
| **Threshold（临界值）** | 关键主粮自给率低于90%，或粮食进口依存度高于30%时，粮食武器便开始有效；若耕地集中度达到委内瑞拉式“70%耕地集中于3%农地拥有者”且缺乏战略储备，则粮食主权已实质沦丧。 |
| **前提与约束（Premises）** | 国际体系处于大国竞争状态，存在能够将粮食武器化的核心国家；；该国参与国际分工并开放农产品贸易，未实行完全自给自足的封闭经济；；该国不具备绝对军事霸权或资源垄断收益来抵消粮食依赖；；该断言适用于主权国家的长期生存竞争，不涵盖短期人道主义救援情景。 |
| **Falsification（证伪条件）** | 若能找到一个长期高度依赖粮食进口、产业体系残缺但仍保持国家安全与主权独立、未受制于人的国家；或证明核心国的粮食期货操纵和农业补贴并未削弱任何发展中国家的农业基础，则该断言可被推翻。 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 国家就像一栋楼：农业是地基，工业是承重墙，货币权是外墙；GDP不过是装修。若只追求装修光鲜而挖掉地基（放弃粮食自给），一遇外部风暴或断供，整栋楼必然坍塌。

### 🔗 文字版因果链

1. 1980年代GDP统计改为按市场交换计算增加值，传统农业等非市场化活动被低估，维持农业的国家在GDP竞赛中落败并被误判为“贫困国家”。
2. 这种误判使相关国家承受放弃农业、按比较优势发展工业/金融的外部压力，农业与基础产业萎缩。
3. 核心大国（美欧日）自身用巨额财政补贴保护农业，同时操纵大宗农产品期货价格，向开放国倾销低价粮食，摧毁其国内农业产能。
4. 进口依赖国逐渐丧失粮食自给能力，粮食安全变成结构性软肋。
5. 一旦发生禁运、价格冲击或物资短缺，粮食即武器；依赖国无法自保，出现社会动荡、政府被逼采取军队接管工厂等极端措施。
6. 农业与工业基础被破坏后，产业完整性被击穿，国家安全与主权底线随之失守。
