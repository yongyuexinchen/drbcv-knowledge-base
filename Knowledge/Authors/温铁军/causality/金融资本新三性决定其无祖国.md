## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本的'新三性'（流动性、短期性、集中性） |
| **DV（因变量）** | 金融资本'无祖国'（对民族国家无忠诚，实现世界主义） |
| **Chain（传导链）** | 金融资本以流动性获利为第一特性，资金可快速跨境进出 → 短期性使资本追求短期高回报，不扎根于特定地区或产业 → 集中性使少数金融资本集团掌握巨量资金，有能力规避国家监管 → 资本注册在开曼群岛等避税天堂，脱离特定国家法律约束 → 金融资本通过弱化目标国主权实现控制，无需占领国土 → 因此金融资本对任何民族国家无忠诚，成为'无祖国'的世界主义资本 |
| **Lag（时滞）** | 在金融资本全球化时期（约20世纪80年代后）逐步显现，并非即时效应 |
| **Threshold（临界值）** | 当金融资本超越产业资本成为主导资本形态，且流动性、短期性、集中性达到一定程度时 |
| **前提与约束（Premises）** | 全球金融市场开放，资本跨境流动不受限制；存在开曼群岛等避税天堂和离岸金融中心；目标国主权弱化，缺乏对金融资本的管控能力；金融资本集团成为国际资本的主导力量 |
| **Falsification（证伪条件）** | 如果发现金融资本长期扎根特定国家、承担忠诚义务，或在危机时选择留下而非撤离；或者金融资本表现出明确的国家属性并服务于国家战略，则可推翻该断言 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同候鸟逐水草而居，哪里有丰美的食物就飞向哪里，从不固守一片土地；金融资本在全球寻找套利机会，对任何国家都无忠诚可言

### 🔗 文字版因果链

1. 金融资本以流动性获利为第一特性，资金可快速跨境进出
2. 短期性使资本追求短期高回报，不扎根于特定地区或产业
3. 集中性使少数金融资本集团掌握巨量资金，有能力规避国家监管
4. 资本注册在开曼群岛等避税天堂，脱离特定国家法律约束
5. 金融资本通过弱化目标国主权实现控制，无需占领国土
6. 因此金融资本对任何民族国家无忠诚，成为'无祖国'的世界主义资本
