## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 核心国金融流动性进出期货市场 |
| **DV（因变量）** | 资源出口国资产（股市/货币）价格暴涨暴跌 |
| **Chain（传导链）** | 核心国货币政策调整引起金融流动性变化 → 流动性进出大宗商品期货市场，决定大宗商品价格（而非供求决定） → 资源出口国出口收入随大宗商品价格波动 → 资源国股市和货币资产随之暴涨暴跌 |
| **Lag（时滞）** | 流动性变化传导至大宗商品价格，再传导至资源国资产，通常为数月至数年 |
| **Threshold（临界值）** | 资源出口占出口总额比重超过50%（如委内瑞拉96%、印尼煤炭+棕榈油）且核心国有显著流动性变动（如美联储加息/降息周期） |
| **前提与约束（Premises）** | 该国是净资源出口国；资源出口占出口总额比重大；该国无资源定价权，即对期货市场无话语权 |
| **Falsification（证伪条件）** | 若发现资源国资产价格与美元流动性呈正相关，或与大宗商品价格负相关，或大宗商品价格主要由供求决定而非流动性，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像小农户卖粮，价格由大收购商说了算，收购商钱多时抬价、撤资时压价，农户收入随收购商脸色起伏，资源国就是这种没有定价权的‘大农户’

### 🔗 文字版因果链

1. 核心国货币政策调整引起金融流动性变化
2. 流动性进出大宗商品期货市场，决定大宗商品价格（而非供求决定）
3. 资源出口国出口收入随大宗商品价格波动
4. 资源国股市和货币资产随之暴涨暴跌
