# 去依附文本中的宏观因果断言（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：去依附文本中的宏观因果断言.md

## 总体因果图

- 在传统农业国家实行“耕者有其田”式的土地改革（均田免赋/城乡二元结构基本体制） → 国家长期政治稳定
- 发展中国家通过非暴力谈判获得政治主权 → 陷入“发展陷阱”且难以自拔（经济上和政治上继续依附原宗主国）
- 高通胀压力 → 经济萧条（高通胀之后必然继之以工商业衰退）
