# 国家长期政治稳定

> 属于因果簇：[[去依附文本中的宏观因果断言]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 在传统农业国家实行“耕者有其田”式的土地改革（均田免赋/城乡二元结构基本体制） |
| **DV（因变量）** | 国家长期政治稳定 |
| **Chain（传导链）** | 土地改革实现土地这一农民最重要财产的平均化再分配，形成“耕者有其田” → 农民获得基本生存保障，形成对政权的内部国民动员 → 乡土社会成为“海绵社会”，吸纳城市资本转嫁的危机与负外部性 → 东亚儒家文化圈国家和地区（中日韩朝越及中国台湾地区）均因类似体制维持长期稳定 |
| **Lag（时滞）** | 文本未明确量化，但中国历史上大凡搞了“均田免赋”的朝代都能保持较为长期的稳定；1949年土改后短期内即见效 |
| **Threshold（临界值）** | 必须实现“耕者有其田”的平均化再分配；对亚洲“儒家文化圈”国家具有普遍意义，无特定数值阈值 |
| **前提与约束（Premises）** | 适用于传统农业国家或亚洲“儒家文化圈”国家；需要以城乡二元结构基本体制为前提；排除已完成工业化、农业人口占比极小的国家 |
| **Falsification（证伪条件）** | 若某实行了类似土地改革的国家未能维持长期稳定，或者未实行土改的国家也能长期稳定，则该断言被削弱或推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像给每个家庭成员都分了宅基地和自留地，大家都有了安身立命的根基，自然不愿破坏秩序，整个社会就像打了地基的房子一样稳固。

### 🔗 文字版因果链

1. 土地改革实现土地这一农民最重要财产的平均化再分配，形成“耕者有其田”
2. 农民获得基本生存保障，形成对政权的内部国民动员
3. 乡土社会成为“海绵社会”，吸纳城市资本转嫁的危机与负外部性
4. 东亚儒家文化圈国家和地区（中日韩朝越及中国台湾地区）均因类似体制维持长期稳定
