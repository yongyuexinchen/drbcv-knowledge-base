## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资源国收回资源主权 |
| **DV（因变量）** | 单一经济国政权危机 |
| **Chain（传导链）** | 资源国收回资源主权 → 触动跨国资本利益 → 核心国（美国）能源独立后放手打压（制裁+油价战） → 单一经济国财政崩溃 → 政权危机 |
| **Lag（时滞）** | 数月至数年（取决于制裁强度与油价跌幅） |
| **Threshold（临界值）** | 石油占出口90%以上且美国已实现能源独立时，机制启动；油价跌幅与制裁力度需达到使该国财政收支严重失衡、外部融资枯竭的程度 |
| **前提与约束（Premises）** | 该国经济结构单一，石油占出口90%以上；该国无完整工业体系与粮食主权；美国已实现能源独立（页岩气革命） |
| **Falsification（证伪条件）** | 若资源国在收回资源主权后，虽遭制裁与油价战，但财政未崩溃或政权保持稳定，则该因果断言不成立；或若美国未实现能源独立仍能同等打压，也需修正 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同走独木桥：单一经济是独木桥，资源主权是桥头；一旦触动外部利益，有人砍断桥索（制裁+油价战），独木桥上的国家便失足坠落

### 🔗 文字版因果链

1. 资源国收回资源主权
2. 触动跨国资本利益
3. 核心国（美国）能源独立后放手打压（制裁+油价战）
4. 单一经济国财政崩溃
5. 政权危机
