# 陕甘宁边区货币超发与通胀及后续治理的因果链条

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 财政赤字严重，财政入不敷出 |
| **DV（因变量）** | 银行增发货币（边币）以弥补财政空缺 |
| **Chain（传导链）** | 边区财政每月入不敷出，需要17万元而尚差4万多元 → 政府无法依靠常规收入弥补缺口 → 银行放款成为政府解决财政空缺的重要方式 → 财政机关款占银行放款比例大幅上升，1940年达69.2% → 边区中央局直接要求银行增发钞票交财政厅使用 |
| **Lag（时滞）** | 短期，财政缺口出现后即需增发 |
| **Threshold（临界值）** | 财政机关款占银行放款比例从1938年的21.6%升至1940年的69.2%；直接财政放款占93.1% |
| **前提与约束（Premises）** | 战争环境下税收等正常财政收入不足；政府具有货币发行权且银行受政府控制；缺乏其他融资渠道 |
| **Falsification（证伪条件）** | 如果财政赤字扩大但银行货币发行量没有相应增加，则该因果断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个家庭入不敷出时，只能靠刷信用卡度日，欠款越滚越大。

### 🔗 文字版因果链

1. 边区财政每月入不敷出，需要17万元而尚差4万多元
2. 政府无法依靠常规收入弥补缺口
3. 银行放款成为政府解决财政空缺的重要方式
4. 财政机关款占银行放款比例大幅上升，1940年达69.2%
5. 边区中央局直接要求银行增发钞票交财政厅使用

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 货币发行量过快增长 |
| **DV（因变量）** | 物价上涨和边币贬值 |
| **Chain（传导链）** | 银行增大边币发行量，1941年3月至6月月平均递增率31.9% → 市场上货币供给量超过实际物资基础 → 延安物价递增率由3月的12.9%增至6月的26.7% → 边币与法币比价递增率由6.6%增至14.6% → 边币对内购买力下降，对外汇率贬值 |
| **Lag（时滞）** | 约1-3个月，货币增发后物价和汇率在数月内明显变化 |
| **Threshold（临界值）** | 边币月平均递增率超过18%时，物价递增大幅上涨；7-8月紧缩至月递增率7%-8.5%后通胀压力有所缓解 |
| **前提与约束（Premises）** | 货币增发缺乏相应的物资增长支撑；边区经济封闭，物资供给有限；法币作为参照货币存在比价关系 |
| **Falsification（证伪条件）** | 如果货币发行量大幅增长但物价稳定或下跌，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 往一杯水里不断加糖，水越来越甜，糖就是货币，甜度就是物价。

### 🔗 文字版因果链

1. 银行增大边币发行量，1941年3月至6月月平均递增率31.9%
2. 市场上货币供给量超过实际物资基础
3. 延安物价递增率由3月的12.9%增至6月的26.7%
4. 边币与法币比价递增率由6.6%增至14.6%
5. 边币对内购买力下降，对外汇率贬值

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 银行采取紧缩发行政策 |
| **DV（因变量）** | 货币增发速度放缓，通胀压力暂时缓解 |
| **Chain（传导链）** | 面对物价和比价快速上涨，银行在7、8月采取紧缩政策 → 边币月递增率降至7%和8.5% → 货币供给增速减慢，通胀压力得到一定控制 |
| **Lag（时滞）** | 当月或次月见效 |
| **Threshold（临界值）** | 月递增率从31.9%降至7%-8.5% |
| **前提与约束（Premises）** | 政府能够控制货币发行渠道；紧缩期间没有其他财政压力迫使增发；物资供应没有同时恶化 |
| **Falsification（证伪条件）** | 如果紧缩政策实施后物价继续以同样速度上涨，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水龙头关小了，水池里的水涨得就慢了。

### 🔗 文字版因果链

1. 面对物价和比价快速上涨，银行在7、8月采取紧缩政策
2. 边币月递增率降至7%和8.5%
3. 货币供给增速减慢，通胀压力得到一定控制

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对农业、工业、商业放款采取折实措施（实物贷款、订货办法） |
| **DV（因变量）** | 贷款保本保值、促进生产、农贷可持续周转 |
| **Chain（传导链）** | 银行发放农贷时按市价折成实物（粮食或棉花）放出 → 农民收获后交还等价实物 → 银行避免因货币贬值而损失本金 → 农民获得生产工具和口粮，促进生产 → 农贷得以持续周转，对公私双方都合理 |
| **Lag（时滞）** | 一个生产周期，约数月至一年（春贷秋还） |
| **Threshold（临界值）** | 1942年400万元农贷中除部分地区外基本采用实物贷款；不同地区采用不同折实方式（如以农具贷出、以农产品收回） |
| **前提与约束（Premises）** | 边区处于通货膨胀、货币贬值环境；实物具有相对稳定的价值；农业生产周期可预期；当地有相应的实物供需 |
| **Falsification（证伪条件）** | 如果折实贷款导致银行收回的实物价值低于放出实物价值，或农民不愿意归还，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 借给别人大米，收回时也要大米，而不是收回可能贬值的纸币。

### 🔗 文字版因果链

1. 银行发放农贷时按市价折成实物（粮食或棉花）放出
2. 农民收获后交还等价实物
3. 银行避免因货币贬值而损失本金
4. 农民获得生产工具和口粮，促进生产
5. 农贷得以持续周转，对公私双方都合理

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 边区进出口贸易入超（进口大于出口） |
| **DV（因变量）** | 金融波动、物价猛涨、边币币值下跌 |
| **Chain（传导链）** | 1943年边区进口647264万元，出口536472万元，入超达110792万元 → 大量边币用于购买进口物资，而出口创汇不足 → 边区外汇（法币）储备减少，进口物资价格上涨 → 边币对外价值下降，对内购买力下降 → 物价猛涨，金融波动加剧 |
| **Lag（时滞）** | 数月至一年，1943年困难到1944年表现明显 |
| **Threshold（临界值）** | 入超达11亿元以上；盐与棉花、布的交换比价大幅恶化（100斤食盐从1940年换30.5斤棉花降至1944年换7.5斤） |
| **前提与约束（Premises）** | 边区经济对外依赖度高，必需品（棉花、布）依赖进口；出口产品（盐）价格受外部封锁和战争影响；缺乏足够的外汇储备 |
| **Falsification（证伪条件）** | 如果贸易入超扩大但金融稳定、物价未上涨，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

### 🔗 文字版因果链

1. 1943年边区进口647264万元，出口536472万元，入超达110792万元
2. 大量边币用于购买进口物资，而出口创汇不足
3. 边区外汇（法币）储备减少，进口物资价格上涨
4. 边币对外价值下降，对内购买力下降
5. 物价猛涨，金融波动加剧

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 通过“屯盐斗争”提高盐价、增加出口盈余 |

| **Chain（传导链）** | 边区追加资本开展屯盐，共屯盐1000多万斤 → 利用敌人封锁导致的外部供应中断，囤积居奇 → 迫使周边地区不得不来边区买盐 → 盐价从每百斤12000元赔本价提到16000元有利价，后续进一步上涨 → 出口收入增加，贸易由入超转为出超（1944年出超19亿元边币） → 外贸盈余增加，边区银行法币储备增加，边币币值稳定 |
| **Lag（时滞）** | 数月至一年（1944年4月开始屯盐，当年实现出超） |
| **Threshold（临界值）** | 盐价须越过保本价13000元，达到16000元以上；屯盐1000多万斤，投入资本7亿元 |
| **前提与约束（Premises）** | 边区对盐出口具有垄断或控制能力；外部对边区盐存在刚性需求；战争导致海盐来源受阻，增强了边区盐的谈判地位；有足够的资金支持屯盐 |
| **Falsification（证伪条件）** | 如果屯盐后盐价下跌或出口量锐减，未实现出超，则该断言不成立 |
| **Confidence（确信度）** | well-established |

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发行“商业流通券”（盐票）作为本位币，逐步收回边币 |
| **DV（因变量）** | 边币与法币比价从12:1、10:1降至8.5:1并稳定，实现币值稳定 |
| **Chain（传导链）** | 设计“偷梁换柱”方案：盐业公司发流通券，定价与法币1:1，与边币固定为1:9 → 流通券逐步流通并收回边币，边币流通量减少 → 边币因稀缺性增加而对外升值 → 边币与法币比价从原先12:1、10:1降到8.5:1 → 流通券支持贸易收购和银行资金周转，保持吞吐有度 → 币值稳定后，停止盐票发行，以边币收回盐票 |
| **Lag（时滞）** | 1944年5月决定发行，6月后比价降至8.5:1并稳定，约1-3个月 |
| **Threshold（临界值）** | 流通券每元折换边币20元，票面50元；边币与法币比价从12:1、10:1降至8.5:1 |
| **前提与约束（Premises）** | 边区政府有能力控制货币流通和兑换；流通券具有物资（盐业）信用背书；外贸盈余提供了外汇储备基础；市面对流通券接受度足够 |
| **Falsification（证伪条件）** | 如果流通券发行后边币比价未上升或出现恶性通胀，则该断言不成立 |
| **Confidence（确信度）** | well-established |
