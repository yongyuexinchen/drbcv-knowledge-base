# 城市化率与危机烈度

> **领域**：政治经济学　|　**来源**：_cand_wtj_21.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 殖民化单一经济+超前城市化（80%以上） |
| **DV（因变量）** | 经济危机直接演变为政治危机 |
| **Chain（传导链）** | 殖民化单一经济结构下，超前城市化使城市人口占比超过80% → 单一经济模式导致劳动力成本高企（较基准水平高出50%） → 高劳动力成本使工业部门失去国际竞争力 → 经济危机来临时缺乏有竞争力的工业部门作为缓冲载体 → 经济冲击无法被产业体系吸收，直接转化为政治不稳定与政治危机 |
| **Lag（时滞）** | 中长期：城市化与单一经济结构形成后，需经历一次外部冲击（如美元收紧周期）才触发危机传导 |
| **Threshold（临界值）** | 城市化率超过80%；劳动力成本相对基准上升50%以上 |
| **前提与约束（Premises）** | 前殖民地单一经济结构未发生根本改变；不存在土地改革形成的稳态社会基础（缺乏乡土社会缓冲）；食品与一般消费品依赖进口 |
| **Falsification（证伪条件）** | 若某个城市化率超过80%且经济结构单一的前殖民地国家，在外部危机冲击下未出现政治危机，或经济危机被工业部门有效缓冲，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一座没有消防通道的高层建筑：人口密集（高城市化）但只有一部电梯（单一经济），一旦停电（外部危机），所有人拥堵在楼内无法疏散，必然引发踩踏（政治危机）；而有后门和庭院（二元结构缓冲）的建筑则能缓慢分流，不至于全楼崩溃。

### 🔗 文字版因果链

1. 殖民化单一经济结构下，超前城市化使城市人口占比超过80%
2. 单一经济模式导致劳动力成本高企（较基准水平高出50%）
3. 高劳动力成本使工业部门失去国际竞争力
4. 经济危机来临时缺乏有竞争力的工业部门作为缓冲载体
5. 经济冲击无法被产业体系吸收，直接转化为政治不稳定与政治危机
