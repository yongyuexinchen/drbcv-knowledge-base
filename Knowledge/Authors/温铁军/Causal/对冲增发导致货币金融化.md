# 对冲增发导致货币金融化

> **领域**：宏观经济学/国际金融　|　**来源**：_cand_wtj_08.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 外资大量流入时央行被动按即期汇率对冲增发本币 |
| **DV（因变量）** | 货币供应脱离实体经济，本国主权货币被金融化，引发国内流动性过剩与资产泡沫 |
| **Chain（传导链）** | 外资大量流入导致央行干预外汇市场，按即期汇率买入外汇卖出本币 → 外汇占款成为基础货币投放的主要渠道，基础货币供应外生化 → 货币供应增长远超实体经济产出增长（信贷余额2000-2014年增688%，名义GDP仅增473%） → 超额货币无法被实体吸收，形成流动性过剩 → 过剩流动性涌入资产市场，推高资产泡沫，最终改变主权货币的实质功能 |
| **Lag（时滞）** | 约5-10年（2001年入世后外生化，2009年外汇占款/基础货币达121.6%高点，2016年M2居世界首位） |
| **Threshold（临界值）** | 外汇占款与基础货币比值超过100%（如2009年121.6%），表明基础货币完全由外资流入驱动，金融化加速 |
| **前提与约束（Premises）** | 央行实行有管理的浮动汇率制，需要维持汇率稳定；存在持续大规模的外资流入（经常项目和资本项目双顺差）；央行缺乏完全的冲销工具，或冲销不彻底；实体经济对货币的吸收能力有限，过剩货币转向资产领域 |
| **Falsification（证伪条件）** | 若在外资大量流入期间，央行能够完全冲销外汇占款，使基础货币增速与实体经济产出增速基本一致，或信贷增速与名义GDP增速没有明显背离，且资产价格未出现普遍泡沫，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像往杯子里不停倒水，为了防止水溢出（汇率波动），央行只能用另一个杯子接水（发本币），但杯子本身容量有限，最终水溢得到处都是（流动性过剩），原本用来喝的水变成了洗脚水（货币功能改变）

### 🔗 文字版因果链

1. 外资大量流入导致央行干预外汇市场，按即期汇率买入外汇卖出本币
2. 外汇占款成为基础货币投放的主要渠道，基础货币供应外生化
3. 货币供应增长远超实体经济产出增长（信贷余额2000-2014年增688%，名义GDP仅增473%）
4. 超额货币无法被实体吸收，形成流动性过剩
5. 过剩流动性涌入资产市场，推高资产泡沫，最终改变主权货币的实质功能
