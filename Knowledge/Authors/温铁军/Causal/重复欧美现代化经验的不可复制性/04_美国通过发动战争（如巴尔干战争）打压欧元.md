# 美国通过发动战争（如巴尔干战争）打压欧元

> 属于因果簇：[[重复欧美现代化经验的不可复制性]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 欧元威胁美元成为世界第一货币 |
| **DV（因变量）** | 美国通过发动战争（如巴尔干战争）打压欧元 |
| **Chain（传导链）** | 欧元问世，币值比美元高13.8%，威胁美元地位 → 美国利用巴尔干战争使欧洲安全风险增加 → 欧洲国家参战导致财政赤字增加，超过欧元区3%的赤字约束，拖累欧元汇率 → 欧洲投资者和中东石油美元因避险心理流向美国资本市场 → 美元强势地位得以维持 |
| **Lag（时滞）** | 短期（数月到数年） |
| **Threshold（临界值）** | 欧元币值超过美元或足以威胁美元成为第一货币时 |
| **前提与约束（Premises）** | 美国拥有军事干预能力；欧元区有财政赤字不超过3%的约束；战争会引发资本避险流动 |
| **Falsification（证伪条件）** | 如果欧元威胁美元时美国未发动战争，或战争不能打压欧元，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

3. 欧洲国家参战导致财政赤字增加，超过欧元区3%的赤字约束，拖累欧元汇率
4. 欧洲投资者和中东石油美元因避险心理流向美国资本市场
5. 美元强势地位得以维持
