# 后发国家实现经济增长的可行出路

> 属于因果簇：[[重复欧美现代化经验的不可复制性]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 区域一体化（如欧盟东扩、亚洲区域化整合） |
| **DV（因变量）** | 后发国家实现经济增长的可行出路 |
| **Chain（传导链）** | 全球资本化实际上是区域化，因为欧美经验不可复制 → 欧洲通过欧盟东扩，将原计划体制下的廉价劳动力和资源与欧洲过剩资本结合 → 亚洲国家（如中国）参与区域一体化，如东北亚、东盟十加一、中印俄整合 → 区域内结合资本、劳动力、资源，形成新的增长动力 |
| **Lag（时滞）** | 中期（5～20年） |
| **Threshold（临界值）** | 区域内国家愿意合作，形成制度化一体化安排 |
| **前提与约束（Premises）** | 欧美经验不可复制；区域内存在廉价劳动力和资源；各国愿意放弃部分主权以促进区域合作 |
| **Falsification（证伪条件）** | 如果区域一体化导致经济停滞或失败，而重复欧美经验却成功，则该断言被推翻 |
| **Confidence（确信度）** | plausible |

### 🔗 文字版因果链

1. 全球资本化实际上是区域化，因为欧美经验不可复制
2. 欧洲通过欧盟东扩，将原计划体制下的廉价劳动力和资源与欧洲过剩资本结合
3. 亚洲国家（如中国）参与区域一体化，如东北亚、东盟十加一、中印俄整合
4. 区域内结合资本、劳动力、资源，形成新的增长动力
