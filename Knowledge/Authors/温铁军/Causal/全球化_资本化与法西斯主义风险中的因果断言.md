# 全球化、资本化与法西斯主义风险中的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国农村劳动力严重过剩（农村劳动年龄人口5亿，农业劳动多由半劳力承担） |
| **DV（因变量）** | 劳动力价格极低且长期不上涨（如沿海低层劳动力价格10年不涨） |
| **Chain（传导链）** | 农业劳动力严重过剩，实际农业劳动由半劳力承担 → 市场条件下形成劳动力无限供给 → 劳动者没有条件建立与雇主谈判的地位 → 低层劳动力价格被压低并长期停滞 |
| **Lag（时滞）** | 长期（10年以上） |
| **Threshold（临界值）** | 农村劳动年龄人口达5亿，劳动力绝对过剩 |
| **前提与约束（Premises）** | 市场经济条件下；城乡分割的二元体制结构约束 |
| **Falsification（证伪条件）** | 如果农村劳动力大量减少、工资显著上涨或劳动者谈判地位提高，则此断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同市场上供大于求的滞销商品，价格难以上涨；卖方（劳动者）没有议价能力。

### 🔗 文字版因果链

1. 农业劳动力严重过剩，实际农业劳动由半劳力承担
2. 市场条件下形成劳动力无限供给
3. 劳动者没有条件建立与雇主谈判的地位
4. 低层劳动力价格被压低并长期停滞

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球经济市场化和一体化 |
| **DV（因变量）** | 发展中国家劳工价格与生存条件同一化到最低程度 |
| **Chain（传导链）** | 全球市场一体化使生产要素自由流动 → 市场将最过剩的要素价格压到最低 → 发展中国家劳动力均过剩，劳工价格趋于最低 → 劳工生存条件被拉平到最低水平 |
| **Lag（时滞）** | 持续进行并逐渐显现（文中未给出具体时间） |
| **Threshold（临界值）** | 要素过剩程度越高，价格越低，直至最低水平 |
| **前提与约束（Premises）** | 真正实现全球经济市场化和一体化；劳动力要素在全球范围内可自由流动（但文本也指出实际只有资本全球化） |
| **Falsification（证伪条件）** | 如果某些发展中国家的劳工价格或生存条件显著高于最低水平且长期持续，则此断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水库连通后，各水池水位趋于同一最低水位。

### 🔗 文字版因果链

1. 全球市场一体化使生产要素自由流动
2. 市场将最过剩的要素价格压到最低
3. 发展中国家劳动力均过剩，劳工价格趋于最低
4. 劳工生存条件被拉平到最低水平

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本全球化 |
| **DV（因变量）** | 大城市超前繁荣、传统农区衰败 |
| **Chain（传导链）** | 资本全球化要求自然资源价格压低 → 资源低价使资源转化为资本时有巨大增值空间 → 资源资本化的收益大部分被大资本占有 → 资本向大城市集中，传统农区失去资源而衰败 |
| **Lag（时滞）** | 长期过程 |
| **Threshold（临界值）** | 资源价格被压低到足以产生资本增量收益 |
| **前提与约束（Premises）** | 自然资源可被资本化；大资本占主导地位 |
| **Falsification（证伪条件）** | 如果资源价格高但资本收益仍增长，或大城市繁荣同时乡村同样繁荣，则不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水泵把水从低处抽到高处，低处（农区）逐渐干涸，高处（大城市）积累财富。

### 🔗 文字版因果链

1. 资本全球化要求自然资源价格压低
2. 资源低价使资源转化为资本时有巨大增值空间
3. 资源资本化的收益大部分被大资本占有
4. 资本向大城市集中，传统农区失去资源而衰败

| **Falsification（证伪条件）** | 如果印度在资源匮乏下仍吸引大量资本且未出现法西斯化，则不成立 |
| **Confidence（确信度）** | plausible |

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本流出（或担心资本流出） |
| **DV（因变量）** | 美国/英国垄断资本反对资本流动并进行干预（如美国当裁判，英国反对欧元） |
| **Chain（传导链）** | 资本流出导致国内资本市场收益下降 → 美国需要外部资本流入维持交易收益，否则经济硬着陆 → 因而美国以军事政治手段推动资本从别处流入美国 → 英国担心资本流出导致货币贬值，故反对欧洲统一货币 |
| **Lag（时滞）** | 在资本流出威胁显现时 |
| **Threshold（临界值）** | 外部资本流入减少到无法维持资本市场收益/货币稳定 |
| **前提与约束（Premises）** | 资本高度流动；垄断资本利益与国家政策结合 |
| **Falsification（证伪条件）** | 如果资本大量流出但经济体仍能保持收益和币值稳定而无此类干预，则不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 泳池水位下降，救生员宁可把别人家的水抽过来，也不许自家池子漏水。

### 🔗 文字版因果链

1. 资本流出导致国内资本市场收益下降
2. 美国需要外部资本流入维持交易收益，否则经济硬着陆
3. 因而美国以军事政治手段推动资本从别处流入美国
4. 英国担心资本流出导致货币贬值，故反对欧洲统一货币
