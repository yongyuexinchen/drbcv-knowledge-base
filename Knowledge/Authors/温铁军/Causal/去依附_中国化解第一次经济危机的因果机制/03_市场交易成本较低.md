# 市场交易成本较低

> 属于因果簇：[[去依附：中国化解第一次经济危机的因果机制]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 重化产业以中间产品为主的生产结构 |
| **DV（因变量）** | 市场交易成本较低 |
| **Chain（传导链）** | 国家资本集中于重工业部门 → 生产的是中间产品而非终端消费品 → 无需直接面对高度分散的农村终端市场 → 市场交易成本因此较低 |
| **Lag（时滞）** | 即时（产业结构决定） |
| **Threshold（临界值）** | 重工业比重足够高，且产品主要面向工业链条而非终端消费 |
| **前提与约束（Premises）** | 国家资本主导重工业；中间产品有稳定的计划调配渠道；农村终端市场高度分散且信息化水平低 |
| **Falsification（证伪条件）** | 如果重工业企业仍需大量直接销售给终端散户，或中间产品交易成本同样高昂，则此断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 批发商只对几家大客户发货，比开零售店应对成百上千顾客更省成本

### 🔗 文字版因果链

1. 国家资本集中于重工业部门
2. 生产的是中间产品而非终端消费品
3. 无需直接面对高度分散的农村终端市场
4. 市场交易成本因此较低
