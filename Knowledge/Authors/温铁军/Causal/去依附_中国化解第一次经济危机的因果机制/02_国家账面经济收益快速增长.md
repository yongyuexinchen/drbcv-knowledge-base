# 国家账面经济收益快速增长

> 属于因果簇：[[去依附：中国化解第一次经济危机的因果机制]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 恢复性重建（修复战争部分损毁的基础设施） |
| **DV（因变量）** | 国家账面经济收益快速增长 |
| **Chain（传导链）** | 民国遗留基础设施仅部分损毁 → 国家财政只需支付部分修复成本即可恢复全部设施功能 → 低成本获得高收益，导致账面经济收益增长迅速 |
| **Lag（时滞）** | 1949-1952年期间 |
| **Threshold（临界值）** | 基础设施损毁率为部分而非全部，修复成本低于重置成本 |
| **前提与约束（Premises）** | 战前已有较完整的基础设施体系；战争只造成部分破坏而不及根本；国家有能力组织修复工作 |
| **Falsification（证伪条件）** | 如果修复成本等于或高于新建成本，或基础设施已完全损毁，则账面收益不会快速增长 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 旧房翻新比推倒重建省钱，同样的钱能获得更大面积

### 🔗 文字版因果链

1. 民国遗留基础设施仅部分损毁
2. 国家财政只需支付部分修复成本即可恢复全部设施功能
3. 低成本获得高收益，导致账面经济收益增长迅速
