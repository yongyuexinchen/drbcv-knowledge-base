# 经理人追求短期股市收益、做信息欺诈，损害公司长期利益

> 属于因果簇：[[公司治理结构与金融风险相关性质疑]]（第2块/6块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 给经理人股票期权（以期权激励防止内部人控制） |
| **DV（因变量）** | 经理人追求短期股市收益、做信息欺诈，损害公司长期利益 |
| **Chain（传导链）** | 给经理人期权使其拥有股权 → 期权收益与股价短期表现挂钩 → 经理人更倾向于追求股市短期收益 → 为推高股价倾向美化报表 → 为追求股市收益而有意识进行信息欺诈 → 最终积累风险并在资本市场危机中暴露，损害公司和股东长期利益 |
| **Lag（时滞）** | 短期表现可能良好，长期风险在资本市场危机时暴露；时滞可跨年 |
| **Threshold（临界值）** | 当期权激励占经理人收入比重达到使其行为显著转向短期股价管理的程度时（文中未给定量阈值） |
| **前提与约束（Premises）** | 资本市场存在短期价格与长期价值背离的机制；公司内部监督（如上级公司检查）也偏向短期报表表现；所有者与经营者之间存在信息不对称 |
| **Falsification（证伪条件）** | 若发现实行期权激励的公司长期业绩和股东回报显著优于未实行的公司，且没有增加信息欺诈行为，则可推翻该断言 |
| **Confidence（确信度）** | well-established |
