# 家庭主动节育

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第5块/8块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人均耕地低于0.5亩 |
| **DV（因变量）** | 家庭主动节育 |
| **Chain（传导链）** | 人均耕地不足，粮食不够吃 → 需要买粮食养活家人 → 买粮食的家庭不愿多生孩子，依赖男劳力外出打工挣钱买粮 → 家庭主动减少生育 |
| **Lag（时滞）** | 在一代人或更长时间内显现 |
| **Threshold（临界值）** | 人均耕地低于0.5亩 |
| **前提与约束（Premises）** | 山区农业为主，非农就业机会少；农地承包30年不变，调地难度极大；没有其他社会保障 |
| **Falsification（证伪条件）** | 如果人均耕地低于0.5亩的地区出生率仍很高，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像养不起宠物时，自然就不会再养更多宠物。

### 🔗 文字版因果链

1. 人均耕地不足，粮食不够吃
2. 需要买粮食养活家人
3. 买粮食的家庭不愿多生孩子，依赖男劳力外出打工挣钱买粮
4. 家庭主动减少生育
