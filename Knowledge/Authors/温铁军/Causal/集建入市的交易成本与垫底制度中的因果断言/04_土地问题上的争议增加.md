# 土地问题上的争议增加

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第4块/8块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 乡镇企业私有化改制 |
| **DV（因变量）** | 土地问题上的争议增加 |
| **Chain（传导链）** | 政府经济下的乡镇企业以就业最大化为目标，解决大量农村就业 → 乡镇企业高负债（负债率高达80%以上，其中政府开支占30%多）无法继续经营 → 90年代末企业普遍私有化改制 → 私有化企业以利润最大化为目标，不再解决农村就业 → 原在乡镇企业就业的农民回家，重新依赖土地 → 土地争议增加 |
| **Lag（时滞）** | 90年代末私有化改制后数年内 |
| **Threshold（临界值）** | 乡镇企业负债率高达80%以上，其中借债用于政府开支约占30% |
| **前提与约束（Premises）** | 乡镇企业曾是政府经济，承担政府公益开支和就业功能；企业私有化后目标转为利润最大化；农村集体没有其他收入来源，只能靠地租维持 |
| **Falsification（证伪条件）** | 如果私有化后企业仍大量雇佣农村劳动力，且土地争议未增加，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像国企改制后裁员，员工回老家种地，地就变得金贵了。

### 🔗 文字版因果链

1. 政府经济下的乡镇企业以就业最大化为目标，解决大量农村就业
2. 乡镇企业高负债（负债率高达80%以上，其中政府开支占30%多）无法继续经营
3. 90年代末企业普遍私有化改制
4. 私有化企业以利润最大化为目标，不再解决农村就业
5. 原在乡镇企业就业的农民回家，重新依赖土地
6. 土地争议增加
