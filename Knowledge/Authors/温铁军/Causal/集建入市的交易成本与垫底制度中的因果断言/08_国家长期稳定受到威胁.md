# 国家长期稳定受到威胁

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第8块/8块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体建设用地入市增值收益全部用于当年分配（不建立社保基金） |
| **DV（因变量）** | 国家长期稳定受到威胁 |
| **Chain（传导链）** | 集体土地入市产生增值收益 → 若收益全部用于当年分配，农民当年消费掉 → 农民未来失去可持续的社会保障来源 → 农民只能继续依赖土地或陷入无保障状态 → 社会不安定因素积累，威胁国家长期稳定 |
| **Lag（时滞）** | 长期，可能在多年后显现 |
| **Threshold（临界值）** | 收益未定向安排用于农村社会保障基金 |
| **前提与约束（Premises）** | 政府无法为8亿农民建立现代意义的社会保障；集体土地的保障功能大于生产功能；集体土地收益归集体，由政府做制度安排 |
| **Falsification（证伪条件）** | 如果入市收益当年分配但未来农民有其它途径获得充分保障且社会稳定，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像中彩票后全花光，没留养老金，晚年风险高。

### 🔗 文字版因果链

1. 集体土地入市产生增值收益
2. 若收益全部用于当年分配，农民当年消费掉
3. 农民未来失去可持续的社会保障来源
4. 农民只能继续依赖土地或陷入无保障状态
5. 社会不安定因素积累，威胁国家长期稳定
