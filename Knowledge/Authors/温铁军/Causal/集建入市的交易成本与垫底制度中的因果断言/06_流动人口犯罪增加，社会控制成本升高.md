# 流动人口犯罪增加，社会控制成本升高

> 属于因果簇：[[集建入市的交易成本与垫底制度中的因果断言]]（第6块/8块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 农民离开社区并失去土地财产身份 |
| **DV（因变量）** | 流动人口犯罪增加，社会控制成本升高 |
| **Chain（传导链）** | 农民在社区稳定生活，有土地财产约束，基本不犯罪 → 农民一旦离开社区，失去可获得财产的身份 → 城市无法为流动人口提供同等保障和约束 → 流动人口犯罪比例上升（城市犯罪70%以上是流动人口犯罪） → 社会控制成本升高 |
| **Lag（时滞）** | 离开社区后短期至数年 |
| **Threshold（临界值）** | 无地农民增加时期，社会不安定显著加剧 |
| **前提与约束（Premises）** | 集体土地以社区成员权为基本权利依据；城市就业和社保体系无法覆盖流动人口；土地是农民安身立命的最后保障 |
| **Falsification（证伪条件）** | 如果大量离开土地的农民在城市犯罪率很低且社会稳定，则断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像树有根才稳，拔根移植容易枯萎。

### 🔗 文字版因果链

1. 农民在社区稳定生活，有土地财产约束，基本不犯罪
2. 农民一旦离开社区，失去可获得财产的身份
3. 城市无法为流动人口提供同等保障和约束
4. 流动人口犯罪比例上升（城市犯罪70%以上是流动人口犯罪）
5. 社会控制成本升高
