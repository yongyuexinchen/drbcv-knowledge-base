# 贷款保本保值、促进生产、农贷可持续周转

> 属于因果簇：[[陕甘宁边区货币超发与通胀及后续治理的因果链条]]（第4块/9块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对农业、工业、商业放款采取折实措施（实物贷款、订货办法） |
| **DV（因变量）** | 贷款保本保值、促进生产、农贷可持续周转 |
| **Chain（传导链）** | 银行发放农贷时按市价折成实物（粮食或棉花）放出 → 农民收获后交还等价实物 → 银行避免因货币贬值而损失本金 → 农民获得生产工具和口粮，促进生产 → 农贷得以持续周转，对公私双方都合理 |
| **Lag（时滞）** | 一个生产周期，约数月至一年（春贷秋还） |
| **Threshold（临界值）** | 1942年400万元农贷中除部分地区外基本采用实物贷款；不同地区采用不同折实方式（如以农具贷出、以农产品收回） |
| **前提与约束（Premises）** | 边区处于通货膨胀、货币贬值环境；实物具有相对稳定的价值；农业生产周期可预期；当地有相应的实物供需 |
| **Falsification（证伪条件）** | 如果折实贷款导致银行收回的实物价值低于放出实物价值，或农民不愿意归还，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 借给别人大米，收回时也要大米，而不是收回可能贬值的纸币。

### 🔗 文字版因果链

1. 银行发放农贷时按市价折成实物（粮食或棉花）放出
2. 农民收获后交还等价实物
3. 银行避免因货币贬值而损失本金
4. 农民获得生产工具和口粮，促进生产
5. 农贷得以持续周转，对公私双方都合理
