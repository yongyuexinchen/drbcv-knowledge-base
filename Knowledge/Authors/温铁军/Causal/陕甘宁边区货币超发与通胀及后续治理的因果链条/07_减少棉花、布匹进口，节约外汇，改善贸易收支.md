# 减少棉花、布匹进口，节约外汇，改善贸易收支

> 属于因果簇：[[陕甘宁边区货币超发与通胀及后续治理的因果链条]]（第7块/9块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以高于国民党区域的价格抢收棉花、发展本地棉花生产 |
| **DV（因变量）** | 减少棉花、布匹进口，节约外汇，改善贸易收支 |
| **Chain（传导链）** | 在收棉时节以高出国民党区1.5倍的价格买入棉花 → 吸引民间商人甚至国民党军队向边区卖棉 → 两个月内争取到进口优质新棉花百余万斤 → 同时边区自产棉花300万斤，冬闲时织布 → 减少从国统区进口布匹，节省大量边币和外汇 → 改善贸易收支，为实现出超奠定基础 |
| **Lag（时滞）** | 棉花收购在秋季（9、10月），当年冬天织布，次年见效 |
| **Threshold（临界值）** | 边区收购价每百斤28000元，高出国民党区17000元（国民党区价11000元）；自产棉花300万斤 |
| **前提与约束（Premises）** | 边区有足够资金支持高价收购；棉花是战略物资，农民有种植和织布积极性；外部封锁存在但可被高价突破 |
| **Falsification（证伪条件）** | 如果高价收购棉花后未减少布匹进口，或进口总额未下降，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 家里缺布，与其高价买布，不如高价买棉花自己织布，算总账更划算。

### 🔗 文字版因果链

1. 在收棉时节以高出国民党区1.5倍的价格买入棉花
2. 吸引民间商人甚至国民党军队向边区卖棉
3. 两个月内争取到进口优质新棉花百余万斤
4. 同时边区自产棉花300万斤，冬闲时织布
5. 减少从国统区进口布匹，节省大量边币和外汇
6. 改善贸易收支，为实现出超奠定基础
