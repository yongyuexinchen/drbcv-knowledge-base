# 印度或南亚次大陆可能出现法西斯主义

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第5块/8块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 印度缺乏新的可资本化资源（没有新的资源带来资本收益） |
| **DV（因变量）** | 印度或南亚次大陆可能出现法西斯主义 |
| **Chain（传导链）** | 印度已无足够资源可供资本化 → 金融资本因无收益而进入缓慢或不来 → 外国直接投资远低于中国（为中国的1/10） → 经济困境可能催生法西斯主义 |
| **Lag（时滞）** | 未明确，当代已显现 |
| **Threshold（临界值）** | 外国直接投资仅为中国的1/10，资本流入停滞 |
| **前提与约束（Premises）** | 资本主义生产方式下资本必须获利；印度缺乏可资本化资源 |
| **Falsification（证伪条件）** | 如果印度在资源匮乏下仍吸引大量资本且未出现法西斯化，则不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 没有猎物的猎场，猎手不会来，而饥饿的猎狗可能疯狂。

### 🔗 文字版因果链

1. 印度已无足够资源可供资本化
2. 金融资本因无收益而进入缓慢或不来
3. 外国直接投资远低于中国（为中国的1/10）
4. 经济困境可能催生法西斯主义
