# 中国集全球化过程中各种内外矛盾于一身

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第8块/8块）

## 因果断言 8

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中国存在部门垄断且大部分资源仍处于自然状态（有待资本化） |
| **DV（因变量）** | 中国集全球化过程中各种内外矛盾于一身 |
| **Chain（传导链）** | 垄断部门在全民名义下占有资源 → 资源有待资本化并形成增量资本收益 → 国际大资本要求参与分享权益 → 国内各利益主体要求重新界定资源和财产权益 → 多重压力交织使中国成为矛盾焦点 |
| **Lag（时滞）** | 当前进行时 |
| **Threshold（临界值）** | 资源尚未资本化且存在垄断部门 |
| **前提与约束（Premises）** | 部门垄断存在；国际资本与国内利益主体同时施压 |
| **Falsification（证伪条件）** | 如果资源资本化未引发内外利益冲突，或中国未成为矛盾焦点，则不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 一块未分配的蛋糕放在桌上，周围的人都想分，自然成为矛盾焦点。

### 🔗 文字版因果链

1. 垄断部门在全民名义下占有资源
2. 资源有待资本化并形成增量资本收益
3. 国际大资本要求参与分享权益
4. 国内各利益主体要求重新界定资源和财产权益
5. 多重压力交织使中国成为矛盾焦点
