# 世界法西斯主义的复苏（全球性重大危机）

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第4块/8块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 发展中国家没有新的资源可供资本化 |
| **DV（因变量）** | 世界法西斯主义的复苏（全球性重大危机） |
| **Chain（传导链）** | 全球认同资本主义/现代工业化生产方式 → 所有资源被加速转化为资本 → 资源枯竭后没有新的资源可供资本化 → 资本失去增值来源，引发全球性危机 → 垄断资本在危机中走向法西斯主义 |
| **Lag（时滞）** | 在资源资本化耗尽后出现（未明确具体时长） |
| **Threshold（临界值）** | 发展中国家没有新的资源可供资本化 |
| **前提与约束（Premises）** | 全球都认同资本主义生产方式；资本需要持续增值 |
| **Falsification（证伪条件）** | 如果资源耗尽后出现新的非资本化增长模式，或法西斯主义未复苏，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 蝗虫啃光一片庄稼后，要么迁徙，要么同类相残——资本无新资源可吃时转向法西斯。

### 🔗 文字版因果链

1. 全球认同资本主义/现代工业化生产方式
2. 所有资源被加速转化为资本
3. 资源枯竭后没有新的资源可供资本化
4. 资本失去增值来源，引发全球性危机
5. 垄断资本在危机中走向法西斯主义
