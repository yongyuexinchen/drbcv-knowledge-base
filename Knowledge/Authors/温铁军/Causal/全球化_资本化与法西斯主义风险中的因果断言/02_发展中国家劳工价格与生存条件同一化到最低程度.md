# 发展中国家劳工价格与生存条件同一化到最低程度

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第2块/8块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球经济市场化和一体化 |
| **DV（因变量）** | 发展中国家劳工价格与生存条件同一化到最低程度 |
| **Chain（传导链）** | 全球市场一体化使生产要素自由流动 → 市场将最过剩的要素价格压到最低 → 发展中国家劳动力均过剩，劳工价格趋于最低 → 劳工生存条件被拉平到最低水平 |
| **Lag（时滞）** | 持续进行并逐渐显现（文中未给出具体时间） |
| **Threshold（临界值）** | 要素过剩程度越高，价格越低，直至最低水平 |
| **前提与约束（Premises）** | 真正实现全球经济市场化和一体化；劳动力要素在全球范围内可自由流动（但文本也指出实际只有资本全球化） |
| **Falsification（证伪条件）** | 如果某些发展中国家的劳工价格或生存条件显著高于最低水平且长期持续，则此断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水库连通后，各水池水位趋于同一最低水位。

### 🔗 文字版因果链

1. 全球市场一体化使生产要素自由流动
2. 市场将最过剩的要素价格压到最低
3. 发展中国家劳动力均过剩，劳工价格趋于最低
4. 劳工生存条件被拉平到最低水平
