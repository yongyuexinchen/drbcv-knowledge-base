# 美国最可能向法西斯化转变

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第6块/8块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 美国没有新的资源可供资本饕餮转化为资本收益 |
| **DV（因变量）** | 美国最可能向法西斯化转变 |
| **Chain（传导链）** | 资本需要不断将新资源转化为资本收益 → 美国虽发达但新资源可资本化空间耗尽 → 资本收益难以维持，泡沫经济崩溃 → 大垄断资本为自救推动法西斯化制度转变 → 美国制度转化成本最低、条件最好、潜在收益最大 |
| **Lag（时滞）** | 在泡沫经济崩溃过程中显现 |
| **Threshold（临界值）** | 没有新资源可供资本化，或新资源资本化收益无法维持资本市场 |
| **前提与约束（Premises）** | 垄断资本主导；美国具备低制度转换成本 |
| **Falsification（证伪条件）** | 如果美国在资源耗尽后走向其他制度调整而非法西斯化，则不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 一个靠家底挥霍的富豪坐吃山空时，也许会铤而走险，而越是豪宅林立的社区越容易发生黑吃黑。

### 🔗 文字版因果链

1. 资本需要不断将新资源转化为资本收益
2. 美国虽发达但新资源可资本化空间耗尽
3. 资本收益难以维持，泡沫经济崩溃
4. 大垄断资本为自救推动法西斯化制度转变
5. 美国制度转化成本最低、条件最好、潜在收益最大
