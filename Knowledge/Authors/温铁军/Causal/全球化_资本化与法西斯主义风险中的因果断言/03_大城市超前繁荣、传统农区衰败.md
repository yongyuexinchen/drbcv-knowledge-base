# 大城市超前繁荣、传统农区衰败

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第3块/8块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本全球化 |
| **DV（因变量）** | 大城市超前繁荣、传统农区衰败 |
| **Chain（传导链）** | 资本全球化要求自然资源价格压低 → 资源低价使资源转化为资本时有巨大增值空间 → 资源资本化的收益大部分被大资本占有 → 资本向大城市集中，传统农区失去资源而衰败 |
| **Lag（时滞）** | 长期过程 |
| **Threshold（临界值）** | 资源价格被压低到足以产生资本增量收益 |
| **前提与约束（Premises）** | 自然资源可被资本化；大资本占主导地位 |
| **Falsification（证伪条件）** | 如果资源价格高但资本收益仍增长，或大城市繁荣同时乡村同样繁荣，则不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 水泵把水从低处抽到高处，低处（农区）逐渐干涸，高处（大城市）积累财富。

### 🔗 文字版因果链

1. 资本全球化要求自然资源价格压低
2. 资源低价使资源转化为资本时有巨大增值空间
3. 资源资本化的收益大部分被大资本占有
4. 资本向大城市集中，传统农区失去资源而衰败
