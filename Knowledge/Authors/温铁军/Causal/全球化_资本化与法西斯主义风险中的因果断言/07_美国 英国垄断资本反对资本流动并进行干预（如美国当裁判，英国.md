# 美国 英国垄断资本反对资本流动并进行干预（如美国当裁判，英国

> 属于因果簇：[[全球化、资本化与法西斯主义风险中的因果断言]]（第7块/8块）

## 因果断言 7

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本流出（或担心资本流出） |
| **DV（因变量）** | 美国/英国垄断资本反对资本流动并进行干预（如美国当裁判，英国反对欧元） |
| **Chain（传导链）** | 资本流出导致国内资本市场收益下降 → 美国需要外部资本流入维持交易收益，否则经济硬着陆 → 因而美国以军事政治手段推动资本从别处流入美国 → 英国担心资本流出导致货币贬值，故反对欧洲统一货币 |
| **Lag（时滞）** | 在资本流出威胁显现时 |
| **Threshold（临界值）** | 外部资本流入减少到无法维持资本市场收益/货币稳定 |
| **前提与约束（Premises）** | 资本高度流动；垄断资本利益与国家政策结合 |
| **Falsification（证伪条件）** | 如果资本大量流出但经济体仍能保持收益和币值稳定而无此类干预，则不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 资本流出导致国内资本市场收益下降
2. 美国需要外部资本流入维持交易收益，否则经济硬着陆
3. 因而美国以军事政治手段推动资本从别处流入美国
4. 英国担心资本流出导致货币贬值，故反对欧洲统一货币
