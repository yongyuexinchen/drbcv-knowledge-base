# 粮食主权与国家安全

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 粮食进口依赖度高（基本农产品不能自给） |
| **DV（因变量）** | 国家安全风险升高（社会动荡、政权更迭等） |
| **Chain（传导链）** | 粮食依赖进口且经济单一，使国家暴露于国际粮价波动 → 跨国资本控制农业产业链，国际粮价被金融资本操纵，导致输入型通胀 → 输入型通胀推高国内粮食价格，引发民众不满 → 社会不满累积，可能导致社会动荡甚至政权更迭（如2011年中东颜色革命） |
| **Lag（时滞）** | 从国际粮价冲击到社会风险显现通常存在数月至数年的时滞，具体取决于国内缓冲机制（如政府补贴、战略储备） |
| **Threshold（临界值）** | 当粮食自给率低于临界水平（如基本农产品不能自给）且国际粮价波动幅度超过国内可承受范围时，因果效应显著 |
| **前提与约束（Premises）** | 该国基本农产品不能自给；跨国资本控制其农业产业链（大种植园、期货定价）；国际粮价被金融资本操纵 |
| **Falsification（证伪条件）** | 若发现高粮食进口依赖国家在国际粮价大幅上涨时未出现显著社会风险，或粮食自给率低但经济多元化国家仍发生社会动荡，则该断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人依靠外卖生存，若外卖价格被商家垄断且自己无法做饭，一旦外卖涨价或断供，他的生存就受威胁；而自己种菜做饭的人则更安全

### 🔗 文字版因果链

1. 粮食依赖进口且经济单一，使国家暴露于国际粮价波动
2. 跨国资本控制农业产业链，国际粮价被金融资本操纵，导致输入型通胀
3. 输入型通胀推高国内粮食价格，引发民众不满
4. 社会不满累积，可能导致社会动荡甚至政权更迭（如2011年中东颜色革命）
