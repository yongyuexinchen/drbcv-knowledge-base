# 金融资本与生产资本脱钩，引发金融狂热与危机

> 属于因果簇：[[金融资本与技术革命联姻的因果机制]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本与新兴产业“联姻”（过度投入） |
| **DV（因变量）** | 金融资本与生产资本脱钩，引发金融狂热与危机 |
| **Chain（传导链）** | 金融资本从新兴产业获得高额回报，习惯了高收益预期 → 新兴产业虽增长迅速但规模有限，无法吸收所有投资资金 → 旧产业利润下降，现代化进程缓慢且风险高 → 可供投资的资金超过优质投资机会，金融资本开发复杂金融工具“以钱生钱” → 金融资本不再满足于为生产活动融资，金融资本与生产资本脱钩 → 脱钩导致账面财富与实际财富增长脱钩，引发股市崩溃等危机 |
| **Lag（时滞）** | 中期（技术革命爆发后数年至数十年，在导入期中期显现） |
| **Threshold（临界值）** | 金融资本可支配资金超过其认定的优质投资机会规模，且对回报率的期望固化在高水平 |
| **前提与约束（Premises）** | 新兴产业无法吸收所有可用投资资金；旧范式潜力耗尽，传统业务利润降低；金融资本追求高回报的偏好持续强化 |
| **Falsification（证伪条件）** | 如果金融资本在投入新兴产业后，始终能保持与生产资本的紧密联系，未出现脱钩现象，也未发生股市崩溃等危机，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同热恋中的人对伴侣期望过高，当现实无法满足时，关系破裂，甚至引发激烈冲突（危机）

### 🔗 文字版因果链

1. 金融资本从新兴产业获得高额回报，习惯了高收益预期
2. 新兴产业虽增长迅速但规模有限，无法吸收所有投资资金
3. 旧产业利润下降，现代化进程缓慢且风险高
4. 可供投资的资金超过优质投资机会，金融资本开发复杂金融工具“以钱生钱”
5. 金融资本不再满足于为生产活动融资，金融资本与生产资本脱钩
6. 脱钩导致账面财富与实际财富增长脱钩，引发股市崩溃等危机
