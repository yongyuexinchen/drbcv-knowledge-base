# 金融资本开始资助新技术探索，为下一次技术革命创造条件

> 属于因果簇：[[技术革命成熟阶段金融资本行为模式与动荡种子]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 旧范式成熟阶段投资机会耗竭、金融资本寻求新出路 |
| **DV（因变量）** | 金融资本开始资助新技术探索，为下一次技术革命创造条件 |
| **Chain（传导链）** | 主导范式可获利的创新领域出现耗竭迹象 → 金融资本为寻找新利润来源，愿意承担新技术风险 → 打破循规蹈矩创新的限制，真正全新的技术获得资金支持 → 部分新技术汇聚成下一次技术革命（如蒸汽船、汽车、电子计算机） → 旧范式末期同时积累衰落的阵痛和新范式的萌芽 |
| **Lag（时滞）** | 金融资本开始资助新技术到下一次技术革命爆发通常需要10-30年（如20世纪60年代资助电子技术，90年代互联网革命） |
| **Threshold（临界值）** | 当旧范式内创新回报率降至低于新技术潜在回报率时，资本开始转向；新技术获得融资的门槛在成熟阶段后期显著降低 |
| **前提与约束（Premises）** | 存在有潜力的新技术方向（如蒸汽、电力、电子）；金融资本具有风险承担意愿和能力；旧范式对新技术的排斥和边缘化达到一定程度，反而激发突破 |
| **Falsification（证伪条件）** | 若在成熟阶段金融资本未转向资助新技术，或资助未能催生下一次技术革命，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 主导范式可获利的创新领域出现耗竭迹象
2. 金融资本为寻找新利润来源，愿意承担新技术风险
3. 打破循规蹈矩创新的限制，真正全新的技术获得资金支持
4. 部分新技术汇聚成下一次技术革命（如蒸汽船、汽车、电子计算机）
5. 旧范式末期同时积累衰落的阵痛和新范式的萌芽
