# 技术革命转折点中的因果机制（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：技术革命转折点中的因果机制.md

## 总体因果图

- 狂热阶段金融资本主导下的过度投机和收入分配失衡 → 经济崩溃和随之而来的衰退
- 经济崩溃和衰退 → 金融资本接受监管，生产资本重新主导
- 技术革命导入期力度不足或金融资本不热衷 → 偏离典型狂热阶段，出现非典型发展路径
