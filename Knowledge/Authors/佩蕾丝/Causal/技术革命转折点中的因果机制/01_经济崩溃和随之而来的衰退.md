# 经济崩溃和随之而来的衰退

> 属于因果簇：[[技术革命转折点中的因果机制]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 狂热阶段金融资本主导下的过度投机和收入分配失衡 |
| **DV（因变量）** | 经济崩溃和随之而来的衰退 |
| **Chain（传导链）** | 金融资本追求高利润，推动资产价格膨胀，形成泡沫 → 真实财富增长跟不上账面财富增长，产生结构性紧张 → 收入集中于少数群体，导致有效需求不足，市场过早饱和 → 社会排斥和贫富差距扩大，引发政治和社会压力 → 紧张关系达到极限，泡沫破裂，引发经济崩溃和衰退 |
| **Lag（时滞）** | 泡沫积累数年，崩溃在狂热阶段末期突然发生 |
| **Threshold（临界值）** | 贫富差距越过临界点，或资产价格与基本面严重脱钩 |
| **前提与约束（Premises）** | 资本主义体系内存在金融资本与生产资本的利益冲突；缺乏有效监管，金融资本行为不受约束；技术革命处于导入期结束、展开期开始的转折点 |
| **Falsification（证伪条件）** | 如果泡沫持续膨胀而不破裂，或经济崩溃后未出现衰退，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同吹气球，越吹越大，最终必然爆裂，但爆裂的时机和方式难以预测

### 🔗 文字版因果链

1. 金融资本追求高利润，推动资产价格膨胀，形成泡沫
2. 真实财富增长跟不上账面财富增长，产生结构性紧张
3. 收入集中于少数群体，导致有效需求不足，市场过早饱和
4. 社会排斥和贫富差距扩大，引发政治和社会压力
5. 紧张关系达到极限，泡沫破裂，引发经济崩溃和衰退
