# 债务危机爆发（违约、经济崩溃）

> 属于因果簇：[[狂热阶段金融资本与两极分化及泡沫破裂的因果机制]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 边缘国家债务累积（用于旧范式投资） |
| **DV（因变量）** | 债务危机爆发（违约、经济崩溃） |
| **Chain（传导链）** | 边缘国家在成熟阶段借入大量外债投资旧范式 → 新技术革命兴起，旧范式投资收益率下降 → 债务国经济收益不足以偿还债务 → 债务违约风险增加，国际资本撤离 → 债务危机爆发，经济陷入衰退 |
| **Lag（时滞）** | 债务累积到危机爆发通常为10-20年 |
| **Threshold（临界值）** | 债务占GDP比重过高，或偿债能力持续恶化 |
| **前提与约束（Premises）** | 边缘国家经济结构单一，依赖旧范式；国际金融市场存在资本流动波动；缺乏有效的债务管理机制 |
| **Falsification（证伪条件）** | 如果边缘国家债务累积但未发生危机，或危机发生但无前期债务累积，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同借债建桥，但桥建好后河流改道，桥无人使用，债务无法偿还

### 🔗 文字版因果链

1. 边缘国家在成熟阶段借入大量外债投资旧范式
2. 新技术革命兴起，旧范式投资收益率下降
3. 债务国经济收益不足以偿还债务
4. 债务违约风险增加，国际资本撤离
5. 债务危机爆发，经济陷入衰退
