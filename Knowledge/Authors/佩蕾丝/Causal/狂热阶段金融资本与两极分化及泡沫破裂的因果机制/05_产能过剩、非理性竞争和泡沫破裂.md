# 产能过剩、非理性竞争和泡沫破裂

> 属于因果簇：[[狂热阶段金融资本与两极分化及泡沫破裂的因果机制]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 新兴产业投资过热（如运河、铁路、互联网） |
| **DV（因变量）** | 产能过剩、非理性竞争和泡沫破裂 |
| **Chain（传导链）** | 新技术革命带来高利润预期，吸引大量投资 → 投资者盲目跟风，重复投资同一领域 → 产能过度扩张，超过实际需求 → 价格竞争加剧，利润下降 → 投资回报恶化，泡沫破裂，引发经济危机 |
| **Lag（时滞）** | 投资热潮到泡沫破裂通常为5-10年 |
| **Threshold（临界值）** | 投资增长率远超需求增长率，或产能利用率大幅下降 |
| **前提与约束（Premises）** | 金融市场资本充裕，利率较低；投资者存在从众心理和过度乐观；缺乏有效的市场协调和监管 |
| **Falsification（证伪条件）** | 如果投资过热但未出现产能过剩，或产能过剩但未引发危机，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同多人同时挖井，挖得太多，水不够分，最终都白费力气

### 🔗 文字版因果链

1. 新技术革命带来高利润预期，吸引大量投资
2. 投资者盲目跟风，重复投资同一领域
3. 产能过度扩张，超过实际需求
4. 价格竞争加剧，利润下降
5. 投资回报恶化，泡沫破裂，引发经济危机
