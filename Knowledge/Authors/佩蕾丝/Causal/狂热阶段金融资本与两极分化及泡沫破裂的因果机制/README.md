# 狂热阶段金融资本与两极分化及泡沫破裂的因果机制（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：狂热阶段金融资本与两极分化及泡沫破裂的因果机制.md

## 总体因果图

- 金融资本与生产资本脱钩，金融资本追求高额短期收益 → 社会两极分化加剧（富者愈富、穷者愈穷）
- 资产价格上涨引发乐观预期和投机行为 → 资产泡沫形成并最终破裂
- 边缘国家债务累积（用于旧范式投资） → 债务危机爆发（违约、经济崩溃）
- 后发国家利用技术革命机遇窗口（如亚洲四小龙） → 经济赶超成功（实现跳跃式发展）
- 新兴产业投资过热（如运河、铁路、互联网） → 产能过剩、非理性竞争和泡沫破裂
- 金融资本过剩（闲置资金大量积累） → 企业兼并和垄断趋势增强
