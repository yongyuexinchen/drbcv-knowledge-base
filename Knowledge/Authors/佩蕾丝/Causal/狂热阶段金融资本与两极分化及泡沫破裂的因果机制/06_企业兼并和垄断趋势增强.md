# 企业兼并和垄断趋势增强

> 属于因果簇：[[狂热阶段金融资本与两极分化及泡沫破裂的因果机制]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 金融资本过剩（闲置资金大量积累） |
| **DV（因变量）** | 企业兼并和垄断趋势增强 |
| **Chain（传导链）** | 狂热阶段产生大量闲置资金 → 资金寻求高回报投资机会 → 通过收购和兼并吞并竞争对手 → 市场集中度提高，形成垄断或寡头 → 竞争减弱，利润集中，可能阻碍创新 |
| **Lag（时滞）** | 狂热阶段末期，数年 |
| **Threshold（临界值）** | 资金过剩程度高，且存在可收购的目标企业 |
| **前提与约束（Premises）** | 反垄断法规不完善或执行不力；金融市场允许大规模融资并购；技术变革导致设备过早报废，中小企业竞争力弱 |
| **Falsification（证伪条件）** | 如果资金过剩但未出现兼并潮，或兼并潮出现但无资金过剩，则断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大鱼吃小鱼，水多鱼多，大鱼更容易吞并小鱼

### 🔗 文字版因果链

1. 狂热阶段产生大量闲置资金
2. 资金寻求高回报投资机会
3. 通过收购和兼并吞并竞争对手
4. 市场集中度提高，形成垄断或寡头
5. 竞争减弱，利润集中，可能阻碍创新
