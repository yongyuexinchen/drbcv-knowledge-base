> 属于因果簇：[[技术-经济范式演进的四阶段因果模型]]（第5块/5块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 范式成熟和市场饱和 |
| **DV（因变量）** | 成熟阶段（增长放缓、社会质疑、下一次革命酝酿） |
| **Chain（传导链）** | 最晚出现的技术体系和产品生命周期缩短 → 市场逐渐饱和，利润受生产力瓶颈制约 → 企业通过并购、出口和转移业务维持利润 → 社会对资本主义制度提出深刻质疑 → 对新技术解决方案的探求突破现有范式逻辑 → 下一次技术革命舞台搭建就绪 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 主要产业出现萎缩的投资机会和停滞的市场 |
| **前提与约束（Premises）** | 范式潜力已充分展开；社会对进步承诺的期待未完全兑现；存在未满足的社会需求 |
| **Falsification（证伪条件）** | 如果范式成熟后未出现增长放缓和社会质疑，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 最晚出现的技术体系和产品生命周期缩短
2. 市场逐渐饱和，利润受生产力瓶颈制约
3. 企业通过并购、出口和转移业务维持利润
4. 社会对资本主义制度提出深刻质疑
5. 对新技术解决方案的探求突破现有范式逻辑
6. 下一次技术革命舞台搭建就绪
