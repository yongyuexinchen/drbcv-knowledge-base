# 转折点（监管改革、制度重构）

> 属于因果簇：[[技术-经济范式演进的四阶段因果模型]]（第3块/5块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 狂热阶段积累的结构性紧张关系（金融泡沫破裂、社会动荡） |
| **DV（因变量）** | 转折点（监管改革、制度重构） |
| **Chain（传导链）** | 金融泡沫破裂引发经济衰退 → 社会动荡和抗议活动加剧 → 决策者认识到现有做法不可持续 → 制定、实施和接受监管措施的条件成熟 → 确立新的增长模式，从金融标准转向生产能力标准 |
| **Lag（时滞）** | 短期至中期（数月到数年） |
| **Threshold（临界值）** | 金融泡沫破裂且经济衰退严重到足以迫使政策转向 |
| **前提与约束（Premises）** | 存在社会力量推动改革；决策者愿意接受替代方案；结构性紧张关系无法通过旧方法解决 |
| **Falsification（证伪条件）** | 如果金融泡沫破裂后未出现制度重构，而是回到原有模式，则该断言不成立 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大病之后必须调整生活方式，否则旧病复发

### 🔗 文字版因果链

1. 金融泡沫破裂引发经济衰退
2. 社会动荡和抗议活动加剧
3. 决策者认识到现有做法不可持续
4. 制定、实施和接受监管措施的条件成熟
5. 确立新的增长模式，从金融标准转向生产能力标准
