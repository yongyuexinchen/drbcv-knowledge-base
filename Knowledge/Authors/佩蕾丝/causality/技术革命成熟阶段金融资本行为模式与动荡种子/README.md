# 技术革命成熟阶段金融资本行为模式与动荡种子（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：技术革命成熟阶段金融资本行为模式与动荡种子.md

## 总体因果图

- 技术革命进入成熟阶段（范式扩张接近极限，核心产业增长乏力） → 金融资本放贷标准放宽，信贷扩张至弱质借款人，积累坏账并酝酿债
- 成熟阶段核心市场饱和、利润率下降 → 企业通过并购、寡头垄断和多元化收购来维持利润，形成资本集中
- 成熟阶段国内投资机会减少、金融资本过剩 → 资本向边缘国家外流，推动基础设施建设和生产转移，同时为边缘国
- 成熟阶段金融资本过剩、传统投资渠道收益下降 → 金融资本转向非传统操作（投机、避税、汇率操纵），导致金融异化
- 旧范式成熟阶段投资机会耗竭、金融资本寻求新出路 → 金融资本开始资助新技术探索，为下一次技术革命创造条件
