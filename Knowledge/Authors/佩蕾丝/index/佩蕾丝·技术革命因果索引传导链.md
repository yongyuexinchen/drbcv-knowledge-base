## 主传导链

```
重大技术突破（蒸汽/电力/汽车/信息/AI...）
        │
        ▼
技术-经济范式建立（新产业+新基础设施+新组织方式）
        │
        ▼
金融资本与生产资本联姻 → 爆发阶段（核心产业+基础设施投资潮）
        │
        ▼
狂热阶段：金融资本主导 → 资产泡沫 + 两极分化
        │
        ├──→ 泡沫破裂（转折点）→ 衰退/调整
        │
        ▼
制度重构（监管/法规/社会契约）→ 协同阶段（黄金时代）
        │
        ▼
范式成熟 → 收益递减 → 下一轮技术革命（巨潮更替）
```

## 不变式

1. **范式是因果母机**：技术革命不是孤立的，它重构整个经济范式（产业/组织/制度）
2. **金融资本双面性**：联姻时是引擎（爆发），主导时是灾难（狂热泡沫）
3. **转折点由制度决定**：泡沫破裂后是否进入黄金时代，取决于制度重构（监管/社会契约）
