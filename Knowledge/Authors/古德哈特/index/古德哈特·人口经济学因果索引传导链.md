## 主传导链（全书核心论点骨架）

```
[过去 30 年：人口"甜头"]
劳动年龄人口激增（中国2.4亿+东欧1.1亿） + 全球化劳动力供给翻倍
        │
        ▼
储蓄供给充足 + 工资被压制 → 通胀低 + 实际利率低（被全球化压制）
        │
        ▼
[现在：大逆转开启]
老龄化加速 + 中国"历史性动员"终结 + 逆全球化
        │
        ▼
劳动力供给收缩 + 抚养比上升 + 储蓄率下降
        │
        ├──→ 通胀卷土重来（第5章）
        │         │
        │         ▼
        │   名义利率上升（预期滞后数年调整）──→ 实际利率上升（第6章）
        │
        ├──→ 增长放缓（抚养比上升，第3章）
        │
        └──→ 社会层面：不平等缩小 / 民粹消退（第7章，未精读）
        │
        ▼
[日本案例：为什么过去没发生？]（第9章）
日本人口先老 → 但国内投资收缩更快 → 储蓄>投资 → 利率仍低
（例外不证伪：投资侧收缩对冲了储蓄侧收缩）
```

## 底层框架不变式（古德哈特的固定前提）

1. **储蓄-投资均衡决定长期利率**：实际利率是人口结构（储蓄侧）与投资需求的均衡结果——不是央行决定的
2. **人口是慢变量之母**：人口结构变化是通胀、利率、不平等的底层驱动，周期政策只是表层
3. **"甜头"不可持续**：全球化+人口红利带来的低通胀低利率是历史性例外，不是常态
4. **政策会滞后**：名义利率对通胀的响应有数年滞后，期间实际利率可能先降后升

## 跨作者交叉点（🔴 融合研判素材）

| 变量 | 付鹏（政策端） | 古德哈特（人口端） | 张力 |
|---|---|---|---|
| 实际利率 | 短期由美联储决定（2020趴地板→2021收紧→黄金反转） | 长期由储蓄-投资均衡决定（人口逆转→上行） | **时间尺度不同，结论相反** |
| 通胀 | 供应链错配（2021，周期视角） | 人口结构（长期，结构性视角） | 短周期 vs 长结构 |

**研判提示**：付鹏"政策决定实际利率"与古德哈特"人口决定实际利率"不是谁对谁错——是**短期套利逻辑 vs 长期配置逻辑**。2020-2022 付鹏对（政策主导），2025+ 若人口逆转主导则古德哈特框架开始生效。这正是"融合研判"要落地的第一个跨作者命题。
