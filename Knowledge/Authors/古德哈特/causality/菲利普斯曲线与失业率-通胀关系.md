# 菲利普斯曲线与失业率-通胀关系

> **领域**：宏观经济学　|　**来源**：chapter_36.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 失业率 |
| **DV（因变量）** | 工资或价格变动率（通胀率） |
| **Chain（传导链）** | 失业率较低时，劳动力需求大于供给，雇主为吸引劳动力提高工资，导致价格上升 → 失业率较高时，劳动力供给超过需求，工资面临下行压力，价格下降 → 短期通胀预期固定，失业率与通胀负相关；长期预期适应后，失业率回到自然率，通胀不再受失业率影响 |
| **Lag（时滞）** | 短期：即时或数月；长期：预期完全适应，可能数年 |
| **Threshold（临界值）** | 自然失业率（NAIRU）：失业率低于此值，通胀加速；高于此值，通胀减速 |
| **前提与约束（Premises）** | 劳动力市场存在摩擦和异质性；通胀预期在短期内相对固定；长期中预期完全适应；适用于发达经济体，且需考虑人口结构、工会力量等制度因素 |
| **Falsification（证伪条件）** | 若在失业率持续低于自然率时通胀率不上升，或失业率大幅变动而通胀率保持稳定（如2007-2020年），则短期或长期菲利普斯曲线关系可能失效 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像弹簧：短期拉长（低失业）会弹回（通胀上升），但长期弹簧本身长度（自然失业率）不变，除非改变弹簧材质（供给侧因素）

### 🔗 文字版因果链

1. 失业率较低时，劳动力需求大于供给，雇主为吸引劳动力提高工资，导致价格上升
2. 失业率较高时，劳动力供给超过需求，工资面临下行压力，价格下降
3. 短期通胀预期固定，失业率与通胀负相关；长期预期适应后，失业率回到自然率，通胀不再受失业率影响
