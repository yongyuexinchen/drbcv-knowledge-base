# 欧洲银行跨境贷款大幅减少（去杠杆）

> 属于因果簇：[[债务陷阱的形成与锁定机制]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 全球金融危机后银行监管要求提高资本充足率（CARs） |
| **DV（因变量）** | 欧洲银行跨境贷款大幅减少（去杠杆） |
| **Chain（传导链）** | 当局要求银行保持更高的资本充足率 → 欧洲缺乏公共资金为资本不足的银行注资，压力测试不可信 → 银行选择通过去杠杆（减少资产和存款负债）而非筹集新股来满足资本要求 → 当局向国内银行施压维持对当地借款人的贷款 → 银行减少跨境贷款，导致跨境贷款大幅减少 |
| **Lag（时滞）** | 危机后数年内 |
| **Threshold（临界值）** | 当银行无法通过筹集新股满足资本充足率要求，且股票市场疲软时 |
| **前提与约束（Premises）** | 欧洲没有类似美国TARP的公共资金为银行注资；银行家关注净资产收益率，倾向于去杠杆而非股权融资；当局显性或隐性地要求银行维持国内贷款 |
| **Falsification（证伪条件）** | 如果欧洲银行在资本充足率提高后仍能维持或增加跨境贷款，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭被要求降低负债率，但没有外部资金支持，只能卖掉海外资产、减少对外投资，导致海外业务大幅收缩

### 🔗 文字版因果链

1. 当局要求银行保持更高的资本充足率
2. 欧洲缺乏公共资金为资本不足的银行注资，压力测试不可信
3. 银行选择通过去杠杆（减少资产和存款负债）而非筹集新股来满足资本要求
4. 当局向国内银行施压维持对当地借款人的贷款
5. 银行减少跨境贷款，导致跨境贷款大幅减少
