# 日本人口结构变化与全球劳动力市场的因果分析（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：日本人口结构变化与全球劳动力市场的因果分析.md

## 总体因果图

- 日本国内劳动力供给减少 → 日本企业增加对外直接投资（FDI）
- 日本国内劳动力减少 → 日本总产出增长缓慢但人均产出（生产率）增长较快
- 日本国内劳动力市场疲软（隐性失业） → 菲利普斯曲线平坦（工资增长停滞，即使失业率低）
- 中国自20世纪90年代以来的崛起（全球劳动力供给增加） → 日本经济表现（通缩、低利率、低工资增长）
