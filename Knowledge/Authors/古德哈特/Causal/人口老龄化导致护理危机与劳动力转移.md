# 人口老龄化导致护理危机与劳动力转移

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 预期寿命提高导致老年人口中痴呆及依赖性病症（如帕金森病、关节炎）比例上升 |
| **DV（因变量）** | 更高比例的劳动力投入护理老人工作（作为家人或护工） |
| **Chain（传导链）** | 预期寿命提高，老年人口比例增加 → 老年人口中痴呆、帕金森病、关节炎等导致依赖性的病症多发 → 这些病症需要外部护理和情感支持 → 护理需求增加，机器人无法替代情感支持 → 更多劳动力从其他生产性活动转向护理工作 |
| **Lag（时滞）** | 数十年（随人口年龄结构变化逐步显现） |
| **Threshold（临界值）** | 当老年抚养比超过一定水平（如65岁以上人口占比显著上升）时，护理需求急剧增加 |
| **前提与约束（Premises）** | 护理包括个人情感支持，机器人无法完全替代；痴呆等病症的医疗进步（如药物）尚未根本改变护理需求；家庭和社会倾向于由人力提供护理 |
| **Falsification（证伪条件）** | 如果出现有效预防或治愈痴呆等依赖性病症的医疗突破，或机器人能提供情感支持，则此因果链可能减弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭中老人增多，子女不得不减少工作来照顾他们，家庭总收入下降，但护理支出上升。

### 🔗 文字版因果链

1. 预期寿命提高，老年人口比例增加
2. 老年人口中痴呆、帕金森病、关节炎等导致依赖性的病症多发
3. 这些病症需要外部护理和情感支持
4. 护理需求增加，机器人无法替代情感支持
5. 更多劳动力从其他生产性活动转向护理工作
