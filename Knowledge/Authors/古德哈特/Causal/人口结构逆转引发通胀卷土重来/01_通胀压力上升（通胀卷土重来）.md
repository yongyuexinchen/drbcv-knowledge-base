# 通胀压力上升（通胀卷土重来）

> 属于因果簇：[[人口结构逆转引发通胀卷土重来]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口结构逆转（劳动力短缺，工人议价能力增强） |
| **DV（因变量）** | 通胀压力上升（通胀卷土重来） |
| **Chain（传导链）** | 人口结构逆转导致劳动力短缺 → 劳动力短缺增强工人的议价能力 → 工人利用较强的议价能力争取更高的工资 → 工资上涨推高生产成本和消费能力 → 整体价格水平上升，通胀压力再度抬头 |
| **Lag（时滞）** | 中期（数年至数十年，随人口结构变化逐步显现） |
| **Threshold（临界值）** | 劳动力供给显著低于需求，工人议价能力足以扭转工资停滞状态 |
| **前提与约束（Premises）** | 社会保障体系仍将存在，老年人依赖政府援助，消费年龄分布曲线保持平坦或向上倾斜；为实现从工人向老年人的资源转移，必须显著提高对工人的征税税率；发达经济体（以及一些新兴经济体）出现劳动力短缺；排除大规模移民或自动化技术完全替代劳动力的情况 |
| **Falsification（证伪条件）** | 如果劳动力短缺出现但工资水平持续停滞，或通胀率在人口老龄化加深时反而持续下降，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像劳动力市场上供不应求时，工人像稀缺的明星球员一样可以要求更高的转会费和薪水，推高整个球队的运营成本，最终导致票价上涨。

### 🔗 文字版因果链

1. 人口结构逆转导致劳动力短缺
2. 劳动力短缺增强工人的议价能力
3. 工人利用较强的议价能力争取更高的工资
4. 工资上涨推高生产成本和消费能力
5. 整体价格水平上升，通胀压力再度抬头
