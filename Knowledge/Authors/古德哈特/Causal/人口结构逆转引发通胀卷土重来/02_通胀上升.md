# 通胀上升

> 属于因果簇：[[人口结构逆转引发通胀卷土重来]]（第2块/2块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口老龄化（工人与被抚养者比例失衡） |
| **DV（因变量）** | 通胀上升 |
| **Chain（传导链）** | 人口老龄化导致工人数量相对减少，被抚养者（老年人和年轻人）比例上升 → 工人的产出大于自身消费，而被抚养者消费大于产出 → 工人与被抚养者之间的平衡被打破，社会总储蓄下降、消费需求结构变化 → 为实现资源从工人向老年人的转移，需提高税率或增加政府支出 → 政府支出增加和工资上涨共同推高通胀 |
| **Lag（时滞）** | 长期（人口结构变化缓慢，效应在数十年内逐步显现） |
| **Threshold（临界值）** | 劳动年龄人口占比下降至关键水平，抚养比显著上升 |
| **前提与约束（Premises）** | 社会保障体系持续存在，老年人依赖政府转移支付；老年人不会为更长寿命进行大量储蓄；政府通过征税实现资源转移，而非大幅削减福利 |
| **Falsification（证伪条件）** | 如果老龄化加深但政府通过削减福利或移民政策有效平衡抚养比，且通胀未上升，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个家庭中赚钱的年轻人越来越少，而需要花钱的老人和孩子越来越多，家庭必须动用储蓄或借债，最终导致家庭财务压力增大，物价上涨。

### 🔗 文字版因果链

1. 人口老龄化导致工人数量相对减少，被抚养者（老年人和年轻人）比例上升
2. 工人的产出大于自身消费，而被抚养者消费大于产出
3. 工人与被抚养者之间的平衡被打破，社会总储蓄下降、消费需求结构变化
4. 为实现资源从工人向老年人的转移，需提高税率或增加政府支出
5. 政府支出增加和工资上涨共同推高通胀
