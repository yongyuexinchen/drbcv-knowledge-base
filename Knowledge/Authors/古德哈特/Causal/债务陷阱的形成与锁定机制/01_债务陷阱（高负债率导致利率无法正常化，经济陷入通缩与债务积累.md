# 债务陷阱（高负债率导致利率无法正常化，经济陷入通缩与债务积累

> 属于因果簇：[[债务陷阱的形成与锁定机制]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 长期低利率政策 |
| **DV（因变量）** | 债务陷阱（高负债率导致利率无法正常化，经济陷入通缩与债务积累的循环） |
| **Chain（传导链）** | 长期低利率鼓励经济主体加杠杆，导致资本错配 → 经济增长改善或金融稳定担忧促使央行加息 → 利率上升损害经济增长，推高债务偿付压力 → 为防止衰退，央行被迫再次降息，债务进一步积累 → 高负债率使利率无法大幅或快速上升，否则引发债务偿付危机 → 债务陷阱形成并自我强化 |
| **Lag（时滞）** | 数年至数十年（从低利率政策到债务陷阱形成） |
| **Threshold（临界值）** | 当主要宏观经济部门（非金融企业、居民、公共部门）的负债率高到利率的任何大幅或快速上升都会使大部分私人部门陷入债务偿付危机时 |
| **前提与约束（Premises）** | 财政政策受约束，无法充分扩张以抵消通缩压力；货币政策被迫持续扩张，利率接近有效下限；债务规模上升几乎完全与利率下降相当，偿债率保持稳定；企业高管关注净资产收益率，偏好债务融资而非股权融资 |
| **Falsification（证伪条件）** | 如果观察到高负债率国家能够在不引发债务危机的情况下实现利率正常化，且经济持续增长，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个人靠信用卡维持生活，债务越滚越大，一旦银行要求提高还款额（加息），就会破产，因此银行只能继续降低利率让他借新还旧，最终陷入债务泥潭无法自拔

### 🔗 文字版因果链

1. 长期低利率鼓励经济主体加杠杆，导致资本错配
2. 经济增长改善或金融稳定担忧促使央行加息
3. 利率上升损害经济增长，推高债务偿付压力
4. 为防止衰退，央行被迫再次降息，债务进一步积累
5. 高负债率使利率无法大幅或快速上升，否则引发债务偿付危机
6. 债务陷阱形成并自我强化
