# 非金融企业债务进一步积累

> 属于因果簇：[[债务陷阱的形成与锁定机制]]（第3块/4块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 量化宽松（QE）和官方负利率政策 |
| **DV（因变量）** | 非金融企业债务进一步积累 |
| **Chain（传导链）** | 全球金融危机后财政政策受限，货币政策被迫更具扩张性 → 量化宽松和官方负利率成为唯一选择 → 极低利率环境有利于非金融企业债务的延续 → 低利率加快债务积累速度，企业债务规模上升 |
| **Lag（时滞）** | 2009年第一轮QE后持续数年 |
| **Threshold（临界值）** | 当利率接近有效下限且企业债务融资成本低于股权融资成本时 |
| **前提与约束（Premises）** | 财政政策受限制，无法充分扩张；通胀和名义利率预计将再次上升但尚未实现；企业高管关注净资产收益率，偏好债务融资 |
| **Falsification（证伪条件）** | 如果量化宽松和负利率政策导致企业去杠杆而非加杠杆，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同给一个已经负债累累的人提供更低利率的贷款，他不仅不会还清旧债，反而会借更多新债来维持生活

### 🔗 文字版因果链

1. 全球金融危机后财政政策受限，货币政策被迫更具扩张性
2. 量化宽松和官方负利率成为唯一选择
3. 极低利率环境有利于非金融企业债务的延续
4. 低利率加快债务积累速度，企业债务规模上升
