# 从债权融资转向股权融资的因果分析（因果簇）

> 因果簇索引：6 个子因果卡。父卡文件：从债权融资转向股权融资的因果分析.md

## 总体因果图

- 大幅调增股权融资的财务优势，降低债权融资的财务优势 → 实现债权融资向股权融资的转变，形成新的融资平衡
- 住房抵押贷款中引入股权融资元素（如共享增值抵押贷款） → 家庭住房融资从固定利息债务转向更接近股权融资的模式
- 学生贷款从固定利息债务转向基于股权的融资模式（如收入比例贷款） → 学生融资成本与未来收入挂钩，降低固定债务负担
- 公共部门发行名义收入债券（与GDP或名义收入挂钩） → 公共部门融资从固定利息债务转向更接近股权融资的模式
- 纠正债权融资相对于股权融资的财务优势（如税收、监管待遇） → 企业部门从债权融资转向股权融资
- 股权持有人的有限责任与经理人激励机制的统一 → 短期主义行为减少，投资水平提高
