# 学生融资成本与未来收入挂钩，降低固定债务负担

> 属于因果簇：[[从债权融资转向股权融资的因果分析]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 学生贷款从固定利息债务转向基于股权的融资模式（如收入比例贷款） |
| **DV（因变量）** | 学生融资成本与未来收入挂钩，降低固定债务负担 |
| **Chain（传导链）** | 贷款机构提供基于学生未来应税收入比例的融资工具 → 学生选择此类贷款，还款额随收入变化 → 学生毕业后收入高则还款多，收入低则还款少，降低违约风险 → 学生融资结构更接近股权融资 |
| **Lag（时滞）** | 长期（10-20年），涉及学生整个职业生涯 |
| **Threshold（临界值）** | 收入比例贷款的还款比例设定合理，且对高收入学生具有约束力 |
| **前提与约束（Premises）** | 贷款机构能够有效追踪学生未来收入；政策允许或强制要求此类融资模式；避免富裕学生因预期高还款而放弃高等教育；累进再分配功能被社会接受 |
| **Falsification（证伪条件）** | 如果收入比例贷款导致学生总体融资成本高于固定利息贷款，或学生选择率极低，则该断言不成立 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同政府征收累进所得税，收入高者多缴，收入低者少缴，而非固定税负

### 🔗 文字版因果链

1. 贷款机构提供基于学生未来应税收入比例的融资工具
2. 学生选择此类贷款，还款额随收入变化
3. 学生毕业后收入高则还款多，收入低则还款少，降低违约风险
4. 学生融资结构更接近股权融资
