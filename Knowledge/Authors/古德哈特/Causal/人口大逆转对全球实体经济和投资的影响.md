# 人口大逆转对全球实体经济和投资的影响

> **领域**：宏观经济学、人口经济学　|　**来源**：demog_ch01_intro.txt　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人口结构逆转（从人口红利转向人口负债） |
| **DV（因变量）** | 全球通胀、工资、名义利率上升，生产率提高，劳动力份额增加，不平等缩小 |
| **Chain（传导链）** | 人口结构逆转导致劳动力供给减少，劳动力稀缺性上升 → 劳动力稀缺推动工资上涨，进而推高通胀 → 通胀上升迫使央行提高名义利率 → 劳动力稀缺促使企业增加资本投入和技术创新，提高生产率 → 劳动力份额在国民产出中上升，资本回报相对下降，收入分配改善，不平等缩小 |
| **Lag（时滞）** | 中期至长期（数年至数十年） |
| **Threshold（临界值）** | 人口结构转折点（如劳动年龄人口占比见顶回落） |
| **前提与约束（Premises）** | 人口结构逆转是持续性的，而非短期波动；政策制定者未能及时应对人口变化；金融市场未充分预期人口趋势的转变；全球范围内人口结构变化同步发生或相互影响 |
| **Falsification（证伪条件）** | 如果人口结构逆转后，通胀和工资没有上升，或名义利率下降，或生产率未提高，或不平等未缩小，则该断言被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像果园里果树数量减少，果实变得稀缺，价格上升；果农为了增产会采用更先进的技术，果实质量提高，但果园的收益分配更偏向劳动者。

### 🔗 文字版因果链

1. 人口结构逆转导致劳动力供给减少，劳动力稀缺性上升
2. 劳动力稀缺推动工资上涨，进而推高通胀
3. 通胀上升迫使央行提高名义利率
4. 劳动力稀缺促使企业增加资本投入和技术创新，提高生产率
5. 劳动力份额在国民产出中上升，资本回报相对下降，收入分配改善，不平等缩小
