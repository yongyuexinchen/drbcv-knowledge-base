# 人口结构逆转对全球经济增长的因果影响

> **领域**：宏观经济学、人口经济学　|　**来源**：demog_ch03_growth.txt　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 劳动年龄人口增速放缓与抚养比上升（人口结构逆转） |
| **DV（因变量）** | 全球经济增长潜力下降（产出增长放缓） |
| **Chain（传导链）** | 生育率下降且寿命延长导致老龄人口占比上升 → 劳动年龄人口增速放缓，劳动力供给增长趋缓 → 老年抚养比上升，社会负担加重，储蓄率可能下降 → 资本积累和劳动生产率增长受到制约 → 总产出增速和潜在增长率下降 |
| **Lag（时滞）** | 约10-20年（从生育率下降到劳动年龄人口减少的时滞） |
| **Threshold（临界值）** | 抚养比拐点出现，即劳动年龄人口占比停止上升并开始下降 |
| **前提与约束（Premises）** | 生育率持续低于更替水平且无显著回升；寿命延长趋势持续；移民等外部劳动力补充不足以抵消人口结构变化；适用于发达经济体和部分新兴市场（如中国、德国） |
| **Falsification（证伪条件）** | 如果劳动年龄人口增速放缓但生产率大幅提升，或自动化替代劳动力，导致产出增长未下降，则该断言被削弱 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个家庭中，如果赚钱的年轻人减少而需要赡养的老人增多，家庭总收入增长就会变慢，甚至可能下降。

### 🔗 文字版因果链

1. 生育率下降且寿命延长导致老龄人口占比上升
2. 劳动年龄人口增速放缓，劳动力供给增长趋缓
3. 老年抚养比上升，社会负担加重，储蓄率可能下降
4. 资本积累和劳动生产率增长受到制约
5. 总产出增速和潜在增长率下降
