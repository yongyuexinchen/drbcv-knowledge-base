# 人口大逆转与不平等及民粹主义兴起（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：人口大逆转与不平等及民粹主义兴起.md

## 总体因果图

- 中国等亚洲国家融入世界贸易体系（全球化） → 全球不平等水平下降（国家间不平等缩小）
- 全球化（中国效应）与有利人口趋势结合导致有效劳动力供给空前增长 → 西方发达经济体下层中产阶级经济状况恶化
- 左翼领导人与蓝领工人在移民问题上的态度分歧 → 蓝领工人转向支持右翼民粹主义而非左翼社会主义
