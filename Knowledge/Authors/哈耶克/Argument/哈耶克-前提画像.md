# 哈耶克 · 前提画像（世界观公理）

> 用途：理解哈耶克全部结论的**地基**。他所有论断（政府干预→奴役、市场优于计划）都从这五条前提推出。
> **读法**：前提成立 → 结论成立；前提被攻破 → 全楼摇晃。

## 前提体系（五层公理）

| 层 | 前提 | 一句话 |
|---|---|---|
| 人性观 | 个人理性有限，但**个人利益动机可靠** | 人不可能全知，但都知道自己最想要什么 |
| 知识观 | **知识分散于个体**，价格是知识传递机制 | 没有任何一个大脑能掌握全部信息，只有市场能 |
| 社会观 | 社会是**自发秩序**（语言/货币/法律皆演化产物） | 好东西都是长出来的，不是设计出来的 |
| 历史观 | 20 世纪极权 = **计划经济的必然结果** | 德国纳粹不是偶然，是集体主义逻辑走到头 |
| 国家观 | 最小国家（守夜人）：只保契约与规则 | 政府是裁判，不是运动员 |

## 推导链（前提 → 结论）

```
知识分散（前提2）→ 集中计划不可行（推论）
     ↓
自发秩序优于设计秩序（前提3）→ 社会主义=伪科学（推论）
     ↓
政府干预积累权力 → 权力集中 → 奴役（前提1+4+5 → 核心结论《通往奴役之路》）
```

**核心断言**：政府每多管一件事，就多拿走一分自由；管到底就是奴役。

## 与其他作者的前提冲突（第 2 集辩论地图）

| 对立面 | 冲突点 | 冲突的层 |
|---|---|---|
| **波兰尼** | 自发秩序 vs **社会建构**（市场是人造的制度） | 社会观（最深层） |
| 凯恩斯 | 政府该不该干预（萧条时） | 国家观 |
| 明斯基 | 市场是否内生不稳定（明斯基：是） | 人性观/市场观 |
| 温铁军 | 中国语境：市场自由化 vs 去依附 | 历史观/国家观 |

## 前提的证据评估（批判性视角）

| 前提 | 支持证据 | 反例/软肋 |
|---|---|---|
| 知识分散 | 苏联计划经济失败；价格机制效率 | 现代大公司内部"计划"也很成功（企业内部非市场） |
| 自发秩序 | 语言/货币演化 | 市场自由化也有灾难案例（拉美休克疗法） |
| 计划→奴役 | 纳粹/斯大林 | 北欧混合经济并未走向奴役（反例常被忽略） |
| 最小国家 | 自由市场繁荣 | 2008 年金融危机=市场失灵，靠国家救 |

## 立场底色（政商关系/阶级）
- 学术谱系：奥地利学派（米塞斯 → 哈耶克）→ 芝加哥学派部分继承
- 立场：**市场精英/资本**（他的理论为自由放任辩护）
- 政商：伦敦经济学院/芝加哥大学；撒切尔主义的精神导师（⚠ 他本人未直接参政）
