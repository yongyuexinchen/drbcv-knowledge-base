# 自由受损

> 属于因果簇：[[法律面前平等与物质平等之冲突]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 追求物质平等（平均主义） |
| **DV（因变量）** | 自由受损 |
| **Chain（传导链）** | 平均主义要求消除因环境（家庭、遗产、教育）造成的不平等 → 为实现此目标，国家必须使用有差别的强制手段，控制与个人前途相关的所有条件 → 这种控制使个人选择空间缩小，最终导向奴役，损害自由 |
| **Lag（时滞）** | 长期，随着干预加深而逐渐显现 |
| **Threshold（临界值）** | 当国家开始对个人能力进行统一评估和分配时，自由即开始受损 |
| **前提与约束（Premises）** | 平均主义要求超越法律平等，追求结果平等；国家有能力也有意愿控制个人发展条件；自由社会反对任何有意的分配方案，无论平等与否 |
| **Falsification（证伪条件）** | 若证明在高度干预下个人自由仍能保持（如某些高福利国家），则该断言需修正 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持福利国家和社会民主主义的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如果要求所有树木长得一样高，就必须修剪高枝、扶持矮木，但这会破坏森林的自然生态，最终使所有树木都失去自由生长的空间。

### 🔗 文字版因果链

1. 平均主义要求消除因环境（家庭、遗产、教育）造成的不平等
2. 为实现此目标，国家必须使用有差别的强制手段，控制与个人前途相关的所有条件
3. 这种控制使个人选择空间缩小，最终导向奴役，损害自由
