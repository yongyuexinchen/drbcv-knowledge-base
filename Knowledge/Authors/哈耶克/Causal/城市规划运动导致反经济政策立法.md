## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 城市规划运动（由奥姆斯特德、格迪斯、芒福德等人领导） |
| **DV（因变量）** | 反经济的法律和政策（如没收全部开发收益） |
| **Chain（传导链）** | 城市规划者形成反经济的理念和蓝图 → 战争期间经济学家忙于战争任务，无暇顾及立法准备 → 城市规划者利用这一空档推动其理念进入立法议程 → 议会通过法律时缺乏对影响程度的理解，无人预见后果 → 主管部长利用法律赋予的权力下令没收全部开发收益 |
| **Lag（时滞）** | 短期（战争期间至立法通过后） |
| **Threshold（临界值）** | 无明确量化阈值，但前提是经济学家缺席立法准备阶段 |
| **前提与约束（Premises）** | 战争期间经济学家被战争任务占据，无法参与立法；议会成员对法律影响缺乏理解；城市规划者有能力在立法空档期施加影响 |
| **Falsification（证伪条件）** | 如果战争期间经济学家仍积极参与立法准备，或者议会成员充分理解法律影响，则此因果链不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | plausible |

### 🔗 文字版因果链

1. 城市规划者形成反经济的理念和蓝图
2. 战争期间经济学家忙于战争任务，无暇顾及立法准备
3. 城市规划者利用这一空档推动其理念进入立法议程
4. 议会通过法律时缺乏对影响程度的理解，无人预见后果
5. 主管部长利用法律赋予的权力下令没收全部开发收益
