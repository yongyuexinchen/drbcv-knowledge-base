# 一般性法律规则通过社会秩序促进公共利益

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循一般性法律规则（而非针对特定情况的个别命令） |
| **DV（因变量）** | 社会和平与秩序，进而促进公共利益和整体福利 |
| **Chain（传导链）** | 一般性规则为所有社会成员提供稳定的行为预期 → 稳定的预期减少冲突和不确定性，形成社会和平与秩序 → 社会和平与秩序使分工合作成为可能，提高整体效率 → 整体效率的提升补偿个别情况下规则可能造成的不公，最终促进公共利益 |
| **Lag（时滞）** | 长期（规则需持续贯彻，效果在时间中累积显现） |
| **Threshold（临界值）** | 规则必须是一般性的、固定不变的，且被社会整体或大多数所赞同 |
| **前提与约束（Premises）** | 规则适用于所有人和所有情况，不因个人特性或处境而改变；社会成员普遍遵守规则，且规则被持续贯彻；个别情况下的弊端被整体利益所补偿，且这种补偿是充分的 |
| **Falsification（证伪条件）** | 如果能够证明在一般性规则下，社会整体福利长期低于无规则或个别化裁决的社会，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张根据具体情况灵活裁决以实现最大效用的功利主义（如行为功利主义）存在冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 交通规则：红灯停绿灯行看似在个别情况下（如深夜无车时）造成不便，但整体上避免了混乱和事故，使所有人受益。

### 🔗 文字版因果链

1. 一般性规则为所有社会成员提供稳定的行为预期
2. 稳定的预期减少冲突和不确定性，形成社会和平与秩序
3. 社会和平与秩序使分工合作成为可能，提高整体效率
4. 整体效率的提升补偿个别情况下规则可能造成的不公，最终促进公共利益
