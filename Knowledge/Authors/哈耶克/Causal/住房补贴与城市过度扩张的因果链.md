# 住房补贴与城市过度扩张的因果链

> **领域**：宏观经济学、城市经济学　|　**来源**：哈耶克_chapter_86_part_01_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府提供住房补贴（或公共住房） |
| **DV（因变量）** | 城市规模超出经济合理性的过度扩张，以及受益者对当局的依赖 |
| **Chain（传导链）** | 政府以低于成本的价格提供住房，降低了特定群体的居住成本 → 这刺激了更多人口迁入城市，因为迁入的私人收益高于私人成本 → 城市人口增加，对住房和基础设施的需求进一步上升 → 政府为满足新增需求，不得不继续扩大补贴和公共住房供给 → 最终导致城市规模超过经济合理性，且受益者形成对当局的依赖 |
| **Lag（时滞）** | 长期（数年至数十年） |
| **Threshold（临界值）** | 当补贴使住房价格低于市场均衡价格，且补贴范围扩大到一定比例人口时 |
| **前提与约束（Premises）** | 补贴只针对部分群体，且住房供给不能完全替代私人供给；政府无法有效限制补贴对象的范围，存在政治压力使补贴扩大；城市存在从贫困地区迁入的潜在人口 |
| **Falsification（证伪条件）** | 如果数据显示，在长期内补贴没有导致城市人口显著增加，或者城市规模没有超出经济合理性，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张通过补贴改善穷人住房的福利经济学观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同给植物过度浇水，短期内看似茂盛，但长期会导致根部腐烂，整个生态系统失衡。

### 🔗 文字版因果链

1. 政府以低于成本的价格提供住房，降低了特定群体的居住成本
2. 这刺激了更多人口迁入城市，因为迁入的私人收益高于私人成本
3. 城市人口增加，对住房和基础设施的需求进一步上升
4. 政府为满足新增需求，不得不继续扩大补贴和公共住房供给
5. 最终导致城市规模超过经济合理性，且受益者形成对当局的依赖
