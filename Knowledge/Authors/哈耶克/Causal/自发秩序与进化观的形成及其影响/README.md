# 自发秩序与进化观的形成及其影响（因果簇）

> 因果簇索引：18 个子因果卡。父卡文件：自发秩序与进化观的形成及其影响.md

## 总体因果图

- 亚当·斯密和亚当·弗格森对自发秩序和选择进化观点的系统运用 → 取代静态的亚里士多德观点，形成进化观的突破
- 达尔文在1838年阅读亚当·斯密 → 达尔文做出决定性的突破（形成进化论）
- 18世纪苏格兰道德哲学家建立进化理论 → 产生控制论、一般系统论、协同论、自动生成论等学科变种，并促进
- 卡尔·门格尔认识到生成因素与理论知识的认识不可分 → 将进化观点变成研究复杂现象的主要工具
- 进化论观点的传播 → 影响研究发展，使科学界将世界视为结构和秩序的世界
- 亚当·斯密提供的范式 → 成为许多科学工作分支的威力强大的工具
- 进化观的人文学科来源（如“genetic”一词的借用） → 促进生物学进化理论的发展
- 边际革命（19世纪70年代） → 提供对市场过程的满意解释，取代穆勒父子的单一因果判断
- 约翰·穆勒的教条主义信念（价值规律无需再澄清） → 阻碍了对价格指导作用的理解，导致边际革命产生爆炸性效果
- 马克思主义经济学试图从单一因果角度解释复杂交往秩序 → 未能解释复杂现象，不如自我调控过程有效
- 结构能够通过摹写形成（自我恒久化的演化结构） → 产生时间之箭，出现过去未曾存在的特征
- 群体行为模式通过一代传给下一代 → 秩序保留一般特征，通过不断变化适应
- 卢梭对自然（本能）的肯定 → 导致对文明规则的否定，产生异化、逃避现实和寄生虫式要求
- 社会主义教义（无论有无劳绩都拥有权利） → 教唆人们破坏法律，破坏扩展秩序的道德规范
- 游戏中的规则 → 产生自发秩序，促进生产力全面增长
- 更大的人口密度 → 引起更广泛的劳动分工，增加国家财富
- 人口规模与环境和技术的关系 → 决定经济剩余和社会闲暇的可能性
- 人口调节机制（如生物学家所说） → 调整人口数量使其与领土承受力长期均衡
