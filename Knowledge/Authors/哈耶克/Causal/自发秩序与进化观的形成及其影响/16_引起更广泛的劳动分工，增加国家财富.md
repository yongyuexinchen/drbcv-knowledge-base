# 引起更广泛的劳动分工，增加国家财富

> 属于因果簇：[[自发秩序与进化观的形成及其影响]]（第16块/18块）

## 因果断言 16

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 更大的人口密度 |
| **DV（因变量）** | 引起更广泛的劳动分工，增加国家财富 |
| **Chain（传导链）** | 更大的人口密度 → 导致更广泛的劳动分工 → 提高生产效率，增加财富 |
| **Lag（时滞）** | 短期至长期（人口增长后逐渐显现） |
| **Threshold（临界值）** | 无明确量化阈值（但配第提到八百万人口比四百万富一倍） |
| **前提与约束（Premises）** | 人口增长带来市场扩大；劳动分工受市场规模限制 |
| **Falsification（证伪条件）** | 若能证明人口密度增加未导致劳动分工或财富增加，则断言不成立 |
| **Data（定量佐证）** | 配第提到八百万人口比四百万人口富一倍（定性数据） |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同大城市因人多而分工更细，商品更便宜更好。

### 🔗 文字版因果链

1. 更大的人口密度
2. 导致更广泛的劳动分工
3. 提高生产效率，增加财富
