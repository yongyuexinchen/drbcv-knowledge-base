## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 追求分配公平的政策目标 |
| **DV（因变量）** | 法治的破坏与指令经济的形成 |
| **Chain（传导链）** | 政府设定分配公平目标，要求决定特定人的物质地位 → 为达到目标，政府必须决定个人努力的方向和资源配置 → 这需要中央权威配置资源，无法通过一般性规则实现 → 政府被迫采取厚此薄彼和酌情裁量的做法，围困或漠视法治原则 → 最终导致法治被彻底废弃，代之以指令经济 |
| **Lag（时滞）** | 渐进过程，在具体事例中逐步侵蚀法治 |
| **Threshold（临界值）** | 当政府试图实现分配的公平（区别于交换的公平）时 |
| **前提与约束（Premises）** | 法治要求政府强制手段仅用于执行一般性规则；分配公平要求由中央权威配置资源；政府若对不同人平等对待则结果不平等，若允许自由使用能力则结果不可预料 |
| **Falsification（证伪条件）** | 如果存在一个在法治框架内实现分配公平的可行案例，且未导致指令经济，则该断言可被质疑 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持分配公平的干预主义观点冲突，如罗尔斯等 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像在棋盘游戏中，如果裁判开始决定每个玩家的棋子应该怎么走以追求结果公平，那么游戏规则就被破坏了，最终变成裁判的独裁游戏。

### 🔗 文字版因果链

1. 政府设定分配公平目标，要求决定特定人的物质地位
2. 为达到目标，政府必须决定个人努力的方向和资源配置
3. 这需要中央权威配置资源，无法通过一般性规则实现
4. 政府被迫采取厚此薄彼和酌情裁量的做法，围困或漠视法治原则
5. 最终导致法治被彻底废弃，代之以指令经济
