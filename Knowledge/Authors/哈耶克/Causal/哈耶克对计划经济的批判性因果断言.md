## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划经济（政府集中控制生产资料和分配） |
| **DV（因变量）** | 通往奴役之路（个人自由丧失、极权主义） |
| **Chain（传导链）** | 中央计划需要统一目标，无法协调分散的个体知识 → 为实现计划目标，政府必须强制统一价值观和资源配置 → 经济控制扩展到社会各领域，压制个人选择 → 权力集中导致信息扭曲和决策失误，为维持计划而加强强制 → 最终形成极权体制，个人自由被彻底剥夺 |
| **Lag（时滞）** | 长期过程，通常跨越数十年，随计划深入逐步显现 |
| **Threshold（临界值）** | 当政府控制超过经济活动的关键比例（如生产资料国有化超过50%）时，自由衰退加速 |
| **前提与约束（Premises）** | 仅当计划取代市场机制成为主要协调方式时成立；在知识分散且无法集中汇总的复杂社会中有效；排除小规模、局部计划（如企业内部计划）的情况 |
| **Falsification（证伪条件）** | 若存在中央计划经济国家长期保持高水平个人自由和民主制度的实例，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义及社会主义计划经济支持者（如奥斯卡·兰格）的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 中央计划需要统一目标，无法协调分散的个体知识
2. 为实现计划目标，政府必须强制统一价值观和资源配置
3. 经济控制扩展到社会各领域，压制个人选择
4. 权力集中导致信息扭曲和决策失误，为维持计划而加强强制
5. 最终形成极权体制，个人自由被彻底剥夺
