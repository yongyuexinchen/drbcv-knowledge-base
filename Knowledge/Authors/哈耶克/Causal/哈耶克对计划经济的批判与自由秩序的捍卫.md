## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府对经济的集中计划与干预 |
| **DV（因变量）** | 个人自由受到侵蚀并最终走向奴役 |
| **Chain（传导链）** | 政府集中计划取代分散的市场决策，导致信息无法有效利用 → 计划者需要统一目标，压制个体差异与偏好 → 为执行计划，政府不断扩大权力，限制经济自由 → 经济自由的丧失逐步扩展到政治与社会自由 → 最终形成极权主义，个人沦为计划的工具 |
| **Lag（时滞）** | 长期过程，通常跨越数十年，随干预程度加深而渐进显现 |
| **Threshold（临界值）** | 当政府计划超越维护法治的底线，开始决定资源分配与个人选择时，奴役路径启动 |
| **前提与约束（Premises）** | 仅当计划取代市场机制成为主要资源配置方式时成立；在法治框架内有限度的政府干预不在此列；排除自发秩序能够自我修正的情况 |
| **Falsification（证伪条件）** | 若存在长期高度计划经济但个人自由未受侵蚀的案例，或计划体制下自由反而增强的证据，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证；但可参考20世纪苏联、东欧计划经济的实践作为历史案例 |
| **Conflicts（观点冲突）** | 与凯恩斯主义及部分社会主义理论冲突，后者认为政府干预可促进自由与福利 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同让一个厨师为所有人定制菜单，起初只是限制选择，最终连吃什么、何时吃都由他人决定，个人失去自主权

### 🔗 文字版因果链

1. 政府集中计划取代分散的市场决策，导致信息无法有效利用
2. 计划者需要统一目标，压制个体差异与偏好
3. 为执行计划，政府不断扩大权力，限制经济自由
4. 经济自由的丧失逐步扩展到政治与社会自由
5. 最终形成极权主义，个人沦为计划的工具
