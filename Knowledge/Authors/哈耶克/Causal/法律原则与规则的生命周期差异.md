# 法律原则与规则的生命周期差异

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律原则的相对不变性与规则的可替换性 |
| **DV（因变量）** | 法律体系的稳定性和连续性 |
| **Chain（传导链）** | 法律原则作为推理的出发点，具有相对稳定性或沿不变方向发展 → 法律规则作为具体规定，易被废除或取代，寿命较短 → 原则的稳定性为法律推理提供持久基础，规则的更替适应社会变化 → 因此，法律体系在保持核心价值连续性的同时，能够灵活调整具体规范 |
| **Lag（时滞）** | 长期（原则的稳定性体现在数十年至数百年尺度，规则的更替通常在数年或数十年内发生） |
| **Threshold（临界值）** | 无明确量化阈值，但原则的稳定性需在多个规则更替周期中体现 |
| **前提与约束（Premises）** | 法律体系存在区分原则与规则的结构；原则与规则的功能不同，原则指导推理，规则提供具体行为标准；社会变化导致规则需要更新，但原则反映基本价值，变化缓慢 |
| **Falsification（证伪条件）** | 如果发现某一法律原则在短期内被根本改变，或某一规则长期保持不变且未被取代，则该断言可能不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法律原则如同房屋的地基，规则如同墙上的装饰——地基稳固才能支撑房屋，装饰可以随时更换而不影响结构

### 🔗 文字版因果链

1. 法律原则作为推理的出发点，具有相对稳定性或沿不变方向发展
2. 法律规则作为具体规定，易被废除或取代，寿命较短
3. 原则的稳定性为法律推理提供持久基础，规则的更替适应社会变化
4. 因此，法律体系在保持核心价值连续性的同时，能够灵活调整具体规范
