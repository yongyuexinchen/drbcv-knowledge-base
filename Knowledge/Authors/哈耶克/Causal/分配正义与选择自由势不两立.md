# 分配正义与选择自由势不两立

> **领域**：政治哲学　|　**来源**：哈耶克_chapter_70_part_01_p3　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实行分配正义（按功绩或某种标准分配报酬） |
| **DV（因变量）** | 选择行动的自由被削弱或取消 |
| **Chain（传导链）** | 分配正义要求按照某种预设标准（如功绩、需要）来分配资源 → 这种分配需要一个权威机构来判定每个人的功绩或需要 → 权威机构必须制定等级制规则并强制实施 → 个人不再能通过自由选择（如市场交换）来决定自己的报酬 → 因此选择行动的自由被破坏，社会走向等级制组织 |
| **Lag（时滞）** | 长期，随着分配制度的确立和强化逐渐显现 |
| **Threshold（临界值）** | 当分配正义成为社会主导原则并取代交换正义时 |
| **前提与约束（Premises）** | 分配正义被理解为按功绩或需要等标准进行集中分配；社会存在一个能够执行分配正义的权威机构；自由社会以交换正义为基础，个人自由选择是核心价值 |
| **Falsification（证伪条件）** | 如果存在一个实行分配正义的社会，同时个人仍保有高度的选择自由（如自愿参与分配体系），则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持分配正义的社会主义者观点冲突，如加利（文中提及） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像自助餐（自由选择）与固定套餐（分配正义）——固定套餐由厨师决定你吃什么，你失去了选择菜品的自由。

### 🔗 文字版因果链

1. 分配正义要求按照某种预设标准（如功绩、需要）来分配资源
2. 这种分配需要一个权威机构来判定每个人的功绩或需要
3. 权威机构必须制定等级制规则并强制实施
4. 个人不再能通过自由选择（如市场交换）来决定自己的报酬
5. 因此选择行动的自由被破坏，社会走向等级制组织
