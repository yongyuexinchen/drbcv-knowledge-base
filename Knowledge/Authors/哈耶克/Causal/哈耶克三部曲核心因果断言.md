# 哈耶克三部曲核心因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划（政府集中控制经济资源与决策） |
| **DV（因变量）** | 通往奴役之路（个人自由丧失与极权主义兴起） |
| **Chain（传导链）** | 中央计划需要统一目标，压制分散的个体偏好 → 为执行计划，政府必须扩大权力，控制信息与舆论 → 权力集中导致对反对声音的镇压，逐步侵蚀法治与个人权利 → 最终形成全面控制的极权体制，个人沦为工具 |
| **Lag（时滞）** | 长期（数十年至数代，随权力扩张逐步显现） |
| **Threshold（临界值）** | 当政府计划覆盖关键经济部门并垄断信息传播时，奴役趋势不可逆 |
| **前提与约束（Premises）** | 仅当计划是全面且强制性的，而非局部或自愿协调；假设社会缺乏自发秩序（如市场）的有效替代；排除民主制下有限干预的情况 |
| **Falsification（证伪条件）** | 若存在一个长期实行全面中央计划但个人自由显著增长的国家案例，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于历史案例如苏联、纳粹德国） |
| **Conflicts（观点冲突）** | 与凯恩斯主义（政府干预可稳定经济且不必然损害自由）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个管家接管家庭所有开支，起初为效率，最终连家人吃什么、穿什么都由他决定，自由尽失

### 🔗 文字版因果链

1. 中央计划需要统一目标，压制分散的个体偏好
2. 为执行计划，政府必须扩大权力，控制信息与舆论
3. 权力集中导致对反对声音的镇压，逐步侵蚀法治与个人权利
4. 最终形成全面控制的极权体制，个人沦为工具

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 自发秩序（市场机制下个体自由交换形成的秩序） |
| **DV（因变量）** | 社会繁荣与文明进步 |
| **Chain（传导链）** | 个体基于局部知识自由决策，形成分散的信息利用 → 价格机制传递信号，协调供需，促进资源有效配置 → 竞争与试错推动创新和知识增长 → 长期积累导致经济繁荣与文明扩展 |
| **Lag（时滞）** | 中期至长期（数年显现经济效果，数十年显现文明进步） |
| **Threshold（临界值）** | 当市场规则稳定且产权保护明确时，自发秩序优于人为设计 |
| **前提与约束（Premises）** | 仅当存在法治和产权保障；假设个体具有理性且信息分散；排除市场失灵极端情况（如垄断、外部性） |
| **Falsification（证伪条件）** | 若存在一个完全自由市场但长期停滞或衰退的案例，且非外部因素所致，则断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引用历史如工业革命时期的英国） |
| **Conflicts（观点冲突）** | 与计划经济支持者（如波兰尼）认为市场需要国家嵌入冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同蚁群无需中央指挥，每只蚂蚁按简单规则行动，却能建造复杂巢穴，比任何工程师设计更高效

### 🔗 文字版因果链

1. 个体基于局部知识自由决策，形成分散的信息利用
2. 价格机制传递信号，协调供需，促进资源有效配置
3. 竞争与试错推动创新和知识增长
4. 长期积累导致经济繁荣与文明扩展

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 传统与道德规范（社会演化形成的规则） |
| **DV（因变量）** | 社会生存能力与扩展秩序 |
| **Chain（传导链）** | 传统规则积累群体经验，降低协调成本 → 遵守道德规范增强群体凝聚力与信任 → 信任促进分工与交易，扩大合作范围 → 最终形成超越血缘的扩展秩序，提升社会整体生存能力 |
| **Lag（时滞）** | 长期（跨代际，数十年至数百年） |
| **Threshold（临界值）** | 当传统规则与市场机制兼容时，其积极作用最大化 |
| **前提与约束（Premises）** | 仅当传统是演化形成的，而非人为强加；假设环境变化缓慢，传统能适应；排除传统阻碍创新或维护压迫的情况 |
| **Falsification（证伪条件）** | 若存在一个抛弃传统但社会生存能力显著提升的案例，则断言需修正 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于人类学与历史比较） |
| **Conflicts（观点冲突）** | 与理性建构主义（如笛卡尔式怀疑一切传统）冲突 |
| **Confidence（确信度）** | plausible |

1. 传统规则积累群体经验，降低协调成本
2. 遵守道德规范增强群体凝聚力与信任
3. 信任促进分工与交易，扩大合作范围
4. 最终形成超越血缘的扩展秩序，提升社会整体生存能力
