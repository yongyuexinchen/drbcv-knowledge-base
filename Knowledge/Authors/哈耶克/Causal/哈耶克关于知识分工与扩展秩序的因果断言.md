## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 分散的知识与信息在市场中通过价格机制进行传递 |
| **DV（因变量）** | 形成自发的扩展秩序，促进社会协作与文明进步 |
| **Chain（传导链）** | 市场中的个体拥有局部、分散的实践知识 → 价格机制作为信号系统，汇总并传递这些分散知识 → 个体依据价格信号调整自身行为，实现资源有效配置 → 无数个体自发的互动形成超越个人设计的复杂秩序 → 这种扩展秩序使陌生人之间能够有效协作，推动文明发展 |
| **Lag（时滞）** | 长期，知识积累与秩序演化需数代人的时间 |
| **Threshold（临界值）** | 价格信号必须真实反映资源稀缺性，且市场参与者能自由响应 |
| **前提与约束（Premises）** | 仅当市场机制未被政府过度干预时成立；假设个体拥有不可言传的实践知识，且无法被中央计划者完全收集；排除完全信息与零交易成本的理想化假设 |
| **Falsification（证伪条件）** | 若中央计划体制在长期内能持续实现比市场更高的经济增长率与创新水平，且无需依赖黑市或地下经济，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义主张政府积极干预经济以稳定周期的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 市场中的个体拥有局部、分散的实践知识
2. 价格机制作为信号系统，汇总并传递这些分散知识
3. 个体依据价格信号调整自身行为，实现资源有效配置
4. 无数个体自发的互动形成超越个人设计的复杂秩序
5. 这种扩展秩序使陌生人之间能够有效协作，推动文明发展
