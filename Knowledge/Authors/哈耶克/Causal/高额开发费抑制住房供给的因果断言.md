# 高额开发费抑制住房供给的因果断言

> **领域**：宏观经济学、住房政策　|　**来源**：哈耶克_chapter_86_part_02_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府征收高额开发费（如100%的开发收益） |
| **DV（因变量）** | 住房供给减少，进而加剧住房短缺 |
| **Chain（传导链）** | 政府将开发费设定为开发收益的100%，使开发商无法从开发中获利 → 开发商因无利可图而减少或停止新的住房开发项目 → 住房供给增速下降，无法满足人口增长或需求增长 → 住房市场供不应求，导致住房短缺或价格上涨 |
| **Lag（时滞）** | 中期（数月至数年，取决于开发周期和市场反应速度） |
| **Threshold（临界值）** | 开发费占开发收益的比例接近或达到100%时，开发激励基本消失 |
| **前提与约束（Premises）** | 开发商以利润最大化为目标，且没有其他非经济动机（如社会责任）；政府没有提供其他补贴或补偿来抵消开发费的影响；住房需求保持稳定或增长，不会因高费用而自动下降；市场机制在住房供给中起主导作用，不存在完全的计划经济替代 |
| **Falsification（证伪条件）** | 如果开发费提高后，住房供给仍显著增加（例如因政府直接建设或技术进步大幅降低成本），则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（原文仅提及100%开发费，未提供具体数据） |
| **Conflicts（观点冲突）** | 与主张政府干预可有效调节住房市场的观点冲突（如某些凯恩斯主义或计划经济支持者） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像政府对果园征收全部果实作为税，果农自然不再种树，最终果园荒芜，果子更少。

### 🔗 文字版因果链

1. 政府将开发费设定为开发收益的100%，使开发商无法从开发中获利
2. 开发商因无利可图而减少或停止新的住房开发项目
3. 住房供给增速下降，无法满足人口增长或需求增长
4. 住房市场供不应求，导致住房短缺或价格上涨
