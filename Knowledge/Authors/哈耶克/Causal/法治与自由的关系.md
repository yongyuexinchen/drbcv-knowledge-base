## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法治（法律至上，权力分立） |
| **DV（因变量）** | 个人自由（免受专断意志支配） |
| **Chain（传导链）** | 法治确立普遍、确定、平等的法律规则 → 法律规则约束政府权力，防止专断意志 → 权力分立（立法、行政、司法分离）确保法律执行不偏不倚 → 个人在已知规则下行动，自由得到保障 |
| **Lag（时滞）** | 长期（法治确立需历史演进，如英国宪政发展） |
| **Threshold（临界值）** | 法律必须具有普遍性、确定性和平等适用性；权力必须分立 |
| **前提与约束（Premises）** | 法律是公开、明确、非追溯性的；司法独立于立法和行政；政府权力受法律限制，不存在任意裁量权 |
| **Falsification（证伪条件）** | 如果存在一个法治国家但个人自由显著受限（如高度管制但法律明确），则该断言可能被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为法治可能成为多数人暴政工具的观点冲突（如托克维尔对多数专制的担忧） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法治如同交通规则：明确的红绿灯和车道划分让所有司机自由行驶，若没有规则或规则随意改变，则交通混乱，无人自由。

### 🔗 文字版因果链

1. 法治确立普遍、确定、平等的法律规则
2. 法律规则约束政府权力，防止专断意志
3. 权力分立（立法、行政、司法分离）确保法律执行不偏不倚
4. 个人在已知规则下行动，自由得到保障
