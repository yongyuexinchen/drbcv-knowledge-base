# 对未列举权利的保护程度（可能导致权利被忽视或侵犯）

> 属于因果簇：[[联邦制分权与司法审核对自由的保障]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 宪法对个人权利的明文列举（权利法案） |
| **DV（因变量）** | 对未列举权利的保护程度（可能导致权利被忽视或侵犯） |
| **Chain（传导链）** | 宪法明文列举某些权利 → 未列举的权利容易被解释为不受保护 → 政府可能利用这一解释侵犯未列举的权利 → 因此，明文列举权利反而可能削弱对整体权利的保护 |
| **Lag（时滞）** | 长期，随着司法实践和解释逐渐显现 |
| **Threshold（临界值）** | 当列举的权利清单不完整时，风险增加 |
| **前提与约束（Premises）** | 权利的范围大于任何文件所能详尽列举的；司法或政治解释倾向于将列举视为排他性；存在有意扩张权力的行为者 |
| **Falsification（证伪条件）** | 若存在一个宪法明确列举权利的国家，其未列举权利依然得到充分保护，且无侵犯案例，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张权利法案必要性的观点冲突（如美国后来的实践） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同列出“禁止偷苹果”却未提“禁止偷梨”，人们可能认为偷梨是允许的，反而增加了梨被偷的风险。

### 🔗 文字版因果链

1. 宪法明文列举某些权利
2. 未列举的权利容易被解释为不受保护
3. 政府可能利用这一解释侵犯未列举的权利
4. 因此，明文列举权利反而可能削弱对整体权利的保护
