### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 司法审核（法院宣布违宪法律无效的权力） |
| **DV（因变量）** | 对立法机构的限制与对法治的维护 |
| **Chain（传导链）** | 法院拥有司法审核权 → 立法机构通过的法律若违反宪法原则，法院可宣布其无效 → 这迫使立法机构在立法时遵循普遍性原则 → 从而限制立法机构的权力，维护法治 |

| **前提与约束（Premises）** | 法院独立于立法和行政机构；宪法具有最高法律效力；法院能够正确解释宪法原则 |

### 🔗 文字版因果链

1. 法院拥有司法审核权
2. 立法机构通过的法律若违反宪法原则，法院可宣布其无效

4. 从而限制立法机构的权力，维护法治
