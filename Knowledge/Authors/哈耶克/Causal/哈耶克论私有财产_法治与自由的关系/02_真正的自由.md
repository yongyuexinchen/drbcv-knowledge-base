# 真正的自由

> 属于因果簇：[[哈耶克论私有财产、法治与自由的关系]]（第2块/4块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法治（the Rule of Law） |
| **DV（因变量）** | 真正的自由 |
| **Chain（传导链）** | 法治要求政府行为受事前规定并宣布的规则约束 → 个人能预见当权者如何使用强制权力 → 个人据此规划自身事务，不依赖他人或权威机构的批准 → 自由得以实现 |
| **Lag（时滞）** | 即时（法治确立后自由即存在） |
| **Threshold（临界值）** | 政府必须遵守一般性、抽象、平等适用的规则 |
| **前提与约束（Premises）** | 法律规则事先公布且平等适用于所有人；政府权力（包括立法权）受到限制；排除政府以法律为工具任意强制（rule by law） |
| **Falsification（证伪条件）** | 若在法治下个人行动仍受任意干预或无法预见权力使用，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与法律实证主义或无限政府观冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：红绿灯事先公布，司机能预判他人行为，才能自由驾驶；若交警随意拦车，则无自由可言。

### 🔗 文字版因果链

1. 法治要求政府行为受事前规定并宣布的规则约束
2. 个人能预见当权者如何使用强制权力
3. 个人据此规划自身事务，不依赖他人或权威机构的批准
4. 自由得以实现
