# 社会保险制度演变为收入再分配工具，威胁个人自由

> 属于因果簇：[[社会保险制度从救济向再分配工具的转变及其对自由的威胁]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 国家建立统一、垄断性的社会保险组织并强制个人参保 |
| **DV（因变量）** | 社会保险制度演变为收入再分配工具，威胁个人自由 |
| **Chain（传导链）** | 国家强制个人加入统一管理的保险组织，取代竞争性私人保险 → 垄断组织拥有酌处权，可按需分配而非基于协议，从而进行收入再分配 → 再分配成为主要意图，制度从救济转向平均主义工具 → 政府获得决定个人'公正'地位和分配收入的权力，自由受到严重威胁 |
| **Lag（时滞）** | 长期，随着制度发展逐渐显现 |
| **Threshold（临界值）** | 当国家垄断保险并强制参保，且再分配成为主要目标时 |
| **前提与约束（Premises）** | 国家承认有义务消除绝对贫困并保障最低福利水平；政府被授予提供特定服务的排他性权力；制度设计使多数人无法了解自身缴费与受益的关系 |
| **Falsification（证伪条件）** | 如果存在反例表明统一垄断保险制度未导致再分配或未威胁自由，则该断言可被推翻 |
| **Data（定量佐证）** | 意大利半熟练工人：雇主支付49美分/小时，工人仅得27美分，22美分交国家（约44%）。 |
| **Conflicts（观点冲突）** | 与支持福利国家或社会保险的学者观点冲突，如贝弗里奇报告的支持者 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个强制性的社区食堂，起初为饥饿者提供食物，但后来管理者决定所有人必须缴纳费用，并按照他们认为的'公平'分配食物，最终人们失去了选择自己饮食的自由。

### 🔗 文字版因果链

1. 国家强制个人加入统一管理的保险组织，取代竞争性私人保险
2. 垄断组织拥有酌处权，可按需分配而非基于协议，从而进行收入再分配
3. 再分配成为主要意图，制度从救济转向平均主义工具
4. 政府获得决定个人'公正'地位和分配收入的权力，自由受到严重威胁
