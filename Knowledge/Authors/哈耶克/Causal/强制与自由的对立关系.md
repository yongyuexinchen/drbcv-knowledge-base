## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 强制（国家或他人对个人行为的干预） |
| **DV（因变量）** | 自由的丧失（个人自由受限） |
| **Chain（传导链）** | 强制迫使个人违背自身目的行事 → 个人无法按照自己的目标行动 → 自由因此被削减或摧毁 |
| **Lag（时滞）** | 即时 |
| **Threshold（临界值）** | 任何形式的强制，无论出于何种目的，都会导致自由减少 |
| **前提与约束（Premises）** | 强制被定义为违背个人意志的干预；自由被理解为个人按自身目的行动的能力；该断言适用于所有社会形态，包括民主社会 |
| **Falsification（证伪条件）** | 若能证明某种强制在长期内增加了个人自由（如强制教育提高自主能力），则该断言可能被削弱，但哈耶克认为强制本身即恶，除非为减少更大强制 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与功利主义或家长式干预观点冲突，如密尔在《论自由》中允许为防止伤害他人而强制 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 强制如同绳索束缚，无论绳索是金丝还是麻绳，都限制行动自由。

### 🔗 文字版因果链

1. 强制迫使个人违背自身目的行事
2. 个人无法按照自己的目标行动
3. 自由因此被削减或摧毁
