# 计划导致独裁的因果断言

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集中计划（中央计划） |
| **DV（因变量）** | 独裁（平民主义独裁或极权主义） |
| **Chain（传导链）** | 集中计划要求对经济活动进行统一指导，需要压制个人自由 → 议会因目标不一致无法有效指导，只能授权给计划机构 → 计划机构在冲突目标间选择，其决定难以被否决或修正 → 议会沦为安全阀，实际权力集中于政府首脑 → 政府首脑利用权力操纵选举，巩固独裁地位 → 最终形成平民主义独裁或极权主义，破坏个人自由 |
| **Lag（时滞）** | 长期过程，随计划范围扩大而逐步显现 |
| **Threshold（临界值）** | 当计划范围超出多数人真正一致的领域，且需要强制推行理想时 |
| **前提与约束（Premises）** | 社会依赖中央计划行使职能；议会无法就目标达成一致，只能授予细节权力；存在需要强制推行的集体主义信条或理想 |
| **Falsification（证伪条件）** | 若存在一个中央计划经济体，其议会能有效指导计划且个人自由未受破坏，则可推翻此断言 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与民主社会主义者如拉斯基（认为议会民主可服务于社会主义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家庭中，如果父母对教育目标分歧巨大，只能让一个孩子全权决定，最终这个孩子可能成为小独裁者，而其他成员失去发言权。

### 🔗 文字版因果链

1. 集中计划要求对经济活动进行统一指导，需要压制个人自由
2. 议会因目标不一致无法有效指导，只能授权给计划机构
3. 计划机构在冲突目标间选择，其决定难以被否决或修正
4. 议会沦为安全阀，实际权力集中于政府首脑
5. 政府首脑利用权力操纵选举，巩固独裁地位
6. 最终形成平民主义独裁或极权主义，破坏个人自由
