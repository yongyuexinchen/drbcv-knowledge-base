# 哈耶克关于自由与法治的因果断言（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：哈耶克关于自由与法治的因果断言.md

## 总体因果图

- 政府干预（计划经济、福利国家政策） → 个人自由丧失（通往奴役之路）
- 法治（形式法治，法律面前人人平等） → 个人自由保障
- 传统和自发秩序（包括道德规范、习俗） → 文明进步（知识扩展、社会繁荣）
- 平等（机会平等） → 社会效率与个人自由
