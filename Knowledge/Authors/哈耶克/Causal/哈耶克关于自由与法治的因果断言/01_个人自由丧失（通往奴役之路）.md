# 个人自由丧失（通往奴役之路）

> 属于因果簇：[[哈耶克关于自由与法治的因果断言]]（第1块/4块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府干预（计划经济、福利国家政策） |
| **DV（因变量）** | 个人自由丧失（通往奴役之路） |
| **Chain（传导链）** | 政府干预经济和社会生活，集中权力 → 权力集中导致信息分散和知识利用效率下降 → 为维持干预效果，政府不得不进一步扩大控制范围 → 个人选择空间被压缩，自由逐步丧失 → 最终走向极权主义或奴役状态 |
| **Lag（时滞）** | 长期（数十年至数代） |
| **Threshold（临界值）** | 当政府干预超出维护法治和基本秩序的限度，开始主导资源配置时 |
| **前提与约束（Premises）** | 仅当政府干预是系统性、全面性的计划经济或福利国家政策时；在法治健全、权力受到有效制衡的社会中，干预的奴役效应可能被延缓；排除临时性、局部性的危机干预（如战时经济管制） |
| **Falsification（证伪条件）** | 如果存在一个长期实行高度政府干预但个人自由显著增加且未走向极权的实例，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、民主社会主义（如瑞典模式）的实践和理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像父母过度管控孩子，起初为了安全，但逐渐剥夺了孩子独立成长的能力，最终孩子失去自主性

### 🔗 文字版因果链

1. 政府干预经济和社会生活，集中权力
2. 权力集中导致信息分散和知识利用效率下降
3. 为维持干预效果，政府不得不进一步扩大控制范围
4. 个人选择空间被压缩，自由逐步丧失
5. 最终走向极权主义或奴役状态
