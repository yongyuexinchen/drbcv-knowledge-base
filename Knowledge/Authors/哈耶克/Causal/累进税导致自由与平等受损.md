# 累进税导致自由与平等受损

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 实行累进税 |
| **DV（因变量）** | 自由与平等受损，公民受压迫 |
| **Chain（传导链）** | 累进税初期税率较低，不易察觉 → 若不警惕，税率会迅速提高并扩大范围 → 高税率使部分公民（高收入者）承担过重负担，形成压迫 → 最终破坏公民间的平等与自由 |
| **Lag（时滞）** | 初期不明显，但会迅速成倍增加，直至无法及时阻止 |
| **Threshold（临界值）** | 累进税税率一旦开始提高，若无警惕，将迅速扩大至无法控制 |
| **前提与约束（Premises）** | 仅当公民未意识到累进税的危险时；在民主制度下，累进税可能被政治操弄 |
| **Falsification（证伪条件）** | 若累进税长期保持低税率且未扩大，或未导致公民压迫，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持累进税的观点冲突，如布卢姆和卡尔文《并不轻松的累进税案例》 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 累进税如同温水煮青蛙，初始水温舒适，但逐渐升高，青蛙最终无法逃脱。

### 🔗 文字版因果链

1. 累进税初期税率较低，不易察觉
2. 若不警惕，税率会迅速提高并扩大范围
3. 高税率使部分公民（高收入者）承担过重负担，形成压迫
4. 最终破坏公民间的平等与自由
