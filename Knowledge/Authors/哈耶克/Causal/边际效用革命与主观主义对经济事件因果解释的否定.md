# 边际效用革命与主观主义对经济事件因果解释的否定

> **领域**：宏观经济学　|　**来源**：哈耶克_chapter_48_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 边际效用理论（主观主义革命）的发现与传播 |
| **DV（因变量）** | 经济理论被整合为严密体系，并正确理解供应与需求的决定机制 |
| **Chain（传导链）** | 边际效用理论将效用视为因人而异的主观属性，而非物品的客观属性 → 这一理论揭示了供应和需求是由个人主观评价决定的，而非客观的因果链 → 由此，市场过程被理解为信息传递过程，使人们能够利用更多信息和技能 → 经济理论因此从古典的客观因果解释转向主观主义解释，形成严密体系 |
| **Lag（时滞）** | 约100年（从19世纪70年代发现到20世纪70年代仍未普及） |
| **Threshold（临界值）** | 无明确量化阈值，但需突破古典经济学客观效用观的认知障碍 |
| **前提与约束（Premises）** | 仅当个人效用不可跨人际比较时成立；仅当市场参与者拥有分散且不可集中的知识时成立；排除宏观经济学试图在统计数字间寻找因果关系的做法 |
| **Falsification（证伪条件）** | 若能证明效用是客观可计量的属性，且经济事件可由以往事件直接因果解释，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与古典政治经济学（如穆勒立场）及宏观经济学（如凯恩斯主义）的客观因果解释冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像从地心说转向日心说，不是增加更多本轮，而是彻底改变观察视角，才能解释行星运动

### 🔗 文字版因果链

1. 边际效用理论将效用视为因人而异的主观属性，而非物品的客观属性
2. 这一理论揭示了供应和需求是由个人主观评价决定的，而非客观的因果链
3. 由此，市场过程被理解为信息传递过程，使人们能够利用更多信息和技能
4. 经济理论因此从古典的客观因果解释转向主观主义解释，形成严密体系

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 宏观经济学（在统计数字中寻找因果关系）的兴起 |
| **DV（因变量）** | 边际效用理论的贡献被掩盖，政府政策基于幼稚的客观价值解释 |
| **Chain（传导链）** | 宏观经济学大量采用数学和统计，在假定可计算的事物间寻找因果关系 → 这种谬见因数学形式而打动政客，鼓励了技术官僚操纵经济的企图 → 它无法说明贸易和市场在协调生产中的作用，导致政策基于错误的价值解释 → 边际效用理论的贡献因此黯然失色，市场秩序的真实过程被掩盖 |
| **Lag（时滞）** | 过去40年（相对于写作时间） |
| **Threshold（临界值）** | 无明确量化阈值，但宏观经济学需在统计上建立看似显著的因果关系 |
| **前提与约束（Premises）** | 仅当宏观经济学被政客接受并用于政策制定时成立；仅当经济学家误将分散知识视为可集中利用的‘现有数据’时成立；排除对市场过程作为发现过程的正确理解 |
| **Falsification（证伪条件）** | 若宏观经济学能成功解释并预测市场协调过程，且不依赖客观价值假设，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与宏观经济学的主流实践（如计量经济学）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像用平均体温来诊断个体疾病，看似科学，却掩盖了每个病人的具体症状

### 🔗 文字版因果链

1. 宏观经济学大量采用数学和统计，在假定可计算的事物间寻找因果关系
2. 这种谬见因数学形式而打动政客，鼓励了技术官僚操纵经济的企图
3. 它无法说明贸易和市场在协调生产中的作用，导致政策基于错误的价值解释
4. 边际效用理论的贡献因此黯然失色，市场秩序的真实过程被掩盖

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对贸易和利润的鄙视（基于无知和返祖现象） |
| **DV（因变量）** | 政治态度歪曲，阻碍最有效的生产组织发展，鼓舞社会主义错误希望 |
| **Chain（传导链）** | 知识分子和道学家因无知而鄙视贸易、货币和利润追求 → 这种态度源于原始群体对隐藏信息获利的憎恨，是返祖现象 → 它导致对贸易作用的管制和干预，以伪科学形式复活 → 管制失败后助长对‘资本主义’的猜疑，阻碍生产组织发展 |
| **Lag（时滞）** | 长期（从中世纪管制到现代伪科学形式） |
| **Threshold（临界值）** | 无明确量化阈值，但需在公众和政治意见中形成普遍偏见 |
| **前提与约束（Premises）** | 仅当知识分子缺乏对边际效用理论和市场过程的理解时成立；仅当政府干预货币和贸易垄断存在时成立；排除对市场正确了解的个人 |
| **Falsification（证伪条件）** | 若对贸易和利润的鄙视能改善资源配置或提高生产效率，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与社会主义口号‘为用途而生产，不为利润而生产’（亚里士多德至罗素等）冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 知识分子和道学家因无知而鄙视贸易、货币和利润追求
2. 这种态度源于原始群体对隐藏信息获利的憎恨，是返祖现象
3. 它导致对贸易作用的管制和干预，以伪科学形式复活
4. 管制失败后助长对‘资本主义’的猜疑，阻碍生产组织发展
