## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划者试图集中控制经济决策 |
| **DV（因变量）** | 社会走向奴役（个人自由丧失、极权主义） |
| **Chain（传导链）** | 中央计划者无法获取分散在无数个体中的局部知识 → 计划必然依赖单一价值排序，压制个体偏好差异 → 为执行计划，需要强制统一目标，限制言论与选择自由 → 经济控制扩展到社会各领域，最终导致极权主义 |
| **Lag（时滞）** | 数十年（一代人以上） |
| **Threshold（临界值）** | 当计划覆盖关键生产资料与价格形成机制时 |
| **前提与约束（Premises）** | 知识是分散的、情境化的，不可完全集中；个体目标多元且不可通约；存在独立于经济领域的政治自由传统 |
| **Falsification（证伪条件）** | 若某个中央计划经济体在长期内保持高经济增长且个人自由指数不下降，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、民主社会主义（如萧伯纳、韦伯夫妇）的理性计划信念冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同试图用一张静态地图导航动态城市，必然导致绕路和强制改道

### 🔗 文字版因果链

1. 中央计划者无法获取分散在无数个体中的局部知识
2. 计划必然依赖单一价值排序，压制个体偏好差异
3. 为执行计划，需要强制统一目标，限制言论与选择自由
4. 经济控制扩展到社会各领域，最终导致极权主义
