# 工会强制权力对工资与就业的影响（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：工会强制权力对工资与就业的影响.md

## 总体因果图

- 工会的强制权力（胁迫非会员入会、限制劳动力供给） → 实际工资水平、整体劳动生产率、就业结构
- 工会持续施加货币工资上涨压力 → 通货膨胀
- 工会特权（法律豁免权、强制会员制度） → 自由社会基础（法治、个人自由）
