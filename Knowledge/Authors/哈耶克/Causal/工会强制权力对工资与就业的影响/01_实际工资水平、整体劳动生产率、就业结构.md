# 实际工资水平、整体劳动生产率、就业结构

> 属于因果簇：[[工会强制权力对工资与就业的影响]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工会的强制权力（胁迫非会员入会、限制劳动力供给） |
| **DV（因变量）** | 实际工资水平、整体劳动生产率、就业结构 |
| **Chain（传导链）** | 工会通过强制手段（如封闭型企业、纠察线）胁迫工人入会，限制劳动力供给 → 劳动力供给减少导致特定行业工资高于自由市场水平 → 高工资吸引更多工人，但工会限制供给，导致部分工人失业或滞留低薪岗位 → 劳动力配置扭曲，整体劳动生产率下降，平均实际工资水平降低 |
| **Lag（时滞）** | 长期（数年），短期可能表现为货币工资上升但实际工资不变或下降 |
| **Threshold（临界值）** | 当工会能将工资抬高至自由市场均衡工资之上时，才会产生上述效应 |
| **前提与约束（Premises）** | 工会拥有法律豁免权或执法者默许的强制权力；工会能有效控制特定劳动力供给；存在资本专用性，雇主难以迅速调整 |
| **Falsification（证伪条件）** | 若在工会强大且无强制权力的国家，实际工资和生产率高于工会较弱国家，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义认为工会可提高整体购买力促进增长的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 工会像水库闸门，限制水流（劳动力）以抬高水位（工资），但下游（其他行业）水量减少，整体灌溉效率下降。

### 🔗 文字版因果链

1. 工会通过强制手段（如封闭型企业、纠察线）胁迫工人入会，限制劳动力供给
2. 劳动力供给减少导致特定行业工资高于自由市场水平
3. 高工资吸引更多工人，但工会限制供给，导致部分工人失业或滞留低薪岗位
4. 劳动力配置扭曲，整体劳动生产率下降，平均实际工资水平降低
