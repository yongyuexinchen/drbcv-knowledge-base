# 自由社会基础（法治、个人自由）

> 属于因果簇：[[工会强制权力对工资与就业的影响]]（第3块/3块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工会特权（法律豁免权、强制会员制度） |
| **DV（因变量）** | 自由社会基础（法治、个人自由） |
| **Chain（传导链）** | 工会获得法律豁免权，不受一般法律约束 → 工会可强制个人违背意愿加入或服从，侵犯个人自由 → 政府无法有效防范强制和暴力，法治原则被破坏 → 自由社会的基础（个人权利、契约自由）受到威胁 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 当工会成为唯一不受一般法律规则约束的机构时 |
| **前提与约束（Premises）** | 法治原则是自由社会的基石；政府有责任防范强制和暴力；工会特权无法被民主政体控制而不摧毁自身 |
| **Falsification（证伪条件）** | 若工会特权未导致个人自由显著受损，或民主政体能有效控制工会而不损害自身，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与集体主义或社会主义观点冲突，后者认为工会特权是工人解放的必要手段 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 工会特权像给特定群体发放的“免罪金牌”，破坏了法律面前人人平等的原则，最终导致社会秩序混乱。

### 🔗 文字版因果链

1. 工会获得法律豁免权，不受一般法律约束
2. 工会可强制个人违背意愿加入或服从，侵犯个人自由
3. 政府无法有效防范强制和暴力，法治原则被破坏
4. 自由社会的基础（个人权利、契约自由）受到威胁
