## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划经济（对全社会实行理性计划） |
| **DV（因变量）** | 通往奴役之路（个人自由丧失、文明退化） |
| **Chain（传导链）** | 计划经济基于'致命的自负'，即人类理性可以全面掌握社会复杂现象 → 试图为整个社会设定统一目标，用强制手段推行计划 → 破坏扩展秩序（自发秩序）中个人利用分散知识的机制 → 导致个人自由受侵犯，社会退回到小群体部落状态 → 最终走向奴役 |
| **Lag（时滞）** | 长期（数十年，如苏联计划经济实践） |
| **Threshold（临界值）** | 当计划覆盖整个社会、取代市场机制时 |
| **前提与约束（Premises）** | 人类理性无法掌握分散、多样、易变的个人知识；扩展秩序（市场）是文明发展的关键，其形成非理性设计；政府权力若不限于保护产权和公正规则，必然导致强制 |
| **Falsification（证伪条件）** | 若计划经济能长期维持经济效率和个人自由，或能证明理性计划优于市场自发秩序，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义干预政策、社会主义计划经济理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像试图用一张地图精确规划整个森林的每一棵树，最终会迷失方向，反而破坏了森林的生态

### 🔗 文字版因果链

1. 计划经济基于'致命的自负'，即人类理性可以全面掌握社会复杂现象
2. 试图为整个社会设定统一目标，用强制手段推行计划
3. 破坏扩展秩序（自发秩序）中个人利用分散知识的机制
4. 导致个人自由受侵犯，社会退回到小群体部落状态
5. 最终走向奴役
