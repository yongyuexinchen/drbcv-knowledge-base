# 个人选择目标的自由受到侵蚀

> 属于因果簇：[[功绩报酬与自由社会的矛盾]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 根据功绩确定报酬的原则 |
| **DV（因变量）** | 个人选择目标的自由受到侵蚀 |
| **Chain（传导链）** | 功绩必须可估价，即他人能辨认并形成一致见解 → 可估价的功绩要求判断主观努力和痛苦，而非客观结果 → 但真实判断功绩需要掌握行动者全部知识、技能、心态等，这些条件普遍缺乏 → 因此，若强制按功绩分配，需由他人（权力层）决定何为功绩，引导个人行动 → 个人失去依据自身知识和能力追求不确定目标的自由，转而服从他人判断 → 最终导致个人选择目标的自由被剥夺 |
| **Lag（时滞）** | 长期，制度性影响逐渐显现 |

| **前提与约束（Premises）** | 功绩必须可估价且他人能形成一致见解；真实功绩判断需要掌握行动者全部主观因素，而这些条件普遍缺乏；自由社会依赖个人运用自身知识和能力自主决策 |
| **Falsification（证伪条件）** | 若能证明存在一种可行机制，可以在不侵犯个人自由的前提下准确评估功绩并据此分配报酬，则该断言被推翻 |

| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像老师想按学生的努力程度打分，但老师无法真正知道每个学生花了多少心思，于是只能按考试成绩（结果）打分，结果学生为了高分而放弃自己真正感兴趣的科目，失去了学习的自由。

### 🔗 文字版因果链

1. 功绩必须可估价，即他人能辨认并形成一致见解
2. 可估价的功绩要求判断主观努力和痛苦，而非客观结果
3. 但真实判断功绩需要掌握行动者全部知识、技能、心态等，这些条件普遍缺乏
4. 因此，若强制按功绩分配，需由他人（权力层）决定何为功绩，引导个人行动
5. 个人失去依据自身知识和能力追求不确定目标的自由，转而服从他人判断
6. 最终导致个人选择目标的自由被剥夺
