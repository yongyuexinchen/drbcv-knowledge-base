# 个人成就（尤其是非测试可测的贡献）

> 属于因果簇：[[教育机会分配与知识进步的关系]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 家庭环境对知识兴趣的传递 |
| **DV（因变量）** | 个人成就（尤其是非测试可测的贡献） |
| **Chain（传导链）** | 家庭重视知识，形成知识兴趣和背景 → 这种兴趣和背景促进非认知能力的发展 → 这些能力在成就中发挥关键作用，甚至超过天生智力 |
| **Lag（时滞）** | 长期（从童年到成年） |
| **Threshold（临界值）** | 家庭环境对知识重视程度显著高于平均水平 |
| **前提与约束（Premises）** | 家庭具有传递知识兴趣的条件；社会允许家庭通过物质牺牲支持子女教育；平均主义政策不消除这种家庭优势 |
| **Falsification（证伪条件）** | 若控制家庭背景后，测试能力完全预测成就，且家庭兴趣无独立影响，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与强调先天能力决定论的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 像种子和土壤：同样的种子，肥沃的土壤（家庭环境）比贫瘠的土壤更可能长成大树，即使种子本身大小相似。

### 🔗 文字版因果链

1. 家庭重视知识，形成知识兴趣和背景
2. 这种兴趣和背景促进非认知能力的发展
3. 这些能力在成就中发挥关键作用，甚至超过天生智力
