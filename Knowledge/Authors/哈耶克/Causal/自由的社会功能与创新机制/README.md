# 自由的社会功能与创新机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：自由的社会功能与创新机制.md

## 总体因果图

- 他人对自由的利用（尤其是少数人的自由） → 个人从自由中获得的好处（包括非自由者）
- 行动自由（包括经济自由） → 新思想的产生与文明进步
- 竞争（包括组织间竞争） → 社会选择与进步
- 理性控制社会进程的企图 → 自发创新力量的削弱与文明停滞
