# 法治与个人自由的因果关系

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法治（法律具有普遍性、确定性，对行政权力施加限制） |
| **DV（因变量）** | 个人自由（不受他人专断意志支配，自由支配人身、行为、财产） |
| **Chain（传导链）** | 法律确立普遍、确定、非专断的规则，约束所有人和政府 → 公民在已知规则下可预期行为后果，免受任意干预 → 行政权力受到法律限制，不能随意侵犯个人权利 → 个人自由得以维护和扩展 |
| **Lag（时滞）** | 长期，历史演变过程（如英国数百年发展） |
| **Threshold（临界值）** | 法律必须具有普遍性、确定性，且对行政机关裁量权严格限制 |
| **前提与约束（Premises）** | 法律是已知的、非追溯既往的；法律平等适用于所有人，无特权；政府权力受法律约束，分权制衡存在 |
| **Falsification（证伪条件）** | 若存在法治但个人自由未得到保障，或无法治但个人自由仍存在，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与无政府主义或绝对自由放任观点冲突（如认为法律本身就是对自由的限制） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法治如同交通规则：没有规则，道路混乱，人人自危；有了明确规则，大家才能安全自由地行驶。

### 🔗 文字版因果链

1. 法律确立普遍、确定、非专断的规则，约束所有人和政府
2. 公民在已知规则下可预期行为后果，免受任意干预
3. 行政权力受到法律限制，不能随意侵犯个人权利
4. 个人自由得以维护和扩展
