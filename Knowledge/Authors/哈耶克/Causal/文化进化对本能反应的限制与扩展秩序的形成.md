# 文化进化对本能反应的限制与扩展秩序的形成

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人类逐渐演化出的行为规则（如私有财产、诚信、契约、交换、贸易、竞争、收获和私生活的规则） |
| **DV（因变量）** | 扩展秩序（文明）的形成与人类社会的扩大 |
| **Chain（传导链）** | 人类通过传统、教育和模仿习得非本能的规则 → 这些规则限制或制止了本能的集体主义行为（如休戚与共和利他主义） → 遵守规则的群体能够更成功地繁衍生息，并吸收外人 → 规则使广泛分散的知识和技能得以利用，形成超越个人的合作模式 → 最终产生出人类交往的扩展秩序，即文明 |
| **Lag（时滞）** | 数千年至数十万年（文化进化过程漫长，市场秩序只是相对晚近的产物） |
| **Threshold（临界值）** | 规则必须被足够多的人遵守，且能有效协调更多成员的行为，否则扩展秩序无法形成 |
| **前提与约束（Premises）** | 规则必须是非本能的，通过学习得到；规则必须适用于超越小群体的范围，甚至超越国家界线；个人必须忍受对本能冲动的限制，即使不理解其作用；存在一个巨大的制度和传统架构（经济的、法律的和道德的）作为支撑 |
| **Falsification（证伪条件）** | 如果发现某个文明在没有类似规则（如私有财产、契约）的情况下也能形成大规模扩展秩序，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与卢梭等主张回归天性、反对限制本能的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：虽然限制了个人的随意驾驶本能，但使得成千上万的车辆能够有序高效地通行，形成庞大的交通网络。

### 🔗 文字版因果链

1. 人类通过传统、教育和模仿习得非本能的规则
2. 这些规则限制或制止了本能的集体主义行为（如休戚与共和利他主义）
3. 遵守规则的群体能够更成功地繁衍生息，并吸收外人
4. 规则使广泛分散的知识和技能得以利用，形成超越个人的合作模式
5. 最终产生出人类交往的扩展秩序，即文明
