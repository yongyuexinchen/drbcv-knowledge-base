# 资源保护与产权制度因果分析

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 产权制度（私有产权或公有产权） |
| **DV（因变量）** | 资源保护效果（资源可持续利用程度） |
| **Chain（传导链）** | 产权制度决定资源使用的激励结构 → 私有产权下，资源使用者承担未来收益与成本，形成长期保护激励 → 公有产权下，个体使用资源的收益归己而成本外溢，导致过度使用 → 过度使用导致资源耗竭，保护效果下降 |
| **Lag（时滞）** | 长期（数十年至数代，取决于资源更新周期） |
| **Threshold（临界值）** | 当资源使用率超过可持续产量时，资源存量开始下降 |
| **前提与约束（Premises）** | 资源具有稀缺性且产权界定清晰；资源使用者具有理性经济人行为；排除政府有效管制或社区自治等替代机制 |
| **Falsification（证伪条件）** | 若在公有产权下资源仍能长期维持可持续利用（如某些社区共管成功案例），则推翻该断言 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与某些社区共管资源成功案例（如Ostrom的公共池塘资源研究）冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 公共牧场上的羊：如果草地是共有的，每个牧民都想多放羊，草地很快被啃光；如果草地分给每家，大家就会精心养护。

### 🔗 文字版因果链

1. 产权制度决定资源使用的激励结构
2. 私有产权下，资源使用者承担未来收益与成本，形成长期保护激励
3. 公有产权下，个体使用资源的收益归己而成本外溢，导致过度使用
4. 过度使用导致资源耗竭，保护效果下降
