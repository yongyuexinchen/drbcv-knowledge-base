# 哈耶克《致命的自负》第一章核心因果断言（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：哈耶克_致命的自负_第一章核心因果断言.md

## 总体因果图

- 人类遵守禁止按本能行事的规则（如私有财产、诚信、契约、交换、贸易、竞争等） → 文明的建立与扩展秩序的形成
- 遵守新规则（尤其是有利于群体繁衍生息的行为方式）的群体 → 群体更成功地繁衍生息并吸收外人，使规则传播
- 竞争（作为发现过程） → 人类对新情况的适应能力与效率的提高
- 通过模仿进行学习的能力（而非理性设计） → 文化传统的传递与文明的持续发展
