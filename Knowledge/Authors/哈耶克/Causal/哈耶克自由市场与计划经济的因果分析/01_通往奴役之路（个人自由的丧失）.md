# 通往奴役之路（个人自由的丧失）

> 属于因果簇：[[哈耶克自由市场与计划经济的因果分析]]（第1块/2块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府对经济的集中计划与控制 |
| **DV（因变量）** | 通往奴役之路（个人自由的丧失） |
| **Chain（传导链）** | 政府集中计划需要统一目标，压制个体差异 → 为执行计划，政府扩大权力并限制个人选择 → 权力集中导致信息扭曲和决策失误，经济效率下降 → 为维持计划，政府进一步强制，最终走向极权 |
| **Lag（时滞）** | 长期（数十年，随计划深化逐步显现） |
| **Threshold（临界值）** | 当政府计划取代市场自发秩序，且覆盖范围超出国防等有限职能时 |
| **前提与约束（Premises）** | 仅当计划涉及经济活动的全面控制时成立；在知识分散、信息不完全的现实条件下有效；排除政府仅提供法律框架和公共品的有限干预 |
| **Falsification（证伪条件）** | 若某国实行全面计划经济但个人自由未受损害且经济持续繁荣，则断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义政府干预理论冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同父母为子女规划一切，虽出于好意，却使子女失去独立人格和应变能力

### 🔗 文字版因果链

1. 政府集中计划需要统一目标，压制个体差异
2. 为执行计划，政府扩大权力并限制个人选择
3. 权力集中导致信息扭曲和决策失误，经济效率下降
4. 为维持计划，政府进一步强制，最终走向极权
