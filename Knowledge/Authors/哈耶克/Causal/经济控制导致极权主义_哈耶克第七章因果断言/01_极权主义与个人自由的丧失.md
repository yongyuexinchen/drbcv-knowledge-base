# 极权主义与个人自由的丧失

> 属于因果簇：[[经济控制导致极权主义：哈耶克第七章因果断言]]（第1块/6块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对经济活动的集中控制（中央计划） |
| **DV（因变量）** | 极权主义与个人自由的丧失 |
| **Chain（传导链）** | 对相互关联的经济活动进行有意识的指导需要由专家和总指挥集中决策 → 集中计划意味着由社会（或其代表）决定各种需要的相对重要性，而非由个人决定 → 控制一切经济活动的人同时控制了实现所有目标的手段 → 对手段的唯一控制权必然决定哪些目标被认可、哪些被贬低，从而决定人们应当相信和追求什么 → 经济控制扩展至消费、职业、闲暇等全部生活领域，最终形成极权主义控制 |
| **Lag（时滞）** | 无明确时滞；随着计划范围扩大而逐步显现，可能是数年到数十年 |
| **Threshold（临界值）** | 当局对经济活动拥有唯一且全面的控制权；一旦“任何控制一切经济活动的人”出现，因果链启动 |
| **前提与约束（Premises）** | 现代社会高度分工，个人生活几乎都依赖于他人的经济活动；中央计划取代竞争性市场机制；计划当局的权力不受民主程序约束 |
| **Falsification（证伪条件）** | 若能证明中央计划可以与政治民主和个人自由长期共存，或集中控制经济不会导致对目标与价值的全面决定，则可证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 一个人若控制了你的钱包和所有谋生渠道，就实际上决定了你能追求什么梦想；就像水闸控制水流，也决定了哪块田地能灌溉。

### 🔗 文字版因果链

1. 对相互关联的经济活动进行有意识的指导需要由专家和总指挥集中决策
2. 集中计划意味着由社会（或其代表）决定各种需要的相对重要性，而非由个人决定
3. 控制一切经济活动的人同时控制了实现所有目标的手段
4. 对手段的唯一控制权必然决定哪些目标被认可、哪些被贬低，从而决定人们应当相信和追求什么
5. 经济控制扩展至消费、职业、闲暇等全部生活领域，最终形成极权主义控制
