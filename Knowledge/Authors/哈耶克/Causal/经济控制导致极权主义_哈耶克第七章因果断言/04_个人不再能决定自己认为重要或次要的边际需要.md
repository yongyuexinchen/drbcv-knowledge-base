# 个人不再能决定自己认为重要或次要的边际需要

> 属于因果簇：[[经济控制导致极权主义：哈耶克第七章因果断言]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集中计划代替个人决策 |
| **DV（因变量）** | 个人不再能决定自己认为重要或次要的边际需要 |
| **Chain（传导链）** | 在竞争性经济中，经济得失通过价格影响边际需要，个人可自由决定什么重要 → 集中计划要求社会或代表决定不同需要的相对重要性 → 个人宣布具体目的时必须获得计划者批准，否则受控 → 于是个人在所有事情上都被控制，连“什么是边际需要”也由计划者决定 |
| **Lag（时滞）** | 随计划对资源配置的介入而同步发生 |
| **Threshold（临界值）** | 计划当局一旦介入资源配置，并有权批准或拒绝个人具体目的 |
| **前提与约束（Premises）** | 不存在纯粹的经济目的；经济因素只是追求其他目标的条件；计划当局掌握有限手段的配置权 |
| **Falsification（证伪条件）** | 如果中央计划只影响物质边际而不触及个人价值判断，或计划者不决定个人目的的优先次序，则该断言可被推翻 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 旅行社不仅决定你住哪家酒店，还替你决定什么是“值得看的风景”；你以为是自己在旅行，其实只是按行程单走。

### 🔗 文字版因果链

1. 在竞争性经济中，经济得失通过价格影响边际需要，个人可自由决定什么重要
2. 集中计划要求社会或代表决定不同需要的相对重要性
3. 个人宣布具体目的时必须获得计划者批准，否则受控
4. 于是个人在所有事情上都被控制，连“什么是边际需要”也由计划者决定
