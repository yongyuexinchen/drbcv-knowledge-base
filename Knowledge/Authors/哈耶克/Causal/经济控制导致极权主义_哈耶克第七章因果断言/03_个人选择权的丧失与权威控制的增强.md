# 个人选择权的丧失与权威控制的增强

> 属于因果簇：[[经济控制导致极权主义：哈耶克第七章因果断言]]（第3块/6块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以非经济激励（公开表彰、特权、实物分配等）取代金钱报酬 |
| **DV（因变量）** | 个人选择权的丧失与权威控制的增强 |
| **Chain（传导链）** | 金钱作为一种通用工具，给穷人提供广泛的选择机会 → 若报酬采取非货币形式，接受者无法自行选择使用方式 → 分配者不仅决定报酬大小，还决定报酬的具体形式与享受方式 → 个人对自身目标的自主权被削弱，权威对生活的控制增强 |
| **Lag（时滞）** | 一旦普遍实行非经济报酬制度，控制效果立即出现 |
| **Threshold（临界值）** | 所有或大部分报酬都由中央权威以非货币形式分配 |
| **前提与约束（Premises）** | 报酬分配权集中在计划者或当局手中；个人无法将非经济报酬自由转换为其他形式 |
| **Falsification（证伪条件）** | 如果能设计一种非经济激励体系，使接受者可以自由选择所希望的回报形式，或分配者不决定具体享受方式，则可证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 发给你一张只能在指定商店兑换指定商品的奖券，而不是现金；发奖人决定的不只是奖赏大小，还包括你的消费方向。

### 🔗 文字版因果链

1. 金钱作为一种通用工具，给穷人提供广泛的选择机会
2. 若报酬采取非货币形式，接受者无法自行选择使用方式
3. 分配者不仅决定报酬大小，还决定报酬的具体形式与享受方式
4. 个人对自身目标的自主权被削弱，权威对生活的控制增强
