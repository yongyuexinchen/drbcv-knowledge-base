# 社会主义计划导致通往奴役之路

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会主义（集体主义经济计划） |
| **DV（因变量）** | 通往奴役（极权主义、丧失个人自由） |
| **Chain（传导链）** | 社会主义以集体计划取代个人自由决策 → 计划需要集中权力，强制实施统一目标 → 权力集中导致对个人自由的限制和压制 → 最终演变为极权主义或法西斯主义 |
| **Lag（时滞）** | 长期，数十年（如从19世纪社会主义兴起到20世纪极权主义出现） |
| **Threshold（临界值）** | 当经济计划取代市场机制，且政治权力不受制约时 |
| **前提与约束（Premises）** | 仅当社会主义以中央计划为核心且缺乏法治和民主制衡时成立；在民主社会主义框架下若保留个人自由和市场机制，可能不成立；排除混合经济或社会民主主义（如北欧模式） |
| **Falsification（证伪条件）** | 若存在一个实行中央计划但保持高程度个人自由且未走向极权主义的长期案例，则可推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与民主社会主义者（如伯恩斯坦）认为社会主义可与自由兼容的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 社会主义以集体计划取代个人自由决策
2. 计划需要集中权力，强制实施统一目标
3. 权力集中导致对个人自由的限制和压制
4. 最终演变为极权主义或法西斯主义
