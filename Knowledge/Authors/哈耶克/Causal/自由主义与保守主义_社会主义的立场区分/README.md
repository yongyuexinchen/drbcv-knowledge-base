# 自由主义与保守主义、社会主义的立场区分（因果簇）

> 因果簇索引：2 个子因果卡。父卡文件：自由主义与保守主义_社会主义的立场区分.md

## 总体因果图

- 自由主义者对个人理性的不信任和对自发秩序的尊重 → 自由主义者与保守主义者和社会主义者保持距离，形成独特的政治立
- 自由主义者对专断权力的反对 → 自由主义与辉格主义传统相连，成为一贯反对专断权力的思想体系
