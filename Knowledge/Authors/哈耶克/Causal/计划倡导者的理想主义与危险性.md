# 计划倡导者的理想主义与危险性

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 计划倡导者结合了理想主义者和单一任务献身者，且其观察具有局限性并夸大目标 |
| **DV（因变量）** | 计划倡导者成为最危险和最不能容忍别人计划的人 |
| **Chain（传导链）** | 计划倡导者多为理想主义者，专注于单一目标，缺乏对社会全面观察 → 这种局限性导致他们夸大所重视目标的重要性 → 当这些理想主义者被允许实施计划时，其偏执和狂热倾向会显现 → 从理想家到狂热者仅一步之遥，导致他们不容忍其他计划，成为危险力量 |
| **Lag（时滞）** | 即时，当计划者获得权力时效应显现 |
| **Threshold（临界值）** | 无明确量化阈值，但前提是计划者获得实施计划的权力 |
| **前提与约束（Premises）** | 计划者具有真心真意的理想主义但观察局限；计划者被允许实施其计划；社会是自由社会，存在个人行动的非人为限制 |
| **Falsification（证伪条件）** | 如果计划倡导者在获得权力后表现出宽容和全面考虑，且未导致不容忍和危险后果，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与计划支持者如哈耶克所批评的集体主义计划观冲突，但哈耶克本人也持类似批评，故无直接冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一群只盯着自己目标的狂热粉丝，一旦掌权，会把自己的喜好强加于人，排斥其他一切，最终让世界变得单调而难以忍受。

### 🔗 文字版因果链

1. 计划倡导者多为理想主义者，专注于单一目标，缺乏对社会全面观察
2. 这种局限性导致他们夸大所重视目标的重要性
3. 当这些理想主义者被允许实施计划时，其偏执和狂热倾向会显现
4. 从理想家到狂热者仅一步之遥，导致他们不容忍其他计划，成为危险力量
