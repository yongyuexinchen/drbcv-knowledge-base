# 价值计算成为生命核算（引导个人做最有益于增加成员的事情）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第9块/15块）

## 因果断言 9

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场经济占上风（因其规则使群体更好繁衍） |
| **DV（因变量）** | 价值计算成为生命核算（引导个人做最有益于增加成员的事情） |
| **Chain（传导链）** | 市场经济规则使采纳者群体繁衍更成功 → 因此，市场经济的价值计算被采用 → 这种计算引导个人行为，即使非本意，也最有益于增加群体成员 → 生命核算成为市场活动的最终后果 |
| **Lag（时滞）** | 长期（繁衍和规则扩散需要时间） |
| **Threshold（临界值）** | 无明确阈值，但市场经济需在群体中占主导 |
| **前提与约束（Premises）** | 市场经济确实使群体繁衍更成功；价值计算被个人遵循；个人行为影响群体人口 |
| **Falsification（证伪条件）** | 如果市场经济下群体繁衍失败，或价值计算未引导有益行为，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为市场经济导致人口下降或道德沦丧的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同企业追求利润最大化，最终导致员工增加，尽管非本意

### 🔗 文字版因果链

1. 市场经济规则使采纳者群体繁衍更成功
2. 因此，市场经济的价值计算被采用
3. 这种计算引导个人行为，即使非本意，也最有益于增加群体成员
4. 生命核算成为市场活动的最终后果
