# 选择文明（接受扩展秩序，即使住贫民窟）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第15块/15块）

## 因果断言 15

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人们的选择（当有选择权时） |
| **DV（因变量）** | 选择文明（接受扩展秩序，即使住贫民窟） |
| **Chain（传导链）** | 第三世界平民百姓欣然接受扩展秩序机会 → 即使意味着住在城市贫民窟 → 欧洲农民对城市资本主义的反应类似 → 因此，人们有选择权时通常选择文明 |
| **Lag（时滞）** | 短期（选择立即做出） |
| **Threshold（临界值）** | 无明确阈值，但需要提供选择机会 |
| **前提与约束（Premises）** | 人们了解扩展秩序的好处；贫民窟是过渡代价；没有其他更好选择 |
| **Falsification（证伪条件）** | 如果人们有选择权但选择非文明（如回归乡村），则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为人们偏好传统乡村生活的浪漫观点冲突 |
| **Confidence（确信度）** | well-established |
