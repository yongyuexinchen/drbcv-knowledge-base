# 边缘地区贫困

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第3块/15块）

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 边缘地区居民受经济边际效用支配（而非乡下人） |
| **DV（因变量）** | 边缘地区贫困 |
| **Chain（传导链）** | 边缘地区居民受经济边际效用支配，意味着他们的经济活动处于边际状态 → 第三世界政府的经济管理产生逆循环效用，并让步于既得利益者 → 这些政策消灭边缘群体的就业机会 → 因此，边缘地区贫困持续 |
| **Lag（时滞）** | 中期（政策影响逐渐显现） |
| **Threshold（临界值）** | 无明确阈值，但政府干预程度越高，贫困越严重 |
| **前提与约束（Premises）** | 边缘地区居民确实受边际效用支配；政府政策对就业机会有负面影响；存在既得利益者或社会改革家的让步 |
| **Falsification（证伪条件）** | 如果边缘地区贫困在政府干预减少时改善，或政府政策未影响就业，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为贫困主要源于个人懒惰或资源匮乏的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🔗 文字版因果链

1. 边缘地区居民受经济边际效用支配，意味着他们的经济活动处于边际状态
2. 第三世界政府的经济管理产生逆循环效用，并让步于既得利益者
3. 这些政策消灭边缘群体的就业机会
4. 因此，边缘地区贫困持续
