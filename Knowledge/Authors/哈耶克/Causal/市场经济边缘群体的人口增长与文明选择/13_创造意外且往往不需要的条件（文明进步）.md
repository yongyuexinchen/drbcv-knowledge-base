# 创造意外且往往不需要的条件（文明进步）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第13块/15块）

## 因果断言 13

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 人们开始让具体共同目标服从抽象规则 |
| **DV（因变量）** | 创造意外且往往不需要的条件（文明进步） |
| **Chain（传导链）** | 抽象规则使人们参与有序合作过程 → 这个过程无人能完全安排或预测 → 因此，产生意外结果，包括人口增长 → 这些结果使文明成为可能 |
| **Lag（时滞）** | 长期（规则演化需要时间） |
| **Threshold（临界值）** | 无明确阈值，但需要规则被广泛遵循 |
| **前提与约束（Premises）** | 抽象规则被采纳；合作过程有序；结果不可预测但可接受 |
| **Falsification（证伪条件）** | 如果抽象规则导致混乱或文明倒退，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为具体目标导向更有效率的观点冲突 |
| **Confidence（确信度）** | plausible |
