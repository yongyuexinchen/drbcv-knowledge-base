# 市场报酬与功绩原则的因果分析

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_70_part_02_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场根据个人为他人提供的价值（而非主观功绩）决定报酬 |
| **DV（因变量）** | 个人收入差异及社会对不平等的感知 |
| **Chain（传导链）** | 市场通过价格机制反映个人服务对他人的价值 → 个人收入取决于其服务在市场上的交换价值，而非其主观努力或功绩 → 因此，收入差异反映的是市场评价的差异，而非道德功绩的差异 → 当社会试图按功绩分配报酬时，会导致对不平等的认知扭曲，加剧妒忌和怨恨 |
| **Lag（时滞）** | 长期显现，随社会观念转变而逐渐明显 |
| **Threshold（临界值）** | 当社会从市场分配转向功绩分配时，因果效应显著增强 |
| **前提与约束（Premises）** | 市场机制有效运行，个人可自由选择职业；个人能力存在差异，且市场评价与主观功绩不一致；社会普遍接受市场分配原则，而非追求绝对平等 |
| **Falsification（证伪条件）** | 如果在一个按功绩分配的社会中，妒忌和怨恨没有增加，或市场分配导致更大的社会不满，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张按功绩或需要分配报酬的正义理论（如罗尔斯的分配正义）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像比赛评分，裁判按选手表现打分（市场价值），但观众可能认为某选手更努力应得更高分（功绩），这种分歧导致争议和不满。

### 🔗 文字版因果链

1. 市场通过价格机制反映个人服务对他人的价值
2. 个人收入取决于其服务在市场上的交换价值，而非其主观努力或功绩
3. 因此，收入差异反映的是市场评价的差异，而非道德功绩的差异
4. 当社会试图按功绩分配报酬时，会导致对不平等的认知扭曲，加剧妒忌和怨恨
