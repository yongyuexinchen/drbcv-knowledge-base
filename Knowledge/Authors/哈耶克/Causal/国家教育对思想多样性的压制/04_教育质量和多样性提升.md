# 教育质量和多样性提升

> 属于因果簇：[[国家教育对思想多样性的压制]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 教育凭单制度（政府资助但学校竞争） |
| **DV（因变量）** | 教育质量和多样性提升 |
| **Chain（传导链）** | 家长凭单自由选择学校，学校为吸引生源而竞争 → 竞争促使学校改善教学、创新课程 → 多样化学校满足不同需求，整体教育水平提高 |
| **Lag（时滞）** | 短期至中期（1-5年） |
| **Threshold（临界值）** | 凭单覆盖全部教育费用或大部分，且学校准入自由 |
| **前提与约束（Premises）** | 存在足够数量的私立学校可供选择；政府仅提供资金和基本标准监管，不直接管理学校；家长有信息和能力做出选择 |
| **Falsification（证伪条件）** | 如果凭单制度导致教育质量下降或加剧不平等，则此断言需重新评估 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与政府直接办学支持者冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同餐饮业竞争，食客用代金券自由选择，促使餐馆提升菜品和服务。

### 🔗 文字版因果链

1. 家长凭单自由选择学校，学校为吸引生源而竞争
2. 竞争促使学校改善教学、创新课程
3. 多样化学校满足不同需求，整体教育水平提高
