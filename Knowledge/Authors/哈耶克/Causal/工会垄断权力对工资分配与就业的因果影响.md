# 工会垄断权力对工资分配与就业的因果影响

> **领域**：劳动经济学、宏观经济学　|　**来源**：哈耶克_chapter_82_part_02_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 工会的垄断性权力（如封闭型企业制度、集体谈判特权、强制入会） |
| **DV（因变量）** | 低收入群体的实际收入下降、就业机会减少、工资结构扭曲 |
| **Chain（传导链）** | 工会利用强制入会和集体谈判特权，限制劳动力供给，抬高部分工会成员的工资 → 高工资成本转嫁给消费者和雇主，导致雇主减少雇佣或投资于替代技术 → 未组织起来的低收入工人（如女佣、小商人）面临更激烈的竞争和更低的相对工资 → 整体工资结构偏离市场均衡，实际工资水平与充分就业目标冲突 |
| **Lag（时滞）** | 短期（数月到数年）内显现工资差异，长期（数年）内导致就业结构变化 |
| **Threshold（临界值）** | 当工会覆盖率达到一定水平（如行业性集体谈判覆盖多数企业）时，垄断效应显著 |
| **前提与约束（Premises）** | 工会拥有法律赋予的强制权力（如封闭型企业制度）；劳动力市场存在不完全竞争，替代性就业机会有限；货币政策适应工资变化而非相反（如非金本位制度） |
| **Falsification（证伪条件）** | 如果数据显示工会化程度高的行业工资增长与低工会化行业同步，且低收入群体实际收入未下降，则该断言被推翻 |
| **Data（定量佐证）** | 美国女佣（未组织）年均工资1947年比1939年增加2.72倍，而钢铁工人（高度组织）仅增加1.98倍 |
| **Conflicts（观点冲突）** | 与凯恩斯主义或支持工会的学者（如贝弗里奇、伍顿）的工资政策主张冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个村庄里，最强壮的农夫联合起来垄断了水井，迫使其他村民用更高的代价买水，结果最穷的村民反而喝不上水。

### 🔗 文字版因果链

1. 工会利用强制入会和集体谈判特权，限制劳动力供给，抬高部分工会成员的工资
2. 高工资成本转嫁给消费者和雇主，导致雇主减少雇佣或投资于替代技术
3. 未组织起来的低收入工人（如女佣、小商人）面临更激烈的竞争和更低的相对工资
4. 整体工资结构偏离市场均衡，实际工资水平与充分就业目标冲突
