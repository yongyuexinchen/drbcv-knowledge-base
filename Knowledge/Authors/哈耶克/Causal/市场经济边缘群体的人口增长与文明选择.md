## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 市场经济边缘群体尚未完全适应市场经济的传统、道德和习惯（如仍实践高生育率习惯） |
| **DV（因变量）** | 这些城市的人口增长（边缘群体生育更多后代） |
| **Chain（传导链）** | 边缘群体从参与市场经济中获益（如医疗、信息、经济制度） → 但未完全适应市场经济传统，仍保留旧生育习惯（财富增加时首先生育后代） → 旧习惯逐渐消失，靠近中心的群体接受节制生育传统 → 因此，在过渡期间，边缘群体生育率较高，推动城市人口增长 |
| **Lag（时滞）** | 一代人或更长时间（旧习惯逐渐消失，但过程缓慢或迅速因地区而异） |
| **Threshold（临界值）** | 无明确量化阈值，但边缘群体靠近中心程度越高，节制生育接受越快 |
| **前提与约束（Premises）** | 边缘群体确实从市场经济中获益；旧生育习惯在财富增加时首先表现为生育后代；存在一个逐渐接受节制生育的过程 |
| **Falsification（证伪条件）** | 如果边缘群体在获得财富后立即降低生育率，或城市人口增长主要来自移民而非生育，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与马尔萨斯人口论中关于人口增长导致贫困的悲观观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 如同新移民初到发达国家时保留原生育习惯，但第二代后逐渐融入当地低生育率模式

### 🔗 文字版因果链

1. 边缘群体从参与市场经济中获益（如医疗、信息、经济制度）
2. 但未完全适应市场经济传统，仍保留旧生育习惯（财富增加时首先生育后代）
3. 旧习惯逐渐消失，靠近中心的群体接受节制生育传统
4. 因此，在过渡期间，边缘群体生育率较高，推动城市人口增长
