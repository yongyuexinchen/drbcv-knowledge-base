## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律作为一般抽象规则（非具体命令） |
| **DV（因变量）** | 个人自由（不屈服于他人意志） |
| **Chain（传导链）** | 法律被制定为一般且抽象的规则，不针对特定人或情况 → 立法者无法预见规则适用的具体情形，因此无法将个人意志强加于行动者 → 个人在遵守规则时，仍能运用自身知识追求自己的目标 → 因此，个人行动不受他人专断意志支配，实现自由 |
| **Lag（时滞）** | 即时（法律性质决定其效果） |
| **Threshold（临界值）** | 法律必须具有普遍性和抽象性，且对所有人（包括政府）平等适用 |
| **前提与约束（Premises）** | 法律规则不针对特定个人或群体；法律规则对立法者、执法者和被统治者一视同仁；法律规则不指定具体行动，只划定行动边界 |
| **Falsification（证伪条件）** | 如果存在法律规则虽抽象但仅对特定群体有利或有害，且该区分不被群体内外共同认可，则自由受损 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与霍姆斯'一般主张决定不了具体情况'及'法律不能统治国家，惟独人才能统治'的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：红灯停是普遍规则，不针对特定司机，但每个司机都能在遵守规则的前提下自由选择目的地和路线。

### 🔗 文字版因果链

1. 法律被制定为一般且抽象的规则，不针对特定人或情况
2. 立法者无法预见规则适用的具体情形，因此无法将个人意志强加于行动者
3. 个人在遵守规则时，仍能运用自身知识追求自己的目标
4. 因此，个人行动不受他人专断意志支配，实现自由
