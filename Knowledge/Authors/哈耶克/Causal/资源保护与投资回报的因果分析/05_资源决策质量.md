# 资源决策质量

> 属于因果簇：[[资源保护与投资回报的因果分析]]（第5块/6块）

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府集中知识 |
| **DV（因变量）** | 资源决策质量 |
| **Chain（传导链）** | 政府掌握一般性知识，但缺乏特定资源的地方性知识 → 特定知识分散于个人所有者，无法集中 → 集中决策可能忽略关键信息，导致决策质量下降 → 分散决策能整合更多知识，提高决策质量 |
| **Lag（时滞）** | 即时至短期（决策时） |
| **Threshold（临界值）** | 当特定知识的重要性超过一般知识时 |
| **前提与约束（Premises）** | 仅当资源决策依赖地方性知识时；政府无法获取或处理所有分散知识 |
| **Falsification（证伪条件）** | 若政府能有效整合所有相关知识，或集中决策优于分散决策，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持中央计划的知识优越性观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个大型图书馆，中央管理员知道所有书的分类，但只有各领域的专家知道哪本书最适合特定问题，因此需要分散咨询。

### 🔗 文字版因果链

1. 政府掌握一般性知识，但缺乏特定资源的地方性知识
2. 特定知识分散于个人所有者，无法集中
3. 集中决策可能忽略关键信息，导致决策质量下降
4. 分散决策能整合更多知识，提高决策质量
