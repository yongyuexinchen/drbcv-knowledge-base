# 政府投资效率

> 属于因果簇：[[资源保护与投资回报的因果分析]]（第4块/6块）

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府以较低利率借款 |
| **DV（因变量）** | 政府投资效率 |
| **Chain（传导链）** | 政府以低利率借款，看似成本低 → 但风险由纳税人承担，实际风险未减少 → 政府可能因风险外部化而过度投资或投资不当 → 导致资源分配效率低于市场 |
| **Lag（时滞）** | 中期（投资周期内） |
| **Threshold（临界值）** | 政府投资风险与私人投资风险相当时，低利率优势消失 |
| **前提与约束（Premises）** | 仅当政府投资失败风险由纳税人承担时；政府无法准确评估投资风险 |
| **Falsification（证伪条件）** | 若政府投资能准确评估风险且回报率高于私人投资，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持政府低利率借款促进长期投资的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 政府以低利率借款，看似成本低
2. 但风险由纳税人承担，实际风险未减少
3. 政府可能因风险外部化而过度投资或投资不当
4. 导致资源分配效率低于市场
