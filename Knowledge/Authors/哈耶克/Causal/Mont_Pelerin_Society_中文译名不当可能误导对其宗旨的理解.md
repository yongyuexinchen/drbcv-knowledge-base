# Mont Pelerin Society 中文译名不当可能误导对其宗旨的理解

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 将“Mont Pelerin”误译为“朝圣山” |
| **DV（因变量）** | 对学社宗旨（表达意见自由、自由市场经济、开放社会的政治价值观）的错误理解 |
| **Chain（传导链）** | “朝圣山”一词带有宗教朝圣含义，而实际地名并无此意 → 译名中的“朝圣”暗示学社具有某种神圣或宗教性使命，偏离其实际的政治经济主张 → 读者可能基于译名产生对学社性质的误解，从而错误理解其宗旨 |
| **Lag（时滞）** | 长期，译名一旦固定并广泛使用，误解会持续存在 |
| **Threshold（临界值）** | 无明确量化阈值，但译名若被广泛采用则影响显著 |
| **前提与约束（Premises）** | 译名在中文语境中被广泛使用；读者对学社背景不了解，依赖译名进行初步理解 |
| **Falsification（证伪条件）** | 若能证明“朝圣山”译名并未导致读者对学社宗旨的误解，或该地名确有朝圣历史，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 无 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像把“Newfoundland”译为“新发现地”可能让人误以为该地是新近发现的，而实际上其历史久远，译名会误导认知。

### 🔗 文字版因果链

1. “朝圣山”一词带有宗教朝圣含义，而实际地名并无此意
2. 译名中的“朝圣”暗示学社具有某种神圣或宗教性使命，偏离其实际的政治经济主张
3. 读者可能基于译名产生对学社性质的误解，从而错误理解其宗旨
