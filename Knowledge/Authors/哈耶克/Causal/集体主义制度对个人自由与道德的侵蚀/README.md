# 集体主义制度对个人自由与道德的侵蚀（因果簇）

> 因果簇索引：5 个子因果卡。父卡文件：集体主义制度对个人自由与道德的侵蚀.md

## 总体因果图

- 以政治权力代替经济权力（经济权力集中化） → 个人自由的丧失，依附性等同于奴隶制度
- 集体主义制度（共同目标体系与最大权力愿望） → 道德体系丧失普遍规则，个人良心自由被剥夺
- 集体主义道德缺乏绝对正式规则 → 个人习惯被工具化，道德品格消失
- 极权主义政体（基于集体主义前提） → 残酷镇压异己、无视个人生命幸福的行为
- 极权主义领导职位选拔机制 → 残酷无情、寡廉鲜耻者占据高位
