# 个人自由的丧失，依附性等同于奴隶制度

> 属于因果簇：[[集体主义制度对个人自由与道德的侵蚀]]（第1块/5块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 以政治权力代替经济权力（经济权力集中化） |
| **DV（因变量）** | 个人自由的丧失，依附性等同于奴隶制度 |
| **Chain（传导链）** | 经济权力分散在私人手中时，其强制力有限且非排他性 → 当经济权力被集中并作为政治权力的工具时，其控制范围扩大至个人全部生活 → 个人对集中权力的依附性增强，最终导致类似奴隶制度的依附状态 |
| **Lag（时滞）** | 长期，随着权力集中程度加深而逐步显现 |
| **Threshold（临界值）** | 当经济权力完全从属于政治权力，且政治权力无处不在时 |
| **前提与约束（Premises）** | 经济权力原本分散于私人手中；政治权力集中且不受限制；排除经济权力本身作为唯一强制工具的情况 |
| **Falsification（证伪条件）** | 如果存在一个经济权力高度集中但个人自由未受损害的社会实例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自由放任主义或古典自由主义观点冲突，如亚当·斯密认为经济自由是个人自由的基础 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同将分散的溪流汇成洪流，一旦决堤，淹没一切；分散的经济权力如溪流，集中后如洪水，摧毁个人自由的堤坝

### 🔗 文字版因果链

1. 经济权力分散在私人手中时，其强制力有限且非排他性
2. 当经济权力被集中并作为政治权力的工具时，其控制范围扩大至个人全部生活
3. 个人对集中权力的依附性增强，最终导致类似奴隶制度的依附状态
