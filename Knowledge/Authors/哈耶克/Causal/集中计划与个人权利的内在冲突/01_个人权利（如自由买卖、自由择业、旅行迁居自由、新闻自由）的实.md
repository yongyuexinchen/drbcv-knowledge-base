# 个人权利（如自由买卖、自由择业、旅行迁居自由、新闻自由）的实

> 属于因果簇：[[集中计划与个人权利的内在冲突]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集中计划（政府全面控制经济生活） |
| **DV（因变量）** | 个人权利（如自由买卖、自由择业、旅行迁居自由、新闻自由）的实质性丧失 |
| **Chain（传导链）** | 集中计划要求政府控制资源分配和产业布局 → 为实施计划，政府必须对买卖、职业、迁徙、信息传播等施加限制 → 这些限制以'公共福利'等名义被合理化，但实际剥夺了个人选择权 → 最终，形式上承认的权利因缺乏实质保障而失去意义 |
| **Lag（时滞）** | 短期（计划实施后立即显现） |
| **Threshold（临界值）** | 当政府对经济活动的控制达到'彻底管制'程度时，个人权利即失效 |
| **前提与约束（Premises）** | 计划当局拥有对关键资源（如纸张、发行渠道）的垄断控制；'公共福利'等模糊概念被用作限制的正当理由；经济政策工具可被用于歧视特定群体 |
| **Falsification（证伪条件）** | 如果存在一个集中计划体制下个人权利得到实质性保障的实证案例，且该体制未依赖市场自发秩序，则此断言可被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与威尔斯在《人权宣言》中主张个人权利与计划兼容的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像一个人既想完全控制厨房的每道菜，又希望厨师有自由发挥的空间——最终控制必然扼杀自由

### 🔗 文字版因果链

1. 集中计划要求政府控制资源分配和产业布局
2. 为实施计划，政府必须对买卖、职业、迁徙、信息传播等施加限制
3. 这些限制以'公共福利'等名义被合理化，但实际剥夺了个人选择权
4. 最终，形式上承认的权利因缺乏实质保障而失去意义
