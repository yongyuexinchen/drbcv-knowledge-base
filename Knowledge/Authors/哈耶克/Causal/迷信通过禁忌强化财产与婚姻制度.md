## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 迷信（禁忌）的存在 |
| **DV（因变量）** | 私有财产关系的强化与婚姻性道德的遵守 |
| **Chain（传导链）** | 迷信赋予某些事物以禁忌地位，使其具有超自然或神秘力量 → 禁忌使非所有者不敢接近或侵犯，从而保护私有财产 → 禁忌强化对婚姻的尊重，使已婚者和未婚者更严格服从性道德规则 → 最终，迷信通过提供行为端正的动机（即使动机错误）促进社会秩序 |
| **Lag（时滞）** | 长期，跨代际（弗雷泽引用历史与当代民族志证据） |
| **Threshold（临界值）** | 无明确量化阈值，但需禁忌具有社会普遍认可的超自然效力 |
| **前提与约束（Premises）** | 社会成员普遍相信禁忌的超自然力量；禁忌适用于财产和婚姻等核心社会制度；行为比动机更重要，社会关注的是外在行为而非内在看法 |
| **Falsification（证伪条件）** | 如果存在一个社会，其禁忌体系完善但私有财产混乱或婚姻道德松弛，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（引用新西兰和马昆德群岛的早期报告） |
| **Conflicts（观点冲突）** | 与社会主义观点冲突（弗雷泽暗示社会主义者视禁忌为'打造锁链'） |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 迷信如同社会制度的'防盗锁'，即使锁的钥匙是错的，但锁本身仍能防止小偷进入

### 🔗 文字版因果链

1. 迷信赋予某些事物以禁忌地位，使其具有超自然或神秘力量
2. 禁忌使非所有者不敢接近或侵犯，从而保护私有财产
3. 禁忌强化对婚姻的尊重，使已婚者和未婚者更严格服从性道德规则
4. 最终，迷信通过提供行为端正的动机（即使动机错误）促进社会秩序
