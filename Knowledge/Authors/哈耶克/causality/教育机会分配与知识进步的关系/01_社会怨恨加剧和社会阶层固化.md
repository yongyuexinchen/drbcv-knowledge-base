# 社会怨恨加剧和社会阶层固化

> 属于因果簇：[[教育机会分配与知识进步的关系]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 基于测试和考试的能力筛选制度 |
| **DV（因变量）** | 社会怨恨加剧和社会阶层固化 |
| **Chain（传导链）** | 按测试能力分配教育机会，形成官方等级划分 → 等级被赋予‘功绩’合法性，强化职业声望差异 → 未获机会者将失败归因于制度合法性，怨恨反而加剧 → 社会模式趋于僵化，而非流动 |
| **Lag（时滞）** | 短期至中期（一代人内显现） |
| **Threshold（临界值）** | 当测试成为唯一或主导的筛选标准时 |
| **前提与约束（Premises）** | 教育机会主要由国家统一分配；社会普遍接受测试的合法性；存在不同社会群体间的机会差异 |
| **Falsification（证伪条件）** | 若证据显示基于测试的筛选显著提高社会流动性且怨恨水平下降，则断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持‘机会平等’（按能力分配）的平等主义观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 像用一把尺子量所有水果，苹果和香蕉都按长度分级，但消费者可能更怨恨被标为‘次品’的香蕉，而不是接受它们本来的不同。

### 🔗 文字版因果链

1. 按测试能力分配教育机会，形成官方等级划分
2. 等级被赋予‘功绩’合法性，强化职业声望差异
3. 未获机会者将失败归因于制度合法性，怨恨反而加剧
4. 社会模式趋于僵化，而非流动
