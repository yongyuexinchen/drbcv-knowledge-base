# 教育机会分配与知识进步的关系（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：教育机会分配与知识进步的关系.md

## 总体因果图

- 基于测试和考试的能力筛选制度 → 社会怨恨加剧和社会阶层固化
- 家庭环境对知识兴趣的传递 → 个人成就（尤其是非测试可测的贡献）
- 独立的研究中心和多元资助来源 → 知识进步的速度和原创性
