# 边际效用革命与主观主义对经济事件因果解释的否定（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：边际效用革命与主观主义对经济事件因果解释的否定.md

## 总体因果图

- 边际效用理论（主观主义革命）的发现与传播 → 经济理论被整合为严密体系，并正确理解供应与需求的决定机制
- 宏观经济学（在统计数字中寻找因果关系）的兴起 → 边际效用理论的贡献被掩盖，政府政策基于幼稚的客观价值解释
- 对贸易和利润的鄙视（基于无知和返祖现象） → 政治态度歪曲，阻碍最有效的生产组织发展，鼓舞社会主义错误希望
