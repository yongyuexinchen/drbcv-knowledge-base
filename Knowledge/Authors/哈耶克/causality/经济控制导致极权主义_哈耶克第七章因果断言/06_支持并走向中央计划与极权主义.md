# 支持并走向中央计划与极权主义

> 属于因果簇：[[经济控制导致极权主义：哈耶克第七章因果断言]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对“潜在丰裕”的虚幻信念（认为不存在经济问题、无需选择） |
| **DV（因变量）** | 支持并走向中央计划与极权主义 |
| **Chain（传导链）** | 人们因害怕痛苦的选择而希望不存在经济问题 → “潜在丰裕”的说法让人相信选择并非必要 → 这一虚幻希望推动人们接受中央计划作为解决方案 → 而集中计划必然要求集中控制，最终走向极权主义 |
| **Lag（时滞）** | 长期存在的思想影响；可能经过数代人的政治动员后才显现制度后果 |
| **Threshold（临界值）** | 当多数人被“无需选择”的承诺吸引并接受计划体制时 |
| **前提与约束（Premises）** | “潜在丰裕”在事实上不成立，迄今没有可行的增产计划来消除稀缺；资源稀缺和选择不可避免 |
| **Falsification（证伪条件）** | 如果“潜在丰裕”被证实且存在无需牺牲自由的计划方案能消除稀缺，或计划可以不通过集中控制实现，则该断言被证伪 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 相信只要发明一种“万能药”就不需要医生诊断；这种幻觉让你心甘情愿把健康决策交给一个统一开药的权威。

### 🔗 文字版因果链

1. 人们因害怕痛苦的选择而希望不存在经济问题
2. “潜在丰裕”的说法让人相信选择并非必要
3. 这一虚幻希望推动人们接受中央计划作为解决方案
4. 而集中计划必然要求集中控制，最终走向极权主义
