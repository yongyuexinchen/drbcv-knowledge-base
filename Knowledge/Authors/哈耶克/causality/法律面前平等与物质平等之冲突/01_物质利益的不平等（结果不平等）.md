# 物质利益的不平等（结果不平等）

> 属于因果簇：[[法律面前平等与物质平等之冲突]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律面前人人平等（形式平等） |
| **DV（因变量）** | 物质利益的不平等（结果不平等） |
| **Chain（传导链）** | 法律面前人人平等要求政府对所有公民一视同仁，不因个人差异区别对待 → 由于个人在天赋、能力、家庭背景和环境上存在巨大差异，同等对待必然导致实际地位和物质利益的不平等 → 因此，法律平等与物质平等不可兼得，追求物质平等必然要求区别对待，即使用有差别的强制手段 |
| **Lag（时滞）** | 即时显现，但长期累积效应更显著 |
| **Threshold（临界值）** | 无明确量化阈值，但强调两者不可兼得，只能择其一 |
| **前提与约束（Premises）** | 个人之间存在先天和后天差异，且差异显著；政府强制手段应限于一般性规则，不得针对特定群体或个体；自由社会的基本公理是平等法律限制所有强制手段 |
| **Falsification（证伪条件）** | 若证明在保持法律平等的同时，通过非强制手段（如自愿再分配）能实现物质平等且不损害自由，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张通过国家干预实现物质平等的平等主义观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 赛跑中，所有选手站在同一起跑线（法律平等），但最终成绩必然有差异（物质不平等）；若要让所有人同时到达终点（物质平等），就必须让跑得快的人负重或让跑得慢的人提前起跑（区别对待）。

### 🔗 文字版因果链

1. 法律面前人人平等要求政府对所有公民一视同仁，不因个人差异区别对待
2. 由于个人在天赋、能力、家庭背景和环境上存在巨大差异，同等对待必然导致实际地位和物质利益的不平等
3. 因此，法律平等与物质平等不可兼得，追求物质平等必然要求区别对待，即使用有差别的强制手段
