# 道德体系丧失普遍规则，个人良心自由被剥夺

> 属于因果簇：[[集体主义制度对个人自由与道德的侵蚀]]（第2块/5块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 集体主义制度（共同目标体系与最大权力愿望） |
| **DV（因变量）** | 道德体系丧失普遍规则，个人良心自由被剥夺 |
| **Chain（传导链）** | 集体主义要求共同目标体系，并追求最大权力以实现目标 → 为达目标，道德规则变为权宜之计，以目的证明手段正当 → 个人良心不能自由运用规则，缺乏一般性道德约束，导致道德相对化 |
| **Lag（时滞）** | 中期，随着制度巩固而逐渐显现 |
| **Threshold（临界值）** | 当集体目标凌驾于一切个人价值之上时 |
| **前提与约束（Premises）** | 存在一个凌驾一切的目标体系；个人必须服从集体目标；排除个人主义道德体系存在的情况 |
| **Falsification（证伪条件）** | 如果存在一个集体主义制度但个人良心自由和普遍道德规则得以保留的实例，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与康德义务论伦理学冲突，后者强调道德规则的绝对性 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同游戏规则被随意更改以利于某方，集体主义道德如同无固定规则的比赛，裁判（集体）说了算

### 🔗 文字版因果链

1. 集体主义要求共同目标体系，并追求最大权力以实现目标
2. 为达目标，道德规则变为权宜之计，以目的证明手段正当
3. 个人良心不能自由运用规则，缺乏一般性道德约束，导致道德相对化
