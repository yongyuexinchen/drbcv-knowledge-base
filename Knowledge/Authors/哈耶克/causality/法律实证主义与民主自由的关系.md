## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律实证主义的胜利 |
| **DV（因变量）** | 民主与个人自由的分离 |
| **Chain（传导链）** | 法律实证主义强调法律与道德的分离，将法律视为主权者的命令或规范体系 → 这导致法律权威的合法性不再依赖于超越性的道德或自然法原则 → 民主制度因此被理解为多数决的程序，而非保障个人自由的机制 → 结果，民主与自由主义（个人自由）在理论上被分离开来 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 法律实证主义成为主流法学范式（如凯尔森的理论获得公认） |
| **前提与约束（Premises）** | 法律实证主义在法学界取得主导地位；民主理论接受实证主义的前提，将法律视为纯粹的人为规范 |
| **Falsification（证伪条件）** | 如果存在一个法律实证主义占主导但民主与个人自由仍紧密关联的案例，则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与自然法传统（如洛克、孟德斯鸠）认为民主与自由内在一致的观点冲突 |
| **Confidence（确信度）** | plausible |

### 🧩 生活类比

> 就像把游戏规则与道德分开后，多数人投票可以决定任何规则，但不再保证每个人的基本权利不受侵犯。

### 🔗 文字版因果链

1. 法律实证主义强调法律与道德的分离，将法律视为主权者的命令或规范体系
2. 这导致法律权威的合法性不再依赖于超越性的道德或自然法原则
3. 民主制度因此被理解为多数决的程序，而非保障个人自由的机制
4. 结果，民主与自由主义（个人自由）在理论上被分离开来
