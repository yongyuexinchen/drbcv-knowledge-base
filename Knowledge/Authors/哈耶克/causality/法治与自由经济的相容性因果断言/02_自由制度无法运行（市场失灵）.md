# 自由制度无法运行（市场失灵）

> 属于因果簇：[[法治与自由经济的相容性因果断言]]（第2块/3块）

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府实施物价管制与数量管制 |
| **DV（因变量）** | 自由制度无法运行（市场失灵） |
| **Chain（传导链）** | 物价管制使价格无法反映供求变化，市场信号扭曲 → 为维持管制，必须实行数量管制，决定谁可买卖 → 数量管制必然依赖行政酌情裁量，导致专断和不平等 → 市场机制被破坏，自由制度无法运行 |
| **Lag（时滞）** | 短期至中期，管制实施后市场扭曲逐渐显现 |
| **Threshold（临界值）** | 任何形式的物价管制或数量管制，无论程度如何，均与自由制度不相容 |
| **前提与约束（Premises）** | 市场是资源配置的有效机制；政府管制无法依据一般性规则实施，必然涉及具体判断；自由制度以个人决策和价格信号为基础 |
| **Falsification（证伪条件）** | 若存在物价管制下市场仍有效运行的案例，或管制未导致专断决策，则断言可能被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与支持价格管制以稳定经济的观点冲突，如某些计划经济理论 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 物价管制如同强行固定河流水位，但上游来水变化无常，最终只能靠人为分配水量，导致下游生态（市场）失衡。

### 🔗 文字版因果链

1. 物价管制使价格无法反映供求变化，市场信号扭曲
2. 为维持管制，必须实行数量管制，决定谁可买卖
3. 数量管制必然依赖行政酌情裁量，导致专断和不平等
4. 市场机制被破坏，自由制度无法运行
