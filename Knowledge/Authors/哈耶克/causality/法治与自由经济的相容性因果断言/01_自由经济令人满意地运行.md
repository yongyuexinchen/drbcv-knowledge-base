# 自由经济令人满意地运行

> 属于因果簇：[[法治与自由经济的相容性因果断言]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府强制行动受一般性法律规则约束（法治） |
| **DV（因变量）** | 自由经济令人满意地运行 |
| **Chain（传导链）** | 法治确保政府强制行动遵循持久、一般、非歧视的规则 → 个人能基于稳定预期进行规划，减少不确定性 → 市场机制（价格调整）得以正常运作，资源有效配置 → 自由经济实现令人满意的运行 |
| **Lag（时滞）** | 长期，法治框架的建立和效果显现需要时间 |
| **Threshold（临界值）** | 无明确量化阈值，但要求所有强制行动必须由持久性法律框架决定 |
| **前提与约束（Premises）** | 法治适用于所有政策领域，包括经济领域；政府强制行动必须明确由一般性规则决定，而非具体目的；市场机制本身运行良好，无其他重大干扰 |
| **Falsification（证伪条件）** | 若存在法治健全但自由经济运行不佳的实例，或法治不健全但自由经济运行良好的反例，则断言可能被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与主张政府干预经济有效的观点冲突，如凯恩斯主义 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 法治如同交通规则，车辆（经济主体）在明确规则下行驶，才能高效有序；若规则模糊或随意，交通（经济）必然混乱。

### 🔗 文字版因果链

1. 法治确保政府强制行动遵循持久、一般、非歧视的规则
2. 个人能基于稳定预期进行规划，减少不确定性
3. 市场机制（价格调整）得以正常运作，资源有效配置
4. 自由经济实现令人满意的运行
