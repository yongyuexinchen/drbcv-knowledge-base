# 宪法限制政府权力以保障自由

> **领域**：政治哲学、宪法学　|　**来源**：哈耶克_chapter_76_part_02_p1　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 成文宪法对政府权力（尤其是立法权）的明确限制 |
| **DV（因变量）** | 公民自由与财产权的保障 |
| **Chain（传导链）** | 成文宪法确立固定的基本法，高于普通立法 → 立法机构权力源于宪法，不得超越宪法界限 → 司法机构有权审查并宣布违宪法律无效 → 政府权力受到约束，无法任意侵犯个人权利 → 公民自由与财产权得到有效保障 |
| **Lag（时滞）** | 长期（宪法实施后持续生效，但效果随司法实践逐步显现） |
| **Threshold（临界值）** | 宪法必须包含对立法权的特定例外限制（如不得通过剥夺权利法案、事后追补法律等），且司法审查机制有效运作 |
| **前提与约束（Premises）** | 宪法是固定的、高于立法机构的最高法律；立法机构不能自行修改宪法（需特殊制宪程序）；存在独立的司法机构执行违宪审查；排除直接民主制（防止多数人暴政） |
| **Falsification（证伪条件）** | 若某国拥有成文宪法但公民自由仍被系统性侵犯（如宪法被架空或司法不独立），则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于历史案例与理论论证） |
| **Conflicts（观点冲突）** | 与卢梭式人民主权绝对论冲突（认为立法机构代表公意不应受限） |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 宪法如同游戏规则，裁判（司法）确保玩家（政府）不违规，否则游戏（自由）会被破坏。

### 🔗 文字版因果链

1. 成文宪法确立固定的基本法，高于普通立法
2. 立法机构权力源于宪法，不得超越宪法界限
3. 司法机构有权审查并宣布违宪法律无效
4. 政府权力受到约束，无法任意侵犯个人权利
5. 公民自由与财产权得到有效保障
