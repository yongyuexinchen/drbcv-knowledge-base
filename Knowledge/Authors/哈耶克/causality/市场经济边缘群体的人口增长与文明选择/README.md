# 市场经济边缘群体的人口增长与文明选择（因果簇）

> 因果簇索引：15 个子因果卡。父卡文件：市场经济边缘群体的人口增长与文明选择.md

## 总体因果图

- 市场经济边缘群体尚未完全适应市场经济的传统、道德和习惯（如仍实践高生育率习惯） → 这些城市的人口增长（边缘群体生育更多后代）
- 城市贫民窟的存在（作为边缘群体聚集地） → 农村人口并未减少，且农村人口从城市发展中获益
- 边缘地区居民受经济边际效用支配（而非乡下人） → 边缘地区贫困
- 商业道德对后来者的冲击（未学会应对的后来者） → 后来者受到最残酷打击，但最终受益并改善生活质量
- 依赖不同规则体系的人数（核心群体遵循的体系） → 哪种规则体系占优势
- 资本主义（私有财产基础和市场秩序） → 无产者的生存（包括西方和发展中国家无产阶级）
- 资本主义采用从生产中获取收入的新方式 → 人们独立于家族或部落，获得解放
- 采用抽象规则（如储蓄、私有财产）代替具体目标 → 群体人口更快速繁衍（增加人口增长前景）
- 市场经济占上风（因其规则使群体更好繁衍） → 价值计算成为生命核算（引导个人做最有益于增加成员的事情）
- 生命核算（在拯救更多人和更少人之间选择） → 人类生命总体风险降低（通过牺牲少数人）
- 人类生理构造和传统的主要目标（生育后代） → 人口增长（人类异常成功）
- 市场秩序的存在 → 今天大多数人的生存（生命延续）
- 人们开始让具体共同目标服从抽象规则 → 创造意外且往往不需要的条件（文明进步）
- 遵守相同的普遍原则（如私有财产制度） → 现有人口的生存（避免大规模饿死）
- 人们的选择（当有选择权时） → 选择文明（接受扩展秩序，即使住贫民窟）
