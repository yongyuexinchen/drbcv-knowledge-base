# 无产者的生存（包括西方和发展中国家无产阶级）

> 属于因果簇：[[市场经济边缘群体的人口增长与文明选择]]（第6块/15块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资本主义（私有财产基础和市场秩序） |
| **DV（因变量）** | 无产者的生存（包括西方和发展中国家无产阶级） |
| **Chain（传导链）** | 资本家提供维持生活的手段（工具和生计） → 无产者依赖这些手段生存，否则不可能存在 → 资本主义通过市场秩序创造机会，使无产者得以生存 → 即使共产主义国家也依赖西方维持国民生存 |
| **Lag（时滞）** | 即时或短期（生存机会的持续提供） |
| **Threshold（临界值）** | 无明确阈值，但需要维持私有财产基础和市场秩序 |
| **前提与约束（Premises）** | 资本主义提供就业和生存机会；无产者没有其他生存手段；市场秩序有效运行 |
| **Falsification（证伪条件）** | 如果资本主义崩溃但无产者生存未受影响，或社会主义能更好维持生存，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与马克思主义认为资本主义剥削无产阶级的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同工厂提供工作使工人能养家糊口，尽管工人可能感到被剥削

### 🔗 文字版因果链

1. 资本家提供维持生活的手段（工具和生计）
2. 无产者依赖这些手段生存，否则不可能存在
3. 资本主义通过市场秩序创造机会，使无产者得以生存
4. 即使共产主义国家也依赖西方维持国民生存
