# 思想传播与政治决策的因果链条（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：思想传播与政治决策的因果链条.md

## 总体因果图

- 新思想由少数抽象思想家提出并传播 → 政治决策和社会制度发生变革
- 政治哲学家坚持不受多数人意见约束的独立观点 → 民主制的有效运行和进步
- 民主制对多数人权力施加自我限制（法治） → 民主制的持续有效运行和个人自由
