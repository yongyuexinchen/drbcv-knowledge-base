# 个人自由丧失（通往奴役）

> 属于因果簇：[[哈耶克关于计划与自由的核心因果断言]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 中央计划（政府对经济的集中控制） |
| **DV（因变量）** | 个人自由丧失（通往奴役） |
| **Chain（传导链）** | 中央计划要求统一目标，排斥个人分散的偏好 → 为执行计划，政府需掌握更多信息并集中权力 → 权力集中导致对异议的压制，思想与言论自由受限 → 经济控制延伸至政治控制，最终形成极权主义 |
| **Lag（时滞）** | 长期，数十年至数代（取决于计划实施强度与既有制度韧性） |
| **Threshold（临界值）** | 当计划超出法律规则框架，且政府拥有自由裁量权时，奴役趋势不可逆 |
| **前提与约束（Premises）** | 仅当计划是全面的、强制性的，而非局部或自愿协调时；在缺乏法治传统和分权制衡的社会中尤为显著；排除自发秩序（如市场）能够自我修正的情况 |
| **Falsification（证伪条件）** | 若存在长期实行全面中央计划但个人自由未受侵蚀的案例（如某些高福利国家），则断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（基于历史案例如苏联、纳粹德国，但无具体统计数字） |
| **Conflicts（观点冲突）** | 与凯恩斯主义、民主社会主义（如罗尔斯）认为计划可与自由兼容的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像把整个城市的交通交给一个总调度员，他必须知道每个人的目的地，最终会为了效率而限制你的出行自由。

### 🔗 文字版因果链

1. 中央计划要求统一目标，排斥个人分散的偏好
2. 为执行计划，政府需掌握更多信息并集中权力
3. 权力集中导致对异议的压制，思想与言论自由受限
4. 经济控制延伸至政治控制，最终形成极权主义
