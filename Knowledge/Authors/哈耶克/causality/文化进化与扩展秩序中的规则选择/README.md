# 文化进化与扩展秩序中的规则选择（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：文化进化与扩展秩序中的规则选择.md

## 总体因果图

- 遵守通过学习得到的规则（而非本能或直接利他行为） → 扩展秩序的形成与更大利益的产生
- 竞争（而非合作） → 效率提高与对未知环境的适应能力
- 文化进化（通过模仿学习，非理性设计） → 人类理性与道德的形成
- 握有强制力的政权干预 → 文化进化的受阻与协调力量的扩展受限
