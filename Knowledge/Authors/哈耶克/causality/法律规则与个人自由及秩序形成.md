# 法律规则与个人自由及秩序形成

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 法律提供明确、稳定、可预见的行为规则 |
| **DV（因变量）** | 个人能够扩展其预见行动后果的范围，有效使用自身知识，并形成自发社会秩序 |
| **Chain（传导链）** | 法律规则明确告知个人可依赖的环境和行为的可能后果 → 个人据此制定连贯一致的计划，预期他人行为 → 个人在规则范围内自由运用其知识，适应特殊情况 → 众多个人行为相互适应，形成无需统一指挥的自发秩序 |
| **Lag（时滞）** | 长期，规则通过历史经验逐渐演化，效果在代际间显现 |
| **Threshold（临界值）** | 规则必须是一般性、抽象、无例外的，且适用于所有情况 |
| **前提与约束（Premises）** | 个人具有理性，能够理解并遵守规则；规则是稳定的，不因特殊情况而随意变更；立法者无法预见所有具体情况，因此只能制定一般规则；社会成员普遍遵守规则，形成共同预期 |
| **Falsification（证伪条件）** | 如果法律规则明确且稳定，但个人仍无法预见后果或秩序混乱，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与功利主义“根据具体后果权衡行动”的观点冲突，也与认为秩序需要统一指挥的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同交通规则：红灯停绿灯行，每个人都知道他人会遵守，才能安全驾驶，形成有序交通；若规则随意改变，则交通混乱。

### 🔗 文字版因果链

1. 法律规则明确告知个人可依赖的环境和行为的可能后果
2. 个人据此制定连贯一致的计划，预期他人行为
3. 个人在规则范围内自由运用其知识，适应特殊情况
4. 众多个人行为相互适应，形成无需统一指挥的自发秩序
