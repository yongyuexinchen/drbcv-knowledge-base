# 道德准则非理性产物而是理性前提

> **领域**：宏观经济学、社会哲学　|　**来源**：哈耶克_chapter_68_part_01_p2　|　**状态**：candidate

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 遵循未经设计的准则和传统（而非理性建构） |
| **DV（因变量）** | 自由社会的运行和成功 |
| **Chain（传导链）** | 社会运作依赖分散个人的综合努力，复杂现实超出个人理性掌握能力 → 遵循抽象准则和传统为个人提供行动框架，无需每次重新检验理由 → 这种框架使个人行动协调一致，避免因理性不足导致的错误决策 → 长期积累的准则和传统承载过去经验，成为社会有效运作的基础 → 因此，自由社会的运行依赖于这些非理性设计的准则和传统 |
| **Lag（时滞）** | 长期（准则和传统通过历史积累形成，效果随时间显现） |
| **Threshold（临界值）** | 无明确量化阈值，但强调必须将自由视为至高无上原则，不容实用思想限制 |
| **前提与约束（Premises）** | 社会运作以分散个人的综合努力为基础；个人理性不足以掌握复杂现实的全部细节；自由社会允许不同群体遵循不同理想，不强制统一；准则和传统是历史经验积累的产物，非人为设计 |
| **Falsification（证伪条件）** | 如果能够证明人为理性设计的道德体系在复杂社会中比自发演化的准则更有效，且无需依赖传统，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与理性主义（如笛卡尔原则）冲突，理性主义主张怀疑一切并依赖个人理性建构道德体系 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同语言，语言并非由某个人设计，而是自然演化而来，我们使用语言时无需知道其语法规则的全部原因，但语言却是我们思考和交流的基础。

### 🔗 文字版因果链

1. 社会运作依赖分散个人的综合努力，复杂现实超出个人理性掌握能力
2. 遵循抽象准则和传统为个人提供行动框架，无需每次重新检验理由
3. 这种框架使个人行动协调一致，避免因理性不足导致的错误决策
4. 长期积累的准则和传统承载过去经验，成为社会有效运作的基础
5. 因此，自由社会的运行依赖于这些非理性设计的准则和传统
