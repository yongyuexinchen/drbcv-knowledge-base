# 哈耶克对社会主义与扩展秩序的因果断言（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：哈耶克对社会主义与扩展秩序的因果断言.md

## 总体因果图

- 群体无意中遵守某些传统道德做法 → 人类合作中不断扩展的秩序（文明 资本主义）的起源与维持
- 竞争性市场分配产品 → 个人确定努力方向并为总产量做出最大贡献
- 遵循社会主义道德（以中央集体支配资源为基础） → 人类中许多人遭到毁灭，另一些人陷入贫困
