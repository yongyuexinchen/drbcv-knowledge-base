# 亚里士多德静态伦理学对动态社会秩序的阻碍

> **领域**：宏观经济学、社会哲学　|　**来源**：哈耶克_chapter_45_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 亚里士多德基于静态秩序观的伦理学（后被经院哲学及教会正统化） |
| **DV（因变量）** | 社会（如雅典城邦）无法适应动态扩展秩序，导致经济停滞与退化（如城邦退化为村庄） |
| **Chain（传导链）** | 亚里士多德从微观秩序（如家庭、小社群）中归纳出适用于静止状态的道德规范 → 该伦理学被托马斯·阿奎那在13世纪采纳，并被罗马天主教会宣布为正统学说 → 教会据此反对商业、谴责利息为高利贷、宣扬公正价格并蔑视利润 → 这些教义抑制了贸易、金融和创新活动，阻碍了社会向动态扩展秩序演进 → 社会因缺乏自组织扩展的动力而趋于停滞或退化 |
| **Lag（时滞）** | 数百年至两千年（从亚里士多德时代到中世纪及近代早期，影响持续累积） |
| **Threshold（临界值）** | 当教会将亚里士多德伦理学确立为不可挑战的正统教义时，其阻碍效应达到制度化峰值 |
| **前提与约束（Premises）** | 仅当社会处于需要动态扩展（如贸易增长、技术进步）的阶段时，该阻碍效应才显著；前提是亚里士多德伦理学的教义被广泛接受并作为法律或道德强制实施；排除那些已经通过其他思想（如休谟的自发秩序观）打破该教条的社会 |
| **Falsification（证伪条件）** | 如果存在一个长期奉行亚里士多德-阿奎那教义却仍实现高度经济动态增长的社会（如某些中世纪意大利城邦在教会权威下仍繁荣），则该断言被削弱 |
| **Data（定量佐证）** | 定性断言，无定量佐证（提及休谟1739年著作，但无具体经济指标） |
| **Conflicts（观点冲突）** | 与大卫·休谟的自发秩序理论冲突（休谟认为市场无需善意即可服务公益）；与亚当·斯密“看不见的手”思想冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同给一棵正在生长的树苗浇灌固定用的水泥——亚里士多德的静态伦理本为小花园设计，却被用来浇灌整片森林，使其根系无法伸展，最终整片森林萎缩成盆栽。

### 🔗 文字版因果链

1. 亚里士多德从微观秩序（如家庭、小社群）中归纳出适用于静止状态的道德规范
2. 该伦理学被托马斯·阿奎那在13世纪采纳，并被罗马天主教会宣布为正统学说
3. 教会据此反对商业、谴责利息为高利贷、宣扬公正价格并蔑视利润
4. 这些教义抑制了贸易、金融和创新活动，阻碍了社会向动态扩展秩序演进
5. 社会因缺乏自组织扩展的动力而趋于停滞或退化
