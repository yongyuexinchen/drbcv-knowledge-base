# 功绩报酬与自由社会的矛盾

> **领域**：政治哲学、社会经济学　|　**来源**：哈耶克_chapter_70_part_01_p2　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 根据功绩确定报酬的原则 |
| **DV（因变量）** | 个人选择目标的自由受到侵蚀 |
| **Chain（传导链）** | 功绩必须可估价，即他人能辨认并形成一致见解 → 可估价的功绩要求判断主观努力和痛苦，而非客观结果 → 但真实判断功绩需要掌握行动者全部知识、技能、心态等，这些条件普遍缺乏 → 因此，若强制按功绩分配，需由他人（权力层）决定何为功绩，引导个人行动 → 个人失去依据自身知识和能力追求不确定目标的自由，转而服从他人判断 → 最终导致个人选择目标的自由被剥夺 |
| **Lag（时滞）** | 长期，制度性影响逐渐显现 |
| **Threshold（临界值）** | 当社会普遍采用功绩作为报酬分配的唯一或主要标准时 |
| **前提与约束（Premises）** | 功绩必须可估价且他人能形成一致见解；真实功绩判断需要掌握行动者全部主观因素，而这些条件普遍缺乏；自由社会依赖个人运用自身知识和能力自主决策 |
| **Falsification（证伪条件）** | 若能证明存在一种可行机制，可以在不侵犯个人自由的前提下准确评估功绩并据此分配报酬，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与功利主义或结果导向的分配正义观（如按贡献或结果分配）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像老师想按学生的努力程度打分，但老师无法真正知道每个学生花了多少心思，于是只能按考试成绩（结果）打分，结果学生为了高分而放弃自己真正感兴趣的科目，失去了学习的自由。

### 🔗 文字版因果链

1. 功绩必须可估价，即他人能辨认并形成一致见解
2. 可估价的功绩要求判断主观努力和痛苦，而非客观结果
3. 但真实判断功绩需要掌握行动者全部知识、技能、心态等，这些条件普遍缺乏
4. 因此，若强制按功绩分配，需由他人（权力层）决定何为功绩，引导个人行动
5. 个人失去依据自身知识和能力追求不确定目标的自由，转而服从他人判断
6. 最终导致个人选择目标的自由被剥夺

## 因果断言 2

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 按功绩奖赏与按结果价值奖赏的混淆 |
| **DV（因变量）** | 社会激励扭曲和同工不同酬 |
| **Chain（传导链）** | 功绩与主观努力相关，结果价值与客观结果相关 → 市场按结果价值提供报酬，但功绩难以评估 → 若试图按功绩奖赏，则无法评价不同人实现同样结果所付出的努力 → 导致同工不同酬，或奖赏与结果价值脱节 → 削弱个人判断努力是否值得的依据，迫使个人依赖他人指示 |
| **Lag（时滞）** | 中期，随着制度实施逐渐显现 |
| **Threshold（临界值）** | 当社会试图以功绩而非结果价值作为报酬依据时 |
| **前提与约束（Premises）** | 功绩与结果价值是不同概念；市场能评估结果价值但无法评估功绩；自由社会依赖结果价值信号引导个人决策 |
| **Falsification（证伪条件）** | 若能证明市场或社会机制可以同时准确评估功绩和结果价值，并保持激励相容，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与认为功绩应得报酬的道德直觉冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像两个厨师做同一道菜，一个花了三天三夜，一个碰巧做得好，但顾客只按菜的味道付钱，如果硬要按努力付钱，厨师们就不会再研究新菜，而只比谁更辛苦。

### 🔗 文字版因果链

1. 功绩与主观努力相关，结果价值与客观结果相关
2. 市场按结果价值提供报酬，但功绩难以评估
3. 若试图按功绩奖赏，则无法评价不同人实现同样结果所付出的努力
4. 导致同工不同酬，或奖赏与结果价值脱节
5. 削弱个人判断努力是否值得的依据，迫使个人依赖他人指示

## 因果断言 3

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 社会普遍接受功绩与成功必然联系的观点 |
| **DV（因变量）** | 不成功者更难以忍受社会，社会凝聚力下降 |
| **Chain（传导链）** | 社会普遍认为高收入证明有功绩，低收入证明无功绩 → 人们将价值与功绩混淆，假定价值背后必有功绩 → 不成功者被视为无功绩，遭受道德贬低 → 这种社会比公开承认功绩与成功无必然联系的社会更令人难以忍受 → 导致社会不满和分裂 |
| **Lag（时滞）** | 长期，文化观念形成后持续影响 |
| **Threshold（临界值）** | 当社会主流观念将收入与功绩紧密挂钩时 |
| **前提与约束（Premises）** | 功绩与成功（如收入）无必然联系；社会观念影响个体心理感受；自由社会应承认价值与功绩的区分 |
| **Falsification（证伪条件）** | 若能证明在普遍认为功绩与成功挂钩的社会中，不成功者的心理满意度反而更高，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与精英统治论或功绩主义（Meritocracy）观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像考试后，如果大家都认为分数高就是聪明，分数低就是笨，那么低分者不仅失败，还被贴上“笨”的标签，比单纯分数低更难受。

### 🔗 文字版因果链

1. 社会普遍认为高收入证明有功绩，低收入证明无功绩
2. 人们将价值与功绩混淆，假定价值背后必有功绩
3. 不成功者被视为无功绩，遭受道德贬低
4. 这种社会比公开承认功绩与成功无必然联系的社会更令人难以忍受
5. 导致社会不满和分裂

## 因果断言 4

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府试图根据功绩或分配公正原则控制收入分配 |
| **DV（因变量）** | 社会走向全面控制，与自由社会对立 |
| **Chain（传导链）** | 政府采用功绩或分配公正原则作为收入分配基础 → 公正要求该原则适用于所有人，并区分“挣得的”和“非挣得的”收入 → 国家必须应用无法普遍应用的原则，导致不断进行新的控制 → 公共权力决定个人要做什么以及如何做 → 社会在所有主要方面与自由社会大相径庭 |
| **Lag（时滞）** | 中期至长期，随着政策扩展而加剧 |
| **Threshold（临界值）** | 当政府将分配公正原则作为强制性的社会制度时 |
| **前提与约束（Premises）** | 功绩无法客观评估；分配公正原则要求普遍适用，但无法实现；自由社会反对公共权力决定个人行动 |
| **Falsification（证伪条件）** | 若能证明政府可以在不扩大控制的前提下，基于功绩或分配公正原则进行收入分配，且不损害自由，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与福利国家或再分配政策支持者（如罗尔斯）冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像父母试图按每个孩子的“努力”分配零花钱，但无法真正衡量，于是只能不断制定规则监督孩子，最后孩子做什么都要向父母汇报，失去了自主。

### 🔗 文字版因果链

1. 政府采用功绩或分配公正原则作为收入分配基础
2. 公正要求该原则适用于所有人，并区分“挣得的”和“非挣得的”收入
3. 国家必须应用无法普遍应用的原则，导致不断进行新的控制
4. 公共权力决定个人要做什么以及如何做
5. 社会在所有主要方面与自由社会大相径庭

## 因果断言 5

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 承认公民因出生或成员资格而有权分享社会财富 |
| **DV（因变量）** | 民族性群体排他性增强，国际摩擦加剧 |
| **Chain（传导链）** | 个人因属于某社会或民族而要求物质生活水平权利 → 这种要求与功绩分配原则矛盾，且无道德基础 → 在国家内应用该原则，创造对国家资源的集体专有财产权 → 民族性群体变得排他，排斥外国人分享好处 → 该原则跨越国界，导致国际摩擦和冲突 |
| **Lag（时滞）** | 长期，随着观念传播和制度固化 |
| **Threshold（临界值）** | 当公民资格或居留被赋予要求特定生活水平的权利时 |
| **前提与约束（Premises）** | 功绩不是与生俱来的；出生地是偶然事件，不构成分配权利的基础；国家资源集体所有权缺乏正当性 |
| **Falsification（证伪条件）** | 若能证明基于成员资格的分配权利不导致排他性和国际冲突，且具有道德正当性，则该断言被推翻 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与世界主义或全球正义观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 就像小区业主认为小区财富只属于业主，外人不能享受，结果小区越来越封闭，与外界矛盾不断。

### 🔗 文字版因果链

1. 个人因属于某社会或民族而要求物质生活水平权利
2. 这种要求与功绩分配原则矛盾，且无道德基础
3. 在国家内应用该原则，创造对国家资源的集体专有财产权
4. 民族性群体变得排他，排斥外国人分享好处
5. 该原则跨越国界，导致国际摩擦和冲突
