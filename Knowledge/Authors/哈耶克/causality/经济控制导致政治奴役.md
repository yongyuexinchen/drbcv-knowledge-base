# 经济控制导致政治奴役

> **领域**：政治经济学　|　**来源**：哈耶克_chapter_81_part_01_p3　|　**状态**：candidate

---

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 政府对经济活动的集中控制（如国有化、中央计划） |
| **DV（因变量）** | 个人自由的丧失（政治奴役） |
| **Chain（传导链）** | 政府扩大对经济资源的控制，如国有化银行、保险、大型股份公司等 → 经济权力的集中导致政治权力的集中，行政机构成为社会的主导力量 → 个人对政府的依赖加深，因为就业、升迁、生活机会均受政府支配 → 新闻自由、立法机构的独立性等政治自由被侵蚀，最终走向奴役 |
| **Lag（时滞）** | 长期，随着行政机器扩张而逐步显现 |
| **Threshold（临界值）** | 当国有化覆盖关键经济部门（如银行、保险、大型企业）且行政机构获得高效组织时，弊端显著 |
| **前提与约束（Premises）** | 仅当政府控制达到足够广泛和深入的程度；行政机构的组织效率越高，对自由的威胁越大；排除政府干预仅限于临时性、有限范围的情况 |
| **Falsification（证伪条件）** | 若存在高度国有化但政治自由未受侵蚀的实例，或政府控制扩大但个人自由反而增强的证据 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与凯恩斯主义、福利国家支持者（如汉森）的观点冲突，他们认为政府干预可促进经济增长和稳定 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同一个家长逐渐接管孩子的一切决定，起初是衣食住行，最后连思想也被控制，孩子失去独立人格

### 🔗 文字版因果链

1. 政府扩大对经济资源的控制，如国有化银行、保险、大型股份公司等
2. 经济权力的集中导致政治权力的集中，行政机构成为社会的主导力量
3. 个人对政府的依赖加深，因为就业、升迁、生活机会均受政府支配
4. 新闻自由、立法机构的独立性等政治自由被侵蚀，最终走向奴役
