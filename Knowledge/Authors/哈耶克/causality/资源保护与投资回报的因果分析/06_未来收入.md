# 未来收入

> 属于因果簇：[[资源保护与投资回报的因果分析]]（第6块/6块）

## 因果断言 6

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 资源保护投资 |
| **DV（因变量）** | 未来收入 |
| **Chain（传导链）** | 资源保护投资占用资本 → 若投资回报率低于其他资本用途，则未来收入减少 → 资源保护应视为投资，需与其他投资比较回报率 |
| **Lag（时滞）** | 长期（数十年） |
| **Threshold（临界值）** | 保护投资的边际回报率应等于或高于其他投资 |
| **前提与约束（Premises）** | 仅当资源保护与其他投资可比较时；需考虑总收入而非特定资源形态 |
| **Falsification（证伪条件）** | 若保护投资回报率高于其他投资，或资源保护带来非经济价值，则此断言不成立 |
| **Data（定量佐证）** | 定性断言，无定量佐证 |
| **Conflicts（观点冲突）** | 与环保主义者认为资源保护优先于经济回报的观点冲突 |
| **Confidence（确信度）** | well-established |

### 🧩 生活类比

> 如同储蓄，若将钱存入低息账户，不如投资高收益项目，最终财富增长更慢。

### 🔗 文字版因果链

1. 资源保护投资占用资本
2. 若投资回报率低于其他资本用途，则未来收入减少
3. 资源保护应视为投资，需与其他投资比较回报率
