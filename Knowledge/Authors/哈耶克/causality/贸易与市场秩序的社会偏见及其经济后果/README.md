# 贸易与市场秩序的社会偏见及其经济后果（因果簇）

> 因果簇索引：3 个子因果卡。父卡文件：贸易与市场秩序的社会偏见及其经济后果.md

## 总体因果图

- 对商业活动的传统道德偏见（如视贸易为低贱、不诚实、巫术） → 对市场秩序和贸易的持续厌恶，阻碍对市场过程的理解与接受
- 交换和贸易（基于价格机制的信息传递） → 资源有效配置和财富增加（价值创造）
- 个人目标多样性 → 满足多样化需求的能力和文明复杂性
