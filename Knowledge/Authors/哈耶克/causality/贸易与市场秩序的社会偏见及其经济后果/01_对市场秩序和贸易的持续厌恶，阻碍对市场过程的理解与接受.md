# 对市场秩序和贸易的持续厌恶，阻碍对市场过程的理解与接受

> 属于因果簇：[[贸易与市场秩序的社会偏见及其经济后果]]（第1块/3块）

## 因果断言 1

### 🔬 CAO 结构表

| 字段 | 内容 |
|------|------|
| **IV（自变量）** | 对商业活动的传统道德偏见（如视贸易为低贱、不诚实、巫术） |
| **DV（因变量）** | 对市场秩序和贸易的持续厌恶，阻碍对市场过程的理解与接受 |
| **Chain（传导链）** | 原始社会基于小群体互助模式，将贱买贵卖视为不诚实，形成道德鄙视 → 商业活动依赖保密和个人知识，不符合理性主义对可观察信息的要求，引发怀疑 → 商人活动涉及无形价值转化，超出日常感知，被类比为巫术或欺骗 → 体力劳动被赋予道德价值，而贸易被视为非生产性，加深了偏见 → 这些偏见代代相传，导致即使在经济上受益，仍持续厌恶市场秩序 |
| **Lag（时滞）** | 数百年至数千年，偏见根深蒂固，短期难以改变 |
| **Threshold（临界值）** | 无明确量化阈值，但偏见强度随社会现代化和知识普及而减弱 |
| **前提与约束（Premises）** | 适用于存在小群体互助传统的社会；当商业活动依赖非公开信息时，偏见更易产生；在体力劳动价值被高估的文化中，偏见更强烈 |
| **Falsification（证伪条件）** | 若在长期内社会对贸易的接受度显著提高且无道德谴责，则该断言被削弱 |

| **Conflicts（观点冲突）** | 与亚当·斯密对商业的正面评价冲突 |
| **Confidence（确信度）** | well-established |

### 🔗 文字版因果链

1. 原始社会基于小群体互助模式，将贱买贵卖视为不诚实，形成道德鄙视
2. 商业活动依赖保密和个人知识，不符合理性主义对可观察信息的要求，引发怀疑
3. 商人活动涉及无形价值转化，超出日常感知，被类比为巫术或欺骗
4. 体力劳动被赋予道德价值，而贸易被视为非生产性，加深了偏见
5. 这些偏见代代相传，导致即使在经济上受益，仍持续厌恶市场秩序
