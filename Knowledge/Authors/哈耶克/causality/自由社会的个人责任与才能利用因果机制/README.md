# 自由社会的个人责任与才能利用因果机制（因果簇）

> 因果簇索引：4 个子因果卡。父卡文件：自由社会的个人责任与才能利用因果机制.md

## 总体因果图

- 自由社会赋予个人选择职业和利用具体知识的自由 → 个人才能得到最大程度利用，社会整体繁荣
- 个人相信成功完全依赖自身努力（而非外部环境） → 个人行动更有效，更可能获得成功
- 责任范围扩大至个人无法预见或控制的结果 → 个人责任感减弱，行动效率降低
- 小社会（熟人社区）的消失，被大社会网络取代 → 个人对他人（尤其远方不幸者）的责任感减弱，转而依赖国家保护
