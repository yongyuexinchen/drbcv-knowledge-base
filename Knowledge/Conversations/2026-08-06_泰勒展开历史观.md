# 泰勒展开历史观（整理版）

> 事件源（不可变）：2026-08-06 用户整理的与 GPT 讨论结论。
> 已提取：Self 卡「泰勒展开历史观_历史是体系的局部展开」+ 技能 history-system-analysis（Hermes 研究协议）。

## 核心思想

数学泰勒展开：用局部信息逼近整体变化（f(x)=f(a)+f'(a)(x-a)+f''(a)(x-a)²/2!+...）
迁移到历史：历史不是事件列表，是复杂系统在不同尺度下的局部展开。
无法知道未来完整状态，但可观察：当前状态 + 变化趋势 + 变化速度 + 变化加速度 → 推演短期演化。

| 数学 | 历史 |
|------|------|
| 函数 | 文明/体系 |
| 当前点 | 当前历史状态 |
| 一阶导数 | 当前变化趋势 |
| 二阶导数 | 趋势变化速度 |
| 高阶项 | 突发变量/黑天鹅 |

## 三原则

1. **还原生成函数**：不看事件列表（事后解释陷阱），问"为什么这个系统会产生这些事件"——寻找历史生成机制（例：房地产繁荣=土地财政需求+银行信用扩张+城市化需求+居民资产配置的组合）
2. **结构比较**：不比事件比结构（法国大革命/王朝更替/金融危机同构：旧体系→资源分配失衡→维护成本增加→新力量→旧秩序失效）。Hermes 遇历史现象问"有没有类似结构"而非"有没有类似事件"
3. **还原求极限**：现象→事件→制度→结构→矛盾→底层约束，越接近底层跨时代复用能力越强。但不能追求绝对极限（还原到"人性"=万能解释无预测力）。真正的底层结构必须能产生预测：底层机制→可观察信号→未来预测

## 与 Radar 连接

Radar = 泰勒历史观的工程化：历史研究寻找"体系函数"，Radar 监控"函数导数变化"。
例：房地产（土地财政模型）：当前点=高库存，一阶=销售下降，二阶=人口趋势恶化，三阶=财政模式不可持续 → 转换窗口。
