# 事件源：死亡驱力理论 v2（生存半径）

> 处理：归档 → 升级 [[正常行为是死亡恐惧的日常化]]（v2 表述+生存半径）→ Radar 模板字段说明 → 逃逸报告修正

## 原始内容（GPT 整理摘要）

### 视角修正：不是"错误选择"，是"生存性选择"
- 我用了"错误选择"=默认事后观察者位置（站在终点、拥有完整信息，评价当时是否最优）
- 死亡驱力框架真正关注：身处死亡压力中的存在体，如何在有限信息和有限时间内维持自身存在
- 落水者抓任何东西：岸上看=抓错木头/方向；落水者视角=手能碰到什么抓什么——优化目标不是"找到最优解"，是"延迟死亡"

### 机制修正
```
❌ 死亡压力 → 错误判断 → 错误行为
✅ 死亡压力 → 存在体进入求生模式 → 调用当前可获得的认知模型和资源 → 形成当下合理的生存行为
```

### 进化论视角
- 恐龙大型化：当时环境=合理策略（更强捕食/竞争优势）；环境变化后优势变负担——不是错误，是生存条件改变
- 很多行为不是"正确"，而是"在当时环境中足够维持存在"

### 晚清修正
- 不是"误判死亡来源"——它调用自身文明已有的解释系统（军事/技术落后→洋务），在认知边界内抓最近的救命稻草；只是抓到的东西无法解决更深层死亡

### 新概念：生存半径（Survival Radius）
```
死亡威胁 → 认知边界 → 资源边界 → 可行动空间 → 正常反应
```
系统只能抓自己能够感知和触碰到的东西。

### 时代残酷性的解释
- 旧时代的正常行为=旧死亡结构下优化出的最优反应（不是错误）
- 死亡对象改变 → 原来的正常突然变成障碍
- 两代人在争的不是"谁正确"，是"哪一种死亡模型是真实的"（上代：老年无人照顾→孩子；这代：经济压力+个人价值消耗→不进入婚育结构）

### 逃逸理论修正
- 逃逸≠逃离错误结构；=当原有生存策略无法应对新的死亡压力时，产生新的存在实验
- 朋克/二次元/AI伴侣/躺平=不同群体面对不同死亡压力时产生的生存实验（不是简单反抗）

### 死亡驱力理论 v2 完整表述
> 一切存在体都在死亡压力下生成"正常行为"。正常不是客观正确，而是在特定死亡结构、认知边界和资源条件下维持存在连续性的最佳可用策略。当死亡结构改变时，旧正常会失效，并产生新的逃逸线。

### 与锚点理论连接
保存的不只是答案，而是每个时代的人如何在自己的死亡阴影下努力活下去。

## 提取要点

- v2 核心升级：正常=特定条件下的最佳可用策略（非客观正确）
- 生存半径链条：死亡威胁→认知边界→资源边界→可行动空间→正常反应
- 两代人争的是死亡模型真实性，不是对错
- 逃逸=新死亡压力下的存在实验
