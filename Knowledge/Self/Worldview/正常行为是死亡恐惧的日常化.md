# 正常行为是死亡恐惧的日常化

## 一句话

人的"正常"选择（结婚生子/照顾老人/循规蹈矩）的深层根源，是**死亡恐惧的日常化**——对无依无靠、孤独终老、无人送终的恐惧；"正常"不是理性选择，是恐惧驱动的社会复制。

## 为什么这么想

触发链（2026-08-07 事件）：
```
外公老年痴呆 → 家里人讨论照顾 → 母亲这一代只有一个孩子
→ 我这一代结婚都不太可能 → 时代结构下的个人决策 → 死亡恐惧的推演
```

四层认识：
1. **时代结构砸在每个人头上**：个人决策（结婚/生子/养老）被时代结构决定——外公那一代多子女是常态（养老靠多生），母亲这一代独生（养老靠国家+自己），我这一代不婚（养老自备）——**同一件事（养老）在三代人身上是完全不同的决策结构**
2. **"正常"行为的恐惧根源**：结婚生子"正常"吗？不是——它是死亡恐惧的日常化（对衰老无人照料的恐惧被社会复制成"正常"）。恐惧越深，行为越"正常"
3. **自我认识修正（认识论事件）**：我之前对现实的认识不够——我无法想象未来的现实；若想象自己无儿无女且老年痴呆，也会招致死亡恐惧，也会被现实修正，也会产生"正常的"结婚生子念头——**认识不足的表现不是想错了，是无法想象**
4. **时代逃避的双面**：范式如此有力地砸在每个人头上，但时代选择逃避这个问题——互联网上充斥着二次元与烂俗梗与模因污染：**这是反抗？还是麻木？**（开放问题）

## 支撑证据

- 三代人养老结构差异（外公多子女/母亲独生/我这代不婚）——同一问题三种决策结构
- 社会观察：生育率下降（S5 出生 792 万——中国经济体系卡）与"催婚催生"焦虑并存——恐惧驱动与逃避并存
- 模因污染观察：二次元/烂俗梗的狂欢恰在人口结构剧变期（逃避结构问题的时代症状）
- 与 [[人无法得到目的以外的任何东西]] 的镜像：目的可以是恐惧驱动的（无目的的受害者 ↔ 恐惧驱动的一切正常行为）

## 反例与动摇

- 并非所有"正常"行为都是死亡恐惧——部分人结婚生子是爱/责任/社会认同，恐惧只是多重动机之一（避免单因论）
- 二次元/模因也可能是"反抗"（对结构的戏谑解构）而非"麻木"（逃避）——开放问题未决
- 死亡恐惧是否可被"想象"充分推演——无体验者的想象可能失真（我没老年痴呆过，想象可能低估或高估）
