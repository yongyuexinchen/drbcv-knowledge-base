# 明斯基周期（金融不稳定假说）

## 一句话

**稳定本身就是不稳定的来源**——稳定期→风险偏好上升→杠杆积累→体系脆弱→危机；周期的终点不是外部冲击，是系统自身的稳定。金融不稳定是内生的。

## 为什么这么想

明斯基三阶段融资分类：
```
对冲性融资（收入能覆盖利息+本金）→ 稳定
投机性融资（收入只够利息，靠再融资）→ 脆弱积累
庞氏融资（收入不够利息，靠资产升值）→ 临界
稳定期越长，投融资/庞氏占比越高 → 危机越近
```

应用：AI 泡沫（AI产业卡周期节：技术突破→资本涌入→预期膨胀→ROI 验证→淘汰→真实应用留下）——ROI 验证阶段就是"投机性融资占比过高"的检验点。

## 反例与动摇

- 有效市场假说（EMH）：市场理性定价，不存在系统性内生不稳定——明斯基与 EMH 对立
