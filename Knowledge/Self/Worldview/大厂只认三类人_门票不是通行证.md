# 大厂只认三类人：门票不是通行证

> 生成来源：AI 深度分析（用户确认吸收）——2026-08-06

## 一句话
非全学历是"让你不被一票否决"的加分项，不是"让你被优先录取"的通行证；**大厂只认三类人**（校招天才型/项目硬核型/业务结果型）；纯包装必翻车（技术深挖/细节追问/现场推导三道防线），把真实经历表达得更工程化是必须能力。

## 为什么这么想
1. 前提1：非全研究生的真实权重——加分项（不是强加分），补学历短板，"让你不被一票否决"的东西，不是"让你被优先录取"的东西
2. 前提2：大厂 AI/RAG/应用方向真正看三件事：①项目复杂度（真实工程架构/线上系统/数据流/用户/性能优化——不是"做过项目"）②解决问题能力（向量检索怎么优化延迟？RAG如何避免幻觉？agent失败怎么兜底？）③业务理解
3. 前提3：面试三道防线：技术深挖（embedding模型？chunk策略？recall评估？rerank？latency？——一两处答不上来经验可信度崩）、细节追问（"具体改了哪一行代码？"）、现场推导（现场设计RAG/写简化版）——"大厂不是看简历，是看你脑子里有没有那套系统"
4. 前提4：现实概率——非全+AI工作1年+真实项目 → 30%~60% 进大厂AI应用岗；非全+包装+没硬项目 → 接近 0%
5. 结论：真正该关注的不是"能不能进大厂"，而是"我能不能做出一个'别人必须认真看我简历'的系统"——那时是大厂来筛你，不是你去挤大厂

## 支撑证据
1. "大厂只认三类人：①校招天才型 ②项目硬核型 ③业务结果型"（深度分析）
2. "纯包装=基本会翻车"（深度分析）
3. "把没做过的说成做过的❌不建议；把做过的东西表达得更工程化、更系统化✔️必须能力"（深度分析）
4. Phase 路径：小公司真实工程经验(1-2年)+非全+2-3个能讲透的项目 → 大厂AI应用组/Agent组（深度分析）

## 反例与动摇
- 30-60% 是估计不是保证——概率随市场变化（AI 就业窗口期）
- "门票论"不否定读研价值——价值在身份转换（见 [[考研是工具不是改变人生]]）
- 三类人不是绝对分类——有人跨型（项目硬核+业务结果）
