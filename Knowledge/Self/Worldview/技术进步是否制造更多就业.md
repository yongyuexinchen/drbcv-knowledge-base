# 技术进步是否制造更多就业

## 一句话

技术进步历史上总是"消灭岗位→创造新岗位"（农业机械化→工业、工业自动化→服务业），但 **AI 首次直接攻击"认知岗位"本身**——新岗位是否还能被创造、创造速度是否跟得上淘汰速度，是悬而未决的核心问题。

## 为什么这么想

历史三阶段：
```
农业机械化：减少农民 → 增加工业岗位
工业自动化：减少制造岗位 → 增加服务业岗位
AI：减少认知岗位 → 新岗位在哪里？← 悬而未决
```

关键差异：前两次替代的是"肌肉"和"重复动作"，AI 替代的是"思考"——而思考/认知是**人类比较优势的核心**。如果比较优势本身被替代，补偿性岗位创造机制可能失效。

## 支撑证据

- 历史：每次技术革命都伴随"就业毁灭恐慌"→ 最终岗位总量增长（卢德谬误的乐观面）
- 现在：AI 已直接替代客服/初级编程/翻译/文书——且替代速度 > 新岗位创造速度（观察中）
- 结构：AI 的资本回报高度集中（巨头），不像前两次革命那样广泛创造本地就业

## 反例与动摇

- 卢德谬误论证：历次恐慌都错了，这次可能也错（人类会创造新的"人独有"岗位——情感/判断/责任/伦理）
- 但"可能"不是"必然"——结构性失业（技能错配）在每次转型期都真实存在，AI 转型期可能更长更痛
