# 人文学科与实证科学的双轨认知模型

## 核心命题

> 人文学科的核心产出不是确定答案，而是对复杂系统的**认知模型**；实证科学的核心产出是可重复验证的**规律**。
> 知识系统的价值在于收集不同认知模型，通过**结构比较、因果链拆解和历史展开**，发现跨领域结构相似性。

## 一、两类知识生产模式

### 实证科学（Evidence-driven）
核心问题：**世界如何运行？**

```
提出假设 → 设计实验 → 观察结果 → 重复验证 → 形成规律
```

特点：可复现 / 可证伪 / 变量控制 / 数学表达
知识卡重点：定义、公式、实验、边界条件、证明过程
例：物理（力→加速度）、生物（基因→性状）、计算机（算法复杂度→性能边界）

### 人文学科/社会科学（Meaning-driven）
核心问题：**人类为什么这样行动？体系为什么这样演化？**

```
历史观察 → 经验归纳 → 逻辑解释 → 建立叙事模型 → 现实检验
```

特点：不完全可实验复现 / 高维变量无法控制 / 依赖经验积累 / 依赖解释能力
知识卡重点：作者、时代背景、核心问题、核心命题、因果链、适用边界、反方攻击、现实案例
例：马克思（生产力→生产关系矛盾→社会结构变化）、明斯基（繁荣→预期提升→杠杆增加→脆弱性积累→危机）

## 二、知识库真正价值：不是存知识，而是比较认知模型

传统知识库：知识A、B、C……只是收藏。
KOS：知识A/B/C → 结构抽取 → **寻找同构结构**。

结构相似性示例：

| 金融危机（明斯基） | 技术革命（互联网） | AI革命 |
|------------------|-------------------|--------|
| 稳定时期 | 基础设施建设 | 模型突破 |
| 风险偏好增加 | 资本涌入 | 资本投入 |
| 杠杆增加 | 预期膨胀 | 预期膨胀 |
| 系统脆弱 | 泡沫破裂 | ROI验证 |
| 危机 | 真正应用留下 | 应用留下 |

共同结构：

```
系统稳定 → 反馈增强 → 复杂度提升 → 脆弱性积累 → 相变
```

这就是"泰勒历史展开"的用武之地——用结构对比代替事件罗列。

## 三、泰勒展开历史观

核心：**历史不是重复，而是在局部区域可以展开**。

- 函数整体未知，但局部附近可以用展开式近似
- 未来不可预测，但当前阶段附近可以通过过去类似结构推演

流程：寻找历史结构 → 抽取状态变量 → 比较变化方向 → 寻找高阶导数 → 判断相变点

例：日本90年代（资产价格/债务/人口/利率/企业行为）→ 中国对应变量（房地产/地方债/人口/政策/企业投资）
不是"中国一定变日本"，而是"**中国处于类似展开区域吗？**"

## 四、历史求导问题（分段求导）

历史(t) 不是连续函数——存在战争、制度变化、技术突破、黑天鹅。
不能 d历史/dt，而应**分段求导**（类似物理：连续运动→碰撞瞬间→重新建立模型）：

```
稳定阶段 → 积累变量 → 相变点 → 新阶段重新展开
```

> **历史 = 分段函数 + 相变点**
> 研究重点不是预测全部未来，而是找到：当前阶段 + 主要变量 + 下一次不可逆变化点

## 五、混沌-确定性循环

- **确定性阶段**：系统建立规则/制度/反馈机制，越来越稳定（例：房价上涨→土地财政→基建→经济增长）
- **混沌进入**：外部变量攻击（人口下降/技术变化/战争/制度变化），旧模型失效
- **新确定性形成**：新的反馈机制出现（房地产时代：土地→金融→地产；AI时代可能：数据→模型→Agent→智能生产）

> **混沌不是随机，而是旧确定性瓦解、新确定性形成之间的过渡区。**

## 六、视频化表达为什么适合人文学科

人文学科的问题不是缺少信息，而是：复杂因果链 → 普通人无法建立心理模型。

视频寓言 = **认知压缩**：抽象模型 → 故事映射 → 情境模拟 → 认知压缩。
例：托帕不是讲债务理论，而是"一个角色面对选择、产生冲突、承担后果"——观众通过故事理解信用/风险/激励/制度。类似柏拉图洞穴寓言。

→ 人文学科的产出方向：**以做视频的方式认识**（输出即认识方式）。

## 七、知识系统定位

> **KOS 不是知识收藏系统，而是认知模型实验场。**

- 输入：人类历史经验、科学理论、个人经历、社会观察
- 处理：结构抽取、因果链、反方攻击、历史比较、极限还原
- 输出：预测模型、视频寓言、行动策略

> 为什么这个系统不是普通 RAG——它是"**人类认知模型的版本控制系统 + 历史结构分析引擎**"。

3. ~~结构相似性是否过度类比？~~ → **接住 + 概念升级**：结构比较预测力的判据 = **目的（比什么）× 约束（是否相同的工程问题）× 抽象层级**——"我和秦始皇都是人→都有5根手指"（同层级/同源）vs"我和大象→推不出5根手指"（层级错）；"操作系统 vs 人格"无统一源头但**都是相同的工程问题**（核心稳定vs外围灵活）→ 趋同演化（convergence）的活案例

### 追刀（第二轮追加）

4. **数据可信度自指**（官方数据=政治污染，但 S1-S5 全用官方数据）→ **接住 + 概念升级**：数据可信度 = **造假利益强度 × 监督机制**，不是来源类型。投行研报有同行拆台声誉机制→较高；不良率（银行+不良资产公司勾连）→低（"债总是要人还的"）；失业率（政治利益）→低（经济差时直接不公布）。**信号可信度分级待落地**（S1 不良率正被自己判为低可信——账面 1.6% vs 真实不良率是 S1 要监控的裂缝）
5. **同源如何事前判别** → **接住 + 概念升级**：**目的决定比什么**（中国vs日本=相同范式体系表现；操作系统vs人格=相同工程问题），**约束同构 = 事前判据**（不需要共同祖先，需要共同约束→相似架构解）

### 概念升级汇总（写入正文）

1. 分类轴：学科标签 → **认识论方法**（假设驱动 vs 数据驱动）
2. 数据分级：来源类型 → **利益强度 × 监督机制**
3. 同源判别：共同源头（homology）→ **共同工程问题/约束**（convergence）；目的定比较对象，约束定同源判据，层级定预测力
4. 双层产出确认：卡片=原貌精准，视频=降采样普及（丢细节不丢结果）+ 创作纠错循环
