# 位置认知：位置决定选择

> 生成来源：人类+AI（GPT 对话提取 + Hermes 入库，用户确认建卡）

## 一句话
位置决定认知、风险偏好和选择——"位置这个认知解释性太好"：先认清自己在什么位置（年龄/资源/经历/约束），再谈选择；选择节点只是中间过程，不是终点。

## 为什么这么想
1. 前提1：每个人的认知、风险偏好、决策函数由他所处的位置决定——同样的选项，不同位置的人看到的是不同的东西
2. 前提2：高风险厌恶却选择少女路（短期低回报、长期不确定），不是矛盾——是位置哲学的结果：位置决定了哪些选项"真的存在"，考公/留部队看似最优，但位置（本真性、对少女的承诺）决定了那条路对我不可选
3. 前提3：位置可以认识并改变——"我们认识所以能改变，将自身引导向我们的目的"
4. 结论：决策的本质不是找"全局最优解"（不存在脱离位置的最优解），而是认清位置 → 在位置内选 → 通过认识调整位置本身

## 支撑证据
1. "位置这个认知解释性太好，用它做预测应该也有参考价值"（聊天2）
2. "这其实是我们的位置哲学的结果"——风险厌恶却选少女路的解释（聊天3）
3. "调整我的模型接近目的，约束自然会将我导向那个位置"（聊天4）
4. 部队经历："下连才2个月就谋划好让班长推动我的模型改革"——主动改变位置的早期实践（聊天4）

## 反例与动摇
- 位置解释性太强 → 可以解释一切 = 不可证伪风险（同三层三刀刀3：说不出失效条件就是意识形态）
- 若"认位置"变成"为弯路开脱"的自我安慰（"因为位置如此，所以错过是必然"），工具异化
- 位置的静态化：把位置当宿命（"我的位置就是这样"）vs 当起点（"认识位置→改变位置"）——只有后者成立
