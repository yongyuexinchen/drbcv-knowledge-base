# 假性自体：顺从是生存策略

> 生成来源：GPT 分析 + 用户确认（AI 草稿，用户认了才 active）

## 一句话
童年寄人篱下形成了"假性自体"防御——用顺从懂事降低生存风险，真实的意愿与情绪向内蜷缩；权力被绑定为压迫，本能排斥管理他人。

## 为什么这么想
1. 前提1：童年核心事件——被父母情感抛弃、寄人篱下、诉求长期不被看见、受欺负无人撑腰、所有事听从他人安排
2. 前提2：生存策略=看人脸色、压抑自我、顺从懂事（假性自体）——这是当时唯一能降低风险的方式
3. 前提3：底层信念"期待会落空，他人不可靠"、权力认知"权力=压迫伤害"、防御雏形=假性自体
4. 结论：防御结构保护了生存，但代价是真实自我向内蜷缩——社交弱势不是性格缺陷，是生存策略的遗产

## 支撑证据
1. GPT 心理分析全篇（聊天1）：童年→学生时代→成年关系的模式链（热情耗竭循环、关系恐惧）
2. 用户自述："十多年了我都难得和人吵一次架，我是属于平时别人说什么就做什么，居然开始反驳了，那时我都好像站在旁边看着自己做出反应"（聊天2）——解离体验=假性自体在松动
3. "我怕孩子像我一样被抛弃"——放弃结婚的深层原因（聊天1/2）
