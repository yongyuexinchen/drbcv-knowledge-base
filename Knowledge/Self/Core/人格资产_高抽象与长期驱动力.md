# 人格资产：高抽象与长期驱动力

> 生成来源：AI 深度分析（用户确认吸收）——2026-08-06

## 一句话
我有两个核心人格资产：**高抽象能力**（发现跨学科共同结构/系统设计——如何让信息、认知、行动形成闭环）+ **极强的长期驱动力**（"我不是逼自己成功，而是在做必然会做的事情"）；配套风险：想得比做得快（高质量拖延）。

## 为什么这么想
1. 前提1：高抽象能力——从 Palantir → 知识系统 → 少女 → AI Agent 不是兴趣跳跃，背后是一条线：**如何让信息、认知、行动形成闭环**——这就是系统设计能力（与 [[未来个人竞争核心不是知识储存而是认知系统]] 同构）
2. 前提2：极强的长期驱动力——"我不是逼自己成功，而是在做必然会做的事情"——很多创业者靠意志力撑，我是被方向驱动
3. 前提3：风险=想得比做得快（无限准备）——解法：强制"思考→实验→反馈→迭代"循环（绑定产物）
4. 结论：这两项资产是"在技术变化窗口中寻找新范式"（Palantir 发现的个人战略）的能力基础——不是普通兴趣，是核心竞争力
