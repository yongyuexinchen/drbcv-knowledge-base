# 命途与派系

> ⚠ 本卡为原始设定；创作向改编见 Video-Creation

## 核心概念
命途是《星穹铁道》世界观中由星神所象征并主导的宇宙法则与道路。每一位星神对应一条命途，命途既赋予力量，也定义追随者的行动逻辑。追随者围绕星神与命途形成各种派系和组织。目前已知共有 **15条命途**，并存在独立于这一体系之外的“黄金裔”势力（翁法罗斯）。

> 另立：**黄金裔（翁法罗斯）**——不属于上述15命途体系，具体性质待考据。

**令使（Emanator）**：星神力量的直接代行者。已知实例：
- **绝灭大君**：毁灭命途，共8位：幻胧、焚风、星啸、归寂、铸王、光逝、诛罗、反造物主。
- **仙舟令使**：巡猎命途，已知包括华、景元等。

## 时间线/纪年
- 本卡暂无与命途体系直接绑定的具体纪年。星海世界常用“琥珀纪”（存护星神克里珀相关）与“开拓历”（星穹列车相关），但需另行考据。
- 黄金裔（翁法罗斯）的时间线位置不明，待补充。

## 与视频创作的映射
在《托帕的金融小课堂》中，命途体系可类比为“职场/金融赛道”：
- **星神 = 公司愿景/行业风口**；**令使 = 区域总经理/合伙人**；**派系 = 业务线/部门**。
- 例如：
  - 托帕所属的**存护** → “风控与资产保全”，对应金融小课堂里的“保本思维”；
  - **开拓** → “出差做项目/市场拓展”；
  - **毁灭** → “不良资产处置”；
  - **智识** → “量化分析与内幕推演”；
  - **同谐** → “团队建设与客户关系”；
  - **虚无** → “躺平学/价值投资躺赢”；
  - **欢愉** → “财经段子手/韭菜的快乐生活”；
  - **终末** → “破产清算与退市预警”。
- 梗源：把15条命途比作“股市风格板块”，托帕作为“存护系”投资人，给玩家讲解如何在不同“命途板块”中配置资产。
