# 星核与裂界

> ⚠ 本卡为原始设定；创作向改编见 Video-Creation

## 核心概念

**星核（万界之癌）** 是自2147琥珀纪起观测到的神秘现象，本质为一类异常能量结点，能够扰乱世界的虚数能量流向，使其陷入系统性的混乱与腐化。星核的运作方式类似癌细胞渗透并改造宿主世界，常伴随可见的“裂界”侵蚀。星核的起源与活动轨迹直接关联毁灭星神**纳努克**与**反物质军团**，被认为是后者侵入并毁灭世界的前置手段。

**裂界** 是星核催生的侵蚀现象，也是星核污染世界的具体表现形式。裂界会将现实空间扭曲为异常区域，区域内的造物虽保留原型的记忆与外形特征，却服从于排他性的生态法则，排斥一切非“正常”的存在。裂界还能记录世界中的以太信息，并以此为基底产出具有嫁接特征的合成造物——即保留原型能力、但被重新组装的新事物。

已知被星核侵蚀的实例包括：雅利洛-VI（引发寒潮与裂界）、仙舟罗浮（激活建木、诱发魔阴身）、匹诺康尼（梦主阴谋的核心）以及翁法罗斯（德谬歌被引爆）。

## 关键机制

| 机制 | 说明 | 例子 |
| ---- | ---- | ---- |
| 虚数扰乱 | 星核扭曲虚数能量流向，破坏世界物理规则 | 雅利洛-VI持续寒潮 |
| 癌细胞式蔓延 | 星核像肿瘤一样侵蚀世界根基，扩散不可逆 | 裂界面积随感染加深扩大 |
| 造物记忆保留 | 裂界中的造物保有原型记忆，但行为逻辑转变为排他性 | 寒潮裂界中的怪物仍残留居民形态 |
| 以太信息记录 | 裂界自动记录世界的以太信息，作为生成素材 | 产出拥有原型技能、重新组合的嫁接造物 |
| 星神关联 | 星核活动最终服务于纳努克的毁灭意志 | 反物质军团伴随星核出现 |

## 时间线/纪年

- **2147琥珀纪**：星核现象首次被明确记录，视为“万界之癌”纪年起点。
- 琥珀纪未知年份：雅利洛-VI遇星核侵蚀，裂界吞没文明。
- 琥珀纪未知年份：仙舟罗浮受星核影响，建木异动，魔阴身爆发。
- 琥珀纪未知年份：匹诺康尼星核引发梦主阴谋。
- 琥珀纪未知年份：翁法罗斯星核导致德谬歌被引爆。

## 与视频创作的映射

在《托帕的金融小课堂》中，**星核**可类比为“系统性金融风险种子”——一个看似无害的高杠杆产品（如次级贷）一旦埋入经济体，就会扰乱资金流向，像虚数能量失控一样引发连锁危机。**裂界**则对应“金融危机中的异化市场”：既有的金融工具（抵押品、衍生品）保留着原始合同记忆，但其流通逻辑变得排他且扭曲，不再服务于实体经济。**以太信息记录与嫁接造物** 可映射为“金融工程合成品”——把不同资产的历史现金流拼接成新的结构化产品（如CDO），既保留原资产影子，又具备危险的新性质。托帕作为“债务催收专家”对抗星核，就好比运用债务重组手段遏制金融危机的蔓延。
