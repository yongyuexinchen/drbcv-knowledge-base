## 是什么
Dify（"Do It For You"）是一个开源的大模型应用开发平台，已有超过 10 万个应用基于它构建。它提供可视化的提示词编排界面，支持对话型和文本生成型两种应用模式，内置知识库（RAG）管理、模型管理、成员权限管理、应用嵌入和 API 访问等功能。企业可以用它在零代码/低代码条件下快速构建智能客服、内容审核、合同分析、批量文档生成等 AI 应用。

## 输入-输出空间
- **输入**: 腾讯云服务器（亚太节点，推荐孟买）+ OpenAI/智谱/讯飞等模型 API 密钥 + 知识库文档
- **输出**: 可通过公网 IP 访问的 Dify 平台，支持创建、发布、分享 AI 应用
- **前置条件**: 服务器需安装 Docker + docker-compose；腾讯云每条新终端都必须先 `sudo su` 提权；首次登录需访问 `/install` 路径设置管理员账号

## 正例（≥2 个）
1. **企业微信智能问答**: 导入公司规章制度和产品手册到知识库，创建对话型应用，嵌入企业微信——员工在企微里直接问「年假怎么算」，机器人基于知识库精准回复。
2. **批量合同审核**: 创建文本生成型应用，上传 5 份保密合同模板，设定审核维度（合同范围、保密义务、违约责任等），一次性批量生成审核报告——律所的工作效率提升 5 倍以上。

## 反例/边界（≥1 个）
1. **Nginx 服务导致公网 IP 打不开**: 部署后访问公网 IP 卡住→排查 `docker ps` 确认 nginx 服务名→`docker restart <nginx_service>` 重启即可。错误原因是 nginx 容器未正常启动。
2. **本地部署无官方示例模板**: 官网 cloud 版内置了丰富的应用示例模板（探索模块），但本地部署的版本没有——需要完全自行搭建。
3. **Rerank 模型需科学上网**: 混合检索需配置 Cohere 的 Rerank 模型，但 Cohere 官网需要 Google 登录和魔法上网——国内无梯子用户建议只用向量检索，效果已足够好。

## 详细解释

### 部署流程（腾讯云）
| 步骤 | 操作 | 关键点 |
|------|------|--------|
| 1. 服务器选配 | 腾讯云 CVM，按量计费，亚太-孟买，4 核 16GB，Ubuntu 22.04 | 孟买性价比最高（约 1 元/小时）；必须分配公网 IP |
| 2. 基础环境 | SSH 登录 → `sudo su` 提权 → 安装 Docker + docker-compose + git | 每开新终端都要执行 `sudo su` |
| 3. 克隆部署 | git clone → cd 项目目录 → docker-compose up -d | 首次运行会自动拉取所有镜像 |
| 4. 初始化 | 公网 IP:端口 访问 → 右上角切简体中文 → 地址栏改 `/install` → 创建管理员账户 | 密码必须含数字和字母，≥8 位 |

### 核心能力列表
- **模型管理**: 支持 OpenAI、智谱、通义千问、讯飞星火等主流模型，可在前端界面直接添加
- **提示词编排**: System/User 双提示词模式 + 变量（文本/段落/下拉选项三种字段类型）
- **知识库**: 支持导入文本文件（TXT/PDF/CSV 等），自动分段与清洗，向量检索
- **应用发布**: 一键生成可分享的 Web 链接 / 嵌入代码 / 后端 API
- **成员管理**: 邀请团队成员共同使用，区分管理员和普通成员权限
- **数据分析**: 后台提供消息数、活跃用户、费用消耗等分析图表
