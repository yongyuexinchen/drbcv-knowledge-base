## 建卡原则
严格遵循已有卡格式（frontmatter + 类型判定 + 是什么 + 正例 + 反例 + 详细解释 + 生活类比 + 个人见解留空 + 关系）。区分 discriminant/connection/mixed：
- 网络层功能/IPv4分组结构 → discriminant
- 子网划分/子网掩码 → connection（含计算：子网数、主机数）
- CIDR → connection（含路由聚合计算）
- NAT/ARP/DHCP → connection（含工作流程）
- ICMP → discriminant + connection
