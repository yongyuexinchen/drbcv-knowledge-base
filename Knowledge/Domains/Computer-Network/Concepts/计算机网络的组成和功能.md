# 计算机网络的组成和功能

## 类型判定
判别型 — 回答"计算机网络由什么组成、能做什么"，属于基础概念分类类知识。

## 是什么
计算机网络是一个由**硬件、软件和协议**共同组成的庞大复杂系统。从不同视角可以有不同的分类描述：

| 视角 | 组成 |
|------|------|
| **组成要素** | 硬件（主机、通信设备、通信链路）+ 软件（网络软件、固件）+ 协议（通信规则） |
| **工作方式** | 边缘部分（直接为用户服务的主机+软件）+ 核心部分（路由器和链路，提供连通性和交换服务） |
| **逻辑功能** | 资源子网（提供资源共享的主机部分）+ 通信子网（负责信息传输的通信设备和介质部分） |

计算机网络的功能包括：数据通信、资源共享、分布式处理、提高可靠性、负载均衡等。

## 正例（≥2个）
1. **网络适配器（网卡）**：手机和电脑内部安装的网络适配器芯片，包含硬件和固件（特殊的软件），共同实现 TCP/IP 协议。出厂时厂家将固件写入 ROM 芯片，使硬件和软件结合来实现网络协议——体现了"协议由硬件和软件共同实现"。
2. **网盘冗余备份**：用户上传文件到网盘，服务器 A 会向服务器 B 备份该文件。如果服务器 A 损坏，仍可从服务器 B 下载——这是"提高可靠性"功能的典型体现。

## 反例/边界（≥1个）
1. **混淆通信子网和资源子网的界限**：主机内部的网络适配器和底层网络协议属于通信子网（用于实现信息传输），而主机上的其他硬件和软件（如应用软件）属于资源子网。不能把整个主机都归为资源子网。

## 详细解释

### 组成要素详解

**硬件**：看得见摸得着的物理设备。主机（端系统）包括电脑、手机、服务器、智能摄像头等；通信设备包括路由器、集线器、交换机、调制解调器等；通信链路包括网线、光纤、无线信道等。

**软件**：安装在主机或通信设备上的程序。电脑和手机上的聊天软件、视频播放器属于网络软件；路由器的操作系统用于实现网络通信功能。

**协议**：通信双方必须遵守的规则。协议通常由软件和硬件共同实现——例如网卡（硬件）加上其固件（软件）共同实现 TCP/IP 协议。

### 边缘部分 vs 核心部分

- **边缘部分**：由所有联网的主机和安装在其上的软件组成，直接为用户（人）服务。
- **核心部分**：为边缘部分的主机提供**连通性**（A 与 B 能互通）和**交换服务**（动态选择数据传送的最佳路径，实现网络内部资源的动态配置）。

核心部分的交换服务由路由器实现。路由器根据网络负载情况，自动为数据包选择一条合适的路径——相当于对网络内部资源的动态配置。

### 六大功能

| 功能 | 说明 | 举例 |
|------|------|------|
| **数据通信** | 最基本最重要的功能，其他功能的基础 | 发消息、传文件 |
| **资源共享** | 共享硬件、软件和数据资源 | 智能音箱使用云端算力（硬件）；应用商店下载软件（软件）；视频共享（数据） |
| **分布式处理** | 将复杂任务拆分给多台计算机分别处理 | 矩阵乘法拆分为多个子任务并行计算 |
| **提高可靠性** | 多台计算机互为替代机 | 网盘文件在多个服务器上冗余备份 |
| **负载均衡** | 多台计算机共同分担繁重任务 | 游戏服务器的对战匹配和实际对战分离处理 |
| **其他** | 满足社会和生活需求 | 远程办公、远程教育、网络娱乐 |
