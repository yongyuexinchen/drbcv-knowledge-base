# RIP工作过程

## 类型判定
连接型 — 回答"RIP协议从启动到收敛如何工作、如何适应拓扑变化、有什么缺陷"的问题，核心是演示距离向量算法在RIP中的完整运作流程。

## 是什么
RIP的工作过程是一个"从启动到收敛再到应对变化"的闭环：路由器启动→初始化直连路由→与邻居交换完整路由表→用距离向量算法更新→多轮迭代直至收敛。拓扑变化时，RIP能动态调整（但"坏消息"传播很慢），并且错误的距离信息会导致路由环路（"踢皮球"）。

## 输入-输出空间
- **输入**：邻居定期发来的RIP响应报文（完整路由表），以及本地探测到的直连网络变化
- **输出**：路由器不断更新的路由表，最终达到稳定收敛状态
- **映射关系**：映射关系 — 邻居的距离向量经过"距离+1、下一跳指向邻居"的修改后，与本地路由表做比较、合并或替换

## 正例（至少2个）
1. **RIP收敛（从启动到稳定）**：4台路由器R1-R4、4个网络net1-net4同时开机。各路由器先建立初始路由表（只含直连网络）。然后每30秒交换一次路由表：第0轮发现直连邻居的网络，第30轮发现非直连的网络，第60轮所有路由器都知道所有网络，RIP收敛。
2. **RIP适应新链路**：假设R1和R4之间原有路径需经过R3中转，后来直接拉了一条光纤直连。R1收到R4发来的路由表后发现直连路径更短（距离从3变为2），立即更新路由表并逐轮传递这个好消息，其他路由器也逐渐改用更优路径。

## 反例/边界（至少1个）
1. **RIP的慢收敛（坏消息传得慢）**：路由器R2突然损坏，R1需要等180秒超时才意识到R2不可达。而且因为R1从R3/R4那里误学了"可以到net2"的错误信息，导致IP数据报在R1↔R3↔R4之间"踢皮球"形成环路。每30秒错误距离+1，直到16才确认不可达。

## 详细解释

### 阶段一：路由器启动到收敛

**初始状态**：所有路由器同时开机
1. 每台路由器先探测**直连网络**，构建初始路由表（直连网络距离=1）
2. 各路由器立即向邻居发送自己的完整路由表

**第0轮交换**（刚开机瞬间）：
- R1收到R2路由表（net2），R1原本没有net2的记录 → 添加(net2, 距离2, 下一跳R2)
- R1收到R3路由表（net3），同理添加(net3, 距离2, 下一跳R3)
- R2通过R1发现net0和net1
- R3通过R1发现net0和net1；通过R4发现net4
- R4通过R3发现net3

**第30轮交换**：
- R1从R3的表中发现net4（距离3）→ 添加(net4, 距离3, 下一跳R3)
- R2从R1的表中发现net3
- R3已知所有网络不变；R4从R3发现net2

**第60轮交换**：
- R2从R1发现net4；R4从R3发现net2
- **此时所有路由器都知道所有目的网络 → RIP收敛**

### 阶段二：RIP如何更新路由表

路由器收到邻居X发来的RIP报文后，对每个表项执行：

1. **修改报文**：距离+1，下一跳改为邻居X（为距离向量算法服务）
2. **逐项比较**：

| 条件 | 动作 |
|------|------|
| 路由表中没有目的网络N | 添加该表项（发现新网络） |
| 已有目的网络N，且下一跳就是X | 替换为收到的信息（以最新为准） |
| 已有目的网络N，且下一跳不是X，但新距离<原距离 | 替换（发现更优路径） |
| 已有目的网络N，且下一跳不是X，新距离≥原距离 | 不做任何操作 |

### 阶段三：动态适应拓扑变化——新链路加入

示例：R1和R4之间新增一条直连链路（代价=1）

**120轮**：R1和R4成为新邻居，交换路由表
- R1发现走R4到net4距离=2（原来走R3距离=3）→ **更新为更优路径**
- R4发现走R1到net0/1/2距离更短 → 更新

**150轮**：R2从R1收到更新的net4信息（距离=2→变为3，即R1→R4新路径）
- R2更新net4距离为3（下一跳仍是R1）

**收敛**：所有路由器在新拓扑下重新收敛

### 阶段四：RIP的缺点——慢收敛与路由环路

示例：R2损坏（第160时刻）

**第330时刻**（R2损坏后约170秒，距上次联系已超180秒）：
- R1判定R2不可达（距离改为16）
- 但R1之前从R3/R4那里学到"到达net2距离=4" → R1误以为net2可通过R3/R4到达
- **形成环路**：发给net2的IP包在R1↔R3↔R4之间踢皮球，直到TTL=0

**环路消失过程**（计数到无穷）：
- 第330轮：R1误以为到net2距离=4；R3看到R1的错误信息后把距离从3改成5
- 第360轮：所有路由器认为到net2距离=5
- 每30秒距离+1，直到达到 **16**（不可达）
- 最终在第690时刻才完成收敛，从R2损坏到收敛共耗时530秒

**RIP的三个主要缺点**：
1. **网络规模受限**：最大跳数15，只能用于小型网络
2. **交换完整路由表**：路由表臃肿时，周期性的全量交换开销大
3. **慢收敛**：坏消息传播慢，收敛时间长，期间可能产生路由环路

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 收敛时间 | 理想状态下约60-90秒（大规模网络更长） |
| 超时判定 | 180秒未收到邻居更新则标记为不可达 |
| 环路防止 | 最大跳数16，计数到无穷后自动停止 |
| 负载均衡 | 等价多路径时，RIP支持轮询转发 |

### RIP的负载均衡
当到达同一目的网络有多条距离相等的路径时，RIP会将多条路径都写入路由表，采用轮询转发的策略实现负载均衡。
