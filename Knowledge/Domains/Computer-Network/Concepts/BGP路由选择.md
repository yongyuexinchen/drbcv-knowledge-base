# BGP路由选择

## 类型判定
连接型 — 回答"当到达某个外部网络有多条AS路径可选时，BGP如何决策选哪条"的问题，核心是BGP的四步路由选择策略算法。

## 是什么
当一台BGP路由器得知到达某个**外部**目的网络有多条不同AS路径时，它需要决定走哪条路。BGP路由选择采用**逐级裁决**的策略，依次比较四条标准：①本地偏好值最高 → ②AS跳数最少 → ③热土豆路由（尽快离开本AS） → ④BGP标识符最小。

每个策略只在前一个策略无法分出胜负（多条路径平局）时才触发下一个。**第四步一定能决出唯一路径**（因为BGP标识符全局唯一）。

## 输入-输出空间
- **输入**：多条到达同一外部目的网络的BGP路由信息（每条含本地偏好值、AS_PATH、NEXT_HOP等属性）
- **输出**：唯一选中的最佳路由
- **映射关系**：映射关系 — 多条候选路由经过四级筛选策略，最终映射为一条最佳路由

## 正例（至少2个）
1. **基于经济成本的选路**：AS1有两条路到AS5的目的网络X——上面经AS2→AS3→AS5（3跳），下面经AS4→AS5（2跳）。但AS2收费比AS4便宜，管理员为经AS2的路由设置更高本地偏好值（例如200），经AS4的路径不管多远都被优先选择（除非AS2的路由出故障）。
2. **基于出口代价的选路（热土豆）**：AS1内部有两台边界路由器都能到外部目的X，且本地偏好值和AS跳数都相同。R1在内部查IGP发现：到上边界路由器代价=3，到下边界路由器代价=5。R1选择代价更小的上边界路由器（尽快把"烫手土豆"扔出去）。

## 反例/边界（至少1个）
1. **BGP路由选择 ≠ 只在AS内部选路**：如果目的网络就在本AS内部（通过IGP即可到达），根本不需要BGP路由选择的规则。BGP选路只适用于**外部**AS的目的网络。

## 详细解释

### BGP路由选择的四步策略

```
多条候选路由到达同一外部网络X
         │
         ▼
┌─ 第1步：本地偏好值最高？ ─→ 是 → 选中
         │ 否（平局）
         ▼
┌─ 第2步：AS跳数最少？ ──→ 是 → 选中
         │ 否（平局）
         ▼
┌─ 第3步：热土豆（最小出口代价）？ ─→ 是 → 选中
         │ 否（平局）
         ▼
┌─ 第4步：BGP标识符最小 → 必能选出
```

#### 第1步：本地偏好值（Local Preference）最高
- **什么是本地偏好值**：每条BGP路由可被管理员赋予一个"本地偏好"数值，数值越高优先级越高
- **由谁设置**：**本AS的管理员**手工配置，基于政治/安全/经济等因素
- **设置场景举例**：
  - 经AS2的路径虽然跳数多，但AS2收费低 → 设置高本地偏好值
  - 经AS4的路径会经过敌对国 → 设置低本地偏好值（甚至不用）
- **作用**：管理员可以人为地**控制本AS流出流量的方向**

#### 第2步：AS跳数（AS_PATH长度）最少
- **什么是AS跳数**：AS_PATH属性中AS编号的个数
- 如果管理员对所有路径都没有设置本地偏好（或偏好相同），就选择AS跳数最少的路径
- **注意**：AS跳数最少 ≠ 路由器跳数最少！AS内部的IGP路径可能很长

#### 第3步：热土豆路由选择算法（Hot Potato / 最小出口代价）
- **核心思想**：让"烫手山芋"（IP数据报）尽快离开本AS——选择到达**出口路由器**代价最小的路径
- **具体做法**：结合本AS的内部网关协议（RIP/OSPF），计算从本路由器到各出口路由器的代价，选择代价最小的出口
- **代价度量**：取决于IGP类型（RIP看跳数，OSPF看总代价）

**示例1（AS内用RIP）**：
- 走上面出口需R1→R2（2跳）才能离开本AS
- 走下面出口需R1→R3→R4（3跳）
- → 选上面出口

**示例2（AS内用OSPF）**：
- 走上面出口总代价=6
- 走下面出口总代价=2+3=5
- → 选代价更小的下面出口

#### 第4步：BGP标识符（BGP Identifier / BGP ID）最小
- **BGP ID**：运行BGP路由器的唯一标识（32位），类似"员工工号"
- **如何确定**：通常选取路由器各接口中**最大的IP地址**（或管理员手动指定）
- **逻辑**：多条路由各方面性能都相同，选择"老员工"（ID更小）提供的路由
- 因为BGP ID全局唯一，此步**一定能选出唯一路由**

### 路由选择综合示例

AS1的左边路由器R1需要发IP分组到外部AS5的目的网络X。

**候选路由A**（经R2→R3→R5→AS2→AS3→AS5）：
- R1→R2代价=3（IGP计算）
- 本地偏好值=100
- AS_PATH=AS2,AS3,AS5（3跳）
- 由R2（BGP ID=6661）通告

**候选路由B**（经R4→R6→AS4→AS5）：
- R1→R4代价=5（IGP计算）
- 本地偏好值=100
- AS_PATH=AS4,AS5（2跳）
- 由R6（BGP ID=6662）通告

**选路过程**：
1. **第1步**：本地偏好值相等（都是100） → 进入第2步
2. **第2步**：AS跳数比较——路由B（2跳）< 路由A（3跳）→ **选中路由B**

如果两条路由AS跳数也相同（都是3跳）：
3. **第3步**：热土豆——路由A的出口代价（R1→R2=3）< 路由B（R1→R4=5）→ **选中路由A**

如果出口代价也相同（如R1→R2=5, R1→R4=5）：
4. **第4步**：BGP ID——路由A的通告者R2（ID=6661）< 路由B的通告者R6（ID=6662）→ **选中路由A**

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 本地偏好值范围 | 通常0~65535，越大越优先 |
| AS跳数 | AS_PATH列表中AS的个数 |
| 热土豆算法 | 让数据报以最少代价离开本AS |
| BGP ID确定 | 通常用路由器最大接口IP |
| 唯一结果 | 第4步一定能选出唯一路由 |

### 记忆口诀
"本AS跳土豆"——**本**地偏好 → A**S**跳数 → **土豆**（热土豆）→ BGP ID
