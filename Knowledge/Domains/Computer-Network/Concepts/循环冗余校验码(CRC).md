# 循环冗余校验码(CRC)

## 类型判定
连接型 — 回答"CRC码如何构造/如何校验"，核心是"模2除法"计算规则和检错判断过程，含完整计算流程。

## 是什么
循环冗余校验码（Cyclic Redundancy Check，CRC）是一种基于**二进制模2除法**的检错编码技术。发送方和接收方事先约定一个**生成多项式**（即除数），发送方在K位信息位后拼接R位校验位（冗余位），使整个码字除以生成多项式的余数为0。接收方同样做模2除法：余数为0→无误，余数非0→有错误。CRC能检测所有奇数个错误、所有双比特错误，以及所有长度≤R的突发错误。

## 输入-输出空间
- **输入**：K位信息位 + 生成多项式G(x)
- **输出**：K+R位CRC校验码（信息位+校验位）
- **映射关系**：映射关系 — 校验位由信息位和生成多项式通过模2除法唯一确定

## 正例（至少2个）
1. **CRC编码**：信息位为 `110101`，生成多项式G(x)=x³+x²+1（对应二进制`1101`）。信息位左移3位补0得 `110101000`，模2除以`1101`得余数`001`，最终CRC码为 `110101001`。接收方用`1101`做模2除得到余数`000`→无误。
2. **CRC检错**：上面码字在传输中某位（如C2位）出错变成 `110111001`，接收方用`1101`做模2除得到余数`010`（非0）→检测出错误。

## 反例/边界（至少1个）
1. **信息位过长时CRC无法纠错**：如果校验位只有3位（最多表示8种状态），而码字有9位（9种出错位置+1种正确状态=10>8），则不同的出错位置可能映射到相同的余数，此时CRC只能检错不能纠错。但在信息位较短（满足2ᴿ ≥ K+R+1）时，CRC可以纠正单比特错误。

## 详细解释

### 基本概念
- **信息位**：K位原始数据
- **校验位/冗余位**：R位，由模2除法求得
- **生成多项式G(x)**：二进制除数，其最高次幂决定校验位位数R
- **CRC码**：K+R位的完整发送码字

### 编码步骤（手动计算）
1. 确定校验位位数R = 生成多项式的最高次幂
2. 信息位左移R位（末尾补R个0）
3. 用补0后的数与生成多项式做**模2除法**
4. 得到的R位余数即校验位
5. 原始信息位 + 校验位 = CRC校验码

### 模2除法规则
模2除法与普通除法的核心区别：
- **模2加/减**等同于**异或运算**（不进位/不借位）
- 商的每一位仅看被除数当前最高位：为1则商1，为0则商0
- 余数的位数比除数少1

### 检错与纠错能力
| 能力 | 说明 |
|------|------|
| 检错 | 所有奇数位错误、所有双比特错误、长度≤R的突发错误 |
| 纠错 | 满足 2ᴿ ≥ K+R+1 时可纠正单比特错误（实际网络中一般只用于检错） |

### 名称由来
当出错位位置变化时，余数呈现循环规律（例如001→010→100→...→001），故称"循环"冗余校验码。

## 生活类比
就像发快递时约定的"打包规则"：你和快递员约定用7除包裹重量必须余数为0。发货时你在包裹里加一些填充物让总重能被7整除。收货方一秤——能整除说明大概率没少东西；不能整除肯定少了或多了东西。只要填充物（校验位）够多，你还能通过余数推断具体少了什么东西在哪个位置。
