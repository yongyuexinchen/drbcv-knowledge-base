# 以太网与IEEE 802.3

## 类型判定
连接型 — 回答"以太网如何运作"，描述MAC帧格式（662N4）、物理层传输过程、单播/广播帧的转发行为、以及冲突域与广播域的划分。

## 是什么
以太网（Ethernet）是目前最主流的**有线局域网技术**，其标准化工作由IEEE 802.3工作组负责。在实际网络中，"以太网"本质上是DIX Ethernet V2标准（DEC、Intel、Xerox联合发布），而802.3标准仅在帧格式的**类型/长度字段**上与之有细微差异。当前市面上流行的是V2标准。

## 工作原理（连接型详解）

### 一、物理层标准命名规律
格式：**速率** + **Base**（基带信号） + **介质代号**
- **10Base5**：10Mbps，同轴电缆，最大段长500m
- **10Base2**：10Mbps，同轴电缆，最大段长200m
- **10BaseT**：10Mbps，双绞线（Twisted pair）
- **10BaseF**：10Mbps，光纤（Fiber）
- **100BaseTX** / **1000BaseT**：高速以太网

**半双工 vs 全双工**判断：
- 同轴电缆 → 只支持**半双工** → 需CSMA/CD
- 双绞线 → 速率<2.5Gbps时可选半双工/全双工；≥2.5Gbps只支持全双工
  - 连接集线器 → 半双工 → 需CSMA/CD
  - 连接交换机 → 默认全双工 → 无需介质访问控制
- 光纤 → 始终**全双工**（至少2根光纤） → 无需介质访问控制

### 二、MAC帧格式——662N4
以太网V2标准的MAC帧由5个字段组成，记忆口诀：**662N4收发斜数验**（收方地址→发送方地址→类型→数据→校验）

| 字段 | 长度 | 含义 |
|------|------|------|
| 目的地址 | 6字节（48bit） | 接收方的MAC地址；全1=广播帧 |
| 源地址 | 6字节（48bit） | 发送方的MAC地址 |
| 类型 | 2字节 | 标识上层网络层协议（如IPv4/IPv6） |
| 数据 | 46~1500字节 | IP数据报；不足46字节需填充 |
| FCS | 4字节 | CRC循环冗余校验码 |

**帧总长度范围**：64字节 ~ 1518字节

> **V2 vs 802.3差异**：V2的"类型"字段标识网络层协议；802.3标准中该字段表示数据长度（因为802.3设计时认为上层有LLC子层处理协议标识，但LLC已名存实亡）。

### 三、物理层传输过程
1. **前导码（8字节）**：物理层在MAC帧前插入
   - 7字节前同步码（10101010……）→使接收方同步时钟
   - 1字节帧开始定界符（10101011）→标记帧开始
2. **曼彻斯特编码**：以太网物理层采用曼彻斯特编码传输
3. **帧结束定界**：采用**违规编码法**（曼彻斯特编码中间无跳变）标记帧尾 + 传输间隙

### 四、单播帧与广播帧的传播

| 设备 | 冲突域 | 广播域 |
|------|--------|--------|
| 集线器 | 不隔离 | 不隔离 |
| 交换机 | **隔离** | 不隔离 |
| 路由器 | **隔离** | **隔离** |

- **单播帧**：交换机根据目的MAC地址转发到特定端口，不广播到所有端口
- **广播帧**（目的地址=48位全1）：交换机转发到除接收端口外的所有端口；路由器收到广播帧后**不转发**到其他网络（路由器隔离广播域）

### 五、冲突域与广播域
- **冲突域**：若两个节点同时发送数据会发生冲突，则它们位于同一冲突域。集线器不隔离冲突域，交换机隔离冲突域。
- **广播域**：若一个节点发送广播帧可被另一节点收到，则二者位于同一广播域。路由器隔离广播域，交换机不隔离。

## 正例（≥2个）
1. **典型家庭/办公室以太网**：光猫→路由器→交换机→各计算机。计算机与交换机之间使用双绞线（全双工），交换机将单播帧仅转发到目的端口，多台计算机可同时收发数据而不冲突。
2. **交换机+集线器混合网络**：交换机连接多个部门，每个部门使用集线器连接多台电脑。同部门的电脑处于同一冲突域（集线器不隔离冲突域），但不同部门的电脑被交换机隔离了冲突域。整个局域网属于同一广播域（路由器隔离广播域）。

## 反例/边界（≥1个）
1. **同轴电缆以太网不能全双工**：一根同轴电缆上所有节点共享同一物理介质，只能半双工通信——一个节点发送时其他节点必须等待。这是为什么早期的10Base5/10Base2必须使用CSMA/CD的原因。

## 详细解释

### MAC帧格式详解
**目的地址全1 → 广播帧**：当源节点发送目的地址为48位全1的帧时，交换机将其从除接收端口外的所有端口转发出去，该广播域内的所有节点都会收到。

**数据部分范围46~1500**：
- 下限46字节由CSMA/CD的最短帧长（64字节）决定：64 - 6(目的) - 6(源) - 2(类型) - 4(FCS) = 46
- 上限1500字节称为**MTU**（最大传输单元），是IP层分片的依据

### 以太网MAC地址
- 48位（6字节），全球唯一
- 高24位由IEEE分配给厂商，低24位由厂商分配
- 写入网卡ROM中，更换网卡即更换MAC地址

## 生活类比
想象一个办公楼（局域网）：
- **MAC地址**就像每个工位上的"工位号"——全球唯一（公司分配时确保不重复）
- **MAC帧格式（662N4）**就像一封信：收件人工位号（6位）→寄件人工位号（6位）→信件类型（2位）→内容（46~1500字）→邮票/防伪码（4位）
- **交换机**就像聪明的收发室——知道每个工位在哪个楼层哪个房间，只把信送到对应工位
- **集线器**就像笨收发室——不管是谁的信，在每个房间门口都贴一份
- **路由器**就像办公楼大门——大楼内广播的消息不会传到大街上（隔离广播域），但你的信可以寄到其他大楼（转发到其他网络）
