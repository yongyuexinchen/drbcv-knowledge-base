# 万维网WWW与HTTP

## 类型判定
混合模型 — URL和HTML是判别型（回答"是什么"）；HTTP工作流程是连接型（回答"访问网页时一步步发生什么"）

## 是什么
万维网（WWW）是一个全球范围的分布式连接式信息存储空间。三大组成元素为URL（统一资源定位符）、HTTP（超文本传输协议）、HTML（超文本标记语言）。HTTP基于TCP，默认端口80，采用C/S模型。

## 输入-输出空间
- **输入**: 用户在浏览器输入的URL（域名或IP）
- **输出**: 浏览器渲染出的完整网页
- **映射关系**: 映射关系（URL请求 → 网页显示）

## 正例（至少2个）
1. **访问B站**: 浏览器输入 www.bilibili.com → DNS解析获取IP → TCP三次握手 → HTTP请求首页HTML → 解析HTML并请求引用的图片/视频等元素 → 渲染显示完整页面
2. **流水线方式加速**: 持续连接流水线模式下，浏览器一次发出所有HTTP请求获取HTML中引用的多个元素，服务器连续返回所有响应，效率最高

## 反例/边界（至少1个）
1. **常见误解**: 非持续连接每次只能请求一个文件，速度很慢？虽然串行获取慢，但可以采用**并行TCP连接**的方式——同时建立多个TCP连接并发获取文件，将后N个元素的获取时间缩短为原来的1/N

## 详细解释
### 三大组成元素
**1. URL（统一资源定位符）**
格式: `protocol://host[:port]/path`
- protocol: 通信协议（http/https）
- host: 服务器域名或IP地址
- port: 默认为80，可省略
- path: 资源路径，访问首页时可省略（返回默认首页index.html）

**2. HTML（超文本标记语言）**
- 用标签（h1、img、video、br等）描述网页结构和内容
- 一个网页 = 1个HTML文件 + N个网页元素（图片、视频、音频等）
- HTML中指明元素存储路径，浏览器根据路径获取并渲染

**3. HTTP（超文本传输协议）**
- 基于TCP，默认端口80，C/S模型
- 两种数据结构：请求报文（告诉服务器要什么）+ 响应报文（服务器返回数据）
- 请求报文体积小（仅包含请求信息），响应报文可能体积大（携带文件数据）

### 访问网页的完整流程（8步）
1. **DHCP配置**: 主机获取IP、子网掩码、默认网关、DNS服务器地址
2. **DNS解析**: 浏览器构造DNS请求报文（UDP，端口53）→ 本地域名服务器查询 → 返回域名对应IP
3. **TCP三次握手**: 浏览器与Web服务器（IP+80端口）建立TCP连接
4. **第一次HTTP请求/响应**: 第三次握手携带HTTP请求（GET /index.html）→ 服务器返回HTTP响应（携带HTML文件）
5. **解析HTML**: 浏览器解析HTML，发现引用的元素（图片、视频等）
6. **获取引用元素**: 对每个元素发起HTTP请求/响应，方式取决于HTTP工作模式
7. **渲染**: 浏览器将HTML和所有元素组合渲染
8. **显示**: 完整网页呈现在用户眼前

### HTTP的三种工作方式
**非持续连接（HTTP/1.0默认）**
- 每次HTTP请求/响应后立即断开TCP连接
- 获取N个文件需N次TCP连接
- 每个文件至少需要2×RTT时间
- 可用并行TCP连接加速（但第一个HTML必须串行获取）

**持续连接非流水线（HTTP/1.1默认）**
- TCP连接保持不立即断开
- 串行发出请求：获得一个响应后再请求下一个
- 减少TCP连接建立的开销

**持续连接流水线**
- TCP连接保持
- 浏览器一次连续发出所有请求
- 服务器连续返回所有响应
- 效率最高

### 关键图示解读
- HTTP请求报文画成细线：请求报文体积小，传输时延可忽略
- HTTP响应报文画成宽条：响应报文可能携带大文件，传输时延不可忽略
- 非持续连接中，前一个连接未完全释放即可开始建立下一个连接

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| HTTP默认端口 | 80 |
| HTTPS | HTTP的加密增强版（"Pro Max Ultra版"） |
| 应用层模型 | C/S模型 |
| 传输层协议 | 基于TCP |
| HTTP/1.0默认方式 | 非持续连接 |
| HTTP/1.1默认方式 | 持续连接（可用Connection: close切换为非持续） |

### 使用原则
- 访问网页第一步永远是DNS解析
- 第一个HTML文件必须与其他元素串行获取（因为解析HTML后才能知道引用了哪些元素）
- 持续连接保持的时间由Web服务器程序配置
