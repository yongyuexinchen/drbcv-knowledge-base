# 物理层设备

## 类型判定
判别型 — 回答"物理层有哪些设备、各自的工作方式是什么、有何区别"，属于物理层的设备分类知识点。核心是区分中继器与集线器的功能原理、冲突域概念，以及"543原则"等约束。

## 是什么
**物理层设备**是工作在物理层的网络互连设备，主要功能是接收、整形再生和转发信号，以扩展网络的覆盖范围。考研需要掌握两种设备：**中继器**（2端口，信号再生转发）和**集线器**（多端口中继器，信号广播转发）。二者都不能隔离冲突域——所有连接在同一个中继器/集线器上的节点处于同一个冲突域中。

## 正例（≥2个）
1. **10Base-5同轴电缆网络扩展**：10Base-5标准规定同轴电缆最远传输500米。若A在100米处、B在800米处，可在中间部署中继器：A→电缆段1（500米）→中继器→电缆段2（300米）→B，信号经中继器整形再生后继续传输，确保B收到不失真的信号。
2. **集线器组网冲突域判定**：一台集线器连接4台主机，任意两台同时发送数据会冲突→4台主机同属一个冲突域。三台集线器各自连接4台主机，每台集线器对应一个独立冲突域（总共3个）。但若用主干集线器连接三台集线器→所有主机合并到同一个大冲突域。

## 反例/边界（≥1个）
1. **集线器 ≠ 交换机**：集线器（Hub）工作在物理层，转发信号时不识别MAC地址，将信号广播到所有端口；以太网交换机（Switch）工作在数据链路层，根据MAC地址有选择地转发帧，可以**隔离冲突域**。这是考研的常考易混点。

## 详细解释

### 中继器（Repeater）

**工作原理**：
- 只有**2个端口**：一个端口接收信号，整形再生后从另一个端口转发
- 信号传输距离越远，失真越严重（电阻导致电压/电流衰减）。中继器在信号失真"还可识别"的范围内将其**整形成标准信号**后继续传播
- 支持**半双工通信**：两个方向不能同时传输，否则发生信号冲突
- 两个端口分别对应两个网段

**使用限制**：
- **543原则**：以太网标准限制中继器串联数。用中继器串联同轴电缆时：
  - 最多串联**5个网段**
  - 最多使用**4台中继器**
  - 5个网段中只有**3个**可以挂接计算机
  - 超出此限制会导致信号失真无法恢复

### 集线器（Hub）

**工作原理**：
- **多端口中继器**：将从一个端口收到的信号整形再生后，**广播转发到其他所有端口**
- 任意时刻只能有一个端口发送数据，否则信号冲突
- 每个端口对应一个网段，所有网段处于同一个冲突域

**关键特性**：

| 特性 | 说明 |
|------|------|
| 冲突域隔离 | ❌ 不能隔离——所有端口在同一冲突域 |
| 广播域隔离 | ❌ 不能隔离 |
| 拓扑结构 | 物理上**星型**，逻辑上**总线型** |
| 带宽共享 | 总带宽由各节点共享（如10Mbps总带宽、8台主机→每台平均1.25Mbps） |
| 传输介质 | 可连接不同类型的传输介质（如同时支持同轴电缆和双绞线） |
| 传输速率 | 可连接不同速率的网段（向下兼容，以最低速率为准） |

> **教材与现实差异提示**：大多数国内教材说中继器/集线器"不能连接不同物理层协议"或"不能连接不同速率网段"，但现实产品可以做到（如通过内部芯片转换编码方式）。考研做题时以教材为准，但需了解现实中的灵活性。

### 冲突域概念

**冲突域**（碰撞域）：若两台主机**同时发送数据会导致信号冲突**，则它们属于同一个冲突域。

- 中继器/集线器连接的节点 → 同属一个冲突域
- 以太网交换机连接的节点 → 可隔离冲突域（不同端口分属不同冲突域）
- 路由器连接的节点 → 可隔离冲突域和广播域

**冲突域的意义**：同一冲突域内的主机在发送数据前需要进行**信道征用**（使用CSMA/CD等介质访问控制协议），以避免或解决冲突问题。

## 生活类比
中继器就像**语音信号中继站**：你在山顶喊话，山谷那边的人听不清，中间放一个中继器（人）把你的话重复一遍——但他只能同时听和说一个方向（半双工），不能同时接两个方向的电话。

集线器就像一个**老式教室广播系统**：老师（一个端口）对着麦克风说话，广播把声音传到每个教室（所有其他端口）。但如果有两个老师同时对着麦克风说话（两个端口同时发），声音就乱成一团（信号冲突）——所以老师之间需要约定"你来说，我听着"，不能同时讲。
