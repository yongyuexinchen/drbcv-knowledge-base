# OSPF 路由器类型（ASBR / ABR / 内部路由器）

## 类型判定
判别型 — 回答"OSPF 网络中有哪几类路由器、各自负责什么"的问题。核心是按"路由器在 AS 中的位置和职责"分类，三类路由器对应三种不同的路由转发任务。

## 类比
**一句话比喻：** ASBR 是海关——管进出国的货物；ABR 是省界收费站——管跨省通行；内部路由器是市内快递员——只在自己城市跑。

| 路由器类型 | 生活映射 | 一句话职责 |
|-----------|---------|-----------|
| **ASBR** | 国际机场海关 | 本 AS 和外界的唯一出入口，引进外部路由 |
| **ABR** | 省界收费站 | 连接主干区域和非主干区域，跨区转发 |
| **内部路由器** | 市内快递员 | 所有接口在同一个区域内，只管内循环 |

## 是什么

在 OSPF 分区域架构中，路由器按所处位置和职责分为三类：

```
                     ┌─── 其他自治系统 ───┐
                     │                    │
              ┌──────▼──┐          ┌──────▼──┐
              │  ASBR   │          │  ASBR   │  ← 自治系统边界路由器
              │  (R6)   │          │  (R10)  │     (青色)
              └────┬────┘          └────┬────┘
                   │                    │
    ═══════════════╪════════ 区域 0 ════╪══════════════
                   │         (主干)      │
    ┌──────┐  ┌───▼──┐  ┌───▼──┐  ┌───▼──┐  ┌──────┐
    │内部  │  │ ABR  │  │内部  │  │ ABR  │  │内部  │
    │路由器│  │(R3)  │  │路由器│  │(R7)  │  │路由器│
    │(R5)  │  └──┬───┘  │(R4)  │  └──┬───┘  │(R10?)│
    └──────┘     │      └──────┘     │      └──────┘
    ════════════╪═══════  区域 2 ═══╪══════════════
          区域 1 │                  │ 区域 3
    ┌──────┐  ┌─▼──┐  ┌──────┐  ┌──▼──┐
    │内部  │  │内部│  │内部  │  │内部 │
    │路由器│  │路由│  │路由器│  │路由 │
    │(R1)  │  │(R2)│  │(R8)  │  │(R9) │
    └──────┘  └────┘  └──────┘  └─────┘
```

## 正例（≥2 个）

1. **ABR 连接区域 0 和区域 1**：R3 同时属于区域 0 和区域 1，维护两份 LSDB（区域 0 的 + 区域 1 的）。区域 1 内部的路由器 R1、R2 发往区域 2 的 IP 分组 → 交给 ABR(R3) → R3 通过主干区域转发给 ABR(R4) → R4 交给区域 2 的内部路由器 R8。ABR 是跨区通信的必经之路。

2. **ASBR 引入外部路由**：R6 除了运行 OSPF，还通过 BGP 学到"其他 AS 的网段"。R6 把这些外部路由注入 OSPF，让 AS 内所有路由器知道怎么去外部。没有 ASBR，本 AS 的路由器不知道外部世界的存在。

## 反例/边界（≥1 个）

1. **一台路由器可以同时是 ABR 和 ASBR**：如果 R6 同时连接区域 0 和外部 AS，它就是 ABR+ASBR 双重身份。分类不是互斥的——看职责。
2. **内部路由器 ≠ 不重要**：主干区域内的内部路由器（如 R5）虽然不跨界，但在 Dijkstra 计算中承担转发任务，是主干拓扑的关键节点。

## 详细解释

### 三类路由器对比

| | ASBR | ABR | 内部路由器 |
|---|------|-----|----------|
| **全称** | Autonomous System Boundary Router | Area Border Router | Internal Router |
| **位置** | AS 边界，连接外部网络 | 区域边界，至少连接两个区域（必须含 Area 0） | 所有接口在同一区域内 |
| **职责** | 引入外部路由、向外通告本 AS 路由 | 跨区域转发、汇总区域路由 | 区域内转发 |
| **LSDB 数量** | 1 份（所在区域）+ 外部路由 | 每个连接区域各 1 份 | 1 份（所在区域） |
| **典型角色** | 连接 Internet 的出口路由器 | 省网和省干网的桥梁 | 接入层路由器 |
| **图中颜色** | 🔵 青色 | 🟢 绿色 | ⚪ 白色 |

### 为什么要分区？

如果整个 AS 不分区：
- 任何一条链路抖动 → LSA 洪泛全网 → 所有路由器重新跑 Dijkstra
- 500 台路由器的 LSDB 巨大，Dijkstra 计算量 $O(n^2)$

分区后：
- 洪泛局限在区域内（不跨区）
- ABR 只向其他区域通告**汇总路由**，不通告每条具体链路
- 每台路由器只需维护自己所在区域的 LSDB

### 区域标识符（Area ID）

- 32 bit 长度，通常写成点分十进制：`0.0.0.0`（主干）、`0.0.0.1`（区域 1）
- **Area 0 = 主干区域**，所有非主干区域必须直连 Area 0
- 非主干区域之间不能直接通信——必须经过 Area 0 转发
