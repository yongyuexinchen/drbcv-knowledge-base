# 以太网交换机

## 类型判定
连接型 — 回答交换机"如何工作"的问题，核心是自学习算法如何动态建立交换表、以及两种交换方式（直通 vs 存储转发）的转发机制差异。

## 是什么
以太网交换机是一种工作在数据链路层的网络设备，基于**MAC地址**对以太网帧进行转发。它具有多个端口，每个端口通常支持全双工通信。交换机的核心能力来自**自学习功能**：通过动态维护一张交换表（MAC地址 ↔ 端口号的映射），自动学习每个节点连接在哪个端口，实现"即插即用"。交换机本质上是多端口的网桥。

## 输入-输出空间
- **输入**：从某个端口收到一个以太网帧（含目的MAC和源MAC地址）
- **输出**：根据目的MAC在交换表中查找对应端口，从该端口转发出去；若查不到则广播到除入口外所有端口
- **映射关系**：映射关系 — 输入帧的MAC地址，经过查表决策，输出转发端口的选择

## 正例（至少2个）
1. **办公室网络**：办公室20台电脑连接到一台交换机。当A电脑第一次给B电脑发数据时，交换机不知道B在哪个端口，就广播此帧；B回复后交换机学到B的位置。此后A再给B发数据，交换机直接从对应端口精准转发。
2. **学校机房**：机房内两台交换机级联（通过Trunk口连接），学生机随机接入任意交换机端口。交换机的自学习功能自动记录每台电脑的MAC地址与端口的映射关系，无需任何手动配置，即插即用。

## 反例/边界（至少1个）
1. **交换机 ≠ 集线器**：集线器（Hub）工作在物理层，收到信号无脑广播到所有端口；交换机工作在数据链路层，能根据MAC地址选择性转发，不造成不必要的冲突和浪费。集线器连接的端口只能工作在半双工模式，而交换机端口通常支持全双工。

## 详细解释

### 自学习算法（交换机工作的核心）
每台交换机内部维护一张**交换表**，初始为空。自学习过程通过**被动监听**进行：

```
收到一个来自端口X的帧，源MAC = S，目的MAC = D：

1. 学习：将(S, X) 写入/更新交换表（"从哪个端口来的→这个MAC在哪个端口"）
2. 转发决策：
   - 如果D在交换表中查得到（对应端口Y），从端口Y转发（单播转发）
   - 如果D查不到，从除X外的所有端口转发（广播泛洪）
   - 如果D对应的端口就是X，丢弃此帧（不转发回来源）
3. 表项老化：每个表项设有效期，超时自动删除
```

**为什么需要老化？**
如果一台主机从端口1拔下改插到端口2，交换表中"MAC→端口1"的旧记录就错了。老化机制让错误的表项过期失效，此后当该主机发送下一个帧时，交换机能重新学习到正确位置。

### 完整自学习示例（两交换机级联）

假设两台交换机S1和S2级联，节点A(9A)~L(95)分布在各个端口：

| 步骤 | 帧 | 交换机1学到 | 交换机2学到 | 转发方式 |
|------|------|------------|------------|---------|
| ①A→C | A在端口1 | A在端口1(收到广播) | 广播(未学到C) |
| ②B→C | B在端口2 | B在端口1(收到广播) | 广播(未学到C) |
| ③C→A | C在端口3 | — | 精准转发（A在端口1） |
| ④H→A | — | H在端口2 | 精准转发（H→A） |
| ⑤H→C | — | C在端口1(学到) | 精准转发（C在端口3） |
| ... | ... | ... | ... | ... |

经过几轮帧交换，两台交换机的交换表收敛到完整的MAC-端口映射。

### 两种交换方式

| 特性 | 直通交换（Cut-through） | 存储转发交换（Store-and-forward） |
|------|------------------------|---------------------------------|
| **接收程度** | 只接收前6字节（目的MAC） | 接收完整帧（全部存入缓存） |
| **转发时延** | 低（仅处理目的地址的时间） | 高（需缓存完整帧） |
| **差错检测** | 不支持 | 支持（CRC校验后转发） |
| **协议转换** | 不支持 | 支持（如标准以太网帧↔802.1Q帧） |
| **速率匹配** | 不支持（输入输出速率需相同） | 支持（可缓存后再以不同速率输出） |
| **适用场景** | 低延迟要求的内部网络 | 需要差错控制、协议转换、速率适配的复杂网络 |

**生活类比**：
- **直通交换** ≈ 快递分拣员只看包裹上的地址标签就丢到对应传送带，不看里面装了什么、有没有破损
- **存储转发** ≈ 快递分拣员先接收整个包裹，检查有没有破损、录单号存档，再放到对应传送带上送走

### 直通交换的转发时延计算
直通交换只需读取前6字节（48比特）的目的MAC地址即可开始转发：
```
转发时延 ≥ 接收6字节的时间 = 48比特 ÷ 端口速率
```
例如100Mbps端口：48 ÷ 100×10⁶ = 0.48微秒

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 交换表 | 记录MAC地址↔端口号映射和表项有效期 |
| 全双工 | 交换机端口默认全双工（同时收发），连接集线器时降为半双工 |
| 即插即用 | 无需手动配置，自学习自动适应拓扑变化 |

### 交换机的数据链路层定位
- 以太网交换机基于MAC地址转发帧（数据链路层功能）
- 与路由器区别：路由器基于IP地址转发分组（网络层功能）
- 与集线器区别：集线器无脑广播（物理层功能）
