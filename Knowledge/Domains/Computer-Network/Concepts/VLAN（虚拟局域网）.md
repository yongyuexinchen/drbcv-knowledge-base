# VLAN（虚拟局域网）

## 类型判定
判别型 — 解决"什么是VLAN"的分类与识别问题，回答VLAN的概念、划分方式、帧格式等是什么层面的知识。

## 是什么
虚拟局域网（VLAN, Virtual LAN）是一种通过逻辑方式将一个物理局域网划分为多个独立的广播域的技术。每个VLAN对应一个独立的广播域，同一VLAN内的节点可以相互通信，不同VLAN间的节点默认隔离。VLAN的核心价值在于**缩小广播域规模、提升网络安全性**，由IEEE 802.1Q工作组标准化。

## 输入-输出空间
- **输入**：一个物理局域网（连接到支持VLAN的交换机的一组节点）
- **输出**：多个逻辑上隔离的虚拟局域网，每个VLAN用VID（VLAN ID，12比特）标识
- **映射关系**：从属关系 — VLAN是对物理局域网的逻辑划分

## 正例（至少2个）
1. **校园网隔离**：学校校园网是一个大型局域网，广播帧会传播到全校所有节点。通过VLAN将不同部门（教学区、行政楼、数据中心）划分为不同VLAN，广播仅限各自VLAN内传播，避免广播风暴，同时保护数据中心服务器不被普通终端探测。
2. **企业内外网分离**：公司将财务部服务器划入VLAN 10，普通员工电脑划入VLAN 20。财务部对外不可见，即使连接同一台物理交换机，员工也无法访问财务服务器，实现安全隔离。

## 反例/边界（至少1个）
1. **VLAN ≠ 子网**：VLAN是数据链路层（Layer 2）的概念，基于MAC地址或端口划分；子网是网络层（Layer 3）的概念，基于IP地址划分。但实践中VLAN常与IP子网一一对应部署。

## 详细解释

### 为什么要用VLAN？
传统大型局域网面临两大问题：
1. **广播风暴**：交换机组网的所有节点同属一个广播域，广播帧会扩散到全网。规模越大，广播帧越多，网络负载和节点处理负担急剧上升。
2. **安全性差**：高敏感节点（如服务器、数据中心）暴露在整个局域网中，易被探测和攻击。

VLAN通过逻辑分组将一个大广播域拆分为多个小广播域，从根本上解决上述问题。

### 三种划分方式

| 划分方式 | 映射关系 | 特点 |
|---------|---------|------|
| **基于接口（端口）** | VID ↔ 端口号 | 最常用；节点换接口会改变所属VLAN |
| **基于MAC地址** | VID ↔ MAC地址 | 节点换接口不改变归属；需配置MAC表 |
| **基于IP地址** | VID ↔ IP地址 | 需网络层支持，可跨越路由器组建VLAN |

### 802.1Q帧（干线链路帧格式）
交换机和交换机之间（即干线链路/Trunk链路上）传输时，使用802.1Q帧格式：
- 标准以太网帧：`6(目的MAC) + 6(源MAC) + 2(类型) + N(数据) + 4(FCS)`
- 802.1Q帧：在源MAC之后插入**4字节VLAN标签** → `6 + 6 + 4(VLAN标签) + 2 + N + 4`
- VLAN标签的4字节：前2字节固定值（标识802.1Q帧），后2字节中前4位无意义，后12位为**VID**（VLAN ID）

**关键规则**：主机与交换机之间传标准以太网帧；交换机和交换机之间（Trunk链路）传802.1Q帧。

### Trunk端口与Access端口
- **Access端口**：连接终端主机的端口，只属于一个VLAN，收发标准以太网帧
- **Trunk端口**：连接交换机之间的端口，允许多个VLAN的帧通过，收发802.1Q帧（带VLAN标签）

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| VID | VLAN标识符，12比特，取值范围0-4095 |
| 802.1Q标签 | 4字节，含TPID(2B) + Priority(3bit) + CFI(1bit) + VID(12bit) |
| 广播域 | 每个VLAN是一个独立广播域，广播帧不跨VLAN |

### 使用原则
- 同一VLAN内的节点通过交换机直接通信
- 不同VLAN间的通信必须经过路由器（三层转发）
- 支持VLAN的交换机才能进行VLAN配置
