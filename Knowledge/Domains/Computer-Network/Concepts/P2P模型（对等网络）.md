# P2P模型（对等网络）

## 类型判定
判别模型 — 回答"一个网络应用属于哪种模型"

## 是什么
P2P模型（对等网络模型）是一种去中心化的网络应用架构，各主机（称为对等方peer）之间地位平等，任意两台主机可以直接通信。核心思想是去中心化——"我为人人，人人为我"。

## 输入-输出空间
- **输入**: 网络应用的架构描述
- **输出**: 是否属于P2P模型
- **映射关系**: 从属关系

## 正例（至少2个）
1. **BT种子下载（µTorrent）**: 一台主机拥有资源后做成BT种子发布，其他主机通过种子从所有拥有该资源的主机同时索取数据，下载速度随分享者增多而加快
2. **P2P文件共享应用**: 多台对等方同时为下载者传输文件的不同部分，合并成完整文件

## 反例/边界（至少1个）
1. **常见误解**: P2P模型没有缺点？不，P2P也有缺点：主机在被服务的同时需要给其他主机服务导致负载较大；去中心化导致网络数据流量不可控，易造成拥塞；频繁读写硬盘可能缩短寿命

## 详细解释
P2P模型的核心特点是**去中心化**：

- 任两台对等方之间可直接通信（C/S模型中客户间不能直接通信）
- 单个节点损坏不影响全局（其他节点仍可提供服务）
- 各节点分摊负载，下载者越多下载速度越快

**优点**: 单个节点损坏不影响全局；各节点分摊负载，下载速度快
**缺点**: 主机在享受服务的同时需为他人服务，负载较大；数据流量不可控，易导致网络拥塞；硬盘频繁读写影响寿命

## 细节备注

### 子特性
| 特性 | 说明 |
|------|------|
| 地位关系 | 平等，去中心化 |
| 节点间通信 | 任意对等方可直接通信 |
| 负载特点 | 同时在服务他人和被他人服务 |
| 抗风险性 | 单个节点损坏不影响全局 |

### 使用原则
- ISP（互联网服务提供商）通常讨厌P2P应用，因其流量大且不可管控
- 现实中的P2P应用可能被反对，原因包括硬盘损耗和网络拥塞
