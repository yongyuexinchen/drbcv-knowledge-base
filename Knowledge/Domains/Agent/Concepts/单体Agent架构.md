# 单体Agent架构

## 类型判定
以一个大语言模型为核心，通过调用外部工具来扩展能力、自我规划和自我反省以完成用户目标的单一智能体工作模式。

## 类比 ★
### 一句话比喻
就像一个配备齐全的个人助理——他本身很聪明但数学差，所以随身带着计算器；记不住长文档，所以有个档案柜（向量数据库）；需要查实时信息就上网搜索——所有工具都听他一个人调度。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 大语言模型（LLM） | 助理的大脑 |
| 工具（Tools） | 助理随身携带的计算器、搜索引擎 |
| Agent | 助理本人（大脑+工具+执行能力） |
| Zero Shot Agent | 万能型助理，啥都能做 |
| Prompt / 提示词 | 工作任务说明书 |
| 文件加载 + 文本分割 | 把厚书拆成一页页方便查阅 |

## 是什么
单体 Agent 是以大语言模型为核心，能够自主规划行为、调用外部工具、进行自我反省，最终帮助用户完成特定目标的一套流程。它不是简单的"一问一答"，而是"理解意图 → 规划步骤 → 选择工具 → 执行 → 检查结果 → 反馈"的完整闭环。核心公式：**Agent = LLM + Tools + 自我规划 + 自我反省**。

## 正例（≥2 个）
1. **计算型 Agent**：LLM（ChatGPT）+ 计算工具（Calculator），用户输入复杂算式 → Agent 识别需要计算 → 调用计算器 → 得到结果 → 返回用户。解决了大模型计算能力弱的痛点。
2. **招股书分析 Agent**：LLM + 文件加载器 + 文本分割器 + 向量数据库 + 向量检索 + 搜索工具 + 计算工具。上传 400+ 页 PDF → 分割成小块 → 向量化存储 → 用户提问时检索相关内容 → LLM 综合回答。

## 反例/边界（≥1 个）
1. 纯大模型对话（无工具）：只是一个 Chat 界面，没有工具调用、没有自我规划能力，只能基于训练数据回答，不能执行操作、查实时信息或精确计算。
2. 多智能体系统：单体 Agent 只有一个"大脑"在调度所有工具，而多智能体有多个独立角色分工讨论。

## 详细解释
单体 Agent 的关键设计要素：
1. **LLM 底座**：Agent 的核心推理引擎，目前 GPT-4 效果最佳，ChatGLM3 在低版本 LangChain 下"带不动"
2. **工具集成**：通过 Agent 节点连接工具节点，工具包括计算器、搜索引擎（Bing/Google）、向量检索工具等
3. **提示词工程（Prompt）**：指导 Agent 的行为方式——什么时候该做什么、调用什么工具、输出什么格式
4. **预设问题**：通过 input 变量预设常问问题，用户只需上传文件即可自动执行分析流程
5. **Temperature 设置**：严谨应用场景（如招股书分析）建议设为 0，追求创造性可调高

文件处理链路：上传 PDF → 文件加载器读取 → 文本分割器切分（大文档无法一次塞入 LLM） → embedding 向量化 → 存入向量数据库 → 用户问题向量化 → 向量检索 → 返回相关内容给 LLM → LLM 综合回答。
