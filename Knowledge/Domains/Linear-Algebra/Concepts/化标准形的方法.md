# 化标准形的方法

## 是什么

将含交叉项的**普通二次型**化为只含平方项的**标准形**（或进一步化为规范形）的两种核心方法：

| 方法 | 原理 | 特点 |
|------|------|------|
| **正交变换法** | 求特征值 → 正交矩阵 $Q$ → $X = QY$ | 系数 = 特征值；保距（图形不扭曲） |
| **配方法** | 逐项配完全平方 → 换元 $X = PY$ | 系数非特征值但同正负；可化规范形 |

> 一句话：正交变换法是"旋转坐标系看本质"，配方法是"初中配方的高维版"。

## 正例

### 例1 — 正交变换法

$f = x_1^2 - 2x_2^2 - 2x_3^2 - 4x_1x_2 + 4x_1x_3 + 8x_2x_3$

**Step 1**：写矩阵 $A = \begin{bmatrix} 1 & -2 & 2 \\ -2 & -2 & 4 \\ 2 & 4 & -2 \end{bmatrix}$

**Step 2**：求特征值 → $\lambda_1 = -2, \lambda_2 = 1, \lambda_3 = 1$（重根）

**Step 3**：求特征向量 + 施密特正交化 + 单位化 → 拼成正交矩阵 $Q$

**Step 4**：令 $X = QY$，得标准形 $f = -2y_1^2 + y_2^2 + y_3^2$

正惯性指数 $p = 2$，负惯性指数 $q = 1$，秩 $r = 3$。

### 例2 — 配方法（有平方项）

$f = 2x_1^2 + 2x_2^2 + 2x_1x_2 - 4x_1x_3$

**配 $x_1$**（一次解决一项）：

$$\begin{aligned}
f &= 2(x_1^2 + x_1x_2 - 2x_1x_3) + 2x_2^2 \\
  &= 2[(x_1 + \tfrac{1}{2}x_2 - x_3)^2 - (\tfrac{1}{2}x_2 - x_3)^2] + 2x_2^2 \\
  &= 2(x_1 + \tfrac{1}{2}x_2 - x_3)^2 + \tfrac{3}{2}x_2^2 + 2x_2x_3 - 2x_3^2
\end{aligned}$$

**再配 $x_2$**：继续对剩余项配方 → 最终得到标准形。

换元 $Y = CX$，则 $X = C^{-1}Y$（注意旧变量在左侧）。

### 例3 — 化规范形（接例2）

标准形系数为 $2, \frac{3}{2}, -\frac{10}{3}$，进一步令：

$$z_1 = \sqrt{2}y_1,\quad z_2 = \sqrt{\tfrac{3}{2}}y_2,\quad z_3 = \sqrt{\tfrac{10}{3}}y_3$$

则规范形：$f = z_1^2 + z_2^2 - z_3^2$

## 反例/边界

- **配方法的坑**：最后得到的换元是 $Y = CX$（新变量 = 旧变量的表达式），但要求的是 $X = PY$（旧变量在左）→ 必须对 $C$ **求逆**：$P = C^{-1}$
- **无平方项的二次型**无法直接配方 → 先做**平方差换元**创造平方项：
  - 令 $x_1 = y_1 + y_2,\ x_2 = y_1 - y_2,\ x_3 = y_3$（利用交叉项 $x_1x_2$ 创造平方差）
  - 换元后 $x_1x_2$ 变成 $y_1^2 - y_2^2$，出现平方项后再继续配
- 正交变换法**不能化规范形**（系数被锁死在特征值）
- 配方法的标准化系数**不是特征值**，只保证**同正负**（惯性定理）

## 详细解释

### 方法对比

| | 正交变换法 | 配方法 |
|---|---|---|
| 本质 | 求特征值 + 正交对角化 | 逐项配方 + 换元 |
| 变换矩阵 | 正交矩阵 $Q$（$Q^T = Q^{-1}$） | 可逆矩阵 $P$（一般非正交） |
| 标准形系数 | 特征值 $\lambda_i$ | 配方后系数（与 $\lambda_i$ 同正负） |
| 能否化规范形 | ❌ | ✅（吸收系数到平方内） |
| 几何意义 | 旋转坐标系（保距） | 可拉伸变形 |
| 适用场景 | 考研大题必考 | 无特征值要求时更灵活 |

### 配方法核心规则

1. **一次只解决一个变量**：先把所有含 $x_1$ 的项揪出来，配成完全平方，$x_1$ 从此消失
2. **借了要还**：配平方时多出来的项要减去
3. **线性变换矩阵**：
   - 先写出 $Y = CX$（新 = $C \times$ 旧）
   - 所求 $X = PY$ 中 $P = C^{-1}$
4. **$C$ 的可逆性**：因为每次只解决一个变量，$C$ 是主对角形矩阵 → $\lvert C \rvert \neq 0$

### 平方差换元（无平方项时的救场）

若二次型只有交叉项无平方项（如 $f = 2x_1x_2 + 2x_1x_3 + 2x_2x_3$）：

$$\begin{cases}
x_1 = y_1 + y_2 \\
x_2 = y_1 - y_2 \\
x_3 = y_3
\end{cases}$$

则 $x_1x_2 = y_1^2 - y_2^2$，平方项就出现了，然后继续配方。

> 变换矩阵 $\begin{bmatrix}1 & 1 & 0 \\ 1 & -1 & 0 \\ 0 & 0 & 1\end{bmatrix}$，行列式 $= -2 \neq 0$，可逆 ✓

### 多次换元的合成

若经过两次换元 $X = C_1 Y,\ Y = C_2^{-1} Z$，则：

$$X = C_1 C_2^{-1} Z$$

总变换矩阵 = 两次变换矩阵的乘积。

## 类比 ★ 必须

### 一句话比喻

正交变换法就像**端着相机拍照**：你只是旋转相机（正交矩阵），被拍的碗（二次型）形状完全不变，换个角度看碗沿三个坐标轴方向的弯曲程度（特征值）。配方法则是**用手捏碗**：先捏 $x_1$ 方向（配 $x_1$），再捏 $x_2$ 方向，捏来捏去碗的样子变了（系数不同），但向上拱和向下凹的口子数目不会变（惯性指数守恒）。

### 生活映射

| 概念世界 | 现实世界 |
|---------|---------|
| 正交变换 $X = QY$ | 旋转相机——被拍物体不变，只是角度变了 |
| 特征值 $\lambda_i$ | 从"主轴视角"看到的弯曲程度 |
| 配方法（逐项配方） | 初中配方的高维版——$ax^2 + bx + c \to a(x + \frac{b}{2a})^2 + \cdots$ |
| "一次解决一项" | 先收拾 $x_1$ 的所有项 → $x_1$ 消失 → 再收拾 $x_2$ → 依次消灭 |
| 平方差换元 | 没有平方项？创造一个——把交叉项"掰成"平方差 |
| 换元后求逆 $P = C^{-1}$ | 你把新变量写成了旧变量的表达式 → 要求旧变量 = ？新变量 → 取逆 |
| 惯性指数 $p, q$ | 无论怎么捏，向上拱的口子数 ($p$) 和向下凹的口子数 ($q$) 永远不变 |
