# 行列式按行（列）展开（余子式 → 代数余子式 → 展开定理 → 替换法则）

## 类型判定
程序型 — 将高阶行列式降为低阶行列式计算的核心方法，也是替换法则（解代数余子式求和问题）的理论基础。

## 是什么

**行列式展开定理**：行列式等于某一行（列）的各元素与其对应的代数余子式乘积之和。

按第 $i$ 行展开：
$$
D = a_{i1} A_{i1} + a_{i2} A_{i2} + \cdots + a_{in} A_{in}
$$

按第 $j$ 列展开：
$$
D = a_{1j} A_{1j} + a_{2j} A_{2j} + \cdots + a_{nj} A_{nj}
$$

其中：
- **余子式** $M_{ij}$：删去 $a_{ij}$ 所在的行和列，剩余元素构成 $n-1$ 阶行列式
- **代数余子式** $A_{ij} = (-1)^{i+j} M_{ij}$：带符号的余子式

**替换法则（推论）**：某行元素 × **另一行**的代数余子式之和 = 0。

## 正例（≥2 个）

1. **四阶行列式降为三阶**
   将行列式通过倍加性质在一行（列）制造多个 0，只留一个非零元素，按该行展开：
   $$
   \text{四阶} \;\xrightarrow{\text{造零}}\; a_{ij} \cdot (-1)^{i+j} \cdot \text{三阶行列式}
   $$
   再用对角线法则计算三阶行列式。

2. **行列式按第一行展开（二阶）**
   $$
   \begin{vmatrix} a & b \\ c & d \end{vmatrix}
   = a \cdot A_{11} + b \cdot A_{12}
   = a \cdot (-1)^{1+1} \cdot d + b \cdot (-1)^{1+2} \cdot c
   = ad - bc
   $$

3. **替换法则实战**
   已知三阶行列式 $\lvert A \rvert = 1$，求 $A_{11} + A_{12} + A_{13}$：
   → 用 $1,1,1$ 替换原第一行 → 计算新行列式 = 替换后第一行 × 原代数余子式之和 = 1。

## 反例/边界（≥1 个）

1. **余子式 vs 代数余子式的符号陷阱**
   - 求**余子式 $M_{ij}$ 的和**，必须先转成代数余子式：$M_{ij} = (-1)^{i+j} A_{ij}$
   - 例如 $M_{11} + M_{21} + M_{31} = A_{11} - A_{21} + A_{31}$（符号跟位置有关）

2. **展开时必须一行/列的所有元素都参与**
   如果某行只剩两个非零元素（其余为 0），展开后是两个 $a_{ij}A_{ij}$ 的和——不是只留一个非零就只剩一项。

3. **替换法则只对同一套代数余子式有效**
   若 $A_{ij}$ 来自行列式 $D_1$，则 $\sum k_i A_{ij}$ 等价于用 $k_i$ 替换 $D_1$ 第 $j$ 列的**新行列式**。

## 详细解释

### 展开定理的核心思想：降阶

高阶行列式 → 挑选一行（列）→ 通过倍加性质把该行除一个元素外全变成 0 → 按该行展开 → 阶数降 1 → 重复直到可手算。

**最佳展开策略**：选 0 最多的行或列，用倍加性质在同行（列）继续造 0。

### 替换法则的本质

设行列式 $D = \lvert a_{ij} \rvert_{n \times n}$，$A_{ij}$ 为其代数余子式。

- **同行展开**：$\sum_{k=1}^{n} a_{ik} A_{ik} = D$
  — 该行元素 × 自己的代数余子式 = 行列式本身

- **异行展开**：$\sum_{k=1}^{n} a_{ik} A_{jk} = 0 \quad (i \neq j)$
  — 该行元素 × 另一行的代数余子式 = 0（相当于用该行替换了另一行 → 两行相同 → 行列式为 0）

**替换法则口诀**：
- 看到 $\sum k_i A_{i*}$ → 用 $k_i$ 去替换原行列式第 $i$ 行
- 看到 $\sum k_i A_{*j}$ → 用 $k_i$ 去替换原行列式第 $j$ 列
- 替换后计算新行列式，结果即为所求

### 降阶法的典型步骤

1. 观察行列式，找 0 最多的行或列
2. 利用倍加性质在该行（列）继续造 0，只保留 1~2 个非零元素
3. 按该行（列）展开，降一阶
4. 重复或用对角线法则收尾

## 类比 ★ 必须

### 一句话比喻
**余子式展开就像拆一栋摩天大楼——整栋楼太重搬不动，于是我们把它逐层拆解：选一层楼（某行），把这一层每个房间的面积（元素值）乘以"拆掉这一层后，剩下楼层围成的空间体积"（代数余子式），所有房间加起来就是整栋楼的总体积。如果你能在这一层里把大部分房间清空（造零），最后只剩一个房间有东西，那"整栋楼的体积 = 这个房间 × 剩下楼的体积"——一下子从 N 层问题变成了 N-1 层问题。**

### 生活映射

| 概念世界 | 现实世界 |
|---------|---------|
| 余子式 $M_{ij}$ | 把第 $i$ 层第 $j$ 号房间拆掉后，剩余楼层自行围成的"小楼" |
| 代数余子式 $A_{ij}$ | 带"风水系数"（$(-1)^{i+j}$）的余子式——位置决定正负，和棋盘的黑白格一样 |
| 展开定理 | 逐层清点法——每层每个房间 × 剩下楼的体积，全加起来 = 整栋楼 |
| 造零→只留一个非零 | 把一层楼的房间全部搬空，只剩一间有货——只要算那间就行 |
| 替换法则 | "冒名顶替"——用另一组数据假装成第 $i$ 行，去参与同一套代数余子式的计算 |
| 异行展开 = 0 | 把第二层的数据抄到第一层——两层一模一样 → 楼塌了，体积为 0 |
| 降阶 | 拆掉一层楼 → 问题从 $n$ 层变成 $n-1$ 层 |
