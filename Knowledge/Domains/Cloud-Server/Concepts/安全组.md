# 安全组

## 类型判定
这是一个概念定义——解释云服务器「安全组」是什么：它是一组防火墙规则，控制哪些端口的流量可以进出服务器。

## 类比 ★
### 一句话比喻
安全组就是你别墅院子的门禁清单——你告诉保安：「正门（22号门）允许保姆和主人刷卡进，侧门（80号门）允许访客进来看房，后门（3306号门）谁都不许开。」没有清单的门默认全部锁死，连只苍蝇都飞不进去。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 云服务器 | 你的别墅院子 |
| 安全组 | 保安手里的门禁清单 |
| 端口号 | 院子的门牌编号 |
| SSH 端口（22） | 正门——主人和保姆刷卡进出 |
| HTTP 端口（80） | 展厅门——访客随便进来看 |
| HTTPS 端口（443） | 加密展厅门——带安检的访客通道 |
| 自定义端口（如8000） | 你新开的一个侧门——不在清单上就打不开 |
| 0.0.0.0/0 | 「任何人都可以来」 |
| 添加安全组规则 | 在门禁清单上加一行：「8000号门，允许所有人进」 |

## 是什么
安全组是云服务器（阿里云ECS / 腾讯云CVM）的虚拟防火墙。它通过一组入站/出站规则，控制哪些IP可以通过哪个端口访问服务器。默认情况下所有端口关闭，必须手动添加规则才能开放。

## 正例（≥2 个）
1. 部署一个Web项目在8000端口 → 在安全组中添加规则：协议TCP、端口8000、授权对象0.0.0.0/0 → 保存后，外网就能访问 `http://公网IP:8000`。
2. 只需要自己SSH登录服务器 → 安全组只开放22端口给你的家庭IP → 其他人无法SSH连接，避免被暴力破解。

## 反例/边界（≥1 个）
1. 安全组没有开放22端口 → SSH连接永远卡在「connecting…」→ 你将无法远程登录这台服务器。就像保安把正门锁了，主人也进不去——必须先通过云控制台修改安全组规则。

## 详细解释
云服务器出厂时就像一座全封闭的堡垒，所有端口默认关闭。安全组规则就是一层一层地把需要的门打开。

**三个必开端口：**

| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | SSH | 远程登录服务器 |
| 80 | HTTP | 普通网站访问 |
| 443 | HTTPS | 加密网站访问 |

**规则要素：**
- 协议类型：TCP（常用）/ UDP / ICMP
- 端口范围：单个端口如 `8000`，或范围如 `8000-9000`
- 授权对象：`0.0.0.0/0` 表示全网开放（测试常用），也可限制为特定IP

**腾讯云 vs 阿里云的区别：**
- 阿里云：添加规则时端口直接填数字（如 `8000`）
- 腾讯云：格式为 `TCP:端口号`（如 `TCP:8000`），注意是 `TCP` 不是 `TPC`

安全组修改后即时生效，无需重启实例。
