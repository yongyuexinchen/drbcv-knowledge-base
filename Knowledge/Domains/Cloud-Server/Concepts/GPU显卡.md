# GPU显卡

## 类型判定
这是一个概念定义——解释云服务器中「GPU显卡」的两大分类（消费级 vs 计算型）、常见型号以及如何根据需求选择。

## 类比 ★
### 一句话比喻
GPU就是电脑里的「绘画大师」——CPU是总经理，什么活都能干但都不精；GPU是专门雇来画画的，手下有几千个学徒同时挥笔，一张大海报（AI模型推理）总经理要画三天，大师十分钟搞定。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| CPU | 万能总经理——什么事都能处理，但一个人效率有限 |
| GPU | 千人绘画团队——只干一件事（并行计算），但干得飞快 |
| 消费级显卡（4090） | 民间高手——画得又快又好，价格亲民 |
| 计算型显卡（V100/A100） | 国家队大师——画最复杂的工程图，价格昂贵但不出错 |
| 显存大小 | 画布能铺多大——画布不够大，大画就画不了 |
| 租GPU按小时计费 | 按小时雇大师来画画，画完就结账走人 |
| AutoDL用消费级卡 | 雇民间高手，便宜好用 |
| 阿里云/腾讯云用计算型卡 | 雇国家队，贵但稳定规范 |

## 是什么
GPU（Graphics Processing Unit，图形处理器）是一种擅长并行计算的芯片。在云服务器领域，GPU用于AI模型训练和推理、大数据分析、视频渲染等需要大量并行计算的任务。云服务器的GPU分为两类：消费级显卡（如 RTX 4090）和计算型显卡（如 V100、A100、T4）。

## 正例（≥2 个）
1. 在 AutoDL 上租一台 RTX 4090（消费级）服务器跑 AI 大模型推理，价格约1元/小时，性能出色——性价比之选。
2. 在阿里云上租一台 V100（计算型）做企业级模型训练，价格约3元/小时，稳定性极高，适合生产环境。

## 反例/边界（≥1 个）
1. 用 CPU 跑大模型推理——可以跑，但速度慢几千倍。就像让总经理一个人画清明上河图，理论上能画完，但实际等不起。AI 任务必须用 GPU。

## 详细解释
GPU 之所以适合 AI 计算，是因为它有成千上万个小型计算核心，可以同时处理大量简单的矩阵乘法——这正是深度学习（神经网络）的核心运算。

**GPU 型号速查表：**

| 型号 | 类型 | 性能 | 价格 | 推荐场景 |
|------|------|------|------|----------|
| RTX 4090 | 消费级 | ★★★★★ | ★★ | 小模型推理，学习测试（AutoDL主力） |
| RTX 3090 | 消费级 | ★★★★ | ★★ | 中模型推理 |
| RTX 3080 | 消费级 | ★★★ | ★ | 轻量推理 |
| V100 | 计算型 | ★★★★ | ★★★★ | 企业训练/推理，稳定首选 |
| A100 | 计算型 | ★★★★★ | ★★★★★ | 顶级大模型训练 |
| T4 | 计算型 | ★★★ | ★★★ | 中小模型推理 |
| A10 | 计算型 | ★★★ | ★★★ | 图形+推理混合 |

**选卡原则：**
- 学习/测试/小模型 → AutoDL + 4090/3090（便宜够用）
- 企业生产/稳定性优先 → 阿里云/腾讯云 + V100/T4
- 顶级大模型训练 → A100（仅顶级场景需要）

**AutoDL 提示「GPU不足」：** 说明该地域的卡被租完了 → 换一个地域即可。
