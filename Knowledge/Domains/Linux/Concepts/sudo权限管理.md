# sudo权限管理

## 类型判定
这是一个概念定义——解释Linux中「管理员权限」和「普通用户权限」的区分，以及 `sudo` 如何临时获取管理员身份。

## 类比 ★
### 一句话比喻
你是房子的业主（管理员），想拆墙就拆墙；你朋友来做客（普通用户），只能坐沙发看电视，想把电视卖了？必须你点头才行。`sudo` 就是你给朋友临时签的一张「授权条」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| root（管理员） | 房子的产权所有者，想干嘛干嘛 |
| 普通用户（如 ubuntu） | 来做客的朋友，只能使用不能破坏 |
| sudo 指令 | 临时授权条：「我允许他以我的名义动这件东西」 |
| sudo su | 直接把房本过户给你——你变成了业主 |
| Permission denied | 保安拦住你：「你不是业主，不能进去」 |

## 是什么
`sudo`（superuser do）是 Linux 中的权限提升命令。在需要管理员权限的操作前面加上 `sudo`，系统会临时以 root（超级管理员）身份执行该命令。普通用户默认只能操作自己的文件，`sudo` 让用户在必要时获得更高权限。

## 正例（≥2 个）
1. `apt update` 执行失败（Permission denied）→ 加上 `sudo apt update` 后成功执行，因为更新软件包需要管理员权限。
2. `sudo su` 从普通用户 `ubuntu` 直接切换为 root 用户，命令提示符从 `$` 变为 `#`。

## 反例/边界（≥1 个）
1. 不必要的操作不要加 `sudo`——比如在自己的 home 目录下创建文件、查看文件列表，普通权限足够。滥用 `sudo` 就像让朋友拿着你的房本去买菜，风险太大。

## 详细解释
Linux 是一个多用户系统，权限隔离是它的安全基石。root 用户拥有最高权限，可以修改任何文件、安装/卸载软件、创建/删除用户。普通用户只能在自己的 home 目录下活动。

`sudo` 指令的原理是：在命令前加 `sudo`，系统检查当前用户是否在 sudoers 名单中，如果在，就临时赋予 root 权限执行该命令。

在 Windows 系统中的类比操作是「右键 → 以管理员身份运行」。

`sudo su` 比 `sudo` 更进一步——它直接把当前终端会话切换为 root 身份，后续所有命令都无需再加 `sudo`，直到输入 `exit` 退出。
