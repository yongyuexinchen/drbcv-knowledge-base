# 公网IP与域名

## 类型判定
这是一个概念定义——解释「公网IP是什么」以及「域名是如何给它起名字的」。

## 类比 ★
### 一句话比喻
公网IP就是你家的经纬度坐标（北纬39.9°，东经116.4°），域名就是你家的快递地址「北京市朝阳区XX小区3号楼501」——前者机器认得准，后者人类记得住。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 公网IP（如 110.242.68.66） | 你家的精确经纬度坐标 |
| 域名（如 baidu.com） | 你填快递时的「XX省XX市XX路XX号」 |
| DNS 解析 | 快递公司把文字地址翻译成地图经纬度 |
| URL / 网址 | 完整的快递单：收件人+地址+门牌号 |
| 端口 | 大楼里具体房间的门牌号 |

## 是什么
- **公网IP**：全球唯一标识一台互联网设备的数字地址，形如 `110.242.68.66`。
- **域名**：把难记的IP数字转换成人类可读的名称（如 `baidu.com`），一个域名可对应一个或多个公网IP。
- **网址 / URL**：在域名基础上加上协议和路径，完整定位互联网上的一个资源。

## 正例（≥2 个）
1. 在浏览器输入 `www.baidu.com`，DNS 自动把域名翻译成百度的公网IP，然后连接到百度服务器。
2. 用 `ping baidu.com` 命令可以看到百度实际的公网IP地址（一串数字）。

## 反例/边界（≥1 个）
1. 直接用公网IP访问百度通常打不开——出于安全考虑，服务器会拒绝只有IP没有域名的请求。就像你只报门牌号、不报小区名，保安不让你进。

## 详细解释
互联网上每一台设备都需要一个唯一的「门牌号」才能被找到，这就是IP地址。但 IPv4 地址只有约43亿个，不够全世界每台设备分，所以有了公网IP（全球唯一）和内网IP（局域网内使用）的区分。

因为公网IP是数字串，人类记不住，于是发明了域名系统（DNS）。它就像一个全球电话簿：你查「百度」，它告诉你号码「110.242.68.66」。

一个完整的网址（URL）包含：协议（http/https）+ 域名 + 端口（可省略）+ 路径。例如 `https://www.baidu.com:443/search`。
