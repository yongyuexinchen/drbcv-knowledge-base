# AI应用开发-公司类型选择

## 是什么（What）

深圳AI应用开发岗位分布在四类公司，每类的薪资、技术栈、成长路径完全不同。**科技/创业公司是用户的"第一站最优解"** — Python + RAG + Agent 技术栈完美匹配，薪资中位22K，成长快。

这就像选餐厅工作：大厂=米其林（进得去但门槛极高），创业公司=网红餐厅（快速成长、全能锻炼），猎头外包=宴会承办（按项目来，无归属感），传统企业=单位食堂（技术栈偏老）。

## 为什么重要（Why）

- 大厂/名企（12条）：薪资中位31K，但要求 Java/Go + 系统设计能力，现阶段难进
- **科技/创业公司（41条）：薪资中位22K，Python技术栈为主，最适合第一站**
- 猎头/外包（16条）：薪资中位38K（虚高），驻场开发无产品归属感，可过渡不宜久留
- 其他企业（1条）：传统企业智能化转型，技术栈偏老

## 怎么做（How）

### 四类公司详细对比

| 类型 | 数量 | 薪资中位 | 高频技能 | 适合你吗 |
|------|------|---------|----------|---------|
| 大厂/名企 | 12条 | 31K | 大模型+Python+Go+Agent+Java | 🟡 现阶段难，1年后可冲 |
| **科技/创业** | **41条** | **22K** | 大模型+Agent+Python+RAG+Prompt | 🟢 **最适合第一站** |
| 猎头/外包 | 16条 | 38K | 大模型+深度学习+Python+LLaMA | 🟡 可过渡(3-6月) |
| 其他企业 | 1条 | 32K | Python+Java+Transformer | 🟡 除非没选择 |

### 首选科技/创业公司的理由

```
1. Python 技术栈完美匹配 — 你不需要学 Java
2. 成长快 — 小公司要求全能，3个月能接触RAG/Agent/部署全流程
3. 无大厂内卷 — 面试不考 LeetCode Hard，不要求985学历
4. 薪资够用 — 22K中位，对接下来的学习生活足够了
5. 跳板价值 — 1年创业公司经验 → 冲大厂35K+岗位
```

### 简历投递策略

```
投递优先级：
  科技/创业公司(60%精力) → 猎头/外包(20%) → 大厂(15%) → 传统企业(5%)

面试顺序（用不太想去的公司练手）：
  猎头外包(练手) → 中小创业公司(实战) → 心仪创业公司(认真面) → 大厂(冲冲看)
```
