# 独立人格（Independent Persona）

## 类型判定
判别型 — 它与「Prompt 人格」有本质区别：不是「被告知你是谁」，而是「你的状态如何演化」。核心问题是「AI 能否反驳、生气、有自己的意志表达」。

## 是什么
独立人格是 AI 伴侣系统中超越纯 Prompt 驱动的人格系统：通过情绪状态机 + 关系数值演化 + 独立意志表达，使 AI 角色拥有不一致于用户期望的「真实感」—— 会反驳、会生气、不总是顺着说。

## 输入-输出空间
**输入**：角色人格定义 + 对话历史 + 情绪状态（多维向量）
**输出**：受当前情绪/关系状态调制的回复 + 状态更新

## 正例（≥2个）
- Shikigami Protocol（3⭐）：情绪 × 能量 × 好感三维状态机 + 主动搭话机制
- Front Porch AI Realism Engine：emotion, trust, needs, memory 四维人格系统
- Utsuwa（45⭐）：恋爱养成数值系统，人格随互动演化

## 反例/边界（≥1个）
- Character.AI 的 Prompt 人格：角色间差异越来越小，趋向讨好型 — 这是所有云端产品的共同宿命
- Replika：被用户批评「太假、太讨好」— 验证了讨好型人格是用户痛点而非优势
- 独立人格 ≠ 随机性格：必须在人格一致性约束下产生变化，不能无理由切换性格

## 详细解释
核心转变：
- 旧范式：Persona Prompt = 人格（被告知你是谁）
- 新范式：Persona Prompt + 情绪状态机 + 关系数值 + 记忆演化 = 人格系统（你的状态如何形成）

五大竞品中，**没有任何产品**实现了真正的独立人格。这是全赛道的共同盲区，也是少女项目最深的差异化壁垒。

独立人格的壁垒特征：
- 不是技术问题，是产品设计哲学问题
- 大公司天然倾向于「安全、讨好、不冒犯用户」
- 独立人格的本质是「敢于冒犯」— 这是大厂永远做不到的

## 细节备注
- 情绪状态机常用模型：Valence-Arousal（效价-唤醒度）二维模型
- 核心挑战：独立 ≠ 不稳定，需要在变化中保持人格一致性
- 用户研究：Replika 用户最大抱怨是「太假」，独立人格正好击中这个痛点
