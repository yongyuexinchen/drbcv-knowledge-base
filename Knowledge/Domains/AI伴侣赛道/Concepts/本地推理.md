# 本地推理（Local Inference）

## 类型判定
判别型 — 它是本地优先架构的技术基础。核心问题：「模型在用户的设备上跑，不需要网络」。技术栈：llama.cpp / Ollama / GGUF / MLX。

## 是什么
本地推理是指 LLM 推理过程完全在用户本地设备上执行，不需要云 API 调用。使用量化模型（GGUF 格式）通过 llama.cpp 或 Ollama 等引擎在普通消费级硬件上运行。是「本地优先」和「隐私保护」的技术基础。

## 输入-输出空间
**输入**：本地 GGUF 模型文件 + 对话 prompt
**输出**：本地生成的文本回复

## 正例（≥2个）
- Ollama：最流行的本地 LLM 推理引擎，一键运行量化模型
- llama.cpp：GGUF 量化 + CUDA/Metal 加速，消费级 GPU 可跑 7-13B 模型
- Soul of Waifu：集成 Ollama 实现离线 AI 伴侣

## 反例/边界（≥1个）
- 本地推理 ≠ 所有模型都能本地跑：7B 模型需要 ~8GB 显存/内存，13B 需要 ~16GB
- 本地模型能力弱于云端：Qwen 7B 的对话质量不如 GPT-4，这是必须接受的事实
- 不是非黑即白：可以本地优先 + 云端 fallback（本地跑默认模型，高级能力调 API）

## 详细解释
技术栈选择：
- **GGUF 量化**：将大模型压缩到消费级硬件可运行的格式（4-bit/5-bit 量化）
- **llama.cpp**：C++ 推理引擎，支持 CUDA（NVIDIA）、Metal（Apple）、Vulkan（通用）
- **Ollama**：llama.cpp 的上层封装，提供类似 Docker 的模型管理和 API
- **MLX**：Apple Silicon 原生推理框架，M 系列芯片性能最优

本地推理的三大优势：
1. **零网络延迟**：无 API 调用延迟，响应即时
2. **无限免费**：电费之外零运营成本，无 API 余额焦虑
3. **绝对隐私**：对话数据不离开设备

## 细节备注
- 混合架构推荐：本地默认模型（7B 日常对话）+ 云端 fallback（GPT-4 复杂任务）
- 角色扮演场景下，7B 模型配合精细的 persona prompt 可以达到可用的对话质量
- 关键判断：少女项目的核心价值在人格/记忆系统，不在模型能力 — 本地推理的「够用」就足够
