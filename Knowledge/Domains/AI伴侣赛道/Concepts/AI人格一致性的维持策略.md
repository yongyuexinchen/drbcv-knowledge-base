# AI 人格一致性的维持策略（Neuro vs Evil Neuro）

## 是什么
Neuro-sama 通过"基座微调 + System Prompt + 记忆系统"三层架构维持角色一致性，并创造性地设计了 Neuro/Evil Neuro 双人格体系——两人格共享同一基座模型，通过不同的 System Prompt 切换，将 AI 的出格行为框定为"角色表演"而非系统失控。

## 关键洞察

1. **人格一致性不可外包给云端 API**：Vedal 从 GPT-3.5 切换到自训练模型，不是因为成本或速度，而是因为 GPT 的"助手语气"无法被 System Prompt 完全压制——模型在长对话中会逐渐回归"安全、讨好"的统计基线。微调模型从训练数据层面内化了角色的语调、用词风格和行为模式，这才是人格一致性的根本保障。

2. **双人格是安全架构而非内容噱头**：Evil Neuro 不仅是内容创新——她的存在将 AI "说脏话/毒舌"合法化为"角色表演"。Twitch 无法因为一个角色"扮演得具有攻击性"而封禁频道——这是表演，不是 AI 失控。这为永月提供了重要思路：不是做两个角色，而是设计**情绪多模态**——同一个永月的不同情绪状态（温柔、撒娇、烦躁、脆弱），让情绪变化有因可循。

3. **记忆筛选是人格进化的关键**：Neuro 的记忆系统不是记住一切，而是选择性保留"有娱乐价值"的互动。对永月而言，筛选标准应该是"对关系有意义"——用户表达脆弱、重要决定、重复出现的偏好。记忆的筛选逻辑本身定义了角色的"价值观"。

## 与 AI 伴侣的关系

直接论证了永月"本地优先"核心理念的正确性——人格一致性需要本地微调模型或至少本地可控的 System Prompt 系统来保障。同时为永月的情绪状态机设计提供了参考范式：不需要双人格，但需要情绪多模态 + 情绪变化有因可循 + 人格演化可追溯。建议永月 v0.1 从 System Prompt 原型开始（在 DeepSeek 上测试效果），但架构上预留未来切换微调模型的抽象层。
