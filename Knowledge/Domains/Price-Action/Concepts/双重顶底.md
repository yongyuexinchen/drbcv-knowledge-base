# 双重顶底（Double Top / Double Bottom）

## 类型判定
判别 — 定义了价格两次测试相近极值后反转的结构形态，是 MTR"极点测试失败"环节最常见的实现形式，仅诊断、不下单

## 类比 ★
### 一句话比喻
**双重顶底 = 跳高运动员两次尝试同一个高度都失败了**——第一次冲到横杆前起跳，差一点点（第一次触顶）。退回来助跑，再冲一次（回撤+第二次测试），又失败了。裁判判定：这个高度过不去，比赛结束（反转）。如果你在第一次失败后就赌"他第二次一定跳不过去"，那是预判；等他两次都跳完了裁判吹哨，那才是确认。交易中也是一样：双顶底提供反转证据，但不能在第二次测试还没完成前就开反向单。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 双顶（Double Top）| 跳高两次失败——同一高度撞了两次，这个高度确实过不去 |
| 颈线（Neckline）| 横杆下方的基准线——跌破这条线才确认运动员不是"暂时失误"而是"真的不行了" |
| 微型双顶底（MDB/MDT）| 热身试跳失败——小级别的两次试探，信号不如正式比赛的大双顶可靠 |
> 双重顶底是反转证据，不是反转命令。双顶 + 趋势线突破 + 趋势恢复失败 + 极点测试失败 = MTR 四组件齐全。仅有双顶不等于 MTR。

## 是什么
双顶（Double Top）是价格两次测试相近高点后反转向下，双底（Double Bottom）是两次测试相近低点后反转向上。微型版本（MDB/MDT）是即时窗口内的两棒级别小双重。双重顶底是 MTR"极点测试失败"组件最常见的实现形式，意味着原有趋势力量衰竭。但 PA Agent 仅将其作为诊断标签（double_top_bottom/reversal_attempt），禁止因双顶底产出逆势三价——必须等 MTR 四组件齐全才能确认反转，且即使确认也仅诊断不下单。

## 正例（≥2 个）
1. **双顶反转诊断**：上涨趋势中价格冲到 100（第一次高点），回撤至 95，再冲到 99.8（第二次高点，未创新高）→double_top_bottom + reversal_attempt。若同时趋势线被突破+无新高→可升级为 mtr 标签，仍仅诊断。
2. **区间下边界双底+MDB**：交易区间下边界附近，K2 和 K1 形成微双底（两棒低点差距 <2 跳，K1 收阳线）→MDB 做多信号。但须 direction=bullish/AIL 才评估三价，且须 §10.3 通过。

## 反例/边界（≥1 个）
1. **铁丝网中看到"假双顶"就判反转**：铁丝网中的小波动经常形成看起来像双顶的结构，实际只是噪音重叠。铁丝网规则覆盖→不下单。环境判断必须先于形态判断。

## 详细解释

### 有效 vs 无效双顶底

| 有效 | 无效 |
|------|------|
| 两次极点价位接近（允许小幅刺破但收盘不确认） | 第二次大幅创新高/新低（只是趋势延续） |
| 第二次测试后出现反向趋势棒 | 铁丝网/区间中部的小波动 |
| 中间有清晰回撤（颈线可识别） | 仅单根长上影，无第二次结构化测试 |

### 识别与监测流程

| 次序 | 行为 | PA Agent |
|------|------|---------|
| 第一次触顶/底 | 正常回撤可能 | 不追、不下单 |
| 第二次触顶/底失败 | 确认极点 | 诊断 reversal_attempt/double_top_bottom |
| 突破颈线后回撤 | Brooks 二次入场 | watch_points 监测；禁止逆势三价 |

### 与 MTR 的关系

双顶底是 MTR 组件 4（极点测试失败）的最常见形式。仅有双顶底但无组件 2（趋势线突破）和组件 3（趋势恢复失败）→仅 reversal_attempt，不能标 mtr。四组件齐全→mtr，仍禁止下单。

### MDB/MDT 方向门控

- MDB 做多：仅 direction=bullish/AIL 时可评估三价
- MDT 做空：仅 direction=bearish/AIS 时可评估三价
- 逆势 MDB/MDT → 仅诊断，禁止三价
