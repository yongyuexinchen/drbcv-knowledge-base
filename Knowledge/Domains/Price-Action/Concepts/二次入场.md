# 二次入场（Second Entry）

## 类型判定
程序 — 定义了何时应跳过第一次信号等待第二次确认的决策规则，覆盖楔形、MTR、双重顶底、区间边界、趋势线突破五类场景的二次入场条件与 PA Agent "顺势可评估、逆势仅诊断"的硬约束

## 类比 ★
### 一句话比喻
**二次入场 = 过马路时的"先看左再看右"**——第一辆车过去了（第一次信号），你不能立刻冲出去，因为可能有第二辆车紧跟在后面（第一次反转尝试多数失败）。你得等第一辆车完全过去、确认视野清晰（信号确认）、再左右看一遍（二次入场确认），然后才迈步。虽然多等了几秒，但保住了命。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 第一次反转尝试（多数失败） | 马路上第一辆车——看起来很像是空隙，但往往后面紧跟着第二辆，冲出去就被撞 |
| High 2 / Low 2 二次确认 | 确认双向都无来车——第二次测试告诉你第一波动能已被消化，现在是真的空隙 |
| 60/40 规则 | 走路 vs 被撞的概率——60% 的交易小盈小亏相互抵消，20–30% 大盈利靠趋势，10–20% 大亏损来自假信号，二次入场减少"小亏损"的数量 |
> 二次入场的哲学：市场总是先骗你一次——第一次突破、第一次反转、第一次测试大多是陷阱。真正的交易机会在第二次。

## 是什么
二次入场是一套系统性的入场时机选择方法论，核心原则是：第一次反转/突破/测试尝试多数失败，第二次信号通常更可靠。这不是"等两根 K 线"的机械规则，而是一个基于价格结构确认的决策框架——二次入场必须在第一次信号后的合理时间内出现（< 2 小时），且回撤不能破坏原结构。PA Agent 的硬约束：顺势二次入场（H2/L2、通道回撤、突破回踩）可评估三价；逆势二次入场（楔形反转、MTR、双重顶底反手）仅诊断不下单。

## 正例（≥2 个）
1. **上涨通道中 High 1 信号偏弱、等 High 2**：K3 是第一次回调信号棒（quality=weak），不做；K8 再次回调到均线附近形成 High 2（quality=strong），顺势做多入场
2. **区间下边界第一次触及反弹后再次回踩**：direction=bullish，价格第一次触及下边界→反弹→第二次再触及下边界形成 High 2，可评估做多。第二次触及确认了边界的支撑有效性
3. **趋势线被第一次突破后迅速回到线内，再次突破**：第一次突破失败（窄通道中经典陷阱）→ 价格回到通道内 → 再次突破趋势线（二次入场），此时顺势入场胜率更高

## 反例/边界（≥1 个）
1. **最常见误解：以为所有交易都要等二次入场**——不是。强信号棒 + 关键位置 + 顺 direction 时，第一次入场（H1/L1）完全可以评估。但必须逐条说明为何无需等 H2/L2。
2. **逆势二次入场 ≠ 可以逆势下单**——楔形反转、MTR 四组件、双重顶底等逆势场景，即使出现完美的"二次入场"信号，PA Agent 也禁止产出逆势三价，仅诊断 + watch_points。
3. **二次入场等待过久**：超过 2 小时（24 根 5 分钟 K 线）未出现二次入场 → 信号已失效，放弃该交易思路。
4. **三推/末端楔形后的"第三次入场"**：第三次尝试（High 3/Low 3）不是二次入场，禁止追顺势、禁止逆势反手。

## 详细解释
### 60/40 规则（Al Brooks 核心洞察）
60% 的交易小盈亏相互抵消，20–30% 产生大利润（趋势交易），10–20% 产生大亏损（止损被触发后市场反转）。二次入场通过提高确认度减少"小亏损"的数量，从而改善整体盈亏比。

### 五类场景的二次入场条件
1. **楔形回撤**：楔形突破后的回踩（顺主趋势架构）→ 可评估顺势入场
2. **MTR**：四组件齐全 → 仅诊断，不下单
3. **双重顶/底**：第二次极点测试失败 → 仅诊断，禁止逆势三价
4. **区间边界**：第二次触及 + direction 同侧 → 可评估顺势入场
5. **趋势线突破**：第一次突破失败→回撤→再次突破 → 顺势入场

### PA Agent 决策流
第一次信号出现 → 评估信号强度 → 弱信号/逆势/关键位置不清晰 → 等二次入场 → 二次入场确认（方向与 direction 一致）→ §9/§10.3 三价。逆势二次入场 → 仅诊断 + watch_points。
