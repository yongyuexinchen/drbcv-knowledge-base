# 楔形形态（Wedge Pattern）

## 类型判定
判别 — 定义了楔形/三推形态的识别标准、楔形回撤 vs 楔形反转的关键区分，以及 PA Agent 的硬约束：末端楔形仅诊断禁止下单、楔形回撤可评估顺势入场

## 类比 ★
### 一句话比喻
**楔形 = 弹簧越压越紧，最终一定会弹开**——三推就像你三次用力压弹簧：第一次压到底（第一推），弹簧反弹一点你又压第二次（第二推，幅度比第一次小），再压第三次（第三推，幅度更小，弹簧几乎压不动了）。这时候弹簧蓄满了能量，一旦你松手（突破确认），它就会朝反方向弹开。但你不能在还没松手时就赌它会弹向哪边——必须等它真正弹开并确认方向。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 三推动能递减 | 压弹簧越来越费力——每推幅度递减，说明原方向势能耗尽，反向势能积累 |
| 楔形回撤（顺主趋势） | 弹簧在回弹途中的小振动——趋势中的短暂回调，弹完后继续原方向 |
| 楔形反转（逆主趋势） | 弹簧被压到极限后的反向弹开——趋势末端的动能衰竭，可能反转 |
> 楔形的核心陷阱：形态名字不自动等于交易方向。上升楔形不自动做空，下降楔形不自动做多——必须先判断是回撤还是反转。

## 是什么
楔形是三推（Three Pushes）形态：价格三次向同一方向推进，每次推进的幅度递减，趋势线和通道线逐渐收敛。本质是方向性动能在三次推进中逐步衰减。楔形分为两个核心子类：楔形回撤（与主趋势相反、通常 < 20 棒、顺势架构→突破后可顺势入场）；楔形反转（与主趋势同向、≥ 20 棒、逆势架构→仅诊断禁止下单）。抛物线楔形是加速变异形式（加速而非收敛），等于高潮信号。

## 正例（≥2 个）
1. **上涨趋势中出现下降楔形回撤、10–15 棒、三推递减、楔形在 EMA 附近**：→ 楔形回撤，向上突破且与 direction=bullish 一致 → 可评估顺势做多（§9/§10.3），目标为楔形起点
2. **上涨趋势末端出现上升楔形、≥ 20 棒、三推收敛明显、与主趋势同向**：→ 楔形反转/末端三推，仅诊断 `wedge`+`reversal_attempt`，`order_type=不下单`，禁止追顺势、禁止逆势做空三价
3. **下跌趋势中出现微楔形（3–4 棒）、在前低附近**：→ 微楔形不单独作为入场依据，结合支撑位 + §9 信号棒质量后才评估

## 反例/边界（≥1 个）
1. **最常见错误：形态名字当交易指令**——"上升楔形 = 做空"、"下降楔形 = 做多"。约 35–40% 的楔形朝原趋势方向突破。PA Agent 禁止逆势三价，末端楔形不下单。
2. **假三推**：不是所有三次推进都是楔形，必须有收敛特征（趋势线和通道线逐渐靠拢）。没有收敛的三推可能是假楔形。
3. **过早数推**：第二推还没完成就假设会有第三推——必须三推全部完成。
4. **抛物线楔形中追原方向**：价格加速创新高/低时不要追单——那可能不是趋势延续而是买入/卖出高潮。

## 详细解释
### 楔形回撤 vs 楔形反转（关键区分）
| 特征 | 楔形回撤 | 楔形反转 |
|------|---------|---------|
| K 线数量 | 10–20 棒 | ≥ 20 棒 |
| 架构性质 | 顺势架构（与趋势相反） | 逆势架构（与趋势同向） |
| 突破后 | 回到原趋势方向 | 可能反转 |
| PA Agent | 可评估顺势入场 | 仅诊断，不下单 |

### 特殊变体
- **抛物线楔形**：加速而非收敛，= 买入/卖出高潮。禁止追原方向、禁止逆势反手。
- **微楔形**：3–4 棒迷你楔形，不单独作为入场依据。
- **嵌套楔形**：第三推本身是更小楔形，动能衰竭更强。
- **High 3/Low 3**：第三次同向计数呈三推递减 → 按楔形处理，禁止当 H2/L2 追顺势。
