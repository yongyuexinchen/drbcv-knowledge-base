# Hermes 任务使用规范

这份规范用于降低 token 消耗，并让本地知识库任务更稳定。

## 总原则

1. 大任务先开新会话：建库、批量读文件、多 Agent、长课程处理都先 `/new`。
2. 先预算，再执行：先让 Hermes 统计文件、估算字数、预计轮次和风险。
3. 先样例，再批量：先做 3-5 张样卡，确认风格和深度后再全量生成。
4. 只传路径，不贴全文：大文件、日志、PDF、JSON、网页快照都写文件，让 Hermes 返回摘要和路径。
5. 工具输出要短：要求 Hermes 不把完整文件内容、完整 JSON、完整命令输出贴回聊天。
6. 子 Agent 只交付文件：主会话只接收产物路径、数量、失败项，不接收全文。
7. 技能维护单独做：不要在同一轮里一边建库一边改技能。
8. 验证用脚本：占位符、frontmatter、wikilink、双向链接、重复文件都优先用脚本查。

## 任务分级

| 等级 | 适用情况 | 推荐做法 |
| --- | --- | --- |
| 小任务 | 1-3 篇短文，少于 5k 字 | 可直接让主 Agent 提取和写卡 |
| 中任务 | 1 篇长文或 4-10 个文件 | 先做清单和样卡，再批量 |
| 大任务 | 10+ 文件、课程、书籍、20+ 张卡 | `/new`，预算确认，分阶段，必要时子 Agent |

## 推荐固定流程

### 1. 预算阶段

复制这段给 Hermes：

```text
/new
我要处理：<文件夹或文件路径>

先不要全量执行。第一步只做：
1. 统计文件数、总大小、估算字数
2. 检查重复文件
3. 抽样 2 篇判断内容结构
4. 估算需要多少轮、是否需要子 Agent、预计 token 风险
5. 输出一个执行方案

工具输出不要贴全文，只返回摘要和产物路径。
等我确认后再继续。
```

### 2. 样卡阶段

```text
按刚才方案，只生成 3-5 张样卡。
要求覆盖不同类型：定义型、方法型、关系型、难点型。
不要全量生成。
生成后运行占位符/frontmatter/wikilink 检查。
只告诉我样卡路径、检查结果和你建议调整的地方。
```

### 3. 全量阶段

```text
样卡风格确认。现在开始全量生成。
要求：
1. 大中间产物写入 temp/
2. 不要把完整 JSON 或完整卡片贴回聊天
3. 每阶段完成后只汇总：新增数、更新数、失败数、产物路径
4. 如果发现缺资料，不要写“待补充”，写入失败报告
5. 全量完成后运行 reviewer_check.py 或等价脚本
```

### 4. 修复阶段

```text
只修复检查失败项。
先读取 review-report，不要重新扫描全部源文。
每次最多修复 10 张卡。
修复后重新运行检查，输出失败项清单即可。
```

## 禁用话术

这些说法容易触发高成本行为：

| 不建议说 | 改成 |
| --- | --- |
| 全要 | 先做样例，列预算，等我确认 |
| 你推吧 | 给我执行计划和成本风险 |
| 直接开始 | 先统计和抽样，不要全量 |
| 把所有文件都读一遍 | 先建文件清单和去重报告 |
| 看看之前聊天 | 只搜索相关关键词，返回摘要 |
| 自动多 Agent | 说明为什么需要子 Agent，以及每个子 Agent 的输出文件 |
| 把这个写进技能 | 先记录到待更新清单，任务结束后统一改技能 |

## 多 Agent 规则

只有满足以下任一条件才使用多 Agent：

- 源文件超过 10 个。
- 源文本超过 20k 字。
- 预计概念卡超过 20 张。
- 用户明确接受高成本批量处理。

多 Agent 必须遵守：

- 每个 Agent 只处理自己的文件或 chunk。
- 输出写到 `temp/*.json` 或 `temp/*.md`。
- 不把完整输出回灌主聊天。
- 主 Agent 只合并、抽查、验证。

## 文件读取规则

读取大文件前先做：

```text
先显示文件名、大小、估算字数。
不要读取全文。
如果需要读取，只读取相关章节或前 200 行做判断。
```

日志排查时使用：

```text
只搜索错误关键词和最近 200 行。
不要 cat 全量日志。
```

JSON 检查时使用：

```text
不要把 JSON 打印到聊天。
用脚本统计 concepts 数、relationships 数、缺字段数、孤立关系数。
结果写入 temp/report.json。
```

## 知识库质量门槛

一张卡至少满足：

- frontmatter 有 `name`、`type`、`status`、`source` 或 `sources`。
- 正文没有“待补充”“待爆破”“TODO”“???”。
- 至少有 1 个有效 `[[wikilink]]`。
- 方法/数学卡必须有步骤、适用条件、例题或类比。
- 不允许出现工具 JSON、内部思考文本、命令输出残留。

## 成本止损线

出现以下情况要暂停：

- 单轮工具输出超过 20k 字符。
- 同一个工具连续失败 2 次。
- 子 Agent 返回大段全文。
- 发现重复源文件超过 20%。
- 样卡不满意但已经准备全量生成。
- 当前会话已经很长，还想继续新建库。

暂停后先问：

```text
当前任务可能继续放大成本。
请先给我：已完成产物、失败项、下一步最小修复方案。
不要继续全量执行。
```

## 安全提醒

不要把 API Key、账单明细、私密聊天整段贴进任务上下文。需要排查时只给文件路径，让 Hermes 用脚本提取必要字段，并避免在回复中复述密钥。
