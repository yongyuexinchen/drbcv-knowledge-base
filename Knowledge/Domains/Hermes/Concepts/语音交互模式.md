# 语音交互模式

## 类型判定
Hermes Agent 的语音输入输出能力——用户用麦克风说话控制 Agent，Agent 用合成语音读出回复，实现免打字的人机对话。

## 类比 ★
### 一句话比喻
就像给 Siri 换了个超级大脑——你不用打字，直接对着电脑喊"帮我查一下今天大模型有什么新闻"，它听完后用自然语音回答你，还一边说一边在后台默默执行搜索和总结。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 语音转文字（STT / Whisper） | 耳朵（听你说话→转成文字） |
| 文本转语音（TTS / Edge TTS） | 嘴巴（把文字读出来） |
| `voice on` / `voice off` | 打开/关闭免提对讲 |
| `voice tts` | 打开语音回复（否则只打字） |
| Ctrl+B 按住说话 | 按下对讲机按钮 |
| 本地 Whisper 模型 | 内置翻译官（离线工作） |

## 是什么
语音交互模式是 Hermes Agent 的多模态交互能力。通过 `/voice on` 开启语音输入（用户按住 Ctrl+B 说话，本地 Whisper 模型将语音转为文字），通过 `/voice tts` 开启语音输出（Edge TTS 将 Agent 的文字回复合成为语音朗读）。语音模式依赖两个核心组件：**STT（语音转文字）**——默认使用本地 Fast Whisper 模型（约 300-400MB），首次使用需下载；**TTS（文字转语音）**——默认使用微软 Edge TTS，免费无需 API Key。也可配置付费在线 TTS 服务改善音质。

## 正例（≥2 个）
1. **基础语音对话**：`/voice on` → 按住 Ctrl+B 说"你叫什么名字？"→ Whisper 转录为文字 → LLM 回复"我叫 Hermes"→ 文字显示在终端。
2. **语音回答模式**：`/voice on` + `/voice tts` → 问"什么是大模型？"→ Hermes 用语音完整读出回答："大模型通俗来说就是参数规模非常庞大的深度学习网络……"
3. **语音状态检查**：`/voice status` → 查看当前语音模式状态（on/off、TTS 是否开启）。

## 反例/边界（≥1 个）
1. **首次使用下载慢**：首次使用 Whisper 模型需下载 300-400MB → 如果网络慢或开启了科学上网（国内镜像不兼容），下载会失败。必须关闭科学上网工具后重试。
2. **TTS 音质限制**：Edge TTS 免费但音质一般，朗读长文本时需等完整读完才能继续对话（TTS 是转译生成的 MP3 文件播放，不是实时流式合成）。

## 详细解释
语音模式配置步骤：
1. **安装系统依赖**：Ubuntu 执行 `sudo apt install portaudio19-dev python3-pyaudio`；macOS 用 brew 安装
2. **安装 Python 依赖**：进入 Hermes 的 Python 虚拟环境目录 → `uv pip install pyaudio openai-whisper edge-tts` 等
3. **关闭科学上网**：下载 Whisper 模型时必须关闭，否则国内镜像不可用
4. **麦克风设置**：虚拟机中确保声卡检测到麦克风设备，选择"使用默认主机声卡"

语音命令汇总：
- `/voice on` — 开启语音输入
- `/voice off` — 关闭语音输入
- `/voice tts` — 开启语音回复
- `/voice status` — 查看语音模式状态
- Ctrl+B — 按住开始/停止录音（录音时有提示音）

语音转文字流程：用户说话 → 本地 Whisper 模型转录（首次下载 300-400MB 模型）→ 文本传给 LLM
文字转语音流程：LLM 生成文本 → Edge TTS 合成 MP3 → 本地播放

Windows 支持：Hermes 完全支持在 Windows PowerShell 中运行和配置语音模式。
