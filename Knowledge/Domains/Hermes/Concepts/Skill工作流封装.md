# Skill工作流封装

## 类型判定
将多步骤操作流程（调用工具、执行代码、读写文件）封装为一个可复用、可分享的 Skill 包，使 Agent 像调用快捷键一样执行复杂任务。

## 类比 ★
### 一句话比喻
就像把"打开咖啡机→磨豆→萃取→打奶泡→拉花"这一套做拿铁的流程写成操作手册，下次你说"来杯拿铁"咖啡师直接翻到那一页照着做，不用你每次都从头教一遍。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Skill 封装 | 把操作流程写成 SOP 手册 |
| SKILL.md 文件 | 手册中某一页的详细步骤 |
| Skill 目录结构 | 手册按章节分类（开发类、新闻类） |
| ClawdHub | 开源 SOP 共享平台 |
| 调用工具（Tool） | 手册中说"此时使用咖啡机" |
| 外部脚本 | 手册附录中的配方表 |

## 是什么
Skill 工作流封装是将一组有序操作（调用工具、执行代码、读写文件等）打包为一个可复用的技能模块。Skill 的核心文件是 SKILL.md，描述该技能的名称、用途、触发条件和分步执行逻辑。一个 Skill 可以调用零个或多个工具（搜索、邮件、消息通知等），也可以完全不调用工具而按描述的逻辑顺序执行。Skill 同时是跨 Agent 通用的——在 Hermes、Claude Code、OpenCode 或自研 Agent 中均可使用。

## 正例（≥2 个）
1. **科技新闻简报 Skill**：步骤①搜索指定关键字的 24 小时科技新闻 → ②访问受限时跳过付费墙 → ③合成 Markdown 简报 → ④保存到 desktop 目录。整个流程封装为一个 tech-news Skill，用户只需说"斜杠tech-news 大模型"。
2. **百度热搜监控 Skill**：从 ClawdHub 下载的第三方 Skill → 包含 Python 采集脚本 + SQLite 数据库初始化 → 支持"采集50条热搜""查询AI热度""初始化数据库"等命令 → 解压到 skill/ 目录即用。
3. **多工具协同 Skill**：步骤①搜索网络获取信息（搜索 Tool）→ ②对信息做总结分析（LLM 推理）→ ③将结果发邮件通知（邮件 Tool）——三个工具在一个 Skill 中串行执行。

## 反例/边界（≥1 个）
1. **单次工具调用**：只说"帮我查天气"→ Agent 直接调用搜索工具→ 返回结果。这不需要封装为 Skill，因为没有多步骤流程。
2. **Skill 描述不清晰**：如果 SKILL.md 中步骤描述模糊，Agent 可能误解意图或调用错误工具，导致流程失败。

## 详细解释
Skill 的创建和使用方式：
1. **手写 SKILL.md**：在 `~/.hermes/skill/类别/技能名/` 下创建 SKILL.md，写清楚 YAML 元数据和步骤
2. **从 ClawdHub 下载**：访问 ClawdHub 网站搜索所需 Skill → 下载 ZIP → 解压到对应 skill/ 目录 → 重启 Hermes 即可使用
3. **AI 辅助生成**：让 AI 帮你写 SKILL.md，但需要人工检查测试

使用第三方 Skill 的安全注意事项：
- 检查 SKILL.md 和脚本中是否有文件泄露风险
- 让 AI 审查代码是否有恶意操作
- 不需要 API Key 的 Skill 更安全（无需额外凭证）

Skill 在 Hermes 中的调用方式：
- `斜杠+技能名`：如 `/tech-news` 直接触发
- 自然语言触发：描述匹配到 Skill 的元数据描述时自动调用
