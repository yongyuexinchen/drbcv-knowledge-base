# 消息平台网关集成

## 类型判定
通过 Gateway 网关将 Hermes Agent 连接到 QQ、微信、钉钉、飞书等外部消息平台，使用户能在手机端远程操控电脑的能力。

## 类比 ★
### 一句话比喻
就像给你的电脑装了一个远程对讲机——你在外面用手机 QQ 发条消息"帮我把桌面文件整理一下"，家里的电脑就自动动起来了，做完还会用语音回复你"搞定啦"。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Hermes Gateway | 家里的对讲机基站 |
| QQ/微信机器人 | 你手机上的对讲机 APP |
| 扫码登录 | 配对对讲机频道 |
| 消息平台集成 | 对讲机接入家庭控制系统 |
| Voice TTS 回复 | 对讲机语音播放 |
| 长连接轮询 | 信号持续在线 |

## 是什么
消息平台网关集成是 Hermes Agent 的外部通信能力。通过 `hermes gateway setup` 命令配置 Gateway 网关，将 Hermes 连接到 QQ、微信、企业微信、钉钉、飞书、Telegram、Discord、Slack、WhatsApp 等消息平台。配置完成后，用户可在手机端通过聊天消息远程操控电脑——发文字或语音指令，Hermes 在电脑上执行操作（读写文件、运行命令、搜索信息），并通过文字或 TTS 语音回复结果。底层通信基于 HTTP 长连接轮询，不需要公网 IP 或反向代理。

## 正例（≥2 个）
1. **QQ 远程控制**：`hermes gateway setup` → 选择 QQ → 扫码登录 → 手机 QQ 发消息"检查系统版本"→ Hermes 返回"Ubuntu 22.04"→ 发语音"把版本信息写到桌面文件"→ Hermes 执行并语音回复"已写好"。
2. **微信远程控制**：`hermes gateway setup` → 选择微信 → 扫码 → 手机微信发"读取桌面故事.txt"→ Hermes 返回文件内容 → 发"删除桌面的系统版本文件"→ 允许后执行删除。
3. **语音模式远程对话**：手机 QQ 发语音消息 → Hermes 接收后转录为文字 → LLM 处理 → TTS 语音回复 → 手机听到语音回答。

## 反例/边界（≥1 个）
1. **Gateway 未启动**：没有运行 `hermes gateway start` → 外部消息平台无法连接 → 手机消息发不进来。Gateway 服务是消息平台集成的必需前提。
2. **群聊中使用**：将机器人放入群聊可能导致微信封号——建议仅用于一对一私聊。
3. **微信/飞书语音**：当前对微信和飞书的语音支持不如 QQ 好，语音会转译为音频文件而非原生聊天语音。

## 详细解释
Gateway 配置流程：
1. **安装依赖**：进入 Hermes Python 虚拟环境，`uv pip install aiohttp` 等
2. **注册机器人**：在 QQ 开放平台（q.qq.com）创建机器人
3. **配置 Gateway**：`hermes gateway setup` → 选择平台（QQ/微信/钉钉/飞书）→ 扫码登录 → 全部默认配置 → 确认重启
4. **使用**：Gateway online 后，手机端发送消息即可操控电脑

支持的消息平台：
- 国内：QQ、微信、企业微信、钉钉、飞书
- 国外：Telegram、Discord、Slack、WhatsApp

Gateway 相关命令：
- `hermes gateway start` — 启动网关服务
- `hermes gateway restart` — 重启网关
- `hermes gateway status` — 查看网关状态

语音控制：手机端发语音消息 → Hermes 自动语音转文字（STT）→ 处理后可通过 `/voice tts` 开启语音回复。

注意事项：Gateway 可能因虚拟机性能问题出现卡顿或启动慢——重启 Gateway 通常能解决。
