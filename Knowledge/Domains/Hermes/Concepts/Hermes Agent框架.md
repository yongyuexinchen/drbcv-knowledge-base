# Hermes Agent框架

## 类型判定
一个开源的 AI Agent 运行时框架，让大语言模型能操作本地文件系统、调用工具、执行代码和集成消息平台来完成任务。

## 类比 ★
### 一句话比喻
就像给 ChatGPT 装上手脚——它不仅会聊天，还能帮你翻电脑里的文件、上网查资料、发邮件、写代码并运行，甚至把你的常用操作打包成快捷方式下次一键调用。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Hermes Agent | 一个配备齐全的数字管家 |

| 消息平台集成 | 管家可以通过微信/QQ 远程接单 |

## 是什么
Hermes Agent 是一个 AI Agent 框架，类似 OpenCode 或 Claude Code。它运行在终端中，能操作本机文件系统、浏览器、执行代码、调用外部工具。相比同类产品，Hermes Agent 有三大核心优势：① Token 消耗显著更低（得益于优秀的上下文管理机制）；② 自动将重复对话模式封装为 Skill，避免每次重新描述；③ 支持 200+ 模型厂商且支持消息平台集成（微信、QQ、钉钉、飞书、Telegram、Discord 等）。

## 正例（≥2 个）
1. **文件操作**：用户说"把桌面上的报告总结一下"→ Hermes 读取文件 → LLM 分析总结 → 写回桌面。
2. **多步骤自动化**：用户说"搜索过去 24 小时大模型科技新闻，总结后发邮件给我"→ Hermes 搜索 → 总结 → 调用邮件工具发送。
3. **Skill 复用**：用户第一次让 Hermes 做"搜索+总结+发邮件"，第二次只需说同样的命令，Hermes 自动复用缓存的 Skill 流程。

## 反例/边界（≥1 个）
1. 纯聊天机器人（ChatGPT 网页版）：只能问答不能操作本地系统，不能执行代码，不能集成消息平台。Hermes Agent 是"行动型"框架，不是"对话型"界面。
2. Claude Code：功能类似但 Token 消耗更高，且不支持 QQ/微信等国内消息平台集成。

## 详细解释
Hermes Agent 的核心定位：
- **终端优先**：默认在终端中运行，可配置 Web UI
- **多模型支持**：200+ 模型厂商，相比 OpenCode 模型生态更丰富
- **Token 节省**：实测比 OpenCode 节省显著 Token，适合长期运行
- **Skill 自动缓存**：对话中自动识别重复模式并封装——不是每次都重新加载完整上下文
- **跨平台部署**：Windows、macOS、Linux、服务器均可
- **消息平台集成**：微信、QQ、钉钉、飞书、Telegram、Discord、Slack、WhatsApp——你在手机上发消息就能控制电脑

与 OpenCode 的关系：Hermes Agent 可以看作是 OpenCode + Claude Code 的结合体——既有对话式任务执行能力，又有代码编写能力，且内置 Claude Code 插件。
