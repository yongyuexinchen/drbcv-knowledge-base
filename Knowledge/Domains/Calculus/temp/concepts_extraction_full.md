## 1. 原函数

### 定义
设函数 f(x) 定义在某区间 I 上, 若存在可导函数 F(x), 使得在该区间内每一点都有
$$F'(x) = f(x)$$
则称 F(x) 是 f(x) 在该区间上的一个**原函数**(Antiderivative / Primitive Function).

### 公式
$$F'(x) = f(x) \implies F(x) 	ext{ 是 } f(x) 	ext{ 的一个原函数}$$

同一函数的任意两个原函数之差为常数:
$$G'(x) = f(x),\ F'(x) = f(x) \implies G(x) - F(x) = C$$

### 推导过程
**原函数的唯一性(相差常数)推导**:
设 G(x) 和 F(x) 都是 f(x) 在区间 I 上的原函数, 即 G'(x) = f(x), F'(x) = f(x).
作差: G'(x) - F'(x) = f(x) - f(x) = 0
由求导运算性质: [G(x) - F(x)]' = 0
导数恒为零的函数只能是常数, 故: G(x) - F(x) = C

关键逻辑: 导数做差 -> 差的导数为零 -> 差函数为常数 -> 两原函数只相差一个常数.

### 例题

**例题1**: 验证 F(x) = x^2 是 f(x) = 2x 的原函数
**解**: F'(x) = (x^2)' = 2x = f(x), 故 x^2 是 2x 的一个原函数. 所有原函数为 x^2 + C.

**例题2**: 求 f(x) = 1/x 的原函数
**解**: 当 x > 0 时, (ln x)' = 1/x, 原函数为 ln x + C. 当 x < 0 时, (ln(-x))' = 1/x, 原函数为 ln(-x) + C. 合并: 1/x 的全体原函数为 ln|x| + C.

### 类比
- 物理映射: 原函数 F(x) 对应路程函数 S(t), 导函数 f(x) 对应速度函数 v(t)
- 生活类比: 一哥给五套房子收租, 收多少租金很清楚(正运算=求导); 但指着一袋钞票问"这是从哪几套房子收来的",就得想一想(逆运算=求原函数)
