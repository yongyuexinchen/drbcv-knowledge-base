# 万能代换（半角代换）(Universal / Weierstrass Substitution)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
令 $u = \tan\frac{x}{2}$，则 $\sin x = \frac{2u}{1+u^2}$，$\cos x = \frac{1-u^2}{1+u^2}$，$dx = \frac{2}{1+u^2}\,du$。将任何 $R(\sin x, \cos x)$ 的积分转化为有理函数的积分。

## 输入-输出空间
- **输入**: 三角函数有理式 $R(\sin x, \cos x)$
- **输出**: 换元后的有理函数积分形式
- **映射关系**: $x \mapsto u=\tan\frac{x}{2}$

## 正例（至少2个）
1. **场景1**: $\int \frac{dx}{1+\sin x+\cos x} \xrightarrow{u=\tan\frac{x}{2}} \int \frac{du}{u+1} = \ln|u+1| + C$
2. **场景2**: $\int \frac{dx}{\sin x+\cos x+2}$ 用万能代换化为有理函数积分

## 反例/边界（至少1个）
1. **常见误解/边界**: 万能代换是通法但未必最优——对于 $\sin$ 奇次、$\cos$ 奇次等有规律的情形，凑微分法更快捷。例如 $\int\cos^3 x\,dx$ 用万能代换会很繁琐，而凑 $d\sin x$ 一步就解决。万能代换最适合 $\sin x$ 和 $\cos x$ 都只有一次的情形。

## 详细解释
万能代换特别适用于 $\sin x$ 和 $\cos x$ 只有一次的情形。虽然不一定是最简方法，但保证可积。三个公式中分母都是 $1+u^2$。

### 推导过程（★ 数学卡必须）
**三个公式的推导**：

令 $u=\tan\frac{x}{2}$：

**(1) $\sin x$**：
$$\sin x = 2\sin\frac{x}{2}\cos\frac{x}{2} = \frac{2\tan\frac{x}{2}\cos^2\frac{x}{2}}{\cos^2\frac{x}{2}+\sin^2\frac{x}{2}} = \frac{2u}{1+u^2}$$

**(2) $\cos x$**：
$$\cos x = \cos^2\frac{x}{2}-\sin^2\frac{x}{2} = \frac{\cos^2\frac{x}{2}-\sin^2\frac{x}{2}}{\cos^2\frac{x}{2}+\sin^2\frac{x}{2}} = \frac{1-u^2}{1+u^2}$$

**(3) $dx$**：
$$dx = \frac{2}{1+u^2}\,du$$（因为 $du = d\tan\frac{x}{2} = \sec^2\frac{x}{2}\cdot\frac{1}{2}\,dx = \frac{1+u^2}{2}\,dx$）

**记忆口诀**：分母全是 $1+u^2$，分子分别是 $2u$、$1-u^2$、$2$。

### 重要推论（★ 数学卡必须）
1. 万能代换可将任何 $R(\sin x,\cos x)$ 化为有理函数积分，**保证可积**。
2. 最适合 $\sin x$、$\cos x$ 均为一次的情形——次数越低越好用。
3. 代换时"凌空换元"——不需要积分中出现 $\tan\frac{x}{2}$，直接令 $u=\tan\frac{x}{2}$ 开始。
4. 做完代换后约分 $1+u^2$，往往极大简化式子。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int\frac{dx}{1+\sin x+\cos x}$
**解**：令 $u=\tan\frac{x}{2}$，代入三个公式：
$$\sin x=\frac{2u}{1+u^2},\ \cos x=\frac{1-u^2}{1+u^2},\ dx=\frac{2\,du}{1+u^2}$$
$$\int\frac{dx}{1+\sin x+\cos x} = \int\frac{\frac{2}{1+u^2}\,du}{1+\frac{2u}{1+u^2}+\frac{1-u^2}{1+u^2}}$$

分子分母统一为 $1+u^2$：
$$= \int\frac{2\,du}{(1+u^2)+2u+(1-u^2)} = \int\frac{2\,du}{2+2u} = \int\frac{du}{1+u}$$
$$= \ln|u+1|+C = \ln\left|\tan\frac{x}{2}+1\right|+C$$

**例题2**
**题目**：求 $\int\frac{dx}{2+\sin x}$
**解**：令 $u=\tan\frac{x}{2}$：
$$\int\frac{\frac{2\,du}{1+u^2}}{2+\frac{2u}{1+u^2}} = \int\frac{2\,du}{2(1+u^2)+2u} = \int\frac{du}{1+u^2+u}$$

配方：$u^2+u+1=(u+\frac{1}{2})^2+\frac{3}{4}$：
$$= \int\frac{du}{(u+\frac{1}{2})^2+(\frac{\sqrt{3}}{2})^2} = \frac{1}{\frac{\sqrt{3}}{2}}\arctan\frac{u+\frac{1}{2}}{\frac{\sqrt{3}}{2}}+C$$
$$= \frac{2}{\sqrt{3}}\arctan\frac{2\tan\frac{x}{2}+1}{\sqrt{3}}+C$$

## 类比

### 一句话比喻
万能代换就像"万能钥匙"——虽然不一定是最快的开锁方式，但任何锁都能开，确保不会卡住。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $u=\tan\frac{x}{2}$ | 万能钥匙 |
| $\sin x=\frac{2u}{1+u^2}$ | 钥匙插入后第一道门开 |
| $\cos x=\frac{1-u^2}{1+u^2}$ | 第二道门开 |
| 有理函数积分 | 标准化问题有确定解法 |
