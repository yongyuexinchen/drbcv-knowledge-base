# ⬜ 对称区间积分公式

## 类型判定
**连接型** — 输入对称区间[-a,a]上的积分→利用奇偶性简化计算

## 是什么
三个结论：①f为奇函数→∫_(-a)^a f(x)dx = 0（奇零）；②f为偶函数→∫_(-a)^a f(x)dx = 2∫_0^a f(x)dx（偶倍）；③对任意f：∫_(-a)^a f(x)dx = ∫_0^a [f(x)+f(-x)]dx。

## 输入-输出空间
- **输入**: 对称区间[-a,a]上的被积函数f
- **输出**: 简化后的积分值
- **映射关系**: 奇偶性→不同简化策略；非奇非偶→拆成f(x)+f(-x)

## 正例
1. **场景A（奇零）**: ∫_(-1)^1 x·e^(-x²) dx = 0，因为x·e^(-x²)是奇函数。
2. **场景B（偶倍）**: ∫_(-1)^1 |x|³ dx = 2∫_0^1 x³ dx = 1/2。
3. **场景C（非奇非偶）**: ∫_(-π/2)^(π/2) sin²x/(1+eˣ) dx
   用公式③：= ∫_0^(π/2) [sin²x/(1+eˣ) + sin²x/(1+e⁻ˣ)] dx
   = ∫_0^(π/2) sin²x dx = π/4。

## 反例/边界
1. **常见误解**: 看到对称区间不能直接写0——必须先判断奇偶性。如x²·x^(3/2)不是x⁵，而是|x|³（偶函数）。
2. **边界**: 公式③证明关键：对∫_(-a)^0 f(x)dx令x=-t换元，得到∫_0^a f(-t)dt。

## 详细解释
对称区间是定积分中最"好"的区间。奇零最常用——看到奇函数直接消。偶倍视情况使用。公式③是二级结论：不要求f奇偶，把左边翻到右边合并计算。核心技巧：拆区间+换元。

## 类比

### 一句话比喻
对称区间积分就像照镜子——奇函数在镜子两边的图像一正一反刚好抵消，偶函数两边长得一样，算一半翻倍就行。

### 物理映射
| 数学对象                                        | 物理类比                |
| ------------------------------------------- | ------------------- |
| 奇函数 $\int_{-a}^a f = 0$                     | 正反方向位移刚好抵消（走了又原路返回） |
| 偶函数 $\int_{-a}^a f = 2\int_0^a f$           | 对称建筑的左右两翼面积相同，算一半乘2 |
| $\int_{-a}^a f = \int_0^a [f(x)+f(-x)]\,dx$ | 把左边翻到右边，合成一块统一计算    |
