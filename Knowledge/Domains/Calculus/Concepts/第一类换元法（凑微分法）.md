# 第一类换元法（凑微分法）

## 类型判定
连接型 — 它是链式法则求导的逆运算，连接了"看到复合函数"和"把它积出来"这两个世界。

## 是什么

第一类换元法的本质：**把被积函数的一部分"塞进微分符号 d 后面"，使整个积分变成关于新变量的简单积分。**

设 $F'(u)=f(u)$，$u=\varphi(x)$ 可导，则：

$$\int f(\varphi(x)) \cdot \varphi'(x)\,dx = \int f(u)\,du = F(u)+C = F(\varphi(x))+C$$

核心动作：识别 $\varphi'(x)dx$，把它写成 $du$。

## 输入-输出空间

| 输入 | 输出 |
|------|------|
| 被积函数含 $\varphi'(x)$ 因子 | 凑成 $\int f(u)du$ → 用基本公式积分 → 换回 $x$ |
| 例：$\int 2x\cos(x^2)dx$ | $2xdx=d(x^2)=du$ → $\int\cos u\,du=\sin u+C=\sin(x^2)+C$ |

## 正例（≥2个）

1. $\int xe^{x^2}dx$：注意 $xdx=\frac{1}{2}d(x^2)$。$u=x^2$，$du=2xdx$，$xdx=\frac{1}{2}du$。原式 $=\frac{1}{2}\int e^u du=\frac{1}{2}e^{x^2}+C$。

2. $\int \frac{\ln x}{x}dx$：$\frac{1}{x}dx = d(\ln x)$。$u=\ln x$，原式 $=\int u\,du=\frac{1}{2}u^2+C=\frac{1}{2}(\ln x)^2+C$。

## 反例/边界（≥1个）

- **没有 $\varphi'(x)$ 因子时不能凑**。$\int e^{x^2}dx$ 看起来像复合函数，但缺少 $2x$ 因子，凑微分法失效——这个积分没有初等表达式。
- 系数必须精确匹配。$\int \cos(3x)dx$：需要 $d(3x)=3dx$，所以 $dx=\frac{1}{3}d(3x)$，答案 $=\frac{1}{3}\sin(3x)+C$。

## 详细解释

### 为什么叫"凑"微分？

链式法则求导：$[F(\varphi(x))]' = f(\varphi(x))\varphi'(x)$。

反过来积分：$\int f(\varphi(x))\varphi'(x)dx = F(\varphi(x))+C$。

关键是把 $\varphi'(x)dx$ 识别为 $d(\varphi(x))$。这个过程叫**凑微分**——不是硬算，是"看出来"。

### 常见凑微分模式

| 被积函数中的因子 | 凑成 | 核心观察 |
|---|---|---|
| $x\,dx$ | $\frac{1}{2}d(x^2)$ | $x$ 是 $x^2$ 导数的 $\frac{1}{2}$ |
| $\frac{1}{x}dx$ | $d(\ln x)$ | $(\ln x)' = \frac{1}{x}$ |
| $e^x dx$ | $d(e^x)$ | $(e^x)' = e^x$ |
| $\cos x\,dx$ | $d(\sin x)$ | $(\sin x)' = \cos x$ |
| $\frac{1}{1+x^2}dx$ | $d(\arctan x)$ | $(\arctan x)' = \frac{1}{1+x^2}$ |
| $\frac{1}{\sqrt{1-x^2}}dx$ | $d(\arcsin x)$ | $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$ |

## 经典例题

**例 1**：$\int \sin^3 x\cos x\,dx$

解：$u=\sin x$，$du=\cos x\,dx$。$\int u^3 du = \frac{1}{4}u^4+C = \frac{1}{4}\sin^4 x+C$。

**例 2**：$\int \frac{dx}{x(1+\ln x)}$

解：$u=1+\ln x$，$du=\frac{1}{x}dx$。$\int \frac{1}{u}du = \ln|u|+C = \ln|1+\ln x|+C$。

**例 3**：$\int \tan x\,dx$

解：$\tan x = \frac{\sin x}{\cos x}$。$u=\cos x$，$du=-\sin x\,dx$。$\int \frac{-du}{u} = -\ln|u|+C = -\ln|\cos x|+C = \ln|\sec x|+C$。

## 细节备注

### 使用原则
- 先看一眼：有没有哪个因子的导数恰好是另一个因子？（最核心的一步）
- 如果差常数倍，补系数即可：$\int f(ax+b)dx = \frac{1}{a}F(ax+b)+C$
- 凑完之后整个积分必须只用新变量 $u$ 表达，不能残留 $x$

## 类比

### 物理映射

**凑微分像给快递换包装盒** —— 包裹（被积函数）本身没变，只是把包装从 $x$ 的格式换成 $u$ 的格式（凑微分），方便寄到目的地（找到原函数）。系数补偿就是新旧包装盒的尺寸换算（$dx = \frac{1}{\varphi'(x)}du$）。

### 一句话口诀

**"看到谁像导数，就把谁塞进 d 后面。"**
