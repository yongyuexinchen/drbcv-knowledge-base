# 洛必达法则 (L'Hôpital's Rule)

## 是什么

对于 \frac{0}{0} 或 \frac{\infty}{\infty} 型不定式极限，若 \lim_{x \to x_0} \frac{f'(x)}{g'(x)} 存在（或为无穷大），则 \lim_{x \to x_0} \frac{f(x)}{g(x)} = \lim_{x \to x_0} \frac{f'(x)}{g'(x)}。


## 定义/定理

### 0/0 型

设 $f(x), g(x)$ 满足：

1. $\lim_{x\to x_0} f(x) = 0$，$\lim_{x\to x_0} g(x) = 0$
2. 在 $x_0$ 的某去心邻域内可导，且 $g'(x) \neq 0$
3. $\lim_{x\to x_0} \dfrac{f'(x)}{g'(x)}$ 存在（或为 $\infty$）

则：

$$\lim_{x\to x_0} \frac{f(x)}{g(x)} = \lim_{x\to x_0} \frac{f'(x)}{g'(x)}$$

### ∞/∞ 型

将上述条件 1 改为 $\lim f(x) = \infty$，$\lim g(x) = \infty$，结论同样成立。

---

## 证明思路

**理论基础**：柯西中值定理

0/0 型证明要点：

1. 补充定义 $f(x_0)=g(x_0)=0$
2. 由柯西中值定理：
   $$\frac{f(x)}{g(x)} = \frac{f(x)-f(x_0)}{g(x)-g(x_0)} = \frac{f'(\xi)}{g'(\xi)}$$
3. $\xi$ 介于 $x_0$ 与 $x$ 之间，$x\to x_0$ 时 $\xi\to x_0$
4. 得证

## 7种未定式处理

### 可直接用洛必达的（2种）

| 类型 | 处理方式 |
|------|---------|
| $\dfrac{0}{0}$ | **直接使用** |
| $\dfrac{\infty}{\infty}$ | **直接使用** |

### 需转化后使用的（5种）

```
          0/0 和 ∞/∞
         ↙         ↘
   0·∞           ∞-∞
    ↓              ↓
 改写为 0/0 或 ∞/∞   通分

1^∞, ∞^0, 0^0
    ↓ (改写为 e 的形式)
   0·∞
    ↓
 0/0 或 ∞/∞
```

| 类型 | 转化方法 |
|------|---------|
| $0 \cdot \infty$ | 将其中一个因子移到分母：$\dfrac{0}{1/\infty}$ 或 $\dfrac{\infty}{1/0}$ |
| $\infty - \infty$ | 通分化为分式 |
| $1^\infty$ | 改写为 $e^{g(x)\ln f(x)}$，化为 $0\cdot\infty$ |
| $\infty^0$ | 改写为 $e^{g(x)\ln f(x)}$，化为 $0\cdot\infty$ |
| $0^0$ | 改写为 $e^{g(x)\ln f(x)}$，化为 $0\cdot\infty$ |

## 使用技巧与注意事项

### ✅ 技巧

1. **先化简**：用等价无穷小代换、有理化、提出非零因子等化简后再用洛必达
2. **可多次使用**：若仍为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，可继续使用
3. **结合其他方法**：泰勒公式、等价代换与洛必达配合使用

### ❌ 常见错误

- **不是** $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 直接使用
- **极限不存在且不为 $\infty$** 时不能用（如 $\lim_{x\to\infty}\frac{x-\sin x}{x+\sin x}$）
- 使用后若极限仍然不存在且非 $\infty$，**不能判定原极限不存在**
- 忘记验证 $g'(x) \neq 0$ 的条件

### 例子对比

**可用**：$\lim_{x\to 0}\frac{x-\sin x}{x^3} \xrightarrow{\text{洛必达}} \lim_{x\to 0}\frac{1-\cos x}{3x^2} = \frac{1}{6}$

**不可用**：$\lim_{x\to\infty}\frac{x-\sin x}{x+\sin x}$（洛必达后 $\lim_{x\to\infty}\frac{1-\cos x}{1+\cos x}$ 不存在，但原极限 $=1$）

## 函数增长快慢比较（重要结论）

当 $x\to +\infty$ 时（$a>1, \alpha>0$）：

$$\log_a x \ll x^\alpha \ll a^x$$

即：**对数**增长最慢 → **幂函数**居中 → **指数**增长最快

例如：$\lim_{x\to+\infty}\frac{\ln x}{x^\alpha}=0$，$\lim_{x\to+\infty}\frac{x^\alpha}{a^x}=0$

## 类比

### 一句话比喻
**洛必达法则像"比身高不如比生长速度"——两个小孩现在一样矮（都趋于 0），比当前身高没意义，但可以比谁长得更快。** 0/0 型极限：分子和分母都趋于 0，比它们的导数（增长速度），谁增长快谁赢。

### 物理映射
| 极限类型 | 物理类比 |
|---------|---------|
| 0/0 | 两辆车同时从起点出发，t→0 时它们的位移比 = 初速度比 |
| ∞/∞ | 两辆车无限加速，t→∞ 时它们的位移比 = 最终加速度比 |
