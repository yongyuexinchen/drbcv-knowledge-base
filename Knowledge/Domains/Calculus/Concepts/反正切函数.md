# 反正切函数 $\arctan X$

## 类型判定
判别型 — 区分/定义概念，建立判断标准

## 是什么
$Y = \arctan X$ 是 $Y = \tan X$ 在 $X \in (-\frac{\pi}{2}, \frac{\pi}{2})$（主值区间）上的反函数。输入正切值 $X \in \mathbb{R}$，输出对应弧度 $Y \in (-\frac{\pi}{2}, \frac{\pi}{2})$。

## 输入-输出空间
- **输入**: $X \in \mathbb{R}$（全体实数，正切值）
- **输出**: $Y \in (-\frac{\pi}{2}, \frac{\pi}{2})$（开区间，对应弧度）
- **映射关系**: $\arctan: \mathbb{R} \to (-\frac{\pi}{2}, \frac{\pi}{2})$，正切值 $\mapsto$ 角度

## 正例（至少2个）
1. **场景1**: $\arctan 1 = \frac{\pi}{4}$
2. **场景2**: $\arctan(-\sqrt{3}) = -\frac{\pi}{3}$

## 反例/边界（至少1个）
1. **常见误解/边界**: 
   - **值域为开区间**：$\arctan x$ 的值域是 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 开区间，$\pm\frac{\pi}{2}$ 永远取不到。$\lim_{x\to +\infty} \arctan x = \frac{\pi}{2}$，$\lim_{x\to -\infty} \arctan x = -\frac{\pi}{2}$。
   - **定义域为全体实数**：与 $\arcsin$ 和 $\arccos$ 不同，$\arctan x$ 对任意实数都有定义。
   - **奇函数**：$\arctan(-x) = -\arctan x$。
   - **单调递增**：$\arctan x$ 严格单调递增，导数为正。

## 详细解释
定义域为全体实数，输出值域在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 内（开区间，端点取不到）。在后续极限、求导、积分中非常常用。

### 推导过程（★ 数学卡必须）
**反函数定义推导**：

$\tan x$ 在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 上严格单调递增（$\tan' x = \sec^2 x > 0$），值域为 $\mathbb{R}$。

$\arctan y$ 定义为：唯一的 $x \in (-\frac{\pi}{2}, \frac{\pi}{2})$ 使 $\tan x = y$。

**导数推导**（反函数求导法则）：

设 $y = \arctan x$，则 $x = \tan y$，$y \in (-\frac{\pi}{2}, \frac{\pi}{2})$。

$$\frac{\,dy}{\,dx} = \frac{1}{\frac{\,dx}{\,dy}} = \frac{1}{\sec^2 y}$$

由恒等式 $\sec^2 y = 1 + \tan^2 y = 1 + x^2$：

$$\therefore \boxed{\frac{d}{\,dx}\arctan x = \frac{1}{1+x^2}}$$

**重要极限**：$$\lim_{x\to +\infty} \arctan x = \frac{\pi}{2}, \quad \lim_{x\to -\infty} \arctan x = -\frac{\pi}{2}$$

**不定积分**：$$\int \frac{1}{1+x^2}\,dx = \arctan x + C$$

### 重要推论（★ 数学卡必须）
1. **恒等式**：
   - $\tan(\arctan x) = x$（$x \in \mathbb{R}$）
   - $\arctan(\tan x) = x$（仅当 $x \in (-\frac{\pi}{2}, \frac{\pi}{2})$）
2. **奇函数**：$\arctan(-x) = -\arctan x$
3. **与 $\operatorname{arccot}$ 的关系**：$\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$（两种不同定义）
4. **常见特殊值**：
   - $\arctan 0 = 0$
   - $\arctan 1 = \frac{\pi}{4}$
   - $\arctan \sqrt{3} = \frac{\pi}{3}$
   - $\arctan \frac{1}{\sqrt{3}} = \frac{\pi}{6}$

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\arctan 1$ 的值。

**解**：在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 上，$\tan(\frac{\pi}{4}) = 1$，且 $\frac{\pi}{4}$ 在此区间内。

$$\arctan 1 = \frac{\pi}{4}$$

**例题2**
**题目**：求 $\arctan(-\sqrt{3})$ 的值。

**解**：在 $(-\frac{\pi}{2}, \frac{\pi}{2})$ 上，$\tan(-\frac{\pi}{3}) = -\sqrt{3}$。

$$\arctan(-\sqrt{3}) = -\frac{\pi}{3}$$

或利用奇函数性质：$\arctan(-\sqrt{3}) = -\arctan(\sqrt{3}) = -\frac{\pi}{3}$。

## 类比

### 一句话比喻
$\arctan$ 就像看赛车的倾斜角度——不管车速快到多远（正切值可以趋近无穷），倾斜角始终在 $-\frac{\pi}{2}$ 到 $\frac{\pi}{2}$ 之间（永远跑不到垂直）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $\arctan x$ | 已知斜坡的高宽比求坡度角 |
| 定义域 $\mathbb{R}$ | 斜坡可以无限陡（高宽比可任意大） |
| 值域 $(-\frac{\pi}{2}, \frac{\pi}{2})$ | 坡度角始终在 ±90° 之间 |
| 导数 $\frac{1}{1+x^2}$ | 坡度越陡，角度变化越慢（饱和效应） |
