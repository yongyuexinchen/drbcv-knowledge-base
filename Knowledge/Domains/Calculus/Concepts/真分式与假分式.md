# 真分式与假分式 (Proper vs Improper Rational Functions)

## 类型判定
定义型 — 明确术语的数学定义

## 是什么
真分式：分子最高次幂严格小于分母最高次幂的有理分式。假分式：分子最高次幂大于等于分母最高次幂的有理分式。假分式可通过多项式除法化为一个多项式与一个真分式的和。

## 输入-输出空间
- **输入**: 有理分式 $\frac{P(x)}{Q(x)}$
- **输出**: 最简分式之和 / 积分结果
- **映射关系**: 复杂有理函数 → 简单分式分解

## 正例（至少2个）
1. **场景1**: 真分式：$\frac{x-3}{(x-1)^2(x+1)}$（分子1次 < 分母3次）
2. **场景2**: 假分式：$\frac{x^4+2x^2+4}{x^2+1}$ 化为 $x^2+1+\frac{3}{x^2+1}$

## 反例/边界（至少1个）
1. **常见误解/边界**: $\frac{x^2+1}{x^2+1}=1$ 是假分式（分子次数=分母次数），化简后为常数 $1$，但没有真分式部分（余数为0）。另外，$\frac{x^2}{x^2+1}=1-\frac{1}{x^2+1}$ 的分解中常数项为1，真分式部分为 $\frac{-1}{x^2+1}$。

## 详细解释
有理函数积分四步法第一步：假分式化为多项式 + 真分式。

### 推导过程（★ 数学卡必须）
**多项式除法（长除法）**：

设 $\frac{P_n(x)}{Q_m(x)}$ 为假分式（$n\ge m$），则存在唯一的多项式 $S(x)$（商）和 $R(x)$（余数，$\deg R < \deg Q$）使得：
$$P_n(x) = Q_m(x)\cdot S(x) + R(x)$$
$$\frac{P_n(x)}{Q_m(x)} = S(x) + \frac{R(x)}{Q_m(x)}$$

操作方法：列竖式除法，盯住最高次幂，逐次消去。

**凑分母法**（简单时更快捷）：
$$\frac{x^4+2x^2+4}{x^2+1}: \text{分子} = x^4+2x^2+4 = (x^2+1)(x^2+1)+3$$
$$\Rightarrow \frac{x^4+2x^2+4}{x^2+1} = x^2+1+\frac{3}{x^2+1}$$

### 重要推论（★ 数学卡必须）
1. 真分式才能进行部分分式分解——这是有理函数积分的核心步骤。
2. 假分式必须先化假为真，才能继续后续步骤。
3. 化假为真有两种方法：凑分母法（简单时用）和长除法（通用）。
4. 多项式部分积分非常容易（逐项积分即可），真分式部分才是需要分解的。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：将假分式 $\frac{x^4+2x^2+4}{x^2+1}$ 化为多项式+真分式
**解**：凑分母法：$x^4+2x^2+4=(x^2+1)^2+3$
$$\frac{x^4+2x^2+4}{x^2+1} = (x^2+1)+\frac{3}{x^2+1}$$

积分：$\int\frac{x^4+2x^2+4}{x^2+1}\,dx = \int(x^2+1)\,dx+3\int\frac{1}{x^2+1}\,dx = \frac{x^3}{3}+x+3\arctan x+C$

**例题2**
**题目**：将 $\frac{x^5+x^4-8}{x^3-x}$ 化为多项式+真分式
**解**：长除法：$x^5+x^4-8 = (x^3-x)(x^2+x+1)+(x^2+x-8)$
$$\frac{x^5+x^4-8}{x^3-x} = x^2+x+1+\frac{x^2+x-8}{x^3-x}$$

分母分解：$x^3-x=x(x-1)(x+1)$，继续部分分式分解真分式部分。

## 类比

### 一句话比喻
假分式就像"超载的车"——货物太多（分子次数高），必须先卸下一部分装到另一辆车（多项式），剩下的才能走小路（部分分式分解）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 假分式 | 超载的货车 |
| 多项式部分 | 卸下的大宗货物 |
| 真分式部分 | 剩余轻量货物可走小路 |
| 多项式除法 | 卸货操作 |
