# 分部积分循环法（还原法）(Integration by Parts with Cyclic Reduction)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
当分部积分一次后，右侧出现与左侧相同形式的积分（系数不同），可通过移项求解。步骤：分部积分两次，得到含原积分的方程，移项求解，除以系数得结果。

## 输入-输出空间
- **输入**: $e^x\sin x$、$\sec^3 x$ 等循环型被积函数
- **输出**: 原函数族 $F(x)+C$
- **映射关系**: 构造方程解出原积分

## 正例（至少2个）
1. **场景1**: 设 $I = \int e^x\sin x\,dx$，则 $I = e^x\sin x - e^x\cos x - I$，故 $I = \frac{1}{2}e^x(\sin x - \cos x) + C$
2. **场景2**: $\int \sec^3 x\,dx = \frac{1}{2}\sec x\tan x + \frac{1}{2}\ln\lvert\sec x + \tan x\rvert + C$

## 反例/边界（至少1个）
1. **常见误解/边界**: 移项后忘记 $+C$。设 $2I = \text{某表达式}$，则 $I = \frac{1}{2}\text{某表达式}+C$，而非 $I = \frac{1}{2}\text{某表达式}$（漏掉常数项）。另外，两次分部时 $u$ 的选取必须一致——如果第一次选 $\sin x$ 为 $u$，第二次也必须选 $\sin x$，否则无法还原。

## 详细解释
循环法也称"分部积分还原"。注意移项后系数要算准确，不能漏掉 $+C$。

### 推导过程（★ 数学卡必须）
**以 $\int e^x\sin x\,dx$ 为例**：

设 $I = \int e^x\sin x\,dx$。

**第一次分部**：取 $u=\sin x$，$dv=e^x\,dx$：
$$I = e^x\sin x - \int e^x\cos x\,dx$$

**第二次分部**：对 $\int e^x\cos x\,dx$ 继续取 $u=\cos x$，$dv=e^x\,dx$：
$$\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I$$

代入第一次结果：
$$I = e^x\sin x - (e^x\cos x + I) = e^x\sin x - e^x\cos x - I$$

移项：$2I = e^x(\sin x - \cos x)$，故 $I = \frac{1}{2}e^x(\sin x-\cos x)+C$。

### 重要推论（★ 数学卡必须）
1. **循环法的适用条件**：两次分部积分后出现原积分，系数不同。
2. **关键约束**：两次分部时 $u$ 的选取方向必须一致（都选三角或都选指数）。
3. **移项规则**：将右侧的原积分移到左侧，合并系数，除以合并后的系数。
4. **常数 $C$**：移项后除以系数的等式右边仍需加 $C$。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int e^x\sin x\,dx$
**解**：设 $I=\int e^x\sin x\,dx$。

第一次分部：$u=\sin x$，$dv=e^x\,dx$：
$$I = e^x\sin x - \int e^x\cos x\,dx$$

第二次分部：$u=\cos x$，$dv=e^x\,dx$：
$$\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I$$

代入得：$I = e^x\sin x - e^x\cos x - I$，故 $2I = e^x(\sin x-\cos x)$：
$$I = \frac{1}{2}e^x(\sin x-\cos x)+C$$

**例题2**
**题目**：求 $\int \sec^3 x\,dx$
**解**：取 $u=\sec x$，$dv=\sec^2 x\,dx$，则 $v=\tan x$，$du=\sec x\tan x\,dx$：
$$\int\sec^3 x\,dx = \sec x\tan x - \int\sec x\tan^2 x\,dx$$

利用 $\tan^2 x = \sec^2 x - 1$：
$$= \sec x\tan x - \int\sec^3 x\,dx + \int\sec x\,dx$$

移项：$2\int\sec^3 x\,dx = \sec x\tan x + \int\sec x\,dx$

而 $\int\sec x\,dx = \ln\lvert\sec x+\tan x\rvert+C$，故：
$$\int\sec^3 x\,dx = \frac{1}{2}\sec x\tan x + \frac{1}{2}\ln\lvert\sec x+\tan x\rvert+C$$
