# 第二类换元积分法 (Second Substitution Rule)

## 类型判定
程序型 — 给出明确的操作步骤或解题方法

## 是什么
设 $x = \varphi(t)$ 单调可导，且 $\varphi'(t) \ne 0$，则 $\int f(x)\,dx \xrightarrow{x=\varphi(t)} \int f(\varphi(t))\varphi'(t)\,dt$。积分完成后，需用反函数 $t = \varphi^{-1}(x)$ 将变量代回。

## 输入-输出空间
- **输入**: 被积函数 $f(x)$（不好直接积的形式）
- **输出**: 原函数族 $F(x)+C$
- **映射关系**: 通过换元将难积形式化为易积形式

## 正例（至少2个）
1. **场景1**: $\int \frac{1}{1+\sqrt{x}}\,dx \xrightarrow{t=\sqrt{x}} \int \frac{2t}{1+t}\,dt$
2. **场景2**: $\int \sqrt{a^2-x^2}\,dx \xrightarrow{x=a\sin t} \int a^2\cos^2 t\,dt$

## 反例/边界（至少1个）
1. **常见误解/边界**: 换元函数必须单调以保证有反函数可代回。若 $\varphi(t)$ 不单调（如 $x=t^2$ 在全实数上），则无法唯一反解 $t$。必须限定单调区间，例如 $t \ge 0$。

## 详细解释
第二类换元法比第一类更直接——把被积函数中"不顺眼"的部分整体换掉。换元函数必须单调以保证可反解。$\varphi'(t) \ne 0$ 保证单调性。

### 推导过程（★ 数学卡必须）
设 $x=\varphi(t)$ 单调可导且 $\varphi'(t)\ne 0$，则 $t=\varphi^{-1}(x)$ 存在。

若 $\int f(\varphi(t))\varphi'(t)\,dt = \Phi(t)+C$，则：
$$\int f(x)\,dx = \Phi(\varphi^{-1}(x)) + C$$

验证：对 $\Phi(\varphi^{-1}(x))$ 求导，由复合函数求导法则：
$$\frac{d}{dx}\Phi(\varphi^{-1}(x)) = \Phi'(t)\cdot\frac{dt}{dx} = f(\varphi(t))\varphi'(t)\cdot\frac{1}{\varphi'(t)} = f(\varphi(t)) = f(x)$$

### 重要推论（★ 数学卡必须）
1. 第二类换元法的核心是**选择适当的换元**，使新积分比原积分更易处理。
2. 常见换元类型：
   - **根式代换**：$t=\sqrt{ax+b}$，去根号
   - **倒代换**：$t=1/x$，降低分母次数
   - **三角换元**：$x=a\sin t$、$x=a\tan t$、$x=a\sec t$
3. 积分完成后**必须代回原变量**——这是与第一类换元法的重要区别。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\int \frac{dx}{1+\sqrt{x}}$
**解**：令 $t=\sqrt{x}$，则 $x=t^2$，$dx=2t\,dt$：
$$\int \frac{dx}{1+\sqrt{x}} = \int \frac{2t}{1+t}\,dt = 2\int\frac{t+1-1}{1+t}\,dt = 2\int\left(1-\frac{1}{1+t}\right)dt$$
$$= 2t - 2\ln|1+t| + C = 2\sqrt{x} - 2\ln(1+\sqrt{x}) + C$$

**例题2**
**题目**：求 $\int \sqrt{a^2-x^2}\,dx$（$a>0$）
**解**：令 $x=a\sin t$（$t\in[-\pi/2,\pi/2]$），$dx=a\cos t\,dt$：
$$\sqrt{a^2-x^2} = \sqrt{a^2-a^2\sin^2 t} = a\cos t$$
$$\int \sqrt{a^2-x^2}\,dx = a^2\int\cos^2 t\,dt = \frac{a^2}{2}\int(1+\cos 2t)\,dt = \frac{a^2}{2}\left(t+\frac{1}{2}\sin 2t\right)+C$$
$$= \frac{a^2}{2}t + \frac{a^2}{2}\sin t\cos t + C$$

代回：$t=\arcsin\frac{x}{a}$，$\sin t=\frac{x}{a}$，$\cos t=\frac{\sqrt{a^2-x^2}}{a}$：
$$= \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C$$

## 类比

### 一句话比喻
第二类换元就像"换货币"——不好用的币种直接全部换成容易计算的币种，算完再换回来。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $x=\varphi(t)$ | 换一种货币计算 |
| $dx=\varphi'(t)\,dt$ | 汇率换算 |
| 积分后代回 $x$ | 算完换回原货币 |
| 单调性要求 | 汇率必须单向可逆 |
