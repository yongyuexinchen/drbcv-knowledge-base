# 等价无穷小

## 类型判定
定义型 — 明确术语的数学定义

## 是什么
若 $\lim \frac{\alpha}{\beta} = 1$，则称 $\alpha$ 与 $\beta$ 是等价无穷小，记作 $\alpha \sim \beta$。表示两者趋于 0 的速度基本相同。

**四组核心等价代换公式**（$x \to 0$）：

**第一组（等价到 $x$ 的一阶）**：
- $\sin x \sim x$、$\tan x \sim x$、$\arcsin x \sim x$、$\arctan x \sim x$
- $e^x - 1 \sim x$、$\ln(1+x) \sim x$

**第二组（含参类型）**：
- $a^x - 1 \sim x\ln a$
- $(1+x)^\alpha - 1 \sim \alpha x$（$\alpha$ 为任意实数，$\alpha \neq 0$）

**第三组（二阶等价）**：
- $1 - \cos x \sim \frac{1}{2}x^2$
- $x - \ln(1+x) \sim \frac{1}{2}x^2$

**第四组（三阶等价）**：
- $x - \sin x \sim \frac{1}{6}x^3$、$\arcsin x - x \sim \frac{1}{6}x^3$
- $\tan x - x \sim \frac{1}{3}x^3$、$x - \arctan x \sim \frac{1}{3}x^3$

**广义化**：以上所有公式中的 $x$ 均可替换为任意趋于 0 的量（"框框"）。如 $e^{\sin x} - 1 \sim \sin x$（当 $\sin x \to 0$）。

## 输入-输出空间
- **输入**: 趋于 0 的变量 $\alpha, \beta$
- **输出**: 比值极限（判断等价性）或等价替换结果
- **映射关系**: 从无穷小量到其趋零速度的比较

## 正例（至少2个）
1. **场景1**: $x \to 0$ 时 $\sin x \sim x$：$\lim_{x\to 0} \frac{\sin x}{x} = 1$
2. **场景2**: $x \to 0$ 时 $(1+x)^3 - 1 \sim 3x$：$\lim_{x\to 0} \frac{(1+x)^3 - 1}{3x} = \lim_{x\to 0} \frac{3x + 3x^2 + x^3}{3x} = 1$

## 反例/边界（至少1个）
1. **常见误解/边界**: 等价代换只能在**整个函数的乘除因子**中进行，不能在加减项中随意代换。例如 $\lim_{x\to 0} \frac{x - \sin x}{x^3}$，若将 $\sin x \sim x$ 代入得 $\frac{x - x}{x^3} = 0$，这是错误的。正确结果是 $\frac{1}{6}$（因为 $x - \sin x \sim \frac{1}{6}x^3$）。若加减项确实可以代换，应先拆极限再代换。

## 详细解释
注意是比值极限为 1 时才等价。等价无穷小可以在整个函数的乘除因子中进行代换。

### 推导过程（★ 数学卡必须）
**等价无穷小在乘除中可代换的证明**：

若 $\alpha \sim \alpha'$，$\beta \sim \beta'$，则：
$$\lim \frac{\alpha}{\beta} = \lim \left(\frac{\alpha}{\alpha'} \cdot \frac{\alpha'}{\beta'} \cdot \frac{\beta'}{\beta}\right) = \lim \frac{\alpha}{\alpha'} \cdot \lim \frac{\alpha'}{\beta'} \cdot \lim \frac{\beta'}{\beta} = 1 \cdot \lim \frac{\alpha'}{\beta'} \cdot 1 = \lim \frac{\alpha'}{\beta'}$$

同理可证 $\alpha \cdot \gamma$ 中也可代换。关键：**必须是乘除因子**（整个函数的一部分作为因子乘在函数上），不能是加减的项。

**等价无穷小与泰勒公式的关系**：
等价无穷小本质上是泰勒展开的一阶近似（或首非零项）。例如：
- $\sin x = x - \frac{1}{6}x^3 + o(x^3)$ → 一阶近似 $\sin x \sim x$
- $1 - \cos x = \frac{1}{2}x^2 + o(x^2)$ → 首非零项为 $\frac{1}{2}x^2$

当等价无穷小精度不够（如加减抵消）时，需用泰勒展开的高阶项。

### 重要推论（★ 数学卡必须）
1. **代换规则**：等价无穷小代换只能在**整个函数的乘除因子**中进行。加减的项不能直接代换，除非先拆极限（需保证拆开后的各极限都存在）。

2. **代换的"王炸"组合**：等价代换 + 拆极限。看到存在就拆出，拆出后每个乘除因子自由代换。

3. **"提后者"技巧**：$e^{f(x)} - e^{g(x)} = e^{g(x)}(e^{f(x)-g(x)} - 1)$。当 $f(x)-g(x) \to 0$ 时，括号内等价于 $f(x)-g(x)$。$e^{g(x)}$ 若极限非零可提前求出。

4. **幂指函数的化简**：对于 $1^\infty$ 型未定式，用 $u^v = e^{v\ln u}$ 或 $e^{v(u-1)}$（当 $u \to 1$ 时 $\ln u \sim u-1$）转化为求指数上的极限。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\lim\limits_{x \to 0} \frac{x - \sin x}{x^2 \tan x}$
**解**：
$$\lim_{x \to 0} \frac{x - \sin x}{x^2 \tan x} = \lim_{x \to 0} \frac{x - \sin x}{x^2 \cdot x} = \lim_{x \to 0} \frac{x - \sin x}{x^3}$$
由第四组公式 $x - \sin x \sim \frac{1}{6}x^3$（这是整个函数的乘除因子！），
$$= \lim_{x \to 0} \frac{\frac{1}{6}x^3}{x^3} = \frac{1}{6}$$

注意：这里的 $\tan x \sim x$ 是在乘除因子中代换（分母中的因子），完全正确。

**例题2**
**题目**：求 $\lim\limits_{x \to 0} \frac{\ln(1+x)\ln(1-x) - \ln(1-x^2)}{x^4}$
**解**：
先通分观察：$\ln(1+x)\ln(1-x) - \ln(1-x^2) = \ln(1+x)\ln(1-x) - \ln[(1+x)(1-x)] = \ln(1+x)\ln(1-x) - \ln(1+x) - \ln(1-x)$

令 $a = \ln(1+x), b = \ln(1-x)$，原式 $= ab - a - b = (a-1)(b-1) - 1$（不直观）。改用泰勒展开或等价代换+拆项更直接。

**换元法**：令 $t = -x$ 不便于直接代换。更好的做法是利用：
$$\ln(1+x) \sim x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \cdots$$
代入整理，分子展开到 $x^4$ 项（分母为 $x^4$）最终可得 $-\frac{5}{12}$（此题更适合用泰勒公式展开处理）。
