# 微分方程的通解

## 类型判定
连接型 — 输入微分方程，输出含任意常数的解族，揭示一族函数曲线的共同结构。

## 是什么
通解（General Solution）是微分方程的解中含有**独立任意常数**、且常数的个数等于**微分方程的阶数**的解。通解不是一个函数，而是一族函数——每个具体的常数值对应族中的一条曲线。不定积分 $\int f(x)dx = F(x) + C$ 本质上就是一阶微分方程 $y' = f(x)$ 的通解。

## 输入-输出空间
- **输入**：微分方程（如 $y' = 2x$、$y'' + y = 0$）
- **输出**：含任意常数的解族（如 $y = x^2 + C$、$y = C_1\cos x + C_2\sin x$）
- **映射关系**：微分方程 → 含 $n$ 个独立常数的解族（$n$ = 方程阶数）

## 正例（≥2个）
1. **一阶微分方程**：$y' = 2x$ → 积分得 $y = x^2 + C$（一个任意常数，一阶）
2. **二阶微分方程**：$y'' + y = 0$ → 通解 $y = C_1\cos x + C_2\sin x$（两个独立常数，二阶）
3. **可分离变量**：$\frac{dy}{dx} = ky$ → 通解 $y = Ce^{kx}$

## 反例/边界（≥1个）
- $y = x^2 + 3$ 不是 $y' = 2x$ 的通解（常数已被指定为 3，这是**特解**）
- $y = C_1 e^x + C_2 e^x = (C_1+C_2)e^x$ 中 $C_1$ 和 $C_2$ 不独立（合并为一个常数）→ 不是二阶方程的通解
- 通解不一定包含所有解：某些非线性方程可能有不在通解族中的"奇解"

## 详细解释

### 通解的判定标准
1. **代入验证**：将通解代入原微分方程，恒等式成立
2. **常数个数**：独立任意常数的个数 = 微分方程的阶数
3. **独立性**：任意常数之间不能相互合并

### 常见类型的通解形式

| 方程类型  | 方程形式                 | 通解                                            |
| ----- | -------------------- | --------------------------------------------- |
| 直接积分型 | $y' = f(x)$          | $y = \int f(x)dx + C$                         |
| 可分离变量 | $g(y)dy = f(x)dx$    | $\int g(y)dy = \int f(x)dx + C$               |
| 一阶线性  | $y' + P(x)y = Q(x)$  | $y = e^{-\int Pdx}(\int Qe^{\int Pdx}dx + C)$ |
| 常系数齐次 | $y'' + py' + qy = 0$ | 特征根法：$r^2 + pr + q = 0$                       |

### 几何含义
通解 $y = x^2 + C$ 在平面上表示**一族抛物线**——所有曲线形状相同（都是 $y=x^2$ 的平移），只是高低位置不同。$C$ 是"族参数"。

### 生活类比
通解像**裁缝做的一批同款衣服**，还没根据具体身材（初始条件）修改——肥瘦长短都一样，只是尺码（$C$）不同。特解是量体裁衣后那件合身的。
