# 函数图形的描绘与渐近线


## 是什么

若曲线上的动点沿曲线趋于无穷远时，该点到某直线的距离趋于0，则称该直线为曲线的渐近线。分为水平渐近线、垂直渐近线（铅垂渐近线）和斜渐近线。


## 一、函数作图的步骤

利用导数描绘函数图形 $y=f(x)$ 的**四步法**：

### Step 1：确定基本属性

- **定义域**：确定 $x$ 的取值范围
- **奇偶性**：奇/偶函数可利用对称性减少作图量
- **周期性**：周期函数只需画一个周期
- **特殊点**：与坐标轴的交点

### Step 2：一阶导数分析（增减性与极值）

- 求 $f'(x)$
- 找出 $f'(x)=0$ 的点（驻点）和 $f'(x)$ 不存在的点
- 用这些点划分定义域，列表判定单调区间和极值点

### Step 3：二阶导数分析（凹凸性与拐点）

- 求 $f''(x)$
- 找出 $f''(x)=0$ 的点和不存在的点
- 用这些点划分定义域，列表判定凹凸区间和拐点

### Step 4：渐近线分析

- 确定**水平、垂直、斜渐近线**（详见下文）
- 结合以上信息，在坐标系中描点连线

## 二、三种渐近线

### 2.1 水平渐近线

若 $\lim_{x\to\infty} f(x) = A$（或 $\lim_{x\to -\infty} f(x) = A$，或 $\lim_{x\to +\infty} f(x) = A$），
则 $y = A$ 是一条**水平渐近线**。

> **判断方法**：看 $x\to\infty$ 时 $f(x)$ 是否有**有限极限**。

**例**：$y = \arctan x$，$\lim_{x\to +\infty} \arctan x = \frac{\pi}{2}$，$\lim_{x\to -\infty} \arctan x = -\frac{\pi}{2}$，故有两条水平渐近线。

### 2.2 垂直渐近线（铅垂渐近线）

若 $\lim_{x\to x_0} f(x) = \infty$（或单侧趋于 $\infty$），
则 $x = x_0$ 是一条**垂直渐近线**。

> **判断方法**：找函数趋于无穷的有限点（通常分母为零的点）。

**例**：$y = \frac{1}{x}$，$\lim_{x\to 0} \frac{1}{x} = \infty$，故 $x=0$（$y$ 轴）是垂直渐近线。

### 2.3 斜渐近线

若存在直线 $y = kx + b$，使得 $\lim_{x\to\infty} [f(x) - (kx+b)] = 0$，则该直线为**斜渐近线**。

**求法**（$x\to +\infty$ 或 $x\to -\infty$ 分别求）：

$$k = \lim_{x\to\infty} \frac{f(x)}{x} \quad (\text{存在且不为 } 0)$$

$$b = \lim_{x\to\infty} [f(x) - kx] \quad (\text{存在})$$

> **注意**：\\
> - 若某侧已有水平渐近线，则**不可能有斜渐近线**（同一侧水平与斜渐近线互斥）\\
> - 正负无穷侧要**分别讨论**

## 三、渐近线判断流程图

```
求 x→∞（或 x→+∞, x→-∞）
    ↓
lim f(x) 是否存在有限值 A？
    ├─ 是 → 水平渐近线 y = A，这一侧不再有斜渐近线
    └─ 否 → 检查斜渐近线：
               k = lim f(x)/x
               ├─ 存在且 ≠0 → b = lim [f(x)-kx] → 斜渐近线 y=kx+b
               └─ 不存在或=0 → 无斜渐近线

求 x→x₀（有限点）
    ↓
lim f(x) = ∞？
    ├─ 是 → 垂直渐近线 x = x₀
    └─ 否 → 无垂直渐近线
```

## 四、综合例题

**例**：作 $f(x) = \dfrac{x^3+4}{x^2}$ 的图形

1. **定义域**：$x \neq 0$
2. **一阶导**：$f'(x) = 1 - \dfrac{8}{x^3}$，驻点 $x=2$\\
   增减性：$(-\infty,0)\uparrow$，$(0,2)\downarrow$，$(2,+\infty)\uparrow$\\
   极小值：$f(2)=3$
3. **二阶导**：$f''(x) = \dfrac{24}{x^4} > 0$，全定义域凹，无拐点
4. **渐近线**：\\
   - 水平：$x\to\infty$ 时 $f(x)\to\infty$，**无**\\
   - 垂直：$x\to 0$ 时 $f(x)\to\infty$，$x=0$ 是垂直渐近线\\
   - 斜：$k=\lim\frac{f(x)}{x}=1$，$b=\lim[f(x)-x]=0$，$y=x$ 是斜渐近线

---

## 五、渐近线分类总结

| 类型 | 方程 | 条件 | 求法 |
|------|------|------|------|
| 水平 | $y=A$ | $\lim_{x\to\infty} f(x)=A$ | 直接求极限 |
| 垂直 | $x=x_0$ | $\lim_{x\to x_0} f(x)=\infty$ | 找分母为零点 |
| 斜 | $y=kx+b$ | $k=\lim\frac{f(x)}{x}\neq 0,\infty$，$b=\lim[f(x)-kx]$ 存在 | 两个极限 |

> **重要结论**：幂函数增长、对数增长、指数增长的快慢与渐近线分析密切相关——例如有理函数，分子次数比分母高1次时，必有一条斜渐近线。

## 正例
**例1**：$f(x)=\frac{1}{x}$ 有水平渐近线 $y=0$ 和垂直渐近线 $x=0$。
**例2**：$f(x)=\frac{x^2}{x+1}=x-1+\frac{1}{x+1}$ 有斜渐近线 $y=x-1$ 和垂直渐近线 $x=-1$。
