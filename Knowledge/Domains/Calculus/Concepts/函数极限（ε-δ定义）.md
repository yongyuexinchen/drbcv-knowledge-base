## 类型判定

这是一个 **连接级 (connection)** 概念卡。函数极限是数列极限从离散到连续的推广，也是后续连续性、导数、积分定义的基础。ε-δ 语言精确刻画了自变量趋近于某点时函数值的逼近行为。

## 是什么

**函数极限**：设函数 f(x) 在点 x₀ 的某去心邻域内有定义（x₀ 本身可以没有定义），A 是一个常数。若对任意给定的正数 ε > 0，总存在正数 δ > 0，使得当 0 < |x - x₀| < δ 时，恒有 |f(x) - A| < ε，则称当 x → x₀ 时 f(x) 的极限为 A，记作：
\\[
\lim_{x \to x_0} f(x) = A
\\]

**核心思想**：\"x 充分接近 x₀ 时，f(x) 充分接近 A\"。

**关键区别**：x → x₀ 意味着 x 无限接近但**取不到** x₀——极限与 f(x₀) 的值无关。

## 输入-输出空间

| 维度 | 说明 |
|------|------|
| **输入** | 函数 f(x)，趋近点 x₀（可为有限数或 ±∞） |
| **输出** | 极限值 A（存在时）；或\"不存在\" |
| **定义域要求** | f 在 x₀ 的某去心邻域有定义 |
| **极限方向** | 左极限（x → x₀⁻）、右极限（x → x₀⁺） |
| **广义极限** | 单侧极限、无穷极限（lim f(x) = ∞） |

**与数列极限的对比**：

| 方面 | 数列极限 (ε-N) | 函数极限 (ε-δ) |
|------|----------------|----------------|
| 自变量 | n → ∞（离散，正整数） | x → x₀（连续，实数） |
| 趋近方式 | 唯一方向（正无穷） | 可从左右两侧趋近 |
| δ/N 的依赖 | N(ε) 随 ε 变小而增大 | δ(ε) 随 ε 变小而变小 |

## 正例

**例 1**：证明 \\(\lim_{x \to 1} (2x+1) = 3\\)

*证*：∀ ε > 0，要找 δ > 0 使 0 < |x-1| < δ 时 |(2x+1)-3| < ε
\\[
|(2x+1)-3| = |2x-2| = 2|x-1|
\\]
要使 2|x-1| < ε，只需 |x-1| < ε/2
取 δ = ε/2，则当 0 < |x-1| < δ 时，|(2x+1)-3| < ε ✓

**例 2**：证明 \\(\lim_{x \to 2} x^2 = 4\\)

*证*：∀ ε > 0，要找 δ > 0 使 0 < |x-2| < δ 时 |x²-4| < ε
\\[
|x²-4| = |x-2||x+2|
\\]
先限定 δ ≤ 1，则 |x-2| < 1 ⇒ x ∈ (1,3) ⇒ |x+2| < 5
故 |x²-4| ≤ 5|x-2|
要使 5|x-2| < ε，只需 |x-2| < ε/5
取 δ = min{1, ε/5}，则当 0 < |x-2| < δ 时，|x²-4| < ε ✓

## 反例/边界

**反例 1**（震荡不存在）：f(x) = sin(1/x)，x → 0
- 在 x=0 的任何去心邻域内，sin(1/x) 在 -1 和 1 之间无限震荡
- 无论取多小的 δ，总存在 x 使 sin(1/x) 远离任何候选 A
- 极限不存在

**反例 2**（左右极限不等）：f(x) = sgn(x)（符号函数），x → 0
- 左极限：\\(\lim_{x\to 0^-} \text{sgn}(x) = -1\\)
- 右极限：\\(\lim_{x\to 0^+} \text{sgn}(x) = 1\\)
- 左右极限不等，故 \\(\lim_{x\to 0} \text{sgn}(x)\\) 不存在

**边界**：极限存在与函数值无关
- f(x) = (x²-1)/(x-1) 在 x=1 处无定义，但 \\(\lim_{x\to 1} f(x) = 2\\)
- 极限只关心 x 趋近于 x₀ 时 f(x) 的趋势，不关心 x₀ 本身的值

## 详细解释

### ε-δ 定义的几何解释

以 x₀ 为中心画一个宽度为 2δ 的小区间（δ 带），以 A 为中心画一个宽度为 2ε 的小区间（ε 带）。ε-δ 语言说的是：

**只要 x 落在 δ 带内（除 x₀ 本身），f(x) 就一定落在 ε 带内。**

δ 的大小依赖于 ε：ε 越小，δ 通常也越小。

### 函数极限的等价形式

1. **Heine 归结原则**：\\(\lim_{x\to x_0} f(x) = A\\) 当且仅当对任意满足 xₙ → x₀（xₙ ≠ x₀）的数列 {xₙ}，都有 f(xₙ) → A
   - 这建立了函数极限与数列极限的联系
   - 常用于证明极限不存在：找到两个不同的数列趋近 x₀，但 f(xₙ) 趋向不同值

2. **单侧极限**：
   - 左极限：\\(\lim_{x\to x_0^-} f(x) = A\\)（x 从左侧趋近）
   - 右极限：\\(\lim_{x\to x_0^+} f(x) = A\\)（x 从右侧趋近）
   - 极限存在 ⇔ 左右极限都存在且相等

### 函数极限的性质

1. **唯一性**：若极限存在，则唯一
2. **局部有界性**：若极限存在，则在 x₀ 附近 f(x) 有界
3. **局部保号性**：若极限 A > 0，则存在 δ 使 f(x) > 0
4. **四则运算**：极限存在时，和差积商的极限等于极限的和差积商（分母极限非零）

## 细节备注

| 子特性 | 说明 |
|--------|------|
| δ 的选取技巧 | 先限定一个试探性的 δ（如 δ ≤ 1），再调整最终 δ = min{试探值, 精确值} |
| 去心邻域 | 0 < |x - x₀| 意味着 x ≠ x₀——极限不关心 x₀ 点的函数值 |
| 自变量趋近方式 | x → ∞ 时，ε-δ 改为 ε-M：∀ ε > 0，∃ M > 0，使 x > M 时 |f(x)-A| < ε |
| Heine 归结原则 | 是证明极限不存在的最有力工具之一 |
| 复合函数极限 | 若内外层极限都存在，可进行复合运算（需满足特定条件） |

### 使用原则

1. **代入原则**：对初等函数，若 x₀ 在定义域内，极限可直接代入（因连续性）
2. **未定式警觉**：若代入后出现 0/0、∞/∞ 等 7 种未定式，需变形后再处理
3. **单侧极限**：分段函数在分段点需分别计算左右极限
4. **无穷极限**：区分\"极限为无穷大\"和\"极限不存在\"——前者是广义极限

## 经典例题

### 例题 1（原文：期末救急速讲文章-例1）

求 \\(\lim_{x \to 1} \frac{x-3}{x^2-9}\\)

**解**：代入 x = 1，分母 = 1-9 = -8 ≠ 0，分子 = -2
这是一个非未定式，直接代入：
\\[
\lim_{x \to 1} \frac{x-3}{x^2-9} = \frac{1-3}{1^2-9} = \frac{-2}{-8} = \frac{1}{4}
\\]

### 例题 2（原文：期末救急速讲文章-例1）

求 \\(\lim_{x \to 3} \frac{x-3}{x^2-9}\\)

**解**：代入 x = 3，分子 = 0，分母 = 0 → **0/0 未定式**，不可直接代入
\\[
\frac{x-3}{x^2-9} = \frac{x-3}{(x-3)(x+3)} = \frac{1}{x+3} \quad (x \neq 3)
\\]
约去零因子后：
\\[
\lim_{x \to 3} \frac{1}{x+3} = \frac{1}{3+3} = \frac{1}{6}
\\]

> **注**：x→3 但 x ≠ 3，故 x-3 ≠ 0，可以安全约分。

## 类比

**狙击手瞄准类比** 🎯

你是一名狙击手，目标在 x₀ 位置。你的瞄准镜精度要求如下：

- A 是目标的中心（极限值）
- ε 是目标区域的半径——指挥官说\"要打在半径 10cm 的圈内\"（精度要求）
- δ 是你的瞄准误差范围——你需要把枪口对准在 x₀ 周围多小的范围内才能保证子弹落在 ε 圈内
- ε 越小（精度要求越高），你需要调整的 δ 就越小（瞄准越要精确）
- 只要对任何精度要求 ε，你都能找到合适的瞄准范围 δ，你就是一名合格的狙击手——极限存在
