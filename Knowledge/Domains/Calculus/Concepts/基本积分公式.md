# 基本积分公式

## 类型判定
连接模型 — 输入被积函数 $f(x)$，输出原函数族 $F(x)+C$，是求导的逆映射。

## 是什么
基本积分公式（Basic Integration Formulas）是五类基本初等函数积分规则的完整集合——不定积分的"乘法口诀表"。每个公式都可通过**对右边求导**验证：$(F(x)+C)' = f(x)$。

## 正例
1. 验证：$\int x^3 dx = \frac{x^4}{4} + C$，求导 $(\frac{x^4}{4})' = x^3$ ✓
2. 线性组合：$\int (3x^2 + \frac{1}{x})dx = x^3 + \ln\lvert x\rvert + C$

## 反例/边界
1. **幂函数的例外**：$\int x^{-1} dx = \ln\lvert x\rvert + C$，不是 $\frac{x^0}{0}$！
2. **绝对值不能丢**：$\int \frac{1}{x} dx = \ln\lvert x\rvert + C$，不能写成 $\ln x + C$
3. **$\tan x$ 不在基本表中**：需凑微分推导

## 基本积分公式全表（21条）

### 常数与幂函数
1. $\displaystyle\int k \, dx = kx + C$
   → 验证：$(kx + C)' = k$

2. $\displaystyle\int x^\alpha \, dx = \frac{x^{\alpha+1}}{\alpha+1} + C \quad (\alpha \neq -1)$
   → 验证：$(\frac{x^{\alpha+1}}{\alpha+1})' = x^\alpha$

3. $\displaystyle\int \frac{1}{x} \, dx = \ln\lvert x\rvert + C$
   → 验证：$(\ln\lvert x\rvert)' = \frac{1}{x}$

### 指数函数
4. $\displaystyle\int e^x \, dx = e^x + C$
   → 验证：$(e^x)' = e^x$

5. $\displaystyle\int a^x \, dx = \frac{a^x}{\ln a} + C$
   → 验证：$(\frac{a^x}{\ln a})' = a^x$

### 三角函数（基础六条）
6. $\displaystyle\int \sin x \, dx = -\cos x + C$
   → 验证：$(-\cos x)' = \sin x$

7. $\displaystyle\int \cos x \, dx = \sin x + C$
   → 验证：$(\sin x)' = \cos x$

8. $\displaystyle\int \sec^2 x \, dx = \tan x + C$
   → 验证：$(\tan x)' = \sec^2 x$

9. $\displaystyle\int \csc^2 x \, dx = -\cot x + C$
   → 验证：$(-\cot x)' = \csc^2 x$

10. $\displaystyle\int \sec x \tan x \, dx = \sec x + C$
    → 验证：$(\sec x)' = \sec x \tan x$

11. $\displaystyle\int \csc x \cot x \, dx = -\csc x + C$
    → 验证：$(-\csc x)' = \csc x \cot x$

### 三角函数（进阶四条）
12. $\displaystyle\int \sec x \, dx = \ln\lvert\sec x + \tan x\rvert + C$
    → 验证：对右边求导得 $\sec x$

13. $\displaystyle\int \csc x \, dx = \ln\lvert\csc x - \cot x\rvert + C$
    → 验证：对右边求导得 $\csc x$

14. $\displaystyle\int \tan x \, dx = -\ln\lvert\cos x\rvert + C$
    → 推导：$\int \frac{\sin x}{\cos x}dx = -\int \frac{d(\cos x)}{\cos x}$

15. $\displaystyle\int \cot x \, dx = \ln\lvert\sin x\rvert + C$
    → 推导：$\int \frac{\cos x}{\sin x}dx = \int \frac{d(\sin x)}{\sin x}$

### 反三角函数与广义形式
16. $\displaystyle\int \frac{1}{\sqrt{1-x^2}} \, dx = \arcsin x + C$
    → 验证：$(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$

17. $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}} \, dx = \arcsin\frac{x}{a} + C$
    → 广义 arcsin

18. $\displaystyle\int \frac{1}{1+x^2} \, dx = \arctan x + C$
    → 验证：$(\arctan x)' = \frac{1}{1+x^2}$

19. $\displaystyle\int \frac{1}{a^2+x^2} \, dx = \frac{1}{a}\arctan\frac{x}{a} + C$
    → 广义 arctan

### 有理函数积分
20. $\displaystyle\int \frac{1}{x^2-a^2} \, dx = \frac{1}{2a}\ln\left\lvert\frac{x-a}{x+a}\right\rvert + C$
    → 有理函数分解

21. $\displaystyle\int \frac{1}{a^2-x^2} \, dx = \frac{1}{2a}\ln\left\lvert\frac{a+x}{a-x}\right\rvert + C$
    → 有理函数分解

## 记忆方法
1. 看到 $\int f(x) dx$，问"谁的导数等于 $f(x)$？"
2. 基本公式 = 基本求导公式的逆序列表
3. **黄金法则**：对积分结果求导 = 被积函数 ✓

## 生活类比
基本积分公式像**乘法口诀表倒过来背**——求导从左往右看，积分从右往左看。
