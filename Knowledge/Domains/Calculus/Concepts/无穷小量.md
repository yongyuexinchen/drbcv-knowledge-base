# 无穷小量

## 类型判定
定义型 — 明确术语的数学定义

## 是什么
极限为 0 的变量称为无穷小量。设 $\alpha = \alpha(x)$（或 $\alpha_n$），若 $\lim \alpha = 0$，则称 $\alpha$ 为无穷小量。如当 $x \to 0$ 时，$\sin x$、$x$、$1-\cos x$ 等都是无穷小量。

**重要澄清**：无穷小量是一个变量（函数或数列），不是一个"非常小的数"。0 是唯一可视为无穷小的常数。

## 输入-输出空间
- **输入**: 趋于 0 的变量 $\alpha, \beta$
- **输出**: 比值极限（判断等价性）或等价替换结果
- **映射关系**: 从无穷小量到其趋零速度的比较

## 正例（至少2个）
1. **场景1**: $x \to 0$ 时，$x$、$\sin x$、$\ln(1+x)$ 都是无穷小量
2. **场景2**: $n \to \infty$ 时，$\frac{1}{n}$、$\frac{1}{n^2}$、$q^n\;(|q| < 1)$ 都是无穷小量

## 反例/边界（至少1个）
1. **常见误解/边界**: 无穷小量不是"一个很小的数"（如 0.0000001），而是一个趋于 0 的**动态过程**。常数 0 是唯一可作为无穷小的数（因为 $\lim 0 = 0$）。另外，无穷多个无穷小量的和不一定仍是无穷小量——例如 $n$ 个 $\frac{1}{n}$ 相加，虽然每个 $\frac{1}{n} \to 0$，但 $n \cdot \frac{1}{n} = 1 \to 1 \neq 0$。

## 详细解释
无穷小乘有界函数仍是无穷小。

### 推导过程（★ 数学卡必须）
**无穷小量的阶的比较**：设 $\alpha, \beta$ 为同一趋近过程下的无穷小量（$\alpha \neq 0$ 在充分接近时）：

$$\lim \frac{\beta}{\alpha} =
\begin{cases}
0 & \text{称 } \beta \text{ 是比 } \alpha \text{ 高阶的无穷小，记 } \beta = o(\alpha) \\
c \neq 0 & \text{称 } \beta \text{ 与 } \alpha \text{ 同阶无穷小} \\
1 & \text{称 } \beta \text{ 与 } \alpha \text{ 等价无穷小，记 } \beta \sim \alpha \\
\infty & \text{称 } \beta \text{ 是比 } \alpha \text{ 低阶的无穷小}
\end{cases}$$

若 $\lim \frac{\beta}{\alpha^k} = c \neq 0$，则称 $\beta$ 是关于 $\alpha$ 的 k 阶无穷小。

**关键性质推导**：
1. **有界乘无穷小**：若 $\alpha$ 为无穷小，$f(x)$ 有界（$|f(x)| \leq M$），则 $\alpha \cdot f$ 也是无穷小。证：$|\alpha \cdot f| \leq M|\alpha| \to 0$（由夹逼定理）。

2. **无穷小的等价关系**：$\alpha \sim \beta \iff \alpha - \beta = o(\alpha)$（等价无穷小相差高阶无穷小）。

3. **有限个无穷小的和/积**仍为无穷小（但无限个不一定）。

### 重要推论（★ 数学卡必须）
1. **阶的比较是求极限的核心**：0/0 型未定式的本质是比较分子和分母无穷小量的"阶"（趋于 0 的速度）。阶高者趋于 0 更快，在比式中占据优势。

2. **同阶无穷小可互代**：若 $\alpha \sim \alpha'$，$\beta \sim \beta'$，且 $\lim \frac{\beta'}{\alpha'}$ 存在，则 $\lim \frac{\beta}{\alpha} = \lim \frac{\beta'}{\alpha'}$（等价无穷小代换定理）。

3. **等价关系是等价代换的理论基础**：在乘除因子中，等价无穷小可以互相替换而不改变极限。

4. **常见无穷小的阶**（$x \to 0$）：
   - 1阶：$x$, $\sin x$, $\tan x$, $\arcsin x$, $\arctan x$, $\ln(1+x)$, $e^x-1$
   - 2阶：$1-\cos x$（$\sim \frac{1}{2}x^2$）, $x - \ln(1+x)$（$\sim \frac{1}{2}x^2$）
   - 3阶：$x - \sin x$（$\sim \frac{1}{6}x^3$）, $\tan x - x$（$\sim \frac{1}{3}x^3$）

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：比较当 $x \to 0$ 时，$1 - \cos x$ 与 $x$ 的无穷小阶数。
**解**：
$$\lim_{x \to 0} \frac{1 - \cos x}{x} = \lim_{x \to 0} \frac{2\sin^2(x/2)}{x} = \lim_{x \to 0} \frac{2 \cdot (x/2)^2}{x} = \lim_{x \to 0} \frac{x}{2} = 0$$
故 $1 - \cos x$ 是比 $x$ 高阶的无穷小。再求其阶数：
$$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \lim_{x \to 0} \frac{\frac{1}{2}x^2}{x^2} = \frac{1}{2}$$
故 $1 - \cos x$ 是关于 $x$ 的 2 阶无穷小。

**例题2**
**题目**：判断 $x \to 0$ 时，$\sqrt{1+x} - 1$ 是关于 $x$ 的几阶无穷小。
**解**：
$$\lim_{x \to 0} \frac{\sqrt{1+x} - 1}{x} = \lim_{x \to 0} \frac{(1+x) - 1}{x(\sqrt{1+x}+1)} = \lim_{x \to 0} \frac{1}{\sqrt{1+x}+1} = \frac{1}{2}$$
故 $\sqrt{1+x} - 1$ 是关于 $x$ 的 1 阶无穷小，且 $\sqrt{1+x} - 1 \sim \frac{1}{2}x$。

## 类比

### 一句话比喻
无穷小量就像水位下降——它不断逼近零，而不是已经为零。高阶无穷小则像"下降得比别人更快的水位"。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 无穷小量 $\alpha \to 0$ | 容器中的水逐渐排空（水位 → 0） |
| 高阶无穷小 $\beta = o(\alpha)$ | A 容器排水速度远超 B 容器 |
| 等价无穷小 $\alpha \sim \beta$ | 两个容器排水速度几乎一致 |
| 无穷小乘有界仍为无穷小 | 微小位移 × 有限速度 = 仍然微小 |
