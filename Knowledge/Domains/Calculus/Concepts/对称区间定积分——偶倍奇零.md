# 对称区间定积分——偶倍奇零

## 类型判定
关联型 — 定理/命题，揭示条件与结论的逻辑关系

## 是什么
若 $f(x)$ 在 $[-a, a]$ 上可积，则：
(1) 若 $f$ 为奇函数（$f(-x) = -f(x)$），则 $\int_{-a}^a f(x) \,dx = 0$
(2) 若 $f$ 为偶函数（$f(-x) = f(x)$），则 $\int_{-a}^a f(x) \,dx = 2\int_0^a f(x) \,dx$

## 输入-输出空间
- **输入**: 对称区间 $[-a,a]$ 上的可积函数 $f(x)$
- **输出**: 简化后的积分值（奇函数直接为 0，偶函数只需算半个区间）
- **映射关系**: 奇偶性 → 简化策略

## 正例（至少2个）
1. **场景1**: $\int_{-1}^1 x e^{-x^2} \,dx = 0$（奇函数）
2. **场景2**: $\int_{-1}^1 (x^2)^{3/2} \,dx = 2\int_0^1 x^3 \,dx = \frac{1}{2}$（注意 $\sqrt{x^2}=\lvertx\rvert$）

## 反例/边界（至少1个）
1. **常见误解/边界**: 误判：$(x^2)^{3/2} = \lvertx\rvert^3$ 是偶函数，不是奇函数。$\sqrt{x^2}=\lvertx\rvert$ 而非 $x$。

## 详细解释
偶倍奇零非常好用，但要注意算术平方根、偶次方根开出来是绝对值。遇到 $\sqrt{x^2}$、$(x^2)^{1/2}$ 要小心。

### 推导过程（★ 数学卡必须）
**奇函数情况的证明**：

将积分拆分为正负半轴之和：
$$\int_{-a}^a f(x)\,dx = \int_{-a}^0 f(x)\,dx + \int_0^a f(x)\,dx$$

对第一项作换元 $x = -t$，则 $\,dx = -\,dt$，$x:-a \to 0$ 对应 $t:a \to 0$：

$$\int_{-a}^0 f(x)\,dx = \int_a^0 f(-t) (-\,dt) = \int_0^a f(-t)\,dt$$

若 $f$ 为奇函数（$f(-t) = -f(t)$），则：

$$\int_{-a}^a f(x)\,dx = \int_0^a f(-t)\,dt + \int_0^a f(x)\,dx = \int_0^a [-f(t)]\,dt + \int_0^a f(x)\,dx = -\int_0^a f + \int_0^a f = 0$$

**偶函数情况的证明**：

若 $f$ 为偶函数（$f(-t) = f(t)$），同理：

$$\int_{-a}^a f(x)\,dx = \int_0^a f(-t)\,dt + \int_0^a f(x)\,dx = \int_0^a f(t)\,dt + \int_0^a f(x)\,dx = 2\int_0^a f(x)\,dx$$

### 重要推论（★ 数学卡必须）
1. **奇偶乘积的奇偶性**：奇 × 奇 = 偶，偶 × 偶 = 偶，奇 × 偶 = 奇。判断复杂被积函数时可逐因子分析。
2. **线性组合中的分离**：若被积函数包含奇函数项，可利用积分线性性单独消去奇函数部分（$\int_{-a}^a [g(x)+h(x)]\,dx = \int_{-a}^a g + \int_{-a}^a h$）。
3. **绝对值陷阱**：偶次方根开出来是绝对值，如 $\sqrt{x^2} = \lvertx\rvert$（偶函数）、$(x^2)^{3/2} = \lvertx\rvert^3$（偶函数），不能简单约分。
4. **复合函数的奇偶性判断**：若 $g$ 是偶函数，$f \circ g$ 是偶函数；若 $g$ 是奇函数，$f \circ g$ 的奇偶性等于 $f$ 的奇偶性。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：$\int_{-1}^1 x e^{-x^2} \,dx$（奇函数）

**解**：判断被积函数的奇偶性。$f(x) = x e^{-x^2}$。

计算 $f(-x) = (-x) e^{-(-x)^2} = -x e^{-x^2} = -f(x)$，故 $f$ 是奇函数。

积分区间 $[-1,1]$ 为对称区间，由"奇零"：

$$\int_{-1}^1 x e^{-x^2} \,dx = 0$$

无需计算原函数即可得到结果。

**例题2**
**题目**：$\int_{-1}^1 (x^2)^{3/2} \,dx$（注意 $\sqrt{x^2}=\lvertx\rvert$）

**解**：先化简被积函数。$(x^2)^{3/2} = (\lvertx\rvert^2)^{3/2} = \lvertx\rvert^3$，或理解为 $(\sqrt{x^2})^3 = \lvertx\rvert^3$。

判断奇偶性：$g(x) = \lvertx\rvert^3$，$g(-x) = \lvert-x\rvert^3 = \lvertx\rvert^3 = g(x)$，是偶函数。

由"偶倍"：

$$\int_{-1}^1 (x^2)^{3/2} \,dx = \int_{-1}^1 \lvertx\rvert^3\,dx = 2\int_0^1 x^3\,dx$$

$$= 2 \cdot \left[\frac{x^4}{4}\right]_0^1 = 2 \cdot \frac{1}{4} = \frac{1}{2}$$

警示：若错误地化简为 $(x^2)^{3/2} = x^3$ 会误判为奇函数而得 0，这是常见的严重错误。

## 类比

### 一句话比喻
偶倍奇零就像秋千——奇函数像荡秋千，两边一高一低刚好抵消回到原点；偶函数像跷跷板两端的镜像，算一头再乘二即可。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 奇函数 $\int_{-a}^a = 0$ | 往返运动：去程位移 + 回程位移 = 0 |
| 偶函数 $\int_{-a}^a = 2\int_0^a$ | 对称结构：左右受力相同，总功 = 2 × 半边功 |
| 换元 $x=-t$ | 将负半轴折叠到正半轴观察 |
