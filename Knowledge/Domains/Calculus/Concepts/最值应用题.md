# 最值应用题 (Applied Optimization Problems)

## 类型判定
程序型 — 题型分类/解题策略

## 是什么
利用导数求实际应用问题中的最大值或最小值。步骤：(1) 建立目标函数（选择合适变量）；(2) 求导数找驻点；(3) 判定极值并确定最值。

## 输入-输出空间
- **输入**: 实际问题描述及约束条件
- **输出**: 目标函数的最大值/最小值及对应变量值
- **映射关系**: 实际问题 $\to$ 目标函数 $\to$ 驻点 $\to$ 最值

## 正例（至少2个）
1. **场景1**: 半径为 $R$ 的球中内接直圆锥体积最大的问题
2. **场景2**: 一块边长为 $a$ 的正方形铁皮，四角各剪去相同小正方形后折成无盖方盒，求容积最大时剪去正方形的边长

## 反例/边界（至少1个）
1. **常见误解/边界**: 目标函数的驻点不一定是最值点。例如 $f(x)=x^3$ 在 $x=0$ 处 $f'(0)=0$，但该点既非最大值也非最小值。此外，开区间上的连续函数可能没有最值（如 $f(x)=x$ 在 $(0,1)$ 上），最值问题通常需要闭区间或驻点唯一等条件保证。

## 详细解释
关键步骤是建立目标函数，变量选择直接影响计算复杂度。应尽量选择使函数形式简单的变量，避免过于复杂的求导运算。

### 推导过程（★ 数学卡必须）
最值应用题的一般解题框架：

**第一步：建模**（建立目标函数）
1. 读懂题目，明确求哪个量的最值（目标量）
2. 选择自变量（通常选"可变化的量"，如长度、角度等）
3. 将目标量表示为自变量的函数 $y=f(x)$
4. 确定自变量的取值范围（定义域）

**第二步：求导找驻点**
$$f'(x) = 0 \quad \Rightarrow \quad \text{驻点 } x_0$$

**第三步：判定极值**
- 用第一充分条件：看 $f'(x)$ 在 $x_0$ 左右是否变号
- 或用第二充分条件：看 $f''(x_0)$ 的正负

**第四步：确定最值**
- 若驻点唯一且定义域为开区间，驻点即为最值点
- 若定义域为闭区间，比较驻点函数值与端点函数值

### 重要推论（★ 数学卡必须）
1. **驻点唯一性定理**：若目标函数在开区间上只有一个驻点，且实际问题确实存在最值，则该驻点必为最值点（不需要再验证）
2. **变量选择原则**：选择使目标函数形式最简单的变量
3. **单位一致性**：建模时注意各量单位统一

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：半径为 $R$ 的球中内接直圆锥，求体积最大时圆锥的高。
**解**：
设圆锥高为 $h$（$0<h<2R$），底面半径 $r$。

由球的截面几何关系：$r^2 + (h-R)^2 = R^2$，即 $r^2 = R^2 - (h-R)^2 = 2Rh - h^2$

圆锥体积：$V = \frac{\pi r^2 h}{3} = \frac{\pi h(2Rh-h^2)}{3} = \frac{\pi}{3}(2Rh^2 - h^3)$

求导：$V'(h) = \frac{\pi}{3}(4Rh - 3h^2) = \frac{\pi h}{3}(4R - 3h)$

驻点：$h=0$（舍去）或 $h=\frac{4R}{3}$

$V''(h) = \frac{\pi}{3}(4R - 6h)$，$V''\left(\frac{4R}{3}\right) = \frac{\pi}{3}\left(4R - 8R\right) = -\frac{4\pi R}{3} < 0$

故 $h=\frac{4R}{3}$ 时圆锥体积最大。最大体积 $V_{\max} = \frac{\pi}{3}\cdot\frac{4R}{3}\cdot 2R\cdot\frac{4R}{3} - \frac{\pi}{3}\left(\frac{4R}{3}\right)^3 = \frac{32\pi R^3}{81}$

**例题2**
**题目**：边长为 $a$ 的正方形铁皮，四角各剪去边长为 $x$ 的小正方形后折成无盖方盒，求 $x$ 为何值时容积最大。
**解**：
折成方盒后：底面边长 $= a-2x$，高 $= x$，容积 $V = x(a-2x)^2$，$x \in (0, a/2)$

$V'(x) = (a-2x)^2 + x\cdot 2(a-2x)(-2) = (a-2x)^2 - 4x(a-2x) = (a-2x)(a-2x-4x) = (a-2x)(a-6x)$

驻点：$x = a/2$（舍去，超出定义域）或 $x = a/6$

$V''(x) = -2(a-6x) - 6(a-2x)$，$V''(a/6) = -2(a-a) - 6(a - a/3) = -6\cdot\frac{2a}{3} = -4a < 0$

故 $x = a/6$ 时容积最大，$V_{\max} = \frac{a}{6}\cdot\left(a-\frac{a}{3}\right)^2 = \frac{a}{6}\cdot\frac{4a^2}{9} = \frac{2a^3}{27}$

## 类比

### 一句话比喻
**最值应用题像"找最佳配方"——你有原材料（约束条件），想做出最好的产品（最大值），就得试各种配方（变量），找到那个刚好让增长率归零的配方（驻点）。**

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 目标函数 | 产品质量评分 |
| 驻点 | 配方刚好不能再改进的那一刻 |
| 约束条件 | 原材料用量限制 |
| 最值 | 最佳配方对应的最高评分 |
