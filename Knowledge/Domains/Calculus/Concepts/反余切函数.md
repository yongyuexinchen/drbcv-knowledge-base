# 反余切函数 $\operatorname{arccot} X$

## 类型判定
判别型 — 区分/定义概念，建立判断标准

## 是什么
$Y = \operatorname{arccot} X$ 是 $Y = \cot X$ 在 $X \in (0, \pi)$（主值区间）上的反函数。输入余切值 $X \in \mathbb{R}$，输出对应弧度 $Y \in (0, \pi)$。

## 输入-输出空间
- **输入**: $X \in \mathbb{R}$（全体实数，余切值）
- **输出**: $Y \in (0, \pi)$（开区间，对应弧度）
- **映射关系**: $\operatorname{arccot}: \mathbb{R} \to (0,\pi)$，余切值 $\mapsto$ 角度

## 正例（至少2个）
1. **场景1**: $\operatorname{arccot} 1 = \frac{\pi}{4}$（因为 $\cot \frac{\pi}{4} = 1$ 且 $\frac{\pi}{4} \in (0,\pi)$）
2. **场景2**: $\operatorname{arccot} \sqrt{3} = \frac{\pi}{6}$（因为 $\cot \frac{\pi}{6} = \sqrt{3}$ 且 $\frac{\pi}{6} \in (0,\pi)$）

## 反例/边界（至少1个）
1. **常见误解/边界**: 
   - **值域为开区间**：$\operatorname{arccot} x$ 的值域是 $(0,\pi)$ 开区间，$0$ 和 $\pi$ 永远取不到。$\lim_{x\to +\infty} \operatorname{arccot} x = 0$，$\lim_{x\to -\infty} \operatorname{arccot} x = \pi$。
   - **单调递减**：$\operatorname{arccot} x$ 严格单调递减（导数恒负）。这与 $\arctan$ 的单调递增相反。
   - **定义域为全体实数**：与 $\arctan$ 相同，$\operatorname{arccot} x$ 对任意实数都有定义。
   - **两种主值定义**：部分教材定义 $\operatorname{arccot}$ 的值域为 $(-\frac{\pi}{2}, 0) \cup (0, \frac{\pi}{2}]$，导致 $\operatorname{arccot} 0$ 有间断。本文采用 $(0,\pi)$ 定义（更常见于高等数学教材）。

## 详细解释
反余切的出场率远低于反正切。主值区间为 $(0, \pi)$（开区间）。

### 推导过程（★ 数学卡必须）
**反函数定义推导**：

$\cot x = \frac{\cos x}{\sin x}$ 在 $(0, \pi)$ 上严格单调递减（$\cot' x = -\csc^2 x < 0$），值域为 $\mathbb{R}$。

$\operatorname{arccot} y$ 定义为：唯一的 $x \in (0,\pi)$ 使 $\cot x = y$。

**导数推导**（反函数求导法则）：

设 $y = \operatorname{arccot} x$，则 $x = \cot y$，$y \in (0,\pi)$。

$$\frac{\,dy}{\,dx} = \frac{1}{\frac{\,dx}{\,dy}} = \frac{1}{-\csc^2 y}$$

由恒等式 $\csc^2 y = 1 + \cot^2 y = 1 + x^2$：

$$\boxed{\frac{d}{\,dx}\operatorname{arccot} x = -\frac{1}{1+x^2}}$$

与 $\arctan$ 的导数 $\frac{1}{1+x^2}$ 只差一个负号。

**与 $\arctan$ 的关系**（定义一，值域 $(0,\pi)$）：

$$\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$$

**重要极限**：$\lim_{x\to +\infty} \operatorname{arccot} x = 0$，$\lim_{x\to -\infty} \operatorname{arccot} x = \pi$

### 重要推论（★ 数学卡必须）
1. **恒等式**：
   - $\cot(\operatorname{arccot} x) = x$（$x \in \mathbb{R}$）
   - $\operatorname{arccot}(\cot x) = x$（仅当 $x \in (0,\pi)$）
2. **单调性**：$\operatorname{arccot} x$ 严格单调递减（导数 $-\frac{1}{1+x^2} < 0$）
3. **与 $\arctan$ 的关系**：$\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$
4. **常见特殊值**：
   - $\operatorname{arccot} 1 = \frac{\pi}{4}$
   - $\operatorname{arccot} 0 = \frac{\pi}{2}$
   - $\operatorname{arccot} \sqrt{3} = \frac{\pi}{6}$

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：求 $\operatorname{arccot} 1$ 的值。

**解**：在 $(0,\pi)$ 上，$\cot(\frac{\pi}{4}) = \frac{\cos(\pi/4)}{\sin(\pi/4)} = 1$。

$$\operatorname{arccot} 1 = \frac{\pi}{4}$$

**例题2**
**题目**：求 $\operatorname{arccot}(-1)$ 的值。

**解**：在 $(0,\pi)$ 上，$\cot(\frac{3\pi}{4}) = \frac{\cos(3\pi/4)}{\sin(3\pi/4)} = \frac{-\sqrt{2}/2}{\sqrt{2}/2} = -1$。

$$\operatorname{arccot}(-1) = \frac{3\pi}{4}$$

## 类比

### 一句话比喻
$\operatorname{arccot}$ 就像从旗杆影子的"余切比"（影子长度与旗杆高度的比值）反推太阳的角度——影子越短对应的角度越接近 $\frac{\pi}{2}$（太阳在头顶），影子越长角度越接近 $0$（太阳在地平线）。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| $\operatorname{arccot} x$ | 已知投影比（底边/高）求仰角 |
| 值域 $(0,\pi)$ | 仰角只能在 $0°$ 到 $180°$ 之间 |
| 导数 $-\frac{1}{1+x^2}$ | 负号反映：比值增大时角度减小 |
| $\arctan x + \operatorname{arccot} x = \frac{\pi}{2}$ | $\tan\theta$ 和 $\cot\theta$ 互为倒数的角度互余 |
