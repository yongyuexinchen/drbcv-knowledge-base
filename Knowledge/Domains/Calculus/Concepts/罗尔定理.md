# 罗尔定理 (Rolle's Theorem)

## 是什么

如果函数 f(x) 在闭区间 [a,b] 上连续，在开区间 (a,b) 内可导，且 f(a) = f(b)，则至少存在一点 ξ ∈ (a,b)，使得 f'(ξ) = 0。


## 定义/定理

若函数 $f(x)$ 满足以下**三个条件**：

1. **闭区间连续**：$f(x) \in C[a,b]$
2. **开区间可导**：$f(x)$ 在 $(a,b)$ 内可导
3. **端点值相等**：$f(a) = f(b)$

则至少存在一点 $\xi \in (a,b)$，使得：

$$
f'(\xi) = 0
$$

> **几何意义**：在区间 $[a,b]$ 上，曲线上至少存在一点的**切线平行于 $x$ 轴**（切线水平）。

---

## 证明思路

**核心思想**：利用**费马引理**，证明最值在区间内部取得。

1. **闭区间上连续** $\Rightarrow$ 存在最大值 $M$ 和最小值 $m$
2. **分类讨论**：
   - **情况1**：$M = m$ $\Rightarrow$ $f(x)$ 为常数，任意点导数均为 $0$
   - **情况2**：$M > m$ $\Rightarrow$ 因 $f(a)=f(b)$，$M$ 和 $m$ 中至少有一个在**开区间内部**取得
3. 内部取得最值的点 $\Rightarrow$ **极值点**（因为内部最值必为极值）
4. 该点可导且为极值 $\xrightarrow{\text{费马引理}}$ 该点导数为 $0$

## 核心应用：构造辅助函数

### 模式识别

结论形如"存在 $\xi$ 使 $f'(\xi)$ 与 $f(\xi)$ 的关系式 $=0$"：

| 结论形式 | 辅助函数构造法 |
|---------|---------------|
| $\xi f'(\xi) + f(\xi) = 0$ | $F(x) = x f(x)$ |
| $f'(\xi) + k f(\xi) = 0$ | $F(x) = e^{kx} f(x)$ |
| $f'(\xi) + g'(\xi)f(\xi)=0$ | $F(x) = e^{g(x)} f(x)$ |
| $f'(\xi)(b-\xi) - f(\xi) + f(a)=0$ | $F(x) = (f(x)-f(a))(b-x)$ |
| $\dfrac{f'(\xi)}{g'(\xi)} = \dfrac{f(b)-f(a)}{g(b)-g(a)}$ | $F(x) = (f(x)-f(a))(g(b)-g(a)) - (f(b)-f(a))(g(x)-g(a))$ |

### 通用方法——分析法

1. 将结论移项至等号一侧，化为 $=0$ 形式
2. 将 $\xi$ 改写为 $x$，观察左边是否为某函数 $F(x)$ 的导数
3. 若能找到 $F(x)$，验证 $F(a)=F(b)$，使用罗尔定理

---

## 例：双中值问题

若题中要求**两个不同点** $\xi, \eta$，且结论对称：

1. 在区间内找一个**中间点 $c$**
2. 分别在 $[a,c]$ 和 $[c,b]$ 上使用拉格朗日定理
3. 各自得到 $\xi$ 和 $\eta$，按题目要求运算即可

## 要点注意

| 要点 | 说明 |
|------|------|
| **端点值相等** | 这是罗尔区别于其他中值定理的核心条件 |
| **开区间可导** | 确保内部极值点可导，才能用费马引理 |
| **闭区间连续** | 保证最值存在 |
| **最值在内部** | 因端点值相等，最大值或最小值必有一个在内部 |

## 类比

### 一句话比喻
**罗尔定理像两人登山——从同一高度出发，又回到同一高度，中间必有一刻你站在水平平台上（速度为零的转折点）。** 无论路线多曲折，起点终点等高意味着中间至少有一个"坡顶"或"坡底"，在那里地面是水平的。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| f(a)=f(b) | 起点终点等高 |
| f'(ξ)=0 | 途中某刻速度为零（折返瞬间） |
| ξ ∈ (a,b) | 折返点在起点终点之间 |

## 正例
**例1**：$f(x)=x(x-1)$ 在 $[0,1]$ 上满足 $f(0)=f(1)=0$，存在 $\xi=\frac{1}{2}$ 使 $f'(\xi)=0$。
**例2**：$f(x)=\sin x$ 在 $[0,\pi]$ 上满足 $f(0)=f(\pi)=0$，存在 $\xi=\frac{\pi}{2}$ 使 $f'(\xi)=0$。
