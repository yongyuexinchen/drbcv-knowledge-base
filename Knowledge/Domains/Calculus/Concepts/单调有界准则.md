# 单调有界准则

## 类型判定
关联型 — 定理/命题，揭示条件与结论的逻辑关系

## 是什么
极限的两大存在准则之一。若数列 $\{x_n\}$ 单调递增且有上界，或单调递减且有下界，则数列极限存在。

**严格表述**：
- 若 $\{x_n\}$ 单调递增（$x_1 \leq x_2 \leq \cdots$）且有上界（$\exists M$ 使 $x_n \leq M$），则 $\lim x_n$ 存在且 $= \sup\{x_n\}$
- 若 $\{x_n\}$ 单调递减（$x_1 \geq x_2 \geq \cdots$）且有下界（$\exists m$ 使 $x_n \geq m$），则 $\lim x_n$ 存在且 $= \inf\{x_n\}$

**关键理解**：单调有界推极限存在，但不直接告诉你极限是多少。需要解方程 $\lim x_{n+1} = f(\lim x_n)$ 来求。

## 输入-输出空间
- **输入**: 满足单调性和有界性的数列 $\{x_n\}$
- **输出**: 数列收敛的结论及可求得的极限值
- **映射关系**: 单调性 + 有界性 → 极限存在 → 解方程求极限值

## 正例（至少2个）
1. **场景1**: $x_{n+1} = \sqrt{2 + x_n}$，$x_1 = \sqrt{2}$。易证单调增且有上界 2，极限存在且 $L = 2$。
2. **场景2**: $x_n = (1 + \frac{1}{n})^n$。可证单调增且有上界 3，故极限存在，即为自然常数 $e$。

## 反例/边界（至少1个）
1. **常见误解/边界**: 单调但无界则发散。如 $x_n = n$（单调递增但无上界，极限为 $+\infty$，极限不存在）。又如 $x_n = -n$（单调递减但无下界，极限为 $-\infty$）。再如 $x_n = (-1)^n n$（不单调，也不有界，发散）。所以两个条件缺一不可。

## 详细解释
与夹逼定理并列的极限存在准则。夹逼定理通常用于处理 N 项和、N 次根号等形式，而单调有界准则常用于处理递推定义的数列。

### 推导过程（★ 数学卡必须）
单调有界准则的理论基础是实数系的**确界原理**（实数完备性）。推导如下：

设 $\{x_n\}$ 单调递增且有上界。由确界原理，$S = \{x_n \mid n \in \mathbb{N}^+\}$ 有上确界，记 $A = \sup\{x_n\}$。

用 ε-N 定义验证 $A$ 即为极限：
- $\forall \varepsilon > 0$，由确界定义，存在某 $x_N$ 使 $x_N > A - \varepsilon$
- 又 $\{x_n\}$ 单调递增，当 $n > N$ 时 $x_n \geq x_N > A - \varepsilon$
- 同时 $x_n \leq A$（A 是上界），故 $x_n < A + \varepsilon$
- 综上，$A - \varepsilon < x_n < A + \varepsilon$，即 $|x_n - A| < \varepsilon$

由 ε-N 定义，$\lim x_n = A$。单调递减有下界的情况对称可证。

### 重要推论（★ 数学卡必须）
1. **极限值求法**：若 $\{x_n\}$ 满足 $x_{n+1} = f(x_n)$ 且单调有界，则 $\lim x_n = L$ 满足方程 $L = f(L)$（需配合连续性条件）。

2. **常见题型模式**：
   - 给定 $x_{n+1} = \sqrt{a + x_n}$（$a > 0$）：单调增有上界，$L = \frac{1+\sqrt{1+4a}}{2}$
   - 给定 $x_{n+1} = \frac{1}{2}(x_n + \frac{a}{x_n})$（$a > 0$）：单调减有下界，$L = \sqrt{a}$（求平方根的牛顿法）

3. **与夹逼定理的对比**：两者同属极限存在准则，但适用场景不同——夹逼定理需要构造上下界，单调有界准则需要验证单调性和有界性（通常用数学归纳法）。

## 经典例题（★ 至少2题，含完整解答）
**例题1**
**题目**：设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2 + x_n}$，证明 $\{x_n\}$ 收敛并求极限。
**解**：
**第一步：证有界**。用数学归纳法：
- $x_1 = \sqrt{2} < 2$。假设 $x_k < 2$，则 $x_{k+1} = \sqrt{2 + x_k} < \sqrt{2 + 2} = 2$。故 $\{x_n\}$ 有上界 2。

**第二步：证单调增**。
$$x_{n+1}^2 - x_n^2 = (2 + x_n) - x_n^2 = -(x_n^2 - x_n - 2) = -(x_n - 2)(x_n + 1)$$
由于 $x_n \in [0, 2]$，$x_n - 2 \leq 0$，$x_n + 1 > 0$，故 $x_{n+1}^2 - x_n^2 \geq 0$，即 $x_{n+1} \geq x_n$。

**第三步：求极限**。由单调有界准则，极限存在。设 $\lim x_n = L$，对递推关系两边取极限：
$$L = \sqrt{2 + L} \quad \Rightarrow \quad L^2 = 2 + L \quad \Rightarrow \quad L^2 - L - 2 = 0$$
解得 $L = 2$ 或 $L = -1$。因 $x_n \geq \sqrt{2} > 0$，故 $L = 2$。

**例题2**
**题目**：证明数列 $x_n = \left(1 + \frac{1}{n}\right)^n$ 单调递增且有上界。
**解**：
**有界性**：利用二项式展开，
$$x_n = \sum_{k=0}^n \binom{n}{k} \frac{1}{n^k} = \sum_{k=0}^n \frac{n(n-1)\cdots(n-k+1)}{k! n^k} \leq \sum_{k=0}^n \frac{1}{k!} < \sum_{k=0}^\infty \frac{1}{k!} = e < 3$$
故有上界 3。

**单调性**：通过证明 $\frac{x_{n+1}}{x_n} > 1$ 可得 $\{x_n\}$ 单调递增（具体证明涉及较复杂的代数变形，在此略）。由单调有界准则，极限存在，即为自然常数 $e$。

## 类比

### 一句话比喻
单调有界数列就像困在水缸里的乌龟拼命往上爬——头顶有盖子（上界），只能一直往上（单调增），最终必然停在盖子的位置。

### 物理映射
| 数学对象 | 物理类比 |
|---------|---------|
| 单调递增 | 物体持续向上运动（只升不降） |
| 有上界 | 头顶有天花板阻挡，无法突破 |
| 极限存在 | 物体最终停止在天花板处 |
| 极限值 = 上确界 | 最终停在刚好碰到天花板的位置 |
