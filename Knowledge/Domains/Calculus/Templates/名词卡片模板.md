# 数学概念卡模板（Calculus vault 专用）

## 模板使用说明

Calculus vault 里的概念卡，核心任务是**把“会做题”变成“会迁移”**：

1. 每个公式/定理必须回答：**从哪里来？能推什么？**
2. 必须标注**推导链**和**关系链**，用 `[[wikilink]]` 链接相关概念卡
3. 例题≥2个，含完整解答
4. 类比必须包含：**一句话比喻** + **物理映射表**

## 公式推导链示例

```
[[定积分的换元法]]
    ↓ 推出
[[区间再现公式]]（x → a+b-x）
    ↓ 与 [[三角函数的积分]] 结合
[[分部积分法]]
    ↓ 得到递推式
[[点火公式(Wallis公式)]]
```

在每张数学概念卡中，**必须明确写出它在推导链中的位置**：

| 关系类型 | 写法 | 例子 |
|---------|------|------|
| 由谁推导 | 由 [[区间再现公式]] + [[分部积分法]] 推导而来 | 点火公式 |
| 能推什么 | 可推出 $\\int_0^{\\pi/2} \\sin^n x\\,dx$ 的精确值 | 点火公式 |
| 等价关系 | 与 [[三角函数的积分]] 在 [0,π/2] 上等价 | 区间再现 |
| 应用场景 | 应用于 [[定积分的几何应用]] 中的旋转体体积 | 点火公式 |
