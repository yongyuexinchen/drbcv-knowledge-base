# 多模态模型

## 类型判定
多模态模型是能同时处理多种类型数据（文本、图像、语音、视频）的 AI 模型——能看、能听、能说、能读。

## 类比 ★
### 一句话比喻
纯文本模型像个只能发短信的朋友——你发文字他回文字，你发张照片他"看不见"；多模态模型像个面对面的真人——你给他看照片他能评价，你跟他说话他能听懂，还能用语音回你。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 纯文本 LLM（GPT-3） | 只能发短信的网友 |
| 多模态模型（GPT-4V） | 能视频通话的真人 |
| 文本输入 | 发短信 |
| 图像输入 | 给对方看照片 |
| 语音输入 | 打电话说话 |
| 多模态输出 | 对方看图说话、语音回复 |

## 是什么
多模态模型突破了传统单一模态（纯文本）的限制，能够输入和/或输出多种数据类型。输入多模态：能理解文本+图片+语音+视频；输出多模态：能生成文本+图片+语音+视频。这是当前大模型发展的核心趋势之一，与 AGI 并列成为两大未来方向。GPT-4V（视觉版）、Gemini、国内的 GLM-4V 都是多模态模型。

## 正例（≥2 个）
1. 上传一张手写笔记的照片，多模态模型能识别潦草字迹并整理为整洁的电子版。
2. 对着手机说一段方言语音，多模态模型先语音识别，再翻译成普通话，还能用语音读出翻译结果。

## 反例/边界（≥1 个）
1. ChatGPT（纯文本版）——你发一张图片给它，它完全"看不见"，只能猜。这是单模态（纯文本）模型。
2. 把文本模型 + 图片识别模型分开调用不是真正的多模态——真正的多模态是同一个模型内部统一处理多种模态，共享表征空间。

## 详细解释
多模态的技术挑战：不同模态的数据格式完全不同（文本是 token 序列，图像是像素矩阵，语音是波形），需要"对齐"到统一的表示空间。常见方案：文本和图像分别 Embedding 后融合 → 联合编码 → 统一解码。多模态模型对中文方言、复杂语境的理解仍有很大挑战——中文博大精深，结合图像和语音后语义更加复杂。
