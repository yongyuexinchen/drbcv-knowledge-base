# 提示词（Prompt）

## 类型判定
提示词就是用户与 AI 大模型对话时输入的内容——你说的每一句话，都是提示词。

## 类比 ★
### 一句话比喻
你跟一个拥有全世界知识但完全不会读心术的天才说话——你说的每个字都是"提示"，你说得越清楚，他回答得越精准；你说得模模糊糊，他就开始自由发挥、胡说八道。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 提示词 | 你向一个超级聪明但不懂社交暗示的人提的问题 |
| 模糊提示词 | "写篇文章"——人家随便写了篇 AI 论文 |
| 清晰提示词 | "写一篇中学生春游的作文，800 字"——精准回应 |
| 大模型的回答 | 对方的回应 |
| 提示词的"一个字偏差" | "你好帅"（真夸）vs "你好帅~"（阴阳怪气） |

## 是什么
Prompt（提示词）是用户与 LLM 交互时输入的自然语言文本。它可以是简单的一句话（"你好"），也可以是几百字的复杂指令（角色设定 + 任务描述 + 格式要求 + 示例）。提示词是决定大模型输出质量的关键因素——参数量再大的模型，没有好的提示词也发挥不出能力。提示词 ≠ 提示词工程：提示词是你说的那"一句话"，提示词工程是如何系统性地设计那句"话"。

## 正例（≥2 个）
1. "写一篇文章"——模型随机写，可能是 AI 论文 → 输出不可控。
2. "写一篇关于中学生春游的作文，800 字，要求有景物描写和情感表达"——精准命中需求。

## 反例/边界（≥1 个）
1. 一句简单的话叫"提示词"，但"提示词工程"是围绕如何写好这句话的一套方法论——两者常被混淆，但不是同一概念。
2. 代码里的函数参数传入一个字符串——技术上也是"输入"，但不叫 Prompt，Prompt 特指 LLM 自然语言交互的输入。

## 详细解释
提示词的核心挑战：语言是模糊的——"苹果"可以是水果也可以是手机，中文更有"话里有话"的复杂语境。因此同样的提示词在不同模型上效果不同、不同表述方式结果天差地别。提示词的背后技术包括 N-gram（基于 N 个前词的统计概率预测下一个词）和深度学习（Transformer 理解语义）。
