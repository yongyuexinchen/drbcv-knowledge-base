# ChatGLM2+LangChain 云端部署与参数配置

## 类型判定
[程序] — 一套在 AutoDL 云平台上部署 ChatGLM2 + LangChain 项目的完整操作流程，含 GPU 选型、SSH 连接、模型参数调节与提示词模板配置。

## 类比 ★
### 一句话比喻
你买不起法拉利（本地高配显卡），于是去租了一辆顶级赛车 + 专业赛道（AutoDL 云 GPU），然后调座椅、后视镜、挂挡模式（参数调节），最后开着它跑出最佳圈速——整个过程就是 ChatGLM2+LangChain 的云端部署与调参。

| 概念世界 | 现实世界 |
|---------|---------|

## 是什么
ChatGLM2 是清华开源的中文最强可商用大语言模型，LangChain 是连接 LLM 与外部数据的工程框架。二者结合后非常吃显存，普通消费级显卡无法带动，必须部署在云端 GPU 平台（推荐 AutoDL 的 RTX 4090，约 2 元/小时）。部署只需三条终端命令，通过 SSH 隧道将云端端口映射到本地浏览器访问。

## 输入-输出空间（程序型必填）
- **输入**: AutoDL 账号（充值 5 元+）、SSH 登录指令、三条部署命令
- **输出**: 本地浏览器可访问的 ChatGLM2+LangChain Web UI 界面
- **前置条件**: 已注册 AutoDL、已充值、已创建 4090 GPU 实例

## 核心参数

### 温度（Temperature）
控制模型输出的"严谨度 vs 创造力"：
- 拉低（接近 0）：回答死板、重复，但精准可靠 → 适合企业业务场景
- 拉高（接近 1）：回答丰富、有想象力，但可能偏离主题 → 适合客服场景（稍拉高即可）
- 极端案例：温度最低时输入"我叫张三"，模型只会复读"我叫张三"

### 历史对话轮数
决定大模型记住几轮上下文：
- 建议 3-5 轮（通用场景）、5-8 轮（客服/销售场景）
- 超过 10 轮容易导致显存溢出、机器崩溃
- 本质是让模型有"记忆力"，不会聊着聊着回到起点

### 模型底座选择
LangChain-ChatGLM 项目默认支持：
- ChatGLM2-6B：无需任何 API 配置，开箱即用
- 质谱（智谱 AI）：需获取 API Key，中文效果与 GLM2 差不多
- OpenAI / Claude：需要海外网络环境 + API Key，中文场景不如国产模型
- 切换模型：修改 `model_config.py` 中对应模型的 key 和路径

### 提示词模板
配置文件：`prompt_config.py`，可预设角色提示词：
- 翻译助手：`"你是一个聪明的翻译助手，请将下面的内容翻译成英语"`
- 智能销售、客服、产品经理：按业务场景灵活调整
- 注意：ChatGLM 的提示词不能写得太详细（与 ChatGPT 不同），过于详细反而效果差

## 正例（≥2 个）
1. **零基础学员部署**：充值 5 元 → 创建 4090 实例 → 终端粘贴三条命令 → 等待启动 → SSH 连接 → 浏览器打开 Web UI → 成功对话。全程约 10 分钟。
2. **企业客服场景调参**：温度设为 0.4（稍保守）、历史轮数设为 6（记住上下文）、提示词模板设为智能客服角色 → 模型回答既准确又不死板。

## 反例/边界（≥1 个）
1. **本地部署失败**：在消费级显卡（如 RTX 3060）上直接跑 ChatGLM2+LangChain，LangChain 本身吃显存严重，ChatGLM2 模型也占显存，两者叠加直接 OOM（显存溢出）。必须上云 GPU。
2. **端口冲突**：配置文件 `server_config.py` 中端口不能重复（如 21001），否则服务启动后访问报错。修改后必须 Ctrl+C 终止 → 重新执行启动命令，不能只刷新页面。

## 详细解释

### 部署流程（步骤表）
| 步骤 | 操作 | 关键注意事项 |
|------|------|-------------|
| 1. 注册充值 | 百度搜索 AutoDL → 注册登录 → 充值 5 元 | 微信扫码即可 |
| 2. 创建实例 | 选 RTX 4090 GPU → 立即创建 | 约 2 元/小时，5 元够用 |
| 3. 打开终端 | 快捷工具 → JupyterLab → 终端 | — |
| 4. 执行部署 | 文档三条命令依次粘贴回车 | 等待 "启动成功" 日志 |
| 5. SSH 连接 | 复制 SSH 指令 → 修改端口号 → PowerShell 粘贴 | Windows: PowerShell; Mac: 终端 |
| 6. 输入密码 | 手动逐字输入密码 | **密码不显示，区分大小写** |
| 7. 访问 Web | 浏览器粘贴 `http://127.0.0.1:端口` | 30 秒内无密码错误提示即成功 |

### 配置修改后重启
任何 `model_config.py` 或 `server_config.py` 修改后：
1. 终端 `Ctrl+C` 终止当前服务
2. 重新粘贴启动命令
3. 等待输出日志确认启动成功
4. 浏览器刷新或重新 SSH 连接
