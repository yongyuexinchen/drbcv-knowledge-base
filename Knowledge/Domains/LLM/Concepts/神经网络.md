# 神经网络

## 类型判定
神经网络是模拟人脑神经元连接结构的计算模型，由输入层、隐藏层、输出层组成，是深度学习的核心架构。

## 类比 ★
### 一句话比喻
人脑里有上百亿个神经元互相连在一起，一个信号传来，神经元们集体"开会讨论"后做出决策。神经网络就是在电脑里模拟了这种"集体讨论"的过程——只不过参与讨论的不是细胞，是数学公式。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 输入层 | 眼睛看到光、耳朵听到声音（感官） |
| 隐藏层 | 大脑神经元集体处理信息 |
| 输出层 | 大脑做出的决策（开灯/关灯） |
| 权重 W | 每个神经元"发言"的重要程度 |
| 偏置 B | 即使没有输入，神经元也有一个基础倾向 |

## 是什么
神经网络由三层构成：①输入层（接收数据，如光照强度）；②隐藏层（通过公式 Z = W×X + B 进行数学运算，模拟人脑处理信息）；③输出层（根据 Z 的值做出决策，如 Z<0.5 则关灯）。复杂的神经网络有成千上万个神经元和多层隐藏层（深度网络）。每个连接都有权重（W）和偏置（B），训练过程就是不断调整这些参数。

## 正例（≥2 个）
1. 最简单的神经网络：输入光照强度 X → 隐藏层 Z=WX+B → 输出层：Z>0.5 开灯，Z<0.5 关灯。这是单神经元网络。
2. 实际的 ChatGPT：输入文本 → Embedding 层 → 几十上百层隐藏层（每层有数千到数万神经元）→ 逐词预测输出。

## 反例/边界（≥1 个）
1. 一个简单的 if-else 判断（if 亮度>阈值 then 关灯）不是神经网络——它没有权重、没有训练过程、没有隐藏层。
2. 线性回归预测房价虽然涉及数学计算，但如果只有一层且没有激活函数，不算真正意义上的神经网络。

## 详细解释
神经网络的核心公式是 Z = W×X + B。训练时：输入 X + 人类正确答案 Y → 模型计算 Y_pred → 比较 Y 和 Y_pred → 修正 W 和 B（反向传播）→ 重复直到准确。参数量 = 所有权重 W 的数量，GPT-3 有 1750 亿参数，GPT-4 达万亿级。神经网络的主要变体：CNN（图像）、RNN（序列）、Transformer（NLP，当前主流）。
