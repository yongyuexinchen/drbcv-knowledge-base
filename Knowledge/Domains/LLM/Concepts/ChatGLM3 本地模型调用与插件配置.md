# ChatGLM3 本地模型调用与插件配置

## 类型判定
[程序] — 在 LangChain-ChatGLM 项目中配置本地 ChatGLM3-6B 模型作为大模型底座，同时安装向量数据库、搜索引擎、Embedding 模型等"插件"，通过 Web UI 拖拽式界面组装成完整的智能问答系统。

## 类比 ★
### 一句话比喻
你买了一辆底盘（LangChain 框架），现在要给它装配发动机、导航仪、行车记录仪——先去仓库（Hugging Face）拉一台 ChatGLM3 发动机（本地大模型），装上矢量导航（向量数据库）、联网搜索模块（搜索引擎）、智能摄像头（Embedding 模型），最后通过中控屏（Web UI 拖拽界面）把所有零件连起来——一辆完整的 AI 智能车就组装好了。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| LangChain-ChatGLM 项目 | 汽车底盘 + 中控系统 |

| Embedding 模型 | 智能摄像头——把路况照片转成机器能理解的数字 |

## 是什么
LangChain-ChatGLM（又名 LangChain-Chat）是一个支持私有化部署的 LLM 应用平台，允许用户将本地下载的 ChatGLM3-6B 模型配置为大模型底座，并通过"插件式"架构添加向量数据库、搜索引擎、Embedding 模型等组件。全部配置完成后，项目以"零代码拖拽"方式使用——在 Web UI 中拖拽模型模块、提示词模块、知识库模块并连线，即可构建完整的 AI 应用。核心价值：不依赖任何 API（OpenAI/智谱），完全在内网运行。

## 输入-输出空间（程序型必填）
- **输入**: ChatGLM3-6B 模型权重（~12 个文件）、向量数据库组件、搜索组件、Embedding 模型、内网 IP
- **输出**: Web UI 上可通过拖拽使用本地模型的完整对话系统（含知识库检索 + 搜索引擎）
- **前置条件**: AutoDL GPU 实例已创建、Docker 已安装、Hugging Face 可访问（或使用学术加速）

## 模型加载与验证

### ChatGLM3 模型下载
```bash
# 1. 在模型目录下 git clone 仓库
# 2. git lfs install && git lfs pull 拉取大权重文件
# 3. ls -la 验证：8 个大文件 + 若干配置小文件
# 4. 验证完整性：带 * 号 = 完整下载
```
- 支持模型底座：ChatGLM2 / ChatGLM3 / 百川 / 质谱等
- 下载约 7-8GB，可能耗时较长

### RT 服务管理（模型上线）
| 步骤 | 操作 | 关键点 |
|------|------|--------|
| 1. 模型管理 | Web UI → 模型管理 → RT 服务 → 创建 | 机器人名称随意 |
| 2. 服务地址 | 填入 `内网IP:9001` | 用英文冒号，是内网非公网 |
| 3. 模型配置 | 参数配置附录中复制 ChatGLM3 的 JSON | 删除多余括号 |
| 4. GPU 指定 | 修改 `gpu_ids: [0]` 为第 0 块 GPU | 用 `nvidia-smi` 查看 GPU ID |
| 5. 上线 | 点击确定 → 等待加载 | 加载完后状态变为"上线" |

## 正例（≥2 个）
1. **全内网部署**：下载 ChatGLM3 → 安装向量库 + 搜索 + Embedding → 拖拽配置 → 知识库上传公司文档 → 员工在 Web UI 用自然语言提问，所有数据不出内网。适合金融、政务等数据安全敏感场景。
2. **大模型选配**：企业先试 ChatGLM3，效果不满意 → 换百川模型 → 只需在模型管理中重新配置路径和参数 → 无需改动其他组件。就像换发动机不用拆导航和摄像头。

## 反例/边界（≥1 个）
1. **端口冲突 / 安全组未配置**：服务地址写 `内网IP:9001` 后打不开——先检查安全组是否添加了 `0.0.0.0/0 TCP:9001` 入站规则；再确认 Docker 服务是否因重启而停止（Docker 重启后所有容器也重启，需手动 restart）。
2. **GPU ID 写错**：模型配置中 `gpu_ids: [7]`，但机器只有 1 块 GPU（ID 为 0）→ 模型上线后无响应或报错。必须先用 `nvidia-smi` 确认实际 GPU 数量和 ID。

## 详细解释

### 完整安装流程（步骤表）
| 步骤 | 操作 | 耗时/注意 |
|------|------|----------|
| 1. 检查已有服务 | `docker ps` 确认向量库和搜索已在运行 | 上节课安装的，关了终端也不停 |
| 2. 安装模型加载组件 | 下载支持本地大模型的配件（70-80GB） | 耗时最长 |
| 3. 创建模型目录 | 在根目录下新建目录存放模型 | 统一管理 |
| 4. 下载 ChatGLM3 | git clone + git lfs pull | 约 12 个大文件 |
| 5. 验证文件完整性 | 检查带 `*` 号的文件 | 不带星号需重新拉取 |
| 6. 检查显卡状态 | `nvidia-smi` | 记录 GPU ID 和显存 |
| 7. 安装 Embedding 模型 | 同样 git clone + lfs pull | 中文推荐 text2vec |
| 8. 配置 RT 服务 | 填入内网 IP:9001 + 模型参数 JSON | GPU ID 一定要对 |
| 9. 上线并测试 | 新建模板 → 拖拽 host 模型 + 提示词 → 对话 | 响应速度取决于 GPU 配置 |

### 故障排查
| 问题 | 原因 | 解决 |
|------|------|------|
| 模型上线后打不开 | 安全组未配 9001 端口 | 添加 0.0.0.0/0 TCP:9001 |
| 刷新后服务全没 | Docker 重启导致容器停止 | 重新 `docker start` |
| 启动报函数错误 | 某个依赖未安装或路径不对 | 重启 Docker → 重新执行安装函数 |
| 响应极慢 | GPU 配置低 | 给企业部署选更高配置 + 包月折扣 |
