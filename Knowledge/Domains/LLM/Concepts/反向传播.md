# 反向传播

## 类型判定
反向传播（Backpropagation）是神经网络训练的核心算法——根据模型输出的错误，反向逐层修正每个神经元的权重和偏置。

## 类比 ★
### 一句话比喻
你教小孩投篮：他投偏了左边，你不是告诉他"重新投"，而是告诉他"手腕往右偏 5 度、膝盖再弯一点"——这种"从结果反推每个动作该怎么调整"的过程，就是反向传播。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 模型预测值 Y_pred | 小孩实际投出的球落点 |
| 人类正确答案 Y | 篮筐中心 |
| 误差（Loss） | 球偏了多少 |
| 反向传播 | 分析"手腕角度、膝盖弯曲"哪出了问题 |
| 更新权重 W 和偏置 B | 调整手腕角度和膝盖弯曲度 |

## 是什么
神经网络训练过程：输入 X → 正向传播（前向计算，得到预测值 Y_pred）→ 计算误差 Loss = |Y - Y_pred| → 反向传播（从输出层向输入层逐层计算每个参数的梯度，即每个参数对误差"贡献了多少"）→ 梯度下降更新 W 和 B → 重复直到误差足够小。反向传播的核心是链式法则——将最终误差逐层"分配"给每个参数。

## 正例（≥2 个）
1. 光照判断开灯模型：输入光照强度 X，模型预测 Y_pred=0（关灯），但人类正确决策 Y=1（该开灯）→ 反向传播修正 W 和 B，下次同样光照时预测更接近 1。
2. 图像分类：模型把猫误判为狗 → 反向传播逐层调整所有连接的权重，让模型下次能正确分辨猫和狗。

## 反例/边界（≥1 个）
1. 正向传播只是"用当前参数跑一遍得到结果"，没有学习。只有加了反向传播，形成"正向→计算误差→反向→更新参数"的闭环，才算真正在训练。
2. 手动调参（人工试不同的 W 值）不是反向传播——反向传播是自动化的数学过程，通过梯度计算精确修正，而非盲目试错。

## 详细解释
反向传播的数学本质是梯度下降 + 链式法则。在深度网络中，误差从输出层开始，通过链式法则逐层向前传递（因此叫"反向"），每层计算自己参数的梯度（偏导数），然后按学习率更新参数。参数量越大（GPT-3 有 1750 亿参数），反向传播的计算量越大，这也是大模型训练需要海量 GPU 的原因。
