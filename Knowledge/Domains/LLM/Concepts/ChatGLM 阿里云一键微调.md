# ChatGLM 阿里云一键微调

## 类型判定
[程序] — 在阿里云 PAI-DSW 平台上通过免费试用资源，用"一键点击"方式对 ChatGLM 进行轻量微调的完整流程，从注册领取免费算力到数据集编辑、模型测试和导出。

## 是什么
阿里云 PAI-DSW（交互式建模）平台提供了 ChatGLM 的一键微调模板，用户无需编写代码、不用输入命令行，通过 DSW Gallery 加载官方微调 notebook，依次点击各环节的"运行"按钮即可完成 ChatGLM 的轻量微调。整个流程包括：领取免费 GPU 资源 → 创建实例 → 加载模板 → 编辑数据集 → 一键微调 → 测试推理 → 导出模型。适合零基础小白和快速原型验证。

## 输入-输出空间（程序型必填）
- **输入**: 阿里云账号（实名认证）、数据集 JSON（≥1000 条）、DSW Gallery 微调模板
- **输出**: 微调后的 ChatGLM 模型 + Web UI 测试页面
- **前置条件**: 已领取 PAI-DSW 免费试用资格、实例创建成功、数据集已按格式准备

## 微调的本质（为什么要微调）

- 干活慢、出错多、得反复验收
- 你耗费巨量精力培训，结果还是不满意

### 微调后 = 十年老员工
- 对公司业务了如指掌，知道每个流程
- 你只需要告诉他干什么，他精准执行
- 前提是你需要"栽培"（投入数据 + 算力）

### 电商客服场景案例
- 一个体量稍大的电商企业可能需要 100+ 客服
- 微调后的 ChatGLM 可替代 50%+ 客服人员工作量
- 十个企业八个需求是智能客服/智能销售
- 降本增效的核心切入点：从客服角度为企业省钱

## 正例（≥2 个）
1. **淘宝女装电商客服**：用 1000+ 条女装商品描述数据微调 ChatGLM → 模型能根据衣服类型、风格、尺码等关键词自动生成专业推荐文案，Web UI 上问"帮我写一个女装的文案"→ 返回精准的商品介绍。
2. **快速验证微调可行性**：企业在决定投入大规模微调前，先用一键微调做 POC（概念验证）→ 花免费算力 2-3 分钟跑一个 demo → 效果满意再投入正式微调。

## 反例/边界（≥1 个）
1. **数据集少于 1000 条 = 效果差**：微调效果严重依赖数据集数量和质量。如果只给几十条数据，微调后模型和没调差不多。至少 1000 条起步，且格式必须严格遵循 JSON 规范——不能有空行、不能有多余空格。
2. **一键微调 ≠ 深度微调**：阿里云一键微调属于轻量微调，适合标注清晰的简单场景（如电商客服问答）。需要工具调用、多轮对话、Agent 等复杂场景，还是得走 ChatGLM3 的完整微调流程。

## 详细解释

### 完整流程（步骤表）
| 步骤 | 操作 | 关键细节 |
|------|------|---------|
| 1. 注册认证 | 阿里云官网 → 注册 → 支付宝实名认证 | 必须个人实名认证 |
| 2. 领取免费算力 | 文档与社区 → 机器学习 PAI → PAI-DSW 试用 | 选"交互式建模 DSW"，免费资源包抵扣 |
| 3. 创建实例 | 创建实例 → 名称英文 → GPU V100 → PyTorch 1.12 | 虽显示 29 元/时，实际免费 |
| 4. 加载模板 | DSW Gallery → 搜索 ChatGLM → "轻量微调和推理" | 在 DSW 中打开 |
| 5. 依次运行 | 按 notebook 中的按钮从上到下依次点击 | 每个按钮等它停止转动再点下一个 |
| 6. 编辑数据集 | 下载原始数据集 → 用编辑软件打开 → 按格式修改 → 上传覆盖 | 参考群文档中的标准格式 |
| 7. 重新加载数据集 | 上传后点击数据集的"运行"按钮重新加载 | 否则微调用的还是旧数据 |
| 8. 微调模型 | 点击微调按钮 → 等待 2-3 分钟 | 出现黄色警告不用管，只看红报错 |
| 9. 推理测试 | 点击推理按钮 → 在 Web UI 对话测试 | 不下载完不要点下一步 |
| 10. 导出模型 | 效果满意后导出模型文件 | 不满意可返工追加数据集 |

### 数据集格式与编辑
- 格式：JSON 数组，每个元素含商品的类别、关键词、风格和详细介绍
- 编辑软件：学习群置顶公告领取（微软面向开发者的编辑器）
- 生成技巧：让商家提供商品资料 → 用 ChatGPT 按格式批量生成 → 人工润色修改
- 严格禁忌：同一数据集内不能有空行，格式要与模板完全一致

### 推理参数调优
- 输出长度：适当拉长，上下文 token 有限制
- Top P：实际区别不大
- 温度：偏左 → 更严谨、更符合数据集但死板；偏右 → 更有想象力但可能偏离；适中最好
