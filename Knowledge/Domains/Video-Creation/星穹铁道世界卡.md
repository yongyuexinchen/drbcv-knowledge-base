# 星穹铁道世界卡

> 🔗 原始设定（忠实还原）：[[星穹铁道/00_设定索引]]（人物/势力/世界观/星球分层目录）

## 类型判定
《崩坏：星穹铁道》的世界观体系——银河尺度下的文明、星神与命途设定，为《托帕的金融小课堂》提供"梗"与"类比"素材库。

## 类比 ★
### 一句话比喻
星穹铁道的宇宙就像一家巨型跨国公司——星神是各行业的巨头老板，命途是不同的人生/经营哲学，星际和平公司是这家公司的财务部，模拟宇宙是老板的沙盘推演室。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 星神 | 各行业垄断巨头（如存护=保险公司，毁灭=军火商） |
| 命途 | 经营哲学/人生路线（稳健派、开拓派、虚无派…） |
| 星际和平公司 | 四大行+评级机构 |
| 模拟宇宙 | 老板办公室里的推演沙盘 |
| 艾利欧（预见未来） | 预言家/战略分析师 |
| 琥珀纪 | 财务报表的会计年度 |

## 是什么
星穹铁道构建了一个以"星神"为中心的银河世界观：星神是宇宙法则的具象化存在，各自代表一种"命途"（哲学路线），人类文明在星神与命途的夹缝中生存发展。玩家作为"开拓者"乘星穹列车穿越各个星球（仙舟、贝洛伯格、匹诺康尼等），卷入星际和平公司、星核猎手、黑塔空间站等势力的博弈。

## 使用铁律（视频中）
- **梗要克制**：每期 1-2 处即可（如艾利欧一句带过），不展开复杂设定——观众是财经受众，不是星铁攻略受众
- **设定服务于论证**：用星铁设定做"类比"，不做"主线"——主体永远是宏观观点+数据
- **标签蹭流量**：星穹铁道/托帕 标签放第 7-8 位，分区仍投财经商业
