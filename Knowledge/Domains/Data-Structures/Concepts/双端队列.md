# 双端队列（Deque）

## 类型判定
判别型 — 双端队列是**操作受限程度最低**的受限线性表之一，允许从两端插入、两端删除。若限制一端操作，可退化为栈或普通队列。

## 是什么
双端队列（Deque，Double-Ended Queue）是一种**两端均可进行插入和删除**的线性表。它衍生出两种变种：
- **输入受限**：只能从一端插入，但可从两端删除
- **输出受限**：只能从一端删除，但可从两端插入

若只使用其中一端，双端队列就**退化成了栈**。

## 输入-输出空间
- **两端均可 Push 和 Pop**：左端 / 右端均可插入、可删除
- **输入受限**：仅一端插入，两端删除
- **输出受限**：仅一端删除，两端插入

## 正例（≥2 个）
1. **输入受限，输入序列 1,2,3,4**：输出序列 `1,4,2,3` 合法——1 先入先出，4 从右出，2 从左出，3 从右出
2. **输出受限，输入序列 1,2,3,4**：输出序列 `1,4,2,3` 也合法——通过两边交替插入构造出所需顺序

## 反例/边界（≥1 个）
1. **输入受限，输出序列 `4,2,1,3`**：4 最先出意味 1-4 已全部入队，但 2 被夹在 1 和 3 中间，只能从两端删 → 非法的
2. **输出受限，输出序列 `4,2,3,1`**：4 最先出意味 1-4 已全部在队列中，只能从一端删除 → 1 和 3 之间隔着 2，不可能先出 3 再出 1

## 详细解释

### 三种结构的操作限制对比

| | 栈 | 队列 | 双端队列 |
|---|---|---|---|
| 插入位置 | 一端 | 一端（队尾） | 两端 |
| 删除位置 | 同一端 | 另一端（队头） | 两端 |
| 特性 | LIFO | FIFO | 无固定特性 |

### 输出序列合法性判断方法

**输入受限**（只有一端能插入）：
- 若元素 k 最先输出，则 1~k-1 在队列中的相对顺序已固定（按输入顺序排列）
- 后续输出只能从这串元素的**两端**取——判断是否能通过两端交替删除得到目标序列

**输出受限**（只有一端能删除）：
- 所有元素只能从一侧出去，因此它们在队列中的**左右排序就是最终的输出顺序**
- 判断能否通过两端交替插入构造出这个左右顺序

### 4 个元素输入 1,2,3,4 的合法输出序列数

| 结构 | 合法序列数（共 24 种排列） |
|------|--------------------------|
| 栈 | 14 种（Catalan 数 $C_4=14$） |
| 输入受限双端队列 | 22 种（仅 2 种不合法：`4,2,1,3` 和 `4,2,3,1`） |
| 输出受限双端队列 | 22 种（仅 2 种不合法：`4,1,3,2` 和 `4,2,3,1`） |

### Catalan 数（栈的合法出栈序列数）
$$C_n = \frac{1}{n+1}\binom{2n}{n}$$
$n=4$ 时 $C_4 = 14$。

## 类比

### 一句话比喻
**双端队列就像一根可以从两头吃的甘蔗——你可以从左边嚼，也可以从右边嚼。普通的栈就像只能从一头啃的玉米棒子（啃一口少一口，后啃的先到嘴）。普通的队列就是从入口进、出口出的回转寿司。输入受限就是你只能往甘蔗一端塞糖，但可以从两头吃；输出受限就是你只能从一头吃，但可以两头塞。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 双端队列 | 两端都能上下客的公交车 |
| 输入受限双端队列 | 排队入口只有一个，但顾客等急了可以从前门后门一起走 |
| 输出受限双端队列 | 出口只有一个，但新员工可以从前门后门一起入职 |
| 退化栈（只从一端操作） | 公交车只开前门——就是普通轿车的单门 |
| 两端插入+一端删除 | 收银台只有一个，但排队的人可以从两边涌过来 |
| 判断输出序列合法性 | 玩华容道——看能不能通过两边滑动拼出目标序列 |
