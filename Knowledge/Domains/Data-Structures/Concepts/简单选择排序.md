# 简单选择排序（Simple Selection Sort）

## 类型判定
程序型 — 属于**选择排序**大类。每趟从待排序元素中选出最小（或最大）的，放到已排序序列末尾。

## 是什么
每一趟扫描剩余未排序元素，找到关键字最小的元素，与当前待排序序列的第一个元素交换。共进行 n-1 趟，最后剩下的一个元素天然是最大的。

## 输入-输出空间
- **输入**：数组 A[0..n-1]，n 个元素
- **输出**：递增有序的数组
- **前置条件**：无

## 正例（≥2 个）
1. **任意序列，趟数固定**：无论初始序列是否有序，n 个元素总是 n-1 趟，每趟扫描剩余全部元素
2. **链表实现**：从头扫描链表挑最小结点，摘下插入到有序链表末尾——思路一致

## 反例/边界（≥1 个）
1. **不稳定**：交换可能把相同关键字的位置打乱。例如 `[2₁, 2₂, 1]` → 第一趟选 1 与 2₁ 交换 → 得到 `[1, 2₂, 2₁]`，两个2的相对位置变了
2. **时间复杂度不随初始状态改变**：即使已有序，仍需全部比较，这是它与插入/冒泡的重要区别

## 详细解释

### 核心代码
```c
void SelectionSort(int A[], int n) {
    int i, j, min;
    for (i = 0; i < n - 1; i++) {        // 共 n-1 趟
        min = i;                          // 假设当前第一个最小
        for (j = i + 1; j < n; j++) {    // 扫描后面所有元素
            if (A[j] < A[min])
                min = j;                  // 记录更小元素位置
        }
        if (min != i)
            swap(A[i], A[min]);           // 把最小的换到前面
    }
}
```

### 关键注意事项
- **n-1 趟而不是 n 趟**：最后一趟只剩一个元素，天然最大，无需处理
- **比较次数固定**：$\sum_{i=0}^{n-2}(n-1-i) = \frac{n(n-1)}{2}$，与初始状态无关
- **交换次数最多 n-1 次**：远少于冒泡的最坏 $O(n^2)$ 次交换

### 时间复杂度
| 情况 | 比较次数 | 交换次数 | 复杂度 |
|------|---------|---------|--------|
| 任何情况 | $\frac{n(n-1)}{2}$ | ≤ n-1 | $O(n^2)$ |

- 空间复杂度：**$O(1)$**
- 稳定性：**不稳定**
- 适用存储：顺序表和链表均可

## 类比 ★

### 一句话比喻
**简单选择排序就像考试后选班长——全班成绩单摊开，找到分数最高的站第一个；然后从剩下的里面再找最高的站第二个；一直选到最后一个人自动归位。不管成绩单原来怎么排的，你都得从头扫到尾找最高分——没得偷懒。而且如果有两个同分的，你随手抓到的那个先站出去，另一个可能就排后面去了——不公平（不稳定）！**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 每趟选最小 | 从剩下的人里挑最高分站出去 |
| min 指针 | "目前看到的最低分在谁手上" |
| swap 交换 | 最低分的人和当前位的人换位置 |
| n-1 趟 | 选 n-1 次，最后一个自动就位 |
| 比较次数固定 | 不管成绩单怎么排，每次都得扫完 |
| 不稳定 | 两个同分的，先被扫到的先出去，相对位置变了 |
