# DAG 与拓扑排序

## 类型判定
程序型 — 有向无环图（DAG）的两个经典应用：描述表达式（判别/构造型） + 拓扑排序（程序型，含代码与复杂度）。

## 是什么

### DAG（Directed Acyclic Graph，有向无环图）
不存在环路的有向图。关键性质：DAG 必有拓扑排序；有环路则无拓扑排序。

### 拓扑排序（Topological Sort）
对 DAG 的所有顶点排一个线性序列，使得：若存在有向边 $\langle A, B \rangle$，则 $A$ 在序列中排在 $B$ 之前。
- AOV 网（Activity On Vertex）：顶点表示活动，边表示先后依赖
- 工程上的含义：找到一组合理的执行顺序，满足所有依赖关系

## 输入-输出空间
- **DAG 描述表达式**：输入算术表达式 → 输出最简有向无环图
- **拓扑排序**：输入 DAG（邻接表） → 输出拓扑排序序列（或 false = 有环）
- **复杂度**：邻接表 $O(|V|+|E|)$；邻接矩阵 $O(|V|^2)$

## 正例（≥2 个）
1. **大学选课顺序**：高数→大物→模电，每门课有先修要求 → 拓扑排序 = 合理排课方案
2. **番茄炒蛋工程**：买菜→洗番茄→切番茄→炒→吃；买菜→打鸡蛋→炒→吃 → 拓扑排序给出合理做饭顺序

## 反例/边界（≥1 个）
1. **存在环路**：洗番茄前要先切番茄，切番茄前要先洗番茄 → 互相等待，工程无法推进 → 无拓扑排序
2. **拓扑序列不唯一**：入度为零的顶点可能同时有多个，选择顺序不同导致不同序列

## 详细解释

---

### Part A：DAG 描述表达式

**步骤**（三层法）：
1. **排操作数**：把表达式中不重复的操作数排成一排
2. **标生效顺序**：给各运算符标上运算优先级次序
3. **分层构建**：按生效顺序依次添加运算符结点（利用下层结果的要放在上层）
4. **自底向上合并**：同一层中左右操作数相同的运算符可合并（减小结点数）

**关键规律**：最终 DAG 中不会出现重复的操作数顶点。

---

### Part B：拓扑排序算法

**手动模拟步骤**：
1. 从 AOV 网中选一个入度为 0 的顶点输出
2. 删除该顶点及所有从它出发的边
3. 重复直到图为空（成功）或不存在入度为 0 的顶点（失败 = 有环）

**代码实现**（邻接表）：
```c
int indegree[MAX_VERTEX_NUM];   // 记录每个顶点当前入度
int print[MAX_VERTEX_NUM];      // 拓扑排序序列
Stack S;                         // 存当前入度为 0 的顶点（栈/队列/数组均可）
int count = 0;

bool TopologicalSort(Graph G) {
    // 初始化入度
    for (int i = 0; i < G.vexnum; i++)
        indegree[i] = 0;
    for (int i = 0; i < G.vexnum; i++)
        for (ArcNode *p = G.vertices[i].first; p != NULL; p = p->next)
            indegree[p->adjvex]++;   // 每条边贡献 1 个入度

    InitStack(S);
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) Push(S, i);  // 入度为 0 的入栈

    while (!StackEmpty(S)) {
        Pop(S, i);
        print[count++] = i;           // 输出顶点 i

        for (ArcNode *p = G.vertices[i].first; p != NULL; p = p->next) {
            int v = p->adjvex;
            if (--indegree[v] == 0)    // "逻辑删除"边：入度减 1
                Push(S, v);            // 减到 0 则可被删除
        }
    }

    return count == G.vexnum;          // true=成功, false=有环
}
```

### 逆拓扑排序
- **定义**：每次选**出度为 0** 的顶点输出
- **DFS 实现**：在 DFS 退出递归前输出顶点 → 得到逆拓扑排序
- **效率**：邻接表找入边需遍历全部边 → 用邻接矩阵或逆邻接表更高效

### 关键考点
- 拓扑排序序列**不唯一**
- 有环必无拓扑排序
- 拓扑排序常用于判断图中是否有环
- 邻接表存储：$O(|V|+|E|)$；邻接矩阵：$O(|V|^2)$

## 类比

### 一句话比喻
**拓扑排序 = 大学选课排顺序。你要修「数据结构」，必须先修「C 语言」；要修「算法」，必须先修「数据结构」和「离散数学」。拓扑排序帮你排出：「离散数学→C 语言→数据结构→算法」这样的合理上课顺序。如果课程之间有循环依赖（C 语言要求先修数据结构，数据结构又要求先修 C 语言），那你就永远毕不了业——这就是「有环，无拓扑排序」。**

| 数据结构世界 | 现实世界 |
