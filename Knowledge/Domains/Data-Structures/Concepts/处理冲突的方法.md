# 处理冲突的方法

## 类型判定
程序型 — 拉链法（同义词链表）+ 开放定址法（线性探测/平方探测/双散列/伪随机序列），含查找长度计算和删除注意事项。

## 是什么
当 $H(key_1) = H(key_2)$ 发生冲突时，解决"谁来占这个位置"的问题。两大流派：**拉链法**（再挂一个链表）和**开放定址法**（另外找一个空位）。

## 正例（≥2 个）
1. **拉链法**：14 和 1 都对 13 取余 = 1 → 用链表串起来，14→1→NULL
2. **线性探测法**：1 想插入地址 1，冲突 → 看地址 2（空）→ 插入地址 2
3. **平方探测法**：1 冲突 → 地址 1+1²=2（冲突？）→ 1-1²=0（冲突？）→ 1+2²=5（空）→ 插入

## 反例/边界（≥1 个）
1. **开放定址法删除不能用物理删除**：删 15 后把该位置清空 → 后续查找 1 遇到空位就停了 → 找不到实际存在的 1（它在更后面！）→ 必须用**逻辑删除**（标记为已删）
2. **平方探测法可能覆盖不全**：表长 M=8 时，平方探测只覆盖一半位置 → 即便有空位也可能插入失败

## 详细解释

### 拉链法

```
散列表：[0]→[1]→[2]→...→[12]→
              ↓           ↓
            14→1→27    23→...
```

- 每个槽位 = 链表头指针
- 插入：默认**头插法** $O(1)$
- 查找：先算散列地址，再顺序遍历链表
- 删除：找到后从链表中删除
- **查找长度只统计关键字对比次数**，空指针对比不计入

### 开放定址法

通用公式：$H_i = (H(key) + d_i) \bmod M$，其中 $d_i$ 是探测序列。

| 方法 | 探测序列 $d_i$ | 特点 |
|---|---|---|
| **线性探测法** | $0, 1, 2, 3, \ldots, M-1$ | 易聚集，但一定覆盖所有位置 |
| **平方探测法** | $0, 1^2, -1^2, 2^2, -2^2, \ldots$ | 减少聚集；表长 $M=4j+3$（质数）时全覆盖 |
| **双散列法** | $d_i = i \times H_2(key)$ | 不同 key 不同序列；$H_2(key)$ 与 $M$ 互质时全覆盖 |
| **伪随机序列法** | 程序员设计的随机序列 | 取决于序列设计 |

### 查找成功的条件
在探测序列中**找到匹配关键字**。

### 查找失败的条件
在探测序列中**遇到空位置**（不是逻辑删除标记！）

### 删除：必须逻辑删除！
```
物理删除（错误）：[14][15][1][  ] → 找 1 时遇空即停 → 出错！
逻辑删除（正确）：[14][15][1][DEL] → 遇 DEL 继续往后找
```

### 复杂度
- 拉链法：查找 $O(1 + \alpha)$（$\alpha$ = 装填因子）
- 开放定址法：取决于 $\alpha$，越满越慢

## 类比 ★

### 一句话比喻
**拉链法 = 快递柜满了就在旁边加挂小箱子（同义词串成链）。开放定址法 = "3 号柜有人了？去 4 号！4 号也有人？5 号！……"（线性探测）或者"3 号有人 → 跳 4（1²）→ 跳 2（-1²）→ 跳 7（2²）→ 跳 -1（-2²）……"（平方探测，左右横跳）。删快递不能直接把柜子清空（后面的人找不到了），只能贴个"已取走"标签（逻辑删除）。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 拉链法 | 同一个快递柜号挂一串快递——用绳子串起来 |
| 头插法 | 新快递直接挂最前面（方便） |
| 线性探测 | "这格有人 → 下一格 → 再下一格"——像停车场找车位 |
| 平方探测 | "这格有人 → 跳 1 格 → 跳回 -1 格 → 跳 4 格"——不挨着挤 |
| 聚集现象 | 线性探测让快递在一段连续格子里扎堆 |
| 逻辑删除 | "这格的快递取走了（但别以为后面没快递）" |
| 物理删除 | 直接把格子擦干净——后面的人找不到了！ |
