# 数据结构的基本概念（Fundamental Concepts of Data Structures）

## 类型判定
判别型 — 本章所有后续概念的基石，定义了数据→数据元素→数据项→数据对象→数据结构的层次体系，以及数据结构的三要素（逻辑结构、物理结构、数据运算）。

## 是什么
**数据结构是相互之间存在一种或多种特定关系的数据元素的集合。** 它回答三个问题：数据元素之间是什么逻辑关系？（逻辑结构）→ 如何在计算机内存中存放？（物理结构/存储结构）→ 能对这些数据做哪些操作？（数据运算）。这三者合称「数据结构三要素」。

## 输入-输出空间
- **输入**：无（概念框架，非算法）
- **核心约束**：学习任何数据结构时，必须从三要素（逻辑结构 → 物理结构 → 数据运算）三个维度去理解

## 正例（≥2 个）
1. **海底捞排队系统**：每个排队顾客 = 一个数据元素（数据项：号数、取号时间、就餐人数）；所有顾客按取号顺序构成一个「线性结构」的数据结构；可以用数组（顺序存储）或链表（链式存储）来实现
2. **微博用户关注关系**：每个用户 = 一个数据元素（数据项：昵称、性别、生日）；用户间的关注关系构成「图状结构」——多对多的网状关系

## 反例/边界（≥1 个）
1. **数据对象 ≠ 数据结构**：所有海底捞门店的排队顾客信息（不管哪个门店）→ 是「数据对象」，因为它们具有相同性质但门店之间的顾客并无先后关系。数据结构强调的是**元素间有关系**，数据对象只要求元素性质相同。
2. **集合结构**：数据元素同属一个集合但没有其他关系（如烤盘上各种食材）→ 虽然是一种逻辑结构，但408考研基本不讨论集合结构，重点在线性/树形/图状三种。

## 详细解释

### 概念层次（从小到大）
```
数据 → 数据元素 → 数据项
```
- **数据**：信息的载体，能被计算机识别和处理的符号集合（对计算机而言就是二进制0/1）
- **数据元素**：数据的基本单位，根据业务需求确定。如排队系统中「一桌顾客」就是一个数据元素
- **数据项**：数据元素的组成部分。如顾客的「号数」「取号时间」「就餐人数」

> ⚠️ 什么是数据元素、什么是数据项，**取决于实际业务需求**，不是绝对固定的。

### 数据结构三要素

| 要素 | 核心问题 | 分类 |
|------|---------|------|
| **逻辑结构** | 数据元素间是什么关系？ | 集合、线性（一对一）、树形（一对多）、图状（多对多） |
| **物理结构（存储结构）** | 怎么在内存中存放？ | 顺序存储、链式存储、索引存储、散列存储 |
| **数据运算** | 能对数据做哪些操作？ | 根据逻辑结构定义运算（插入、删除、查找…），根据存储结构实现运算 |

### 四种存储结构

| 存储结构 | 核心思想 | 特点 |
|---------|---------|------|
| **顺序存储** | 逻辑相邻 → 物理相邻 | 连续空间，找元素快，插入删除慢 |
| **链式存储** | 逻辑相邻 → 物理可不邻，用指针串 | 离散空间，插入删除快，找元素慢 |
| **索引存储** | 建立索引表，记录地址映射 | 需要额外空间存索引表 |
| **散列存储** | 根据关键字直接计算地址 | 第6章详讲，又称哈希存储 |

### 抽象数据类型（ADT）
定义了「逻辑结构 + 数据运算」**但不关心存储结构**。只有当要用计算机实际实现时，才需要考虑采用哪种存储结构。

### 记忆口诀
> **逻辑结构看关系，物理结构看存放，数据运算看操作。**

## 类比

### 一句话比喻
**数据结构三要素就像盖房子——逻辑结构是建筑设计图（这个房间和那个房间什么关系），物理结构是实际用什么材料怎么砌墙（钢筋混凝土还是木结构），数据运算就是这房子能干嘛（住人？开饭店？）。你图纸画得再好，用烂木头盖也是危房；你砖头再好，按一堆乱画的图纸盖也得塌。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 数据元素 | 一个排队顾客 / 一个微博账号 |
| 数据项 | 顾客的号数、就餐人数 / 账号的昵称、性别 |
| 逻辑结构 | 排队顺序（线性） / 关注网络（图状） |
| 顺序存储 | 传统排队——每个人必须物理上站成一排，紧挨着 |
| 链式存储 | 银行取号后随便坐——只要有号，人散落在各座位上也行（靠号码串连） |
| 数据对象 | 全国所有海底捞门店的所有排队顾客（性质相同，但门店间无关系） |
| 数据结构 | 某一家海底捞门店的排队序列（有先后关系！） |
| 索引存储 | 图书馆索书号——查卡片（索引表）找到书的实际位置 |
| 抽象数据类型 (ADT) | 房屋设计效果图——只看功能和外观，不关心施工细节 |
