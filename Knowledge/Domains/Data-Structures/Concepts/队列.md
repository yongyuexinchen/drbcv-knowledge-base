# 队列（Queue）

## 类型判定
判别型 — 队列是**操作受限的线性表**，`is_a` [[线性表]]，核心区别是插入在一端（队尾）、删除在另一端（队头）。

## 是什么
队列是一种只允许在**一端**（队尾 rear）进行插入，在**另一端**（队头 front）进行删除的线性表。

核心特性：**先进先出**（FIFO, First In First Out）——先进入队列的元素，先离开队列。

## 输入-输出空间
- **EnQueue(Q, x)**：将 x 插入队尾
- **DeQueue(Q, &x)**：删除队头元素，用 x 返回
- **GetHead(Q, &x)**：读取队头元素（不删除），用 x 返回
- **QueueEmpty(Q)**：判空

## 正例（≥2 个）
1. **食堂排队打饭**：先到的人先打到饭（FIFO），新来的只能排在队尾
2. **打印机任务队列**：先提交的打印任务先被打印，后来的排队等待
3. **操作系统就绪队列**：多个进程排队等待 CPU，先来的先获得时间片

## 反例/边界（≥1 个）
1. **叠盘子**：后洗的盘子在最上面先用 → 这是 LIFO（[[栈]]），不是 FIFO
2. **任意位置插入删除**：普通线性表可以在中间位置插入/删除 → 队列只能在两端操作

## 详细解释

### 基本操作
| 操作 | 含义 |
|------|------|
| `InitQueue(&Q)` | 初始化空队列 |
| `DestroyQueue(&Q)` | 销毁释放 |
| `EnQueue(&Q, x)` | 入队，x 加入队尾 |
| `DeQueue(&Q, &x)` | 出队，删除队头，x 返回 |
| `GetHead(Q, &x)` | 读队头（不删除） |
| `QueueEmpty(Q)` | 判空 |

### 队列 vs 栈
| | 栈（Stack） | 队列（Queue） |
|---|---|---|
| 插入位置 | 栈顶（一端） | 队尾（一端） |
| 删除位置 | 栈顶（同一端） | 队头（另一端） |
| 特性 | LIFO（后进先出） | FIFO（先进先出） |
| 生活比喻 | 弹夹 | 排队 |
| 逻辑结构 | 线性 | 线性 |

**栈和队列都是"阉割版"线性表，只是阉割的位置不同。**

## 类比

### 一句话比喻
**队列就像排队买奶茶——先来的先买到，后来的乖乖排到队伍最后面去。你要想插队到最前面？后面排队的人能用眼神活活把你瞪死。这就是 FIFO，公平公正、童叟无欺。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 入队（EnQueue） | 新来的顾客走到队伍最后面排着 |
| 出队（DeQueue） | 队头那位买完奶茶走了 |
| 队头（front） | 正在跟店员点单的那位 |
| 队尾（rear） | 刚排到最后、生无可恋刷手机的那位 |
| FIFO | "我先来的凭什么你先买？" |
| LIFO（栈，对比） | 电梯里最后进来的人靠着门最先出去 |
| 空队列 | 奶茶店打烊了，一个人都没有 |
