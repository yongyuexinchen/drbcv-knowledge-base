# 栈的链式实现（Linked Stack）

## 类型判定
程序型 — 栈的**链式存储实现**，本质上是**只能在表头进行插入/删除的单链表**（阉割版单链表），链头 = 栈顶。

## 是什么
用单链表来存储栈中元素，规定**仅在链表头部（表头）进行插入和删除**。链表的头结点（或第一个结点）对应栈顶，表尾对应栈底。可分为**带头结点**和**不带头结点**两种版本。

## 输入-输出空间
- **Push**：头插法插入新结点（O(1)）
- **Pop**：删除头结点后的第一个结点（O(1)）
- **前置条件**：Push 无容量限制（只要内存够）；Pop 需栈非空

## 正例（≥2 个）
1. **头插法 = 进栈**：单链表的头插法就是每次在表头前插入，恰好等于 LIFO 的 Push
2. **不带头结点的链栈**：初始 `L = NULL`，第一个元素入栈就直接成为链头，后续元素头插在它前面

## 反例/边界（≥1 个）
1. **表尾插入**：如果误在表尾做 Push/Pop，每次需要 $O(n)$ 遍历到表尾 → 失去了栈的高效性
2. **忘记修改头指针（不带头结点）**：第一个元素入栈/最后一个元素出栈时需要特殊处理头指针 L，忘记改就崩

## 详细解释

### 结构体定义
```c
// 结点定义（和单链表完全一样）
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} *LiStack;   // 链栈
```

### 核心代码（不带头结点）

```c
// 初始化
bool InitStack(LiStack &S) {
    S = NULL;        // 链栈为空
    return true;
}

// 进栈（头插法）
bool Push(LiStack &S, ElemType e) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    if (p == NULL) return false;   // 内存不够
    p->data = e;
    p->next = S;                    // 新结点指向原栈顶
    S = p;                          // 更新栈顶指针
    return true;
}

// 出栈
bool Pop(LiStack &S, ElemType &e) {
    if (S == NULL) return false;    // 栈空
    LinkNode *p = S;                // 暂存栈顶结点
    e = p->data;
    S = p->next;                    // 栈顶指针下移
    free(p);                        // 释放原栈顶
    return true;
}
```

### 带头结点 vs 不带头结点

| | 带头结点 | 不带头结点 |
|---|---|---|
| **初始化** | malloc 头结点，`S->next = NULL` | `S = NULL` |
| **判空** | `S->next == NULL` | `S == NULL` |
| **Push** | 插在头结点之后（统一逻辑） | 第一个元素需单独处理指针 |
| **Pop** | 删头结点之后的结点 | 删第一个结点 |

### 时间复杂度

| 操作 | 复杂度 |
|------|--------|
| Push | $O(1)$ |
| Pop | $O(1)$ |
| GetTop | $O(1)$ |

### 链栈 vs 顺序栈

||链栈|顺序栈|
|---|---|---|
| 容量|无限（内存允许）|固定（MaxSize）|
| 扩容|天然支持|不支持|
| 额外空间|指针域开销|无|
| 适用场景|元素数量不确定|元素数量可预估|

## 类比

### 一句话比喻
**链栈就像一串回形针——每个回形针（结点）只钩住下面的那个。新来的永远钩在最上面（Push 头插），要用就从最上面取走（Pop）。你想从中间抽一根？不好意思，整串先解开到那为止。而且这串回形针理论上可以无限接长——只要办公室抽屉（内存）装得下。**

### 生活映射

| 数据结构世界 | 现实世界 |
|---|---|
| 头插法 Push | 往回形针链最上面钩一个 |
| Pop 出栈 | 从最上面摘掉一个回形针 |
| 链头 = 栈顶 | 永远是刚加上去的那根回形针 |
| `S = p`（更新栈顶） | 你的手指从旧的回形针挪到新的回形针上 |
| 不带头结点空栈 `S=NULL` | 手里一根回形针都没有 |
| 带头结点 | 先捏住一个"空夹子"（头结点），再往上挂 |
| 内存无限 | 只要抽屉够大，回形针可以无限摞 |
