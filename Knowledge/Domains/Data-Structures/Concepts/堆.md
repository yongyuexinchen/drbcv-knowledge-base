# 堆（Heap）

## 类型判定
程序型 — 堆既是一种**数据结构**（完全二叉树的顺序存储），也是一种**排序算法**（堆排序）。本卡合并：堆的定义 + 建堆 + 堆排序 + 插入 + 删除。高频考点，综合考察二叉树顺序存储。

## 是什么
**堆**是一棵**顺序存储的完全二叉树**，满足：
- **大根堆**：每个分支结点的值 ≥ 左右孩子（根最大）
- **小根堆**：每个分支结点的值 ≤ 左右孩子（根最小）

数组下标为 i 的结点，左孩子下标 $2i$，右孩子下标 $2i+1$，父结点下标 $\lfloor i/2 \rfloor$。叶子结点下标范围 $i > \lfloor n/2 \rfloor$。

**堆排序**基于选择排序思想：大根堆的堆顶最大 → 取出堆顶 → 调整剩余为堆 → 重复。

## 输入-输出空间
- **输入**：数组 A[1..n]（下标从1开始）
- **输出**：递增有序（大根堆）或递减有序（小根堆）
- **前置条件**：下标从1开始存储

## 正例（≥2 个）
1. **建大根堆**：`[53, 17, 78, 09, 45, 65, 87, 32]` → 从 $\lfloor 8/2 \rfloor = 4$ 号结点开始往前调整 → 最终 `[87, 45, 78, 32, 17, 65, 53, 09]`
2. **堆排序**：大根堆 → 递增序列；小根堆 → 递减序列

## 反例/边界（≥1 个）
1. **不稳定**：建堆时若左右孩子相等，优先换左孩子上去 → 可能破坏相同关键字的相对顺序
2. **下标从1开始**：不同于大多数算法的0起始，注意区分

## 详细解释

### 核心操作一：下坠调整（HeadAdjust）
将一个"小"元素不断与更大的孩子交换，直到满足堆性质。
```c
void HeadAdjust(int A[], int k, int len) {
    // 将以 k 为根的子树调整为大根堆
    A[0] = A[k];                         // A[0]暂存根结点
    for (int i = 2 * k; i <= len; i *= 2) {
        if (i < len && A[i] < A[i + 1])  // 选更大的孩子
            i++;
        if (A[0] >= A[i]) break;         // 满足堆性质，停止
        A[k] = A[i];                     // 孩子上移
        k = i;                           // 继续下坠
    }
    A[k] = A[0];                         // 放入最终位置
}
```

### 核心操作二：建堆
```c
void BuildMaxHeap(int A[], int len) {
    for (int i = len / 2; i > 0; i--)   // 从最后一个分支结点往前
        HeadAdjust(A, i, len);
}
```

### 核心操作三：堆排序
```c
void HeapSort(int A[], int len) {
    BuildMaxHeap(A, len);                // ① 建堆 O(n)
    for (int i = len; i > 1; i--) {      // ② n-1 趟
        swap(A[i], A[1]);                // 堆顶↔堆底交换
        HeadAdjust(A, 1, i - 1);         // 调整剩余为堆
    }
}
```

### 核心操作四：插入
新元素放堆底（表尾），然后**不断上升**与父结点比较交换，直到满足堆性质。每上升一层最多比较 1 次关键字。

### 核心操作五：删除
用堆底元素替代被删元素，然后**不断下坠**调整。下坠一层：若有两个孩子需比较 2 次（孩子间 1 次 + 根与选中的孩子 1 次），若仅一个孩子需比较 1 次。

### 时间复杂度
| 操作 | 复杂度 |
|------|--------|
| 建堆 | $O(n)$（关键字对比 ≤ 4n） |
| 每趟排序（下坠） | $O(\log n)$ |
| 堆排序总体 | $O(n \log n)$ |
| 插入 | $O(\log n)$ |
| 删除 | $O(\log n)$ |

- 空间复杂度：**$O(1)$**
- 稳定性：**不稳定**

## 类比 ★

### 一句话比喻
**堆排序就像一场擂台赛——先用所有选手搭好擂台（建堆），擂主（堆顶）一定是最能打的。擂主出列（记入名次），然后把最菜的拉上来替位（堆底换堆顶），让他一路被打下去（下坠调整），直到擂台重新稳定。下一轮新擂主又是最强的——如此往复，名次从强到弱就排出来了。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 大根堆（堆顶最大） | 擂主永远是最强的 |
| 建堆 HeadAdjust | 搭擂台：保证每个小擂台的老大是真老大 |
| 堆顶↔堆底交换 | 擂主出列，最菜的被拉上来充数 |
| 下坠调整 | 充数的人一路被揍下去，直到找到他该待的位置 |
| 插入 | 新人放最底层，能打就一路打上去 |
| 删除 | 删掉某人，最底层的人补位，然后一路被打下去 |
| 不稳定 | 两个一样能打的，调整后谁先谁后不确定 |
