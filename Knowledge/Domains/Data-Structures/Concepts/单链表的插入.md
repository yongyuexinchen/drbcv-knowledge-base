# 单链表的插入

## 类型判定
程序型 — 具体的算法操作步骤，含代码实现和复杂度分析。

## 是什么
在单链表（带头结点）的第 $i$ 个位置插入值为 $e$ 的新结点。核心步骤：找到第 $i-1$ 个结点 → 创建新结点 → 修改指针。

## 输入-输出空间
- **输入**：链表 L（带头结点），插入位序 i，元素值 e
- **输出**：bool — 插入成功/失败
- **前置条件**：$1 \le i \le length+1$

## 正例（≥2 个）
1. **i=1（表头插入）**：找到头结点（第 0 个），新结点插在头结点后面 → 不需要遍历，$O(1)$
2. **i=3（中间插入）**：遍历到第 2 个结点，新结点插入其后 → $O(n)$

## 反例/边界（≥1 个）
1. **两个指针修改语句顺序颠倒**：如果先 `p->next = s` 再 `s->next = p->next`，则 s 的 next 指向自己 → 链表断裂
2. **i 越界**：$i < 1$ 或 $i > length+1$ → 返回 false

## 详细解释

### 核心代码（带头结点，按位序插入）

```c
bool ListInsert(LinkList &L, int i, ElemType e) {
    if (i < 1) return false;               // 位序不合法

    LNode *p = L;                           // p 指向头结点（第0个）
    int j = 0;                              // j 表示 p 指向第几个结点

    while (p != NULL && j < i - 1) {        // 找到第 i-1 个结点
        p = p->next;
        j++;
    }

    if (p == NULL) return false;            // i 超出表长+1

    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;                            // 存入数据
    s->next = p->next;                      // ① 新结点指向原后继
    p->next = s;                            // ② 前驱指向新结点

    return true;
}
```

### 关键注意事项

**① ② 两句不能颠倒！**

正确顺序：
```
s->next = p->next;   // 先让新结点接上后面的链
p->next = s;         // 再让前驱指向新结点
```

如果颠倒：
```
p->next = s;         // p 指向 s，原后续结点丢失
s->next = p->next;   // s 指向 p->next = s 自己！死循环
```

### 头结点的作用
带头结点时，头结点可以看作「第 0 个结点」→ 在 i=1 处插入时，逻辑与中间插入统一，while 循环可直接跳 → $O(1)$。

不带头结点时，i=1 需要特殊处理（修改头指针 L 本身），代码会多分支。

### 时间复杂度
| 情况 | 复杂度 |
|------|--------|
| 表头插入（i=1） | $O(1)$ |
| 表尾插入（i=length+1） | $O(n)$ |
| 平均 | $O(n)$ |

### 指定结点后插（O(1)）
```c
s->next = p->next;   // 新结点指向 p 的后续
p->next = s;         // p 指向新结点
```

### 指定结点前插（O(1) 偷天换日法）
不找前驱，先把新结点插在 p 后面，再交换两个结点的 data：
```c
s->next = p->next;
p->next = s;
// 交换数据
temp = p->data;
p->data = s->data;
s->data = temp;
```

## 类比

### 一句话比喻
**单链表插入就像在食堂排队插队——你想插到小明和小红中间，不能直接把小明推开。正确操作：先让新人把手搭在小红肩上（`s->next = p->next`），再让小明把手搭在新人肩上（`p->next = s`）。如果先让小明搭手——小明一松手，后面整队人就丢了，小红和后面的人全成了流浪儿童。**

### 生活映射
| 代码世界 | 食堂插队现场 |
|---|---|
| `p`（第 i-1 个结点） | 小明——你前面的那个人 |
| `p->next`（原第 i 个结点） | 小红——小明原本拉着的人 |
| `s`（新结点） | 你——插进来的新人 |
| `s->next = p->next` | 你把小红拽住——先接上后面的链 |
| `p->next = s` | 小明松手拉住你——前驱指向新来的 |
| ❌ 顺序颠倒 | 小明先松手拉住你 → 小红没人管了，队伍从此断了 |
| 不带头结点，插在 i=1 | 你要插到最前面当队头——没有"小明"给你拉，需要单独处理 |
