# 快速排序（Quick Sort）

## 类型判定
程序型 — 快速排序属于**交换排序**大类，是所有内部排序算法中**平均性能最优**的算法。必考，代码必须能手写。

## 是什么
快速排序的核心是**分治法**：每次选一个元素作为**枢轴（pivot）**，经过一趟划分将表分成左右两部分——左边全小于枢轴，右边全大于等于枢轴——枢轴到达最终位置。然后递归地对左右子表重复此过程。

## 输入-输出空间
- **输入**：数组 A[low..high]
- **输出**：该区间递增有序
- **前置条件**：无

## 正例（≥2 个）
1. **均匀划分**：每次枢轴恰好是中位数 → 递归深度 $\log_2 n$ → $O(n \log n)$（最好情况）
2. **乱序序列**：实际应用中平均性能接近最好情况，快排是内部排序中"最屌"的

## 反例/边界（≥1 个）
1. **已有序/逆序且每次选第一个元素为枢轴**：每次划分极不均匀（一边0个一边n-1个）→ 递归深度 n → 退化为 $O(n^2)$（最坏情况）
2. **不稳定**：相同关键字可能因划分而改变相对位置
3. **一趟排序 ≠ 一次划分**（408真题定义）：408认为一趟排序是对所有未确定最终位置的元素处理一遍，可能确定多个元素；而一次划分只确定一个枢轴

## 详细解释

### 核心代码（一次划分 Partition）
```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];                 // 选第一个元素为枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot)
            high--;                     // high左移，找比pivot小的
        A[low] = A[high];               // 小的放左边
        while (low < high && A[low] <= pivot)
            low++;                      // low右移，找比pivot大的
        A[high] = A[low];               // 大的放右边
    }
    A[low] = pivot;                     // 枢轴放入最终位置
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivotPos = Partition(A, low, high);  // 划分
        QuickSort(A, low, pivotPos - 1);         // 递归左子表
        QuickSort(A, pivotPos + 1, high);        // 递归右子表
    }
}
```

### 关键注意事项
- **递归过程**：每一次 Partition 确定一个元素的最终位置，然后递归处理左右——递归深度 = 二叉树高度
- **时间复杂度 = n × 递归层数**：每层 Partition 扫描所有待排序元素 $O(n)$
- **优化思路**：选头中尾三数取中作为枢轴，或随机选取枢轴 → 避免最坏情况

### 时间复杂度
| 情况 | 递归深度 | 复杂度 |
|------|---------|--------|
| 最好（均匀划分） | $\log_2 n$ | $O(n \log n)$ |
| 最坏（有序/逆序） | n | $O(n^2)$ |
| 平均 | — | $O(n \log n)$ |

### 空间复杂度
- **来自递归工作栈**：最好 $O(\log n)$，最坏 $O(n)$
- 稳定性：**不稳定**
- 适用存储：顺序表

## 类比 ★

### 一句话比喻
**快速排序就像军训排队——教官随便揪出一个人（pivot）站中间，喊"比他矮的站左边！比他高或一样高的站右边！"然后左边和右边各找一个小教官，用同样的方法继续排。如果每次都揪到最矮或最高的人（最坏情况），左边或右边就没人——等于白喊；如果每次都揪到差不多中间的人，几下就排完了。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| pivot（枢轴） | 教官揪出来做标杆的那个人 |
| Partition 划分 | "比他矮的左边，高的右边"的分拨过程 |
| low/high 指针 | 两个教官从两头往中间走，把人归位 |
| 递归左子表 | 左边那拨人再用同样方法自己排 |
| 递归右子表 | 右边那拨人再用同样方法自己排 |
| 有序/逆序最坏 | 每次揪到最矮的 → 左边永远没人 |
| 不稳定 | 两个一样高的人，排完后左右位置可能互换 |
