# 二叉树的遍历（Binary Tree Traversal — 先序 / 中序 / 后序）

## 类型判定
程序型 — 基于二叉树递归特性的三种深度优先遍历算法，是本章所有算法题的基础。

## 是什么
按照某种规则依次访问二叉树中每个结点（每个结点只被访问一次）。基于「根-左子树-右子树」的递归分解，衍生出三种遍历：
- **先序遍历（PreOrder）**：根 → 左 → 右
- **中序遍历（InOrder）**：左 → 根 → 右
- **后序遍历（PostOrder）**：左 → 右 → 根

## 输入-输出空间
- **输入**：二叉树的根结点指针 `BiTree T`
- **输出**：遍历序列（通过 `visit()` 输出或处理每个结点）
- **前置条件**：二叉树可为空（空树直接返回）

## 正例（≥2 个）
1. **算术表达式树的遍历**：对表达式 `(a+b)×(c-d)-e/f` 的分析树——先序 → 前缀表达式（`-×+ab-cd/ef`），中序 → 中缀表达式，后序 → 后缀表达式（`ab+cd-×ef/-`）
2. **求树的深度**：递归求左右子树深度的最大值 + 1，本质是后序遍历的变体

## 反例/边界（≥1 个）
1. **空树**：直接返回，不访问任何结点——三种遍历都输出空序列
2. **只有左子树的二叉树**：先序=AB，中序=BA，后序=BA——序列依规则产生，正确但可能不直观

## 详细解释

### 三种遍历规则

| 遍历方式 | 规则 | 记忆口诀 |
|----------|------|----------|
| 先序 | 根-左-右 | "进门就看牌匾" |
| 中序 | 左-根-右 | "从左边绕一圈" |
| 后序 | 左-右-根 | "逛完才看门口说明" |

### 核心代码

```c
// 先序遍历（PreOrder）
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);              // 根
        PreOrder(T->lchild);   // 左
        PreOrder(T->rchild);   // 右
    }
}

// 中序遍历（InOrder）
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);    // 左
        visit(T);              // 根
        InOrder(T->rchild);    // 右
    }
}

// 后序遍历（PostOrder）
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);  // 左
        PostOrder(T->rchild);  // 右
        visit(T);              // 根
    }
}
```

### 手算技巧

**分支结点逐层展开法**：遇到分支结点，按规则展开为「左子树序列 + 根 + 右子树序列」。

**路过法（丛丽丽全世界路过）**：从根出发，脑补所有空结点，优先往左走，无路时返回。每个结点会被路过 3 次：
- 第 1 次路过 → 先序访问
- 第 2 次路过 → 中序访问
- 第 3 次路过 → 后序访问

### 时间复杂度

| 情况 | 复杂度 |
|------|--------|
| 时间 | $O(n)$（每个结点访问一次） |
| 空间（递归栈） | $O(h)$，h 为树高（最坏 $O(n)$，最好 $O(\log n)$） |

递归栈深度 = 树高 + 1（最后一层叶子有「空子树」压栈再弹出），常数忽略后为 $O(h)$。

## 类比

### 一句话比喻
**三种遍历就像逛故宫的三种方式——先序遍历是「进门就看太和殿的匾额，然后逛左边再逛右边」（皇帝视角，先看最显赫的）；中序遍历是「从左边长廊绕进去，绕完才走到大殿」（游客的常规游览路线，左→中→右）；后序遍历是「把所有宫院都逛完，最后才回头看门口那块碑文」（打扫卫生的人——先收拾左右厢房，最后才到大殿）。**

### 生活映射
| 数据结构世界 | 故宫游览 |
|---|---|
| 先序（根-左-右） | 进午门就看太和殿（根），再看左边文华殿（左），再看右边武英殿（右） |
| 中序（左-根-右） | 先逛左边的御花园（左），再回到大殿（根），最后逛右边的后宫（右） |
| 后序（左-右-根） | 把左右偏殿都打扫完，最后才扫主殿（根）——因为根是 boss，最后出场 |
| 递归 | 每个宫院里面还套小院子，进屋规则和进大院一模一样 |
| 空树 | 这院子推门一看——空的，退出来 |
| 函数调用栈 | 你的游览路线图——每进一个院子就盖个戳，出来就划掉 |
| $O(h)$ 空间 | 最深能嵌套几层院子——最坏情况是「一进到底」的细长廊 |
