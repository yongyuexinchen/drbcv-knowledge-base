# 单链表的查找

## 类型判定
程序型 — 具体的算法操作步骤，含代码和复杂度分析。分为按位查找和按值查找两类，两者都需从头遍历，时间复杂度均为 $O(n)$（区别于顺序表按位查找的 $O(1)$）。

## 是什么
在单链表（带头结点）中查找结点：
- **按位查找**：找到第 $i$ 个结点（头结点视为第 0 个）并返回结点指针
- **按值查找**：找到第一个数据域等于给定值 $e$ 的结点并返回结点指针

找不到均返回 `NULL`。

## 输入-输出空间
- **输入**：链表 L（带头结点），位序 i（按位）或元素值 e（按值）
- **输出**：`LNode*`（找到的结点指针）或 `NULL`（未找到）
- **前置条件**：$0 \le i$（按位，i=0 返回头结点）

## 正例（≥2 个）
1. **按位查找 i=3**：从头结点开始，p 指针后跳 3 次 → 找到第 3 个数据结点 → $O(n)$
2. **按值查找 e=8**：从头结点后继开始扫描，在第 2 个结点匹配 → 停止，$O(n)$

## 反例/边界（≥1 个）
1. **i 越界（i > 表长）**：遍历到尾结点后 `p == NULL`，循环终止，返回 `NULL` → 调用者判断返回值是否为 `NULL` 即可知道是否越界
2. **i=0 按位查找**：返回头结点（第 0 个），不进行遍历 → 这是合法调用，常用于插入操作中找前驱

## 详细解释

### 核心代码：按位查找

```c
// 找到第 i 个结点（带头结点，头结点视为第 0 个）
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;          // i 不能为负

    LNode *p = L;                    // p 指向头结点（第 0 个）
    int j = 0;                       // j 记录当前 p 指向第几个结点

    while (p != NULL && j < i) {     // 后跳 i 次
        p = p->next;
        j++;
    }
    return p;                        // 可能是目标结点，也可能是 NULL
}
```

**执行示例**：i=3，表长=5
```
初始: p→头结点(0), j=0
第1轮: p→结点1, j=1
第2轮: p→结点2, j=2
第3轮: p→结点3, j=3 → 退出循环，返回结点3
```

### 核心代码：按值查找

```c
// 找到第一个 data == e 的结点
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;              // 从头结点的后继开始（跳过不存数据的头结点）

    while (p != NULL && p->data != e) // 逐个比较
        p = p->next;

    return p;                        // 找到 → 返回结点；找不到 → NULL
}
```

### 求表长

```c
int Length(LinkList L) {
    int len = 0;
    LNode *p = L->next;              // 从第一个数据结点开始
    while (p != NULL) {
        len++;
        p = p->next;
    }
    return len;
}
```

### 封装的价值

将查找封装为 `GetElem` 后，插入和删除可以复用：

```c
// 按位插入 = 找到前驱 + 后插
bool ListInsert(LinkList &L, int i, ElemType e) {
    LNode *p = GetElem(L, i - 1);    // 找第 i-1 个结点
    return InsertNextNode(p, e);     // 在其后插入
}
```

**好处**：如果 `GetElem` 有 bug，只需修一处（不用在插入和删除各修一遍）。

### 时间复杂度

| 操作 | 最好 | 最坏 | 平均 |
|------|------|------|------|
| **按位查找** | $O(1)$（i=0 或 i=1） | $O(n)$（i=n） | $O(n)$ |
| **按值查找** | $O(1)$（第一个匹配） | $O(n)$（最后一个匹配或不存在） | $O(n)$ |
| **求表长** | — | — | $O(n)$ |

### 与顺序表查找的对比

| 方面 | 顺序表按位 | 顺序表按值 | 单链表按位 | 单链表按值 |
|------|-----------|-----------|-----------|-----------|
| 时间复杂度 | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 核心原理 | 随机存取 | 顺序扫描 | 顺序扫描 | 顺序扫描 |
| 返回值 | 元素值 | 位序（int） | 结点指针 | 结点指针 |

## 类比

### 一句话比喻
**单链表按位查找就像你在一条没有门牌号的胡同里找"第 5 个门"——你必须从巷口第一家开始，数 1、2、3、4、5，一家一家走。顺序表按位查找则像一条编号清晰的大街，大喊一声"5 号"直接冲过去。按值查找就更惨了——你得挨家挨户敲门问"张三在不在"，找不到就继续敲下一家，敲完一整条街（$O(n)$）。**

### 生活映射
| 代码世界 | 按门牌号找人家 |
|---|---|
| `GetElem(L, 5)` | 沿着胡同数到第 5 家 |
| `p = p->next` | 往前走一家 |
| `j++` | 心里默数：这是第几家了 |
| `return NULL` | 走到死胡同了还没找到 |
| `LocateElem(L, "张三")` | 挨家敲门问"张三住这吗" |
| `p->data != e` | 开门的人不是张三，继续走 |
| `InsertNextNode(p, e)` | 在第 4 家后面加盖一间房 |
