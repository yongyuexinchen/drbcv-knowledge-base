# 邻接矩阵（Adjacency Matrix）

## 类型判定
判别型 — 图的**顺序存储**实现，`is_a` 图的存储结构，核心是用二维数组 $A[i][j]$ 表示顶点 $i$ 和 $j$ 之间的连接关系。

## 是什么
用一个 $n \times n$ 的二维数组（矩阵）存储图中各顶点之间的邻接关系：
- **无权图**：$A[i][j] = 1$ 表示有边/弧，$0$ 表示无边
- **带权图（网）**：$A[i][j] = w_{ij}$（权值），无边用 $\infty$（或 0）表示

同时用一个一维数组存储各顶点的数据信息。

## 输入-输出空间
- **输入**：顶点集 $V$ + 边集 $E$
- **输出**：$n \times n$ 矩阵 + $n$ 长顶点数组
- **空间复杂度**：$O(|V|^2)$

## 正例（≥2 个）
1. **微信好友（无向图）**：A-B 有边 → $A[0][1]=A[1][0]=1$，每一条无向边在矩阵中对应两个 1
2. **微博关注（有向图）**：A 关注 B → $A[0][1]=1$ 但 $A[1][0]=0$，每条弧只对应一个 1

## 反例/边界（≥1 个）
1. **稀疏图**：$|E| \ll |V|^2$ 时矩阵大量元素为 0，空间严重浪费 → 应改用邻接表
2. **存储 int 型权值却用 int 存 0/1**：每个元素占 4~8 字节，可优化为 bool/enum（1 字节）

## 详细解释

### 代码定义
```c
#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];             // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum]; // 邻接矩阵（边表）
    int vexnum, arcnum;                  // 顶点数、边数
} MGraph;
```

### 求顶点的度
| 操作 | 无向图 | 有向图 |
|------|--------|--------|
| 度 TD(v) | 遍历第 $i$ 行（或列），数非零元素 | 行非零 = 出度；列非零 = 入度；和 = 度 |
| 时间复杂度 | $O(|V|)$ | $O(|V|)$ |

### 带权图的表示
```c
#define INFINITY 最大的int值   // 宏定义"无穷"
// A[i][j] = 权值 或 INFINITY
// 有时 A[i][i] = 0（自己到自己距离为0）
```

### 邻接矩阵的幂次性质（无权图）
设 $A$ 为图 $G$ 的邻接矩阵，则 $A^n[i][j]$ 的值 = 从顶点 $i$ 到顶点 $j$ **长度为 $n$ 的路径数目**。

例：$A^2[i][j] = \sum_k A[i][k] \times A[k][j]$ —— 即经过一个中间顶点 $k$ 的路径数。

### 性能分析
| 特性 | 评价 |
|------|------|
| 空间复杂度 | $O(|V|^2)$ |
| 适合场景 | 稠密图（边多） |
| 表示唯一性 | ✅ 给定图 + 顶点编号 → 矩阵唯一 |
| 判断边存在 | $O(1)$ 直接查 $A[i][j]$ |
| 找邻接点 | 需遍历整行/列，$O(|V|)$ |

### 无向图矩阵是对称矩阵
可利用对称矩阵压缩存储：只存上三角或下三角，节省一半空间。

## 类比

### 一句话比喻
**邻接矩阵就像飞机场的航班时刻表公告牌——横向是所有出发城市，纵向是所有到达城市。格子里写"1"代表有直飞航班，写"0"代表没有。想知道北京到上海有没有直飞？看一眼第「北京」行第「上海」列就行，$O(1)$ 秒出结果。但问题是：全国 300 个城市，公告牌就得 300×300 = 90000 个格子——如果大部分城市之间都没直飞，这牌子 99% 是空白的，纯属浪费空间。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 邻接矩阵 $A[i][j]$ | 航班公告牌：第 i 行第 j 列 |
| $A[i][j] = 1$ | 有直飞航班 |
| $A[i][j] = 0$ | 没有直飞 |
| 无向图对称 | 去程=回程（北京-上海双向都有） |
| 有向图不对称 | 单向航班（只有北京→上海，没有返程） |
| 求顶点的度 | 数这个城市有多少直飞航线 |
| $O(|V|^2)$ 空间 | 300 个城市要 9 万个格子 |
| 矩阵唯一 | 按城市编号排序，公告牌只有一种排法 |
| 稀疏图浪费 | 大部分格子是空的，牌子白做了 |
| $A^2[i][j]$ | 经停一次的中转航线有几条 |
