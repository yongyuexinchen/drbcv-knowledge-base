# BFS（广度优先遍历）

## 类型判定
程序型 — 图的遍历算法，含代码、复杂度分析，并衍生出 BFS 求无权图最短路径。`analogous_to` 树的层序遍历。

## 是什么
BFS（Breadth-First Search）从起始顶点出发，逐层访问——先访问距离为 1 的所有邻接点，再访问距离为 2 的，依次扩展。核心依赖：辅助队列 + visited 标记数组。

## 输入-输出空间
- **输入**：图 $G$（邻接矩阵或邻接表存储），起始顶点 $v$
- **输出**：遍历序列（所有顶点被访问一次）
- **前置条件**：无。非连通图自动通过外层 for 循环处理所有连通分量

## 正例（≥2 个）
1. **连通图一次遍历全部**：从顶点 2 出发 → 2, 1, 6, 5, 3, 7, 4, 8（按邻接矩阵顺序）
2. **BFS 求无权图最短路径**：从顶点 2 出发，BFS 的层数直接 = 距离 → `d[1]=1, d[5]=2, d[8]=3`

## 反例/边界（≥1 个）
1. **忘记 visited 标记**：图中存在回路时 → 死循环，同一顶点被反复入队
2. **非连通图只调一次 BFS**：只能遍历一个连通分量 → 必须外层 for 循环扫描 visited 数组

## 详细解释

### 核心代码
```c
bool visited[MAX_VERTEX_NUM];      // 标记数组
Queue Q;                            // 辅助队列

void BFS(Graph G, int v) {         // 从顶点 v 出发
    visit(v);
    visited[v] = true;
    EnQueue(Q, v);

    while (!QueueEmpty(Q)) {
        DeQueue(Q, v);
        for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
            if (!visited[w]) {
                visit(w);
                visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}

// 处理非连通图
void BFSTraverse(Graph G) {
    for (int i = 0; i < G.vexnum; i++)
        visited[i] = false;
    InitQueue(Q);
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i])
            BFS(G, i);            // 每个连通分量调用一次
}
```

### 复杂度分析
| 存储结构 | 时间复杂度 | 空间复杂度 |
|----------|-----------|-----------|
| 邻接矩阵 | $O(|V|^2)$ | $O(|V|)$（辅助队列最坏大小） |
| 邻接表 | $O(|V| + |E|)$ | $O(|V|)$ |

**分析方法**：时间开销 = 访问所有顶点 + 探索所有边。邻接表探索边只需遍历边结点（$O(|E|)$），邻接矩阵需扫描整行（$O(|V|)$ / 每个顶点）。

### BFS 调用次数
- **无向图**：调用次数 = 连通分量个数
- **有向图**：强连通图只需 1 次，否则可能需多次
- **连通图/强连通图**：1 次

### 广度优先生成树
BFS 过程中，当某个顶点**第一次被访问**时所经过的边 → 标红保留 → 构成 $n$ 个顶点 $n-1$ 条边的树。
- 邻接矩阵存储：生成树唯一
- 邻接表存储：生成树不唯一（边结点顺序可变）

### BFS 求无权图最短路径

改造 BFS：增加两个数组 `d[]`（最短距离）和 `path[]`（直接前驱）。

```c
int d[MAX_VERTEX_NUM];    // d[i] = 从起点到 i 的最短距离
int path[MAX_VERTEX_NUM]; // path[i] = 最短路径上 i 的直接前驱

void BFS_MinDistance(Graph G, int u) {
    for (int i = 0; i < G.vexnum; i++) {
        d[i] = INFINITY;          // 初始无穷
        path[i] = -1;             // 初始无前驱
    }
    d[u] = 0;
    visited[u] = true;
    EnQueue(Q, u);

    while (!QueueEmpty(Q)) {
        DeQueue(Q, u);
        for (w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w)) {
            if (!visited[w]) {
                d[w] = d[u] + 1;        // 距离 = 前驱距离 + 1
                path[w] = u;            // 记录前驱
                visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}
```

**回溯路径**：从目标顶点沿 `path[]` 倒推直到起点（值为 -1），再反转。

**限制**：只能求**无权图**（或所有边权值为 1 的图）。带权图需用 Dijkstra。

## 类比

### 一句话比喻
**BFS 就像你在朋友圈找一个人——先把你所有直接朋友（距离 1）问一遍，都没找到的话，再让这些朋友去问他们的朋友（距离 2），一层层扩散。最先找到的那条路径一定是最短的（经过的人最少）。而 DFS 则是逮住一个朋友，让他一路问到底，走到死胡同再换人——显然 BFS 更适合找人。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 起始顶点 | 你——找人发起者 |
| 队列 | 待问名单（先来先问） |
| visited 标记 | 已问过的人——防止重复问同一个人 |
| 第一层邻接点 | 你的直接朋友（距离 1） |
| 第二层邻接点 | 朋友的朋友（距离 2） |
| 生成树的标红边 | 「谁介绍你认识谁的」——首次接触的路径 |
| BFS 调用次数 | 互不相干的几个社交圈——每个圈子都得从圈内发起 |
| `d[w] = d[u] + 1` | 你是我通过 N 个人找到的，所以距离是 N+1 |
| `path[w] = u` | 记住：我是通过谁找到你的 |
| 无权图最短路径 | 找最少中间人的路径 |
