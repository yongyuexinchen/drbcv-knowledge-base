# 排序算法比较（Sorting Algorithm Comparison）

## 类型判定
比较型 — 汇总第8章所有排序算法的时间复杂度、空间复杂度、稳定性、适用场景，方便横向对比和考前复习。

## 是什么
一张表看清所有排序算法的核心指标，帮你根据题目条件快速选出最优算法。

## 核心对比表

| 排序算法 | 最好时间 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 趟数与初始状态 |
|---------|---------|---------|---------|------|--------|--------------|
| **直接插入排序** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅ 稳定 | 相关（有序时快） |
| **折半插入排序** | $O(n \log n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅ 稳定 | 比较次数相关，移动次数相关 |
| **希尔排序** | — | ~$O(n^{1.3})$ | $O(n^2)$ | $O(1)$ | ❌ 不稳定 | 相关 |
| **冒泡排序** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✅ 稳定 | 相关（有序可提前结束） |
| **快速排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ ~ $O(n)$ | ❌ 不稳定 | 相关（划分均匀度决定） |
| **简单选择排序** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ❌ 不稳定 | **无关** |
| **堆排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | ❌ 不稳定 | 无关 |
| **归并排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | ✅ 稳定 | 无关 |
| **基数排序** | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(r)$ | ✅ 稳定 | 无关 |
| **计数排序** | $O(n+K)$ | $O(n+K)$ | $O(n+K)$ | $O(n+K)$ | ✅ 稳定 | 无关 |

## 归类速记

### 按时间复杂度分类
- **$O(n^2)$**：直接插入、折半插入、冒泡、简单选择
- **$O(n \log n)$**：快速、堆、归并
- **$O(n)$ 级（有条件）**：基数 $O(d(n+r))$、计数 $O(n+K)$

### 按稳定性分类
- **稳定**：直接插入、折半插入、冒泡、归并、基数、计数
- **不稳定**：希尔、快速、简单选择、堆

### 按一趟能否确定一个元素最终位置
- **能**：快速（枢轴）、冒泡（最大/最小）、简单选择（最小）、堆（堆顶）
- **不能**：直接插入、希尔、归并、基数、计数

## 选择策略（考试做题指南）

| 条件 | 推荐算法 |
|------|---------|
| 序列基本有序 | **直接插入排序** 或 冒泡排序（$O(n)$） |
| n 较小（≤50） | 直接插入 或 简单选择 |
| n 较大，要求 $O(n \log n)$ | 快速排序（平均最优）、堆排序、归并排序 |
| n 较大，要求 $O(n \log n)$ 且稳定 | **归并排序**（唯一选择！） |
| n 较大，关键字可拆分为 d 位且 r 小 | **基数排序** |
| 元素取值范围 [0,K] 且 K=O(n) | **计数排序** |
| 数据量大到内存放不下 | 外部排序（归并 + 置换-选择 + 败者树 + 最佳归并树） |
| 只要求时间高效，不管空间 | 计数排序（空间换时间） |

## 特殊记忆点

1. **"基本有序"用插入排序**：这是希尔排序的思想来源
2. **快排最怕有序**：选第一个元素为枢轴，已有序 → $O(n^2)$
3. **堆排序建堆只需 $O(n)$**：虽然每趟 $O(\log n)$，但建堆不是 $O(n \log n)$
4. **归并排序空间 $O(n)$**：内部排序中空间最大的
5. **简单选择排序比较次数固定**：$\frac{n(n-1)}{2}$，与初始状态无关
6. **基数排序"鸡你太稳"**：稳定到飞起
7. **408一道排序题**：先看是否要求稳定 → 缩小范围 → 再看时间要求 → 确定算法

## 类比 ★

### 一句话比喻
**排序算法就像各种交通方式——冒泡是走路（慢但稳），快排是高铁（快但偶尔出状况），归并是飞机（快且稳但贵（费空间）），基数排序是瞬移（快到离谱但需要特定条件），计数排序是直升机（空间换时间）。选哪个取决于你赶不赶时间（时间复杂度）、有没有钱买空间（空间复杂度）、以及你对"同路人是否能保持原队形"的执念（稳定性）。**

### 生活映射
| 算法 | 交通方式 | 特点 |
|------|---------|------|
| 冒泡 | 步行 | 慢但稳，路熟（有序）就快 |
| 快排 | 高铁 | 平均最快，但遇上堵车（有序）会崩溃 |
| 归并 | 飞机 | 快又稳，但机票贵（要 O(n) 空间） |
| 堆排 | 赛车 | 快且省油（O(1)空间），但不稳 |
| 基数 | 瞬移 | 需要特定传送门（d小r小n大） |
| 计数 | 直升机 | 空间换时间，停机坪要大 |
