# 线索二叉树找前驱后继（Find Predecessor & Successor in Threaded Tree）

## 类型判定
程序型 — 在已线索化的二叉树中，利用 tag 标志 + 树形结构特征，快速定位指定结点的前驱和后继。

## 是什么
线索化之后，利用 `ltag`/`rtag` 区分「线索指针」和「孩子指针」，根据不同线索类型（中序/先序/后序）的规则，高效找到指定结点的遍历序列中的前驱和后继。

## 输入-输出空间
- **输入**：指定结点指针 `p`（线索二叉树中的某一结点）
- **输出**：`p` 的前驱结点或后继结点指针
- **前置条件**：二叉树已完成对应类型的线索化

## 正例（≥2 个）
1. **中序线索二叉树找后继**：若 `rtag=1` 直接返回 `rchild`；否则后继 = 右子树最左下结点
2. **中序线索二叉树找前驱**：若 `ltag=1` 直接返回 `lchild`；否则前驱 = 左子树最右下结点

## 反例/边界（≥1 个）
1. **先序线索二叉树找前驱**（二叉链表）：若 `ltag=0`，无法直接找到前驱，必须从头遍历——因为左右子树都在 p 之后访问，而只有向下指针没有向上指针
2. **后序线索二叉树找后继**（二叉链表）：若 `rtag=0`，无法直接找到后继，必须从头遍历——因为左右子树都在 p 之前访问

## 详细解释

### 中序线索二叉树（最完整，前后都能找）

**找后继**：
```c
ThreadNode *FirstNode(ThreadNode *p) {
    // 找到以 p 为根的子树中第一个被中序遍历的结点（最左下）
    while (p->ltag == 0) p = p->lchild;
    return p;
}

ThreadNode *NextNode(ThreadNode *p) {
    if (p->rtag == 0) return FirstNode(p->rchild);  // 右子树最左下
    else return p->rchild;                           // 后继线索
}
```

**找前驱**：
```c
ThreadNode *LastNode(ThreadNode *p) {
    // 找到以 p 为根的子树中最后一个被中序遍历的结点（最右下）
    while (p->rtag == 0) p = p->rchild;
    return p;
}

ThreadNode *PreNode(ThreadNode *p) {
    if (p->ltag == 0) return LastNode(p->lchild);   // 左子树最右下
    else return p->lchild;                           // 前驱线索
}
```

**中序遍历（利用后继，O(1) 空间）**：
```c
void InOrder(ThreadTree T) {
    for (ThreadNode *p = FirstNode(T); p != NULL; p = NextNode(p))
        visit(p);
}
```

### 先序线索二叉树

| 操作 | 条件 | 方法 |
|------|------|------|
| 找后继 | `rtag=1` | 直接返回 `rchild` |
| 找后继 | `rtag=0` 且有左孩子 | 后继 = 左孩子 |
| 找后继 | `rtag=0` 且无左孩子 | 后继 = 右孩子 |
| 找前驱 | `ltag=1` | 直接返回 `lchild` |
| 找前驱 | `ltag=0`（二叉链表） | **无法直接找到** → 需要三叉链表或从头遍历 |
| 找前驱 | `ltag=0`（三叉链表） | 分情况讨论（左孩子/右孩子/左兄弟空/左兄弟非空） |

### 后序线索二叉树

| 操作 | 条件 | 方法 |
|------|------|------|
| 找前驱 | `ltag=1` | 直接返回 `lchild` |
| 找前驱 | `ltag=0` 且有右孩子 | 前驱 = 右孩子 |
| 找前驱 | `ltag=0` 且无右孩子 | 前驱 = 左孩子 |
| 找后继 | `rtag=1` | 直接返回 `rchild` |
| 找后继 | `rtag=0`（二叉链表） | **无法直接找到** → 需要三叉链表或从头遍历 |
| 找后继 | `rtag=0`（三叉链表） | 分情况讨论（右孩子/左孩子+右兄弟空/左孩子+右兄弟非空） |

### 三种线索树能力总结

| | 找前驱 | 找后继 | 正向遍历 | 逆向遍历 |
|---|---|---|---|---|
| **中序** | ✅ 可以 | ✅ 可以 | ✅ | ✅ |
| **先序** | ❌（二叉链表不行） | ✅ | ✅（利用后继） | ❌ |
| **后序** | ✅ | ❌（二叉链表不行） | ❌ | ✅（利用前驱） |

## 类比

### 一句话比喻
**线索二叉树找前驱后继就像在高速公路上开导航——如果下一个出口有路标（`rtag=1`），你直接按路标开就行；如果没路标（`rtag=0`），说明前面是个岔路口（还有右孩子），那你得下岔路，一直靠最左边开到尽头（最左下），那里才是你「按顺序该去的下一站」。**

### 生活映射
| 数据结构世界 | 高速公路导航 |
|---|---|
| `rtag=1`（后继线索） | 路标：「下一出口 5km」→ 直接开到 |
| `rtag=0`（有右孩子） | 没路标但有岔路 → 下岔路一直靠左走到尽头 |
| 最左下结点 | 在岔路区域里「最先路过的那个小镇」 |
| 中序前后都能找 | 中序 = 双向导航（前后都能去） |
| 先序找前驱不行 | 先序 = 只有「往前开」的导航，没法倒车（除非你知道你爸在哪） |
| 后序找后继不行 | 后序 = 只有「倒车」的导航，没法往前开（除非你知道你爸在哪） |
| 三叉链表 | GPS 定位——不仅知道前后路，还知道你爸家的地址 |
