# 循环链表（Circular Linked List）

## 类型判定
判别型 — 循环链表是单链表/双链表的简单变形：把尾结点的 next 指针从 `NULL` 改为指向头结点，形成闭环。核心区别在于判空条件和遍历终止条件的变化。

## 是什么
循环链表分为两种：
- **循环单链表**：表尾结点的 `next` 指向头结点（而不是 `NULL`）
- **循环双链表**：表尾的 `next` 指向头结点，头结点的 `prior` 指向表尾 → 双向闭环

## 输入-输出空间
- **输入**：无（物理结构定义）
- **输出**：无
- **核心特性**：从任意结点出发都能访问到链表中所有结点（单链表只能往后访问）

## 正例（≥2 个）
1. **循环单链表头尾操作优化**：让头指针 L 指向表尾结点（而不是表头），则找表头只需 `L->next`（$O(1)$），找表尾就是 L 本身（$O(1)$）→ 非常适合频繁操作头尾的场景
2. **循环双链表删除最后一个结点**：由于表尾 `next` 指向头结点（而非 NULL），删除代码中 `q->next->prior = p` 永远合法，不需要空指针判断 → 比普通双链表更简洁

## 反例/边界（≥1 个）
1. **遍历死循环**：如果忘记修改循环终止条件（仍用 `p != NULL`），指针会永远在环里打转 → 正确条件：`p != L`（回到头结点时停止）
2. **普通单链表的判空 `L->next == NULL` 不适用于循环链表**：循环链表的判空是 `L->next == L`（头结点指向自身）

## 详细解释

### 循环单链表

```c
// 初始化
bool InitList(LinkList &L) {
    L = (LNode *)malloc(sizeof(LNode));
    if (L == NULL) return false;
    L->next = L;           // 自己指向自己（与普通单链表的 NULL 不同！）
    return true;
}

// 判空
bool Empty(LinkList L) {
    return (L->next == L);
}

// 判断是否到表尾
bool IsTail(LinkList L, LNode *p) {
    return (p->next == L);  // 后继是头结点
}
```

### 循环单链表的优化：L 指向表尾

```c
// 如果 L 指向表尾结点，则：
// 表头 = L->next（O(1)）
// 表尾 = L（O(1)）

// 普通单链表找表尾：从头走到尾，O(n)
```

### 循环双链表

```c
// 初始化
bool InitDLinkList(DLinkList &L) {
    L = (DNode *)malloc(sizeof(DNode));
    if (L == NULL) return false;
    L->prior = L;          // 前驱指向自己
    L->next = L;           // 后继指向自己
    return true;
}

// 判空
bool Empty(DLinkList L) {
    return (L->next == L);  // 自己指向自己
}

// 表尾判断
bool IsTail(DLinkList L, DNode *p) {
    return (p->next == L);
}
```

### 循环双链表的优势：插入删除无需空指针判断

```c
// 在 p 之后插入 s（循环双链表 — 无需判断 p->next 是否为 NULL）
s->next = p->next;
p->next->prior = s;    // 即使 p 是表尾，p->next 指向头结点，合法！
s->prior = p;
p->next = s;
```

### 各链表判空/表尾对比

| 链表类型 | 判空条件 | 表尾判断 | 初始化时 next 指向 |
|---------|---------|---------|------------------|
| 普通单链表（带头） | `L->next == NULL` | `p->next == NULL` | `NULL` |
| 循环单链表 | `L->next == L` | `p->next == L` | `L`（自己） |
| 普通双链表（带头） | `L->next == NULL` | `p->next == NULL` | `NULL` |
| 循环双链表 | `L->next == L` | `p->next == L` | `L`（自己） |
| 不带头单链表 | `L == NULL` | `p->next == NULL` | — |

## 类比

### 一句话比喻
**普通单链表是一条断头路——走到最后一个结点就掉下悬崖（NULL）。循环单链表是把这条路修成了环形跑道——从最后一个结点再跑一步就回到了起点。循环单链表的空表就像一个孤单的人自己抱着自己转圈（next 指向自己）。循环双链表更夸张——双手自己抱住自己转圈（prior 和 next 都指向自己）。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 循环单链表 `L->next = L` | 一个圆桌，每个人右手搭在下一个人的右肩上，最后一个人搭回第一个人 |
| `L` 指向表尾的优化 | 你站在圆桌"最后一人的位置"，找他下一个（表头）只需一步 |
| 判空：`L->next == L` | 桌子旁只有你一个人，你右手搭在自己肩上 |
| 循环双链表空表 | 你一个人，左手和右手都搭在自己肩上 |
| 遍历死循环 `p != NULL` | 你在环形跑道上跑，永远没尽头 |
| 遍历终止 `p != L` | 跑回起点就停 |
