# 冒泡排序（Bubble Sort）

## 类型判定
程序型 — 冒泡排序属于**交换排序**大类，通过相邻元素两两比较并交换，使最大（或最小）的元素像气泡一样"浮"到最终位置。

## 是什么
冒泡排序每一趟从后往前（或从前往后）依次对比相邻的两个元素，若逆序则交换，一趟结束后最小的元素"冒"到最前面。重复 n-1 趟，若某一趟**没有发生任何交换**，说明已全局有序，可提前终止。

## 输入-输出空间
- **输入**：数组 A[0..n-1]，n 个元素
- **输出**：递增（或递减）有序的数组
- **前置条件**：无

## 正例（≥2 个）
1. **已有序序列**：`[1, 2, 3, 4, 5]` → 第一趟扫描 n-1 次比较，0 次交换，直接结束 → **$O(n)$（最好情况）**
2. **一般乱序**：每趟确定一个最小元素的位置，经过 n-1 趟（或提前结束）排好

## 反例/边界（≥1 个）
1. **完全逆序**：`[5, 4, 3, 2, 1]` → 每趟都要把最小元素"冒"到最前，比较次数 = 交换次数 = $n(n-1)/2$ → $O(n^2)$ 最坏
2. **"交换次数" ≠ "移动次数"**：每次 swap 需要 3 次移动（temp=A; A=B; B=temp），考题可能区分这两个概念！

## 详细解释

### 核心代码（从后往前冒泡）
```c
void BubbleSort(int A[], int n) {
    int i, j;
    bool flag;                          // 标记本趟是否发生交换
    for (i = 0; i < n - 1; i++) {
        flag = false;
        for (j = n - 1; j > i; j--) {   // 从后往前两两比较
            if (A[j - 1] > A[j]) {      // 逆序则交换
                swap(A[j - 1], A[j]);
                flag = true;
            }
        }
        if (!flag) return;              // 本趟无交换 → 已有序 → 提前结束！
    }
}
```

### 关键注意事项
- **flag 的作用**：检测是否提前有序——这是冒泡排序独有的优化
- 也可以"从前往后冒大泡"：让最大元素冒到最后——本质相同
- 相等时不交换（`A[j-1] > A[j]` 而非 `>=`）→ **算法稳定**
- 适用于链表：从头扫描，把更大的往后冒——实现思路一致

### 时间复杂度
| 情况 | 比较次数 | 交换次数 | 复杂度 |
|------|---------|---------|--------|
| 最好（已有序） | n-1 | 0 | $O(n)$ |
| 最坏（逆序） | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ | $O(n^2)$ |
| 平均 | — | — | $O(n^2)$ |

- 空间复杂度：**$O(1)$**
- 稳定性：**稳定**（相等不交换）
- 适用存储：顺序表和链表均可

## 类比 ★

### 一句话比喻
**冒泡排序就像小鱼吐泡泡——水底的泡泡最小最轻，自己一路往上冒，经过每个比它大的泡泡都说"借过借过"换位往上。最后所有泡泡从水面往下看，从小到大排好了。如果某一次一个泡泡都没换位置，说明已经排好了——不用再吐了。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 一趟冒泡 | 一个泡泡从水底浮到水面 |
| 相邻两两比较 | 两个泡泡碰一起，小的说"我比你轻，让我上去" |
| swap 交换 | 两个泡泡互换位置 |
| flag 标记 | "这趟下来谁都没动 → 全排好了，收工！" |
| 最好 $O(n)$ | 本来就从矮到高站好了——看一眼就过 |
| 最坏 $O(n^2)$ | 完全反着站——每个都要一路漂到顶 |
