# 树的基本概念与性质（Tree）

## 类型判定
判别型 — 树是「一对多」的层次数据结构，`is_a` 非线性结构，核心特征是除根结点外每个结点有且仅有一个前驱。

## 是什么
树是 **n（n≥0）个结点的有限集合**。当 n=0 时为空树；非空树满足：
- 有且仅有一个**根结点**（root）
- 其余结点可分为 m 个互不相交的有限集合，每个集合本身又是一棵树，称为根的**子树**（subtree）

树是一种**递归定义**的数据结构——任何一棵树都可以看作「根结点 + 若干不相交的子树」。

## 输入-输出空间
- **输入**：无（逻辑结构，不涉及输入输出）
- **输出**：无
- **核心约束**：除根结点外，每个结点有且仅有一个前驱（父结点）；可以有零个或多个后继（子结点）

## 正例（≥2 个）
1. **电脑文件系统**：C 盘下有多层文件夹，每个文件夹可包含子文件夹和文件——典型树形结构
2. **公司组织架构**：CEO → 部门经理 → 小组长 → 员工，层层分支，每个员工只向一个上级汇报
3. **思维导图**：根结点 → 一级分支 → 二级分支，子树之间互不相交

## 反例/边界（≥1 个）
1. **图/网**：如果一个结点有两个前驱（如 F 的父结点既可以是 B 也可以是 E），则不是树，而是图
2. **空树**：n=0，是合法的树——没有结点也是一种树（注意与度为 m 的树区分，后者至少要有 m+1 个结点）
3. **线性表**：一对一关系，每个元素最多一个后继 → 不是树（树是一对多）

## 详细解释

### 基本术语（家族谱系比喻）

| 术语 | 含义 |
|------|------|
| **根结点** | 最顶层结点，没有前驱 |
| **叶子结点 / 终端结点** | 度为 0 的结点，没有孩子 |
| **分支结点 / 非终端结点** | 度 > 0 的结点 |
| **祖先结点** | 从该结点出发向上走到根所经过的所有结点 |
| **子孙结点** | 从该结点出发向下所有分支上的结点 |
| **双亲 / 父结点** | 直接前驱 |
| **孩子 / 子结点** | 直接后继 |
| **兄弟结点** | 同一个双亲的孩子之间 |
| **堂兄弟结点** | 同一层的结点（双亲不同） |
| **结点的度** | 该结点的孩子数 / 分支数 |
| **树的度** | 树中所有结点度的最大值 |
| **结点的层次（深度）** | 从根往下数，根为第 1 层 |
| **结点的高度** | 从叶子往上数，叶子高度为 1 |
| **树的高度（深度）** | 树的总层数 |
| **路径** | 两个结点之间从上到下的边序列（单向，只能从上往下） |
| **路径长度** | 路径经过的边数 |
| **有序树 vs 无序树** | 子树从左到右是否有次序（家谱=有序，行政区划=无序） |
| **森林** | m（m≥0）棵互不相交的树的集合 |

### 树的基本性质

**性质 1：结点数 = 总度数 + 1**
每个结点（除根外）头上都连有一条边（来自父结点），所以「边数 = 结点数 − 1」，而边数 = 总度数。

**性质 2：度为 m 的树 vs m 叉树**

| | 度为 m 的树 | m 叉树 |
|---|---|---|
| 含义 | 各结点度的最大值 = m | 每个结点最多 m 个孩子 |
| 至少有一个度为 m 的结点？ | 是 | 否 |
| 允许空树？ | 否（至少 m+1 个结点） | 是 |
| 结点数下限（高度 h） | h + m − 1 | h |

**性质 3：第 i 层至多有 $m^{i-1}$ 个结点**（m 叉树或度为 m 的树）

**性质 4：高度为 h 的 m 叉树至多有 $\frac{m^h - 1}{m - 1}$ 个结点**（等比数列求和）

**性质 5：高度为 h 的 m 叉树至少有 h 个结点**（每层一个结点）

**性质 6：n 个结点的 m 叉树最小高度**：$h_{\min} = \lceil \log_m (n(m-1) + 1) \rceil$

## 类比

### 一句话比喻
**树就是一本族谱——老祖宗（根结点）在最上面，每一代往下开枝散叶。每页只写一个人的名字和他几个孩子，孩子下面又挂孙子……翻族谱只能从上往下翻（单向路径），不能说从孙子反着找祖宗——那叫"查族谱"（逆向遍历，需要额外手段）。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 根结点 | 老祖宗（族谱第一页） |
| 分支结点 | 生了孩子的族人 |
| 叶子结点 | 没后代（或族谱没往下记）的人 |
| 父结点 / 子结点 | 父子关系，一目了然 |
| 兄弟结点 | 同一爹生的兄弟姐妹 |
| 堂兄弟 | 同辈但不同爹——你叔叔的孩子 |
| 结点的度 | 一个人生了几个孩子 |
| 树的度 | 这家族里最能生的人有几个孩子 |
| 路径（单向） | 族谱只能从上往下查——从祖宗找后人，不能从后人反推祖宗 |
| 森林 | 好几本不同姓氏的族谱摞在一起 |
| 有序树 | 族谱按出生顺序排列（老大在左，老幺在右） |
| 无序树 | 行政区划——省下面几个市，排前排后无所谓 |
