# 红黑树（RBT, Red-Black Tree）

## 类型判定
判别型 + 程序型 — 定义（五条口诀）+ 性质 + 插入调整（看叔叔颜色，旋转+染色）。

## 是什么
一种**相对平衡**的二叉排序树，通过颜色约束（红/黑）和少量旋转来维持近似平衡。相比 AVL 树，插入删除时**调整次数更少、更高效**，是工程中最常用的平衡 BST（如 C++ STL map/set、Java TreeMap）。

## 为什么要发明红黑树
AVL 树要求 `|bf| ≤ 1`（太严格），插入/删除频繁破坏平衡 → 每次都要计算平衡因子、找最小不平衡子树 → **调整开销大**。红黑树约束更宽松（最长路径 ≤ 2× 最短路径），插入后很多情况**不需要调整**，即便调整也是常数级旋转。

## 五条口诀（背下来！）

> **左根右、根叶黑、不红红、黑路同**

| # | 口诀 | 含义 |
|---|---|---|
| 1 | **左根右** | 是 BST：左 < 根 < 右 |
| 2 | **根叶黑** | 根结点必黑；叶结点（失败结点/NULL）必黑 |
| 3 | **不红红** | 不存在相邻的红色结点（红结点的父和子必黑） |
| 4 | **黑路同** | 从任一结点出发到任意叶结点，路径上黑结点数相同 |

### 补充概念：黑高
结点的**黑高** = 从该结点到任意叶结点路径上的黑结点数（不含自身）。由"黑路同"保证唯一。

### 重要性质
1. **最长路径 ≤ 2 × 最短路径**：由"不红红"和"黑路同"推出
2. **高度 $h \leq 2\log_2(n+1)$**：保证查找 $O(\log n)$
3. 黑高为 $h$ 的红黑树，内部结点至少 $2^h - 1$ 个（全黑满树）

## 正例（≥2 个）
1. **根黑，左右红孩子**：根(黑)-左(红)-右(红) → 满足所有规则
2. **全黑满二叉树**：最简单也最标准的红黑树

## 反例/边界（≥1 个）
1. **红结点父子相连**：父红子也红 → 违反"不红红" → 不是红黑树
2. **根结点是红色**：违反"根叶黑" → 不是红黑树
3. **左右黑路不同长**：从根走左边经过 1 黑，走右边经过 2 黑 → 违反"黑路同"

## 详细解释

### 插入策略（两阶段）

**阶段 0：插入**
- 新结点若是根 → **染黑**
- 新结点若非根 → **染红**（保证不破坏"黑路同"）
- 若父亲是黑色 → 不破坏"不红红" → **直接结束！**

**阶段 1：调整（父结点是红色时）**
看**叔叔的脸色**：

| 叔叔颜色 | 操作 | 后续 |
|---|---|---|
| **黑叔叔** | 旋转 + 染色（看 LL/RR/LR/RL，和 AVL 完全一样！） | 结束 |
| **红叔叔** | 叔、父、爷全部**染色**（红变黑、黑变红），**爷变新结点** | 把爷当作新插入结点，回到阶段 0 |

### 旋转策略（和 AVL 完全一致！）
| 类型 | 旋转 | 染色对象 |
|---|---|---|
| LL | 父**右单旋**替代爷 | 父和爷互换颜色 |
| RR | 父**左单旋**替代爷 | 父和爷互换颜色 |
| LR | 儿**先左后右**替代爷 | 儿和爷互换颜色 |
| RL | 儿**先右后左**替代爷 | 儿和爷互换颜色 |

**关键记忆**：谁替了爷的位置，谁就和爷互换颜色！

### 插入举例：构建 20→10→5→30→40 的红黑树
1. 插 20：根 → 染黑
2. 插 10：非根 → 染红，父(20)黑 → 不调整
3. 插 5：染红，父(10)红！叔是黑(叶)且 LL → 父(10)右旋 + 父爷互换颜色
4. 插 30：染红，父(20)黑 → 不调整
5. 插 40：染红，父(30)红！叔是红 → 叔父爷全染色，爷变新结点 → 爷(20)是根 → 染黑

### 复杂度
- 查找/插入/删除：均为 $O(\log n)$
- 插入最多 2 次旋转（LR/RL），常为 0~1 次

## 类比 ★

### 一句话比喻
**红黑树就像黑社会帮派——帮主（根）必须是黑的，各级堂口老大（结点）要么红要么黑。规矩就三条：①红人的上下级不能也是红人（不红红）——防止一派独大；②从帮主到任何一个底层小弟，经过的黑道人数必须一样（黑路同）——防止层级太悬殊；③最底层的小弟（叶子）全部是黑的（根叶黑）。新人入帮（插入）先穿红衣，不破坏规矩就没事；破坏了就看"叔叔"——黑叔叔讲道理，旋转一下坐次就行；红叔叔是个搅屎棍，大家一起换颜色，让爷爷重新排队。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| 红结点 | 新提拔的干部（活跃但不稳定） |
| 黑结点 | 老干部（稳定，决定层级深度） |
| "不红红" | 不能父子俩都是新干部——权力太集中 |
| "黑路同" | 不管走哪条晋升路线，经历的老干部数量一样 |
| 叔叔是黑 → 旋转 | 旁边堂口老大是老干部，讲道理——调整坐次解决 |
| 叔叔是红 → 染色 | 旁边堂口也是新干部，一起重新洗牌 |
| 爷变新结点 | 爷爷被重新审查——看他在新位置上是否违规 |
| 插入常不需调整 | 大多数新人入帮风平浪静 |
| $h \leq 2\log_2 n$ | 再乱也乱不过 2 倍最优高度 |
