# 双链表（Doubly Linked List）

## 类型判定
判别型 — 双链表在单链表基础上为每个结点增加了一个前驱指针（prior），解决了单链表"只能往后找、不能往前找"的根本缺陷。与单链表的 next-only 结构形成核心区别。

## 是什么
双链表是每个结点包含**两个指针**的链式存储结构：`prior` 指向直接前驱，`next` 指向直接后继。这使得从任意结点出发都能方便地找到其前驱和后继。

## 输入-输出空间
- **输入**：无（物理结构定义）
- **输出**：无
- **核心字段**：`data`（数据域）、`prior`（前驱指针）、`next`（后继指针）

## 正例（≥2 个）
1. **双向遍历**：从头结点出发向后遍历找到表尾，再从表尾向前遍历回到表头 — 单链表做不到反向遍历
2. **给定结点 P 的前插操作**：通过 `p->prior` 直接找到前驱，对前驱执行后插 → $O(1)$（单链表前插需用"偷天换日"技巧或用 $O(n)$ 找前驱）

## 反例/边界（≥1 个）
1. **在最后一个结点后插入**：普通双链表如果 `p` 是最后一个结点，`p->next == NULL`，后插时代码 `p->next->prior = s` 会空指针崩溃 → 需加 `if` 判断（循环双链表天然解决此问题）
2. **删除最后一个结点**：同理，`q->next->prior = p` 在 `q` 是最后一个结点时崩溃 → 需加空指针判断

## 详细解释

### 结点定义

```c
typedef struct DNode {
    ElemType data;               // 数据域
    struct DNode *prior, *next;  // 前驱和后继指针
} DNode, *DLinkList;
```

### 初始化（带头结点）

```c
bool InitDLinkList(DLinkList &L) {
    L = (DNode *)malloc(sizeof(DNode));
    if (L == NULL) return false;
    L->prior = NULL;             // 头结点的前驱永远为 NULL
    L->next = NULL;              // 空表
    return true;
}

bool Empty(DLinkList L) {
    return (L->next == NULL);
}
```

### 核心代码：后插操作（在 p 之后插入 s）

```c
// 健壮版：处理 p 可能是最后一个结点的情况
bool InsertNextDNode(DNode *p, DNode *s) {
    if (p == NULL || s == NULL) return false;

    s->next = p->next;           // ① s 的 next 指向 p 原后继
    if (p->next != NULL)         // ② 如果 p 有后继
        p->next->prior = s;      //    后继的 prior 指向 s
    s->prior = p;                // ③ s 的 prior 指向 p
    p->next = s;                 // ④ p 的 next 指向 s
    return true;
}
```

**语句顺序很重要！** 如果先执行 `p->next = s`（④），再执行 `s->next = p->next`（①），那 `s->next` 就会指向 s 自己 → 循环。

### 核心代码：删除 p 的后继结点 q

```c
bool DeleteNextDNode(DNode *p) {
    if (p == NULL) return false;
    DNode *q = p->next;           // q 是待删除结点
    if (q == NULL) return false;  // p 没有后继

    p->next = q->next;            // ① p 跳过 q
    if (q->next != NULL)          // ② 如果 q 有后继
        q->next->prior = p;       //    后继的 prior 指向 p
    free(q);                      // ③ 释放 q
    return true;
}
```

### 销毁双链表

```c
void DestroyList(DLinkList &L) {
    while (L->next != NULL)        // 循环删除头结点的后继
        DeleteNextDNode(L);
    free(L);                       // 释放头结点
    L = NULL;
}
```

### 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 后插（指定结点后） | $O(1)$ | 只需修改 4 个指针 |
| 前插（指定结点前） | $O(1)$ | 通过 prior 找前驱 + 后插 |
| 删除指定结点 | $O(1)$ | 通过 prior 直接修改前驱 |
| 按位查找 | $O(n)$ | 仍需遍历 |
| 按值查找 | $O(n)$ | 仍需遍历 |
| 遍历 | $O(n)$ | 可前向/后向 |

## 类比

### 一句话比喻
**单链表是只能往前走、不能回头的单向隧道——你从一个结点出发，只能看到后面的风景，永远不知道前面是什么。双链表是双向车道——每个结点同时握着前面和后面的人的手（prior 和 next），你可以从任何位置自由地往前走、往后走。插入操作就像在一排手拉手的人中间加一个人——得同时让前后两个人重新拉手，拉错顺序就会有人脱手。**

### 生活映射
| 数据结构世界 | 现实世界 |
|---|---|
| `prior`（前驱指针） | 左手拉着前面的人 |
| `next`（后继指针） | 右手拉着后面的人 |
| `p->next->prior = s` | 让后面的人换左手拉新人 |
| 普通双链表表尾 `next=NULL` | 排头的人右手没拉任何人 |
| 指针修改顺序错误 | 同时松开双手 → 队伍断开 |
| 头结点 `prior=NULL` | 排头前面没有别人 |
| 前插操作 $O(1)$ | 直接找前面的人说"加一个" |
