# 顺序表的查找

## 类型判定
程序型 — 具体的算法操作步骤，分为按位查找和按值查找两类，含代码和复杂度分析。按位查找体现了顺序表「随机存取」的核心优势。

## 是什么
在顺序表中查找元素。分两种：
- **按位查找**：给定位序 $i$，返回第 $i$ 个元素的值 → $O(1)$（随机存取）
- **按值查找**：给定值 $e$，返回第一个值等于 $e$ 的元素的位序 → $O(n)$（顺序扫描）

## 输入-输出空间
- **输入**：顺序表 L，位序 i（按位）或元素值 e（按值）
- **输出**：元素值（按位）或位序（按值，找不到返回 0 或 -1）
- **前置条件**：$1 \le i \le \text{length}$（按位）

## 正例（≥2 个）
1. **按位查找 i=3**：直接 `L.data[2]` → $O(1)$，无需任何循环
2. **按值查找 e=9**：从头扫到尾，在第 3 个位置找到 → 扫描 3 次

## 反例/边界（≥1 个）
1. **按值查找 struct 类型**：C 语言中不能用 `==` 比较两个结构体变量，必须逐个比较结构体中的字段。考研数据结构中通常可以用 `==`（考的是思路），但考 C 语言程序设计的学校可能会扣语法分。
2. **按值查找找不到**：扫描完整个表都不匹配 → 返回 0 或特定标记，$O(n)$

## 详细解释

### 核心代码：按位查找

```c
// 静态分配
ElemType GetElem(SqList L, int i) {
    // 可加健壮性判断
    return L.data[i - 1];   // 位序 i → 下标 i-1, O(1)
}

// 动态分配（同样 O(1)）
ElemType GetElem(SqList L, int i) {
    return L.data[i - 1];   // data 是指针，但同样支持 [] 下标
}
```

### 为什么动态分配也能用 `[]`？

`data` 是指向第一个元素的指针。编译器根据指针类型（如 `int*`）自动计算偏移量：`L.data[i-1]` → `*(L.data + (i-1))` → 地址 = 起始地址 + `(i-1) × sizeof(int)`。

**指针类型决定了每次偏移的字节数！** 如果 `int* p` 指向地址 2000，`sizeof(int)=4`，则 `p[0]` 取 2000~2003，`p[1]` 取 2004~2007。

### 核心代码：按值查找

```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e)          // 基本类型可直接 ==
            return i + 1;             // 返回位序（不是下标！）
    }
    return 0;                         // 未找到
}
```

### 时间复杂度

| 操作 | 最好 | 最坏 | 平均 |
|------|------|------|------|
| **按位查找** | $O(1)$ | $O(1)$ | $O(1)$ |
| **按值查找** | $O(1)$（表头匹配） | $O(n)$（表尾匹配或不存在） | $O(n)$（扫描 (n+1)/2 次） |

### 健壮性增强版：按位查找
```c
bool GetElem(SqList L, int i, ElemType &e) {
    if (i < 1 || i > L.length)
        return false;                 // 位序非法
    e = L.data[i - 1];
    return true;
}
```

## 类比

### 一句话比喻
**按位查找就像你对着一排快递柜——报出第 5 号柜，你瞬间就能走到那个柜子面前（$O(1)$，随机存取）。按值查找就像你在一排快递柜找一个写着"张三"的包裹——必须从左到右一个一个柜门看过去，运气好第一个就是（$O(1)$），运气差找到最后一个才发现（$O(n)$）。**

### 生活映射
| 代码世界 | 快递柜现场 |
|---|---|
| `GetElem(L, 3)` | 直接走到 3 号柜（按位） |
| `LocateElem(L, "张三")` | 逐个柜门看标签找"张三"（按值） |
| 数组下标 `i-1` | 柜号从 0 还是 1 开始数（位序 vs 下标） |
| `return 0` 表示未找到 | 所有柜子翻遍了，没有"张三" |
| 结构体不能 `==` | 标签写了两行，必须两行都对才算匹配 |
| 有序表的按值查找 | 柜子按姓氏拼音排列 → 可以用二分（$O(\log n)$） |
