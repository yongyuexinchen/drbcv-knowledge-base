# 静态链表（Static Linked List）

## 类型判定
判别型 — 静态链表是用数组模拟链表的数据结构，是链式存储思想和顺序存储空间的混合体。核心特点是连续空间 + 游标模拟指针，区分于用实际指针（malloc）的单链表。

## 是什么
静态链表分配一整片连续的内存空间（数组），每个元素是 `{data, next}` 结构体，其中 `next` 是一个整数游标（cursor），记录下一个结点在数组中的下标（而非内存地址）。表尾结点的 `next = -1`（等价于 NULL）。

## 输入-输出空间
- **输入**：无（物理结构定义）
- **输出**：无
- **核心字段**：`data`（数据域）、`next`（游标，int 类型，存储下一结点的数组下标）

## 正例（≥2 个）
1. **早期的低级语言（如 BASIC、FORTRAN）没有指针**：无法用 `malloc` 和指针实现单链表，只能用静态链表模拟链式存储
2. **操作系统的 FAT 文件分配表**：磁盘文件的各数据块在物理上不连续，FAT 表中每个表项用整数（下一块的簇号）串联各个数据块 → 本质就是静态链表

## 反例/边界（≥1 个）
1. **容量固定不可扩展**：静态链表的数组大小在声明时就固定了，不像动态单链表可以随时 `malloc` 新结点 → 数据量不可预知时不适合
2. **空闲结点管理**：需要额外标记哪些数组位置是空闲的（如 `next = -2`），不像 `malloc/free` 有操作系统替你管 — 自己实现回收算法很繁琐

## 详细解释

### 结点定义

```c
#define MaxSize 10           // 静态链表最大容量

typedef struct Node {
    ElemType data;           // 数据域
    int next;                // 游标（下一个结点的数组下标）
} Node;

// 声明静态链表（等价写法）
// 写法一：课本风格（少见但需看懂）
typedef struct {
    ElemType data;
    int next;
} SLinkList[MaxSize];       // SLinkList 等价于 Node[MaxSize]

// 写法二：普通人风格（推荐理解）
struct Node a[MaxSize];     // a 就是静态链表
```

### 初始化

```c
// 初始化静态链表
void InitList(Node a[]) {
    // 0 号结点作为头结点，不存数据
    a[0].next = -1;          // 头结点指向 -1（空表）

    // 标记所有空闲结点（从 1 开始）
    for (int i = 1; i < MaxSize; i++)
        a[i].next = -2;      // -2 表示该结点空闲
}
```

### 逻辑结构与物理结构的分离

```
逻辑顺序：a[0] → a[2] → a[1] → a[5] → 表尾(-1)
         （头）  数据1   数据2   数据3

数组物理布局：
下标:  0       1       2       3       4       5
data:  -       B       A       -       -       C
next:  2       5       1      -2      -2      -1

解释：0→2(A), 2→1(B), 1→5(C), 5→-1(尾)
```

**关键洞察**：`a[2].data = A`，`a[2].next = 1` 表示逻辑上下一个是 `a[1]`。虽然数组物理上 1 在 2 前面，但逻辑上 1 在 2 之后！

### 查找操作

```c
// 按位查找第 i 个结点（返回数组下标，找不到返回 -1）
int GetElem(Node a[], int i) {
    if (i < 1) return -1;

    int p = a[0].next;       // p 指向第一个数据结点
    int j = 1;               // j 记录当前 p 指向第几个

    while (p != -1 && j < i) {
        p = a[p].next;       // 通过游标跳转
        j++;
    }
    return p;                // 返回数组下标，-1 表示未找到
}
```

### 插入操作（思路）

在数组中找到空闲结点（`next == -2`）→ 放入数据 → 修改前驱的游标指向新结点 → 新结点的游标指向原后继。

### 核心特性

| 方面 | 静态链表 | 顺序表 | 单链表（动态） |
|------|---------|--------|-------------|
| 存储空间 | 连续（数组） | 连续（数组） | 离散（malloc） |
| 逻辑关系 | 游标（下标） | 物理相邻 | 指针 |
| 随机存取 | ❌ $O(n)$ | ✅ $O(1)$ | ❌ $O(n)$ |
| 插入删除 | 只改游标（不需移动） | 需移动元素 | 只改指针 |
| 容量 | 固定不可变 | 静态固定/动态可扩 | 灵活可扩 |
| 空间回收 | 需手动标记 | 系统/手动 | malloc/free |

## 类比

### 一句话比喻
**静态链表就像一栋公寓楼——所有住户（结点）住在固定的房间里（数组空间），但你按门牌号顺序进去走访时，每家客厅都贴着一张纸条写着"下一个要找的邻居在 3 楼 5 号房"（游标），而不一定是隔壁。你按纸条指示跳来跳去就能访问所有住户。这和真正邻居物理相邻（顺序表）或住得分散但有详细地址（单链表）都不一样。**

### 生活映射
| 数据结构世界 | 公寓楼寻宝游戏 |
|---|---|
| 数组空间 | 整栋公寓楼的固定房间 |
| 游标 `next` | 每个房间里的纸条："下一个线索在 N 号房" |
| `next = -1` | 纸条上写"宝藏已找到，结束" |
| `next = -2` | 空房间，没人住过 |
| 逻辑顺序 ≠ 物理顺序 | 可能要从 2 楼跳到 5 楼再跳到 1 楼 |
| 查找 $O(n)$ | 必须按纸条一张张跳过去 |
| FAT 文件分配表 | 磁盘文件被切成块，每块标注"下一块是第 X 块" |
