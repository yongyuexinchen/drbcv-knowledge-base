# 数据结构概念卡模板（Data-Structures vault 专用）

## 模板使用说明

数据结构卡的核心任务：**不是背代码，是理解「数据怎么组织 + 操作怎么实现 + 为什么这么设计」。**

1. 每张卡必须标注**类型判定**（判别/程序/比较/定理）
2. 程序型卡片必须有**核心代码** + **复杂度分析**
3. 关系必须用 `[[wikilink]]` 链接，重点是 is_a / 存储实现 / 对比 三条线
4. 正例 ≥2 个，反例 ≥1 个

## 四型卡片侧重点

| 类型 | 必须包含 | 可选 |
|------|---------|------|
| **discriminant**（判别/定义） | 定义 + 正反例 + 一句话比喻 + 与相似概念的区别 | 代码 |
| **procedure**（程序/算法） | 代码 + 复杂度 + 关键注意事项 + 一句话比喻 | 正反例 |
| **comparison**（比较） | 对比表格 + 各自适用场景 + 一句话比喻 | 代码 |
| **theorem**（定理/性质） | 定理陈述 + 证明思路 + 推论 | — |
