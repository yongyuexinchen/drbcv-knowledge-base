# 浮点数的表示范围与特殊状态

## 类型判定
概念型 — 定义 IEEE 754 浮点数（以 float 为主）的规格化/非规格化浮点数的数轴边界值、上溢/下溢判断条件，以及五种特殊状态（正负零、正负无穷、NaN）的二进制表示和触发条件。

## 类比 ★
**一句话比喻：** 像温度计的刻度范围——规格化浮点数是"正常量程"（-126°到 127°），上溢是"温度计爆表"（阶码全 1 = 无穷），下溢是"温度太低表针缩回零"（先用非规格化区间凑合，再低就直接归零），NaN 是"这根温度计坏了用不了"（0÷0 或 √(-1)）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 正上溢 → 正无穷（阶码全 1 尾数全 0） | 计算器算 10¹⁰⁰ → 显示 "Error"（爆表了） |
| 正下溢 → 非规格化 → 机器零 | 水银温度计测 -200°C → 水银缩到底部看不见了 |
| NaN（0÷0、√(-1)） | 问 "用 0 块钱分给 0 个人每人得多少"——没有答案，不是数 |

## 是什么
**浮点数的表示范围与特殊状态**描述了 IEEE 754 单精度浮点数在数轴上的完整分布。规格化浮点数（阶码不全 0 不全 1）的真值范围：最小正数 1.0×2⁻¹²⁶ ≈ 1.18×10⁻³⁸，最大正数 ≈ (2−2⁻²³)×2¹²⁷ ≈ 3.4×10³⁸。超出最大正数 → **正上溢**（记为 +∞）；低于最小正数 → **正下溢**（进入非规格化区间，最小非规格化正数 = 2⁻¹⁴⁹ ≈ 1.4×10⁻⁴⁵；再往下 → **机器零**）。

IEEE 754 规定的五种特殊状态：
- 阶码全 0 + 尾数全 0 → **±0**（符号位区分正零/负零，逻辑等价）
- 阶码全 0 + 尾数不全 0 → **非规格化浮点数**（尾数前隐含 0，阶码真值固定为 1−偏置值 = -126）
- 阶码全 1 + 尾数全 0 → **±∞**（正无穷/负无穷）
- 阶码全 1 + 尾数不全 0 → **NaN**（Not a Number，0÷0、∞−∞、√(−1) 等触发）

## 输入-输出空间
- **输入**：一个 float 型 32 位机器数
- **输出**：判断其类型（规格化/非规格化/零/无穷/NaN）及真值
- **前置条件**：需要先按 1+8+23 拆分符号/阶码/尾数，再按阶码是否全 0 或全 1 走不同解读路径

## 正例（≥2 个）
1. **规格化最大正数**（2018 年 408 真题 14 题）：阶码 = 11111110（254−127=127），尾数全 1 → 1.111…1 × 2¹²⁷ ≈ 3.4×10³⁸。最小的规格化正数：阶码 = 00000001（1−127=−126），尾数全 0 → 1.0×2⁻¹²⁶（选 A）。
2. **非规格化浮点数解读**（2023 年 408 真题 14 题）：阶码全 0、尾数不全 0（如最后一位为 1）→ 符号=1（负），阶码真值固定 −126，尾数前补 0 → 真值 = −(0.00…01)×2⁻¹²⁶ = −2⁻¹⁴⁹ → 选 A。
3. **0÷0 = NaN，非零÷0 = ∞**：1.0÷0.0 → 正无穷（阶码全 1 尾数全 0 符号 0）；0.0÷0.0 → NaN（阶码全 1 尾数不全 0）；−1.0÷0.0 → 负无穷（符号 1）。

## 反例/边界（≥1 个）
1. **"无穷就是 NaN"是错的**：无穷（∞）是阶码全 1 + 尾数全 0，是确定的"超出范围"；NaN 是阶码全 1 + 尾数不全 0，是"无定义的操作结果"。二者二进制表示不同。
2. **非规格化和规格化的尾数解读规则不同**：规格化尾数前隐含"1"，非规格化尾数前隐含"0"——若混用，非规格化数的真值会错。阶码解读也不同：规格化阶码真值 = 按无符号数 − 偏置值，非规格化阶码真值固定 = 1 − 偏置值（float = −126，double = −1022）。
3. **"下溢就是变成 0"不准确**：下溢先进入非规格化区间（阶码从 000...01 降到全 0，尾数保留），只有非规格化也兜不住时才变成机器零——中间有一个"渐进下溢"的缓冲带。

## 详细解释
### float 型数轴全貌（正半轴，负半轴对称）
```
0  →  [非规格化正数区间]  →  [规格化正数区间]  →  +∞
     min: 2⁻¹⁴⁹              min: 2⁻¹²⁶             max: (2−2⁻²³)×2¹²⁷
     max: 2⁻¹²⁶−2⁻¹⁴⁹

  下溢（Underflow）─→                    ←─ 上溢（Overflow）
```

### 五种特殊状态的 float 表示
| 状态 | 符号 S | 阶码（8 位） | 尾数（23 位） | 触发条件/真值 |
|------|--------|-------------|--------------|-------------|
| +0 | 0 | 00000000 | 0…0 | 真值 0 |
| −0 | 1 | 00000000 | 0…0 | 真值 0（逻辑等价于 +0） |
| +∞ | 0 | 11111111 | 0…0 | 上溢 / 非零数 ÷ 0 |
| −∞ | 1 | 11111111 | 0…0 | 负上溢 / 负数非零 ÷ 0 |
| NaN | 任意 | 11111111 | 不全 0 | 0÷0、∞−∞、√(−1) |

### 非规格化数的阶码真值（重要区分！）
| 类型 | float | double |
|------|-------|--------|
| 规格化 | 无符号数 − 127 | 无符号数 − 1023 |
| 非规格化 | 固定 = **1 − 127 = −126** | 固定 = **1 − 1023 = −1022** |

## 备注
- **408 考点 — 数值边界**：规格化最小正数 = 2⁻¹²⁶，非规格化最小正数 = 2⁻¹⁴⁹；规格化最大正数 = (2−2⁻²³)×2¹²⁷；这些数值边界可以直接考选择题（2018 年 14 题、2023 年 14 题）
- **408 考点 — 阶码全 0/全 1 的判定**：阶码不全 0 不全 1 = 规格化（阶码范围 1~254，真值 −126~127）；阶码全 0 = 非规格化或零；阶码全 1 = 无穷或 NaN
- **408 考点 — 默认不响应浮点异常**：IEEE 754 规定默认不中断程序运行，正上溢 → 记 +∞，下溢到机器零 → 置下溢异常标志位 UE 但不中断（除非程序员手动开启响应）
- **408 考点 — NaN vs ∞**：非零数 ÷ 0 = ∞（有符号），0 ÷ 0 = NaN；开方负数 = NaN
