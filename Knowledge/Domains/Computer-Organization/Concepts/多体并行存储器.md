# 多体并行存储器

## 类型判定
判别型 — 定义 M 个独立存储体并行工作的存储器，对比高位/低位两种交叉编址的效果差异，讲清低位交叉的流水线原理——属于"存储器并行技术"类概念。

## 类比 ★
**一句话比喻：** 多体并行是 4 个独立窗口的银行——各有各的柜员和账本。**低位交叉**像取号机轮流叫号：1 号窗1、2 号窗2、3 号窗3、4 号窗4、5 号又回窗1——四个窗口同时干活，吞吐翻几倍；**高位交叉**像按会员段分窗口：1-100 号全挤窗 1，别的窗口闲着——只是把客户（容量）分给了不同窗口，速度一点没提。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 多体并行（M 个独立体，各有独立电路） | 4 个独立窗口——各有柜员和账本，同时干活 |
| 低位交叉编址（连续地址轮流分体） | 取号机轮流叫号——1 号窗1、2 号窗2、3 号窗3、4 号窗4、5 号又窗1 |
| 高位交叉编址（按号段分体） | 按会员段分窗口——1-100 号全挤窗 1，别的窗口闲着 |

## 是什么
**多体并行存储器**由 **M 个容量相同、存取速度相同**的存储体组成，每个体都有**独立的**读写控制电路、地址寄存器、数据寄存器——既能并行工作，也能交叉工作。编址方式决定它的效果：
- **高位交叉编址**（体号 = 地址高位）：连续地址落在**同一体**内 → CPU 连续访问时撞同一个体，要等存取周期 T → **效果 = 单纯扩容，无速度提升**
- **低位交叉编址**（体号 = 地址低位，地址 mod M）：连续地址**轮流分布**在各体 → CPU 每隔 r（存取时间）发起一次访问，M 个访问**流水**进行 → **吞吐接近 M 倍**

核心参数：存取周期 T、存取时间 r、体数 M。当 **T = M×r** 时流水线刚好不中断——**最优体数 M = T/r**。

## 正例（≥2 个）
1. **低位交叉流水（M=4, T=4r）**：CPU 在 0、r、2r、3r 时刻分别向体 0、1、2、3 发起访问。第一个访问 t=4r 出结果，之后**每隔 r 出一个**——4 个连续访问共耗时 7r（单体顺序要 16r），吞吐近 4 倍。
2. **体号计算**：地址 13，M=4 → 13 mod 4 = 1 → 在体 1（二进制末 2 位 = 01）——低位交叉的体号 = 地址末 log₂M 位。
3. **双通道内存**：两根 8GB 内存条插**同色卡槽** = 低位交叉二体——CPU 交替访问两个体，连续访问吞吐翻倍（42 号课修电脑梗："插同色卡槽才叫双通道"）。

## 反例/边界（≥1 个）
1. **"低位交叉 = 随机访问也翻倍"是错的**：流水只对**连续访问**有效——随机访问（地址乱跳）可能反复撞同一个体，撞上就退回 T 等待，提速消失。
2. **"高位交叉也能提速"是错的**：高位交叉连续地址全在**同一体**，效果只是**扩容**（地址空间变大），速度不变——"高位=扩容、低位=流水"必须钉死。
3. **"体数越多越好"是错的**：M > T/r 时流水线已经排满，多出的体**永远空闲**（成本白花）；M = T/r 是流水不中断的最少体数，最优。
4. **双通道不是随便插**：必须同主频、同容量、插同色卡槽；混插会降频或性能不稳定。

## 详细解释
### 低位交叉流水时序（M=4, T=4r）
```
时刻： 0    r    2r    3r    4r    5r    6r    7r
体0：  [访问0]                    出结果0
体1：        [访问1]                   出结果1
体2：              [访问2]                  出结果2
体3：                    [访问3]                 出结果3
CPU：  发    发    发    发    收0   收1   收2   收3
      ↑ 每 r 发一个访问（轮流给不同体）
      ↑ 第一个结果 t=T 出来，之后每 r 出一个
→ 4 个连续访问共 7r；单体顺序执行要 4 次 T = 16r
```

### 高位交叉 vs 低位交叉
| 特征 | 高位交叉 | 低位交叉 |
|------|---------|---------|
| 体号位置 | 地址高位 | 地址低位（末 log₂M 位） |
| 连续地址存放 | 同一体内 | 跨体轮流（0→1→2→3→0…） |
| CPU 连续访问 | 撞同一体，等 T | 各体轮流，流水 |
| 效果 | **单纯扩容** | **吞吐 ≈ M 倍** |
| 体号判断 | 地址 ÷ M | 地址 mod M |

### 最优体数推导
- 每个体：存取周期 T，其中 r 用于存取，其余 T-r 空闲
- 想让 CPU 每 r 就能发起下一次访问（流水不空转），需要 M 个体轮流 → M × r ≥ T → **M ≥ T/r**
- M = T/r 时刚好排满、体数最少、成本最低

### 层次定位：双通道 = 主板级应用
双通道内存 = **低位交叉二体**：两根内存条 = 两个独立体（多体并行架构），插**同色槽** → 低位交叉（流水提速）；插**异色槽** → 高位交叉（只扩容）。注意：两根条**无论同色异色都是"多体并行架构"**，同色/异色选择的是**编址方式**（提速 or 扩容）。对比：单体多字发生在**芯片级**（内存条内部拼宽，与插槽无关，见[[单体多字存储器]]）——两个层次互不干扰：交叉编址管"两根条之间怎么分工"，单体多字管"一根条内部一次读多少"。

## 备注
- **408 考点 — 流水计算**：M=4、T=4r、连续 N 个访问 → 总时间 = T + (N-1)r；吞吐 = N / [T+(N-1)r]
- **408 考点 — 体号**：低位交叉 = 地址 mod M（末 log₂M 位）——给地址算体号必考
- **高位=扩容、低位=流水**——两种编址效果对照（42 号课反复强调）
- **记忆口诀**：取号轮流叫（低位流水）、号段各归各（高位扩容）、体数取整比（M=T/r）
