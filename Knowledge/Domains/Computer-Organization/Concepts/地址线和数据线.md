# 地址线和数据线

## 类型判定
判别型 — 定义系统总线中地址线（单向、定寻址空间）与数据线（双向、定传输宽度）的角色分工，辨析两种"复用"——属于"总线/接口"类概念。

## 类比 ★
**一句话比喻：** 地址线是下单热线——CPU 打电话只报门牌号（单向，报完就挂），不运货；数据线是货运通道——进货出货都走它（双向），通道多宽决定一次能拉几箱（几个螺丝盒）；控制线是红绿灯——告诉通道这次是进货还是出货。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 地址线（单向：CPU → 存储器/IO） | 下单热线——只报门牌号，不运货 |
| 数据线（双向，宽度 = 一次传输位数） | 货运通道——进货出货都走它，多宽一次拉几箱 |
| 地址线根数 → 寻址空间 2ⁿ | 门牌号位数 → 最多能编多少个号 |

## 是什么
系统总线按传输内容分三组，其中**地址线（AB）**和**数据线（DB）**是最核心的两组：
- **地址线**：**单向**（CPU 发出），传送要访问的单元地址。n 根地址线 → 2ⁿ 个编址单元（寻址空间）。宽度设计依据：主存地址空间 + IO 设备编号（统一编址时）。
- **数据线**：**双向**（CPU 与存储器/IO 互相传），传送数据。宽度 = 一次能传的位数（机器字长或存储字长），决定单次传输量和带宽。
- **控制线**：传读写控制信号（WE/OE 等），决定数据流向。

一句话分工：**地址线决定"能访问多大空间"，数据线决定"一次搬多少"**——两者相乘就是容量计算的基础（衔接[[内存条容量计算]]）。

## 正例（≥2 个）
1. **8K×8 存储芯片的连接**：8K = 2^13 → 13 根地址线（A0~A12）接地址总线；8 位字长 → 8 根数据线接数据总线；再加片选 CS + 读写控制线——芯片引脚数 ≥ 13+8+1+1 = 23（43 号课原例）。
2. **32 根地址线 + 64 根数据线**：寻址空间 2³² = 4G 单元，每次传 64 bit → 容量 = 2³² × 64 bit = 32GB——地址线管"多少个门牌"，数据线管"每格多宽"。
3. **8086 经典组合**：20 根地址线 → 1MB 寻址空间；16 根数据线 → 一次传 2 字节。AD0~AD15 是地址/数据**分时复用**线——先传地址后传数据。

## 反例/边界（≥1 个）
1. **"地址线是双向的"是错的**：地址线**单向**（CPU 发出地址），数据线**双向**（读写都走它）。DMA 场景下外设也能驱动总线，但那是总线仲裁的结果，不改变地址线的单向设计。
2. **"数据线宽度 = 机器字长"不绝对**：数据线宽度可以等于机器字长**或**存储字长——比如 64 位 CPU 配 32 位存储字长的芯片时，数据线按存储字长接（8K×1 芯片位扩展的经典例子：1 位芯片拼 8 根数据线）。
3. **两个"复用"别混**：DRAM 的**地址线复用**是行/列地址共用引脚分时送（[[地址线复用]]，引脚减半）；8086 的 **AD 复用**是地址和数据共用引脚分时送。都叫复用，层次完全不同——一个是"地址内部的复用"，一个是"地址和数据的复用"。
4. **"地址线多 = 速度快"是错的**：地址线多 = 寻址空间大，和速度无关；速度由数据线宽度、时钟频率和存储器件本身决定。

## 详细解释
### 三种子总线对比（呼应[[总线概述]]）
| 总线 | 方向 | 宽度依据 | 决定什么 |
|------|------|---------|---------|
| 地址线 AB | 单向（CPU→） | 主存空间 + IO 编号 | 寻址空间 2ⁿ |
| 数据线 DB | 双向 | 机器字长或存储字长 | 单次传输量、带宽 |
| 控制线 CB | 单根单向、整体双向 | 控制信号种类 | 读写方向、时序 |

### 引脚计算模板（存储芯片）
```
引脚数 = 地址引脚（log₂ 单元数，DRAM 还要÷2）+ 数据引脚（字长）
        + 片选 CS(1) + 读写控制(1~2) + 电源地线
例：8K×8 SRAM → 13 + 8 + 1 + 1 + 电源 = ≥23
    1M×1 DRAM → 10（复用后）+ 1 + 1 + 1 + RAS/CAS + 电源
```

### 8086 地址/数据分时复用（AD 线）
```
第一拍：AD0~AD15 上传送 地址（配合 ALE 锁存地址）
第二拍：AD0~AD15 上传送 数据
→ 引脚从 32 根省到 16 根，代价是分时（多一拍）
```
