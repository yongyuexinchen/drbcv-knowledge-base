# 固态硬盘 SSD

## 类型判定
定义型 — 回答"固态硬盘和机械硬盘有什么区别、闪存怎么读写、为什么要磨损均衡"，属于新型辅存特性对比类概念。

## 类比 ★
**一句话比喻：** SSD 像个巨大的白板墙——分成很多块白板（块），每块分成很多小格（页）。写之前必须把整块白板全擦干净才能写，不能只擦一格。读无限次，写一次就要擦一次，擦多了这块白板就废了（磨穿），所以要换着用（磨损均衡）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 页（读写单位） | 白板上的一小格——可以读一万遍，但写一次就得擦整块 |
| 块（擦除单位） | 一整块白板——要写任何一格，先擦干净整块，其他格的文字跟着遭殃 |
| 磨损均衡 | 教室里的黑板轮流用——今天用这块明天用那块，别把一块写到反光 |

## 是什么
SSD（Solid State Drive，固态硬盘）基于闪存技术（Flash Memory，本质是 EEPROM），由**闪存翻译层**（地址映射）+ **多块闪存芯片**（存储介质）构成。每块闪存芯片含多个**块**（Block，擦除单位，16KB~512KB），每块含多个**页**（Page，读写单位，512B~4KB）。SSD 以页为单位读写（类比磁盘扇区），以块为单位擦除。写操作必须"先擦后写"，写速度远慢于读速度。支持随机访问（电路寻址，无机械延迟）。

## 输入-输出空间
- **输入**：逻辑块号（系统通过 IO 总线给定）
- **输出**：对应页的数据
- **前置条件**：写操作时，若目标页已有数据，需先把该块其他有效页复制到新块 → 擦除旧块 → 在新块中写入目标页 + 迁移过来的其他页；闪存翻译层同步更新地址映射

## 正例（≥2 个）
1. **写一页引发的数据迁移**：块 0 的页 0~3 存有数据 A/B/C/D，现要改写页 1（B→B'）。步骤：①块 1（已擦干净）中写入 A（从块 0 复制）；②在块 1 的页 1 位置写入 B'；③复制 C、D 到块 1 对应位置；④擦除块 0；⑤闪存翻译层将逻辑块号重新映射到块 1。→ 写 1 页导致整块迁移，所以写比读慢很多。
2. **SSD vs HDD 对比**：SSD 读数据→电路直接定位→约 0.1ms；HDD 读同一数据→寻道 6ms + 旋转延迟 4ms + 传输 0.02ms→约 10ms。SSD 快 100 倍，且无噪音、抗震、省电。但 SSD 贵，且每个块的擦除次数有限（如 1000~10000 次）。

## 反例/边界（≥1 个）
1. **"SSD 写多了会坏"但不严重**：某 1TB SSD，每块擦写寿命 1000 次，每天写 128GB→每 8 天写满全盘一次→每块平均擦一次→1000×8=8000 天≈23 年才坏。一般用户每天远写不到 128GB，SSD 寿命远长于电脑更换周期。
2. **"页=磁盘扇区"不等同**：SSD 的"页"是读写单位（类比扇区），SSD 的"块"是擦除单位（类比磁道）。术语相同但含义不同，做题要注意上下文。
3. **逻辑地址≠物理地址**：由于磨损均衡和数据迁移，同一个逻辑块号在不同时刻可能映射到不同物理位置，由闪存翻译层透明处理。

## 详细解释

**SSD 与 HDD 特性对比：**

| 特性 | SSD（固态硬盘） | HDD（机械硬盘） |
|------|----------------|----------------|
| 存储原理 | 闪存芯片（电擦除 ROM） | 磁性涂层+电磁读写 |
| 寻址方式 | 电路寻址（随机访问） | 机械寻道+旋转定位 |
| 读写速度 | 读快，写慢（先擦后写） | 读写都慢（机械延迟） |
| 随机访问 | 优秀（任何地址同速） | 差（依赖磁头当前位置） |
| 噪音/抗震 | 安静/耐摔 | 有噪音/怕摔 |
| 能耗 | 低 | 高 |
| 价格 | 高 | 低（同容量） |
| 寿命 | 有限擦写次数 | 几乎无限 |

**磨损均衡技术：**
- **动态磨损均衡**：写数据时优先选择累计擦除次数少的新块，把老块"雪藏"以减少擦除。
- **静态磨损均衡**：后台监控各块的读写频率。把"读多写少"的冷数据（如存好的电影）迁移到老块，"写多读少"的热数据迁移到新块，使擦除均匀分布。两种技术配合延长整体寿命。

## 备注
- SSD 读写以页为单位，擦除以块为单位——「读页写页擦整块」，408 新考点
- 写比读慢（写前要擦除+可能数据迁移），和 U 盘一个道理
- 磨损均衡 = 别老薅同一只羊（别老擦同一个块），动态=写入时选新块，静态=后台挪冷热数据
- 逻辑地址到物理地址的映射会变，由闪存翻译层透明维护
