# 控制线

## 类型判定
判别型 — 定义传送命令/状态信号的控制总线：方向（单根单向、整体双向）、常见信号（读写/片选/中断）、有效电平约定，与地址线数据线辨析——属于"总线/接口"类概念。

## 类比 ★
**一句话比喻：** 三线体系里的第三根——地址线是下单热线（报门牌号），数据线是货运通道（运货），控制线是**调度员的旗语系统**：吹哨子告诉通道这次进（写）还是出（读），门禁刷卡决定开哪栋楼（片选），仓库还会主动打电话"货到了快来取"（中断请求）。而"低电平有效"就像紧急按钮——平时高电平待命，按下去（变低）才触发。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 读写控制线（WE/OE，决定数据方向） | 调度员哨子——吹一声进（写），吹两声出（读） |
| 片选信号 CS（选中哪个芯片/设备） | 门禁刷卡——决定这单货交给哪栋楼（哪个仓库开门） |
| 设备 → CPU 控制线（中断/就绪） | 仓库主动打电话——"货到了，快来取！" |

## 是什么
**控制线（控制总线 CB）**传送**控制信号**——命令（读写、片选、复位）和状态（就绪、中断请求），与地址线（传地址）、数据线（传数据）分工不同。核心特点：
- **单根单向、整体双向**：CPU→设备方向有读写控制（WE/OE）、片选（CS）、地址锁存（ALE）、时钟（CLK）、复位（RESET）；设备→CPU 方向有中断请求（INTR）、总线请求（BR）、就绪（READY）
- **根数 = 所需控制信号种类数**——不像地址线有 2ⁿ 规律，控制线数量由设计需求决定
- **有效电平**：低电平有效用横线/小圆标注（如 WE̅），高电平有效无标注（如 CS）——不同教材口径不同，看题给什么符号

## 正例（≥2 个）
1. **8K×8 存储芯片的控制引脚**：WE（写使能）+ OE（读使能）+ CS（片选）——引脚计算中控制线是固定开销：13 地址 + 8 数据 + 3 控制 + 电源地线（43 号课原例）。
2. **8086 的 ALE（地址锁存）**：AD 线第一拍传地址时，ALE 有效——地址被锁存进外部锁存器，第二拍 AD 线才能放心传数据。没有这根控制线，复用就乱套。
3. **中断请求 INTR**：IO 设备数据就绪 → 拉高 INTR → CPU 停下当前工作响应中断 → 进入中断处理程序。这是"设备主动找 CPU"的唯一途径（衔接[[程序中断方式]]）。

## 反例/边界（≥1 个）
1. **"控制线都是 CPU 发出的"是错的**：中断请求（INTR）、总线请求（BR）、就绪（READY）都是**设备→CPU**方向——所以叫"单根单向、整体双向"。考方向判断题别一刀切。
2. **"低电平有效 = 信号错误"是错的**：低电平有效是**设计约定**（紧急按钮按下才响），不是故障。看符号：有横线/小圆 = 低电平有效；无标注 = 高电平有效。WE 和 WE̅ 是两种口径，做题以题目给为准。
3. **"控制线参与容量计算"是错的**：容量 = 2^地址线 × 数据线，控制线只在**引脚数**计算里出现（片选 1 + 读写 1~2 根的固定开销）。
4. **"控制线越多越好"不成立**：控制信号种类由设计决定——越多越灵活也越复杂，如读写线合用（1 根）vs 分开（WE+OE 两根）各有取舍。

## 详细解释
### 控制信号分类（按方向）
| 方向 | 典型信号 | 作用 |
|------|---------|------|
| CPU → 设备 | WE/WR（写使能）、OE/RD（读使能） | 决定数据线方向 |
| CPU → 设备 | CS/CE（片选） | 选中目标芯片/设备 |
| CPU → 设备 | ALE（地址锁存）、CLK（时钟）、RESET（复位） | 时序与初始化 |
| 设备 → CPU | INTR（中断请求） | 设备要 CPU 处理 |
| 设备 → CPU | BR（总线请求）/BG（总线允许） | DMA/总线仲裁 |
| 设备 → CPU | READY（就绪） | 告诉 CPU 数据已就绪/还没好 |

### 常见缩写速查（408 常考）
| 缩写 | 全称 | 含义 |
|------|------|------|
| WE / WR | Write Enable | 写使能（低或高有效看标注） |
| OE / RD | Output Enable / Read | 读使能 |
| CS / CE | Chip Select / Enable | 片选/芯片使能 |
| ALE | Address Latch Enable | 地址锁存（8086 复用） |
| INTR | Interrupt Request | 中断请求 |
| BR / BG | Bus Request / Grant | 总线请求/允许 |
| READY | — | 就绪信号（慢速设备拖时间用） |

### 低电平有效的符号约定
```
WE̅（有横线/小圆）→ 低电平有效：WE̅=0 时才写
CS （无标注）    → 高电平有效：CS=1 时才选中
引脚图上看小圆（○）就是低电平有效——主存储器与CPU的连接课反复强调
```

### 引脚计算中的位置
```
芯片引脚 = 地址引脚 + 数据引脚 + 控制引脚（片选1 + 读写1~2）+ 电源地线
控制线是"固定开销"——不随容量变化，但方向、合用/分开影响数量
```

## 备注
- **408 考点 — 缩写题**：WE/OE/CS/ALE/INTR/READY——看到要能说出方向和含义
- **408 考点 — 方向判断**：读写/片选是 CPU→设备；中断/就绪/总线请求是设备→CPU——"单根单向、整体双向"
- **符号坑**：横线/小圆 = 低电平有效；无标注 = 高电平有效——同一信号两种画法，按题给符号判断
- **记忆口诀**：哨子管进出（读写）、刷卡管开门（片选）、电话管喊人（中断）——控制线是"命令线"不是"数据线"
