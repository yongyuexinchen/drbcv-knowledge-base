# 只读存储器 ROM

## 类型判定
定义型 — 回答"ROM 有哪几种、各有什么特点、为什么闪存可读可写却还叫 ROM"，属于存储芯片分类概念。

## 类比 ★
**一句话比喻：** ROM 家族像石刻技术演进史——MROM 是刻在石碑上（出厂刻死，改不了），PROM 是刻在木板上（你自己刻一次就定型），EPROM 是用铅笔写字（可擦掉重写但很麻烦），Flash 是白板马克笔（擦写方便但擦的时候必须一整面全擦）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| MROM（掩模式） | 印刷厂批量印书——制版贵，但印一万本单价便宜，内容永不能改 |
| EPROM（紫外线擦除） | 用铅笔写的合同——用橡皮（紫外线）可以擦，但一擦就全没，不能只擦一行 |
| Flash 闪存（块擦除） | 白板——写之前必须先整面擦干净才能写新内容，单格不能只擦不擦别的 |

## 是什么
ROM（Read-Only Memory，只读存储器）是非易失性存储器，断电后数据不丢失。按发展历程分为：**MROM**（掩模式，厂家写入不可改）→ **PROM**（可编程一次，写入后不可改）→ **EPROM/UVEPROM**（紫外线照射擦除，可多次写）→ **EEPROM**（电擦除，字级粒度）→ **Flash Memory**（闪存，电擦除，块级粒度，快速多次重写）→ **SSD**（固态硬盘，由多块闪存芯片 + 控制单元构成）。虽然 Flash 和 SSD 可读可写，但仍归为 ROM 类——手机宣传「RAM 8GB + ROM 256GB」中的 ROM 即指闪存存储。逻辑上，主板上的 BIOS 芯片（存自举装入程序）也是 ROM，与内存条（RAM）统一编址后共同构成主存。

## 输入-输出空间
- **输入**：地址（访问某个存储单元）、写使能信号（对可写 ROM）
- **输出**：存储字的数据
- **前置条件**：Flash 写操作前须先擦除整块（以块为单位擦除），读操作无需擦除

## 正例（≥2 个）
1. **手机开机原理**：关机时 RAM（内存）数据全部丢失。开机时 CPU 从主板上的 BIOS ROM 芯片读取自举装入程序，按程序指引把操作系统从闪存（辅存）调入 RAM（主存），之后 CPU 才能正常执行指令。这块 ROM 就是 BIOS 芯片，逻辑上属于主存的一部分。
2. **U 盘读写**：U 盘使用 Flash 闪存芯片。读数据 → 直接读，速度快；写数据 → 先电擦除目标块 → 再写入，因此**写速度比读速度慢**。可以多次擦除重写，断电后数据不丢失。

## 反例/边界（≥1 个）
1. **"ROM 只能读不能写"是错的**：MROM 和 PROM 确实不可重写，但从 EPROM 开始已支持擦除重写，Flash 和 SSD 更是频繁读写。名字保留"ROM"是历史原因，不代表功能限制。
2. **"ROM 和 RAM 完全对立"是错的**：ROM 也具有随机存取特性——给定地址后，读取速度不因物理位置改变。ROM 和 RAM 的核心区别是「易失性 vs 非易失性」，而非「只读 vs 可读写」。
3. **U 盘 ≠ SSD**：存储介质都是闪存芯片，但控制单元不同。SSD 控制单元更复杂，支持更高并发和磨损均衡。

## 详细解释

**ROM 类型演进表：**

| 类型 | 全称 | 写入方式 | 可重写 | 擦除粒度 |
|------|------|---------|--------|---------|
| MROM | Mask ROM | 厂家掩模写入 | 否 | — |
| PROM | Programmable ROM | 用户用写入器一次写入 | 否 | — |
| UVEPROM | UV Erasable PROM | 紫外线照射 8-20 分钟 | 是 | 全片擦除 |
| EEPROM | Electrically EPROM | 电擦除指定字 | 是 | 字级 |
| Flash | Flash Memory | 电擦除+写入 | 是 | 块级 |

**Flash 关键特性：**
- 每块可擦除次数有限（如 1000 次），老化后不可用
- 写入前须先擦除整块（不能直接覆盖已有数据），写比读慢
- 位密度高于 RAM（每个存储元只需 1 个 MOS 管，体积更小，同样面积容量更大）
- SSD = 多块闪存芯片 + 控制单元（闪存翻译层，负责地址映射和磨损均衡）

**BIOS 与统一编址：** 主板上的 BIOS ROM（存自举装入程序）和 RAM 内存条统一编址。如 ROM 容量 1KB，地址 0~1023 分配给 ROM，1024 起分配给 RAM。CPU 上电后从 ROM 的 0 地址开始取指令。

## 备注
- 手机「RAM 8GB + ROM 256GB」→ RAM=内存（运行内存），ROM=闪存（机身存储），408 常考名词辨析
- Flash 写比读慢（写前要擦除），这是 U 盘/SSD 的通用特性
- BIOS 芯片是 ROM，存自举装入程序，逻辑上算主存、和 RAM 统一编址
- MROM/PROM 是真正的"只读"；EPROM 后用"可擦除可编程 ROM"更准确
