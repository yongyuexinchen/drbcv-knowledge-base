# 随机存取

## 类型判定
判别型 — 定义按地址访问的存储器中"等时访问任意单元"的特性（RAM 的本质），并与顺序存取、直接存取对比——属于"存取方式分类"类概念。

## 类比 ★
**一句话比喻：** 随机存取像快递柜——报 1 号格和报 100 号格，取件时间**完全一样**，所有格子都在"射程"内；顺序存取像传送带——要第 50 件，必须等前面 49 件先划过去；直接存取像图书馆找书——先走到对应那排书架（定位），再在书架上翻找（顺序）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 随机存取 RAM（等时访问） | 快递柜：报几号格都一样快，1 号格和 100 号格取件时间相同 |
| 顺序存取 SAM（时间取决于位置） | 传送带：要第 50 件，必须等前面 49 件先划过去 |
| 直接存取 DAM（定位 + 顺序） | 图书馆找书：先走到对应那排书架，再在书架上顺序翻找 |

## 是什么
**随机存取**是存储器的一种存取方式：访问**任意**存储单元的读写时间与它的**物理位置无关**——所有单元等时可达。随机存取存储器 RAM（Random Access Memory）因此得名。按存取方式，按地址访问的存储器分三类：
- **随机存取 RAM**（等时）：主存、Cache
- **顺序存取 SAM**（位置决定时间）：磁带
- **直接存取 DAM**（定位+顺序，介于两者之间）：磁盘

外加按内容访问的相联存取（CAM，快表）。随机存取的物理基础是**地址译码器**：n 位地址经译码器直接选中 2ⁿ 根选通线中的一根，选中任何单元耗时相同。

## 正例（≥2 个）
1. **主存等时访问**：访问地址 0 的单元和访问地址 4G-1 的单元，都是 1 个存取周期——内存条就是 RAM，读写速度不因位置改变。
2. **数组的 O(1) 随机访问**：C 语言 `a[0]` 和 `a[9999]` 的访问时间相同（都已在主存中）——这正是数组支持"下标直接取"的硬件前提；换成磁带存储，读第 9999 个元素要转完整盘。
3. **速度分级**：同样读一段数据，RAM（等时，1 个周期）> 磁盘 DAM（先移磁头臂再等盘转）> 磁带 SAM（从头转到尾）——38 号课原文的排序。

## 反例/边界（≥1 个）
1. **"随机存取 = 随机乱序访问"是错的**："随机"指**任意单元等时可达**，不是"随机数/乱序"——访问顺序完全由程序决定，可以是顺序的也可以是跳着来的。
2. **"磁盘也是随机存取"是错的**：磁盘是**直接存取**（DAM）——磁头臂移动到目标区域有点像随机存取，但还要等盘片旋转让数据划过磁头（顺序特性）。读写时间因磁道远近、内外圈而不同，不是等时访问。
3. **"程序里访问内存永远等时"不完全对**：RAM 芯片本身等时，但程序感受到的时间差来自 Cache 命中/未命中（层次结构）——那是另一个层面的问题，不是 RAM 的特性。

## 详细解释
### 按存取方式分类（四分法，速度从快到慢）
| 类型 | 访问方式 | 访问时间 | 例子 |
|------|---------|---------|------|
| 相联存取 CAM | 按内容并行比较 | 一轮命中（O(1)） | 快表 TLB |
| **随机存取 RAM** | 按地址，**等时** | 与位置无关，恒定 | 主存、Cache |
| 直接存取 DAM | 定位（随机）+ 旋转（顺序） | 与位置有关，中等 | 磁盘 |
| 顺序存取 SAM | 按地址，从头顺序走 | 与位置强相关，最慢 | 磁带 |

### 地址译码器——随机存取为什么等时
```
n 位地址 ──→ ┌─────────┐
              │ 地址译码器 │ ──→ 2ⁿ 根选通线，只选中其中一根
              └─────────┘
选中 0 号单元：走第 0 根线      ← 译码器"同时扇出"到所有单元
选中 2ⁿ-1 号单元：走最后一根线   ← 无论选中哪根，译码延迟相同
```
关键：译码器的选通信号**并行扇出**到所有存储单元，选中 0 号和选中最后一号走的是等长的逻辑路径——所以读写时间与位置无关。

## 备注
- **408 考点 — 四分法**：相联 > 随机 > 直接 > 顺序（按速度）；RAM/SAM/DAM 按地址访问，CAM 按内容访问
- **"随机"的准确含义**：等时访问（Random = 任意单元同样快），不是乱序——面试/考试被问"为什么叫 Random Access"要答等时
- **记忆口诀**：快递柜等时取（随机），传送带排着等（顺序），图书馆先定位再翻（直接）——磁带最慢、磁盘居中、主存最快
- **易混术语**：磁盘常被叫"硬盘随机访问"，但教材口径是直接存取 DAM——做题按教材走
