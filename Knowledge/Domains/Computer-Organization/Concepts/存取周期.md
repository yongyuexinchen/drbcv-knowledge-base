# 存取周期

## 类型判定
判别型 — 定义存储器连续两次读/写之间必须等待的最短时间间隔（存取周期 TM），并厘清它和存取时间 TA 的区别——属于"性能时序"类概念。

## 类比 ★
**一句话比喻：** 存储器的读/写就像公共厕所冲水——按下冲水键、水流哗啦下去的那一下是存取时间（TA）；水箱重新蓄满水是恢复时间（TR）；而"两次冲水之间必须等的总时长"就是存取周期（TM）。刚冲完马上再按，水箱是空的，冲不出水——存储器刚读完马上再读，读出的是错误数据。

### 生活映射
| 概念世界                | 现实世界                 |
| ------------------- | -------------------- |
| 存取时间 TA（一次读/写操作耗时）  | 按下冲水键，水流哗啦冲下去的瞬间     |
| 恢复时间 TR（操作后存储器恢复稳定） | 水箱重新蓄水的时间——这期间再冲就没水了 |
| 存取周期 TM = TA + TR   | 两次冲水之间必须等的最小间隔（含蓄水）  |

## 是什么
**存取周期（存储周期）TM** 是存储器连续两次读/写之间**允许的最短时间间隔**，由两部分构成：
- **存取时间 TA**：一次读/写操作实际花费的时间（从发出读/写命令到数据就绪/写入完成）
- **恢复时间 TR**：操作结束后，存储器恢复到能进行下一次操作所需的时间（如 DRAM 的预充电）

公式：`TM = TA + TR`。虽然单次读/写理论上只需 TA，但连续操作必须至少间隔 TM——因为存储器需要恢复时间。**存取时间 ≠ 存取周期**，这是 408 高频考点。

## 正例（≥2 个）
1. **连续读操作的最小间隔**：某主存 TA = 50ns，TR = 30ns → TM = 80ns。第一次读结束后不能马上发起第二次读（50ns 时就发），必须等满 80ns——否则读出的数据不对。
2. **数据传输率（主存带宽）**：存储字长 32 位（4 字节 = 4 个螺丝盒），存取周期 80ns → 数据传输率 = 存储字长 ÷ TM = 4B ÷ 80ns = 50MB/s。每个周期恰好读写一个存储字。
3. **DRAM 的物理原因**：DRAM 电容读出是**破坏性读出**——读的过程电荷被放掉，必须立即重写/预充电恢复（这就是 TR 的物理来源）。所以 DRAM 的存取周期明显长于 SRAM（SRAM 触发器读出不破坏数据，恢复时间短）。

## 反例/边界（≥1 个）
1. **"存取时间就是存取周期"是错的**：TA 只是一次操作的时间，TM = TA + TR。题目若问"连续两次读最短间隔"或"数据传输率"，一律用 TM，绝不用 TA。
2. **"单次读只需 TA，所以可以按 TA 连续读"是错的**：第一次读结束后存储器处于"恢复中"状态，此时发起第二次读会得到错误数据——物理上不允许，必须等满 TM。
3. **数据传输率按 TM 算不是按 TA 算**：带宽 = 存储字长 ÷ TM。若误用 TA 会高估带宽（把恢复时间免费送掉了）。

## 详细解释
### 读操作时序（文字版时间轴）
```
     ←——— 存取周期 TM ———→
     ←— TA —→←— TR —→
读命令发出          数据就绪        存储器恢复
    │              │              │
    ▼              ▼              ▼
  ┌────────┐   ┌────────┐   ┌────────┐
  │ 读数据  │ → │ 取走数据 │ → │ 预充电  │ → 下一次读可以开始
  └────────┘   └────────┘   └────────┘
（破坏性读出：DRAM 电容放电，必须恢复/重写）
```

### 关键公式
- 存取周期：`TM = TA + TR`
- 数据传输率（主存带宽）：`数据传输率 = 存储字长 ÷ TM`
  - 单位：字/秒、字节/秒（B/s）或位/秒（b/s）——注意大 B 小 b
- 每个存取周期可读/写**一个存储字**（一整行螺丝盒）

### 为什么必须有恢复时间（物理层）
- DRAM 用**电容**存电荷：读 = 放电，电荷被破坏 → 需要**预充电**恢复电平 → TR
- SRAM 用**触发器**存状态：读不破坏数据 → TR 很短，存取周期 ≈ 存取时间
- 这就是"SRAM 比 DRAM 快"的物理原因之一（另一个是刷新）

## 备注
- **408 考点 — TA vs TM**：存取时间是"单次操作耗时"，存取周期是"连续操作最小间隔"，TM = TA + TR——两者混用必错
- **408 考点 — 带宽公式**：数据传输率 = 存储字长 ÷ 存取周期；题目给 TA 时先算 TM 再代公式
- **单位换算陷阱**：80ns → 12.5MHz；4B/80ns = 50MB/s = 400Mb/s（大 B 小 b 差 8 倍）
- **记忆口诀**：冲水蓄水一周期——"冲一下（TA），蓄满（TR），才能再冲（TM）"
