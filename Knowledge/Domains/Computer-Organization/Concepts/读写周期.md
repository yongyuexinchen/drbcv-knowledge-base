# 读写周期

## 类型判定
判别型 — 定义一次完整读/写操作的总时间（读周期/写周期），讲清其与存取时间、存取周期的层次关系，理解 CPU 与主存配合的时序——属于"存储时序"类概念。

## 类比 ★
**一句话比喻：** 读写周期是**整单交易流程**——报号（送地址）→ 等号码确认（地址稳定）→ 仓库开门（片选有效）→ 搬货/收货（数据传输）→ 销单（撤销信号）；存取时间是**搬货那一下**（货从货架到提货区）；存取周期是**两次交易必须等的最短间隔**（含货架回弹恢复）。一单流程比搬货长，两单间隔比一单长。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 读周期（地址→片选→数据输出→撤销） | 完整取货流程——报号→确认→搬货→收货→销单 |
| 写周期（地址+数据→写命令→写入） | 完整送货流程——报号→放货→签收→销单 |
| 三者关系：TA ≤ 读写周期 ≤ 存取周期 | 搬货那一下 ≤ 整单流程 ≤ 两次交易最小间隔 |

## 是什么
**读写周期**指一次**完整**读/写操作的总时间：
- **读周期**：CPU 送地址 → 等地址信号稳定 → 发出读命令（片选/使能有效）→ 存储单元数据经数据总线输出 → CPU 接收 → 撤销地址和请求信号
- **写周期**：CPU 送地址 + 数据 → 等稳定 → 写命令有效 → 数据写入存储单元 → 撤销信号

与存取时间、存取周期的层次关系：**存取时间 TA**（数据就绪/写入完成那一下）⊂ **读写周期**（完整流程，含地址建立、信号稳定、撤销）⊂ **存取周期 TM**（连续两次操作的最小间隔，= TA + TR 含恢复时间）。典型关系：**TA ≤ 读写周期 ≤ TM**。43 号课原话：RAM 的读写周期"不太重要"（课程跳过细节），但 CPU 与主存配合的时序逻辑是理解总线定时的基础。

## 正例（≥2 个）
1. **读周期完整流程（43 号课时序图）**：CPU 送地址（电信号可能不稳）→ 等信号稳定 → 发主存请求 → 译码器输出有效片选 → 选通芯片 → 数据经数据总线传出（D out）→ CPU 确认接收 → 撤销片选 → 撤销地址。**每一步都是周期的一部分**。
2. **为什么必须"等地址稳定"**：地址线刚输出的电信号可能抖动，若在稳定前就发片选，译码器可能选错存储单元——所以读/写周期里都有一段"地址建立时间"，这是时序图存在的意义。
3. **写周期**：CPU 先送地址和数据（都等稳定）→ 再发写命令（WE 有效）→ 数据写入电容 → 撤销信号——写和读的流程对称，只是"搬货"方向相反。

## 反例/边界（≥1 个）
1. **"存取时间 = 读写周期"是错的**：存取时间是"数据就绪/写入完成"那一下；读写周期是**完整流程**——还包括地址建立、信号稳定、撤销信号这些"非存取"环节。搬货 ≠ 整单交易。
2. **"存取周期 = 读写周期"是错的**：存取周期 = TA + TR（含**恢复时间**），是**连续两次操作**之间的最小间隔；读写周期是一次操作的总时间。两者关系：TM ≥ 读写周期——第一次操作做完还要等恢复才能做第二次。
3. **"读周期和写周期一定相同"不成立**：取决于器件特性——DRAM 读是**破坏性读出**（读后要恢复），写是直接写电容，两者耗时可能不同。408 一般不考具体数值差，但要知道"可能不同"。

## 详细解释
### 读周期时序（文字版）
```
CPU:  送地址 ──→ 等稳定 ──→ 发读命令/片选 ──→ 收数据 ──→ 撤销请求+地址
                │            │                  │
主存:           地址锁存     译码选通           数据输出(D out)
                │            │                  │
        ←────────────── 读周期（完整流程）──────────────→
                      ←TA→（存取时间：数据就绪）
```
- **地址建立**：CPU 送地址后必须等待电信号稳定（setup time），否则译码可能选错
- **数据输出**：选通后存储单元数据经数据总线送到 CPU
- **撤销**：CPU 确认接收后才撤销地址——顺序不能乱

### 写周期时序（文字版）
```
CPU:  送地址+数据 ──→ 等稳定 ──→ 发写命令(WE) ──→ 数据写入 ──→ 撤销信号
                        │              │
主存:                   地址+数据就位   电容充电（写）
```

### 三个时间的关系（钉死）
```
TA（存取时间）   ≤   读写周期（完整流程）   ≤   存取周期 TM（= TA + TR）
货架搬货那一下      整单交易（含报号/确认/销单）    两次交易最小间隔（含货架回弹）
```
