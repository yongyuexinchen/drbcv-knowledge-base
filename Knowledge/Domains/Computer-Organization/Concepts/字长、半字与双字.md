# 字长、半字与双字

## 类型判定
判别型 — 定义"字"这个基本数据单位及其变体（半字/双字）的大小如何随机器字长变化，并厘清它和永远固定不变的 bit/字节之间的关系。

## 类比 ★
**一句话比喻：** 把数据想成五金店——bit 是一颗螺丝，字节是装了 8 颗螺丝的螺丝盒（任何时代都是 8 颗，雷打不动），而"字"是 CPU 的工具箱：32 位时代的工具箱配 4 个螺丝盒，64 位时代配 8 个。箱子规格随时代换，螺丝盒永远不变。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| bit（最小单位，恒为 1 位） | 一颗螺丝，不可再分的最小零件 |
| 字节 B（恒为 8 bit，任何机器都一样） | 螺丝盒，永远装 8 颗螺丝 |
| 字长（随 CPU 时代/标准变化） | 工具箱：32 位 CPU 配 4 个螺丝盒，64 位 CPU 配 8 个螺丝盒 |

## 是什么
- **字（word）**：CPU 处理数据的基本单位。一个"字"包含多少位**没有固定答案**——取决于这台计算机硬件怎么设计，常见 8/16/32/64 位。
- **机器字长**：CPU 一次整数运算能处理的位数，通常等于通用寄存器的宽度。机器字长 32 位 → 一个字 = 32 bit = 4 字节 = 4 个"螺丝盒"。
- **半字（half word）**：字长的一半。32 位机器上 = 16 bit = 2 字节（低配版工具箱）。
- **双字（double word）**：字长的两倍。32 位机器上 = 64 bit = 8 字节（两个工具箱的量）。
- **关键锚点**：bit 和字节永远不变（1 字节 = 8 bit，任何时代、任何 CPU 都成立），变的是"字"——它是随 CPU 标准漂移的。

## 正例（≥2 个）
1. **32 位机器（如 i386 时代）**：字 = 32 bit = 4 字节（工具箱 4 个螺丝盒）；半字 = 16 bit = 2 字节；双字 = 64 bit = 8 字节。
2. **64 位机器（现代 x86-64）**：字 = 64 bit = 8 字节（工具箱 8 个螺丝盒）；半字 = 32 bit = 4 字节；双字 = 128 bit = 16 字节。注意：**32 位机上的双字 = 64 位机上的一个字**——两个时代的"工具箱"和"双倍工具箱"恰好接上。
3. **存储字长的例子**：某主存 MDR 是 16 位寄存器 → 存储字长 = 16 bit，每个存储单元存放 16 bit；若 MAR 是 4 位 → 存储字数 = 2⁴ = 16 个单元，存储容量 = 16 字 × 16 bit。

## 反例/边界（≥1 个）
1. **"字"和"字节"不是一回事**（408 最爱考的混淆点）：中文翻译像，英文 word vs byte 完全不同——字节永远 8 bit，字的大小看机器结构，可能是 8/16/32/64 bit。
2. **x86 汇编语境的 word 是历史遗留**：Intel 从 8086（16 位机）沿用下来的约定——word = 16 bit、dword = 32 bit、qword = 64 bit，是**固定值**；而教材里的"字长随机器而定"是通用语境。两套术语体系别混用。
3. **机器字长 ≠ 存储字长 ≠ 指令字长**：机器字长 = 通用寄存器宽度（CPU 一次运算位数）；存储字长 = MDR 位数（一个存储单元放多少位）；指令字长 = 一条指令的位数。三者由不同硬件部件决定，可以不同（比如机器字长 32 位、指令字长 64 位的情况）。

## 详细解释
### 字长三兄弟（408 核心考点）
| 概念 | 由谁决定 | 含义 |
|------|---------|------|
| 机器字长 | 通用寄存器宽度 | CPU 一次整数运算的位数 |
| 存储字长 | MDR 的位数 | 每个存储单元能放的二进制位数 |
| 指令字长 | 指令格式设计 | 一条机器指令占的位数 |

### 时代演变（工具箱配置表）
| 时代 | 机器字长 | 一个字 | 半字 | 双字 |
|------|---------|--------|------|------|
| 8 位机 | 8 bit | 1 字节（1 盒） | 4 bit | 16 bit |
| 16 位机 | 16 bit | 2 字节（2 盒） | 8 bit | 32 bit |
| 32 位机 | 32 bit | 4 字节（4 盒） | 16 bit | 64 bit |
| 64 位机 | 64 bit | 8 字节（8 盒） | 32 bit | 128 bit |

### 为什么螺丝盒永远 8 颗
字节是内存寻址和文件/网络传输的最小可寻址单位——整个软件生态（ASCII、UTF-8、文件系统）都建立在"1 字节 = 8 bit"之上，改它等于推翻一切。而"字"是 CPU 内部数据通路的宽度，随工艺和设计目标（一次算更多位更快）进化，所以它才是随时代变的那个。

## 备注
- **408 考点 — 存储容量公式**：存储容量 = 存储字数 × 存储字长；MAR 位数 → 存储字数（2^n），MDR 位数 → 存储字长
- **408 考点 — 大小 B**：b = bit（位），B = byte（字节），8 b = 1 B；描述容量时混用大小 B 直接算错
- **记忆口诀**：螺丝（bit）和螺丝盒（B）万年不变，工具箱（字）随 CPU 时代换——"字长看机器，字节看天条"
- **易混术语对照**：教材"字长随机器" vs x86 汇编"word=16bit 固定"——考试按语境走，汇编题用 Intel 约定，组成原理题用机器字长
