# 外部设备

## 类型判定
判别型 — 回答「计算机有哪些常见外部设备、每类外设的工作原理和性能指标」，属于系统构成类概念。

## 类比 ★
**一句话比喻：** 像人和外界交互的五官——键盘鼠标是眼睛耳朵（往里输入信息），显示器打印机是嘴巴手（往外表达），硬盘光盘是日记本（既能写进去又能翻出来）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 输入设备（键盘/鼠标） | 快递员把包裹塞进你家（电信号→ASCII码→塞给主机） |
| 输出设备（显示器/打印机） | 你把做好的菜端出来给人看（主机数据→像素点/墨点→呈现） |
| 显存 vRAM | 画家的调色盘——先调好一整幅画的颜料（存一帧图像），再一笔笔画上去（逐像素刷新） |
| 字符发生器 ROM | 印章模具——你说"A"，它就翻出"A"的模具（字形码）给你印上 |

## 是什么
外部设备（IO 设备）是连接在主机之外的所有设备的统称，分为三大类：**输入设备**（将外界信息送入主机）、**输出设备**（将主机数据输出到外界）、**外存设备**（既可输入又可输出，如磁盘、光盘、SSD）。主机通过 IO 接口与外部设备交互。408 考试重中之重是**显存（vRAM）的计算**和**字符显示器的工作原理**。

## 输入-输出空间
- **输入**：人操作外设产生的物理动作（按键、移动鼠标）→ 电信号 → 编码（如 ASCII）→ 通过 IO 接口送入主机
- **输出**：主机数据 → 通过 IO 接口 → 外设内部处理（如显存缓存一帧 → 字符发生器转换字形码 → 屏幕刷新）
- **前置条件**：外设已通过 IO 接口连接到系统总线；驱动程序已加载

## 正例（≥2 个）
1. **键盘输入的三个步骤**：① 按键触发开关连接，硬件电路确定按下的是哪个键；② 把按键的电信号翻译成主机能接收的编码（一般是 ASCII 码）；③ 通过 IO 接口把编码传给主机。你敲一个 "A"，键盘内部给出 ASCII 码 65（0x41），IO 接口把 65 塞进数据寄存器，CPU 取走。
2. **显存容量计算**：我的电脑屏幕分辨率 1440×900，24 位彩色（每像素 3 字节）→ 一帧图像大小 = 1440×900×3 = 3.7 MB。这就是显存理论最小值——显存放不下至少一帧就无法正常工作。实际上我的集显有 1.5 GB 显存（动态），远超这个最小值，因为还要存 3D 模型、纹理等渲染数据。
3. **字符显示器原理**：显存里只存放字符的 ASCII 码（不是点阵），显示前把 ASCII 码送到字符发生器，字符发生器里的 ROM 存有每个 ASCII 码对应的字形码（点阵信息，如 7×9 点阵 = 63 bit），根据字形码控制每个像素的亮灭，最终在屏幕上打出字符形状。

## 反例/边界（≥1 个）
1. **「独立显卡才有显存」是错的**：集显也有显存，只不过它是从内存里划出来的共享空间（动态分配），不像独显有自己的专用显存芯片。买了独立显卡的电脑，显存是显卡上独立的存储芯片。
2. **灰度级 ≠ 彩色位数**：灰度级是描述黑白显示器每个像素能用多少级深浅的指标（n bit → 2^n 级灰度）；彩色显示器用 RGB 三原色，每个像素通常占 24 bit（红 8+绿 8+蓝 8 = 2^24 种颜色）。显存容量 = 分辨率 × 每像素位数，而非分辨率 × 灰度级。
3. **「教材说 LCD 打不过 CRT」已过时**：1999 年的教材说 CRT 色彩好 Lcd 难超越，但现在的 LCD/LED/OLED 技术早已反超。考试只需理解原理，不必纠结教材中的过时结论。

## 详细解释
### 输入设备
| 设备 | 原理 | 输出信息 |
|------|------|---------|
| 键盘 | 按键→接通开关→硬件电路识别键位→翻译为 ASCII 码 | ASCII 编码 |
| 鼠标（机械式） | 底部滚球滚动→传动内部纵横轴→分辨移动方向和距离 | 移动方向、速度、距离 |
| 鼠标（光电式） | 光传感器检测表面移动→分辨方向和距离 | 移动方向、速度、距离 |

### 显示器分类
- **按显示器件**：CRT（阴极射线管，电子枪打到荧光屏，老式大屁股电视）、LCD（液晶显示器）、LED（发光二极管阵列）
- **按内容**：字符显示器（只显字符）、图形显示器（显示规则的矢量图形，如波形/股线）、图像显示器（丰富多彩的图像，即现代普通的显示器和手机屏）

### 显示器性能指标
| 指标 | 含义 | 考试要点 |
|------|------|---------|
| 屏幕大小 | 对角线长度（英寸） | 同英寸数下方形面积最大 |
| 分辨率 | 横向像素点 × 纵向像素点 | 用于计算一帧数据量 |
| 灰度级/颜色深度 | 每个像素用多少 bit 表示 | n bit → 2^n 种颜色；24 bit = 真彩色 |
| 刷新率 | 每秒刷新多少帧（Hz） | 60 Hz = 每秒 60 帧 |

### 显存计算（408 常考）
- **显存最小容量** = 分辨率 × 颜色深度（bit/像素）÷ 8（换为字节）
- **显存带宽（最低写入速度）** = 一帧大小 × 刷新率（字节/秒）
  - 例：1440×900×24 bit = 3.7 MB/帧；刷新率 60 Hz → 显存带宽需 ≥ 3.7×60 ≈ 222 MB/s

### 字符显示器工作流程
```
显存（存 ASCII 码）→ 字符发生器（ROM 存字形码）→ 输出缓冲寄存器 → 屏幕显示
```
显存储存的是字符编码（如 ASCII），字符发生器的 ROM 里存放字形点阵码（如英文 7×9 点阵 63 bit，中文 16×16 点阵 256 bit），根据编码→查出字形→控制对应像素亮灭。字形码大小 = M×N bit（M×N 为点阵行列数）。

### 打印机分类
| 分类维度 | 类型 | 特点 |
|---------|------|------|
| 印字原理 | 机打式（针式） | 物理撞击→防伪好（留有物理印记）、噪声大、速度慢；银行票据常用 |
| 印字原理 | 非机打式（喷墨/激光） | 速度快、成本低、家用常见；喷墨防水差、激光常用于数码照片 |
| 工作方式 | 串行 | 逐字打印 |
| 工作方式 | 行式 | 逐行打印 |

## 备注
- 408 最高频考点：**显存计算**（容量 = 分辨率×每像素位宽，带宽 = 一帧×刷新率），单位千万别搞错——带宽是速度，单位为字节/秒
- 易混淆：字符显示器的显存里存的是**编码**（如 ASCII），不是字形码；字形码存在字符发生器 ROM 中
- 口诀：「键鼠入，显印出，盘存双」——键盘鼠标=输入，显示器打印机=输出，硬盘光盘=双向（外存）
- 教材中"LCD 不如 CRT""主机侧总是并行传输"等描述已过时，考试只考原理不考优劣评价
