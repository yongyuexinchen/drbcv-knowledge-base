# 进位计数制

## 类型判定
判别型 — 回答"什么是进制、基数、位权，各种进制之间怎么互转"，属于数据表示的基础概念。

## 类比 ★
**一句话比喻：** 像不同国家用的钱——十进制是人用的"人民币"（逢十进一，10个符号），二进制是计算机的"内部货币"（逢二进一，只有0和1两个符号），八进制和十六进制是翻译用的"中介币"（方便人类快速阅读二进制）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 位权（位置决定权重） | 人民币的个十百千万位——同一个数字"5"，在个位是5元，在百位是500元 |
| 基数（每位数码允许的符号个数） | 十进制的"十"好比人有10根手指，数到10就进一位 |
| 不同进制互转 | 把美元换人民币——本质是同一笔钱（同一个数值），用不同规则表达 |

## 是什么
进位计数制由**基数**（每个数码位允许的不同符号个数）和**位权**（每个位置对应的权重，基数的某次方）决定。任何 R 进制数 = Σ(数码 × R^位置)。计算机底层用二进制（两状态物理器件天然表示 0/1），人类阅读时常用八进制（3位二进制一组）、十六进制（4位二进制一组）作为"缩写"。不同进制数之间通过"按权展开"（→十进制）和"分组替换"（二进制↔八/十六进制）实现互转。

## 输入-输出空间
- **输入**：一个R进制数的数码序列（含可能的小数点）
- **输出**：对应的十进制真值，或转换后的目标进制数码序列
- **前置条件**：明确基数R（2/8/10/16）和每个数码位的位权

## 正例（≥2 个）
1. **二进制转十进制**：1101.1₂ → 1×2³ + 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ = 8 + 4 + 0 + 1 + 0.5 = 13.5
2. **二进制转八进制**：1 110 111₂ → 每3位一组（不够高位补0）→ 001 110 111 → 1 6 7₈ = 167₈
3. **二进制转十六进制**：1110 1111₂ → 每4位一组 → E F₁₆ → EFH（E=14，F=15）
4. **不同进制标识**：1010B（二进制）、75D（十进制）、A8H 或 0xA8（十六进制）、125₈（八进制）

## 反例/边界（≥1 个）
1. **"逢R进一"不是"等于R时变1"**：八进制7+1=10（进位后该位归0），不是变成"8"——因为八进制没有符号"8"。同理十六进制 F+1=10₁₆。
2. **二进制转八进制补零方向错**：整数部分高位补零（001）、小数部分低位补零（010→010），方向反了会得错误结果。
3. **"B"结尾不一定是二进制**：虽然B通常表示 binary，但题目如果没明确标注，需结合上下文判断进制类型。

## 详细解释
**不同进制之间的转换方法：**

| 转换方向 | 方法 | 示例 |
|---------|------|------|
| R进制 → 十进制 | 按权展开求和：Σ(数码 × R^位权) | 101.1₂ = 1×4+0×2+1×1+1×0.5 = 5.5 |
| 十进制 → R进制 | 整数除R取余（逆序），小数乘R取整（正序） | 13÷2=6余1, 6÷2=3余0, 3÷2=1余1, 1÷2=0余1 → 1101₂ |
| 二进制 ↔ 八进制 | 每3位二进 = 1位八进 | 110111₂ → 67₈ |
| 二进制 ↔ 十六进制 | 每4位二进 = 1位十六进 | 11011111₂ → DF₁₆ |

**基数与位权**：对于 R 进制，小数点前的第 k 位（从0开始）位权 = R^k，小数点后的第 k 位位权 = R^{-k}。基数是 R，意味着每个数码位允许的符号为 0, 1, ..., R-1（十六进制中 10-15 用 A-F 表示）。

**二进制是计算机的根本原因有三**：
1. 可用两个稳定状态的物理器件表示（高/低电平、正/负电荷）
2. 0/1 正好对应逻辑值的假/真，便于实现逻辑运算
3. 逻辑门电路可方便地处理二进制，实现算术运算

**真值与机器数**：真值是现实世界中带正负号的数值（如 +13、-19），机器数是这些数值在计算机中用二进制编码表示的形式（如 01101）。同一真值可用不同编码（原码/反码/补码/移码）表示。

## 备注
- 权值速记：二进制整数位权从最低位起为 1, 2, 4, 8, 16, 32, 64, 128...，小数位权为 0.5, 0.25, 0.125...
- 常见后缀：B=二进制(binary)、D=十进制(decimal)、H=十六进制(hexadecimal)、O=八进制(octal)；0x前缀也表示十六进制
- 罗马数字不属于进位计数制——它只靠符号反映权重，符号位置不改变权值，不是"进制"
- 408常考各种进制互转的算式和"逢R进一"的加法运算（如十六进制 5.8₁₆ + 0.9₁₆ = 6.1₁₆）
