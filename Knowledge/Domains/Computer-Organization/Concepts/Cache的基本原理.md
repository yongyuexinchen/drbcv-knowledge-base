# Cache 的基本原理

## 类型判定
定义型 — 回答"Cache 为什么能加速、局部性原理是什么、命中率怎么算"，属于存储系统提速核心概念。

## 类比 ★
**一句话比喻：** 像厨房操作台上的调味架——你炒菜时只频繁用盐/酱油/料酒（局部性原理），把这几样从柜子深处（主存）拿到手边架子上（Cache），随手可得，不用每次都弯腰开柜门翻半天。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 空间局部性 | 看书从左到右一行一行读——刚读完第 5 个字，接下来大概率读第 6 个字 |
| 时间局部性 | 循环结构——刚用过加法的函数，for 循环跑 1000 次，这个加法就会用 1000 次 |
| Cache 命中/缺失 | 桌上有笔（命中）直接拿；桌上没笔（缺失）去书包里翻，再放回桌上 |

## 是什么
Cache（高速缓冲存储器）是用 SRAM 制造的小容量高速存储层，被集成在 CPU 内部。其工作原理基于**程序的局部性原理**：CPU 当前访问地址周围的数据（空间局部性）以及刚刚访问过的数据（时间局部性），在不久的将来很可能被再次访问。因此硬件把 CPU 刚访问的主存块复制到 Cache 中，CPU 优先从 Cache 取数据，命中则极快（~1ns），未命中才访问慢速主存（~60ns）。主存和 Cache 之间以**块**（Block，也称行 Line）为单位交换数据。

## 输入-输出空间
- **输入**：CPU 要访问的主存地址
- **输出**：命中→Cache 中数据（耗 TC）；未命中→主存数据（同时将该主存块调入 Cache）
- **前置条件**：主存和 Cache 按相同大小的块划分；主存地址=块号+块内地址

## 正例（≥2 个）
1. **空间局部性（数组遍历）**：C 语言二维数组按行存放，程序 `for(i) for(j) a[i][j]` 一行一行访问。访问 a[0][0] 时，Cache 把 a[0][0] 所在的主存块（含 a[0][1]~a[0][N]）整块调入。之后访问 a[0][1]~a[0][N] 全部命中，性能极高。若改成 `for(j) for(i) a[i][j]`（跳列访问），空间局部性差，命中率暴跌，程序变慢数倍。
2. **时间局部性（循环变量）**：`for(i=0;i<1000;i++) sum+=a[i];` → 变量 i 和 sum 在 1000 次循环中被反复访问，第一次加载到 Cache 后，后续 999 次全部命中。指令层面的加法指令也因循环而反复执行，同样受益于时间局部性。

## 反例/边界（≥1 个）
1. **先访 Cache 再访主存 vs 同时访问**：策略①先查 Cache（耗时 TC）→未命中才访主存（+TM），平均 = H×TC + (1-H)×(TC+TM)。策略②同时查（TC 后可中断主存访问）→命中时=TC，未命中时=TM（因同时开始，不需要额外 TC），平均 = H×TC + (1-H)×TM。同时访问方案性能更好。
2. **引入 Cache 后性能提升倍率计算**：设 Cache 速度 T、主存 5T、命中率 95%、同时访问方案 → 平均 = 0.95×T + 0.05×5T = 1.2T → 性能 = 5T/1.2T = 4.17 倍。先访后访方案 → 平均 = 0.95×T + 0.05×6T = 1.25T → 性能 = 4.0 倍。
3. **"解决了命中率就万事大吉"不是**：还需解决映射方式（块放哪）、替换算法（满了换谁）、写策略（数据一致性）三个配套问题。

## 详细解释

**局部性原理的两个维度：**

| 类型 | 原因 | 指令示例 | 数据示例 |
|------|------|---------|---------|
| 空间局部性 | 指令/数据顺序存放 | 程序计数器 PC 自动 +1 取下一条指令 | 数组元素 a[0]→a[1]→a[2] |
| 时间局部性 | 循环结构重复执行 | 循环体内的指令被反复执行 | 循环计数变量 i、累加变量 sum |

**主存-Cache 分块模型**（例：主存 4MB，Cache 8KB，块大小 1KB）：
- 主存 = 4096 块（块号 0~4095），Cache = 8 块（块号 0~7）
- 主存 22 位地址 = 12 位块号 + 10 位块内地址（1KB 需 10 位）
- 块是主存↔Cache 数据交换的最小单位

**系统平均访问时间计算**：
- 命中率 H：CPU 要的数据在 Cache 中的比例
- 缺失率 = 1-H
- 平均访问时间 T_avg 取决于访问策略（见反例部分）

## 备注
- 局部性原理是 Cache 有效的理论基石——没有它，Cache 就是白花钱
- 命中率公式 H = 命中次数/总访问次数，平均访问时间=H×TC+(1-H)×T_miss
- 两种访问策略：同时访问（更好）vs 先访 Cache 再访主存，做题先读题判断
- Cache 块=Cache 行（Line），主存块=内存块/页框（Page Frame），术语等价但要辨认
