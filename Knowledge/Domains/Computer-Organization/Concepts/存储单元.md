# 存储单元

## 类型判定
判别型 — 定义存储体的基本编址单位（一个存储字），厘清存储元/存储单元/存储体的层级关系以及它与字节的区别——属于"存储结构"类概念。

## 类比 ★
**一句话比喻：** 螺丝盒体系的三级仓库——存储元是一颗螺丝（1 bit），存储单元是一个工具箱（一个存储字，一次访存整体搬运），存储体是整面货架（所有工具箱按门牌号排布）。你要取货，永远是一整个工具箱地搬，不会只拿一颗螺丝。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 存储元（1 位，MOS管+电容） | 一颗螺丝——最小的存储零件 |
| 存储单元（一个存储字） | 一个工具箱——一整排螺丝盒绑在一起，每次整体搬运 |
| 存储体（全部单元的总和） | 整面货架——按门牌号排布的所有工具箱 |

## 是什么
**存储单元**是存储体的**基本编址单位**：每个存储单元存放一个**存储字**（word），大小 = 存储字长 = **MDR 的位数**，一次访存恰好读写一个存储单元（一整行）。层级关系：**存储元**（1 位）→ **存储单元**（一个字，N 位）→ **存储体**（M 个单元）。每个存储单元对应**唯一地址**——MAR 的位数决定存储单元总数（2^MAR 位）。**存储容量 = 存储单元数 × 存储字长**——这是所有容量计算的出发点。

## 正例（≥2 个）
1. **MDR 16 位的主存**：存储字长 = 16 bit，每个存储单元放 16 bit（05 号课例子）——一次访存读出 16 位，放进 MDR。
2. **8K×8 存储芯片**：8K = 2^13 个存储单元（需 13 根地址线），每个单元 8 位（8 根数据线）——容量 = 8K × 8 bit = 8KB。
3. **MAR 4 位的主存**：2^4 = 16 个存储单元，地址 0~15——MAR 位数直接决定了"门牌号能编多少个号"。

## 反例/边界（≥1 个）
1. **存储单元 ≠ 存储元**：存储元存 1 位（一颗螺丝），存储单元存一个存储字（一个工具箱）——单元由 N 个存储元组成，别混。
2. **存储单元 ≠ 字节**：字节固定 8 位，存储单元大小 = 存储字长（MDR 位数），可能是 8/16/32/64 位。32 位字长的机器，一个存储单元 = 4 个字节。
3. **按字节编址时单元与地址不是一一对应**：按字节编址每个**字节**一个地址，一个 32 位存储单元里就有 4 个字节地址（单元起始地址 + 0/1/2/3）——按字寻址时给出的是单元起始地址。

## 详细解释
### 层级结构与容量公式
```
存储元（1 位）    —— 螺丝
   ↓ N 个组成
存储单元（1 字）  —— 工具箱（大小 = 存储字长 = MDR 位数）
   ↓ M 个组成
存储体（M 字）    —— 货架（M = 2^MAR位数 = 2^地址线根数）

存储容量 = 存储单元数 × 存储字长 = 2^地址线 × 数据线(bit)
```

### 一次访存的完整流程（读）
1. CPU 把目标地址送入 MAR（报门牌号）
2. 译码器把地址翻译成对应选通线的高电平（门禁开对应工具箱）
3. 该存储单元的全部存储元同时被选中（整个工具箱搬起）
4. 数据经数据线流入 MDR（放进提货区）
5. CPU 从 MDR 取走数据

关键：**每次读写都是"一整箱"**——你没法只读一个存储元，最小访存单位就是存储单元。
