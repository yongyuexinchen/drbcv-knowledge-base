# 浮点数的加减运算

## 类型判定
程序型 — 描述 IEEE 754 浮点数加减运算的五步流水：对阶、尾数加减、尾数规格化（左归/右归）、尾数舍入（零舍一入 + 100 特殊处理）、溢出判断（阶码上溢/下溢），每步有明确的操作规则和边界条件。

## 类比 ★
**一句话比喻：** 像两位厨师对账——先把小数点对齐（对阶，小阶向大阶看齐），然后尾数部分该加的加该减的减（尾数运算），算完把结果整理成标准格式（规格化：左归像往左推小数点、右归像往右推），多余的零碎零钱按四舍五入处理（舍入：零舍一入，遇 100 看末位），最后看总金额有没有爆表（溢出判断：阶码全 1 上溢 = 无穷，阶码全 0 下溢 = 缩到非规格化或归零）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 对阶：小阶向大阶看齐，尾数右移 | 两个账本对账，用大的那个单位，小的把位往右挪（丢失低位精度） |
| 规格化：左归 / 右归 | 整理收据——太靠右往左推（左归，阶码减），太靠左往右推（右归，阶码加） |
| 舍入：零舍一入 + 100 看末位 | 结算找零：小于 5 毛不要了（零舍），大等于 5 毛进位（一入）；刚好 5 毛时看前面是奇数还是偶数决定加不加 |

## 是什么
**浮点数的加减运算**是 IEEE 754 标准下两个浮点数进行加减法的标准流程，分为五个步骤：
1. **对阶**：小阶向大阶看齐，阶差 = d → 小阶数尾数右移 d 位（移出位至少额外保留 3 位冗余位），阶码统一为较大值
2. **尾数加减**：两个尾数（含隐含 1 和符号）按源码规则加减（硬件内部转补码运算后再转回源码）
3. **尾数规格化**：确保结果尾数为 1.xxx 形式——若为 0.0…01xxx 则**左归**（尾数左移，阶码递减）；若为 1x.xxx 则**右归**（尾数右移 1 位，阶码递增）
4. **尾数舍入**：保留 1+23 位有效尾数，多余位舍弃。默认**就近舍入**：类似零舍一入——最高舍弃位 = 0 直接截断；= 1 则入位加 1。**特殊情况**：舍弃位为 "100" 时，看保留尾数末位：末位 = 1 才加 1，末位 = 0 直接截断
5. **溢出判断**：根据阶码判定——阶码全 1 → **上溢**（结果记为 ±∞）；阶码全 0 → **下溢**（进入非规格化区间，阶码置全 0 尾数保持不动；尾数全 0 则为机器零）

## 输入-输出空间
- **输入**：两个 float 型浮点数 X 和 Y（32 位，1+8+23 格式），运算类型（加/减）
- **输出**：一个 float 型浮点数 Z（32 位），或溢出后的特殊值（±∞ / 非规格化数 / 机器零）
- **前置条件**：尾数需补全隐含的"1"（规格化时）或"0"（非规格化时）；对阶时移出的低位比特需保留至少 3 位以提高精度

## 正例（≥2 个）
1. **1.5 + 0.5 = 2.0（规格化 + 右归）**：
   - X=1.5 → 0 01111111 100…0；Y=0.5 → 0 01111110 000…0
   - 对阶：X 阶码 − Y 阶码 = 127−126 = 1，Y 尾数右移 1 位
   - 尾数加：1.1 + 0.1 = 10.0（二进制源码相加）
   - 规格化：右归 1 位 → 尾数 1.00…0，阶码 +1 → 10000000（真值 1）
   - 舍入：无多余位
   - 溢出判断：阶码 10000000 不全 1 不全 0 → 正常
   - 结果：0 10000000 000…0 = 2.0 ✓
2. **16777216.0 + 1.5 = 16777218.0（舍入"一入"）**：
   - X=2²⁴（尾数 23 个 0），Y=1.5（尾数 1.1）
   - 对阶：Y 尾数右移 24 位 → 1.1 变成 0.00…011（进冗余位）
   - 尾数加：1.0 + 0.00…011 = 1.00…011（超出 24 位）
   - 舍入：舍弃最高位 = 1 且后两位不全 0 → 末尾加 1 → 尾数末位从 0 变 1
   - 结果 = 16777218.0（而非 16777217.5）✓
3. **-6.75 + 3.125 = -3.625**：
   - X=-6.75 → 1 10000001 101100…0（阶码真值 2），Y=3.125 → 0 10000000 100100…0（阶码真值 1）
   - 对阶：Y 阶码小 1 → Y 尾数右移 1 位
   - 尾数减：X 尾数（负）− Y 尾数（正）= 源码转补码减法 → 负的 1.1101
   - 规格化：已规格化
   - 结果 = -3.625 ✓

## 反例/边界（≥1 个）
1. **16777216.0 + 0.5 = 16777216.0（舍入"零舍"）**：0.5 尾数右移 25 位后进入冗余位，多余的三个位最高位 = 0 → 直接截断不加 1 → 结果等于原数。16777216 + 0.5 还是 16777216，精度被舍掉了。
2. **16777216.0 + 1.0 = 16777216.0（100 特殊处理，末位 0 则截断）**：舍弃位刚好是 "100"，且保留尾数末位 = 0 → 直接截断不加 1，结果不变。
3. **16777218.0 + 1.0 = 16777220.0（100 特殊处理，末位 1 则加 1）**：舍弃位 "100"，保留尾数末位 = 1 → 截断后在末尾加 1 → 结果比预期大 1（219 变 220）。
4. **-6.75 − 6.25 = ?（左归）**：尾数相减得到 0.0…01xxx → 需要左归（尾数左移、阶码递减），左归可能导致阶码跌入全 0 → 触发下溢，进入非规格化区间。
5. **最大正数 + 最大正数 → +∞（上溢）**：阶码右归时 +1 后变成全 1 → 上溢，结果强置为 +∞（阶码全 1、尾数全 0、符号 0）。

## 详细解释
### 五步流程总表
| 步骤 | 操作 | 关键规则 |
|------|------|---------|
| ① 对阶 | 小阶向大阶看齐：小阶码尾数右移 (大阶−小阶) 位 | 移出位至少保留 3 位冗余位；符号位保持不变 |
| ② 尾数加减 | 两个尾数（含隐含位和符号）相加/相减 | 硬件内部转补码运算后还原为源码结果 |
| ③ 规格化 | 确保尾数为 1.xxx | 1x.xxx → 右归 1 位，阶码 +1；0.0…01xxx → 左归直到 1.xxx，阶码同步递减 |
| ④ 舍入 | 保留 1+23 位，处理多余位 | 零舍一入 + 100 特殊：末位 0→截断，末位 1→加 1 |
| ⑤ 溢出判断 | 检查最终阶码 | 全 1 → 上溢（记 ±∞）；全 0 → 下溢（非规格化 / 机器零） |

### 舍入规则详解（就近舍入 = IEEE 754 默认）
| 舍弃位模式 | 处理 |
|-----------|------|
| 最高位 = 0 | **零舍**：直接截断，不加 1 |
| 最高位 = 1 且后不全为 0 | **一入**：截断后在保留尾数末位加 1 |
| 最高位 = 1 且后全为 0（即 "100"） | **看保留尾数末位**：末位 = 1 → 加 1；末位 = 0 → 截断（向偶数舍入） |

### 溢出判断速查表
| 阶码状态 | 含义 | 结果处理 |
|---------|------|---------|
| 不全 0 不全 1 | 正常规格化 | 正常保存 |
| 全 1（11111111） | **上溢**（Overflow） | 尾数强置为全 0，结果记为 ±∞，OF 标志位置 1 |
| 全 0（00000000） | **下溢**（Underflow） | 阶码置全 0，尾数保持不动；尾数全 0→机器零，尾数不全 0→非规格化数 |

### 上溢/下溢判断的硬件逻辑
- **上溢判断**：规格化时若阶码为 11111110 且尾数还需右归 → 阶码 +1 后变全 1 → 触发上溢（如最大正数相加）。
- **下溢判断**：规格化时若阶码已为 00000001 且尾数还需左归 → 不继续左归，直接阶码置全 0、尾数不动 → 进入非规格化区间（如接近 0 的减法运算）。

## 备注
- **408 考点 — 五步流程顺序**：对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断（必须按此顺序，不可跳过或颠倒）
- **408 考点 — 对阶规则**：小阶向大阶看齐（而非大阶向小阶），这样可以更大概率直接得到规格化尾数
- **408 考点 — 舍入默认就近舍入**：零舍一入 + 100 看末位（类似十进制四舍五入 + 奇进偶不进）。2017 年 408 大题 43 题第 3 小问直接考察舍入规则
- **408 考点 — 浮点溢出不是尾数溢出**：浮点数的溢出通过阶码是否溢出判断（全 1 → 上溢，全 0 → 下溢），而非尾数溢出——尾数溢出可通过右归纠正
