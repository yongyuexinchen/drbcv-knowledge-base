# 存储芯片的输入输出信号

## 类型判定
判别型 — 回答"存储芯片对外暴露哪些信号引脚、哪些是输入哪些是输出、读写线怎么连、引脚数怎么算"，属于存储系统接口类概念。是 [[主存储器的基本组成]]（芯片内部结构）的外部接口视图，与 [[控制线]]（控制总线视角）互补。

## 类比 ★
**一句话比喻：** 存储芯片像一个带仓库的收发室——**地址信号**是"送货单"（告诉去哪个货架，输入），**数据信号**是"货物"（可进可出，双向），**片选**是"开门指令"（决定这个仓库今天开不开门，输入），**读写控制**是"收货/发货"按钮（输入）。外面的人（CPU）只通过这几个窗口和仓库打交道。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 地址信号（输入） | 送货单——只从外面递进来，指明货架号 |
| 数据信号（双向） | 货物——入库是输入，出库是输出 |
| 片选 CS（输入） | 开门指令——不开门，货架号再对也没用 |
| 读写控制 WE（输入） | 收货/发货开关——低电平=收货（写），高电平=发货（读） |
| 引脚数计算 | 收发室的窗口数=送货单窗口+货物窗口+开关窗口——每个窗口都要占一个位置 |

## 是什么
存储芯片对外暴露**金属引脚（pin）**，用于接收/发送信号。按方向分三类：

### 1. 输入信号（只进不出）
- **地址信号**：经地址总线从 CPU 送入，指明访问哪个存储单元。根数 = 存储字数（2^n 个单元 → n 根）。如 8K 芯片 → 13 根地址线
- **片选信号 CS/CE**：决定芯片是否工作。低电平有效（画横线）或高电平有效（不画），未选中则芯片不响应
- **读写控制信号**：决定读还是写。两种接法：
  - 两根分开：`WE`（写允许，低有效）+ `OE`（读允许/输出使能，低有效）
  - 一根合一：低电平=写，高电平=读（或题目指定）
- **（DRAM 还有）行选通 RAS / 列选通 CAS**：地址分两次送（行地址/列地址），见 [[地址线复用]]

### 2. 输出信号（只出不进）
- **数据信号（读方向）**：读操作时，选中单元的数据经数据线送出。但注意——数据引脚**双向共用**（同一组引脚，读时输出、写时输入），不是"输出专用"

### 3. 双向信号
- **数据信号**：同一组数据引脚，读=输出方向、写=输入方向。根数 = 存储字长（8 位字 → 8 根数据线）

## 输入-输出空间
- **输入**：地址（n 根）、片选 CS、读写控制（WE/OE 或合一）
- **输出**：读出的数据（经数据引脚）
- **双向**：数据引脚（读输出/写输入共用）
- **前置条件**：CS 有效 + 地址稳定（控制电路等地址稳定后才译码）+ 读写控制有效

## 正例（≥2 个）
1. **8K×8 芯片引脚数计算**：地址 13 根（8K=2^13）+ 数据 8 根 + 片选 1 根 + 读写 1 根（合一）= **23 根**。若读写分两根（WE+OE）= 24 根。这就是 408 常考的"芯片至少多少引脚"
2. **读操作流程**：CPU 送地址（输入）→ CS 有效（输入）→ 读控制有效 → 芯片把数据放到数据引脚（输出）→ CPU 取走。整个流程中数据引脚方向是"芯片→CPU"
3. **写操作流程**：CPU 送地址 + CS 有效 + 写控制有效 → CPU 把数据放到数据引脚（输入）→ 芯片写入。同一组数据引脚，方向反转
4. **DRAM 地址复用**：16K×1 芯片理论需 14 根地址线，但 DRAM 用 RAS/CAS 分两次送行/列地址（各 7 根）→ 引脚减半，代价是速度变慢

## 反例/边界（≥1 个）
1. **"数据引脚是输出引脚"不准确**：数据引脚**双向共用**——写时是输入、读时是输出。引脚数计算时只算一组数据引脚，不算两组
2. **"读写控制必须是两根线"是错的**：可以分开（WE+OE 各一根）也可以合一（一根线低写高读）。题目给几根就按几根算——引脚数答案因此不同（差 1 根）
3. **"CS 无效芯片就不耗电"不准确**：CS 无效只是不响应读写（输出高阻），芯片本身仍在供电。片选解决的是"数据总线冲突"，不是"省电"
4. **片选/地址/数据不是全部信号**：还有电源线 VCC/GND（一般不计入"信号引脚"计算）、部分芯片有时钟/使能等——题目说的"引脚数"通常指信号引脚

## 详细解释
### 引脚数计算总公式
```
信号引脚数 = 地址线根数 + 数据线根数 + 片选线(通常1) + 读写控制线(1或2)
地址线根数 = log2(存储字数)     # 8K → 13
数据线根数 = 存储字长          # 8位 → 8
```
> 注意：DRAM 因地址复用，地址引脚减半（RAS/CAS 分时送），计算时按实际引脚数而非逻辑地址位数。

### 三种信号的分工
| 信号 | 方向 | 内容 | 根数决定因素 |
|------|------|------|-------------|
| 地址 | 输入 | 哪个存储单元 | 存储字数（log2） |
| 数据 | 双向 | 存/取的数据 | 存储字长 |
| 片选 CS | 输入 | 哪片芯片工作 | 1 根 |
| 读写 WE/OE | 输入 | 读还是写 | 1 根或 2 根 |

### 与 CPU 连接时的统一视图
多片芯片扩展时：地址线低位并联（片内地址）、数据线按位/按组分配、片选由高位地址译码产生——见 [[选线与片选信号]]。每片芯片的引脚是"单元级"视图，扩展连接是"系统级"视图。
