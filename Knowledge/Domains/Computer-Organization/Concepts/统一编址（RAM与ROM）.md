# 统一编址（RAM与ROM）

## 类型判定
判别型 — 定义 RAM 和 ROM 共享同一个主存地址空间、由片选逻辑区分响应者的编址规则，并与"IO 统一编址"辨析——属于"编址规则"类概念。

## 类比 ★
**一句话比喻：** 主存像一个小区，两种楼混着排号——商品房（RAM）可进可出（能读能写），档案馆（ROM）只能进不能出（只能读）；门牌号连排编（1~1000 号商品房、1001~1100 号档案馆），快递员（CPU）报门牌号就去，**根本不关心那栋楼是什么性质**——只有门禁（片选）知道：刷卡判断你住哪栋，只开对应那栋的门。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| RAM 和 ROM 统一编址（共享地址空间） | 商品房（可进可出）和档案馆（只能读）在小区里门牌连排 |
| CPU 访问只凭地址，不区分器件类型 | 快递员只认门牌号，不关心那栋楼是什么性质 |
| 片选译码区分 RAM 区/ROM 区 | 门禁刷卡自动判断你住哪栋，只开那栋的门 |

## 是什么
**统一编址**指 RAM 和 ROM 在主存地址空间中**统一编号**，组成一个连续的地址空间，CPU 用同一套地址线和译码机制访问它们。典型布局：低地址段给 RAM（可读可写），高地址段给 ROM（只能读，写无效）——如 ROM 占 0~1023，RAM 从 1024 起。CPU 视角没有"RAM/ROM"之分，只有地址；区分由**片选逻辑**（高位地址译码）完成：地址落在 ROM 区就选通 ROM 芯片，落在 RAM 区就选通 RAM 芯片。**统一编址的最大价值**：上电时 RAM 是空的，CPU 从固定地址取第一条指令——该地址必须落在 ROM 区（存有自举程序 BIOS），开机流程才成立。

## 正例（≥2 个）
1. **BIOS 与内存条**：ROM（存自举装入程序）1KB 占地址 0~1023，RAM 从 1024 起。CPU 上电后从 ROM 的 0 地址取第一条指令——地址 500 是 RAM（可读写），地址 1000 是 ROM（只能读）。
2. **8086 的 1MB 空间**：低地址 `00000H~9FFFFH` 给 RAM，高地址 `F0000H~FFFFFH` 给 ROM（BIOS）。上电时 PC 被硬件置为 `FFFF0H`——恰好落在 ROM 区，开始执行自举程序。
3. **指令系统统一**：读 RAM 和读 ROM 都是同一条 LOAD 指令——CPU 不需要"读 RAM 指令"和"读 ROM 指令"两套，地址到了哪个区，片选自动让对应芯片响应。

## 反例/边界（≥1 个）
1. **"统一编址 = ROM 可以写"是错的**：统一编址只解决"地址怎么分"，不改变器件性质——访问 ROM 区的写操作**无效**（数据写不进去）。少数可写 ROM（EPROM/Flash）的写入需要专门流程（擦除再编程），普通访存指令干不了。
2. **"CPU 能区分 RAM 和 ROM"是错的**：CPU 只认地址，不知道也不关心器件类型——区分是片选译码电路的工作（门禁，不是快递员）。
3. **两个"统一编址"不是一回事**：主存内部 RAM/ROM 统一编址 vs **I/O 端口的统一编址**（存储器映射 I/O：I/O 端口占用主存地址空间，用访存指令访问设备）。同名不同物——IO 的统一编址还对应"独立编址"（专用 IN/OUT 指令），做题先看清是哪个。

## 详细解释
### 地址布局示意（统一编址的典型分配）
```
地址空间（连续）：
┌─────────────────────────────┐
│ RAM 区（可读可写）           │ ← 低地址段，运行时程序和数据
├─────────────────────────────┤
│ ROM 区（只读，写无效）        │ ← 高地址段，固件（BIOS 自举程序）
└─────────────────────────────┘
CPU 上电 → PC 指向固定地址（如 FFFF0H）→ 落在 ROM 区 → 执行自举程序
```

### 为什么必须统一编址
1. **指令系统简单**：一条访存指令通吃所有存储器件，不需要两套指令
2. **开机硬需求**：RAM 断电清空、上电为空，第一条指令只能来自 ROM 里的固件——硬件把开机地址固定映射到 ROM 区
3. **分工**：ROM 存"永不改的启动代码"（断电不丢），RAM 存"运行时的程序和数据"（快、可改写）

### 硬件实现：片选译码
- 高位地址线 → 译码器 → 片选信号 CS：选中 RAM 芯片组 **或** ROM 芯片
- 低位地址线 → 片内地址：在选中的芯片内定位具体单元
- 与「主存储器与CPU的连接」的字扩展/门禁比喻完全同构：RAM 和 ROM 就是两种"楼"，片选决定开哪栋的门

## 备注
- **408 考点 — 上电地址**：8086 上电 PC = FFFF0H，落在 ROM（BIOS）区——"为什么第一条指令从 ROM 取"答案：RAM 上电为空
- **408 考点 — ROM 区写无效**：统一编址 ≠ 可写；EPROM/Flash 的写需要擦除流程，不是普通访存
- **易混辨析**：主存内部 RAM/ROM 统一编址（本卡） vs I/O 端口统一编址（存储器映射 I/O）——后者配"独立编址"成对考
- **做题套路**：给 RAM/ROM 容量 → 划分地址范围（低 RAM 高 ROM）→ 判断某地址属于谁 → 算片选译码
