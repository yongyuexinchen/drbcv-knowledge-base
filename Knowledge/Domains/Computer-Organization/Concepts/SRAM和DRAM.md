# SRAM 和 DRAM

## 类型判定
对比型 — 回答"SRAM 和 DRAM 有什么区别、各自用在什么地方、为什么 DRAM 需要刷新"，属于存储芯片特性对比类概念。

## 类比 ★
**一句话比喻：** DRAM 像用漏水的桶装水（电容存电荷，2 毫秒就漏光了，得不停往里添水），SRAM 像用磁铁门闩锁门（双稳态触发器，只要不停电就永远保持状态，不用管它）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| DRAM 电容/破坏性读出 | 用粉笔在黑板上写字——读的时候粉笔灰飘走了，字没了，得重描一遍 |
| SRAM 双稳态触发器 | 用磁铁吸在冰箱上的便签——读一百遍都不会掉，不用重新贴 |
| DRAM 地址复用 | 同一扇门先刷卡进小区（行地址），再刷卡进单元（列地址），一张卡分两次刷 |

## 是什么
**DRAM**（Dynamic RAM，动态随机存储器）用电容存储信息，**SRAM**（Static RAM，静态随机存储器）用双稳态触发器（6 个 MOS 管）存储信息。两者的物理特性差异导致一系列性能和用途差异：DRAM 集成度高、成本低、速度慢、需刷新，用于主存；SRAM 集成度低、成本高、速度快、不需刷新，用于 Cache。

## 输入-输出空间
- **输入**：地址（DRAM 分两次送行列地址，SRAM 同时送）、读写控制信号
- **输出**：存储字的数据
- **前置条件**：DRAM 需在 2ms 内完成一次全部行的刷新；SRAM 不断电即可保持数据

## 正例（≥2 个）
1. **DRAM 破坏性读出**：电容存 1（有电荷）→ 读操作给 MOS 管加电导通 → 电容放电输出电荷 → 读完后电容变为 0，必须重写（给电容重新充电），因此 DRAM 读写周期 = 存取时间 + 恢复时间，周期可能是存取时间的 4 倍。
2. **SRAM 非破坏性读出**：触发器存 1（A 高 B 低）→ 读操作给字线加电 → BLX 线输出低电平 → 触发器状态不变，读出数据后无需重写，读写更快。

## 反例/边界（≥1 个）
1. **"易失性=破坏性读出"是混淆**：DRAM 和 SRAM 都是易失性（断电数据丢失），但只有 DRAM 是破坏性读出（读操作破坏数据需重写），SRAM 是**非破坏性读出**。
2. **DRAM 已过时**：现代主存用的是 SDRAM（同步 DRAM），如 DDR3/DDR4/DDR5，但基本原理仍基于 DRAM 的电容存储。做题时"DRAM"泛指这类电容型存储器。
3. **DRAM 地址线数≠地址位数**：因地址复用技术，DRAM 的地址引脚数=地址位数÷2，先送行地址再送列地址。计算引脚数目时要用减半后的值。

## 详细解释

**对比总表：**

| 特性 | SRAM | DRAM |
|------|------|------|
| 存储元件 | 双稳态触发器（6 MOS 管） | 栅极电容（1 MOS 管+1 电容） |
| 破坏性读出 | 否 | 是（读后需重写） |
| 速度 | 快 | 慢 |
| 集成度 | 低（元件多体积大） | 高（元件少体积小） |
| 成本 | 高 | 低 |
| 功耗 | 高 | 低 |
| 刷新 | 不需要 | 需要（2ms 内刷新全部行） |
| 行列地址 | 同时送 | 分两次送（地址线复用，减半） |
| 用途 | Cache | 主存 |

**DRAM 刷新三种方式：**
1. **分散刷新**：每次读写后刷新一行 → 存取周期翻倍（等于读写 0.5μs+刷新 0.5μs=1μs），2ms 内刷新 2000 次远超 128 行需求。
2. **集中刷新**：前 3872 个周期正常读写，最后 128 个周期集中刷新全部行 → 有"死时间"（CPU 无法访存）。
3. **异步刷新**：2ms 内均匀分布 128 次刷新，每 15.6μs 刷新一行 → 死时间分散，可安排在 CPU 译码等不需要访存的阶段。

刷新由存储器独立完成，不需要 CPU 介入。刷新周期默认 2ms。

## 备注
- 破坏性读出→读写周期>存取时间（T≥4r 常见）；非破坏性读出→读写周期≈存取时间
- DRAM 引脚数: 地址线按复用后算（地址位数/2），408 常考
- 刷新的单位是"行"（一整行存储单元同时刷新），不是单个存储元
- 口诀「S 快 D 慢，S 贵 D 贱，S 不用刷 D 要刷」——S 是 SRAM/Cache，D 是 DRAM/主存
