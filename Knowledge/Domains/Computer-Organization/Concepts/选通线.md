# 选通线

## 类型判定
判别型 — 定义译码器的输出线（一根管一个单元/一行/一列），对比一维与矩阵两种布局的选通线数量，讲清 DRAM 内部"选通线正交数据线"的十字交叉结构——属于"存储芯片内部结构"类概念。

## 类比 ★
**一句话比喻：** 选通线是仓库货架的"指示灯线路"——一维布局每个柜格独占一根灯线（1M 格 = 1M 根线，做不下）；矩阵布局改成电影院座位：1024 根"排灯线"横着 + 1024 根"座灯线"竖着，报"12 排 7 座"点亮两根线的**交叉点**——2048 根线搞定 100 万个座位。而数据线是交叉点的传送带：选通线管"开门"，数据线管"运货"，两者正交。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 选通线（译码器输出，一根管一个单元） | 每个柜格的指示灯线——亮哪格取哪格 |
| 行选通线 × 列选通线正交（矩阵布局） | 城市道路网格——横路×纵路，路口就是目标 |
| 数据线与选通线正交（读出电荷） | 路口放行后，传送带把货送出——选通管"开门"，数据线管"运货" |

## 是什么
**选通线**是地址译码器的**输出线**：CPU 送来的 n 位地址经译码器翻译后，**只有一根**选通线被拉高（选中），对应单元被激活（MOS 管导通）才能读写。它与地址线的关系：**地址线是输入编码（n 根，外部引脚），选通线是译码输出（数量取决于布局，芯片内部）**。数量规律：
- **一维布局**：每单元独占一根 → 选通线 = 单元数 = **2ⁿ**（20 位 → 1M 根，做不出来）
- **矩阵布局**：行/列共享 → 行线 + 列线 = **2×2^(n/2)**（20 位 → 1K + 1K = 2K 根，可行）

DRAM 内部是**十字交叉**结构：行选通线（横向）× 列选通线（纵向）正交，交叉点 = 一个存储单元（MOS 管 + 电容）；**数据线（位线）与选通线正交**——选通线决定"哪个单元开门"，数据线负责"电荷流出/流入"。

## 正例（≥2 个）
1. **8 位地址的选通线数量（40 号课原例）**：一维布局译码器需 2⁸ = 256 根选通线；改矩阵（4 位行 + 4 位列）→ 行译码器 16 根 + 列译码器 16 根 = **32 根**——电路简单了一个数量级。
2. **1M×1 DRAM 的十字交叉**：20 位地址拆成 10+10 → 1024 根行选通线 × 1024 根列选通线，交叉点 = 2²⁰ = 1M 个存储单元。选"行 5、列 3"→ 行线 5 拉高（整行 MOS 管开）+ 列线 3 拉高（该列选中）→ 交叉点那个单元的电容电荷经**位线（数据线）**流出。
3. **读单元完整流程**：行选通线拉高 → 一整行存储元导通 → 列选通线拉高 → 交叉点单元选中 → 电荷经正交的数据线流到读出放大器 → 存入 MDR——选通线"选点"，数据线"运数"，各司其职。

## 反例/边界（≥1 个）
1. **选通线 ≠ 地址线**：地址线是外部引脚（输入编码，n 根，20 位就是 20 根）；选通线是内部译码输出（一根管一个单元/行/列，数量 = 2ⁿ 或 2×2^(n/2)）——隔着译码器，数量差几个数量级。
2. **选通线 ≠ 数据线**：DRAM 里选通线（行/列）和数据线（位线）**正交**——选通线管"选哪个单元"，数据线管"电荷往哪流"。别把"选哪格"和"运什么"当成一根线。
3. **"矩阵布局每单元还是独占一根线"是错的**：矩阵的精髓是**共享**——一根行选通线管一整行（1024 个单元共用），一根列选通线管一整列；单元 = 行线∩列线的交叉点，不用独占。
4. **"选通线数 = 单元数"只对一维成立**：一维独占（2ⁿ）、矩阵共享（2×2^(n/2)）——数量公式随布局变。

## 详细解释
### 译码器：输入编码 → 输出选通
```
n 根地址线（输入，外部）        译码器         选通线（输出，内部）
─── 000...00 ────────────→ ┌──────┐ ──→ 第 0 根拉高（选单元 0）
─── 000...01 ────────────→ │ 译码器 │ ──→ 第 1 根拉高（选单元 1）
─── ...                  ──→ │      │ ──→ ...
─── 111...11 ────────────→ └──────┘ ──→ 第 2ⁿ-1 根拉高（选单元 2ⁿ-1）
   输入少（位数）              翻译            输出多（单元数）
```

### 一维 vs 矩阵（选通线数量）
| 布局 | 选通线数 | 20 位地址时 | 本质 |
|------|---------|-----------|------|
| 一维 | 2ⁿ（独占） | 1M 根（做不下） | 每单元一根线 |
| 矩阵 | 2×2^(n/2)（共享） | 1K+1K = 2K 根（可行） | 行线+列线，交叉定位 |

### DRAM 十字交叉结构（俯视图）
```
          列选通线0  列选通线1  ...  列选通线1023（纵向）
行选通线0 ──[●]──────[●]───────────[●]
行选通线1 ──[●]──────[●]───────────[●]
  ...        │         │             │
行选通线1023─[●]──────[●]───────────[●]
             每个 [●] = 存储单元（MOS管+电容）
             位线（数据线）沿列方向走，与行选通线正交
             行线亮 + 列线亮 → 交叉点单元导通 → 电荷经位线流出
```

### 为什么矩阵能省线（共享 vs 独占）
- 一维：1M 单元，每个单元要一根独立的激活线 → 1M 根
- 矩阵：1M 单元排成 1024×1024，**一排共用一根行线、一列共用一根列线** → 2048 根
- 用"两根线的交叉点"代替"每单元一根线"——这就是矩阵布局的全部秘密

## 备注
- **408 考点 — 数量公式**：一维选通线 = 2ⁿ；矩阵选通线 = 2×2^(n/2)——算"译码器输出线"用这个
- **408 考点 — 三线区分**：地址线（外部输入编码）/ 选通线（内部译码输出）/ 数据线（正交传数据）——概念题最爱混
