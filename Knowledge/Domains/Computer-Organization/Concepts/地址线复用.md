# 地址线复用

## 类型判定
判别型 — 定义 DRAM 芯片把行/列地址分两次送、使地址引脚减半的技术，解释其物理动机（二维排列减少选通线）并与 SRAM 对比——属于"存储芯片设计"类概念。

## 类比 ★
**一句话比喻：** 像电影院报座位号——一个窗口报不完"第 12 排 7 座"这种长号码，就分两拍报：先报"第 12 排"（行地址，一整排灯亮起），再报"7 座"（列地址，和排号交叉唯一锁定一个座位）。窗口（引脚）少了一半，但座位还是那个座位——寻址范围一点没缩水。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 行地址（先送，选中一整行） | 先报"第几排"——一排座椅同时亮灯 |
| 列地址（后送，选中一列） | 再报"第几座"——与排号交叉，唯一确定一个座位 |
| 地址线复用（引脚减半） | 长座位号分两拍报——报号窗口少一半，但目标不变 |

## 是什么
**地址线复用**是 DRAM 芯片为减少地址引脚采用的技术：把 N 位地址拆成**行地址**和**列地址**两半，**分两次**经同一批 N/2 根地址线送入芯片（第一次送行地址到行地址缓冲器，第二次送列地址到列地址缓冲器），再交给行/列译码器。效果：地址引脚从 N 根减到 **N/2 根**。它建立在**二维排列**之上：存储单元排成矩阵，行译码器选中一整行、列译码器选中一列，行和列都选通才定位到唯一单元——这让每个译码器的选通线从 2^N 根降到 2^(N/2) 根（电路可实现的根本原因）。SRAM 容量小、地址短，**同时**送行列地址，不复用。

## 正例（≥2 个）
1. **20 位地址的 DRAM**：不复用需 20 根地址线；复用后 **10 根**——第一拍送 10 位行地址，第二拍送 10 位列地址，寻址范围仍是 2^20 = 1M 单元，一个不少。
2. **选通线对比（40 号课原例）**：8 位地址一维排列 → 译码器需 2^8 = 256 根选通线；改二维（4 位行 + 4 位列）→ 每个译码器只需 16 根，共 32 根——电路简单了一个数量级。
3. **引脚计算题**：1M×1 DRAM 芯片，1M = 2^20 → 地址引脚 **10 根**（复用）+ 数据引脚 1 根 + RAS/CAS/片选/读写等控制引脚。同容量的 SRAM 地址引脚则是 20 根（不复用）——这就是"DRAM 引脚比 SRAM 少"的考点来源。

## 反例/边界（≥1 个）
1. **"复用 = 寻址范围减半"是错的**：复用只是**分时**送地址，N 位地址还是 N 位，寻址范围 2^N 不变——减的是引脚数量，不是地址位数。
2. **"SRAM 也复用"是错的**：SRAM 集成度低、容量小、地址位数少，**同时**送行列地址；只有容量大的 DRAM 才需要复用。
3. **"引脚总数减半"不准确**：减的是**地址引脚**（N → N/2），同时还要**新增** RAS（行选通）、CAS（列选通）两根控制线；数据线、片选、读写线不变。
4. **代价是时间**：分两次送地址多花一个节拍（先送行、再送列），访问稍慢——这是用时间（多一拍）换空间（引脚省一半）。

## 详细解释
### 为什么需要二维排列（减少选通线）
```
一维排列：    2^N 个单元排成一排 → 译码器要 2^N 根选通线
              （20 位地址 → 1M 根线，工程上不可能）

二维矩阵：    排成 2^(N/2) 行 × 2^(N/2) 列
              行译码器 2^(N/2) 根线 + 列译码器 2^(N/2) 根线
              （20 位地址 → 1K + 1K = 2K 根线，轻松实现）
              行选通 + 列选通 = 唯一单元
```

### 地址线复用时序（两次送）
```
第 1 拍：RAS 有效 → 地址线上送 行地址 → 行地址缓冲器 → 行译码器选一整行
第 2 拍：CAS 有效 → 地址线上送 列地址 → 列地址缓冲器 → 列译码器选一列
之后：    行×列交叉点 = 目标存储单元 → 读写
```
同一批 N/2 根线，两个节拍各送一半——引脚减半，RAS/CAS 告诉芯片"现在送的是哪一半"。

### SRAM vs DRAM 送地址方式
| 特性 | SRAM | DRAM |
|------|------|------|
| 容量 | 小（Cache 用） | 大（主存用） |
| 地址位数 | 少 | 多（可达 32 位） |
| 行列地址 | **同时送** | **分两次送（复用）** |
| 地址引脚 | N 根 | N/2 根 |

### 附带：刷新按行进行
DRAM 刷新每次刷**一整行**（读出一行重写），耗时 ≈ 一个读写周期——二维排列让"按行刷新"成为可能（同行考点，40 号课同一节）。

## 备注
- **408 考点 — 引脚计算**：DRAM 芯片地址引脚 = 地址位数 ÷ 2（复用）；SRAM 不除——题目算引脚必考
- **408 考点 — 控制信号**：RAS 选通行地址、CAS 选通列地址；看到这两个英文要反应出行列复用
- **选通线公式**：一维 2^N → 二维 2×2^(N/2)；这是"为什么要改二维"的答案
- **记忆口诀**：先报排、再报座——"排（行）亮一排，座（列）定一点，窗口省一半"
