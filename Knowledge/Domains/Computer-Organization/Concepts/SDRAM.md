# SDRAM

## 类型判定
判别型 — 定义同步动态随机存取存储器（SDRAM）及其 DDR 形态，与 SRAM、异步 DRAM 辨析——属于"存储器件"类概念。

## 类比 ★
**一句话比喻：** SDRAM 像有统一铃声的流水线工厂——所有工位按同一个节拍（系统时钟）干活，节奏整齐还能流水线作业（突发传输）；异步 DRAM 像没铃声的作坊——工头（CPU 控制信号）喊一声动一下，节奏乱；DDR 更狠——钟摆每荡一下搬两趟货（上升沿一趟、下降沿一趟），效率翻倍。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| SDRAM（同步：所有操作跟时钟节拍走） | 流水线工厂统一铃声上下工——按同一节拍干活，还能连续出活（突发） |
| 异步 DRAM（由 CPU 控制信号触发） | 没铃声的作坊——工头喊一声动一下，节奏乱、慢 |
| DDR SDRAM（上升沿+下降沿都传数据） | 钟摆每荡一次搬两趟货——左荡一趟右荡一趟，吞吐翻倍 |

## 是什么
**SDRAM（Synchronous DRAM，同步动态随机存取存储器）**是现代主存的主流实现（内存条就是 SDRAM）。它属于 **DRAM 家族**：用电容存电荷 → 需要定期刷新、读出是破坏性的、地址线复用（行/列分时送）。与普通（异步）DRAM 的区别在"**同步**"：所有读写操作与**系统时钟**同步，按时钟节拍流水工作，支持**突发传输**（burst——给一个起始地址，连续输出一串数据，不用每字重发地址）。**DDR SDRAM（Double Data Rate）**在时钟**上升沿和下降沿都传输数据**，带宽翻倍——DDR3、DDR4 都是 SDRAM 的演进型号。**注意**：S 是 Synchronous（同步），不是 Static——SDRAM 是动态的，需要刷新！

## 正例（≥2 个）
1. **内存条 = SDRAM**：40 号课原话——"DRAM 芯片现在其实已经过时了，目前的主存通常是采用 SDRAM"，你买的 DDR4 内存条就是 SDRAM。
2. **DDR 双沿传输**：DDR 内存时钟 800MHz 时，每个时钟周期传 2 次数据 → 等效 1600MT/s（每秒 16 亿次传输）。同样频率下带宽是普通 SDRAM 的两倍。
3. **突发传输**：CPU 连续读一个块（如 4 个字），SDRAM 在突发模式下给 1 个起始地址就连续输出 4 个字——省掉重复送地址的时间，这是它配合 Cache 块读取的关键。

## 反例/边界（≥1 个）
1. **"SDRAM 是 SRAM 的一种"是错的**：S 是 **Synchronous** 不是 **Static**！SDRAM 是动态存储器（电容+刷新+破坏性读出），SRAM 是静态触发器（不需刷新）——Cache 用 SRAM，主存用 SDRAM，两者完全不是一回事。
2. **"DDR = 时钟频率翻倍"不准确**：DDR 翻的是**数据速率**（每个时钟沿都传数据），不是时钟频率本身。DDR4-3200 的"3200"单位是 MT/s（每秒百万次传输），不是 Hz。
3. **"同步一定比异步快"不严谨**：同步化的价值是**时序可控**——所有操作按节拍走，可以流水线化、突发传输，从而整体吞吐高；单次访问未必碾压异步，但连续访问优势巨大。

## 详细解释
### SRAM vs DRAM vs SDRAM 对比
| 特性 | SRAM | DRAM（异步） | SDRAM |
|------|------|-------------|-------|
| 存储元件 | 触发器（6 管） | 电容（1 管+1 电容） | 电容（同 DRAM） |
| 需要刷新 | 否 | 是（2ms 内） | 是 |
| 读出方式 | 非破坏性 | 破坏性（需恢复） | 破坏性 |
| 工作节拍 | 快 | 由控制信号触发 | **与时钟同步** |
| 突发传输 | 支持 | 不支持 | **支持** |
| 用途 | Cache | 过时的主存 | **现代主存（DDR3/4）** |
| 价格 | 最贵 | 便宜 | 便宜（同 DRAM 量级） |

### DDR 双沿原理
```
普通 SDRAM：  ┌───┐   ┌───┐   ┌───┐     每个时钟周期传 1 次数据
时钟 ────────┘   └───┘   └───┘   └──
              ↑上升沿传数据

DDR SDRAM：   ┌───┐   ┌───┐   ┌───┐     每个时钟周期传 2 次数据
时钟 ────────┘   └───┘   └───┘   └──
              ↑   ↑   ↑   ↑
             上升沿+下降沿都传数据（带宽翻倍）
```

### 演进简表（都是 SDRAM）
| 型号 | 电压 | 数据速率示例 |
|------|------|-------------|
| DDR | 2.5V | 200~400 MT/s |
| DDR2 | 1.8V | 400~800 MT/s |
| DDR3 | 1.5V（后期 1.35V） | 800~2133 MT/s |
| DDR4 | 1.2V | 1600~3200 MT/s |

电压一路降、速率一路涨——DDR4 比 DDR 省电得多、快得多。

- **408 考点 — S 的含义**：SDRAM 的 S = Synchronous（同步），不是 Static——它是动态存储器，要刷新
