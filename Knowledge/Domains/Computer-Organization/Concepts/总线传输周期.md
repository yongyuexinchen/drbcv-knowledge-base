# 总线传输周期

## 类型判定
混合型 — 定义一次总线传输的完整时间（总线周期）及其四阶段，讲清它与总线时钟周期的"魔幻"对应关系，并给出带宽计算公式——兼有定义和计算。

## 类比 ★
**一句话比喻：** 总线周期 = 一次货运发车——排队进站（申请/仲裁）→ 报目的地（寻址）→ 装货发车（传输）→ 离站让路（结束）；总线时钟周期 = 铁路信号灯的节拍。两者的对应关系**不固定**：一趟列车可能跨好几个信号周期（一对多，常见），也可能一个信号周期里发两趟车（双沿，多对一）。货运能力 = 每趟载货量 × 发车频率。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 总线周期（申请→寻址→传输→结束） | 一次货运发车——排队进站→报目的地→装货发车→离站让路 |
| 总线周期与时钟周期的对应关系 | 发车趟数与信号灯节拍的关系——一趟跨几拍（1:多）或一拍发两趟（多:1） |
| 总线带宽 = 总线宽度 × 工作频率 | 货运能力 = 每趟载货量 × 发车频率 |

## 是什么
**总线传输周期（总线周期）** = 利用总线传输**一组数据**所需的时间，分为四阶段：**申请**（总线仲裁，决定把总线分给谁）→ **寻址**（主设备经地址总线指明目标单元）→ **传输**（经数据总线读写数据）→ **结束**（释放总线）。一个总线周期完成一组数据的传送（如 32 位）。

**总线时钟周期** = 定时节拍（早期 = 机器时钟周期 = 1/主频；现代可能由桥接器提供，与 CPU 时钟不同频）。总线周期与时钟周期的对应关系**不固定**：一对多（常见）/ 一对一 / 多对一（DDR 双沿：上升沿+下降沿各传一次 = 一个时钟周期含两个总线周期）——**做题必须先审清对应关系**。

衍生指标：**总线工作频率** = 1/总线周期；**总线时钟频率** = 1/时钟周期；**总线宽度（位宽）** = 数据总线并行位数；**总线带宽** = 总线宽度 × 工作频率 = 总线宽度 ÷ 总线周期。

## 输入-输出空间
- **输入**：总线宽度（位）、总线周期或工作频率、时钟频率、对应关系（每时钟周期传几次）
- **输出**：总线带宽（bit/s，÷8 得 B/s）
- **前置条件**：分清"总线周期 vs 时钟周期"的对应关系；区分带宽 vs 有效数据传输率

## 正例（≥2 个）
1. **同步定时读 = 一对多**：T1 送地址 → T2 发读命令 → T3 数据上总线 → T4 撤销释放——一个总线周期 = 4 个时钟周期（衔接[[总线操作和定时]]）。
2. **DDR 双沿 = 多对一（80 号课例题）**：总线 32 根信息线（地址/数据复用），时钟 66MHz，每时钟周期上升沿+下降沿各传一次 → 一个时钟周期 = **2 个总线周期** → 总线工作频率 = 66×2 = 132MHz → 带宽 = 132M × 32bit = 4224Mbit/s = **528MB/s**。
3. **机器时钟周期**：CPU 主频 3.0GHz → 时钟周期 = 1/3.0G ≈ 0.33ns——早期总线时钟周期就是它（一对一的特例）。

## 反例/边界（≥1 个）
1. **"一个总线周期 = 一个时钟周期"是错的**：对应关系"魔幻"——一对多（常见）、一对一、多对一（双沿）都可能。80 号课原话："有可能是1对多，有可能是1对1，也有可能是多对1，并不固定"——**审题第一**。
2. **"带宽 = 时钟频率 × 宽度"是错的**：用**总线工作频率**（1/总线周期），不是时钟频率——DDR 双沿时工作频率 = 2×时钟频率，用错直接差一倍。
3. **"总线宽度 = 所有信息线数"是错的**：通常指**数据总线**宽度（32 根信息线若含地址/数据复用，传输数据时只算数据宽度）。
4. **带宽 ≠ 有效数据传输率**：带宽是最高速率（含校验位/标志位）；有效数据传输率要刨除冗余位——题目问"有效"时别直接用带宽。

## 详细解释
### 总线周期四阶段
| 阶段 | 干什么 | 类比 |
|------|--------|------|
| 申请 | 总线仲裁（谁用总线） | 排队进站 |
| 寻址 | 主设备指明目标地址 | 报目的地 |
| 传输 | 数据总线读写数据 | 装货发车 |
| 结束 | 释放总线使用权 | 离站让路 |

### 周期关系与带宽公式
```
时钟周期（节拍）→ 总线周期（一次传输）→ 完成一组数据
对应关系：1 周期 ↔ N 总线周期（N 可 >1、=1、<1）

总线工作频率 = 1 / 总线周期        （一秒传几次）
总线时钟频率 = 1 / 总线时钟周期     （一秒几个节拍）
总线带宽 = 总线宽度 × 总线工作频率  （= 宽度 ÷ 周期）
         = 并行位数 × 每秒传输次数
```

### 例题演算（80 号课）
```
32 根信息线（地址/数据复用）、时钟 66MHz、每周期双沿各传一次
→ 一个时钟周期 = 2 个总线周期
→ 总线工作频率 = 132MHz
→ 带宽 = 132M × 32bit = 4224Mbit/s ÷ 8 = 528MB/s
```

## 备注
- **408 考点 — 对应关系审题**：总线周期 vs 时钟周期 1对多/1对1/多对1——决定计算用哪个频率
- **408 考点 — 带宽公式**：带宽 = 宽度 × 工作频率 = 宽度 ÷ 周期；双沿时工作频率 = 2×时钟频率
- **易混三件套**：工作频率（1/周期）≠ 时钟频率（1/时钟周期）；带宽 ≠ 有效传输率；宽度 ≠ 总线根数
- **记忆口诀**：发车四步（申寻传结）、节拍不定（对应魔幻）、载货×频率（带宽）
