# 字扩展（增加存储字数）

## 类型判定
判别型 — 回答"怎么用多片同规格芯片增加主存字数、片选信号怎么产生（线选/译码）、地址空间怎么划分"，属于存储扩展类概念。是 [[主存储器与CPU的连接]] 的三种扩展方式之一（位扩展扩展字长、字扩展扩展字数）。

## 类比 ★
**一句话比喻：** 一栋楼房间不够用了，在旁边**再盖几栋一样的楼**（同规格芯片）——每栋楼房间布局相同（片内地址并联），靠"门禁系统"（高位地址+译码器）决定开哪栋楼的门（片选）。楼层号（低位地址）大家都一样，楼号（高位地址）决定去哪栋。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 多片同规格芯片 | 多栋同户型楼——每栋楼房间数相同 |
| 片内地址线并联 | 每栋楼的楼层号规则相同（1楼、2楼……） |
| 高位地址→片选 | 楼号决定进哪栋楼（门禁刷卡） |
| 线选法 | 楼号直接写在大门上——几栋楼几块门牌，楼多了门牌不够用，且门牌号不连续 |
| 译码片选法 | 一个门禁控制器——两位密码管四栋楼，楼号连续 |
| 数据线共享 | 所有楼共用一个货运通道，但只有开门的楼才放货出来（避免撞车） |

## 是什么
**字扩展**：当单块芯片的字长（数据宽度）与 CPU 匹配、但**字数不够**时，用多片**同规格芯片**拼出更大的地址空间。核心思想：

1. **片内地址并联**：所有芯片的地址线（低位）并联，同一时刻收到相同的片内地址
2. **片选择一**：由高位地址产生片选信号，**同一时刻只选一片**——否则多片同时响应会把数据同时放到数据总线上（冲突）
3. **片选信号两种产生方式**：
   - **线选法**：高位地址线直接接各芯片 CS。N 根线管 N 片。**地址不连续、有空洞**
   - **译码片选法**：高位地址送译码器（2-4 / 3-8），N 位输入→2^N 个片选输出。**地址连续**

> 图例：![字扩展连接图](Assets/字扩展连接图.png) —— CPU 的 A0~A12 并联给各片（片内地址），高位地址经 2-4 译码器产生 4 个 CS，每片 8K 拼成 32K 连续空间。

## 输入-输出空间
- **输入**：CPU 低位地址（片内，并联所有片）、高位地址（送译码器/直接接 CS）、读写控制信号
- **输出**：片选信号（译码器输出，选中一片）；被选中片的读出数据
- **前置条件**：数据线按位/按组正确分配（字扩展中每片数据线独立接数据总线不同位——注意与位扩展区分）

## 正例（≥2 个）
1. **字扩展 8K×8 → 32K×8（译码片选法，即用户图）**：4 片 8K×8。A0~A12 并联作片内地址（13 根）；A13、A14 送 2-4 译码器，4 个输出接 4 片 CS。地址划分：
   - Y0（A14A13=00）→ 第 1 片：0000H~1FFFH
   - Y1（A14A13=01）→ 第 2 片：2000H~3FFFH
   - Y2（A14A13=10）→ 第 3 片：4000H~5FFFH
   - Y3（A14A13=11）→ 第 4 片：6000H~7FFFH
   - **连续无空洞**，总容量 32K×8
2. **字扩展 8K×8 → 16K×8（线选法）**：A13 接左片 CS、A14 接右片 CS（高有效）。A13A14=10→左片工作（0000H~1FFFH），=01→右片（2000H~3FFFH）。**但 A13A14=00/11 是非法地址（无芯片响应）→ 地址空间不连续**
3. **字扩展 16K×8 → 64K×8（译码片选法）**：4 片 16K×8。A0~A13 作片内地址（14 根）；A14、A15 送 2-4 译码器。Y0~Y3 各管 16K：0000H~3FFFH、4000H~7FFFH、8000H~BFFFH、C000H~FFFFH——覆盖 64K 全部空间

## 反例/边界（≥1 个）
1. **"字扩展和位扩展是同一回事"是错的**：位扩展=每片字长不足（8K×1 拼 8 片→8K×8），所有片**同时工作**、各贡献 1 位；字扩展=每片字长够但字数不足（8K×8 拼 4 片→32K×8），**片选择一**、每次只一片工作。位扩展 CS 全部接有效电平，字扩展 CS 必须分开控制
2. **"线选法地址连续"是错的**：线选法用地址线直接当 CS，两片芯片之间必然有空洞（A13A14=00/11 无人响应）——这是它被译码法取代的根本原因
3. **译码器输入跳位 → 地址重复（408 高频陷阱）**：若把 A13 和 A15 送译码器、A14 不参与片选，则每片 8K 却有 16K 个地址映射（A14 取 0/1 都选中同一片）→ 实际一半地址重复，可用空间减半
4. **片选信号有效电平不匹配**：高电平有效的芯片接"输出高电平有效"的译码器（Y 输出 1），低电平有效的芯片接"输出带小圆"的译码器（输出 0）——接反则芯片永远不工作或永远工作

## 详细解释
### 字扩展 vs 位扩展（关键区分）
| 维度 | 位扩展 | 字扩展 |
|------|--------|--------|
| 解决 | 字长不足（宽度） | 字数不足（容量） |
| 芯片 | 8K×1 ×8 片 | 8K×8 ×4 片 |
| 片选 | 全部接有效电平（同时工作） | 译码择一（分时工作） |
| 地址线 | 全部并联（同地址） | 低位并联 + 高位片选 |
| 数据线 | 各片 1 位拼成 8 位 | 每片独立 8 位接总线 |

### 译码器怎么选型号
- 需要管 2^n 片芯片 → 用 n-2^n 译码器（2-4 译码器管 4 片、3-8 管 8 片）
- 高位地址位数 = 需要的片选数对应的译码器输入位数

### 74LS138（3-8 译码器）考点
- 3 个输入端（A/B/C）+ 8 个输出端（Y0~Y7）+ 多个使能端
- 使能端（EN）：高有效/低有效组合，全部满足才工作——可接 CPU 访存请求信号（无请求→译码器不工作→无片选→无芯片被选通）
- 输出有效电平分两种画法：无小圆=输出高有效，有小圆=输出低有效——**要和芯片 CS 的有效电平匹配**

### 访存时序（为什么要有使能端）
CPU 送地址（电信号可能不稳定）→ 等稳定 → 发访存请求（使能端激活）→ 译码器选通某片 → 数据传出 → 撤销请求（片选失效）。使能端接请求信号 = 给片选加"总开关"，防止地址不稳定时误选片。
