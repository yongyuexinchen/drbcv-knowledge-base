# 算数逻辑单元ALU

## 类型判定
判别型 — 回答"ALU是什么、在CPU中处于什么地位、支持哪些功能、控制信号位数怎么算、图示怎么读、标志位输出到哪"，是运算器的核心概念。

## 类比 ★
**一句话比喻：** ALU像瑞士军刀——一把刀上集成了切、削、锯、开瓶器等多种功能，你用哪把功能取决于你按哪个按钮（控制信号）；而加法器只是其中最常用的一把主刀。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| ALU（算术+逻辑+其他功能） | 瑞士军刀：小刀（加法）、剪刀（与运算）、螺丝刀（移位）全在一把上 |
| 控制信号（M位，选择执行哪种运算） | 功能旋钮：拧到不同档位，军刀弹出不同工具 |
| M ≥ ⌈log₂K⌉（K种功能） | 有8种功能至少需要3个旋钮档位（2³=8） |
| PSW/FR（标志寄存器） | 手术后的体检报告单：记录了这次手术有没有异常（OF）、结果正负（SF）等 |

## 是什么
ALU（Arithmetic Logic Unit，算术逻辑单元）是运算器的核心部件，是一种组合逻辑电路。**功能**：算术运算（加/减/乘/除）、逻辑运算（与/或/非/异或/移位）、其他（求补码、直送）。**地位层级**：CPU = 控制器 + 运算器 → 运算器核心 = ALU → ALU核心 = 加法器。内部实现：K个功能电路各自运算 → 多路选择器根据M位控制信号选一路输出。机器字长 = ALU一次能处理的运算数位数。

## 输入-输出空间
- **输入**：A（N比特）、B（N比特）、M位控制信号（来自控制器）、C_in（进位输入）
- **输出**：F（N比特运算结果）、C_out（进位输出）、OF/SF/ZF/CF 四个标志位（送入 PSW/FR）
- **前置条件**：M ≥ ⌈log₂K⌉，其中K是ALU支持的功能总数

## 正例（≥2 个）
1. **ALU支持8种功能**：则控制信号至少需要 ⌈log₂8⌉ = 3 位（000~111 对应8种操作）
2. **ALU支持11种功能（算术4+逻辑5+其他2）**：控制信号至少 ⌈log₂11⌉ = 4 位
3. **ALU执行"直送"功能**：输入 0101，控制信号=直送对应的编码 → 输出仍为 0101（原封不动输出）
4. **ALU执行"求补码"功能**：输入B端为某数的源码，控制信号=求补码 → 输出端得到对应补码

## 反例/边界（≥1 个）
1. **控制信号位数不够**：ALU支持9种功能但只给3位控制信号（最多8种）→ 有一种功能永远无法被选中
2. **机器字长 ≠ ALU位数**：机器字长由ALU运算位数决定，而非反过来。若ALU是16位，则机器字长=16位
3. **标志位归谁管**：标志位是ALU运算后**自动输出**的，并送入PSW（程序状态字寄存器，又称FR标志寄存器），不是ALU自己"存储"标志位

## 详细解释
**ALU在CPU中的层级关系**：

```
CPU
├── 控制器（CU）：解析指令 → 发出控制信号给 ALU
└── 运算器
    ├── 通用寄存器（暂存数据）
    ├── ALU（核心）：执行各种运算
    │   └── 加法器（核心的核心）
    └── PSW/FR（存储标志位）
```

**ALU内部简化实现原理**：

| 步骤 | 描述 |
|------|------|
| ① | A和B两个运算数同时送入K个功能电路（加法电路、乘法电路、与电路、移位电路……） |
| ② | K个电路各自独立运算，产生K个结果 |
| ③ | K个结果全部接入多路选择器的输入端 |
| ④ | M位控制信号决定多路选择器选哪一路输出 |

**ALU图示解读要点**：

| 图示元素 | 含义 |
|---------|------|
| 左端 A[N-1:0]、B[N-1:0] | 两个N比特运算数输入 |
| 右端 F[N-1:0] | N比特运算结果输出 |
| 侧面虚线箭头 OP[M-1:0] | 控制信号（来自控制器），M ≥ ⌈log₂K⌉ |
| 绿色输出 OF/SF/ZF/CF | 标志位，送入 PSW/FR |
| C_in / C_out | 进位输入/进位输出 |

## 关系
### → 指向
- [[加法器]] (ALU的核心是加法器，所有运算最终通过加法器实现)
- [[多路选择器与三态门]] (ALU内部用多路选择器从K个功能电路中选一路输出)
- [[逻辑门电路]] (ALU内部所有功能电路均由门电路组合实现)
- [[定点数的加减运算]] (ALU的标志位在加减运算中用于溢出判断和结果特征标记)
### ← 被指向
- 无（ALU是顶层运算部件，被CPU系统架构引用）

## 备注
- **408必考**："CPU=控制器+运算器，运算器核心=ALU，ALU核心=加法器"——选择题三连
- **控制信号位数**：M ≥ ⌈log₂K⌉，其中K=功能总数（含算术+逻辑+求补码+直送等全部）
- **PSW = FR**：程序状态字寄存器 = 标志寄存器，同一个东西两种叫法，408真题交替出现
- **机器字长由ALU决定**：N位ALU → N位机器字长，反过来问"ALU位数由什么决定"没有意义
