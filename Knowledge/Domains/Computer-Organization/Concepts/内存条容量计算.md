# 内存条容量计算

## 类型判定
程序型 — 给出从地址线/数据线、芯片规格或内存条颗粒推算总容量的标准步骤与陷阱清单，属于"计算流程"类概念。

## 类比 ★
**一句话比喻：** 内存条容量 = 仓库能放多少个柜格 × 每个柜格能装多少螺丝——柜格数由门牌号位数（地址线）决定，每格容量由货架宽度（数据线）决定。货架宽 64 格、门牌 32 位 → 2³² 个柜格 × 64 颗螺丝/格。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 存储单元数（2^地址线） | 仓库柜格数——门牌号能编多少个号 |
| 存储字长（数据线根数） | 每个柜格能装多少颗螺丝 |
| 总容量 = 单元数 × 字长 | 仓库总容量 = 柜格数 × 每格容量 |

## 是什么
**内存条容量**指内存条（主存）能存储的二进制信息总量，由两个因子决定：**存储单元数**（由地址线/MAR 位数决定，2^n）和**存储字长**（由数据线/MDR 位数决定）。基本公式：**容量 = 存储单元数 × 存储字长**——所有计算题都是这个公式的变形：给定不同条件（线数/芯片规格/颗粒数）求容量，或给容量反推地址线。DRAM 特有的地址线复用和 bit/Byte 换算是两大陷阱。

## 输入-输出空间
- **输入**（三选一）：① 地址线根数 n + 数据线根数 m；② 芯片规格（如 8K×8 位）；③ 内存条颗粒数 + 单颗粒容量（如 8 颗 8Gbit）
- **输出**：总容量（bit → 可换算为 B/KB/MB/GB）
- **前置条件**：分清 bit/Byte；按字节编址还是按字编址

## 标准步骤
1. **确定存储单元数**：单元数 = 2^(地址线根数)，或直接从规格读（8K×8 的前一个数）
2. **确定存储字长**：字长 = 数据线根数 = MDR 位数，或从规格读（8K×8 的后一个数）
3. **套公式**：容量(bit) = 单元数 × 字长
4. **换算单位**：÷8 得字节；再 ÷2^10/2^20/2^30 得 KB/MB/GB
5. **反推（给容量求地址线）**：单元数 = 容量(bit) ÷ 字长 → 地址线 = log₂(单元数)
6. **内存条组合**：总容量 = 颗粒数 × 单颗粒容量（注意 Gbit→GB 的 ×8/÷8）

## 正例（≥2 个）
1. **由线数算容量**：地址线 32 根、数据线 64 根 → 2³² × 64 bit = 2³² × 8 B = **32GB**。
2. **由容量反推地址线**：8GB 内存条，按字节编址 → 8GB = 2³³ B → 需 **33 根**地址线；4GB = 2³² → 32 根。
3. **内存条颗粒组合**：8 颗 8Gbit 颗粒 → 8 × 8Gbit = 64Gbit = **8GB**（64÷8）。"16GB 2Rx8" = 双面 × 每面 8 颗，共 16 颗。

## 反例/边界（≥1 个）
1. **Gbit vs GB 差 8 倍**：8 颗 2Gbit 颗粒 = 16Gbit = **2GB** 不是 16GB——单位没换算直接算错。
2. **DRAM 地址线复用（引脚减半）**：DRAM 芯片行/列地址分时送，4G 单元需 32 位地址但芯片可能只有 16 根地址引脚。问"芯片引脚数"用复用后的数；问"地址线位数"用完整数。
3. **"字节"当"字"用**：题目给的容量若是字节数，按字节编址求地址线直接用 log₂(字节数)；若按字编址，先 ÷ 字长得到字数再求地址线——两种口径别混。
4. **读写控制线/片选影响引脚数**：算芯片引脚 = 地址线 + 数据线 + 片选(1) + 读写控制(1 或 2) + 电源地线——题目没说合用读写线就按 2 根算。

## 详细解释
### 公式全家桶
```
芯片级：   容量 = 单元数 × 字长           （8K×8 → 8KB）
线数级：   容量 = 2^地址线 × 数据线(bit)   （32 线 + 64 线 → 32GB）
内存条级： 容量 = 颗粒数 × 单颗粒容量      （8 × 8Gbit → 8GB）
反推：     地址线 = log₂(容量 ÷ 字长)      （8GB ÷ 1B → 33 根）
```

### 常见规格速查（按字节编址）
| 容量 | 二进制 | 地址线根数 |
|------|--------|-----------|
| 1GB | 2³⁰ B | 30 |
| 4GB | 2³² B | 32 |
| 8GB | 2³³ B | 33 |
| 16GB | 2³⁴ B | 34 |
| 32GB | 2³⁵ B | 35 |

### 为什么内存条是"拼"出来的
单颗 DRAM 芯片容量有限（如 1G×8），内存条用**位扩展**（多颗同地址、各贡献几位数据）和**字扩展**（片选区分，增加单元数）把多颗拼成想要的容量——这就是「主存储器与CPU的连接」卡的实战场景。
