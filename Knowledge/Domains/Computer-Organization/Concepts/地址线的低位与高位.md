# 地址线的低位与高位

## 类型判定
判别型 — 回答"CPU 的地址线为什么要分成低位和高位、分界线怎么定、各自干什么、划错了会怎样"，属于存储互连类概念。是 [[选线与片选信号]]（片选怎么产生）的"输入侧"视角，也是 [[字扩展（增加存储字数）]] 的地基——多片芯片连接时地址线必然要分工。

## 类比 ★
**一句话比喻：** 地址线低位 = "楼层号"，地址线高位 = "楼号"。一个完整地址 = "几号楼 + 几层"——CPU 说"3 号楼 12 层"，楼号（高位）决定开哪栋楼的门（片选），楼层号（低位）决定进哪个房间（片内单元）。分界线 = 每栋楼的层数（芯片容量）决定的。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 低位地址线（A0~An） | 楼层号——同一栋楼内找房间（片内地址，并联到所有芯片） |
| 高位地址线（A(n+1)~） | 楼号——决定进哪栋楼（片选译码） |
| 分界线 = log2(单芯片容量) | 每栋楼多少层——层数定了，楼层号需要几位就定了 |
| 低位并联所有芯片 | 每栋楼的楼层号规则相同（都有 12 层这个概念） |
| 高位送译码器 | 楼号送门禁系统，只有一栋楼开门 |
| 跳位接法（A13/A15 送译码器） | 楼号跳着编（没有 2 号楼，但有 1 号和 3 号）——地址空洞/重复 |

## 是什么
CPU 访问主存时，N 位地址线按**用途**分成两段：

- **低位地址线**：作为**片内地址**，并联接到所有存储芯片——指明"选中的芯片内部哪个存储单元"。位数 = log2(单芯片存储字数)。例：8K 芯片 → 13 根（A0~A12）
- **高位地址线**：作为**片选译码输入**，不直接进芯片——决定"哪一片芯片被选中"。位数 = 总地址位数 - 片内位数。例：CPU 16 根地址线，13 根片内 → 3 根高位（A13~A15）可管 2³=8 片

**核心原则**：低位=片内选择（容量内），高位=片间选择（扩展用）。分界线由**单芯片容量**决定。

## 输入-输出空间
- **输入**：CPU 发出的完整 N 位地址
- **输出**：
  - 低位 → 所有芯片的片内地址引脚（并联，各芯片同时收到相同低位）
  - 高位 → 译码器输入（产生片选）或直接接片选引脚（线选法）
- **前置条件**：低位位数 ≥ log2(单芯片字数)；高位位数 + 低位位数 = CPU 地址线总数

## 正例（≥2 个）
1. **8K×8 芯片，CPU 16 位地址（字扩展 32K×8，图例）**：8K = 2¹³ → A0~A12（13 根）作片内地址并联；A13、A14 送 2-4 译码器产生 4 个片选（管 4 片）；A15 暂不用。地址：0000H~1FFFH（片1）、2000H~3FFFH（片2）…… 每片 8K，4 片连续覆盖 32K
2. **16K×8 芯片，CPU 16 位地址（64K 满扩展）**：16K = 2¹⁴ → A0~A13（14 根）片内；A14、A15 送 2-4 译码器管 4 片。4 片覆盖 0000H~FFFFH 全部 64K——**正好用满，无剩余**
3. **线选法（2 片 8K×8）**：A0~A12 片内并联；A13 直接接左片 CS、A14 接右片 CS（高有效）。A13A14=10→左片、=01→右片，但 =00/=11 无人响应——**高位地址跳着用，地址有空洞**

## 反例/边界（≥1 个）
1. **"高位地址线也接进芯片"是错的**：高位**不进芯片**（否则每片都响应相同高位 → 冲突），它只参与片选产生。进芯片的只有低位（片内地址）
2. **分界线不是固定的**：分界 = log2(单芯片容量)。芯片从 8K 换 16K，片内从 13 位变 14 位，高位少一位——同一 CPU 接不同芯片，分界不同
3. **译码器跳位 → 地址重复（408 高频）**：A13 和 A15 送译码器、A14 不参与 → 每片 8K 有 16K 地址映射（A14=0/1 都选中同一片）→ 一半地址重复，容量实际减半。**高位地址必须连续参与片选**
4. **"低位地址进所有芯片 = 所有芯片都在工作"是误解**：低位是"并联送到"，但只有被高位片选选中的那一片**响应**——低位只是"候选房间号"，片选才是"开门"（呼应 [[选线与片选信号]] 的"门禁"类比）

## 详细解释
### 为什么必须分低位/高位？
多片芯片扩展时，若所有芯片**共享全部地址线**且同时响应 → 数据总线冲突。分工解决：
- 低位共享（同房号概念）→ 只有一片会真正读
- 高位独立（不同楼号）→ 译码择一，保证"同一时刻只有一片工作"

### 分界线怎么定？
```
片内地址位数 = log2(单芯片存储字数)   # 8K → 13 位
高位位数     = CPU地址线总数 - 片内位数  # 16 - 13 = 3 位
可管芯片数   = 2^高位位数                 # 2³ = 8 片
```
> 高位没用完（如只用 2 位管 4 片）→ 有剩余地址空间未映射（正常设计）；高位不够 → 扩展不出那么多片。

### 和"按字/按字节寻址"的关系
低位位数还取决于**编址单位**：按字节编址时，片内字节数 = 芯片容量；若按字编址，片内字数 = 容量 ÷ 字长，片内地址线可少 log2(字长) 根（呼应 [[按字寻址与按字节寻址]]）。

### 看图快速定位
用户图（字扩展 8K×8→32K×8）：橙色地址线 A12~A0 = 低位（片内，并联），A13/A14 = 高位（送译码器产生 CS）——一眼分清：**进芯片的线是低位，进译码器的线是高位**。
