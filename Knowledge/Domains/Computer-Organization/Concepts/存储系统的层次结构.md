# 存储系统的层次结构

## 类型判定
判别型 — 回答"计算机里有哪些存储器、为什么分层、各层什么特点"，属于系统结构类概念。

## 类比 ★
**一句话比喻：** 像宿舍楼的储物体系——寄存器和Cache是桌上的保温杯（随拿随喝），主存是床底的行李箱（常翻但费劲），辅存是宿舍楼下的大仓库（什么都放但得跑一趟）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 寄存器 | 手里捏着的笔，随取随用，数量极少 |
| Cache | 桌面的常用工具盒，快但装不下多少 |
| 主存/辅存 | 书架上的书 vs 楼下图书馆的书库 |

## 是什么
存储系统按「速度-容量-成本」三角关系自下而上分层：**辅存（磁盘/SSD）→ 主存（内存）→ Cache（高速缓冲存储器）→ 寄存器**。越靠近 CPU 速度越快、容量越小、单位造价越高。CPU 只能直接访问寄存器和 Cache/主存，辅存中的数据必须先调入主存才能被 CPU 使用（如启动 App 时把程序从辅存读到主存）。

## 输入-输出空间
- **输入**：CPU 要访问的数据地址
- **输出**：数据（命中时来自更高层，未命中时逐层向下查找并调入）
- **前置条件**：数据以块为单位在相邻层之间复制（如主存块 ↔ Cache 块）

## 正例（≥2 个）
1. **微信启动的 2-3 秒**：启动时把微信程序从辅存（手机机身存储）调入主存，之后 CPU 才能执行微信的代码——辅存数据必须进主存才能被访问。
2. **视频通话卡顿优化**：视频聊天时频繁访问的那段代码从主存复制到 Cache，CPU 直接读 Cache 副本，避免每次访问慢速主存——Cache 缓解主存与 CPU 的速度矛盾。

## 反例/边界（≥1 个）
1. **"主存和辅存是对称的"是错的**：CPU 不能直接访问辅存（磁盘/U盘），辅存数据必须调入主存；而主存可以被 CPU 直接读写。两者地位不对称。
2. **辅存/外存划分不统一**：有的教材把装在机内的磁盘叫"辅存"、U盘光盘叫"外存"；有的统称"辅存/外存"。做题时以题目定义为准。

## 详细解释
层次结构遵循**局部性原理**驱动：程序执行时短时间内只会频繁访问一小部分数据，硬件就把这部分数据复制到更快的层，让 CPU 多数时间访问快速层，整体性能接近最快层、价格接近最慢层。

| 层次 | 典型容量 | 速度 | 造价 | CPU 直接访问 |
|------|---------|------|------|-------------|
| 寄存器 | 几十个 | 最快（纳秒级） | 最高 | ✅ |
| Cache | 几 MB | 快（几 ns） | 高 | ✅ |
| 主存 | 8-16 GB | 中（几十 ns） | 中 | ✅ |
| 辅存 | 128 GB+ | 慢（ms 级） | 低 | ❌ 需先调入主存 |

数据流向：辅存 → 主存 → Cache → 寄存器，每层都是上一层的"副本缓存"。Cache 中修改过的数据最终要写回主存保持一致性。
