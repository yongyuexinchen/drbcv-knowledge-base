# AI应用开发-12周学习路线图

## 是什么（What）

面向 Python 初学者的优化版12周学习路线，修正了原计划 `Docker → Java基础 → AI伴侣项目` 的问题。新路线分三阶段：地基搭建（RAG全流程项目）→ 技能深化（Agent编排+API工程化）→ 整合冲刺（AI伴侣MVP+面试）。

这就像健身计划：第一月减脂+基础力量（RAG项目），第二月增肌+力量突破（Agent项目），第三月塑形+备赛（MVP+面试）。每天练什么、第几周达到什么标准，全都标好了。

## 为什么重要（Why）

- 核心修正：删除Java、新增Prompt+RAG+Agent、AI伴侣从唯一项目改为3个递增难度的项目
- 每个阶段都有可展示的具体产出 — 面试官不看你学了什么，看你做出过什么
- 与黑马V6.5同步（第3周开课），互为补充而非重复
- 目标明确：2026年10月底投递深圳AI应用开发工程师，目标薪资20-25K

## 怎么做（How）

### 三阶段总览

```
原计划：Docker → Java基础 → AI伴侣项目
  ↓ 修正 ↓
优化后：
  第1-4周: Docker + Prompt + RAG全流程项目
  第5-8周: Agent编排 + API工程化 + 企业级RAG
  第9-12周: AI伴侣MVP + MCP + 面试冲刺
```

### 里程碑

| 周 | 里程碑 | 产出 |
|----|--------|------|
| 第1周 | Docker Compose + PromptManager | `docker-compose.yml` + `prompt_manager.py` |
| 第2周 | 向量检索打通 | `embedder.py` + `vector_store.py` + `chunker.py` |
| 第3-4周 | **个人知识库问答系统** | GitHub仓库 `personal-rag-qa`，含混合检索+Rerank |
| 第5-6周 | **多Agent客服系统** | GitHub仓库 `multi-agent-cs`，含路由+专业化Agent |
| 第7-8周 | API工程化+RAGAS评估 | 两个项目加异常处理/限流/日志/RAGAS |
| 第9-10周 | **永月MVP** | ST+DeepSeek+Memobase+edge-tts，3分钟演示视频 |
| 第11周 | 面试冲刺 | 简历打磨+技术模拟+30题算法+系统设计 |
| 第12周 | 投递面试 | Boss直聘+猎聘批量投递，以面代练 |

### 面试自检清单

```
□ RAG完整流程是什么？每个环节有哪些优化手段？
□ 你做的RAG项目遇到了什么问题？怎么解决的？
□ Agent编排中的路由逻辑怎么设计？边界情况怎么处理？
□ 不用框架手写一个ReAct Agent，伪代码写出来
□ FastAPI的async/await原理，和同步有什么区别？
□ 向量数据库选型：FAISS vs Chroma vs Milvus 各有什么场景？
□ 你的AI伴侣MVP用了什么记忆方案？为什么这样设计？
```
