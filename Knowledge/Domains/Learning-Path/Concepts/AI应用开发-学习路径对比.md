# AI应用开发-学习路径对比

## 是什么（What）

对比国内外主流AI应用开发学习资源：国内培训班（尚硅谷¥8,800-11,800 / 黑马V6.5已报名 / 千锋）、国外平台（DeepLearning.AI短期课程 / Fast.ai）。核心结论：**黑马V6.5是主力，DeepLearning.AI短期课程是查漏补缺利器，尚硅谷24项目是灵感库**。

这就像选健身房：国内培训班=私教课（手把手带、项目实战），DeepLearning.AI=团课（1-2小时搞定一个技能点），Fast.ai=CrossFit（硬核但未必对应用开发直接有用）。

## 为什么重要（Why）

- 用户已报黑马V6.5（100天，8月开课），这是主力学习资源
- 但黑马有两个覆盖缺口：Python工程化能力（训的是写代码不是做项目）、独立项目能力（跟着做≠自己能做）
- 关键认知：培训班的项目可以写简历，但面试追问细节会露馅——必须每个模块学完后自己做独立变体

## 怎么做（How）

### 资源对比

| 资源 | 价格 | 周期 | 覆盖 | 适合场景 |
|------|------|------|------|----------|
| 尚硅谷大模型 | ¥8,800 | 4月 | RAG+Agent+Dify+24项目 | 参考项目灵感 |
| **黑马V6.5** | 已报 | 100天 | RAG+Agent+微调+部署 | **主力学习** |
| 千锋AI+Java | — | — | Java路线AI | ❌ 不推荐 |
| DeepLearning.AI | 免费/低价 | 1-2h/课 | RAG/Agent/MCP/记忆 | 查漏补缺 |
| Fast.ai | 免费 | 25课 | 深度学习原理 | 补充(Part 1) |

### 黑马覆盖评估

| 技能 | 黑马V6.5 | 缺口 |
|------|----------|------|
| LLM API | ✅ | — |
| Prompt | ✅ | — |
| RAG | ✅ | 缺RAGAS评估 |
| Agent | ✅ | 缺MCP协议 |
| 向量DB | ✅ | — |
| FastAPI | ✅ | 缺工程化(异常/限流/并发) |
| Docker | ✅ | — |
| 独立项目能力 | ❌ | 必须自己补 |

### 补缺策略

```
黑马上课期间同步做的事：
1. 每周手写200行Python（不用AI辅助）— 补工程化能力
2. 每个模块学完做独立变体项目 — 补独立项目能力
3. DeepLearning.AI 短期课程做查漏补缺 — 补MCP/RAGAS
```
