# 贴现率分析引擎（Discount Analyzer）

## 类型判定
判别型 — 量化「叙事中讨论的传导链，有多少已在数据中兑现了」的核心引擎，是整个系统区别于传统因果发现的创新点。

## 类比 ★
### 一句话比喻
你朋友在朋友圈连发三天「我要暴富」，你查他银行卡余额——只多了500块。但翻他历史记录发现，以前每次他喊「暴富」后一个月内平均多赚5000块。贴现率 = 500 / 5000 = 10%。结论：他的「暴富叙事」只兑了10%，可能马上要收到一笔大额转账了——这是低贴现率的前瞻信号。

反过来，如果他喊了三天已经到账4800块（贴现率96%），你再跟风就晚了——已经充分定价。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 贴现率 (discount rate) | 已兑现比例——叙事吹的牛，数据兑现了多少 |
| 已实现效应 (realized impact) | 银行卡实际多了多少钱——看了就知道 |
| 预期总效应 (expected impact) | 翻他历史记录——以前喊完牛平均能到账多少 |
| 历史类似模式 (analogues) | 翻聊天记录找「上次他也这样说」的场景——用余弦相似度匹配 |
| 低贴现率 (<30%) | 牛吹了但钱还没到账——可能还在路上，是机会信号 |
| 高贴现率 (>70%) | 钱已经到了甚至超了——牛已兑现，再追就是接盘 |
| 实现曲线 (realization curve) | 每天追踪到账进度——D+1到了8%，D+5到了35%，画出来就是兑现速度 |

## 是什么
贴现率分析引擎是宏观传导发现系统最核心的模块。它不发现新传导链，而是评估**已有传导链的兑现状态**：叙事中讨论的传导关系，有多少已经在数据中观察到了？贴现率 = 已兑现效应 / 预期总效应，其中预期总效应来自历史类似场景下该传导的平均效应量。贴现率 < 30% → 低贴现，传导尚未被市场充分定价（前瞻信号）；贴现率 > 70% → 高贴现，传导可能已被过度反应。

## 输入-输出空间
- **输入**: 源板块收益率序列 + 目标板块收益率序列 + 叙事起点（最近一次源板块 >2σ异动） + 发现层产出的显著传导边
- **输出**: 贴现率(0~1) + 实现曲线 + 预计剩余天数 + 历史类似模式 + 信号标记（is_opportunity / is_overpriced）
- **前置条件**: 足够的回看历史数据（>滚动窗口×2）；传导边需已被发现层标记为显著

## 正例（≥2 个）
1. **芯片禁令→科技股盈利下修**: 2024年3月美国对华芯片禁令升级（叙事起点），历史类似事件（2018中兴、2020中芯）平均导致科技股盈利下修15%。当前只下修了2.3%，贴现率=15%，系统标记为「LOW_DISCOUNT — 低贴现前瞻信号」。
2. **美联储降息→黄金上涨**: 降息叙事启动后，黄金涨了3%。历史5次降息周期中黄金平均涨幅12%，贴现率=25%。系统输出「预计还需约40个交易日完全兑现，历史类似模式相似度0.87」。

## 反例/边界（≥1 个）
1. **数据不足时失效**: 如果源-目标板块的历史数据不足1年（<250个交易日），滚动回归估计的历史预期beta不可靠，整个贴现率计算失去锚定——此时只输出定性分析。
2. **叙事起点检测噪音**: 系统用「源板块 > 2倍滚动标准差」自动检测叙事起点。在剧烈波动行情中（如2020年3月），可能误触发多个叙事起点——需人工确认或结合新闻事件校准。
3. **不是交易信号**: 低贴现率 ≠ 一定会涨。只是说「历史上这类传导通常会走完，而现在只走了一小段」。如果这次是不同的宏观范式，历史模式失效，贴现率毫无意义。

## 详细解释

### 核心算法
1. **找叙事起点**: 从后往前扫描源板块日收益率，找到第一个超过2倍滚动标准差的日期
2. **估算历史预期**: 叙事起点前 `rolling_window` 天内源-目标的 beta 系数（滚动回归）
3. **计算已实现**: 从叙事起点至今，目标板块的累计绝对波动
4. **贴现率 = realized / expected**，钳制在 [0, 1]
5. **找历史类似模式**: 用余弦相似度在回看窗口（~2年）中匹配最近的源-目标联合行为模式
6. **预计剩余天数**: 用最近5天兑现速度线性外推

### 信号层级
```
贴现率 < 0.3  → 🔵 低贴现 — 机会信号（数据尚未反映叙事）
0.3 ≤ 贴现率 ≤ 0.7 → ⚪ 正常 — 传导在途中
贴现率 > 0.7  → 🔴 高贴现 — 过度反应风险（叙事已充分定价）
```
