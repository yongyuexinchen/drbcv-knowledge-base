# AI Agent（智能体）

## 类型判定
判别型 — 区别于普通聊天机器人的「输入→输出」模式，Agent 按照「目标→规划→调用工具→执行→反馈→调整」的闭环自主行动。

## 类比 ★
### 一句话比喻
普通聊天机器人像图书馆问询台的大爷——你问啥他答啥，答完就完。AI Agent 像你雇的私人助理——你给个目标「帮我把下周面试准备好」，他自己上网搜公司背景、整理面经、在日历上标出模拟面试时间、完事了还问你「要不要再练一轮」。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Agent 自主执行 | 私人助理——给目标，他自己拆任务、找资源、干完汇报 |
| Tool Calling（工具调用） | 助理掏出手机——查地图、发邮件、订餐厅，不用你教他每一步 |
| Reflection（自我修正） | 助理发现路线堵车了——自己改走另一条路，而不是问你要不要改 |

## 是什么
AI Agent 是一种以 LLM 为推理核心、具备**自主规划和工具调用能力**的智能系统。它的工作模式不是「用户说一句、AI 回一句」的被动应答，而是「用户给目标 → Agent 拆解任务 → 调用外部工具 → 感知执行结果 → 反思调整 → 直到目标达成」的主动闭环。在 AI 伴侣场景中，Agent 让 AI 从「能聊」升级到「能做事」——不只是陪你聊面试焦虑，而是真的帮你准备面试。

## 输入-输出空间
- **输入**: 用户目标（自然语言描述的任务或问题）
- **输出**: 任务完成结果 + 过程报告
- **核心循环**: `Observe（感知） → Plan（规划） → Act（执行工具调用） → Reflect（反思结果） → 循环或结束`
- **与传统 Chatbot 的区别**: Chatbot 是单轮映射（输入→输出），Agent 是多步交互（环境↔Agent 之间的循环）

## 正例（≥2 个）
1. **AutoGPT / BabyAGI**: 最早的自主 Agent 实现——给一个目标，自动拆分任务、搜索网页、写文件、自我修正直到完成
2. **AI 伴侣中的「帮我规划旅行」**: 用户说「帮我规划周末深圳两日游」→ Agent 搜景点 → 查天气 → 排行程 → 订酒店 → 返回完整计划——这是 Agent，不是 Chatbot

## 反例/边界（≥1 个）
1. **标准 ChatGPT 对话**: 你问「深圳有什么好玩的地方」→ GPT 列几个景点。这不是 Agent——没有目标循环、没有工具调用、没有多步规划
2. **边界 — 自主权边界**: Agent 能自主到什么程度？能花钱订酒店吗？能发邮件吗？——涉及「人在回路（Human-in-the-loop）」的安全设计

## 详细解释
Agent 与普通 LLM 对话的本质区别：

| 维度 | 普通 LLM 对话 | AI Agent |
|-----|-------------|----------|
| 交互模式 | 单轮/有限多轮 | 多步自主循环 |
| 能力边界 | 仅语言生成 | 感知+行动+推理 |
| 外部交互 | 无（纯文本） | 工具调用、环境感知 |
| 目标导向 | 无（被动应答） | 有（主动追求目标） |
| 自我修正 | 无 | 有（Reflection） |

在 AI 伴侣架构中的定位：
```
用户目标 → Agent（Planning + Tool Calling + Reflection）
              ↓
           LLM（推理核心）
              ↓
         Memory（持久化上下文）
```

## 关系
### → 指向
- [[LLM]] — Agent 以 LLM 为推理引擎，所有规划和决策最终由 LLM 产出
- [[Planning]] — 规划是 Agent 的核心能力之一，将目标分解为可执行步骤
- [[Tool Calling]] — 工具调用是 Agent 与外部世界交互的手段
- [[Reflection]] — 反思是 Agent 自我修正的机制
- [[Long-term Memory]] — Agent 依赖长期记忆获取用户背景来做出相关决策

### ← 被指向
- [[Background Agent]] — 后台智能体是 Agent 的一种持续运行形态
- [[Function Calling]] — Function Calling 是 Agent 实现 Tool Calling 的底层技术
- [[RAG]] — RAG 为 Agent 提供外部知识检索能力
- [[User Model]] — User Model 为 Agent 提供用户画像以个性化行为
