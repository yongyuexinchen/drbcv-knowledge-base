# Semantic Memory（语义记忆）

## 类型判定
判别型 — 从具体经历中提炼出的抽象知识和规律性认知，回答「用户是什么样的人」。

## 类比 ★
### 一句话比喻
语义记忆像你朋友在心里给你贴的标签——「这家伙做事喜欢系统化」「她对声音特别敏感」「这人熬夜但早起不了」。这些标签不是某一次谈话留下的，而是相处半年后从无数件小事里自动浮现出来的印象。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| Semantic Memory 条目 | 朋友心里对你的标签——不是某件事，是长期观察到的模式 |
| 偏好提取 | 观察十次你点咖啡都选冰美式 → 标签「喜欢冰美式」 |
| 知识更新（覆盖旧标签） | 你突然开始喝热拿铁 → 标签从「冰美式党」换成「最近改喝拿铁了」 |

## 是什么
语义记忆是 AI 伴侣对用户和世界的**抽象认知**，以键值对或结构化知识图谱的形式存储。例如 `{偏好: {学习方式: "系统化"}, {沟通风格: "直接"}, {兴趣: ["AI", "哲学"]}}`。它与 Episodic Memory 的区别在于：Episodic 记住「某天发生了什么」，Semantic 记住「这意味着什么」——前者是日记，后者是人物小传。

## 输入-输出空间
- **输入**: 多条 Episodic Memory（从具体事件中归纳）+ 用户显式声明（「我是 INTJ」）
- **输出**: 结构化知识条目（偏好、性格、能力、价值观、关系）
- **存储形式**: 键值对、三元组（subject-predicate-object）、JSON 文档
- **更新逻辑**: 新证据覆盖旧认知（置信度阈值机制）——如果用户连续5次表现出新偏好，更新语义记忆

## 正例（≥2 个）
1. **学习偏好归纳**: 用户3次提到「先看框架图再学细节」→ 语义记忆记录 `{学习风格: "top-down"}` → 之后 AI 推荐资源时优先给思维导图而非逐章教程
2. **性格推断**: 用户多次在决策时列出利弊表、引用数据 → 语义记忆记录 `{决策风格: "理性分析型"}` → AI 在给建议时附上数据和逻辑论证

## 反例/边界（≥1 个）
1. **一次性事件（「上周三他吃了顿火锅」）**: 这是 Episodic Memory，不是 Semantic Memory——单次事件不构成抽象认知
2. **边界 — 过度泛化**: 从2次相似行为就推断「用户永远喜欢X」可能导致错误——需要足够样本量（如≥3次一致行为）才形成语义记忆

## 详细解释
语义记忆的提炼过程：

```
Episodic Memory × N（多个具体事件）
         ↓ 模式识别
Semantic Memory（抽象规律）
         ↓
   ┌─────┴─────┐
   ↓           ↓
User Model   Persona
```

语义记忆是 User Model 的「认知骨架」——User Model 整合 Semantic（是什么样的人）+ Episodic（经历了什么）+ 实时状态（当前在做什么）。

## 关系
### → 指向
- [[User Model]] — 语义记忆是用户模型的核心组成部分（用户的属性、偏好、性格）
- [[Persona]] — AI 的语义记忆（对用户的认知）影响 AI 如何调整自己的 Persona 表现
- [[Long-term Memory]] — 语义记忆是长期记忆中「去时间化的抽象知识」子类

### ← 被指向
- [[Episodic Memory]] — 多条情景记忆经模式识别提炼为语义记忆
- [[Memory Consolidation]] — 记忆巩固过程识别出跨事件的规律，生成或更新语义记忆
- [[Memory Decay]] — 长期未被新证据确认的语义记忆可能衰减或降级
