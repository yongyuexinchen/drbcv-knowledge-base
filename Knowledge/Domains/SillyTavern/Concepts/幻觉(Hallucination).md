# ⬜ 幻觉(Hallucination)

## 类型判定
**判别型** — 判断模型输出是否属于"不符合事实/设定的内容"

## 是什么
AI模型生成看似合理但实际不符合事实、逻辑或当前对话设定的内容。在角色扮演中表现为：角色突然说出不符合设定的台词、编造不存在的剧情、混淆角色关系。

## 输入-输出空间
- **输入**: AI生成的文本
- **输出**: {"有幻觉（不符合设定/事实）", "无幻觉（符合设定/事实）"}
- **映射关系**: 从属关系——每条输出被判定是否符合真实/设定

## 正例
1. **场景A（幻觉）**: 角色A设定"没有兄弟姐妹"，聊到第20轮AI说"你哥哥昨天来找你了"——编造了不存在的哥哥。
2. **场景B（非幻觉）**: 角色设定"喜欢猫"，AI在合适场景下说"我家的橘猫今天又打翻花盆了"——虽然有创意但符合设定，不算幻觉。

## 反例/边界
1. **常见误解**: 幻觉不是"AI撒谎"——AI没有主观意图。幻觉是概率生成模型的固有特性：模型在不确定时倾向于"编"一个看起来合理的答案。
2. **边界**: 区分"创意发挥"和"幻觉"——如果角色设定允许自由发挥，"编故事"不算幻觉；但如果编造的内容直接违背设定，就是幻觉。

## 详细解释
幻觉（Hallucination）是大模型的固有缺陷。原因：①训练数据的局限性②概率采样的不确定性③上下文窗口过长时模型注意力分散。在角色扮演中，减少幻觉的方法：精调用高质量角色扮演数据训练、优化上下文管理（避免长窗口稀释注意力）、降低Temperature（减少随机性）。DeepSeek Tavern V1声称通过精调大幅减少了幻觉。


## 细节备注

### 常见类型
| 类型 | 例子 |
|------|------|
| 事实幻觉 | 编造不存在的事件/数据 |
| 设定违背 | 角色说出不符合设定的内容 |
| 关系混淆 | 角色A的事安到角色B身上 |
| 逻辑断裂 | 前后矛盾 |

### 减少方法
1. 精调高质量数据
2. 优化世界书触发精准度
3. 降低Temperature
4. 控制上下文长度（避免过长稀释注意力）
