# ⬜ 触发关键词(Trigger Keyword)

## 类型判定
**判别型** — 判断「当前对话中的某个词是否应触发世界书条目」

## 是什么
世界书的核心激活机制。每个世界书条目绑定一组关键词，当对话中出现这些词时，对应条目的内容自动注入AI上下文。一个条目的关键词通常包含中文名、英文名、简称、昵称等多种变体。

## 输入-输出空间
- **输入**: 对话中出现的所有词
- **输出**: {"触发（注入对应条目内容）", "不触发"}
- **映射关系**: 从属关系——每个词被判定是否匹配任何条目的关键词列表

## 正例
1. **场景A**: 对话"我们去暗影森林吧"→检测到"暗影森林"→触发对应条目→自动注入"暗影森林位于大陆东部，终年迷雾，深处有精灵遗迹"。AI瞬间"知道"暗影森林的一切。
2. **场景B**: 好的关键词设计——一个地点配多个变体："暗影森林"+"Shadow Forest"+"黑森林"+"暗影之森"→无论用户用哪个称呼都能触发。

## 反例/边界
1. **常见误解**: 关键词不是"越多越好"——关键词太多会导致误触发。比如给"森林"设关键词会触发所有森林相关条目。
2. **边界**: 区分"精确匹配"和"正则匹配"——正则可以实现模糊匹配但性能开销更大。新手先用精确匹配。

## 详细解释
触发关键词是世界书的"钥匙"。设计原则：①覆盖所有可能称呼（中英文、昵称、简称）②避免过于广泛（如"人"会误触发所有NPC条目）③预判用户会怎么提到这个事物。好的关键词设计让世界书"刚好在需要的时候出现"。


## 细节备注

### 设计原则
| 原则 | 说明 |
|------|------|
| 覆盖变体 | 中文+英文+简称+昵称 |
| 避免过泛 | "人"会误触发所有NPC条目 |
| 预判用户 | 用户会怎么提到这个事物 |

### 匹配方式
| 方式 | 说明 |
|------|------|
| 精确匹配 | 完全一致才触发 |
| 正则匹配 | 模糊匹配，一行正则覆盖几十种表达（进阶） |
