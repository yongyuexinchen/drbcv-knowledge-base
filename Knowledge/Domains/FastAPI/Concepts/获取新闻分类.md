# 获取新闻分类

## 类型判定
procedure — 按标准接口四步流程：定义模块化路由 → 定义 ORM 模型类 → 封装 CRUD 查询方法 → 路由调用并响应结果。

## 类比 ★
### 一句话比喻
获取新闻分类就像报纸的栏目导航条——时政、体育、娱乐每个栏目一个标签，读者一眼就知道有哪些板块可以看。每个分类就是数据库 news_category 表里的一行记录。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| news_category 表 | 报社的栏目清单——记录所有可用的分类 |
| select 查询 | 翻开栏目清单看一眼——有哪些分类一目了然 |
| skip / limit 分页参数 | 栏目太多时翻页看——跳过前 N 个，只看当前页 |
| routers/news.py | 报社前台——处理"给我看看有哪些栏目"的请求 |
| CRUD/news.py 的 get_categories | 仓库管理员——去档案室把栏目清单取出来 |

## 是什么
获取新闻分类是新闻模块的第一个接口，GET 请求 `/api/news/categories`，返回数据库中所有的新闻分类列表（头条、社会、国内、国际、财经、科技、娱乐、体育共 8 个分类）。这是接口开发四步流程（路由→模型类→CRUD→调用响应）的标准示范。

## 输入-输出空间（程序型必填）
- **输入**：skip: int(默认0)、limit: int(默认100) — 分页参数
- **输出**：`{"code": 200, "message": "success", "data": [分类1, 分类2, ...]}`
- **前置条件**：已配置 ORM（异步引擎 + 会话工厂 + get_db 依赖项）

## 核心代码 + 步骤表
```python
# ===== models/news.py：第二步，定义模型类 =====
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, Integer
from datetime import datetime

class Base(DeclarativeBase):
    pass

class NewsCategory(Base):
    __tablename__ = "news_category"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(50), unique=True, nullable=False)
    sort_order: Mapped[int] = mapped_column(Integer, default=0, nullable=False)
    created_at: Mapped[datetime] = mapped_column(default=datetime.now)
    updated_at: Mapped[datetime] = mapped_column(default=datetime.now, onupdate=datetime.now)

# ===== CRUD/news.py：第三步，封装查询方法 =====
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from models.news import NewsCategory

async def get_categories(db: AsyncSession, skip: int = 0, limit: int = 100):
    stmt = select(NewsCategory).offset(skip).limit(limit).order_by(NewsCategory.sort_order)
    result = await db.execute(stmt)
    return result.scalars().all()

# ===== routers/news.py：第一+四步，路由调用 =====
from fastapi import Depends, APIRouter
from CRUD import news as news_crud
from config.db_config import get_db

router = APIRouter(prefix="/api/news", tags=["news"])

@router.get("/categories")
async def get_categories(
    skip: int = 0,
    limit: int = 100,
    db: AsyncSession = Depends(get_db)
):
    categories = await news_crud.get_categories(db, skip, limit)
    return {"code": 200, "message": "获取新闻分类成功", "data": categories}
```

| 步骤 | 说明 | 参照依据 |
|------|------|---------|
| ① 定义模块化路由 | APIRouter + prefix + tags | API 接口规范文档 |
| ② 定义 ORM 模型类 | 继承 Base，字段映射数据库表 | 数据库表结构（DDL） |
| ③ 封装 CRUD 方法 | select → offset/limit → execute → scalars | ORM 查询语法 |
| ④ 路由调用响应 | Depends 注入 db → await crud 方法 → return | FastAPI 路由规范 |

## 正例（≥2 个）
1. **所有查询接口通用此流程**：获取新闻列表、获取新闻详情、获取用户信息等接口，都遵循同样的四步流程——学会一个就等于学会所有。
2. **通用字段放 Base 类**：created_at 和 updated_at 几乎所有表都有，放在 Base 中统一管理——新闻表、用户表、分类表都自动继承这两个时间字段。
3. **按接口文档写路由**：接口文档规定路径 `/api/news/categories`、方法 GET、参数 skip/limit——严格对照实现，前后端联调零歧义。

## 反例/边界（≥1 个）
1. **模型类表名写错**：`__tablename__ = "news_categories"`（多写了 s）——查询时报错"表不存在"。表名必须和数据库实际表名完全一致。
2. **字段类型不匹配**：数据库 name 字段是 VARCHAR(50)，模型类却写成 `Mapped[int]`——查询时报类型错误。必须对着 DDL 逐个核对。
3. **忘记 __tablename__**：模型类只写了字段但没指定表名——SQLAlchemy 不知道查哪张表，报错。

## 详细解释
**接口开发四步流程**是 FastAPI 项目开发的通用模式：
1. **路由**（参照 API 接口规范文档）：确定请求方法、路径、参数和响应格式
2. **模型类**（参照数据库表结构 / DDL）：定义 ORM 模型，字段与数据库列一一对应
3. **CRUD**：在 CRUD 文件夹中封装增删改查函数，传入 db session 执行 SQLAlchemy 操作
4. **调用响应**：在路由处理函数中 Depends 注入 db → await CRUD 方法 → return 结果

这个流程适用于几乎所有接口，后续的新闻列表、新闻详情、用户注册、用户登录都是这个套路。
