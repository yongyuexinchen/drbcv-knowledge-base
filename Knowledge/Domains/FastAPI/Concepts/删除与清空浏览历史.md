# 删除与清空浏览历史

## 类型判定
procedure — 两个 DELETE 接口合并：删除单条（按 history_id 路径参数精确删）+ 清空全部（按 user_id 批量删），共享 delete + rowcount 检查模式。

## 类比 ★
### 一句话比喻
删除与清空浏览历史就像管理借阅登记本——删除单条是撕掉登记本的某一页（"大邱借新闻3的那条记录不要了"），清空是烧掉整本登记本（"大邱的所有借阅记录全清掉"）。撕一页需要知道是哪一页（history_id），烧整本只需要知道是谁的本子（user_id）。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 删除单条：DELETE /delete/{history_id} | 撕掉登记本第 N 页——精确到哪一行 |
| 清空：DELETE /clear | 整本扔进碎纸机——按人批量销毁 |
| history_id（路径参数） | "第3页"——登记本的页码 |
| rowcount 检查命中 | 撕之前确认这一页还在不在——不在就报"404 记录不存在" |
| rowcount 获取数量 | 烧本子后数灰烬——清空了 8 条 |

## 是什么
浏览历史模块包含两个 DELETE 接口：

1. **删除单条浏览记录**（DELETE `/api/history/delete/{history_id}`）：通过路径参数 `history_id` 精准删除一条记录。删除前检查 rowcount，命中 0 则抛 404。

2. **清空浏览历史列表**（DELETE `/api/history/clear`）：按当前用户 `user_id` 批量删除所有浏览记录。与清空收藏列表模式一致，但无需返回删除数量（message 直接返回"清空成功"即可，也可选择返回）。

## 输入-输出空间（程序型必填）

**删除单条：**
- **输入**：history_id: int（路径参数）、user（Depends 注入）、db（Depends 注入）
- **输出**：`{"code": 200, "message": "删除成功"}` 或 404 "浏览记录不存在"

**清空：**
- **输入**：user（Depends 注入）、db（Depends 注入）——无额外参数
- **输出**：`{"code": 200, "message": "清空成功"}`

- **前置条件**：用户已登录、History 模型类已定义

## 核心代码 + 步骤表

### 删除单条
```python
# ===== CRUD/history.py =====
async def remove_history(db: AsyncSession, history_id: int, user_id: int):
    stmt = delete(History).where(
        History.id == history_id,
        History.user_id == user_id   # 安全：只能删自己的
    )
    result = await db.execute(stmt)
    await db.commit()
    return result.rowcount > 0

# ===== routers/history.py =====
@router.delete("/delete/{history_id}")
async def delete_history(
    history_id: int,                              # 路径参数
    user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    result = await history_crud.remove_history(db, history_id, user.id)
    if not result:
        raise HTTPException(status_code=404, detail="浏览记录不存在")
    return success_response(message="删除成功")
```

| 步骤 | 代码 | 说明 |
|------|------|------|
| ① 路径参数获取 | `@router.delete("/delete/{history_id}")` | 前端传 `/delete/5` |
| ② 双条件删除 | `where(id=history_id, user_id=user_id)` | 防止用户删别人的记录 |
| ③ 检查命中 | `result.rowcount > 0` | 0 → 404 |
| ④ 响应 | `success_response(message="删除成功")` | data 默认为 null |

### 清空全部
```python
# ===== CRUD/history.py =====
async def clear_history(db: AsyncSession, user_id: int):
    stmt = delete(History).where(History.user_id == user_id)
    result = await db.execute(stmt)
    await db.commit()
    return result.rowcount or 0

# ===== routers/history.py =====
@router.delete("/clear")
async def clear_history(
    user: User = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    count = await history_crud.clear_history(db, user.id)
    return success_response(message=f"清空了{count}条浏览记录")
```

| 步骤 | 代码 | 说明 |
|------|------|------|
| ① 无请求参数 | 仅 Depends 注入 user 和 db | 不需要指定删哪个 |
| ② 按用户批量删 | `delete(History).where(user_id=...)` | 当前用户的所有浏览记录 |
| ③ 可选返回数量 | `result.rowcount` | 可拼入 message 告知删了多少 |

## 正例（≥2 个）
1. **删除单条**：大邱在浏览历史列表页，点第3条右侧的叉号 → 前端调用 `DELETE /delete/3` → rowcount=1 → 成功，该条目从列表移除。
2. **删除不存在的记录**：用户传 `history_id=999`（不属于自己或不存在）→ rowcount=0 → 返回 404 "浏览记录不存在"。
3. **清空所有**：大邱有 8 条浏览记录，点击右上角清空 → `DELETE /clear` → rowcount=8 → 列表变空，message 可选 `"清空了8条浏览记录"`。
4. **安全隔离**：用户 A 试图删除用户 B 的浏览记录（`DELETE /delete/5`，即使 history_id=5 属于 B），CRUD 层 `where(id=5, user_id=A)` → rowcount=0 → 404。

## 反例/边界（≥1 个）
1. **删除单条不加 user_id 条件**：`where(History.id == history_id)` 不加 `user_id` → 用户可以删任何人的浏览记录——安全漏洞。
2. **清空不加 where**：`delete(History)` 无任何条件 → 清空所有用户的所有浏览记录——灾难性操作。
3. **路径参数与查询参数混淆**：`/delete/{history_id}` 是路径参数，写成 `DELETE /delete?historyId=5` → FastAPI 找不到路由，404。

## 详细解释
**路径参数 vs 查询参数**：删除单条用路径参数（`/delete/{history_id}`），因为 `history_id` 是资源的唯一标识，属于 URL 的一部分。取消收藏用查询参数（`/remove?newsId=xxx`），因为 `news_id` 不是 history 表的主键，更适合做过滤条件。

**双重安全校验**：删除单条时 WHERE 同时检查 `id` 和 `user_id`，即使前端传了别人的 history_id，后端也会因为 `user_id` 不匹配而 rowcount=0 → 404，不会误删。

**与收藏模块删除的对照**：
| | 取消收藏 | 删除单条浏览 | 清空收藏 | 清空浏览 |
|---|---|---|---|---|
| 路径/参数 | `/remove?newsId=` | `/delete/{history_id}` | `/clear` | `/clear` |
| WHERE 条件 | user_id + news_id | history_id + user_id | user_id | user_id |
| 删除依据 | 新闻 ID | 历史记录主键 | 用户 ID | 用户 ID |
