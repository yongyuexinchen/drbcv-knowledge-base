# FastAPI导学

## 类型判定
discriminant — 定义课程整体框架：学什么、为什么学、学完能做什么，是整个 FastAPI 学习路线的总地图。

## 是什么
本课程是黑马程序员的 **FastAPI 从入门到实战** 教程，目标是让学员具备三大能力：**Python 语言基础 → Web 服务化能力（FastAPI）→ 大模型训练与部署**。课程设计为 7 个章节，包含两个完整项目，从框架基础到 AI 模型服务化，最终产出可被外部调用的 AI 接口。

## 正例（≥2 个）
1. **后端开发转 AI 部署**：已有 Flask/Django 经验的开发者，通过这套课程快速将训练好的模型用 FastAPI 暴露成 API，供前端或其他服务调用。
2. **零基础学员**：课程从 FastAPI 框架基础讲起，逐步过渡到项目实战，Python 基础 + 框架 + AI 模型三步走，学习路径清晰。
3. **公司内部工具系统搭建**：学完后可独立搭建 Web 后端服务，如内部管理系统、数据查询接口等。

## 反例/边界（≥1 个）
1. **完全零编程基础**：课程假设学员已具备 Python 语言基础，如果完全没写过代码，需要先补 Python 基础，不能直接从框架开始。
2. **只想学模型训练不学 Web**：课程重点在"服务化"——让模型能被调用。如果只关心算法本身而不关心部署，这门课的核心价值就浪费了一半。

## 详细解释
课程结构（7 章 × 2 项目）：
- **FastAPI 框架基础**（2 章）：路由、参数（路径/查询/请求体）、响应类型、异常处理、依赖注入、ORM 等
- **项目一：AI 掘金头条**（4 章）：新闻展示、AI 问答（接入千问模型）、用户模块（登录/注册/收藏）——重点练封装接口的能力
- **项目二：模型训练+部署**（1 章）：用随机森林算法训练文本分类模型 → FastAPI 部署服务 → Streamlit 前端调用

FastAPI 被选为首选框架的原因：天生异步（基于 ASGI + async/await）、Pydantic 自动类型校验、自动生成 Swagger 交互式文档。
