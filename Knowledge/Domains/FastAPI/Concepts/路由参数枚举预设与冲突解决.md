# 路由参数枚举预设与冲突解决

## 类型判定
procedure — 三步进阶：定义枚举类限制可选值 → Path() 加参数级描述 → 理解路由匹配顺序避免冲突。

## 类比 ★
### 一句话比喻
枚举预设参数就像**奶茶店的甜度选择**——不是让你随便写，而是只能选"无糖/三分糖/半糖/全糖"，店员（FastAPI）给你一个下拉框，超出这个范围的直接拒单。路由冲突解决则像**电话总机转接规则**——如果两条线路号码格式相似（如 `/EMP/all` 和 `/EMP/{id}`），总机按顺序匹配，先接通的占线，后面那条永远接不到。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| `Enum` 枚举类 | 奶茶店甜度菜单——"张三/李四/王五"就是仅有的选项 |
| Swagger 下拉框 | 点单屏幕上的下拉菜单——只能从预设选项中选 |
| `Path()` description | 每个选项旁边的说明标签——"员工名字，只能是张三李四王五其中之一" |
| 路由按顺序匹配 | 电话总机——先注册的规则优先接通 |
| 路径参数路由 vs 固定路径路由 | 两条线：`/EMP/all` 是专线，`/EMP/{id}` 是通用线——谁排在前面谁先接 |
| 多值查询参数（list） | 团购点单——一次传三个奶茶，用同一个参数名传三次 |

## 是什么
**枚举预设参数**：用 Python 的 `Enum` 类限制路径参数只能取预设的几个值，Swagger 文档自动生成下拉选择框。**路由冲突解决**：当多个路由的 URL 模式重叠时（如 `/EMP/all` 和 `/EMP/{emp_id}`），FastAPI **按定义顺序匹配**，先定义的优先。**多值查询参数**：同一个参数名传多个值（如 `?ids=1&ids=2&ids=3`），用 `list` 类型接收。

## 核心代码

### 枚举预设值参数
```python
from enum import Enum

class EmpName(str, Enum):
    zhangsan = "张三"
    lisi = "李四"
    wangwu = "王五"

@router.put("/EMP/{emp_name}")
async def update_emp(
    emp_name: EmpName = Path(..., description="员工名字，只能是张三李四王五其中之一")
):
    return {"name": emp_name.name, "value": emp_name.value}
# Swagger 下拉：张三 | 李四 | 王五
```

### 路由顺序冲突示例
```python
# ❌ 错误顺序：{emp_id} 在前，/all 永远匹配不到
@router.get("/EMP/{emp_id}")   # 会把 "all" 当成 emp_id
async def get_one(emp_id: int): ...

@router.get("/EMP/all")         # 永远进不来！
async def get_all(): ...

# ✅ 正确：固定路径放在前面
@router.get("/EMP/all")         # "all" 先被匹配
async def get_all(): ...

@router.get("/EMP/{emp_id}")    # 数字才走到这里
async def get_one(emp_id: int): ...
```

### 多值查询参数
```python
@router.delete("/EMP/batch")
async def batch_delete(
    emp_ids: list[int] = Query(default=[], description="多个员工ID")
):
    return {"deleted": emp_ids}
# 请求: /EMP/batch?emp_ids=12&emp_ids=23&emp_ids=45
# 接收: emp_ids = [12, 23, 45]
```

## 正例（≥2 个）
1. **状态字段**：订单状态只能是 `待支付/已支付/已发货/已完成`，用枚举限制，Swagger 自动出下拉框，前端对接零歧义。
2. **固定路径优先**：`/book/search` 必须在 `/book/{book_id}` 之前定义，否则 `search` 被当成 book_id 导致类型校验失败。
3. **批量删除**：前端传 `?ids=101&ids=102&ids=103`，后端用 `list[int]` 一次性接收全部要删除的 ID。
4. **同名查询参数**：搜索接口支持 `?keyword=FastAPI&keyword=Python`，用 `list[str]` 接收实现多关键词搜索。

## 反例/边界（≥1 个）
1. **枚举值传了不在列表里的**：枚举只有张三/李四/王五，传"赵六" → 422 校验错误，Swagger 中只有下拉框不会出错（但直接改 URL 可以）。
2. **路由顺序搞反**：`/EMP/{id}` 在 `/EMP/all` 前面 → "all" 被当作 id 参数，`int` 类型校验失败返回 422，而非"查所有员工"。
3. **多值查询参数用 str 接收**：写 `emp_ids: str = Query(...)` 却传多个值 → 只接收到最后一个值。

## 详细解释
路由三要素：**请求路径 + 请求方法 + 处理函数**。两个路由即使 URL 完全相同，只要请求方法不同（GET vs DELETE），就不会冲突。

`Enum` 中 `.name` 是枚举成员名（如 `zhangsan`），`.value` 是枚举值（如 `"张三"`），两者可以相同也可以不同。
