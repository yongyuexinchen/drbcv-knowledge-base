# 路由处理函数（Path Operation Function）

## 类型判定
discriminant — 定义路由处理函数是什么：它不是装饰器，不是路由配置，而是**被装饰的那个 async def 函数本身**。定义它和其他路由层概念（装饰器、依赖项、中间件）的边界。

## 类比 ★
### 一句话比喻
路由处理函数就像餐厅后厨的**炒菜师傅**——菜单（装饰器）上写了"鱼香肉丝 18 元"，客人点菜（发请求），传菜员把订单递进厨房，师傅拿到订单上的备注"少辣、加蒜"（参数），哐哐炒完装盘（业务逻辑），最后把菜端出来（return）。师傅不管菜单怎么写、传菜员怎么跑——他只管接单→炒菜→出菜。

### 生活映射
| 概念世界 | 现实世界 |
|---------|---------|
| 装饰器 `@app.get("/dish")` | 菜单上的菜名和价格——挂在外面的牌子 |
| 路由处理函数 `async def cook():` | 后厨的炒菜师傅——真正干活的人 |
| 函数形参（path/query/body） | 客人订单上的备注——"少辣""加饭""打包" |
| FastAPI 参数自动解析 | 传菜员自动把备注翻译成师傅能懂的话 |
| `return {"dish": "ready"}` | 师傅把菜放上传菜口——出菜 |
| 依赖注入 `Depends(get_db)` | 师傅喊"帮我拿瓶酱油"——助手递过来 |

## 是什么
路由处理函数是 FastAPI 中**真正执行业务逻辑的异步函数**。它位于路由装饰器正下方，FastAPI 在请求到达时自动完成三件事：① 从请求中提取参数并注入形参（路径参数/查询参数/请求体/依赖项），② 执行函数体中的业务代码，③ 把 `return` 值自动转为 JSON 响应。

## 正例（≥2 个）
1. **最简单的处理函数**：
   ```python
   @app.get("/")
   async def root():           # 无参数的处理函数
       return {"message": "Hello World"}
   ```
2. **带多种参数的处理函数**：
   ```python
   @app.get("/news/{category_id}")
   async def news_list(
       category_id: int,               # 路径参数
       page: int = Query(1, ge=1),     # 查询参数
       db: AsyncSession = Depends(get_db)  # 依赖注入
   ):
       news = await db.execute(select(News).where(News.category_id == category_id))
       return news.scalars().all()
   ```
   这个函数里 FastAPI 自动完成了：URL 中提取 `category_id` → int、查询字符串中提取 `page` → int 且 ≥1、调用 `get_db()` 注入数据库会话。

## 反例/边界（≥1 个）
1. **不是装饰器**：`@app.get("/path")` 是路由配置，不是处理函数——它是"贴在函数上的标签"，告诉 FastAPI 哪个 URL 映射到哪个函数。
2. **不是中间件**：处理函数只对当前路由生效，中间件对所有请求生效。
3. **同步函数也可以**：FastAPI 不强制 `async def`——如果没有 IO 等待，用 `def` 也可以，FastAPI 会在线程池中运行它。
4. **函数名不重要**：`async def xyz():` 叫什么名不影响路由匹配，路由只看装饰器里的路径。

## 详细解释

### 处理函数的"魔法"：参数自动解析

FastAPI 会根据形参的类型注解和默认值，自动推断参数来源：

| 形参写法 | FastAPI 推断 | 来源 |
|---------|-------------|------|
| `id: int` | 路径参数（如果在路径中出现过 `{id}`） | URL 路径 |
| `page: int = 1` | 查询参数（路径中没有同名参数） | `?page=1` |
| `body: SomeModel` | 请求体（Pydantic 模型） | POST body JSON |
| `db = Depends(get_db)` | 依赖注入 | 调用 `get_db()` |

FastAPI 做这些推断不需要任何额外配置——全靠函数签名。

### 处理函数的返回值

```python
async def handler():
    return {"key": "value"}    # dict → JSON
    return "plain text"        # str → text/plain
    return SomeModel(...)      # Pydantic → JSON（配合 response_model）
    return HTMLResponse("...") # 直接返回指定响应类型
```

FastAPI 自动把 dict/list/Pydantic 模型转为 JSON；如果返回的是 `Response` 子类（如 `HTMLResponse`），则原样返回。

### 和依赖注入的关系

依赖注入发生在处理函数执行之前：FastAPI 先调用所有 `Depends()` 依赖项，把返回值注入形参，**然后**才执行函数体。如果依赖项抛异常，函数体根本不会执行——请求直接返回错误。

### 生命周期

```
请求到达 → FastAPI 查路由表匹配装饰器 → 解析参数注入形参 → 执行函数体 → return 值自动序列化 → 响应返回
```
